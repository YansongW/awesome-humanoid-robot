## 概述

世界模型 / WAM 构建（World Model/WAM Construction）是人形机器人产品开发流程 P12 阶段（VLA / WAM / AI 算法集成）下的三级工序节点，编号 P12.3.1。它通过视频生成模型、动力学模型、神经辐射场与 MPC 的结合，构建能预测动作后果的决策内核，支持长程规划与风险预判。它真正改变的不是单个预测算法的精度，而是让机器人从"感知-反应"的反射式控制升级为"预测-规划"的主动式决策。

## 核心内容

### 是什么：准确定义

世界模型 / WAM 构建是 P12.3「世界模型与人机交互」工作包下的首个三级子任务，属于方法（method）类型，归属领域为 `07_ai_models_algorithms`，价值链层级为 `intelligence`。它不是一个单一算法，而是一组工程化流程的集合：从输入梳理与目标量化开始，经过算法/控制方案设计、算法实现与仿真验证、算法调参与性能验证，最终以文档输出与下游交付收尾。

该工序节点的核心方法/工具组合为：**视频生成模型、动力学模型、神经辐射场、MPC 结合**。设计思考逻辑是"预测动作后果，支持长程规划与风险预判"；关键约束包括模型幻觉、计算开销、预测时域；完成标准/输出物为"世界模型预测能力演示、预测误差指标"。

### 为什么存在：痛点与历史定位

在人形机器人产品化进程中，传统控制方法（如纯 MPC 或强化学习）面临一个根本性困境：**它们只能对"当前状态"做出反应，无法对"未来状态"进行推演**。这导致机器人在面对长程任务（如"把客厅收拾干净"）时，缺乏将粗粒度指令分解为细粒度子任务并预判后果的能力。

世界模型 / WAM 构建正是为解决这一痛点而存在。它位于 P12 阶段的决策核心位置，上游承接感知栈（P12.1）输出的场景理解结果，下游为 VLA 与操作策略（P12.2）提供预测性先验。它的历史定位在于：将 AI 能力从"实验室演示"变成"可验收的工程交付物"——通过标准化的五步法（输入梳理→方案设计→实施/原型→验证闭环→文档交付），让世界模型的预测能力可量化、可追溯、可交付。

### 原理拆解

**① 预测即规划：世界模型的核心逻辑**

世界模型的核心思想是：**如果机器人能预测动作的未来后果，它就能在真实执行之前进行"心智演练"**。这一逻辑通过以下公式形式化表达：

$$
\hat{s}_{t+1} = f_{\theta}(s_t, a_t) \quad \Rightarrow \quad \pi^*(a_t) = \arg\max_{a_t} \sum_{k=0}^{H} \gamma^k \, r(\hat{s}_{t+k}, a_{t+k})
$$

其中 $f_{\theta}$ 是学习到的世界模型（由视频生成模型、动力学模型或神经辐射场实现），$H$ 是预测时域，$\gamma$ 是折扣因子。该公式表明：最优动作 $\pi^*$ 不是直接由当前状态决定，而是通过"预测未来状态序列 → 评估累积回报"的推演过程得出。

**② 多模态融合：视频生成 + 动力学 + 神经辐射场**

- **视频生成模型**负责预测像素级未来帧，提供视觉层面的后果预演；
- **动力学模型**负责预测物理量（位置、速度、接触力），提供力学层面的后果推演；
- **神经辐射场（NeRF）**负责隐式场景表征，提供几何与外观的连续建模；
- **MPC（模型预测控制）**作为优化引擎，在预测时域内求解最优控制序列。

这四者的结合形成了"视觉-物理-几何-控制"的闭环预测链。工程判断：在实际部署中，视频生成模型的计算开销最大，因此通常以较低频率运行（如 1–5 Hz），而动力学模型与 MPC 以较高频率运行（如 50–100 Hz），形成"粗预测 + 细控制"的分层架构。

### 谁在用·应用案例

**案例一：DSWAM 双系统世界动作模型**（关联实体 `ent_paper_dswam_a_dual_system_world_acti_2026`）

DSWAM 通过双系统架构解决了现有 World Action Models 在复杂多步家庭任务中缺乏语言级规划接口的问题。其 System 1 作为默认控制路径，基于世界感知进行动作生成；System 2 仅在需要任务分解时激活，从短期视觉历史和全局任务提示中预测可执行的子任务。这一设计正是 P12.3.1 中"预测动作后果，支持长程规划"的典型实现。

**案例二：WAM-TTT 测试时训练**（关联实体 `ent_paper_wam_ttt_steering_world_action_2026`）

WAM-TTT 将人类视频作为自适应记忆融入冻结的 WAM 中，通过自监督视频预测任务将其编码进轻量级键-值记忆模块。测试时仅需未标注的人类视频即可更新记忆，无需额外机器人演示或任务微调。这体现了 P12.3.1 中"输入梳理与目标量化"的工程智慧——将人类视频这一上游输入转化为可量化的记忆更新目标。

**案例三：CLASP 接触约束形状精化**（关联实体 `ent_paper_saund_clasp_constrained_latent_shape_2021`）

CLASP 在变分形状网络的隐空间中维护粒子滤波器，通过将粒子投影到接触流形上，确保生成的形状同时符合网络先验与接触信息。这展示了世界模型如何利用多模态感知（视觉 + 触觉）来精化环境状态估计，与 P12.3.1 中"神经辐射场"的几何建模目标高度契合。

### 局限与边界

1. **模型幻觉**：世界模型预测的未来状态可能与真实物理不符，尤其在长预测时域下误差累积显著。工程判断：需通过预测误差指标（完成标准之一）进行量化监控，并在超出容忍阈值时回退到保守控制策略。

2. **计算开销**：视频生成模型与神经辐射场的推理成本极高，难以在嵌入式平台上实时运行。工程判断：需采用分层架构（低频粗预测 + 高频细控制）或模型压缩技术（如 TensorRT 加速，见 DSWAM 案例）。

3. **预测时域受限**：受计算开销与误差累积的双重约束，预测时域 H 通常无法覆盖完整的长程任务。工程判断：需结合任务分解（如 DSWAM 的 System 2）将长程任务拆解为短时域可预测的子任务序列。

4. **数据依赖**：世界模型的训练需要大量配对的人-机器人数据或高质量仿真数据，数据稀缺是实际部署的主要瓶颈。

### 常见误区

1. **"世界模型就是视频预测模型"**——错。视频生成只是世界模型的一种实现工具，完整的 WAM 构建还需结合动力学模型、神经辐射场与 MPC 优化，形成"预测-评估-决策"的闭环。

2. **"预测误差越小越好"**——不完全是。过拟合于训练分布的"完美预测"反而会降低泛化能力。工程判断：应关注预测误差在典型/极端工况下的分布特性，而非单纯追求均值最小化。

3. **"MPC 与世界模型是竞争关系"**——错。在 P12.3.1 的方法组合中，MPC 是世界模型的优化引擎，二者是协作关系：世界模型提供预测，MPC 在预测时域内求解最优控制序列。

4. **"仿真验证通过就等于产品可用"**——错。P12.3.1.3 的仿真验证仅证明功能正确性，P12.3.1.4 的调参与性能验证才是确保典型/极端工况下满足指标的关键环节。

## Overview

World Model/WAM Construction is a third-level process node under the P12 phase (VLA / WAM / AI algorithm integration) of the humanoid robot product development process, numbered P12.3.1. It combines video generation models, dynamics models, neural radiance fields, and MPC to build a decision-making core that can predict action consequences, supporting long-horizon planning and risk anticipation. What it truly changes is not the accuracy of a single prediction algorithm, but rather upgrading the robot from reflexive "perception-reaction" control to proactive "prediction-planning" decision-making.

## Content

### What It Is: Precise Definition

World Model/WAM Construction is the first third-level subtask under the P12.3 "World Model and Human-Robot Interaction" work package. It is of the method type, belongs to the domain `07_ai_models_algorithms`, and sits at the `intelligence` level of the value chain. It is not a single algorithm but a collection of engineered processes: starting from input organization and goal quantification, proceeding through algorithm/control scheme design, algorithm implementation and simulation verification, algorithm tuning and performance validation, and finally concluding with documentation output and downstream delivery.

The core method/tool combination for this process node is: **video generation models, dynamics models, neural radiance fields, MPC integration**. The design rationale is "predict action consequences, support long-horizon planning and risk anticipation"; key constraints include model hallucination, computational overhead, and prediction horizon; the completion criteria/deliverables are "world model prediction capability demonstration, prediction error metrics."

### Why It Exists: Pain Points and Historical Positioning

In the humanoid robot productization process, traditional control methods (such as pure MPC or reinforcement learning) face a fundamental dilemma: **they can only react to the "current state" and cannot reason about the "future state."** This leaves robots lacking the ability to decompose coarse-grained instructions into fine-grained subtasks and anticipate consequences when facing long-horizon tasks (e.g., "tidy up the living room").

World Model/WAM Construction exists precisely to address this pain point. It sits at the decision-making core of the P12 phase, receiving scene understanding results from the upstream perception stack (P12.1) and providing predictive priors to the downstream VLA and manipulation policies (P12.2). Its historical positioning lies in transforming AI capabilities from "laboratory demonstrations" into "auditable engineering deliverables"—through a standardized five-step method (input organization → scheme design → implementation/prototype → validation loop → documentation delivery), making the predictive capability of world models quantifiable, traceable, and deliverable.

### Principle Breakdown

**① Prediction as Planning: The Core Logic of World Models**

The core idea of a world model is: **if a robot can predict the future consequences of its actions, it can perform "mental rehearsal" before actual execution.** This logic is formalized by the following formula:

$$
\hat{s}_{t+1} = f_{\theta}(s_t, a_t) \quad \Rightarrow \quad \pi^*(a_t) = \arg\max_{a_t} \sum_{k=0}^{H} \gamma^k \, r(\hat{s}_{t+k}, a_{t+k})
$$

where $f_{\theta}$ is the learned world model (implemented by video generation models, dynamics models, or neural radiance fields), $H$ is the prediction horizon, and $\gamma$ is the discount factor. This formula shows that the optimal action $\pi^*$ is not directly determined by the current state, but derived through the reasoning process of "predicting future state sequences → evaluating cumulative reward."

**② Multimodal Fusion: Video Generation + Dynamics + Neural Radiance Fields**

- **Video generation models** predict pixel-level future frames, providing visual consequence rehearsal;
- **Dynamics models** predict physical quantities (position, velocity, contact forces), providing mechanical consequence reasoning;
- **Neural radiance fields (NeRF)** provide implicit scene representation, offering continuous modeling of geometry and appearance;
- **MPC (Model Predictive Control)** serves as the optimization engine, solving for the optimal control sequence within the prediction horizon.

The combination of these four forms a closed-loop prediction chain of "vision-physics-geometry-control." Engineering judgment: in actual deployment, video generation models incur the highest computational cost and therefore typically run at lower frequencies (e.g., 1–5 Hz), while dynamics models and MPC run at higher frequencies (e.g., 50–100 Hz), forming a hierarchical architecture of "coarse prediction + fine control."

### Who Uses It · Application Cases

**Case 1: DSWAM Dual-System World Action Model** (related entity `ent_paper_dswam_a_dual_system_world_acti_2026`)

DSWAM addresses the lack of language-level planning interfaces in existing World Action Models for complex multi-step household tasks through a dual-system architecture. Its System 1 serves as the default control path, generating actions based on world perception; System 2 activates only when task decomposition is needed, predicting executable subtasks from short-term visual history and global task prompts. This design is a typical implementation of "predict action consequences, support long-horizon planning" in P12.3.1.

**Case 2: WAM-TTT Test-Time Training** (related entity `ent_paper_wam_ttt_steering_world_action_2026`)

WAM-TTT incorporates human videos as adaptive memory into a frozen WAM, encoding them into a lightweight key-value memory module through self-supervised video prediction tasks. At test time, only unlabeled human videos are needed to update the memory, without requiring additional robot demonstrations or task fine-tuning. This reflects the engineering wisdom of "input organization and goal quantification" in P12.3.1—transforming human videos, an upstream input, into quantifiable memory update objectives.

**Case 3: CLASP Contact-Constrained Shape Refinement** (related entity `ent_paper_saund_clasp_constrained_latent_shape_2021`)

CLASP maintains a particle filter in the latent space of a variational shape network, projecting particles onto the contact manifold to ensure generated shapes conform to both network priors and contact information. This demonstrates how world models leverage multimodal perception (vision + touch) to refine environment state estimation, closely aligning with the geometric modeling goals of "neural radiance fields" in P12.3.1.

### Limitations and Boundaries

1. **Model hallucination**: Future states predicted by world models may not match physical reality, with error accumulation becoming significant especially over long prediction horizons. Engineering judgment: quantitative monitoring via prediction error metrics (one of the completion criteria) is required, with fallback to conservative control strategies when exceeding tolerance thresholds.

2. **Computational overhead**: The inference cost of video generation models and neural radiance fields is extremely high, making real-time execution on embedded platforms difficult. Engineering judgment: hierarchical architectures (low-frequency coarse prediction + high-frequency fine control) or model compression techniques (such as TensorRT acceleration, see the DSWAM case) are needed.

3. **Limited prediction horizon**: Constrained by both computational overhead and error accumulation, the prediction horizon H typically cannot cover complete long-horizon tasks. Engineering judgment: task decomposition (such as DSWAM's System 2) is needed to break long-horizon tasks into subtask sequences predictable within short horizons.

4. **Data dependency**: Training world models requires large amounts of paired human-robot data or high-quality simulation data, with data scarcity being a primary bottleneck in actual deployment.

### Common Misconceptions

1. **"A world model is just a video prediction model"**—Wrong. Video generation is only one implementation tool for world models; complete WAM construction also requires integrating dynamics models, neural radiance fields, and MPC optimization to form a closed loop of "prediction-evaluation-decision."

2. **"The smaller the prediction error, the better"**—Not entirely. "Perfect prediction" that overfits the training distribution can actually reduce generalization capability. Engineering judgment: focus on the distribution characteristics of prediction errors under typical/extreme conditions rather than simply minimizing the mean.

3. **"MPC and world models are competitors"**—Wrong. In the method combination of P12.3.1, MPC is the optimization engine for world models; the two are collaborative: world models provide predictions, and MPC solves for the optimal control sequence within the prediction horizon.

4. **"Passing simulation verification means the product is ready"**—Wrong. The simulation verification in P12.3.1.3 only proves functional correctness; the tuning and performance validation in P12.3.1.4 is the critical step ensuring metrics are met under typical/extreme conditions.

## 개요

세계 모델 / WAM 구축(World Model/WAM Construction)은 휴머노이드 로봇 제품 개발 프로세스 P12 단계(VLA / WAM / AI 알고리즘 통합)의 3차 공정 노드로, 번호는 P12.3.1입니다. 비디오 생성 모델, 동역학 모델, 신경 방사 필드(NeRF)와 MPC를 결합하여 행동의 결과를 예측할 수 있는 의사결정 커널을 구축하며, 장기 계획과 위험 사전 예측을 지원합니다. 이것이 실제로 바꾸는 것은 단일 예측 알고리즘의 정확도가 아니라, 로봇이 '지각-반응'의 반사적 제어에서 '예측-계획'의 능동적 의사결정으로 업그레이드되도록 하는 것입니다.

## 핵심 내용

### 무엇인가: 정확한 정의

세계 모델 / WAM 구축은 P12.3 '세계 모델 및 인간-로봇 상호작용' 작업 패키지의 첫 번째 3차 하위 작업으로, 방법(method) 유형에 속하며, 소속 도메인은 `07_ai_models_algorithms`, 가치 사슬 계층은 `intelligence`입니다. 이것은 단일 알고리즘이 아니라 일련의 엔지니어링 프로세스 집합입니다: 입력 정리 및 목표 정량화에서 시작하여, 알고리즘/제어 방안 설계, 알고리즘 구현 및 시뮬레이션 검증, 알고리즘 튜닝 및 성능 검증을 거쳐, 최종적으로 문서 출력 및 하류 전달로 마무리됩니다.

이 공정 노드의 핵심 방법/도구 조합은: **비디오 생성 모델, 동역학 모델, 신경 방사 필드, MPC 결합**입니다. 설계 사고 논리는 '행동 결과 예측, 장기 계획 및 위험 사전 예측 지원'이며, 핵심 제약 조건은 모델 환각, 계산 비용, 예측 시간 영역을 포함합니다. 완료 기준/산출물은 '세계 모델 예측 능력 시연, 예측 오차 지표'입니다.

### 왜 존재하는가: 문제점과 역사적 위치

휴머노이드 로봇 제품화 과정에서 전통적 제어 방법(순수 MPC 또는 강화 학습 등)은 근본적인 딜레마에 직면합니다: **현재 상태에만 반응할 수 있고, 미래 상태를 추론할 수 없습니다**. 이로 인해 로봇은 장기 작업(예: '거실 청소하기')을 수행할 때, 거친 명령을 세분화된 하위 작업으로 분해하고 결과를 사전 예측하는 능력이 부족합니다.

세계 모델 / WAM 구축은 바로 이 문제점을 해결하기 위해 존재합니다. P12 단계의 의사결정 핵심 위치에 있으며, 상류는 지각 스택(P12.1)이 출력하는 장면 이해 결과를 받고, 하류는 VLA 및 조작 전략(P12.2)에 예측적 사전 정보를 제공합니다. 역사적 위치는 AI 능력을 '실험실 시연'에서 '검증 가능한 엔지니어링 산출물'로 전환하는 것입니다 — 표준화된 5단계 방법(입력 정리 → 방안 설계 → 구현/프로토타입 → 검증 폐루프 → 문서 전달)을 통해 세계 모델의 예측 능력을 정량화하고, 추적 가능하며, 전달 가능하게 만듭니다.

### 원리 분해

**① 예측이 곧 계획: 세계 모델의 핵심 논리**

세계 모델의 핵심 아이디어는: **로봇이 행동의 미래 결과를 예측할 수 있다면, 실제 실행 전에 '정신적 시뮬레이션'을 수행할 수 있다**는 것입니다. 이 논리는 다음 공식으로 형식화됩니다:

$$
\hat{s}_{t+1} = f_{\theta}(s_t, a_t) \quad \Rightarrow \quad \pi^*(a_t) = \arg\max_{a_t} \sum_{k=0}^{H} \gamma^k \, r(\hat{s}_{t+k}, a_{t+k})
$$

여기서 $f_{\theta}$는 학습된 세계 모델(비디오 생성 모델, 동역학 모델 또는 신경 방사 필드로 구현), $H$는 예측 시간 영역, $\gamma$는 할인 계수입니다. 이 공식은 최적 행동 $\pi^*$가 현재 상태에 의해 직접 결정되는 것이 아니라, '미래 상태 시퀀스 예측 → 누적 보상 평가'의 추론 과정을 통해 도출됨을 보여줍니다.

**② 다중 모달 융합: 비디오 생성 + 동역학 + 신경 방사 필드**

- **비디오 생성 모델**은 픽셀 수준의 미래 프레임을 예측하여 시각적 결과 예행연습을 제공합니다;
- **동역학 모델**은 물리량(위치, 속도, 접촉력)을 예측하여 역학적 결과 추론을 제공합니다;
- **신경 방사 필드(NeRF)**는 암시적 장면 표현을 담당하여 기하학과 외관의 연속적 모델링을 제공합니다;
- **MPC(모델 예측 제어)**는 최적화 엔진으로, 예측 시간 영역 내에서 최적 제어 시퀀스를 해결합니다.

이 네 가지의 결합은 '시각-물리-기하-제어'의 폐루프 예측 체인을 형성합니다. 엔지니어링 판단: 실제 배포에서 비디오 생성 모델의 계산 비용이 가장 크므로, 일반적으로 낮은 주파수(예: 1–5 Hz)로 실행되고, 동역학 모델과 MPC는 높은 주파수(예: 50–100 Hz)로 실행되어 '거친 예측 + 세밀한 제어'의 계층 구조를 형성합니다.

### 사용자·적용 사례

**사례 1: DSWAM 이중 시스템 세계 행동 모델** (관련 엔티티 `ent_paper_dswam_a_dual_system_world_acti_2026`)

DSWAM은 이중 시스템 아키텍처를 통해 기존 World Action Models가 복잡한 다단계 가정 작업에서 언어 수준 계획 인터페이스가 부족한 문제를 해결합니다. System 1은 기본 제어 경로로, 세계 지각을 기반으로 행동을 생성합니다; System 2는 작업 분해가 필요할 때만 활성화되어, 단기 시각 기록과 전역 작업 프롬프트에서 실행 가능한 하위 작업을 예측합니다. 이 설계는 P12.3.1의 '행동 결과 예측, 장기 계획 지원'의 전형적인 구현입니다.

**사례 2: WAM-TTT 테스트 시 훈련** (관련 엔티티 `ent_paper_wam_ttt_steering_world_action_2026`)

WAM-TTT는 인간 비디오를 적응형 메모리로 고정된 WAM에 통합하고, 자기 지도 비디오 예측 작업을 통해 이를 경량 키-값 메모리 모듈에 인코딩합니다. 테스트 시에는 주석이 없는 인간 비디오만으로 메모리를 업데이트할 수 있으며, 추가 로봇 시연이나 작업 미세 조정이 필요 없습니다. 이는 P12.3.1의 '입력 정리 및 목표 정량화'의 엔지니어링 지혜를 보여줍니다 — 인간 비디오라는 상류 입력을 정량화 가능한 메모리 업데이트 목표로 전환합니다.

**사례 3: CLASP 접촉 제약 형상 정밀화** (관련 엔티티 `ent_paper_saund_clasp_constrained_latent_shape_2021`)

CLASP는 변분 형상 네트워크의 잠재 공간에서 입자 필터를 유지하고, 입자를 접촉 다양체에 투영하여 생성된 형상이 네트워크 사전 정보와 접촉 정보를 동시에 충족하도록 보장합니다. 이는 세계 모델이 다중 모달 지각(시각 + 촉각)을 활용하여 환경 상태 추정을 정밀화하는 방법을 보여주며, P12.3.1의 '신경 방사 필드'의 기하학적 모델링 목표와 높은 일치를 보입니다.

### 한계와 경계

1. **모델 환각**: 세계 모델이 예측한 미래 상태는 실제 물리와 일치하지 않을 수 있으며, 특히 긴 예측 시간 영역에서 오차 누적이 두드러집니다. 엔지니어링 판단: 예측 오차 지표(완료 기준 중 하나)를 통해 정량적 모니터링을 수행하고, 허용 임계값을 초과할 경우 보수적 제어 전략으로 회귀해야 합니다.

2. **계산 비용**: 비디오 생성 모델과 신경 방사 필드의 추론 비용이 매우 높아, 임베디드 플랫폼에서 실시간 실행이 어렵습니다. 엔지니어링 판단: 계층 구조(저주파 거친 예측 + 고주파 세밀한 제어) 또는 모델 압축 기술(예: TensorRT 가속, DSWAM 사례 참조)을 채택해야 합니다.

3. **예측 시간 영역 제한**: 계산 비용과 오차 누적의 이중 제약으로 인해, 예측 시간 영역 H는 일반적으로 전체 장기 작업을 포괄할 수 없습니다. 엔지니어링 판단: 작업 분해(예: DSWAM의 System 2)를 결합하여 장기 작업을 단기 시간 영역에서 예측 가능한 하위 작업 시퀀스로 분해해야 합니다.

4. **데이터 의존성**: 세계 모델 훈련에는 대량의 쌍을 이루는 인간-로봇 데이터 또는 고품질 시뮬레이션 데이터가 필요하며, 데이터 희소성은 실제 배포의 주요 병목입니다.

### 일반적인 오해

1. **'세계 모델은 비디오 예측 모델이다'** — 틀렸습니다. 비디오 생성은 세계 모델의 한 구현 도구일 뿐이며, 완전한 WAM 구축은 동역학 모델, 신경 방사 필드 및 MPC 최적화를 결합하여 '예측-평가-의사결정'의 폐루프를 형성해야 합니다.

2. **'예측 오차가 작을수록 좋다'** — 완전히 맞지는 않습니다. 훈련 분포에 과적합된 '완벽한 예측'은 오히려 일반화 능력을 저하시킵니다. 엔지니어링 판단: 일반/극한 조건에서의 예측 오차 분포 특성에 주목해야 하며, 단순히 평균 최소화를 추구해서는 안 됩니다.

3. **'MPC와 세계 모델은 경쟁 관계다'** — 틀렸습니다. P12.3.1의 방법 조합에서 MPC는 세계 모델의 최적화 엔진이며, 둘은 협력 관계입니다: 세계 모델은 예측을 제공하고, MPC는 예측 시간 영역 내에서 최적 제어 시퀀스를 해결합니다.

4. **'시뮬레이션 검증 통과 = 제품 사용 가능'** — 틀렸습니다. P12.3.1.3의 시뮬레이션 검증은 기능적 정확성만 증명하며, P12.3.1.4의 튜닝 및 성능 검증이 일반/극한 조건에서 지표를 충족하는지 보장하는 핵심 단계입니다.
