## 概述

任务规划（Task Planning）研究如何为高层目标生成可执行的动作序列：经典路线用 PDDL 等形式化语言描述动作的前置条件与效果，以搜索求解；现代路线用大语言模型做任务分解，并用可供性（affordance）函数把"语言上合理"约束为"物理上做得到"——SayCan 的"语言概率 × 物理可行性"是这一思想的极简表达（来源：项目 Wiki 第 20 章 §20.4.1；arXiv:2204.01691）。

## 核心内容

### 是什么：准确定义

任务规划的输入是目标（"把杯子放到桌上"）与世界模型/技能库，输出是技能/动作的时序序列。它处于机器人决策栈的最上层：下层（运动规划、全身控制）回答"怎么动"，任务规划回答"先做什么、再做什么"（来源：项目 Wiki 第 20 章）。

两条技术路线：
- **符号规划**：用 PDDL 描述动作前置条件（precondition）与效果（effect），以 A*、SAT 编码或规划图搜索求解；
- **学习型规划**：用 LLM 的常识直接分解任务，再用价值/可供性函数接地（grounding）。

### 为什么存在：痛点与历史定位

人形机器人走进家庭与工厂，面对的不是单条指令而是**长程目标**："收拾餐桌"隐含取物、开门、放置等十步级依赖。经典符号规划对这类依赖处理自然且正确性可验证，但**领域模型需要人工编写**，符号与连续感知/控制之间的接地鸿沟始终存在——真实场景很难穷举前置条件（Wiki §20.4.1）。

LLM 规划器走了另一条路：常识免费，但会给出"语言合理、物理不可行"的计划。SayCan（Google，2022）的补救成为范式：**让 LLM 提议、让可供性否决**。它真正改变的不是规划算法，而是"知识从哪来"——规划所需的世界常识第一次可以继承自互联网语料而非手工公理。

### 原理拆解

**① 符号规划：PDDL 与搜索**

PDDL 把每个动作描述为前置条件 + 效果，规划器在状态空间中搜索从初态到目标的动作序列。优点是正确性可验证、长程依赖处理自然；缺点是领域模型人工编写、接地鸿沟（Wiki §20.4.1）。

**② SayCan：语言概率 × 物理可行性**

设 LLM 对候选技能 $s$ 给出的语义得分为 $p_{\mathrm{LLM}}(s \mid \ell, \mathrm{context})$，价值/可供性函数给出该技能在当前状态成功完成的概率 $V(s)$，则选择（Wiki §20.4.1）：

$$
s^* = \arg\max_s \; p_{\mathrm{LLM}}(s \mid \ell, \mathrm{context}) \cdot V(s)
$$

LLM 负责"什么步骤在语义上合理"，价值函数负责"机器人此刻做不做的到"——二者相乘，任一项为零即否决。

**③ 神经符号混合与想象推演**

当代系统把符号规划、LLM 分解与世界模型想象组合：LLM 提出候选子目标，世界模型前向滚动评估后果，树搜索组织多步推演（Wiki 第 20 章长期推理部分）。这对应"数据引擎先行、在线规划殿后"的产业节奏。

### 局限与边界

- **符号路线**：领域模型人工编写、接地鸿沟（Wiki §20.4.1）；
- **LLM 路线**：幻觉步骤、无正确性保证、长程一致性弱；
- **可供性函数依赖**：SayCan 式方法的能力上限由价值/可供性函数的准确度决定；
- **闭环重规划成本**：执行失败后的重规划频率与延迟是工程难点（**工程判断**）。

### 常见误区

1. **"LLM 会规划"**——LLM 会"说得像计划"，不等于物理可行；可供性接地不可省。
2. **"符号规划已过时"**——结构化场景（仓库、产线）中其可验证性仍是刚需；混合架构才是现代形态。
3. **"任务规划 = 运动规划"**——前者输出技能序列，后者输出几何/动力学轨迹，是决策栈的不同层。
4. **"规划可以一次性完成"**——开放环境必须闭环重规划；一次性开环计划对扰动零容错。

## Overview

Task Planning studies how to generate executable action sequences for high-level goals: the classical route uses formal languages like PDDL to describe action preconditions and effects, solving via search; the modern route uses large language models for task decomposition and affordance functions to constrain "linguistically plausible" into "physically feasible"—SayCan's "language probability × physical feasibility" is the minimal expression of this idea (Source: Project Wiki Chapter 20 §20.4.1; arXiv:2204.01691).

## Content

### What It Is: Precise Definition

The input to task planning is a goal ("put the cup on the table") and a world model/skill library; the output is a temporal sequence of skills/actions. It sits at the top of the robot decision stack: lower layers (motion planning, whole-body control) answer "how to move," while task planning answers "what to do first, what next" (Source: Project Wiki Chapter 20).

Two technical routes:
- **Symbolic planning**: Uses PDDL to describe action preconditions and effects, solved via A*, SAT encoding, or planning graph search;
- **Learning-based planning**: Uses LLM common sense to decompose tasks directly, then grounds them with value/affordance functions.

### Why It Exists: Pain Points and Historical Positioning

Humanoid robots entering homes and factories face not single commands but **long-horizon goals**: "clear the table" implicitly involves picking objects, opening doors, placing items—ten-step-level dependencies. Classical symbolic planning handles such dependencies naturally with verifiable correctness, but **domain models require manual authoring**, and the grounding gap between symbols and continuous perception/control persists—real-world scenarios make it hard to exhaustively enumerate preconditions (Wiki §20.4.1).

LLM planners took another path: common sense comes free, but they produce plans that are "linguistically reasonable, physically infeasible." SayCan's (Google, 2022) remedy became the paradigm: **let the LLM propose, let affordance veto**. What it truly changed is not the planning algorithm but "where knowledge comes from"—the world common sense needed for planning could, for the first time, be inherited from internet corpora rather than hand-crafted axioms.

### Principle Breakdown

**① Symbolic Planning: PDDL and Search**

PDDL describes each action as preconditions + effects; the planner searches the state space for an action sequence from the initial state to the goal. Advantages: verifiable correctness, natural handling of long-horizon dependencies; disadvantages: manually authored domain models, grounding gap (Wiki §20.4.1).

**② SayCan: Language Probability × Physical Feasibility**

Let the LLM's semantic score for candidate skill $s$ be $p_{\mathrm{LLM}}(s \mid \ell, \mathrm{context})$, and the value/affordance function give the probability of that skill succeeding in the current state $V(s)$; then the selection is (Wiki §20.4.1):

$$
s^* = \arg\max_s \; p_{\mathrm{LLM}}(s \mid \ell, \mathrm{context}) \cdot V(s)
$$

The LLM handles "what steps are semantically reasonable," the value function handles "whether the robot can do it right now"—multiplying the two, either being zero results in a veto.

**③ Neuro-Symbolic Hybrids and Imagined Rollouts**

Contemporary systems combine symbolic planning, LLM decomposition, and world model imagination: the LLM proposes candidate subgoals, the world model rolls forward to evaluate consequences, and tree search organizes multi-step reasoning (Wiki Chapter 20, long-term reasoning section). This corresponds to the industrial rhythm of "data engine first, online planning last."

### Who Uses It / Application Cases

- **SayCan** (Google, 2022): The paradigm setter for LLM proposal + affordance veto (arXiv:2204.01691);
- **Humanoid whole-body tasks**: The combination of VLA + task planning is the mainstream "brain-cerebellum" hierarchy for current humanoids (Wiki Chapters 19/20);
- **Neuro-symbolic direction**: The graph `ent_method_neuro_symbolic_reasoning` carries the symbolic + learning hybrid route.

### Limitations and Boundaries

- **Symbolic route**: Manually authored domain models, grounding gap (Wiki §20.4.1);
- **LLM route**: Hallucinated steps, no correctness guarantees, weak long-horizon consistency;
- **Affordance function dependence**: The capability ceiling of SayCan-style methods is determined by the accuracy of the value/affordance function;
- **Closed-loop replanning cost**: Replanning frequency and latency after execution failure are engineering challenges (**engineering judgment**).

### Common Misconceptions

1. **"LLMs can plan"**—LLMs can "talk like a plan," but that does not mean physical feasibility; affordance grounding is indispensable.
2. **"Symbolic planning is outdated"**—In structured scenarios (warehouses, production lines), its verifiability remains a hard requirement; hybrid architectures are the modern form.
3. **"Task planning = motion planning"**—The former outputs skill sequences, the latter outputs geometric/dynamic trajectories; they are different layers of the decision stack.
4. **"Planning can be done once"**—Open environments require closed-loop replanning; one-shot open-loop plans have zero tolerance for disturbances.

## 개요

작업 계획(Task Planning)은 높은 수준의 목표를 위해 실행 가능한 행동 시퀀스를 생성하는 방법을 연구한다: 고전적 접근법은 PDDL과 같은 형식 언어로 행동의 전제 조건과 효과를 기술하고 탐색으로 해결한다; 현대적 접근법은 대규모 언어 모델로 작업을 분해하고, 어포던스(affordance) 함수로 "언어적으로 합리적인" 것을 "물리적으로 실행 가능한" 것으로 제약한다——SayCan의 "언어 확률 × 물리적 실현 가능성"이 이 사상의 가장 간결한 표현이다(출처: 프로젝트 Wiki 20장 §20.4.1; arXiv:2204.01691).

## 핵심 내용

### 무엇인가: 정확한 정의

작업 계획의 입력은 목표("컵을 테이블 위에 놓기")와 세계 모델/스킬 라이브러리이고, 출력은 스킬/행동의 시간적 시퀀스이다. 이는 로봇 의사결정 스택의 최상위에 위치한다: 하위 계층(운동 계획, 전신 제어)은 "어떻게 움직일지"를 담당하고, 작업 계획은 "무엇을 먼저 하고, 무엇을 다음에 할지"를 담당한다(출처: 프로젝트 Wiki 20장).

두 가지 기술 경로:
- **기호 계획(Symbolic Planning)**: PDDL로 행동의 전제 조건(precondition)과 효과(effect)를 기술하고, A*, SAT 인코딩 또는 플래닝 그래프 탐색으로 해결;
- **학습 기반 계획(Learning-based Planning)**: LLM의 상식을 사용해 작업을 직접 분해하고, 가치/어포던스 함수로 접지(grounding)한다.

### 왜 존재하는가:痛点과 역사적 위치

휴머노이드 로봇이 가정과 공장에 들어서면서, 단일 명령이 아닌 **장기 목표**를 마주한다: "식탁 정리"는 물건 집기, 문 열기, 놓기 등 10단계 수준의 의존성을 암시한다. 고전적 기호 계획은 이러한 의존성을 자연스럽고 검증 가능하게 처리하지만, **도메인 모델을 수동으로 작성해야 하며**, 기호와 연속적 지각/제어 사이의 접지 간극이 항상 존재한다——실제 시나리오에서 전제 조건을 완전히 열거하는 것은 어렵다(Wiki §20.4.1).

LLM 플래너는 다른 길을 택했다: 상식은 공짜지만 "언어적으로 합리적이고 물리적으로 불가능한" 계획을 제시한다. SayCan(Google, 2022)의 해결책이 패러다임이 되었다: **LLM이 제안하고, 어포던스가 거부한다**. 이것이 진정으로 바꾼 것은 계획 알고리즘이 아니라 "지식이 어디서 오는가"이다——계획에 필요한 세계 상식이 처음으로 수동 공리가 아닌 인터넷 말뭉치에서 상속될 수 있게 되었다.

### 원리 분석

**① 기호 계획: PDDL과 탐색**

PDDL은 각 행동을 전제 조건 + 효과로 기술하고, 플래너는 상태 공간에서 초기 상태에서 목표까지의 행동 시퀀스를 탐색한다. 장점은 정확성 검증 가능, 장기 의존성 처리의 자연스러움; 단점은 도메인 모델 수동 작성, 접지 간극(Wiki §20.4.1).

**② SayCan: 언어 확률 × 물리적 실현 가능성**

LLM이 후보 스킬 $s$에 대해 제공하는 의미 점수를 $p_{\mathrm{LLM}}(s \mid \ell, \mathrm{context})$, 가치/어포던스 함수가 현재 상태에서 해당 스킬의 성공 확률 $V(s)$를 제공한다고 할 때, 선택은(Wiki §20.4.1):

$$
s^* = \arg\max_s \; p_{\mathrm{LLM}}(s \mid \ell, \mathrm{context}) \cdot V(s)
$$

LLM은 "어떤 단계가 의미적으로 합리적인지"를 담당하고, 가치 함수는 "로봇이 지금 실행할 수 있는지"를 담당한다——둘을 곱하여, 어느 하나가 0이면 거부된다.

**③ 신경-기호 혼합과 상상 추론**

현대 시스템은 기호 계획, LLM 분해, 세계 모델 상상을 결합한다: LLM이 후보 하위 목표를 제안하고, 세계 모델이 전방 롤아웃으로 결과를 평가하며, 트리 탐색이 다단계 추론을 조직한다(Wiki 20장 장기 추론 부분). 이는 "데이터 엔진 선행, 온라인 계획 후행"의 산업적 리듬에 해당한다.

(근거: 프로젝트 Wiki 20장 §20.4.)

### 누가 사용하는가 / 적용 사례

- **SayCan**(Google, 2022): LLM 제안 + 어포던스 거부 패러다임의 확립자(arXiv:2204.01691);
- **휴머노이드 전신 작업**: VLA + 작업 계획의 조합은 현재 휴머노이드 "대뇌-소뇌" 계층 구조의 주류(Wiki 19/20장);
- **신경-기호 방향**: 그래프 `ent_method_neuro_symbolic_reasoning`이 기호와 학습 혼합 경로를 계승.

### 한계와 경계

- **기호 경로**: 도메인 모델 수동 작성, 접지 간극(Wiki §20.4.1);
- **LLM 경로**: 환각 단계, 정확성 보장 없음, 장기 일관성 약함;
- **어포던스 함수 의존성**: SayCan식 방법의 능력 상한은 가치/어포던스 함수의 정확도에 의해 결정됨;
- **폐루프 재계획 비용**: 실행 실패 후 재계획 빈도와 지연은 공학적 난제(**공학적 판단**).

### 흔한 오해

1. **"LLM이 계획한다"**——LLM은 "계획처럼 말할" 뿐, 물리적 실현 가능성과는 다르다; 어포던스 접지는 생략할 수 없다.
2. **"기호 계획은 구식이다"**——구조화된 시나리오(창고, 생산 라인)에서 검증 가능성은 여전히 필수; 혼합 아키텍처가 현대적 형태다.
3. **"작업 계획 = 운동 계획"**——전자는 스킬 시퀀스를 출력하고, 후자는 기하/동역학 궤적을 출력하며, 의사결정 스택의 다른 계층이다.
4. **"계획은 한 번에 완료될 수 있다"**——개방 환경에서는 폐루프 재계획이 필수; 일회성 개루프 계획은 교란에 대해 제로 허용 오차를 가진다.
