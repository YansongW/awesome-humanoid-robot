## 概述
EMC/EMI 设计与测试是电子电气与能源系统（P13）阶段中的三级工序节点，编号 P13.3.2，聚焦于解决大功率电机驱动与高速计算共存场景下的电磁兼容性问题。该方法以屏蔽、滤波、接地、PCB 布局、辐射/传导测试为核心手段，以 CE/FCC/UL 标准为约束边界，最终输出 EMC 设计规范、预测试报告与整改记录。它真正改变的不是"把电路画出来"这件事，而是让机器人的动力系统与计算系统在同一个电磁环境里达成可验证的共存秩序。

## 核心内容

### 是什么：P13.3.2 在开发流程中的定位
P13.3.2 EMC/EMI 设计与测试是 P13 电子电气与能源系统阶段下的三级子任务，属于"intelligence"与"upstream"两个域的交汇处——它既需要智能层面的标准理解与风险预判，又处于上游设计阶段，必须在硬件定型前完成电磁兼容性的系统性规划。

该工序节点遵循 P13 阶段统一的五步工程动作模板，展开为五个四级子任务：输入梳理与目标量化、概念与详细设计、实施/原型/样件制作、测试执行与结果分析、文档输出与下游交付。每个四级子任务下又有若干关键动作，形成从目标定义到交付闭环的完整链条。

该节点的核心交付物包括：EMC 设计规范、预测试报告、整改记录。这些输出物不是"合规证明"的堆砌，而是下游整机集成、认证测试与量产制造的电磁兼容性事实来源——如果预测试报告中的辐射数据不准确，整机认证就会在最后一刻被推翻；如果整改记录不完整，批量生产的每一台机器都可能带着同样的隐患出厂。

### 为什么存在：痛点与历史定位
在人形机器人早期开发中，EMC 设计往往被当作"认证前最后补的作业"，导致三类系统性痛点：

**第一，动力与计算的电磁战争。** 人形机器人同时承载大功率电机驱动与高速计算单元。电机驱动器在 PWM 开关瞬间产生纳秒级上升沿的电压跳变，通过线缆与地平面形成共模电流；而高速计算单元（如应用处理器、DDR 总线、高速串行接口）对电源噪声与地弹极其敏感。两者共存于同一块 PCB 与同一套线束中，若不在设计阶段做电磁隔离与滤波规划，轻则通信误码、传感器漂移，重则系统复位、功能安全失效。

**第二，标准合规的"最后一刻惊魂"。** CE/FCC/UL 等标准对辐射发射、传导发射、抗扰度均有明确限值。若等到整机完成才进行 EMC 测试，发现超标后的整改往往涉及 PCB 改版、线束重新布局、屏蔽结构重新设计——这些改动在量产前期的成本与时间代价极高。P13.3.2 将 EMC 验证前置到设计阶段，通过预测试与仿真提前暴露风险，正是为了把"最后一刻惊魂"转化为"设计阶段的可控迭代"。

**第三，重量与成本的隐性博弈。** 屏蔽罩、磁环、滤波器件、多层 PCB 都是 EMC 的经典手段，但它们同时带来重量增加与成本上升。人形机器人对重量极度敏感——每增加 100 克腿部负载，关节电机就需要额外扭矩，进而推高电池容量与整机重量，形成正反馈循环。P13.3.2 的设计约束中明确列出"重量、成本"与 CE/FCC/UL 标准并列，意味着 EMC 方案必须在合规与轻量化之间寻找工程最优解，而非无限制堆料。

### 原理拆解
**① 电磁干扰的三要素模型**
任何 EMI 问题都包含三个要素：干扰源、耦合路径、敏感设备。在人形机器人场景中：

- **干扰源**：电机驱动器的 PWM 逆变器（开关频率通常在 10–50 kHz，但开关沿的谐波可延伸至数百 MHz）、DC-DC 转换器、高速数字接口。
- **耦合路径**：传导路径（电源线、信号线、地平面）与辐射路径（线缆天线效应、PCB 走线辐射、机箱缝隙泄漏）。
- **敏感设备**：传感器模拟前端、通信收发器、微控制器复位电路、无线模块。

EMC 设计的本质，是在三要素的任意一环切断环路。屏蔽针对辐射路径，滤波针对传导路径，接地则同时影响两者——它决定了共模电流的回流路径与参考电位。

**② 共模与差模：两种必须分开治理的噪声**
$$
I_{\text{CM}} = \frac{V_{\text{CM}}}{Z_{\text{CM}}}, \quad I_{\text{DM}} = \frac{V_{\text{DM}}}{Z_{\text{DM}}}
$$

共模电流（I_CM）是两条导线上的同向电流，通过寄生电容流向大地或参考地，是辐射发射的主要来源；差模电流（I_DM）是信号本身的电流回路，主要影响传导发射。滤波器的设计必须分别针对两者：共模扼流圈对共模呈现高阻抗、对差模几乎无影响；X 电容跨接在火线与零线之间抑制差模，Y 电容连接火线/零线与地之间泄放共模。工程判断：在人形机器人这种电机驱动与数字电路共存的场景中，共模噪声通常比差模噪声更难治理，因为它的路径依赖寄生参数，难以精确建模。

**③ 接地：EMC 的第一原则**
接地不是"把地线接上"那么简单。在 EMC 语境下，接地意味着为所有信号与电源电流提供可控的回流路径。单点接地适用于低频（<1 MHz），多点接地适用于高频（>10 MHz），混合接地则用于宽频场景。人形机器人中，电机驱动属于低频大电流，数字电路属于高频小电流，两者必须分区接地，再在单点汇合，否则高频数字噪声会通过地平面注入模拟与功率电路。

### 横向对比
P13.3.2 与 P13 阶段其他三级子任务（如计算平台架构、PCB 设计、通信总线）相比，具有三个显著差异：

**第一，验证前置性。** PCB 设计关注"把电路做对"，EMC 设计关注"把电路做静"。前者验证的是功能正确性，后者验证的是电磁环境兼容性。EMC 的验证必须依赖预测试与仿真，无法仅通过设计评审确认。

**第二，跨域耦合性。** 计算平台架构决定算力分布，通信总线决定信号拓扑，而 EMC 设计必须同时考虑两者与功率系统的电磁交互。它是 P13 阶段中唯一一个"必须同时理解功率、模拟、数字三个领域"的子任务。

**第三，标准驱动性。** 其他子任务的验收标准主要来自内部功能需求，而 P13.3.2 的验收标准部分来自外部法规（CE/FCC/UL）。这意味着它的"完成"定义不是"功能达标"，而是"合规达标"——两者有时并不一致。

### 谁在用·应用案例
P13.3.2 的直接执行者是硬件工程师与 EMC 工程师，但它的输出物被多个下游环节依赖：

- **整机集成团队**：依据 EMC 设计规范进行线束布局与结构接地设计，确保屏蔽措施在整机层面得到落实。
- **认证测试团队**：依据预测试报告判断正式测试的通过概率，提前准备整改预案。
- **软件团队**：EMC 整改记录中的滤波与屏蔽措施可能影响信号时序与通信协议，软件需要据此调整驱动配置。
- **制造团队**：EMC 设计规范中的 PCB 布局要求与屏蔽件安装方式，直接决定产线的装配工艺与测试工位配置。

典型应用场景：一台全尺寸双足人形机器人在行走测试中频繁出现关节编码器数据跳变。排查发现，电机驱动器的 PWM 开关噪声通过电源线传导至编码器供电端，导致模拟前端饱和。整改措施包括：在驱动器电源输入端增加共模扼流圈、将编码器信号线改为屏蔽双绞线并单端接地、在 PCB 上增加电源与地之间的去耦电容阵列。整改后辐射发射降低约 20 dB（工程判断，具体数值需自行确认），编码器数据恢复稳定。

### 局限与边界
P13.3.2 的边界与局限需要明确：

**第一，预测试不等于正式认证。** 预测试通常在实验室环境进行，测试场地、设备校准、天线系数与正式认证实验室存在差异。预测试通过不代表正式测试必然通过，必须预留裕量（工程判断：通常预留 6 dB 以上裕量）。

**第二，仿真模型的精度有限。** 电磁仿真依赖器件模型、寄生参数与结构建模的准确性。对于人形机器人这种包含大量线束、连接器与运动结构的复杂系统，仿真结果只能作为趋势参考，不能替代实测。

**第三，整改的边际收益递减。** 当 EMC 问题进入整改阶段，每增加一层屏蔽或一个滤波器，带来的改善幅度会逐渐减小，而重量与成本代价持续上升。工程判断：当整改措施超过 3–4 轮仍未达标时，应考虑回到设计源头重新审视布局与滤波架构，而非继续堆料。

**第四，标准的地域差异。** CE（欧洲）、FCC（美国）、UL（美国安全标准）的限值与测试方法并不完全一致。面向全球市场的人形机器人需要同时满足多套标准，这要求设计阶段就采用"最严格限值"作为统一目标。

### 常见误区
1. **"EMC 是测试阶段的事"**——错。EMC 问题的根源在设计阶段就已埋下。PCB 布局、接地策略、滤波拓扑一旦定型，后期整改的成本是指数级上升的。P13.3.2 将 EMC 设计前置到概念与详细设计阶段，正是为了在成本最低的环节解决问题。

2. **"屏蔽越多越好"**——错。屏蔽是 EMC 手段之一，但过度屏蔽会带来重量、成本与散热问题。人形机器人对重量极度敏感，屏蔽方案必须在合规与轻量化之间做工程权衡。更优的路径往往是先优化布局与滤波，再用屏蔽解决残余问题。

3. **"接地就是接大地"**——错。在 EMC 语境下，接地是"为电流提供可控回流路径"。人形机器人是移动平台，通常没有大地参考，所谓"接地"实际是接机壳或接系统地。设计的关键是控制回流路径的阻抗与环路面积，而非物理上连接大地。

4. **"预测试通过就万事大吉"**——错。预测试环境与正式认证环境存在差异，且整机状态（线束布置、结构装配、软件负载）在预测试后可能发生变化。必须预留测试裕量，并在正式测试前进行最终状态确认。

## Overview
EMC/EMI Design and Testing is a third-level process node in the Electronic, Electrical, and Energy Systems (P13) phase, numbered P13.3.2, focusing on solving electromagnetic compatibility issues in scenarios where high-power motor drives and high-speed computing coexist. This method uses shielding, filtering, grounding, PCB layout, and radiated/conducted testing as core measures, with CE/FCC/UL standards as the constraint boundary, ultimately producing an EMC design specification, pre-compliance test report, and rectification records. What it truly changes is not "drawing the circuit," but enabling the robot's power system and computing system to achieve verifiable coexistence order within the same electromagnetic environment.

## Content

### What It Is: Positioning of P13.3.2 in the Development Process
P13.3.2 EMC/EMI Design and Testing is a third-level subtask under the P13 Electronic, Electrical, and Energy Systems phase, situated at the intersection of the "intelligence" and "upstream" domains—it requires both standard understanding and risk prediction at the intelligence level, and, being in the upstream design phase, must complete systematic electromagnetic compatibility planning before hardware is finalized.

This process node follows the unified five-step engineering action template of the P13 phase, expanding into five fourth-level subtasks: input review and target quantification, conceptual and detailed design, implementation/prototype/sample fabrication, test execution and result analysis, and documentation output and downstream delivery. Each fourth-level subtask contains several key actions, forming a complete chain from goal definition to delivery closure.

The core deliverables of this node include: EMC design specification, pre-compliance test report, and rectification records. These outputs are not a pile of "compliance certificates," but rather the source of truth for electromagnetic compatibility for downstream system integration, certification testing, and mass production—if the radiated emission data in the pre-compliance test report is inaccurate, system-level certification will be overturned at the last moment; if the rectification records are incomplete, every unit produced in mass production may leave the factory with the same hidden risks.

### Why It Exists: Pain Points and Historical Positioning
In early humanoid robot development, EMC design was often treated as "homework to be completed at the last minute before certification," leading to three systemic pain points:

**First, the electromagnetic war between power and computing.** Humanoid robots simultaneously carry high-power motor drives and high-speed computing units. Motor drivers generate nanosecond-rise-time voltage transients during PWM switching, forming common-mode currents through cables and ground planes; meanwhile, high-speed computing units (such as application processors, DDR buses, and high-speed serial interfaces) are extremely sensitive to power supply noise and ground bounce. When both coexist on the same PCB and within the same wiring harness, without electromagnetic isolation and filtering planning at the design stage, the consequences range from communication bit errors and sensor drift to system resets and functional safety failures.

**Second, the "last-minute panic" of standards compliance.** Standards such as CE/FCC/UL impose clear limits on radiated emissions, conducted emissions, and immunity. If EMC testing is deferred until the complete system is finished, rectification after discovering violations often involves PCB revisions, wiring harness re-layout, and shielding structure redesign—changes that carry extremely high cost and time penalties in the pre-production phase. P13.3.2 moves EMC verification forward to the design stage, exposing risks early through pre-compliance testing and simulation, precisely to transform "last-minute panic" into "controlled iteration at the design stage."

**Third, the hidden trade-off between weight and cost.** Shielding enclosures, ferrite cores, filtering components, and multilayer PCBs are classic EMC measures, but they simultaneously bring increased weight and cost. Humanoid robots are extremely weight-sensitive—every additional 100 grams of leg load requires extra torque from joint motors, which in turn drives up battery capacity and overall robot weight, creating a positive feedback loop. The design constraints of P13.3.2 explicitly list "weight, cost" alongside CE/FCC/UL standards, meaning that EMC solutions must find the engineering optimum between compliance and lightweight design, rather than unlimited material stacking.

### Principle Breakdown
**① The Three-Element Model of Electromagnetic Interference**
Any EMI problem involves three elements: interference source, coupling path, and susceptible device. In the humanoid robot scenario:

- **Interference sources**: PWM inverters in motor drivers (switching frequencies typically 10–50 kHz, but harmonics of switching edges can extend to hundreds of MHz), DC-DC converters, and high-speed digital interfaces.
- **Coupling paths**: conducted paths (power lines, signal lines, ground planes) and radiated paths (cable antenna effects, PCB trace radiation, chassis seam leakage).
- **Susceptible devices**: sensor analog front-ends, communication transceivers, microcontroller reset circuits, and wireless modules.

The essence of EMC design is to break the loop at any one of the three elements. Shielding targets the radiated path, filtering targets the conducted path, and grounding affects both—it determines the return path of common-mode currents and the reference potential.

**② Common Mode and Differential Mode: Two Types of Noise That Must Be Treated Separately**
$$
I_{\text{CM}} = \frac{V_{\text{CM}}}{Z_{\text{CM}}}, \quad I_{\text{DM}} = \frac{V_{\text{DM}}}{Z_{\text{DM}}}
$$

Common-mode current (I_CM) is the in-phase current on two conductors, flowing to earth or reference ground through parasitic capacitance, and is the primary source of radiated emissions; differential-mode current (I_DM) is the current loop of the signal itself, primarily affecting conducted emissions. Filter design must address each separately: common-mode chokes present high impedance to common mode while having almost no effect on differential mode; X capacitors are connected across line and neutral to suppress differential mode, while Y capacitors connect line/neutral to ground to discharge common mode. Engineering judgment: in scenarios like humanoid robots where motor drives and digital circuits coexist, common-mode noise is typically more difficult to manage than differential-mode noise because its path depends on parasitic parameters that are hard to model precisely.

**③ Grounding: The First Principle of EMC**
Grounding is not simply "connecting the ground wire." In the EMC context, grounding means providing a controlled return path for all signal and power currents. Single-point grounding is suitable for low frequencies (<1 MHz), multi-point grounding for high frequencies (>10 MHz), and hybrid grounding for wideband scenarios. In humanoid robots, motor drives belong to low-frequency high-current, while digital circuits belong to high-frequency low-current; the two must be grounded in separate zones and then joined at a single point; otherwise, high-frequency digital noise will inject into analog and power circuits through the ground plane.

Engineering judgment: EMC testing for complete humanoid robots typically references EN 55011 (industrial equipment) or EN 55032 (multimedia equipment); the applicable standard depends on product classification and target market.

### Horizontal Comparison
Compared with other third-level subtasks in the P13 phase (such as computing platform architecture, PCB design, and communication buses), P13.3.2 has three notable differences:

**First, verification is front-loaded.** PCB design focuses on "making the circuit correct," while EMC design focuses on "making the circuit quiet." The former verifies functional correctness; the latter verifies electromagnetic environment compatibility. EMC verification must rely on pre-compliance testing and simulation and cannot be confirmed through design review alone.

**Second, cross-domain coupling.** Computing platform architecture determines compute distribution, communication buses determine signal topology, and EMC design must simultaneously consider the electromagnetic interaction of both with the power system. It is the only subtask in the P13 phase that "must simultaneously understand the power, analog, and digital domains."

**Third, standards-driven nature.** The acceptance criteria for other subtasks come primarily from internal functional requirements, whereas part of the acceptance criteria for P13.3.2 comes from external regulations (CE/FCC/UL). This means its definition of "complete" is not "functionally adequate" but "compliant"—and the two are not always aligned.

### Who Uses It · Application Cases
The direct executors of P13.3.2 are hardware engineers and EMC engineers, but its outputs are relied upon by multiple downstream links:

- **System integration team**: Uses the EMC design specification for wiring harness layout and structural grounding design, ensuring shielding measures are implemented at the system level.
- **Certification testing team**: Uses the pre-compliance test report to assess the probability of passing formal testing and prepares rectification contingency plans in advance.
- **Software team**: Filtering and shielding measures in the EMC rectification records may affect signal timing and communication protocols, requiring software to adjust driver configurations accordingly.
- **Manufacturing team**: PCB layout requirements and shielding component installation methods in the EMC design specification directly determine the assembly process and test station configuration on the production line.

Typical application scenario: a full-size bipedal humanoid robot frequently experienced joint encoder data glitches during walking tests. Investigation revealed that PWM switching noise from the motor driver conducted through the power line to the encoder supply terminal, saturating the analog front-end. Rectification measures included: adding a common-mode choke at the driver power input, changing encoder signal lines to shielded twisted pair with single-ended grounding, and adding decoupling capacitor arrays between power and ground on the PCB. After rectification, radiated emissions were reduced by approximately 20 dB (engineering judgment; specific values need independent confirmation), and encoder data returned to stability.

### Limitations and Boundaries
The boundaries and limitations of P13.3.2 need to be clarified:

**First, pre-compliance testing is not equivalent to formal certification.** Pre-compliance testing is typically conducted in a laboratory environment, where test site, equipment calibration, and antenna factors differ from formal certification laboratories. Passing pre-compliance testing does not guarantee passing formal testing; margin must be reserved (engineering judgment: typically 6 dB or more of margin).

**Second, the accuracy of simulation models is limited.** Electromagnetic simulation depends on the accuracy of device models, parasitic parameters, and structural modeling. For complex systems like humanoid robots containing numerous wiring harnesses, connectors, and moving structures, simulation results can only serve as trend references and cannot replace actual measurements.

**Third, diminishing marginal returns from rectification.** When EMC issues enter the rectification phase, each additional layer of shielding or filter yields progressively smaller improvements while weight and cost penalties continue to rise. Engineering judgment: if rectification measures have not achieved compliance after 3–4 rounds, one should return to the design source and re-examine layout and filtering architecture rather than continuing to add materials.

**Fourth, regional differences in standards.** The limits and test methods of CE (Europe), FCC (US), and UL (US safety standard) are not fully consistent. Humanoid robots targeting the global market must simultaneously satisfy multiple standards, requiring the design phase to adopt the "strictest limits" as a unified target.

### Common Misconceptions
1. **"EMC is a testing-phase matter"**—Wrong. The root causes of EMC problems are already embedded during the design phase. Once PCB layout, grounding strategy, and filtering topology are finalized, the cost of later rectification rises exponentially. P13.3.2 front-loads EMC design into the conceptual and detailed design phases precisely to solve problems at the stage where cost is lowest.

2. **"The more shielding, the better"**—Wrong. Shielding is one EMC measure, but excessive shielding brings weight, cost, and thermal issues. Humanoid robots are extremely weight-sensitive, so shielding solutions must involve engineering trade-offs between compliance and lightweight design. The better path is often to optimize layout and filtering first, then use shielding to address residual issues.

3. **"Grounding means connecting to earth ground"**—Wrong. In the EMC context, grounding means "providing a controlled return path for current." Humanoid robots are mobile platforms and typically have no earth reference; so-called "grounding" actually means connecting to the chassis or system ground. The key to design is controlling the impedance and loop area of the return path, not physically connecting to earth.

4. **"Passing pre-compliance testing means everything is fine"**—Wrong. The pre-compliance environment differs from the formal certification environment, and the complete system state (wiring harness arrangement, structural assembly, software load) may change after pre-compliance testing. Test margin must be reserved, and final state confirmation must be performed before formal testing.

### 무엇인가: P13.3.2의 개발 프로세스 내 위치
P13.3.2 EMC/EMI 설계 및 테스트는 P13 전자전기 및 에너지 시스템 단계의 3차 하위 작업으로, "intelligence"와 "upstream" 두 영역의 교차점에 위치합니다——지능적 차원의 표준 이해와 위험 예측이 필요하면서도, 업스트림 설계 단계에 있어 하드웨어 확정 전에 전자기 적합성의 체계적 계획을 완료해야 합니다.

이 공정 노드는 P13 단계의 통일된 5단계 엔지니어링 액션 템플릿을 따르며, 5개의 4차 하위 작업으로 전개됩니다: 입력 정리 및 목표 정량화, 개념 및 상세 설계, 구현/프로토타입/시제품 제작, 테스트 실행 및 결과 분석, 문서 출력 및 다운스트림 인도. 각 4차 하위 작업 아래에는 여러 핵심 액션이 있어 목표 정의부터 인도까지의 완결된 체인을 형성합니다.

이 노드의 핵심 산출물은 EMC 설계 규격, 사전 테스트 보고서, 시정 기록입니다. 이러한 출력물은 "적합성 증명"의 단순 나열이 아니라, 다운스트림 전체 시스템 통합, 인증 테스트, 양산 제조의 전자기 적합성 사실 소스입니다——사전 테스트 보고서의 방사 데이터가 부정확하면 전체 시스템 인증이 마지막 순간에 무너질 수 있고, 시정 기록이 불완전하면 양산되는 모든 기기가 동일한 잠재적 결함을 안고 출고될 수 있습니다.

### 왜 존재하는가:痛点과 역사적 위치
휴머노이드 로봇 초기 개발에서 EMC 설계는 종종 "인증 직전에 마지막으로 보충하는 숙제"로 취급되어, 세 가지 유형의 체계적痛点을 초래했습니다:

**첫째, 동력과 컴퓨팅의 전자기 전쟁.** 휴머노이드 로봇은 대전력 모터 구동과 고속 컴퓨팅 유닛을 동시에 탑재합니다. 모터 드라이버는 PWM 스위칭 순간에 나노초급 상승 에지의 전압 점프를 생성하며, 케이블과 접지 평면을 통해 공통 모드 전류를 형성합니다. 반면 고속 컴퓨팅 유닛(애플리케이션 프로세서, DDR 버스, 고속 직렬 인터페이스 등)은 전원 노이즈와 접지 바운스에 매우 민감합니다. 둘 다 동일한 PCB와 동일한 와이어 하네스에 공존하므로, 설계 단계에서 전자기 격리와 필터링 계획을 하지 않으면 가벼운 경우 통신 오류, 센서 드리프트, 심한 경우 시스템 리셋, 기능 안전 실패가 발생합니다.

**둘째, 표준 적합성의 "마지막 순간의 공포".** CE/FCC/UL 등 표준은 방사 방출, 전도 방출, 내성에 대해 명확한 한계값을 규정합니다. 전체 시스템 완성 후에 EMC 테스트를 수행하면, 한계 초과 발견 후의 시정은 종종 PCB 개정, 와이어 하네스 재배치, 차폐 구조 재설계를 수반합니다——이러한 변경은 양산 초기 단계에서 비용과 시간 측면에서 매우 높습니다. P13.3.2는 EMC 검증을 설계 단계로 앞당기고, 사전 테스트와 시뮬레이션을 통해 위험을 조기에 노출시켜 "마지막 순간의 공포"를 "설계 단계의 통제 가능한 반복"으로 전환하는 것입니다.

**셋째, 무게와 비용의 은밀한 게임.** 차폐 커버, 페라이트 코어, 필터 부품, 다층 PCB는 모두 EMC의 전형적인 수단이지만, 동시에 무게 증가와 비용 상승을 초래합니다. 휴머노이드 로봇은 무게에 극도로 민감합니다——다리 부하가 100그램 증가할 때마다 관절 모터는 추가 토크가 필요하고, 이는 배터리 용량과 전체 무게를 끌어올려 정(+)의 피드백 루프를 형성합니다. P13.3.2의 설계 제약에는 "무게, 비용"이 CE/FCC/UL 표준과 나란히 명시되어 있어, EMC 솔루션이 적합성과 경량화 사이에서 공학적 최적해를 찾아야 하며, 무제한적인 부품 추가가 아님을 의미합니다.

### 원리 분해
**① 전자기 간섭의 3요소 모델**
모든 EMI 문제는 세 가지 요소를 포함합니다: 간섭원, 결합 경로, 민감 장치. 휴머노이드 로봇 시나리오에서:

- **간섭원**: 모터 드라이버의 PWM 인버터(스위칭 주파수는 일반적으로 10–50 kHz이지만, 스위칭 에지의 고조파는 수백 MHz까지 확장 가능), DC-DC 컨버터, 고속 디지털 인터페이스.
- **결합 경로**: 전도 경로(전원선, 신호선, 접지 평면)와 방사 경로(케이블 안테나 효과, PCB 트레이스 방사, 섀시 틈새 누설).
- **민감 장치**: 센서 아날로그 프론트엔드, 통신 트랜시버, 마이크로컨트롤러 리셋 회로, 무선 모듈.

EMC 설계의 본질은 3요소 중 어느 한 링크에서 루프를 차단하는 것입니다. 차폐는 방사 경로를 대상으로 하고, 필터링은 전도 경로를 대상으로 하며, 접지는 둘 모두에 영향을 줍니다——공통 모드 전류의 복귀 경로와 기준 전위를 결정합니다.

**② 공통 모드와 차동 모드: 반드시 분리하여 관리해야 하는 두 가지 노이즈**
$$
I_{\text{CM}} = \frac{V_{\text{CM}}}{Z_{\text{CM}}}, \quad I_{\text{DM}} = \frac{V_{\text{DM}}}{Z_{\text{DM}}}
$$

공통 모드 전류(I_CM)는 두 도선의 동일 방향 전류로, 기생 커패시턴스를 통해 대지 또는 기준 접지로 흐르며, 방사 방출의 주요 원인입니다. 차동 모드 전류(I_DM)는 신호 자체의 전류 루프로, 주로 전도 방출에 영향을 줍니다. 필터 설계는 각각에 대해 별도로 대응해야 합니다: 공통 모드 초크는 공통 모드에 높은 임피던스를 나타내고 차동 모드에는 거의 영향을 주지 않습니다. X 커패시터는 라이브 와이어와 뉴트럴 와이어 사이에 연결되어 차동 모드를 억제하고, Y 커패시터는 라이브/뉴트럴 와이어와 접지 사이를 연결하여 공통 모드를 방출합니다. 공학적 판단: 모터 구동과 디지털 회로가 공존하는 휴머노이드 로봇 시나리오에서 공통 모드 노이즈는 일반적으로 차동 모드 노이즈보다 관리하기 어렵습니다. 그 경로가 기생 파라미터에 의존하여 정밀한 모델링이 어렵기 때문입니다.

**③ 접지: EMC의 제1원칙**
접지는 "접지선을 연결하는 것"만큼 단순하지 않습니다. EMC 맥락에서 접지는 모든 신호와 전원 전류에 대해 통제 가능한 복귀 경로를 제공하는 것을 의미합니다. 단일점 접지는 저주파(<1 MHz)에 적합하고, 다중점 접지는 고주파(>10 MHz)에 적합하며, 혼합 접지는 광대역 시나리오에 사용됩니다. 휴머노이드 로봇에서 모터 구동은 저주파 대전류에 속하고 디지털 회로는 고주파 소전류에 속하므로, 반드시 구역별로 접지한 후 단일 지점에서 합류해야 합니다. 그렇지 않으면 고주파 디지털 노이즈가 접지 평면을 통해 아날로그 및 전력 회로에 주입됩니다.

참고로, CE/FCC/UL의 구체적인 한계값(예: 방사 방출의 dBμV/m 한계값, 전도 방출의 주파수 범위)은 직접 확인해야 하며, 말뭉치는 구체적인 수치를 제공하지 않습니다. 공학적 판단: 휴머노이드 로봇 전체 시스템 EMC 테스트는 일반적으로 EN 55011(산업 장비) 또는 EN 55032(멀티미디어 장비)를 참조하며, 구체적인 적용 표준은 제품 분류와 목표 시장에 따라 달라집니다.

### 횡적 비교
P13.3.2는 P13 단계의 다른 3차 하위 작업(컴퓨팅 플랫폼 아키텍처, PCB 설계, 통신 버스 등)과 비교하여 세 가지 뚜렷한 차이점이 있습니다:

**첫째, 검증의 선행성.** PCB 설계는 "회로를 올바르게 만드는 것"에 초점을 맞추고, EMC 설계는 "회로를 조용하게 만드는 것"에 초점을 맞춥니다. 전자는 기능적 정확성을 검증하고, 후자는 전자기 환경 적합성을 검증합니다. EMC 검증은 사전 테스트와 시뮬레이션에 의존해야 하며, 설계 검토만으로는 확인할 수 없습니다.

**둘째, 영역 간 결합성.** 컴퓨팅 플랫폼 아키텍처는 연산 분포를 결정하고, 통신 버스는 신호 토폴로지를 결정하며, EMC 설계는 이 둘과 전력 시스템의 전자기 상호작용을 동시에 고려해야 합니다. 이는 P13 단계에서 "전력, 아날로그, 디지털 세 영역을 동시에 이해해야 하는" 유일한 하위 작업입니다.

**셋째, 표준 주도성.** 다른 하위 작업의 검수 기준은 주로 내부 기능 요구사항에서 오는 반면, P13.3.2의 검수 기준은 일부 외부 규제(CE/FCC/UL)에서 옵니다. 이는 "완료"의 정의가 "기능 달성"이 아니라 "적합성 달성"임을 의미합니다——둘은 때로 일치하지 않습니다.

### 누가 사용하는가·적용 사례
P13.3.2의 직접 실행자는 하드웨어 엔지니어와 EMC 엔지니어이지만, 그 출력물은 여러 다운스트림 단계에서 의존합니다:

- **전체 시스템 통합 팀**: EMC 설계 규격에 따라 와이어 하네스 배치와 구조 접지 설계를 수행하여 차폐 조치가 전체 시스템 차원에서 구현되도록 합니다.
- **인증 테스트 팀**: 사전 테스트 보고서를 기반으로 공식 테스트의 통과 확률을 판단하고, 사전에 시정 대비책을 준비합니다.
- **소프트웨어 팀**: EMC 시정 기록의 필터링 및 차폐 조치는 신호 타이밍과 통신 프로토콜에 영향을 줄 수 있으므로, 소프트웨어는 이에 따라 드라이버 구성을 조정해야 합니다.
- **제조 팀**: EMC 설계 규격의 PCB 레이아웃 요구사항과 차폐 부품 설치 방식은 생산 라인의 조립 공정과 테스트 스테이션 구성을 직접 결정합니다.

전형적인 적용 시나리오: 전신장 이족 휴머노이드 로봇이 보행 테스트 중 관절 엔코더 데이터 점프가 빈번하게 발생했습니다. 조사 결과, 모터 드라이버의 PWM 스위칭 노이즈가 전원선을 통해 엔코더 전원단으로 전도되어 아날로그 프론트엔드가 포화된 것이 원인이었습니다. 시정 조치에는 드라이버 전원 입력단에 공통 모드 초크 추가, 엔코더 신호선을 차폐 꼬임선으로 교체하고 단일 종단 접지, PCB에 전원과 접지 사이의 디커플링 커패시터 어레이 추가가 포함되었습니다. 시정 후 방사 방출은 약 20 dB 감소했고(공학적 판단, 구체적인 수치는 직접 확인 필요), 엔코더 데이터는 안정적으로 복구되었습니다.

### 한계와 경계
P13.3.2의 경계와 한계는 명확히 해야 합니다:

**첫째, 사전 테스트는 공식 인증과 같지 않습니다.** 사전 테스트는 일반적으로 실험실 환경에서 수행되며, 테스트 장소, 장비 교정, 안테나 계수는 공식 인증 실험실과 차이가 있습니다. 사전 테스트 통과가 공식 테스트의 반드시 통과를 의미하지 않으므로, 여유를 확보해야 합니다(공학적 판단: 일반적으로 6 dB 이상의 여유 확보).

**둘째, 시뮬레이션 모델의 정밀도는 제한적입니다.** 전자기 시뮬레이션은 부품 모델, 기생 파라미터, 구조 모델링의 정확성에 의존합니다. 많은 와이어 하네스, 커넥터, 운동 구조를 포함하는 휴머노이드 로봇과 같은 복잡한 시스템의 경우, 시뮬레이션 결과는 추세 참고용으로만 사용할 수 있으며 실측을 대체할 수 없습니다.

**셋째, 시정의 한계 효용 체감.** EMC 문제가 시정 단계에 들어서면, 차폐 층이나 필터를 추가할 때마다 개선 폭은 점차 줄어들고 무게와 비용 부담은 계속 증가합니다. 공학적 판단: 시정 조치가 3–4회 이상 반복되어도 기준을 달성하지 못하면, 계속 부품을 추가하기보다 설계 원점으로 돌아가 레이아웃과 필터 아키텍처를 재검토해야 합니다.

**넷째, 표준의 지역적 차이.** CE(유럽), FCC(미국), UL(미국 안전 표준)의 한계값과 테스트 방법은 완전히 일치하지 않습니다. 글로벌 시장을 대상으로 하는 휴머노이드 로봇은 여러 표준을 동시에 충족해야 하며, 이는 설계 단계에서 "가장 엄격한 한계값"을 통일된 목표로 채택해야 함을 요구합니다.

### 흔한 오해
1. **"EMC는 테스트 단계의 일이다"**——틀림. EMC 문제의 근원은 설계 단계에서 이미 심어져 있습니다. PCB 레이아웃, 접지 전략, 필터 토폴로지가 한번 확정되면, 후기 시정 비용은 지수적으로 증가합니다. P13.3.2가 EMC 설계를 개념 및 상세 설계 단계로 앞당기는 것은 비용이 가장 낮은 단계에서 문제를 해결하기 위해서입니다.

2. **"차폐가 많을수록 좋다"**——틀림. 차폐는 EMC 수단 중 하나이지만, 과도한 차폐는 무게, 비용, 방열 문제를 초래합니다. 휴머노이드 로봇은 무게에 극도로 민감하므로, 차폐 솔루션은 적합성과 경량화 사이에서 공학적 균형을 이루어야 합니다. 더 나은 경로는 종종 레이아웃과 필터링을 먼저 최적화한 후, 잔여 문제를 차폐로 해결하는 것입니다.

3. **"접지는 대지에 연결하는 것이다"**——틀림. EMC 맥락에서 접지는 "전류에 통제 가능한 복귀 경로를 제공하는 것"입니다. 휴머노이드 로봇은 이동 플랫폼으로 일반적으로 대지 기준이 없으며, 소위 "접지"는 실제로 섀시 접지 또는 시스템 접지입니다. 설계의 핵심은 복귀 경로의 임피던스와 루프 면적을 제어하는 것이지, 물리적으로 대지에 연결하는 것이 아닙니다.

4. **"사전 테스트 통과하면 모든 것이 해결된다"**——틀림. 사전 테스트 환경과 공식 인증 환경은 차이가 있으며, 전체 시스템 상태(와이어 하네스 배치, 구조 조립, 소프트웨어 부하)는 사전 테스트 후 변경될 수 있습니다. 테스트 여유를 확보하고, 공식 테스트 전에 최종 상태를 확인해야 합니다.
