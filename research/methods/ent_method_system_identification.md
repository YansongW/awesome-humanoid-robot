## 概述

系统辨识（System Identification）是从实验数据估计机器人真实动力学参数（质量、质心、惯性张量、摩擦、执行器增益与延迟）的方法体系。核心数学事实是：刚体动力学方程对这些参数是**线性的**——$\boldsymbol{\tau} = \mathbf{Y}(\mathbf{q},\dot{\mathbf{q}},\ddot{\mathbf{q}})\,\boldsymbol{\pi}$，因此可用最小二乘从力矩-运动数据中解出最小参数集。它是 sim-to-real"缩小差距"路线与高精度模型控制（MPC/WBC）的共同前提（来源：项目 Wiki 第 8 章 §8.3.10、第 18 章 §18.6.3）。

## 核心内容

### 是什么：准确定义

机器人标准动力学方程 $\boldsymbol{\tau} = \mathbf{M}(\mathbf{q})\ddot{\mathbf{q}} + \mathbf{C}(\mathbf{q},\dot{\mathbf{q}})\dot{\mathbf{q}} + \mathbf{g}(\mathbf{q})$ 对动力学参数是线性的（来源：项目 Wiki 第 8 章 §8.3.10）：

$$
\boldsymbol{\tau} = \mathbf{Y}(\mathbf{q}, \dot{\mathbf{q}}, \ddot{\mathbf{q}}) \, \boldsymbol{\pi}
$$

$\mathbf{Y}$ 为回归矩阵，$\boldsymbol{\pi}$ 为待辨识参数向量。每根连杆有 10 个参数（质量、3 个质心坐标、6 个惯性张量独立量），n 连杆名义 10n 个参数，但多数对力矩无独立影响或可线性合并——可由数据唯一辨识的最小子集称为**最小参数集（base parameter set）**，需对回归矩阵做秩分析/QR/SVD 分解确定（Wiki §8.3.10）。

### 为什么存在：痛点与历史定位

CAD 名义参数与真实机器人存在系统性偏差：材料密度不均、加工余量、电缆质量、紧固件公差、装配差异（Wiki §8.3.10）。这个偏差直接决定模型类控制器的性能上限——MPC 的预测模型、WBC 的动力学约束、重力前馈的准确性，全部建立在参数之上。

在 learning 时代，辨识的地位不降反升：sim-to-real 的现实差距很大程度上就是**参数差距**。Wiki 第 18 章给出的工程准则（§18.6.3）：全局辨识所有参数既昂贵又欠定，实践只对任务敏感的少数参数（接触摩擦、关键关节执行器增益与延迟、负载质量）校准，其余交给域随机化覆盖。**它真正改变的不是某个矩阵的数值，而是"模型可不可信"的预算分配**——把有限的标定预算集中在对任务回报影响最大的参数子集上。

### 原理拆解

**① 线性参数化与最小二乘**

沿激励轨迹在 N 个时刻采样 $(\mathbf{q}, \dot{\mathbf{q}}, \ddot{\mathbf{q}}, \boldsymbol{\tau})$，堆叠成超定方程组，最小二乘求解 $\hat{\boldsymbol{\pi}} = \arg\min \|\mathbf{W}\boldsymbol{\pi} - \boldsymbol{\Gamma}\|^2$（W 为堆叠回归矩阵，Γ 为堆叠力矩）（Wiki §8.3.10）。

**② 激励轨迹设计**

回归矩阵病态则参数不可分。激励轨迹需"充分激励"全部待辨识参数——常用有限傅里叶级数轨迹，以回归矩阵条件数为优化目标做轨迹优化（Wiki §8.3.10 激励轨迹设计节）。

**③ 物理一致性约束**

原始最小二乘可能给出非物理参数（负质量、非正定惯性张量）。物理一致性约束辨识把 $m_i > 0$、惯性张量正定性（必要时质心位于凸包内）作为约束纳入优化（Wiki §8.3.10 物理一致性节）。

**④ 人形机器人的特殊性与近年扩展**

浮动基无固定参考，需结合 IMU 与力传感器做浮动基辨识；常用做法是单腿/单臂独立运动辨识局部参数、再整机协调运动辨识耦合参数（Wiki 第 8 章 §8.4 附近讨论）。辨识对象也从刚体参数扩展到**执行器模型**（电流-力矩增益、延迟）与**能耗模型**——如对 Unitree G1 手臂的物理功耗模型辨识（arXiv:2606.15915）。

### 局限与边界

- **欠定与病态**：回归矩阵不满秩的参数组合永远无法从力矩数据分离；
- **激励轨迹侵入性**：充分激励要求关节大幅运动，与某些场景（已装机、限空间）冲突；
- **时变参数**：减速器磨合、温度漂移使参数随时间变化，一次辨识不终身有效（**工程判断**）；
- **非刚体项**：线缆、齿轮弹性、齿隙不在刚体参数化内，需扩展模型结构。

### 常见误区

1. **"CAD 参数够用了"**——装配与线缆引入的系统偏差是模型控制器性能的第一瓶颈（Wiki §8.3.10）。
2. **"参数全部可辨识"**——只有最小参数集可被唯一辨识；强行全辨识得到的是病态解。
3. **"辨识是一锤子买卖"**——磨合与温漂使参数漂移，量产场景需要周期性再辨识。
4. **"学习法让辨识过时"**——残差学习模型的输入正是名义模型；辨识越准，要学的残差越小。

## Overview

System Identification is a methodological framework for estimating a robot's true dynamic parameters (mass, center of mass, inertia tensor, friction, actuator gains and delays) from experimental data. The core mathematical fact is that rigid-body dynamics equations are **linear** in these parameters—$\boldsymbol{\tau} = \mathbf{Y}(\mathbf{q},\dot{\mathbf{q}},\ddot{\mathbf{q}})\,\boldsymbol{\pi}$—so least squares can be used to solve for the base parameter set from torque-motion data. It is a common prerequisite for both the sim-to-real "gap reduction" pipeline and high-precision model-based control (MPC/WBC) (source: Project Wiki Chapter 8 §8.3.10, Chapter 18 §18.6.3).

## Content

### What It Is: Precise Definition

The standard robot dynamics equation $\boldsymbol{\tau} = \mathbf{M}(\mathbf{q})\ddot{\mathbf{q}} + \mathbf{C}(\mathbf{q},\dot{\mathbf{q}})\dot{\mathbf{q}} + \mathbf{g}(\mathbf{q})$ is linear in the dynamic parameters (source: Project Wiki Chapter 8 §8.3.10):

$$
\boldsymbol{\tau} = \mathbf{Y}(\mathbf{q}, \dot{\mathbf{q}}, \ddot{\mathbf{q}}) \, \boldsymbol{\pi}
$$

$\mathbf{Y}$ is the regression matrix, and $\boldsymbol{\pi}$ is the vector of parameters to be identified. Each link has 10 parameters (mass, 3 center-of-mass coordinates, 6 independent inertia tensor components), giving a nominal 10n parameters for n links, but most have no independent effect on torque or can be linearly combined—the minimal subset uniquely identifiable from data is called the **base parameter set**, determined via rank analysis/QR/SVD decomposition of the regression matrix (Wiki §8.3.10).

### Why It Exists: Pain Points and Historical Context

CAD nominal parameters deviate systematically from real robots: non-uniform material density, machining allowances, cable mass, fastener tolerances, and assembly variations (Wiki §8.3.10). This deviation directly determines the performance ceiling of model-based controllers—the prediction model of MPC, the dynamic constraints of WBC, and the accuracy of gravity feedforward all rest on these parameters.

In the learning era, the importance of identification has risen rather than fallen: the sim-to-real gap is largely a **parameter gap**. The engineering guideline given in Wiki Chapter 18 (§18.6.3) is that globally identifying all parameters is both expensive and underdetermined; in practice, only a few task-sensitive parameters (contact friction, key joint actuator gains and delays, payload mass) are calibrated, with the rest left to domain randomization. **What it truly changes is not the numerical values of some matrix, but the budget allocation of "whether the model is trustworthy"**—concentrating limited calibration budget on the parameter subset with the greatest impact on task reward.

### Principle Breakdown

**① Linear Parameterization and Least Squares**

Sample $(\mathbf{q}, \dot{\mathbf{q}}, \ddot{\mathbf{q}}, \boldsymbol{\tau})$ at N time instants along an excitation trajectory, stack them into an overdetermined system, and solve via least squares: $\hat{\boldsymbol{\pi}} = \arg\min \|\mathbf{W}\boldsymbol{\pi} - \boldsymbol{\Gamma}\|^2$ (W is the stacked regression matrix, Γ is the stacked torque vector) (Wiki §8.3.10).

**② Excitation Trajectory Design**

If the regression matrix is ill-conditioned, parameters cannot be separated. The excitation trajectory must "sufficiently excite" all parameters to be identified—commonly using finite Fourier series trajectories, with trajectory optimization targeting the condition number of the regression matrix (Wiki §8.3.10, excitation trajectory design section).

**③ Physically Consistent Constraints**

Raw least squares can yield non-physical parameters (negative mass, non-positive-definite inertia tensor). Physically consistent identification incorporates constraints such as $m_i > 0$ and positive definiteness of the inertia tensor (and, when necessary, the center of mass lying within the convex hull) into the optimization (Wiki §8.3.10, physical consistency section).

**④ Specifics for Humanoid Robots and Recent Extensions**

A floating base has no fixed reference, so identification must combine IMU and force sensors; a common approach is to identify local parameters via single-leg/single-arm independent motion, then identify coupled parameters via whole-body coordinated motion (Wiki Chapter 8, discussion near §8.4). The identification target has also expanded from rigid-body parameters to **actuator models** (current-torque gain, delay) and **energy consumption models**—e.g., physical power consumption model identification for the Unitree G1 arm (arXiv:2606.15915).

### Who Uses It / Application Cases

- **Prerequisite for model-based control**: standard procedure before MPC/WBC deployment (Wiki §8.3.10);
- **real2sim calibration**: core dependency of the zero-shot sim-to-real pipeline (Wiki §18.6.5);
- **Energy consumption modeling**: physical power consumption model identification for the Unitree G1 arm (arXiv:2606.15915; graph `ent_paper_deniz_identification_of_a_physics_ba_2026`);
- **Integration with in-the-loop validation**: identification results are confirmed via HIL (`ent_method_hardware_in_the_loop`) before deployment.

### Limitations and Boundaries

- **Underdetermination and ill-conditioning**: parameter combinations for which the regression matrix is rank-deficient can never be separated from torque data;
- **Invasiveness of excitation trajectories**: sufficient excitation requires large joint motions, conflicting with certain scenarios (already installed, constrained space);
- **Time-varying parameters**: gearbox break-in and temperature drift cause parameters to change over time; a one-time identification is not valid forever (**engineering judgment**);
- **Non-rigid-body terms**: cables, gear elasticity, and backlash are not within the rigid-body parameterization and require extended model structures.

### Common Misconceptions

1. **"CAD parameters are good enough"**—systematic deviations from assembly and cabling are the primary bottleneck for model-based controller performance (Wiki §8.3.10).
2. **"All parameters are identifiable"**—only the base parameter set can be uniquely identified; forcing full identification yields an ill-conditioned solution.
3. **"Identification is a one-shot deal"**—break-in and thermal drift cause parameter drift; periodic re-identification is needed in mass production scenarios.
4. **"Learning methods make identification obsolete"**—the input to residual learning models is precisely the nominal model; the more accurate the identification, the smaller the residual to be learned.

## 개요

시스템 식별(System Identification)은 실험 데이터로부터 로봇의 실제 동역학 파라미터(질량, 질량 중심, 관성 텐서, 마찰, 액추에이터 이득 및 지연)를 추정하는 방법론입니다. 핵심 수학적 사실은 강체 동역학 방정식이 이러한 파라미터에 대해 **선형적**이라는 것입니다 — $\boldsymbol{\tau} = \mathbf{Y}(\mathbf{q},\dot{\mathbf{q}},\ddot{\mathbf{q}})\,\boldsymbol{\pi}$, 따라서 최소자승법을 통해 토크-운동 데이터에서 최소 파라미터 집합을 풀어낼 수 있습니다. 이는 sim-to-real "격차 해소" 경로와 고정밀 모델 기반 제어(MPC/WBC)의 공통 전제 조건입니다(출처: 프로젝트 Wiki 8장 §8.3.10, 18장 §18.6.3).

## 핵심 내용

### 무엇인가: 정확한 정의

로봇 표준 동역학 방정식 $\boldsymbol{\tau} = \mathbf{M}(\mathbf{q})\ddot{\mathbf{q}} + \mathbf{C}(\mathbf{q},\dot{\mathbf{q}})\dot{\mathbf{q}} + \mathbf{g}(\mathbf{q})$는 동역학 파라미터에 대해 선형적입니다(출처: 프로젝트 Wiki 8장 §8.3.10):

$$
\boldsymbol{\tau} = \mathbf{Y}(\mathbf{q}, \dot{\mathbf{q}}, \ddot{\mathbf{q}}) \, \boldsymbol{\pi}
$$

$\mathbf{Y}$는 회귀 행렬, $\boldsymbol{\pi}$는 식별 대상 파라미터 벡터입니다. 각 링크는 10개의 파라미터(질량, 3개의 질량 중심 좌표, 6개의 관성 텐서 독립 성분)를 가지며, n-링크의 경우 명목상 10n개의 파라미터가 있지만 대부분은 토크에 독립적인 영향을 미치지 않거나 선형적으로 결합될 수 있습니다 — 데이터에서 고유하게 식별 가능한 최소 부분집합을 **최소 파라미터 집합(base parameter set)** 이라고 하며, 회귀 행렬의 랭크 분석/QR/SVD 분해를 통해 결정해야 합니다(Wiki §8.3.10).

### 왜 존재하는가: 문제점과 역사적 위치

CAD 명목 파라미터와 실제 로봇 사이에는 체계적 편차가 존재합니다: 재료 밀도 불균일, 가공 여유, 케이블 질량, 체결 공차, 조립 차이(Wiki §8.3.10). 이 편차는 모델 기반 제어기의 성능 상한을 직접 결정합니다 — MPC의 예측 모델, WBC의 동역학 제약, 중력 피드포워드의 정확성은 모두 파라미터 위에 구축됩니다.

러닝(learning) 시대에 식별의 위상은 낮아지지 않고 오히려 높아졌습니다: sim-to-real의 현실적 격차는 상당 부분 **파라미터 격차**입니다. Wiki 18장이 제시하는 공학적 기준(§18.6.3): 모든 파라미터의 전역 식별은 비용이 높고 과소결정(underdetermined)되므로, 실제로는 작업에 민감한 소수의 파라미터(접촉 마찰, 핵심 관절 액추에이터 이득 및 지연, 부하 질량)만 보정하고 나머지는 도메인 무작위화로 커버합니다. **이것이 실제로 바꾸는 것은 특정 행렬의 수치가 아니라 "모델을 신뢰할 수 있는지"의 예산 배분입니다** — 제한된 보정 예산을 작업 보상에 가장 큰 영향을 미치는 파라미터 부분집합에 집중시키는 것입니다.

### 원리 분해

**① 선형 파라미터화와 최소자승법**

가진 궤적을 따라 N개의 시점에서 $(\mathbf{q}, \dot{\mathbf{q}}, \ddot{\mathbf{q}}, \boldsymbol{\tau})$를 샘플링하여 과결정 연립방정식으로 쌓고, 최소자승법으로 $\hat{\boldsymbol{\pi}} = \arg\min \|\mathbf{W}\boldsymbol{\pi} - \boldsymbol{\Gamma}\|^2$를 풉니다(W는 쌓인 회귀 행렬, Γ는 쌓인 토크)(Wiki §8.3.10).

**② 가진 궤적 설계**

회귀 행렬이 ill-conditioned이면 파라미터를 분리할 수 없습니다. 가진 궤적은 모든 식별 대상 파라미터를 "충분히 가진"해야 합니다 — 일반적으로 유한 푸리에 급수 궤적을 사용하며, 회귀 행렬의 조건수를 최적화 목표로 궤적 최적화를 수행합니다(Wiki §8.3.10 가진 궤적 설계 절).

**③ 물리적 일관성 제약**

원시 최소자승법은 비물리적 파라미터(음의 질량, 비양정부호 관성 텐서)를 산출할 수 있습니다. 물리적 일관성 제약 식별은 $m_i > 0$, 관성 텐서 양정부호성(필요 시 질량 중심이 볼록 껍질 내부에 위치)을 제약으로 최적화에 포함합니다(Wiki §8.3.10 물리적 일관성 절).

**④ 휴머노이드 로봇의 특수성과 최근 확장**

플로팅 베이스는 고정 기준점이 없으므로 IMU와 힘 센서를 결합한 플로팅 베이스 식별이 필요합니다; 일반적인 방법은 단일 다리/단일 팔 독립 운동으로 국소 파라미터를 식별한 후, 전신 협조 운동으로 결합 파라미터를 식별하는 것입니다(Wiki 8장 §8.4 부근 논의). 식별 대상도 강체 파라미터에서 **액추에이터 모델**(전류-토크 이득, 지연)과 **에너지 소비 모델**로 확장되었습니다 — 예: Unitree G1 팔의 물리적 전력 소비 모델 식별(arXiv:2606.15915).

### 한계와 경계

- **과소결정 및 병적 상태**: 회귀 행렬이 풀랭크가 아닌 파라미터 조합은 토크 데이터에서 절대 분리할 수 없음;
- **가진 궤적 침습성**: 충분한 가진은 관절의 큰 움직임을 요구하며, 일부 시나리오(이미 설치됨, 공간 제약)와 충돌;
- **시변 파라미터**: 감속기 마모, 온도 드리프트로 파라미터가 시간에 따라 변하므로 일회성 식별로 영구 유효하지 않음(**공학적 판단**);
- **비강체 항목**: 케이블, 기어 탄성, 백래시는 강체 파라미터화에 포함되지 않으므로 모델 구조 확장이 필요.

### 일반적인 오해

1. **"CAD 파라미터로 충분하다"** — 조립과 케이블이 도입하는 체계적 편차는 모델 기반 제어기 성능의 첫 번째 병목입니다(Wiki §8.3.10).
2. **"모든 파라미터를 식별할 수 있다"** — 최소 파라미터 집합만 고유하게 식별 가능; 무리한 전체 식별은 병적 해를 얻습니다.
3. **"식별은 일회성 작업이다"** — 마모와 온도 드리프트로 파라미터가 변하므로 양산 시나리오에서는 주기적 재식별이 필요합니다.
4. **"학습법이 식별을 구식으로 만든다"** — 잔차 학습 모델의 입력은 바로 명목 모델입니다; 식별이 정확할수록 학습할 잔차가 작아집니다.
