## 概述

Unified-IO 2 是 Allen Institute for AI 提出的 70 亿参数自回归多模态模型，从零训练，统一处理图像、文本、音频、动作等模态的输入与生成。其核心贡献在于提出多模态混合去噪训练目标与一系列架构稳定性改进，在超过 35 个数据集上验证了通用性，并实现了 4 倍训练吞吐量提升。

## 它改变了什么

多模态生成模型的传统路径是“预训练 LLM + 外挂模态适配器”，这导致语言能力与感知能力在架构上割裂，且难以实现模态间的相互监督。Unified-IO 2 真正改变的是“从零训练”这一前提——它不依赖任何预训练语言模型，而是将文本、图像、音频、动作统一为 token 序列，用单一编码器-解码器 Transformer 端到端学习。这使得模型能够利用模态共现作为监督信号，更接近人类通过多感官协同学习的方式，同时避免了昂贵的 LLM 预训练阶段，让方法可复现性大幅提升。

另一个关键改变在于训练目标的重新设计。现有模型要么只做生成、要么只做理解，而 Unified-IO 2 将去噪与生成统一为“多模态混合去噪器”，让同一模型既能根据文本生成图像，也能根据图像生成文本，还能完成具身动作预测。这种统一目标不仅简化了训练流程，还让不同模态的任务共享底层表征，从而在数据效率上获得优势——这在 600 太字节的庞大数据规模下尤为重要。

## 方法拆解

### 统一任务表示
所有模态（文本、图像、音频、动作、边界框等）的输入与输出均分词为共享语义空间中的 token 序列，由单一编码器-解码器 Transformer 处理。文本使用 LLaMA 的字节对编码；边界框、关键点、相机位姿离散化后用 1000 个特殊 token 编码；具身动作生成为文本命令（如“move ahead”），机器人状态用特殊 token 编码。

### 图像与音频编码
- 图像：预训练 ViT 编码，拼接第二层与倒数第二层 patch 特征，经线性层得到嵌入。生成侧使用 8×8 patch 的 VQ-GAN，将 256×256 图像编码为 1024 个 token，码本大小 16512。
- 音频：编码最多 4.08 秒音频为频谱图，用预训练 AST 编码，拼接第二层与倒数第二层特征。生成侧使用自实现 ViT-VQGAN，8×8 patch，将 256×128 频谱图编码为 512 个 token，码本大小 8196。
- 历史输入：允许最多四个额外图像/音频段，经 perceiver resampler 压缩为图像 32 个、音频 16 个 token，减少序列长度。

### 架构稳定性改进
- **2D 旋转嵌入**：用 RoPE 替代相对位置嵌入，对非文本模态扩展到二维位置，query 和 key 各半分别应用两个坐标的旋转嵌入。
- **QK 归一化**：观察到包含图像和音频模态时注意力 logits 出现极大值，导致注意力权重退化为 0 或 1。在点积注意力计算前对 query 和 key 应用 LayerNorm。
- **缩放余弦注意力**：perceiver resampler 中即使有 QK 归一化，logits 仍可能极端，应用缩放余弦注意力显著稳定训练。
- **float32 注意力 logits**：避免数值不稳定；预训练期间冻结 ViT 和 AST，指令调优结束时微调。

### 训练目标
提出多模态混合去噪器目标，结合跨模态去噪与生成。文本目标遵循 UL2 范式（[R] 标准 span corruption、[S] 因果语言建模、[X] 极端 span corruption）；图像和音频定义类似范式（[R] 掩码去噪、[S] 仅基于其他模态生成目标模态）。训练时用模态 token（[Text]、[Image]、[Audio]）和范式 token（[R]、[S]、[X]）前缀输入文本。自回归动态掩码解决图像和音频掩码去噪在自回归方式中的解码器信息泄漏问题。

### 效率优化
动态打包提供 4 倍训练吞吐量提升，以处理高度可变的序列长度。

## 关键创新

1. **从零训练的统一多模态架构**：不依赖预训练 LLM，而是将文本、图像、音频、动作统一为 token 序列端到端学习。这避免了模态适配器的架构割裂，让模态间相互监督成为可能，且无需昂贵的语言模型预训练阶段，方法可复现性显著提升。

2. **多模态混合去噪器目标**：将去噪与生成统一为单一训练目标，文本、图像、音频共享 [R]/[S]/[X] 范式。这一设计让同一模型既能理解也能生成所有模态，且通过模态共现提供额外监督信号，在数据效率上优于分阶段训练。

3. **针对多模态训练的稳定性改进组合**：2D RoPE、QK 归一化、缩放余弦注意力、float32 注意力 logits 四者结合，解决了从零训练多模态模型时注意力 logits 极端化导致的训练崩溃问题（XXL 版本在 350k 步后损失爆炸、400k 步准确率下降）。这些改进虽非全新，但组合应用于多模态从零训练场景并验证有效性，具有工程价值。

## 实验与结果

在超过 35 个数据集上评估，覆盖视觉、语言、音频、视频和具身 AI 任务。关键结果如下：

| 评估维度 | 结果 |
|---------|------|
| GRIT 基准 | 达到最先进性能 |
| 视觉与语言任务 | 匹配或超越许多利用预训练 LLM 的近期 VLM |
| 图像生成 | 超越最接近竞争对手（利用预训练稳定扩散模型的 Tang et al. 2023），尤其在忠实度方面 |
| 训练稳定性 | XXL 版本在 350k 步后损失爆炸，400k 步准确率显著下降（未采用改进时） |
| 训练吞吐量 | 动态打包提供 4 倍提升 |

## 工程启示

复现或借鉴 Unified-IO 2 时，优先核对以下三点：

1. **训练稳定性是首要风险**：从零训练多模态模型时，注意力 logits 极端化是常见崩溃点。务必先实现 QK 归一化与 float32 注意力 logits，再考虑 2D RoPE 和缩放余弦注意力。若跳过这些改进，XXL 规模下 350k 步后损失爆炸是大概率事件。

2. **数据规模与动态打包**：600 太字节数据量对大多数团队不现实，但动态打包带来的 4 倍吞吐量提升是通用技巧，可独立迁移到任何序列长度高度可变的训练场景。建议先在小规模数据上验证动态打包的正确性，再扩展数据量。

3. **模态编码器的冻结策略**：预训练期间冻结 ViT 和 AST，仅在指令调优结束时微调。这一策略降低了训练难度，但意味着视觉和音频编码器的表征质量直接决定模型上限。若下游任务与预训练数据分布差异大，需评估是否提前解冻微调。最易踩坑处在于 perceiver resampler 的 token 压缩——图像压缩为 32 个、音频为 16 个 token，若任务需要高细节视觉信息（如细粒度物体识别），需验证压缩是否造成信息损失。

## 개요
기존 로봇 VLA 모델은 추론 능력 부족과 높은 계산 비용이라는 두 가지 주요 과제에 직면해 있습니다. RoboMamba는 비전 인코더를 Mamba와 통합하고, 비전-언어 공동 훈련 전략을 채택하여 모델에 상식 추론 능력을 부여합니다. 이 모델은 극소량의 파라미터(0.1%)만 미세 조정하여 조작 기술을 습득할 수 있으며, 일반 및 로봇 평가 벤치마크에서 우수한 추론 성능을 보여주고, 시뮬레이션 및 실제 실험에서 기존 모델 대비 3배의 추론 속도를 구현합니다.
