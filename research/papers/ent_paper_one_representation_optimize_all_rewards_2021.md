## 概述

本文提出Forward-Backward（FB）表示学习框架，通过无监督方式学习一对函数F和B，使得任意后验指定的奖励函数都能直接映射为最优策略，无需规划或微调。作者来自DeepMind等机构，核心贡献是证明了FB表示在理论上存在、对近似误差鲁棒，并在离散/连续迷宫、FetchReach和像素级Ms. Pacman上验证了其超越目标导向基线的性能。

## 它改变了什么

传统强化学习将奖励函数视为先验输入，而FB表示试图将“学习环境结构”与“优化特定奖励”彻底解耦。这改变了无奖励RL的范式：此前HER只能处理目标状态集，世界模型需要为新奖励重新规划，而[BBQ+18]的通用后继特征要求用户预先提供特征函数且仅限线性组合。FB表示的核心突破在于，它学习的是一个“奖励无关的压缩对象”，使得任意奖励（包括稠密、加权组合、带约束的复杂形式）都能通过一次内积运算直接获得近优策略，将后验奖励优化的计算成本降为O(d)的向量运算。

## 方法拆解

### 核心架构
- 学习F: S×A×Z→Z和B: S×A→Z（Z≃ℝᵈ），使得F(s,a,z)ᵀB(s′,a′)逼近后继测度M^{π_z}(s,a,ds′,da′)/ρ(ds′,da′)
- 策略定义为π_z(s) := argmax_a F(s,a,z)ᵀz

### 关键代数推导
- 给定奖励r，计算z_R = ∫r(s,a)B(s,a)ρ(ds,da)
- 则Q*(s,a) = F(s,a,z_R)ᵀz_R，π_{z_R}为最优策略
- 证明核心：若M^{π_z} = F_zᵀB，则Q_r^{π_z} = F_zᵀBr，令z_R := Br，则π_{z_R}是其自身Q函数的贪心策略

### 无监督训练损失
- 基于后继测度的贝尔曼方程（公式4），更新规则（公式5）：
  δθ := ∂_θ m_θ^π(s₀,a₀,s₀,a₀) + ∂_θ m_θ^π(s₀,a₀,s′,a′) × (γm_θ^π(s₁,a₁,s′,a′) - m_θ^π(s₀,a₀,s′,a′))
- 训练时使用softmax策略π_z = softmax(F(s,a,z)ᵀz/τ)，温度τ固定
- 通过辅助损失归一化B（解决F与B的不可辨识性）

### 奖励估计阶段
- 黑盒奖励：重新运行探索策略，平均r(s,a)B(s,a)
- 显式奖励（如到达目标避开禁区）：直接设置z_R = B(s₀,a₀) - λΣB(sᵢ,aᵢ)
- 代数奖励：在重放缓冲区上平均r(s,a)B(s,a)

### 先验信息整合
- 若奖励只依赖特征g=φ(s,a)，B可只在g上训练，F仍用完整状态，理论保证不变（定理4）

## 关键创新

1. **双表示学习取代单特征**：与[BBQ+18]的单特征F不同，FB学习F和B两个表示，B编码“奖励到z的映射”，使得任意奖励（不仅是线性组合）都能通过B的积分直接获得z_R，突破了连续空间需要无限特征的局限。

2. **无规划的最优策略恢复**：世界模型需要为每个新奖励显式规划，而FB表示通过z_R = Br的代数操作直接得到最优策略，将后验奖励优化的计算复杂度降为O(d)，且理论保证（定理2）表明训练完美时对所有奖励可证明最优。

3. **对近似误差的鲁棒性理论**：定理8-9给出了次优性与FB训练误差的显式界（3ε||r||∞/(1-γ)），并揭示了误差矩阵E(z)在偏离最优轨迹一步的状态-动作处的关键作用，为实际部署提供了理论保障。

## 边界与局限

- **探索问题未解决**：方法假设存在良好探索策略，实验中用随机z的π_z探索，不保证覆盖所有状态
- **信息损失**：奖励被压缩为d维向量z_R = E[r·B]，与B不相关的奖励被视为0；d控制可优化奖励类型数量，先验上可能需要很大d
- **隐式偏差**：rank-d近似倾向于马尔可夫链拉普拉斯算子的小特征向量（长程低频行为），局部奖励细节可能模糊（图3）
- **方差问题**：大环境中可能存在方差问题（实验中未出现），缓解策略（如利用期望解耦）留待未来
- **连续空间理论缺口**：m^π因t=0项含Dirac奇异分量，连续参数模型只能在弱拓扑下逼近，作者称“未发现理论和实践问题”但无严格证明
- **B的最优性缺乏严格结果**：作者明确承认“we have no rigorous result here”，关于B应捕获空间光滑特征只是直觉

## 工程启示

- **复现核对清单**：先确认z采样分布（重缩放高斯×Cauchy）、温度τ=200、Polyak α=0.95、正则化λ=1、replay buffer 10⁶；这些超参数对稳定性至关重要
- **维度选择陷阱**：d过小导致空间平滑（离散迷宫d=25失败），建议从d=100起步；若奖励依赖特定特征，优先将B限制在该特征空间（B(g)）而非增大d
- **奖励估计踩坑**：z_R = E[r·B]必须在与训练F/B相同的分布ρ上计算（附录B.5）；若测试分布不同，需预先计算Cov_ρB矩阵，否则线性奖励模型只是近似
- **下游团队指导**：FB表示适合多任务/多奖励场景，一次训练可服务任意后验奖励；但对单一固定奖励，目标导向基线（如HER）可能更优——FB的trade-off是通用性换特定任务性能
- **方差缓解**：若大环境中出现不稳定，可尝试结合HER选择与当前状态-动作相关的目标，或利用更新解耦为两个期望乘积的移动平均估计（需处理d×d矩阵，留待未来）

## Overview

This paper proposes a Forward-Backward (FB) representation learning framework that learns a pair of functions F and B in an unsupervised manner, such that any posteriori specified reward function can be directly mapped to an optimal policy without planning or fine-tuning. The authors are from DeepMind and other institutions. The core contribution is proving that FB representations exist theoretically, are robust to approximation errors, and demonstrate performance surpassing goal-oriented baselines in discrete/continuous mazes, FetchReach, and pixel-level Ms. Pacman.

## What It Changes

Traditional reinforcement learning treats the reward function as a prior input, while FB representations attempt to completely decouple "learning environment structure" from "optimizing specific rewards." This changes the paradigm of reward-free RL: previously, HER could only handle goal state sets, world models required replanning for new rewards, and the universal successor features of [BBQ+18] required users to provide feature functions in advance and were limited to linear combinations. The core breakthrough of FB representations is that it learns a "reward-agnostic compressed object," enabling any reward (including dense, weighted combinations, and complex constrained forms) to directly obtain a near-optimal policy through a single inner product operation, reducing the computational cost of posteriori reward optimization to O(d) vector operations.

## Method Breakdown

### Core Architecture
- Learn F: S×A×Z→Z and B: S×A→Z (Z≃ℝᵈ), such that F(s,a,z)ᵀB(s′,a′) approximates the successor measure M^{π_z}(s,a,ds′,da′)/ρ(ds′,da′)
- Policy defined as π_z(s) := argmax_a F(s,a,z)ᵀz

### Key Algebraic Derivation
- Given reward r, compute z_R = ∫r(s,a)B(s,a)ρ(ds,da)
- Then Q*(s,a) = F(s,a,z_R)ᵀz_R, and π_{z_R} is the optimal policy
- Proof core: if M^{π_z} = F_zᵀB, then Q_r^{π_z} = F_zᵀBr; letting z_R := Br, then π_{z_R} is the greedy policy with respect to its own Q-function

### Unsupervised Training Loss
- Based on the Bellman equation for successor measures (Equation 4), with update rule (Equation 5):
  δθ := ∂_θ m_θ^π(s₀,a₀,s₀,a₀) + ∂_θ m_θ^π(s₀,a₀,s′,a′) × (γm_θ^π(s₁,a₁,s′,a′) - m_θ^π(s₀,a₀,s′,a′))
- Training uses softmax policy π_z = softmax(F(s,a,z)ᵀz/τ) with fixed temperature τ
- B is normalized via an auxiliary loss (addressing the unidentifiability of F and B)

### Reward Estimation Phase
- Black-box reward: rerun exploration policy, average r(s,a)B(s,a)
- Explicit reward (e.g., reach goal while avoiding forbidden zones): directly set z_R = B(s₀,a₀) - λΣB(sᵢ,aᵢ)
- Algebraic reward: average r(s,a)B(s,a) over the replay buffer

### Prior Information Integration
- If the reward depends only on features g=φ(s,a), B can be trained only on g while F still uses the full state, with theoretical guarantees preserved (Theorem 4)

## Key Innovations

1. **Dual representation learning replaces single features**: Unlike the single feature F in [BBQ+18], FB learns two representations, F and B, where B encodes the "reward-to-z mapping," allowing any reward (not just linear combinations) to directly obtain z_R through integration with B, breaking through the limitation of requiring infinite features in continuous spaces.

2. **Optimal policy recovery without planning**: World models require explicit planning for each new reward, while FB representations directly obtain the optimal policy through the algebraic operation z_R = Br, reducing the computational complexity of posteriori reward optimization to O(d), with theoretical guarantees (Theorem 2) showing provable optimality for all rewards when training is perfect.

3. **Robustness theory for approximation errors**: Theorems 8-9 provide explicit bounds on suboptimality in terms of FB training error (3ε||r||∞/(1-γ)), and reveal the critical role of the error matrix E(z) at state-action pairs one step off the optimal trajectory, providing theoretical guarantees for practical deployment.

## Boundaries and Limitations

- **Exploration problem unsolved**: The method assumes the existence of a good exploration policy; experiments use π_z with random z for exploration, with no guarantee of state coverage
- **Information loss**: Rewards are compressed into a d-dimensional vector z_R = E[r·B]; rewards uncorrelated with B are treated as zero; d controls the number of optimizable reward types and may need to be large a priori
- **Implicit bias**: The rank-d approximation tends toward small eigenvectors of the Markov chain Laplacian (long-range low-frequency behavior), potentially blurring local reward details (Figure 3)
- **Variance issues**: Potential variance problems in large environments (not observed in experiments); mitigation strategies (e.g., leveraging expectation decoupling) are left for future work
- **Theoretical gap in continuous spaces**: m^π contains a Dirac singular component from the t=0 term, so continuous parametric models can only approximate in the weak topology; the authors state "no theoretical or practical issues found" but without rigorous proof
- **Lack of rigorous results for B optimality**: The authors explicitly acknowledge "we have no rigorous result here"; the intuition that B should capture spatially smooth features remains unproven

## Engineering Insights

- **Reproduction checklist**: First confirm the z sampling distribution (rescaled Gaussian × Cauchy), temperature τ=200, Polyak α=0.95, regularization λ=1, replay buffer 10⁶; these hyperparameters are critical for stability
- **Dimension selection pitfalls**: Too small d causes spatial smoothing (discrete maze d=25 fails); recommend starting with d=100; if rewards depend on specific features, prefer restricting B to that feature space (B(g)) over increasing d
- **Reward estimation pitfalls**: z_R = E[r·B] must be computed under the same distribution ρ used for training F/B (Appendix B.5); if the test distribution differs, the Cov_ρB matrix must be precomputed, otherwise the linear reward model is only approximate
- **Guidance for downstream teams**: FB representations suit multi-task/multi-reward scenarios, where one training serves arbitrary posteriori rewards; but for a single fixed reward, goal-oriented baselines (e.g., HER) may be superior—FB's trade-off is generality for specific-task performance
- **Variance mitigation**: If instability arises in large environments, consider combining HER to select goals relevant to the current state-action, or exploit update decoupling into moving-average estimates of two expectation products (requiring d×d matrices, left for future work)

## 개요

본 논문은 Forward-Backward(FB) 표현 학습 프레임워크를 제안하며, 비지도 방식으로 한 쌍의 함수 F와 B를 학습하여 사후에 지정된 임의의 보상 함수를 계획이나 미세 조정 없이 직접 최적 정책으로 매핑할 수 있게 한다. 저자는 DeepMind 등 기관 소속이며, 핵심 기여는 FB 표현이 이론적으로 존재하고 근사 오차에 강건하며, 이산/연속 미로, FetchReach, 픽셀 단위 Ms. Pacman에서 목표 지향 기준선을 능가하는 성능을 검증한 것이다.

## 그것이 바꾸는 것

전통적 강화 학습은 보상 함수를 사전 입력으로 간주하는 반면, FB 표현은 "환경 구조 학습"과 "특정 보상 최적화"를 완전히 분리하려 한다. 이는 무보상 RL의 패러다임을 변화시킨다: 이전의 HER은 목표 상태 집합만 처리할 수 있었고, 월드 모델은 새 보상에 대해 재계획이 필요했으며, [BBQ+18]의 일반화된 후속 특징은 사용자가 사전에 특징 함수를 제공해야 하고 선형 결합만 가능했다. FB 표현의 핵심 돌파구는 "보상과 무관한 압축 객체"를 학습하여 임의의 보상(조밀한 보상, 가중 결합, 제약이 있는 복잡한 형태 포함)이 단 한 번의 내적 연산으로 직접 준최적 정책을 얻을 수 있게 하여, 사후 보상 최적화의 계산 비용을 O(d)의 벡터 연산으로 줄인다는 점이다.

## 방법 분해

### 핵심 아키텍처
- F: S×A×Z→Z 및 B: S×A→Z (Z≃ℝᵈ) 학습, F(s,a,z)ᵀB(s′,a′)가 후속 측도 M^{π_z}(s,a,ds′,da′)/ρ(ds′,da′)를 근사하도록 함
- 정책은 π_z(s) := argmax_a F(s,a,z)ᵀz로 정의

### 핵심 대수적 유도
- 보상 r이 주어지면 z_R = ∫r(s,a)B(s,a)ρ(ds,da) 계산
- 그러면 Q*(s,a) = F(s,a,z_R)ᵀz_R, π_{z_R}은 최적 정책
- 증명 핵심: M^{π_z} = F_zᵀB이면 Q_r^{π_z} = F_zᵀBr, z_R := Br로 두면 π_{z_R}은 자신의 Q 함수에 대한 탐욕 정책

### 비지도 훈련 손실
- 후속 측도에 대한 벨만 방정식(수식 4) 기반, 갱신 규칙(수식 5):
  δθ := ∂_θ m_θ^π(s₀,a₀,s₀,a₀) + ∂_θ m_θ^π(s₀,a₀,s′,a′) × (γm_θ^π(s₁,a₁,s′,a′) - m_θ^π(s₀,a₀,s′,a′))
- 훈련 시 softmax 정책 π_z = softmax(F(s,a,z)ᵀz/τ) 사용, 온도 τ 고정
- 보조 손실로 B 정규화(F와 B의 비식별성 해결)

### 보상 추정 단계
- 블랙박스 보상: 탐색 정책을 재실행하여 r(s,a)B(s,a) 평균
- 명시적 보상(예: 목표 도달 및 금지 구역 회피): z_R = B(s₀,a₀) - λΣB(sᵢ,aᵢ) 직접 설정
- 대수적 보상: 리플레이 버퍼에서 r(s,a)B(s,a) 평균

### 사전 정보 통합
- 보상이 특징 g=φ(s,a)에만 의존하면 B는 g에 대해서만 훈련 가능, F는 전체 상태 사용, 이론적 보장은 불변(정리 4)

## 핵심 혁신

1. **단일 특징 대신 이중 표현 학습**: [BBQ+18]의 단일 특징 F와 달리 FB는 F와 B 두 표현을 학습하며, B는 "보상에서 z로의 매핑"을 인코딩하여 임의의 보상(선형 결합뿐만 아니라)이 B의 적분으로 직접 z_R을 얻을 수 있게 하여, 연속 공간에서 무한 특징이 필요한 한계를 돌파한다.

2. **계획 없는 최적 정책 복원**: 월드 모델은 각 새 보상에 대해 명시적 계획이 필요하지만, FB 표현은 z_R = Br의 대수적 연산으로 직접 최적 정책을 얻고, 사후 보상 최적화의 계산 복잡도를 O(d)로 줄이며, 이론적 보장(정리 2)은 완벽한 훈련 시 모든 보상에 대해 증명 가능한 최적성을 보여준다.

3. **근사 오차에 대한 강건성 이론**: 정리 8-9는 차선성과 FB 훈련 오차의 명시적 경계(3ε||r||∞/(1-γ))를 제시하고, 오차 행렬 E(z)가 최적 궤적에서 한 단계 벗어난 상태-행동에서의 핵심 역할을 밝혀 실제 배포에 이론적 보장을 제공한다.

## 경계 및 한계

- **탐색 문제 미해결**: 방법은 좋은 탐색 정책이 존재한다고 가정하며, 실험에서는 랜덤 z의 π_z로 탐색하여 모든 상태를 덮는다는 보장이 없음
- **정보 손실**: 보상이 d차원 벡터 z_R = E[r·B]로 압축되며, B와 무관한 보상은 0으로 간주됨; d는 최적화 가능한 보상 유형 수를 제어하며, 사전적으로 큰 d가 필요할 수 있음
- **암시적 편향**: rank-d 근사는 마르코프 체인 라플라시안 연산자의 작은 고유벡터(장거리 저주파 행동)를 선호하여 국소 보상 세부 사항이 흐려질 수 있음(그림 3)
- **분산 문제**: 대규모 환경에서 분산 문제가 발생할 수 있음(실험에서는 나타나지 않음), 완화 전략(예: 기대값 분리 활용)은 향후 과제로 남김
- **연속 공간 이론적 공백**: m^π는 t=0 항에 Dirac 특이 성분을 포함하여 연속 매개변수 모델은 약한 위상에서만 근사 가능하며, 저자는 "이론과 실제 문제를 발견하지 못했다"고 하지만 엄밀한 증명은 없음
- **B의 최적성에 대한 엄밀한 결과 부재**: 저자는 "we have no rigorous result here"라고 명시적으로 인정하며, B가 공간의 매끄러운 특징을 포착해야 한다는 것은 직관일 뿐

## 공학적 시사점

- **재현 체크리스트**: 먼저 z 샘플링 분포(재스케일링된 가우시안 × 코시), 온도 τ=200, Polyak α=0.95, 정규화 λ=1, 리플레이 버퍼 10⁶ 확인; 이러한 하이퍼파라미터는 안정성에 매우 중요
- **차원 선택 함정**: d가 너무 작으면 공간 평활화 발생(이산 미로 d=25 실패), d=100부터 시작 권장; 보상이 특정 특징에 의존하면 d를 늘리는 대신 B를 해당 특징 공간(B(g))으로 제한하는 것이 우선
- **보상 추정 함정**: z_R = E[r·B]는 F/B 훈련과 동일한 분포 ρ에서 계산해야 함(부록 B.5); 테스트 분포가 다르면 Cov_ρB 행렬을 사전 계산해야 하며, 그렇지 않으면 선형 보상 모델은 근사일 뿐
- **하류 팀 지침**: FB 표현은 다중 작업/다중 보상 시나리오에 적합하며, 한 번의 훈련으로 임의의 사후 보상을 서비스할 수 있음; 그러나 단일 고정 보상의 경우 목표 지향 기준선(예: HER)이 더 나을 수 있음 — FB의 트레이드오프는 범용성과 특정 작업 성능의 교환
- **분산 완화**: 대규모 환경에서 불안정이 발생하면 HER과 결합하여 현재 상태-행동과 관련된 목표를 선택하거나, 갱신을 두 기대값 곱의 이동 평균 추정으로 분리하는 방법을 시도할 수 있음(d×d 행렬 처리 필요, 향후 과제로 남김)
