## 概述

本文提出一个统一的多任务强化学习框架，将参考运动视为行为塑造的先验而非部署时的约束，通过联合训练参考引导模仿任务和目标条件泛化任务，使单一策略在Unitree G1人形机器人上同时获得类人运动质量和超出演示数据集的泛化能力。核心贡献在于用课程机制（辅助力缩放与任务混合调度）弥合参考跟踪与纯任务驱动RL之间的鸿沟，无需对抗目标、显式轨迹跟踪或相位变量。

## 它改变了什么

参考驱动方法长期存在一个根本性矛盾：要么严格跟随参考轨迹，在演示分布外脆弱不堪；要么完全抛弃参考，用稀疏任务奖励硬学，结果动作质量崩塌（如直接从50cm箱子跳下而非受控下降）。作者看穿了现有范式的共同盲点——参考运动被当作部署时的约束（轨迹、教师、分布），而非训练时的行为先验。这一区分是本质性的：约束限制策略的表达空间，先验则塑造策略的偏好而不限制其能力。

该框架真正改变了"参考数据如何参与策略学习"这一核心问题。通过将参考从策略输入中彻底移除（不观测参考轨迹、未来窗口或相位变量），策略被迫学习目标条件与运动行为之间的结构化映射，而非记忆特定演示。这使得运动质量与特定参考数据解耦，为泛化到训练分布之外的新任务条件提供了可能。

## 方法拆解

### 多任务联合训练
单一目标条件策略π(a_t|s_t, g_t)在两个任务上联合训练，共享观测和动作空间，但初始化、命令空间和奖励结构不同：
- **参考引导模仿任务**：参考轨迹定义密集模仿奖励r_t^imi = r_track + r_reg + r_surv，但参考不作为策略输入
- **目标条件泛化任务**：目标独立于参考采样，奖励仅反映任务成功r_t^gen = r_goal + r_reg + r_surv

### 观测与动作空间
- 策略观测：机器人状态s_t（关节配置/速度、投影重力、躯干角速度，字符中心坐标系）+ 目标g_t（水平面目标根位置2D坐标）
- 动作空间：关节级PD控制器，策略输出残差动作a_t，映射到命令关节位置：q_j^cmd = q̄ + Σa_t，其中q̄为默认关节位置，Σ为每自由度动作尺度对角矩阵。**省略参考关节位置作为前馈项**，以保留偏离参考的能力

### 课程机制
全局难度标量λ∈[0,1]在线自适应调整，控制两个关键机制：
1. **辅助力课程**：F_b = M(v̂̇ + k_p^v(p̂−p) + k_d^v(v̂−v) − g)，M_b = Iω̂̇ + k_p^ω I(Φ̂⊖Φ) + k_d^ω I(ω̂−ω) + ω×(Iω) − r_b,com×Mg，应用辅助扳手w_e = β(λ)[F_b; M_b]，β(λ) = (1−λ)β_max，β_max = 0.75
2. **任务混合调度**：p_imi(λ) = (1−λ)p_0 + λp_target，从p_0 = 1.0线性过渡到p_target = 0.5

### 训练架构
Isaac Lab中PPO，非对称actor-critic。Actor为三层MLP（1024, 512, 256），映射(s_t, g_t)到PD目标关节位置的高斯动作分布。Critic额外接收任务指示变量k_t和特权信息（完整根部状态、接触力、辅助扳手信号），仅用于价值估计。

## 关键创新

1. **参考作为先验而非约束**：这是范式层面的创新。参考运动仅通过密集奖励信号塑造行为偏好，从不进入策略输入或作为前馈项。这使得策略在部署时完全不受参考数据束缚，能够适应训练分布之外的新条件。

2. **统一课程标量λ同时控制辅助力和任务混合**：单一难度变量协调两个互补机制——训练早期用强辅助力防止灾难性失败，同时以高模仿概率塑造运动质量；随训练推进，辅助力减弱、泛化任务占比增加。这种协同设计避免了分别调参的复杂性。

3. **无对抗、无相位变量的简洁设计**：相比ZEST等需要对抗训练或相位变量的方法，本框架仅需标准PPO和精心设计的奖励结构，大幅降低训练复杂度和复现门槛。

## Overview

This paper proposes a unified multi-task reinforcement learning framework that treats reference motion as a behavioral prior for training rather than a constraint during deployment. By jointly training a reference-guided imitation task and a goal-conditioned generalization task, a single policy achieves both human-like motion quality and generalization beyond the demonstration dataset on the Unitree G1 humanoid robot. The core contribution lies in using a curriculum mechanism (assistive force scaling and task mixing scheduling) to bridge the gap between reference tracking and pure task-driven RL, without requiring adversarial objectives, explicit trajectory tracking, or phase variables.

## What It Changes

Reference-driven methods have long suffered from a fundamental contradiction: either strictly following reference trajectories, which are fragile outside the demonstration distribution, or completely discarding references and hard-learning with sparse task rewards, resulting in collapsed motion quality (e.g., jumping directly off a 50cm box instead of descending in a controlled manner). The authors see through a common blind spot in existing paradigms—reference motion is treated as a deployment-time constraint (trajectory, teacher, distribution) rather than a training-time behavioral prior. This distinction is essential: constraints limit the policy's expressible space, while priors shape the policy's preferences without limiting its capabilities.

The framework fundamentally changes the core question of "how reference data participates in policy learning." By completely removing the reference from the policy input (no reference trajectory, future window, or phase variables observed), the policy is forced to learn a structured mapping between goal conditions and motor behaviors, rather than memorizing specific demonstrations. This decouples motion quality from specific reference data, enabling generalization to new task conditions beyond the training distribution.

## Method Breakdown

### Multi-Task Joint Training
A single goal-conditioned policy π(a_t|s_t, g_t) is jointly trained on two tasks sharing observation and action spaces, but differing in initialization, command space, and reward structure:
- **Reference-Guided Imitation Task**: Reference trajectories define a dense imitation reward r_t^imi = r_track + r_reg + r_surv, but the reference is not used as policy input
- **Goal-Conditioned Generalization Task**: Goals are sampled independently of the reference, with rewards reflecting only task success r_t^gen = r_goal + r_reg + r_surv

### Observation and Action Spaces
- Policy observation: robot state s_t (joint configuration/velocity, projected gravity, torso angular velocity, character-centric coordinate frame) + goal g_t (2D goal root position in the horizontal plane)
- Action space: joint-level PD controller, with the policy outputting residual actions a_t mapped to commanded joint positions: q_j^cmd = q̄ + Σa_t, where q̄ is the default joint position and Σ is a per-DoF action scale diagonal matrix. **The reference joint position is omitted as a feedforward term** to preserve the ability to deviate from the reference

### Curriculum Mechanism
A global difficulty scalar λ∈[0,1] is adaptively adjusted online, controlling two key mechanisms:
1. **Assistive Force Curriculum**: F_b = M(v̂̇ + k_p^v(p̂−p) + k_d^v(v̂−v) − g), M_b = Iω̂̇ + k_p^ω I(Φ̂⊖Φ) + k_d^ω I(ω̂−ω) + ω×(Iω) − r_b,com×Mg, applying an assistive wrench w_e = β(λ)[F_b; M_b], where β(λ) = (1−λ)β_max and β_max = 0.75
2. **Task Mixing Schedule**: p_imi(λ) = (1−λ)p_0 + λp_target, linearly transitioning from p_0 = 1.0 to p_target = 0.5

### Training Architecture
PPO in Isaac Lab with asymmetric actor-critic. The actor is a three-layer MLP (1024, 512, 256) mapping (s_t, g_t) to a Gaussian action distribution over PD target joint positions. The critic additionally receives a task indicator variable k_t and privileged information (full root state, contact forces, assistive wrench signals), used only for value estimation.

## Key Innovations

1. **Reference as Prior, Not Constraint**: This is a paradigm-level innovation. Reference motion shapes behavioral preferences only through dense reward signals, never entering the policy input or serving as a feedforward term. This allows the policy to remain completely unconstrained by reference data at deployment, adapting to new conditions beyond the training distribution.

2. **Unified Curriculum Scalar λ Controlling Both Assistive Force and Task Mixing**: A single difficulty variable coordinates two complementary mechanisms—early training uses strong assistive forces to prevent catastrophic failures while maintaining a high imitation probability to shape motion quality; as training progresses, assistive forces diminish and the generalization task share increases. This synergistic design avoids the complexity of tuning each component separately.

3. **Clean Design Without Adversarial Objectives or Phase Variables**: Compared to methods like ZEST that require adversarial training or phase variables, this framework only needs standard PPO and carefully designed reward structures, significantly reducing training complexity and reproduction barriers.

## Boundaries and Limitations

- **Perception Not Integrated**: Hardware experiments rely on MoCap for global state feedback, without integrating onboard external perception, limiting autonomy in real deployment
- **Limited Goal Interface**: Only root goal position and discrete behavior labels are supported, not extended to richer task descriptions
- **Skill Library Scale**: Only three skills are validated (walk-jump, walk-climb, climb-down), each using a single reference motion, without testing multiple reference motions or large-scale datasets
- **Long-Horizon Composition**: Multi-skill composition is only demonstrated in simulation, without validating long-horizon compositional behavior on real hardware
- **High-Level Decision Making**: Learned high-level policies do not replace hand-designed state machines; long-horizon decision-making still relies on manual orchestration

## Engineering Insights

- **Check Curriculum Hyperparameters First**: β_max = 0.75, p_0 = 1.0, p_target = 0.5 are key starting points. The λ update criterion (avoiding early termination + loose tracking consistency) is critical for training stability and should be prioritized for reproduction
- **Most Common Pitfall: Reward Weights**. The σ_i normalization constants in the tracking reward (e.g., base position σ₁ = 0.4, joint position σ₅ = 0.3·√n_j) have a significant impact on motion quality and require careful verification. In the regularization terms, the foot slip penalty (−2.0) and flat ankle penalty (−20.0) are crucial for preventing unnatural gaits
- **PD Gains Not Specified Numerically**: Only stated as specified per the procedure in reference [25]. These must be determined during reproduction; it is recommended to start from default Unitree G1 parameters and perform sensitivity analysis
- **Control Frequency of 50Hz** (simulation step 0.004s, downsampled by 5) is a hard constraint; downstream deployment must ensure inference latency meets this frequency
- **Domain Randomization Range** (friction 𝒰(0.8, 2.5), torso mass ±4kg, external push 0.4m/s) is key to sim-to-real transfer and should be fully reproduced rather than simplified
- **Privileged Information in Asymmetric Critic** (full root state, contact forces, assistive wrench signals) is used only for training; the actor does not rely on these at deployment, but the observation spaces for training and deployment must be strictly consistent

## 개요

본 논문은 참조 동작을 배포 시 제약 조건이 아닌 행동 형성의 사전 지식으로 간주하는 통합 다중 작업 강화 학습 프레임워크를 제안한다. 참조 유도 모방 작업과 목표 조건 일반화 작업을 공동 훈련함으로써, 단일 정책이 Unitree G1 휴머노이드 로봇에서 인간과 유사한 동작 품질과 데모 데이터셋을 넘어서는 일반화 능력을 동시에 획득하게 한다. 핵심 기여는 보조 힘 스케일링과 작업 혼합 스케줄링을 포함한 커리큘럼 메커니즘을 통해 참조 추적과 순수 작업 중심 RL 사이의 간극을 메우는 것이며, 적대적 목표, 명시적 궤적 추적 또는 위상 변수가 필요 없다.

## 무엇을 바꾸는가

참조 기반 방법은 오랫동안 근본적인 모순을 안고 있었다: 참조 궤적을 엄격히 따르면 데모 분포 밖에서 취약해지고, 참조를 완전히 버리고 희소 작업 보상으로 억지로 학습하면 동작 품질이 붕괴된다(예: 통제된 하강 대신 50cm 상자에서 직접 점프). 저자들은 기존 패러다임의 공통된 맹점을 간파했다—참조 동작이 배포 시 제약 조건(궤적, 교사, 분포)으로 취급되었지, 훈련 시 행동 사전 지식으로 취급되지 않았다는 점이다. 이 구분은 본질적이다: 제약 조건은 정책의 표현 공간을 제한하지만, 사전 지식은 정책의 능력을 제한하지 않으면서 선호도를 형성한다.

이 프레임워크는 "참조 데이터가 정책 학습에 어떻게 참여하는가"라는 핵심 문제를 진정으로 변화시킨다. 참조를 정책 입력에서 완전히 제거함으로써(참조 궤적, 미래 창, 위상 변수를 관측하지 않음), 정책은 특정 데모를 암기하는 대신 목표 조건과 운동 행동 사이의 구조적 매핑을 학습하도록 강제된다. 이를 통해 동작 품질이 특정 참조 데이터와 분리되어 훈련 분포를 벗어난 새로운 작업 조건으로의 일반화가 가능해진다.

## 방법 분석

### 다중 작업 공동 훈련
단일 목표 조건 정책 π(a_t|s_t, g_t)는 두 작업에서 공동 훈련되며, 관측 및 행동 공간을 공유하지만 초기화, 명령 공간 및 보상 구조는 다르다:
- **참조 유도 모방 작업**: 참조 궤적은 밀집 모방 보상 r_t^imi = r_track + r_reg + r_surv를 정의하지만, 참조는 정책 입력으로 사용되지 않는다
- **목표 조건 일반화 작업**: 목표는 참조와 독립적으로 샘플링되며, 보상은 작업 성공만 반영한다 r_t^gen = r_goal + r_reg + r_surv

### 관측 및 행동 공간
- 정책 관측: 로봇 상태 s_t(관절 구성/속도, 투영 중력, 몸통 각속도, 캐릭터 중심 좌표계) + 목표 g_t(수평면 목표 루트 위치 2D 좌표)
- 행동 공간: 관절 수준 PD 제어기, 정책은 잔차 행동 a_t를 출력하여 명령 관절 위치에 매핑: q_j^cmd = q̄ + Σa_t, 여기서 q̄는 기본 관절 위치, Σ는 자유도별 행동 스케일 대각 행렬이다. **참조 관절 위치를 피드포워드 항으로 생략**하여 참조에서 벗어날 수 있는 능력을 보존한다

### 커리큘럼 메커니즘
전역 난이도 스칼라 λ∈[0,1]는 온라인으로 적응적으로 조정되며 두 가지 핵심 메커니즘을 제어한다:
1. **보조 힘 커리큘럼**: F_b = M(v̂̇ + k_p^v(p̂−p) + k_d^v(v̂−v) − g), M_b = Iω̂̇ + k_p^ω I(Φ̂⊖Φ) + k_d^ω I(ω̂−ω) + ω×(Iω) − r_b,com×Mg, 보조 렌치 w_e = β(λ)[F_b; M_b] 적용, β(λ) = (1−λ)β_max, β_max = 0.75
2. **작업 혼합 스케줄링**: p_imi(λ) = (1−λ)p_0 + λp_target, p_0 = 1.0에서 p_target = 0.5로 선형 전환

### 훈련 아키텍처
Isaac Lab에서 PPO, 비대칭 actor-critic. Actor는 3층 MLP(1024, 512, 256)로 (s_t, g_t)를 PD 목표 관절 위치의 가우시안 행동 분포에 매핑한다. Critic은 추가로 작업 지시 변수 k_t와 특권 정보(전체 루트 상태, 접촉 힘, 보조 렌치 신호)를 수신하며, 가치 추정에만 사용된다.

## 핵심 혁신

1. **참조를 제약 조건이 아닌 사전 지식으로**: 이는 패러다임 수준의 혁신이다. 참조 동작은 밀집 보상 신호를 통해서만 행동 선호도를 형성하며, 정책 입력이나 피드포워드 항으로 절대 들어가지 않는다. 이를 통해 정책은 배포 시 참조 데이터에 전혀 구속되지 않고 훈련 분포를 벗어난 새로운 조건에 적응할 수 있다.

2. **단일 커리큘럼 스칼라 λ가 보조 힘과 작업 혼합을 동시에 제어**: 단일 난이도 변수가 두 가지 상호 보완 메커니즘을 조정한다—훈련 초기에는 강한 보조 힘으로 치명적 실패를 방지하면서 높은 모방 확률로 동작 품질을 형성하고, 훈련이 진행됨에 따라 보조 힘은 약화되고 일반화 작업 비중이 증가한다. 이러한 협력 설계는 개별 파라미터 튜닝의 복잡성을 피한다.

3. **적대적 훈련이나 위상 변수가 없는 간결한 설계**: ZEST 등 적대적 훈련이나 위상 변수가 필요한 방법과 달리, 본 프레임워크는 표준 PPO와 정교하게 설계된 보상 구조만 필요로 하여 훈련 복잡성과 재현 장벽을 크게 낮춘다.

## 실험 및 결과

### 기준선 비교(표 I, 성공률)

| 작업 | 조건 | ZEST mocap | Tabula rasa RL | Ours |
|------|------|-----------|----------------|------|
| Walk-Jump | Nominal | 0.98 | 1.00 | **1.00** |
| Walk-Jump | Beyond Nominal | 0.17 | 0.54 | **0.62** |
| Walk-Climb | Nominal | 0.92 | 1.00 | **1.00** |
| Walk-Climb | Beyond Nominal | 0.57 | 0.53 | **0.76** |
| Climb-Down | Nominal | 0.90 | 0.91 | **1.00** |
| Climb-Down | Beyond Nominal | 0.90 | 0.91 | **0.98** |

### 소거 연구(표 II, Beyond Nominal 성공률)

| 작업 | w/o task curriculum | w/o imitation | w/o generalization | Ours |
|------|---------------------|---------------|-------------------|------|
| Walk-Jump | 0.00 | 0.00 | 0.27 | **0.62** |
| Walk-Climb | 0.00 | 0.00 | 0.53 | **0.76** |
| Climb-Down | 0.69 | 0.97 | 0.70 | **0.98** |

핵심 발견: 작업 커리큘럼을 제거하면 walk-jump와 walk-climb가 완전히 실패(성공률 0.00)하여 커리큘럼 메커니즘이 접촉이 풍부한 기술 학습에 필수적임을 보여준다; 모방 작업을 제거하면 동작 품질이 붕괴한다(root R 최대 4.75, joint pos q 최대 12.97); 일반화 작업을 제거하면 표준 조건에서는 거의 손실이 없지만 Beyond Nominal에서는 현저히 감소한다(walk-jump가 0.62에서 0.27로).

정성적 관찰: tabula rasa RL은 climb-down에서 통제된 하강 대신 50cm 높이 상자에서 직접 점프한다; 본 방법은 walk-jump와 walk-climb에서 약 2초 만에 작업을 완료하는 반면, 참조 동작은 일반적으로 10초가 필요하여 정책이 단순히 참조를 재현하는 것이 아니라 더 효율적인 운동 전략을 학습했음을 보여준다.

## 경계 및 한계

- **인식 미통합**: 하드웨어 실험은 MoCap에 의존하여 전역 상태 피드백을 얻으며, 온보드 외부 인식이 통합되지 않아 실제 배포의 자율성이 제한된다
- **목표 인터페이스 제한**: 루트 목표 위치와 이산 행동 레이블만 지원하며, 더 풍부한 작업 설명으로 확장되지 않았다
- **기술 라이브러리 규모**: 세 가지 기술(walk-jump, walk-climb, climb-down)만 검증했으며, 각각 단일 참조 동작을 사용하여 다중 참조 동작이나 대규모 데이터셋을 테스트하지 않았다
- **장기간 조합**: 다중 기술 조합은 시뮬레이션에서만 시연되었으며, 실제 하드웨어에서 장기 조합 동작이 검증되지 않았다
- **고수준 의사결정**: 학습된 고수준 정책으로 수동 설계 상태 머신을 대체하지 않았으며, 장기간 의사결정은 여전히 수동 편성에 의존한다

## 공학적 시사점

- **커리큘럼 하이퍼파라미터를 먼저 확인**: β_max = 0.75, p_0 = 1.0, p_target = 0.5가 핵심 출발점이다. λ의 업데이트 기준(조기 종료 방지 + 완화된 추적 일관성)은 훈련 안정성에至关重要하므로 이 메커니즘을 우선적으로 재현하는 것이 좋다
- **가장 함정에 빠지기 쉬운 부분: 보상 가중치**. 추적 보상의 σ_i 정규화 상수(예: 베이스 위치 σ₁ = 0.4, 관절 위치 σ₅ = 0.3·√n_j)는 동작 품질에 큰 영향을 미치므로 신중히 확인해야 한다. 정규화 항의 발 미끄러짐 패널티(−2.0)와 발목 평평 패널티(−20.0)는 부자연스러운 보행을 방지하는 데 필수적이다
- **PD 이득은 구체적인 수치가 제공되지 않았으며**, 문헌[25] 절차에 따라 지정된다고만 설명되어 있다. 재현 시 직접 결정해야 하며, 기본 Unitree G1 파라미터에서 시작하여 민감도 분석을 수행할 것을 권장한다
- **제어 주파수 50Hz**(시뮬레이션 스텝 0.004s, 다운샘플링 5)는 하드 제약이며, 하류 배포 시 추론 지연이 이 주파수를 충족하는지 확인해야 한다
- **도메인 무작위화 범위**(마찰 𝒰(0.8, 2.5), 몸통 질량 ±4kg, 외부 추력 0.4m/s)는 sim-to-real 전이의 핵심이므로 단순화하지 말고 완전히 재현하는 것이 좋다
- **비대칭 critic의 특권 정보**(전체 루트 상태, 접촉 힘, 보조 렌치 신호)는 훈련에만 사용되며, 배포 시 actor는 이에 의존하지 않지만 훈련과 배포의 관측 공간이 엄격히 일치하는지 확인해야 한다
