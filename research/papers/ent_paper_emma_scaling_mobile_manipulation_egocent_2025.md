## 概述

EMMA 是一个端到端模仿学习框架，用 Meta Project Aria 眼镜采集的人类以自我为中心移动操作数据（RGB、手部姿态、头部姿态）替代昂贵的移动遥操作数据，训练差分驱动机器人完成移动操作任务。核心贡献在于通过导航重定向、阶段识别和跨具身联合训练，实现了仅用 1 小时人类数据即可超越 1 小时遥操作数据 30% 成功率的效果。

## 它改变了什么

移动操作模仿学习长期被 Mobile ALOHA 这类遥操作框架卡住脖子——采集一套移动操作演示需要双人协作（一人控臂、一人控车），数据量上不去，策略泛化自然无从谈起。EMMA 真正改变的是数据采集的“成本结构”：把人类戴眼镜走路干活这种近乎零成本的日常行为变成训练信号，让移动操作学习从“实验室奢侈品”变成“可规模化采集”的范式。

这背后的关键判断是：导航知识（去哪里、怎么走）本质上与具身形态无关，人类走路轨迹经过运动学重定向后可以直接迁移到差分驱动机器人；而操作技能（抓取、放置）则继续依赖静态机器人数据。这种“导航纯人类、操作双源”的拆分，避开了跨具身学习中最难的全身动作映射问题，是 EMMA 能work的根本原因。

## 方法拆解

### 数据采集与观测空间
- 人类数据：Project Aria 眼镜采集第一人称 RGB（宽视场）、3D 双手姿态 H_p ∈ SE(3)×SE(3)、SLAM 估计的头部姿态 H_d ∈ SE(3)
- 机器人数据：两个倒置安装的 ViperX 300 机械臂（6-DoF）+ AgileX TRACER 差速底盘，腕部 Intel Realsense D405 相机
- 共享模态：第一人称 RGB 图像 I_ego 是跨具身对齐的锚点

### 导航重定向（关键设计）
1. 将头部姿态投影到地面，提取 2D 基座姿态 h_base^t ∈ SE(2)
2. 维护位移阈值 d_thresh=0.25m 的稀疏航点历史 W_t
3. 通过约束优化求解差分驱动速度命令 z（公式 1-4）：
   - 优化目标：最小化位置误差（λ_pos=32.0）、偏航误差（λ_yaw=2.0）、速度平滑性（λ_smooth=1.0）
   - 约束：v ∈ [−1.0, 1.0] m/s，ω ∈ [−π, π] rad/s
   - 积分步长 Δt = 0.02 × STEP 秒

### 阶段识别（无监督）
- 基于运动动力学：手部速度/头部速度比 > τ_ratio=2.0 且头部速度 < τ_head=0.4 m/s → 操作阶段
- 对头部位置拟合 K=2 分量 GMM，概率密度 < τ_pdf=10⁻³ → 操作阶段
- 最小时长过滤：τ_duration=30 帧（1 秒），防止振荡切换

### 统一架构
- 每模态专用 stem（图像用 ResNet-18，低维状态用 MLP）
- 交叉注意力 token 化（每模态 16 个潜在查询，8 头注意力）
- 16 层 decoder-only Transformer 主干（隐藏维度 256，8 头）
- 动作头：机器人关节（ℝ^{K×14}）、人类笛卡尔末端执行器（ℝ^{K×3}）、导航动作（(x,y,ω) ∈ ℝ^{K×3}）、阶段预测（p ∈ {0,1}^K）
- 动作块长度统一为 100，导航 10 步线性插值到 100（x,y 线性，yaw 用 atan2）

### 联合训练策略
- 人类批次：激活人类本体感觉、共享视觉 stem、人类操作头、导航头、阶段头
- 机器人批次：激活机器人本体感觉、腕部图像 stem、共享视觉 stem、机器人操作头
- 每个数据源独立 Z-score 归一化处理分布差异

## 关键创新

1. **导航知识的纯人类迁移**：现有跨具身工作（如 EgoMimic）只做桌面操作，EMMA 首次证明人类走路轨迹经运动学重定向后可直接驱动差分机器人，且效果优于遥操作数据。这打破了移动操作对遥操作数据的刚性依赖。

2. **无监督阶段识别机制**：通过手部/头部速度比 + GMM 空间聚类自动区分操作与导航阶段，无需人工标注。阶段感知控制（操作时导航动作插值到第一个航点）解决了人类数据中“边走边操作”的混合行为问题，消融实验显示移除该机制导致完全失败。

3. **双源数据联合训练架构**：人类数据提供导航+操作语义，静态机器人数据提供精确操作控制，共享第一人称视觉 stem 作为跨具身桥接。这种“导航人类、操作机器人”的职责分离，比端到端跨具身映射更工程可行。

## 工程启示

1. **先核对数据采集协议**：手部跟踪置信度过滤（<0 丢弃）和航点稀疏化（≥0.25m）是数据质量的关键，复现时务必严格遵循，否则阶段识别和导航重定向都会崩。

2. **阶段识别是最大坑点**：消融显示移除阶段识别直接归零。复现时先单独验证 GMM 聚类和速度比阈值在你的数据上是否产生合理的阶段划分，再端到端训练。

3. **导航重定向的优化权重敏感**：λ_pos=32.0 远大于 λ_yaw=2.0，说明位置精度优先于朝向。如果你的任务需要精确朝向（如对准货架），可能需要调整权重。

4. **数据量规划**：15 分钟人类数据已有 36% 成功率，1 小时到 82%。建议先收集 30 分钟验证 pipeline，再决定是否扩展到 1 小时。

5. **硬件对齐**：人类数据用 SLAM 估计相机位姿，机器人用手眼标定，两套坐标系必须严格对齐到观测时刻的第一人称相机系，否则跨具身迁移会引入系统性偏差。

## Overview

EMMA is an end-to-end imitation learning framework that uses egocentric mobile manipulation data collected from humans wearing Meta Project Aria glasses (RGB, hand poses, head poses) to replace expensive mobile teleoperation data, training differential-drive robots to complete mobile manipulation tasks. The core contribution lies in navigation retargeting, phase identification, and cross-embodiment joint training, achieving a 30% success rate improvement over 1 hour of teleoperation data using only 1 hour of human data.

## What It Changes

Mobile manipulation imitation learning has long been bottlenecked by teleoperation frameworks like Mobile ALOHA—collecting a single mobile manipulation demonstration requires two-person collaboration (one controlling the arm, one controlling the base), limiting data scale and thus policy generalization. What EMMA truly changes is the "cost structure" of data collection: turning near-zero-cost daily activities of humans wearing glasses and performing tasks into training signals, shifting mobile manipulation learning from a "laboratory luxury" to a "scalable collection" paradigm.

The key insight behind this is: navigation knowledge (where to go, how to get there) is inherently embodiment-agnostic, and human walking trajectories can be directly transferred to differential-drive robots after kinematic retargeting; while manipulation skills (grasping, placing) continue to rely on static robot data. This "pure human navigation, dual-source manipulation" split avoids the hardest whole-body motion mapping problem in cross-embodiment learning, and is the fundamental reason EMMA works.

## Method Breakdown

### Data Collection and Observation Space
- Human data: Project Aria glasses capture first-person RGB (wide field of view), 3D two-hand poses H_p ∈ SE(3)×SE(3), and SLAM-estimated head pose H_d ∈ SE(3)
- Robot data: two inverted-mounted ViperX 300 robotic arms (6-DoF) + AgileX TRACER differential-drive base, wrist-mounted Intel Realsense D405 cameras
- Shared modality: first-person RGB image I_ego serves as the cross-embodiment alignment anchor

### Navigation Retargeting (Key Design)
1. Project head pose onto the ground plane to extract 2D base pose h_base^t ∈ SE(2)
2. Maintain a sparse waypoint history W_t with displacement threshold d_thresh=0.25m
3. Solve for differential-drive velocity commands z via constrained optimization (Equations 1-4):
   - Optimization objective: minimize position error (λ_pos=32.0), yaw error (λ_yaw=2.0), velocity smoothness (λ_smooth=1.0)
   - Constraints: v ∈ [−1.0, 1.0] m/s, ω ∈ [−π, π] rad/s
   - Integration step size Δt = 0.02 × STEP seconds

### Phase Identification (Unsupervised)
- Based on motion dynamics: hand velocity/head velocity ratio > τ_ratio=2.0 and head velocity < τ_head=0.4 m/s → manipulation phase
- Fit K=2 component GMM to head positions, probability density < τ_pdf=10⁻³ → manipulation phase
- Minimum duration filtering: τ_duration=30 frames (1 second), preventing oscillation between phases

### Unified Architecture
- Per-modality dedicated stems (ResNet-18 for images, MLP for low-dimensional states)
- Cross-attention tokenization (16 latent queries per modality, 8 attention heads)
- 16-layer decoder-only Transformer backbone (hidden dimension 256, 8 heads)
- Action heads: robot joints (ℝ^{K×14}), human Cartesian end-effectors (ℝ^{K×3}), navigation actions ((x,y,ω) ∈ ℝ^{K×3}), phase prediction (p ∈ {0,1}^K)
- Action chunk length uniformly set to 100, navigation linearly interpolated from 10 steps to 100 (x,y linear, yaw via atan2)

### Joint Training Strategy
- Human batches: activate human proprioception, shared vision stem, human manipulation head, navigation head, phase head
- Robot batches: activate robot proprioception, wrist camera stem, shared vision stem, robot manipulation head
- Each data source independently Z-score normalized to handle distribution differences

## Key Innovations

1. **Pure human transfer of navigation knowledge**: Existing cross-embodiment works (e.g., EgoMimic) only handle tabletop manipulation. EMMA is the first to demonstrate that human walking trajectories, after kinematic retargeting, can directly drive differential robots with better performance than teleoperation data. This breaks the rigid dependence of mobile manipulation on teleoperation data.

2. **Unsupervised phase identification mechanism**: Automatically distinguishes manipulation and navigation phases via hand/head velocity ratio + GMM spatial clustering, requiring no manual annotation. Phase-aware control (interpolating navigation actions to the first waypoint during manipulation) resolves the "walking while manipulating" mixed behavior in human data; ablation studies show removing this mechanism leads to complete failure.

3. **Dual-source data joint training architecture**: Human data provides navigation + manipulation semantics, static robot data provides precise manipulation control, with a shared first-person vision stem serving as the cross-embodiment bridge. This "human navigation, robot manipulation" responsibility split is more engineering-feasible than end-to-end cross-embodiment mapping.

## Boundaries and Limitations

The paper does not explicitly discuss limitations. Inferred boundaries from the method itself:
- Navigation retargeting assumes human walking is sufficiently close to differential-drive kinematics, which may fail for scenarios requiring in-place rotation or narrow passages
- Phase identification relies on hand/head velocity ratios, which may misclassify edge cases of "stationary manipulation" and "manipulation while walking"
- Manipulation skills still depend on static robot data; cross-embodiment transfer of manipulation itself remains unsolved
- Does not address multi-robot collaboration, long-term deployment stability, dynamic obstacle avoidance, or other practical deployment issues
- Training configuration (epochs, batch size, learning rate) is not disclosed, creating reproducibility uncertainty

## Engineering Insights

1. **Verify data collection protocols first**: Hand tracking confidence filtering (<0 discarded) and waypoint sparsification (≥0.25m) are critical to data quality. Strictly follow these during reproduction, otherwise both phase identification and navigation retargeting will collapse.

2. **Phase identification is the biggest pitfall**: Ablation shows removing it leads to complete failure. During reproduction, first independently validate whether GMM clustering and velocity ratio thresholds produce reasonable phase segmentation on your data before end-to-end training.

3. **Navigation retargeting optimization weights are sensitive**: λ_pos=32.0 is much larger than λ_yaw=2.0, indicating position accuracy takes priority over orientation. If your task requires precise orientation (e.g., aligning with shelves), you may need to adjust the weights.

4. **Data volume planning**: 15 minutes of human data already achieves 36% success rate, reaching 82% at 1 hour. It is recommended to collect 30 minutes first to validate the pipeline before deciding whether to scale to 1 hour.

5. **Hardware alignment**: Human data uses SLAM-estimated camera poses, robot data uses hand-eye calibration. The two coordinate systems must be strictly aligned to the first-person camera frame at observation time; otherwise, cross-embodiment transfer will introduce systematic bias.

## 개요

EMMA는 Meta Project Aria 안경으로 수집한 인간의 자기중심적 이동 조작 데이터(RGB, 손 자세, 머리 자세)로 값비싼 이동 원격 조작 데이터를 대체하여, 차동 구동 로봇이 이동 조작 작업을 수행하도록 훈련하는 엔드투엔드 모방 학습 프레임워크입니다. 핵심 기여는 내비게이션 리타게팅, 단계 인식, 교차 체현 공동 훈련을 통해 단 1시간의 인간 데이터만으로 1시간의 원격 조작 데이터보다 30% 높은 성공률을 달성한 것입니다.

## 무엇을 바꾸었는가

이동 조작 모방 학습은 오랫동안 Mobile ALOHA와 같은 원격 조작 프레임워크에 발목이 잡혀 있었습니다. 이동 조작 시연을 수집하려면 두 사람이 협력해야 하고(한 명은 팔 제어, 한 명은 차체 제어), 데이터 양이 늘지 않으니 정책 일반화는 논할 수 없었습니다. EMMA가 실제로 바꾼 것은 데이터 수집의 "비용 구조"입니다. 인간이 안경을 쓰고 걸어 다니며 일하는 거의 비용이 들지 않는 일상 행동을 훈련 신호로 바꾸어, 이동 조작 학습을 "실험실 사치품"에서 "대규모 수집 가능한" 패러다임으로 전환했습니다.

이면의 핵심 판단은 내비게이션 지식(어디로 갈지, 어떻게 갈지)이 본질적으로 체현 형태와 무관하며, 인간의 보행 궤적은 운동학적 리타게팅을 거쳐 차동 구동 로봇에 직접 전이될 수 있다는 것입니다. 반면 조작 기술(파지, 배치)은 계속 정적 로봇 데이터에 의존합니다. 이러한 "내비게이션은 순수 인간, 조작은 이중 소스"의 분리는 교차 체현 학습에서 가장 어려운 전신 동작 매핑 문제를 피하며, 이것이 EMMA가 작동할 수 있는 근본 이유입니다.

   - 제약: v ∈ [−1.0, 1.0] m/s, ω ∈ [−π, π] rad/s
   - 적분 스텝 Δt = 0.02 × STEP 초

### 단계 인식(비지도)
- 운동 역학 기반: 손 속도/머리 속도 비율 > τ_ratio=2.0 및 머리 속도 < τ_head=0.4 m/s → 조작 단계
- 머리 위치에 K=2 성분 GMM 피팅, 확률 밀도 < τ_pdf=10⁻³ → 조작 단계
- 최소 지속 시간 필터: τ_duration=30프레임(1초), 진동 전환 방지

### 통합 아키텍처
- 모달리티별 전용 stem(이미지는 ResNet-18, 저차원 상태는 MLP)
- 교차 어텐션 토큰화(모달리티당 16개 잠재 쿼리, 8헤드 어텐션)
- 16레이어 decoder-only Transformer 백본(은닉 차원 256, 8헤드)
- 액션 헤드: 로봇 관절(ℝ^{K×14}), 인간 데카르트 엔드 이펙터(ℝ^{K×3}), 내비게이션 액션((x,y,ω) ∈ ℝ^{K×3}), 단계 예측(p ∈ {0,1}^K)
- 액션 블록 길이는 100으로 통일, 내비게이션 10스텝을 100으로 선형 보간(x,y는 선형, yaw는 atan2 사용)

### 공동 훈련 전략
- 인간 배치: 인간 고유수용감각, 공유 비전 stem, 인간 조작 헤드, 내비게이션 헤드, 단계 헤드 활성화
- 로봇 배치: 로봇 고유수용감각, 손목 이미지 stem, 공유 비전 stem, 로봇 조작 헤드 활성화
- 각 데이터 소스는 독립적으로 Z-score 정규화하여 분포 차이 처리

## 핵심 혁신

1. **내비게이션 지식의 순수 인간 전이**: 기존 교차 체현 연구(예: EgoMimic)는 데스크톱 조작만 다루었지만, EMMA는 인간의 보행 궤적이 운동학적 리타게팅을 거쳐 차동 로봇을 직접 구동할 수 있고 원격 조작 데이터보다 효과적임을 처음으로 증명했습니다. 이는 이동 조작의 원격 조작 데이터에 대한 경직적 의존을 깨뜨렸습니다.

2. **비지도 단계 인식 메커니즘**: 손/머리 속도 비율 + GMM 공간 클러스터링으로 조작과 내비게이션 단계를 자동 구분하며, 수동 주석이 필요 없습니다. 단계 인식 제어(조작 시 내비게이션 액션을 첫 번째 웨이포인트로 보간)는 인간 데이터의 "걸으면서 조작" 혼합 행동 문제를 해결하며, 절제 실험에서 이 메커니즘 제거 시 완전 실패가 발생함을 보여줍니다.

3. **이중 소스 데이터 공동 훈련 아키텍처**: 인간 데이터는 내비게이션+조작 의미를 제공하고, 정적 로봇 데이터는 정밀한 조작 제어를 제공하며, 공유 1인칭 비전 stem이 교차 체현 브리지 역할을 합니다. 이러한 "내비게이션은 인간, 조작은 로봇"의 역할 분리는 엔드투엔드 교차 체현 매핑보다 공학적으로 더 실현 가능합니다.

## 실험 및 결과

### 주요 결과(Handover Wine 작업, 고정 100개 정적 로봇 시연)

| 구성 | 성공률 |
|------|--------|
| EMMA(1시간 인간 데이터) | 82% |
| Mobile ALOHA(1시간 원격 조작 데이터) | 52% |
| EMMA 운동학적 리타게팅 제거 | 52%(-30%) |
| EMMA 단계 인식 제거 | 0%(완전 실패) |

### 데이터 확장성(H3)

| 데이터량 | EMMA | Mobile ALOHA | 격차 |
|--------|------|--------------|------|
| 15분 | 36% | 26% | 10% |
| 60분 | 82% | 52% | 30% |

### 시나리오 일반화
- 새 환경(5m×2m, 수신자 무작위 위치): EMMA 54%, Mobile ALOHA는 초기 파지도 완료 불가
- 총 950회 rollout 평가(구성당 50회, 95% 신뢰 구간)

핵심 의미: EMMA의 우위는 데이터량이 증가할수록 확대되며(10%→30%), 인간 데이터가 규모화 후 정보 밀도가 원격 조작 데이터보다 현저히 높음을 시사합니다. 시나리오 일반화 테스트는 인간 데이터가 가져오는 시각적 다양성이 직접적으로 배포 견고성으로 전환됨을 증명합니다.

## 경계 및 한계

논문은 한계를 명시적으로 논의하지 않았습니다. 방법 자체에서 추론할 수 있는 경계:
- 내비게이션 리타게팅은 인간 보행과 차동 구동 운동학이 충분히 유사하다고 가정하며, 제자리 회전, 좁은 통로 등이 필요한 시나리오에서는 실패할 수 있음
- 단계 인식은 손/머리 속도 비율에 의존하며, "정지 조작"과 "보행 중 조작"의 경계 사례에서 오판할 수 있음
- 조작 기술은 여전히 정적 로봇 데이터에 의존하며, 조작 자체의 교차 체현 전이는 해결되지 않음
- 다중 로봇 협업, 장기 배포 안정성, 동적 장애물 회피 등 실제 배포 문제는 다루지 않음
- 훈련 구성(에폭 수, 배치 크기, 학습률)이 공개되지 않아 재현에 불확실성이 있음

## 공학적 시사점

1. **데이터 수집 프로토콜 먼저 확인**: 손 추적 신뢰도 필터(<0 폐기)와 웨이포인트 희소화(≥0.25m)는 데이터 품질의 핵심이며, 재현 시 반드시 엄격히 준수해야 합니다. 그렇지 않으면 단계 인식과 내비게이션 리타게팅이 모두 붕괴됩니다.

2. **단계 인식이 가장 큰 함정**: 절제 실험에서 단계 인식 제거 시 성공률이 0으로 떨어집니다. 재현 시 먼저 GMM 클러스터링과 속도 비율 임계값이 데이터에서 합리적인 단계 구분을 생성하는지 단독 검증한 후 엔드투엔드 훈련을 진행하세요.

3. **내비게이션 리타게팅의 최적화 가중치 민감성**: λ_pos=32.0이 λ_yaw=2.0보다 훨씬 크므로 위치 정밀도가 방향보다 우선함을 의미합니다. 정밀한 방향(예: 선반 정렬)이 필요한 작업이라면 가중치 조정이 필요할 수 있습니다.

4. **데이터량 계획**: 15분 인간 데이터로 이미 36% 성공률, 1시간이면 82%입니다. 먼저 30분을 수집하여 파이프라인을 검증한 후 1시간으로 확장할지 결정하는 것을 권장합니다.

5. **하드웨어 정렬**: 인간 데이터는 SLAM으로 카메라 자세를 추정하고, 로봇은 손-눈 캘리브레이션을 사용하므로, 두 좌표계는 관측 시점의 1인칭 카메라 좌표계에 엄격히 정렬되어야 합니다. 그렇지 않으면 교차 체현 전이에 체계적 편향이 발생합니다.
