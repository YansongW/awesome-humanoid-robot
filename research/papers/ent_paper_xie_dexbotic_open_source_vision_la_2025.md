## 概述

Dexbotic 是一个开源的视觉-语言-动作（VLA）工具箱，由 Dexmal 团队开发，旨在统一碎片化的 VLA 研究生态。其核心贡献在于提供从零预训练的 DexboticVLM 基座、统一的模块化框架（VLM + 动作专家）、标准化的 Dexdata 数据格式，以及一套完整的训练、评估和部署工具链，显著提升了多种现有 VLA 策略在模拟和真实世界任务中的表现。

## 它改变了什么

VLA 研究领域长期被框架碎片化所困扰：不同机构使用不同的深度学习框架、模型架构和数据格式，导致策略比较时需要在多个实验环境中反复配置，且难以保证每个基线都被优化到最佳状态，从而产生不公平的对比。更关键的是，许多现有 VLA 模型（如 OpenVLA、CogACT、OFT）仍基于过时的视觉语言模型（如 Llama2），用户无法直接受益于 Qwen3 等新一代 VLM 的能力提升。

Dexbotic 真正改变的是“VLA 研究的基础设施层”。它不再只是提出一个新策略，而是提供了一个统一的操作系统：将策略解耦为 VLM 和动作专家两部分，让研究者可以像搭积木一样替换组件。这种设计直接降低了新策略的接入成本，同时通过提供更强的预训练基座（DexboticVLM），让所有下游策略都能站在更高质量的肩膀上。此外，Dexdata 格式相比 LeRobot 和 RLDS 更节省存储，DOS-Twins 模拟器则解决了仿真到现实的迁移一致性问题，这些都是从“研究工具”而非“单个模型”角度出发的变革。

## 方法拆解

### 统一模块化框架
VLA 策略被拆分为两个核心组件：
- **VLM**：由视觉编码器（CLIP）、投影器（两层 MLP）和 LLM（Qwen2.5）组成。
- **动作专家（AE）**：可为扩散 Transformer（DiT）、MLP 或混合专家（MoE）架构。

### DexboticVLM 预训练
从零开始训练，流程类似 LLaVA：
1. **阶段一**：冻结视觉编码器和 LLM，仅训练投影器进行跨模态对齐。
2. **阶段二**：解冻全部参数，使用 LLaVA 和 Cambrian 数据集进行端到端微调。

### 离散动作表示
连续机器人动作被映射到 LLM 输出空间的离散 token。每个动作维度单独离散化为 **256** 个 bin，模型预测 N 个离散 token（N 为自由度）。

### 模型系列
- **Dexbotic-Base**：在 DexboticVLM 基础上，使用单臂数据（Open-X Embodiment 子集、RLBench、LIBERO、ManiSkill2 及 UR5 真实数据）预训练，监督目标为预测 N 个离散 token。
- **Dexbotic-CogACT**：基于 Dexbotic-Base 初始化 VLM，DiT 头随机初始化，使用连续动作监督。数据包含 Open-X 子集和私有数据集（**52** 个操作任务，**8** 种单臂机器人）。
- **混合臂连续模型**：将噪声 token 数从 **7** 修改为 **16**，覆盖 6-DoF 和 7-DoF 双臂。前半 token 表示左臂，后半表示右臂。单臂数据仅监督前半 token，后半损失忽略。多视图输入共享视觉编码器，视觉 token 拼接后输入 LLM。

### 实验层与数据格式
- **分层配置 + 工厂注册 + 入口调度**：用户通过继承 base_exp 脚本并覆盖字段来开发新实验，无需复制整个文件。
- **Dexdata 格式**：包含 video（mp4）和 jsonl 目录，每行含多视图图像、机器人状态和文本提示，相比 LeRobot 和 RLDS 更节省存储。
- **DOS-Twins 模拟器**：基于 Isaac Sim 物理引擎和 3DGS 渲染前端，保证视觉、运动和交互一致性。

## 关键创新

1. **从零预训练的 VLM 基座**：DexboticVLM 直接基于 Qwen2.5 构建，而非像 OpenVLA 等使用过时的 Llama2。这意味着所有下游策略都能自动获得新一代 LLM 的推理和泛化能力，这是一个“基座级”的改进，而非简单的调参优化。

2. **统一的模块化抽象**：将 VLA 策略解耦为 VLM + 动作专家，使得扩散 Transformer、MLP、MoE 等不同动作头可以在同一框架下公平比较。这种抽象不仅简化了实验开发，还让“公平比较”从口号变成了工程现实。

3. **跨 embodiment 的混合臂训练策略**：通过将噪声 token 数从 7 扩展到 16，并采用“前半左臂、后半右臂”的分配方式，实现了单臂和双臂数据的混合训练。单臂数据仅监督前半 token 的设计，巧妙地解决了不同自由度数据无法直接混合的问题，这是工程上的一个实用创新。

## 边界与局限

- 细粒度操作任务（如 Shred the scrap paper 和 Pour fries into plate）对现有 VLA 策略仍构成挑战，Dexbotic 未解决这类高精度操作问题。
- 原始 CogACT 策略不支持多视图和双臂设置，需要修改噪声 token 数量，说明框架对某些策略的适配仍需手工干预。
- 不同机器人具有不同 DoF 和 embodiment，对基础设施能力构成挑战，混合臂训练策略虽有效，但未完全解决跨 embodiment 的通用性问题。
- 论文未明确说明 DexboticVLM 在纯语言任务上的表现是否因机器人预训练而有所退化。

## 工程启示

1. **优先复用 Dexbotic-Base 而非从零训练**：实验数据表明，基于 Dexbotic-Base 微调的策略（DB-CogACT、DB-OFT、DB-MemVLA）在几乎所有基准上都显著优于原始版本，且提升幅度与任务复杂度正相关。复现时直接使用其 Huggingface 权重可节省大量预训练成本。

2. **注意数据格式转换**：Dexdata 格式与 LeRobot、RLDS 不兼容，接入自有数据时需编写转换脚本。建议先在小规模数据上验证转换正确性，再扩展到全量数据，避免因格式错误导致训练异常。

3. **混合臂训练时务必检查 token 分配**：单臂数据仅监督前半 token 的设计虽然巧妙，但若数据集中混入双臂数据而未正确设置掩码，会导致后半 token 的梯度异常。建议在训练脚本中显式打印每个 batch 的 token 掩码以确认正确性。

4. **消费级 GPU 可复现**：支持 RTX 4090 和云服务（阿里云、火山引擎），但真实世界数据收集需 **8** 种不同机器人平台，硬件门槛较高。若仅做模拟实验，可跳过真实数据部分，使用 Open-X 和模拟数据即可获得大部分收益。

5. **推理部署采用 Flask + DexClient**：通过网络请求方式解耦训练和推理，适合多机器人并行部署场景。但需注意网络延迟对实时控制的影响，建议在本地回环或低延迟网络环境下使用。

## Overview
Dexbotic is an open-source VLA toolbox designed for robotic manipulation tasks, aimed at lowering the entry barrier for embodied intelligence researchers. It supports multiple mainstream VLA policies through a unified codebase, allowing users to reproduce different methods with just a single environment configuration. The toolbox is experiment-centric, enabling users to quickly build new experiments by modifying Exp scripts. Additionally, Dexbotic provides pretrained models with stronger performance, which can significantly boost the performance of existing state-of-the-art VLA policies, and it will continuously integrate the latest foundation models and cutting-edge VLA models from the industry.

## Content
### Method Overview
Dexbotic adopts a modular design that decouples visual encoding, language understanding, and action generation into independent components, facilitating researchers in replacing or combining different modules. Its core architecture is based on Transformers, integrating input and output formats from various VLA policies through a unified interface.

### Experimental Setup
- **Environment Configuration**: Built on the PyTorch framework, it supports both single-GPU and multi-GPU training and provides preconfigured Docker images to simplify deployment.
- **Data Format**: Supports standardized vision-language-action triplets and is compatible with mainstream dataset formats such as Open X-Embodiment.
- **Evaluation Benchmarks**: Includes multiple built-in robotic manipulation benchmarks (e.g., CALVIN, MetaWorld), automatically generating key metrics such as success rate and average reward.

### Key Numbers and Performance
- **Pretrained Models**: Provides three pretrained models of different scales (with parameter counts of 1.2B, 7B, and 13B). On the CALVIN benchmark, the 13B model improves task success rate by 12.3% compared to baseline methods (e.g., RT-2).
- **Reproduction Efficiency**: Users can switch between different VLA policies (e.g., Octo, RT-1-X) with just 2 lines of code, and a single environment configuration supports over 10 mainstream methods.
- **Experiment Development**: By modifying Exp scripts, the time required to set up new experiments is reduced from several days to several hours.

### Conclusion
Dexbotic, in the form of an open-source toolbox, addresses the issues of complex environment configuration and high reproduction costs in VLA research, while pushing the performance boundary with stronger pretrained models. Its continuous update mechanism ensures it stays in sync with the industry's cutting edge.
