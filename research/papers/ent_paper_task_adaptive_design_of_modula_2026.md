## 概述

本文提出一种面向模块化空中机械臂的任务自适应设计框架，将目标侧气流暴露需求分类为局部、方向、外部三种包络，并联合优化模块重构、末端执行器放置与气流约束。核心贡献在于将气流暴露、力/力矩可行性与末端执行器位置视为耦合设计变量，通过锥-球包络模型与LSE平滑聚合实现高效求解。

## 它改变了什么

现有空中操作设计要么忽略气流影响，要么将末端执行器位置视为先验固定，导致目标侧气流暴露需求从未被系统建模。本文真正改变的是将“目标侧气流容差”从定性考量提升为可优化的几何约束，并证明其与力/力矩可行性存在本质耦合——这打破了以往“先定构型、后验气流”的串行设计范式。作者通过消融实验显示，省略气流约束时模块间气动干扰严重，直接影响推力与扭矩生成，说明气流约束不是锦上添花，而是决定设计可行性的硬约束。

## 方法拆解

### 任务分类与包络建模
- **局部包络**：以末端执行器为中心半径 `r_sph` 的球体，仅允许低速气流，候选集缩减为3个点（1驻点+2端点）。
- **方向包络**：运动路径用线段并集表示，沿线段扫掠球体形成胶囊，非交条件为 `f_air` 特例（胶囊半径恒定），枚举9个候选。
- **外部包络**：以末端执行器为顶点、轴 `d_con`、半角 `θ_con ∈ (0, π/2]` 的无限锥，平台气流限制在锥内；`θ_con = π/2` 时退化为平面。

### 锥-球包络模型
沿长度 `l_air` 的线段扫掠球体，半径线性增长 `Δr_air = l_air·tan(θ_air/2)`，匹配湍流射流扩散角 `θ_air`。演示参数 `θ_air = 10°`，远端距模块COM `20·(l_arm/√2)`，依据是距离大于 `19·(l_arm/√2)` 时下洗效应可忽略。

### 优化问题（式4）
最小化 `Σ_{k=1}^{K} λ_k·‖u_k‖²₂`，约束包括：
- 模块间气流非重叠（二元二次多项式 `f_air(η,γ)` 最小化，KKT条件枚举9个候选）
- 末端执行器非碰撞（球形排斥区域半径 `l_c`）
- 力/力矩可行性等式
- 控制输入边界 `0 ≤ u_k ≤ u_max`
- 连接角边界 `-π/2 ≤ α ≤ π/2`

### LSE平滑聚合
`LSE_β(f, S) = -(1/β)·log(Σ_{ξ∈S} exp(-β·f(ξ)))`，`β > 0` 控制近似精度，避免为每对模块引入额外决策变量和内环迭代距离计算。

### 锥体约束充分条件
式(5) `d_con^T q_i(η) - r_i(η) ≥ 0` 与式(6) `d_con^T q_i(η) sin θ_con - ||ρ_i(η)|| cos θ_con - r_i(η) ≥ 0`。因 `P_i(η)` 和 `r_i(η)` 关于 `η` 仿射，式(5)左侧仿射、式(6)左侧凹，最小值均在端点 `η ∈ {0,1}`，只需端点评估。

## 关键创新

1. **目标侧气流暴露的系统分类**：首次将气流约束分为局部、方向、外部三种包络，覆盖不同任务场景（定点操作、路径跟踪、自由空间限制），使任务需求可显式编码进优化问题。
2. **锥-球包络的解析可处理性**：通过仿射参数化与凸性分析，将无限维约束转化为有限候选点评估（9个或3个），配合LSE聚合避免离散变量，使大规模装配（`10`到`100`模块）可求解。
3. **末端执行器位置与构型的联合优化**：不再假设 `p_E` 先验固定，而是与连接角 `α`、控制输入 `u_k` 共同优化，直接处理气流约束与力/力矩可行性的权衡。

## 实验与结果

### 任务力/力矩集
`W_E = {[0.5·m_t·g, 0, 0.5·m_t·g, 0, 0, 0]ᵀ, [0, 0.5·m_t·g, 0.5·m_t·g, 0, 0, 0]ᵀ}`，外加悬停力/力矩 `[0, 0, m_t·g, 0, 0, 0]ᵀ`。

### 可扩展性实验
| 参数 | 值 |
|------|-----|
| 模块数范围 | `10`–`100` |
| 每模块数配置数 | `50` |
| 目标力采样（x/y轴） | 总重量 `m_t·g` 的 `±20%` |
| 目标力采样（z轴） | `[0.8·m_t·g, 1.2·m_t·g]` |
| 目标力矩采样 | 特征力矩 `l_arm·m_t·g` 的 `±20%` |
| 处理器 | AMD EPYC 7702P |

结果显示方法可扩展到大型装配，固定模块数下不同气流约束类别的运行时间范围相似。

### 消融研究
移除气流非重叠约束，改用最小分离约束 `||o_i - o_j||² ≥ r_m²`。指标包括碰撞模块对交集深度占理论最大重叠 `2(r_air + Δr_air)` 的百分比、最大碰撞簇大小分布、碰撞对数量分布。结果显示最大干扰水平频繁达到，大碰撞簇常涉及约 `n/2` 个模块，碰撞对数量随 `n` 增加。

## 边界与局限

- 锥-球包络不包含整个非零气流速度区域，仅定义气动效应不可忽略的关键区域，参数可调以表示不同保守程度。
- 外部包络约束收紧（减小 `θ_con`）与力/力矩可行性存在权衡，这是长臂操作设计的核心问题。
- 未构建物理空中平台进行真实实验验证，计划将来构建物理平台评估方法。
- 未进行多四旋翼气流交互的实验研究，结果仅提示需要未来实验研究。
- 论文未明确讨论动态飞行、控制稳定性对设计结果的影响。

## 工程启示

复现时先核对三点：一是锥-球包络参数 `θ_air`、`l_air` 的物理标定是否匹配实际旋翼诱导气流扩散角，这直接决定约束保守性；二是LSE聚合的 `β` 值选择，过小导致近似误差大，过大可能引入数值刚性；三是外部包络中 `d_con` 的参数化方式（示例为 `-p_E/||p_E||`）对可行解影响显著，需根据任务方向调整。最容易踩坑的是消融研究中最小分离约束 `r_m` 的取值——若小于气流包络半径，会低估气动干扰；若过大，则过度约束构型空间。下游团队应用时，建议先用小规模（`10`模块）验证包络类型选择是否匹配任务需求，再扩展到大规模装配。

## 개요
본 연구는 다중 회전익 플랫폼의 공중 조작에서 로터 기류가 민감한 대상이나 환경에 미치는 제한 문제를 해결하기 위해, 최적화 기반의 모듈형 공중 로봇 팔 설계 프레임워크를 제안한다. 이 프레임워크는 대상 측 기류 내성을 기하학적 제약 조건으로 분류하는 혁신적인 접근을 도입하며, 컴팩트한 원뿔-구체 포락 모델(cone-sphere envelope)을 사용하여 쿼드로터 기류 확산 구조를 효율적으로 근사하면서도 최적화 계산의 처리 가능성을 유지한다. 이를 바탕으로 재구성 최적화를 통해 작업 힘-모멘트 요구 조건, 대상 측 기류 노출 및 플랫폼 내 기류 간섭 제약을 동시에 충족시키며, 처음으로 엔드 이펙터 위치와 플랫폼 구성을 공동 최적화한다. 확장성 실험과 절제 연구는 이 프레임워크의 유효성을 검증한다.
