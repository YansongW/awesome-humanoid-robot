## 概述

Instruct2Act 提出一种基于大语言模型（LLM）的通用机器人操作框架，通过将多模态指令（纯语言、语言-视觉、指向语言）映射为可执行的 Python 程序，并借助 SAM 与 CLIP 等基础模型完成感知。核心贡献在于用 LLM 生成代码的方式替代传统端到端策略，并在 VIMABench 上验证了其跨任务泛化能力，同时针对零样本感知的缺陷设计了图像预处理与掩码后处理模块。

## 它改变了什么

现有方法如 CaP（Code as Policies）虽也利用 LLM 生成代码，但其感知 API 受限于预定义模块，难以应对复杂指令中的视觉推理与目标识别。Instruct2Act 真正改变的是将感知与规划解耦：感知层完全交给 SAM 与 CLIP 这类通用基础模型，而 LLM 仅负责根据指令与 API 定义生成操作序列。这种设计让系统不再依赖任务特定的感知头，而是通过提示工程（API 定义 + 上下文示例）驱动 LLM 自主调用视觉工具，从而在零样本条件下覆盖操作、视觉目标达成与视觉推理三类任务。

另一个关键变化在于对零样本 SAM 输出质量的工程化修正。作者明确指出，直接使用 SAM 会因阴影、纹理或离散掩码导致抓取失败，因此插入图像预处理（灰度阈值 + 闭运算）与掩码后处理（尺寸过滤、开运算、NMS）模块。这看似是细节，实则决定了系统能否从“演示可用”走向“实际可抓”——没有这一步，后续规划模块再强也会因感知噪声而失效。

## 方法拆解

### 整体架构
系统由三个模块组成：感知（Perception）、规划（Planning）、执行（Execution）。感知模块调用 SAM（ViT-H）与 CLIP（ViT-H-14）提取目标掩码与语义特征；规划模块由 ChatGPT（text-davinci-003）根据指令、API 定义及上下文示例生成 Python 程序；执行模块将程序翻译为 VIMABench 的基本动作原语。

### 多模态指令处理
- **纯语言指令**：直接输入 LLM，配合 API 定义生成代码。
- **语言-视觉指令**：将观察图像与语言描述拼接，CLIP 编码后作为额外上下文。
- **指向语言指令**：用户通过光标点击目标对象，点击点作为 SAM 的点提示（point prompt），增强分割准确性。

### 感知增强（附录核心）
1. **图像预处理**：灰度阈值滤波去除阴影，随后闭形态学操作填补小间隙。
2. **掩码后处理**：
   - 按掩码面积过滤，剔除明显非目标区域（如桌面纹理）。
   - 膨胀 + 腐蚀（开运算）消除内部小孔与不连续间隙，同时避免掩码尺寸漂移。
   - 对同一对象的多个分割结果执行非极大值抑制（NMS），保留最高置信度掩码。

### 代码生成策略
LLM 输出受两个条件约束：API 定义（列出可用函数与参数）与上下文示例（展示输入-输出对）。消融实验表明，仅提供 API 定义时 LLM 易产生语法错误；仅提供示例时缺乏函数签名约束；两者结合可稳定生成可执行代码。

## 关键创新

1. **感知-规划解耦的代码生成范式**：不同于 CaP 将感知 API 硬编码，Instruct2Act 让 LLM 动态选择并组合 SAM/CLIP 调用，使系统能处理未见过的对象组合与指令表述。这是对“LLM 作为机器人控制器”路线的实质性推进——从“写控制逻辑”升级为“写感知-规划联合逻辑”。

2. **零样本感知的工程化修复**：针对 SAM 在真实场景中的阴影误判、掩码空洞问题，提出轻量级预处理与后处理管线。这一创新虽不涉及算法突破，但解决了基础模型落地中的关键痛点，且不依赖额外训练数据，可直接迁移到其他感知模型。

3. **指向语言增强模式**：通过用户点击提供点提示，将人类先验注入 SAM 分割流程。在任务 01 与 03 上分别达到 90.7 与 98.0（表 6），显著高于纯语言模式，证明交互式感知能有效降低歧义。

## 实验与结果

实验在 VIMABench 的 6 个代表性元任务（编号 01、02、03、04、05、17）上评估，采用 150 个实例与 3 个随机种子，报告平均成功率。

| 方法 | 任务01 | 任务02 | 任务03 | 任务04 | 任务05 | 任务17 | 平均 |
|------|--------|--------|--------|--------|--------|--------|------|
| Ours-Multi | 91.3 | 81.4 | 98.2 | 78.5 | 72.0 | 85.2 | 84.4 |
| Ours-Single | 86.7 | - | 94.6 | - | - | 63.0 | - |
| VIMA-20M | - | - | - | - | - | - | 84.4 |
| DT-20M | - | - | - | - | - | - | 43.8 |
| Gato-20M | - | - | - | - | - | - | 40.8 |
| Flamingo-20M | - | - | - | - | - | - | 45.5 |

**关键结果解读**：
- Ours-Multi 平均 84.4，与 VIMA-20M（84.4）持平，但后者需在 20M 规模数据上预训练，而 Instruct2Act 为零样本。
- 指向语言增强模式（表 6）在任务 01 上 90.7、任务 03 上 98.0，均优于纯语言模式（任务 01 的 91.3 与任务 03 的 98.2 为多模态模式，但指向模式在任务 01 上略低，任务 03 上接近），说明用户点击提供的先验在复杂场景中更有效。
- 消融实验（图 7）显示，仅掩码后处理或仅图像预处理均无法完全消除 SAM 的冗余输出，两者结合才能获得干净掩码。

## 边界与局限

- **计算成本**：作者承认系统不适合实时部署，SAM ViT-H 与 CLIP ViT-H-14 的推理开销大，且 LLM 代码生成延迟高（论文未明确具体时延）。
- **动作原语受限**：仅支持 VIMABench 定义的基本动作，无法扩展到真实机械臂的连续控制或力控任务。
- **模拟环境局限**：所有实验在仿真中完成，未涉及真实世界的光照变化、物体材质差异或动态干扰。
- **感知后处理依赖人工调参**：灰度阈值、形态学核大小等参数需针对场景调整，论文未提供自适应策略。
- **指向语言模式需人工介入**：依赖用户点击，无法全自动运行。

## 工程启示

- **复现优先核对感知管线**：直接运行官方代码时，若 SAM 输出出现阴影误判或掩码空洞，请先检查图像预处理（灰度阈值）与后处理（开运算、NMS）参数是否与附录一致。这是最容易踩坑的地方——LLM 生成的代码本身较稳定，但感知质量会直接导致抓取失败。
- **提示工程是性能分水岭**：消融实验表明，仅提供 API 定义或仅提供示例都会显著降低代码生成成功率。复现时务必同时注入两者，且示例需覆盖不同指令模态（纯语言、指向语言）。
- **选型建议**：若下游任务对实时性要求高，应替换 SAM ViT-H 为轻量版本（如 MobileSAM），并考虑用蒸馏后的 LLM 替代 text-davinci-003。论文未明确量化延迟，但 3090Ti 上运行 ViT-H 级模型难以达到实时。
- **扩展方向**：指向语言模式在任务 03 上接近满分（98.0），说明交互式感知对高歧义任务增益明显。若团队有遥操作或人工示教场景，可优先集成该模式。
- **注意随机性**：LLM 输出具有随机性，论文在消融中展示三次连续输出结果。复现时建议固定温度参数（论文未明确），并多次运行取平均以稳定评估。

## 개요
Instruct2Act 프레임워크는 대규모 언어 모델을 통해 다중 모달 지침을 로봇이 실행 가능한 순차적 동작으로 변환합니다. 인식 모듈에서는 사전 정의된 API를 호출하여 Segment Anything Model(SAM)이 후보 객체를 정밀하게 위치시키고, CLIP을 활용하여 분류함으로써 기초 모델의 전문성과 로봇 능력을 통합합니다. 이 프레임워크는 지침의 모달리티와 입력 유형을 유연하게 조정할 수 있으며, 데스크톱 조작 영역의 다중 시나리오 작업에서 실용성과 효율성을 검증했습니다. 제로샷 방식은 여러 작업에서 현재 최첨단 학습 기반 정책보다 우수한 성능을 보입니다.

## 핵심 내용
### 방법 아키텍처
Instruct2Act의 핵심은 대규모 언어 모델을 사용하여 Python 프로그램을 생성하고, 이를 통해 로봇 작업의 인식, 계획 및 동작 루프를 구성하는 것입니다. 인식 부분은 사전 정의된 API를 통해 여러 기초 모델을 호출합니다: Segment Anything Model(SAM)은 후보 객체의 정밀한 분할을 담당하고, CLIP은 분할 결과를 분류합니다. 이러한 설계는 복잡한 고수준 지침을 정밀한 정책 코드로 변환하면서도 다양한 지침 모달리티(예: 텍스트, 이미지)와 입력 유형에 대한 적응성을 유지합니다.

### 실험 설정 및 주요 결과
- 데스크톱 조작 영역의 다중 시나리오 작업에서 평가되었으며, 집기, 놓기 등의 전형적인 조작을 포함합니다.
- 제로샷 테스트에서 Instruct2Act는 여러 작업에서 최첨단 학습 정책을 능가했으며, 예를 들어 객체 분류 및 위치 파악 작업에서 두드러진 성능을 보였습니다.
- 코드는 https://github.com/OpenGVLab/Instruct2Act 에서 오픈소스로 제공되며, 다중 모달 고차원 로봇 지침 작업의 벤치마크로 활용될 수 있습니다.

### 결론
Instruct2Act는 대규모 언어 모델과 기초 모델(SAM, CLIP)을 통합하여 다중 모달 지침에서 로봇 동작으로의 효율적인 매핑을 구현했으며, 제로샷 능력은 프레임워크의 일반화 가능성과 실용성을 검증하여 로봇 조작 작업에 확장 가능한 솔루션을 제공합니다.
