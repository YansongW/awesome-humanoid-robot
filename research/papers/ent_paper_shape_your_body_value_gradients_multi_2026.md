## 概述

本文提出 VGDS（Value Gradient for Design Search），一种将通用多形态价值函数转化为可复用机器人设计模型的方法。作者在多种机器人上训练一个形态感知的策略和价值函数，训练后冻结，通过将价值函数对设计参数求导来优化候选形态，从而避免为每个新机器人重新运行完整的 RL co-design 循环。核心贡献在于将价值梯度与软信任区域结合，实现了在高维连续设计空间中的快速、可迁移的机器人形态优化。

## 它改变了什么

机器人硬件设计长期依赖人工直觉，而现有 co-design 方法（如 Transform2Act、BodyGen、Stackelberg PPO）虽然将设计与控制联合优化，但每个新机器人、设计空间或任务都必须重新运行完整的双层优化循环，成本极高。作者真正改变的是将“为每个机器人单独设计”转变为“训练一次、复用多次”的范式：通过训练一个覆盖多形态分布的价值函数，使其成为可微的“设计代理”，从而将设计搜索从需要完整 RL 训练的分钟/小时级问题，压缩为仅需价值梯度上升的秒/分钟级问题。

这一转变的关键在于，作者没有试图让价值函数在未见过的设计上精确预测（这本质上是不可能的），而是通过软信任区域约束，让优化只在价值函数可靠的邻域内进行。这使得设计搜索从“全局优化”退化为“局部改进”，但换来了极高的效率和跨形态的泛化能力——这正是实际工程中更需要的：在已有良好参考设计的基础上，快速探索其邻域内的改进空间。

## 方法拆解

### 总体流程
1. **多形态 RL 训练**：在多种机器人设计上训练一个形态感知的策略和价值函数（URMA 架构），训练过程中通过课程系数 c_t 从名义设计逐步扩展到完整设计空间 F = [-1,1]^d_design。
2. **冻结与求导**：训练完成后冻结策略和价值函数，将价值函数对归一化设计向量 f 求导，作为可微代理来优化候选形态。

### 关键架构组件
- **URMA 策略/评论家**：处理不同拓扑、运动学和动力学。观测分为固定大小的通用观测 o_g 和可变大小的逐关节观测 {o_j}；每个关节配描述向量 d_j（编码关节轴、相对位置、限制、增益、身体质量、惯量、几何）。
- **直接设计评论家（direct-design critic）**：将编码器 g_ψ 扩展为同时接收观测和描述 g_ψ(o_j, d_j)，使形态参数对注意力值有更直接影响，经验上产生更强的设计梯度。
- **集成**：使用 K=3 个核心值头共享逐关节和逐足编码器，优化均值预测，降低价值函数近似误差的敏感性。

### 设计搜索目标
- **状态库**：从最终策略在完整设计空间上的 rollout 中收集多样化状态库 S = {s_1, ..., s_M}，使设计搜索廉价且确定性。
- **软信任区域目标**：
  Ĵ_λ(f) = (1/M) Σ_{m=1}^{M} V̄(s_m, Φ(f)) - λ‖f - f_ref‖₂²/d_design
  其中二次惩罚阻止设计远离参考机器人，除以 d_design 确保不同设计空间上 λ 可比。
- **VGDS 优化**：对状态库小批量 B 做梯度上升，目标 Ĵ_{λ,B}(f_n)；设计梯度 g_n = ∇_f Ĵ_{λ,B}(f_n) 包含通过冻结评论家和设计映射 Φ 反向传播的价值梯度项，以及解析信任区域梯度项 -2λ/d_design (f_n - f_ref)；使用 Adam 上升步，每参数更新裁剪至 δ_max = 0.1，然后裁剪到 [-1,1]。

### 关键设计决策及理由
- **软信任区域而非硬约束**：无约束的评论家最大化往往将设计推向设计空间边界（评论家预测高回报但真实性能崩溃），软惩罚比硬投影更稳健，避免显式调半径。
- **直接设计评论家**：让形态参数直接进入价值预测，而非仅通过注意力间接影响，产生更强的设计梯度。
- **集成价值头**：降低单头价值函数的近似误差，避免灾难性设计更新。

## 关键创新

1. **价值函数作为可复用设计代理**：这是首次将训练好的多形态价值函数直接用于下游设计优化，而非仅作为 RL 训练的副产品。其新颖性在于识别出价值函数对设计参数的梯度本身就是一种高质量的设计信号，且通过信任区域约束使其在未见设计上依然可用。

2. **软信任区域与高维设计空间的结合**：在高维（358-688 参数）连续设计空间中，无约束优化极易被价值函数的外推误差误导。作者提出的 λ‖f - f_ref‖₂²/d_design 惩罚项，将搜索限制在价值函数可靠的邻域内，且通过除以维度数使 λ 在不同机器人间可比。这一设计决策是方法在 50 个机器人上均能稳定工作的关键。

3. **跨形态泛化的实证验证**：在留出设置（训练集不包含目标机器人）下，VGDS 仍能为目标机器人找到改进设计，证明价值函数学到了跨形态的可迁移知识，而非简单的记忆。这为“一次训练、多机器人复用”的工程范式提供了首个实证支持。

## 实验与结果

### 单机器人设计（10 个初始设计平均 ΔR）
| 机器人 | VGDS (λ=100) | GC-PFO | 随机搜索 | CEM |
|--------|-------------|--------|---------|-----|
| Unitree Go2 | +20.60 | 最强基线 | 远低于 VGDS | 远低于 VGDS |
| MIT Humanoid | +28.84 | 最强基线 | 远低于 VGDS | 远低于 VGDS |
| Golem | +16.85 | 最强基线 | 远低于 VGDS | 远低于 VGDS |

- VGDS 与 GC-PFO（唯一其他利用梯度信息的方法）在速度跟踪误差减少上几乎相同，证明价值梯度在高维设计空间中的有效性。
- 信任域敏感性：λ=0 时 Go2 上 ΔR=-18.93（灾难性外推），λ=100 时 +20.60，说明软信任域不可或缺。

### 跨形态泛化（留出设置）
- 全 50 机器人训练：VGDS 为 Go2 和 Humanoid 找到超过参考设计性能的设计。
- Golem 上六足专用训练集（仅 4 个机器人）达到更高改进，因为全训练集以四足和双足为主，评论家对六足不够专门化。

### 设计分析
- MIT Humanoid：最强变化为名义关节位置和增益，以及减小足部尺寸；仅将优化增益复制到初始设计即可将回报从 5.8 提升到 12.5。
- Golem：VGDS 显著降低动作尺度（-12.2%）、降低 P 增益（-4.1%）、增加 D 增益（+4.4%）。
- 价值预测与真实 rollout 回报正相关：整体 Spearman ρ = 0.40，MIT Humanoid、Go2、Golem 分别为 ρ = 0.50、0.60、0.83。

### 效率
- 初始训练约 7–9 小时；每个额外设计仅需约 1–2 分钟搜索时间；RL 基线随设计数量线性扩展，VGDS 复用同一策略和评论家。

## 边界与局限

- **拓扑固定**：VGDS 仅优化固定机器人拓扑的连续参数，不能添加或移除关节或身体部件，因为通过 URMA 网络没有拓扑变化的梯度。
- **依赖价值函数覆盖范围**：方法依赖策略和价值函数的覆盖范围与准确性；信任区域有助于外推误差，但并非总能获得足够好的参考设计。
- **仿真局限**：所有实验在 MuJoCo 模拟中进行，未评估优化设计是否可制造或可迁移到硬件；正确检查可制造性需要额外的约束或模拟器（材料、电子、驱动、制造）。
- **多样性崩溃**：设计搜索从不同初始设计收敛到相似机器人特定最优（附录 I），预期但不总是受欢迎。
- **大型人形机器人未完全收敛**：部分大型人形（附录 G）需更多训练步，这是某些机器人改进较小的原因。
- **基线适配不完全**：RL co-design 基线适配（附录 F）不完全复现原始方法，结果应解释为底层思想的比较而非具体实现。

## 工程启示

- **先核对价值函数覆盖范围**：VGDS 的效果完全取决于训练时设计空间的覆盖程度。如果目标机器人的设计空间与训练分布差异过大，信任区域会限制搜索范围，改进有限。建议先检查目标机器人在训练集中的代表性（如 Golem 在六足专用训练集上效果更好）。
- **λ 的选择是关键超参数**：λ=100 在三个机器人上均表现良好，但 λ=0 会导致灾难性外推（Go2 上 ΔR=-18.93）。复现时建议从 λ=100 开始，并根据设计空间维度调整（除以 d_design 后可比）。
- **最容易踩坑的地方**：直接设计评论家的价值潜在维度（32 维最优，ΔR=+17.76）和集成头数（K=3）对性能影响显著，不要随意改动。另外，状态库的收集必须使用最终策略在完整设计空间上的 rollout，而非训练过程中的状态。
- **对下游团队的指导**：VGDS 适合在已有良好参考设计（如厂商提供的默认参数）基础上做局部改进，而非从零探索全新形态。若需要保留设计多样性，可减少迭代次数或降低学习率，但会牺牲部分最终性能。

## Overview

This paper introduces VGDS (Value Gradient for Design Search), a method that converts a general multi-morphology value function into a reusable robot design model. The authors train a morphology-aware policy and value function on multiple robots, freeze them after training, and optimize candidate morphologies by differentiating the value function with respect to design parameters, thereby avoiding a full RL co-design loop for each new robot. The core contribution lies in combining value gradients with a soft trust region, enabling fast, transferable robot morphology optimization in high-dimensional continuous design spaces.

## What It Changes

Robot hardware design has long relied on human intuition, and existing co-design methods (e.g., Transform2Act, BodyGen, Stackelberg PPO) jointly optimize design and control, but every new robot, design space, or task requires rerunning the full bilevel optimization loop, which is extremely costly. What the authors truly change is shifting from "designing for each robot individually" to a "train once, reuse many times" paradigm: by training a value function that covers a distribution of morphologies, it becomes a differentiable "design proxy," compressing design search from a minutes/hours-level problem requiring full RL training to a seconds/minutes-level problem requiring only value gradient ascent.

The key to this shift is that the authors do not attempt to make the value function predict accurately on unseen designs (which is essentially impossible), but instead use a soft trust region constraint to ensure optimization only occurs within neighborhoods where the value function is reliable. This degrades design search from "global optimization" to "local improvement," but gains high efficiency and cross-morphology generalization—which is precisely what real engineering needs: starting from a good reference design, quickly exploring improvements within its neighborhood.

## Method Breakdown

### Overall Pipeline
1. **Multi-morphology RL training**: Train a morphology-aware policy and value function (URMA architecture) on multiple robot designs, expanding from nominal designs to the full design space F = [-1,1]^d_design via a curriculum coefficient c_t during training.
2. **Freeze and differentiate**: After training, freeze the policy and value function, and differentiate the value function with respect to the normalized design vector f, using it as a differentiable proxy to optimize candidate morphologies.

### Key Architectural Components
- **URMA policy/critic**: Handles different topologies, kinematics, and dynamics. Observations are split into fixed-size universal observations o_g and variable-size per-joint observations {o_j}; each joint has a descriptor vector d_j (encoding joint axis, relative position, limits, gains, body mass, inertia, geometry).
- **Direct-design critic**: Extends the encoder g_ψ to simultaneously receive observations and descriptors g_ψ(o_j, d_j), giving morphology parameters a more direct influence on attention values, empirically producing stronger design gradients.
- **Ensemble**: Uses K=3 core value heads sharing per-joint and per-foot encoders, optimizing the mean prediction to reduce sensitivity to value function approximation error.

### Design Search Objective
- **State buffer**: Collect a diverse state buffer S = {s_1, ..., s_M} from rollouts of the final policy over the full design space, making design search cheap and deterministic.
- **Soft trust region objective**:
  Ĵ_λ(f) = (1/M) Σ_{m=1}^{M} V̄(s_m, Φ(f)) - λ‖f - f_ref‖₂²/d_design
  where the quadratic penalty prevents designs from moving too far from the reference robot, and dividing by d_design ensures λ is comparable across different design spaces.
- **VGDS optimization**: Perform gradient ascent on mini-batches B from the state buffer with objective Ĵ_{λ,B}(f_n); the design gradient g_n = ∇_f Ĵ_{λ,B}(f_n) includes the value gradient term backpropagated through the frozen critic and design mapping Φ, plus the analytic trust region gradient term -2λ/d_design (f_n - f_ref); use Adam ascent steps with per-parameter updates clipped to δ_max = 0.1, then clipped to [-1,1].

### Key Design Decisions and Rationale
- **Soft trust region rather than hard constraints**: Unconstrained critic maximization often pushes designs to the boundary of the design space (where the critic predicts high returns but true performance collapses); soft penalties are more robust than hard projections, avoiding explicit radius tuning.
- **Direct-design critic**: Letting morphology parameters directly enter value prediction, rather than only indirectly through attention, produces stronger design gradients.
- **Ensemble value heads**: Reduces approximation error of single-head value functions, avoiding catastrophic design updates.

## Key Innovations

1. **Value function as a reusable design proxy**: This is the first time a trained multi-morphology value function is directly used for downstream design optimization, rather than merely as a byproduct of RL training. The novelty lies in recognizing that the gradient of the value function with respect to design parameters is itself a high-quality design signal, and that trust region constraints make it usable on unseen designs.

2. **Combining soft trust regions with high-dimensional design spaces**: In high-dimensional (358–688 parameter) continuous design spaces, unconstrained optimization is easily misled by value function extrapolation error. The proposed λ‖f - f_ref‖₂²/d_design penalty restricts search to neighborhoods where the value function is reliable, and dividing by dimensionality makes λ comparable across robots. This design decision is key to the method working stably across 50 robots.

3. **Empirical validation of cross-morphology generalization**: Under held-out settings (training set excludes the target robot), VGDS still finds improved designs for the target robot, demonstrating that the value function learns transferable knowledge across morphologies rather than simple memorization. This provides the first empirical support for the "train once, reuse across robots" engineering paradigm.

## Experiments and Results

### Single-Robot Design (Average ΔR over 10 Initial Designs)
| Robot | VGDS (λ=100) | GC-PFO | Random Search | CEM |
|--------|-------------|--------|---------|-----|
| Unitree Go2 | +20.60 | Strongest baseline | Far below VGDS | Far below VGDS |
| MIT Humanoid | +28.84 | Strongest baseline | Far below VGDS | Far below VGDS |
| Golem | +16.85 | Strongest baseline | Far below VGDS | Far below VGDS |

- VGDS and GC-PFO (the only other method leveraging gradient information) achieve nearly identical reductions in velocity tracking error, demonstrating the effectiveness of value gradients in high-dimensional design spaces.
- Trust region sensitivity: λ=0 yields ΔR=-18.93 on Go2 (catastrophic extrapolation), while λ=100 yields +20.60, showing the soft trust region is indispensable.

### Cross-Morphology Generalization (Held-Out Setting)
- Full 50-robot training: VGDS finds designs exceeding reference design performance for Go2 and Humanoid.
- On Golem, a hexapod-specific training set (only 4 robots) achieves higher improvements because the full training set is dominated by quadrupeds and bipeds, making the critic less specialized for hexapods.

### Design Analysis
- MIT Humanoid: The strongest changes are nominal joint positions and gains, plus reduced foot size; simply copying the optimized gains to the initial design improves return from 5.8 to 12.5.
- Golem: VGDS significantly reduces action scale (-12.2%), lowers P gains (-4.1%), and increases D gains (+4.4%).
- Value predictions are positively correlated with true rollout returns: overall Spearman ρ = 0.40, with MIT Humanoid, Go2, and Golem at ρ = 0.50, 0.60, and 0.83, respectively.

### Efficiency
- Initial training takes approximately 7–9 hours; each additional design requires only about 1–2 minutes of search time; RL baselines scale linearly with the number of designs, while VGDS reuses the same policy and critic.

## Boundaries and Limitations

- **Fixed topology**: VGDS only optimizes continuous parameters of a fixed robot topology; it cannot add or remove joints or body parts because there is no gradient for topology changes through the URMA network.
- **Dependence on value function coverage**: The method relies on the coverage and accuracy of the policy and value function; the trust region helps with extrapolation error, but a sufficiently good reference design is not always available.
- **Simulation limitations**: All experiments are conducted in MuJoCo simulation; whether optimized designs are manufacturable or transferable to hardware is not evaluated; properly checking manufacturability requires additional constraints or simulators (materials, electronics, actuation, fabrication).
- **Diversity collapse**: Design search converges from different initial designs to similar robot-specific optima (Appendix I), which is expected but not always desirable.
- **Large humanoids not fully converged**: Some large humanoids (Appendix G) require more training steps, which explains smaller improvements for certain robots.
- **Incomplete baseline adaptation**: The RL co-design baseline adaptation (Appendix F) does not fully reproduce the original methods; results should be interpreted as comparisons of underlying ideas rather than specific implementations.

## Engineering Insights

- **Check value function coverage first**: VGDS's effectiveness depends entirely on how well the training design space covers the target. If the target robot's design space differs too much from the training distribution, the trust region will restrict search scope and improvements will be limited. It is recommended to first check the target robot's representativeness in the training set (e.g., Golem performs better on a hexapod-specific training set).
- **λ selection is a critical hyperparameter**: λ=100 performs well across all three robots, but λ=0 leads to catastrophic extrapolation (ΔR=-18.93 on Go2). When reproducing, start with λ=100 and adjust based on design space dimensionality (comparable after dividing by d_design).
- **Most common pitfalls**: The direct-design critic's value latent dimension (32-dimensional optimal, ΔR=+17.76) and ensemble head count (K=3) significantly affect performance; do not change them arbitrarily. Additionally, the state buffer must be collected from rollouts of the final policy over the full design space, not from states during training.
- **Guidance for downstream teams**: VGDS is suitable for local improvements on existing good reference designs (e.g., manufacturer-provided default parameters), rather than exploring entirely new morphologies from scratch. If design diversity needs to be preserved, reduce the number of iterations or lower the learning rate, at the cost of some final performance.

## 개요

본 논문은 VGDS(Value Gradient for Design Search)를 제안하며, 이는 범용 다형태 가치 함수를 재사용 가능한 로봇 설계 모델로 변환하는 방법이다. 저자는 다양한 로봇에서 형태 인식 정책과 가치 함수를 훈련한 후 동결시키고, 가치 함수를 설계 파라미터에 대해 미분하여 후보 형태를 최적화함으로써, 새로운 로봇마다 전체 RL 공동 설계 루프를 재실행하는 것을 피한다. 핵심 기여는 가치 기울기를 소프트 신뢰 영역과 결합하여 고차원 연속 설계 공간에서 빠르고 전이 가능한 로봇 형태 최적화를 달성하는 것이다.

## 무엇을 바꾸었는가

로봇 하드웨어 설계는 오랫동안 수동 직관에 의존해 왔으며, 기존 공동 설계 방법(예: Transform2Act, BodyGen, Stackelberg PPO)은 설계와 제어를 공동 최적화하지만, 새로운 로봇, 설계 공간 또는 작업마다 전체 이중 최적화 루프를 재실행해야 하므로 비용이 매우 높다. 저자가 실제로 바꾼 것은 "로봇별 개별 설계"를 "한 번 훈련, 여러 번 재사용" 패러다임으로 전환한 것이다: 다형태 분포를 포괄하는 가치 함수를 훈련하여 미분 가능한 "설계 에이전트"로 만들고, 설계 탐색을 전체 RL 훈련이 필요한 분/시간 단위 문제에서 가치 기울기 상승만 필요한 초/분 단위 문제로 압축한다.

이 전환의 핵심은 저자가 가치 함수가 보지 못한 설계에서 정확히 예측하도록 시도하지 않는다는 점이다(이는 본질적으로 불가능하다). 대신 소프트 신뢰 영역 제약을 통해 최적화가 가치 함수가 신뢰할 수 있는 이웃 내에서만 수행되도록 한다. 이로써 설계 탐색은 "전역 최적화"에서 "국소 개선"으로 축소되지만, 높은 효율성과 교차 형태 일반화 능력을 얻는다—이는 실제 공학에서 더 필요한 것이다: 기존의 좋은 참조 설계를 바탕으로 그 이웃 내 개선 공간을 빠르게 탐색하는 것.

## 방법 분해

### 전체 흐름
1. **다형태 RL 훈련**: 다양한 로봇 설계에서 형태 인식 정책과 가치 함수(URMA 아키텍처)를 훈련하고, 훈련 중 커리큘럼 계수 c_t를 통해 명목 설계에서 전체 설계 공간 F = [-1,1]^d_design으로 점진적으로 확장한다.
2. **동결 및 미분**: 훈련 완료 후 정책과 가치 함수를 동결하고, 가치 함수를 정규화된 설계 벡터 f에 대해 미분하여 미분 가능한 에이전트로 사용해 후보 형태를 최적화한다.

### 핵심 아키텍처 구성 요소
- **URMA 정책/비평가**: 서로 다른 토폴로지, 운동학, 동역학을 처리한다. 관측은 고정 크기 일반 관측 o_g와 가변 크기 관절별 관측 {o_j}로 나뉜다; 각 관절에는 설명 벡터 d_j(관절 축, 상대 위치, 제한, 이득, 몸체 질량, 관성, 기하학 인코딩)가 있다.
- **직접 설계 비평가(direct-design critic)**: 인코더 g_ψ를 확장하여 관측과 설명을 동시에 수신 g_ψ(o_j, d_j)하도록 하여, 형태 파라미터가 어텐션 값에 더 직접적인 영향을 미치게 하고, 경험적으로 더 강한 설계 기울기를 생성한다.
- **앙상블**: K=3개의 핵심 가치 헤드가 관절별 및 발별 인코더를 공유하고, 평균 예측을 최적화하여 가치 함수 근사 오차에 대한 민감도를 낮춘다.

### 설계 탐색 목표
- **상태 저장소**: 최종 정책을 전체 설계 공간에서 롤아웃하여 다양한 상태 저장소 S = {s_1, ..., s_M}를 수집하여 설계 탐색을 저비용이고 결정론적으로 만든다.
- **소프트 신뢰 영역 목표**:
  Ĵ_λ(f) = (1/M) Σ_{m=1}^{M} V̄(s_m, Φ(f)) - λ‖f - f_ref‖₂²/d_design
  여기서 2차 페널티는 설계가 참조 로봇에서 멀어지는 것을 방지하고, d_design로 나누어 서로 다른 설계 공간에서 λ가 비교 가능하도록 한다.
- **VGDS 최적화**: 상태 저장소의 미니배치 B에 대해 기울기 상승을 수행하고, 목표 Ĵ_{λ,B}(f_n); 설계 기울기 g_n = ∇_f Ĵ_{λ,B}(f_n)는 동결된 비평가와 설계 매핑 Φ를 통한 역전파 가치 기울기 항과 해석적 신뢰 영역 기울기 항 -2λ/d_design (f_n - f_ref)을 포함한다; Adam 상승 단계를 사용하고, 파라미터별 업데이트를 δ_max = 0.1로 클리핑한 후 [-1,1]로 클리핑한다.

### 핵심 설계 결정 및 근거
- **소프트 신뢰 영역 대 하드 제약**: 제약 없는 비평가 최대화는 종종 설계를 설계 공간 경계로 밀어낸다(비평가가 높은 보상을 예측하지만 실제 성능은 붕괴). 소프트 페널티는 하드 프로젝션보다 더 견고하며, 반경을 명시적으로 조정할 필요가 없다.
- **직접 설계 비평가**: 형태 파라미터가 어텐션을 통한 간접적 영향이 아닌 가치 예측에 직접 들어가도록 하여 더 강한 설계 기울기를 생성한다.
- **앙상블 가치 헤드**: 단일 헤드 가치 함수의 근사 오차를 줄여 재앙적 설계 업데이트를 방지한다.

## 핵심 혁신

1. **가치 함수를 재사용 가능한 설계 에이전트로 사용**: 훈련된 다형태 가치 함수를 RL 훈련의 부산물이 아닌 다운스트림 설계 최적화에 직접 사용한 것은 이번이 처음이다. 그 참신함은 가치 함수의 설계 파라미터에 대한 기울기 자체가 고품질 설계 신호이며, 신뢰 영역 제약을 통해 보지 못한 설계에서도 사용 가능하다는 점을 인식한 데 있다.

2. **소프트 신뢰 영역과 고차원 설계 공간의 결합**: 고차원(358-688 파라미터) 연속 설계 공간에서 제약 없는 최적화는 비평가의 외삽 오차에 쉽게 오도된다. 저자가 제안한 λ‖f - f_ref‖₂²/d_design 페널티 항은 탐색을 가치 함수가 신뢰할 수 있는 이웃으로 제한하고, 차원 수로 나누어 λ가 서로 다른 로봇 간에 비교 가능하도록 한다. 이 설계 결정은 방법이 50개 로봇에서 안정적으로 작동하는 핵심이다.

3. **교차 형태 일반화의 실증 검증**: 홀드아웃 설정(훈련 세트에 대상 로봇 미포함)에서 VGDS는 여전히 대상 로봇에 대한 개선 설계를 찾아내며, 가치 함수가 단순한 기억이 아닌 교차 형태 전이 가능한 지식을 학습했음을 증명한다. 이는 "한 번 훈련, 다중 로봇 재사용" 엔지니어링 패러다임에 대한 첫 실증적 지원을 제공한다.

## 실험 및 결과

### 단일 로봇 설계(10개 초기 설계 평균 ΔR)
| 로봇 | VGDS (λ=100) | GC-PFO | 무작위 탐색 | CEM |
|--------|-------------|--------|---------|-----|
| Unitree Go2 | +20.60 | 가장 강한 기준선 | VGDS보다 훨씬 낮음 | VGDS보다 훨씬 낮음 |
| MIT Humanoid | +28.84 | 가장 강한 기준선 | VGDS보다 훨씬 낮음 | VGDS보다 훨씬 낮음 |
| Golem | +16.85 | 가장 강한 기준선 | VGDS보다 훨씬 낮음 | VGDS보다 훨씬 낮음 |

- VGDS는 GC-PFO(기울기 정보를 활용하는 유일한 다른 방법)와 속도 추적 오차 감소에서 거의 동일하며, 고차원 설계 공간에서 가치 기울기의 효과를 증명한다.
- 신뢰 영역 민감도: λ=0일 때 Go2에서 ΔR=-18.93(재앙적 외삽), λ=100일 때 +20.60으로 소프트 신뢰 영역이 필수적임을 보여준다.

### 교차 형태 일반화(홀드아웃 설정)
- 전체 50개 로봇 훈련: VGDS는 Go2와 Humanoid에 대해 참조 설계 성능을 초과하는 설계를 찾는다.
- Golem에서 6족 전용 훈련 세트(로봇 4개만)가 더 높은 개선을 달성하는데, 이는 전체 훈련 세트가 4족 및 2족 위주라 비평가가 6족에 충분히 특화되지 않았기 때문이다.

### 설계 분석
- MIT Humanoid: 가장 강한 변화는 명목 관절 위치와 이득, 그리고 발 크기 감소; 이득 최적화만 초기 설계에 복사해도 보상이 5.8에서 12.5로 향상된다.
- Golem: VGDS는 동작 스케일을 크게 감소(-12.2%), P 이득 감소(-4.1%), D 이득 증가(+4.4%)시킨다.
- 가치 예측과 실제 롤아웃 보상은 양의 상관관계: 전체 Spearman ρ = 0.40, MIT Humanoid, Go2, Golem은 각각 ρ = 0.50, 0.60, 0.83.

### 효율성
- 초기 훈련 약 7–9시간; 추가 설계당 약 1–2분 탐색 시간; RL 기준선은 설계 수에 따라 선형적으로 확장되지만, VGDS는 동일한 정책과 비평가를 재사용한다.

## 경계 및 한계

- **토폴로지 고정**: VGDS는 고정된 로봇 토폴로지의 연속 파라미터만 최적화하며, URMA 네트워크를 통한 토폴로지 변화 기울기가 없으므로 관절이나 몸체 부품을 추가하거나 제거할 수 없다.
- **가치 함수 적용 범위 의존성**: 방법은 정책과 가치 함수의 적용 범위와 정확성에 의존한다; 신뢰 영역은 외삽 오차에 도움이 되지만, 항상 충분히 좋은 참조 설계를 얻을 수 있는 것은 아니다.
- **시뮬레이션 한계**: 모든 실험은 MuJoCo 시뮬레이션에서 수행되었으며, 최적화된 설계가 제조 가능하거나 하드웨어로 전이 가능한지 평가되지 않았다; 제조 가능성의 올바른 검사는 추가 제약 또는 시뮬레이터(재료, 전자, 구동, 제조)가 필요하다.
- **다양성 붕괴**: 설계 탐색은 서로 다른 초기 설계에서 유사한 로봇 특정 최적점으로 수렴한다(부록 I). 예상되지만 항상 바람직하지는 않다.
- **대형 휴머노이드 미완전 수렴**: 일부 대형 휴머노이드(부록 G)는 더 많은 훈련 단계가 필요하며, 이는 일부 로봇의 개선이 작은 이유이다.
- **기준선 적응 불완전**: RL 공동 설계 기준선 적응(부록 F)은 원래 방법을 완전히 재현하지 않으며, 결과는 구체적 구현이 아닌 기본 아이디어의 비교로 해석되어야 한다.

## 공학적 시사점

- **먼저 가치 함수 적용 범위를 확인하라**: VGDS의 효과는 전적으로 훈련 시 설계 공간의 적용 범위에 달려 있다. 대상 로봇의 설계 공간이 훈련 분포와 너무 다르면 신뢰 영역이 탐색 범위를 제한하여 개선이 제한적이다. 대상 로봇의 훈련 세트 내 대표성(예: Golem이 6족 전용 훈련 세트에서 더 좋은 성과)을 먼저 확인하는 것이 좋다.
- **λ 선택이 핵심 하이퍼파라미터**: λ=100은 세 로봇 모두에서 잘 작동하지만, λ=0은 재앙적 외삽(Go2에서 ΔR=-18.93)을 초래한다. 재현 시 λ=100에서 시작하고 설계 공간 차원에 따라 조정하는 것이 좋다(d_design로 나눈 후 비교 가능).
- **가장 함정에 빠지기 쉬운 부분**: 직접 설계 비평가의 가치 잠재 차원(32차원 최적, ΔR=+17.76)과 앙상블 헤드 수(K=3)는 성능에 큰 영향을 미치므로 임의로 변경하지 말 것. 또한 상태 저장소 수집은 훈련 중 상태가 아닌 최종 정책을 전체 설계 공간에서 롤아웃한 것을 사용해야 한다.
- **다운스트림 팀에 대한 지침**: VGDS는 기존의 좋은 참조 설계(예: 제조업체 제공 기본 파라미터)를 바탕으로 국소 개선을 하는 데 적합하며, 완전히 새로운 형태를 처음부터 탐색하는 데는 적합하지 않다. 설계 다양성을 유지해야 한다면 반복 횟수를 줄이거나 학습률을 낮출 수 있지만, 일부 최종 성능을 희생하게 된다.
