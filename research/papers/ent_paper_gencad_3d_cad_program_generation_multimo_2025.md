## 概述

GenCAD-3D 提出了一种多模态 CAD 程序生成框架，通过对比学习将 CAD 程序与点云、网格等几何表示对齐到共享潜在空间，并利用条件潜在扩散模型实现跨模态生成。核心贡献在于引入 SynthBal 合成数据平衡策略，显著缓解了复杂 CAD 程序在数据集中比例失衡的问题，同时提出了序列长度归一化评估指标以更公平地衡量模型在高复杂度样本上的表现。

## 它改变了什么

CAD 程序生成领域长期被 sketch-and-extrude 这一受限命令集所束缚，且现有方法（如 Point2Cyl、CAD-SIGNet、TransCAD）无法推广到 revolve、fillet 等工业常见命令。更根本的问题在于，DeepCAD 等数据集存在严重的序列长度分布失衡——序列长度不超过 6 的程序占 42%，而长度超过 20 的复杂程序占比极低，导致模型训练被简单样本主导，评估指标也被过表示的长度区间所掩盖。GenCAD-3D 真正改变的是对"数据不平衡"这一核心瓶颈的处理方式：不再像 DeepCAD 的 random replacement 或 ContrastCAD 那样在训练中盲目增强，而是离线生成经过有效性验证的平衡数据集，并配合序列长度归一化指标，让复杂几何上的改进不再被平均指标淹没。此外，它首次将网格模态纳入对比对齐框架，突破了 CAD-MLLM 等依赖已有基础模型的方法无法处理网格这类未开发模态的限制。

## 方法拆解

### 三阶段架构
1. **CAD 自动编码器**：使用因果 transformer（与 GenCAD 相同）将 CAD 程序 𝒞 = (𝐜₁, …, 𝐜_ℓ) 编码为连续潜在向量 𝐳_𝒞 ∈ ℝ^{d_m}，通过因果掩码保持命令顺序关系。
2. **多模态对比对齐**：对每个模态（点云、点云+法线、网格）使用专用编码器 ℰ 映射到潜在空间，通过对比损失（公式 3）对齐模态与 CAD 潜在空间。关键设计是冻结 CAD 编码器，仅训练模态编码器，使框架可扩展至大规模数据集。余弦相似度 p(𝐮,𝐯) = 𝐮ᵀ𝐯/(||𝐮||||𝐯||)，τ 为可学习温度，批次大小 B 产生 2B 个数据点，仅对应配对为正样本。
3. **条件潜在扩散**：生成模型分解为 p(𝒞|ℳ,ℰ) = p(𝒞|𝐳_𝒞) × p(𝐳_𝒞|𝐳_ℳ)，先验为基于 ResNet-MLP 的条件扩散模型（参考 gorishniy2021revisiting），损失 L = 𝔼[||ε − ε_θ(𝐳_t, t, 𝐳_ℳ)||²₂]。每个模态训练独立的先验网络。

### 模态编码器
- **点云（DGCNN）**：4 层动态图卷积（通道 128,128,256,512），KNN=20，拼接中间层嵌入，max+mean pooling，MLP 1024-512，dropout 0.2，2.598×10⁶ 参数。
- **点云+法线（PC+N）**：6D 输入（位置+法线），2.599×10⁶ 参数，产生均匀表面采样。
- **网格（FeaStNet）**：Feature-Steered 卷积，顶点输入 6D（位置+法线），通道 16,32,64,128,256，滤波器库 M=10，mean-pooling 降维，2.66×10⁶ 参数。

### SynthBal 数据增强
- 目标：各序列长度均匀平衡（n_ℓ^𝒮 = N^𝒮/|ℒ|），先填充比例 r 的真实数据，其余用合成数据补齐。
- 两种操作：(1) **Noise**：对连续参数添加扰动（[−m·256, m·256] 均匀采样，裁剪到 [1,255]），忽略离散值（如外伸方向）；(2) **Replace-Sketch**：随机替换程序中的草图操作为另一程序的对应草图。
- 选择策略：40% 概率大噪声（m=0.07, p=0.6），60% 概率小噪声（m=0.02, p=0.8）后接 Replace-Sketch。
- 关键区别：SynthBal 在训练外生成并验证（编译为 CAD 对象且无自相交），而 DeepCAD/ContrastCAD 在训练中增强且不验证。

### 训练策略
- 先在 SynthBal 数据集上训练（1000 epochs, lr=1e-3, warmup 2000），再在 reduction-balanced 真实数据集（4,503 个模型）上微调最后一层（100 epochs, lr=1e-5）。
- 数据防泄漏：仅在同一 train/val/test 拆分内配对，评估始终在原始 DeepCAD 数据集上进行。

## 关键创新

1. **SynthBal 离线验证式数据平衡**：与现有增强方法在训练中盲目操作不同，SynthBal 在训练外生成合成数据并验证其可编译性，将无效 CAD 生成率从 3.44% 降至 0.845%。这一设计使数据增强从"碰运气"变为"可保证质量"，且能针对长序列（高复杂度）程序定向补充。
2. **序列长度归一化评估指标**：标准指标对整个数据集取平均，被占比 42% 的短序列样本主导。m^SL(𝒳) = (1/|ℒ|)Σ_ℓ m(𝒳_ℓ) 消除了对过表示长度的偏向，使复杂几何上的改进（或失败）不再被掩盖。这是评估方法论上的重要贡献，直接影响后续研究如何报告结果。
3. **网格模态的对比对齐**：首次将网格（FeaStNet）纳入 CAD 程序生成的对比学习框架，突破了依赖已有基础模型（如 CAD-MLLM）的限制。网格感知编码器在 top-1 检索上相对点云基线提升最高 11%，且增益在大型检索规模（2048 个 CAD 模型）中最显著，表明网格模态提供了点云无法捕获的表面拓扑信息。

## 工程启示

复现时首先核对数据预处理管线：网格重网格化（MeshLab 三次中点细分+五次各向同性重网格化）是瓶颈，约 10% 的网格会因错误被丢弃，建议提前验证目标顶点数（2000-4000）与偏转参数（线性 0.001，角度 0.1）的兼容性。SynthBal 的 r 参数（真实数据填充比例）是关键超参数——r=0.2 时 83.3% 为合成数据，r=0.8 时 86.1% 为合成数据，但微调阶段必须使用 reduction-balanced 真实数据集（4,503 个模型），否则合成数据分布偏移会导致性能退化。最容易踩坑的是对比训练中冻结 CAD 编码器这一设计——若同时训练两个编码器，对比损失可能破坏 CAD 潜在空间的语义结构，导致生成阶段解码失败。评估时务必同时报告原始指标和序列长度归一化指标，否则长序列上的改进会被短序列主导的平均值掩盖。硬件需求为单块 H100 80GB，点云对比训练 300 epochs 约需数天，生成训练 1×10⁶ epochs 需数周，建议先用 SynthBal-170K 验证管线再扩展至 1M。

## Overview

GenCAD-3D proposes a multimodal CAD program generation framework that aligns CAD programs with geometric representations such as point clouds and meshes into a shared latent space via contrastive learning, and leverages a conditional latent diffusion model for cross-modal generation. The core contribution lies in introducing the SynthBal synthetic data balancing strategy, which significantly alleviates the issue of imbalanced proportions of complex CAD programs in the dataset, while also proposing a sequence-length-normalized evaluation metric to more fairly measure model performance on high-complexity samples.

## What It Changes

The field of CAD program generation has long been constrained by the limited command set of sketch-and-extrude, and existing methods (e.g., Point2Cyl, CAD-SIGNet, TransCAD) fail to generalize to industrially common commands such as revolve and fillet. A more fundamental issue is that datasets like DeepCAD suffer from severe sequence-length distribution imbalance—programs with sequence length no greater than 6 account for 42%, while complex programs with length exceeding 20 are extremely scarce, causing model training to be dominated by simple samples and evaluation metrics to be obscured by over-represented length ranges. What GenCAD-3D truly changes is the handling of the core bottleneck of "data imbalance": rather than blindly augmenting during training as in DeepCAD's random replacement or ContrastCAD, it generates offline a validity-verified balanced dataset, paired with a sequence-length-normalized metric, so that improvements on complex geometry are no longer drowned out by averaged metrics. Furthermore, it is the first to incorporate the mesh modality into the contrastive alignment framework, breaking through the limitations of methods like CAD-MLLM that rely on existing foundation models and cannot handle undeveloped modalities such as meshes.

## Method Breakdown

### Three-Stage Architecture
1. **CAD Autoencoder**: Uses a causal transformer (same as GenCAD) to encode a CAD program 𝒞 = (𝐜₁, …, 𝐜_ℓ) into a continuous latent vector 𝐳_𝒞 ∈ ℝ^{d_m}, preserving command order relationships via causal masking.
2. **Multimodal Contrastive Alignment**: For each modality (point cloud, point cloud + normals, mesh), a dedicated encoder ℰ maps to the latent space, aligning the modality with the CAD latent space via a contrastive loss (Equation 3). A key design choice is freezing the CAD encoder and training only the modality encoders, making the framework scalable to large datasets. Cosine similarity p(𝐮,𝐯) = 𝐮ᵀ𝐯/(||𝐮||||𝐯||), with τ as a learnable temperature; a batch size of B yields 2B data points, with only corresponding pairs treated as positive samples.
3. **Conditional Latent Diffusion**: The generative model factorizes as p(𝒞|ℳ,ℰ) = p(𝒞|𝐳_𝒞) × p(𝐳_𝒞|𝐳_ℳ), where the prior is a ResNet-MLP-based conditional diffusion model (referencing gorishniy2021revisiting), with loss L = 𝔼[||ε − ε_θ(𝐳_t, t, 𝐳_ℳ)||²₂]. A separate prior network is trained for each modality.

### Modality Encoders
- **Point Cloud (DGCNN)**: 4-layer dynamic graph convolution (channels 128,128,256,512), KNN=20, concatenated intermediate layer embeddings, max+mean pooling, MLP 1024-512, dropout 0.2, 2.598×10⁶ parameters.
- **Point Cloud + Normals (PC+N)**: 6D input (position + normals), 2.599×10⁶ parameters, producing uniform surface sampling.
- **Mesh (FeaStNet)**: Feature-Steered convolution, vertex input 6D (position + normals), channels 16,32,64,128,256, filter bank M=10, mean-pooling for dimensionality reduction, 2.66×10⁶ parameters.

### SynthBal Data Augmentation
- Goal: uniform balance across sequence lengths (n_ℓ^𝒮 = N^𝒮/|ℒ|), first filling a proportion r with real data, and the remainder with synthetic data.
- Two operations: (1) **Noise**: Adds perturbations to continuous parameters (uniform sampling from [−m·256, m·256], clipped to [1,255]), ignoring discrete values (e.g., extrusion direction); (2) **Replace-Sketch**: Randomly replaces a sketch operation in the program with a corresponding sketch from another program.
- Selection strategy: 40% probability of large noise (m=0.07, p=0.6), 60% probability of small noise (m=0.02, p=0.8) followed by Replace-Sketch.
- Key difference: SynthBal generates and validates outside training (compiles to CAD objects with no self-intersections), whereas DeepCAD/ContrastCAD augment during training without validation.

### Training Strategy
- First train on the SynthBal dataset (1000 epochs, lr=1e-3, warmup 2000), then fine-tune the last layer on a reduction-balanced real dataset (4,503 models) (100 epochs, lr=1e-5).
- Data leakage prevention: pairing is performed only within the same train/val/test split, and evaluation is always conducted on the original DeepCAD dataset.

## Key Innovations

1. **SynthBal Offline Validated Data Balancing**: Unlike existing augmentation methods that operate blindly during training, SynthBal generates synthetic data outside training and validates its compilability, reducing the invalid CAD generation rate from 3.44% to 0.845%. This design transforms data augmentation from "trial and error" to "guaranteed quality," and enables targeted supplementation of long-sequence (high-complexity) programs.
2. **Sequence-Length-Normalized Evaluation Metric**: Standard metrics average over the entire dataset, dominated by short-sequence samples that account for 42%. m^SL(𝒳) = (1/|ℒ|)Σ_ℓ m(𝒳_ℓ) removes the bias toward over-represented lengths, ensuring that improvements (or failures) on complex geometry are no longer masked. This is a significant contribution to evaluation methodology, directly influencing how future research reports results.
3. **Contrastive Alignment for the Mesh Modality**: This is the first time meshes (FeaStNet) are incorporated into a contrastive learning framework for CAD program generation, breaking through the limitations of methods that rely on existing foundation models (e.g., CAD-MLLM). The mesh-aware encoder achieves up to 11% relative improvement in top-1 retrieval over point cloud baselines, with gains most pronounced at large retrieval scales (2048 CAD models), indicating that the mesh modality provides surface topology information that point clouds cannot capture.

### Result Interpretation
SynthBal yields the most significant improvements in Chamfer distance for long-sequence (high-complexity) programs (up to 89%), directly validating the effectiveness of the data balancing strategy. The advantage of the mesh encoder on large retrieval libraries indicates that as the candidate set grows, the surface topology information provided by meshes is more effective than point clouds for distinguishing similar geometries. The sequence-length-normalized metric reveals that unnormalized metrics primarily reflect performance for lengths 5-15, while performance on high-length samples is systematically underestimated.

## Boundaries and Limitations

The paper explicitly restricts commands to Line, Arc, Circle, and Extrude, not covering industrially common commands such as fillets, lofts, and revolves. Although the architecture does not assume command types, experimental validation only covers sketch-and-extrude. The remeshing process introduces errors that lead to the removal of approximately 10% of training meshes (152,530→136,384), potentially introducing selection bias. The paper does not mention experimental results for different command types, inference time, model inference frequency, or ablation study details, nor does it provide direct comparison numbers with other methods (e.g., Point2Cyl, CAD-SIGNet) under identical conditions. SynthBal's validation relies on OpenCascade compilation, and synthetic data that cannot be compiled is directly discarded, potentially filtering out certain meaningful geometric variants.

## Engineering Insights

When reproducing, first verify the data preprocessing pipeline: mesh remeshing (MeshLab three midpoint subdivisions plus five isotropic remeshing steps) is the bottleneck, with approximately 10% of meshes discarded due to errors; it is advisable to validate in advance the compatibility of the target vertex count (2000-4000) and deflection parameters (linear 0.001, angular 0.1). The r parameter in SynthBal (proportion of real data filling) is a critical hyperparameter—at r=0.2, 83.3% of data is synthetic, and at r=0.8, 86.1% is synthetic—but the fine-tuning stage must use the reduction-balanced real dataset (4,503 models); otherwise, distribution shift from synthetic data can lead to performance degradation. The most likely pitfall is the design of freezing the CAD encoder during contrastive training—if both encoders are trained simultaneously, the contrastive loss may disrupt the semantic structure of the CAD latent space, leading to decoding failures in the generation stage. During evaluation, it is essential to report both the original metrics and the sequence-length-normalized metrics; otherwise, improvements on long sequences will be masked by averages dominated by short sequences. Hardware requirements are a single H100 80GB; point cloud contrastive training for 300 epochs takes approximately several days, and generation training for 1×10⁶ epochs takes several weeks; it is recommended to first validate the pipeline with SynthBal-170K before scaling to 1M.

## 개요

GenCAD-3D는 멀티모달 CAD 프로그램 생성 프레임워크를 제안하며, 대조 학습을 통해 CAD 프로그램을 점군, 메시 등의 기하 표현과 공유 잠재 공간에 정렬하고, 조건부 잠재 확산 모델을 활용하여 교차 모달 생성을 구현한다. 핵심 기여는 SynthBal 합성 데이터 균형 전략을 도입하여 복잡한 CAD 프로그램이 데이터셋에서 차지하는 비율 불균형 문제를 크게 완화하고, 시퀀스 길이 정규화 평가 지표를 제안하여 고복잡도 샘플에 대한 모델 성능을 더 공정하게 측정한다는 점이다.

## 무엇을 바꾸었는가

CAD 프로그램 생성 분야는 오랫동안 sketch-and-extrude라는 제한된 명령 집합에 묶여 있었으며, 기존 방법(Point2Cyl, CAD-SIGNet, TransCAD 등)은 revolve, fillet과 같은 산업에서 흔한 명령으로 일반화되지 못했다. 더 근본적인 문제는 DeepCAD와 같은 데이터셋에 심각한 시퀀스 길이 분포 불균형이 존재한다는 점이다——시퀀스 길이가 6 이하인 프로그램이 42%를 차지하는 반면, 길이가 20을 초과하는 복잡한 프로그램의 비율은 극히 낮아 모델 훈련이 단순 샘플에 의해 지배되고, 평가 지표도 과대 표현된 길이 구간에 의해 가려진다. GenCAD-3D가 실제로 바꾼 것은 "데이터 불균형"이라는 핵심 병목에 대한 처리 방식이다: DeepCAD의 random replacement나 ContrastCAD처럼 훈련 중 맹목적으로 증강하는 대신, 유효성이 검증된 균형 데이터셋을 오프라인에서 생성하고, 시퀀스 길이 정규화 지표를 함께 사용하여 복잡한 기하 구조에서의 개선이 평균 지표에 묻히지 않도록 한다. 또한, 처음으로 메시 모달리티를 대조 정렬 프레임워크에 통합하여 CAD-MLLM 등 기존 기반 모델에 의존하는 방법이 처리할 수 없는 메시와 같은 미개발 모달리티의 한계를 돌파했다.

## 방법 분해

### 3단계 아키텍처
1. **CAD 오토인코더**: 인과 트랜스포머(GenCAD와 동일)를 사용하여 CAD 프로그램 𝒞 = (𝐜₁, …, 𝐜_ℓ)을 연속 잠재 벡터 𝐳_𝒞 ∈ ℝ^{d_m}로 인코딩하며, 인과 마스크를 통해 명령 순서 관계를 유지한다.
2. **멀티모달 대조 정렬**: 각 모달리티(점군, 점군+법선, 메시)에 대해 전용 인코더 ℰ를 사용하여 잠재 공간에 매핑하고, 대조 손실(수식 3)을 통해 모달리티와 CAD 잠재 공간을 정렬한다. 핵심 설계는 CAD 인코더를 동결하고 모달리티 인코더만 훈련하여 프레임워크가 대규모 데이터셋으로 확장 가능하게 하는 것이다. 코사인 유사도 p(𝐮,𝐯) = 𝐮ᵀ𝐯/(||𝐮||||𝐯||), τ는 학습 가능한 온도, 배치 크기 B는 2B개의 데이터 포인트를 생성하며, 대응하는 쌍만 양성 샘플이다.
3. **조건부 잠재 확산**: 생성 모델은 p(𝒞|ℳ,ℰ) = p(𝒞|𝐳_𝒞) × p(𝐳_𝒞|𝐳_ℳ)로 분해되며, 사전 분포는 ResNet-MLP 기반 조건부 확산 모델(gorishniy2021revisiting 참조)이고, 손실은 L = 𝔼[||ε − ε_θ(𝐳_t, t, 𝐳_ℳ)||²₂]이다. 각 모달리티에 대해 독립적인 사전 네트워크를 훈련한다.

### 모달리티 인코더
- **점군(DGCNN)**: 4층 동적 그래프 합성곱(채널 128,128,256,512), KNN=20, 중간 레이어 임베딩 연결, max+mean pooling, MLP 1024-512, dropout 0.2, 2.598×10⁶ 파라미터.
- **점군+법선(PC+N)**: 6D 입력(위치+법선), 2.599×10⁶ 파라미터, 균일한 표면 샘플링 생성.
- **메시(FeaStNet)**: Feature-Steered 합성곱, 정점 입력 6D(위치+법선), 채널 16,32,64,128,256, 필터 뱅크 M=10, mean-pooling 차원 축소, 2.66×10⁶ 파라미터.

### SynthBal 데이터 증강
- 목표: 각 시퀀스 길이를 균일하게 균형화(n_ℓ^𝒮 = N^𝒮/|ℒ|), 먼저 비율 r만큼 실제 데이터를 채우고, 나머지는 합성 데이터로 보충.
- 두 가지 연산: (1) **Noise**: 연속 파라미터에 섭동 추가([−m·256, m·256] 균일 샘플링, [1,255]로 클리핑), 이산 값(예: 돌출 방향)은 무시; (2) **Replace-Sketch**: 프로그램의 스케치 연산을 다른 프로그램의 해당 스케치로 무작위 교체.
- 선택 전략: 40% 확률로 큰 노이즈(m=0.07, p=0.6), 60% 확률로 작은 노이즈(m=0.02, p=0.8) 후 Replace-Sketch 적용.
- 핵심 차이점: SynthBal은 훈련 외부에서 생성하고 검증(컴파일하여 CAD 객체로 변환하고 자체 교차가 없는지 확인)하는 반면, DeepCAD/ContrastCAD는 훈련 중 증강하고 검증하지 않는다.

### 훈련 전략
- 먼저 SynthBal 데이터셋에서 훈련(1000 epochs, lr=1e-3, warmup 2000), 그 다음 reduction-balanced 실제 데이터셋(4,503개 모델)에서 마지막 레이어를 미세 조정(100 epochs, lr=1e-5).
- 데이터 누출 방지: 동일한 train/val/test 분할 내에서만 페어링하며, 평가는 항상 원본 DeepCAD 데이터셋에서 수행.

## 핵심 혁신

1. **SynthBal 오프라인 검증형 데이터 균형**: 훈련 중 맹목적으로 연산하는 기존 증강 방법과 달리, SynthBal은 훈련 외부에서 합성 데이터를 생성하고 컴파일 가능성을 검증하여 유효하지 않은 CAD 생성률을 3.44%에서 0.845%로 낮춘다. 이 설계는 데이터 증강을 "운에 맡기는 것"에서 "품질 보장 가능"으로 바꾸고, 긴 시퀀스(고복잡도) 프로그램을 대상으로 한정적으로 보충할 수 있다.
2. **시퀀스 길이 정규화 평가 지표**: 표준 지표는 전체 데이터셋에 대해 평균을 내므로 42%를 차지하는 짧은 시퀀스 샘플에 의해 지배된다. m^SL(𝒳) = (1/|ℒ|)Σ_ℓ m(𝒳_ℓ)는 과대 표현된 길이에 대한 편향을 제거하여 복잡한 기하 구조에서의 개선(또는 실패)이 더 이상 가려지지 않게 한다. 이는 평가 방법론에서 중요한 기여이며, 이후 연구가 결과를 보고하는 방식에 직접적인 영향을 미친다.
3. **메시 모달리티의 대조 정렬**: 처음으로 메시(FeaStNet)를 CAD 프로그램 생성의 대조 학습 프레임워크에 통합하여 기존 기반 모델(CAD-MLLM 등)에 의존하는 방법의 한계를 돌파했다. 메시 인식 인코더는 top-1 검색에서 점군 기준선 대비 최대 11% 향상되었으며, 이득은 대규모 검색 규모(2048개 CAD 모델)에서 가장 두드러져 메시 모달리티가 점군이 포착할 수 없는 표면 토폴로지 정보를 제공함을 시사한다.

## 실험 및 결과

### 핵심 결과 요약

| 지표 | 기준선(점군) | GenCAD-3D(메시) | 개선 |
|------|-------------|-------------------|------|
| 명령 정확도 | - | - | 상대적 향상 최대 15% |
| 파라미터 정확도 | - | - | 3% 향상 |
| Top-1 검색(2048 라이브러리) | - | - | 상대적 향상 최대 11% |
| 유효하지 않은 CAD 생성률 | 3.44%(원본 데이터 훈련) | 0.845%(SynthBal) | 75% 감소(표 내 수치 60.0÷0.8로 계산) |
| 중앙값 Chamfer 거리 | - | - | 최대 89% 감소(긴 시퀀스) |

### 실험 설정
- 데이터셋: DeepCAD 178,238개 프로그램, 컴파일 후 168,656개; 메시 재메시화 후 훈련 세트가 152,530개에서 136,384개로 감소.
- SynthBal: N^𝒮=170,000(표 내 수치 3.44÷89.0으로 계산), r=0.2(16.7% 실제 복제, 83.3% 합성); SynthBal-1M: N^𝒮=1,000,000, r=0.8(13.9% 실제, 86.1% 합성).
- 검색 평가: 라이브러리 배치 크기 10/128/1024/2048, 7,616개 테스트 프로그램에서 bootstrap 샘플링, 배치당 평균 100회.
- 훈련 하드웨어: 단일 H100 80GB.

### 결과 해석
SynthBal은 긴 시퀀스(고복잡도) 프로그램에서 Chamfer 거리 개선이 가장 두드러지며(최대 89%), 데이터 균형 전략의 효과를 직접 검증한다. 메시 인코더가 대규모 검색 라이브러리에서 보이는 우위는 후보 집합이 커질 때 메시가 제공하는 표면 토폴로지 정보가 점군보다 유사한 기하 구조를 구별하는 데 더 유리함을 시사한다. 시퀀스 길이 정규화 지표는 비정규화 지표가 주로 길이 5-15의 성능을 반영하며, 긴 길이 샘플의 성능이 체계적으로 과소평가된다는 것을 드러낸다.

## 경계 및 한계

논문은 명령을 Line, Arc, Circle, Extrude로 명시적으로 제한하며, fillets, lofts, revolves 등 산업에서 흔한 명령은 포함하지 않는다. 아키텍처가 명령 유형을 가정하지 않지만, 실험 검증은 sketch-and-extrude만을 다룬다. 재메시화 과정에서 발생한 오류로 인해 약 10%의 훈련 메시가 제거되어(152,530→136,384) 선택 편향이 발생할 수 있다. 논문은 서로 다른 명령 유형의 실험 결과, 추론 시간, 모델 추론 빈도, 절제 실험 세부 사항을 언급하지 않았으며, 다른 방법(Point2Cyl, CAD-SIGNet 등)과 동일 조건에서의 직접 비교 수치도 제공하지 않는다. SynthBal의 검증은 OpenCascade 컴파일에 의존하며, 컴파일할 수 없는 합성 데이터는 직접 폐기하므로 의미 있는 기하 변형이 일부 필터링될 수 있다.

## 엔지니어링 시사점

재현 시 먼저 데이터 전처리 파이프라인을 확인해야 한다: 메시 재메시화(MeshLab 3회 중점 세분화 + 5회 등방성 재메시화)가 병목이며, 약 10%의 메시가 오류로 인해 폐기되므로 목표 정점 수(2000-4000)와 편향 파라미터(선형 0.001, 각도 0.1)의 호환성을 사전에 검증하는 것이 좋다. SynthBal의 r 파라미터(실제 데이터 채우기 비율)는 핵심 하이퍼파라미터이다——r=0.2일 때 83.3%가 합성 데이터이고, r=0.8일 때 86.1%가 합성 데이터이지만, 미세 조정 단계에서는 반드시 reduction-balanced 실제 데이터셋(4,503개 모델)을 사용해야 하며, 그렇지 않으면 합성 데이터 분포 이동으로 성능이 저하된다. 가장 함정에 빠지기 쉬운 부분은 대조 훈련에서 CAD 인코더를 동결하는 설계이다——두 인코더를 동시에 훈련하면 대조 손실이 CAD 잠재 공간의 의미 구조를 파괴하여 생성 단계의 디코딩 실패를 초래할 수 있다. 평가 시에는 원본 지표와 시퀀스 길이 정규화 지표를 반드시 함께 보고해야 하며, 그렇지 않으면 긴 시퀀스에서의 개선이 짧은 시퀀스가 지배하는 평균값에 가려진다. 하드웨어 요구 사항은 단일 H100 80GB이며, 점군 대조 훈련 300 epochs는 수일이 소요되고, 생성 훈련 1×10⁶ epochs는 수주가 소요되므로 먼저 SynthBal-170K로 파이프라인을 검증한 후 1M으로 확장하는 것이 좋다.
