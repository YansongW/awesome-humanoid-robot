## 概述

BeamDojo 是上海人工智能实验室等机构提出的面向人形机器人的稀疏立足点敏捷运动框架，核心贡献在于设计了基于足底采样的连续立足点奖励、双评论家架构以及两阶段课程化强化学习训练策略。该方法在 IsaacGym 仿真和 Unitree G1 真机上验证了从踏脚石到平衡木等多种危险地形的穿越能力，实现了 80% 的零样本 sim-to-real 迁移成功率。

## 它改变了什么

人形机器人在稀疏立足点地形上的运动控制长期受制于两个根本矛盾：一是多边形足与点状足在落脚评估上的几何差异，导致四足机器人成熟方法无法直接迁移；二是稀疏的立足点奖励与稠密的运动奖励在时间尺度上严重不匹配，使得强化学习在混合奖励环境下难以收敛。现有基于模型的方法需要引入半空间约束来保证落脚安全，但这给在线规划带来了显著的计算负担，而纯学习型方法又因奖励信号过于稀疏而学习效率极低。

BeamDojo 真正改变的是将“稀疏立足点”这一任务从“可解但低效”推进到“工程可用”的层面。它没有试图用更复杂的模型或更精细的奖励工程去硬解稀疏奖励问题，而是通过双评论家架构将稠密与稀疏奖励的梯度流解耦，再配合两阶段训练让策略先在“软约束”下充分探索落脚策略，再在“硬约束”下精调安全边界。这种设计思路跳出了“奖励越精细越好”的惯性，转而从优化结构层面解决了稀疏奖励信用分配的根本困难。

## 方法拆解

### 采样式立足点奖励
针对人形机器人多边形足模型，在足底均匀采样 n 个点，通过计算采样点与安全区域（石头、横梁）的重叠程度来评估落脚质量。奖励定义为：
`r_foothold = −Σ_{i=1}^{2} ℂ_i Σ_{j=1}^{n} 𝟙{d_ij < ε}`
其中 ℂ_i 为足 i 是否接触地形的指示函数，ε 为深度容差（设为 -0.1 m），d_ij < ε 表示该采样点处地形高度显著偏低。该奖励与接触面积成正比，鼓励最大化足底与安全区域的重叠，而非简单的二元判断。

### 双评论家架构
基于 PPO 训练两个独立的评论家网络 {V_φ1, V_φ2}，分别估计两组奖励的值函数：
- R_1 = {r_i}_{i=0}^{n}：常规运动奖励组（稠密，含速度跟踪、姿态、关节限制等）
- R_2 = {r_foothold}：任务特定立足点奖励组（稀疏）

每个值网络用 TD 损失独立更新，各自优势用 GAE 计算后分别归一化，再合成总优势：
`Â_t = w_1·(Â_{1,t}−μ)/σ + w_2·(Â_{2,t}−μ)/σ`
权重 w1=1.0, w2=0.25。关键设计在于独立归一化防止稀疏奖励的噪声干扰稠密奖励的学习，同时让策略能在更长时域内规划足部放置。

### 两阶段 RL 训练
- **阶段1（软地形动力学约束）**：将任务地形 T 映射到同尺寸的平坦地形 F，两者共享地形噪声且点一一对应。机器人实际在平坦地形上行走，接收任务地形 T 的高程图作为感知反馈。立足点奖励由真实地形 T 提供，运动奖励由平坦地形 F 提供。失误受惩罚但不终止回合，允许持续尝试落脚。
- **阶段2（硬地形动力学约束）**：直接在真实任务地形 T 上微调，失误立即终止回合，强制严格遵守真实地形约束。此阶段不施加航向命令，要求机器人通过地形动力学学习持续面向前方。

### 观测与动作空间
观测 o_t = [c_t, o_t^proprio, o_t^percept, a_{t−1}]，其中命令 c_t ∈ ℝ³ 为期望速度，本体感受 o_t^proprio ∈ ℝ⁶⁴ 含基座角速度、重力方向、29 个关节的位置与速度，感知观测 o_t^percept ∈ ℝ^{15×15} 为以机器人为中心的自我中心高程图（网格间距 0.1 m）。动作 a_t ∈ ℝ¹² 为 12 个下半身关节的目标位置，上半身关节使用默认位置，PD 控制器将关节目标转换为力矩。

### 地形课程设计
难度级别 l 从 0 到 8，包含三种训练地形：
- **Stones Everywhere**：石头尺寸 max{0.25, 1.5(1-0.1l)}，石头距离 0.05⌈l/2⌉
- **Stepping Stones**：石头尺寸序列 [0.8, 0.65, 0.5, 0.4, 0.35, 0.3, 0.25, 0.2, 0.2]，最大石头距离 0.1+0.05l
- **Balancing Beams**：石头尺寸 0.3-0.05⌊l/3⌋，x 方向距离 0.4-0.05l，最高难度形成单一连续平衡梁

## 关键创新

**连续立足点奖励替代二元判断**：传统立足点奖励仅在足部落入或落出安全区域时给出离散信号，而 BeamDojo 的采样式奖励与接触面积成正比，提供了连续的梯度信号。这使得策略能够学习“部分落脚”时的微调行为，而非仅在完全失败时获得惩罚。对比实验显示，连续奖励在中等难度 Stepping Stones 上达到 95.67% 成功率，而最优的二元阈值方案（foothold-30%）仅为 93.67%，且落脚误差从 11.43% 降至 7.79%（由表内数值 11.43→7.79 计算）。

**双评论家解耦稠密与稀疏奖励**：这是对 PPO 架构的实质性扩展。将稠密运动奖励与稀疏立足点奖励分别用独立评论家估计值函数，优势归一化后再加权合成，有效避免了稀疏奖励的噪声污染稠密奖励的梯度估计。消融实验显示，去除双评论家后困难难度 Stepping Stones 成功率从 91.67% 降至 55.67%，步态平滑度从 0.7603 恶化至 1.2705，证明该设计同时改善了足部规划与整体运动质量。

**两阶段软-硬约束训练范式**：阶段1在平坦地形上训练但提供真实地形感知，让策略在“安全”环境下充分探索落脚策略而不被提前终止打断；阶段2切换到真实地形并启用终止条件，强制策略遵守真实物理约束。这种课程化设计解决了稀疏奖励环境下单次失误导致训练提前终止、阻碍充分探索的核心问题。消融实验显示，去除软约束阶段后困难难度 Stepping Stones 成功率从 91.67% 降至 42.00%。

## 边界与局限

作者明确承认感知模块的限制：LiDAR 里程计的不准确性、抖动和地图漂移对真实世界部署构成挑战，噪声测量与地形动态变化（如石头抖动）之间的权衡难以在仿真中模拟。方法未在 Stepping Beams 和 Gaps 地形上显式训练，虽然展示了零样本泛化能力，但泛化边界未系统探索。此外，论文未充分利用高程图信息，未充分解决具有显著立足点高度变化的地形挑战，未来工作指向楼梯等需要步态规划的复杂表面。训练中未暴露于间隙和平衡木地形，但实现了对这些稀疏立足点地形的零样本泛化，这一结论的适用范围限于论文测试的地形参数范围。

## 工程启示

复现 BeamDojo 时，优先核对三个关键实现细节：一是立足点奖励的采样点数 n 与深度容差 ε 的取值，ε 设为 -0.1 m，采样点分布需覆盖足底多边形面积；二是双评论家的优势归一化逻辑，必须分别计算均值和标准差后再加权合成，权重 w1=1.0, w2=0.25 不可随意调整；三是两阶段训练的地形映射关系，阶段1的平坦地形 F 与任务地形 T 必须逐点对应且共享噪声，否则感知反馈与立足点奖励会不一致。

最容易踩坑的地方在于阶段2的航向命令处理。作者发现不施加航向命令比施加更有效，原因是模型会过拟合航向命令角速度，难以处理真实世界含噪里程计数据，且真实世界需要精确手动校准初始位置。如果下游团队沿用带航向命令的设计，需要额外处理里程计噪声和初始位置校准问题。另外，高度图域随机化是 sim-to-real 迁移的关键，缺失该设计的消融实验成功率显著降低（Stepping Stones 从 4/5 降至 1/5），复现时务必完整实现 Table IX 中的噪声参数范围。训练配置方面，4096 个并行机器人、每阶段 10000 次迭代是论文标准设置，降低并行度会显著影响训练效率。

## 개요
인간형 로봇이 희소한 디딤발 지형에서 운동할 때 정밀한 발 위치 설정과 안정적인 제어가 필요하지만, 기존 강화 학습 방법은 희소한 디딤발 보상과 비효율적인 학습 과정으로 인해 성능이 저조한 경우가 많습니다. BeamDojo는 세 가지 혁신을 통해 이 문제를 해결합니다: 첫째, 샘플링 기반 다각형 발바닥 디딤발 보상 함수를 설계하고, 이중 비평가 아키텍처를 도입하여 밀집 운동 보상과 희소 디딤발 보상 학습의 균형을 맞춥니다; 둘째, 두 단계 강화 학습 전략을 채택합니다——먼저 평평한 지형에서 로봇이 작업 지형을 인식하도록 훈련한 다음, 실제 지형에서 정책을 미세 조정합니다; 마지막으로, 기내 LiDAR 고도 지도를 통합하여 실제 세계 배포를 구현합니다. 시뮬레이션과 실물 실험 모두 이 방법이 희소한 디딤발에서의 민첩한 운동 능력을 검증하며, 강한 외부 교란에도 높은 성공률을 유지합니다.

## 핵심 내용
### 방법 아키텍처
BeamDojo의 핵심 프레임워크는 강화 학습을 기반으로 하며, 다음 주요 구성 요소를 포함합니다:
- **샘플링 기반 디딤발 보상**: 다각형 발바닥을 위해 설계되었으며, 후보 디딤발 위치를 샘플링하고 목표 위치와의 일치도를 계산하여 희소하지만 정밀한 보상 신호를 제공합니다.
- **이중 비평가 메커니즘**: 하나의 비평가는 밀집 운동 보상(예: 속도 추적, 자세 안정화)을 담당하고, 다른 하나는 희소 디딤발 보상을 전담 처리하며, 두 그래디언트 업데이트의 균형을 통해 학습 편향을 방지합니다.
- **두 단계 훈련 전략**:
  - **1단계**: 평평한 지형에서 훈련하지만, 정책 네트워크에 작업 지형의 인식 관측(예: 고도 지도 특징)을 입력하여 로봇이 지형 인식 능력을 학습하도록 합니다.
  - **2단계**: 실제 작업 지형에서 정책을 미세 조정하며, 1단계에서 학습한 인식 사전 지식을 활용하여 수렴을 가속화합니다.

### 실험 설정
- **시뮬레이션 환경**: Isaac Gym 기반으로 구축되었으며, 다양한 희소 디딤발 지형(예: 매화 말뚝, 분산된 돌 블록)을 포함하고, 무작위 외부 교란(추력, 경사)을 추가합니다.
- **실제 배포**: Unitree H1 인간형 로봇을 사용하며, 360° LiDAR를 장착하여 실시간 고도 지도를 생성하고, 정책은 50Hz 주파수로 실행됩니다.
- **비교 기준선**: 두 단계 훈련이 없는 RL 방법, 이중 비평가가 없는 단일 보상 방법, 그리고 전통적인 모델 예측 제어(MPC) 방법을 포함합니다.
