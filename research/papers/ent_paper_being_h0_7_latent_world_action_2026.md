## 概述

Being-H0.7 是一个 3B 参数的潜在世界-动作模型（latent world-action model），由北京大学 Zongqing Lu 团队提出，通过双分支架构（先验分支 + 未来感知后验分支）在紧凑潜在空间中注入未来信息，而非像素级视频预测。核心贡献在于证明了"问哪些未来信息对控制重要"优于"下一帧图像长什么样"，在保持 VLA 推理效率（3–4 ms/step）的同时，在 LIBERO、RoboCasa、CALVIN 等模拟基准和 12 个真实世界任务上取得领先。

## 它改变了什么

VLA 领域长期存在一个根本性张力：动作监督稀疏且与示范高度相关，模型容易走捷径——直接从视觉线索映射到动作，而不学习物体动力学、接触和任务进展的中间表征。像素级世界模型（如 Fast-WAM 之前的 WAM 方法）试图通过视频展开注入未来预测，但像素空间对控制而言是昂贵且间接的底物：视觉上不同的未来可能对应相同正确动作，视觉上合理的未来可能对控制无关甚至误导。更致命的是，图像-然后-动作架构在互联网规模视频预训练时扩展性差，推理时每步展开未来帧引入的延迟和内存成本，对动态任务（接住移动物体、传送带交互）是硬约束。

Being-H0.7 真正改变的是"未来信息如何进入策略"这一问题的答案。它不重建像素，而是学习一个紧凑的潜在推理空间——一组可学习的潜在查询（latent queries）在多模态上下文与动作 token 之间充当"预测性工作记忆"。这个设计选择同时解决了三个问题：避免了像素重建的欠定性和计算开销；通过先验-后验分支对齐将未来感知信号注入动作生成；推理时完全丢弃后验分支，不增加任何部署负担。这是从"预测未来帧"到"预测控制相关的潜在状态"的范式转移，其意义在于：未来建模第一次可以成为 VLA 的免费午餐，而非需要权衡的额外成本。

## 方法拆解

### 双分支架构
模型在增强序列 S = [x; o_{−H:0}; s; Q; a_{0:T}] 中插入 K=16 个可学习潜在查询 Q ∈ ℝ^{K×d}。先验分支（可部署）仅基于当前上下文生成动作；后验分支（仅训练）将潜在查询替换为未来嵌入 z^{post} = E(õ_{0:T})，其中 E 为冻结 ViT + Perceiver 重采样器，将未来观测聚合为 K 个嵌入。

### 对齐机制
- 联合对齐损失：L_align = (1/L) Σ_{ℓ=1}^{L} (1/|h_ℓ|) ‖h_ℓ^{prior} − h_ℓ^{post}‖_F²，应用于最后 L=9 个 Transformer 层
- 关键设计：两个分支共享上下文 token，但分支 token 间不允许互相注意，仅通过对齐损失耦合
- 位置 ID 分配：先验和后验对应 token 分配相同位置 ID，确保结构匹配

### 高效实现
采用 Mixture-of-Transformers（MoT）结构：动作和状态向量由 Action Expert（Qwen3）处理，其他信号由 Understanding Expert（InternVL3.5）处理。先验和后验分支打包进单一序列，共享上下文 token，分支特定 token 占据不同潜在推理位置。

### 训练目标
- 流匹配：L_FM = L_FM^{prior} + L_FM^{post}，插值动作 a_t = ta + (1−t)ε，目标速度 u_t = a − ε
- 防坍缩正则化：范数正则器 R_norm(h) = [ReLU(τ − ‖h‖₂)]² 防止对齐状态坍缩至消失量级；谱多样性正则器基于 Gram 矩阵特征值谱熵 R_rank(H) = Σ p_i log p_i，防止方向坍缩
- 总目标：L = L_FM + w_align·L_align + L_reg，w_align = 10⁻³，w_norm = w_rank = 10⁻⁴

### 推理
完全丢弃后验分支，不进行未来帧生成或像素空间展开。上下文图像 224×224，未来帧 256×256（仅训练时使用）。预训练遵循 UniHand 2.0 统一序列格式，混合人类和机器人操作数据。

## 关键创新

1. **潜在未来推理替代像素预测**：这是对世界模型范式的根本性重构。像素空间预测对控制是间接底物，而潜在查询空间直接与动作生成对齐。通过先验-后验分支对齐，模型学会"哪些未来相关信息对控制重要"，而非"下一帧长什么样"。这一设计使未来建模从昂贵的可选组件变为几乎零成本的训练信号。

2. **双分支单序列的高效实现**：MoT 结构将先验和后验分支打包进单一序列，共享上下文 token，避免了两倍计算开销。位置 ID 分配确保结构匹配，注意力掩码防止分支间直接通信——仅通过对齐损失耦合。这使得训练时未来感知、推理时零额外成本成为可能。

3. **防坍缩正则化的系统性设计**：潜在对齐的常见失败模式是表示坍缩（所有状态坍缩到同一向量）。范数正则器防止量级坍缩，谱多样性正则器通过最小化负谱熵防止方向坍缩。这两个正则器是潜在对齐方法能否真正学到有区分度表征的关键，也是本方法在 RoboCasa 等复杂场景中保持鲁棒性的原因。

## 工程启示

- **复现优先级**：先核对双分支注意力掩码和位置 ID 分配——这是最容易出错的地方。共享上下文 token 对两个分支可见，但分支 token 间不允许互相注意，仅通过对齐损失耦合。位置 ID 必须一致，否则结构匹配被破坏，对齐损失会学到错误对应
- **防坍缩正则器不可省略**：如果直接实现潜在对齐而不加范数和谱多样性正则器，大概率会遇到表示坍缩——所有潜在状态收敛到同一向量，对齐损失趋近于零但模型失去预测能力。先验分支的潜在查询初始化和正则器阈值 τ 需要仔细调
- **下游后训练注意**：后训练仅优化动作生成目标和潜在对齐损失，不应用防坍缩正则器。这意味着下游微调时潜在空间可能漂移——如果下游任务与预训练分布差异大，需监控对齐损失是否异常增大
- **UAC 机制的关键规则**：从不重写已提交前缀，只将未来后缀拼接回缓冲区。这个前缀锁定/后缀更新设计是吸收模型、传输和调度抖动的核心，实现时不要"优化"掉这个约束
- **数据格式统一是前提**：预训练遵循 UniHand 2.0 统一序列格式，混合人类和机器人数据。如果下游团队有自己的数据格式，需要先对齐到该格式，否则预训练收益无法迁移
- **最可能踩坑的地方**：后验分支的未来帧分辨率（256×256）与上下文帧（224×224）不同，且未来观测编码器冻结、上下文编码器可训练——这个不对称设计容易在实现时被忽略，导致训练/推理行为不一致

## Overview

Being-H0.7 is a 3B-parameter latent world-action model proposed by Zongqing Lu's team at Peking University. It injects future information into a compact latent space via a dual-branch architecture (prior branch + future-aware posterior branch), rather than pixel-level video prediction. The core contribution lies in demonstrating that "asking which future information matters for control" outperforms "what the next frame looks like," achieving leading results on simulation benchmarks such as LIBERO, RoboCasa, and CALVIN, as well as 12 real-world tasks, while maintaining VLA inference efficiency (3–4 ms/step).

## What It Changes

The VLA field has long faced a fundamental tension: action supervision is sparse and highly correlated with demonstrations, making it easy for models to take shortcuts—mapping directly from visual cues to actions without learning intermediate representations of object dynamics, contact, and task progress. Pixel-level world models (such as WAM methods prior to Fast-WAM) attempted to inject future predictions through video rollouts, but pixel space is an expensive and indirect substrate for control: visually different futures can correspond to the same correct action, and visually plausible futures can be irrelevant or even misleading for control. More critically, image-then-action architectures scale poorly during internet-scale video pretraining, and the latency and memory costs of rolling out future frames at each inference step impose hard constraints on dynamic tasks (catching moving objects, conveyor belt interactions).

What Being-H0.7 truly changes is the answer to the question "how future information enters the policy." Instead of reconstructing pixels, it learns a compact latent reasoning space—a set of learnable latent queries that act as "predictive working memory" between multimodal context and action tokens. This design choice simultaneously addresses three issues: it avoids the ill-posedness and computational overhead of pixel reconstruction; it injects future-aware signals into action generation through prior-posterior branch alignment; and it completely discards the posterior branch at inference, adding no deployment burden. This is a paradigm shift from "predicting future frames" to "predicting control-relevant latent states," with the significance that future modeling can for the first time become a free lunch for VLA, rather than an additional cost requiring trade-offs.

## Method Breakdown

### Dual-Branch Architecture
The model inserts K=16 learnable latent queries Q ∈ ℝ^{K×d} into the augmented sequence S = [x; o_{−H:0}; s; Q; a_{0:T}]. The prior branch (deployable) generates actions based solely on current context; the posterior branch (training-only) replaces latent queries with future embeddings z^{post} = E(õ_{0:T}), where E is a frozen ViT + Perceiver resampler that aggregates future observations into K embeddings.

### Alignment Mechanism
- Joint alignment loss: L_align = (1/L) Σ_{ℓ=1}^{L} (1/|h_ℓ|) ‖h_ℓ^{prior} − h_ℓ^{post}‖_F², applied to the last L=9 Transformer layers
- Key design: the two branches share context tokens, but branch tokens are not allowed to attend to each other—they are coupled only via the alignment loss
- Position ID assignment: corresponding tokens in the prior and posterior branches receive identical position IDs, ensuring structural matching

### Efficient Implementation
A Mixture-of-Transformers (MoT) structure is adopted: action and state vectors are processed by the Action Expert (Qwen3), while other signals are handled by the Understanding Expert (InternVL3.5). The prior and posterior branches are packed into a single sequence, sharing context tokens, with branch-specific tokens occupying different latent reasoning positions.

### Training Objectives
- Flow matching: L_FM = L_FM^{prior} + L_FM^{post}, with interpolated actions a_t = ta + (1−t)ε and target velocity u_t = a − ε
- Anti-collapse regularization: a norm regularizer R_norm(h) = [ReLU(τ − ‖h‖₂)]² prevents aligned states from collapsing to vanishing magnitudes; a spectral diversity regularizer based on the spectral entropy of Gram matrix eigenvalues R_rank(H) = Σ p_i log p_i prevents directional collapse
- Total objective: L = L_FM + w_align·L_align + L_reg, with w_align = 10⁻³ and w_norm = w_rank = 10⁻⁴

### Inference
The posterior branch is completely discarded; no future frame generation or pixel-space rollout is performed. Context images are 224×224, and future frames are 256×256 (training-only). Pretraining follows the UniHand 2.0 unified sequence format, mixing human and robot manipulation data.

## Key Innovations

1. **Latent future reasoning replaces pixel prediction**: This is a fundamental restructuring of the world model paradigm. Pixel-space prediction is an indirect substrate for control, whereas the latent query space aligns directly with action generation. Through prior-posterior branch alignment, the model learns "which future-relevant information matters for control" rather than "what the next frame looks like." This design transforms future modeling from an expensive optional component into a nearly zero-cost training signal.

2. **Efficient dual-branch single-sequence implementation**: The MoT structure packs the prior and posterior branches into a single sequence, sharing context tokens and avoiding double computational cost. Position ID assignment ensures structural matching, and attention masks prevent direct communication between branches—coupling occurs only via the alignment loss. This makes future-awareness at training time and zero additional cost at inference time possible.

3. **Systematic design of anti-collapse regularization**: A common failure mode of latent alignment is representation collapse (all states collapsing to the same vector). The norm regularizer prevents magnitude collapse, and the spectral diversity regularizer prevents directional collapse by minimizing negative spectral entropy. These two regularizers are key to whether latent alignment methods can truly learn discriminative representations and are the reason this method maintains robustness in complex scenarios such as RoboCasa.

### Key Findings
- **RoboTwin 2.0 domain randomization robustness**: 90.2% in clean settings vs. 89.6% under domain randomization, a drop of only 0.6%, significantly outperforming other methods' sensitivity to visual perturbations
- **CALVIN zero-shot generalization**: 4.48 in the ABC→D setting, surpassing all baselines, demonstrating the contribution of latent future modeling to generalization in unseen environments
- **Real world**: 12 tasks across 5 capability suites (dynamic scenes, physical reasoning, motion reasoning, long-horizon, generalization), 20 blind trials per task, with Being-H0.7 leading across all. The advantage is most pronounced in the dynamic scenes suite (Fast-WAM is the strongest baseline, consistent with its low-latency design); the closest baseline in physical reasoning and long-horizon suites is Being-H0.5
- **Deployment efficiency**: 3–4 ms/step under the UAC mechanism, with GPU memory identical to the non-UAC version

### Notable Shortcomings
RoboCasa-50 lags Cosmos-Policy by 5 percentage points, and GR1 lags ABot-M0 by 9.1 percentage points—both benchmarks are few-shot scenarios (50 or 1000 demonstrations), suggesting that the advantage of latent alignment is less pronounced than large-scale pretrained baselines when data is scarce.

## Boundaries and Limitations

- **Lack of quantitative real-world comparison**: The paper only reports "leading" without specific success rates, nor does it provide quantitative comparisons with other methods on real-world tasks—making the real-world advantage impossible to independently verify
- **No ablation of hyperparameters**: No ablation studies are conducted on the number of latent queries K, alignment layers L, or regularization weights w_align/w_norm/w_rank, making it impossible to assess the sensitivity of these design choices
- **Training data scale undisclosed**: The number of hours or trajectories in the pretraining data is not mentioned, affecting verification of the claim regarding "internet-scale pretraining scalability"
- **Failure modes not analyzed**: No mention of failure modes in out-of-distribution scenarios, nor a systematic categorization of failure cases
- **Latent space is uninterpretable**: The authors explicitly do not perform interpretability analysis or visualization validation of the latent reasoning space—what the "predictive working memory" internally encodes remains a black box
- **Underperformance on RoboCasa and GR1**: Lagging behind specialized baselines in few-shot scenarios indicates that the advantage of latent alignment may depend on sufficient pretraining data support

## Engineering Insights

- **Reproduction priority**: First verify the dual-branch attention mask and position ID assignment—these are the most error-prone areas. Shared context tokens are visible to both branches, but branch tokens are not allowed to attend to each other, coupled only via the alignment loss. Position IDs must be consistent; otherwise, structural matching is broken and the alignment loss learns incorrect correspondences
- **Anti-collapse regularizers are indispensable**: If latent alignment is implemented directly without norm and spectral diversity regularizers, representation collapse is highly likely—all latent states converge to the same vector, the alignment loss approaches zero, but the model loses predictive capability. The initialization of prior-branch latent queries and the regularizer threshold τ require careful tuning
- **Downstream post-training considerations**: Post-training optimizes only the action generation objective and latent alignment loss, without applying anti-collapse regularizers. This means the latent space may drift during downstream fine-tuning—if the downstream task differs significantly from the pretraining distribution, monitor whether the alignment loss increases abnormally
- **Key rules of the UAC mechanism**: Never rewrite already-committed prefixes; only append future suffixes back to the buffer. This prefix-locking/suffix-updating design is central to absorbing model, transmission, and scheduling jitter—do not "optimize away" this constraint during implementation
- **Unified data format is a prerequisite**: Pretraining follows the UniHand 2.0 unified sequence format, mixing human and robot data. If downstream teams have their own data formats, they must first align to this format; otherwise, pretraining benefits cannot transfer
- **Most likely pitfall**: The posterior branch's future frame resolution (256×256) differs from the context frame resolution (224×224), and the future observation encoder is frozen while the context encoder is trainable—this asymmetric design is easily overlooked during implementation, leading to inconsistent training/inference behavior

## 개요

Being-H0.7은 베이징대학교 Zongqing Lu 팀이 제안한 3B 파라미터 잠재 세계-행동 모델(latent world-action model)로, 픽셀 수준의 비디오 예측 대신 이중 분기 아키텍처(사전 분기 + 미래 인식 사후 분기)를 통해 컴팩트한 잠재 공간에 미래 정보를 주입합니다. 핵심 기여는 "다음 프레임 이미지가 어떻게 생겼는가"보다 "제어에 중요한 미래 정보가 무엇인가"를 묻는 것이 우월함을 증명한 것이며, VLA 추론 효율(3–4 ms/step)을 유지하면서 LIBERO, RoboCasa, CALVIN 등의 시뮬레이션 벤치마크와 12개의 실제 세계 작업에서 선두를 차지했습니다.

## 무엇을 바꾸었는가

VLA 분야에는 오랫동안 근본적인 긴장이 존재해 왔습니다: 행동 감독은 희소하고 데모와 높은 상관관계를 가지므로, 모델은 물체 역학, 접촉, 작업 진행 상황의 중간 표현을 학습하지 않고 시각적 단서에서 행동으로 직접 매핑하는 지름길을 쉽게 취합니다. 픽셀 수준 세계 모델(예: Fast-WAM 이전의 WAM 방법)은 비디오 전개를 통해 미래 예측을 주입하려 했지만, 픽셀 공간은 제어에 있어 비용이 많이 들고 간접적인 기질(substrate)입니다: 시각적으로 다른 미래가 동일한 올바른 행동에 대응할 수 있고, 시각적으로 그럴듯한 미래가 제어에 무관하거나 오히려 오해를 불러일으킬 수 있습니다. 더 치명적인 것은, 이미지-그리고-행동 아키텍처는 인터넷 규모 비디오 사전 학습에서 확장성이 낮고, 추론 시 매 단계 미래 프레임을 전개할 때 발생하는 지연과 메모리 비용이 동적 작업(움직이는 물체 잡기, 컨베이어 벨트 상호작용)에 있어 하드 제약이 된다는 점입니다.

Being-H0.7이 진정으로 바꾼 것은 "미래 정보가 정책에 어떻게 들어가는가"라는 질문에 대한 답입니다. 픽셀을 재구성하지 않고, 컴팩트한 잠재 추론 공간, 즉 학습 가능한 잠재 쿼리(latent queries) 집합이 다중 모달 컨텍스트와 행동 토큰 사이에서 "예측적 작업 기억(predictive working memory)" 역할을 하도록 학습합니다. 이 설계 선택은 세 가지 문제를 동시에 해결합니다: 픽셀 재구성의 부정정성(underdetermination)과 계산 오버헤드를 피하고; 사전-사후 분기 정렬을 통해 미래 인식 신호를 행동 생성에 주입하며; 추론 시 사후 분기를 완전히 폐기하여 배포 부담을 전혀 추가하지 않습니다. 이는 "미래 프레임 예측"에서 "제어 관련 잠재 상태 예측"으로의 패러다임 전환이며, 그 의미는 미래 모델링이 처음으로 VLA의 공짜 점심(free lunch)이 될 수 있다는 점, 즉 절충이 필요한 추가 비용이 아니라는 점입니다.

## 방법 분해

### 이중 분기 아키텍처
모델은 증강 시퀀스 S = [x; o_{−H:0}; s; Q; a_{0:T}]에 K=16개의 학습 가능한 잠재 쿼리 Q ∈ ℝ^{K×d}를 삽입합니다. 사전 분기(배포 가능)는 현재 컨텍스트만 기반으로 행동을 생성하고; 사후 분기(훈련 전용)는 잠재 쿼리를 미래 임베딩 z^{post} = E(õ_{0:T})로 대체하며, 여기서 E는 동결된 ViT + Perceiver 리샘플러로 미래 관측을 K개의 임베딩으로 집계합니다.

### 정렬 메커니즘
- 결합 정렬 손실: L_align = (1/L) Σ_{ℓ=1}^{L} (1/|h_ℓ|) ‖h_ℓ^{prior} − h_ℓ^{post}‖_F², 마지막 L=9개의 Transformer 레이어에 적용
- 핵심 설계: 두 분기는 컨텍스트 토큰을 공유하지만, 분기 토큰 간에는 상호 어텐션이 허용되지 않으며 정렬 손실을 통해서만 결합됩니다
- 위치 ID 할당: 사전 및 사후 대응 토큰에 동일한 위치 ID를 할당하여 구조적 일치를 보장합니다

### 효율적인 구현
Mixture-of-Transformers(MoT) 구조를 채택: 행동 및 상태 벡터는 Action Expert(Qwen3)가 처리하고, 다른 신호는 Understanding Expert(InternVL3.5)가 처리합니다. 사전 및 사후 분기는 단일 시퀀스로 패킹되어 컨텍스트 토큰을 공유하며, 분기별 토큰은 서로 다른 잠재 추론 위치를 차지합니다.

### 훈련 목표
- 흐름 매칭: L_FM = L_FM^{prior} + L_FM^{post}, 보간 행동 a_t = ta + (1−t)ε, 목표 속도 u_t = a − ε
- 붕괴 방지 정규화: 노름 정규화기 R_norm(h) = [ReLU(τ − ‖h‖₂)]²는 정렬 상태가 소멸 수준으로 붕괴되는 것을 방지하고; 스펙트럼 다양성 정규화기는 Gram 행렬 고유값 스펙트럼 엔트로피 R_rank(H) = Σ p_i log p_i를 기반으로 방향 붕괴를 방지합니다
- 총 목표: L = L_FM + w_align·L_align + L_reg, w_align = 10⁻³, w_norm = w_rank = 10⁻⁴

### 추론
사후 분기를 완전히 폐기하고, 미래 프레임 생성이나 픽셀 공간 전개를 수행하지 않습니다. 컨텍스트 이미지는 224×224, 미래 프레임은 256×256(훈련 시에만 사용)입니다. 사전 훈련은 UniHand 2.0 통합 시퀀스 형식을 따르며 인간과 로봇 조작 데이터를 혼합합니다.

## 핵심 혁신

1. **픽셀 예측을 대체하는 잠재 미래 추론**: 이는 세계 모델 패러다임의 근본적인 재구성입니다. 픽셀 공간 예측은 제어에 있어 간접적인 기질인 반면, 잠재 쿼리 공간은 행동 생성과 직접 정렬됩니다. 사전-사후 분기 정렬을 통해 모델은 "다음 프레임이 어떻게 생겼는가"가 아니라 "제어에 중요한 미래 관련 정보가 무엇인가"를 학습합니다. 이 설계는 미래 모델링을 비용이 많이 드는 선택적 구성 요소에서 거의 비용이 들지 않는 훈련 신호로 전환합니다.

2. **이중 분기 단일 시퀀스의 효율적인 구현**: MoT 구조는 사전 및 사후 분기를 단일 시퀀스로 패킹하고 컨텍스트 토큰을 공유하여 두 배의 계산 오버헤드를 피합니다. 위치 ID 할당은 구조적 일치를 보장하고, 어텐션 마스크는 분기 간 직접 통신을 방지합니다—정렬 손실을 통해서만 결합됩니다. 이는 훈련 시 미래 인식, 추론 시 추가 비용 제로를 가능하게 합니다.

3. **붕괴 방지 정규화의 체계적 설계**: 잠재 정렬의 일반적인 실패 모드는 표현 붕괴(모든 상태가 동일한 벡터로 붕괴)입니다. 노름 정규화기는 크기 붕괴를 방지하고, 스펙트럼 다양성 정규화기는 음의 스펙트럼 엔트로피를 최소화하여 방향 붕괴를 방지합니다. 이 두 정규화기는 잠재 정렬 방법이 진정으로 구별 가능한 표현을 학습할 수 있는지의 핵심이며, RoboCasa와 같은 복잡한 시나리오에서 이 방법의 견고성을 유지하는 이유이기도 합니다.

- **배포 효율성**: UAC 메커니즘 하에서 3–4 ms/step, GPU 메모리는 비-UAC 버전과 동일합니다

## 경계 및 한계

- **실제 세계에서의 정량적 비교 부재**: 논문은 "선두"만 보고할 뿐 구체적인 성공률 수치를 제공하지 않으며, 다른 방법과의 실제 세계 작업 정량적 비교도 없습니다—이로 인해 실제 세계 우위를 독립적으로 검증할 수 없습니다
- **하이퍼파라미터 소거 실험 부재**: 잠재 쿼리 수 K, 정렬 레이어 수 L, 정규화 가중치 w_align/w_norm/w_rank에 대한 소거 연구가 없어 이러한 설계 선택의 민감도를 판단할 수 없습니다
- **훈련 데이터 규모 미공개**: 사전 훈련 데이터의 시간 수나 궤적 수가 언급되지 않아 "인터넷 규모 사전 훈련 확장성" 주장의 검증에 영향을 미칩니다
- **실패 모드 미분석**: 훈련 분포를 벗어난 시나리오에서의 실패 모드가 언급되지 않았고, 실패 사례의 체계적 분류도 없습니다
- **잠재 공간의 해석 불가능성**: 저자는 잠재 추론 공간에 대한 해석 가능성 분석이나 시각화 검증을 명시적으로 수행하지 않았습니다—"예측적 작업 기억" 내부에 무엇이 인코딩되는지는 여전히 블랙박스입니다
- **RoboCasa 및 GR1에서의 뒤처짐**: 소수 샷 시나리오에서 전용 베이스라인에 뒤처지며, 잠재 정렬의 이점이 충분한 사전 훈련 데이터 지원에 의존할 수 있음을 시사합니다

## 공학적 시사점

- **재현 우선순위**: 먼저 이중 분기 어텐션 마스크와 위치 ID 할당을 확인하세요—이것이 가장 오류가 발생하기 쉬운 부분입니다. 공유 컨텍스트 토큰은 두 분기에 모두 보이지만, 분기 토큰 간 상호 어텐션은 허용되지 않으며 정렬 손실을 통해서만 결합됩니다. 위치 ID는 일치해야 하며, 그렇지 않으면 구조적 일치가 깨지고 정렬 손실이 잘못된 대응을 학습하게 됩니다
- **붕괴 방지 정규화기는 생략 불가**: 노름 및 스펙트럼 다양성 정규화기 없이 잠재 정렬을 직접 구현하면 표현 붕괴를 만날 가능성이 높습니다—모든 잠재 상태가 동일한 벡터로 수렴하고 정렬 손실이 0에 가까워지지만 모델은 예측 능력을 잃습니다. 사전 분기의 잠재 쿼리 초기화와 정규화기 임계값 τ는 신중히 조정해야 합니다
- **다운스트림 후훈련 주의**: 후훈련은 행동 생성 목표와 잠재 정렬 손실만 최적화하고 붕괴 방지 정규화기를 적용하지 않습니다. 이는 다운스트림 미세 조정 시 잠재 공간이 드리프트할 수 있음을 의미합니다—다운스트림 작업이 사전 훈련 분포와 크게 다르면 정렬 손실이 비정상적으로 증가하는지 모니터링해야 합니다
- **UAC 메커니즘의 핵심 규칙**: 이미 제출된 접두사를 절대 덮어쓰지 않고, 미래 접미사만 버퍼에 다시 연결합니다. 이 접두사 잠금/접미사 업데이트 설계는 흡수 모델, 전송 및 스케줄링 지터를 처리하는 핵심이므로, 구현 시 이 제약을 "최적화"하여 제거하지 마십시오
- **데이터 형식 통일이 전제**: 사전 훈련은 UniHand 2.0 통합 시퀀스 형식을 따르며 인간과 로봇 데이터를 혼합합니다. 다운스트림 팀이 자체 데이터 형식을 가지고 있다면 먼저 해당 형식에 맞춰야 하며, 그렇지 않으면 사전 훈련 이점이 이전되지 않습니다
- **가장 함정에 빠지기 쉬운 부분**: 사후 분기의 미래 프레임 해상도(256×256)와 컨텍스트 프레임(224×224)이 다르고, 미래 관측 인코더는 동결되고 컨텍스트 인코더는 훈련 가능하다는 비대칭 설계는 구현 시 쉽게 간과되어 훈련/추론 동작 불일치를 초래할 수 있습니다
