## 概述

SafeHumanoid 提出一种基于 VLM-RAG 的模块化架构，将语义场景理解映射为人形机器人上肢阻抗参数与速度调度。系统在 Unitree G1 上以 50 Hz 控制环运行，通过检索经验数据库实现上下文感知的刚度/阻尼调整，并在未见任务中展示泛化能力。核心贡献在于首次将检索增强生成应用于人形机器人 HRI 的阻抗控制，建立语义推理与物理交互安全之间的桥梁。

## 它改变了什么

现有机器人控制研究长期割裂两个层面：视觉系统负责几何感知却缺乏语义判断，无法区分旁观者与主动协作者；而 VLM/VLA 管线聚焦任务可行性与位置执行，完全忽略阻抗行为（刚度、阻尼、速度调制）对交互安全与舒适度的决定性影响。固定阻抗设置无法应对递脆弱物体需软接触、擦桌需稳定这类对立需求，自适应控制器又多在交互发生后被动反应，缺乏主动预判能力。

SafeHumanoid 真正改变的是将“语义理解”从任务规划层下沉到“物理交互参数层”。它不再问“做什么”，而是问“以何种刚度、何种速度去做”。这种转变使得机器人能在接触发生前，根据对象脆弱性、人类存在状态、工作区复杂度等语义线索，主动选择安全的阻抗配置——这是从反应式安全向预测式安全的范式迁移，也是首次将 RAG 引入人形机器人阻抗控制领域。

## 方法拆解

系统采用客户端-服务器模型，模块化分解为通信、感知、安全参数生成、机器人控制四层。

### 感知层
- Molmo-7B BnB 4-bit 模型处理第一视角 RGB 帧，固定任务特定提示强制 JSON 输出
- 输出键包括：任务类型、主对象、对象脆弱性、人类存在、障碍物数量与类型、工作区条件、手臂姿态、对象位置、间距、整体复杂度、置信度分数
- 图像流以 1–2 Hz 频率通过 TCP/IP Wi-Fi 传输

### RAG 检索层
- VLM 输出经 all-MiniLM-L6-v2 编码为 384 维嵌入向量
- FAISS 精确最近邻搜索（欧氏距离），数据库含 16 个经验验证场景
- 输出 28 个阻抗参数（14 关节 × 比例/微分增益）、名义关节速度、元数据
- 回退逻辑：若两个候选相似度接近或最佳匹配低于置信度阈值，拒绝检索并回退保守参数

### 控制层
- IK 求解器在锁定非手臂关节的简化模型上运行，优化成本平衡平移、旋转、正则化、平滑项，权重 {w_trans, w_rot, w_reg, w_smooth}
- 输出 q_ref 和重力补偿前馈力矩 τ_ff（RNEA）
- 低层阻抗控制器以 50 Hz 执行命令集 {q_ref, q̇_ref, τ_ff, K_p, K_d}
- 阻抗方程：τ = K_p (q_ref − q) + K_d (q̇_ref − q̇) + τ_ff；力映射 F = J(q)^(−⊤) τ

### 执行模式
- G1 执行器位置控制模式，需指定 PD 增益与目标位置/速度
- 轨迹来源为预定义末端执行器目标位姿，架构源无关，未来可由 6-DoF 位姿估计或 VLA 生成

## 关键创新

**1. 语义到阻抗的直接映射**：现有 VLM/RAG 工作（ImpedanceGPT、Shake-VLA）均未应用于人形机器人 HRI 的阻抗控制。SafeHumanoid 首次将检索增强生成与阻抗参数生成结合，使语义推理结果直接驱动物理交互参数，而非停留在任务规划层面。

**2. 主动预判而非被动反应**：传统自适应控制器在交互后调整参数，本系统通过 VLM 语义分析在接触前预判安全行为。这种预测式安全机制对递脆弱物体、人机交接等场景至关重要，因为交互后的反应往往已造成伤害。

**3. 轻量检索替代端到端训练**：无端到端训练，RAG 检索驱动，数据库仅 16 行 × 34 列。这种设计使系统可快速扩展新场景（只需添加数据库条目），避免 VLA 管线的大规模训练成本，且回退逻辑保证检索失败时的安全性。

## 实验与结果

实验在 Unitree G1 人形机器人上进行，机载 PC 为 NVIDIA Jetson Orin NX，服务器为 RTX 4090（24GB VRAM），覆盖六种桌面操作任务。

| 任务 | 结果 |
|------|------|
| pin 交接（不在数据库） | 成功泛化，正确调整阻抗 |
| cube 交接（在数据库） | 正确切换低刚度，人离开后恢复 |
| 酱油瓶交接 | 速度 medium → slow → medium |
| 表面擦拭 | 系统成功调整阻抗参数与名义速度 |
| 液体倒出 | 系统成功调整阻抗参数与名义速度 |

关键数字：K_p ∈ [10, 60]，K_d ∈ [0.1, 2.0]；名义速度三个离散值（slow、mid、normal）；VLM–RAG 循环延迟高达 1.4 s；数据库任务分布：pick (9)、handover (4)、other (3)；人类存在条件：none (9)、hand_visible (7)。

结果表明系统在所有情况下均成功调整参数，且对未见任务（pin 交接）展现泛化能力。但 1.4 s 延迟限制动态 HRI 适用性，数据库手动策划也限制可扩展性。

## 边界与局限

作者明确承认的局限包括：离板推理延迟高达 1.4 s，限制动态 HRI 适用性；场景数据库手动策划需人工监督，限制可扩展性与多样性；实验使用预定义末端执行器位姿，依赖手动指定轨迹，非全自主动作生成；未集成深度感知（RealSense 深度未用于距离估计或对象定位）；未扩展语义接地到连续物理属性（如硬度、重量、表面摩擦、合规性）；未自动化数据集构建（未用仿真到现实迁移、合成数据增强、自标注）。

论文未明确提及系统在多人场景、非结构化环境或长时间运行下的稳定性表现，也未讨论 Wi-Fi 通信中断时的具体降级策略细节。

## 工程启示

复现时先核对三个关键点：**数据库质量**——16 个场景的阻抗参数标注是否覆盖目标任务分布，回退逻辑的置信度阈值设置直接影响检索失败时的安全性；**通信延迟**——1–2 Hz 图像流与 50 Hz 控制环的异步耦合，需确保机载 PC 在通信中断时能正确回退保守配置；**VLM 输出稳定性**——Molmo-7B 的 JSON 模式输出是否可靠，建议增加输出校验与重试机制。

最容易踩坑的地方是 RAG 检索的相似度阈值：若阈值过松，错误场景的阻抗参数会被误用；过紧则频繁回退保守配置，丧失自适应能力。建议在部署前对目标场景做相似度分布分析，确定合理阈值区间。另外，预定义轨迹限制了全自主性，若下游团队需要动态任务，需先集成 6-DoF 位姿估计或 VLA 轨迹生成模块。

## 개요
SafeHumanoid는 자기 중심적 시각 처리 파이프라인을 구축하여 구조화된 VLM 프롬프트를 통해 1인칭 시점 이미지를 처리하고, 임베딩 결과를 사전 검증된 장면 데이터베이스와 매칭합니다. 시스템은 검색 증강 생성 기술을 활용하여 매칭 결과를 관절 수준 임피던스 명령으로 매핑함으로써, 데스크톱 조작 작업에서 상황 인식형 강성, 감쇠, 속도 조절을 구현합니다. 실험은 닦기, 물체 인계, 액체 따르기 등의 시나리오를 포함하며, 해당 방법이 작업 성공률을 유지하면서 안전성을 향상시킬 수 있음을 보여줍니다. 다만 현재 추론 지연 시간(최대 1.4초)이 매우 동적인 환경에서의 응답 속도를 제한합니다.

## 핵심 내용
### 방법 아키텍처
- **시각 처리 파이프라인**: 자기 중심적 시각(egocentric vision)을 입력으로 사용하며, 구조화된 VLM 프롬프트를 통해 1인칭 시점 이미지 프레임을 처리합니다.
- **검색 증강 생성**: VLM 출력의 임베딩 벡터를 사전 검증된 장면 데이터베이스와 매칭하고, RAG 기술을 활용하여 가장 관련성 높은 임피던스 제어 파라미터를 검색합니다.
- **관절 수준 제어**: 역운동학을 통해 검색된 임피던스 파라미터를 관절 수준의 강성, 감쇠, 속도 명령으로 매핑하여 상체 임피던스의 실시간 스케줄링을 구현합니다.

### 실험 설정
- **작업 시나리오**: 데스크톱 조작 환경에서 닦기(wiping), 물체 인계(object handovers), 액체 따르기(liquid pouring)의 세 가지 작업 유형을 테스트합니다.
- **비교 조건**: 사람이 있는 경우와 없는 경우의 시나리오를 각각 실험하여, 시스템의 상황 변화 적응 능력을 평가합니다.
- **성능 지표**: 작업 성공률과 안전성 지표 간의 균형을 중점적으로 살펴보며, 추론 지연 시간이 동적 응답에 미치는 영향도 기록합니다.

### 주요 결과
- **상황 적응 능력**: 시스템은 인간의 접근 정도와 작업 유형에 따라 임피던스 파라미터를 자동으로 조정하며, 사람이 있는 시나리오에서는 강성과 속도를 낮추어 안전성을 향상시킵니다.
- **작업 성공률**: 기준 방법과 유사한 작업 완료율을 유지하면서도, 예상치 못한 충돌 위험을 크게 줄입니다.
- **지연 시간 제한**: 현재 추론 지연 시간은 최대 1.4초로, 매우 동적인 상호작용 시나리오에서는 응답이 부족하지만, 의미 기반 임피던스 제어(semantic grounding of impedance control)의 실현 가능성을 입증합니다.

### 결론
SafeHumanoid는 VLM과 RAG를 결합하여 휴머노이드 로봇의 임피던스 제어에 적용할 수 있는 잠재력을 보여주며, 안전 기준을 충족하는 인간-로봇 협업의 새로운 경로를 제시합니다. 향후 작업은 실시간 동적 상호작용을 지원하기 위해 추론 속도를 최적화해야 합니다.
