## 概述

Vesta 是一个从 Qwen3-VL-8B 微调而来的通用具身推理模型，旨在将定位、导航、空间推理和长时程规划统一到单一规划器中，而非堆叠多个专家模型。其核心贡献在于通过监督微调混合六类数据，并引入极简记忆装置（固定预算图像采样 + 文本子任务缓存），在学术基准、离线规划和真实机器人任务上均显著超越 SOTA 基线与专家集成。

## 它改变了什么

这篇工作真正改变的是“具身智能体能力组织方式”的默认假设。过去，导航、定位、推理各自为政，每个能力都有专门的模型和基准，部署时要么堆叠多模型（计算开销大、级联错误），要么指望单个 VLM 在某个任务上碰巧表现好。Vesta 用数据混合和统一训练证明了：一个 8B 模型可以在所有具身认知任务上同时达到或超过专家水平，且这种统一不是简单的“能力叠加”，而是产生了正迁移——统一模型在导航上比纯导航专家还高 1.4 SR，在具身认知上比纯具身专家高 3.9 平均分。这直接动摇了“专业模型必然优于通用模型”的行业惯例。

另一个被改变的是记忆机制的设计哲学。现有方法（MemER、MEM）都在追求更聪明的记忆——学习型检索器、场景表示、事件追踪器。Vesta 反其道而行，用固定预算的近期帧采样加文本子任务日志，结果在真实机器人上比仅执行器基线提升 38.3% 成功率。这说明在 planner-actor 分层架构下，记忆的“模态组合”比“检索策略”更重要——图像+文本混合记忆比任何单模态都强，而均匀采样与近期偏置采样几乎无差别。这对那些在记忆机制上过度工程化的团队是一个清醒的提醒。

## 方法拆解

### 总体架构
- 基础模型：Qwen3-VL-8B，全参数微调（视觉塔 + 投影器 + 语言骨干），纯 bf16。
- 训练：1 epoch，lr 1e-5，cosine 调度，weight decay 0.01，batch size 256，128 块 H100，FSDP 全分片，FlashAttention-2，序列打包，截断长度 8192，最大视频帧 32。
- 所有结构化输出（点、框）通过语言头以文本 token 解码，与自由形式答案共用解码头——这是统一接口的关键设计。

### 数据混合（SFT 六类）
| 数据类别 | 占比 |
|---|---|
| 空间智能 | 27.1% |
| 导航 | 21.8% |
| 定位 | 20.8% |
| 通用 VLM | 16.2% |
| 具身推理 | 9.8% |
| 真实机器人 | 4.3% |

### 定位：base–tail 策略
- Base：Objects365、COCO、LVIS（广泛类别覆盖）。
- Tail：第一人称观察、操作中心标注、时间演化交互序列（适应部分可观测性和视角变化）。

### 导航：R2R 风格 VLN 公式
- episode e = (I, s₀, g)，决策点 t 观察位姿 sₜ、第一人称图像 oₜ、采样视觉历史 Hₜ。
- 优化目标：max_θ 𝔼[𝟙{d(s_T, g) ≤ d_succ}]，d_succ = 3.0m。
- 输出三种动作：像素目标（↓ + 归一化路点 (u,v) ∈ [0,1000]²）、转向序列（{←,→}）、stop。
- 数据：R2R、RxR、ScaleVLN 的 VLN-CE，仿真渲染。

### 带记忆的动作规划
- 非马尔可夫过程：aₜ = π(o_{≤t}, a_{<t}, g)，近似状态 sₜ = Φ(oₜ, ℳₜ, g)。
- 每个子任务前生成四阶段 CoT：Observation → Progress → Reasoning → Action，仅 aₜ 写入记忆。
- 记忆装置：元组 mᵢ = ⟨i, τᵢ, oᵢ, aᵢ, g⟩，历史图像经采样算子 𝒮ₜ 限制最多 K 帧，第一帧始终保留，支持均匀或近期偏置采样。

### 分层执行架构（真实机器人）
- Planner VLM（Vesta）输出子任务 → Actor VLA（Gr00t-N1.6）执行动作。
- 同步模式：planner 推理为阻塞调用（约 1 秒），目标变化或超过最大陈旧度 τ_max 时暂停 actor。
- 异步模式：planner 线程持续运行，控制循环每 tick 读取缓存子任务，不阻塞。
- 通信仅通过共享变量 z（当前子任务），planner 记忆对 actor 不可见。

## 关键创新

1. **统一规划器取代专家集成**：Vesta 在 11 个认知基准和 5 个定位基准上平均分分别达 68.7 和 69.9，超过所有单模型基线，且比 oracle ensemble 高 >10%。这不是简单的“多任务学习”，而是证明了正迁移——统一模型在导航 SR 上比纯导航专家高 1.4，在具身认知上比纯具身专家高 3.9。对工程团队意味着：不需要再维护多个模型和切换逻辑。

2. **极简记忆装置的有效性**：固定预算图像采样 + 文本子任务缓存，无学习型检索器。消融显示图像+文本混合记忆（75.9 总体分）远超仅图像（63.1）和仅文本（49.7），而均匀采样与近期偏置采样几乎无差别（75.9 vs 75.3）。这证明在 planner-actor 架构下，记忆的模态组合是主要瓶颈，帧选择策略是次要问题——这为记忆机制设计提供了明确优先级。

3. **过渡采样（transition oversampling）的发现**：默认采样下过渡阶段数据仅占约 25%，将过渡采样从 1× 增至 2× 带来过渡准确率大幅提升（58.1→68.1）和总体准确率增益（73.6→75.9），增至 3× 仅边际改善且损害执行。这是一个可操作的数据工程洞见：在长时程任务中，任务切换瞬间（过渡）比执行阶段更值得关注。

## 边界与局限

- **真实机器人评估范围有限**：仅单一平台（I2RT 双臂 YAM 夹爪）和三个任务，未涉及人形机器人（全身运动+双臂耦合）、移动操作器（导航与操作切换）、灵巧手（细粒度子任务词汇）。
- **规模局限**：所有数字均为 8B 规模，具身 SFT 混合数据的缩放行为远不如网络数据被充分理解，更大规模下结论可能不成立。
- **记忆未学习**：记忆 harness 是固定的（均匀/近因采样 + 文本日志），未将记忆本身作为学习对象，未涉及终身学习（跨 episode 的巩固、遗忘、重检索）。
- **actor 假设**：当前设置隐含假设 actor 能以固定控制率忠实执行一小套自然语言子任务，若 actor 语言跟随能力弱，规划器优势会被执行错误掩盖（真实机器人实验中大多数失败由执行器驱动）。
- **未做之事**：未评估其他机器人平台、未进行大规模真实世界多任务部署、未与其他通用模型在更大规模对比、未做蒸馏和边缘部署实验。

## 工程启示

- **先核对数据混合比例**：Vesta 的成功高度依赖六类数据的配比（空间智能 27.1%、导航 21.8%、定位 20.8%）。复现时不要随意调整比例，尤其注意导航数据不可缺失——所有通用 VLM 基线在 R2R-CE 上 SR=0.0，说明导航能力必须显式训练。
- **最容易踩坑的是过渡采样**：默认采样下过渡数据仅占 25%，不调整的话长时程任务表现会显著下降（73.6 vs 75.9）。建议在数据管线中显式统计过渡阶段占比，并设置 2× 过采样。
- **记忆模态比检索策略重要**：如果资源有限，优先保证图像+文本混合记忆，不要花时间调帧采样策略——均匀采样和近期偏置几乎无差别（75.9 vs 75.3）。
- **分层架构的通信协议要简单**：planner 和 actor 仅通过共享变量 z（当前子任务）通信，planner 记忆对 actor 不可见。同步模式适合实验复现，异步模式适合生产部署（运动平滑性优先）。
- **真实机器人评估注意执行器瓶颈**：执行器错误驱动大多数失败 episode，评估时务必区分规划器错误和执行器错误，否则会误判规划器性能。建议先单独评估 actor 的语言跟随能力。
- **训练配置可直接复用**：1 epoch、lr 1e-5、weight decay 0.01、batch 256、128 H100、FSDP 全分片、FlashAttention-2、序列打包、截断 8192、最大视频帧 32——这些参数在论文中明确给出，可直接作为起点。

## Overview

Vesta is a general-purpose embodied reasoning model fine-tuned from Qwen3-VL-8B, designed to unify grounding, navigation, spatial reasoning, and long-horizon planning into a single planner rather than stacking multiple expert models. Its core contribution lies in supervised fine-tuning on a mixture of six data categories and introducing a minimalist memory mechanism (fixed-budget image sampling + text subtask caching), significantly surpassing SOTA baselines and expert ensembles on academic benchmarks, offline planning, and real-robot tasks.

## What It Changes

What this work truly changes is the default assumption about "how embodied agent capabilities are organized." Previously, navigation, grounding, and reasoning each operated in silos, with dedicated models and benchmarks for each capability. Deployment meant either stacking multiple models (high compute overhead, cascading errors) or hoping a single VLM would happen to perform well on a given task. Vesta demonstrates through data mixing and unified training that a single 8B model can simultaneously match or exceed expert-level performance across all embodied cognition tasks—and this unification is not merely "capability stacking" but produces positive transfer: the unified model outperforms a pure navigation expert by 1.4 SR on navigation and a pure embodied expert by 3.9 average points on embodied cognition. This directly challenges the industry convention that "specialized models are necessarily superior to generalist models."

Another change concerns the design philosophy of memory mechanisms. Existing methods (MemER, MEM) pursue smarter memory—learned retrievers, scene representations, event trackers. Vesta goes against the grain, using fixed-budget recent-frame sampling plus text subtask logs, achieving a 38.3% success rate improvement over an actor-only baseline on real robots. This shows that under a planner-actor hierarchical architecture, the "modality composition" of memory matters more than the "retrieval strategy"—image+text hybrid memory outperforms any single modality, while uniform sampling and recency-biased sampling are nearly indistinguishable. This serves as a sobering reminder for teams over-engineering memory mechanisms.

## Method Breakdown

### Overall Architecture
- Base model: Qwen3-VL-8B, full-parameter fine-tuning (vision tower + projector + language backbone), pure bf16.
- Training: 1 epoch, lr 1e-5, cosine schedule, weight decay 0.01, batch size 256, 128 H100 GPUs, FSDP full sharding, FlashAttention-2, sequence packing, truncation length 8192, max video frames 32.
- All structured outputs (points, boxes) are decoded as text tokens through the language head, sharing the same decoder head as free-form answers—a key design for the unified interface.

### Data Mixture (Six SFT Categories)
| Data Category | Proportion |
|---|---|
| Spatial Intelligence | 27.1% |
| Navigation | 21.8% |
| Grounding | 20.8% |
| General VLM | 16.2% |
| Embodied Reasoning | 9.8% |
| Real Robot | 4.3% |

### Grounding: Base–Tail Strategy
- Base: Objects365, COCO, LVIS (broad category coverage).
- Tail: first-person observations, manipulation-centric annotations, temporally evolving interaction sequences (adapted to partial observability and viewpoint changes).

### Navigation: R2R-Style VLN Formulation
- Episode e = (I, s₀, g); at decision point t, observe pose sₜ, first-person image oₜ, and sampled visual history Hₜ.
- Optimization objective: max_θ 𝔼[𝟙{d(s_T, g) ≤ d_succ}], d_succ = 3.0m.
- Outputs three action types: pixel target (↓ + normalized waypoint (u,v) ∈ [0,1000]²), turn sequences ({←,→}), and stop.
- Data: VLN-CE from R2R, RxR, ScaleVLN, rendered in simulation.

### Action Planning with Memory
- Non-Markovian process: aₜ = π(o_{≤t}, a_{<t}, g), with approximate state sₜ = Φ(oₜ, ℳₜ, g).
- Before each subtask, generate a four-stage CoT: Observation → Progress → Reasoning → Action; only aₜ is written to memory.
- Memory device: tuple mᵢ = ⟨i, τᵢ, oᵢ, aᵢ, g⟩; historical images are restricted to at most K frames via sampling operator 𝒮ₜ, with the first frame always retained, supporting uniform or recency-biased sampling.

### Hierarchical Execution Architecture (Real Robot)
- Planner VLM (Vesta) outputs subtasks → Actor VLA (Gr00t-N1.6) executes actions.
- Synchronous mode: planner inference is a blocking call (~1 second); the actor pauses when the goal changes or maximum staleness τ_max is exceeded.
- Asynchronous mode: planner thread runs continuously; the control loop reads cached subtasks every tick without blocking.
- Communication occurs only through shared variable z (current subtask); planner memory is invisible to the actor.

## Key Innovations

1. **Unified Planner Replaces Expert Ensembles**: Vesta achieves average scores of 68.7 and 69.9 across 11 cognition benchmarks and 5 grounding benchmarks, surpassing all single-model baselines and exceeding the oracle ensemble by >10%. This is not simple "multi-task learning" but evidence of positive transfer—the unified model outperforms a pure navigation expert by 1.4 SR and a pure embodied expert by 3.9 on embodied cognition. For engineering teams, this means no longer needing to maintain multiple models and switching logic.

2. **Effectiveness of the Minimalist Memory Device**: Fixed-budget image sampling + text subtask caching, with no learned retriever. Ablations show image+text hybrid memory (75.9 overall score) far exceeds image-only (63.1) and text-only (49.7), while uniform sampling and recency-biased sampling are nearly identical (75.9 vs 75.3). This proves that under a planner-actor architecture, memory modality composition is the primary bottleneck, and frame selection strategy is secondary—providing clear priorities for memory mechanism design.

3. **Discovery of Transition Oversampling**: Under default sampling, transition-phase data accounts for only ~25%. Increasing transition oversampling from 1× to 2× yields substantial gains in transition accuracy (58.1→68.1) and overall accuracy (73.6→75.9); increasing to 3× provides only marginal improvement and hurts execution. This is an actionable data-engineering insight: in long-horizon tasks, task-switching moments (transitions) deserve more attention than execution phases.

## Boundaries and Limitations

- **Limited real-robot evaluation scope**: Only a single platform (I2RT dual-arm YAM gripper) and three tasks; does not cover humanoid robots (whole-body motion + dual-arm coupling), mobile manipulators (navigation-manipulation switching), or dexterous hands (fine-grained subtask vocabularies).
- **Scale limitations**: All numbers are at 8B scale; the scaling behavior of embodied SFT data mixtures is far less understood than web data, and conclusions may not hold at larger scales.
- **Memory is not learned**: The memory harness is fixed (uniform/recency sampling + text logs); memory itself is not treated as a learning objective, and lifelong learning (cross-episode consolidation, forgetting, re-retrieval) is not addressed.
- **Actor assumption**: The current setup implicitly assumes the actor can faithfully execute a small set of natural language subtasks at a fixed control rate; if the actor's language-following ability is weak, planner advantages will be masked by execution errors (most failures in real-robot experiments are actor-driven).
- **What was not done**: No evaluation on other robot platforms, no large-scale real-world multi-task deployment, no comparison with other generalist models at larger scales, and no distillation or edge deployment experiments.

## Engineering Takeaways

- **Verify data mixture ratios first**: Vesta's success heavily depends on the proportions of six data categories (spatial intelligence 27.1%, navigation 21.8%, grounding 20.8%). Do not arbitrarily adjust ratios when reproducing; especially note that navigation data is indispensable—all general VLM baselines achieve SR=0.0 on R2R-CE, indicating navigation must be explicitly trained.
- **Transition oversampling is the easiest pitfall**: Under default sampling, transition data accounts for only 25%; without adjustment, long-horizon task performance drops significantly (73.6 vs 75.9). It is recommended to explicitly track transition-phase proportions in the data pipeline and set 2× oversampling.
- **Memory modality matters more than retrieval strategy**: If resources are limited, prioritize image+text hybrid memory and do not spend time tuning frame sampling strategies—uniform sampling and recency bias are nearly identical (75.9 vs 75.3).
- **Keep the hierarchical architecture's communication protocol simple**: The planner and actor communicate only through shared variable z (current subtask); planner memory is invisible to the actor. Synchronous mode suits experimental reproduction; asynchronous mode suits production deployment (prioritizing motion smoothness).
- **Watch for actor bottlenecks in real-robot evaluation**: Actor errors drive most failed episodes; always distinguish planner errors from actor errors during evaluation, or you will misjudge planner performance. It is recommended to evaluate the actor's language-following ability separately first.
- **Training configuration can be reused directly**: 1 epoch, lr 1e-5, weight decay 0.01, batch 256, 128 H100s, FSDP full sharding, FlashAttention-2, sequence packing, truncation 8192, max video frames 32—these parameters are explicitly stated in the paper and can serve as a direct starting point.

## 개요

Vesta는 Qwen3-VL-8B에서 미세 조정된 범용 임베디드 추론 모델로, 위치 파악, 내비게이션, 공간 추론 및 장기 계획을 여러 전문가 모델을 쌓는 대신 단일 플래너에 통합하는 것을 목표로 합니다. 핵심 기여는 여섯 가지 데이터 유형을 혼합한 지도 미세 조정과 극도로 간결한 메모리 장치(고정 예산 이미지 샘플링 + 텍스트 하위 작업 캐시)를 도입하여 학술 벤치마크, 오프라인 계획 및 실제 로봇 작업에서 SOTA 기준선 및 전문가 앙상블을 크게 능가한다는 점입니다.

## 무엇을 바꾸었는가

이 연구가 진정으로 바꾼 것은 "임베디드 에이전트 능력 구성 방식"의 기본 가정입니다. 과거에는 내비게이션, 위치 파악, 추론이 각각 독립적으로 존재했으며, 각 능력마다 전용 모델과 벤치마크가 있었고, 배포 시에는 여러 모델을 쌓거나(계산 오버헤드 및 캐스케이드 오류), 단일 VLM이 특정 작업에서 우연히 잘 작동하기를 기대해야 했습니다. Vesta는 데이터 혼합과 통합 훈련을 통해 8B 모델이 모든 임베디드 인지 작업에서 전문가 수준에 동시에 도달하거나 능가할 수 있음을 증명했으며, 이러한 통합은 단순한 "능력 중첩"이 아니라 긍정적 전이를 생성합니다—통합 모델은 순수 내비게이션 전문가보다 내비게이션에서 1.4 SR 높고, 순수 임베디드 전문가보다 임베디드 인지에서 3.9 평균 점수 높습니다. 이는 "전문 모델이 범용 모델보다 반드시 우월하다"는 업계 관행을 직접적으로 흔듭니다.

또 다른 변화는 메모리 메커니즘의 설계 철학입니다. 기존 방법(MemER, MEM)은 더 똑똑한 메모리—학습 기반 검색기, 장면 표현, 이벤트 추적기—를 추구했습니다. Vesta는 반대로 고정 예산의 최근 프레임 샘플링과 텍스트 하위 작업 로그를 사용했으며, 그 결과 실제 로봇에서 액터 전용 기준선보다 성공률이 38.3% 향상되었습니다. 이는 planner-actor 계층 구조에서 메모리의 "모달리티 조합"이 "검색 전략"보다 더 중요함을 시사합니다—이미지+텍스트 혼합 메모리는 어떤 단일 모달리티보다 강하며, 균일 샘플링과 최근 편향 샘플링은 거의 차이가 없습니다. 이는 메모리 메커니즘에 과도하게 엔지니어링하는 팀에게 분명한 경고입니다.

## 방법 분석

### 전체 아키텍처
- 기본 모델: Qwen3-VL-8B, 전체 파라미터 미세 조정(비전 타워 + 프로젝터 + 언어 백본), 순수 bf16.
- 훈련: 1 epoch, lr 1e-5, cosine 스케줄, weight decay 0.01, batch size 256, 128대 H100, FSDP 전체 샤딩, FlashAttention-2, 시퀀스 패킹, 최대 길이 8192, 최대 비디오 프레임 32.
- 모든 구조화된 출력(점, 박스)은 언어 헤드를 통해 텍스트 토큰으로 디코딩되며, 자유 형식 답변과 디코더 헤드를 공유합니다—이는 통합 인터페이스의 핵심 설계입니다.

### 데이터 혼합(SFT 6가지 유형)
| 데이터 유형 | 비율 |
|---|---|
| 공간 지능 | 27.1% |
| 내비게이션 | 21.8% |
| 위치 파악 | 20.8% |
| 일반 VLM | 16.2% |
| 임베디드 추론 | 9.8% |
| 실제 로봇 | 4.3% |

### 위치 파악: base–tail 전략
- Base: Objects365, COCO, LVIS(광범위한 카테고리 커버리지).
- Tail: 1인칭 관찰, 조작 중심 주석, 시간적 진화 상호작용 시퀀스(부분 관측 가능성 및 시점 변화 적응).

### 내비게이션: R2R 스타일 VLN 공식화
- 에피소드 e = (I, s₀, g), 결정 시점 t에서 포즈 sₜ, 1인칭 이미지 oₜ, 샘플링된 시각적 히스토리 Hₜ 관찰.
- 최적화 목표: max_θ 𝔼[𝟙{d(s_T, g) ≤ d_succ}], d_succ = 3.0m.
- 세 가지 동작 출력: 픽셀 목표(↓ + 정규화된 웨이포인트 (u,v) ∈ [0,1000]²), 회전 시퀀스({←,→}), stop.
- 데이터: R2R, RxR, ScaleVLN의 VLN-CE, 시뮬레이션 렌더링.

### 메모리를 사용한 동작 계획
- 비마르코프 프로세스: aₜ = π(o_{≤t}, a_{<t}, g), 근사 상태 sₜ = Φ(oₜ, ℳₜ, g).
- 각 하위 작업 전에 4단계 CoT 생성: Observation → Progress → Reasoning → Action, aₜ만 메모리에 기록.
- 메모리 장치: 튜플 mᵢ = ⟨i, τᵢ, oᵢ, aᵢ, g⟩, 히스토리 이미지는 샘플링 연산자 𝒮ₜ를 통해 최대 K 프레임으로 제한, 첫 프레임은 항상 유지, 균일 또는 최근 편향 샘플링 지원.

### 계층적 실행 아키텍처(실제 로봇)
- Planner VLM(Vesta)이 하위 작업 출력 → Actor VLA(Gr00t-N1.6)이 동작 실행.
- 동기 모드: planner 추론은 블로킹 호출(약 1초), 목표 변경 또는 최대 지연 τ_max 초과 시 actor 일시 중지.
- 비동기 모드: planner 스레드가 지속적으로 실행, 제어 루프는 매 틱마다 캐시된 하위 작업을 읽고, 블로킹 없음.
- 통신은 공유 변수 z(현재 하위 작업)를 통해서만 이루어지며, planner 메모리는 actor에 보이지 않음.

## 핵심 혁신

1. **통합 플래너가 전문가 앙상블 대체**: Vesta는 11개 인지 벤치마크와 5개 위치 파악 벤치마크에서 평균 68.7 및 69.9를 달성하여 모든 단일 모델 기준선을 능가하고, oracle ensemble보다 >10% 높습니다. 이는 단순한 "멀티태스크 학습"이 아니라 긍정적 전이를 증명합니다—통합 모델은 내비게이션 SR에서 순수 내비게이션 전문가보다 1.4 높고, 임베디드 인지에서 순수 임베디드 전문가보다 3.9 높습니다. 엔지니어링 팀에게 의미하는 바: 여러 모델과 전환 로직을 유지할 필요가 없습니다.

2. **극도로 간결한 메모리 장치의 효과**: 고정 예산 이미지 샘플링 + 텍스트 하위 작업 캐시, 학습 기반 검색기 없음. 절제 실험에서 이미지+텍스트 혼합 메모리(75.9 전체 점수)가 이미지만(63.1) 및 텍스트만(49.7)을 크게 능가하며, 균일 샘플링과 최근 편향 샘플링은 거의 차이가 없습니다(75.9 vs 75.3). 이는 planner-actor 아키텍처에서 메모리의 모달리티 조합이 주요 병목이며, 프레임 선택 전략은 부차적 문제임을 증명합니다—메모리 메커니즘 설계에 명확한 우선순위를 제공합니다.

3. **전환 오버샘플링(transition oversampling) 발견**: 기본 샘플링에서 전환 단계 데이터는 약 25%만 차지하며, 전환 샘플링을 1×에서 2×로 증가시키면 전환 정확도가 크게 향상되고(58.1→68.1) 전체 정확도가 향상됩니다(73.6→75.9). 3×로 증가하면 미미한 개선만 있고 실행을 손상시킵니다. 이는 실행 가능한 데이터 엔지니어링 통찰력입니다: 장기 작업에서 작업 전환 순간(전환)이 실행 단계보다 더 주목할 가치가 있습니다.

## 경계 및 한계

- **실제 로봇 평가 범위 제한**: 단일 플랫폼(I2RT 양팔 YAM 그리퍼) 및 세 가지 작업만, 휴머노이드 로봇(전신 운동 + 양팔 결합), 이동 조작기(내비게이션과 조작 전환), 정교한 손(세밀한 하위 작업 어휘)은 포함하지 않음.
- **규모 한계**: 모든 수치는 8B 규모이며, 임베디드 SFT 혼합 데이터의 스케일링 동작은 웹 데이터만큼 충분히 이해되지 않아 더 큰 규모에서 결론이 유지되지 않을 수 있음.
- **메모리 미학습**: 메모리 하네스는 고정(균일/최근 샘플링 + 텍스트 로그)되어 있으며, 메모리 자체를 학습 대상으로 삼지 않았고, 평생 학습(에피소드 간 통합, 망각, 재검색)을 다루지 않음.
- **actor 가정**: 현재 설정은 actor가 고정 제어율로 작은 자연어 하위 작업 세트를 충실히 실행할 수 있다고 암묵적으로 가정하며, actor의 언어 추종 능력이 약하면 플래너의 이점이 실행 오류에 가려질 수 있음(실제 로봇 실험에서 대부분의 실패는 액터에 의해 유발).
- **수행하지 않은 것**: 다른 로봇 플랫폼 평가, 대규모 실제 세계 멀티태스크 배포, 더 큰 규모에서 다른 일반 모델과의 비교, 증류 및 엣지 배포 실험.

## 엔지니어링 시사점

- **데이터 혼합 비율 먼저 확인**: Vesta의 성공은 여섯 가지 데이터 유형의 비율(공간 지능 27.1%, 내비게이션 21.8%, 위치 파악 20.8%)에 크게 의존합니다. 재현 시 비율을 임의로 조정하지 마세요. 특히 내비게이션 데이터가 없으면 안 됩니다—모든 일반 VLM 기준선이 R2R-CE에서 SR=0.0으로, 내비게이션 능력은 명시적 훈련이 필요함을 시사합니다.
- **가장 쉽게 함정에 빠지는 부분은 전환 샘플링**: 기본 샘플링에서 전환 데이터는 25%만 차지하며, 조정하지 않으면 장기 작업 성능이 크게 저하됩니다(73.6 vs 75.9). 데이터 파이프라인에서 전환 단계 비율을 명시적으로 통계화하고 2× 오버샘플링을 설정하는 것이 좋습니다.
- **메모리 모달리티가 검색 전략보다 중요**: 리소스가 제한된 경우 이미지+텍스트 혼합 메모리를 우선 보장하고, 프레임 샘플링 전략을 조정하는 데 시간을 쓰지 마세요—균일 샘플링과 최근 편향은 거의 차이가 없습니다(75.9 vs 75.3).
- **계층 아키텍처의 통신 프로토콜은 단순해야 함**: 플래너와 액터는 공유 변수 z(현재 하위 작업)를 통해서만 통신하며, 플래너 메모리는 액터에 보이지 않습니다. 동기 모드는 실험 재현에 적합하고, 비동기 모드는 프로덕션 배포(운동 평활성 우선)에 적합합니다.
- **실제 로봇 평가 시 액터 병목 주의**: 액터 오류가 대부분의 실패 에피소드를 유발하므로, 평가 시 플래너 오류와 액터 오류를 반드시 구분해야 합니다. 그렇지 않으면 플래너 성능을 잘못 판단할 수 있습니다. 먼저 actor의 언어 추종 능력을 별도로 평가하는 것이 좋습니다.
- **훈련 구성은 직접 재사용 가능**: 1 epoch, lr 1e-5, weight decay 0.01, batch 256, 128 H100, FSDP 전체 샤딩, FlashAttention-2, 시퀀스 패킹, 최대 길이 8192, 최대 비디오 프레임 32—이러한 매개변수는 논문에 명확히 제시되어 있으며 시작점으로 직접 사용할 수 있습니다.
