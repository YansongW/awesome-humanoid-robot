## 概述
针对多步骤双臂移动操作中数据采集成本高昂的难题，MoMaGen 提出了一种自动化数据生成框架。该框架将机器人基座放置与摄像头视角规划分别建模为可达性硬约束与可见性软约束，通过约束优化方法在仿真中合成大规模多样化演示数据。实验表明，该方法在四个复杂任务上生成的数据集多样性显著优于先前工作，且基于此训练的模仿学习策略仅需 40 个真实演示即可成功迁移至真实硬件。

## 核心内容
### 背景与挑战
- 传统模仿学习依赖大规模人类演示数据，但多步骤双臂移动操作需同时遥操作移动基座与两个高自由度机械臂，数据采集成本极高。
- 先前 X-Gen 系列工作虽能通过仿真增强静态双臂操作数据，但无法解决移动基座带来的**可达性**（基座位置对后续操作的影响）与主动摄像头带来的**可见性**（导航时视角对策略训练的影响）问题。

### 方法：约束优化框架
- **硬约束**：将机器人基座放置问题建模为可达性约束，确保机械臂能完成目标操作。
- **软约束**：将导航过程中的摄像头视角规划建模为可见性约束，平衡任务执行与数据采集质量。
- 该公式化方法可泛化至多数现有自动化数据生成方法，为后续研究提供理论基础。

### 实验设置与结果
- **任务**：在四个多步骤双臂移动操作任务上评估（如开门取物、协作搬运）。
- **数据多样性**：MoMaGen 生成的数据集在场景配置、物体位置、基座轨迹等维度上多样性显著优于 X-Gen 等基线方法。
- **策略训练**：
  - 仅需**单个人类演示**作为种子，即可训练出成功的模仿学习策略。
  - 使用**40 个真实世界演示**微调后，策略可直接部署于真实机器人硬件。
- **关键数字**：相比基线方法，数据多样性提升幅度未明确量化，但消融实验证实硬/软约束的联合优化是性能提升的核心。

### 结论
MoMaGen 通过约束优化框架解决了移动操作数据生成的独特挑战，为低样本模仿学习提供了可扩展的解决方案。项目页面：momagen.github.io

## Overview
Imitation learning from large-scale, diverse human demonstrations has been shown to be effective for training robots, but collecting such data is costly and time-consuming. This challenge intensifies for multi-step bimanual mobile manipulation, where humans must teleoperate both the mobile base and two high-DoF arms. Prior X-Gen works have developed automated data generation frameworks for static (bimanual) manipulation tasks, augmenting a few human demos in simulation with novel scene configurations to synthesize large-scale datasets. However, prior works fall short for bimanual mobile manipulation tasks for two major reasons: 1) a mobile base introduces the problem of how to place the robot base to enable downstream manipulation (reachability) and 2) an active camera introduces the problem of how to position the camera to generate data for a visuomotor policy (visibility). To address these challenges, MoMaGen formulates data generation as a constrained optimization problem that satisfies hard constraints (e.g., reachability) while balancing soft constraints (e.g., visibility while navigation). This formulation generalizes across most existing automated data generation approaches and offers a principled foundation for developing future methods. We evaluate on four multi-step bimanual mobile manipulation tasks and find that MoMaGen enables the generation of much more diverse datasets than previous methods. As a result of the dataset diversity, we also show that the data generated by MoMaGen can be used to train successful imitation learning policies using a single source demo. Furthermore, the trained policy can be fine-tuned with a very small amount of real-world data (40 demos) to be succesfully deployed on real robotic hardware. More details are on our project page: momagen.github.io.

## 개요
다단계 양팔 이동 조작에서 데이터 수집 비용이 높다는 난제를 해결하기 위해, MoMaGen은 자동화된 데이터 생성 프레임워크를 제안한다. 이 프레임워크는 로봇 베이스 배치와 카메라 시점 계획을 각각 도달 가능성 하드 제약 조건과 가시성 소프트 제약 조건으로 모델링하고, 제약 최적화 방법을 통해 시뮬레이션에서 대규모의 다양한 시연 데이터를 합성한다. 실험 결과, 이 방법은 네 가지 복잡한 작업에서 생성된 데이터셋의 다양성이 이전 연구보다 현저히 우수하며, 이를 기반으로 훈련된 모방 학습 정책은 단 40개의 실제 시연만으로 실제 하드웨어에 성공적으로 전이할 수 있음을 보여준다.

## 핵심 내용
### 배경 및 과제
- 전통적인 모방 학습은 대규모 인간 시연 데이터에 의존하지만, 다단계 양팔 이동 조작은 이동 베이스와 두 개의 고자유도 로봇 팔을 동시에 원격 조작해야 하므로 데이터 수집 비용이 매우 높다.
- 이전 X-Gen 시리즈 연구는 시뮬레이션을 통해 정적 양팔 조작 데이터를 강화할 수 있었지만, 이동 베이스로 인한 **도달 가능성**(베이스 위치가 후속 조작에 미치는 영향)과 능동 카메라로 인한 **가시성**(내비게이션 중 시점이 정책 훈련에 미치는 영향) 문제는 해결하지 못했다.

### 방법: 제약 최적화 프레임워크
- **하드 제약 조건**: 로봇 베이스 배치 문제를 도달 가능성 제약 조건으로 모델링하여 로봇 팔이 목표 조작을 완료할 수 있도록 보장한다.
- **소프트 제약 조건**: 내비게이션 과정에서 카메라 시점 계획을 가시성 제약 조건으로 모델링하여 작업 실행과 데이터 수집 품질 간의 균형을 맞춘다.
- 이 공식화 방법은 대부분의 기존 자동화 데이터 생성 방법에 일반화될 수 있으며, 후속 연구에 이론적 기반을 제공한다.

### 실험 설정 및 결과
- **작업**: 네 가지 다단계 양팔 이동 조작 작업에서 평가(예: 문 열고 물건 집기, 협동 운반).
- **데이터 다양성**: MoMaGen이 생성한 데이터셋은 장면 구성, 객체 위치, 베이스 궤적 등의 차원에서 X-Gen 등 기준 방법보다 다양성이 현저히 우수하다.
- **정책 훈련**:
  - **단일 인간 시연**만 시드로 사용하여 성공적인 모방 학습 정책을 훈련할 수 있다.
  - **40개의 실제 세계 시연**으로 미세 조정한 후, 정책을 실제 로봇 하드웨어에 직접 배포할 수 있다.
- **핵심 수치**: 기준 방법 대비 데이터 다양성 향상 폭은 명확히 정량화되지 않았지만, 소거 실험을 통해 하드/소프트 제약 조건의 공동 최적화가 성능 향상의 핵심임을 확인했다.

### 결론
MoMaGen은 제약 최적화 프레임워크를 통해 이동 조작 데이터 생성의 고유한 과제를 해결하며, 저표본 모방 학습을 위한 확장 가능한 솔루션을 제공한다. 프로젝트 페이지: momagen.github.io
