## 概述

本文提出 VLN↻BERT，一种将循环机制直接嵌入 Vision-and-Language BERT 架构的导航模型，使预训练 V&L BERT 本身成为导航策略网络，无需外部循环模块（如 LSTM）或下游决策网络。作者通过在 BERT 内部引入自回归状态 token 和跨模态注意力匹配，在 R2R 和 REVERIE 两个基准上取得当时 SoTA 结果，并系统验证了仅在初始化时对语言做自注意力的计算效率优势。

## 它改变了什么

这项工作的核心改变在于：它把 V&L BERT 从"语言编码器"或"指令-路径匹配器"的角色，直接提升为"导航决策器"本身。此前 PREVALENT 等模型虽然利用了预训练 V&L BERT，但只是将其作为特征提取器，真正的决策仍由下游的 EnvDrop 等网络完成。VLN↻BERT 证明了 BERT 的 Transformer 架构可以通过内部循环状态天然适配 POMDP 问题，这改变了"BERT 不适合序列决策"的普遍认知。

另一个关键改变是对语言自注意力的处理策略。作者通过实验证明，在每一步对语言重新做自注意力（Re-Attn）会导致严重的性能退化（SR 从 58.71% 降至 37.76%），因为每步输出的语言特征会过度聚焦当前视点相关的线索，抑制了指令其他部分对未来决策的价值。这一发现挑战了"更多注意力=更好性能"的直觉，为 V&L 模型在长序列决策任务中的计算分配提供了新的设计原则。

## 方法拆解

### 核心架构：循环状态 token
- 初始化（t=0）：将 `[CLS]`、指令 token、`[SEP]` 输入模型，取 `[CLS]` 输出作为初始状态 s₀
- 导航步（t>0）：语言 token 仅作为 Transformer 的 keys/values（类似 LXMERT 跨模态编码器），不参与查询计算，大幅节省计算
- 状态 sₜ 作为引导 token 与视觉 token 拼接输入，通过跨模态自注意力更新内容，并以自回归方式成为下一步输入

### 状态细化（Eq. 9-12）
- 在最后一层（l=12），计算状态与文本/视觉 token 的注意力分数
- 跨 K=12 个注意力头平均并 Softmax 得到权重
- 加权求和原始特征，通过元素级乘积进行跨模态匹配
- REVERIE 中仅使用视觉特征（因指令是高层级的，逐步匹配价值低）

### 决策制定
- 动作概率直接取最后一层所有注意力头对视觉 token 的平均注意力权重：pₜᵃ = Ãₗ^{s,v}
- 停止通过向可导航方向列表添加零向量 vₜ^stop 实现，模型预测最大注意力分数时停止
- REVERIE 中，当对象 token 的注意力分数超过所有场景 token 时停止并选择分数最大的对象

### 训练目标
- 混合 A2C 强化学习和模仿学习：ℒ = -Σₜ aₜˢ log(pₜᵃ) Aₜ - λ Σₜ aₜ* log(pₜᵃ)
- 奖励塑形：进度奖励（接近 +1.0/远离 -1.0）+ nDTW 路径保真奖励 + 负停止奖励（首次接近目标后又离开时触发）
- 从 OSCAR 或 PREVALENT 初始化，适应 PREVALENT 时移除跨模态编码器中的语言分支

## 关键创新

1. **循环机制内嵌于 BERT 架构**：无需显式记忆缓冲区或外部 LSTM，仅通过状态 token 的自回归传递实现历史依赖建模。这是首次让 V&L BERT 本身具备处理 POMDP 的能力，而非依赖外部循环模块。

2. **语言自注意力的"初始化一次"策略**：通过实验证明每步重新自注意力会导致性能显著退化（Re-Attn 的 SR 比 Ours 低 20.95%），而仅在初始化时编码语言、后续仅作为 keys/values 参与计算，既保持性能又大幅降低内存（batch size 16 时仅 9.2GB vs 其他方法 batch size 6 时 11.0GB）。

3. **注意力权重直接作为动作概率**：将最后一层 Transformer 对视觉 token 的平均注意力权重直接映射为动作分布，消除了传统 Actor 网络的需求。这一设计使 BERT 的注意力机制同时承担特征融合和策略输出的双重角色，简化了架构并提升了可解释性。

## 边界与局限

- 论文未明确讨论局限性，但可从实验推断：模型在 REVERIE 的 RGS 指标上仍远低于人类（16.50% vs 77.84%），物体接地能力是明显短板
- 未在连续环境（VLN-CE）或多语言导航（RxR）上验证，作者仅提及这些数据集存在但未实验
- 未使用大规模数据集预训练，依赖 OSCAR/PREVALENT 的初始化质量；从随机初始化训练需要 600,000 次迭代约 7 天，收敛速度依赖预训练
- 梯度累积实验显示，若在每步做语言自注意力（Emb-Attn），在更大有效 batch size 下 Unseen SR 可达 61.00%，超过 Ours 的 58.71%，说明计算资源充足时"初始化一次"策略未必最优
- 训练时间较长：init. OSCAR 需 7 天完成 600K 迭代，即使 init. PREVALENT 也需 4.5 天

## 工程启示

复现时优先核对三点：**语言自注意力的时机**（仅在 t=0 编码，后续作为 keys/values）、**状态 token 的自回归传递**（sₜ 作为下一步引导 token）、**注意力权重到动作概率的映射**（最后一层平均注意力，无需额外 Actor 网络）。最容易踩坑的是 Re-Attn 陷阱——若在每步对语言重新自注意力，SR 会暴跌约 20%，这不是调参能救回来的。

工程上注意：单张 2080Ti 可跑 batch size 16（9.2GB 内存），但训练仍需数天；建议从 PREVALENT 初始化（1 天达到最佳），而非 OSCAR（3.5 天）。REVERIE 中物体特征需拼接位置投影（Wᵖ ∈ ℝ⁵ˣ¹²⁸）和方向编码，维度为 2048+128+128=2304。奖励塑形（nDTW + 负停止奖励）仅带来约 1% 的 SPL 提升，若时间紧张可先不加，优先保证循环 BERT 结构正确。

## Overview

This paper proposes VLN↻BERT, a navigation model that embeds a recurrent mechanism directly into the Vision-and-Language BERT architecture, enabling the pretrained V&L BERT itself to serve as the navigation policy network without requiring external recurrent modules (such as LSTM) or downstream decision networks. By introducing autoregressive state tokens and cross-modal attention matching within BERT, the authors achieve state-of-the-art results on the R2R and REVERIE benchmarks at the time, and systematically validate the computational efficiency advantage of applying self-attention to language only at initialization.

## What It Changes

The core change of this work is that it elevates V&L BERT from the role of "language encoder" or "instruction-path matcher" directly to the "navigation decision-maker" itself. Previous models such as PREVALENT, although leveraging pretrained V&L BERT, only used it as a feature extractor, with the actual decision-making still handled by downstream networks like EnvDrop. VLN↻BERT demonstrates that BERT's Transformer architecture can naturally adapt to POMDP problems through internal recurrent states, challenging the common perception that "BERT is unsuitable for sequential decision-making."

Another key change is the processing strategy for language self-attention. Through experiments, the authors prove that re-applying self-attention to language at every step (Re-Attn) leads to severe performance degradation (SR drops from 58.71% to 37.76%), because the language features output at each step over-focus on cues relevant to the current viewpoint, suppressing the value of other parts of the instruction for future decisions. This finding challenges the intuition that "more attention equals better performance" and provides new design principles for computational allocation in long-horizon sequential decision tasks for V&L models.

## Method Breakdown

### Core Architecture: Recurrent State Token
- Initialization (t=0): Input `[CLS]`, instruction tokens, and `[SEP]` into the model, and use the `[CLS]` output as the initial state s₀
- Navigation step (t>0): Language tokens serve only as keys/values for the Transformer (similar to LXMERT's cross-modal encoder), not participating in query computation, significantly saving computation
- State sₜ is concatenated with visual tokens as a guiding token, updated through cross-modal self-attention, and fed autoregressively as input for the next step

### State Refinement (Eq. 9-12)
- At the last layer (l=12), compute attention scores between the state and text/visual tokens
- Average across K=12 attention heads and apply Softmax to obtain weights
- Weighted sum of original features, performing cross-modal matching via element-wise product
- In REVERIE, only visual features are used (since instructions are high-level, step-by-step matching has low value)

### Decision Making
- Action probabilities are directly taken as the average attention weights across all attention heads at the last layer over visual tokens: pₜᵃ = Ãₗ^{s,v}
- Stopping is implemented by adding a zero vector vₜ^stop to the list of navigable directions; the model stops when predicting the maximum attention score
- In REVERIE, the model stops when the attention score of an object token exceeds all scene tokens, and selects the object with the highest score

### Training Objective
- Hybrid A2C reinforcement learning and imitation learning: ℒ = -Σₜ aₜˢ log(pₜᵃ) Aₜ - λ Σₜ aₜ* log(pₜᵃ)
- Reward shaping: progress reward (close to +1.0 / move away -1.0) + nDTW path fidelity reward + negative stop reward (triggered when first approaching the goal and then leaving)
- Initialized from OSCAR or PREVALENT; when adapting PREVALENT, the language branch in the cross-modal encoder is removed

## Key Innovations

1. **Recurrent mechanism embedded within the BERT architecture**: No explicit memory buffer or external LSTM is needed; historical dependency modeling is achieved solely through the autoregressive passing of state tokens. This is the first time V&L BERT itself possesses the capability to handle POMDPs, rather than relying on external recurrent modules.

2. **"Initialize once" strategy for language self-attention**: Experiments prove that re-applying self-attention at every step causes significant performance degradation (Re-Attn's SR is 20.95% lower than Ours), while encoding language only at initialization and subsequently using it only as keys/values maintains performance while greatly reducing memory (9.2GB at batch size 16 vs. 11.0GB for other methods at batch size 6).

3. **Attention weights directly as action probabilities**: The average attention weights of the last-layer Transformer over visual tokens are directly mapped to the action distribution, eliminating the need for a traditional Actor network. This design allows BERT's attention mechanism to simultaneously serve the dual roles of feature fusion and policy output, simplifying the architecture and enhancing interpretability.

## Boundaries and Limitations

- The paper does not explicitly discuss limitations, but they can be inferred from experiments: the model's RGS metric on REVERIE remains far below human performance (16.50% vs 77.84%), indicating that object grounding is a clear weakness
- No validation on continuous environments (VLN-CE) or multilingual navigation (RxR); the authors only mention these datasets exist but do not experiment on them
- No large-scale dataset pretraining; relies on the initialization quality of OSCAR/PREVALENT; training from random initialization requires 600,000 iterations (~7 days), with convergence speed dependent on pretraining
- Gradient accumulation experiments show that if language self-attention is performed at every step (Emb-Attn), with a larger effective batch size, Unseen SR can reach 61.00%, surpassing Ours at 58.71%, indicating that the "initialize once" strategy may not be optimal when computational resources are abundant
- Training time is relatively long: init. OSCAR requires 7 days for 600K iterations, and even init. PREVALENT requires 4.5 days

## Engineering Insights

When reproducing, prioritize verifying three points: **the timing of language self-attention** (encoded only at t=0, subsequently used as keys/values), **the autoregressive passing of the state token** (sₜ as the guiding token for the next step), and **the mapping from attention weights to action probabilities** (average attention at the last layer, no additional Actor network needed). The most common pitfall is the Re-Attn trap—if language self-attention is re-applied at every step, SR drops by approximately 20%, which cannot be recovered through hyperparameter tuning.

From an engineering perspective: a single 2080Ti can run batch size 16 (9.2GB memory), but training still takes several days; it is recommended to initialize from PREVALENT (reaching optimal performance in 1 day) rather than OSCAR (3.5 days). In REVERIE, object features need to be concatenated with position projection (Wᵖ ∈ ℝ⁵ˣ¹²⁸) and direction encoding, with a dimension of 2048+128+128=2304. Reward shaping (nDTW + negative stop reward) only brings approximately 1% improvement in SPL; if time is constrained, it can be omitted initially, prioritizing the correctness of the recurrent BERT structure.

## 개요

본 논문은 VLN↻BERT를 제안하며, 순환 메커니즘을 Vision-and-Language BERT 아키텍처에 직접 내장한 내비게이션 모델로, 사전 훈련된 V&L BERT 자체가 내비게이션 정책 네트워크가 되도록 하여 외부 순환 모듈(예: LSTM)이나 하위 결정 네트워크가 필요 없게 한다. 저자는 BERT 내부에 자기회귀 상태 토큰과 교차 양식 주의 매칭을 도입하여 R2R 및 REVERIVE 두 벤치마크에서 당시 최고 수준(SoTA) 결과를 달성했으며, 언어에 대한 자기 주의를 초기화 시에만 수행하는 계산 효율성 이점을 체계적으로 검증했다.

## 무엇을 바꾸었는가

이 작업의 핵심 변화는 V&L BERT를 "언어 인코더" 또는 "명령-경로 매칭기" 역할에서 "내비게이션 결정기" 자체로 승격시킨 것이다. 이전의 PREVALENT와 같은 모델은 사전 훈련된 V&L BERT를 활용했지만 단지 특징 추출기로만 사용했으며, 실제 결정은 여전히 하위의 EnvDrop과 같은 네트워크가 수행했다. VLN↻BERT는 BERT의 Transformer 아키텍처가 내부 순환 상태를 통해 POMDP 문제에 자연스럽게 적응할 수 있음을 증명했으며, 이는 "BERT는 순차적 결정에 적합하지 않다"는 일반적인 인식을 바꾸었다.

또 다른 핵심 변화는 언어 자기 주의 처리 전략이다. 저자는 실험을 통해 각 단계에서 언어에 대해 자기 주의를 다시 수행(Re-Attn)하면 심각한 성능 저하(SR이 58.71%에서 37.76%로 하락)가 발생함을 증명했는데, 이는 각 단계에서 출력되는 언어 특징이 현재 시점과 관련된 단서에 과도하게 집중하여 명령의 다른 부분이 미래 결정에 기여하는 가치를 억제하기 때문이다. 이 발견은 "더 많은 주의 = 더 나은 성능"이라는 직관에 도전하며, 장기 시퀀스 결정 작업에서 V&L 모델의 계산 할당에 대한 새로운 설계 원칙을 제공한다.

## 방법 분석

### 핵심 아키텍처: 순환 상태 토큰
- 초기화(t=0): `[CLS]`, 명령 토큰, `[SEP]`를 모델에 입력하고 `[CLS]` 출력을 초기 상태 s₀로 사용
- 내비게이션 단계(t>0): 언어 토큰은 Transformer의 keys/values로만 사용되며(LXMERT 교차 양식 인코더와 유사), 쿼리 계산에는 참여하지 않아 계산을 크게 절약
- 상태 sₜ는 안내 토큰으로 시각 토큰과 함께 입력되며, 교차 양식 자기 주의를 통해 내용이 업데이트되고 자기회귀 방식으로 다음 단계의 입력이 됨

### 상태 정제(Eq. 9-12)
- 마지막 레이어(l=12)에서 상태와 텍스트/시각 토큰 간의 주의 점수를 계산
- K=12개의 주의 헤드에 걸쳐 평균을 내고 Softmax로 가중치를 얻음
- 가중 합산된 원본 특징을 요소별 곱으로 교차 양식 매칭 수행
- REVERIE에서는 명령이 높은 수준이므로 단계별 매칭 가치가 낮아 시각 특징만 사용

### 결정 수립
- 행동 확률은 마지막 레이어의 모든 주의 헤드가 시각 토큰에 대해 갖는 평균 주의 가중치를 직접 사용: pₜᵃ = Ãₗ^{s,v}
- 정지는 이동 가능한 방향 목록에 제로 벡터 vₜ^stop을 추가하여 구현되며, 모델이 최대 주의 점수를 예측할 때 정지
- REVERIE에서는 객체 토큰의 주의 점수가 모든 장면 토큰을 초과할 때 정지하고 점수가 가장 큰 객체를 선택

### 훈련 목표
- A2C 강화 학습과 모방 학습의 혼합: ℒ = -Σₜ aₜˢ log(pₜᵃ) Aₜ - λ Σₜ aₜ* log(pₜᵃ)
- 보상 형태: 진행 보상(접근 +1.0/이탈 -1.0) + nDTW 경로 충실도 보상 + 음의 정지 보상(목표에 처음 접근한 후 다시 이탈할 때 트리거)
- OSCAR 또는 PREVALENT에서 초기화하며, PREVALENT에 적응할 때 교차 양식 인코더의 언어 분기를 제거

## 핵심 혁신

1. **BERT 아키텍처에 내장된 순환 메커니즘**: 명시적 메모리 버퍼나 외부 LSTM 없이 상태 토큰의 자기회귀 전달만으로 이력 의존성을 모델링한다. 이는 V&L BERT 자체가 외부 순환 모듈에 의존하지 않고 POMDP를 처리할 수 있게 한 최초의 사례다.

2. **언어 자기 주의의 "초기화 일회" 전략**: 실험을 통해 각 단계에서 자기 주의를 다시 수행하면 성능이 크게 저하되고(Re-Attn의 SR은 Ours보다 20.95% 낮음), 초기화 시에만 언어를 인코딩하고 이후에는 keys/values로만 참여하는 방식이 성능을 유지하면서 메모리를 크게 절약함(batch size 16에서 9.2GB vs 다른 방법 batch size 6에서 11.0GB)을 증명했다.

3. **주의 가중치를 행동 확률로 직접 사용**: 마지막 레이어 Transformer가 시각 토큰에 대해 갖는 평균 주의 가중치를 행동 분포에 직접 매핑하여 전통적인 Actor 네트워크의 필요성을 제거했다. 이 설계는 BERT의 주의 메커니즘이 특징 융합과 정책 출력의 이중 역할을 동시에 수행하게 하여 아키텍처를 단순화하고 해석 가능성을 높였다.

### 소거 실험 핵심 발견
- 사전 훈련된 BERT로 언어만 인코딩(Model #1)하면 오히려 Baseline보다 나쁨(Unseen SR 44.15% vs 49.81%), 미세 조정이 필수
- 시각 토큰 추가(Model #3)는 심각한 저하(SR 30.74%), 단순 연결만으로는 부족하며 상태 및 결정 메커니즘이 필요함을 시사

## 경계 및 한계

- 논문은 한계를 명시적으로 논의하지 않았지만 실험에서 추론할 수 있다: 모델은 REVERIE의 RGS 지표에서 여전히 인간보다 훨씬 낮으며(16.50% vs 77.84%), 객체 접지 능력이 명백한 약점이다.
- 연속 환경(VLN-CE)이나 다국어 내비게이션(RxR)에서는 검증되지 않았으며, 저자는 이러한 데이터셋이 존재함을 언급만 하고 실험하지 않았다.
- 대규모 데이터셋 사전 훈련을 사용하지 않았으며 OSCAR/PREVALENT의 초기화 품질에 의존한다. 무작위 초기화에서 훈련하려면 약 600,000회 반복으로 약 7일이 걸리며, 수렴 속도는 사전 훈련에 의존한다.
- 그래디언트 누적 실험에 따르면 각 단계에서 언어 자기 주의(Emb-Attn)를 수행하면 더 큰 유효 batch size에서 Unseen SR이 61.00%에 도달하여 Ours의 58.71%를 초과하므로, 계산 자원이 충분할 때 "초기화 일회" 전략이 항상 최적은 아님을 시사한다.
- 훈련 시간이 길다: init. OSCAR는 600K 반복에 7일이 필요하며, init. PREVALENT도 4.5일이 필요하다.

## 공학적 시사점

재현 시 다음 세 가지를 우선 확인하라: **언어 자기 주의의 시점**(t=0에서만 인코딩하고 이후에는 keys/values로 사용), **상태 토큰의 자기회귀 전달**(sₜ가 다음 단계의 안내 토큰), **주의 가중치에서 행동 확률로의 매핑**(마지막 레이어 평균 주의, 추가 Actor 네트워크 불필요). 가장 쉽게 빠지는 함정은 Re-Attn 함정이다—각 단계에서 언어에 대해 자기 주의를 다시 수행하면 SR이 약 20% 급락하며, 이는 하이퍼파라미터 조정으로 해결할 수 없다.

공학적 측면에서 주의: 단일 2080Ti로 batch size 16(9.2GB 메모리)을 실행할 수 있지만 훈련에는 여전히 며칠이 걸린다. OSCAR(3.5일)보다 PREVALENT에서 초기화(1일 만에 최적 도달)를 권장한다. REVERIE에서 객체 특징은 위치 투영(Wᵖ ∈ ℝ⁵ˣ¹²⁸)과 방향 인코딩을 연결해야 하며, 차원은 2048+128+128=2304이다. 보상 형태(nDTW + 음의 정지 보상)는 SPL을 약 1%만 향상시키므로 시간이 부족하면 먼저 추가하지 않고 순환 BERT 구조의 정확성을 우선 보장하라.
