## 概述

Mask2Real-WM 提出将灵巧操作世界模型分解为分割空间动力学模型（WM1）与外观渲染模型（WM2）的两阶段架构，利用分割掩码作为 sim-to-real 桥梁，在 IsaacLab 中生成 53.7 小时合成数据预训练 WM1，再以少于 2.5 小时真实数据微调。该方法在 23-DoF 灵巧手连续拾放任务上，将动作可控性从单阶段基线的 0.6 ID 提升至 0.95 ID，并显著改善未见物体泛化与预测锐度。

## 它改变了什么

灵巧操作世界模型的根本难点在于动作空间高维（23 DoF）与真实数据稀缺的冲突。现有动作条件视频生成方法（如 Ctrl-World）针对低自由度平行夹爪设计，直接扩展到灵巧手时，RGB 空间的 sim-to-real 差距导致预测模糊、接触区域失真，且分布偏移下性能急剧退化。作者意识到问题不在渲染能力，而在动力学预测——单阶段模型被迫同时学习几何运动与外观变化，两者耦合使得仿真预训练收益甚微。

Mask2Real-WM 真正改变的是将“预测什么”与“如何呈现”解耦。通过分割掩码作为中间表示，动力学模型只需学习手与物体的几何运动，完全规避光照、纹理、背景等外观因素，使大规模仿真预训练成为可能。这一设计选择将世界模型构建从“需要照片级真实仿真”的困境中解放出来，转而要求仿真仅具备几何与运动学保真度，大幅降低了合成数据生成的工程成本。

## 方法拆解

### 两阶段概率分解
联合分布分解为 `p(m_{t+1:t+H} | m_{t-k:t}, a_{t-k:t+H}) × p(I_{t+1:t+H} | I_{t-k:t}, m_{t-k:t+H}, a_{t-k:t+H})`，分别由 WM1 与 WM2 建模。WM1 在分割空间操作，WM2 以 WM1 预测掩码为条件渲染 RGB。

### WM1：动力学模型
- 从 SVD 初始化，采用 Ctrl-World 的多视图、动作条件公式
- 过去分割 VAE 潜变量与噪声未来潜变量沿时间维拼接，形状 `(B, k+H, C, V·H/f, W/f)`，其中 `f=8` 为 VAE 空间压缩因子，两视图沿高度维堆叠
- 6-DoF 末端执行器位姿与 17 个手部关节角分别经独立 MLP 投影为 1024 维逐帧嵌入，求和后通过逐帧交叉注意力注入每个 SVD U-Net 块
- 仿真预训练 55000 步（lr 10⁻⁴），真实数据 LoRA 微调 45000 步（lr 5×10⁻⁶），rank 16, α=16
- 去噪目标：`L_WM1 = E_{x,ε,σ} ||x̂_θ(x_σ; m_{t-k:t}, a_{t-k:t+H}, σ) - x||₂²`

### WM2：渲染模型
- 共享 WM1 的 SVD 骨干，在 RGB 空间操作，仅在真实数据上训练 70000 步（lr 10⁻⁴）
- 三个条件信号：过去 RGB 帧（SVD VAE 编码）、分割掩码（轻量 CNN 编码器 + ControlNet 模块）、动作（双分支 MLP 交叉注意力）
- CNN 编码器在像素空间操作，三个卷积块（Conv2d + GroupNorm + SiLU），专门处理 VAE 编码器会模糊的手和物体边界
- ControlNet 通过零初始化卷积注入特征；SVD 骨干冻结，LoRA 适配（rank 16, α=16），CNN 编码器与 ControlNet 完全微调
- 掩码与动作条件 dropout 各 10%，支持推理时 classifier-free guidance

### 数据管线
- 仿真：IsaacLab 生成 13950 个 episode（53.7 小时 @ 5 fps），含 MimicGen 管道（5000 干净 + 5000 带噪）、随机运动生成器（3700）、遥操作演示（250）；PD 增益与摩擦参数经 CMA-ES 系统辨识匹配物理机器人
- 真实：218 个 episode（2.5 小时），Rokoko 手套遥操作，SAM 3 文本提示生成掩码；合成掩码额外模糊（σ=1.5 px）软化光栅化边缘

### 推理流程
SAM 3 处理 5 帧上下文窗口获取初始掩码，WM1 滚动预测未来掩码序列，WM2 渲染 RGB；长时预测时最后预测帧和掩码滑入上下文窗口，后续自回归块不再使用 SAM 3。

## 关键创新

**分割掩码作为 sim-to-real 桥梁**：这是首个将分割空间作为灵巧操作世界模型中间表示的工作。掩码空间的 sim-to-real 差距远小于 RGB，使 WM1 能在 53.7 小时合成数据上预训练而无需照片级真实感，同时现成分割器（SAM 3）提供无标签噪声的监督信号。这一设计将仿真要求从“外观保真”降为“几何与运动学保真”，显著降低合成数据生成门槛。

**两阶段分解解耦动力学与渲染**：WM1 只建模手与物体的几何运动，WM2 负责外观渲染。这种分解使错误来源可定位——作者明确所有主要失败模式都出现在 WM1 的物体状态预测，而非 WM2 渲染。更重要的是，WM2 仅需 2.5 小时真实数据即可训练，且掩码条件天然支持零样本部署（与机器人动作空间解耦），为跨平台迁移提供了新思路。

**像素空间 CNN 掩码编码器**：作者发现 SVD VAE 编码器为自然 RGB 重建训练，对平坦分类掩码会产生边界重建伪影。专用 CNN 编码器在像素空间操作，边界响应强度比 VAE 编码器高约 48%（4.41 vs 2.98），这一细节对分割条件扩散模型的实现具有直接指导意义。

## 实验与结果

### 动作可控性（3 点评分，5 个 ID + 5 个 OOD 样本）
| 配置 | ID | OOD |
|---|---|---|
| 完整模型（WM1: sim→real, WM2: real） | ≈0.95 | ≈0.87 |
| 单阶段基线（Ctrl-World） | ≈0.6 | ≈0.44 |
| 仅仿真训练 WM1 | ≈0.85 | ≈0.73 |
| 仅真实训练 WM1 | ≈0.68 | ≈0.51 |

仿真中间训练提升 0.68→0.85 ID（由表内数值计算），真实微调进一步提升至 0.95 ID。

### WM1 分割空间质量（表 1，两视图合并）
| 配置 | ID PSNR | ID LPIPS | OOD PSNR | OOD LPIPS |
|---|---|---|---|---|
| real only | 22.00 | 0.119 | 20.48 | 0.147 |
| sim only | 19.03 | 0.229 | 20.33 | 0.184 |
| sim+real | 20.72 | 0.158 | 21.74 | 0.122 |

OOD 分割质量上 sim+real 配置 PSNR 21.7 vs real-only 20.5（由表内数值计算），表明仿真预训练提升分布外泛化。

### 未见物体泛化（Table 2，n=300，双视角合并，无微调）
| 物体 | 基线 PSNR/SSIM/LPIPS | Mask2Real-WM (WM1 seg) PSNR/SSIM/LPIPS |
|---|---|---|
| Banana | 19.40 / 0.613 / 0.202 | 19.76 / 0.860 / 0.201 |
| Cup | 19.01 / 0.618 / 0.200 | 19.48 / 0.867 / 0.180 |
| Cylinder | 19.06 / 0.616 / 0.194 | 19.80 / 0.866 / 0.190 |

WM1 在未见物体上保持高分割空间保真度（SSIM ≈ 0.86），显著优于基线。

### WM2 条件消融
- 锐度（Laplacian variance）：ID 上仅动作变体达到地面真值 0.8×，仅掩码与掩码+动作均恢复 0.97×
- 地面真值掩码 oracle：26.8 PSNR / 0.85 SSIM / 0.044 LPIPS；完整流水线：20.1 / 0.70 / 0.150；基线：20.8 / 0.70 / 0.139
- OOD 退化：基线 6× LPIPS 增加 vs 本方法 2.8×

## 边界与局限

作者明确所有主要失败模式都出现在 WM1 的物体状态预测：手遮挡物体数步后 WM1 会从预测掩码中丢弃物体，或幻觉出第二个物体实例。无深度信息时此问题尤为突出，深度条件化是自然补救措施。长时程中颜色类掩码无物体级绑定导致身份漂移，需文本提示或物体 ID 条件化解决。

合成数据未完全覆盖自然操作运动，MimicGen 依赖手动指定的子任务边界，适用于拾放设置但对更复杂任务可能受限。固定相机假设限制部署灵活性，未条件化相机内参和外参。两个顺序扩散过程推理昂贵，未实现近实时 rollout。未见物体泛化仅测试了 WM1 在仿真中见过但 WM2 未渲染过的物体，未测试完全未知物体。分割颜色词汇限于单物体，未扩展到多物体操作。

## 工程启示

复现时优先核对仿真与真实的系统辨识质量——PD 增益与摩擦参数经 CMA-ES 优化匹配物理机器人，这是 WM1 仿真预训练有效性的前提。若跳过此步骤，仿真动力学与真实差距会直接传导至微调阶段，导致动作可控性显著下降。

WM2 训练时务必使用像素空间 CNN 掩码编码器而非 VAE 编码器，边界响应强度差异约 48% 直接影响渲染锐度。掩码与动作条件 dropout 各 10% 是 classifier-free guidance 的关键，不可省略。训练配置参考：WM1 预训练 55000 步（lr 10⁻⁴）单块 H200，微调 45000 步（lr 5×10⁻⁶）；WM2 训练 70000 步（lr 10⁻⁴）8 块 H100。

下游团队最易踩坑处：WM1 的物体状态预测是瓶颈，部署前应重点测试遮挡场景下的掩码连续性；长时 rollout 中身份漂移会累积，建议在推理时定期用 SAM 3 重置掩码上下文；若目标场景相机位置与训练不同，需重新采集数据而非简单微调。
