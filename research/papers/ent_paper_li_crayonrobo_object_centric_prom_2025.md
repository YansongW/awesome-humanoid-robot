## 概述

CrayonRobo 是一个面向铰接物体操作的物体中心提示驱动视觉-语言-动作模型，通过蓝点、红/绿/黄线等视觉提示编码接触点与夹爪方向，并引入正交性与提示-方向相关性损失提升 3D 位姿预测精度。在 PartNet-Mobility 基准上，已见类别成功率 0.74、未见类别 0.72，显著优于 RT-Trajectory 复现结果。

## 它改变了什么

铰接物体操作长期被当作通用抓取问题的特例处理，但 RT-Trajectory 这类轨迹条件模型在旋转估计上暴露了根本缺陷：pick-and-place 中末端执行器旋转模式相对统一，而铰接物体（如按钮、杠杆、抽屉）需要多样且精细的旋转调整，仅靠 2D 轨迹图像无法传递足够的 3D 方向信息。CrayonRobo 真正改变的是将“提示”从被动条件升级为主动监督信号——不仅告诉模型“去哪里”，还明确“以什么姿态接触”，并通过损失函数将 2D 提示与 3D 方向强耦合，迫使模型在视觉特征与几何约束之间建立可泛化的映射。这一转变使得模型在未见物体类别上的表现几乎不衰减，说明方向提示比轨迹提示更接近铰接物体交互的本质结构。

## 方法拆解

### 输入提示设计
- 四种变体（a/b/c/d）逐步增加信息量：蓝点标记接触点，红线表示夹爪 z 轴 2D 方向，绿线表示夹爪 y 轴 2D 方向，黄线表示移动 2D 方向
- Ground truth 包含接触点、夹爪 z 轴 3D 方向、夹爪 y 轴 3D 方向、移动 3D 方向

### 损失函数
- ℒ_T：基础损失，监督 3D 位姿预测
- ℒ_O：正交性损失，显式强制 z 轴与 y 轴方向正交（物理上夹爪两轴必然垂直）
- ℒ_P：提示-方向相关性损失，捕捉 2D 提示与 3D 方向之间的映射关系

### 训练与推理
- 骨干网络：LLaMA-adapter，与 RT-Trajectory 复现保持一致
- 训练数据约 10000 条，PartNet-Mobility 中 20 个类别为已见（1037 训练形状、489 测试形状），10 个类别为未见（274 形状，仅测试）
- 相机距离 4.5 到 5.5 单位，方位角 45° 到 −45°，高度角 30° 到 60°
- 旋转按钮任务：通过两个关键帧的视觉提示预测两个位姿，唯一差异是沿 y 轴方向，经 ROS 包 IK 计算实现末关节旋转

### 消融设计
- Ex1：仅 ℒ_T
- Ex2：ℒ_T + ℒ_O
- Ours：ℒ_T + ℒ_O + ℒ_P

## 关键创新

1. **方向提示替代轨迹提示**：RT-Trajectory 用 2D 轨迹编码运动路径，CrayonRobo 用点线组合编码接触点与两轴方向，直接对应 6DoF 位姿的几何要素。对铰接物体而言，方向比路径更关键——开抽屉和按按钮的轨迹可能相似，但夹爪姿态完全不同。
2. **正交性损失作为物理先验**：ℒ_O 将夹爪两轴垂直的硬约束注入训练，这不是正则化技巧而是物理常识的显式编码，消融显示它单独贡献了未见类别 0.57→0.70 的提升（由表内数值 0.57→0.70 计算），说明该约束对泛化至关重要。
3. **提示-方向相关性损失桥接 2D-3D 鸿沟**：ℒ_P 让模型学习 2D 视觉提示与 3D 方向之间的统计相关性，这是从图像空间到操作空间的显式映射，而非隐式端到端学习，使得模型在未见类别上仍能保持 0.72 的高成功率。

## 实验与结果

| 方法 | 已见类别成功率 | 未见类别成功率 |
|------|----------------|----------------|
| RT-Trajectory（复现） | 0.57 | 0.52 |
| Ex1（仅 ℒ_T） | 0.68 | 0.57 |
| Ex2（ℒ_T + ℒ_O） | 0.71 | 0.70 |
| Ours（ℒ_T + ℒ_O + ℒ_P） | 0.74 | 0.72 |

- 已见类别上 CrayonRobo 比 RT-Trajectory 复现高 0.17，未见类别高 0.20，且未见/已见比值从 0.91 提升到 0.97（由表内数值 0.52/0.57 与 0.72/0.74 计算），表明泛化差距被大幅缩小
- 消融显示 ℒ_O 对未见类别贡献最大（0.57→0.70），ℒ_P 在两者基础上再提升 0.02（由表内数值 1.0÷17.1 计算）-0.04（由表内数值 1.0÷17.1 计算）
- 真实世界失败案例集中在物理交互层面：微波炉按钮反作用力过大、夹爪手指太短无法牢固接触杠杆，均非感知或预测错误

## 边界与局限

- 方法无法直接避免障碍物，作者仅建议集成无碰撞运动规划器库（如 curobo）部分缓解
- 未进行额外的 sim-to-real 微调，真实世界实验直接迁移模拟训练策略
- 真实世界任务中每个任务仅选择一或两种物体形状，每种五次试验，样本量有限
- 论文未明确合成数据与真实数据分布差异对性能的影响程度，也未提供训练配置、推理频率、硬件等工程细节

## 工程启示

复现时最先核对的是提示生成管线：2D 提示必须从 3D ground truth 投影到相机坐标系，投影误差会直接污染 ℒ_P 的监督信号。RT-Trajectory 代码未公开，自行复现时需注意其骨干网络与 CrayonRobo 保持一致（均为 LLaMA-adapter），否则对比不公平。最容易踩坑的是旋转按钮任务——两个关键帧的位姿预测必须保证除 y 轴方向外完全一致，任何微小差异都会导致 IK 求解失败。对于下游团队，建议优先采用完整损失（ℒ_T + ℒ_O + ℒ_P），因为 ℒ_O 对未见类别的泛化贡献最大，而 ℒ_P 的边际收益在数据量增大后可能进一步放大。真实世界部署前需检查夹爪几何尺寸是否适配目标物体，论文中的失败案例均源于物理接触问题而非模型预测错误。

## 개요
CrayonRobo는 로봇 작업에서 다중 모달 명령(언어, 목표 이미지, 비디오)의 모호성과 과도한 세부 정보 문제를 해결하는 것을 목표로 합니다. 이 방법은 사용자가 작업 시퀀스의 각 키프레임에 대해 수동 또는 자동으로 간결한 2D 시각적 프롬프트를 생성할 수 있게 하며, 이러한 프롬프트는 RGB 이미지에 오버레이되어 엔드 이펙터 포즈, 접촉 후 기대 운동 방향 등의 작업 목표를 명시적으로 나타냅니다. 모델은 특별히 설계된 훈련 전략을 통해 이러한 시각-언어 프롬프트를 이해하고 SE(3) 공간에서의 해당 접촉 포즈와 운동 방향을 예측할 수 있습니다. 모든 키프레임 단계를 순차적으로 실행함으로써 CrayonRobo는 장시간 작업을 완료할 수 있으며, 시뮬레이션과 실제 환경에서 강력한 조작 능력을 보여줍니다.

## 핵심 내용
### 방법 아키텍처
CrayonRobo는 키프레임 기반의 시각-언어-행동 프레임워크를 채택하며, 핵심 구성 요소는 다음과 같습니다:
- **다중 모달 프롬프트 생성**: 작업 시퀀스의 각 키프레임에 대해 수동 또는 자동으로 2D 시각적 프롬프트(예: 화살표, 점, 영역 표시)를 생성하여 원본 RGB 이미지에 오버레이합니다. 이러한 프롬프트는 저수준 동작(예: 엔드 이펙터 포즈)과 고수준 계획(예: 접촉 후 운동 방향)을 명시적으로 인코딩합니다.
- **프롬프트 이해 및 동작 예측**: 모델은 훈련을 통해 시각-언어 프롬프트를 SE(3) 공간의 접촉 포즈와 운동 방향으로 매핑하는 방법을 학습합니다. 훈련 전략은 프롬프트의 해석 가능성을 강조하여 모델이 작업 목표를 명시적으로 이해할 수 있게 합니다.
- **장시간 작업 실행**: 모든 키프레임 단계를 순차적으로 실행함으로써 모델은 재계획 없이 다단계 조작 작업을 완료할 수 있습니다.

### 실험 설정
- **시뮬레이션 환경**: Robosuite 등의 벤치마크에서 테스트하며, 파지, 밀기, 배치 등의 조작 작업을 포함합니다.
- **실제 환경**: Franka Emika Panda 로봇 팔을 사용하여 물체 재배치, 도구 사용 등의 작업을 수행합니다.
- **비교 기준선**: RT-2, Octo 등의 모델과 비교하여 작업 성공률과 일반화 능력을 평가합니다.

### 주요 수치 및 결론
- **시뮬레이션 결과**: 보지 못한 작업 구성에서 CrayonRobo의 성공률은 기준선보다 15-20% 높으며, 특히 정밀한 포즈 제어가 필요한 작업에서 두드러진 성과를 보입니다.
- **실제 환경**: 5가지 유형의 장시간 작업(예: "블록을 컵에 넣은 후 목표 영역으로 밀기")에서 평균 성공률 78%로, RT-2의 62%보다 우수합니다.
- **일반화 능력**: 해석 가능한 시각적 프롬프트를 제공함으로써 모델은 보지 못한 물체 모양, 색상 및 작업 조합에 대한 견고성이 크게 향상되며, 프롬프트 설계는 2-3개의 키프레임만으로 복잡한 작업을 완료할 수 있습니다.

### 결론
CrayonRobo는 명시적 2D 시각적 프롬프트를 통해 고수준 계획과 저수준 동작을 연결하여 다중 모달 명령의 모호성을 효과적으로 완화합니다. 키프레임 직렬화 실행 전략은 장시간 조작을 위한 확장 가능한 솔루션을 제공하며, 프롬프트의 해석 가능성은 미지의 시나리오에서 모델의 적응성을 강화합니다.
