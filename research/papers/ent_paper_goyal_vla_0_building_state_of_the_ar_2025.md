## 概述

VLA-0 提出一种极简的 VLA 构建范式：直接利用 VLM 原生文本生成能力，将连续动作归一化为整数序列并以空格分隔的文本形式输出，不对底层模型做任何架构或词表修改。基于 3B 参数的 Qwen-VL-2.5，在 LIBERO 基准上以 94.7% 平均成功率超越所有使用相同机器人数据的现有方法，甚至超过多数使用大规模动作预训练的模型，并在真实 SO-100 机器人上以 4 Hz 推理速度超越预训练基线 SmolVLA 12.5 个百分点。

## 它改变了什么

现有 VLA 构建路径几乎都默认需要“改造”VLM：要么把连续动作离散成 bin 再映射到词表（Discrete Token），要么在 VLM 上外挂扩散或流匹配头（Generative Action Head），要么动架构、加参数、改训练流程（Custom Architecture）。这些做法各有代价：离散化限制动作分辨率且挪用文本词表损害语言能力；外挂动作头引入需微调的新网络，常导致底层 VLM 的 grounding 能力退化；自定义架构则牺牲了 VLM 的即插即用性。作者指出了一个被行业惯性忽略的事实——VLM 本身就能以文本形式输出任意精度的数字，为什么还要绕路去发明新的动作表示？VLA-0 的真正改变在于：它把“构建 VLA”从一项需要专门设计的工程问题，还原为一个纯粹的提示工程问题。这动摇了“VLA 必须修改 VLM”这一隐含前提，证明零修改的文本动作输出不仅能工作，而且在同等数据条件下比所有精心设计的替代方案都更强。这一结果对社区的意义在于：大量针对动作头、tokenizer、架构的复杂创新，可能都是在为一个本不存在的问题提供解决方案。

## 方法拆解

### 总体流程
VLA-0 的训练与推理完全复用标准 VLM 流程，仅改变输入提示和输出目标格式。

### 输入构造
- 系统提示（System Prompt）明确要求模型输出 H×D 个整数，格式为空格分隔的序列，范围 [0, B]：
  > "Analyze the input image and predict robot actions for the next H timesteps. Each action has D dimensions. Output a single sequence of H×D integers (0 - B each)... Provide only space-separated numbers. Nothing else."
- 仿真使用第三视角 + 腕部相机图像；真实实验使用左右相机。备选方案将多图拼接为单一复合图像，实验表明两种输入方式性能无显著差异（94.5 vs 94.7）。

### 动作编码与解码
- 连续动作值归一化到固定整数范围（LIBERO 上 B=1000），每个动作维度对应一个整数 token。
- 与 Discrete Token VLA 的关键区别：无需将整数映射到词表子集，VLM 直接生成数字字符，因此动作分辨率仅受整数范围限制，可任意调整（实验测试 250、1000、4000 三档）。

### 训练策略
- 全量微调 Qwen-VL-2.5-3B，标准交叉熵损失，Adam 优化器，64 epochs，batch size 192，学习率 5e-6，8 张 A100 训练约 32 小时。
- **Masked Action Augmentation**：训练时随机遮蔽目标动作字符串中的部分字符。动机：VLM 自回归生成时每个 token 依赖先前 token，若不遮蔽，模型可能学会“自动补全”已开始的数字序列而非真正基于视觉推理；遮蔽迫使模型从观察和指令中推断被遮动作。

### 推理集成
- 采用 ACT 引入的预测集成：每个推理步生成 n 个未来动作；对当前时间步 t，取 t、t-1、…、t-n+1 步生成的 n 个预测的平均值作为最终动作。消融显示该组件贡献 2.0 个百分点（94.7 → 92.0）。

## 关键创新

1. **零修改的文本动作输出**：这是首个系统验证“VLM 原生文本生成即可胜任动作预测”的工作。它彻底绕开了动作 tokenizer、动作头、架构修改这三条既有路径，将 VLA 构建简化为提示设计。其新颖性在于：不是提出新模块，而是证明一个被忽视的简单方案在同等数据下全面超越所有复杂方案。
2. **Masked Action Augmentation**：针对“文本动作”这一特定表示的自回归特性设计的训练增强。它精准打击了文本动作输出的核心风险——模型可能退化为数字序列的自动补全器而非视觉-语言-动作推理器。这一设计是 Discrete Token VLA 和 Action Head VLA 都不需要的，因为它只对“文本形式动作”有意义。
3. **动作分辨率与词表解耦**：通过将动作映射到整数文本而非词表 token，动作分辨率从词表大小的约束中解放出来。实验表明 1000 的分辨率已足够（升至 4000 无收益，降至 250 损失 1.5 点），这为不同精度需求的场景提供了直接可调的旋钮。

- 四个任务各 100 个演示，VLA-0 平均成功率超越在大规模 SO-100 数据上预训练的 SmolVLA **12.5 个百分点**。
- 推理速度 4 Hz（5090 GPU，标准 PyTorch，流式输出）。

## 边界与局限

- **未探索大规模动作数据训练**：所有实验均基于任务内数据微调，VLA-0 在类似 OpenVLA、π₀ 的大规模预训练数据上的表现论文未明确。
- **真实实验未使用动作集成**：因需 8 个并行模型实例，作者指出可行但未实施；这意味着真实世界结果可能低估了 VLA-0 的潜力。
- **推理速度未优化**：4 Hz 为未量化、未蒸馏的标准 PyTorch 实现；作者认为通过量化或蒸馏可显著提升，但未给出数据。
- **与 LLARVA、HAMSTER 的区分**：这两者均采用两阶段（先预测 2D 轨迹再映射动作），VLA-0 直接端到端输出完整动作；但论文未与这两者做直接实验对比。
- **动作范围假设**：整数归一化范围 [0, 1000] 在 LIBERO 上验证充分，但其他机器人平台的动作尺度、分布特性可能影响该范围的适用性，论文未明确。

## 工程启示

- **复现第一优先级**：先核对动作归一化方式——LIBERO 上 [0, 1000] 的整数范围是性能关键，范围过低（250）损失 1.5 点，过高（4000）无收益。不同数据集需重新标定该范围。
- **最容易踩坑的地方**：Masked Action Augmentation 的遮蔽比例和策略论文未给出具体数值，这是影响训练稳定性的敏感超参；建议从较低遮蔽率开始网格搜索。另外，Ensembling 的窗口大小 n 论文未明确，复现时需自行确定。
- **对下游团队的选型建议**：若你的场景已有可用的 VLM 且数据量有限（如单任务 100 个演示），VLA-0 的零修改方案值得优先尝试——它省去了动作头设计、tokenizer 调试和架构迁移的成本。但需注意：VLA-0 的优势建立在 Qwen-VL-2.5-3B 的文本生成能力上，换用其他 VLM 时需重新验证其数字序列生成的稳定性。
- **工程实现细节**：训练 32 小时 / 8×A100 的成本对 3B 模型而言合理；推理 4 Hz 对实时控制偏慢，若需部署到真实机器人，建议先做量化或蒸馏，但论文未提供这些优化后的精度数据，需自行评估 trade-off。

## 개요
VLA-0는 시각-언어-행동 모델을 구축하는 가장 간단한 경로를 탐구한다: 기존 방법처럼 VLM 어휘를 수정하거나 전용 행동 헤드를 도입하는 대신, 로봇 행동을 직접 텍스트로 인코딩하는 것이다. 실험 결과, 이 간단한 설계는 LIBERO 벤치마크에서 놀라운 성능을 보여주며, 동일한 로봇 데이터로 훈련된 모든 모델을 능가할 뿐만 아니라 대규모 로봇 데이터로 훈련된 π_0.5-KI, π_0, GR00T-N1 및 MolmoAct보다도 우수하다. 실제 세계 실험에서도 VLA-0는 대규모 실제 데이터로 사전 훈련된 SmolVLA보다 우수하다. 논문은 이러한 높은 성능을 달성하는 데 필요한 구체적인 기술을 자세히 요약한다.

## 핵심 내용
### 방법
- **핵심 아이디어**: 로봇 행동을 직접 텍스트 문자열로 표현하며, VLM의 어휘를 수정하거나 전용 행동 헤드를 추가할 필요가 없다.
- **설계 원칙**: VLM 아키텍처를 변경하지 않고, 텍스트 입력/출력 인터페이스를 통해서만 행동 정보를 처리한다.

### 실험 설정
- **벤치마크 테스트**: 주로 LIBERO 벤치마크를 사용하며, 이는 VLA를 평가하는 널리 사용되는 표준이다.
- **비교 모델**: π_0.5-KI, OpenVLA-OFT, SmolVLA(동일 데이터로 훈련) 및 π_0.5-KI, π_0, GR00T-N1, MolmoAct(대규모 로봇 데이터로 훈련)를 포함한다.

### 주요 결과
- **LIBERO 벤치마크**: VLA-0는 동일한 로봇 데이터로 훈련된 모든 기존 방법(π_0.5-KI, OpenVLA-OFT 및 SmolVLA 포함)을 능가한다.
- **규모 간 비교**: 대규모 로봇 전용 훈련 없이도 VLA-0는 대규모 로봇 데이터로 훈련된 π_0.5-KI, π_0, GR00T-N1 및 MolmoAct보다 우수하다.
- **실제 세계 검증**: 실제 로봇 실험에서 VLA-0는 대규모 실제 데이터로 사전 훈련된 SmolVLA보다 우수하다.
