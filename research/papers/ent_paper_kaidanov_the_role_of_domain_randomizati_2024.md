## 概述

UniVLA 提出将视觉、语言与动作信号统一离散化为共享词汇表上的 token，以无编码器自回归 Transformer 联合建模跨模态依赖。该方法在 LIBERO 基准上平均成功率 95.5%，超越 π₀-FAST 的 85.5%，并通过世界模型后训练显著提升策略学习，尤其在长时程与分布外任务上。

## 它改变了什么

现有 VLA 模型（如 OpenVLA、π₀）遵循“语言中心”范式，视觉先投影到语义空间再推导动作，这种晚期融合虽利于语义理解，却割裂了感知与动作间的深度耦合。核心问题在于视觉（高维连续）、语言（抽象离散）与动作（时间有序、因果依赖）本质异质，而静态映射无法利用视频中的时间动态。UniVLA 真正改变的是将三者置于同一离散 token 空间，使自回归链式建模天然承载时间与因果依赖，而非孤立处理各模态。这一转变让动作生成不再是对静态图像的响应，而是对动态感知-动作循环的推理，从而在策略学习上获得结构性优势。

## 方法拆解

### 统一 token 化
- 视觉：采用 VQ tokenizer（同 Emu3 设计），将连续图像帧映射为离散视觉 token。
- 动作：遵循 FAST 方法，对时间窗口内的连续动作序列应用离散余弦变换（DCT），转换为离散动作 token 序列 [T₁,…,Tₙ]，n 个 token 来自大小为 |V| 的共享词汇表，动作序列长度可变。
- 语言：指令作为离散 token 序列输入。

### 序列格式
- 使用特殊 token（boi/eoi、boa/eoa）标记图像与动作边界。
- 语言指令在任务开始时提供，随后是视觉观察与动作的自然交错序列，形成统一输入流。

### 训练目标
- 所有模态转为离散 token 后，训练简化为标准下一个 token 预测（交叉熵损失）。
- 根据任务格式选择性计算特定 token 的损失，例如策略学习仅对动作 token 计算损失。

### 两阶段训练
1. **世界模型后训练**：将语言指令视为通用动作形式，给定当前观察 L_v¹ 和指令 L_t¹，预测未来视觉内容，序列公式为 S_v = {L_t¹, L_v¹, L_v², …, L_vᵗ}，仅用视觉 token 损失监督。
2. **微调阶段**：将动作交错插入序列，进行下游策略学习。

### 架构关键
- 无编码器（encoder-free）架构，不使用 ViT 进行图像编码，直接以离散 token 序列输入自回归 Transformer。
- 统一 token 表示支持跨模态联合学习，自回归马尔可夫链式建模自然融入因果依赖。

## 关键创新

1. **统一离散 token 空间**：将视觉、语言、动作全部映射到共享词汇表，打破模态异质性壁垒，使跨模态联合学习成为可能。这是对“晚期融合”范式的根本性替代，而非简单拼接。
2. **世界模型后训练**：将语言指令视为通用动作形式，在大规模无动作视频上预训练模型预测未来视觉内容。这一设计让模型先学习环境动态与因果结构，再微调策略，显著提升长时程与分布外任务的泛化能力。
3. **无编码器架构**：摒弃 ViT 图像编码器，直接以离散 token 序列输入 Transformer，简化了模态对齐流程，使视觉信息不再经过语义投影的“瓶颈”，保留更多时空细节用于动作推理。

## 实验与结果

在 LIBERO 基准上，UniVLA 平均成功率 95.5%，超越 π₀-FAST 的 85.5%，提升 10 个百分点（由表内数值 85.5%→95.5% 计算）。该结果验证了统一 token 表示与自回归建模在策略学习上的有效性。论文还提及在 CALVIN、Simplenv-Bridge 等模拟基准上取得新 SOTA，以及真实 ALOHA 操作和自动驾驶场景中的广泛适用性，但具体数字未在片段中提供。

## 工程启示

复现 UniVLA 时，首先核对视觉 VQ tokenizer 与动作 DCT 编码的词汇表大小 |V| 及动作 token 数量 n 的设定，这两者直接影响序列长度与模型容量。其次，两阶段训练的顺序不可颠倒——世界模型后训练需在大规模无动作视频上充分收敛，再微调策略，否则长时程任务性能可能显著下降。最容易踩坑的地方在于损失计算：策略微调阶段需仅对动作 token 计算交叉熵，若误将视觉 token 损失纳入，会干扰动作学习。下游团队选型时，若任务涉及长时程操作或分布外泛化，UniVLA 的结构性优势明显；但若计算资源有限，无编码器架构虽省去 ViT 开销，自回归生成仍对推理延迟敏感，需评估实时性需求。

## 개요
휴머노이드 로봇은 인체 구조와 유사하여 원격 조작, 모션 캡처, 심지어 인간 비디오로부터 풍부한 시연 데이터를 얻을 잠재력이 있지만, 시연으로부터 제어 정책을 증류하는 것은 여전히 도전 과제입니다. 확산 정책은 로봇 조작 작업에서 우수한 성능을 보였지만, 운동 제어 및 휴머노이드 로봇 분야에서의 적용은 아직 충분히 탐구되지 않았습니다. 본 연구는 IsaacGym 시뮬레이션 환경에서 적대적 운동 사전 에이전트를 훈련하고 다양한 도메인 무작위화 조건을 적용하여 합성 시연 데이터셋을 생성한 뒤, 다양한 규모와 다양성을 가진 데이터셋에서 확산 정책의 훈련 효과를 체계적으로 비교했습니다. 실험 결과, 단순한 시나리오에서도 운동 제어 정책의 성공적인 훈련에는 조작 작업보다 훨씬 더 크고 다양한 데이터셋이 필요함을 보여줍니다.

- 휴머노이드 로봇은 구조적 생체 모방 덕분에 원격 조작, 모션 캡처 또는 인간 비디오를 통해 시연 데이터를 얻을 수 있지만, 정책 증류는 여전히 핵심 과제입니다.
- 확산 정책은 로봇 조작 작업에서 상당한 성과를 거두었지만, 전신 운동 제어 및 휴머노이드 로봇 분야에서의 적용 가능성은 아직 체계적으로 검증되지 않았습니다.

### 방법 설계
- **시뮬레이션 환경**: IsaacGym 기반으로 휴머노이드 로봇 전신 제어 시뮬레이션 시나리오를 구축했습니다.
- **데이터 생성**: 적대적 운동 사전(AMP) 강화 학습 에이전트를 훈련하고, 다양한 도메인 무작위화 조건에서 합성 시연 궤적을 생성했습니다.
- **도메인 무작위화 조건**: 외력 간섭과 같은 섭동 무작위화와 지면 요철과 같은 지형 무작위화를 포함하여 실제 환경의 불확실성을 모사했습니다.

### 실험 설정
- **데이터셋 변수**: 데이터셋 규모(수천 개에서 수십만 개의 궤적)와 다양성(도메인 무작위화 매개변수 조정을 통해 구현)을 체계적으로 변경했습니다.
- **정책 훈련**: 확산 정책을 사용하여 다양한 특징의 데이터셋을 피팅하고, 안정적인 보행 동작 생성 능력을 평가했습니다.

### 주요 발견
- **규모 요구 사항**: 운동 제어 작업에 필요한 데이터셋 규모는 조작 작업보다 훨씬 크며, 단순한 시나리오에서도 수만 개의 시연 궤적이 필요합니다.
- **다양성의 중요성**: 섭동 무작위화와 지형 무작위화가 정책의 일반화 능력 향상에 가장 두드러지며, 다양성이 부족한 데이터셋은 보지 못한 시나리오에서 정책이 실패하게 만듭니다.
- **성능 비교**: 확산 정책은 충분히 훈련되면 안정적인 보행을 달성할 수 있지만, 수렴 속도와 최종 성능은 데이터셋의 적용 범위에 크게 의존합니다.
