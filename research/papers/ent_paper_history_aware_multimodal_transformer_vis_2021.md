## 概述

本文提出 HAMT（History Aware Multimodal Transformer），一个全 Transformer 架构的视觉-语言导航（VLN）模型，通过分层编码器显式建模长程历史轨迹，并结合指令与当前观测进行多模态动作预测。作者在 R2R、RxR、R4R、CVDN、REVERIE 等七个数据集上取得 SOTA，尤其在长时程导航任务上增益显著。

## 它改变了什么

VLN 领域长期被 Seq2Seq + LSTM 的范式主导，历史信息被压缩进固定维度的循环状态，导致长时程导航中早期观测与动作的记忆严重衰减。此前的工作如 PREVALENT 虽引入 Transformer 预训练，但仅编码单步观测与指令，缺乏对轨迹历史的显式建模。HAMT 真正改变的是将“历史”从隐式循环状态提升为显式的分层 token 序列，使模型能够以与文本、当前观测同等地位的方式参与跨模态注意力计算。这一改动直接回应了 VLN 中“长指令 + 长轨迹”场景下记忆丢失的核心痛点，并在 R2R-Back、R4R 等需要回溯或长距离规划的任务上带来显著提升。

## 方法拆解

### 整体架构
- 三个编码器：单模态语言编码器（BERT 初始化）、单模态视觉编码器（ViT-B/16）、跨模态 Transformer。
- 历史编码采用**分层策略**：每步的定向视图先编码为局部观测 token，再聚合为全局历史 token，与当前观测 token 一起送入跨模态 Transformer。

### 两阶段训练
1. **代理任务预训练**（端到端）：
   - MLM（掩码语言建模）：15% 概率掩码指令词，负对数似然损失。
   - MRM（掩码区域建模）：15% 概率掩码观测，KL 散度匹配 ImageNet 预训练 ViT 的类别分布。
   - ITM（指令-轨迹匹配）：4 个负样本（2 随机、2 时间打乱），Noisy Contrastive Estimation。
   - SAP(R)（单步动作预测与回归）：模仿学习直接预测动作。
   - SPREL（空间关系预测）：自监督学习全景中的空间关系。
   - 采样比例：MLM:MRM:ITM:SAP:SAR:SPREL = 5:2:2:1:1:1。
2. **微调**：RL + IL 联合优化，不同任务使用不同奖励（R2R/RxR/R4R 考虑路径保真度；R2R-Last/REVERIE/CVDN 仅用距离减少）。

### 关键设计决策
- 视觉特征：代理任务阶段用 ImageNet 预训练 ViT；RxR 实验用 CLIP 特征（不端到端）；REVERIE 用 R2R 端到端优化的 ViT 提取物体特征。
- 结构变体：编码器-解码器变体（去除文本到视觉的跨模态注意力）在长指令任务（R4R、RxR）中更高效。
- 优化器：AdamW；使用 RandAugment 和 stochastic depth 防过拟合。

## 关键创新

1. **显式分层历史编码**：将历史轨迹编码为全局 token 序列，与文本和当前观测并列参与跨模态注意力。相比循环状态或仅时间编码，分层方式在 R2R-Back 上 val unseen SPL 从 37.7 提升至 51.7（无 e2e），证明其能有效保留长时程信息。
2. **两阶段端到端训练**：先代理任务预训练再 RL 微调，而非单阶段端到端。单阶段 25k 迭代后 SPL 仅 53.5，反而低于无端到端的 56.5，说明 VLN 数据有限时渐进式训练更稳定。
3. **SPREL 自监督任务**：通过预测全景空间关系增强未见环境的泛化能力。消融显示加入 SPREL 后 val unseen SR 从 64.5 提升至 65.7，且与 SAP(R) 互补。

## 边界与局限

- **REVERIE 物体定位短板**：RGS 和 RGSPL 在测试集上差于 SOTA，作者归因于用 R2R 优化的 ViT 提取物体特征，泛化性不如物体检测预训练特征。
- **单阶段端到端失败**：25k 迭代效果反而差于无端到端，说明 VLN 数据量不足以支撑直接端到端训练。
- **推理开销**：HAMT 比 RecBERT 慢 1.5 倍（104s vs 69s），noT2V 变体慢 1.1 倍，实时部署需权衡。
- **与人类差距**：RxR 上多语言 HAMT 与人类表现仍有较大差距，论文未量化具体差距数值。
- **未做之事**：未涉及连续动作 VLN、跨数据集迁移的详细分析、真实机器人部署验证；失败案例分析仅定性提及（如酒架识别失败）。

## 工程启示

- **先核对历史编码方式**：若复现，务必确认分层历史 token 的聚合方式（全局 vs 局部）与论文一致，这是性能提升的核心。仅时间编码在 R2R-Back 上 SPL 损失近 9 个点。
- **两阶段训练不可跳过**：直接端到端训练会掉点（SPL 53.5 vs 56.5），代理任务预训练的顺序和采样比例（5:2:2:1:1:1）需严格遵循。
- **视觉特征选择是双刃剑**：ViT 端到端优化在 unseen 上提升 2.1% SPL，但会牺牲 seen 上 0.8% SPL；REVERIE 任务中物体特征需用物体检测预训练模型，否则 RGS 会落后。
- **RL+IL 缺一不可**：仅 IL 的 SR 仅 57.2，仅 RL 为 63.5，联合后达 65.7，说明模仿学习提供稳定梯度、RL 负责探索，两者互补。
- **推理时间预算**：若部署场景对延迟敏感，使用 noT2V 变体（76s vs 104s），性能仅损失 1% SR，但需确认长指令任务上的表现。
- **最容易踩坑**：代理任务中 ITM 的负样本采样（2 随机 + 2 时间打乱）和 Noisy Contrastive Estimation 的实现细节；R2R-Back 的奖励需分两阶段计算（先到原目标再回起点），否则训练不稳定。

## Overview

This paper introduces HAMT (History Aware Multimodal Transformer), a fully Transformer-based architecture for Vision-and-Language Navigation (VLN). It explicitly models long-range historical trajectories through a hierarchical encoder, integrating instructions and current observations for multimodal action prediction. The authors achieve state-of-the-art results on seven datasets including R2R, RxR, R4R, CVDN, and REVERIE, with particularly significant gains on long-horizon navigation tasks.

## What It Changes

The VLN field has long been dominated by the Seq2Seq + LSTM paradigm, where historical information is compressed into a fixed-dimensional recurrent state, causing severe memory decay of early observations and actions in long-horizon navigation. Previous works such as PREVALENT introduced Transformer pretraining but only encoded single-step observations and instructions, lacking explicit modeling of trajectory history. What HAMT truly changes is elevating "history" from an implicit recurrent state to an explicit hierarchical token sequence, enabling it to participate in cross-modal attention computation on equal footing with text and current observations. This change directly addresses the core pain point of memory loss in "long instruction + long trajectory" scenarios in VLN, yielding significant improvements on tasks requiring backtracking or long-distance planning, such as R2R-Back and R4R.

## Method Breakdown

### Overall Architecture
- Three encoders: a unimodal language encoder (BERT-initialized), a unimodal visual encoder (ViT-B/16), and a cross-modal Transformer.
- History encoding employs a **hierarchical strategy**: each step's oriented view is first encoded into local observation tokens, then aggregated into a global history token, which is fed into the cross-modal Transformer alongside current observation tokens.

### Two-Stage Training
1. **Auxiliary Task Pretraining** (end-to-end):
   - MLM (Masked Language Modeling): 15% probability of masking instruction words, negative log-likelihood loss.
   - MRM (Masked Region Modeling): 15% probability of masking observations, KL divergence matching the class distribution of an ImageNet-pretrained ViT.
   - ITM (Instruction-Trajectory Matching): 4 negative samples (2 random, 2 temporally shuffled), using Noisy Contrastive Estimation.
   - SAP(R) (Single-step Action Prediction and Regression): imitation learning for direct action prediction.
   - SPREL (Spatial Relationship Prediction): self-supervised learning of spatial relationships in panoramas.
   - Sampling ratio: MLM:MRM:ITM:SAP:SAR:SPREL = 5:2:2:1:1:1.
2. **Fine-tuning**: Joint RL + IL optimization, with different rewards for different tasks (R2R/RxR/R4R consider path fidelity; R2R-Last/REVERIE/CVDN use only distance reduction).

### Key Design Decisions
- Visual features: ImageNet-pretrained ViT during the auxiliary task phase; CLIP features for RxR experiments (not end-to-end); object features extracted by an R2R end-to-end optimized ViT for REVERIE.
- Architecture variants: The encoder-decoder variant (removing text-to-vision cross-modal attention) is more efficient on long-instruction tasks (R4R, RxR).
- Optimizer: AdamW; RandAugment and stochastic depth used to prevent overfitting.

## Key Innovations

1. **Explicit Hierarchical History Encoding**: Encodes trajectory history as a sequence of global tokens, placed alongside text and current observations for cross-modal attention. Compared to recurrent states or mere temporal encoding, the hierarchical approach improves val unseen SPL on R2R-Back from 37.7 to 51.7 (without e2e), demonstrating its effectiveness in preserving long-horizon information.
2. **Two-Stage End-to-End Training**: Auxiliary task pretraining followed by RL fine-tuning, rather than single-stage end-to-end training. After 25k iterations, single-stage training achieves only 53.5 SPL, lower than the 56.5 without end-to-end, indicating that progressive training is more stable given limited VLN data.
3. **SPREL Self-Supervised Task**: Enhances generalization to unseen environments by predicting panoramic spatial relationships. Ablation shows that adding SPREL improves val unseen SR from 64.5 to 65.7, complementing SAP(R).

### Key Conclusions
- Auxiliary task pretraining yields a relative SR improvement of 16.7% on val unseen compared to training from scratch.
- End-to-end ViT training improves SPL by 2.1% on val unseen but decreases it by 0.8% on val seen.
- Multilingual HAMT achieves an SR improvement of 12.83% over the runner-up on the RxR test set, yet remains far below human performance.

## Boundaries and Limitations

- **REVERIE Object Grounding Shortfall**: RGS and RGSPL lag behind SOTA on the test set, attributed by the authors to using an R2R-optimized ViT for object feature extraction, which generalizes less effectively than object-detection-pretrained features.
- **Single-Stage End-to-End Failure**: 25k iterations perform worse than without end-to-end, indicating that VLN data volume is insufficient to support direct end-to-end training.
- **Inference Overhead**: HAMT is 1.5x slower than RecBERT (104s vs 69s), and the noT2V variant is 1.1x slower, requiring trade-offs for real-time deployment.
- **Gap to Human Performance**: Multilingual HAMT still lags significantly behind human performance on RxR, though the paper does not quantify the exact gap.
- **What Was Not Done**: No coverage of continuous-action VLN, detailed cross-dataset transfer analysis, or real-robot deployment validation; failure case analysis is only qualitative (e.g., failure to recognize wine racks).

## Engineering Insights

- **Verify History Encoding First**: When reproducing, ensure the aggregation method of hierarchical history tokens (global vs. local) matches the paper, as this is the core of performance gains. Temporal-only encoding loses nearly 9 SPL points on R2R-Back.
- **Two-Stage Training Is Not Optional**: Direct end-to-end training causes performance drops (SPL 53.5 vs 56.5); the order and sampling ratio of auxiliary task pretraining (5:2:2:1:1:1) must be strictly followed.
- **Visual Feature Selection Is a Double-Edged Sword**: End-to-end ViT optimization improves SPL by 2.1% on unseen but sacrifices 0.8% SPL on seen; for REVERIE, object features require object-detection-pretrained models, otherwise RGS lags behind.
- **RL+IL Are Both Essential**: IL-only achieves only 57.2 SR, RL-only 63.5, and their combination reaches 65.7, showing that imitation learning provides stable gradients while RL handles exploration—they are complementary.
- **Inference Time Budget**: For latency-sensitive deployment, use the noT2V variant (76s vs 104s) with only a 1% SR loss, but verify performance on long-instruction tasks.
- **Most Likely Pitfalls**: The negative sampling for ITM in auxiliary tasks (2 random + 2 temporally shuffled) and the implementation details of Noisy Contrastive Estimation; R2R-Back rewards must be computed in two stages (first reaching the original target, then returning to the start), otherwise training becomes unstable.

## 개요

본 논문은 HAMT(History Aware Multimodal Transformer)를 제안한다. 이는 전체 Transformer 아키텍처 기반의 시각-언어 내비게이션(VLN) 모델로, 계층적 인코더를 통해 장기간의 궤적 히스토리를 명시적으로 모델링하고, 지시문 및 현재 관측과 결합하여 다중 모달 행동 예측을 수행한다. 저자는 R2R, RxR, R4R, CVDN, REVERIE 등 7개 데이터셋에서 SOTA를 달성했으며, 특히 장기 내비게이션 작업에서 큰 성능 향상을 보였다.

## 무엇을 바꾸었는가

VLN 분야는 오랫동안 Seq2Seq + LSTM 패러다임이 지배해 왔으며, 히스토리 정보는 고정 차원의 순환 상태로 압축되어 장기 내비게이션에서 초기 관측과 행동에 대한 기억이 심각하게 감쇠되었다. PREVALENT와 같은 이전 연구들은 Transformer 사전 학습을 도입했지만, 단일 단계의 관측과 지시문만 인코딩할 뿐 궤적 히스토리에 대한 명시적 모델링이 부족했다. HAMT가 진정으로 바꾼 것은 '히스토리'를 암시적 순환 상태에서 명시적인 계층적 토큰 시퀀스로 승격시켜, 텍스트 및 현재 관측과 동등한 지위로 교차 모달 어텐션 계산에 참여할 수 있게 한 것이다. 이 변경은 VLN의 '긴 지시문 + 긴 궤적' 시나리오에서 메모리 손실이라는 핵심 문제점을 직접적으로 해결했으며, 역추적이나 장거리 계획이 필요한 R2R-Back, R4R 등의 작업에서 상당한 향상을 가져왔다.

## 방법 분석

### 전체 아키텍처
- 세 개의 인코더: 단일 모달 언어 인코더(BERT 초기화), 단일 모달 시각 인코더(ViT-B/16), 교차 모달 Transformer.
- 히스토리 인코딩은 **계층적 전략**을 사용: 각 단계의 방향성 뷰를 먼저 로컬 관측 토큰으로 인코딩한 후, 전역 히스토리 토큰으로 집계하여 현재 관측 토큰과 함께 교차 모달 Transformer에 입력.

### 2단계 훈련
1. **에이전트 작업 사전 학습**(엔드투엔드):
   - MLM(마스크 언어 모델링): 15% 확률로 지시문 단어 마스킹, 음의 로그 우도 손실.
   - MRM(마스크 영역 모델링): 15% 확률로 관측 마스킹, ImageNet 사전 학습 ViT의 클래스 분포와 KL 발산 매칭.
   - ITM(지시문-궤적 매칭): 4개의 네거티브 샘플(2개 무작위, 2개 시간 순서 섞기), Noisy Contrastive Estimation.
   - SAP(R)(단일 단계 행동 예측 및 회귀): 모방 학습으로 행동 직접 예측.
   - SPREL(공간 관계 예측): 파노라마 내 공간 관계를 자기 지도 학습.
   - 샘플링 비율: MLM:MRM:ITM:SAP:SAR:SPREL = 5:2:2:1:1:1.
2. **미세 조정**: RL + IL 공동 최적화, 작업별 다른 보상 사용(R2R/RxR/R4R은 경로 충실도 고려; R2R-Last/REVERIE/CVDN은 거리 감소만 사용).

### 핵심 설계 결정
- 시각 특징: 에이전트 작업 단계에서는 ImageNet 사전 학습 ViT 사용; RxR 실험에서는 CLIP 특징 사용(엔드투엔드 아님); REVERIE에서는 R2R 엔드투엔드 최적화 ViT로 객체 특징 추출.
- 구조 변형: 인코더-디코더 변형(텍스트-시각 교차 모달 어텐션 제거)은 긴 지시문 작업(R4R, RxR)에서 더 효율적.
- 옵티마이저: AdamW; RandAugment 및 stochastic depth로 과적합 방지.

## 핵심 혁신

1. **명시적 계층 히스토리 인코딩**: 궤적 히스토리를 전역 토큰 시퀀스로 인코딩하여 텍스트 및 현재 관측과 병렬로 교차 모달 어텐션에 참여. 순환 상태나 시간 인코딩만 사용하는 방식과 비교하여, 계층적 방식은 R2R-Back에서 val unseen SPL을 37.7에서 51.7로 향상(e2e 없이)시켜 장기 정보를 효과적으로 보존함을 증명.
2. **2단계 엔드투엔드 훈련**: 단일 단계 엔드투엔드가 아닌 에이전트 작업 사전 학습 후 RL 미세 조정. 단일 단계 25k 반복 후 SPL은 53.5에 불과하여 엔드투엔드 없는 56.5보다 오히려 낮았으며, 이는 VLN 데이터가 제한적일 때 점진적 훈련이 더 안정적임을 시사.
3. **SPREL 자기 지도 작업**: 파노라마 공간 관계 예측을 통해 보지 못한 환경에 대한 일반화 능력 향상. 절제 실험에서 SPREL 추가 시 val unseen SR이 64.5에서 65.7로 향상되었으며, SAP(R)과 상호 보완적.

### 핵심 결론
- 에이전트 작업 사전 학습은 처음부터 훈련하는 것보다 val unseen에서 SR이 상대적으로 16.7% 향상.
- ViT 엔드투엔드 훈련은 val unseen에서 SPL 2.1% 향상, 그러나 val seen에서는 0.8% 하락.
- 다국어 HAMT는 RxR 테스트 세트에서 SR이 2위보다 12.83% 높지만, 여전히 인간 성능에는 크게 미치지 못함.

## 경계 및 한계

- **REVERIE 객체 위치 파악 한계**: RGS 및 RGSPL이 테스트 세트에서 SOTA보다 낮음. 저자는 R2R 최적화 ViT로 객체 특징을 추출하여 객체 감지 사전 학습 특징보다 일반화가 떨어진다고 분석.
- **단일 단계 엔드투엔드 실패**: 25k 반복 시 오히려 엔드투엔드 없는 것보다 나쁨. VLN 데이터 양이 직접 엔드투엔드 훈련을 지원하기에 부족함을 시사.
- **추론 오버헤드**: HAMT는 RecBERT보다 1.5배 느림(104초 vs 69초), noT2V 변형은 1.1배 느림. 실시간 배포 시 트레이드오프 필요.
- **인간과의 격차**: RxR에서 다국어 HAMT와 인간 성능 간 격차가 여전히 크며, 논문은 구체적인 격차 수치를 정량화하지 않음.
- **수행하지 않은 것**: 연속 행동 VLN, 교차 데이터셋 전이의 상세 분석, 실제 로봇 배포 검증 미포함; 실패 사례 분석은 정성적으로만 언급(예: 주류 선반 인식 실패).

## 공학적 시사점

- **히스토리 인코딩 방식 먼저 확인**: 재현 시 계층적 히스토리 토큰의 집계 방식(전역 vs 로컬)이 논문과 일치하는지 반드시 확인. 이것이 성능 향상의 핵심. 시간 인코딩만 사용하면 R2R-Back에서 SPL이 약 9포인트 손실.
- **2단계 훈련은 건너뛸 수 없음**: 직접 엔드투엔드 훈련은 성능 하락(SPL 53.5 vs 56.5). 에이전트 작업 사전 학습의 순서와 샘플링 비율(5:2:2:1:1:1)을 엄격히 준수해야 함.
- **시각 특징 선택은 양날의 검**: ViT 엔드투엔드 최적화는 unseen에서 SPL 2.1% 향상, 그러나 seen에서 0.8% SPL 희생; REVERIE 작업에서는 객체 감지 사전 학습 모델로 객체 특징을 추출해야 하며, 그렇지 않으면 RGS가 뒤처짐.
- **RL+IL 둘 다 필수**: IL만 사용 시 SR 57.2, RL만 63.5, 공동 사용 시 65.7. 모방 학습은 안정적인 그래디언트를 제공하고 RL은 탐색을 담당하며 상호 보완적.
- **추론 시간 예산**: 지연 시간에 민감한 배포 시나리오에서는 noT2V 변형 사용(76초 vs 104초), 성능은 SR 1%만 손실되지만 긴 지시문 작업에서의 성능 확인 필요.
- **가장 함정에 빠지기 쉬운 부분**: 에이전트 작업에서 ITM의 네거티브 샘플링(2개 무작위 + 2개 시간 순서 섞기) 및 Noisy Contrastive Estimation 구현 세부 사항; R2R-Back의 보상은 2단계로 계산해야 함(먼저 원래 목표에 도달한 후 시작점으로 복귀), 그렇지 않으면 훈련이 불안정해짐.
