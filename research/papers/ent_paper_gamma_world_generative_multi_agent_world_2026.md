## 概述

Gamma-World 提出了一种生成式多智能体世界模型，支持两个以上玩家在共享环境中的同步、可控视频预测。其核心贡献在于引入置换对称的 Simplex Rotary Agent Encoding 和线性成本的 Sparse Hub Attention，并通过三阶段蒸馏（双向教师→因果学生→few-step 蒸馏）在保持流式推理能力的同时逼近双向模型的质量。该工作在 Minecraft 多智能体场景和真实机器人双臂任务上验证了有效性，并展示了零样本扩展到四智能体的能力。

## 它改变了什么

现有视频世界模型要么是单智能体设定，要么像 Solaris 那样通过密集联合注意力处理多玩家，但后者有两个结构性缺陷：一是计算成本随智能体数量二次增长，超过两个玩家后实时 rollout 基本不可行；二是它学习 per-slot ID 嵌入来区分玩家，这破坏了共享世界中智能体天然的可交换性（permutation symmetry），导致模型被绑定到固定玩家名单，无法在不重训的情况下扩展。Gamma-World 真正改变的是将多智能体世界建模从“固定双人、不可扩展”的框架中解放出来，它证明了可以同时满足三个此前被认为难以兼得的要求：独立可控（每个智能体有独立动作信号）、置换对称（模型不依赖玩家身份或顺序）、可扩展到两个以上玩家（架构和训练不随玩家数二次增长）。此外，它还解决了流式推理与生成质量之间的经典矛盾——通过蒸馏将双向模型的建模能力转移到因果流式架构中，这在多智能体场景下尤为重要，因为实时 rollout 是交互式模拟的基本前提。

## 方法拆解

### 问题形式化
学习函数 𝛾-World({𝑜^𝑝_{1:𝑡}}^𝑃_{𝑝=1}, {𝑎^𝑝_{1:𝑡}}^𝑃_{𝑝=1})，输入 𝑃 个智能体的过去观测和动作序列，输出每个智能体的下一观测。所有观测对应同一底层世界状态的不同视角。

### 基础架构
基于 DiT 的潜视频扩散 transformer，采用 flow-matching 目标：给定 z0、噪声 𝜖∼𝒩(0, I)、噪声水平 𝜎∈[0,1]，训练速度场 𝑣_𝜃 回归 𝜖−z0。潜序列划分为 𝑛 帧的时间块，每块独立采样噪声水平，块内双向注意力，块间因果。

### 关键设计决策
- **Simplex Rotary Agent Encoding**：将 3D RoPE 扩展为 4D（时间、智能体、高度、宽度），智能体表示为旋转角度空间中正则单纯形的顶点。顶点构造为 s_𝑣 = √(𝑉/(𝑉−1)) · Q(e_𝑣 − (1/𝑉)1)，满足所有智能体对等距（‖s_𝑣 − s_𝑣′‖²₂ = 2𝑉/(𝑉−1)），即置换等价。训练时随机分配活跃智能体到池中不同顶点，推理时从池中选额外顶点即可扩展玩家数，无需重训。
- **Sparse Hub Attention (SHA)**：添加少量可学习 hub token 作为紧凑共享通信状态。智能体 token 只 attend 到同智能体流和 hub token；hub token attend 到所有智能体和其他 hub token。跨智能体信息通过两跳路径（agent → hub → agent）流动。成本从 𝒪(𝑃²𝑛²𝐿²) 降至 𝒪(𝑃𝑛𝐿(𝑛𝐿+𝑛𝐾))，在智能体数 𝑃 上线性。
- **三阶段训练配方**：
  1. **双向教师**：密集双向注意力，单一共享噪声水平，训练高质量条件去噪模型。
  2. **因果学生**：块因果注意力 + SHA，每块独立噪声水平，作为完整多步扩散模型训练。
  3. **条件 Self-Forcing 蒸馏**：用 DMD 将多步因果学生蒸馏为 few-step 生成器，学生从多步因果模型初始化，教师提供高质量条件分布匹配信号。蒸馏时向教师和学生提供相同条件包（首帧观测和每智能体动作），防止偏离控制。

### 推理
蒸馏后的 few-step 学生每次生成一个时间块，以 24 FPS 流式输出。为每个智能体流维护独立 KV cache，hub token 维护共享 KV cache。

## 关键创新

1. **置换对称的智能体编码**：Simplex Rotary Agent Encoding 是第一个将智能体身份编码为旋转角度空间中正则单纯形顶点的方案。它无参数、置换对称、不引入学习到的 per-slot 身份，从根本上解决了 Solaris 中 per-slot ID 嵌入破坏对称性和不可扩展的问题。训练时随机分配顶点避免了 slot 特定过拟合，推理时从池中选额外顶点即可扩展玩家数，这是架构层面的零样本扩展能力。
2. **线性成本的跨智能体通信**：Sparse Hub Attention 通过少量 hub token 作为共享通信状态，将跨智能体注意力成本从二次降为线性。这不仅使超过两个玩家的实时 rollout 成为可能，还通过两跳信息流动路径（agent → hub → agent）保持了跨智能体信息交换的完整性，同时避免了密集 token 级成对交换的高昂代价。
3. **三阶段蒸馏配方**：与常见的“因果训练作为 few-step 蒸馏前短 warm-up”不同，因果学生作为完整多步扩散模型训练，在压缩前即可用多步采样产生合理自回归 rollout。这保证了蒸馏时学生已有良好的自回归基础，few-step 蒸馏只是压缩步数而非从头学习生成能力。条件 Self-Forcing 蒸馏确保 few-step 模型不偏离指定初始状态或动作控制。

## Overview

Gamma-World proposes a generative multi-agent world model that supports synchronized, controllable video prediction for more than two players in a shared environment. Its core contribution lies in introducing permutation-symmetric Simplex Rotary Agent Encoding and linear-cost Sparse Hub Attention, and through a three-stage distillation pipeline (bidirectional teacher → causal student → few-step distillation) it approaches the quality of bidirectional models while maintaining streaming inference capability. The work validates effectiveness on Minecraft multi-agent scenarios and real robot dual-arm tasks, and demonstrates zero-shot scalability to four agents.

## What It Changes

Existing video world models are either single-agent setups or, like Solaris, handle multiple players through dense joint attention—but the latter has two structural flaws: first, computational cost grows quadratically with the number of agents, making real-time rollout infeasible beyond two players; second, it learns per-slot ID embeddings to distinguish players, which breaks the natural permutation symmetry of agents in a shared world, binding the model to a fixed player roster and preventing extension without retraining. What Gamma-World truly changes is liberating multi-agent world modeling from the "fixed two-player, non-scalable" framework. It demonstrates that three requirements previously considered difficult to satisfy simultaneously can be met: independent controllability (each agent has its own action signal), permutation symmetry (the model does not depend on player identity or order), and scalability to more than two players (architecture and training do not grow quadratically with player count). Additionally, it resolves the classic tension between streaming inference and generation quality—by distilling the modeling capability of bidirectional models into a causal streaming architecture, which is especially important in multi-agent scenarios because real-time rollout is a fundamental prerequisite for interactive simulation.

## Method Breakdown

### Problem Formulation
Learn a function 𝛾-World({𝑜^𝑝_{1:𝑡}}^𝑃_{𝑝=1}, {𝑎^𝑝_{1:𝑡}}^𝑃_{𝑝=1}) that takes as input the past observations and action sequences of 𝑃 agents and outputs the next observation for each agent. All observations correspond to different views of the same underlying world state.

### Base Architecture
A DiT-based latent video diffusion transformer trained with a flow-matching objective: given z0, noise 𝜖∼𝒩(0, I), and noise level 𝜎∈[0,1], train a velocity field 𝑣_𝜃 to regress 𝜖−z0. The latent sequence is partitioned into temporal blocks of 𝑛 frames, each block samples an independent noise level, with bidirectional attention within blocks and causal attention across blocks.

### Key Design Decisions
- **Simplex Rotary Agent Encoding**: Extends 3D RoPE to 4D (time, agent, height, width), representing agents as vertices of a regular simplex in the space of rotation angles. Vertices are constructed as s_𝑣 = √(𝑉/(𝑉−1)) · Q(e_𝑣 − (1/𝑉)1), satisfying pairwise isometry across all agents (‖s_𝑣 − s_𝑣′‖²₂ = 2𝑉/(𝑉−1)), i.e., permutation equivariance. During training, active agents are randomly assigned to different vertices in the pool; at inference, additional vertices can be selected from the pool to extend the number of players without retraining.
- **Sparse Hub Attention (SHA)**: Adds a small number of learnable hub tokens as a compact shared communication state. Agent tokens attend only to tokens in their own agent stream and to hub tokens; hub tokens attend to all agents and other hub tokens. Cross-agent information flows through a two-hop path (agent → hub → agent). Cost is reduced from 𝒪(𝑃²𝑛²𝐿²) to 𝒪(𝑃𝑛𝐿(𝑛𝐿+𝑛𝐾)), linear in the number of agents 𝑃.
- **Three-Stage Training Recipe**:
  1. **Bidirectional Teacher**: Dense bidirectional attention with a single shared noise level, training a high-quality conditional denoising model.
  2. **Causal Student**: Block-causal attention + SHA with independent noise levels per block, trained as a full multi-step diffusion model.
  3. **Conditional Self-Forcing Distillation**: Uses DMD to distill the multi-step causal student into a few-step generator. The student is initialized from the multi-step causal model, and the teacher provides high-quality conditional distribution matching signals. During distillation, both teacher and student receive the same conditioning package (first-frame observation and per-agent actions) to prevent deviation from control.

### Inference
The distilled few-step student generates one temporal block at a time, streaming output at 24 FPS. Independent KV caches are maintained for each agent stream, while hub tokens maintain a shared KV cache.

## Key Innovations

1. **Permutation-Symmetric Agent Encoding**: Simplex Rotary Agent Encoding is the first scheme to encode agent identity as vertices of a regular simplex in the space of rotation angles. It is parameter-free, permutation-symmetric, and does not introduce learned per-slot identities, fundamentally solving the issues of broken symmetry and non-scalability caused by per-slot ID embeddings in Solaris. Random vertex assignment during training avoids slot-specific overfitting, and selecting additional vertices from the pool at inference enables player expansion—an architectural-level zero-shot scalability capability.
2. **Linear-Cost Cross-Agent Communication**: Sparse Hub Attention uses a small number of hub tokens as a shared communication state, reducing cross-agent attention cost from quadratic to linear. This not only makes real-time rollout with more than two players feasible but also preserves the completeness of cross-agent information exchange through a two-hop information flow path (agent → hub → agent), while avoiding the high cost of dense token-level pairwise exchange.
3. **Three-Stage Distillation Recipe**: Unlike the common approach of "causal training as a short warm-up before few-step distillation," the causal student is trained as a full multi-step diffusion model, capable of producing reasonable autoregressive rollouts via multi-step sampling before compression. This ensures the student already has a solid autoregressive foundation at distillation time; few-step distillation merely compresses the number of steps rather than learning generation capability from scratch. Conditional Self-Forcing distillation ensures the few-step model does not deviate from the specified initial state or action control.

## Boundaries and Limitations

The paper does not explicitly include a limitations statement, but inferences from the method details suggest: the simplex pool supports agent count expansion within a fixed rotary agent band (𝑉 ≤ 𝑑_𝑝/2 + 1), and very large populations may require larger bands or hierarchical agent grouping; the model does not explicitly enforce 3D geometric or physical constraints, so long rollouts may accumulate inconsistencies; evaluation focuses primarily on game environments and robot examples, with broader validation in more complex, heterogeneous, and long-horizon settings left for future work. Additionally, reproduction-critical details such as specific model size, training steps, batch size, learning rate, and data volume are not fully disclosed.

## Engineering Insights

When reproducing or adopting this method, first verify the relationship between simplex pool size 𝑉 and rotary agent band dimension 𝑑_𝑝 (𝑉 ≤ 𝑑_𝑝/2 + 1), which determines the maximum supported number of agents. The most likely pitfall is random vertex assignment during training—it is essential to randomly sample vertices and shuffle agent slot order at each training step; otherwise, the model degenerates into relying on slot positions rather than simplex markers to distinguish players. Second, the number of hub tokens K in Sparse Hub Attention requires ablation (K=8 is near-optimal in the paper; K=32/128 yield limited gains but increase computation), and hub tokens must reuse the temporal RoPE phase of their associated frames while using identity rotation across agent, height, and width bands. The key to the distillation stage is providing the same conditioning package (first-frame observation and per-agent actions) to both teacher and student; otherwise, the few-step model deviates from control. At inference, use a 4-step denoising schedule and do not use CFG (empirically, guidance-free sampling is more accurate). When extending a pretrained video DiT, follow ReRoPE to allocate the 𝑑_𝑝 dimension from the low-frequency end of the temporal band, leaving the high-frequency temporal and spatial bands unchanged.

## 개요

Gamma-World는 두 명 이상의 플레이어가 공유 환경에서 동기화되고 제어 가능한 비디오 예측을 지원하는 생성적 다중 에이전트 세계 모델을 제안한다. 핵심 기여는 치환 대칭(permutation symmetric) Simplex Rotary Agent Encoding과 선형 비용의 Sparse Hub Attention을 도입하고, 3단계 증류(양방향 교사 → 인과 학생 → few-step 증류)를 통해 스트리밍 추론 능력을 유지하면서 양방향 모델의 품질에 근접하는 것이다. 이 작업은 Minecraft 다중 에이전트 시나리오와 실제 로봇 이중 팔 작업에서 유효성을 검증했으며, 4개 에이전트로의 제로샷 확장 능력을 보여준다.

## 무엇을 바꾸었는가

기존 비디오 세계 모델은 단일 에이전트 설정이거나 Solaris처럼 밀집 결합 주의(dense joint attention)로 다중 플레이어를 처리하지만, 후자는 두 가지 구조적 결함이 있다. 첫째, 계산 비용이 에이전트 수에 따라 2차적으로 증가하여 두 명 이상의 플레이어에서 실시간 rollout이 사실상 불가능하다. 둘째, per-slot ID 임베딩을 학습하여 플레이어를 구분하는데, 이는 공유 세계에서 에이전트의 자연스러운 교환 가능성(permutation symmetry)을 파괴하여 모델이 고정된 플레이어 명단에 묶이게 되고 재훈련 없이는 확장할 수 없다. Gamma-World가 진정으로 바꾼 것은 다중 에이전트 세계 모델링을 "고정 2인, 확장 불가능"이라는 프레임워크에서 해방시킨 것이다. 이전에는 동시에 충족하기 어렵다고 여겨졌던 세 가지 요구 사항, 즉 독립적 제어(각 에이전트가 독립적인 행동 신호 보유), 치환 대칭(모델이 플레이어 정체성이나 순서에 의존하지 않음), 두 명 이상의 에이전트로 확장(아키텍처와 훈련이 에이전트 수에 따라 2차적으로 증가하지 않음)을 모두 충족할 수 있음을 증명했다. 또한 스트리밍 추론과 생성 품질 사이의 고전적 모순도 해결했다. 증류를 통해 양방향 모델의 모델링 능력을 인과 스트리밍 아키텍처로 전이하는데, 이는 실시간 rollout이 대화형 시뮬레이션의 기본 전제이므로 다중 에이전트 시나리오에서 특히 중요하다.

## 방법 분해

### 문제 형식화
함수 𝛾-World({𝑜^𝑝_{1:𝑡}}^𝑃_{𝑝=1}, {𝑎^𝑝_{1:𝑡}}^𝑃_{𝑝=1})를 학습한다. 입력은 𝑃개 에이전트의 과거 관측 및 행동 시퀀스이고, 출력은 각 에이전트의 다음 관측이다. 모든 관측은 동일한 기본 세계 상태의 서로 다른 관점에 해당한다.

### 기본 아키텍처
DiT 기반 잠재 비디오 확산 transformer로, flow-matching 목표를 사용한다: z0, 노이즈 𝜖∼𝒩(0, I), 노이즈 수준 𝜎∈[0,1]이 주어졌을 때, 속도장 𝑣_𝜃가 𝜖−z0을 회귀하도록 훈련한다. 잠재 시퀀스는 𝑛 프레임의 시간 블록으로 분할되며, 각 블록은 독립적으로 노이즈 수준을 샘플링하고, 블록 내부는 양방향 주의, 블록 간은 인과적이다.

### 핵심 설계 결정
- **Simplex Rotary Agent Encoding**: 3D RoPE를 4D(시간, 에이전트, 높이, 너비)로 확장하고, 에이전트는 회전 각도 공간에서 정칙 단체(regular simplex)의 꼭짓점으로 표현된다. 꼭짓점은 s_𝑣 = √(𝑉/(𝑉−1)) · Q(e_𝑣 − (1/𝑉)1)로 구성되며, 모든 에이전트 쌍이 등거리(‖s_𝑣 − s_𝑣′‖²₂ = 2𝑉/(𝑉−1))를 만족하므로 치환 등가이다. 훈련 시 활성 에이전트를 풀의 서로 다른 꼭짓점에 무작위로 할당하고, 추론 시 풀에서 추가 꼭짓점을 선택하여 재훈련 없이 플레이어 수를 확장할 수 있다.
- **Sparse Hub Attention (SHA)**: 소수의 학습 가능한 hub token을 컴팩트한 공유 통신 상태로 추가한다. 에이전트 token은 동일 에이전트 스트림과 hub token에만 주의를 기울이고, hub token은 모든 에이전트와 다른 hub token에 주의를 기울인다. 에이전트 간 정보는 두 홉 경로(agent → hub → agent)를 통해 흐른다. 비용은 𝒪(𝑃²𝑛²𝐿²)에서 𝒪(𝑃𝑛𝐿(𝑛𝐿+𝑛𝐾))로 감소하여 에이전트 수 𝑃에 대해 선형이다.
- **3단계 훈련 레시피**:
  1. **양방향 교사**: 밀집 양방향 주의, 단일 공유 노이즈 수준, 고품질 조건부 노이즈 제거 모델 훈련.
  2. **인과 학생**: 블록 인과 주의 + SHA, 각 블록 독립 노이즈 수준, 완전한 다단계 확산 모델로 훈련.
  3. **조건부 Self-Forcing 증류**: DMD를 사용하여 다단계 인과 학생을 few-step 생성기로 증류한다. 학생은 다단계 인과 모델에서 초기화되고, 교사는 고품질 조건부 분포 정합 신호를 제공한다. 증류 시 교사와 학생에게 동일한 조건 패키지(첫 프레임 관측 및 각 에이전트 행동)를 제공하여 제어에서 벗어나는 것을 방지한다.

### 추론
증류된 few-step 학생은 각 시간 블록을 생성하며 24 FPS로 스트리밍 출력한다. 각 에이전트 스트림에 대해 독립적인 KV cache를 유지하고, hub token은 공유 KV cache를 유지한다.

## 핵심 혁신

1. **치환 대칭 에이전트 인코딩**: Simplex Rotary Agent Encoding은 에이전트 정체성을 회전 각도 공간의 정칙 단체 꼭짓점으로 인코딩하는 최초의 방식이다. 파라미터가 없고 치환 대칭이며 학습된 per-slot 정체성을 도입하지 않아 Solaris에서 per-slot ID 임베딩이 대칭성을 파괴하고 확장 불가능한 문제를 근본적으로 해결한다. 훈련 시 꼭짓점을 무작위로 할당하여 slot 특정 과적합을 방지하고, 추론 시 풀에서 추가 꼭짓점을 선택하여 플레이어 수를 확장할 수 있는 아키텍처 수준의 제로샷 확장 능력이다.
2. **선형 비용의 에이전트 간 통신**: Sparse Hub Attention은 소수의 hub token을 공유 통신 상태로 사용하여 에이전트 간 주의 비용을 2차에서 선형으로 낮춘다. 이는 두 명 이상의 플레이어에서 실시간 rollout을 가능하게 할 뿐만 아니라, 두 홉 정보 흐름 경로(agent → hub → agent)를 통해 에이전트 간 정보 교환의 완전성을 유지하면서 밀집 token 수준의 쌍별 교환의 높은 비용을 피한다.
3. **3단계 증류 레시피**: 일반적인 "인과 훈련을 few-step 증류 전 짧은 warm-up으로 사용"과 달리, 인과 학생은 완전한 다단계 확산 모델로 훈련되어 압축 전에 다단계 샘플링으로 합리적인 자기회귀 rollout을 생성할 수 있다. 이는 증류 시 학생이 이미 좋은 자기회귀 기반을 갖추고 있으며, few-step 증류는 처음부터 생성 능력을 학습하는 것이 아니라 단계 수를 압축하는 것임을 보장한다. 조건부 Self-Forcing 증류는 few-step 모델이 지정된 초기 상태나 행동 제어에서 벗어나지 않도록 보장한다.

## 경계 및 한계

논문은 명시적인 한계 선언을 언급하지 않았지만, 방법 세부 사항에서 추론할 수 있다: 단체 풀은 고정 회전 에이전트 대역 내에서 에이전트 수 확장을 지원하며(𝑉 ≤ 𝑑_𝑝/2 + 1), 매우 큰 그룹은 더 큰 대역이나 계층적 에이전트 그룹화가 필요할 수 있다; 모델은 3D 기하학이나 물리적 제약을 명시적으로 강제하지 않아 긴 rollout에서 불일치가 누적될 수 있다; 평가는 주로 게임 환경과 로봇 예시에 집중되어 있으며, 더 복잡하고 이질적이며 장기적인 설정에서의 광범위한 검증은 향후 작업으로 남겨진다. 또한 구체적인 모델 크기, 훈련 단계 수, batch size, 학습률, 데이터 양 등 재현에 중요한 세부 사항이 완전히 공개되지 않았다.

## 공학적 시사점

이 방법을 재현하거나 채택할 때, 먼저 단체 풀 크기 𝑉와 회전 에이전트 대역 차원 𝑑_𝑝의 관계(𝑉 ≤ 𝑑_𝑝/2 + 1)를 확인해야 한다. 이는 최대 지원 가능한 에이전트 수를 결정한다. 가장 함정에 빠지기 쉬운 부분은 훈련 시 무작위 꼭짓점 할당이다. 각 훈련 단계에서 꼭짓점을 무작위로 샘플링하고 에이전트 슬롯 순서를 섞어야 하며, 그렇지 않으면 모델이 단체 표식이 아닌 slot 위치에 의존하여 플레이어를 구분하는 것으로 퇴화한다. 둘째, Sparse Hub Attention의 hub token 수 K는 소거가 필요하다(논문에서 K=8이 이미 최적에 가깝고, K=32/128은 개선이 제한적이지만 계산을 증가시킨다). 또한 hub token은 관련 프레임의 시간 RoPE 위상을 재사용해야 하며, 에이전트, 높이, 너비 대역에서는 항등 회전을 사용한다. 증류 단계의 핵심은 교사와 학생에게 동일한 조건 패키지(첫 프레임 관측 및 각 에이전트 행동)를 제공하는 것이며, 그렇지 않으면 few-step 모델이 제어에서 벗어난다. 추론 시 4단계 노이즈 제거 스케줄을 사용하고 CFG를 사용하지 않는다(경험적으로 무유도 샘플링이 더 정확함). 사전 훈련된 비디오 DiT를 확장할 때는 ReRoPE를 따라 시간 대역의 저주파 끝에서 𝑑_𝑝 차원을 할당하고, 고주파 시간 및 공간 대역은 변경하지 않는다.
