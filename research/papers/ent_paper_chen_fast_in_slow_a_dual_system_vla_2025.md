## 概述

FiS-VLA 提出一种双系统 VLA 架构，将完整 7B VLM 的末端 transformer 块复用为高频动作生成模块（System 1），与低频推理模块（System 2）共享同一骨干网络，实现 21.9 Hz 的仿真控制频率与 69% 平均成功率。核心贡献在于打破先前双系统方法中 System 1 作为独立轻量模型的范式，通过参数共享与双感知协同训练，在保留互联网规模预训练知识的同时实现实时执行。

## 它改变了什么

现有双系统 VLA 方法（如 Helix、HIRT）将 System 1 设计为独立轻量模型，仅依赖 System 2 提取的特征表示，导致快速执行模块无法直接利用 VLM 的互联网规模预训练知识。FiS-VLA 改变了这一设计假设：与其在 VLM 之外附加策略头，不如直接复用 VLM 自身的 transformer 块作为执行模块，使两个系统源自同一基础模型。这一改动看似简单，实则解决了双系统架构中最根本的“知识割裂”问题——System 1 不再需要从零学习视觉-语言对齐，而是继承 System 2 已编码的语义理解。

该方法的真正价值在于重新定义了双系统的耦合方式。先前方法将 System 1 视为 System 2 的“下游消费者”，而 FiS-VLA 将 System 1 视为 System 2 的“内部子例程”，通过共享参数实现无缝协调。这种设计不仅消除了独立 System 1 的参数量开销，还使得高频执行路径天然具备 VLM 的推理先验，在未见物体、复杂背景等泛化场景中表现出更强的鲁棒性。

## 方法拆解

### 架构设计
- 骨干网络：7B LLaMA2（32 个 transformer 块），基于 Prismatic VLM 初始化
- 视觉编码：SigLIP（f_SigLIP ∈ ℝ^(N_v×1024)）与 DINOv2（f_DINO ∈ ℝ^(N_v×1152)）沿通道拼接，输入图像 resize 至 224×224
- 点云编码：轻量级 3D tokenizer（最远点采样 + k 近邻聚合 + 可学习线性层），点云下采样至 1024 点，经共享视觉编码器投影到 LLM 嵌入空间
- System 2：完整 VLM 负责高层推理，接收语言指令与 2D 图像，自回归生成离散动作 token 或语言计划
- System 1：复用 System 2 末端 2 个 transformer 块，接收 2D 图像、3D 点云、机器人状态及 System 2 的周期性潜在特征，通过扩散模型生成连续动作

### 双系统协调
- 异步频率：System 2 低频运行（处理 2D 图像与语言指令），System 1 高频运行（每时间步生成动作），频率比 1:n（n 为动作 horizon 长度）
- 异构模态：System 2 仅用 2D 视觉与语言（利用互联网预训练），System 1 额外接收 3D 点云与机器人状态（保证执行精度）
- 训练时异步采样降低 System 2 频率，鼓励 System 1 保持任务理解的时间一致性

### 双感知协同训练
- System 1 扩散损失：L_fast = E[||η − π_θf(√β_τ ã + √(1−β_τ) η, c, τ)||²]，其中 τ ~ U(1, T)，T=100，β_τ 为噪声调度
- System 2 自回归损失：L_slow = −Σ log P(â_i | context, θ)，监督信号可为离散动作或语言计划
- 总目标：L_FiS-VLA = L_fast + L_slow，联合训练防止灾难性遗忘 System 2 的推理能力

### 预训练与微调
- 预训练：Open X-Embodiment、DROID、ROBOMIND 等 37 个数据集，860K 轨迹，5 epochs，仅用单视角 RGB
- 微调：仿真每任务 100 条轨迹，300 epochs，AdamW，8×A800 GPU，混合精度；真实世界每任务 100 条演示

## 关键创新

1. **参数级双系统融合**：将 System 1 嵌入 System 2 的 transformer 块中，而非附加独立策略头。这是首个在参数层面统一快慢系统的 VLA 方法，使得高频执行路径直接继承 VLM 的预训练知识，避免了独立 System 1 的知识瓶颈。

2. **异构模态分工设计**：System 2 仅处理 2D 图像与语言（充分利用互联网预训练），System 1 额外接收 3D 点云与机器人状态（保证执行精度）。这种模态分工既保留了 VLM 的语义理解能力，又通过 3D 信息增强了空间操作精度，消融实验显示点云贡献 8% 成功率提升（由表内 0.69→0.61 计算）。

3. **双感知协同训练策略**：同时优化扩散动作生成与自回归推理目标，通过联合训练防止 System 2 推理能力退化。移除 L_slow 时性能从 69% 降至 62%，验证了协同训练的必要性。

## 实验与结果

### 仿真实验（RLBench，10 任务）
| 模型 | Mean S.R. | Infer. speed |
|---|---|---|
| ManipLLM | 0.38 ± 0.04 | 2.2 Hz |
| OpenVLA | 0.40 ± 0.04 | 6.3 Hz |
| π₀ | 0.55 ± 0.03 | 13.8 Hz |
| CogACT | 0.61 ± 0.04 | 9.8 Hz |
| FiS-VLA | 0.69 ± 0.03 | 21.9 Hz |

FiS-VLA 平均成功率超过 CogACT 8%、π₀ 14%，控制频率比 CogACT 快 2 倍以上、比 π₀ 快 1.6 倍以上（action chunk=1）。π₀ 使用 2.6B 参数 LLM，CogACT 与 FiS-VLA 均基于 7B 参数。

### 消融实验
- 共享块数：2 块时性能饱和（0.69），1 块仅 0.49，4 块 0.66，8 块 0.64
- 模态输入：完整输入 0.69，去点云 0.61，去点云+图像 0.44，去全部 0.22
- 频率比：1:4 最优（0.69），1:1 为 0.60，1:8 为 0.61
- 训练策略：移除 L_slow 降至 62%

### 真实世界实验
| 平台 | π₀ Mean S.R. | FiS-VLA Mean S.R. |
|---|---|---|
| Agilex | 0.59 | 0.68 |
| AlphaBot | 0.61 | 0.74 |

泛化实验（未见物体）：AlphaBot 上 FiS-VLA 下降 19%，π₀ 下降 38%；复杂背景：FiS-VLA 下降 25%，π₀ 下降 38%；光照变化：FiS-VLA 成功率均超 50%。

### 推理频率
action chunk=8 时理论控制频率达 117.7 Hz（NVIDIA 4090 GPU）。

## 边界与局限

- 硬件限制：机器人平台不支持双系统并行推理（不同于 Helix），频率比受限于单 GPU 部署，并行推理可进一步提升速度但未实现
- 预训练数据无子目标级语言指令，需在微调阶段手动标注子任务计划
- 静态配置 System 1 共享块数与频率比，未实现基于任务复杂度的动态适应
- 真实世界失败案例：双臂交接碰撞、薄物体高度预测误差、位置预测错误、交接旋转误差
- 论文未明确 System 2 推理延迟的具体数值，以及不同频率比下 System 2 的计算开销

## 工程启示

复现时优先核对三个关键点：一是 System 1 共享块数必须设为 2（1 块性能骤降至 0.49，4 块以上反而下降）；二是频率比严格设为 1:4（1:1 与 1:8 均显著退化）；三是点云输入不可省略（去除后成功率从 0.69 降至 0.61）。训练时注意预训练阶段仅用单视角 RGB，微调阶段才引入多视角与点云，模态切换可能导致分布偏移。真实世界部署时，Agilex 用末端执行器位姿控制（14-DoF），AlphaBot 用关节位置控制（16-DoF），需根据平台调整动作空间编码。最易踩坑的是点云生成依赖外部视角深度图与相机内外参标定，标定误差会直接影响 System 1 的执行精度。

## 개요
Fast-in-Slow (FiS)는 카너먼의 이중 시스템 이론을 차용하여 통합된 이중 시스템 비전-언어-행동 모델을 제안한다. 기존 방법은 고수준 추론을 담당하는 VLM 기반 System 2와 실시간 제어를 담당하는 독립적인 System 1을 분리하여, System 1이 VLM의 사전 학습 지식을 충분히 활용하지 못하는 문제가 있었다. FiS는 System 1 실행 모듈을 System 2 내부에 내장하고 일부 파라미터를 공유함으로써, 고주파 실행을 달성하면서도 추론과 실행 구성 요소 간의 협력을 촉진한다. 이 모델은 두 시스템을 위해 이질적 모달리티 입력과 비동기 실행 주파수를 설계하고, 이중 인식 협력 훈련 전략을 채택하여 System 1이 행동 생성 능력을 획득하는 동시에 System 2의 맥락 추론 표현을 보존한다.

## 핵심 내용
### 방법 아키텍처
- **이중 시스템 설계**: FiS-VLA는 빠른 실행 모듈(System 1)을 VLM 기반의 느린 추론 시스템(System 2) 내부에 내장하고, 부분 파라미터 공유를 통해 통합 아키텍처를 구현한다. System 2는 고수준 의미 추론과 작업 계획을 담당하고, System 1은 실시간 행동 생성을 담당한다.
- **이질적 모달리티 입력**: 두 시스템은 서로 다른 입력 모달리티를 사용한다—System 2는 전역 시각 및 언어 명령을 처리하고, System 1은 국소 인식 정보와 고주파 센서 데이터를 수신하여 각자의 기능적 요구에 적응한다.
- **비동기 실행 주파수**: System 2는 낮은 주파수(예: 5-10 Hz)로 추론하고, System 1은 높은 주파수(117.7 Hz)로 행동을 실행하며, 행동 블록 크기는 8로 설정된다.

### 훈련 전략
- **이중 인식 협력 훈련**: System 1이 행동 생성 능력을 획득하면서도 System 2의 맥락 추론 표현을 손상시키지 않는 공동 훈련 방법을 제안한다. 이 전략은 공유 파라미터의 그래디언트 전파를 통해 두 시스템이 훈련 과정에서 서로 방해하지 않고 상호 촉진하도록 보장한다.

### 실험 설정 및 결과
- **시뮬레이션 환경**: 여러 표준 로봇 조작 벤치마크에서 테스트한 결과, FiS-VLA의 평균 성공률이 이전 최고 방법보다 8% 향상되었다.
- **실세계 작업**: 실제 로봇 플랫폼에서 다양한 조작 작업(예: 파지, 배치, 조립)을 수행하여 평균 성공률이 11% 향상되었다.
- **제어 주파수**: 행동 블록 크기가 8인 조건에서 117.7 Hz의 제어 주파수를 달성하여 실시간 조작 요구를 충족한다.
- **절제 실험**: 파라미터 공유 전략, 이질적 모달리티 입력, 비동기 주파수 설계가 성능에 기여하는 바를 검증했으며, 각 구성 요소가 유의미한 향상을 가져왔다.

### 결론
FiS-VLA는 통합된 이중 시스템 아키텍처를 통해 로봇 조작에서 일반화 정책과 실행 효율성 간의 모순을 효과적으로 해결하며, 시뮬레이션과 실제 시나리오 모두에서 선도적인 성능을 달성하면서 고주파 실시간 제어 능력을 유지한다. 프로젝트 페이지: fast-in-slow.github.io.
