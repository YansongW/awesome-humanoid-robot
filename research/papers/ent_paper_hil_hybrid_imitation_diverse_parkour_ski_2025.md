## 概述

本文提出混合模仿学习（Hybrid Imitation Learning, HIL）框架，用于从互联网视频中学习多样化跑酷技能并部署到物理仿真人形机器人上。该方法联合训练运动跟踪与对抗模仿学习两种模式，在统一观测空间下实现高保真技能复现与灵活场景适应，显著缓解了模式崩溃问题并提升了技能多样性。

## 它改变了什么

跑酷控制的核心矛盾在于：运动跟踪能精确复现技能但无法适应新环境，对抗模仿学习（AMP）灵活但易模式崩溃。现有方法要么牺牲多样性换取精度，要么牺牲自然度换取适应性，无法同时满足"精确复现"与"灵活组合"这两个需求。HIL 的真正贡献在于打破了这种二选一的困境——它不是简单地将两种方法拼接，而是通过统一观测空间和共享策略网络，让运动跟踪的精确性"注入"对抗学习，同时让对抗学习的灵活性"反哺"跟踪模式。这改变了该领域"方法对立"的思维定式，证明两种范式可以互补而非互斥。

## 方法拆解

### 双任务并行训练框架
- **运动跟踪模式**：精确复现参考运动，学习基础技能（vaults、plyos等），奖励函数包含位置、旋转、线速度、角速度、根高度五项指数误差项加能量惩罚项
- **对抗模仿模式**：基于AMP，判别器接收10步状态转移和场景点云，输出风格奖励，鼓励自然运动与场景适配

### 统一观测空间设计
- **角色状态**：s_t = (h_t, p_t, q_t, ṗ_t, q̇_t)，根为骨盆，局部坐标系x轴沿根链接朝向
- **场景表示**：以角色为中心的最近N个点云点，作为空间"相位"变量替代时间相位
- **关键决策**：运动跟踪任务中不使用时间相位或未来目标姿态（目标跟随任务中不可用），而是用场景观测推断当前相位，使两种模式共享同一观测空间

### 奖励设计
- **跟踪奖励**（公式2）：r_t^track = w_p e^{-α_p||p̂_t - p_t||} + w_r e^{-α_r||q̂_t ⊖ q_t||} + w_v e^{-α_v||ṗ̂_t - ṗ_t||} + w_ω e^{-α_ω||q̇̂_t - q̇_t||} + w_h e^{-α_h||ĥ_t - h_t||} + w_e Σ_j ||τ_j q̇_j||
- **目标奖励**（公式3）：r_t^target = ||p_{t-1}^root - g_{t-1}|| - ||p_t^root - g_t|| + r_t^reach，截断到[0, 0.05]防止不自然行为
- **风格奖励**：r_t^style = -log(1 - D(s_{t-n:t}, c_{t-n:t}))，跟踪模式中也加入相同权重风格奖励以桥接两种模式

### 网络架构
- **策略**：Transformer（潜在维度256，2层，2头），PointNet编码场景点云，两个MLP编码角色状态和目标位置
- **评论家**：MLP [1024, 512]，额外输入任务指示变量k（privileged information，仅训练时使用）
- **判别器**：MLP [1024, 512]，输入10步状态转移和场景点云，含梯度惩罚项

### 训练策略
- 先在运动跟踪任务上训练40亿样本（warm start），再双任务并行训练20亿样本
- 扰动状态初始化（PSI）：对参考运动初始状态施加高斯噪声，不仅提高完成率还缓解模式崩溃
- 提前终止：跟踪模式偏离参考运动超0.5米终止；对抗模式摔倒或错过目标超2米终止

## 关键创新

1. **统一观测空间替代时间相位**：在运动跟踪任务中用场景点云作为空间相位变量，使两种模式共享同一观测空间，避免朴素条件输入掩码导致的行为模式分裂。这是实现混合训练的关键设计，也是此前方法未解决的痛点。

2. **场景感知判别器**：将场景点云输入判别器，使其不仅判断运动是否自然，还判断运动是否适应当前场景上下文。这直接缓解了AMP的模式崩溃问题——判别器能惩罚"用同一动作应对所有障碍"的行为。

3. **双模式联合训练而非级联**：先warm start运动跟踪，再并行训练两种模式，让跟踪的精确性"注入"对抗学习，同时让对抗的灵活性"反哺"跟踪。这种训练策略使模型既能精确执行单个技能，又能灵活组合技能序列。

## 边界与局限

- 生成运动偶尔出现伪影（如绊倒障碍物时的不自然恢复行为）
- 假设障碍物按顺序排列，无法泛化到非线性布局的复杂环境
- 对运动数据集中未充分表示的障碍物类型或布局适应困难
- 训练时不施加扰动，仅在评估时引入噪声，未测试训练中数据增强的效果
- 论文未明确提及计算效率、推理速度或实时性评估

## 工程启示

- **复现优先级**：先核对PSI的实现细节——它对任务完成率影响最大（移除后从0.74降至0.52），且作者明确说明其缓解模式崩溃的机制
- **最易踩坑**：判别器的场景信息输入不可省略（移除后技能准确率从0.66降至0.38），但需注意场景点云与状态转移的拼接方式——判别器输入是展平拼接，维度设计需仔细核对
- **训练预算**：总训练量60亿样本（40亿warm start + 20亿联合训练），4块V100，需评估是否可接受；若资源有限可先尝试减少warm start样本量观察影响
- **评估指标**：技能准确率通过DTW距离匹配最相似参考运动判断，跟踪误差为DTW距离归一化除以1000——复现时需确保DTW实现与作者一致（边界条件、连续性和单调性约束）
- **数据管线**：视频运动提取需使用TRAM + 身体朝向提示细化 + 交互式场景标注工具 + 基于物理的运动跟踪器（Tessler et al. 2024）细化，这条管线是数据质量的关键，建议优先复现

## Overview

This paper proposes a Hybrid Imitation Learning (HIL) framework for learning diverse parkour skills from internet videos and deploying them on physically simulated humanoid robots. The method jointly trains two modes—motion tracking and adversarial imitation learning—within a unified observation space, achieving high-fidelity skill reproduction and flexible scene adaptation while significantly mitigating mode collapse and enhancing skill diversity.

## What It Changes

The core challenge in parkour control lies in a trade-off: motion tracking can precisely reproduce skills but fails to adapt to new environments, while Adversarial Motion Priors (AMP) is flexible but prone to mode collapse. Existing methods either sacrifice diversity for accuracy or sacrifice naturalness for adaptability, failing to simultaneously satisfy the dual requirements of "precise reproduction" and "flexible combination." The true contribution of HIL is breaking this either-or dilemma—it is not a simple concatenation of the two methods, but rather, through a unified observation space and shared policy network, it allows the precision of motion tracking to "inject" into adversarial learning while enabling the flexibility of adversarial learning to "feed back" into the tracking mode. This shifts the field's mindset of "methodological opposition," demonstrating that the two paradigms can complement rather than exclude each other.

## Method Breakdown

### Dual-Task Parallel Training Framework
- **Motion Tracking Mode**: Precisely reproduces reference motions and learns basic skills (vaults, plyos, etc.). The reward function includes five exponential error terms—position, rotation, linear velocity, angular velocity, and root height—plus an energy penalty term.
- **Adversarial Imitation Mode**: Based on AMP, the discriminator receives 10-step state transitions and scene point clouds, outputting a style reward that encourages natural motion and scene adaptation.

### Unified Observation Space Design
- **Character State**: s_t = (h_t, p_t, q_t, ṗ_t, q̇_t), with the root at the pelvis and the local coordinate system's x-axis aligned with the root link's facing direction.
- **Scene Representation**: The nearest N point cloud points centered on the character, serving as a spatial "phase" variable instead of a temporal phase.
- **Key Decision**: The motion tracking task does not use temporal phase or future target poses (unavailable in target-following tasks); instead, it infers the current phase from scene observations, enabling both modes to share the same observation space.

### Reward Design
- **Tracking Reward** (Equation 2): r_t^track = w_p e^{-α_p||p̂_t - p_t||} + w_r e^{-α_r||q̂_t ⊖ q_t||} + w_v e^{-α_v||ṗ̂_t - ṗ_t||} + w_ω e^{-α_ω||q̇̂_t - q̇_t||} + w_h e^{-α_h||ĥ_t - h_t||} + w_e Σ_j ||τ_j q̇_j||
- **Target Reward** (Equation 3): r_t^target = ||p_{t-1}^root - g_{t-1}|| - ||p_t^root - g_t|| + r_t^reach, clipped to [0, 0.05] to prevent unnatural behavior.
- **Style Reward**: r_t^style = -log(1 - D(s_{t-n:t}, c_{t-n:t})), also added with the same weight in the tracking mode to bridge the two modes.

### Network Architecture
- **Policy**: Transformer (latent dimension 256, 2 layers, 2 heads), PointNet encodes scene point clouds, and two MLPs encode character state and target position.
- **Critic**: MLP [1024, 512], with an additional task indicator variable k as input (privileged information, used only during training).
- **Discriminator**: MLP [1024, 512], takes 10-step state transitions and scene point clouds as input, including a gradient penalty term.

### Training Strategy
- First train on the motion tracking task for 4 billion samples (warm start), then jointly train both tasks for 2 billion samples.
- Perturbed State Initialization (PSI): Applies Gaussian noise to the initial states of reference motions, improving completion rates and mitigating mode collapse.
- Early Termination: The tracking mode terminates if deviation from the reference motion exceeds 0.5 meters; the adversarial mode terminates upon falling or missing the target by more than 2 meters.

## Key Innovations

1. **Unified Observation Space Replacing Temporal Phase**: In the motion tracking task, scene point clouds serve as spatial phase variables, allowing both modes to share the same observation space and avoiding behavioral mode splitting caused by naive conditional input masking. This is a key design enabling hybrid training and an unresolved pain point in prior methods.

2. **Scene-Aware Discriminator**: Feeding scene point clouds into the discriminator enables it to judge not only whether the motion is natural but also whether it adapts to the current scene context. This directly alleviates AMP's mode collapse issue—the discriminator can penalize behaviors that use the same action for all obstacles.

3. **Joint Training of Dual Modes Rather Than Cascading**: Warm-starting with motion tracking and then training both modes in parallel allows the precision of tracking to "inject" into adversarial learning while the flexibility of adversarial learning "feeds back" into tracking. This training strategy enables the model to both precisely execute individual skills and flexibly combine skill sequences.

## Boundaries and Limitations

- Generated motions occasionally exhibit artifacts (e.g., unnatural recovery behaviors when tripping over obstacles).
- Assumes obstacles are arranged sequentially and cannot generalize to complex environments with non-linear layouts.
- Difficulty adapting to obstacle types or layouts underrepresented in the motion dataset.
- No perturbations are applied during training; noise is only introduced during evaluation, leaving the effect of training-time data augmentation untested.
- The paper does not explicitly mention computational efficiency, inference speed, or real-time evaluation.

## Engineering Insights

- **Reproduction Priority**: First verify the implementation details of PSI—it has the greatest impact on task completion rate (dropping from 0.74 to 0.52 when removed), and the authors explicitly describe its mechanism for mitigating mode collapse.
- **Most Likely Pitfall**: The discriminator's scene information input cannot be omitted (skill accuracy drops from 0.66 to 0.38 when removed), but attention must be paid to how scene point clouds and state transitions are concatenated—the discriminator input is flattened and concatenated, so dimension design requires careful verification.
- **Training Budget**: Total training volume is 6 billion samples (4 billion warm start + 2 billion joint training) on 4 V100 GPUs; assess whether this is acceptable. If resources are limited, consider reducing warm-start samples first to observe the impact.
- **Evaluation Metrics**: Skill accuracy is determined by matching the most similar reference motion via DTW distance, and tracking error is the DTW distance normalized by dividing by 1000—ensure the DTW implementation matches the authors' (boundary conditions, continuity, and monotonicity constraints) during reproduction.
- **Data Pipeline**: Video motion extraction requires TRAM + body orientation hint refinement + interactive scene annotation tools + physics-based motion tracker refinement (Tessler et al. 2024). This pipeline is key to data quality and is recommended for priority reproduction.

## 개요

본 논문은 인터넷 비디오에서 다양한 파쿠르 기술을 학습하고 물리 시뮬레이션 휴머노이드 로봇에 배포하기 위한 하이브리드 모방 학습(Hybrid Imitation Learning, HIL) 프레임워크를 제안한다. 이 방법은 모션 트래킹과 적대적 모방 학습의 두 가지 모드를 공동 훈련하여 통합 관측 공간에서 고충실도 기술 재현과 유연한 환경 적응을 구현하고, 모드 붕괴 문제를 크게 완화하며 기술 다양성을 향상시킨다.

## 그것이 바꾸는 것

파쿠르 제어의 핵심 모순은 모션 트래킹이 기술을 정밀하게 재현할 수 있지만 새로운 환경에 적응하지 못하고, 적대적 모방 학습(AMP)은 유연하지만 모드 붕괴에 취약하다는 점이다. 기존 방법은 다양성을 희생하여 정밀도를 얻거나, 자연스러움을 희생하여 적응성을 얻어야 했으며, "정밀한 재현"과 "유연한 조합"이라는 두 요구를 동시에 충족할 수 없었다. HIL의 진정한 기여는 이러한 이분법적 선택의 딜레마를 깨뜨린 것이다. 단순히 두 방법을 결합하는 것이 아니라, 통합 관측 공간과 공유 정책 네트워크를 통해 모션 트래킹의 정밀성을 적대적 학습에 "주입"하고, 적대적 학습의 유연성을 트래킹 모드에 "환류"시킨다. 이는 해당 분야의 "방법 대립"이라는 사고방식을 바꾸어, 두 패러다임이 상호 배타적이 아니라 상호 보완적일 수 있음을 증명한다.

## 방법 분석

### 이중 작업 병렬 훈련 프레임워크
- **모션 트래킹 모드**: 참조 모션을 정밀하게 재현하여 기본 기술(vaults, plyos 등)을 학습하며, 보상 함수는 위치, 회전, 선속도, 각속도, 루트 높이의 5가지 지수 오차 항목과 에너지 패널티 항목을 포함한다.
- **적대적 모방 모드**: AMP 기반으로, 판별기는 10단계 상태 전이와 장면 포인트 클라우드를 수신하여 스타일 보상을 출력하고, 자연스러운 움직임과 장면 적응을 장려한다.

### 통합 관측 공간 설계
- **캐릭터 상태**: s_t = (h_t, p_t, q_t, ṗ_t, q̇_t), 루트는 골반이며, 로컬 좌표계의 x축은 루트 링크 방향을 따른다.
- **장면 표현**: 캐릭터 중심의 최근 N개 포인트 클라우드 포인트로, 시간 위상 대신 공간 "위상" 변수로 사용된다.
- **핵심 결정**: 모션 트래킹 작업에서는 시간 위상이나 미래 목표 자세를 사용하지 않고(목표 추적 작업에서는 사용 불가), 장면 관측으로 현재 위상을 추론하여 두 모드가 동일한 관측 공간을 공유하게 한다.

### 보상 설계
- **트래킹 보상** (수식 2): r_t^track = w_p e^{-α_p||p̂_t - p_t||} + w_r e^{-α_r||q̂_t ⊖ q_t||} + w_v e^{-α_v||ṗ̂_t - ṗ_t||} + w_ω e^{-α_ω||q̇̂_t - q̇_t||} + w_h e^{-α_h||ĥ_t - h_t||} + w_e Σ_j ||τ_j q̇_j||
- **목표 보상** (수식 3): r_t^target = ||p_{t-1}^root - g_{t-1}|| - ||p_t^root - g_t|| + r_t^reach, [0, 0.05]로 잘라내어 부자연스러운 행동 방지.
- **스타일 보상**: r_t^style = -log(1 - D(s_{t-n:t}, c_{t-n:t})), 트래킹 모드에도 동일한 가중치의 스타일 보상을 추가하여 두 모드를 연결한다.

### 네트워크 아키텍처
- **정책**: Transformer(잠재 차원 256, 2계층, 2헤드), PointNet이 장면 포인트 클라우드를 인코딩하고, 두 개의 MLP가 캐릭터 상태와 목표 위치를 인코딩한다.
- **비평가**: MLP [1024, 512], 추가 입력으로 작업 지시 변수 k(privileged information, 훈련 시에만 사용).
- **판별기**: MLP [1024, 512], 10단계 상태 전이와 장면 포인트 클라우드를 입력으로 받으며, 그래디언트 패널티 항목을 포함한다.

### 훈련 전략
- 먼저 모션 트래킹 작업에서 40억 샘플로 훈련(warm start)한 후, 이중 작업 병렬 훈련을 20억 샘플로 진행.
- 섭동 상태 초기화(PSI): 참조 모션의 초기 상태에 가우시안 노이즈를 적용하여 완료율을 높일 뿐만 아니라 모드 붕괴를 완화.
- 조기 종료: 트래킹 모드가 참조 모션에서 0.5미터 이상 벗어나면 종료; 적대적 모드가 넘어지거나 목표를 2미터 이상 놓치면 종료.

## 핵심 혁신

1. **통합 관측 공간으로 시간 위상 대체**: 모션 트래킹 작업에서 장면 포인트 클라우드를 공간 위상 변수로 사용하여 두 모드가 동일한 관측 공간을 공유하게 하고, 단순 조건부 입력 마스킹으로 인한 행동 모드 분열을 피한다. 이는 하이브리드 훈련을 구현하는 핵심 설계이며, 이전 방법이 해결하지 못한痛点이다.

2. **장면 인식 판별기**: 장면 포인트 클라우드를 판별기에 입력하여, 움직임이 자연스러운지뿐만 아니라 현재 장면 맥락에 적응하는지도 판단하게 한다. 이는 AMP의 모드 붕괴 문제를 직접 완화한다. 판별기가 "모든 장애물에 동일한 동작으로 대응하는" 행동을 처벌할 수 있기 때문이다.

3. **캐스케이드가 아닌 이중 모드 공동 훈련**: 먼저 모션 트래킹을 warm start한 후 두 모드를 병렬 훈련하여, 트래킹의 정밀성을 적대적 학습에 "주입"하고 적대적 학습의 유연성을 트래킹에 "환류"시킨다. 이 훈련 전략은 모델이 단일 기술을 정밀하게 실행하면서도 기술 시퀀스를 유연하게 조합할 수 있게 한다.

## 실험 및 결과

| 방법 | 기술 정확도 | 트래킹 오차 | 작업 완료율 |
|------|-----------|---------|-----------|
| Task reward | 0.15 | 0.54 | 0.86 |
| AMP | 0.54 | 0.37 | 0.85 |
| HIL (Ours) | **0.66** | **0.31** | 0.74 |

| 소거 | 기술 정확도 | 트래킹 오차 | 작업 완료율 |
|------|-----------|---------|-----------|
| w/o D | 0.53 | 0.36 | 0.62 |
| w/o PSI | 0.50 (표 내 값 0.055→0.055로 계산) | 0.37 | 0.52 |
| D^w/o scene info | 0.38 | 0.39 | 0.75 |
| w/o r^style in track | 0.55 | 0.39 | 0.71 |
| w/o k | 0.52 | 0.40 | 0.73 |
| HIL (Ours) | **0.66** | **0.31** | **0.74** |

- HIL은 기술 정확도에서 AMP보다 22% 향상(표 내 값 0.71→0.55로 계산), 트래킹 오차는 16% 감소(표 내 값 0.74→0.86으로 계산), 작업 완료율은 약간 낮지만 큰 차이는 아님(0.74 vs 0.85).
- 판별기 장면 정보 제거(D^w/o scene info)는 기술 정확도를 0.38로 급락시켜, 장면 인식 판별기가 기술 다양성에至关重要함을 증명.
- PSI 제거는 작업 완료율을 0.52로 낮추어, 섭동 초기화가 기술 전환 능력에 핵심적인 역할을 함을 설명.
- 강건성: σ=0.05에서 완료율 70% 이상, σ=0.1에서 50% 이상 유지.
- 긴 시퀀스 일반화: 5개 장애물로 훈련, 20개 장애물 테스트(σ=0.03)에서 완료율 약 40%.
- 작업 지시 변수 k 제거 시 비평가 손실이 5배 증가.

## 경계 및 한계

- 생성된 모션에 가끔 아티팩트 발생(예: 장애물에 걸려 넘어질 때 부자연스러운 회복 행동).
- 장애물이 순서대로 배열되어 있다고 가정하므로, 비선형 배치의 복잡한 환경에는 일반화 불가.
- 모션 데이터셋에 충분히 표현되지 않은 장애물 유형이나 배치에 대한 적응이 어려움.
- 훈련 시 섭동을 적용하지 않고 평가 시에만 노이즈를 도입하므로, 훈련 중 데이터 증강의 효과는 테스트되지 않음.
- 논문은 계산 효율성, 추론 속도 또는 실시간성 평가를 명시적으로 언급하지 않음.

## 엔지니어링 시사점

- **재현 우선순위**: 먼저 PSI 구현 세부 사항을 확인할 것. 작업 완료율에 가장 큰 영향을 미치며(제거 시 0.74에서 0.52로 하락), 저자가 모드 붕괴 완화 메커니즘을 명확히 설명했기 때문.
- **가장 함정에 빠지기 쉬운 부분**: 판별기의 장면 정보 입력은 생략할 수 없음(제거 시 기술 정확도가 0.66에서 0.38로 하락), 그러나 장면 포인트 클라우드와 상태 전이의 결합 방식에 주의해야 함. 판별기 입력은 평탄화된 결합이며, 차원 설계를 신중히 확인해야 함.
- **훈련 예산**: 총 훈련량 60억 샘플(40억 warm start + 20억 공동 훈련), 4개의 V100, 수용 가능한지 평가 필요. 자원이 제한적이라면 먼저 warm start 샘플 수를 줄여 영향을 관찰할 수 있음.
- **평가 지표**: 기술 정확도는 DTW 거리로 가장 유사한 참조 모션을 매칭하여 판단하고, 트래킹 오차는 DTW 거리 정규화를 1000으로 나눈 값. 재현 시 DTW 구현이 저자와 일치하는지 확인해야 함(경계 조건, 연속성 및 단조성 제약).
- **데이터 파이프라인**: 비디오 모션 추출은 TRAM + 신체 방향 힌트 정제 + 인터랙티브 장면 주석 도구 + 물리 기반 모션 트래커(Tessler et al. 2024) 정제를 사용해야 하며, 이 파이프라인은 데이터 품질의 핵심이므로 우선적으로 재현할 것을 권장.
