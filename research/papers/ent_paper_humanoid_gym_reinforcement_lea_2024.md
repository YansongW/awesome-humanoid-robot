## 概述

Humanoid-Gym 是一个基于 Nvidia Isaac Gym 的开源强化学习框架，由 Robot Era 团队开发，专为人形机器人设计，实现了从仿真到真实世界的零样本迁移。核心贡献在于提供了一套完整的训练、验证和部署工具链，包括 sim-to-sim 验证（Isaac Gym 到 MuJoCo）和针对不同尺寸人形机器人（XBot-S 与 XBot-L）的严格测试，显著降低了人形机器人运动控制领域的研究门槛。

## 它改变了什么

人形机器人的 sim-to-real 迁移一直是机器人学习领域的痛点，其复杂的高自由度结构和动力学特性使得仿真与现实的差距远大于四足机器人。此前，该领域缺乏一个专门针对人形机器人、且经过真实硬件验证的开源框架，研究者往往需要从零搭建训练和部署流程，这极大地阻碍了进展。Humanoid-Gym 的出现改变了这一局面，它不仅仅是一个代码库，更是一个经过真实机器人验证的“标准答案”，为后续研究提供了可复现的基线。

这个框架真正改变了“人形机器人 RL 研究难以起步”的现状。通过将训练、sim-to-sim 验证和真实部署的完整流程封装并开源，它让缺乏物理机器人或工程经验的研究团队也能快速进入该领域。更重要的是，它证明了通过细致的系统设计（如域随机化、特权学习、步态相位奖励），零样本迁移是可行的，这为整个社区树立了信心和参照系。

## 方法拆解

Humanoid-Gym 的方法核心是一个结合了特权学习与步态相位引导的 PPO 训练框架，其设计旨在最大化策略在真实世界中的泛化能力。

### 问题建模与训练范式
- 采用部分可观测马尔可夫决策过程（POMDP）建模，训练时使用全状态空间（特权信息），部署时仅使用观测空间。
- 使用 **Asymmetric Actor-Critic** 架构，Critic 网络在训练时访问特权状态（如摩擦、质量、推力等），而 Actor 网络仅依赖可部署的观测。
- 策略优化使用 **PPO** 损失，配合 **GAE** 进行优势估计，价值函数损失为 ℒv = ‖Rₜ − V(sₜ)‖₂。

### 观测与状态空间设计
- **观测空间（47 维）**：包含周期时钟信号 [sin(2πt/C_T), cos(2πt/C_T)]、速度命令、关节位置/速度、角速度、欧拉角及上一动作。
- **状态空间（73 维）**：在观测基础上增加摩擦系数、身体质量、基座线速度、推力、推力矩、跟踪差异、步态掩码和足部接触检测。
- 采用多帧观测堆叠（15 帧）以捕捉动态信息，对不平地形任务至关重要。

### 步态生成与奖励塑形
- 通过正弦波生成参考运动，并定义步态相位（双支撑相 DS 与单支撑相 SS），周期为 C_T。
- 设计周期性姿态掩码 I_p(t) 指示足部接触模式，并通过奖励函数鼓励实际接触与掩码对齐。
- 总奖励 rₜ = ∑ᵢ rᵢ · μᵢ，包含速度跟踪、步态奖励和正则化项。关键设计是**速度不匹配项权重故意设为零**，因为命令中不包含 z、γ、β 方向的速度，保持为零以确保稳定行走。

### 控制架构
- 策略网络以 **100 Hz** 运行，输出 PD 控制器的目标关节位置。
- 内部 PD 控制器以 **1000 Hz** 高频运行，确保底层力矩控制的稳定性。

### 域随机化与验证
- 训练时应用域随机化（Table III），包括关节位置/速度噪声、系统延迟、摩擦、电机强度、有效载荷等，以最小化 sim-to-real gap。
- 训练在 Isaac Gym（GPU 并行）进行，随后在 MuJoCo（CPU 高精度）中进行 sim-to-sim 验证，结合了高速与高保真的优势。

## 关键创新

1.  **完整的零样本 sim-to-real 验证体系**：不同于以往仅停留在仿真或单一平台验证的工作，Humanoid-Gym 在两种不同尺寸的真实人形机器人（XBot-S 1.2 米、XBot-L 1.65 米）上验证了零样本迁移能力，并提供了 MuJoCo 作为中间验证层。这为“仿真训练-仿真验证-真实部署”的流程提供了可复制的范本，其价值在于证明了该框架的泛化性，而非针对单一机器人调参。

2.  **步态相位与接触掩码的显式奖励设计**：将生物力学中的步态周期概念（DS/SS 相位）引入奖励函数，通过周期性姿态掩码 I_p(t) 直接约束足部接触模式。这一设计比单纯的速度跟踪奖励更有效地引导策略学习自然、稳定的行走步态，是解决人形机器人行走稳定性的关键创新。

3.  **Asymmetric Actor-Critic 与多帧观测的实用结合**：在训练时利用特权信息（如摩擦、推力）加速收敛，部署时仅依赖本体感觉和时钟信号，并通过多帧堆叠（15 帧）补偿部分可观测性。这种组合在工程上非常实用，既保证了训练效率，又确保了部署时的可行性，是 sim-to-real 成功的重要保障。

## 实验与结果

实验验证了框架在平坦和崎岖两种地形上的有效性，并重点展示了 MuJoCo 作为 sim-to-sim 验证工具的可靠性。

### 关键实验设置
- 训练环境：Isaac Gym，8192 个并行环境，回合长度 2400 步。
- 验证环境：MuJoCo，用于评估策略在更精确物理引擎下的表现。
- 真实机器人：Robot Era 的 XBot-S（1.2 米）和 XBot-L（1.65 米）。

### 主要结果分析
- **MuJoCo 校准**：通过对比 MuJoCo 与真实环境中的腿部摆动正弦波，发现轨迹几乎一致。特别地，在左膝关节和左踝关节的相位图对比中，MuJoCo 的动态特性比 Isaac Gym 更接近真实环境。这证明了 MuJoCo 作为 sim-to-sim 验证层的有效性，能更准确地预测真实世界表现。
- **零样本迁移**：训练后的策略直接部署到真实机器人，无需任何微调，成功实现了稳定行走。这验证了域随机化策略和奖励设计的有效性。

## 边界与局限

论文未明确列出局限性，但可以从技术细节中推断出一些边界。首先，所有实验均基于 Robot Era 的特定机器人型号，其硬件特性（如电机响应、结构刚度）可能与其他平台存在差异，因此框架的通用性在未测试的硬件上存疑。其次，虽然验证了平坦和崎岖地形，但未涉及更复杂的动态任务（如跳跃、奔跑或上下楼梯），策略的适用范围仅限于行走。此外，训练依赖于 Isaac Gym 和 MuJoCo 的特定版本，其 API 变化可能导致复现问题。最后，论文未提及对真实世界动态扰动（如强外力推搡）的鲁棒性测试，其“零样本”迁移的结论在极端工况下可能不成立。

## 工程启示

对于希望复现或基于此框架开发的团队，以下几点值得特别关注：

1.  **优先核对 MuJoCo 校准环节**：这是整个流程中承上启下的关键。务必按照论文方法，对比 MuJoCo 与真实机器人的关节轨迹相位图，确保仿真动态的准确性。如果这一步的误差过大，后续的零样本迁移几乎不可能成功。

2.  **重视域随机化参数的物理意义**：Table III 中的参数范围（如摩擦 [0.1, 2.0]、延迟 [0, 10] ms）并非随意设定，而是基于真实硬件环境的合理估计。在复现时，应根据自身机器人的特性调整这些范围，而不是盲目照搬。特别是电机强度 [95, 105] % 和有效载荷 [-5, 5] kg，直接关系到硬件差异。

3.  **最容易踩坑的地方是奖励函数中的“速度不匹配项”**：论文明确指出其权重故意设为零，因为命令中不包含 z、γ、β 方向的速度。如果在复现时错误地激活了该项，策略可能会为了“匹配”一个不存在的命令而产生异常行为，破坏行走稳定性。务必检查命令空间的定义与奖励函数的对应关系。

4.  **注意控制频率的设定**：策略 100 Hz 与 PD 控制器 1000 Hz 的搭配是经过验证的。降低 PD 频率可能导致关节跟踪精度下降，而提高策略频率则会增加计算负担，均可能影响最终效果。在真实机器人上部署时，需确保实时控制循环能满足这两个频率要求。

## Overview
Humanoid-Gym provides an easy-to-use reinforcement learning framework specifically designed for training locomotion skills for humanoid robots. The framework is built on Nvidia Isaac Gym and integrates a sim-to-sim module from Isaac Gym to Mujoco, allowing users to verify the robustness and generalization capabilities of trained policies across different physical simulation environments. The framework has been validated in real-world settings on RobotEra's XBot-S (1.2m tall) and XBot-L (1.65m tall) humanoid robots, successfully achieving zero-shot sim-to-real transfer.
