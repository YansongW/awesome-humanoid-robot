## 概述

Uni-NaVid 是一个基于视频的视觉-语言-动作（VLA）模型，由研究团队提出，旨在统一多种具身导航任务（VLN、ObjectNav、EQA、Human Following）。其核心贡献在于通过在线视觉 token 合并策略和统一的数据格式，实现了端到端的动作生成，并在多个基准上超越了现有方法，同时展示了在真实世界中的零样本部署能力。

## 它改变了什么

现有具身导航模型多为特定任务定制，依赖预定义地图或离散航点，难以作为现实世界的通用模型。这种碎片化导致模型在跨任务泛化和 sim-to-real 迁移上表现不佳。Uni-NaVid 真正改变了这一局面，它不再为每个任务训练独立模型，而是将导航问题统一为“视频+语言输入，动作或语言输出”的序列生成范式，从而让一个模型能够处理多种导航任务。

更重要的是，它摒弃了依赖预定义图的离散化决策方式，直接输出连续动作（如前进 25 cm、转向 30°），这为现实部署提供了更高的灵活性。此外，通过引入互联网视频问答数据作为辅助任务，它有效缓解了模拟器渲染质量有限带来的 sim-to-real 差距，这是以往方法未能充分解决的。

## 方法拆解

### 统一任务建模
所有任务（VLN、ObjectNav、EQA、Human Following）的数据被统一为单一格式，在 token 空间中交叉交错输入输出，采用 next-token-prediction 范式联合学习。导航任务通过特殊 token `<NAV>` 触发动作预测，输出 4 个动作 token，动作集为 {FORWARD, TURN-LEFT, TURN-RIGHT, STOP}。

### 在线视觉 Token 合并
基于 Atkinson-Shiffrin 记忆模型，将视觉 token 分为当前、短期、长期三类：
- 当前观测：网格池化参数 α_curr=2，得到 64 个 token。
- 短期记忆：网格池化参数 α_short=8，得到 4 个 token。
- 长期记忆：网格池化参数 α_long=16，得到 1 个 token。
- 缓冲区大小 B=64，长期 token 合并阈值 τ=0.95。

新帧到达时，当前 token 经网格池化转为短期 token，短期 token 转为长期 token。若新长期 token 与列表中最后一个 token 的余弦相似度高于 τ，则按帧数 K 加权平均合并（X_last_long = 1/(K+1) × (K × X_long[-1] + X_short→long)），否则插入新 token。

### 训练策略
采用两阶段训练：先训练视觉投影器（使用 Image QA 和 Video QA 数据），再联合训练投影器和 LLM（使用导航数据）。仅训练 1 个 epoch。视觉编码器为 EVA-CLIP，每帧提取 256 个 patch token，经投影器映射到语言空间。LLM 为 Vicuna-7B。

## 关键创新

1.  **在线 token 合并机制**：这是首个将 Atkinson-Shiffrin 记忆模型引入 VLA 导航的方法。通过将视觉历史压缩为短期和长期 token，模型能够高效处理长视频序列，同时保持推理速度稳定在约 0.2 秒，解决了以往方法（如 QFormer）随 token 数增加而耗时剧增的问题。
2.  **任务统一与数据格式标准化**：将四个导航子任务和两个辅助任务（视频问答、视频描述）统一为单一格式，在 token 空间联合学习。这种设计让模型能够从多任务中获取协同效益，实验表明多任务学习在所有导航任务上带来一致的性能提升。
3.  **语言指令驱动的人类跟随**：引入了一种新型人类跟随任务，由自然语言指令指定目标（如“跟随穿蓝衬衫的男人”），而非依赖预定义边界框。这摆脱了对上游检测器的依赖，更贴近真实世界应用场景。

## 实验与结果

实验在多个基准上进行了全面评估，关键结果如下：

| 任务 | 指标 | Uni-NaVid | 最佳对比方法 | 提升 |
|------|------|-----------|--------------|------|
| VLN-CE R2R Val-Unseen | SR | 48.7 | NaVid 23.8 | +25.7% |
| VLN-CE R2R Val-Unseen | SPL | 40.9 | NaVid 21.2 | - |
| HM3D ObjectNav | SR | 73.7 | PIRLNav-IL-RL 70.4 | +4.7% |
| MP3D EQA (CE) | ACC | 47.3 | NaviLLM 44.5 | - |
| Human Following (HM3D) | SR | 61.21 | IBVS† 50.58 | +21.0% |
| ScanQA | CIDEr | 94.72 | NaviLLM 80.77 | +13.1% |

消融实验显示，移除视觉记忆时 VLN 任务 SR 下降 −80.3%，而 Following 任务仅下降 −8%，表明长期记忆对需要空间推理的任务至关重要。τ 值从 0.9 增至 0.95 时，VLN SR 从 40.2 提升至 48.7，但继续增至 0.99 时性能下降，验证了 0.95 的平衡性。真实世界 VLN 实验中，Uni-NaVid 在复杂指令上达到 84% 成功率，远超 NaVid 的 20%。

## 边界与局限

论文未明确提供完整实验协议和额外结果，均放在补充材料中。所有导航训练数据均来自合成环境（Habitat-Matterport 和 Matterport 3D），真实世界数据仅用于视频问答辅助任务，未提及对真实世界导航数据的直接采集（因成本过高）。作者承认 ObjectNav 性能可通过引入强化学习技术进一步提升。跨数据集评估（RxR）中，所有指标相比包含 RxR 训练数据时显著下降，作者推测原因是 R2R 轨迹长度相对均匀（约 10 米），而 RxR 轨迹长度差异大（约 2 米到 20 米），凸显了多样化轨迹训练的重要性。

## 工程启示

复现时需注意以下几点：首先，训练数据规模庞大（总计 5.9M 样本），需要约 1400 GPU 小时（40 块 NVIDIA H800），硬件门槛较高。其次，在线 token 合并的参数（α_curr=2, α_short=8, α_long=16, τ=0.95）对性能影响显著，消融实验表明 τ 值从 0.9 增至 0.95 时 VLN SR 提升 8.5%，但继续增至 0.99 时性能下降，建议严格遵循论文设定。第三，使用最短路径作为导航视频样本会导致极低性能（30.1% SR），必须采用 DAGGER 等交互式数据收集方法。最后，部署时模型推理约 0.2 秒，互联网通信约 0.3 秒，需确保网络延迟可控；机器人执行动作时优先执行最新命令（非阻塞导航），这是保证实时性的关键。

### 방법

### 훈련 데이터
- 총 360만 개의 내비게이션 데이터 샘플로, 네 가지 핵심 하위 작업을 포함:
  - 지시 따르기(Instruction Following)
  - 목표 탐색(Object Search)
  - 시각 질의응답(Visual Question Answering)
  - 사람 추적(Person Tracking)
- 데이터는 작업 간 협력 학습 전략을 통해 혼합 훈련되어, 서로 다른 작업 간의 지식 전이를 촉진합니다.
