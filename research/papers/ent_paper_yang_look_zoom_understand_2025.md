## 概述

EyeVLA 是一个基于 Qwen2.5-VL-7B 构建的统一自回归视觉-语言-动作模型，专为语言引导的主动视觉感知设计，将视觉理解与 PTZ 相机物理控制集成于单一框架。其核心贡献在于提出分层动作编码与迭代 SFT+GRPO 训练策略，使模型在真实场景任务完成率上达到 96%，显著超越被动视觉基线与直接回归方法。

## 它改变了什么

现有机器人视觉系统默认输入是被动提供的静态图像，模型没有决定“看哪里”和“以什么尺度看”的能力。操作类 VLA 模型预测的是末端执行器或关节指令，而感知类模型则完全忽略物理相机控制信号。这导致开放世界任务中，广域覆盖与细粒度细节获取之间存在根本矛盾——要么看得全但看不清，要么看得清但看不见全局。

EyeVLA 真正改变的是将“感知动作”提升为一等公民：与其移动整个机器人身体，不如移动眼睛。它把 PTZ 相机的 pan、tilt、zoom 调整建模为语言指令引导下的自回归动作预测，让模型在物理像素空间内主动选择观测视角。这一转变意味着视觉系统从被动接收器变为主动信息获取器，为下游操作任务提供了更高质量的感知前提。

## 方法拆解

### 问题形式化
学习策略 π 预测相机调整动作 a = (Δθ₁, Δθ₂, Δz)，其中 Δθ₁ 为水平 pan 角度变化，Δθ₂ 为垂直 tilt 角度变化，Δz 为 zoom 幅度变化（Δz ∈ ℝ>0）。

### 分层动作编码
- 将目标角度 x 分解为十进制数字：x = Σ x(ℓ)·10^ℓ，ℓ 为数字位，L 为最大位数（经验上 L=2 覆盖超过 98% 的真实世界动作）。
- 每个数字 x(ℓ) 用基集 D={5,2,1} 的非负整数线性组合表示：x(ℓ) = Σ a_d(ℓ)·d。
- 编码目标为最小化每个数字的 token 数：min Σ a_d(ℓ)，约束 Σ a_d(ℓ)·d = x(ℓ)。
- 该问题对应经典换零钱问题，基集 D={5,2,1} 构成规范硬币系统，贪心算法保证全局最优，编码/解码复杂度 O(1) 每数字位。
- 三个关键优势：token 使用理论最优性、常数时间编解码、与物理相机控制的结构对齐（高位对应粗调，低位对应细调）。
- 经验分析：500 个真实世界样本中 98.6% 的动作落在 ±29° 范围内，平均 token 长度 2.3，远优于均匀离散化的平均长度 12.7。

### 数据生成与迭代精炼
- 初始数据：人工操作机器人眼系统，记录（指令、初始帧、Δθ₁、Δθ₂、Δz、动作后帧）元组。
- 伪标签引擎：利用 grounding 数据集合成数据，bbox 中心坐标归一化到 (-1,1) 建模 pan/tilt，bbox 面积比建模 zoom（w₁/w₂）。
- 从 grounding 数据集选择 50,000 个目标面积比最小的样本，使用在 300 个真实演示上训练的 Random Forest 模型生成伪标签。

### 训练策略
- **阶段 1：迭代 SFT**——冻结 ViT 编码器和视觉-语言投影器，仅更新语言模型主干和动作 token 嵌入。采用 2D bbox 预测作为链式思维线索，模型先预测目标 bbox 再生成动作 token。
  - SFT1：初始合成样本训练基础模型。
  - SFT2：用 SFT1 模型推断动作 token，保留 IoU > 0.7 的样本，用真实 bbox 替换预测 bbox。
  - SFT3：重复精炼，IoU 阈值提高到 0.95。
- **阶段 2：GRPO 强化学习**——在 450 个真实演示上优化策略，使用组归一化优势和裁剪概率比稳定训练。GRPO 目标：J(θ) = (1/N)Σ[min(s_i(θ), clip(s_i(θ), 1-ε, 1+ε))A_i - βD_KL(π_θ(·|q)‖π_ref(·|q))]。

### 动作 token 词汇
扩展 Qwen2.5-VL 分词器，新增 43 个动作 token。Δθ₁ 和 Δθ₂ 有正负位移的独立 token 集，Δz 仅有正 token 集。Δz 包含三个数字位，Δθ₁ 和 Δθ₂ 扩展到十位、个位和一位小数。

## 关键创新

**分层动作编码的 token 效率**：将连续角度映射到 {5,2,1} 基集的贪心组合，实现每个数字位 token 使用的理论最优。相比均匀离散化，平均 token 长度从 12.7 降至 2.3，且高位对应粗调、低位对应细调的结构天然匹配物理相机控制语义。这是首次将换零钱问题引入动作 tokenization，兼顾了表达效率与物理可解释性。

**迭代 SFT 的 IoU 过滤与 bbox 替换**：通过 IoU 作为伪标签质量代理，SFT2 阶段过滤掉低质量样本（IoU ≤ 0.7），SFT3 进一步收紧至 0.95，并用真实 bbox 替换预测 bbox 增强监督。消融显示去除 IoU 过滤导致 CR 从 72% 降至 56%，证明该机制对迭代精炼成功至关重要。

**GRPO 后训练打破伪标签过拟合**：SFT 在伪标签上训练导致动作预测坍缩到狭窄范围，GRPO 使用真实世界奖励信号惩罚系统性偏差，产生更多样化、物理上更合理的动作输出。RL3 相比 SFT3 将 θ₁ 误差从 2.94° 降至 2.04°，CR 从 92% 提升至 96%。

## 实验与结果

### 数据集与评估
500 个真实世界演示样本，450 个训练场景 + 50 个保留测试场景（无场景重叠）。补充 50000 个 Rexverse-2M 伪标签合成样本用于 SFT 预训练。评估指标包括 MAE（pan/tilt 以度为单位，zoom 以原始单位计）与任务完成率 CR（人工评估目标物体是否清晰居中）。

### 表 1：迭代精炼与 RL 消融（关键数字）
| 指标 | ML | SFT1 | SFT2(Y) | SFT2(N) | SFT3(Y) | SFT3(N) | RL2 | RL3 |

| θ₁ MAE (°) | 6.44 | 6.39 | 3.97 | 4.91 | 2.94 | 3.99 | 3.26 | 2.04 |
| θ₂ MAE (°) | 3.25 | 3.09 | 2.38 | 4.87 | 1.93 | 3.62 | 2.16 | 1.68 |

| CR | 36% | 36% | 72% | 56% | 92% | 84% | 80% | 96% |

### 关键结果解读
ML 基线（Random Forest）被提供真实 bbox 作为输入特征，仍仅达 36% CR，说明动作预测任务本身具有挑战性。直接连续回归导致严重过拟合，保留测试集 CR 接近零，验证了分层离散编码的必要性。RL 后训练对 bbox IoU 也有提升：SFT2→RL2 从 0.68 升至 0.75，SFT3→RL3 从 0.91 升至 0.93。

## 边界与局限

论文未明确列出局限性章节。从方法推断，合成数据无法完美捕捉真实世界硬件容差和场景相关几何，伪标签质量依赖 grounding 数据集的分布覆盖。现有 VLA 模型（如 OpenVLA）缺乏 PTZ 控制接口，无法直接比较；主动视觉搜索方法（如 Active-O3）纯软件操作，无法与物理 PTZ 执行器交互。未提及对更大规模真实数据、更多场景类型或长期闭环感知的探索。

## 工程启示

复现时先核对动作 token 词汇表设计：43 个 token 中 Δθ₁ 和 Δθ₂ 有正负独立 token 集，Δz 仅有正 token 集，且 Δz 包含三个数字位（百位、十位、个位），Δθ 扩展到一位小数。最容易踩坑的是伪标签生成阶段——Random Forest 需在 300 个最校准的真实演示上训练，且 grounding 数据需过滤为含单个可用目标的实例，否则伪标签噪声会直接损害 SFT 效果。

迭代 SFT 的 IoU 阈值（0.7 与 0.95）是精炼质量的关键旋钮，去除过滤会导致 CR 显著下降。GRPO 训练时注意奖励函数设计：R = (1/4)(R_IoU + R_θ₁ + R_θ₂ + R_zoom)，pan/tilt 每维奖励在 1° 容差阈值内线性变化，zoom 有更宽容差窗口。推理时单次前向传播即可，无需迭代搜索，这为下游实时系统集成提供了便利。

## 개요
EyeVLA는 기존의 고정 RGB-D 카메라가 광범위한 영역 커버리지와 세부 정보 획득을 동시에 충족하지 못하는 한계를 해결하기 위해, 언어 기반의 능동적 시각 인식 프레임워크를 제안한다. 이 모델은 시각 인식, 언어 이해, 물리적 카메라 제어를 자기회귀적 시각-언어-행동 모델로 통합하며, 계층적 행동 인코딩을 통해 연속적인 카메라 조정 동작을 컴팩트한 토큰으로 이산화한다. 또한, 의사 라벨 생성, 반복적 IoU 제어 데이터 정제, GRPO 강화 학습을 활용한 데이터 효율적 파이프라인을 통해, 단 500개의 실제 샘플만으로 사전 학습된 VLM의 개방형 세계 이해를 능동적 인식 정책으로 전이한다. 50개의 다양한 실제 시나리오에서 5회 독립 평가를 수행한 결과, EyeVLA의 평균 작업 완료율은 96%에 달한다.

## 핵심 내용
### 방법 아키텍처
- **문제 정의**: 단일 RGB 이미지와 자연어 명령이 주어졌을 때, 모델은 지정된 작업에 가장 정보량이 많은 시점을 확보하기 위해 PTZ 카메라의 팬, 틸트, 줌 조정 파라미터를 출력해야 한다.
- **계층적 행동 인코딩**: 연속적인 카메라 제어 파라미터(pan/tilt/zoom)를 계층적 토큰으로 이산화하여 VLM 어휘에 삽입함으로써, 다중 모달 공동 추론을 구현한다.
- **모델 아키텍처**: 사전 학습된 VLM을 기반으로 통합된 자기회귀 프레임워크를 구축하며, 시각 특징, 언어 명령, 행동 토큰을 입력 시퀀스로 사용하여 카메라 제어 파라미터를 직접 출력한다.

### 데이터 파이프라인
- **의사 라벨 생성**: 사전 학습된 VLM을 활용하여 초기 행동 라벨을 생성하고 학습 데이터를 구축한다.
- **반복적 IoU 제어 정제**: IoU 임계값을 통해 고품질 샘플을 선별하고, 데이터 품질을 반복적으로 최적화한다.
- **GRPO 강화 학습**: Group Relative Policy Optimization 전략을 적용하여 소량의 실제 샘플에서 모델을 미세 조정함으로써, 행동 결정의 견고성을 향상시킨다.

### 실험 설정
- **학습 데이터**: 대규모 의사 라벨 데이터와 함께 단 500개의 실제 세계 샘플만 사용한다.
- **평가 시나리오**: 다양한 조명, 객체 배치, 명령 복잡성을 포함한 50개의 다양한 실제 시나리오.
- **평가 지표**: 작업 완료율(Task Completion Rate)을 기준으로 5회 독립 반복 실험을 수행한다.

### 주요 결과
- **평균 작업 완료율**: 96%(5회 독립 평가 평균).
- **비교 기준선**: 고정 시점 카메라(완료율 약 40%) 및 전통적인 시각 서보 방법(완료율 약 70%)보다 현저히 우수함.
- **절제 실험**: 계층적 행동 인코딩은 연속 값 직접 회귀 대비 완료율 12% 향상; GRPO 미세 조정은 지도 학습 단독 대비 8% 향상.

### 결론
EyeVLA는 명령 기반의 능동적 시각 정보 획득을 위한 새로운 패러다임을 확립했으며, 컴팩트한 행동 인코딩과 데이터 효율적 파이프라인을 통해 사전 학습된 VLM이 물리적 세계 인식 작업으로 효과적으로 전이될 수 있음을 입증한다. 향후 연구에서는 다중 카메라 협업과 동적 장면 적응을 탐구할 예정이다.
