## 概述

DUET（Dual-scale Graph Transformer）是面向视觉语言导航（VLN）的双尺度图Transformer模型，由法国团队提出，核心贡献在于用纯Transformer架构替代循环状态跟踪，并通过粗尺度拓扑图与细尺度全景编码的协同推理，同时提升目标导向导航（REVERIE、SOON）中的探索效率与物体接地精度。在REVERIE测试集上，其成功率较当时SOTA（HAMT）提升22.11%，SPL提升9.39%。

## 它改变了什么

这个工作的真正价值在于它同时动了VLN中两个长期被默认的"地基"：一是状态跟踪机制，二是动作空间的定义。此前主流方法（HAMT、E.T.）把导航视为马尔可夫决策过程，每一步只能移动到相邻位置，回溯N步就要重跑N次模型——这不仅放大了循环架构的误差累积，也让长程规划在计算上变得不可承受。DUET把"回溯"从隐式的序列重放变成了显式的图搜索：一旦拓扑图建立，从任意节点到任意节点的路径可以用Floyd算法一次性解出，模型只需预测目标节点，无需逐步逼近。这是从"过程控制"到"目标控制"的范式转换。

另一个被改变的假设是"拓扑图节点用压缩视觉特征就够了"。以往基于图的方法（如[8,19,20]）为了图的可扩展性，牺牲了节点的细粒度信息，导致指令中的"蓝色沙发旁的落地灯"这类描述无法与图中节点对齐。DUET的洞察是：粗尺度图负责"去哪里"，细尺度全景负责"确认那里有什么"，两者必须同时存在且动态融合。这个"双尺度"设计不是简单的多任务拼接，而是对VLN任务本质的重新拆解——导航是层级决策，不是单尺度序列决策。

## 方法拆解

### 拓扑映射：增量建图
- 环境图G未知，模型沿路径逐步构建局部图Gt = {Vt, Et}，节点分三类：已访问、可导航（未探索但部分可见）、当前节点。
- 每步将当前节点的未访问邻居加入图，边仅连接可互相导航的节点。
- 节点视觉表示：当前节点用全景特征Rt和物体特征Ot的平均池化；可导航节点从多个位置看到时，平均所有部分视图嵌入。
- 关键设计：保留Rt、Ot作为细粒度表示，不压缩——这是后续细尺度推理的输入。

### 粗尺度跨模态编码器（全局动作）
- 节点嵌入 = 视觉特征 + 位置编码（当前节点自我中心视角的方向/距离）+ 导航步编码（已访问节点的最近访问时间，未探索为0）。
- 添加'stop'节点v0，与所有节点全连接。
- 图感知自注意力（GASA）：在标准自注意力中加入可学习的距离偏置矩阵M = EWe + be，其中E为成对最短距离矩阵。公式：GASA(X) = Softmax(XWq(XWk)T/√d + M)XWv。
- 全局动作分数：sci = FFN(ˆvi)，掩蔽已访问节点。

### 细尺度跨模态编码器（局部接地）
- 输入：指令 + 当前节点的{Rt, Ot}。
- 两类位置嵌入：①当前节点相对起始节点的地图位置（支持"去一楼客厅"）；②每个邻居相对当前节点的自我中心方向（支持"右转"）。
- 添加'stop'标记r0，拼接为[r0; Rt; Ot]输入标准跨模态Transformer。
- 输出：局部动作分数s fi和物体接地分数（基于ˆOt的FFN）。

### 动态融合
- 将局部分数映射到全局空间：已访问节点分数 = sback（N(Vt)中已访问节点分数之和），未访问邻居保留原分数。
- 融合权重：σt = Sigmoid(FFN([ˆv0; ˆr0]))，即由两个尺度的stop表示共同决定信任哪个尺度。
- 最终分数：si = σtsci + (1 − σt)s f′i。

### 训练
- 预训练：行为克隆（SAP）+ 掩码语言建模（MLM）+ 掩码区域分类（MRC）+ 物体接地（OG）。
- 策略学习：伪交互式演示器（PID），类似DAgger，训练时可访问环境图，选择到最终目的地整体最短距离的节点作为下一目标，避免专家轨迹的次优性。
- 总损失：L = λLSAP + LPID + LOG，λ平衡行为克隆与PID。

### 推理
- 每步更新拓扑图 → 预测全局动作 → 若为导航动作，用Floyd算法计算最短路径 → 超过最大步数强制停止 → 在停止位置选物体分数最大的物体。

## 关键创新

1. **图感知自注意力（GASA）**：将拓扑图的成对距离矩阵作为注意力偏置注入Transformer。这不是简单的图神经网络消息传递，而是让注意力权重直接编码"节点间最短路径长度"——模型可以隐式学习"距离越近越相关"的归纳偏置，同时避免GNN的过平滑问题。消融显示，GASA在动态融合下将SPL从32.88提升至33.73，RGS从29.91提升至32.15。

2. **伪交互式演示器（PID）替代强化学习**：传统RL（如REVERIE中的RL微调）需要与环境交互采样，样本效率低且不稳定。PID利用训练时可访问的环境图，直接选择"到最终目的地最短路径上的下一节点"作为监督信号，相当于用最优路径规划器生成在线演示。消融显示，PID比RL在SR上提升4.63%（42.35→46.98），且无需额外交互成本。

3. **双尺度动态融合**：不是简单的分数平均，而是用两个尺度的stop表示学习一个门控权重σt。这个设计的精妙之处在于：σt本身反映了"当前节点是否足够确定"——当细尺度对stop有信心时（如已到达目标房间），σt趋近0，细尺度主导；当需要长程探索时，粗尺度主导。消融显示，动态融合比平均融合在SPL上提升1.79%（31.94→33.73）。

- 错误房间类型占29.82%，正确房间但错误位置占23.20%——细粒度场景理解仍是主要瓶颈。

## 边界与局限

- **离散环境局限**：方法依赖Matterport3D的离散导航图（预定义位置和动作集），未在连续环境（如真实机器人）中验证。作者明确承认此局限。
- **细粒度理解不足**：29.82%的错误源于房间类型判断错误，模型在多个相似房间（如多个浴室）时可能到达不含目标物体的房间。
- **语言鲁棒性差**：同一轨迹的三条指令中仅一条成功，模型对指令措辞变化敏感。
- **SOON数据噪声**：SOON的物体标注约50%的多边形不包含物体中心点，作者虽用BUTD检测器清洗，但伪标签质量仍可能限制上限。
- **计算资源未披露**：论文未提及总参数量、推理频率和训练时间，复现成本难以预估。
- **合成数据增强的边际效应**：在PID策略学习阶段，合成指令数据无提升（SR 46.98→46.58），说明增强仅对预训练有效。

## 工程启示

- **复现优先级**：先核对GASA的距离矩阵计算——E必须是成对最短路径距离（用Floyd或BFS预计算），而非直接相邻距离。这是注意力偏置的关键，错误实现会导致图结构信息丢失。
- **训练顺序敏感**：预训练（SAP+OG+Aux）和策略学习（PID）必须分开。合成数据增强只在预训练阶段有效，在PID阶段反而轻微降低SR——不要在所有阶段统一使用增强数据。
- **λ平衡因子**：λ=0时导航性能最好（SR 48.22）但物体定位弱（RGS 32.12）；λ=0.2是综合最优。若下游任务更重物体定位，可尝试λ=0.5（RGS 32.43）。λ=1时各项指标全面下降，说明行为克隆权重过高会抑制PID的探索收益。
- **回溯行为是特征而非bug**：val unseen中48.6%的轨迹包含回溯，但val seen仅13.7%——回溯比例可作泛化能力的诊断指标。若你的模型在unseen中回溯比例显著低于此值，可能说明探索不足。
- **SOON的坑**：数据集划分采用发布挑战赛划分而非原论文划分，且需用BUTD检测器清洗标注。复现时务必确认划分版本，否则对比结果无意义。
- **硬件门槛不高**：预训练2块P100，微调1块P100即可，但SOON微调batch size仅2，需注意梯度累积策略。

## Overview

DUET (Dual-scale Graph Transformer) is a dual-scale graph Transformer model for Vision-and-Language Navigation (VLN), proposed by a French team. Its core contribution lies in replacing recurrent state tracking with a pure Transformer architecture and synergizing coarse-scale topological graphs with fine-scale panoramic encoding to simultaneously improve exploration efficiency and object grounding accuracy in goal-oriented navigation (REVERIE, SOON). On the REVERIE test set, its success rate improved by 22.11% over the then-SOTA (HAMT), with SPL improving by 9.39%.

## What It Changed

The true value of this work lies in simultaneously addressing two long-standing "foundations" in VLN: the state tracking mechanism and the definition of the action space. Previous mainstream methods (HAMT, E.T.) treated navigation as a Markov decision process, where each step could only move to adjacent positions, and backtracking N steps required re-running the model N times—this not only amplified error accumulation in recurrent architectures but also made long-horizon planning computationally prohibitive. DUET transformed "backtracking" from implicit sequence replay into explicit graph search: once the topological graph is built, paths between any two nodes can be solved in one pass using the Floyd algorithm, and the model only needs to predict the target node without step-by-step approximation. This is a paradigm shift from "process control" to "goal control."

Another assumption that was changed is "compressed visual features suffice for topological graph nodes." Previous graph-based methods (e.g., [8,19,20]) sacrificed fine-grained node information for graph scalability, making descriptions like "the floor lamp beside the blue sofa" impossible to align with graph nodes. DUET's insight is that the coarse-scale graph handles "where to go," while the fine-scale panorama handles "confirming what is there"—both must coexist and be dynamically fused. This "dual-scale" design is not a simple multi-task concatenation but a re-decomposition of the VLN task's essence: navigation is hierarchical decision-making, not single-scale sequential decision-making.

## Method Breakdown

### Topological Mapping: Incremental Graph Construction
- The environment graph G is unknown; the model incrementally builds a local graph Gt = {Vt, Et} along the path, with three node types: visited, navigable (unexplored but partially visible), and current node.
- Each step adds the current node's unvisited neighbors to the graph, with edges only connecting mutually navigable nodes.
- Node visual representation: current node uses average pooling of panoramic features Rt and object features Ot; navigable nodes average all partial view embeddings when seen from multiple positions.
- Key design: Rt and Ot are preserved as fine-grained representations without compression—these serve as input for subsequent fine-scale reasoning.

### Coarse-Scale Cross-Modal Encoder (Global Actions)
- Node embedding = visual features + positional encoding (direction/distance from the current node's egocentric view) + navigation step encoding (most recent visit time for visited nodes, 0 for unexplored).
- A 'stop' node v0 is added, fully connected to all nodes.
- Graph-Aware Self-Attention (GASA): adds a learnable distance bias matrix M = EWe + be to standard self-attention, where E is the pairwise shortest distance matrix. Formula: GASA(X) = Softmax(XWq(XWk)T/√d + M)XWv.
- Global action scores: sci = FFN(ˆvi), with visited nodes masked.

### Fine-Scale Cross-Modal Encoder (Local Grounding)
- Input: instruction + current node's {Rt, Ot}.
- Two types of positional embeddings: ① map position of the current node relative to the start node (supports "go to the living room on the first floor"); ② egocentric direction of each neighbor relative to the current node (supports "turn right").
- A 'stop' token r0 is added, concatenated as [r0; Rt; Ot] into a standard cross-modal Transformer.
- Output: local action scores s fi and object grounding scores (based on FFN over ˆOt).

### Dynamic Fusion
- Map local scores to global space: visited node scores = sback (sum of scores for visited nodes in N(Vt)), unvisited neighbors retain original scores.
- Fusion weight: σt = Sigmoid(FFN([ˆv0; ˆr0])), where the stop representations from both scales jointly determine which scale to trust.
- Final scores: si = σtsci + (1 − σt)s f′i.

### Training
- Pre-training: Behavior Cloning (SAP) + Masked Language Modeling (MLM) + Masked Region Classification (MRC) + Object Grounding (OG).
- Policy learning: Pseudo-Interactive Demonstrator (PID), similar to DAgger, with access to the environment graph during training, selecting the node on the overall shortest path to the final destination as the next target, avoiding suboptimality of expert trajectories.
- Total loss: L = λLSAP + LPID + LOG, with λ balancing behavior cloning and PID.

### Inference
- Update topological graph each step → predict global action → if navigation action, compute shortest path using Floyd algorithm → force stop if maximum steps exceeded → select the object with the highest object score at the stop position.

## Key Innovations

1. **Graph-Aware Self-Attention (GASA)**: Injects the topological graph's pairwise distance matrix as an attention bias into the Transformer. This is not simple graph neural network message passing but directly encodes "shortest path length between nodes" into attention weights—the model can implicitly learn the inductive bias that "closer means more relevant" while avoiding GNN oversmoothing. Ablation shows GASA improves SPL from 32.88 to 33.73 and RGS from 29.91 to 32.15 under dynamic fusion.

2. **Pseudo-Interactive Demonstrator (PID) Replacing Reinforcement Learning**: Traditional RL (e.g., RL fine-tuning in REVERIE) requires sampling through environment interaction, with low sample efficiency and instability. PID leverages the environment graph accessible during training to directly select "the next node on the shortest path to the final destination" as supervision, equivalent to generating online demonstrations with an optimal path planner. Ablation shows PID improves SR by 4.63% over RL (42.35→46.98) without additional interaction costs.

3. **Dual-Scale Dynamic Fusion**: Not simple score averaging but learning a gating weight σt from both scales' stop representations. The elegance of this design: σt itself reflects "whether the current node is sufficiently certain"—when the fine scale is confident about stop (e.g., arrived at the target room), σt approaches 0 and the fine scale dominates; when long-horizon exploration is needed, the coarse scale dominates. Ablation shows dynamic fusion improves SPL by 1.79% over average fusion (31.94→33.73).

| R2R | SR | 69 | SOTA 65 | +4% |

- The largest improvement is on SOON, as the task requires long-horizon exploration (average 9.5 steps) and fine-grained object localization, for which DUET's dual-scale design is precisely suited.
- On R2R, SR improves but SPL is comparable, indicating DUET does not sacrifice path efficiency in step-by-step navigation tasks.

### Failure Analysis (REVERIE)
- Wrong room type accounts for 29.82%, correct room but wrong position 23.20%—fine-grained scene understanding remains the primary bottleneck.
- Object localization accuracy after reaching the correct position is 68.43%—object grounding performs reasonably well in localized scenes.

## Boundaries and Limitations

- **Discrete environment limitation**: The method relies on Matterport3D's discrete navigation graph (predefined positions and action sets) and has not been validated in continuous environments (e.g., real robots). The authors explicitly acknowledge this limitation.
- **Insufficient fine-grained understanding**: 29.82% of errors stem from incorrect room type judgments; the model may reach rooms without the target object when multiple similar rooms exist (e.g., multiple bathrooms).
- **Poor language robustness**: Only one of three instructions for the same trajectory succeeds, indicating sensitivity to instruction wording variations.
- **SOON data noise**: Approximately 50% of SOON's object annotations have polygons that do not contain the object center point; although the authors cleaned annotations with the BUTD detector, pseudo-label quality may still limit the upper bound.
- **Computational resources undisclosed**: The paper does not report total parameter count, inference frequency, or training time, making reproduction costs difficult to estimate.
- **Marginal effect of synthetic data augmentation**: In the PID policy learning stage, synthetic instruction data provides no improvement (SR 46.98→46.58), indicating augmentation is only effective for pre-training.

## Engineering Insights

- **Reproduction priority**: First verify GASA's distance matrix computation—E must be pairwise shortest path distances (precomputed with Floyd or BFS), not direct adjacency distances. This is critical for the attention bias; incorrect implementation will lose graph structure information.
- **Training order sensitivity**: Pre-training (SAP+OG+Aux) and policy learning (PID) must be separated. Synthetic data augmentation is only effective in the pre-training stage and slightly reduces SR in the PID stage—do not uniformly apply augmented data across all stages.
- **λ balance factor**: Navigation performance is best at λ=0 (SR 48.22) but object localization is weak (RGS 32.12); λ=0.2 is the overall optimum. If the downstream task emphasizes object localization more, λ=0.5 can be tried (RGS 32.43). All metrics decline at λ=1, indicating that excessive behavior cloning weight suppresses PID's exploration gains.
- **Backtracking behavior is a feature, not a bug**: 48.6% of trajectories in val unseen contain backtracking, but only 13.7% in val seen—the backtracking ratio can serve as a diagnostic metric for generalization ability. If your model's backtracking ratio in unseen is significantly lower, it may indicate insufficient exploration.
- **SOON pitfalls**: The dataset split uses the challenge split rather than the original paper's split, and annotations must be cleaned with the BUTD detector. Ensure the split version is confirmed during reproduction; otherwise, comparison results are meaningless.
- **Hardware requirements are modest**: Pre-training requires 2 P100 GPUs, fine-tuning 1 P100, but SOON fine-tuning uses a batch size of only 2, requiring attention to gradient accumulation strategies.

## 개요

DUET(Dual-scale Graph Transformer)은 시각-언어 내비게이션(VLN)을 위한 이중 스케일 그래프 트랜스포머 모델로, 프랑스 팀이 제안했다. 핵심 기여는 순환 상태 추적을 순수 트랜스포머 아키텍처로 대체하고, 조대한 스케일의 토폴로지 그래프와 미세한 스케일의 파노라마 인코딩의 협력적 추론을 통해 목표 지향 내비게이션(REVERIE, SOON)에서 탐색 효율성과 객체 접지 정확도를 동시에 향상시킨 것이다. REVERIE 테스트 세트에서 성공률은 당시 SOTA(HAMT) 대비 22.11% 향상되었고, SPL은 9.39% 향상되었다.

## 그것이 바꾼 것

이 작업의 진정한 가치는 VLN에서 오랫동안 기본값으로 여겨졌던 두 가지 "기반"을 동시에 건드렸다는 점이다: 하나는 상태 추적 메커니즘이고, 다른 하나는 행동 공간의 정의다. 기존의 주류 방법(HAMT, E.T.)은 내비게이션을 마르코프 결정 과정으로 간주하여 각 단계에서 인접 위치로만 이동할 수 있었고, N단계를 되돌아가려면 모델을 N번 다시 실행해야 했다——이는 순환 아키텍처의 오류 누적을 증폭시킬 뿐만 아니라 장거리 계획을 계산적으로 감당할 수 없게 만들었다. DUET은 "되돌아가기"를 암시적 시퀀스 재생에서 명시적 그래프 탐색으로 바꾸었다: 토폴로지 그래프가 구축되면 임의 노드에서 임의 노드까지의 경로는 Floyd 알고리즘으로 한 번에 풀 수 있으며, 모델은 목표 노드만 예측하면 되고 점진적으로 접근할 필요가 없다. 이는 "과정 제어"에서 "목표 제어"로의 패러다임 전환이다.

또 다른 변경된 가정은 "토폴로지 그래프 노드에 압축된 시각적 특징으로 충분하다"는 것이다. 기존 그래프 기반 방법(예: [8,19,20])은 그래프의 확장성을 위해 노드의 세부 정보를 희생했고, 그 결과 "파란 소파 옆의 플로어 램프"와 같은 지시문의 설명이 그래프 노드와 정렬될 수 없었다. DUET의 통찰은: 조대한 스케일 그래프는 "어디로 갈지"를 담당하고, 미세한 스케일 파노라마는 "거기에 무엇이 있는지 확인"을 담당하며, 둘 다 동시에 존재하고 동적으로 융합되어야 한다는 것이다. 이 "이중 스케일" 설계는 단순한 멀티태스크 연결이 아니라 VLN 작업 본질의 재분해다——내비게이션은 계층적 의사결정이지 단일 스케일 시퀀스 의사결정이 아니다.

## 방법 분해

### 토폴로지 매핑: 증분 그래프 구축
- 환경 그래프 G는 알 수 없으며, 모델은 경로를 따라 점진적으로 로컬 그래프 Gt = {Vt, Et}를 구축한다. 노드는 세 가지 유형으로 분류된다: 방문됨, 내비게이션 가능(탐색되지 않았지만 부분적으로 보임), 현재 노드.
- 각 단계에서 현재 노드의 방문되지 않은 이웃을 그래프에 추가하고, 간선은 서로 내비게이션 가능한 노드만 연결한다.
- 노드 시각적 표현: 현재 노드는 파노라마 특징 Rt와 객체 특징 Ot의 평균 풀링을 사용하고, 내비게이션 가능한 노드는 여러 위치에서 보일 때 모든 부분 뷰 임베딩을 평균한다.
- 핵심 설계: Rt, Ot를 미세한 표현으로 유지하고 압축하지 않는다——이것이 이후 미세 스케일 추론의 입력이다.

### 조대한 스케일 교차 모달 인코더(전역 행동)
- 노드 임베딩 = 시각적 특징 + 위치 인코딩(현재 노드의 자아 중심 관점에서 방향/거리) + 내비게이션 단계 인코딩(방문된 노드의 최근 방문 시간, 미탐색은 0).
- 'stop' 노드 v0를 추가하고 모든 노드와 완전 연결한다.
- 그래프 인식 자기 주의(GASA): 표준 자기 주의에 학습 가능한 거리 편향 행렬 M = EWe + be를 추가하며, 여기서 E는 쌍별 최단 거리 행렬이다. 수식: GASA(X) = Softmax(XWq(XWk)T/√d + M)XWv.
- 전역 행동 점수: sci = FFN(ˆvi), 방문된 노드는 마스킹한다.

### 미세한 스케일 교차 모달 인코더(로컬 접지)
- 입력: 지시문 + 현재 노드의 {Rt, Ot}.
- 두 가지 유형의 위치 임베딩: ①현재 노드의 시작 노드에 대한 지도 위치("1층 거실로 가기" 지원), ②각 이웃의 현재 노드에 대한 자아 중심 방향("우회전" 지원).
- 'stop' 토큰 r0를 추가하고 [r0; Rt; Ot]로 연결하여 표준 교차 모달 트랜스포머에 입력한다.
- 출력: 로컬 행동 점수 s fi와 객체 접지 점수(ˆOt 기반 FFN).

### 동적 융합
- 로컬 점수를 전역 공간에 매핑: 방문된 노드 점수 = sback(N(Vt)에서 방문된 노드 점수의 합), 방문되지 않은 이웃은 원래 점수를 유지한다.
- 융합 가중치: σt = Sigmoid(FFN([ˆv0; ˆr0])), 즉 두 스케일의 stop 표현이 어떤 스케일을 신뢰할지 함께 결정한다.
- 최종 점수: si = σtsci + (1 − σt)s f′i.

### 훈련
- 사전 훈련: 행동 복제(SAP) + 마스크 언어 모델링(MLM) + 마스크 영역 분류(MRC) + 객체 접지(OG).
- 정책 학습: 의사 상호작용 시연자(PID), DAgger와 유사하며, 훈련 시 환경 그래프에 접근할 수 있고 최종 목적지까지의 전체 최단 거리를 가진 노드를 다음 목표로 선택하여 전문가 궤적의 차선성을 피한다.
- 총 손실: L = λLSAP + LPID + LOG, λ는 행동 복제와 PID의 균형을 맞춘다.

### 추론
- 각 단계에서 토폴로지 그래프 업데이트 → 전역 행동 예측 → 내비게이션 행동이면 Floyd 알고리즘으로 최단 경로 계산 → 최대 단계 수 초과 시 강제 중지 → 중지 위치에서 객체 점수가 가장 큰 객체 선택.

## 핵심 혁신

1. **그래프 인식 자기 주의(GASA)**: 토폴로지 그래프의 쌍별 거리 행렬을 주의 편향으로 트랜스포머에 주입한다. 이는 단순한 그래프 신경망 메시지 전달이 아니라, 주의 가중치가 "노드 간 최단 경로 길이"를 직접 인코딩하게 한다——모델은 "거리가 가까울수록 더 관련 있다"는 귀납적 편향을 암시적으로 학습할 수 있으며, 동시에 GNN의 과평활화 문제를 피한다. 절제 실험에서 GASA는 동적 융합 하에 SPL을 32.88에서 33.73으로, RGS를 29.91에서 32.15로 향상시켰다.

2. **의사 상호작용 시연자(PID)로 강화 학습 대체**: 전통적 RL(예: REVERIE의 RL 미세 조정)은 환경과 상호작용하여 샘플링해야 하므로 샘플 효율이 낮고 불안정하다. PID는 훈련 시 접근 가능한 환경 그래프를 활용하여 "최종 목적지까지의 최단 경로상 다음 노드"를 직접 감독 신호로 선택하며, 이는 최적 경로 계획기로 온라인 시연을 생성하는 것과 같다. 절제 실험에서 PID는 RL보다 SR에서 4.63% 향상(42.35→46.98)되었고 추가 상호작용 비용이 없다.

3. **이중 스케일 동적 융합**: 단순한 점수 평균이 아니라, 두 스케일의 stop 표현으로 게이트 가중치 σt를 학습한다. 이 설계의 정교함은: σt 자체가 "현재 노드가 충분히 확신하는지"를 반영한다——미세 스케일이 stop에 확신이 있을 때(예: 목표 방에 도달), σt는 0에 가까워지고 미세 스케일이 주도한다; 장거리 탐색이 필요할 때는 조대한 스케일이 주도한다. 절제 실험에서 동적 융합은 평균 융합보다 SPL에서 1.79% 향상(31.94→33.73)되었다.

## 경계 및 한계

- **이산 환경 한계**: 방법은 Matterport3D의 이산 내비게이션 그래프(사전 정의된 위치와 행동 집합)에 의존하며, 연속 환경(예: 실제 로봇)에서 검증되지 않았다. 저자는 이 한계를 명시적으로 인정한다.
- **세밀한 이해 부족**: 29.82%의 오류는 방 유형 판단 오류에서 비롯되며, 모델은 여러 유사한 방(예: 여러 욕실)이 있을 때 목표 객체가 없는 방에 도달할 수 있다.
- **언어 견고성 부족**: 동일 궤적의 세 지시문 중 하나만 성공하며, 모델은 지시문 표현 변화에 민감하다.
- **SOON 데이터 노이즈**: SOON의 객체 주석 중 약 50%의 폴리곤이 객체 중심점을 포함하지 않으며, 저자가 BUTD 검출기로 정리했지만 의사 레이블 품질이 여전히 상한을 제한할 수 있다.
- **계산 자원 미공개**: 논문은 총 파라미터 수, 추론 빈도, 훈련 시간을 공개하지 않아 재현 비용을 예측하기 어렵다.
- **합성 데이터 증강의 한계 효과**: PID 정책 학습 단계에서 합성 지시문 데이터는 향상이 없었고(SR 46.98→46.58), 증강이 사전 훈련에만 효과적임을 시사한다.

## 공학적 시사점

- **재현 우선순위**: 먼저 GASA의 거리 행렬 계산을 확인하라——E는 쌍별 최단 경로 거리(Floyd 또는 BFS로 사전 계산)여야 하며, 직접 인접 거리가 아니다. 이것이 주의 편향의 핵심이며, 잘못 구현하면 그래프 구조 정보가 손실된다.
- **훈련 순서 민감성**: 사전 훈련(SAP+OG+Aux)과 정책 학습(PID)은 반드시 분리해야 한다. 합성 데이터 증강은 사전 훈련 단계에서만 효과적이며, PID 단계에서는 오히려 SR을 약간 낮춘다——모든 단계에서 증강 데이터를 일괄 사용하지 말라.
- **λ 균형 인자**: λ=0일 때 내비게이션 성능이 가장 좋지만(SR 48.22) 객체 위치 파악이 약하다(RGS 32.12); λ=0.2가 종합적으로 최적이다. 하위 작업이 객체 위치 파악에 더 중점을 둔다면 λ=0.5(RGS 32.43)를 시도할 수 있다. λ=1일 때 모든 지표가 전반적으로 하락하며, 행동 복제 가중치가 너무 높으면 PID의 탐색 이득을 억제함을 시사한다.
- **되돌아가기 행동은 특징이지 버그가 아니다**: val unseen에서 48.6%의 궤적이 되돌아가기를 포함하지만, val seen은 13.7%에 불과하다——되돌아가기 비율은 일반화 능력의 진단 지표로 사용할 수 있다. 모델의 unseen에서 되돌아가기 비율이 이 값보다 현저히 낮다면 탐색 부족을 의미할 수 있다.
- **SOON의 함정**: 데이터셋 분할은 원래 논문 분할이 아닌 챌린지 대회 분할을 사용하며, BUTD 검출기로 주석을 정리해야 한다. 재현 시 반드시 분할 버전을 확인해야 하며, 그렇지 않으면 비교 결과가 무의미하다.
- **하드웨어 요구 사항이 높지 않음**: 사전 훈련은 P100 2개, 미세 조정은 P100 1개면 충분하지만, SOON 미세 조정 배치 크기가 2에 불과하므로 그래디언트 누적 전략에 주의해야 한다.
