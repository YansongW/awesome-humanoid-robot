## 概述

BeyondMimic 是首个在真实人形机器人（Unitree G1）上，通过引导扩散（guided diffusion）将大规模人类运动数据转化为多功能、自然全身控制的系统。它由运动跟踪（motion tracking）与引导扩散策略（guided diffusion policy）两部分组成，前者解决高质量动态运动跟踪，后者解决多技能组合与下游任务执行，并首次在真实硬件上实现了跳跃、侧手翻、舞蹈等高度动态行为。

## 它改变了什么

此前领域内存在一条清晰的分界线：基于物理的角色动画方法（如 DeepMimic 系）在仿真中表现优异，但迁移到真实人形机器人时被未建模动力学、硬件限制和不完美的状态估计击穿；而真实硬件上的多运动跟踪方法（OmniH2O、Exbody、HumanPlus、TWIST 等）要么运动质量严重退化，要么仅支持低动态行走，要么牺牲全局轨迹跟踪换取鲁棒性。作者指出，至今没有系统能在真实人形硬件上同时具备高运动质量和高度动态技能的多运动跟踪演示——这是 BeyondMimic 要填补的空白。

在扩散策略一侧，现有方法（如 HugWBC）缺乏灵活的测试时引导机制，因为任务目标定义在状态空间，而动作序列定义在 PD 目标或力矩空间，两者难以直接比较；新任务通常需要重新训练。BeyondMimic 的关键改变在于：将任务成本函数直接定义为可微函数，通过贝叶斯定理将引导项转化为成本负梯度，从而在测试时无需重新训练即可切换任务（摇杆转向、航点导航、碰撞避免）。此外，作者观察到扩散模型在分布外场景下表现出「惰性」（inert）——机器人摔倒或被物理阻挡时，人类可安全扶回，而典型 RL 策略会产生 erratic 行为——这为真实部署中的安全性提供了新的视角。

## 方法拆解

### 运动跟踪框架（第 III 节）
- **锚定跟踪目标**：不跟踪绝对身体姿态，而是指定参考体 `b_ref`（通常为根或躯干）作为锚点，允许全局漂移同时保留风格。锚定期望姿态公式：`T_hat_b = T_anchor * T^{-1}_{b_ref} * T_{b,motion}`，其中 `p_anchor = [p_{b_ref.x}, p_{b_ref.y}, p_{b_ref.z,motion}]`，`R_anchor = R_z(yaw(R_{b_ref} R^T_{b_ref,motion}))`。期望扭转不变：`V_hat_b = V_{b,motion}`。选择目标体子集 `B_target ⊆ B`，跟踪目标为 `g_tracking = (T_hat_{b_ref}, T_hat_b, V_hat_b)`。
- **观测空间**：单时间步向量，包含三部分：运动关节位置和速度 `c = [q_joint,motion, v_joint,motion]`（仅作为相位信息，不直接跟踪关节值）；参考体姿态跟踪误差 `ξ_{b_ref} ∈ R^9`（三维位置误差加旋转误差矩阵前两列）；运动无关观测（根扭转 `^{b_root}V_{b_root}`、关节位置 `q_joint`、速度 `v_joint`、上一动作 `a_last`）。完整观测 `o = [c, ξ_{b_ref}, ^{b_root}V_{b_root}, q_joint, v_joint, a_last]`。当不需要位置漂移补偿或状态估计不可靠时，可省略线性姿态跟踪误差和线性根扭转。
- **非对称 actor-critic**：critic 额外输入每个体相对于参考体的相对姿态 `T^{-1}_{b_ref} T_{b,motion}`。
- **关节阻抗与动作**：采用 Raibert 启发式设置 `k_{p,j} = I_j ω_n²`，`k_{d,j} = 2 I_j ζ ω_n`，其中 `I_j = k²_{g,j} I_{motor,j}`（反射惯量）。阻尼比 `ζ = 2`（过阻尼）而非 Raibert 的 1（临界阻尼），因为仅考虑电机电枢会低估惯量；自然频率设为较低的 10 Hz 以促进柔顺性。动作设计为归一化关节位置设定点：`q_{j,t} = q̄_j + α_j a_{j,t}`，其中 `α_j = 0.25 * τ_{j,max} / k_{p,j}`。设定点不裁剪关节运动学限制，作为生成期望力矩的中间变量。
- **奖励设计**：任务奖励为 DeepMimic 风格，正且均匀加权，在任务空间表达。误差指标：`e_{p,b} = p̂_b - p_b`，`e_{R,b} = log(R̂_b R_b^T)`，`e_{v,b} = v̂_b - v_b`，`e_{w,b} ≈ ŵ_b - w_b`。均方误差 `ē_χ = (1/|B_target|) Σ_{b∈B_target} ||e_{χ,b}||²`，高斯风格归一化 `r(ē_χ, σ) = exp(-ē_χ / σ²_χ)`，组合跟踪奖励 `r_tracking = Σ_{χ∈{p,R,v,w}} r(ē_χ, σ_χ)`。正则化仅三个惩罚：关节极限 `r_limit`、动作平滑 `r_smooth`、自碰撞 `r_contact`（计算末端执行器集合 `B_ee` 中自接触力超过阈值的体数）。总奖励 `r = r_target - λ_l r_limit - λ_s r_smooth - λ_c r_contact`。
- **终止与重置**：终止条件为参考体高度或姿态（仅俯仰和横滚）误差超阈值，或任何末端执行器高度显著偏离参考轨迹。重置时从整个参考轨迹自适应采样运动相位，并添加随机扰动。
- **自适应采样**：将整个运动起始索引分为 S 个一秒的 bin，按经验失败统计采样。失败率用指数移动平均平滑，使用非因果指数衰减核 `k(τ) = γ^τ` 加权附近失败。采样概率 `p_s = Σ_{τ=0}^{K-1} α^τ r̄_{s+τ} / Σ_{j=1}^{S} Σ_{τ=0}^{K-1} α^τ r̄_{j+τ}`，与均匀分布混合 `p'_s = λ(1/B) + (1-λ)p_s` 防止灾难性遗忘。起始 bin 从 `Multinomial(p'_1, ..., p'_S)` 抽取。
- **域随机化**：三项——地面摩擦系数、默认关节位置 `q̄_j`（模拟关节偏移校准误差）、躯干质心位置；另加环境扰动。

### 引导扩散框架（第 IV 节）
- 采用 Diffuse-CLoC 的状态-动作联合扩散框架。训练时预测未来轨迹 `τ_t = [a_t, s_{t+1}, ..., s_{t+H}, a_{t+H}]`，视界 H 步，条件为观测历史 `O_t = [s_{t-N}, a_{t-N}, ..., s_t]`（N 步）。损失 `L = MSE(x_{0,θ}(τ^k_t, O_t, k), τ_t)`。推理时 DDPM 更新规则 `τ^{k-1}_t = α_k(τ^k_t - γ_k ε_θ(τ^k_t, O_t, k) + N(0, σ²_k I))`。状态和动作使用独立噪声调度，`k = (k_s, k_a)`。
- **引导**：通过贝叶斯定理，条件分布分数分解为无条件分数加引导项：`∇_τ log p(τ|τ*) = ∇_τ log p(τ) + ∇_τ log p(τ*|τ)`。引导项为可微任务成本函数 `G^c_τ(τ)`，`p(τ*|τ) ∝ exp(-G^c_τ(τ))`，引导简化为成本的负梯度 `-∇_τ G^c_τ(τ)`。
- **下游任务成本函数**：
  - 摇杆转向：`G^c_τ(τ) = (1/2) Σ_{t'=t}^{t+H} ||V_{xy,t'}(τ_{t'}) - g_v||²`，`g_v ∈ R²` 为目标根速度。
  - 航点导航：`G^ts_τ(τ) = Σ_{t'=t}^{t+H} (1-e^{-2d})||P_x(s_{t'}) - g_p||² + e^{-2d}||V_{x,t'}(τ_{t'})||²`，`d = ||P_x(s_{t'}) - g_p||`（从梯度计算中分离）。
  - 碰撞避免：`G^c_τ(τ) = Σ_{t'=t}^{t+H} Σ_{b∈B_c} B(SDF(P_{b,t'}(τ)) - r_i, δ)`，使用 SDF 和松弛障碍函数 `B(x,δ)`（分段：`x≥δ` 时 `-ln(x)`；`x<δ` 时 `-ln(δ) + 0.5[((x-2δ)/δ)² - 1]`）。
- **动作延迟处理**：由于扩散模型在测试时处于延迟驱动（delayed actuation）状态，训练期间加入动作延迟域随机化（action delay domain randomization），这是与运动跟踪器的关键区别。
- **模型架构**：Transformer decoder，6 层、4 个注意力头、512 维嵌入，总参数量 19.95M。训练配置：观测历史 N=4，预测时域 H=16，通过损失掩码将动作预测时域限制为 8 步；20 个去噪步；注意力 dropout 概率 0.3。推理时使用 TensorRT 在 NVIDIA RTX 4060 Mobile GPU 上离板运行，异步独立线程，每步约 20 ms；引导代价梯度使用 CppAD 在每个去噪迭代中自动计算。

## 关键创新

1. **锚定跟踪（anchored tracking）机制**：不跟踪绝对身体姿态，而是指定参考体作为锚点，允许全局漂移同时保留风格。这一设计打破了此前方法在「全局轨迹跟踪」与「运动质量」之间的取舍——GMT 牺牲全局轨迹换取鲁棒性，而 BeyondMimic 通过锚定同时获得高动态性和风格保真。公式 `T_hat_b = T_anchor * T^{-1}_{b_ref} * T_{b,motion}` 将全局漂移从风格跟踪中解耦，是真实硬件上实现数分钟长参考运动跟踪的关键。

2. **自适应采样（adaptive sampling）**：将整个运动起始索引分为一秒的 bin，按经验失败统计（指数移动平均平滑 + 非因果指数衰减核加权）采样起始相位，并与均匀分布混合防止灾难性遗忘。这一机制直接解决了长序列训练中「困难片段被反复失败、简单片段被过度训练」的问题——消融显示无自适应采样时所有长序列在 mujoco 中 30k 训练迭代后仍失败，有自适应采样时 10k 迭代收敛。

3. **测试时引导（test-time guidance）作为任务切换机制**：通过贝叶斯定理将引导项转化为可微任务成本函数的负梯度 `-∇_τ G^c_τ(τ)`，使得摇杆转向、航点导航、碰撞避免等下游任务无需重新训练即可在测试时切换。这解决了此前扩散策略「新任务需要重新训练」的根本局限。此外，作者发现扩散模型在分布外场景下表现出「惰性」——机器人摔倒或被物理阻挡时，人类可安全扶回，而典型 RL 策略会产生 erratic 行为——这一性质对真实部署的安全性具有重要意义。

## 实验与结果

### 真实世界性能
- 短动态运动：Cristiano Ronaldo 庆祝动作和 Side Kick 可连续重复 5 次，无稳定性或跟踪质量退化。
- 静态平衡运动：Single Leg Balance 和 Swallow Balance 使用与其他运动相同的超参数完成。
- 高度动态运动：双/单腿跳跃、连续两个侧手翻、往返冲刺、带 180° 和 360° 旋转的前跳；360° 旋转跳是身体要求极高的动作。
- 风格化运动：Charleston 舞、Moonwalk、行走到爬行过渡、老年风格行走、羽毛球和网球等运动动作。

### 自适应采样消融（表 II，收敛迭代次数）

| 运动 | 无 AS | 有 AS |
|---|---|---|
| Cristiano Ronaldo | 3k | 1.5k |
| Swallow Balance | 2.8k | 1.8k |
| dance1_subject1 | 失败（侧手翻） | 8k |
| dance2_subject1 | 失败（跳跃旋转） | 9k |

无自适应采样时，所有长序列在 mujoco 中 30k 训练迭代后仍失败；有自适应采样时 10k 迭代收敛。

### 状态表示消融（表 III，成功率 %）

| 状态表示 | Walk + Perturb | Joystick Control |
|---|---|---|
| Body-Pos State | 100 | 80 |
| Joint-Rot State | 72 | 0 |

Body-Pos 状态在两个任务上均显著优于 Joint-Rot。作者推测 Joint-Rot 理论上更具马尔可夫性，但关节位置估计的小误差通过运动学链累积，使其比直接预测笛卡尔身体姿态更容易受到扩散预测误差累积的影响。在 Joint-Rot 状态上添加引导时，joystick 控制即使经过仔细调参也会快速且突然地失败，原因是基础控制器缺乏鲁棒性，引导将其进一步推离分布。

### 工程性能
- 状态估计：500 Hz，使用低层广义动量观测器结合卡尔曼滤波器；无外部动作捕捉系统。
- 推理：所有策略在机器人 CPU 上使用 ONNX Runtime 执行，每次推理步骤小于 1.0 ms；扩散策略在 NVIDIA RTX 4060 Mobile GPU 上每步约 20 ms（20 个去噪步）。
- 数据：LAFAN1 数据集 40 个几分钟长参考，随机选 25 个训练；29 个片段用于硬件测试。

## 边界与局限

论文未设明确的局限性章节，但可从事实要点中识别以下边界：

- **状态估计漂移**：仍会遇到偶发失败，原因是状态估计漂移，特别是当末端执行器接触假设被违反时，例如跟踪策略的起身动作或某些扩散策略的恢复模式。开发一个能泛化到如此多样化动作的状态估计器仍是一个挑战性问题，留作未来工作。
- **技能转换困难**：当前基于动作的扩散模型在技能转换方面存在困难——模型可被概念化为学习一个流形，每个技能对应一条曲线，转换发生在曲线交点处；分类器引导可作为将模型「吸附」到不同曲线上的机制，但当目标技能在流形上距离过远时，模型常被困在当前模式中无法完成转换。
- **测试场地限制**：因测试场地空间有限，只选择 29 个片段进行硬件测试；部分 LAFAN1 片段在真实硬件上未测试。
- **极端接触丰富行为**：对于如从地面起身等极端接触丰富行为，需要额外措施（LIO 位置校正或排除状态估计相关观测）。
- **未做之事**：未做 real-to-sim 适配，未使用动作特定的随机化参数；扩散策略的具体消融结果未在事实要点中给出（论文片段在「VI Diffusion Experiments and Results」处截断）。

## 工程启示

对复现与工程部署的具体指导：

1. **先核对锚定参考体的选择**：`b_ref` 的选择（通常为根或躯干）直接影响全局漂移与风格保真的平衡。复现时应先验证锚定公式 `T_hat_b = T_anchor * T^{-1}_{b_ref} * T_{b,motion}` 在目标硬件上的数值稳定性，特别是旋转误差矩阵前两列的提取方式。

2. **自适应采样是长序列训练的关键**：消融数据明确显示，无自适应采样时所有长序列在 30k 迭代后仍失败，有自适应采样时 10k 迭代收敛。复现时务必实现指数移动平均平滑的失败统计与非因果指数衰减核 `k(τ) = γ^τ`，并保留与均匀分布的混合比例 `λ` 以防止灾难性遗忘。

3. **关节阻抗参数是硬件适配的核心**：阻尼比 `ζ = 2`（过阻尼）而非 Raibert 的 1，自然频率设为 10 Hz。复现时需根据目标电机的反射惯量 `I_j = k²_{g,j} I_{motor,j}` 重新计算 `k_{p,j}` 和 `k_{d,j}`，否则动作设定点 `q_{j,t} = q̄_j + α_j a_{j,t}` 的缩放因子 `α_j = 0.25 * τ_{j,max} / k_{p,j}` 会失真。

4. **状态表示选择直接决定扩散策略成败**：Body-Pos 状态在 Walk+Perturb 上 100% vs Joint-Rot 72%，在 Joystick Control 上 80% vs 0%。复现扩散策略时，不要被 Joint-Rot 的理论马尔可夫性吸引——关节位置估计误差通过运动学链累积，会放大扩散预测误差。直接预测笛卡尔身体姿态虽然需要更大的表示和模型，但提供显式空间锚定。

5. **动作延迟域随机化不可省略**：这是扩散策略与运动跟踪器的关键区别。由于扩散模型在测试时处于延迟驱动状态，训练期间必须加入动作延迟域随机化，否则部署时会出现观测接收与动作物理执行之间的时间滞后问题。

6. **最容易踩坑的地方**：扩散策略在 Joint-Rot 状态上添加引导时会快速且突然地失败——即使仔细调参。如果下游任务需要引导（如 joystick 控制），务必使用 Body-Pos 状态表示。此外，极端接触丰富行为（如起身）需要 LIO 位置校正或排除状态估计相关观测，否则状态估计漂移会导致偶发失败。

## Overview

BeyondMimic is the first system to transform large-scale human motion data into versatile, natural full-body control on a real humanoid robot (Unitree G1) through guided diffusion. It consists of two components: motion tracking and a guided diffusion policy. The former addresses high-quality dynamic motion tracking, while the latter addresses multi-skill combination and downstream task execution. It achieves highly dynamic behaviors such as jumping, cartwheels, and dancing on real hardware for the first time.

## What It Changes

Previously, there was a clear dividing line in the field: physics-based character animation methods (such as the DeepMimic family) performed excellently in simulation but broke down when transferred to real humanoid robots due to unmodeled dynamics, hardware limitations, and imperfect state estimation. Meanwhile, multi-motion tracking methods on real hardware (OmniH2O, Exbody, HumanPlus, TWIST, etc.) either suffered severe degradation in motion quality, only supported low-dynamic walking, or sacrificed global trajectory tracking for robustness. The authors point out that no system has yet demonstrated multi-motion tracking with both high motion quality and highly dynamic skills on real humanoid hardware—this is the gap BeyondMimic fills.

On the diffusion policy side, existing methods (such as HugWBC) lack flexible test-time guidance mechanisms because task objectives are defined in state space while action sequences are defined in PD target or torque space, making direct comparison difficult; new tasks typically require retraining. The key change in BeyondMimic is defining task cost functions directly as differentiable functions and converting the guidance term into the negative gradient of the cost via Bayes' theorem, enabling task switching (joystick steering, waypoint navigation, collision avoidance) at test time without retraining. Additionally, the authors observe that diffusion models exhibit "inertness" in out-of-distribution scenarios—when the robot falls or is physically blocked, a human can safely assist it back up, whereas typical RL policies produce erratic behavior—providing a new perspective on safety in real-world deployment.

## Method Breakdown

### Motion Tracking Framework (Section III)
- **Anchored tracking target**: Instead of tracking absolute body pose, a reference body `b_ref` (typically the root or torso) is specified as the anchor, allowing global drift while preserving style. The anchored desired pose formula: `T_hat_b = T_anchor * T^{-1}_{b_ref} * T_{b,motion}`, where `p_anchor = [p_{b_ref.x}, p_{b_ref.y}, p_{b_ref.z,motion}]`, `R_anchor = R_z(yaw(R_{b_ref} R^T_{b_ref,motion}))`. The desired twist is invariant: `V_hat_b = V_{b,motion}`. A subset of target bodies `B_target ⊆ B` is selected, with tracking target `g_tracking = (T_hat_{b_ref}, T_hat_b, V_hat_b)`.
- **Observation space**: A single time-step vector containing three parts: motion joint positions and velocities `c = [q_joint,motion, v_joint,motion]` (used only as phase information, not directly tracked joint values); reference body pose tracking error `ξ_{b_ref} ∈ R^9` (3D position error plus the first two columns of the rotation error matrix); motion-independent observations (root twist `^{b_root}V_{b_root}`, joint positions `q_joint`, velocities `v_joint`, previous action `a_last`). The full observation is `o = [c, ξ_{b_ref}, ^{b_root}V_{b_root}, q_joint, v_joint, a_last]`. Linear pose tracking error and linear root twist can be omitted when position drift compensation is not needed or state estimation is unreliable.
- **Asymmetric actor-critic**: The critic additionally receives the relative pose of each body with respect to the reference body `T^{-1}_{b_ref} T_{b,motion}`.
- **Joint impedance and actions**: Raibert-inspired settings are used: `k_{p,j} = I_j ω_n²`, `k_{d,j} = 2 I_j ζ ω_n`, where `I_j = k²_{g,j} I_{motor,j}` (reflected inertia). The damping ratio `ζ = 2` (overdamped) rather than Raibert's 1 (critically damped), because considering only the motor armature underestimates inertia; the natural frequency is set to a lower 10 Hz to promote compliance. Actions are designed as normalized joint position setpoints: `q_{j,t} = q̄_j + α_j a_{j,t}`, where `α_j = 0.25 * τ_{j,max} / k_{p,j}`. Setpoints are not clipped to joint kinematic limits, serving as intermediate variables for generating desired torques.
- **Reward design**: The task reward is DeepMimic-style, positive and uniformly weighted, expressed in task space. Error metrics: `e_{p,b} = p̂_b - p_b`, `e_{R,b} = log(R̂_b R_b^T)`, `e_{v,b} = v̂_b - v_b`, `e_{w,b} ≈ ŵ_b - w_b`. Mean squared error `ē_χ = (1/|B_target|) Σ_{b∈B_target} ||e_{χ,b}||²`, Gaussian-style normalization `r(ē_χ, σ) = exp(-ē_χ / σ²_χ)`, combined tracking reward `r_tracking = Σ_{χ∈{p,R,v,w}} r(ē_χ, σ_χ)`. Only three regularization penalties: joint limits `r_limit`, action smoothing `r_smooth`, self-collision `r_contact` (counting bodies in the end-effector set `B_ee` where self-contact force exceeds a threshold). Total reward `r = r_target - λ_l r_limit - λ_s r_smooth - λ_c r_contact`.
- **Termination and reset**: Termination conditions are reference body height or orientation (pitch and roll only) error exceeding thresholds, or any end-effector height significantly deviating from the reference trajectory. On reset, motion phases are adaptively sampled from the entire reference trajectory with random perturbations added.
- **Adaptive sampling**: The entire motion start index is divided into S one-second bins, sampled according to empirical failure statistics. Failure rates are smoothed with exponential moving average, using a non-causal exponential decay kernel `k(τ) = γ^τ` to weight nearby failures. Sampling probability `p_s = Σ_{τ=0}^{K-1} α^τ r̄_{s+τ} / Σ_{j=1}^{S} Σ_{τ=0}^{K-1} α^τ r̄_{j+τ}`, mixed with uniform distribution `p'_s = λ(1/B) + (1-λ)p_s` to prevent catastrophic forgetting. Start bins are drawn from `Multinomial(p'_1, ..., p'_S)`.
- **Domain randomization**: Three items—ground friction coefficient, default joint positions `q̄_j` (simulating joint offset calibration errors), torso center of mass position; plus environmental perturbations.

### Guided Diffusion Framework (Section IV)
- Adopts the Diffuse-CLoC state-action joint diffusion framework. During training, predicts future trajectory `τ_t = [a_t, s_{t+1}, ..., s_{t+H}, a_{t+H}]` with horizon H steps, conditioned on observation history `O_t = [s_{t-N}, a_{t-N}, ..., s_t]` (N steps). Loss `L = MSE(x_{0,θ}(τ^k_t, O_t, k), τ_t)`. At inference, DDPM update rule `τ^{k-1}_t = α_k(τ^k_t - γ_k ε_θ(τ^k_t, O_t, k) + N(0, σ²_k I))`. States and actions use independent noise schedules, `k = (k_s, k_a)`.
- **Guidance**: Via Bayes' theorem, the conditional distribution score decomposes into the unconditional score plus a guidance term: `∇_τ log p(τ|τ*) = ∇_τ log p(τ) + ∇_τ log p(τ*|τ)`. The guidance term is a differentiable task cost function `G^c_τ(τ)`, with `p(τ*|τ) ∝ exp(-G^c_τ(τ))`, simplifying guidance to the negative gradient of the cost `-∇_τ G^c_τ(τ)`.
- **Downstream task cost functions**:
  - Joystick steering: `G^c_τ(τ) = (1/2) Σ_{t'=t}^{t+H} ||V_{xy,t'}(τ_{t'}) - g_v||²`, where `g_v ∈ R²` is the target root velocity.
  - Waypoint navigation: `G^ts_τ(τ) = Σ_{t'=t}^{t+H} (1-e^{-2d})||P_x(s_{t'}) - g_p||² + e^{-2d}||V_{x,t'}(τ_{t'})||²`, where `d = ||P_x(s_{t'}) - g_p||` (separated from gradient computation).
  - Collision avoidance: `G^c_τ(τ) = Σ_{t'=t}^{t+H} Σ_{b∈B_c} B(SDF(P_{b,t'}(τ)) - r_i, δ)`, using SDF and a relaxed barrier function `B(x,δ)` (piecewise: `-ln(x)` when `x≥δ`; `-ln(δ) + 0.5[((x-2δ)/δ)² - 1]` when `x<δ`).
- **Action delay handling**: Since the diffusion model operates in delayed actuation mode at test time, action delay domain randomization is added during training—a key difference from the motion tracker.
- **Model architecture**: Transformer decoder, 6 layers, 4 attention heads, 512-dimensional embedding, 19.95M total parameters. Training configuration: observation history N=4, prediction horizon H=16, action prediction horizon limited to 8 steps via loss masking; 20 denoising steps; attention dropout probability 0.3. At inference, TensorRT is used on an NVIDIA RTX 4060 Mobile GPU off-board, running asynchronously on an independent thread, approximately 20 ms per step; guidance cost gradients are computed automatically using CppAD at each denoising iteration.

## Key Innovations

1. **Anchored tracking mechanism**: Instead of tracking absolute body pose, a reference body is specified as the anchor, allowing global drift while preserving style. This design breaks the previous trade-off between "global trajectory tracking" and "motion quality"—GMT sacrifices global trajectory for robustness, while BeyondMimic achieves both high dynamism and style fidelity through anchoring. The formula `T_hat_b = T_anchor * T^{-1}_{b_ref} * T_{b,motion}` decouples global drift from style tracking, and is key to tracking multi-minute reference motions on real hardware.

2. **Adaptive sampling**: The entire motion start index is divided into one-second bins, sampled according to empirical failure statistics (exponential moving average smoothing + non-causal exponential decay kernel weighting), mixed with uniform distribution to prevent catastrophic forgetting. This mechanism directly addresses the problem of "difficult segments repeatedly failing, easy segments over-trained" in long-sequence training—ablations show that without adaptive sampling, all long sequences still fail after 30k training iterations in mujoco, while with adaptive sampling, convergence occurs at 10k iterations.

3. **Test-time guidance as a task switching mechanism**: Via Bayes' theorem, the guidance term is converted into the negative gradient of a differentiable task cost function `-∇_τ G^c_τ(τ)`, enabling downstream tasks such as joystick steering, waypoint navigation, and collision avoidance to be switched at test time without retraining. This resolves the fundamental limitation of previous diffusion policies where "new tasks require retraining." Additionally, the authors find that diffusion models exhibit "inertness" in out-of-distribution scenarios—when the robot falls or is physically blocked, a human can safely assist it back up, whereas typical RL policies produce erratic behavior—a property of significant importance for real-world deployment safety.

## Experiments and Results

### Real-World Performance
- Short dynamic motions: Cristiano Ronaldo celebration and Side Kick can be repeated 5 times consecutively without degradation in stability or tracking quality.
- Static balance motions: Single Leg Balance and Swallow Balance are completed using the same hyperparameters as other motions.
- Highly dynamic motions: Double/single leg jumps, two consecutive cartwheels, back-and-forth sprints, forward jumps with 180° and 360° rotations; the 360° rotational jump is an extremely physically demanding motion.
- Stylized motions: Charleston dance, Moonwalk, walk-to-crawl transitions, elderly-style walking, badminton and tennis sports motions.

### State Representation Ablation (Table III, success rate %)

| State Representation | Walk + Perturb | Joystick Control |
|---|---|---|
| Body-Pos State | 100 | 80 |
| Joint-Rot State | 72 | 0 |

Body-Pos state significantly outperforms Joint-Rot on both tasks. The authors speculate that Joint-Rot is theoretically more Markovian, but small errors in joint position estimation accumulate through the kinematic chain, making it more susceptible to diffusion prediction error accumulation than directly predicting Cartesian body pose. When guidance is added on the Joint-Rot state, joystick control fails quickly and abruptly even with careful tuning, because the base controller lacks robustness and guidance pushes it further out of distribution.

### Engineering Performance
- State estimation: 500 Hz, using a low-level generalized momentum observer combined with a Kalman filter; no external motion capture system.
- Inference: All policies execute on the robot's CPU using ONNX Runtime, with each inference step under 1.0 ms; the diffusion policy runs at approximately 20 ms per step on an NVIDIA RTX 4060 Mobile GPU (20 denoising steps).
- Data: 40 multi-minute references from the LAFAN1 dataset, with 25 randomly selected for training; 29 clips used for hardware testing.

## Boundaries and Limitations

The paper does not include a dedicated limitations section, but the following boundaries can be identified from factual points:

- **State estimation drift**: Occasional failures still occur due to state estimation drift, particularly when end-effector contact assumptions are violated, such as in the tracking policy's get-up motion or certain recovery modes of the diffusion policy. Developing a state estimator that generalizes to such diverse motions remains a challenging problem left for future work.
- **Skill transition difficulty**: The current action-based diffusion model struggles with skill transitions—the model can be conceptualized as learning a manifold where each skill corresponds to a curve and transitions occur at curve intersections; classifier guidance can serve as a mechanism to "adhere" the model to different curves, but when the target skill is too far away on the manifold, the model often gets trapped in its current mode and cannot complete the transition.
- **Test site limitations**: Due to limited test site space, only 29 clips were selected for hardware testing; some LAFAN1 clips were not tested on real hardware.
- **Extreme contact-rich behaviors**: For extreme contact-rich behaviors such as getting up from the ground, additional measures are needed (LIO position correction or excluding state-estimation-related observations).
- **What was not done**: No real-to-sim adaptation was performed, no action-specific randomization parameters were used; specific ablation results for the diffusion policy are not given in the factual points (the paper excerpt is truncated at "VI Diffusion Experiments and Results").

## Engineering Insights

Specific guidance for reproduction and engineering deployment:

1. **First verify the choice of anchored reference body**: The selection of `b_ref` (typically root or torso) directly affects the balance between global drift and style fidelity. When reproducing, first validate the numerical stability of the anchoring formula `T_hat_b = T_anchor * T^{-1}_{b_ref} * T_{b,motion}` on the target hardware, particularly the extraction method for the first two columns of the rotation error matrix.

2. **Adaptive sampling is key to long-sequence training**: Ablation data clearly shows that without adaptive sampling, all long sequences still fail after 30k iterations, while with adaptive sampling, convergence occurs at 10k iterations. When reproducing, be sure to implement exponential moving average smoothed failure statistics with the non-causal exponential decay kernel `k(τ) = γ^τ`, and preserve the mixing ratio `λ` with the uniform distribution to prevent catastrophic forgetting.

3. **Joint impedance parameters are the core of hardware adaptation**: The damping ratio `ζ = 2` (overdamped) rather than Raibert's 1, with natural frequency set to 10 Hz. When reproducing, recalculate `k_{p,j}` and `k_{d,j}` based on the target motor's reflected inertia `I_j = k²_{g,j} I_{motor,j}`, otherwise the scaling factor `α_j = 0.25 * τ_{j,max} / k_{p,j}` for action setpoints `q_{j,t} = q̄_j + α_j a_{j,t}` will be distorted.

## 개요

BeyondMimic는 실제 휴머노이드 로봇(Unitree G1)에서 유도 확산(guided diffusion)을 통해 대규모 인간 모션 데이터를 다기능, 자연스러운 전신 제어로 변환하는 최초의 시스템입니다. 이는 고품질 동적 모션 추적을 해결하는 모션 추적(motion tracking)과 다중 스킬 조합 및 하위 작업 실행을 해결하는 유도 확산 정책(guided diffusion policy) 두 부분으로 구성되며, 실제 하드웨어에서 점프, 옆돌기, 춤과 같은 고도로 동적인 행동을 최초로 구현했습니다.

## 무엇을 바꾸었는가

이전에는 이 분야에 명확한 경계선이 존재했습니다: 물리 기반 캐릭터 애니메이션 방법(DeepMimic 계열)은 시뮬레이션에서 우수한 성능을 보였지만, 실제 휴머노이드 로봇으로 이전할 때 모델링되지 않은 역학, 하드웨어 제약, 불완전한 상태 추정으로 인해 붕괴되었습니다. 반면 실제 하드웨어에서의 다중 모션 추적 방법(OmniH2O, Exbody, HumanPlus, TWIST 등)은 모션 품질이 심각하게 저하되거나, 저동적 보행만 지원하거나, 견고성을 위해 전역 궤적 추적을 희생했습니다. 저자들은 현재까지 실제 휴머노이드 하드웨어에서 높은 모션 품질과 고도로 동적인 스킬을 동시에 갖춘 다중 모션 추적 데모를 제공한 시스템이 없다는 점을 지적합니다 — 이것이 BeyondMimic이 메우려는 공백입니다.

확산 정책 측면에서 기존 방법(예: HugWBC)은 유연한 테스트 시 유도 메커니즘이 부족합니다. 작업 목표가 상태 공간에 정의되고 동작 시퀀스가 PD 목표 또는 토크 공간에 정의되어 직접 비교가 어렵기 때문입니다. 새로운 작업은 일반적으로 재훈련이 필요합니다. BeyondMimic의 핵심 변화는 작업 비용 함수를 직접 미분 가능한 함수로 정의하고, 베이즈 정리를 통해 유도 항을 비용 음의 기울기로 변환하여 테스트 시 재훈련 없이 작업(조이스틱 조향, 웨이포인트 내비게이션, 충돌 회피)을 전환할 수 있게 한 것입니다. 또한 저자들은 확산 모델이 분포 외 시나리오에서 '관성'(inert)을 보인다는 것을 관찰했습니다 — 로봇이 넘어지거나 물리적으로 막혔을 때 인간이 안전하게 다시 세울 수 있지만, 일반적인 RL 정책은 불규칙한( erratic) 행동을 생성합니다 — 이는 실제 배포에서 안전성에 대한 새로운 관점을 제공합니다.

## 방법 분해

### 모션 추적 프레임워크 (섹션 III)
- **앵커 추적 목표**: 절대 신체 자세를 추적하지 않고, 기준체 `b_ref`(일반적으로 루트 또는 몸통)를 앵커로 지정하여 전역 드리프트를 허용하면서 스타일을 보존합니다. 앵커 기대 자세 공식: `T_hat_b = T_anchor * T^{-1}_{b_ref} * T_{b,motion}`, 여기서 `p_anchor = [p_{b_ref.x}, p_{b_ref.y}, p_{b_ref.z,motion}]`, `R_anchor = R_z(yaw(R_{b_ref} R^T_{b_ref,motion}))`. 기대 트위스트는 불변: `V_hat_b = V_{b,motion}`. 목표체 부분집합 `B_target ⊆ B`를 선택하고, 추적 목표는 `g_tracking = (T_hat_{b_ref}, T_hat_b, V_hat_b)`.
- **관측 공간**: 단일 시간 단계 벡터로 세 부분으로 구성: 모션 관절 위치 및 속도 `c = [q_joint,motion, v_joint,motion]`(위상 정보로만 사용, 관절 값을 직접 추적하지 않음); 기준체 자세 추적 오차 `ξ_{b_ref} ∈ R^9`(3차원 위치 오차 + 회전 오차 행렬의 처음 두 열); 모션 무관 관측(루트 트위스트 `^{b_root}V_{b_root}`, 관절 위치 `q_joint`, 속도 `v_joint`, 이전 동작 `a_last`). 전체 관측 `o = [c, ξ_{b_ref}, ^{b_root}V_{b_root}, q_joint, v_joint, a_last]`. 위치 드리프트 보상이 필요 없거나 상태 추정이 신뢰할 수 없을 때 선형 자세 추적 오차와 선형 루트 트위스트는 생략할 수 있습니다.
- **비대칭 actor-critic**: critic은 추가로 각 체의 기준체에 대한 상대 자세 `T^{-1}_{b_ref} T_{b,motion}`를 입력받습니다.
- **관절 임피던스 및 동작**: Raibert 휴리스틱을 사용하여 `k_{p,j} = I_j ω_n²`, `k_{d,j} = 2 I_j ζ ω_n` 설정, 여기서 `I_j = k²_{g,j} I_{motor,j}`(반사 관성). 감쇠비 `ζ = 2`(과감쇠)는 Raibert의 1(임계 감쇠) 대신 사용하는데, 이는 모터 전기자만 고려하면 관성을 과소평가하기 때문입니다. 고유 주파수는 유연성을 촉진하기 위해 낮은 10 Hz로 설정. 동작은 정규화된 관절 위치 설정점으로 설계: `q_{j,t} = q̄_j + α_j a_{j,t}`, 여기서 `α_j = 0.25 * τ_{j,max} / k_{p,j}`. 설정점은 관절 운동학적 제한을 자르지 않으며, 원하는 토크를 생성하는 중간 변수로 사용됩니다.
- **보상 설계**: 작업 보상은 DeepMimic 스타일로, 양수이고 균일하게 가중되며 작업 공간에서 표현됩니다. 오차 지표: `e_{p,b} = p̂_b - p_b`, `e_{R,b} = log(R̂_b R_b^T)`, `e_{v,b} = v̂_b - v_b`, `e_{w,b} ≈ ŵ_b - w_b`. 평균 제곱 오차 `ē_χ = (1/|B_target|) Σ_{b∈B_target} ||e_{χ,b}||²`, 가우시안 스타일 정규화 `r(ē_χ, σ) = exp(-ē_χ / σ²_χ)`, 결합 추적 보상 `r_tracking = Σ_{χ∈{p,R,v,w}} r(ē_χ, σ_χ)`. 정규화는 세 가지 페널티만 사용: 관절 한계 `r_limit`, 동작 평활화 `r_smooth`, 자체 충돌 `r_contact`(끝단효과기 집합 `B_ee`에서 자체 접촉 힘이 임계값을 초과하는 체 수 계산). 총 보상 `r = r_target - λ_l r_limit - λ_s r_smooth - λ_c r_contact`.
- **종료 및 리셋**: 종료 조건은 기준체 높이 또는 자세(피치와 롤만) 오차가 임계값을 초과하거나, 끝단효과기 높이가 참조 궤적에서 크게 벗어나는 경우입니다. 리셋 시 전체 참조 궤적에서 모션 위상을 적응적으로 샘플링하고 무작위 섭동을 추가합니다.
- **적응형 샘플링**: 전체 모션 시작 인덱스를 S개의 1초 bin으로 나누고 경험적 실패 통계에 따라 샘플링합니다. 실패율은 지수 이동 평균으로 평활화하고, 비인과 지수 감쇠 커널 `k(τ) = γ^τ`를 사용하여 주변 실패에 가중치를 부여합니다. 샘플링 확률 `p_s = Σ_{τ=0}^{K-1} α^τ r̄_{s+τ} / Σ_{j=1}^{S} Σ_{τ=0}^{K-1} α^τ r̄_{j+τ}`, 균일 분포와 혼합 `p'_s = λ(1/B) + (1-λ)p_s`하여 치명적 망각을 방지합니다. 시작 bin은 `Multinomial(p'_1, ..., p'_S)`에서 추출됩니다.
- **도메인 무작위화**: 세 가지 — 지면 마찰 계수, 기본 관절 위치 `q̄_j`(관절 오프셋 보정 오차 시뮬레이션), 몸통 질량 중심 위치; 추가로 환경 섭동.

### 유도 확산 프레임워크 (섹션 IV)
- Diffuse-CLoC의 상태-동작 결합 확산 프레임워크를 채택합니다. 훈련 시 미래 궤적 `τ_t = [a_t, s_{t+1}, ..., s_{t+H}, a_{t+H}]`을 예측하고, 시야 H 단계, 관측 이력 `O_t = [s_{t-N}, a_{t-N}, ..., s_t]`(N 단계)을 조건으로 합니다. 손실 `L = MSE(x_{0,θ}(τ^k_t, O_t, k), τ_t)`. 추론 시 DDPM 업데이트 규칙 `τ^{k-1}_t = α_k(τ^k_t - γ_k ε_θ(τ^k_t, O_t, k) + N(0, σ²_k I))`. 상태와 동작은 독립적인 노이즈 스케줄을 사용하며, `k = (k_s, k_a)`.
- **유도**: 베이즈 정리를 통해 조건부 분포 점수는 무조건부 점수에 유도 항을 더한 것으로 분해됩니다: `∇_τ log p(τ|τ*) = ∇_τ log p(τ) + ∇_τ log p(τ*|τ)`. 유도 항은 미분 가능한 작업 비용 함수 `G^c_τ(τ)`이며, `p(τ*|τ) ∝ exp(-G^c_τ(τ))`, 유도는 비용의 음의 기울기 `-∇_τ G^c_τ(τ)`로 단순화됩니다.
- **하위 작업 비용 함수**:
  - 조이스틱 조향: `G^c_τ(τ) = (1/2) Σ_{t'=t}^{t+H} ||V_{xy,t'}(τ_{t'}) - g_v||²`, `g_v ∈ R²`는 목표 루트 속도.
  - 웨이포인트 내비게이션: `G^ts_τ(τ) = Σ_{t'=t}^{t+H} (1-e^{-2d})||P_x(s_{t'}) - g_p||² + e^{-2d}||V_{x,t'}(τ_{t'})||²`, `d = ||P_x(s_{t'}) - g_p||`(기울기 계산에서 분리).
  - 충돌 회피: `G^c_τ(τ) = Σ_{t'=t}^{t+H} Σ_{b∈B_c} B(SDF(P_{b,t'}(τ)) - r_i, δ)`, SDF 및 완화 장벽 함수 `B(x,δ)` 사용(조각 함수: `x≥δ`일 때 `-ln(x)`; `x<δ`일 때 `-ln(δ) + 0.5[((x-2δ)/δ)² - 1]`).
- **동작 지연 처리**: 확산 모델이 테스트 시 지연 구동(delayed actuation) 상태에 있으므로 훈련 중 동작 지연 도메인 무작위화(action delay domain randomization)를 추가합니다. 이는 모션 트래커와의 핵심 차이점입니다.
- **모델 아키텍처**: Transformer decoder, 6개 레이어, 4개 어텐션 헤드, 512차원 임베딩, 총 파라미터 수 19.95M. 훈련 구성: 관측 이력 N=4, 예측 시역 H=16, 손실 마스킹을 통해 동작 예측 시역을 8단계로 제한; 20개의 노이즈 제거 단계; 어텐션 dropout 확률 0.3. 추론 시 TensorRT를 사용하여 NVIDIA RTX 4060 Mobile GPU에서 온보드 외부(offboard)로 실행, 비동기 독립 스레드, 단계당 약 20 ms; 유도 비용 기울기는 CppAD를 사용하여 각 노이즈 제거 반복에서 자동 계산됩니다.

## 핵심 혁신

1. **앵커 추적(anchored tracking) 메커니즘**: 절대 신체 자세를 추적하지 않고 기준체를 앵커로 지정하여 전역 드리프트를 허용하면서 스타일을 보존합니다. 이 설계는 이전 방법의 '전역 궤적 추적'과 '모션 품질' 사이의 트레이드오프를 깨뜨립니다 — GMT는 견고성을 위해 전역 궤적을 희생하는 반면, BeyondMimic은 앵커링을 통해 높은 동역학성과 스타일 충실도를 동시에 얻습니다. 공식 `T_hat_b = T_anchor * T^{-1}_{b_ref} * T_{b,motion}`은 전역 드리프트를 스타일 추적에서 분리하며, 실제 하드웨어에서 수 분 길이의 참조 모션 추적을 가능하게 하는 핵심입니다.

2. **적응형 샘플링(adaptive sampling)**: 전체 모션 시작 인덱스를 1초 bin으로 나누고 경험적 실패 통계(지수 이동 평균 평활화 + 비인과 지수 감쇠 커널 가중치)에 따라 시작 위상을 샘플링하며, 균일 분포와 혼합하여 치명적 망각을 방지합니다. 이 메커니즘은 긴 시퀀스 훈련에서 '어려운 구간이 반복적으로 실패하고 쉬운 구간이 과도하게 훈련되는' 문제를 직접 해결합니다 — 소거 실험에 따르면 적응형 샘플링 없이는 모든 긴 시퀀스가 mujoco에서 30k 훈련 반복 후에도 실패하지만, 적응형 샘플링이 있으면 10k 반복으로 수렴합니다.

3. **테스트 시 유도(test-time guidance)를 작업 전환 메커니즘으로 사용**: 베이즈 정리를 통해 유도 항을 미분 가능한 작업 비용 함수의 음의 기울기 `-∇_τ G^c_τ(τ)`로 변환하여 조이스틱 조향, 웨이포인트 내비게이션, 충돌 회피와 같은 하위 작업을 재훈련 없이 테스트 시 전환할 수 있게 합니다. 이는 기존 확산 정책의 '새 작업은 재훈련 필요'라는 근본적 한계를 해결합니다. 또한 저자들은 확산 모델이 분포 외 시나리오에서 '관성'을 보인다는 것을 발견했습니다 — 로봇이 넘어지거나 물리적으로 막혔을 때 인간이 안전하게 다시 세울 수 있지만, 일반적인 RL 정책은 불규칙한 행동을 생성합니다 — 이 특성은 실제 배포의 안전성에 중요한 의미를 갖습니다.

## 경계 및 한계

논문에는 명시적인 한계 섹션이 없지만, 사실적 요점에서 다음 경계를 식별할 수 있습니다:

- **상태 추정 드리프트**: 상태 추정 드리프트로 인해 간헐적 실패가 여전히 발생합니다. 특히 끝단효과기 접촉 가정이 위반될 때, 예를 들어 추적 정책의 기상 동작이나 일부 확산 정책의 복구 모드에서 그렇습니다. 이렇게 다양한 동작에 일반화할 수 있는 상태 추정기를 개발하는 것은 여전히 도전적인 문제이며 향후 작업으로 남아 있습니다.
- **스킬 전환 어려움**: 현재 동작 기반 확산 모델은 스킬 전환에 어려움이 있습니다 — 모델은 매니폴드를 학습하는 것으로 개념화할 수 있으며, 각 스킬은 곡선에 해당하고 전환은 곡선 교차점에서 발생합니다; 분류기 유도는 모델을 다른 곡선에 '흡착'시키는 메커니즘으로 작용할 수 있지만, 목표 스킬이 매니폴드에서 너무 멀리 떨어져 있으면 모델은 종종 현재 모드에 갇혀 전환을 완료하지 못합니다.
- **테스트 장소 제한**: 테스트 장소 공간이 제한되어 하드웨어 테스트에는 29개 클립만 선택되었습니다; 일부 LAFAN1 클립은 실제 하드웨어에서 테스트되지 않았습니다.
- **극단적 접촉 풍부 행동**: 지면에서 일어나기와 같은 극단적 접촉 풍부 행동의 경우 추가 조치(LIO 위치 보정 또는 상태 추정 관련 관측 제외)가 필요합니다.
- **수행하지 않은 것**: real-to-sim 적응을 수행하지 않았고, 동작별 무작위화 파라미터를 사용하지 않았습니다; 확산 정책의 구체적인 소거 결과는 사실적 요점에 제공되지 않았습니다(논문 조각이 'VI Diffusion Experiments and Results'에서 잘림).

## 엔지니어링 시사점

재현 및 엔지니어링 배포에 대한 구체적인 지침:

1. **앵커 기준체 선택을 먼저 확인**: `b_ref`의 선택(일반적으로 루트 또는 몸통)은 전역 드리프트와 스타일 충실도의 균형에 직접적인 영향을 미칩니다. 재현 시 앵커 공식 `T_hat_b = T_anchor * T^{-1}_{b_ref} * T_{b,motion}`이 목표 하드웨어에서 수치적으로 안정적인지, 특히 회전 오차 행렬의 처음 두 열 추출 방식을 먼저 검증해야 합니다.

2. **적응형 샘플링은 긴 시퀀스 훈련의 핵심**: 소거 데이터는 적응형 샘플링 없이는 모든 긴 시퀀스가 30k 반복 후에도 실패하고, 적응형 샘플링이 있으면 10k 반복으로 수렴함을 명확히 보여줍니다. 재현 시 지수 이동 평균 평활화된 실패 통계와 비인과 지수 감쇠 커널 `k(τ) = γ^τ`을 반드시 구현하고, 치명적 망각 방지를 위한 균일 분포 혼합 비율 `λ`을 유지해야 합니다.

3. **관절 임피던스 파라미터는 하드웨어 적응의 핵심**: 감쇠비 `ζ = 2`(과감쇠)는 Raibert의 1 대신, 고유 주파수는 10 Hz로 설정합니다. 재현 시 목표 모터의 반사 관성 `I_j = k²_{g,j} I_{motor,j}`을 기반으로 `k_{p,j}`와 `k_{d,j}`를 다시 계산해야 합니다. 그렇지 않으면 동작 설정점 `q_{j,t} = q̄_j + α_j a_{j,t}`의 스케일링 팩터 `α_j = 0.25 * τ_{j,max} / k_{p,j}`가 왜곡됩니다.
