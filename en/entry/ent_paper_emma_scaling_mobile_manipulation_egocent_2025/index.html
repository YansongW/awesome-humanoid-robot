Summary

Scaling mobile manipulation imitation learning is bottlenecked by expensive mobile robot teleoperation. We present Egocentric Mobile MAnipulation (EMMA), an end-to-end framework training mobile manipulation policies from human mobile manipulation data with static robot data, sidestepping mobile teleoperation. Institutions per source list: Georgia Tech.

Overview

EMMA is an end-to-end imitation learning framework that uses egocentric mobile manipulation data collected with Meta Project Aria glasses (RGB, hand pose, head pose) to replace expensive mobile teleoperation data, training differential-drive robots to complete mobile manipulation tasks. The core contribution lies in navigation retargeting, phase identification, and cross-embodiment joint training, achieving a 30% higher success rate with only 1 hour of human data compared to 1 hour of teleoperation data.

What It Changes

Mobile manipulation imitation learning has long been bottlenecked by teleoperation frameworks like Mobile ALOHA—collecting a single mobile manipulation demonstration requires two-person collaboration (one controlling the arm, one controlling the base), limiting data scale and thus policy generalization. What EMMA truly changes is the "cost structure" of data collection: turning near-zero-cost daily activities of humans wearing glasses and performing tasks into training signals, shifting mobile manipulation learning from a "lab luxury" to a "scalable collection" paradigm.

The key insight behind this is: navigation knowledge (where to go, how to get there) is inherently embodiment-agnostic. Human walking trajectories, after kinematic retargeting, can be directly transferred to differential-drive robots; while manipulation skills (grasping, placing) continue to rely on static robot data. This "pure human for navigation, dual-source for manipulation" split avoids the hardest whole-body motion mapping problem in cross-embodiment learning, which is the fundamental reason EMMA works.

Method Breakdown

Data Collection and Observation Space

  • Human data: Project Aria glasses capture first-person RGB (wide field of view), 3D bimanual hand pose H_p ∈ SE(3)×SE(3), and SLAM-estimated head pose H_d ∈ SE(3)
  • Robot data: Two inverted-mounted ViperX 300 robotic arms (6-DoF) + AgileX TRACER differential-drive base, wrist-mounted Intel Realsense D405 cameras
  • Shared modality: First-person RGB image I_ego serves as the anchor for cross-embodiment alignment

Navigation Retargeting (Key Design)

  1. Project head pose onto the ground plane to extract 2D base pose h_base^t ∈ SE(2)
  2. Maintain a sparse waypoint history W_t with displacement threshold d_thresh=0.25m

  4. Optimization objective: minimize position error (λ_pos=32.0), yaw error (λ_yaw=2.0), velocity smoothness (λ_smooth=1.0)
  5. Constraints: v ∈ [−1.0, 1.0] m/s, ω ∈ [−π, π] rad/s
  6. Integration step size Δt = 0.02 × STEP seconds

Phase Identification (Unsupervised)

  • Based on motion dynamics: hand velocity/head velocity ratio > τ_ratio=2.0 and head velocity < τ_head=0.4 m/s → manipulation phase
  • Fit K=2 component GMM to head positions; probability density < τ_pdf=10⁻³ → manipulation phase
  • Minimum duration filtering: τ_duration=30 frames (1 second) to prevent oscillatory switching

Unified Architecture

  • Per-modality dedicated stems (ResNet-18 for images, MLP for low-dimensional states)
  • Cross-attention tokenization (16 latent queries per modality, 8 attention heads)
  • 16-layer decoder-only Transformer backbone (hidden dimension 256, 8 heads)
  • Action heads: robot joints (ℝ^{K×14}), human Cartesian end-effector (ℝ^{K×3}), navigation actions ((x,y,ω) ∈ ℝ^{K×3}), phase prediction (p ∈ {0,1}^K)
  • Action chunk length uniformly set to 100; navigation linearly interpolated from 10 steps to 100 (x,y linear, yaw via atan2)

Joint Training Strategy

  • Human batches: activate human proprioception, shared vision stem, human manipulation head, navigation head, phase head
  • Robot batches: activate robot proprioception, wrist image stem, shared vision stem, robot manipulation head
  • Independent Z-score normalization per data source to handle distribution differences

Key Innovations

  1. Pure human transfer of navigation knowledge: Existing cross-embodiment works (e.g., EgoMimic) only handle tabletop manipulation. EMMA is the first to demonstrate that human walking trajectories, after kinematic retargeting, can directly drive differential robots with better performance than teleoperation data. This breaks the rigid dependence of mobile manipulation on teleoperation data.

  2. Unsupervised phase identification mechanism: Automatically distinguishes manipulation and navigation phases via hand/head velocity ratio + GMM spatial clustering, requiring no manual annotation. Phase-aware control (interpolating navigation actions to the first waypoint during manipulation) resolves the "walking while manipulating" mixed behavior in human data; ablation studies show removing this mechanism leads to complete failure.

  3. Dual-source joint training architecture: Human data provides navigation + manipulation semantics, static robot data provides precise manipulation control, with the shared first-person vision stem serving as the cross-embodiment bridge. This "human for navigation, robot for manipulation" responsibility split is more engineering-feasible than end-to-end cross-embodiment mapping.

Experiments and Results

We use Mobile ALOHA as the primary baseline, whose backbone is identical to EMMA, with only the prediction head extended to output future base velocity chunks, thereby comparing the source of mobile manipulation supervision under controlled variables. Additionally, we set up two ablation variants: EMMA w/o action retargeting (replacing optimization-based retargeting with raw human navigation actions) and EMMA w/o phase identification (removing the phase identification mechanism). All models undergo 50 trials each on three real-world mobile manipulation tasks (Table Service, Handover Wine, Grocery Shopping), with each trial lasting up to 2 minutes, totaling 950 mobile manipulation rollouts for evaluation. We report 95% confidence interval error bars and ensure all baselines and ablations are evaluated under identical environmental conditions and object positions.

Implication 1: Human demonstrations can replace mobile teleoperation data. In the Handover Wine task, replacing 1 hour of teleoperated mobile robot data with 1 hour of human mobile manipulation data, EMMA achieves an 82% success rate, a 30% improvement over the 52% success rate of teleoperation robot data (computed from table values 0.82→0.52), with statistical significance (p < 0.05). This validates hypothesis H1: without mobile teleoperation data, EMMA performs comparably or better than baselines trained on teleoperation data.

Implication 2: Kinematic retargeting and phase identification are critical components for skill transfer. Ablation experiments show that removing kinematic retargeting reduces success rate by 30%, while removing the phase identification mechanism leads to complete task failure. This validates hypothesis H2: both mechanisms are necessary for human-to-robot skill transfer—retargeting optimization ensures kinematic feasibility while minimizing deviation from human trajectories, and phase identification achieves reliable phase prediction through minimum duration constraints (τ_duration = 30 frames) and GMM spatial clustering (K = 2), preventing oscillatory switching during deployment.

Implication 3: Human data exhibits superior scaling efficiency. With fixed 1 hour of static robot manipulation data, EMMA's success rate steadily rises from 0.36 to 0.82 (human mobile manipulation data increasing from 15 minutes to 1 hour), while Mobile ALOHA improves from 0.26 to 0.52 (teleoperation data increasing from 15 minutes to 1 hour). The performance gap widens from 10% to 30% as data volume increases from 15 to 60 minutes (all computed from table values). This validates hypothesis H3: additional human mobile manipulation data yields greater performance gains than equivalent mobile robot teleoperation data.

Implication 4: Human data diversity provides scene generalization advantages. In new spatial layouts only seen through human demonstrations (human receivers randomly positioned in a larger 5m × 2m area), EMMA achieves a 54% success rate after collecting 30 minutes of human demonstrations, while Mobile ALOHA fails to complete the initial grasp due to environmental changes. Qualitative observations further indicate that EMMA exhibits better robustness to target poses, fewer environmental collisions, and higher overall success rates, demonstrating that the inherent diversity of human data provides generalization capabilities superior to lab-constrained teleoperation.

Boundaries and Limitations

The paper does not explicitly discuss limitations. Boundaries inferable from the method itself: - Navigation retargeting assumes human walking is sufficiently close to differential-drive kinematics, which may fail in scenarios requiring in-place rotation, narrow passages, etc. - Phase identification relies on hand/head velocity ratios, which may misclassify edge cases of "stationary manipulation" and "manipulation while walking" - Manipulation skills still depend on static robot data, not addressing cross-embodiment transfer of manipulation itself - Does not address multi-robot collaboration, long-term deployment stability, dynamic obstacle avoidance, and other practical deployment issues - Training configurations (epochs, batch size, learning rate) are not disclosed, introducing uncertainty for reproduction

Engineering Insights

  1. Verify data collection protocols first: Hand tracking confidence filtering (<0 discarded) and waypoint sparsification (≥0.25m) are critical for data quality. Strictly follow these during reproduction; otherwise, both phase identification and navigation retargeting will collapse.

  2. Phase identification is the biggest pitfall: Ablations show removing it directly zeroes performance. During reproduction, first independently verify that GMM clustering and velocity ratio thresholds produce reasonable phase segmentation on your data before end-to-end training.

  3. Navigation retargeting optimization weights are sensitive: λ_pos=32.0 is much larger than λ_yaw=2.0, indicating position accuracy takes priority over orientation. If your task requires precise orientation (e.g., aligning to shelves), you may need to adjust weights.

  4. Data volume planning: 15 minutes of human data already yields 36% success rate, reaching 82% at 1 hour. We recommend collecting 30 minutes first to validate the pipeline before deciding whether to scale to 1 hour.

  5. Hardware alignment: Human data uses SLAM-estimated camera poses, while robots use hand-eye calibration. The two coordinate systems must be strictly aligned to the first-person camera frame at observation time; otherwise, cross-embodiment transfer will introduce systematic bias.
