Summary

WorldVLA: Towards Autoregressive Action World Model (WorldVLA), is a 2025 large vision-language-action model for robotic manipulation, introduced by DAMO Academy, Alibaba Group, Hupan Lab, Zhejiang University.

Sources

  • WorldVLA: Towards Autoregressive Action World Model (arXiv)
  • WorldVLA source

概述

WorldVLA 是一个自回归动作世界模型，由阿里巴巴团队提出，旨在统一动作与图像的理解和生成。其核心贡献在于将动作作为输入纳入世界模型，通过动作注意力掩码策略解决自回归动作块生成的性能退化问题，实现动作模型与世界模型的相互增强。

它改变了什么

现有 VLA 模型将动作仅视为输出，缺乏对动作的因果影响分析，这限制了模型对动作后果的深层理解。同时，世界模型虽能预测未来视觉状态，却无法直接产出动作，形成功能缺口。WorldVLA 的变革在于打破这一壁垒，将动作同时作为输入和输出，使模型能够基于动作预测视觉未来，并基于视觉反馈优化动作决策。这种双向耦合改变了 VLA 的建模范式，使动作不再是被动响应，而是主动参与环境动态的构建。

方法拆解

架构与分词

  • 模型从 Chameleon 初始化，采用单一 LLM 架构，统一处理图像、文本与动作三种模态。
  • 图像分词器为 VQ-GAN，压缩比 16，码本大小 8192；256×256 图像生成 256 个 token，512×512 图像生成 1024 个 token。
  • 动作分词器将连续动作每维度离散化为 256 个 bin，动作表示为 7 个 token（3 相对位置、3 相对角度、1 绝对夹爪状态）。
  • 文本分词器为 BPE，词汇表 65536，共享图像与动作 token。

训练目标

  • 动作模型：输入文本为 "What action should the robot take to + task instruction + ?"，输入 M 张图像，输出 K 个动作，仅计算动作 token 损失 L_action。
  • 世界模型：输入文本为 "Generate the next frame based on the current image and the action."，基于动作重复 N 次预测下一帧，仅计算图像 token 损失 L_world。
  • 总损失 L = L_action + α·L_world，α 固定为 0.04，用于平衡图像 token（256 或 1024 个）与动作 token（7 个）的数量差异。

动作注意力掩码

  • 当前动作仅依赖文本和视觉输入，禁止访问先前动作，使自回归框架能并行生成多个动作。
  • 世界模型部分保持传统因果注意力掩码，确保时序一致性。

数据与训练

  • 混合动作模型数据与世界模型数据训练，世界模型学习环境物理，动作模型增强视觉理解。
  • 默认 M=2，K=10（Long 任务）或 K=5（其余任务），N=1。

关键创新

  1. 动作作为世界模型输入：首次将动作 token 纳入世界模型的输入序列，使模型能显式模拟动作后果，填补了 VLA 与纯世界模型之间的功能缺口。
  2. 动作注意力掩码策略：针对自回归模型顺序生成动作导致性能下降（成功率下降 10% 至 50%）的问题，提出当前动作仅依赖文本与视觉、禁止访问先前动作的掩码机制，带来 4% 至 23% 的成功率提升（由表内数值计算）。
  3. 统一分词器架构：三个独立分词器共享同一词汇表，在单一 LLM 内实现跨模态理解与生成，避免了多模型级联的误差传播。

结果表明，动作注意力掩码是性能提升的关键（Average 从 54.0 升至 76.6），世界模型联合训练进一步增益（78.1）。512×512 分辨率显著优于 256×256，尤其在 Object 任务（96.2 vs 89.0）。

边界与局限

  • 图像分词器依赖离散表示，在感知表达力上存在局限，可能限制高保真视觉生成。
  • 动作块长度过长时，机器人及时调整策略的能力受限，导致整体性能下降。
  • 数据和模型规模的扩展未充分探索，论文未明确在更大规模数据上的表现。
  • 视频预测模型对比中，无动作输入时存在固有歧义，部分任务产生负面影响。

工程启示

  • 复现时优先核对动作注意力掩码的实现，这是性能提升的核心（Average 从 54.0 到 76.6 的关键差异）。
  • 输入图像数 M 与动作块大小 K 的配置需按任务调整：Long 任务 K=10，其余 K=5；M=2 是默认平衡点，增加至 4 帧时动作块带来的增益减小（SR 从 84.4 到 84.7）。
  • 世界模型预训练对 Long 任务增益显著（23.0 到 30.2），但对 Object 任务增益有限（82.9 到 84.0），下游团队可根据任务类型决定是否启用。
  • 512×512 分辨率在 Object 任务上提升明显（89.0 到 96.2），但计算成本增加，需权衡。
  • 训练数据需过滤失败轨迹和无操作动作，90% 训练 / 10% 验证划分是默认设置。
  • 代码已开源，建议从 Chameleon 初始化，α 固定为 0.04，世界模型单轮 N=1。
