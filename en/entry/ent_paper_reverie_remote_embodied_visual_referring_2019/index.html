Summary

One of the long-term challenges of robotics is to enable robots to interact with humans in the visual world via natural language, as humans are visual animals that communicate through language. Institutions per source list: Yuankai Qi、Qi Wu、Peter Anderson、Xin Wang 等.

Overview

REVERIE is the first remote embodied visual referring expression task and dataset for real indoor environments, proposed by Qi Wu et al. It requires an agent to complete navigation and target object localization based on high-level natural language instructions. The core contribution lies in constructing a large-scale dataset containing 21,702 instructions and proposing an interactive Navigator-Pointer model that significantly surpasses existing SoTA combined methods on unseen scenes, though still far behind human performance.

What It Changed

What REVERIE truly changed is the essence of the task paradigm: it pushes navigation and referring expression from "pipelining" to "collaboration." Previously, VLN only required reaching a location, and RefExp only handled a single visible image, whereas REVERIE forces the agent to simultaneously solve two coupled problems in unknown environments: "where to look" and "what to recognize once found." This shift directly exposed the fatal weakness of existing methods—simply concatenating a SoTA navigator (FAST) with a referring expression model (MAttNet) achieved only 7.07% REVERIE success on the test set, while humans reached 77.84%, a gap of more than 10 times. This demonstrates a huge semantic gap between high-level instruction understanding and low-level visual grounding that cannot be resolved by module stacking.

More critically, REVERIE reveals the collapse of navigation performance under task transfer: FAST-Short achieves an SPL of 43% on R2R's Val-UnSeen, but drops sharply to 6.17% after transferring to REVERIE, a decline of nearly 30 percentage points. This is not a simple dataset difference but a fundamental challenge introduced by instruction granularity—high-level instructions require the agent to possess spatial reasoning and object commonsense, rather than merely following step-by-step actions.

Method Breakdown

Task Definition and Evaluation

  • The agent receives a high-level instruction at the starting position (e.g., "Go to the blue family room and bring the framed picture of a horse rider on the top left of the TV"), and must navigate to the target location and output a bounding box for the target object, with only one guess allowed per episode.
  • REVERIE success rate = number of correctly selected boxes / total tasks; correctness is defined as selecting the correct box from candidates, or predicted box having IoU ≥ 0.5 with ground truth (when no candidates are provided).
  • Navigation success is defined as stopping within 3 meters of the target, with the target visible from the stopping viewpoint.

Dataset Construction

  • Built on the Matterport3D Simulator extension, adding object-level annotations (labels + bounding boxes), handling occlusion by computing overlap between bounding boxes and object depth, retaining only objects within 3 meters of the viewpoint, totaling 20k annotations.
  • Data collection uses an interactive 3D WebGL simulator: first showing path animations, then randomly highlighting target objects for AMT workers to write instructions; each target collects 3 referring expressions, involving over 1,000 workers and approximately 2,648 hours of annotation.

Interactive Navigator-Pointer Model

  • Navigator: Based on FAST-short (sequence-to-sequence LSTM + attention + backtracking), using a visual-text co-grounding model to compute local logits, maintaining a candidate queue and a stop queue, selecting the viewpoint with the highest cumulative logit as the next step.
  • Pointer: Uses MAttNet, decomposing expressions into appearance (subj), location (loc), and relation (rel) modules, with the final matching score being the weighted sum of the three modules.
  • Interaction module (core innovation): The Pointer selects top-3 matched objects in each candidate view, encodes object category labels with a trainable bidirectional LSTM, concatenates with the average output of ResNet FC7 layer to update candidate viewpoint features, and feeds them back into the Navigator. This design makes navigation decisions dynamically influenced by object recognition results, rather than static concatenation.

Loss Function

  • Total loss L = L_nav + λ₄·L_exp, where navigation loss L_nav = cross-entropy + progress monitoring MSE (λ₁=0.5), referring expression ranking loss L_exp includes λ₂=1.0, λ₃=1.0, and distance margin δ, with λ₄ defaulting to 1.0.

Key Innovations

  1. Task-level innovation: REVERIE is the first to define remote embodied referring expression as a complete task, requiring the agent to complete "navigation + grounding" two-stage reasoning in unseen real indoor scenes using only high-level instructions. This is closer to the practical needs of natural human-robot interaction than VLN or RefExp, and the dataset scale (21,702 instructions, 489 object categories) far exceeds ReferCOCO (80 categories), increasing difficulty by an order of magnitude.

  2. Architecture-level innovation: The interactive Navigator-Pointer model breaks the module isolation between navigation and referring expression. The Pointer's top-3 object category labels are encoded via a bidirectional LSTM and fed back to the Navigator, enabling navigation decisions to be aware of "what objects might be seen ahead" rather than moving blindly. This design improves REVERIE success by 4.2% over the non-interactive ablation (FAST-Short + MAttNet) on the test set, validating the necessity of collaborative reasoning.

  3. Evaluation methodology innovation: The authors introduce the FAST-Lan-Only baseline (language-only input, no vision) to detect whether the task has language bias. Results show this baseline drops significantly on both seen and unseen splits, proving that REVERIE genuinely requires visual-linguistic joint reasoning rather than relying on statistical language patterns.

Key Interpretations

  • The authors' model achieves 11.28% REVERIE on Test Unseen, a 59.5% improvement over the strongest baseline FAST-Short (7.07%) (calculated from in-table values 8.92−68.45), but only 14.5% of human performance (77.84%) (calculated from in-table values 10.46→8.92).
  • In the referring expression-only evaluation, MAttNet achieves only 48.98% on Test, far below its 80% on ReferCOCO, indicating that REVERIE's object recognition difficulty far exceeds static image tasks.
  • Navigation performance transfer collapse is significant: FAST-Short's Val-UnSeen SPL drops from 43% on R2R to 6.17% on REVERIE, proving that high-level instructions impose entirely new demands on navigation reasoning.

Boundaries and Limitations

  • The authors explicitly acknowledge that the model still has substantial room for improvement on the unseen test set, with a significant gap from human performance (11.28% vs 77.84%).
  • The task only requires recognizing the target object, without any manipulation (e.g., grasping, folding), so the complete closed loop of embodied interaction cannot be evaluated.
  • The paper does not mention real robot deployment validation, cross-domain generalization tests (e.g., different architectural styles or lighting conditions), or scalability analysis for longer instructions or more complex scenes.
  • Failure cases of the interactive model lack in-depth attribution analysis, making it impossible to determine whether errors mainly stem from navigation misdirection or object misrecognition.
  • Training configurations, inference frequency, hardware resources, and other engineering details are not disclosed, making reproduction challenging.

Engineering Insights

  • Verify data distribution first: In REVERIE, 56% of instructions mention more than 3 objects, the target viewpoint has an average of 7 objects and 50 bounding boxes, with 489 categories. When reproducing, ensure your data preprocessing preserves these high-density scenes; otherwise, the model may overfit to simple scenarios.
  • Most error-prone step: The Pointer's top-3 object category label encoding is key to the interactive model, but vocabulary construction and OOV handling for category labels are highly error-prone. It is recommended to first validate the Pointer's accuracy on Val-Seen independently (should be close to 68.45%) before integrating with the Navigator; otherwise, errors will cascade and amplify.
  • Coupling debugging for navigation and grounding: The authors' model has a Length of 39.05 meters, far exceeding humans (21.18 meters), indicating excessive exploration redundancy. If SPL is low during reproduction, prioritize checking the Navigator's stopping condition—REVERIE requires stopping within 3 meters of the target with the target visible, which differs fundamentally from VLN's stopping logic.
  • Evaluation server caution: Test set ground truth is not public; trajectories and detection boxes must be uploaded via the official evaluation server. It is recommended to establish your own local evaluation pipeline on Val-UnSeen first, ensuring full consistency with official metrics (IoU ≥ 0.5) before submitting, to avoid wasting submission attempts on format errors.
