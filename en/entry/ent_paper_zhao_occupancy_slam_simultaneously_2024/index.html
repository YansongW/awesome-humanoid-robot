Summary

An optimization-based SLAM approach that jointly optimizes robot trajectory and a continuous occupancy map from 2D laser scans and odometry using a Gauss-Newton variant.

Sources

  • Occupancy-SLAM: Simultaneously Optimizing Robot Poses and Continuous Occupancy Map

概述

本文提出Ego-PM，一个两阶段统一预测框架，以手部轨迹为显式条件，联合建模即将发生的动作及其视觉后果。该方法在Ego4D、BridgeData V2和RLBench上验证了有效性，在帧预测质量和下游任务成功率上均优于现有基线。

它改变了什么

现有VLA模型只输出动作，不关心动作如何改变视觉世界；视频预测模型生成未来帧，却不以具体动作为条件，导致预测结果与真实交互脱节。这种割裂使得机器人无法在行动前“想象”后果，也难以从视觉反馈中修正动作。Ego-PM真正改变的是将“动作”从预测的副产品提升为生成视觉未来的显式条件，让模型在推理时同时回答“做什么”和“会看到什么”，这为闭环操作提供了更一致的内部表征。

方法拆解

两阶段训练策略

因训练收敛与内存限制，采用两阶段而非端到端联合训练。

阶段一：Consecutive State Modeling (CoSMo)

  • 视觉编码器：预训练CLIP视觉编码器Φ_V提取每帧特征，经线性投影F对齐到文本嵌入空间。
  • 动作意图编码器/解码器：轻量级3层MLP，引入特殊token ⟨ACT⟩，将动作嵌入与视觉、文本token拼接；推理时通过MLP解码器重建动作信号。
  • 自回归模型：基于LLaVA初始化，类似LEGO设置；每时间步融合文本与动作token以增强时间理解。
  • CoSMo策略：利用当前状态与前一状态（t和t-1）预测未来状态，而非仅依赖当前状态，以增强时间依赖与预测连贯性。
  • 训练目标：L_CoSMo = L_lang,t=1 + λ1·L_act,t=1 + L_lang,t=2 + λ1·L_act,t=2；人类数据用L1+GIoU损失监督手部边界框；机器人数据用L1损失监督7D关键点。

阶段二：动作增强的帧预测

  • 视觉条件：拼接当前帧与先前帧，经线性投影、自注意力与因果交叉注意力（CCA）形成视觉上下文C_V。
  • 文本条件：CLIP文本编码器ψ获取提示嵌入，与阶段一LLM生成的文本嵌入拼接，经自注意力与CCA形成文本上下文C_T。
  • 动作条件：将阶段一动作嵌入经线性层投影到扩散模型潜在空间，形成C_A。
  • 条件融合：C = [C_V, C_T, C_A]，输入扩散模型UNet的交叉注意力层。
  • 帧预测：采用潜在扩散模型（LDM），基于预训练VAE的潜在空间，逐帧生成未来帧；从最后观察帧v_n开始，编码为z_n并加噪，训练网络ε_θ预测噪声。
  • 训练目标：L_LDM = E[‖ε − ε_θ(z_t, t, C)‖²₂]。

关键设计决策

  • 显式建模手部轨迹：手（或机械臂）是动作的主要工具，显式建模作为条件对预测世界未来状态至关重要。
  • CoSMo使用两个连续状态：仅依赖当前状态对序列预测次优，两个连续状态提供更丰富的时间动态。
  • CCA因果约束：每个查询仅关注同时间步或更晚的键值对，提供历史信息用于未来帧预测，保证时间顺序。
  • 动作编码器-解码器而非纯文本：纯文本无法传达明确的动作信息，专用动作token提供有效引导。

关键创新

  1. 统一动作与视觉预测：首次在单一框架中显式联合建模“下一动作”与“其视觉结果”，推理时无需额外标注，直接以手部轨迹为条件生成未来帧。
  2. CoSMo连续状态建模：利用t和t-1两个连续状态预测未来，相比仅用当前状态，更充分地捕捉时间动态，提升序列预测的连贯性。
  3. 因果交叉注意力（CCA）：在扩散模型的交叉注意力中引入因果约束，确保未来帧生成严格遵循时间顺序，避免信息泄漏，同时保留历史上下文。

结果含义：Ego-PM在Ego4D上显著优于LWM*和LEGO，尤其在PSNR和Hand IoU上提升明显；在BridgeData V2上，帧预测质量与This&That相当，但Success Rate（73.7%）超过OpenVLA（70.6%）；在RLBench上，虽不及使用3D输入的SAM-E（81.49%）和RVT（70.71%），但优于2D轨迹基线LLARVA（57.33%）。消融实验证实CoSMo、动作编码器-解码器与CCA三者叠加带来一致增益。

边界与局限

  • 连续预测（t=3）时所有方法性能均下降，表明复合误差问题仍存在，Ego-PM虽保持优势但未根本解决。
  • 在RLBench上，SAM-E与RVT因利用重型3D输入而整体成功率更高；Ego-PM不使用额外3D传感器或真值轨迹，仍优于2D轨迹基线，但与3D方法存在差距。
  • 未来工作可探索更丰富的条件信号，扩展模型以处理更长时域预测与更复杂的多智能体交互。
  • 论文未明确。

工程启示

  • 复现时先核对两阶段训练的损失权重：λ1=0.1，λ2=0.01（基于验证性能设定），若下游任务对动作精度敏感，可优先调整λ1。
  • 自回归模型初始化至关重要：Ego4D用LEGO预训练权重，BridgeData用OpenVLA初始化；冻结CLIP图像编码器，仅微调投影层与LLM，训练3轮。
  • LDM从Stable Diffusion检查点初始化，所有帧分辨率固定256×256；若显存受限，可先验证阶段一收敛再加载阶段二。
  • 最容易踩坑的是动作token与文本token的拼接顺序及CCA的因果掩码实现，务必确保查询仅关注同时间步或更晚的键值对，否则时间顺序会被破坏。
  • 训练时仅需简单手部位置标注作为显式动作线索，推理时无需额外输入；若标注质量差，可考虑用检测模型预生成伪标签。
