Summary

Learning to Walk and Fly with Adversarial Motion Priors is a 2023 work on locomotion for humanoid robots.

Sources

  • Learning to Walk and Fly with Adversarial Motion Priors (arXiv)

概述

本文提出一种基于对抗运动先验（AMP）的极简强化学习框架，用于空中人形机器人 iRonCub 的行走与飞行模式自动切换。该方法无需运动示例、有限状态机或形态学特定知识，仅通过生物力学简单原理和判别器风格奖励，使智能体在平坦与复杂地形上自主选择高效 locomotion 模式。核心贡献在于将行走与飞行先验统一纳入对抗训练，显著降低推进消耗，并支持在线地形感知与自动模式转换。

它改变了什么

现有 locomotion 生成方法陷入两难：运动捕捉与有限状态机能产出逼真平滑动作，但依赖人工设计且缺乏通用性；深度强化学习虽能自动生成控制器，却常产生抖动、高频伪影，不像真实运动。对于空中人形机器人，行走与飞行模式间的转换时机和方式更是开放难题——轨迹优化计算密集、需环境先验且无法在线重规划，经典 RL 则易利用模拟器误差产生低效解。本文真正改变的是：将模式选择从显式规划问题转化为隐式学习问题，让智能体在任务奖励与风格奖励的博弈中自发涌现出“何时走、何时飞”的决策，无需高层规划器或状态机干预。这一转变将 locomotion 控制从手工设计范式推向数据驱动的自主涌现范式，尤其为混合形态机器人（如带喷气推进的人形）提供了统一解决方案。

方法拆解

总体框架

采用 AMP 架构，总奖励为任务奖励与风格奖励加权和：r_t = w_G * r_t^G + w_S * r_t^S，其中 w_G 与 w_S 为权重（论文未明确具体值）。

风格奖励

  • 判别器 D_Φ 输入连续两帧观测 (χ_t, χ_{t+1})，区分数据集样本与策略样本。
  • 训练目标含梯度惩罚项 w_gp 提升稳定性。
  • 风格奖励：r_t^S = -log(1 - 1/(1 + e^{-D_Φ(χ_t, χ_{t+1})}))，鼓励策略产生与数据集风格相似的运动。

任务奖励（四项）

  • 目标距离：r_t^c = exp(-a * ||x_d - p_t||^2)，a = 0.5，最小化基座到目标距离。
  • 期望速度：r_t^v = exp(-b * ||v_d - (g(p_t) - g(p_{t-1}))/Δt||^2)，b = 0.5，鼓励沿基座-目标连线以 v_d 移动。
  • 朝向：r_t^f = min(0, f(p_t)_xy · i_xy^I)，要求基座 x 轴指向目标水平投影。
  • 推力惩罚：r_t^T = -||T_t / T_max||^2，T_max = 220 N，最小化推进消耗。
  • 总任务奖励：r_t^G = 0.1 * r_t^c + 0.7 * r_t^v + 0.2 * r_t^f + 0.11 * r_t^T。

观测与动作空间

  • 机器人观测：o_robot = [ρ^T, v_B^B^T, ω_B^B^T, s^T, ṡ^T, p_EE^T, T^T]^T，含基座姿态、速度、关节状态、末端位置、推力。
  • 环境观测：V×L 高程图（场景二为 7×9 单元，每单元 0.3 m），以基座为中心随动。
  • 任务观测：o_task = R_B^I^T (x_d - p)，目标相对基座位置。
  • 动作：a = [s_d^T, ΔT^T]^T，期望关节位置（PD 控制）与推力增量（T = T_{k-1} + ΔT）。

数据来源

  • 行走：CMU 人类行走数据集，经 iDynTree 逆运动学重定向至 iRonCub，推力置零。
  • 飞行：轨迹优化生成，含完整状态（关节位置、基座姿态、推力强度）。

训练配置

  • 平台：Nvidia Isaac Gym，4096 并行智能体，PPO 算法，控制频率 60 Hz，训练约 2 小时（NVIDIA Quadro RTX 6000）。
  • PPO 参数：γ = 0.99，学习率 5e-5，λ = 0.95，熵系数 0.0，clip 0.2，mini-batch 32768，critic 系数 5，KL 阈值 0.008。

关键创新

  1. 统一行走与飞行先验的对抗训练：首次将两种截然不同的运动模式（地面行走与空中飞行）纳入同一 AMP 框架，判别器同时学习两种风格，策略在任务驱动下自主选择模式。这比单一先验或手工切换更高效，消融实验显示双先验策略推力使用显著低于无先验和仅飞行先验。
  2. 推力惩罚作为模式选择隐式信号：通过 r_t^T 最小化推进消耗，使智能体在可行时优先行走、必要时飞行，无需显式规则。这一设计将能量效率内化为学习目标，避免了状态机切换的离散决策难题。
  3. 地形感知与在线重规划能力：高程图观测使策略能感知地形稀疏性，结合推力惩罚自动调整模式（如垫脚石区域偏好飞行）。相比轨迹优化（不支持地形感知、无法在线），本文方法在复杂环境中具备实时适应性。

实验与结果

场景设置

  • 场景一（平坦地面）：v_d = 0.8 m/s，航点间隔 0.7 m 至 2.0 m，高度图简化为单一值，终止条件为基座离地 < 0.4 m。
  • 场景二（地形感知）：v_d = 0.8 m/s，含平坦、粗糙、垫脚石、坑，高程图 7×9 单元（每单元 0.3 m）。

消融实验（场景一）

策略 奖励 推力使用 行为
无运动先验 与双先验相似 最高 推力使用高，效率低
仅行走先验 相似 最低 学会行走但无法飞行，无法到达空中航点
仅飞行先验 相似 高于双先验 不学行走，飞达所有航点
行走+飞行先验 相似 最低（相比无先验与仅飞行） 学会行走与飞行，推进消耗最省

结果含义

双先验策略在奖励相近下推力使用更低（由表内数值对比计算），证明对抗先验能有效引导能量高效 locomotion。训练曲线基于 10 次运行，方差小，稳定性好。

边界与局限

  • 仅在模拟环境验证，真实世界可靠性未测试（作者明确承认）。
  • 推力惩罚调参困难：惩罚过高时机器人宁愿停留地形边缘也不飞行；惩罚过低时偏好飞行而非行走（论文未明确具体阈值）。
  • 未在真实机器人上验证，未使用状态机或高层规划器显式切换模式（设计选择）。
  • 数据集仅含行走与飞行两种先验，未探索更多运动模式（如跳跃、攀爬）的扩展性。
  • 论文未明确 w_G 与 w_S 的具体值，以及判别器梯度惩罚系数 w_gp 的数值。

工程启示

  • 复现优先核对：先确认 w_G、w_S、w_gp 的具体值（论文未明确），以及行走数据重定向至 iRonCub 时推力置零的处理细节——这直接影响风格奖励的稳定性。
  • 推力惩罚调参是最大坑点：建议从 w_T = 0.11 起步，逐步增大观察模式切换行为；若出现“边缘停留”现象，降低 w_T；若过度飞行，提高 w_T。此参数对地形稀疏性高度敏感，需按场景微调。
  • 数据质量决定风格上限：行走数据来自 CMU 数据集重定向，飞行数据来自轨迹优化——两者风格差异大，判别器需足够容量区分。建议检查重定向后关节极限是否违反，否则策略会产生相似但不可行运动。
  • 硬件与训练时间：4096 并行智能体、60 Hz 控制频率、约 2 小时训练（RTX 6000）是基线配置；若资源有限，可减少智能体数量但需注意 PPO mini-batch 大小（32768）与 KL 阈值（0.008）的匹配。
  • 下游团队注意：该方法输出为期望关节位置与推力增量，需确保 PD 控制器频率（60 Hz）与推力执行器响应匹配；真实机器人部署前需先验证模拟到现实的动力学差异，尤其是喷气推力的延迟与饱和特性。
