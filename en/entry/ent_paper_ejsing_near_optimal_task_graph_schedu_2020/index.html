Summary

This paper reduces preemptive and non-preemptive task graph scheduling to fastest-path location reachability in Priced Timed Automata and Priced Timed Markov Decision Processes, implements the approach in Uppaal Cora and Uppaal Stratego, and evaluates it on the Kasahara-Narita standard task graph set.

Sources

  • Near Optimal Task Graph Scheduling with Priced Timed Automata and Priced Timed Markov Decision Processes

概述

本文提出 FastDSAC，一种面向高并行 off-policy 强化学习训练的轻量级稳定化方案。其核心贡献在于将探索与目标 Q 值估计解耦，仅对目标动作施加均值中心截断正则化，并采用连续高斯策略建模以避免 tanh 挤压带来的数值问题。该方法在 MuJoCo Playground 和 HumanoidBench 上实现了更稳定的训练与更优的渐近性能。

它改变了什么

高并行采样与大批量更新在压缩训练时间的同时，正悄然侵蚀 off-policy actor-critic 方法的根基。数据量与更新频率的激增使 TD 误差中的噪声被放大，目标 Q 值估计因极端低概率动作的出现而方差飙升，这直接威胁到值学习的稳定性，并逐步削弱策略网络的可塑性。可塑性丧失与 primacy bias 及后期性能退化紧密相关，意味着早期训练中的不稳定会被固化，最终限制算法的渐近表现。

FastDSAC 的实质改变在于，它不再试图通过调整更新频率或批量大小来缓解问题，而是从目标 Q 值估计的源头入手。它明确区分了探索性动作与用于形成 TD 误差的目标动作，仅对后者施加约束。这一设计选择承认了探索的随机性对策略学习是必要的，但目标值的计算必须基于更可靠的分布支撑，从而在不牺牲探索效率的前提下，显著降低值估计的方差。

方法拆解

策略参数化

  • 策略网络输出对角高斯分布的均值 μ_φ(s) 与标准差 σ_φ(s)，即 π_φ(a|s) ~ N(μ_φ(s), σ_φ²(s))。
  • 使用重参数化技巧采样：a = μ_φ(s) + σ_φ(s) ⊙ ε，其中 ε ~ N(0, I)。
  • 对数概率闭式可计算：log π_φ(a|s) = Σ_{i=1}^{d} log N(a_i | μ_φ^i(s), (σ_φ^i(s))²)。
  • 与 tanh-squashed 参数化相比，高斯策略避免了边界处梯度消失、tanh 挤压带来的对数似然修正及数值不稳定问题。

目标动作截断

  • 策略均值 μ_φ(s) 被限制在 [m_min, m_max] 内，防止早期训练中均值动作过大。
  • 标准差 σ_φ(s) 初始化为小值，并限制在 [ℓ_min, ℓ_max] 内。
  • 目标动作采用均值中心截断：a' = μ_φ(s') + c·tanh(u' − μ_φ(s'))，其中 u' ~ π_φ(·|s')。
  • 该截断对诱导动作分布的支撑施加均值中心约束，过滤罕见极端样本，同时保留适度随机性用于探索。

熵项与更新流程

  • 熵项使用与约束目标动作一致的对数概率计算，保证目标值与策略优化的一致性。
  • 算法流程（Algorithm 1）：初始化双 critic 网络 Q_θ1, Q_θ2 与 actor 网络 π_φ；初始化目标网络与回放缓冲区；每步采样动作、存储样本；执行 num_updates 次更新：采样小批量、计算目标 Q 值（使用截断目标动作）、更新 critic、按周期 d 更新 actor 与熵温度、通过 Polyak 平均 ρ 更新目标 critic。
  • 使用双 critic 取最小值（Q_θ′^min）构造目标值，以缓解高估偏差。

关键创新

  1. 探索与目标估计的解耦：这是对 off-policy actor-critic 训练范式的直接修正。以往方法将策略采样动作同时用于探索与目标值计算，FastDSAC 明确区分二者，仅对目标动作施加均值中心截断。这一设计直接针对大批量训练下极端低概率动作导致的目标 Q 值方差问题，而非间接调整更新节奏。

  2. 连续高斯建模替代离散值分布：与 FastTD3 和 FastSAC 相比，FastDSAC 采用连续高斯策略并自适应调节方差。这避免了离散化带来的信息损失，同时通过闭式对数概率计算熵项，保持了熵正则化的完整性，且无需 tanh 挤压的修正项，数值上更稳健。

  3. 均值中心截断的支撑约束：截断操作并非简单裁剪动作幅度，而是对诱导动作分布的支撑施加均值中心约束。这一机制在过滤罕见极端样本的同时，保留了围绕均值的适度随机性，既稳定了目标 Q 值估计，又不损害探索的充分性。

实验与结果

实验在 MuJoCo Playground 和 HumanoidBench 两个平台进行，与 FastTD3 和 FastSAC 基线对比。摘要声明 FastDSAC 不仅稳定了整体训练过程，还实现了优于最先进基线的渐近性能和更快收敛。高 UTD 比在早期训练阶段加速策略收敛的有效性在 MuJoCo Playground 上得到验证。具体成功率、误差或参数数值在提供的片段中未给出，论文未明确。

边界与局限

论文片段中未明确列出作者承认的局限或未做之事。从方法本身推断，均值中心截断的引入可能对动作分布的形状敏感，若真实最优策略的动作分布高度偏斜，截断可能引入偏差。此外，截断参数 c、均值与标准差边界 [m_min, m_max] 与 [ℓ_min, ℓ_max] 的选取依赖任务特性，论文未提供通用调参准则。高 UTD 比在早期加速收敛的结论基于 MuJoCo Playground，其泛化至其他物理引擎或真实机器人系统的程度论文未明确。

工程启示

复现 FastDSAC 时，首先核对策略网络的标准差初始化与边界限制 [ℓ_min, ℓ_max]，这是自适应方差调节的关键，直接影响探索与稳定的平衡。其次，目标动作截断中的参数 c 需根据任务的动作范围调整，过小会过度限制探索，过大则失去稳定效果。最容易踩坑的地方在于熵项的计算：必须使用与截断目标动作一致的对数概率，否则熵正则化与目标值之间会出现不一致，导致训练不稳定。对于下游团队，若现有 off-policy 训练在高并行下出现值发散或性能退化，可优先尝试仅对目标动作施加均值中心截断，而非修改更新频率或批量大小。开源代码与项目页面已提供，建议在单 GPU 上先复现 MuJoCo Playground 结果，验证截断机制的有效性后再迁移至新任务。
