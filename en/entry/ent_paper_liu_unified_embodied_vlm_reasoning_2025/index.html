Summary

Unified Embodied VLM Reasoning with Robotic Action via Autoregressive Discretized Pre-training (ERIQ), is a 2025 large vision-language-action model for robotic manipulation, introduced by AgiBot Research, AgiBot, Shanghai Innovation Institute.

Sources

  • Unified Embodied VLM Reasoning with Robotic Action via Autoregressive Discretized Pre-training (arXiv)
  • ERIQ source

概述

GenieReasoner 是一个统一的自回归 VLA 架构，通过新提出的 FACT 动作分词器将连续控制信号离散化为紧凑 token，在单一模型中联合优化高层推理与低层动作执行。作者同时构建了 ERIQ 基准（6,052 个 QA 对）用于独立评估具身推理能力，实验表明该方法在推理精度和真实世界操控成功率上均显著优于现有连续与离散基线。

它改变了什么

现有 VLA 领域长期存在一个尴尬的二分法：连续动作模型（如 π0.5）在精细操控上表现出色，但语义推理能力薄弱；离散动作模型（如 π0-FAST）虽然具备更强的语言理解，却因量化伪影导致毫米级抓取失败。这种“推理-精度权衡”并非工程细节问题，而是表征层面的根本矛盾——连续空间适合表达细腻的运动，却难以与离散的语言 token 高效对齐；离散空间适合语义组合，却丢失了动作的保真度。作者真正改变的是将这一矛盾从“表征选择”问题转化为“表征分工”问题：不再让 VLM 直接输出连续动作或粗糙的离散码，而是让 VLM 在紧凑的离散空间内做规划，再通过一个独立的生成式解码器恢复高保真轨迹。

另一个被忽视的问题是评估方式。端到端成功率评估将推理能力与动作执行耦合在一起，导致研究者无法判断模型失败究竟源于“想错了”还是“做错了”。ERIQ 基准的提出将推理能力从动作控制中剥离出来，用确定性的多项选择格式独立度量空间感知、规划、错误恢复和意图理解四个维度。这一改变使得推理能力的评估不再依赖昂贵的机器人 rollout，为模型选型和迭代提供了更廉价的信号。

方法拆解

FACT 动作分词器

  • 编码器：采用 MM-DiT 架构（patch size 1），执行时间压缩（L ≤ H）和空间压缩（D ≤ S），将连续动作序列映射为离散码。
  • 量化机制：使用查找无关量化（sign 函数），码本为 {−1, +1}，默认配置为 2^12 词表 + 码长 20。
  • 解码器：同样基于 MM-DiT，使用 Rectified Flow 目标，通过 ODE 积分从高斯噪声 a^(t=0) ~ N(0, I) 出发，以步长 Δt 积分至 t=1 重建连续轨迹。
  • 训练损失：熵损失（最大化码本使用）+ 承诺损失（保持嵌入接近量化值）+ flow-matching 均方误差损失。

GenieReasoner 架构

  • 统一自回归 transformer，VLM 骨干生成离散动作 token，推理时由 FACT decoder 解码为连续控制信号。
  • 关键设计决策：将细粒度运动生成负担从离散潜在分辨率转移到生成式解码过程。VLM 在紧凑稳定的离散空间内规划，ODE 积分负责恢复高保真连续轨迹。

三阶段训练策略

  1. 第一阶段：训练 FACT tokenizer（损失函数见 Section IV-C）。
  2. 第二阶段：端到端联合预训练，混合通用 VQA 数据（Cambrian-10M、LLaVA-OneVision 等）、具身 VQA 数据（Cosmos-Reason、ShareRobot 等）和 tokenized 动作数据（AgiBot World 等）。
  3. 第三阶段：任务特定后训练，保持联合训练目标（混合具身 VQA 和动作数据），防止推理能力灾难性遗忘。

关键创新

FACT 的“离散规划 + 连续生成”解耦是核心创新。与均匀分箱或 VQ-VAE 不同，FACT 将离散 token 视为“语义摘要”，而将细节恢复完全交给 flow-matching 解码器。这使得 VLM 无需在离散空间内编码所有运动细节，从而在紧凑码长下保持高保真重建——论文报告其重建误差常比 FAST+ 低一个数量级。

ERIQ 基准的独立推理评估是第二个创新点。现有基准（如 MMRo、EgoPlan）主要覆盖基础空间或规划任务，而 ERIQ 是唯一在四个推理维度（空间感知与接地、规划与监控、错误检测与恢复、人类意图理解）提供全面覆盖的框架，且采用确定性 MC 格式，避免了生成式评估的主观性。

三阶段训练配方的系统性消融揭示了关键发现：仅具身 VQA 预训练（Exp #1）可将 ERIQ 分数从 58.64 提升至 82.72，但成功率仍低于 5%；只有加入动作预训练（Exp #3）才能实现有效执行。这表明推理与动作能力在预训练阶段就必须联合优化，而非后训练阶段简单叠加。

关键发现：仅 Action 预训练（Exp #2）导致 ERIQ 完全失效（0.00），但语言跟随和成功率反而最高——说明动作数据本身不提供推理能力，但推理能力也不直接转化为执行能力。联合预训练（Exp #3）在两者间取得平衡，后训练加入 Emb. VQA（Exp #4）进一步将成功率从 0.18 提升至 0.25。

边界与局限

论文未明确列出自身方法的局限性。但根据实验数据可推断：Fine-grained 维度（55.36）显著低于 Gemini-2.5-pro（81.25），说明细粒度空间推理仍是短板。此外，真实世界评估仅在 AgiBot G1 和 ARX AC-One 两个平台上进行，泛化到其他机器人形态（如轮式、四足）的结论未验证。ERIQ 基准虽覆盖 15 个子任务，但采用确定性 MC 格式，可能无法完全反映开放世界中的推理不确定性。论文未明确说明 FACT 在极端长时程任务（如小时级操作）中的重建稳定性。

工程启示

复现时先核对 FACT 的默认配置（2^12 词表 + 码长 20）和 MM-DiT 的 patch size（1），这是重建精度的关键。训练数据混合比例是最大的坑：Exp #2 表明仅动作预训练会让推理能力完全崩溃（ERIQ 0.00），因此必须严格遵循三阶段流程，且第二阶段必须混合通用 VQA 数据以保留基础视觉-语言知识。后训练阶段加入 Emb. VQA 数据可将成功率从 0.18 提升至 0.25（由表内数值 0.18 → 0.25 计算），但需注意这并未提升 ERIQ 分数（80.39 不变），说明推理与执行在后训练阶段已解耦。评估时建议优先使用 ERIQ 作为推理能力的快速筛选信号，再对通过筛选的模型进行真实世界 rollout（每个设置 50 次），以节省资源。
