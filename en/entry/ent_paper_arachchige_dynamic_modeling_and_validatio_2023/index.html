2. Decision-as-Anchor Representation (DAAR)

锚点码本 \(\mathcal{A} = \{a_k\}_{k=1}^{K}\) 通过 k-means 聚类训练轨迹构建，\(K=100\)。训练时采用软锚点目标（soft anchor target）而非硬分类： [ q_k = \frac{\mathbb{I}[k\in\mathcal{N}]\exp(-d(\tau_{\mathrm{gt}},a_k)/\gamma)}{\sum_{j\in\mathcal{N}}\exp(-d(\tau_{\mathrm{gt}},a_j)/\gamma)} ] 其中 \(d(\tau_{\mathrm{gt}},a_k) = \frac{1}{T}\sum_{t=1}^{T}\|\tau_{\mathrm{gt}}^t - a_k^t\|_2\) 为平均 L2 距离，\(\mathcal{N}\) 是 top-N 最近锚点集，\(\gamma\) 是温度系数。软目标的设计理由在于：真实轨迹往往同时接近多个锚点（例如“让行”和“减速”在几何上可能重叠），硬标签会丢失这种多模态信息，而软分布允许模型学习锚点间的模糊边界。

DAAR 提供两种实例化： - 查询式建模（Query-Based）：用可学习查询作为特征锚点分类器，MLP 头输出锚点 logits，损失为 \(\mathcal{L}_{\mathrm{qry}} = -\sum_{k=1}^{K} q_k \log p_{\theta}^{\mathrm{qry}}(a_k|x)\)。这种方式额外延迟仅 33 ms，适合对延迟敏感的场景。 - 自回归建模（Autoregressive）：在 LLM 词表中引入 \(K\) 个特殊 token \(\{y_k\}_{k=1}^{K}\)，每个 token 与锚点一一映射 \(a_k \leftrightarrow y_k\)。训练时在控制 token 后插入最近锚点 token，损失为 \(\mathcal{L}_{\mathrm{ar}} = -\sum_{k=1}^{K} q_k \log p_{\theta}^{\mathrm{ar}}(a_k|x)\)。推理时从控制 token 位置提取锚点 token 子集的 logits。这种方式额外延迟 64 ms，但主结果显示其 SR 最高（77.28% vs 查询式 73.81%），说明将锚点预测统一到 LLM 的 next-token 接口能更好地利用预训练语义先验。

3. Decision-Anchored Residual Flow (DARF)

DARF 在选定锚点定义的残差空间中执行流匹配，而非直接对完整轨迹建模。给定 top-M 候选锚点（\(M=6\)），目标残差为 \(r_{\mathrm{gt}}^k = \tau_{\mathrm{gt}} - a_k\)，流路径为： [ z_t^k = (1-t)\epsilon + t r_{\mathrm{gt}}^k, \quad v_k^ = r_{\mathrm{gt}}^k - \epsilon ] 训练时选择与 GT 轨迹最近的锚点 \(k^{\dagger} = \arg\min_{k\in\mathcal{I}_M} d(\tau_{\mathrm{gt}}, a_k)\)，损失为： [ \mathcal{L}{\mathrm{flow}} = |\hat{v}^}} - v_{k^{\dagger}|1 ] 同时预测置信度分数 \(s_k\)，训练损失为： [ \mathcal{L} ] 推理时用 2 步 Euler 积分速度场，按置信度选择最终轨迹 }} = -\log\frac{\exp(s_{k^{\dagger}})}{\sum_{k\in\mathcal{I}_M}\exp(s_k)\(\hat{\tau} = \hat{\tau}_{\arg\max_{k\in\mathcal{I}_M} s_k}\)。

DARF 的关键设计决策在于残差空间比完整轨迹空间更紧凑：锚点提供了粗轨迹参考，残差目标的变化范围远小于完整轨迹，这缩短了流匹配的传输路径，使有限步（2 步）生成更容易收敛。消融实验证实了这一点：DARF（DS 89.92, SR 77.28%）显著优于 Deterministic（DS 86.74, SR 70.45%）和 Full Flow（DS 88.34, SR 72.73%）。Full Flow 直接对完整轨迹建模，传输路径更长，2 步生成精度受限；Deterministic 则因确定性回归导致多模态细化能力缺失。
