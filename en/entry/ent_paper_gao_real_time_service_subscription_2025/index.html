Summary

This paper formulates the Deadline-Constrained Task Offloading and Resource Allocation Problem (DOAP) in Vehicular Edge Computing and proposes SARound, a 1/4-approximation algorithm using LP rounding and local-ratio techniques, together with an online service-subscription and offloading-control framework evaluated in the OMNeT++/Simu5G-based VecSim simulator.

Sources

  • Real-Time Service Subscription and Adaptive Offloading Control in Vehicular Edge Computing

概述

本文提出 FPL（Freeform Preference Learning）框架，用于从自由形式人类偏好中学习机器人策略。核心贡献是学习单一语言条件奖励模型，并通过奖励条件策略提取实现测试时的行为引导与组合，无需预定义错误类别或固定偏好集合。该方法在仿真与真实世界任务上显著优于现有基线，平均提升 38 个百分点。

它改变了什么

现有偏好学习方法要么绑定预定义错误类别训练多个奖励模型，要么依赖二进制偏好或稀疏成功信号，这些信号过于模糊或太弱，无法提供有效监督。更关键的是，当前视觉-语言-动作模型（VLA）无法以上下文内方式对语言反馈做出反应，使得自然语言纠正或偏好推断方法难以直接应用于机器人学习。FPL 改变了这一局面：它将语言从纠正性反馈提升为定义偏好轴和奖励学习目标的显式接口，使策略能够沿多个未合并的轴进行条件化，从而组合出训练数据中不存在的行为。这不再是“从偏好中学习单一标量”，而是“从多轴语言偏好中学习可引导的策略”。

方法拆解

偏好收集

  • 每个轨迹对提供多个轴特定的判断（如“放置位置”“速度”“对齐”），而非单一整体偏好。
  • 使用自由形式自然语言轴，标注者按轴给出评分或比较，而非固定类别。

奖励学习

  • 学习单一语言条件奖励模型，输入为轨迹与语言轴描述，输出该轴上的奖励。
  • 与 [16]、[17] 不同，无需先学习语言与轨迹对齐的专用空间，也不将语言锐化为单一标量。

策略提取

  • 使用奖励条件策略提取：策略以目标奖励条件为输入，测试时通过改变奖励条件引导行为。
  • 训练时不过滤轨迹，回放缓冲区同时包含每个轴上的高评分与低评分行为，保留可引导性。
  • 多维度奖励学习与奖励条件提取共同作用，使策略能组合轴（如“目标放置位置”与“速度”）。

与基线关键差异

  • 对比 Single Preferences [12]：FPL 使用多轴偏好而非单一“整体质量”轴。
  • 对比 Advantage Conditioning [19]：FPL 不使用成功信号和时间到目标监督训练价值函数。
  • 对比 Weighted Regression [42]：FPL 使用奖励条件策略提取，而非轴间平均奖励加权回归。
  • 对比 Filtered BC [13]：FPL 不依赖稀疏成功奖励进行策略提取。
  • 对比 BC [30]：FPL 包含奖励学习和迭代改进。

关键创新

  1. 单一语言条件奖励模型：从自由形式人类指定轴学习，而非固定类别集合或多个奖励模型。这消除了预定义错误类别的限制，使奖励学习更灵活、更贴近人类表达。
  2. 未合并轴的奖励条件策略提取：策略以目标奖励条件为输入，测试时通过改变条件引导行为，且能组合出训练数据中不存在的行为（如 bimodal square 中快速右侧销与慢速左侧销的组合）。这是对“从偏好学习单一策略”范式的根本性扩展。
  3. 多轴偏好收集效率：每个轨迹对提供多个轴级判断，比单一二进制偏好每个标签快约 50%（原文：approximately 50% faster per label），显著降低标注成本。

  • FPL 在三个仿真任务上均优于所有基线，尤其在 bimodal square inverted 上达到 1.24，而 Filtered BC 为 0.00，说明 FPL 的测试时引导能力显著优于依赖稀疏成功信号的方法。
  • 真实世界任务（4 个，DROID 设置，Franka 机器人）中，FPL 平均比第二好的基线提高 38 个百分点（原文：average improvement of 38 percentage points over the second-best baseline）。
  • 定性分析显示，FPL 学习的奖励在时间上局部化到子任务事件，而二进制偏好奖励在轨迹末端产生大尖峰，缺乏细粒度监督。
  • plate toast 任务收集了 295 个轨迹对比较、超过 1477 个轴级比较、41 个不同标签。

边界与局限

  • 偏好收集成本：偏好学习需要收集人类偏好，比完全无监督方法更昂贵。
  • 测试时奖励值选择：奖励条件策略学习需要在测试时选择适当的奖励值，自动化这一选择是未来工作的重要方向。
  • 固定偏好轴集合：当前策略条件化在一组固定的偏好轴上，扩展到处理可变轴是一个有前景的方向（随着 VLA 能力增强）。
  • 论文未明确说明在偏好轴数量极大或轴间存在冲突时的行为退化情况。

工程启示

  • 复现核对：先确认偏好收集协议是否支持多轴级判断，这是 FPL 与基线差异的根源。若标注者只能提供单一整体偏好，FPL 的优势将大幅削弱。
  • 策略提取实现：奖励条件策略提取是核心，训练时务必保留回放缓冲区中的低评分行为，否则测试时引导能力会退化（对比 Filtered BC 的 0.00 结果）。
  • 测试时奖励值选择：这是最容易踩坑的环节。论文未提供自动化选择方法，工程上需手动调参或设计启发式规则，建议在仿真中先验证不同奖励值对行为的影响。
  • 数据效率：多轴偏好每个标签快约 50%（原文：approximately 50% faster per label），但总标注量仍可能较大（如 plate toast 的 295 个轨迹对、1477 个轴级比较），需评估标注预算。
  • 下游团队：若任务需要组合多个偏好轴（如速度与放置位置），FPL 的未合并轴设计是必要前提；若任务仅需单一质量优化，Single Preferences 可能更简单且足够。
