Summary

FastDriveVLA: Efficient End-to-End Driving via Plug-and-Play Reconstruction-based Token Pruning (FastDriveVLA), is a 2025 large vision-language-action model for robotic manipulation, introduced by Peking University, XPeng Motors.

Sources

  • FastDriveVLA: Efficient End-to-End Driving via Plug-and-Play Reconstruction-based Token Pruning (arXiv)
  • FastDriveVLA source

概述

FastDriveVLA 提出一种即插即用的重建引导 token 剪枝方法，用于加速端到端驾驶模型。核心贡献在于将 token 剪枝视为可学习优化问题，通过重建损失自动识别并移除冗余视觉 token，在保持驾驶性能的同时显著降低计算开销。

它改变了什么

端到端驾驶模型长期受困于视觉 token 数量与推理延迟的矛盾。此前方法要么依赖手工设计的启发式规则（如按注意力分数或空间位置剪枝），要么需要额外训练辅助网络，前者难以适应多变驾驶场景，后者增加训练复杂度。FastDriveVLA 真正改变的是将 token 剪枝从“人工设计策略”转向“自动搜索最优策略”，使模型能根据输入内容动态决定保留哪些 token，而非固定模式。这一转变意味着剪枝决策本身成为可优化的对象，为延迟-精度权衡提供了更精细的控制粒度。

方法拆解

问题形式化

将 token 剪枝定义为优化问题：给定视觉 token 集合 V，寻找子集 S⊂V 使重建损失最小化，同时满足预算约束 |S|≤B。

搜索策略

  • 采用可微分的 token 重要性评分网络，为每个 token 生成保留概率
  • 通过 Gumbel-Softmax 实现离散采样的连续松弛，使梯度可回传
  • 搜索空间覆盖三种操作：保留、合并、丢弃，由评分网络自动选择

重建引导

  • 使用轻量级解码器从剪枝后的 token 重建原始视觉特征
  • 重建损失作为剪枝质量的直接监督信号，避免依赖下游任务梯度
  • 训练时联合优化剪枝策略与重建器，推理时仅保留剪枝模块

即插即用设计

  • 剪枝模块作为独立层插入视觉编码器与 LLM 之间
  • 不修改预训练权重，仅新增可训练参数
  • 支持任意视觉 token 输入，无需针对特定模型重新训练

关键创新

  1. 搜索替代启发式：首次将 token 剪枝策略本身纳入可学习范畴，摆脱手工规则对场景的假设，能自适应不同道路类型、光照条件和物体密度。
  2. 重建信号作为通用监督：以重建损失作为剪枝质量的代理指标，不依赖具体驾驶任务（如轨迹预测或目标检测），使方法具备跨任务迁移能力。
  3. 即插即用架构：无需改动预训练模型结构，降低集成成本，便于在现有 VLA 模型上快速部署。

边界与局限

论文未明确列出局限性。根据方法特性推断：重建损失可能偏向保留低频视觉信息而忽略高频细节（如小物体、远处交通标志）；搜索策略的收敛性依赖训练数据分布，极端天气或罕见场景可能产生次优剪枝；未涉及动态推理时延优化（如自适应预算调整）或超长视频输入的处理。

工程启示

复现时优先核对三点：一是重要性评分网络的初始化方式，不当初始化可能导致训练初期剪枝策略崩溃；二是重建解码器的容量，过小则监督信号不足，过大则引入额外开销；三是 Gumbel-Softmax 的温度退火计划，直接影响搜索的探索-利用平衡。最容易踩坑的是将剪枝模块插入预训练模型后未冻结其他层，导致灾难性遗忘。建议先在小规模数据集上验证剪枝策略的稳定性，再迁移到完整驾驶场景。下游团队集成时，需确认剪枝模块的输入输出维度与现有视觉编码器兼容，并预留重建损失的调参空间。
