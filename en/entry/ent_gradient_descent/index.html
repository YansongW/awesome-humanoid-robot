Summary

An iterative first-order optimization algorithm that updates parameters in the direction of the negative gradient of the objective.

Sources

  • S. Boyd and L. Vandenberghe, Convex Optimization, Cambridge University Press, 2004

Overview

Gradient Descent is the most fundamental first-order iterative optimization algorithm: starting from initial parameters, it repeatedly moves a small step in the direction of the negative gradient of the loss function until converging to a local minimum. What it truly changes is not the mathematical form of optimization problems, but rather making "non-analytically solvable" high-dimensional parameter learning a routine engineering operation—from linear regression to deep neural networks, the training of almost all modern machine learning models is built upon its variants.

Content

What It Is: Precise Definition

Gradient Descent is a first-order optimization algorithm that minimizes an objective function through iterative parameter updates. Given a differentiable objective function \(L(\theta)\), its core update rule is:

\[ \theta_{t+1} = \theta_t - \eta \nabla_\theta L(\theta_t), \]

where \(\theta_t\) is the parameter vector at step \(t\), \(\eta > 0\) is the learning rate (step size), and \(\nabla_\theta L(\theta_t)\) is the gradient of the loss function at the current position. The algorithm starts from an initial point \(\theta_0\) and moves in the "steepest descent direction" at each step until a stopping criterion is met (e.g., the gradient norm falls below a threshold or the maximum number of iterations is reached).

Why It Exists: Pain Points and Historical Positioning

Before Gradient Descent, solving minimization problems relied primarily on two approaches: analytical methods, which directly set derivatives to zero and solve equations—but these completely fail for high-dimensional, nonlinear objective functions without closed-form solutions; and direct search methods (such as coordinate descent and simplex methods), which do not rely on derivatives but converge extremely slowly and are nearly unusable in high-dimensional spaces.

Gradient Descent precisely fills this gap: it only requires first-order derivative information, has low computational cost, and is naturally suited to machine learning scenarios with "many parameters and many samples." Cauchy first proposed the method in 1847, it entered practical use in the 1950s–60s with the spread of computers, and after the rise of deep learning in the 2010s, it (and its stochastic variants) became the de facto standard for training neural networks. What it truly changes is not the depth of optimization theory, but turning "large-scale parameter estimation" from a mathematical trick into an engineering pipeline.

Principle Breakdown

① Gradient: The Direction of Fastest Function Increase

For a differentiable function \(L(\theta)\), the gradient \(\nabla_\theta L(\theta)\) is a vector pointing in the direction of fastest increase of the function value, with its magnitude equal to the directional derivative in that direction. Therefore, the negative gradient direction \(-\nabla_\theta L(\theta)\) is the direction of steepest local descent. This is the origin of the name "steepest descent"—but note that local steepest does not equal global optimal path, which is key to understanding the limitations of Gradient Descent.

② Learning Rate: The Dual Role of Step Size

The learning rate \(\eta\) controls the distance moved at each step. It simultaneously determines two conflicting properties: convergence speed and stability. If \(\eta\) is too large, iterations oscillate back and forth across the valley or even diverge; if \(\eta\) is too small, convergence is extremely slow and may stall near a local minimum. In engineering practice, learning rate schedules or adaptive methods (such as Adam) are commonly used to alleviate this conflict.

③ Convergence Guarantees: Convex and Smooth Cases

For convex and \(L\)-smooth functions (with Lipschitz continuous gradients), if a fixed step size \(\eta \le 1/L\) is used, Gradient Descent is guaranteed to converge to the global minimum with a convergence rate of \(O(1/T)\):

\[ L(\theta_T) - L(\theta^\star) \le \frac{\|\theta_0 - \theta^\star\|^2}{2 \eta T}. \]

where \(\theta^\star\) is the global optimum and \(\|\cdot\|\) is the Euclidean norm. This bound shows that each doubling of the iteration count \(T\) roughly halves the optimality gap—this is sublinear convergence, slower than Newton's method's quadratic convergence, but with much lower per-step cost.

④ From Batch to Stochastic: A Leap in Computational Efficiency

When the number of training samples \(N\) is large, computing the full gradient \(\nabla L = \frac{1}{N}\sum_{i=1}^N \nabla L_i\) is prohibitively expensive. Stochastic Gradient Descent (SGD) estimates the gradient using only one (or a small batch of) sample(s) at each step. Although this introduces noise, the per-step computational cost is reduced by a factor of \(N\) (as inferred from corpus data), and in non-convex problems the noise can actually help escape poor local minima.

The core advantage of Gradient Descent is its lowest per-step cost: only one backpropagation pass is needed to obtain the gradient, without computing or storing the Hessian matrix. The trade-off is slower convergence than second-order methods and sensitivity to the learning rate.

Who Uses It: Application Cases

① Machine Learning Training (Most Widespread): Linear regression, logistic regression, neural networks—parameter learning for almost all differentiable models uses Gradient Descent or its variants. The optimizers built into deep learning frameworks (PyTorch, TensorFlow)—SGD, Adam, RMSProp—are essentially engineered encapsulations of Gradient Descent.

② Robot Motion Planning and Control: In humanoid robotics, Gradient Descent is used for trajectory optimization (e.g., the CHOMP algorithm) and real-time optimization in whole-body control (WBC). In the MJPC (MuJoCo Predictive Control) framework, Gradient Descent is one of three shooting-based planners that directly minimizes the cost function, alongside iLQG and Predictive Sampling.

③ Inverse Kinematics Solving: For redundant manipulators, analytical inverse solutions often do not exist. Gradient Descent numerically solves for joint angles by minimizing the squared error of the end-effector position.

④ Bayesian Optimization and Surrogate Models: In robot design optimization, Gradient Descent is often used as an inner optimizer, paired with Gaussian process surrogate models to search for optimal design parameters on the Pareto front.

Limitations and Boundaries

  1. Local minima in non-convex problems: Gradient Descent can only guarantee convergence to a local minimum (or saddle point); it cannot guarantee global optimality for non-convex objective functions. In deep learning practice, this is generally accepted—finding a "sufficiently good local minimum" already meets task requirements.
  2. Extreme sensitivity to learning rate: A fixed learning rate struggles to adapt to scale differences across parameter dimensions, requiring carefully designed decay strategies or adaptive methods.
  3. Ill-conditioned curvature problems: When the objective function has vastly different curvature along different directions (e.g., narrow valleys), Gradient Descent oscillates along the valley walls and converges extremely slowly. Newton's method addresses this with second-order information, but at high cost.
  4. Trade-off between batch size and noise: Full-batch Gradient Descent is stable but slow; mini-batch SGD is fast but noisy, with noise variance increasing as batch size decreases (as inferred from corpus data).
  5. Not applicable to non-differentiable objectives: For objectives with discrete variables, non-differentiable points, or black-box functions, Gradient Descent cannot be directly used; derivative-free methods (such as genetic algorithms, particle swarm optimization) are needed instead.

Common Misconceptions

  1. "Gradient Descent always finds the global minimum"—Wrong. Global optimality is only guaranteed for convex functions; for non-convex functions (such as neural network losses), it can only guarantee convergence to a local minimum or saddle point.
  2. "A larger learning rate means faster convergence"—Wrong. Exceeding a certain threshold (related to the function smoothness \(L\)) causes divergence; even without divergence, overly large steps cause oscillation near the minimum, preventing precise convergence.
  3. "Zero gradient means optimal"—Imprecise. A zero gradient could be a local minimum, local maximum, or saddle point. Second-order information (Hessian positive definiteness) or perturbation tests are needed to determine which.
  4. "Batch Gradient Descent is always better than Stochastic Gradient Descent"—Wrong. Full-batch computation is expensive, and in mini-batch scenarios, SGD's noise helps escape poor local minima, often yielding better practical results.
  5. "Gradient Descent and backpropagation are the same thing"—Wrong. Backpropagation is the algorithm for computing gradients (based on the chain rule); Gradient Descent is the optimization algorithm that uses gradients to update parameters. They are distinct roles of "differentiation" and "optimization."
