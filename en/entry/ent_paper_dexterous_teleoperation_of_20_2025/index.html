Summary

Dexterous Teleoperation of 20-DoF ByteDexter Hand via Human Motion Retargeting is a 2025 work on hardware design for humanoid robots.

Sources

  • Dexterous Teleoperation of 20-DoF ByteDexter Hand via Human Motion Retargeting (arXiv)

概述

本文提出 CLAP（Causal Language-Action Prediction）方法，将预训练 VLM 直接转为 VLA 模型，通过在预测离散动作 token 前先生成自然语言动作描述，以最小架构改动解决输出分布不匹配问题。作者基于 Qwen3.5 紧凑骨干发布了 0.8B、2B、4B 参数的多尺度开放权重 VLA 家族，2B 模型在 LIBERO 上达到 90.8% 成功率。

它改变了什么

VLM 到 VLA 的适配长期存在一个根本矛盾：标准微调让 VLM 输出裸数字动作 token，这些 token 缺乏预训练时见过的语言结构，导致模型在动作学习过程中可能退化掉支撑语义泛化的表征。现有架构无关方法要么预测裸动作 token 牺牲语言对齐，要么用纯语言描述替代数字动作牺牲直接可执行性，始终无法两全。

CLAP 真正改变的是这个权衡的底层逻辑——它不再把语言和动作视为二选一的输出形式，而是将自然语言动作描述作为条件中间变量，让数字动作 token 在生成时以语言描述为因果前提。这一改动让模型既保留精确可执行的动作 token，又让动作预测过程重新接入 VLM 预训练时的语言分布，同时完全不需要动作专家、词汇修改或人工标注。对紧凑型 VLA 而言，这个改变尤为关键，因为轻量级骨干对微调期间的分布偏移更敏感，CLAP 提供了一条更透明的路径来理解 VLM 能力如何跨模型规模迁移。

方法拆解

核心架构

CLAP 采用因果语言-动作预测框架，整个序列自回归生成，因果注意力确保数字动作 token 以先前生成的语言描述为条件。

生成流程

  1. 模型先接收任务指令（如视觉观察 + 语言指令）
  2. 自回归生成自然语言动作描述（如“move forward, tilt right, and close the gripper”）
  3. 在语言描述之后继续生成离散数字动作 token 序列
  4. 数字动作 token 用于精确控制，语言描述仅作为条件中间变量而非辅助预测目标

关键设计决策

  • 语言描述作为条件而非预测目标：不额外添加语言损失，避免干扰动作学习主任务
  • 因果注意力机制：保证动作 token 只能看到已生成的语言描述，不能看到未来信息
  • 单 epoch 微调：整个适配过程仅需一个训练轮次，大幅降低计算成本
  • 无需架构改动：不修改 VLM 原有结构，不引入动作专家模块，不改变词汇表

模型规模

基于 Qwen3.5 紧凑骨干，发布 0.8B、2B、4B 三个参数规模的开放权重模型，来自单一 VLM 谱系以保证跨规模可比性。

关键创新

1. 语言作为因果中间变量而非辅助输出 这是与所有现有方法最本质的区别。以往方法要么将语言作为并行预测头，要么完全替换动作输出，CLAP 首次将语言描述置于动作 token 的因果前提位置，使动作生成过程天然继承 VLM 预训练时的语言空间结构，同时不牺牲动作的精确可执行性。

2. 零架构改动的 VLM-to-VLA 转换 不需要动作专家、词汇修改、人工标注或任何架构调整，仅通过改变生成序列的结构就实现了分布对齐。这使得 VLA 研究门槛大幅降低，任何拥有预训练 VLM 的团队都能快速转为 VLA，让 VLA 研究像 VLM 研究一样可及。

3. 多尺度开放权重 VLA 家族 发布 0.8B、2B、4B 三个规模的模型，来自单一 VLM 谱系，为研究 VLM 能力如何跨模型规模迁移到 VLA 提供了标准化的比较平台，这在现有文献中较为罕见。

  • 在 LIBERO-PRO 的语言、物体、空间扰动下，CLAP 展现出更强的鲁棒性

结果的含义：语言条件中间变量确实帮助模型在动作预测时保持了语义泛化能力，尤其在面对扰动时表现更稳定，这验证了分布对齐假设的有效性。

边界与局限

论文片段未明确列出作者承认的局限或未做之事。基于现有信息可推断的边界包括：实验仅在 LIBERO 基准上验证，未涉及真实机器人部署；模型规模仅覆盖 0.8B 到 4B，更大规模（如 7B 以上）的表现未知；单 epoch 微调的效果是否在更复杂任务上保持未验证；论文未提供数据量、训练配置、推理频率、硬件等工程细节，复现难度可能较高。

工程启示

对复现和选型的具体指导：

  1. 先核对生成序列结构：CLAP 的核心在于语言描述与动作 token 的因果顺序，复现时务必确认注意力掩码是否正确实现因果约束，这是最容易出错的地方。

  2. 单 epoch 微调是双刃剑：虽然大幅降低计算成本，但意味着对学习率和优化器设置非常敏感。建议先在小规模（0.8B）上验证训练稳定性，再扩展到更大模型。

  3. 语言描述的质量直接影响动作精度：由于动作 token 以语言为条件，语言描述若与任务指令不一致，可能导致动作生成偏差。下游团队需要检查语言描述生成是否与任务语义对齐。

  4. 开放权重家族便于跨规模对比：如果团队需要研究模型规模对 VLA 能力的影响，这套 0.8B/2B/4B 模型提供了现成的标准化平台，无需自行训练多个规模。

  5. 最可能踩坑的地方：论文未提供训练配置细节（如 batch size、学习率调度、数据混合比例），复现时这些超参数可能需要自行搜索。建议先复现 2B 模型在 LIBERO 上的结果，确认达到 90.8% 附近后再进行下游适配。
