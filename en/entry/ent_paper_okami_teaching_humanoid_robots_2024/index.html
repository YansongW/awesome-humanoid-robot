Summary

OKAMI: Teaching Humanoid Robots Manipulation Skills through Single Video Imitation is a 2024 work on manipulation for humanoid robots.

Sources

  • OKAMI: Teaching Humanoid Robots Manipulation Skills through Single Video Imitation (arXiv)
  • OKAMI: Teaching Humanoid Robots Manipulation Skills through Single Video Imitation project page

概述

OKAMI 提出一种通过单段人类视频教会人形机器人操作技能的方法，核心贡献在于将任务分解为物体识别、运动重定向和轨迹扭曲三个模块，利用 GPT4V 的视觉理解能力与逆运动学技术实现跨场景模仿。该方法在模拟环境中对多种精细操作任务取得显著优于基线 ORION 的成功率，并验证了无视觉感知时的性能上限。

它改变了什么

该工作真正改变的，是机器人操作学习中对“动作标注数据”的依赖范式。以往从视频学习策略，要么需要大量机器人本体动作数据，要么在视觉特征与动作空间之间建立脆弱的映射。OKAMI 将问题重新定义为“从视频中提取任务意图并重定向到新场景”，这跳过了端到端策略学习的黑箱，转而利用大模型（GPT4V）的常识推理和成熟的运动学求解器，使单段视频即可驱动人形机器人完成操作。

另一个关键转变在于，它把“模仿”从像素级对齐提升到“语义级重定向”。传统方法试图让机器人复现视频中的视觉轨迹，而 OKAMI 先识别被操作物体与参考物体，再将人体运动映射到机器人构型，最后根据新场景物体位置对轨迹进行 SE(3) 扭曲。这种分解使得方法天然具备跨场景泛化能力，而非局限于训练时的固定布局。

方法拆解

流程分解

  1. 物体识别：使用 GPT4V 分两步识别任务相关物体。第一步列出场景中所有前景物体，第二步从中筛选出“可能被人类操作或靠近人类的物体”，排除静止背景干扰物。随后再次调用 GPT4V 区分被操作物体（与手接触）与参考物体（放置或交互目标，若不存在则输出 "None"）。
  2. 运动重定向：
  3. 身体：从 SMPL-H 提取肩、肘、腕姿态，使用开源库 Pink 求解逆运动学（IK），确保肩肘方向与腕部姿态相似。IK 权重设置为：肩方向 0.04、肘方向 0.04、腕方向 0.08、腕位置 1.0。
  4. 手部：从 SMPL-H 手部网格获取 3D 关节位置，计算旋转角后应用到与机器人硬件同尺寸的规范 SMPL-H 模型，再用 dex-retarget 包优化求解机器人手部关节角。
  5. 轨迹扭曲：轨迹点用 SE(3) 表示，起点 p_start、终点 p_end。扭曲后轨迹为 p_t = T_start · p_start + (τ̂^robot(t) − T_start · p_start)，其中 τ̂^robot(t) = (τ^robot(t) − p_start)/(p_end − p_start) · (T_end · p_end − T_start · p_start) + T_start · p_start。该变换假设轨迹终点与起点不同，将参考轨迹线性映射到新场景的目标位置。
  6. 时间分割与接触检测：使用 CoTracker 跨帧跟踪物体采样关键点，计算每帧平均速度，用无监督变点检测算法识别关键帧作为子目标状态。接触检测通过计算物体点云间相对距离，低于阈值判定为接触；对难以几何推断的关系（如倒水）用 GPT4V 预测语义关系。

关键设计决策

  • 对比学习 vs 语义分解：OKAMI 未采用对比学习对齐视觉与动作特征，而是直接利用 GPT4V 的语义理解跳过模态对齐，这避免了负样本选择的敏感性。
  • IK 权重分配：腕位置权重 1.0 远高于方向权重（0.08），反映操作任务中末端位置精度优先于姿态精度。
  • 轨迹扭曲的线性假设：适用于大多数操作行为（起点终点不同），但限制了处理循环或复杂非线性轨迹的能力。

关键创新

  1. 大模型驱动的物体识别：首次将 GPT4V 的视觉常识推理引入人形机器人操作模仿流程，替代传统目标检测或人工标注。这使系统能自动区分任务相关与无关物体，且无需针对特定任务训练检测器，显著提升跨任务泛化性。

  2. SMPL-H 到人形机器人的完整重定向管线：同时处理身体与灵巧手，通过混合 IK 与角度映射，将人体运动学精确迁移到机器人构型。相比仅估计手掌轨迹的基线（ORION），该方法保留了手指级操作细节，这是完成精细任务（如撒盐、关抽屉）的关键。

  3. 语义引导的轨迹扭曲：将轨迹扭曲建立在物体语义关系（被操作物体、参考物体）之上，而非纯几何匹配。这使得扭曲能适应新场景中物体位置的任意变化，且通过时间分割与接触检测自动识别子目标状态，无需人工指定关键帧。

实验与结果

模拟评估（robosuite，GR1FixedLowerBody，50 次 rollout 平均成功率）

任务 OKAMI (w/ vision) OKAMI (w/o vision) ORION
Sprinkle-salt 82% 100% 0%
Close-the-drawer 84% 100% 10%
  • OKAMI 无视觉版本成功率远高于有视觉版本，说明感知噪声（部分观测点云、位置估计偏差）是主要误差来源，而非策略学习本身。
  • ORION 在 Sprinkle-salt 上完全失败（0%），在 Close-the-drawer 上仅 10%，证明仅估计手掌轨迹无法支撑精细操作。

成功条件

  • Sprinkle-salt：盐瓶到达盐被倒入碗中的位置。
  • Close-the-drawer：抽屉被推回包含区域。
  • 其他任务（Plush-toy-in-basket、Close-the-laptop、Place-snacks-on-plate、Bagging）均有明确定义的成功判据。

边界与局限

  • 模拟结果优于真实实验，作者归因于灵巧手与物体在模拟中更简单的物理交互，真实场景的接触动力学和感知噪声会显著降低性能。
  • 轨迹扭曲质量高度依赖物体位置估计精度，部分观测点云是主要误差来源；作者指出更强的高精度视觉模型预期可提升性能。
  • 轨迹扭曲假设起点与终点不同，不适用于循环轨迹或起点终点重合的操作。
  • 未在真实机器人平台验证，未探索跨数据集（不同机器人形态）迁移，未进行消融实验单独评估视觉/动作编码器影响。
  • 依赖 GPT4V 的识别准确性，其对“相关/无关”物体的判断可能受限于模型常识与提示词设计。

工程启示

  • 复现优先级：先核对 GPT4V 提示词设计，这是物体识别准确性的关键；其次确认 IK 权重（肩/肘/腕方向 0.04/0.04/0.08，腕位置 1.0）是否适配你的机器人构型。
  • 最容易踩坑：轨迹扭曲的线性假设在真实场景中可能失效，尤其是物体位置估计偏差较大时。建议先验证感知模块（CoTracker 跟踪 + 点云配准）的精度，再评估策略成功率。
  • 性能瓶颈：OKAMI 无视觉版本（100%）远高于有视觉版本（82%/84%），说明感知噪声是主要限制。若下游团队追求真实部署，应优先投入高精度视觉模型或滤波算法，而非优化策略网络。
  • 工程选型：身体 IK 用 Pink、手部重定向用 dex-retarget、跟踪用 CoTracker、策略用 ACT（DinoV2 骨干），这些均为现成开源组件，可快速搭建原型。ACT 超参数（KL weight 10、chunk size 60、hidden dim 512、batch size 45、ff dim 3200、epochs 25000、lr 5e-5、temporal weighting 0.01）可直接复用。
  • 验证建议：在模拟中先跑无视觉版本确认重定向与扭曲正确性，再逐步引入感知模块定位误差来源。
