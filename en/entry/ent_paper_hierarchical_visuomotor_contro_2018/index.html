Summary

Hierarchical visuomotor control of humanoids is a 2018 work on physics-based character animation for humanoid robots.

Sources

  • Hierarchical visuomotor control of humanoids (arXiv)

概述

本文提出一种分层视觉运动控制架构，用于构建具备感知、记忆与运动技能复用能力的人形智能体。高层控制器基于第一人称视觉与LSTM记忆，通过离散选择或连续转向指令，驱动由运动捕捉数据预训练的低层反应式运动技能库。核心贡献在于将数据驱动的低层技能库与高层语义决策解耦，并系统验证了“控制片段”作为高层动作原语的有效性。

它改变了什么

该工作真正改变的，是为人形机器人“视觉-运动”耦合问题提供了一条去手工化的可行路径。此前，端到端强化学习在同时处理高维视觉输入与56自由度动作输出时，在复杂任务（如觅食）中完全失效；而结构化控制器虽能工作，却依赖动画师级别的手工分割、混合与图转换设计。本文的动机并非提出新算法，而是重新划分问题边界：将“运动控制”与“语义决策”彻底分层，使高层只需在预训练的低层技能库上做稀疏选择，从而将高维连续控制问题转化为低维离散决策问题。这一架构性判断，使得视觉记忆与运动技能的组合首次在非稳定化第一人称视角下成为可能。

方法拆解

低层技能库训练

  • 使用CMU mocap数据，为每个2-6秒动作片段训练单一用途跟踪策略，56自由度身体采用位置控制，驱动范围映射至关节角度范围。
  • 奖励函数基于能量函数：E_total = w_qpos·E_qpos + w_qvel·E_qvel + w_ori·E_ori + w_gyro·E_gyro + w_vel·E_vel + w_ee·E_ee，系数分别为5、1、20、1、1、2；奖励 r_t = exp(-10·E_total / w_total)。
  • 策略仅接收自我中心观测（关节角度/速度、根到末端执行器向量、速度计、陀螺仪、加速度计、重力传感器），先监督预训练预测目标姿态，再以离策略分布式actor-critic（Retrace + SVG(0)）训练，目标网络每500步更新，使用固定噪声σ=0.1的随机策略与KL散度限制实现保守更新。

低层控制器变体

  • 可转向控制器：以转向半径作为额外输入，扭曲参考轨迹，训练单一策略实现连续可控转弯。
  • 切换控制器：基于1-of-k输入与预定义转换图，单一策略在多个行为间切换。
  • 控制片段：将行为切割为0.1-0.3秒微行为（实验中统一为3时间步，即0.09秒），由高层随机访问切换，无需手工设计转换。

高层控制器

  • 输入本体感觉与64x64第一人称图像，ResNet编码图像，LSTM实现时间整合；输出连续转向角（范围[-1.5, 1.5]）或1-of-K离散索引。
  • 使用V-Trace与Espeholt等人方法训练，策略梯度损失仅在采样新动作时非零；查询式控制片段选择基于Wolpertinger方法，生成高斯查询与片段特征键比较，但性能不如离散选择。

关键创新

  1. 控制片段作为高层动作原语：将行为切割为0.09秒的微行为，由高层随机访问切换，消除了手工设计转换图的负担，同时保持行为连贯性。这是对“技能复用”的极简实现，其有效性在Gaps任务中通过359个片段（4原始+8跳跃）得到验证。
  2. 分层解耦的架构判断：明确放弃端到端，将高维视觉-运动问题分解为“低层反应式跟踪”与“高层语义决策”两个可独立训练的子问题。这一判断使得复杂任务（如异质觅食）首次在非稳定化第一人称视觉下成功，而端到端方法在Forage任务中完全失败。
  3. 冷切换机制：高层可在任意时刻切换控制片段，无需等待步态周期或行为自然终止，这为高层提供了最大响应性，是Walls任务中能到达终点但速度较低的关键设计。

实验与结果

任务 高层输入 关键结果
Go-to-target 无图像 离散片段选择最佳；可转向控制器因固定转弯半径导致长旅行时间
Walls 64x64图像 切换控制器能到达终点但速度较低；离散片段选择表现最佳
Gaps 64x64图像 12个单片段策略（4原始+8跳跃）产生359个片段，离散选择成功
Forage 64x64图像 离散片段选择分数>150（600为最大）；端到端完全失败
Heterogeneous Forage 64x64图像 需记忆奖励值（+30/-10），离散片段选择成功
  • 查询式方法未优于离散选择，45/105个控制片段被训练策略选择，第二偏好片段通常不是参考键最相似的片段，暗示查询式前提不成立。
  • 控制片段长度比较：1时间步（0.03（由表内数值 0.1−0.1 计算）秒）与3时间步（0.09秒）训练最稳定；长度3在行为连贯性与性能间权衡最佳；增加片段数量不损害训练，额外无关策略易被忽略。

边界与局限

  • 结构化低层控制器（图转换、可转向）仍需大量手工策划，包括手工分割、混合/平滑，依赖动画师技能。
  • 作者明确承认未进行完全客观的算法比较，因结构化控制器训练涉及大量人工组件。
  • 端到端方法在复杂任务中失败，视觉外观不佳；低层技能自然度有限，不支持更通用的环境交互。
  • 查询式控制片段选择的前提（查询动作与片段特征键的语义对应）被实验否定，但作者未深入分析替代方案。
  • 论文未明确硬件配置、训练时间、样本效率等工程指标。

工程启示

复现时首先核对低层策略的保守更新细节：固定噪声σ=0.1与KL散度限制是关键，若改为学习方差易导致训练不稳定。控制片段长度建议从3时间步（0.09秒）起步，这是行为连贯性与响应性的经验平衡点；增加冗余策略（如8行为而非4行为）可加速训练且不损害性能，但需注意无关策略会被高层自然忽略。高层训练时，离散选择远优于查询式方法，后者因特征键语义不精确而失败，不建议投入工程资源。对于下游团队，最易踩坑的是低层技能库的覆盖度——Gaps任务需要额外跳跃策略，而Forage任务需要转向与转身策略，技能库设计应基于任务语义而非动作数量。若需处理非稳定化第一人称视觉，务必采用分层架构，端到端在复杂任务中已被证明不可行。
