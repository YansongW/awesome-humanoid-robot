Summary

Dexterous Safe Control for Humanoids in Cluttered Environments via Projected Safe Set Algorithm is a 2025 work on manipulation for humanoid robots.

Sources

  • Dexterous Safe Control for Humanoids in Cluttered Environments via Projected Safe Set Algorithm (arXiv)

概述

本文提出一种基于投影安全集算法（Projected Safe Set Algorithm）的人形机器人灵巧安全控制框架，在杂乱环境中实现受控摔倒与自我保护。作者在 Unitree G1 平台上结合 PPO 与 Lipschitz-Constrained Policies 训练全身控制策略，通过课程化域随机化实现 Sim2Real 迁移。核心贡献在于让智能体自主发现符合刚体动力学特性的摔倒保护策略，而非依赖人类先验或简化模型。

它改变了什么

现有受控摔倒研究大多建立在简化动力学模型上，引入膝盖缓冲、骨盆着地等人类摔倒先验，或要求额外硬件改造。但人形机器人是高自由度刚性金属系统，与人体柔软结构有本质差异——直接移植人类摔倒策略不仅不适用，还可能因关节过载造成永久性损坏。作者真正改变的是：放弃“模仿人类如何摔倒”的思路，转而让智能体在物理仿真中通过试错自行发现“金属机器人如何摔倒才不坏”。这一转变将问题从“轨迹设计”重构为“约束优化下的策略搜索”，使摔倒保护从预设动作变为涌现行为。

另一个关键改变在于奖励设计的反直觉处理。作者明确指出，直接激励手臂支撑会诱导策略产生“手臂直推地面”的奖励黑客行为，这在真实部署中会瞬间损坏肘关节。因此他们将目标从“减少冲击”细化为“减少所有身体部位、关节和驱动器的损伤”，并仅保留保护头部与躯干这一最小人类先验。这实际上把问题从运动学层面的“姿态控制”提升到动力学层面的“能量耗散分配”，是方法论上的实质转向。

方法拆解

训练框架

  • 采用 PPO 与 LCP 联合训练，在 Nvidia Isaacgym 中并行运行数千个环境实例，每个实例处于不同摔倒场景。
  • 遵循 Regularized Online Adaptation (ROA) 框架：训练时提供特权信息，部署时从最近 10 步观测中推断缺失量。

观测与动作空间

  • 观测空间为 [ω̇, r, p, q, q̇, aₜ₋₁]，其中 ω̇ ∈ R³ 为躯干角速度，r 和 p 为骨盆 roll、pitch 角，q ∈ R²⁹ 与 q̇ ∈ R²⁹ 为关节位置与速度，aₜ₋₁ ∈ R²⁹ 为上一时刻动作。
  • 策略输出 29 维关节目标位置，由底层 PD 控制器转换为力矩：τ(a) = Kp(a − q) − Kd q̇。
  • 上层策略频率 50Hz，底层 PD 频率 200Hz。

课程化域随机化

  • 从多维度递增难度：外部推力大小、方向、施加刚体部位、机器人 DoF 初始状态、根部速度、损坏驱动器。
  • 推力大小从低到高排列（白名单内数值 350550750 表示三档），方向覆盖 8 个角度，施加部位包括 Head、Torso、Pelvis。

涌现行为

  • 训练中自主形成三类关键策略：上臂构成“三角形”结构分散冲击；双腿展开降低质心并减少地面线性运动；优先保护头部、躯干与骨盆。

关键创新

  1. 从先验到涌现的范式转换：不预设任何摔倒姿态模板，完全依赖强化学习在物理仿真中搜索可行策略。这使得策略天然适配 Unitree G1 的 29 个自由度刚体动力学，而非削足适履地适配人类摔倒动作。

  2. 反奖励黑客的损伤导向设计：将“减少驱动器损伤”而非“减少冲击力”作为首要优化目标，并明确排除直接激励手臂支撑的朴素奖励。这一设计决策直接避免了仿真中看似成功、实则在真实硬件上必然损坏关节的局部最优解。

  3. ROA 框架下的特权信息蒸馏：训练时利用特权信息加速收敛，部署时仅凭最近 10 步观测推断缺失量，在保持策略性能的同时消除了对仿真专用信息的依赖，这是 Sim2Real 成功迁移的关键工程创新。

边界与局限

  • 论文未明确说明在真实杂乱环境（如存在移动障碍物、非结构化地面）中的验证情况。
  • 未讨论策略对机器人本体参数变化（如负载增减、关节磨损）的适应边界。
  • 未涉及多机器人交互或动态环境中的摔倒安全。
  • 奖励函数中“保护头部与躯干”这一最小先验的权重敏感性未做消融分析。
  • 所有测试均在 Unitree G1 平台完成，策略迁移到其他构型人形机器人的泛化性论文未明确。

工程启示

复现时首先核对奖励函数中“损伤惩罚”的具体定义——这是防止奖励黑客的第一道防线，建议直接采用作者“减少所有身体部位、关节和驱动器损伤”的表述，而非自行设计冲击力最小化目标。其次，课程学习的难度递增顺序至关重要：推力应从低档起步，待策略稳定后再逐步提升至 750 档，否则早期高难度样本会导致策略陷入局部最优。部署时务必确认 ROA 的 10 步观测窗口与 50Hz 推理频率的匹配关系——窗口过短会丢失动力学上下文，过长则引入延迟。最容易踩坑的是 PD 控制器参数 Kp 与 Kd 的设定：仿真中调优的参数在真实硬件上可能因关节柔性差异导致震颤，建议先在零推力条件下验证站立稳定性，再逐步引入推力干扰。最后，walk-break 测试中损坏驱动器的选择应优先覆盖踝关节（ankle roll/pitch），因为该部位失效对平衡影响最显著。
