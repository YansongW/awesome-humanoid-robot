Summary

RetoVLA: Reusing Register Tokens for Spatial Reasoning in Vision-Language-Action Models (RetoVLA), is a 2025 large vision-language-action model for robotic manipulation, introduced by School of Computing, Gachon University.

Sources

  • RetoVLA: Reusing Register Tokens for Spatial Reasoning in Vision-Language-Action Models (arXiv)
  • RetoVLA source

概述

RetoVLA 是一种面向轻量级视觉-语言-动作（VLA）模型的架构改进方法，通过主动复用视觉 Transformer 中通常被丢弃的 Register Tokens，在不增加计算负担的前提下恢复空间推理能力。该方法由研究团队提出，核心贡献在于建立双流信息通路，将全局空间上下文注入动作专家（Action Expert）的交叉注意力层，并辅以门控机制自适应调节其影响。

它改变了什么

轻量级 VLA 模型（如 SmolVLA）在追求部署效率时，往往通过削减模型深度来换取速度，但这直接导致空间推理能力的显著退化。此前的主流观点认为，视觉 Transformer 中的 Register Tokens 仅用于吸收冗余注意力噪声，对下游任务无实际价值。RetoVLA 从根本上挑战了这一假设，它证明这些被丢弃的令牌中蕴含着场景布局、物体 3D 关系等关键空间上下文，并成功将其转化为可用的推理信号。

这项工作的真正改变在于：它打破了“效率与空间能力不可兼得”的固有权衡。通过复用而非丢弃现有计算产物，RetoVLA 在保持轻量模型推理速度的同时，将真实机器人操作成功率提升了 17.14 个百分点（由表内数值 50.28%→67.42% 计算），这为资源受限的机器人部署提供了新的设计范式——优化方向不再局限于模型规模，而是转向对已有信息流的深度挖掘。

方法拆解

架构总览

RetoVLA 基于标准 VLM 主干（仅使用前 N=L/2 层）与 Action Expert 构建，建立双流信息通路： - 语义特征流：VLM 浅层输出的高维语义特征，直接传递至 Action Expert - 空间上下文流：通过 Spatial Context Aggregator 生成的 Register Tokens，注入 Action Expert 的交叉注意力层

Register Token 生成

图像 patch 嵌入 P∈ℝ^(B×N×D_vlm) 输入标准多头注意力块，可学习初始寄存器令牌 R_init∈ℝ^(K×D_vlm) 作为 Query，图像 patch 作为 Key/Value，生成场景相关 Register Tokens R_scene（公式 1）。这一设计使令牌能够根据具体场景动态调整，而非固定不变。

注入 Action Expert

R_scene 投影到 Action Expert 维度后转换为 Key/Value 对（K_reg、V_reg），与 VLM 的标准语义 Key/Value 对（K_vlm、V_vlm）拼接，注入最终交叉注意力层（公式 2、3）。这种非侵入式设计允许查询灵活关注语义特征或全局空间摘要，根据任务需求动态选择信息源。

门控机制

引入可学习标量 g，经 sigmoid 函数 σ(·) 缩放 Register Tokens 的影响。该设计解决了不同任务对全局上下文需求不均的问题：需要整体场景理解的任务（如多米诺骨牌搭建）自动放大全局信息权重，而需要局部精度的任务（如按大小堆叠）则自动抑制。

训练目标

采用条件流匹配（Conditional Flow Matching），学习向量场 v_θ(a_t,t,c)，将噪声分布变换为动作分布。插值 a_t=(1-t)a_0+t a_1，向量场 u_t=a_1-a_0，损失为预测与真实向量场的均方误差（MSE）。

关键创新

  1. Register Tokens 的语义重定义：首次系统性地证明视觉 Transformer 中看似“无用”的 Register Tokens 蕴含可操作的空间上下文，并将其转化为机器人控制信号。这一发现挑战了计算机视觉领域的既有认知，为信息复用提供了新思路。

  2. 非侵入式双流融合机制：通过将空间上下文作为额外的 Key/Value 对注入交叉注意力层，而非修改主干结构，实现了对现有 VLA 架构的最小侵入改造。这种设计使得 RetoVLA 可以轻松适配不同的 VLM 主干和 Action Expert，具有良好的可扩展性。

  3. 自适应门控机制：可学习标量 g 通过 sigmoid 函数动态调节全局上下文的影响，解决了不同任务对空间信息需求差异巨大的问题。这一机制避免了手动调整融合权重的繁琐过程，使模型能够自主学习何时依赖全局信息、何时依赖局部细节。

实验与结果

真实机器人实验（7-DOF 机械臂，7 个任务）

指标 SmolVLA RetoVLA Δ
平均成功率 50.28%±11.06% 67.42%±9.07% +17.14%p

任务级提升最显著的是 Close Drawer（+36.0%p）和 Build Domino Line（+28.0%p），而 Stack by Size 出现 -4.0%p 的退化，验证了门控机制在局部精度任务上的权衡。

自定义仿真实验

MSR 从 62.8% 提升至 74.8%（+12.0%p），其中 Build Domino Line 提升 +24.0%p，Pull and Place (Jenga) 提升 +16.0%p，与真实实验趋势一致。

LIBERO 基准

基准 SmolVLA MSR RetoVLA MSR Δ
Spatial 75.8% 76.2% +0.4%p
Object 70.8% 71.8% +1.0%p
Goal 80.4% 80.4% 0.0%p

LIBERO 基准提升有限，但任务级变化范围较大（-26.0%p 到 +18.0%p），表明 Register Tokens 的效果高度依赖任务特性。

最优配置为 2 个 Register Tokens，超过 2 个后性能下降，说明过多的全局摘要可能引入噪声。

边界与局限

论文未明确评估动态环境中的表现，也未在更大主干（如 OpenVLA）上验证方法的泛化性。在需要高局部精度的任务上存在性能权衡（如 Stack by Size -4.0%p），作者承认需更深入调查更复杂的门控或融合机制。此外，方法仅聚焦于操作任务，未评估移动导航等其他机器人领域。LIBERO 基准上的提升有限（最高 +1.0%p），表明在标准化仿真环境中 Register Tokens 的增益可能被其他因素稀释。

工程启示

复现 RetoVLA 时，首先核对 Register Tokens 的数量配置——消融实验表明 2 个为最优，超过 2 个会导致性能下降，这是最容易踩坑的参数。其次，注意峰值性能检查点差异：SmolVLA 约 40k-50k 步，RetoVLA 约 60k-70k 步，训练步数不足可能导致对比不公平。对于下游团队，建议优先在需要全局场景理解的任务（如长序列操作、多物体交互）上部署，而在高精度局部操作任务上谨慎评估。门控机制的初始值设置可能影响收敛速度，建议参考论文中的默认配置并针对具体任务微调。最后，注意真实实验中的相机配置差异（如 Clean Marker on Mirror 仅用单腕部相机），这会影响 Register Tokens 对空间信息的捕捉能力。
