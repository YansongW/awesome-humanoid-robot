Summary

NuExo: A Wearable Exoskeleton Covering all Upper Limb ROM for Outdoor Data Collection and Teleoperation of Humanoid Robots is a 2025 work on teleoperation for humanoid robots.

Sources

  • NuExo: A Wearable Exoskeleton Covering all Upper Limb ROM for Outdoor Data Collection and Teleoperation of Humanoid Robots (arXiv)

概述

NuExo 是国防科技大学智能科学学院研发的一款可穿戴上肢外骨骼，专为户外数据采集与人形机器人遥操作设计。其核心贡献在于通过创新的肩部联动机构与同步带传动，首次实现了胸锁关节补偿的可穿戴化，在覆盖全上肢活动范围（ROM）的同时将总重控制在 5.2 kg，并集成了力、视觉、手指等多模态数据同步采集能力。

它改变了什么

现有上肢数据采集与遥操作设备面临一个根本性矛盾：精度、舒适性、多功能性与便携性难以兼得。手持控制器和 VR/XR 设备虽然轻便，但缺乏力反馈且操作直觉性差；视觉/惯性动捕系统（如 Noitom）精度尚可，但长时间使用存在漂移，且无法提供力数据。更关键的是，传统肩部外骨骼为补偿胸锁关节运动，往往需要增加两个额外执行器，导致肩部模块多达五个电机，机械干涉严重、重量分布失衡，完全无法支撑户外非结构化场景的部署需求。

NuExo 真正改变的是“肩部补偿必须付出重量与复杂度代价”这一设计定式。它通过将 GH 关节水平移动与上臂旋转自由度在机械传动层面合并，把肩部执行器从五个削减到一个，同时不牺牲跟踪性能。这一结构性突破使得“全上肢 ROM 覆盖 + 力传感 + 户外便携”首次成为可能，而非在各项指标间做取舍。它重新定义了可穿戴遥操作设备的性能边界——不是“更轻的实验室设备”，而是“能走出实验室的完整解决方案”。

方法拆解

肩部机构：联动与同步带传动

  • 采用四连杆联动机构，将胸锁关节的水平移动（GH 水平移动）与上臂旋转通过机械传动合并为一个自由度。
  • 关键参数：L1=150 mm，L2=187 mm，θE=2.508 rad，θ2=1.444θ1+0.938 rad。该参数设计确保联动机构在肩部全 ROM 内无奇异点，且电机扭矩传递效率最优。
  • 同步带传动替代传统直驱，使电机可重新布置到肘部附近，避免抬臂时与人体头部干涉。

肘部与腕部模块

  • 肘部采用双执行器结构，将肩部节省下的一个电机重新定位至肘部，实现“肩一肘二”的驱动分配，平衡整臂重量分布。
  • 腕部放弃传统机械机构，改用差分 IMU 配置（两个 IMU 差分计算腕部姿态），优先保证人体工学兼容性，并简化与力反馈数据手套的集成。

控制框架：统一遥操作

  • 核心为速度（twist）跟踪 + 位置（pose）闭环，通过阻抗控制实现，并引入主动力分量 F_ft。
  • 肩部控制律：τ_cmd^s = k_p f_P^{-1}(q^t) + k_d J^{-1} q̇^t + λ J^T F_ft，其中 q^t = q^{s*} q^m，q̇^t = q̇̂^m - q̇̂^s。
  • 肘/手指控制律：q^t_i = q^m_i - q^s_i，τ_cmd-i^s = k_p q_t + k_d q̇^t_i + λ τ_ft。
  • 主端外骨骼控制：τ_cmd^m = τ_com^m + τ_h^m，其中 τ_com^m 包含惯性、科里奥利力、重力、摩擦补偿，τ_h^m 基于全臂协调机制（FCM）与绑定对齐策略（BAS），确保人机交互力最小化。

软件架构

  • 四个模块化节点：外骨骼节点、人形机器人节点、遥操作控制器节点、底层驱动程序。更换驱动节点即可适配不同机器人，且支持多实例并行控制多台机器人。
  • 数据采集系统同步采集六类数据：遥操作指令、上肢运动学、第一人称视频、手指运动、里程计、力反馈，通过 IMU 里程计系统实现时空对齐。

关键创新

  1. 胸锁关节补偿的可穿戴化：此前 Harmony-SHR、ANYexo 等方案均以增加执行器为代价实现肩部补偿，导致机械干涉与重量失控。NuExo 通过联动机构将两个自由度机械合并，首次在可穿戴尺度上实现补偿功能，且肩部仅保留一个电机。这是机构设计层面的范式转变，而非参数优化。

  2. 差分 IMU 腕部方案：传统腕部外骨骼需要复杂的机械关节来匹配腕部三自由度运动，体积与重量代价高。NuExo 用差分 IMU 配置替代，牺牲部分绝对精度换取人体工学兼容性与集成便利性，为力反馈手套等下游设备留出接口空间。这一取舍在“数据采集”而非“高精度遥操作”场景下是合理的。

  3. 力反馈与遥操作控制的统一框架：控制律中显式引入 F_ft 主动力项，使外骨骼既是数据采集设备，又是力反馈执行器。这种“采集-反馈”双向通道的设计，在现有系统中极为罕见，为后续技能学习中的力信息利用提供了硬件基础。

实验与结果

数据采集精度对比（与 Noitom® PN studio 惯性动捕系统）

指标 NuExo (EXO) Noitom (IMC)

起始阶段平均偏差 (rad) x=-0.05, y=0.04, z=0.07 x=-0.14, y=0.02, z=-0.06
扰动后最大偏差 (rad) x=0.26, y=0.39, z=0.33 x=0.20, y=0.21, z=0.22

关键结果

  • 校准后静态精度：两者均约 0.1 rad，初始精度相当。
  • 10 分钟高强度运动（跑步、跳跃）后：IMC 峰值静态误差达 0.41 rad，NuExo 持续低于 0.14 rad（由表内数值 0.41→0.14 计算，误差降低约 66%（由表内数值 0.41→0.14 计算））。
  • 遥操作高动态跟踪：平均角度误差 0.015 rad，峰值 0.05 至 0.08 rad（主要源于从动机器人机械惯性）。
  • 低速操作：平均误差降至 0.01 rad；滤波器抑制人体震颤低于 0.015 rad。
  • 精细任务：电螺丝刀拧紧直径 2.5 mm 螺丝头；高动态任务：抛球入 1.2 米外箱子。

结果含义

NuExo 在静态精度上与商业动捕系统持平，但在高强度运动后的抗漂移能力上显著优于 IMC。这验证了机械约束（外骨骼）相比纯惯性推算（IMC）在长时间非结构化场景下的本质优势。遥操作精度足以支撑毫米级精细操作，且不同操作者无需预训练即可完成任务，说明其人体工学设计有效降低了学习成本。

边界与局限

  • 仅覆盖上肢：论文未涉及下肢或全身运动，对于全身遥操作或全身技能学习场景，NuExo 无法独立提供完整数据。
  • 多模态数据有效性未验证：作者明确表示，六类数据组合在类人机器人技能学习中的有效性尚未实验验证，力数据的具体应用效果同样未测试。
  • 腕部精度取舍：差分 IMU 方案在静态精度上可能不如机械关节，论文未提供腕部独立精度数据，仅给出整体上肢结果。
  • 长期佩戴舒适性：5.2 kg 总重虽在可穿戴设备中较轻，但论文未提供长时间（数小时）佩戴的舒适性主观或客观评估。
  • 对比基准单一：仅与 Noitom 惯性动捕对比，未与光学动捕或现有外骨骼（如 Harmony-SHR）进行直接对比。

工程启示

  • 复现优先核对肩部联动参数：L1=150 mm、L2=187 mm、θE=2.508 rad、θ2=1.444θ1+0.938 rad 是机构设计的核心，任何偏差都可能导致 ROM 覆盖不足或奇异点。建议先用仿真验证联动轨迹，再加工实物。
  • 电机布置是最大工程风险：肩部单电机 + 肘部双执行器的方案依赖同步带传动，带轮张紧力与传动比需精确标定。若张紧不当，会出现回程误差，直接影响遥操作精度（目标 0.015 rad 级）。
  • 力传感器集成位置敏感：六轴力传感器位于上臂和前臂绑定界面，安装时需确保与皮肤接触面均匀，否则 F_ft 信号噪声会污染控制律中的 λ J^T F_ft 项。
  • 下游团队选型建议：若任务需要长时间户外数据采集且关注力信息，NuExo 是当前唯一公开的完整方案；若仅需高精度运动学数据且场景受控，传统光学动捕仍是更稳妥选择。
  • 软件适配成本低：模块化节点设计意味着更换底层驱动即可对接不同人形机器人，但需注意不同机器人的关节限位与速度限制，否则遥操作指令可能触发安全保护。
