Summary

This paper proposes a multi-agent framework—Active Spatial Brain for active spatial perception and planning, and Generalizable Action Cerebellum for decoupled lower-body locomotion and upper-body dexterous manipulation—that enables spatial-aware humanoid whole-body manipulation without task-specific real-robot data. It is validated on a spatial intelligence benchmark and on a real Unitree G1 humanoid robot.

Sources

  • Humanoid Whole-Body Manipulation via Active Spatial Brain and Generalizable Action Cerebellum

Overview

This paper proposes a humanoid whole-body manipulation framework that does not require real robot data, adopting a hierarchical multi-agent architecture with an "Active Spatial Brain" and a "Generalizable Action Cerebellum." It leverages VLM spatial reasoning and generalization knowledge to complete spatial perception, task planning, and action generation. The system is validated on the Unitree G1 robot and significantly outperforms data-driven baselines across various spatial perception tasks, with particularly notable success rate improvements in hard scenarios.

What It Changes

The core change of this work lies in shifting humanoid whole-body manipulation from a "data-driven paradigm" to a "model-driven + spatial reasoning paradigm." Existing methods (such as TrajBooster, Ψ₀) rely on large-scale real robot trajectory data, which works reasonably well in tabletop scenarios. However, when extended to humanoid robots, the observation space (RGB-D + proprioception) and action space (camera, dexterous hands, upper and lower body) expand dramatically, making data collection costs and distribution shift issues the bottleneck. This paper directly bypasses the data bottleneck, replacing data-driven perception and planning with VLM spatial intelligence, and replacing learned action generation with parameterized action primitives, thereby achieving cross-scenario generalization under zero real robot training data.

More critically, it changes the role of "spatial perception" in manipulation tasks—no longer passive observation from a fixed viewpoint, but rather treating active camera motion (2-DoF neck + 4-DoF base) as a decision variable, allowing the VLM to dynamically adjust the viewpoint based on the task stage. This "perception-as-action" design enables the system to proactively eliminate occlusion and obtain more comprehensive spatial information, which is difficult for data-driven methods to achieve. At the same time, it decouples fine-grained metric tasks (such as waypoint generation) from the VLM, delegating them to deterministic algorithms (grid map + A* + RDP), thereby circumventing the VLM's weaknesses in precise measurement.

Method Breakdown

Overall Architecture: Hierarchical Closed-Loop Multi-Agent

The system forms a closed loop with two tightly coupled components: the Active Spatial Brain (VLM-driven) handles spatial perception, task decomposition, and decision-making; the Generalizable Action Cerebellum (MLLM + parameterized primitives) generates executable actions. The Brain decomposes long-horizon goals into a sequence of subtasks, progressively invoking agents in the Cerebellum for execution, and feeds feedback back to the Brain until task completion.

Active Spatial Perception

  • Predefined action space: 2-DoF camera neck motion + 4-DoF base motion (x, y, z translation + rotation about z).
  • The VLM directly makes viewpoint decisions from RGB-D observations and task instructions, without requiring explicit 3D reconstruction.

Memory Bank

  • Hybrid recording motion-conditioned policy: Archives only images captured by the perception module since the last base movement, pairing each image with its camera pose.
  • Simultaneously maintains a text log recording all instructions and feedback issued from the Brain to the Cerebellum.
  • Design rationale: Selective image archiving avoids information redundancy, while the global text log enables the VLM to accurately infer the task stage and maintain spatial perception consistency.

Adaptive Task Planning

  • At each step, evaluates the sequence and memory bank, triggering one of two behaviors: (i) active viewpoint adjustment; (ii) invocation of downstream agents.
  • Supports dynamic replanning: automatically re-invokes the manipulation agent for a second attempt upon detecting grasp failure.

Lower-Body Locomotion

  • Navigation agent: Depth map → camera-frame 3D point cloud → discretized ground grid map (grid size d). Occupancy determination: 𝒢(i,j)=1 if ∃𝐱∈𝒞_ij such that z(𝐱)>h, otherwise 0. A* algorithm computes collision-free paths, RDP algorithm simplifies to generate waypoint sequences {𝐩_i}, closed-loop tracking computes v_x,t and ω_y,t, maintaining nominal base height h_t.
  • End-effector reachability solver: Optimization objective min λ₁‖Δ𝐝‖²₂ + λ₂(Δz)² + λ₃‖𝐩_obj(𝐩_t,Δ𝐝,Δz)−𝐩_shoulder(Δz)‖²₂, with constraint ‖𝐩_obj−𝐩_shoulder‖₂≤ηL (η=0.8 safety margin). MuJoCo simulation estimates the kinematic offset model Φ(z)=(δx(z),δz(z)).
  • RL policy: Adopts the HOMIE method, taking proprioceptive state s_t and base command c_t=[v_x,t,ω_y,t,h_t] as input, outputting a_lower,t=π_loco(s_t,c_t).

Upper-Body Dexterous Manipulation

  • Grasp pose generation: Multimodal foundation generation model synthesizes hand-object interaction images Î_ho → Hyper3D generates 3D mesh ℳ_o → EasyHOI estimates MANO hand pose 𝒢_mano → fingertip alignment retargeting, optimizing min Σ_k‖p_dex,ft_k−p_mano,ft_k‖²₂.
  • Post-grasp trajectory generation: Large model predicts semantic 2D keypoints and selects action primitives; keypoints are lifted to 3D and 6-DoF end-effector poses are derived via primitive kinematic rules. Four primitives: Push (linear translation), Pull (linear translation), Place (maintaining hand-object spatial offset), Rotate (local rotation based on pivot). All primitives begin with an alignment phase, and an IK solver converts continuous poses into joint commands.

Key Innovations

  1. Zero real robot data whole-body manipulation framework: This is the first humanoid whole-body manipulation approach that completely bypasses the data-driven paradigm. Existing methods (TrajBooster, Ψ₀) require at least 20 trajectories of fine-tuning per task setup, whereas this paper requires no task-specific real data training or fine-tuning, directly leveraging VLM pretrained knowledge for cross-scenario generalization. This carries paradigmatic significance in the humanoid robotics field where data collection costs are prohibitively high.

  2. Closed-loop design of active spatial perception and memory bank: Incorporating camera motion into decision variables enables the system to proactively eliminate occlusion and obtain more comprehensive spatial information. The hybrid recording motion-conditioned policy (archiving only images after base movement + global text log) balances information completeness and computational efficiency, enabling the VLM to accurately infer task stages—a "perception-as-action" capability difficult for data-driven methods to achieve.

  3. Decoupling of VLM high-level planning and deterministic algorithm fine-grained execution: Tasks requiring precise measurement, such as waypoint generation, are stripped from the VLM and delegated to deterministic algorithms like grid map + A* + RDP; grasp pose generation is delegated to specialized foundation models like Hyper3D + EasyHOI. This division of labor—"VLM makes decisions, specialized models execute"—circumvents the VLM's weaknesses in fine-grained measurement (Task 3 best Appropriate rate only 64.91%) while preserving the VLM's generalization capability.

Boundaries and Limitations

The paper does not include a dedicated "Limitations" section; the following boundaries can be inferred from the content: - Limited advantage in simple scenarios: In easy tasks, this framework shows little difference from Ψ₀ and CaP (some tasks tie), indicating data-driven methods remain competitive in low-difficulty scenarios. - VLM metric perception bottleneck: The best Appropriate rate for Task 3 waypoint generation is only 64.91%, with a Fail rate still at 21.05%, indicating the VLM's limited capability for precise spatial measurement. This framework circumvents the issue through decoupling, but the VLM's inherent capability remains the system's upper bound. - Dynamic environments not covered: No mention of moving obstacles, dynamic targets, or similar scenarios; the current design assumes static environments. - Multi-object and long-horizon tasks not validated: No coverage of multi-object complex manipulation or extended continuous multi-task execution. - Platform transfer not validated: Only validated on Unitree G1 + Inspire FTP dexterous hand + Realsense D435i; other dexterous hand models or humanoid platforms have not been tested.

Engineering Insights

  • Verify VLM selection first: Table 4 shows gemini-3.1-pro leads comprehensively in spatial reasoning (Task 1/2), but qwen3.5-plus has a clear speed advantage (Task 2 time 32.15 seconds vs. gemini-3.1-pro's 44.73 seconds). If real-time requirements are high, a trade-off between accuracy and speed is necessary.
  • Most likely pitfall: The VLM's fine-grained measurement capability (Task 3) is the system bottleneck, with the best Appropriate rate only 64.91%. When reproducing, be sure to maintain the decoupled design of "VLM for high-level decisions, deterministic algorithms for fine-grained execution"—do not attempt to have the VLM directly output precise waypoints or poses.
  • Active Perception (AP) and End-effector Reachability Solver (EES) are both essential: Ablation shows the best results when combined (67.5%/70.0%), with significant degradation when either component is used alone. When reproducing, ensure both modules are correctly implemented, especially the MuJoCo kinematic offset model Φ(z) calibration for EES.
  • Hard scenarios are the core value proposition: This framework improves Task4 (obstacle avoidance) hard scenario from 0% to 60%, and Task3 (height + position) hard scenario from 10% to 55%. If downstream tasks are primarily simple tabletop manipulations, this framework's advantage is limited, and data-driven approaches may be considered.
  • Memory bank design requires attention: The hybrid recording strategy (archiving only images after base movement + global text log) is key to spatial perception consistency. When reproducing, ensure precise alignment between camera poses and images; otherwise, the VLM's spatial inference will be distorted.
