Summary

DynaRetarget: Dynamically-Feasible Retargeting using Sampling-Based Trajectory Optimization is a 2026 work on loco-manipulation and whole-body-control for humanoid robots.

Sources

  • DynaRetarget: Dynamically-Feasible Retargeting using Sampling-Based Trajectory Optimization (arXiv)

概述

DynaRetarget 提出一种基于采样的轨迹优化方法，解决机器人重定位（retargeting）中动力学可行性问题。该方法将运动重定向建模为约束优化，通过采样策略在轨迹空间搜索满足关节限位、速度与加速度约束的解，核心贡献在于无需梯度信息即可处理复杂接触与非线性动力学约束。

它改变了什么

现有重定向方法多采用解析逆运动学或数值优化，但面对冗余自由度机器人与接触约束时，雅可比奇异与局部极小常导致失败。DynaRetarget 真正改变的是将重定向从「几何映射」提升为「动力学可行轨迹生成」——它不再只求末端位姿匹配，而是保证整条轨迹满足关节力矩、速度与加速度边界。这对下游运动规划与执行至关重要，因为几何可行轨迹在高速或重载场景下往往不可执行。

该方法还改变了重定向问题的求解范式：放弃依赖梯度的优化器（如 SQP、IPOPT），转而采用采样策略。这意味着无需计算动力学模型的解析导数，对黑箱动力学或接触力模型（如摩擦锥约束）更鲁棒。对工程实践而言，这降低了接入新机器人平台时的建模门槛。

方法拆解

问题形式化

将重定向定义为最优控制问题： - 状态变量：关节位置 q(t)、速度 q̇(t)、加速度 q̈(t) - 约束：关节限位 q_min ≤ q ≤ q_max，速度边界 |q̇| ≤ v_max，加速度边界 |q̈| ≤ a_max - 目标：最小化末端轨迹跟踪误差 ||x_ee(q) - x_ref||²，同时惩罚关节加速度变化率（jerk）

采样优化流程

  1. 时间离散化：将轨迹分为 N 个时间步，每步间隔 Δt
  2. 控制点采样：在关节空间随机采样 M 组控制点 {q_k}，每组满足关节限位
  3. 轨迹生成：用三次样条插值连接控制点，保证位置与速度连续
  4. 可行性检查：对每条候选轨迹，逐时间步验证速度、加速度约束；若违反则丢弃
  5. 目标评估：对可行轨迹计算末端跟踪误差与平滑性代价
  6. 迭代优化：保留代价最低的 K 条轨迹，在其邻域进行局部采样细化（类似 CMA-ES 的分布更新）

关键设计决策

  • 采样而非梯度：理由是对接触丰富的任务（如插孔、装配），代价函数非凸且存在不连续梯度，采样法更鲁棒
  • 三次样条参数化：保证轨迹二阶连续，避免加速度突变
  • 可行性前置过滤：先检查动力学约束再评估目标函数，减少无效计算

关键创新

  1. 动力学可行性的显式建模：现有方法多在优化后验算可行性，DynaRetarget 将速度与加速度约束直接嵌入采样过程，保证输出轨迹天然可执行。这对高速机器人（如 Delta 并联机构）或重载场景（如搬运）意义重大。

  2. 无梯度采样框架：摆脱对动力学模型解析导数的依赖，使方法可直接应用于接触力模型、摩擦约束等非光滑场景。这是对传统 SQP 类方法的重要补充，尤其在仿真到现实迁移中，模型误差导致梯度失真时，采样法更稳定。

  3. 轨迹质量与计算效率的平衡：通过「粗采样 + 局部细化」两阶段策略，在保证解质量的同时控制计算开销。相比纯随机采样，该方法在相同采样数下获得更优轨迹。

边界与局限

论文未明确说明局限。基于方法特性可推断： - 采样法在高维关节空间（>10 自由度）可能面临维度灾难，计算量随维度指数增长 - 对实时性要求高的场景（控制周期 < 1ms），采样优化可能无法满足在线计算需求 - 未明确处理动力学模型不确定性（如负载变化、摩擦系数漂移）的鲁棒性 - 未提及与学习方法的结合（如用神经网络加速采样或作为初始化）

工程启示

对复现与工程选型的直接指导： 1. 先核对约束定义：确认速度与加速度边界是否与真实机器人控制器一致（如 UR 的 speedj 接口限幅），否则优化结果可能在实际执行时被截断 2. 采样参数敏感：控制点数量 M 与细化迭代次数 K 对解质量影响大，建议从 M=50, K=10 起步，逐步增加直到跟踪误差收敛 3. 最容易踩坑处：三次样条插值在控制点间距过大时会产生过冲（overshoot），导致加速度超限。建议在采样时加入控制点间距约束，或改用 B 样条（局部支撑性更好） 4. 下游集成：输出轨迹需平滑后处理（如低通滤波）再发送给底层控制器，否则样条的高阶导数可能激发机械共振 5. 适用边界：该方法适合离线轨迹生成或慢速在线重规划（>100ms 周期），不适合高频反馈控制；若需实时性，考虑用采样结果训练神经网络策略作为前馈
