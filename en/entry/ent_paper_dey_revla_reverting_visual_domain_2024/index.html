Summary

ReVLA: Reverting Visual Domain Limitation of Robotic Foundation Models (ReVLA), is a 2024 large vision-language-action model for robotic manipulation, introduced by INSAIT, Sofia University “St. Kliment Ohridski”, and published at ICRA 2024.

Sources

  • ReVLA source

概述

ReVLA 针对 OpenVLA 等机器人基础模型在视觉域外（OOD）场景泛化失败的问题，提出一种基于模型合并的逐步骨干网络回退方法。该方法在保持训练协议不变的前提下，通过线性插值调度逐步恢复 DINO-v2 与 SigLIP 的预训练权重，有效缓解了视觉编码器的灾难性遗忘。在 SIMPLER 仿真环境的域内与 OOD 任务上，ReVLA 相比 OpenVLA 基线取得了显著性能提升，尤其在抓取与举起成功率上表现突出。

它改变了什么

现有机器人基础模型（如 OpenVLA）在预训练后微调于特定数据集时，视觉骨干网络会发生灾难性遗忘，导致深度估计等底层视觉能力退化，进而损害模型对未见场景的泛化。作者通过实验证实，OpenVLA 中的 DINO-v2 编码器在训练后其深度回归能力严重下降（DPT 输出常数），这直接限制了模型在 OOD 视觉条件下的表现。ReVLA 的核心改变在于：它不修改训练数据或损失函数，而是通过模型合并技术，在微调过程中逐步将视觉骨干的权重向预训练状态回退，从而在保留任务相关技能的同时恢复通用视觉表征。这一思路将问题从“如何设计更好的训练目标”转向“如何在后训练阶段修复已损坏的表示”，为机器人基础模型的持续学习提供了一种轻量级、无需额外数据的补救范式。

方法拆解

回退调度

  • 权重插值公式：θ = (1−α)·θ_OpenVLA + α·θ_Pretrained，其中 α 为预训练权重混合系数。
  • 步进课程：每 n 步将 α 增加 1/k，总训练步数 N = k × n。本文设置 N = 100000 步，n = 10000 步，即 α 在 10 个阶段内从 0 线性升至 1。
  • 回退对象：DINO-v2（负责空间与 3D 推理）与 SigLIP（负责语义理解），训练期间视觉骨干保持冻结，仅更新策略头与语言编码器。

变体设计

  • ReVLA (DS gradual)：逐步回退 DINO-v2 与 SigLIP 两个骨干。
  • ReVLA (DS flip)：训练开始时（α=1）硬回退两个骨干。
  • ReVLA (D gradual)：仅逐步回退 DINO-v2，SigLIP 全程冻结。
  • ReVLA (D flip)：仅硬回退 DINO-v2。

评估框架

  • 基于 SIMPLER 环境（SAPIEN 模拟器）构建 OOD 评估，引入 YCB 数据集对象（Pear、Mustard Bottle、Tomato Can）与视觉干扰物，共 216 个 OOD 场景（每设置 36 个 episode）。
  • 域内评估沿用 SIMPLER 的 Pick Coke Can 任务，采用 Visual Matching 与 Variant Aggregation 两种协议。

训练配置

  • 数据集：Fractal RT-1 机器人动作数据集，约 73.5K 条轨迹，含模板化语言注释。
  • 硬件：单个 Nvidia A100 节点。
  • 基线：OpenVLA（OpenX 训练）与 OpenVLA-fractal（Fractal 微调，相同步数与超参数）。

关键创新

  1. 首次将模型合并用于修复机器人基础模型的视觉遗忘：不同于常见的合并后推理或合并后微调，ReVLA 将合并作为训练过程中的动态调度机制，在微调阶段逐步注入预训练权重，实现了“边训练边修复”的效果。这一设计直接针对视觉编码器的灾难性遗忘，而非通过数据增强或正则化间接缓解。
  2. 区分视觉骨干的功能角色：通过分别回退 DINO-v2 与 SigLIP，作者揭示了空间/深度推理（DINO-v2）与语义理解（SigLIP）在 OOD 泛化中的不同贡献。实验表明，仅回退 DINO-v2 即可获得大部分收益，而 SigLIP 的硬回退（flip）在 OOD 总成功率上略优于逐步回退，说明不同骨干的最优修复策略存在差异。
  3. 无需额外数据或计算开销的通用补救方案：ReVLA 完全复用 OpenVLA 的训练协议与数据，仅改变权重更新方式，即可在域内与 OOD 任务上同时提升性能。这为已部署的机器人基础模型提供了一条低成本、可即插即用的升级路径。

关键结论

  • ReVLA (gradual) 在 Visual Matching 协议下比 OpenVLA 提升 42.3%（由表内 0.177→0.600 计算），比 OpenVLA-fractal 提升 23.9%（由表内 0.361→0.600 计算）。
  • OOD 任务中，ReVLA (DS flip) 比 OpenVLA 提升 12.5%（由表内 0.162→0.287 计算），对应抓取与举起任务分别提升 77% 与 66%（论文原文标注）。
  • 消融显示：ReVLA (Flip) 在 OOD 总成功率上比 ReVLA (Gradual) 高 0.9%（由表内 0.287→0.278 计算），但 ReVLA (Gradual) 的抓取成功率更高（0.579 vs 0.495）。

边界与局限

  • 训练仅在 Fractal 数据集上进行，该数据集规模与多样性有限（约 73.5K 轨迹，Table-Top 与 kitchen-top 场景），可能无法代表机器人领域的多样真实场景，尤其是跨实施例（cross-embodiment）的泛化。
  • 作者未探索模型合并技术的进一步潜力，如更复杂的合并策略（如 Task Arithmetic、TIES）或与其他数据集结合，认为整合额外机器人数据集可能带来更大性能提升。
  • 未在完整 OpenX 数据集上训练 ReVLA，因计算成本限制（仅使用单个 A100 节点），因此无法验证方法在大规模、多源数据下的表现。
  • 论文未明确评估 ReVLA 在真实机器人上的迁移效果，所有实验均在 SIMPLER 仿真环境中完成。

工程启示

  • 复现时先核对回退调度实现：α 的步进课程（每 10000 步增加 0.1）是核心机制，需确保训练步数 N=100000 与 n=10000 严格对齐，否则回退曲线会偏离预期，导致性能退化。
  • 优先尝试 DINO-v2 单独回退：实验表明 ReVLA (D gradual) 在 OOD 总成功率（0.259）上已接近双骨干回退（0.278），且实现更简单、计算开销更低。若资源有限，可先仅回退 DINO-v2。
  • 硬回退 vs 逐步回退的选择：若下游任务更看重抓取成功率，逐步回退（Gradual）更优（0.579 vs 0.495）；若更看重整体 OOD 成功率，硬回退（Flip）略优（0.287 vs 0.278）。需根据任务目标权衡。
  • 注意视觉骨干冻结：ReVLA 在训练中冻结 DINO-v2 与 SigLIP，仅更新策略头。若下游团队希望同时微调视觉特征，需重新设计回退调度，否则可能破坏已恢复的预训练表征。
  • 评估框架可复用：作者将公开 OOD 评估框架（基于 SIMPLER，含 YCB 对象与干扰物），下游团队可直接用于评测自身模型的视觉泛化能力，建议优先复现该框架以建立可比基准。
