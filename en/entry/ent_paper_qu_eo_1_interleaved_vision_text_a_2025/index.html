Summary

EO-1: Interleaved Vision-Text-Action Pretraining for General Robot Control (EO-1), is a 2025 large vision-language-action model for robotic manipulation, introduced by Harbin Institute of Technology (Shenzhen).

Sources

  • EO-1: Interleaved Vision-Text-Action Pretraining for General Robot Control (arXiv)
  • EO-1 source

概述

本文提出 RT-V3，一个将共享控制形式化为贝叶斯推断的统一框架，用于高自由度机械臂在 SE(3) 空间中的遥操作辅助。核心贡献在于将意图估计与反应式规划统一到一个基于 Transformer 的条件生成模型中，通过因子化动作表示和异步共享控制机制，在低带宽输入条件下实现多物体、多可供性的抓取辅助。实验表明 RT-V3 在闭环规划成功率（90.4%）和用户研究中显著优于基线。

它改变了什么

共享控制领域长期存在一个根本性割裂：意图估计与反应式规划被当作两个独立模块分别设计，前者预测用户想去哪，后者负责怎么去，两者之间的接口往往是手工设计的启发式规则。RT-V3 真正改变的是将这两者统一进一个贝叶斯推断框架，让意图先验 p(i|c) 和用户命令似然 p(u|i) 在同一个概率模型中联合推理，而不是先预测目标再规划路径。这个转变意味着辅助系统不再需要显式的目标集合或预设的抓取位姿，而是直接从场景上下文和用户输入中推断出完整的动作序列。

另一个关键改变是控制空间的维度。RT-V2 及其前作将共享控制限制在 2D 平移空间，这在实际操作中几乎不可用——真实机械臂抓取需要在 SE(3) 中同时调整位置和姿态。RT-V3 将问题扩展到完整的 6D 操纵空间，但并非简单地把动作维度从 3 加到 6，而是通过因子化分解（先采样平移、再条件化采样旋转）来应对高维密度估计的挑战。这个设计决策直接回应了低带宽输入与高自由度系统之间的不匹配问题，使得用户可以通过操纵杆等简单设备控制完整的机械臂运动，而不是被迫使用限制抓取策略的简化方案。

方法拆解

贝叶斯推断框架

共享控制被形式化为 p(i|u,c) ∝ p(u|i)p(i|c)，其中 i 是用户意图（表示为未来轨迹），u 是当前用户命令，c 是环境上下文。先验 p(i|c) 建模场景下可能的行为，似然 p(u|i) 捕捉输入设备的不确定性。

上下文编码

  • 点云通过 PT-V3 编码器得到 f_pcl ∈ ℝ^{M̃ × C_p}，再以过去动力学编码 h_0^d 为 query 通过 Transformer decoder 得到 h^pcl
  • 抓取候选集合 𝒢 通过 Transformer encoder 编码，同样以 h_0^d 为 query 解码得到 h^grasp
  • 上下文表示 h^c = [h^pcl; h^grasp]

因子化动作表示

  • 动作 a_t = [v_t, w_t] ∈ ℝ⁶ 为 𝔰𝔢(3) twist
  • 分解为 p(a_t|h_t, z) = p(w_t|h_t, z, v_t) p(v_t|h_t, z)
  • 平移分布：v_t^z ∼ 𝒩(μ_t^z, Σ_t^z)，参数由 MLP 生成
  • 旋转分布：w_t^z ∼ 𝒩(ω_t^z, Γ_t^z)，条件于平移采样
  • 对机动类别先验 p(z|h_0) 边缘化后，联合动作空间隐式形成 GMM，捕捉多模态意图

贝叶斯融合

用户命令 a_0^u 通过卡尔曼增益融合进先验： - K_v = Σ_0^z(Σ_0^z + Σ^sys)^{-1} - μ̃_0^z = μ_0^z + K_v(v_0^u − μ_0^z) - Σ̃_0^z = (I − K_v)Σ_0^z 旋转分量类似处理，机动类别后验通过贝叶斯公式更新

异步共享控制

系统每时间步监测用户输入：检测到命令则执行后验决策，否则执行自主策略中最可能的动作。当末端执行器距物体表面小于预设距离时禁用该机制，避免干扰精细调整。

关键创新

  1. 统一贝叶斯框架：将意图估计与反应式规划整合进单一概率模型，消除了传统方法中两个模块之间的手工接口。这是从"预测目标+规划路径"到"直接推断动作分布"的范式转变，使得辅助系统能够自然地权衡用户命令的置信度与场景上下文的先验知识。

  2. 平移条件化的旋转分解：直接建模 6D 动作分布面临高维度和强耦合挑战，而平移决定全局轨迹结构、旋转多为目标附近的局部精调。将旋转分布条件化于平移采样，既降低了密度估计的复杂度，又提高了闭环执行的稳定性——实验表明联合建模的"6D pred"变体虽然开环预测更优（ADE-BoM 21.05），但闭环规划成功率仅 3.4%，而因子化版本达到 90.4%。

  3. 异步共享控制机制：利用用户不活跃的时间段持续更新意图推断并执行自主行动，这直接针对低带宽接口的疲劳问题。用户不需要持续提供命令，系统在用户暂停时仍能推进任务，显著降低认知负荷。实验中的 Laggy User 模拟（以概率 0.8 重复上一动作）验证了该机制在输入延迟下的鲁棒性。

关键发现：加入点云编码器略微降低 ML 预测性能（ADE-ML 从 30.36 升至 32.05），但显著提升规划成功率（78.8% → 90.4%）并降低碰撞率（10.3% → 7.9%）和任务超时率（10.9% → 1.7%）。"6D pred"变体在开环预测上最优，但因复合误差导致闭环规划崩溃。

共享控制实验

768 次试验，四种模拟用户（Noisy、Laggy、Mode-Switching、Single-DoF）。RT-V3 结合 NeoSS 可实现非常低的碰撞率（0% ∼ 6%）且成功率小幅牺牲（由表内数值 90.4% → 83.5% 计算）。

用户研究

RT-V3 在成功率、效率方面显著优于基线，并大幅降低用户的身体和心理负担（具体数字论文未明确）。

边界与局限

  • RT-V3 在规划成功率上低于 CuRobo（90.4% vs 95.9%），但 CuRobo 不支持多模态意图预测，两者并非直接可比
  • 加入点云编码器略微降低 ML 预测性能，说明场景上下文编码与轨迹预测之间存在权衡
  • 异步共享控制在接近物体表面时被禁用，这意味着精细调整阶段仍需用户全程参与
  • 实验仅在 Franka Research 3 单平台上验证，跨平台泛化性论文未明确
  • 训练数据全部来自仿真（22,265 个场景），真实世界迁移效果论文未明确

工程启示

复现 RT-V3 时，最先需要核对的是数据生成管线：22,265 个场景、833,324 个有效抓取、568,277 条高质量轨迹的规模决定了模型性能上限。抓取候选的质量直接影响意图推断——使用现成抓取规划器时，务必检查候选抓取是否覆盖多可供性场景，否则模型会偏向单一抓取模式。

最容易踩坑的地方是"6D pred"变体的诱惑：它在开环预测指标上全面领先（ADE-BoM 21.05 vs 26.70），但闭环规划成功率仅 3.4%。如果只关注轨迹预测指标而忽略闭环性能，很容易误选这个变体。因子化动作分解不是性能优化，而是闭环稳定性的必要条件。

异步共享控制的触发逻辑需要仔细调参：禁用距离阈值过大会导致辅助过早退出，过小则可能在精细调整阶段产生干扰。建议在真实机器人上先做小规模用户测试，观察用户在接近目标时的操作模式，再确定阈值。另外，贝叶斯融合中的系统噪声参数 Σ^sys 和 Γ^sys 直接影响用户命令的信任权重，需要根据实际输入设备的噪声特性标定。
