Summary

Generalist Robot Manipulation beyond Action Labeled Data (MotoVLA), is a 2025 large vision-language-action model for robotic manipulation, introduced by INSAIT, Sofia University “St. Kliment Ohridski”, ETH Zurich, and published at CoRL25.

Sources

  • Generalist Robot Manipulation beyond Action Labeled Data (arXiv)
  • MotoVLA source

概述

MotoVLA 是首个允许在无动作标签数据（人类与机器人视频）上学习通用操作运动先验的端到端 VLA 模型。其核心贡献在于两阶段训练：先以 3D 动态点云预测为自监督目标建立本体无关的运动表示，再在少量带标签数据上微调为动作预测器。该方法在 SIMPLER 域内基准上平均成功率 68.2%，显著超越 LAPA、π0 等基线，并在真实 WidowX 域外任务上取得最佳表现。

它改变了什么

长期以来，VLA 模型的规模化受制于带动作标签的机器人演示数据——这类数据采集成本极高，且分布外泛化性能随任务偏离训练分布而急剧下降。此前从人类视频或无标签数据学习的方法要么局限于专家级小规模策略，要么未能成功扩展到通用 VLA 架构，根本原因在于缺乏一种既能跨越人-机器人域差距、又能与动作空间对齐的中间表示。

MotoVLA 真正改变的是将“运动先验”从动作空间中解耦出来。它不再试图直接从无标签视频中预测动作，而是先学习预测 3D 动态点云——一种与具体本体无关、但蕴含丰富物理与运动信息的表示。这一设计使得海量人类演示视频（如 RH20T）可以被用于预训练，而动作对齐仅需少量带标签数据即可完成。这实质上是将 VLA 的训练从“数据饥渴”模式转向“表示学习 + 轻量对齐”模式，为突破机器人数据瓶颈提供了新的路径。

方法拆解

两阶段训练框架

  1. 阶段一：动态点云预训练
    在无动作标签数据（RH20T 人类演示、BridgeData V2 与 Rt-1 机器人视频，丢弃动作标签）上训练 3D 动态点云预测器。输入为当前点云与带噪未来点云样本，通过流匹配（flow-matching）回归去噪向量场，损失函数为：
    L_points = E[||v_points(P_t^τ, o_t) - (P_t - (1-σ_min)ε)||²]
    其中 P_t^τ = (1-(1-σ_min)τ)ε + τP_t，τ = (1-σ_min)(1-z)，z ~ Beta(1.5, 1)。

  2. 阶段二：动作对齐
    在 BridgeData V2 动作数据上，将动态点云预测器权重初始化为动作预测器，输入当前点云、本体感觉 q_{t-1} 与带噪动作样本，预测动作块 A_t。损失函数为：
    L_action = E[||v_act(A_t^τ, o_t) - (A_t - (1-σ_min)ε)||²]
    线性编码器与解码器随机初始化，其余权重继承自阶段一。

动态点云提取流程

  • 从视频中采样帧索引 t ~ N(T/2, 0.4·T)。
  • Grounding DINO 检测手/夹爪边界框，Segment Anything V2 生成分割掩码。
  • 从掩码均匀采样 200 个像素位置，BootsTAPIR 前后跟踪。
  • 单目深度估计器 MoGE 将 2D 轨迹提升至 3D，结合相机内参生成点云序列（长度 4）。

架构细节

  • VLM 骨干：Paligemma（30 亿参数，SigLIP 视觉编码器 + Gemma 语言模型）。
  • 预测器：300 百万参数，遵循 Gemma 架构，特征维度 1024，MLP 维度 4096。
  • 条件化机制：预测器通过自注意力（拼接键和值）条件化于 VLM 隐藏特征。
  • 注意力模式：Paligemma token 间双向注意力，但不能关注预测器 token；预测器 token 可全注意力于其他 token，但当前点云与本体感觉 token 不能关注噪声 token。
  • 推理：欧拉积分，Δt = 0.1，在 WidowX 上执行整个动作块（长度 4）。

关键设计决策

  • 冻结视觉编码器于阶段一，保留开放词汇视觉能力。
  • 阶段二视觉编码器可训练，以适应动作预测目标。
  • 消融显示 Mixture of Transformers 架构（预测器分离）优于共训练方案。

关键创新

  1. 动态点云作为视觉链式思维：这是首次将 3D 动态点云预测作为 VLA 的中间监督信号。不同于静态图像特征或 2D 轨迹，动态点云显式编码了物体的空间位移与运动趋势，迫使模型学习物理与运动规律，而非表面视觉相关性。这一表示天然跨本体，使得人类视频预训练成为可能。

  2. 两阶段训练策略：先自监督学习运动先验，再轻量动作对齐。这一设计将数据需求从“带标签的机器人演示”放宽为“无标签视频 + 少量带标签数据”，训练时间仅需 15 小时（阶段一）+ 4 小时（阶段二）在 TPUv5e-256 上，效率远高于从头训练 VLA。

  3. 流匹配预测框架：采用流匹配而非扩散或回归，使得预测器可以处理连续动作序列，且推理时欧拉积分仅需 Δt = 0.1，计算开销可控。这一选择在动作块长度 4 的条件下保持了实时性。

实验与结果

域内评估（SIMPLER 模拟器，4 任务 × 24 配置）

模型 平均成功率
MotoVLA (R+H) 68.2%
MotoVLA (R) 65.6%
π0 (B) 56.8%
LAPA (OXE) 54.1%
ATM (B) 20.8%

MotoVLA (R+H) 在 Put eggplant in basket 上达 97.9%，但在 Put gray on yellow block 上仅 47.9%，显示对精细对齐任务仍有挑战。加入人类数据（R+H vs R）在 Put gray on yellow block 上从 12.5% 提升至 47.9%（由表内数值 12.5→47.9 计算），证明人类视频对泛化的显著贡献。

域外评估（真实 WidowX，8 任务 × 10 配置 × 3 次试验）

  • MotoVLA (R+H) 平均成功率最佳，最大增益出现在 Push Button、Cube on Scale、Cable in Basket、Clamp in Cup——这些任务存在于人类演示数据集中。
  • OpenVLA 性能比 MotoVLA (R+H) 差 9.8%。

消融研究（SIMPLER）

变体 平均成功率
MotoVLA (R+H) 68.2%
MotoVLA (R+H) 2D 64.2%
MotoVLA 32 Points 60.9%
MotoVLA Grid 54.7%
MotoVLA Co-Training 47.9%
MotoVLA Separation 46.9%

2D 轨迹在 SIMPLER 中性能下降 4.0%，真实机器人上下降 12.5%，证实 3D 表示的关键作用。点数从 200 降至 32 导致 7.3% 下降（由表内数值 68.2→60.9 计算），说明点云密度对性能敏感。

边界与局限

  • 数据域限制：RH20T 人类演示与机器人域接近（静态第三人称相机），但大多数开放世界人类视频是自我中心的、非静态头戴相机，需额外估计相机外参（如 MonST3R），本文未处理此场景。
  • 跟踪鲁棒性：手部运动过快时，TAP 模型会丢失查询点跟踪，影响点云质量。
  • 深度估计精度：单目深度估计器 MoGE 在多样背景下的几何一致性仍有挑战，可能限制跨场景泛化。
  • 评估范围：真实世界仅 8 个任务，未涉及长期任务规划或复杂操作序列；论文未明确提及大规模多任务真实评估。
  • 计算资源：训练依赖 TPUv5e-256 pod，复现门槛较高。

工程启示

  • 复现优先级：先核对动态点云提取流程（Grounding DINO + SAM2 + BootsTAPIR + MoGE）的稳定性，这是整个方法的地基。若跟踪或深度估计失败，后续训练将无意义。
  • 数据选择：人类视频并非越多越好——RH20T 与机器人域接近是关键。若使用自我中心视频，需先解决相机外参估计，否则点云质量会严重下降。
  • 超参数敏感点：点云采样数（200）与序列长度（4）对性能影响显著，消融显示降至 32 点即损失 7.3%。建议保持默认值，不要为省算力随意缩减。
  • 架构陷阱：预测器分离（Mixture of Transformers）优于共训练，但需注意注意力掩码设置——当前点云 token 不能关注噪声 token，否则训练不稳定。
  • 下游集成：推理时欧拉积分 Δt = 0.1 在 WidowX 上可实时执行，但若换用更快的机器人，需重新验证积分步长与动作块长度的匹配。
  • 最易踩坑处：阶段一冻结视觉编码器是保留开放词汇能力的关键，若在阶段二过早解冻，可能导致灾难性遗忘。建议严格遵循两阶段训练顺序。
