Summary

HybridVLA: Collaborative Diffusion and Autoregression in a Unified Vision-Language-Action Model (HybridVLA), is a 2025 large vision-language-action model for robotic manipulation, introduced by Peking University, Beijing Academy of Artificial Intelligence (BAAI), CUHK.

Sources

  • HybridVLA: Collaborative Diffusion and Autoregression in a Unified Vision-Language-Action Model (arXiv)
  • HybridVLA source

概述

HybridVLA 提出一种统一视觉-语言-动作（VLA）框架，在 7B 参数规模下同时训练自回归（HybridVLA-ar）与扩散（HybridVLA-dif）两种动作生成头，并通过置信度阈值实现推理时动作集成。核心贡献在于首次将 KV cache 机制引入 LLM 的扩散式动作生成，在保持 66% 平均成功率的同时将推理频率从 5.0 Hz 提升至 9.4 Hz（由表内数值 5.0→9.4 计算），并验证了双生成模式在精确操作与语义推理任务上的互补性。

它改变了什么

过去 VLA 模型通常绑定单一动作解码范式：自回归擅长长程语义推理但动作精度受限，扩散擅长局部精确操作却缺乏全局规划能力。HybridVLA 真正改变的是将这两种在范式上互斥的生成方式放进同一个 LLM 主干，用协同训练而非模型集成的方式让它们共享视觉-语言表征，从而在推理时按任务特性动态选择或融合动作输出。这打破了“一种动作头打天下”的惯例，为 VLA 架构设计提供了新的自由度。

另一个被改变的点是推理效率的瓶颈。扩散式动作生成通常需要多次去噪迭代，计算开销远高于单步自回归解码。作者将 KV cache 从自回归解码移植到扩散生成中，使得扩散头在推理时不再重复计算历史 token 的键值对，这在保持动作质量的同时显著提升了控制频率——对于真实机器人部署，5 Hz 到 9.4 Hz 的差距意味着能否跟上动态环境。

方法拆解

双动作生成头

  • 共享同一个 7B LLM 主干与视觉编码器，分别接出自回归头（HybridVLA-ar）和扩散头（HybridVLA-dif）。
  • 自回归头按 token 序列预测动作；扩散头以动作序列为去噪目标，条件为视觉-语言特征。
  • 协同训练：两个头在相同 batch 上联合优化，损失为自回归交叉熵与扩散均方误差的加权和（权重论文未明确）。

动作集成策略

  • 推理时先由自回归头输出动作 token 序列，计算其均值置信度。
  • 若置信度 ≥ 阈值（经验最优 0.96），则输出扩散与自回归预测的平均值；否则仅用扩散预测。
  • 阈值消融显示：低于 0.94 时自回归预测不可靠，集成反而拉低成功率；高于 0.98 时有效自回归样本过少，集成退化为纯扩散。

KV cache 机制

  • 在扩散头的每次去噪迭代中，复用 LLM 主干对视觉-语言 token 的 KV cache，避免重复编码观测。
  • 仅对动作 token 的生成进行增量计算，消除冗余前向传播。

数据与观测

  • 预训练：35 个数据集、760k 条轨迹、33m 帧图像，混合权重自动调整（如 Kuka 27.8%、Fractal 9.1%、DROID 7.2%）。
  • 预训练仅用单 2D 观测；微调支持多视角，多视角图像经共享编码器后沿 token 维拼接。
  • 数据预处理沿用先前方法，强调末端执行器序列控制。

关键创新

  1. 首个将 KV cache 用于 LLM 扩散式动作生成：此前 KV cache 仅用于自回归解码，扩散生成因迭代去噪被视为天然不兼容。作者证明在共享主干下，KV cache 可跨迭代复用，将推理频率提升近一倍（5.0→9.4 Hz，由表内数值计算），这是实际部署的关键突破。

  2. 协同训练而非模型集成的双生成范式：不是训练两个独立模型再投票，而是在同一 LLM 内联合优化两种动作头，使它们共享视觉-语言表征。这保证了集成时动作空间的一致性，也避免了双模型的内存翻倍。

  3. 置信度门控的动作融合：用自回归 token 的均值置信度作为开关，动态决定信任哪种生成方式。这一设计简单有效，避免了复杂的概率融合或学习型门控，且消融实验证明 0.96 阈值在 10 个仿真任务上稳定达到 0.74 平均成功率。

KV cache 推理速度

  • 启用 KV cache：平均成功率 66%，推理频率 9.4 Hz。
  • 禁用 KV cache：成功率相近（论文未明确具体值），推理频率降至 5.0 Hz。

真实世界实验

  • 单臂（Franka FR3 + UMI 夹爪）与双臂（AgileX）共 10 类任务，含长时程多步操作（如 open drawer and place、fold shorts）。
  • 论文未提供真实世界成功率量化数据。

边界与局限

  • 旋转预测偏差：在 Pour water、Place bottle at rack 等需精确旋转的任务中，多步旋转累积误差明显，且与目标交互时旋转角度常不正确。
  • 超出机械约束的位姿：模型会预测超出 FR3 或 AgileX 关节限位的工作空间外目标，或在复杂过渡中产生运动学不可行配置。
  • 双臂协调缺陷：模型独立预测每只手臂动作，未建模双臂交互——一臂改变物体状态后，另一臂的预判动作失效。
  • 阈值泛化性：0.96 阈值仅在 RLBench 10 任务上验证，真实场景或新任务分布下是否仍最优，论文未明确。
  • 真实世界成功率缺失：论文未给出真实机器人实验的量化成功率，仅描述任务类型。

工程启示

  • 复现优先核对数据混合权重：预训练效果高度依赖各数据集采样比例（如 Kuka 27.8%、Fractal 9.1%），若下游任务与这些数据集分布差异大，需重新调整权重而非直接沿用。
  • KV cache 收益在长序列更明显：9.4 Hz 的提升是在 7B 模型上测得，若换用更大 LLM 或更长观测序列，收益可能进一步放大；但需注意 KV cache 显存占用随序列长度线性增长。
  • 阈值 0.96 不是银弹：集成策略依赖自回归头的置信度校准，若更换主干或微调数据，需重新做阈值消融（0.90–0.98 区间扫描）。
  • 双臂任务慎用此框架：当前模型无手臂间交互建模，若下游涉及双臂协同（如折叠、装配），建议先验证单臂任务，或引入显式双臂状态融合。
  • 旋转精度是已知短板：若任务需要高精度旋转（如拧螺丝、倒水），优先考虑扩散头并配合运动学后处理，而非依赖自回归头。
