Summary

The ability to react dynamically to tactile signals has long been considered crucial to agile human-level dexterity. Yet contemporary learning-based Vision-Language-Action (VLA) models for robotic manipulation generally either overlook the tactile modality or are limited to encoders with static cues, due in part to the scarcity of diverse training data and standardized evaluation, architectural constraints in current Institutions per source list: UC Berkeley、NVIDIA、Stanford、Panasonic、La Sapienza University、ItalAI.

Overview

T-Rex is a unified foundation model for tactile-reactive dexterous manipulation, proposed by the research team, comprising a large-scale tactile dataset (T-Rex Dataset, 100 hours) and a three-stage training paradigm (pre-training - mid-training - post-training). Its core contribution lies in efficiently injecting high-frequency tactile reactivity into a standard VLA backbone via the Mixture-of-Transformer-Experts (MoT) architecture and asynchronous cascaded flow matching, achieving an average success rate of 65% across 12 contact-rich tasks, surpassing the strongest baseline EgoScale (35%) by 30 percentage points.

What It Changes

Existing VLA models almost systematically ignore tactile sensing in robotic manipulation, or only encode it as static cues. This is not merely a data scarcity issue, but a superposition of three structural contradictions: tactile reactivity requires control frequencies far higher than those of the visual loop (human dexterity relies on fast, fine-grained tactile signals), which standard VLM backbones cannot match in operating frequency; large-scale pre-training paradigms (e.g., EgoScale) primarily use first-person human videos, lacking key physical signals such as force variations, micro-slips, and local deformations; learning tactile policies from scratch requires massive synchronized visual-tactile data, while collecting fine-grained dexterous teleoperation data is prohibitively expensive. The authors do not attempt to solve tactile data scarcity during pre-training. Instead, they insert a dedicated "mid-training" stage between pre-training and task-specific post-training to perform tactile grounding, thereby bypassing the need for tactile data during pre-training. This changes the existing path where "tactile capabilities must be learned from scratch" or "must rely on large-scale tactile pre-training," treating tactile reactivity as an efficiently transferable skill rather than part of the foundational representation.

Method Breakdown

Three-Stage Training Paradigm

  1. Pre-training: Following EgoScale, pre-train a latent expert and an action expert on 22,889 hours of first-person human videos. The latent expert learns visual-language representations from head-mounted observations; the action expert trains retargeted human arm and hand motions in a unified action space.
  2. Mid-training: Using 100 hours of teleoperated bimanual manipulation data (with synchronized tactile signals), adapt the action expert to robot multi-view observations and executable actions, while training a tactile expert to perform high-frequency denoising as fine-grained refinement.
  3. Post-training: Fine-tune on approximately 100 task demonstrations to adapt to specific task requirements while preserving the tactile-reactive behaviors acquired during mid-training.

Model Architecture: Mixture-of-Transformer-Experts (MoT)

  • Latent Expert: Qwen3VL-2B, hidden dimension 2048, 28 layers, 1.41B parameters, processes visual and language observations, predicts future visual representations.
  • Action Expert: Qwen3VL-2B, action dimension 62, action chunk 16, 1.41B parameters, low-frequency action denoising (from pure noise to intermediate timestep τ_split).
  • Tactile Expert: Action dimension 62, action chunk 16, FFN intermediate size 1536, 0.62B parameters, denoises from τ_split to τ=0, refining actions using high-frequency tactile observations.

Spatio-Temporal Tactile Encoding

  • Per-finger VQ-VAE compresses the recent force history f_{t-15:t} (15-step history) into compact temporal tokens (codebook size K=64, EMA updates, magnitude-weighted MSE loss).
  • The current force vector f_t is directly projected to preserve instantaneous contact information.
  • A convolutional encoder (ResNet-18 backbone, single-channel input, first three residual stages) extracts features from the current deformation map d_t.
  • The three are concatenated to form the tactile token sequence z_t^τ.

Asynchronous Tactile-Reactive Cascaded Flow Matching

  • Split the flow matching trajectory at a fixed timestep τ_split: the action expert denoises the upper segment τ∈[τ_split,1], while the tactile expert reuses cached visual-language context and completes the remaining denoising τ∈[0,τ_split] using real-time tactile observations.
  • Shared flow objective: given demonstration action chunk A_demo and Gaussian noise ε, linear interpolation x_τ=(1-τ)A_demo+τε, constant-velocity target v=ε-A_demo; both experts regress the same target v on disjoint sub-intervals.
  • Inference configuration: N=10 Euler steps, τ_split=0.4, K_slow=6 steps (Δτ=-0.1), K_fast=4 steps, action chunk length T_a=16, fast-flow trigger offsets {0,4,8,12}.
  • Training protocol: action expert samples τ_act~Beta(1.5,1.0) in (0,1]; tactile expert samples τ_tac=τ_split·τ̃, τ̃~Beta(1.5,1.0) in (0,τ_split]; total loss L = L_act + λ_tac·L_tac + λ_future·L_future, λ_tac=1.0, λ_future=0.5.
  • Latency augmentation: draw discrete delay δ from Uniform{0,4,8,12}, randomly shift tactile token frame indices to match the staleness distribution at deployment.
  • Runtime serialization: single-threaded request socket plus explicit execution lock, ensuring fast ticks do not start before the slow tick commits the KV_τsplit cache and intermediate boundary state x̂_τsplit.

Key Innovations

  1. Asynchronous Cascaded Flow Matching: Splits the flow matching trajectory at a fixed timestep τ_split, where the action expert (slow flow) and tactile expert (fast flow) regress the same velocity target on disjoint sub-intervals. This resolves the fundamental mismatch between VLA backbone frequency and tactile reactivity requirements—the tactile expert operates entirely independently of raw visual observations, conditioned only on high-frequency tactile tokens and cached visual-language context, with per-control-step computational cost dominated solely by the tactile expert's K_fast Euler steps.
  2. Tactile Grounding Mid-training: Inserts a dedicated tactile grounding stage between pre-training and post-training, using 100 hours of tactile-synchronized teleoperation data (502 object-motion primitive combinations, 22 motion primitives) to efficiently acquire tactile reactivity, bypassing the need for tactile data during pre-training. This significantly reduces the data required for downstream tasks (Figure 5: notable performance gains in the low-data regime).
  3. Spatio-Temporal Tactile Encoding: Per-finger VQ-VAE compresses force history into discrete drift-resistant tokens, the current force vector is directly projected to preserve instantaneous contact information, and a convolutional encoder extracts deformation map features. The three are concatenated into a unified tactile token sequence, balancing temporal context, instantaneous force, and local deformation, with the VQ-VAE discretization enhancing cross-device robustness.

Experiments and Results

In controlled experiments, T-Rex was compared against six baselines (ViTacFormer, RDP, Tactile-VLA, EgoScale, π₀.₅, π₀.₅ + tactile) across 12 contact-dense tasks, with 16 trials per task, randomized object positions and rotations, and progress-based scoring for multi-stage tasks. Table 1 reports the average task success rate (%) for each method, first averaged over trials then over tasks.

  • Large-scale pre-training is foundational for dexterous manipulation: Small policies trained from scratch on task-specific demonstrations alone (ViTacFormer average 3, RDP average 6) consistently underperform across all tasks; EgoScale, leveraging large-scale first-person pre-training and hand-pose supervision, significantly outperforms π₀.₅ (35 vs 17) and Tactile-VLA (35 vs 15), which rely solely on task-specific real-robot data. T-Rex combines pre-training with tactile grounding mid-training, achieving an average success rate of 65, surpassing the strongest baseline EgoScale by 30% (calculated from table values 35→65).
  • Tactile feedback is indispensable for contact-rich manipulation, but integration method determines success: Even pre-trained VLA models like EgoScale fail on precise contact adjustments and force-sensitive behaviors; T-Rex combines large-scale pre-training with tactile grounding mid-training and tactile-reactive control to achieve the strongest overall performance. Notably, naive tactile conditioning actually harms performance—π₀.₅ + tactile drops from 17 to 6 average success rate compared to π₀.₅ (calculated from table values 17→6), highlighting the importance of effective tactile integration.
  • Asynchronous cascading and each tactile modality contribute independently: Ablation studies show that removing all tactile inputs yields the largest drop (average 65→42, -23%); using only deformation (-11%) and only force (-6%) both incur losses, indicating that spatial deformation perception and temporal force encoding are complementary; the VQ-VAE force encoder outperforms the MLP force encoder (59 vs 58, -6% vs -7%); asynchronous refinement consistently outperforms synchronous baselines (60 vs 65, -5%), validating the benefit of decoupling low-frequency visual motion planning from high-frequency tactile control. Training recipe ablations further show that each stage—pre-training and mid-training—contributes: without pre-training and mid-training, the average is only 18; adding mid-training raises it to 34; adding pre-training raises it to 45; the full recipe reaches 65.

Boundaries and Limitations

  • Precise contact coordination in long-horizon tasks and tight-tolerance scenarios makes teleoperation difficult; future work could integrate reinforcement learning or online interactive refinement.
  • Tactile-reactive manipulation is constrained by hardware bottlenecks: sensor distortion, cross-device calibration drift, and lack of dense palm sensing for full-hand manipulation.
  • Not validated on parallel grippers or single-arm embodiments; reinforcement learning integration not explored; cross-device tactile sensor generalization not addressed.
  • Failure case analysis reveals: insufficient fine-grained visual alignment (light bulb colliding with socket in the bulb-screwing task), unstable grasping of small objects (key slipping in the lock-opening task), imprecise positioning (failure to place the egg in the carton in the egg-transfer task), insufficient single-finger coordination (thumb touching adjacent tiles in the mahjong-sorting task), excessive force on deformable objects (squeezing out too much toothpaste in the toothpaste task), and insufficient tactile temporal conditioning for sliding motions (failure to apply uniform force in the card-pulling task).
  • The paper does not specify: exact model parameter counts (beyond the three expert parameter counts in the appendix), number of training epochs, batch size, learning rate, optimizer, training duration, number of GPUs, specific tactile sensor models, data collection frequency, inference frequency values (Hz), or open-source code repository URL (only mentions the project homepage).

Engineering Insights

  • First verify hardware and data collection: T-Rex relies on the Dexmate Vega-1 bimanual platform and Sharpa Wave dexterous hands (22-DoF), with tactile observations being per-fingertip 6D force/torque plus single-channel deformation depth maps. If your platform's tactile sensor model or layout differs, the input distributions for the VQ-VAE force encoder and deformation encoder will shift, requiring recalibration or fine-tuning.
  • Most common pitfall: Runtime serialization of asynchronous cascaded denoising—fast ticks must not start before the slow tick commits the KV_τsplit cache and intermediate boundary state x̂_τsplit, otherwise stale or unready caches will be read. The paper explicitly uses a single-threaded request socket plus explicit execution lock; be sure to implement the same synchronization mechanism when reproducing.
  • Data efficiency is the core selling point: The mid-training stage (100 hours, 502 object-motion primitive combinations) significantly reduces the number of demonstrations required for downstream tasks (Figure 5). If your task budget is limited (e.g., <50 demonstrations), prioritize reusing the T-Rex dataset for mid-training rather than collecting task-specific data from scratch.
  • Tactile encoding details determine success: VQ-VAE codebook size K=64, EMA updates, magnitude-weighted MSE loss (assigning higher penalties to high-force contact frames); convolutional weights are shared across the five fingers, with finger identity embeddings injected before encoding. If your sensor noise is high, first verify the stability of VQ-VAE discretization (drift-resistant design); otherwise, tactile token quality will directly affect fast-flow denoising performance.
  • Inference configuration is tunable: τ_split=0.4, K_slow=6, K_fast=4, action chunk T_a=16, and fast-flow trigger offsets {0,4,8,12} are the paper's defaults. If your task requires higher-frequency tactile reactivity (e.g., faster slip detection), consider reducing τ_split or increasing fast-flow trigger frequency, but note that the visual motion prior provided by the action expert will correspondingly weaken (trade-off in Figure 4).
