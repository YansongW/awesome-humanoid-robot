Summary

A framework for scalable whole-body teleoperation of humanoid robots that maps measured human link orientations and angular velocities to corresponding robot links via constant relative rotations, then solves inverse kinematics directly on the robot URDF model using a dynamical optimization QP formulation.

Sources

  • Whole-Body Geometric Retargeting for Humanoid Robots

概述

本文提出 StereoVLA，一个利用立体视觉几何线索的 VLA 模型，由作者团队构建，核心贡献在于将 FoundationStereo 的过滤代价体 V′_c 与 SigLIP、DINOv2 语义特征融合，并联合训练交互区域深度估计辅助任务，以提升机器人操作精度。在真实世界任务中，StereoVLA 平均成功率 79.3%（小相机随机化），显著优于单视角 SpatialVLA-D（24.6%）及多视角 π₀.₅-S（64.3%）和 GraspVLA-S（71.3%），且在小型物体抓取上达到 30.0% 成功率，而所有基线完全失败。该方法通过 500 万条合成轨迹训练，采用 InternLM-1.8B 语言模型和 300M action expert，以 flow-matching 预测动作块，推理时无额外计算开销。

它改变了什么

这篇工作真正改变的，是VLA（Vision-Language-Action）模型对“空间几何”这一维度的处理方式。此前的主流路线——无论是OpenVLA依赖单目RGB，还是SpatialVLA用单目深度估计——本质上都在用一个病态问题（从单张图像恢复3D结构）去支撑一个对几何精度极其敏感的下游任务（抓取、堆叠）。作者没有选择继续在单目深度估计这条路上堆数据或调网络，而是直接引入立体视觉作为几何信息的源头。这个转向的深层动机在于：立体视差提供的空间线索是物理上确定的，不依赖先验或幻觉，且不需要额外硬件——这对移动机器人和人形机器人尤其关键，因为腕部相机和深度传感器在真实部署中各有硬伤（遮挡、透明物体失效、硬件复杂度）。

更值得注意的改变是，作者没有简单地把立体图像对“塞”进现有多相机VLA（如π₀.₅、GraspVLA），而是识别出这类模型性能次优的根因——立体视图间的细微差异会扰乱多视角token的融合。他们的解法是设计一个专门的Geometric-Semantic Feature Extraction模块，从FoundationStereo的过滤代价体V′_c中提取稠密几何特征，再与SigLIP和DINOv2的语义特征在通道维度拼接。这个设计选择背后有一个关键判断：几何特征和语义特征在表征空间上互补，但token序列拼接会线性增加计算开销，而通道拼接在保持信息密度的同时不增加token数量。另一个务实之处在于，他们跳过了FoundationStereo的迭代细化模块——这是计算瓶颈，而过滤后的代价体已经包含了足够的长程相关性信息。

真正体现问题意识转变的，是Interaction-Region Depth Estimation这个辅助任务。作者意识到，均匀采样深度监督会把模型注意力浪费在桌面、墙壁这类与任务无关的背景上，因此将深度预测限制在包含夹爪和目标物体的交互区域。这个设计直指VLA模型的一个核心痛点：视觉token的语义丰富性并不等于任务相关性。配合渐进式动作生成（先预测2D边界框和关键帧位姿，再预测动作块），模型被引导去关注真正决定操作成败的空间关系。从数据上看，这个思路是有效的——在小型物体抓取任务中，StereoVLA达到30%成功率，而所有基线完全失败；在相机位姿大范围随机化下，立体输入比单目深度估计的SpatialVLA-D（6.8%）高出近一个数量级（61.3%）。这说明立体视觉带来的不是边际改进，而是对几何扰动鲁棒性的质变。

方法拆解

总体架构与动作生成

模型以立体图像对为输入，经 Geometric-Semantic Feature Extraction 模块编码为视觉 token，与语言 token 拼接后送入预训练大语言模型 InternLM-1.8B 进行联合处理。关键设计是：不直接让 LLM 输出动作，而是利用其中间视觉-语言特征（key-value cache），由一个 300M 参数的 action expert 通过 flow-matching 以 delta 末端执行器位姿表示预测动作块。这种解耦使 LLM 专注于语义理解，动作生成由轻量专家完成，避免大模型直接回归连续动作带来的优化困难。

几何-语义特征提取

该模块是核心创新，由三路并行特征构成：

  • 几何特征：从 FoundationStereo 中选取过滤后的代价体 V′_c。设计决策基于两点：(1) V′_c 是稠密特征体，捕获丰富几何信息；(2) 跳过计算开销大的迭代细化模块和仅含匹配分数的相关性体积 V_corr，最小化深度估计的额外计算。选择 V′_c 而非原始代价体 V_c，因其通过混合代价过滤模块纳入长程相关性，消融实验证实 V′_c 优于 V_c（有语义时 77.0% vs 69.0%）。
  • 语义特征：采用 SigLIP 和 DINOv2（遵循 PrismaticVLM），分别捕获高层语义与视觉细节。因左右视图语义高度冗余，仅对左视图应用以节省计算。
  • 特征融合：将 FoundationStereo 特征空间池化至与其他两者一致的 14-pixel stride，沿通道维度拼接。刻意避免 token 序列拼接，因其增加 token 数量及训练推理开销。

Interaction-Region Depth Estimation 辅助任务

与动作块预测联合训练，推理时零额外开销。LLM 被训练预测采样点 (x,y) 的度量深度 d，利用合成数据集的真实深度。关键设计是采样限制在交互区域（包含夹爪和目标物体的区域，由物体 2D 边界框标识），而非均匀采样全图——后者常采到背景（桌子、墙壁）等缺乏任务相关信息的区域。该任务迫使模型在关键空间位置建立几何-语义关联。

数据集与训练策略

  • 合成数据：MuJoCo 生成 500 万条拾取-放置轨迹（10Hz），Isaac Sim 渲染立体观测。立体相机基线和内参在真实 Zed Mini 参数 5% 范围内随机化，增强跨相机泛化。图像渲染 256×256 后调整为 224×224 以适配预训练视觉骨干。
  • 渐进式动作生成：模型先预测目标物体 2D 边界框和夹爪下一关键帧位姿作为中间步骤，引导动作块预测。仅要求左图像上预测边界框以减少计算。
  • 损失与训练：总损失 L = L_action + L_depth + L_bbox + L_pose，其中 L_action 为 flow-matching 损失，其余为交叉熵损失。四任务样本平衡比例 5:2:2:1，强调动作预测为主。训练 160k 步，32 块 H800 GPU，批大小 384，学习率 1.6e-4。

关键设计决策总结

  1. 立体视觉而非深度图：直接利用代价体 V′_c 而非显式深度估计，避免深度估计误差传播（FoundationStereo AbsRel 0.0275 vs VGGT 0.4121），同时保留稠密几何线索。
  2. 语义仅左视图：利用视图间冗余性，计算量减半而不损性能。
  3. 交互区域深度采样：将有限监督信号集中于任务相关空间，提升样本效率。
  4. 中间任务引导：边界框和关键帧位姿预测提供结构化中间表征，缓解动作预测的歧义性。

关键创新

本文的核心创新在于将立体几何线索以“零额外推理成本”的方式注入VLA模型，而非简单堆叠多视角输入。具体有三点：

1. 从代价体而非深度图提取几何特征，实现几何与语义的通道级融合。 现有方法（如SpatialVLA-D）依赖FoundationStereo输出的深度图，但深度估计本身有误差（FoundationStereo的AbsRel为0.0275，而VGGT高达0.4121）。本文直接选取过滤后的代价体V′_c作为几何特征，跳过计算开销大的迭代细化模块，并利用混合代价过滤纳入长程相关性。这一设计既保留了稠密几何信息，又避免了深度估计的额外计算和误差累积。消融实验显示，V′_c（77.0%）显著优于原始代价体V_c（69.0%）和仅含匹配分数的相关性体积V_corr（54.0%），证明“过滤后的代价体”是几何信息的最优载体。

2. 交互区域深度估计作为辅助任务，而非全图均匀采样。 以往深度辅助任务在全图随机采样，大量样本落在背景（桌子、墙壁）上，缺乏任务相关信息。本文利用物体2D边界框将采样限制在夹爪与目标物体所在区域，迫使语言模型在“任务相关”位置学习度量深度。这一设计在推理时零开销（仅训练时使用），却让模型在小型物体抓取上达到30.0%成功率——所有基线完全失败。这直接回应了224×224低分辨率下小型物体性能受限的痛点，用“采样策略”而非“更高分辨率”部分弥补了信息损失。

3. 渐进式动作生成：先预测边界框和关键帧位姿，再预测动作块。 模型不是直接输出动作，而是先预测目标2D边界框和夹爪下一关键帧位姿作为中间步骤，再以flow-matching预测delta末端执行器位姿。这种“由粗到精”的分解让动作预测有了几何锚点，且四个任务（action:depth:bbox:pose=5:2:2:1）联合训练，共享语言模型特征。在真实世界450次试验中，StereoVLA平均成功率（小79.3%、中71.9%、大61.3%）全面超越前+腕相机配置的GraspVLA（71.3%、63.4%、54.8%），且无需额外硬件——这证明立体视觉可以替代腕部相机，简化人形机器人硬件设计。

实验与结果

实验设计围绕三个核心问题展开：立体几何特征是否优于单目深度估计、特征选择是否关键、以及立体输入能否在真实世界任务中超越多相机基线。作者在真实 Franka 机械臂上构建了 0.5m × 0.4m 工作区，包含通用拾取、条形物体多朝向抓取、以及中/小型物体抓取任务，每个测试集 15 次试验，共 450 次，且禁用 "gripper sticking" 启发式，任务完全完成才算成功——这一严格标准使结果更具区分度。

特征选择消融（表 I）在模拟中 100k 训练步后评估，取最近三个检查点平均。结果清晰验证了方法设计：使用相关性体积 V_corr 时，加入语义特征仅从 27.0% 提升至 54.0%；改用原始代价体 V_c 后，无语义 40.0%、有语义 69.0%；而采用过滤后的代价体 V′_c 达到无语义 51.0%、有语义 77.0%。语义特征带来的增益在 V′_c 上依然显著（+26 个百分点），说明几何与语义互补而非替代。V′_c 优于 V_c 的 8 个百分点（有语义条件下）证实了混合代价过滤模块纳入长程相关性的价值。

相机设置对比（表 II）在真实世界进行，三级随机化范围下报告平均成功率：

方法 小随机化 中随机化 大随机化
单视角 SpatialVLA-D 24.6% 13.7% 6.8%
前+腕 π₀.₅ 64.3% 56.5% 51.6%
前+腕 GraspVLA 71.3% 63.4% 54.8%
前+侧 GraspVLA 82.5% 55.7% 24.1%
立体 StereoVLA 79.3% 71.9% 61.3%

关键观察：单视角 SpatialVLA-D 即使使用 FoundationStereo 估计的高质量深度（AbsRel 0.0275 vs VGGT 的 0.4121），性能仍远低于任何多视角方法，说明单目深度估计的几何误差在操作任务中难以容忍。前+侧 GraspVLA 在小随机化下最高（82.5%），但大随机化下骤降至 24.1%，暴露了多相机对视角变化的脆弱性；而 StereoVLA 在大随机化下保持 61.3%，仅比小随机化下降 18 个百分点，远优于前+侧配置的 58.4（由表内数值 82.5−24.1 计算） 个百分点降幅。立体输入的优势在视角变化加剧时愈发明显——这正对应真实部署中相机位姿不确定的场景。

小型物体抓取是区分度最高的测试：StereoVLA 达到 30.0% 成功率（单次执行），所有基线完全失败。这直接归因于立体几何特征提供的亚厘米级空间精度，而 224×224 分辨率限制了上限——作者也承认提高分辨率是未来方向。

综合来看，实验设计严谨地隔离了变量：特征消融证明 V′_c + 语义是最优组合；相机对比证明立体优于多相机在视角鲁棒性上的优势；小型物体测试证明几何精度的实际价值。但需注意，所有结果仅在单一 Franka 具身上获得，且未评估更高分辨率骨干网络，泛化性仍待验证。

边界与局限

作者明确承认的边界集中在三处：一是224×224输入分辨率限制了小型物体（1–2cm）的抓取性能，即便StereoVLA在单次试验条件下达到30.0%成功率，其余基线全部失败，但作者未系统评估更高分辨率骨干网络，仅指出计算成本会大幅增加——这意味着当前结论对高分辨率场景的适用性未被验证。二是模型未捕获长时程时间依赖，动作块预测本质上是短视的，因此对需要多步推理或长时间操作的任务（如装配、工具使用）结论可能不成立。三是评估仅在单一具身（Franka机械臂）上进行，虽然作者声称方法不针对特定机器人，但未提供跨具身迁移证据，泛化到双足人形或不同手爪构型时，delta末端位姿表示与flow-matching动作预测的有效性存疑。

更深层的局限在于实验设计的约束条件。所有真实世界任务均限定在0.5m×0.4m工作区内，且相机位姿随机化范围有明确上限（前视角大范围150×50×60cm），超出此空间尺度的场景（如移动操作、大范围导航）未被覆盖。评估协议仅允许单次执行、无部分得分，这放大了模型在接触失败后的恢复能力缺陷——作者未测试重试或闭环修正策略，因此结论仅适用于“一次成功”的设定。此外，立体相机基线在真实Zed Mini参数5%范围内随机化，但未报告对更大基线偏差（如不同双目型号）的鲁棒性；合成数据（MuJoCo+Isaac Sim）与真实域之间的Sim2Real差距也未量化。交互区域深度估计依赖物体2D边界框，这隐含假设了检测器可用且目标可见，对遮挡或物体部分出界场景的可靠性论文未明确。最后，特征选择消融仅在模拟中100k步评估，真实世界性能与模拟趋势的一致性未直接验证。

工程启示

复现这套系统，第一道坎在数据管线：5M 条合成轨迹依赖 MuJoCo 生成动作、Isaac Sim 渲染立体图，两套仿真器的坐标系、时间戳对齐极易出隐性 bug。建议先核对立体相机基线是否严格落在 Zed Mini 参数 ±5% 范围内——作者明确这是泛化到真实硬件的关键，偏差过大会让几何特征失效。渲染分辨率 256×256 再缩到 224×224，意味着你复现时若直接用 224 渲染，DINOv2/SigLIP 的预训练分布会不匹配，成功率可能直接掉档。

选型上最值得注意的坑是 FoundationStereo 的代价体选择。表 I 显示 V′_c 比 V_c 高 8 个点（77% vs 69%），比 V_corr 高 23 个点——但 V′_c 需要跑混合代价过滤模块，跳过它省算力但性能损失显著。如果你只想快速验证，至少别用 V_corr，那是纯匹配分数，几何信息密度不够。语义特征只取左视图是省算力的聪明设计，但前提是左右视图语义冗余度高，若你的场景有强单侧遮挡，这个假设会破。

训练配置直接照抄风险不大：160k 步、32 张 H800、批 384、lr 1.6e-4，损失比例 5:2:2:1。但注意 action expert 只有 300M 参数，而语言骨干是 InternLM-1.8B——微调时若冻结骨干只训 expert，泛化会差；全量微调则显存压力大，需确认你的集群能装下梯度。

下游团队最容易踩的坑是评估协议。作者禁用了 gripper sticking 启发式、单次执行、无部分得分——这比多数论文严格得多。你复现时若沿用 OpenVLA 的宽松评估，成功率虚高 10-20 个点，横向对比会失真。另外相机位姿随机化分三级，默认小范围（前视角 15×10×15cm），换到中/大范围时表 II 显示 GraspVLA 从 82.5% 掉到 24.1%，而 StereoVLA 只从 79.3% 掉到 61.3%——立体输入的核心优势在强随机化下才显现，评估时务必覆盖大范围，否则看不出方法价值。

最后，小型物体（1-2cm）是硬指标：StereoVLA 单次试验 30% 成功率，其他基线全零。若你的下游任务涉及精密抓取，先验证这个数字能否复现；若复现不了，优先检查深度辅助任务的采样区域是否真的限制在交互区（含夹爪和目标物体的 2D bbox 内），这是作者特意设计来避免背景主导损失的。
