Summary

Extends asynchronous variational integrators (AVIs) to interaction potentials such as penalty contact forces, proves that AVIs remain multisymplectic under relaxed assumptions, and validates long-term energy stability on a thin sphere-plate impact using the Asynchronous Contact Mechanics framework.

Sources

  • Asynchronous Variational Integration of Interaction Potentials for Contact Mechanics

概述

WAM4D 提出一种异步变分积分框架，将几何基础先验（深度）以“空间寄存器蒸馏”方式注入因果视频-动作世界模型（WAM），在不增加推理时稠密几何解码的前提下强化接触几何约束。该方法在 RoboTwin 2.0 仿真和 AstriBot S1 真实机器人上验证，动作成功率与延迟均优于或持平现有视频-动作模型，且推理时几何路径完全移除。

它改变了什么

现有世界动作模型（WAMs）大多在 2D 视频或潜在空间运行，视觉上合理的 rollout 缺少精确操作所需的 3D 空间约束和遮挡接触几何。几何基础模型虽能恢复稠密 3D 结构，但强制 WAM 预测稠密 4D 表示会引入昂贵的几何解码并减慢因果动作生成。更根本的是，显式 4D 预测可能使 WAM 目标偏向几何重建，无法确保几何先验强化视频预测与动作生成之间的因果耦合。

WAM4D 改变的是“几何先验注入方式”：不再将稠密 4D 几何作为显式推理目标，而是通过可学习的空间寄存器 token 在训练时从因果视频特征中蒸馏未来深度，深度损失反向传播到共享骨干，推理时完全移除几何路径。这使得模型在保持轻量 2D 观测到动作推理接口的同时，获得几何先验对动作生成的因果约束，避免部署成本和延迟增加。

方法拆解

骨干架构

  • 基于 LingBot-VA 的因果视频-动作骨干，条件输入为语言指令 l、多视角 RGB 历史、历史动作队列。
  • 因果上下文：𝒞_t = {l, O_t^hist, a_{t-L_a:t-1}}，未来 RGB 帧和动作是预测目标。
  • 视频流：视频 VAE 编码 RGB 序列，分割为历史 token 和干净未来目标。
  • 动作流：轻量动作嵌入层编码历史与噪声未来动作。
  • 输入序列由视频-动作混合专家变换器（MoT）骨干处理，视频和动作头分别预测流匹配目标。

空间寄存器蒸馏

  • 引入可学习的空间寄存器 token 作为几何查询，从因果视频特征提取未来几何信息。
  • 共享寄存器网格复制到未来深度时间步，与多视角 RGB 马赛克对齐。
  • 在选定层（默认 12、14、16、18 之后）通过深度提取块更新：R_t^{ℓ+1} = DepthBlock_ℓ(Q=R_t^ℓ, K,V=[R_t^ℓ, Z_t^{hist,ℓ}])。
  • 更新后的寄存器特征投影到预训练几何头（Depth Anything V3 初始化）输入空间，预测未来深度 D̂_t^fut。
  • 寄存器分支仅训练时使用，深度损失反向传播到共享视频-动作骨干。

因果混合注意力

  • 文本指令通过交叉注意力注入，对视频和动作 token 均可见。
  • 未来动作 token 可关注历史视频、历史动作和自身噪声未来动作。
  • 关键设计：未来动作 token 被屏蔽，不能关注未来视频 token 和空间寄存器，防止非因果捷径。
  • 空间寄存器仅关注自身和有效历史视频 token，不暴露给动作预测器。
  • 推理时移除寄存器、深度块和几何头，模型退化为纯观测到动作生成路径。

训练目标

  • 主视频-动作流使用条件流匹配目标：ℒ_video 和 ℒ_action。
  • 深度蒸馏使用 SmoothL1 损失：ℒ_depth = (1/Σ_{τ∈𝒯_t}|Ω_τ|) Σ_{τ∈𝒯_t} Σ_{p∈Ω_τ} SmoothL1(D̂{τ,p}, D)。
  • 最终目标：ℒ = ℒ_video + λ_act·ℒ_action + λ_depth·ℒ_depth，设 λ_act = 1，λ_depth = 1。

实现细节

  • 骨干从预训练 LingBot-VA 初始化，使用 Wan2.2 视频 VAE。
  • 每序列最多采样 17 帧；历史上下文 1、5 或 9 帧；8 个视频预测目标帧每 4 个采集步采样一次。
  • 默认动作块大小 32。
  • 输入三视角马赛克：主视角 256×320，腕部视角 128×160。
  • 动作表示 16 维（双臂 3D 位置+四元数+夹爪开合），位置通道分位数归一化（q_01/q_99），四元数和夹爪通道固定 [-1,1]。
  • 默认三视角模型使用 960 个空间寄存器 token（8 个未来深度帧 × 120 个/帧）。
  • 几何读出使用预训练 DA3-GIANT-1.1 any-view DualDPT 头，四个可学习线性适配器映射隐藏状态。
  • 训练：AdamW，学习率 2×10⁻⁵√N，10 步预热，梯度裁剪 2.0，bf16，主实验 50k 步，消融 10k 步。

关键创新

  1. 空间寄存器蒸馏（Spatial Register Distillation）：将几何先验以可学习 token 形式注入因果视频-动作骨干，训练时通过深度损失约束共享表征，推理时完全移除几何路径。这是首次在不增加部署成本的前提下，将稠密几何先验与因果动作生成耦合。

  2. 因果混合注意力中的非因果屏蔽：未来动作 token 被严格屏蔽，不能关注未来视频 token 和空间寄存器，确保动作预测仅依赖历史信息。这避免了显式 4D 预测可能引入的“几何重建偏向”，保证几何先验强化而非替代视频-动作因果耦合。

  3. 异步变分积分框架：深度蒸馏与视频-动作流匹配目标联合优化，但几何读出仅在训练时激活。这种“训练时蒸馏、推理时移除”的设计，使模型在部署时保持轻量 2D 观测到动作接口，同时获得几何先验带来的泛化增益。

边界与局限

论文未明确列出作者承认的局限性章节。从实验数据看，WAM4D 在 Randomized 设置下平均成功率（89.9）低于 LingBot-VA（91.6），且部分 Hard 任务（Open Laptop 66、Put Object Cabinet 53）成功率显著下降，表明几何先验对高动态或强遮挡场景的增益有限。真实世界实验仅覆盖 4 个任务、每任务 10 次 rollout，统计显著性未明确。论文未提及不同机器人平台、更多真实世界任务或硬件配置（GPU 型号与数量）的泛化验证。

工程启示

复现或下游应用时，先核对以下几点：

  1. 几何头初始化：几何头从 Depth Anything V3 初始化，使用 DA3-GIANT-1.1 any-view DualDPT 头，四个可学习线性适配器映射隐藏状态。若替换几何头，需重新验证深度蒸馏的收敛性。

  2. 注意力掩码规则：未来动作 token 不能关注未来视频 token 和空间寄存器，这是防止非因果捷径的关键。实现时务必严格遵循掩码矩阵，否则动作预测可能“作弊”导致训练不稳定。

  3. 寄存器配置：默认 960 个空间寄存器 token（8 个未来深度帧 × 120 个/帧），每个寄存器对应输入图像 32×32 单元。若调整输入分辨率或视角数量，需重新计算寄存器网格布局。

  4. 训练预算：主实验 50k 步，消融 10k 步。若计算资源有限，可先用 10k 步验证深度蒸馏是否带来增益，再决定是否扩展。

  5. 推理配置：部署时移除几何路径，仅执行动作预测。延迟 525.43 ms 高于 Fast-WAM（425.53 ms），若对实时性敏感，可考虑减少动作去噪步数（默认 10 步）或优化 KV 缓存更新逻辑。

  6. 最容易踩坑：深度损失反向传播到共享骨干时，若寄存器分支的梯度与视频-动作流冲突，可能导致视频预测质量下降。建议监控 ℒ_video 在蒸馏开启前后的变化，必要时调整 λ_depth（默认 1）。
