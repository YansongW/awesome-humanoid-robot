Summary

This paper presents a hybrid 6-DoF bin-picking approach that combines a fully-convolutional neural network for planar grasp-reward estimation with a model-based controller for lateral orientation adaptation, achieving over 92% real-world grasp success in dense clutter after 27,000 self-supervised grasp attempts with inference under 50 ms.

Sources

  • Robot Learning of 6 DoF Grasping using Model-based Adaptive Primitives

概述

本文提出BiliVLA，一个面向ERCP胆道内镜导航与插管的视觉-语言-动作（VLA）模型，将任务级语言指令与闭环运动控制统一。系统采用两阶段训练（接地增强SFT + GRPO奖励优化），在真实体模上实现91.96%动作精度与84.85%成功率。核心贡献在于将手术语义直接转化为受限空间内的稳定动作，而非依赖模块化解耦。

它改变了什么

现有自主内镜系统普遍采用感知-规划-控制模块化架构，这种解耦在镜面反射、遮挡和域偏移下鲁棒性不足，且手术语义无法直接驱动闭环动作。作者判断，真正需要改变的不是单个模块的性能，而是整个控制范式的耦合方式——让语言条件语义直接参与动作生成，而非作为高层规划的中间表示。

另一个关键改变在于动作空间的离散化设计。将连续控制映射为十一个运动原语（如left-up、forward、backward），配合安全感知策略（接触时强制backward），这实际上将插管操作从“连续轨迹跟踪”问题转化为“受限空间内的离散决策”问题，显著降低了学习难度和部署风险。

方法拆解

问题形式化

  • 每个episode定义为 ℰ = {(o_t, I, s_t)}_{t=1}^{T}，其中 o_t 为RGB图像，I 为目标指令，s_t = (c_t, b_t, a_t) 包含目标类别、归一化边界框和离散控制动作。

动作空间与低层驱动

  • 动作空间包含十一个运动原语：{left-up, left-down, right-up, right-down, left, right, up, down, forward, backward, stop}。
  • 每个动作映射到三维角度增量 Δθ_t = (Δθ_x,t, Δθ_y,t, Δθ_z,t) ∈ ℝ³，其中前两维控制远端尖端正交弯曲，第三维控制插入/回缩。电机更新遵循 θ_{t+1} = θ_t + Δθ(a_t)。

最优决策规则

  • a_t* = {stop（结石居中时）；arg min_{a∈𝒜} ‖p_t(a) − p_c‖₂（当 ‖p_t − p_c‖₂ > τ）；forward（当 ‖p_t − p_c‖₂ ≤ τ）}。

两阶段训练框架

  • 阶段一（接地增强导航SFT）：使用LoRA微调LLM，骨干LLM和分词器冻结；内镜图像由可训练ViT和MLP投影器编码映射到语言嵌入空间；训练数据包含多视图图像、空间接地标注、场景级语义信息和运动命令。
  • 阶段二（奖励引导策略优化）：对每个输入采样K个候选输出，使用结构化奖励函数评估，采用GRPO更新策略，通过组内相对奖励比较估计归一化优势。

奖励函数

  • R(u, s) = R_bbox + R_act + R_fmt，其中 R_bbox 使用预测边界框与真实框之间的IoU定义。

安全感知策略

  • 对检测为管腔壁接触的帧，边界框设为覆盖整个图像 b_t^s = (0, 0, 1, 1)，控制命令设为 a_t^s = backward；其余帧应用名义监督。

关键创新

  1. 语言条件闭环控制：首次将VLA模型直接用于ERCP插管级操作，让任务级文本指令（如“定位结石”）直接参与动作生成，而非仅作为高层规划输入。这消除了模块化架构中的语义传递损耗，使手术意图与底层运动控制形成紧耦合。

  2. 安全感知动作策略：通过接触检测触发“全图边界框 + backward”的强制安全动作，将安全约束内嵌于策略学习而非外部规则。这种设计在高度受限空间内显著降低组织损伤风险，是临床部署的关键保障。

  3. 离散运动原语 + 最优决策规则：将连续控制问题转化为离散决策问题，配合解析最优规则（stop/forward/argmin），既降低了学习复杂度，又保证了动作的可解释性和可验证性。

实验与结果

数据集与任务

  • BiliVLA-Motion数据集包含10k个标注图像-运动对，覆盖三个ERCP子任务：入口导航（3k对）、管腔穿越（2.6k对）、结石定位（4.4k对）。
  • 训练、验证、测试集比例为80%、10%、10%。

关键性能指标

指标 数值
动作精度（action precision） 91.96%
总体成功率（SR） 84.85%

实验设置

  • 内镜成像系统以30 FPS运行，图像分辨率固定为640 × 480像素。
  • 运动标签根据目标中心相对于44像素焦点区域的偏移分配。
  • 边界框由YOLOv11生成并手动精炼。

结果含义

91.96%的动作精度表明模型在离散动作预测上高度可靠，84.85%的总体成功率则验证了端到端策略在真实体模环境中的可行性。值得注意的是，成功率低于动作精度，暗示部分失败源于连续动作执行误差或安全策略触发后的恢复不足。

边界与局限

论文未明确列出作者承认的局限性。从方法推断，以下边界值得注意： - 体模环境与真实人体解剖存在差异，镜面反射、组织变形和生理运动（呼吸、蠕动）未完全模拟。 - 电机角度与远端尖端弯曲角度假设线性映射，实际非线性可能影响精度。 - 安全策略仅处理“接触”这一种异常，未覆盖器械故障、图像完全丢失等极端情况。 - 未提供K值、训练轮数、学习率等关键超参数，复现难度较高。

工程启示

复现或部署BiliVLA时，建议优先核对以下环节： 1. 动作空间映射：确认电机角度与弯曲角度的线性假设在目标平台上是否成立，必要时引入标定补偿。 2. 安全策略触发阈值：接触检测的灵敏度直接影响安全性与任务成功率，需在临床数据上重新调参。 3. 数据分布匹配：训练集包含10k对，其中结石定位占4.4k对（44%），若下游任务分布不同，需重新平衡或进行域适应。 4. GRPO采样数K：论文未提供具体值，建议从K=4开始网格搜索，观察奖励收敛情况。 5. 边界框质量：YOLOv11生成后需人工精炼，标注质量直接影响R_bbox项，建议建立双重标注审核机制。

最易踩坑之处在于安全策略的“全图边界框 + backward”设计——在真实内镜中，backward动作可能因器械弯曲状态而无法立即执行，需在低层控制器中加入运动状态检查。
