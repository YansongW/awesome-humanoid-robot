Summary

Seeing Space and Motion: Enhancing Latent Actions with Spatial and Dynamic Awareness for VLA (SSM-VLA), is a 2025 large vision-language-action model for robotic manipulation, introduced by Tsinghua Shenzhen International Graduate School, Tsinghua University, Amap, Alibaba Group, School of Software Engineering, Xi’an Jiaotong University, Xi’an Jiaotong University..

Sources

  • Seeing Space and Motion: Enhancing Latent Actions with Spatial and Dynamic Awareness for VLA (arXiv)
  • SSM-VLA source

概述

本文提出 SSM-VLA，一种通过增强潜在动作（Latent Actions）空间与时间感知能力的视觉-语言-动作模型。核心贡献是 Farsighted-LAM 框架，利用冻结 DINOv2 特征编码几何先验，并联合预测未来 N 帧的潜在动作，以提升机器人操作在长时程任务中的鲁棒性与泛化性。实验在 CALVIN 基准上达到平均链长 4.38，显著优于现有方法。

它改变了什么

现有 Latent Action Models（LAMs）虽能从未标注视频中学习动作表征，但其瓶颈在于对空间几何与时间动态的建模过于粗糙。端到端训练的图像编码器往往偏向纹理与外观，忽略物体间空间关系与场景布局；而多数方法仅依赖稀疏两帧输入，无法捕捉细粒度运动过渡与长期依赖。这种双重缺陷导致潜在动作表示不稳定、语义模糊，在长时程任务中决策可靠性显著下降。

SSM-VLA 真正改变的，是将“潜在动作”从一种压缩视觉变化的工具，提升为一种显式承载空间结构与时间演化的表征。它不再满足于从相邻帧推断离散动作 token，而是通过几何感知编码与多尺度时间建模，让潜在动作本身蕴含可解释的物理与运动信息。这直接改善了动作生成的连贯性，使模型在未见环境与长任务链中表现更稳定，而非仅仅依赖统计相关性。

方法拆解

Farsighted-LAM 编码器

  • 输入观测包含 RGB 与深度：s_t = (s_t^{rgb}, s_t^{depth})。
  • 使用冻结 DINOv2 特征 Φ_V 提取每帧结构先验：v_t = Φ_V(s_t^{rgb})，得到特征序列 {v_{t+i}}_{i=0}^N。
  • 特征与 N 个可学习潜在动作查询 𝒬 = {q_k}_{k=1}^N 通过时空 transformer Ψ_ST 处理，生成连续潜在向量 z'_{t+k} = Ψ_ST({v_{t+i}}_{i=0}^k, q_k)。
  • 通过最近邻查找量化到离散 token：z_{t+k} = argmin_{c∈𝒞} ||z'_{t+k} - c||_2，码本 𝒞 ⊂ ℝ^D，大小 32。

Farsighted-LAM 解码器

  • 空间 transformer Ψ_S 输入仅 (s_t^{rgb}, z_{t+k})，预测未来观测 ŝ_{t+k} = (ŝ_{t+k}^{rgb}, ŝ_{t+k}^{depth})。
  • 关键设计：解码器对真实目标观测 s_{t+k} 或中间观测不可见，防止学习捷径映射，强制编码器将更多空间与运动信息嵌入潜在动作。

重建损失

  • 多模态重建损失 ℒ_rec 包含：
  • 光度损失 ℒ_rgb：L2 损失 + LPIPS 感知损失（权重 λ_LPIPS）。
  • 深度损失 ℒ_depth：梯度感知的对数损失，按 RGB 图像梯度反加权。
  • 最终损失为所有 N 个未来关键帧的加权和：ℒ_rec = Σ_{k=1}^N (ℒ_rgb(s_{t+k}, ŝ_{t+k}) + λ_d ℒ_depth(s_{t+k}, ŝ_{t+k}))。

SSM-VLA 三阶段级联

  • Stage 1: VisualCoT 预测：视觉预测模块 ℳ_vision 基于历史观测 s_{t-H:t} 和语言指令 l 预测下一视觉状态 ŝ_{t+1}，损失 ℒ_vision = ℒ_rec(s_{t+1}, ŝ_{t+1})。无深度传感器时，用 DepthAnything 预测单目深度，通过 SfM 稀疏图对齐（闭式线性回归求解 â, b̂）生成伪深度目标。
  • Stage 2: Farsighted 潜在动作推断：潜在预测模块 ℳ_latent 基于历史上下文、预测的下一帧特征和先前潜在动作，推断长度为 N 的未来动作意图分布 ẑ_{t+k}，用交叉熵损失 ℒ_latent 监督，以 F-LAM 固定编码器生成的真实潜在动作 z_{t+k} 为目标。
  • Stage 3: 动作生成：动作模块 ℳ_action 生成中间特征 c_t，作为条件 Flow Matching 模型 V_θ（DiT 网络）的条件，预测最终动作，损失 ℒ_action = 𝔼[||V_θ(τa_t + (1-τ)ε, τ, c_t) - (ε - a_t)||_2^2]。

多模态协同注意力

  • 在单一统一 transformer 中实现，采用渐进式结构化注意力掩码：
  • 历史视觉 token 和语言 token 形成双向注意核心上下文。
  • 视觉预测查询仅关注核心上下文。
  • 潜在规划查询关注核心上下文和预测帧，内部使用因果掩码保证时间连贯性。
  • 最终动作查询关注所有前述信息（核心上下文、预测帧、完整潜在计划）。

关键创新

  1. 几何感知空间编码：使用冻结 DINOv2 特征而非端到端训练的图像编码器，显式注入空间布局、隐式深度与物体关系等结构先验。这一设计避免了纹理偏置，使潜在动作对场景几何变化更鲁棒，且无需额外训练视觉骨干，计算开销可控。

  2. 多尺度时间建模（Farsighted-LAM）：在单次前向传播中同时预测未来 N 帧的潜在动作，而非逐帧自回归。这迫使编码器捕捉长期动态与细粒度运动过渡，同时通过解码器对中间观测不可见的设计，防止捷径学习，确保潜在动作承载足够的时间演化信息。

  3. 三阶段级联与协同注意力：将视觉预测、潜在动作推断与动作生成解耦为可独立优化的模块，并通过结构化注意力掩码在统一 transformer 中实现多模态信息的高效交互。这种设计既保持了模块的可解释性，又避免了级联误差累积，使模型能同时利用视觉推理与潜在规划的互补优势。

实验与结果

实验在 CALVIN 基准（ABC-D 设置）上进行，训练于环境 A、B、C，零样本评估于未见环境 D，测试 1000 条独特指令链，每条需完成五个连续任务。

真实世界实验中，单台 AgileX Piper 机器人成功将粉色玩具放入盒子，在 Open-X-Embodiment 预训练后仅用 50 个人类演示微调，展现了对杂乱环境的强泛化能力。

边界与局限

论文未明确列出作者承认的局限。从实验设置推断，当前验证主要基于 CALVIN 仿真基准与单一真实世界任务，对于更复杂、更开放的真实操作场景（如非结构化物体堆叠、动态环境干扰）的泛化性尚未充分验证。此外，Farsighted-LAM 依赖 DINOv2 的冻结特征，其空间先验质量受限于预训练数据分布，在极端几何变化（如透明物体、镜面反射）下可能失效。深度监督在无传感器时依赖单目深度估计，其误差可能影响训练稳定性。

工程启示

复现或应用 SSM-VLA 时，建议优先核对以下环节：

  1. DINOv2 特征质量：冻结特征对空间先验的贡献是核心，需验证在目标场景中 DINOv2 是否有效捕捉物体关系。若场景与 ImageNet 分布差异过大，可考虑微调或替换为其他自监督视觉模型。

  2. 解码器防捷径设计：确保解码器在训练时确实无法访问目标帧与中间帧，否则编码器会退化，潜在动作将失去时间信息。建议在训练日志中监控重建损失与潜在动作的互信息。

  3. 深度监督的可靠性：若使用伪深度（DepthAnything + SfM 对齐），需检查对齐质量。闭式线性回归求解 â, b̂ 对异常值敏感，建议在训练前可视化对齐结果。

  4. 协同注意力掩码实现：渐进式掩码是性能关键（消融显示因果掩码导致平均链长下降 0.68），需确保各查询组的注意力范围严格符合设计，避免信息泄漏。

  5. 训练配置：LAM 与 VLA 采用不同学习率（10^{-4} vs 10^{-3}）与批大小（256 vs 64），且 LAM 训练 100 步、VLA 训练 30 步。若计算资源有限，可先固定 LAM 编码器，仅训练 VLA 模块，以降低显存占用。
