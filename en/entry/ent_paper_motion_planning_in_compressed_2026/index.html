Summary

arXiv:2606.30940v1 Announce Type: new Abstract: Deep learning methods have vastly expanded the capabilities of motion planning in robotics applications, as learning priors from large-scale data has been shown to be essential in capturing the highly complex behavior required for solving tasks such as manipulation or navigation for autonomous vehicles. At the same time, model-based planning algorithms based on search or optimization remain an essential tool due to their flexibility, efficiency, and the ability to incorporate domain knowledge via expert-designed algorithms and objective functions. We propose a new generative framework to unify these two paradigms. First, we learn an autoencoder with a high compression ratio and a latent space of hierarchically ordered, discrete-valued tokens. Leveraging both the dimensionality reduction and the hierarchical coarse-to-fine structure learned by this autoencoder, we then perform motion planning by directly searching in the latent space of tokens. This search can optimize arbitrary objective functions specified at test time, providing a large degree of flexibility while maintaining efficiency and producing realistic solutions by relying on the generative capabilities of the highly compressed autoencoder. We evaluate our method on nuPlan and the Waymo Open Motion Dataset, showing how latent space search can be used for a variety of guided behavior generation tasks, achieving strong performance for closed-loop motion planning and multi-agent guided scenario synthesis without requiring any task-specific training.

概述

本文提出 Action-aware Dynamic Pruning（ADP），一种面向视觉-语言-动作（VLA）模型的即插即用动态剪枝框架。其核心贡献在于将视觉 token 剪枝决策从静态或仅文本驱动，扩展为结合文本相关性预剪枝与动作轨迹幅度动态门控的双重机制，以匹配机器人操作不同阶段视觉冗余度的动态变化。在 OpenVLA 基座上，ADP 实现了 1.35× 加速与 25.8% 的成功率提升。

它改变了什么

现有 VLA 效率优化（如 RoboMamba、DeeR-VLA、VLA-Cache）多采用架构轻量化或静态模态压缩，其隐含假设是视觉冗余度在任务全程恒定。本文作者通过观察指出，这一假设在机器人操作中不成立：粗粒度重定位阶段视觉 token 冗余高，而细粒度抓取阶段需要完整细节。更关键的是，现有方法仅以文本指令为剪枝条件，忽略了动作（末端执行器瞬时运动与夹爪状态）对视觉相关性的约束——这导致静态剪枝在精度与效率间难以平衡，尤其在多视角（场景相机与腕部相机）设置下，剪枝过少则节省有限，剪枝过多则精度损失显著。

ADP 真正改变的是将剪枝决策从“一次性静态选择”转变为“随动作状态动态切换”的在线策略。它不再追求全局最优的固定保留比例，而是通过动作轨迹的局部运动幅度，在“全视觉”与“剪枝”两种模式间自适应切换。这一转变使得视觉计算预算的分配与操作阶段的任务需求对齐，而非与序列长度或注意力分数对齐，从而在保持任务精度的前提下释放计算资源。

方法拆解

ADP 框架分为两个阶段，均在视觉 token 进入 LLM 之前执行：

文本驱动预剪枝（Text-driven Anticipatory Pruning）

  • 使用 LLM 第 l 层的隐藏状态，通过投影矩阵构造文本查询 Q 与视觉键 K。
  • 计算缩放点积相似度矩阵 A，全局重要性分数 Φ(v) 通过对所有注意力头与文本查询求平均得到。
  • 保留 Top-K 个 token，其中 K = ⌊ρ · L_vis⌋，ρ 为保留比例。
  • 多视角场景下，保留配额按权重向量 α 在 C 个视角间分配，每个视角保留 k_c = ⌊α_c · k⌋ 个 token。

动作感知动态策略（Action-Aware Dynamic Strategy）

  • 将每个解码的动作块视为时间窗口 [b_i, e_i]，窗口长度 ω 与 OFT 动作占位符长度匹配。
  • 通过窗口化正向运动学（Windowed FK）计算末端执行器位置，使用体坐标系右乘组合，旋转顺序为 R_x R_y R_z。
  • 窗口轨迹距离 δ_i = Σ ||p_{t+1} - p_t||₂，量化运动幅度。
  • 动态决策函数定义二元状态 s_i ∈ {0,1}（0=全视觉，1=剪枝）：
  • 累积平均阈值方案：s_{i+1} = 1 当 δ_i ≥ δ̄i，否则 s = 0，其中 δ̄_i 为历史窗口距离平均值。
  • 备选相邻极值方案：基于最近 τ 个窗口的最大值 U 与最小值 V 设定阈值，δ_i ≥ U 时剪枝，δ_i ≤ V 时全视觉，中间状态保持上一状态。

复杂度分析

  • 单层 Transformer FLOPs 近似 F(S,D,M) ≈ 2S²D + 4SD² + 6SDM。
  • 剪枝后序列长度 S' = 1 + k + L_prop + L_txt + L_act + 1。
  • 评分开销 F_score = 2L_txtD² + 2L_visD² + 2N^h L_txt L_vis d。
  • 期望节省 E[ΔF_episode] = T·γ·ΔF_ADP，其中 γ 为剪枝状态执行比例。

关键创新

  1. 动作条件驱动的动态门控：这是首个将末端执行器运动幅度作为剪枝开关信号的方案。不同于仅依赖注意力分数或文本相关性，ADP 通过窗口化 FK 将动作轨迹的局部变化率转化为二元状态切换，使得剪枝决策与操作阶段（粗粒度 vs 细粒度）直接对齐。这一设计在物理层面将“何时需要完整视觉”与“何时可容忍视觉缺失”建立了可计算的对应关系。

  2. 文本预剪枝与动作门控的级联架构：文本驱动预剪枝负责空间维度上的 token 筛选（哪些 patch 重要），动作门控负责时间维度上的模式切换（当前时刻是否需要剪枝）。两者解耦又互补，避免了单一信号导致的过度剪枝或欠剪枝，尤其解决了多视角下静态配额分配无法适应动态需求的问题。

  3. 即插即用且无架构修改：ADP 在嵌入阶段、进入 LLM 之前执行，所有 H 层统一受益于缩短的序列长度，无需改动 Transformer 内部结构。这使得其可直接应用于现有 VLA 模型（如 OpenVLA-OFT），降低了集成门槛，且剪枝决策的额外计算开销（F_score）远小于主网络 FLOPs 节省。

实验与结果

实验在 LIBERO 基准测试与真实世界场景中验证，以 OpenVLA (7B) 为基座，视觉编码器使用 DINOv2 与 SigLIP，LLM 使用 Llama2。动作表示为 7 自由度（笛卡尔位移 Δx, Δy, Δz、欧拉角旋转 Δφ, Δθ, Δψ、夹爪命令 g），OpenVLA-OFT 并行解码引入 L_act 个占位符，连续动作每维度均匀离散化为 256 个 bin。

边界与局限

论文片段未明确列出作者承认的局限性。基于方法设计可推断的边界包括：动态门控依赖动作轨迹的窗口化 FK 计算，对于非欧拉角表示或非笛卡尔动作空间（如关节空间控制）需要重新设计距离度量；阈值方案（累积平均或相邻极值）对轨迹噪声敏感，极端情况下可能频繁切换状态导致计算抖动；多视角配额分配权重 α 的设定缺乏自适应机制，固定权重可能无法应对视角间信息量动态变化。此外，实验仅在 LIBERO 套件与特定真实场景验证，未覆盖更广泛的操作任务类型（如灵巧操作或非刚体操作），泛化性论文未明确。

工程启示

复现或应用 ADP 时，建议按以下顺序核对：

  1. 先验证动作表示与 FK 一致性：ADP 的窗口距离 δ_i 依赖体坐标系右乘组合与 R_x R_y R_z 旋转顺序，若下游动作表示改为 ZYX 欧拉或四元数，需重写 Windowed FK，否则 δ_i 计算失真将直接导致门控误判。
  2. 重点调参 ρ 与 τ：ρ（保留比例）决定预剪枝强度，τ（相邻极值窗口）决定门控切换灵敏度。建议先在单一任务上扫描 ρ ∈ [0.3, 0.7] 与 τ ∈ [3, 10]，观察成功率与 FLOPs 的 Pareto 前沿，再迁移到多任务。
  3. 警惕多视角配额 α 的静态性：若场景相机与腕部相机信息量差异大，固定 α 可能导致某一视角过度剪枝。可考虑将 α 改为基于在线注意力熵的动态分配，但需额外计算开销。
  4. 最易踩坑点：在长程任务（Long）中，累积平均阈值方案可能因历史窗口距离均值漂移而延迟响应，建议优先采用相邻极值方案，并确保 τ 覆盖一个完整操作阶段（如一次抓取动作的时长）。
  5. 集成位置确认：剪枝必须在嵌入阶段、进入 LLM 之前执行，且需保证所有 H 层共享剪枝后的序列长度。若下游模型在中间层有跨层注意力或残差连接依赖完整序列，需额外适配。
