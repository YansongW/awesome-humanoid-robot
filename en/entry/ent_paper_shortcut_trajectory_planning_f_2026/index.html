Summary

arXiv:2607.09336v1 Announce Type: cross Abstract: Diffusion-based trajectory planners have shown strong performance in offline reinforcement learning, but their iterative denoising process often incurs high inference cost. Consistency-based planners reduce the number of sampling steps, yet they typically rely on a two-stage teacher--student distillation pipeline that increases training cost and may introduce instability. We propose Shortcut Trajectory Planning (STP), an offline model-based reinforcement learning framework that incorporates shortcut models as efficient trajectory generators. STP trains a conditional shortcut trajectory model in a single stage, supports adjustable one-step and few-step inference through step-size conditioning, and selects candidate plans using a critic augmented with feasibility-aware correction. Across standard D4RL benchmarks, including locomotion, navigation, manipulation, and dexterous control tasks, STP achieves strong performance while simplifying the training pipeline for fast generative planning.

概述

本文提出 Shortcut Trajectory Planning (STP)，一种单阶段训练的离线强化学习轨迹规划框架，用 shortcut 模型替代一致性规划器（CTP）中的教师-学生蒸馏流程。STP 在 D4RL 多个基准上以 2-3 步采样达到或超越 CTP 性能，同时简化训练并保留可调节的推理预算。

它改变了什么

扩散式轨迹规划器（如 Diffuser）性能强但推理成本高，一致性规划器（CP/CTP）虽减少采样步数，却引入两阶段蒸馏的复杂性和不稳定性——最终模型质量依赖教师和学生双双训练成功，这在离线 RL 本就多模态、分布偏移的环境下尤其脆弱。STP 真正改变的是：把“先训练扩散教师、再蒸馏成少步生成器”的间接路径，压缩为直接优化一个支持任意步长跳跃生成的 shortcut 模型。这意味着训练流程从串行依赖变为并行可调，少了一个可能失败的环节，也少了超参数在教师和学生之间的传递误差。

另一个实质变化在于推理时的灵活性。CTP 的采样步数受蒸馏时固定的步数约束，而 STP 通过步长条件化（d），在推理时用同一个模型支持一步、少步或多步生成，用户可按实时性需求动态调整计算预算，无需重新训练。这改变了“效率 vs 质量”的权衡方式——从架构选择变成了运行时参数。

方法拆解

轨迹表示与跳跃步规划

STP 规划的子序列为 (s_k, s_{k+M}, …, s_{k+(H-1)M})，H 为规划视界，M 为规划步长，覆盖 H×M 个环境步。不同任务组采用不同设置：MuJoCo locomotion 用 H=4, M=1；Kitchen 用 H=32, M=4；Maze2D 用 H=32, M=15；AntMaze 用 H=40, M=25；Adroit 用 H=32, M=2。这些与 CTP 基线一致，确保对比聚焦于生成模型本身。

Shortcut 模型

条件模型 S_θ: (x_t, t, d) ↦ Δx，更新规则为 x_{t+d} = x_t + d·S_θ(x_t, t, d)。训练目标联合两项： - 流匹配项：L_FM = E[||S_θ(x_t, t, 0 | s_k) − (x_1(τ) − x_0^noise)||²]，保证单步生成质量。 - 递归自一致性项：L_SC = E[||S_θ(x_t, t, 2d | s_k) − sg(S_target)||²]，其中 S_target = ½S_θ(x_t, t, d | s_k) + ½S_θ(x_{t+d}', t+d, d | s_k)，强制大步长输出与两步小步长输出一致（sg 为停止梯度）。

总损失 L_STP(θ) = L_FM(θ) + λ_SC·L_SC(θ)。网络骨干为 Diffusion Transformer blocks + adaLN-Zero，优化器用 Adam。

辅助模型

  • 逆动力学模型 h_φ(s_k, s_{k+M}) → a_k，训练损失 L(φ) = E[||a_k − h_φ(s_k, s_{k+M})||²]，从选定轨迹的首个步长转移恢复可执行动作。
  • Critic 模型 V_α 输入去噪轨迹，预测累积折扣回报 R_k = Σ_{h=0}^{t_end} γ^h r_{k+h}，训练损失为 MSE。

推理流程

  1. 首步从高斯噪声采样 x₀ ∼ 𝒩(𝟎, 𝐈)。
  2. 后续环境步采用 warm-start：x₀.₃⁽ᵏ⁾ = 0.7 x₀ⁿᵒⁱˢᵉ + 0.3 x₁⁽ᵏ⁻¹⁾，从中间噪声水平 t=0.3 初始化，复用上一步去噪轨迹并加扰动。
  3. 生成 C 个候选轨迹（默认 30，AntMaze-Large 除外），用可行性修正后的 critic 分数排序：Ṽ(x_{t0}^{(c)}) = V_α(x_{t0}^{(c)}) − λ_fea·Ψ(x_{t0}^{(c)})，λ_fea=5，Ψ 为障碍物重叠惩罚。
  4. 选最优计划，经逆动力学模型提取动作。

关键创新

  1. 单阶段训练替代两阶段蒸馏：STP 直接端到端优化 shortcut 模型，无需先训练扩散教师。这不仅省去一个训练阶段，还消除了蒸馏过程中教师-学生能力不匹配导致的不稳定性。对离线 RL 这种数据分布复杂、训练信号稀疏的场景，减少一个易失败的环节是实质性的鲁棒性提升。

  2. 步长条件化实现推理预算可调：通过将步长 d 作为模型输入，STP 在推理时可用同一个模型选择一步、少步或多步生成。这比 CTP 的固定步数蒸馏更灵活——用户可按实时性需求动态调整计算预算，无需重新训练。对机器人实时控制场景，这意味着“精度-延迟”权衡可在运行时调节。

  3. Warm-start 与可行性修正的组合：warm-start 复用上一步去噪轨迹，从 t=0.3 中间噪声水平初始化，减少重复计算并提升时间连贯性。可行性修正显式惩罚违反环境约束的候选轨迹，弥补 critic 只学期望回报、不学物理可行性的盲区。两者结合在 Maze2D-Large 上带来显著提升（181.9 → 215.1），说明在复杂约束环境中，价值排序与可行性校验缺一不可。

实验与结果

评估使用 D4RL 标准基准，150 个独立规划种子，报告归一化回报。STP 采样步数：AntMaze 用 2 步，其他任务用 3 步。关键结果汇总：

任务组 STP CTP 最佳基线 说明
MuJoCo 运动平均 73.9 73.3 D-QL 78.9 STP 略超 CTP，但低于 Diffusion-QL
Maze2D 平均 183.8 179.3 D-QL 159.8 STP 最佳，显著领先
Kitchen 平均 83.6 82.85 D-QL 61.55 STP 大幅领先
AntMaze 平均 85.33 83.33 D-QL 64.6 STP 最佳
Adroit 平均 114.3 106.9 AlignIQL 112.8 STP 最佳，但 Hammer 上 AlignIQL 124.7 更高

消融实验显示 warm-start 在 Maze2D 将平均分从 150.8 提升至 183.8，AntMaze 从 68.0 提升至 85.3；可行性惩罚在 Maze2D-Large 带来显著提升（181.9 → 215.1），但在 U-Maze 和 Medium 上效果有限。

关键结论：STP 在 Maze2D、Kitchen、AntMaze、Adroit 四类任务上取得最佳平均分，但在 MuJoCo 运动任务上不如显式基于价值的 Diffusion-QL（78.9 vs 73.9）。这说明 STP 的优势在长视界、稀疏奖励、强约束场景更明显，而在短视界、密集奖励的运动控制中，价值函数引导的策略优化仍占优。

边界与局限

论文未明确列出 STP 的局限性。从实验结果可推断：在 MuJoCo 运动任务上，STP 平均分 73.9 低于 Diffusion-QL 的 78.9 和 Consistency-AC 的 78.5，说明在短视界、密集奖励场景中，显式价值优化的方法仍占优。Adroit Hammer 任务上 AlignIQL 124.7 高于 STP 120.9，表明在特定高精度操作任务上仍有差距。论文未评估 medium-expert 数据集，未提供超参数敏感性分析、训练时间量化对比，也未深入分析可行性修正失效的场景。推理步数未按任务单独调优（统一用 2 或 3 步），可能未达各任务最优性能。

工程启示

复现 STP 时，先核对三处最容易踩坑的地方：一是 warm-start 的初始化公式 x₀.₃⁽ᵏ⁾ = 0.7 x₀ⁿᵒⁱˢᵉ + 0.3 x₁⁽ᵏ⁻¹⁾ 中噪声与信号的混合比例，这是消融中提升最大的单一因素（Maze2D 提升 33 分）；二是可行性惩罚系数 λ_fea=5 的设定，在 Maze2D-Large 上效果显著，但在简单任务上几乎无影响，说明该系数需按环境复杂度调整；三是规划视界 H 与步长 M 的搭配，论文按任务组固定，若迁移到新环境需重新标定。

对下游团队，STP 的价值在于推理预算可调——同一模型可在 1-3 步间切换，适合需要实时响应的机器人控制场景。但需注意：在短视界、密集奖励的运动控制任务上，Diffusion-QL 类方法仍可能更优，选型时应先评估任务的时间尺度与奖励密度。训练时无需教师模型，单阶段端到端优化，训练流程更简洁，但自一致性项 λ_SC 的权重需调参，论文未给出具体值，建议从 1.0 起调。
