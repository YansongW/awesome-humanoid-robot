Summary

An iterative optimization algorithm that tracks the set of constraints that are active at the solution and solves a sequence of equality-constrained subproblems.

  • J. Nocedal and S. J. Wright, Numerical Optimization, 2nd ed., Springer, 2006

Overview

The active-set method is an iterative algorithm for solving optimization problems with inequality constraints. Its core idea is to maintain a "working set" during each iteration—the set of inequality constraints currently treated as equality constraints—and to approximate the truly active optimal constraint set by repeatedly adding and removing constraints. What it genuinely changes is not the efficiency of solving a single subproblem, but rather the transformation of the combinatorial decision of "which constraints should be active" into a sequence of efficiently solvable equality-constrained subproblems, making it one of the most reliable choices for small- to medium-scale convex quadratic programming (QP).

Content

What It Is: Precise Definition

The active-set method is a feasible-point method for solving optimization problems with inequality constraints. Starting from a feasible point, at each iteration it merges the inequality constraints currently "guessed" to be active (at equality) with all equality constraints into a working set \(\mathcal{W}_k\), then solves an equality-constrained subproblem on this working set to determine the search direction. If the subproblem's optimal solution violates a constraint outside the working set, that constraint is added to the working set; if a Lagrange multiplier corresponding to a constraint in the working set is negative (for a minimization problem), it indicates that the constraint should not be active, and it is removed from the working set. This process repeats until the Karush-Kuhn-Tucker (KKT) conditions are satisfied.

The method is particularly well-suited for convex quadratic programming problems, because each subproblem then has a closed-form solution or can be solved efficiently via direct methods, and the algorithm terminates in a finite number of steps.

Why It Exists: Pain Points and Historical Positioning

Before the active-set method emerged, the dominant approach for handling inequality constraints was the penalty method—incorporating constraint penalty terms into the objective function to convert the constrained problem into an unconstrained one. The penalty method is simple to implement but has two fundamental flaws: first, the penalty parameter requires manual tuning—too large leads to an ill-conditioned Hessian, while too small causes the solution to deviate significantly from the feasible region; second, constraints cannot be satisfied exactly, only approximately.

The historical significance of the active-set method lies in its separation of the combinatorial problem from the continuous problem. The difficulty of inequality constraints is that "which constraints are active" is a combinatorial decision—with \(m\) inequality constraints, one would theoretically need to check \(2^m\) active-set combinations. The active-set method avoids exhaustive enumeration by gradually exchanging the working set, so that each iteration only requires solving an equality-constrained subproblem whose size is far smaller than the original problem. This idea was systematized in the 1980s and became the core engine of QP solvers such as qpOASES.

Principle Breakdown

① Working Set: "Pretending" Inequalities Are Equalities

Consider the convex quadratic program:

\[ \min_x \; \frac{1}{2} x^{\top} H x + g^{\top} x \quad \text{s.t.} \quad A x = b, \; C x \le d. \]

Let the current iterate be \(x_k\), and let the working set \(\mathcal{W}_k\) contain all equality constraints plus the inequality constraints currently active (at equality) at \(x_k\). At \(x_k\), we solve the following equality-constrained subproblem to determine the search direction \(p_k\):

\[ \min_p \; \frac{1}{2} p^{\top} H p + (H x_k + g)^{\top} p \quad \text{s.t.} \quad A p = 0, \; C_{\mathcal{W}_k} p = 0. \]

Note that the right-hand sides of the constraints in the subproblem are set to 0, because \(x_k\) already satisfies the working-set constraints, and we only care about whether these constraints remain satisfied when moving along the direction \(p\).

② Step Size and Constraint Exchange: Two Key Decisions

After solving the subproblem to obtain \(p_k\), we need to determine the step size \(\alpha_k\). If \(p_k = 0\), then \(x_k\) is optimal for the working-set subproblem; at this point, we check the Lagrange multipliers \(\mu_j\) corresponding to the inequality constraints in the working set: if all \(\mu_j \ge 0\), then \(x_k\) is optimal for the original problem and the algorithm terminates; if some \(\mu_j < 0\), we remove that constraint (it should not exert a "push" on the solution) and re-solve.

If \(p_k \neq 0\), we move along the direction \(p_k\), with the step-size upper bound determined by constraints outside the working set:

\[ \alpha_k = \min \left\{ 1, \; \min_{i \notin \mathcal{W}_k, \, c_i^{\top} p_k > 0} \frac{d_i - c_i^{\top} x_k}{c_i^{\top} p_k} \right\}. \]

If \(\alpha_k < 1\), a constraint not yet in the working set has been "hit"; we add it to the working set and re-solve the subproblem.

③ Finite Termination: Guarantee for Convex QP

For convex quadratic programming, the active-set method enjoys finite termination: each iteration either strictly decreases the objective function value or changes the working set while keeping the objective value unchanged (by removing a constraint with a negative multiplier). Since the number of possible working sets is finite, the algorithm necessarily reaches a KKT point in a finite number of steps. This property is not shared by interior-point methods, which only converge asymptotically.

Key Parameters and Specifications

Parameter/Concept Meaning Typical Value or Property
Working set \(\mathcal{W}_k\) The set of constraints currently treated as equalities Changes dynamically across iterations; its size is usually far smaller than the total number of constraints
Search direction \(p_k\) The direction that decreases the objective under working-set constraints Obtained by solving the equality-constrained subproblem
Step size \(\alpha_k\) The distance moved along the search direction The smaller of 1 and the "distance to the nearest constraint hit"
Lagrange multiplier \(\mu_j\) Dual variable for an inequality constraint in the working set Used to decide whether a constraint should be removed from the working set
Termination condition Gradient projection onto the null space is zero + nonnegative multipliers Equivalent to the KKT conditions

Engineering Judgment: In humanoid robot whole-body control (WBC), QP problems are typically small in scale (tens to hundreds of decision variables) but must be solved in real time at 1 kHz or even higher frequencies. The active-set method, thanks to its warm-start capability—the solution from the previous control cycle can serve as the initial working set for the current cycle—has become the preferred choice for real-time solvers such as qpOASES. Interior-point methods (e.g., OSQP, ProxQP) are better suited for offline planning or scenarios requiring extremely high accuracy.

Who Uses It: Application Cases

qpOASES is one of the most famous engineering implementations of the active-set method, designed specifically for parametric QP solving in model predictive control (MPC). In the humanoid robotics domain, it is widely used for:

  • Whole-body motion control (WBC): Solving joint accelerations and contact forces in real time while satisfying dynamic equalities, friction-cone inequalities, and joint torque limits. The "low-level QP or MPC real-time tracking" mentioned in the corpus is precisely this scenario.
  • Model predictive control (MPC): In each receding-horizon optimization step, the QP structure (Hessian and constraint matrices) changes only slightly; the active-set method can leverage the working set from the previous time step as an initial guess, significantly reducing the number of iterations.
  • Trajectory optimization: In the middle layer of hierarchical planning, QPs are used to solve local trajectory correction problems.

Limitations and Boundaries

  1. Risk of combinatorial explosion: Although exhaustive enumeration is avoided, in the worst case the number of working-set exchanges can still grow exponentially with the number of constraints. For problems with extremely many constraints (e.g., more than \(10^4\)), interior-point methods are usually preferable.
  2. Applicable only to convex problems: For nonconvex QPs, the active-set method can only guarantee a locally optimal solution, and finite termination no longer holds.
  3. Requires an initial feasible point: The algorithm requires starting from a feasible point. If the initial point is infeasible, a Phase I procedure (solving an auxiliary LP or QP to find a feasible point) must be run first, which adds implementation complexity.
  4. Numerical stability: When the working-set constraints are nearly linearly dependent, the KKT matrix of the subproblem may become ill-conditioned, requiring regularization or more robust factorization methods.

Common Misconceptions

  1. "The active-set method is just the simplex method"—Both share the geometric intuition of "moving along constraint boundaries," but the simplex method targets linear programming, whereas the active-set method targets (typically convex) nonlinear programming, and the search direction at each iteration is determined by second-order information (the Hessian) of the objective, rather than simply moving along edges.
  2. "A larger working set is better"—An overly large working set increases the subproblem size and computational cost; what matters is whether the working set is accurate, not its size. A working set containing redundant constraints can lead to an incorrect search direction.
  3. "A negative multiplier must always be removed"—This holds only when the current point is optimal (\(p_k = 0\)). If \(p_k \neq 0\), one should first move along the search direction even if negative multipliers exist, rather than immediately adjusting the working set.
  4. "The active-set method is faster than interior-point methods"—This is a problem-size-dependent judgment. It holds in small- to medium-scale scenarios requiring warm-start; however, on large-scale sparse problems, interior-point methods are typically faster.
