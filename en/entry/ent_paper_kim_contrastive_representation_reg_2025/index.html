Summary

Contrastive Representation Regularization for Vision-Language-Action Models (RS-CL), is a 2025 large vision-language-action model for robotic manipulation, introduced by KAIST, UC Berkeley, RLWRLD.

Sources

  • Contrastive Representation Regularization for Vision-Language-Action Models (arXiv)
  • RS-CL source

概述

本文提出一种面向人-机器人协作（HRC）任务分配的新MILP公式，核心贡献在于将原始仅支持同步/协作的分配模型扩展为可建模多agent在同一工件上协同工作的场景。作者通过引入增强agent集合（含所有2-组合）及向量ID约束（公式8），在保持计算可行性的同时（P=(N+1)N/2），实现了对协作分配的显式建模，并设计了可用性成本函数（公式9）以权衡等待时间与任务适合度。该方法明确承认个体适合度无法保证团队表现，且新适合度指标设计超出本文范围，但为工业HRC场景提供了可扩展的分配框架。

它改变了什么

这篇论文真正改变的，不是又提出一种新的动作约束RL算法，而是把整个领域从“各说各话”推进到“可比较、可复现”的阶段。作者敏锐地指出一个被长期忽视的痛点：动作约束强化学习（action-constrained RL）在真实系统里关乎安全与可行性，但现有算法——DDPG、SAC这些主流方法——默认只能处理盒约束（box constraints），面对加权和上界、椭圆约束这类更复杂的可行集就束手无策。更关键的是，尽管已有可微优化层（DOpt）、NFWPO、α-projection等多种专门方法，却从未有人做过系统性的横向对比，研究者各自在自建环境上验证，结论难以互证，工程选型近乎盲人摸象。

作者把问题重新框定为：动作约束必须在整个训练过程中持续满足，而非仅训练结束时达标。这个视角的转变是实质性的——它把约束从“后处理修正”提升为“训练过程的硬性要求”，直接暴露了现有方法的理论漏洞。比如作者指出，DPro（用投影动作训练critic）在理论上不严谨，因为预投影动作的Q值定义不当；可微优化层存在零梯度问题（多个违规动作投影到同一点导致梯度消失）；而α-projection与SAC结合时，投影后概率密度可能变为无穷，需要重新定义测度。这些不是工程细节，而是方法论的根基缺陷。

作者真正的贡献在于两点：一是建立了首个包含13种算法的基准测试框架，覆盖TD3和SAC两大家族，在Reacher、Hopper、Walker2d、HalfCheetah四个环境上施加从线性加权和到椭圆约束的多样化约束组合，每个配置跑10个种子，这种规模在动作约束RL领域前所未有；二是提出了两个新组件——DPre（预投影动作训练critic的简单基线）和径向压缩层（Radial Squashing），后者在中心点处雅可比为单位矩阵，梯度在任何方向不消失，从构造上规避了零梯度问题。这改变了领域的研究范式：从此新算法不能再自说自话，必须在这个统一基准上证明自己。

方法拆解

问题形式化与动作约束的数学刻画

作者将问题建模为连续状态-动作MDP M = ⟨𝒮, 𝒜, T, d₀, d_R, γ⟩，每个状态 s 关联一个已知的可行动作集 𝒜_s ⊆ 𝒜，由线性或凸约束刻画。现有深度RL算法（DDPG、TD3、SAC）默认仅支持盒约束：策略以 tanh 作为最终激活层（squashing）将输出压缩至 [-1,1]，再线性缩放至 [-a_i^max, a_i^max]。这一机制无法处理加权和上界（如 Σ|w_i a_i| ≤ c）或椭圆约束。核心设计决策是引入映射函数 P: 𝒮×𝒜 → 𝒜_s，将策略原始输出投影到可行集，执行 P(s, μ_θ(s)) 而非原始动作。

六类映射方法的构建与关键设计决策

1. 最近点投影（DPro/DPre）
P_s(μ_θ(s)) = argmin_{a∈𝒜_s} ||a - μ_θ(s)||₂，对线性约束退化为二次规划。DPro用投影动作训练critic但actor更新不变（∇_θ Q_w(s_i, μ_θ(s_i))），作者明确指出这在理论上不严谨——预投影动作的Q值定义不当，且critic仅见过投影动作，难以外推。DPre则用预投影动作同时训练actor和critic，投影仅作为环境转移的一部分，计算效率更高但需经验学习投影效果。

2. 可微优化层（DOpt）
通过可微QP层（OptLayer）或凸优化层（PROF）计算雅可比 dP_s/dμ_θ(s)，actor更新变为 (1/N)Σ ∇_a Q_w(s_i,a)|_{a=P_s(μ_θ(s))} (dP_s/dμ_θ(s)) ∇_θ μ_θ(s_i)。关键缺陷是零梯度问题：多个违规动作投影到同一点导致梯度消失，需额外惩罚项 ||max{Ax-b,0}||（A归一化使每行范数为1）缓解。

3. NFWPO（Frank-Wolfe解耦）
将投影与actor更新解耦：critic训练同DDPG（用投影动作），actor通过Frank-Wolfe算法确定参考动作 a_s = P_s(μ_θ(s) + α(c_s - P_s(μ_θ(s))))，其中 c_s = argmax_{c∈𝒜_s} ⟨c, ∇_a Q_w(s,a)|_{a=P_s(μ_θ(s))}⟩，然后最小化 μ_θ(s) 与 a_s 的距离。这避免了雅可比计算和策略梯度，从根本上消除零梯度问题；无约束时退化为标准DDPG。

4. α-projection层
将动作沿从内部点 c_s 到 a 的射线移动至边界，不同射线上的点映射到不同点，梯度不消失。对线性约束有闭式解，以Chebyshev中心作为 c_s 并缓存复用；可扩展至椭圆约束 (a-c(s))ᵀQ(s)(a-c(s))-b(s)。

5. 径向压缩层（Radial Squashing，作者提出）
a ↦ c_s + tanh(||a-c_s||/||b-c_s||)(b-c_s)，其中 b 是可行集边界与射线的交点。在 c_s 处雅可比为单位矩阵，梯度在任何方向不消失，且计算开销远低于优化层。

与SAC结合的熵修正

SAC需计算映射后策略的概率密度。对可微映射 f，q(f(X)) = |det J_f(X)|⁻¹ p(X)。
- SAC+径向压缩：直接计算雅可比 (a-c_s)(grad tanh L/L)ᵀ + (tanh L/L)I，其中 L = ||a-c_s||/||b-c_s||。
- SAC+α-projection：投影后概率密度可能发散（雅可比行列式为零），作者将 𝒜_s 的测度分解为内部标准测度与边界黎曼子流形测度之和，熵为两部分熵之和；边界概率密度需积分 q dσ = ∫_{r₀}^∞ p r^{d-1} dr dΩ，对高斯分布可完成平方后用erf函数显式表达。
- 可微优化层+SAC：因最近点投影可将多维区域压缩至一点，概率分布变化难以确定，作者判定为不可行。

关键设计决策总结

  • 惩罚项设计：线性约束用 ||max{Ax-b,0}||（A归一化），椭圆约束用 max{√((x-c)ᵀQ(x-c)) - √b, 0}（Q归一化使tr Q等于维度），两者并存时取和。
  • 超参数敏感性：NFW的Frank-Wolfe学习率在Reacher调为0.05，其他环境0.01；TD3/SAC的折扣因子、网络宽度等均采用RL Baselines Zoo调优值。
  • 评估协议：每算法-约束组合10个种子，Reacher 3×10⁵步、其余10⁶步，每5000步评估5 episode，最终对最佳参数评估50 episode取均值。

关键创新

这篇论文的核心创新在于将动作约束强化学习从“单点修补”推进到“系统性基准与理论辨析”的层面，其价值主要体现在三点。

第一，首次构建了动作约束RL算法的全面基准框架。 此前DDPG、SAC等主流算法仅能处理盒约束，而可微优化层、NFWPO等方法虽各自提出，却缺乏统一比较。作者系统梳理了13种算法（TD3家族9种、SAC家族4种），覆盖线性、椭圆、加权和等7类约束，在4个连续控制环境上以10个种子进行严格评估。这一基准的稀缺性在于：它首次将“约束满足必须贯穿整个训练过程”作为评估前提，而非仅看最终结果，为后续研究提供了可复现的参照系（代码已开源）。

第二，提出两种新的映射机制，直击现有方法的梯度失效痛点。 可微优化层（DOpt）存在零梯度问题——多个违规动作投影到同一点导致梯度消失；NFWPO虽解耦了投影与actor更新，却牺牲了策略梯度信息。作者设计的径向压缩层（Radial Squashing） 通过围绕Chebyshev中心进行径向压缩，在中心点雅可比为单位矩阵，保证任意方向梯度不消失，且计算开销远低于QP求解。这一设计在数学上优雅地绕过了非光滑投影的梯度困境，是方法层面的实质性突破。

第三，首次系统处理了SAC与复杂约束结合的熵估计难题。 当动作经映射后，概率密度需乘以雅可比行列式的逆。作者指出可微优化层与SAC结合可能不可行（多维区域映射到一点导致密度发散），但为径向压缩和α-projection分别推导了闭式雅可比与边界测度分解公式。这一理论贡献填补了熵正则化RL在约束映射下的空白，使SAC家族能无缝接入动作约束场景，而非仅依赖TD3框架。

值得注意的是，作者坦诚承认DPro的理论不严谨性（预投影动作Q值定义不当）和ConstraintNet的维度灾难问题，这种批判性视角反而增强了基准的可信度。整体而言，该工作为动作约束RL提供了“地图”与“新工具”，而非简单堆砌算法对比。

实验与结果

实验部分的核心是构建首个动作约束RL算法的系统基准，覆盖13种算法、4个连续控制环境与13种约束组合。算法分为TD3家族（DPro、DPro+、DPre、DPre+、DOpt、DOpt+、NFW、DAlpha、DRad）与SAC家族（SPre、SPre+、SAlpha、SRad），其中DPre与DRad为作者提出的新基线。约束类型涵盖无额外约束（R+N）、L2范数（R+L2）、加权L1（R+O03/O10/O30）、单侧加权和（R+M）、椭圆约束（R+T）以及多约束组合（如H+O+S、W+O+S），以检验算法对线性与凸约束的泛化能力。

每个算法-约束组合运行10个随机种子，Reacher环境训练3×10⁵时间步，其余环境为10⁶步；每5000步评估5个episode，最终对最佳参数再评估50个episode取均值。超参数按环境分组调优（表I），例如Reacher中TD3折扣因子0.98、SAC为0.99，Hopper与其余环境统一为0.99；学习率从1e-3（TD3/Reacher）到3e-4（SAC/Hopper）不等。NFW的Frank-Wolfe学习率在Reacher调为0.05，其他环境0.01。实现基于Stable Baselines 3与PyTorch，线性/二次规划用gurobi求解，可微优化层用cvxpylayers。

实验设计的关键洞察在于区分两类训练策略：DPro类方法在critic训练时使用投影动作，理论上不严谨但实现简单；DPre类方法用预投影动作训练critic，投影仅作为环境转移的一部分，计算效率更高且易与SAC结合。DOpt类方法通过可微优化层传播梯度，但面临零梯度问题——多个违规动作投影到同一点导致梯度消失，需额外惩罚项缓解。NFW通过Frank-Wolfe算法确定参考动作，完全规避雅可比计算，但无约束时等价于DDPG，性能上限受限于基础算法。

SAC家族的特殊挑战在于熵项需要映射后策略的概率密度。对可微映射f，密度变换为q(f(X)) = |det J_f(X)|⁻¹ p(X)。SRad直接计算径向压缩的雅可比闭式表达式，而SAlpha需将可行集测度分解为内部标准测度与边界黎曼流形测度之和，对高斯分布可用erf函数显式表达。可微优化层与SAC结合被认为可能不可行，因为最近点投影可将多维区域压缩为一点，概率分布变化难以确定。

实验未纳入ConstraintNet，因其顶点数随动作维度指数增长且难以扩展到状态相关约束。作者明确承认未处理除椭圆约束外的状态相关约束，也未探索线性/凸约束之外的类型。整体基准设计强调动作约束必须在整个训练过程中满足，而非仅训练结束时，这直接影响了DPre与DPro在训练动态上的本质差异——前者让critic学习不可行动作的值，后者则完全回避该问题但牺牲理论严谨性。

边界与局限

本文的边界与局限首先体现在问题形式化层面：作者仅考虑线性或凸约束刻画的可行动作集，对非凸、离散或状态依赖的复杂约束（除椭圆约束外）未做处理；ConstraintNet因顶点数随动作维度指数增长且难以扩展至状态相关约束，被明确排除在评估之外。这意味着结论的适用范围被严格限定在凸约束连续动作空间内。

方法层面存在多处理论不严谨或工程折衷。DPro用投影动作训练critic，作者承认预投影动作的Q值定义不当，critic难以学习其价值；DPre虽计算高效，但agent需通过经验隐式学习投影效果，且可能遭遇零梯度问题。可微优化层（DOpt）计算开销大且存在零梯度问题，需额外惩罚项缓解。α-projection与SAC结合时，边界测度权重取值任意且非尺度不变，作者简单取1，这实质引入了未调优的超参数；而可微优化层与SAC结合被认为可能不可行，因为最近点投影可将多维区域映射到一点，概率密度变化难以确定。

实验验证的边界同样值得注意：所有评估基于PyBullet-Gym和MuJoCo仿真环境，未涉及真实机器人系统；每个算法-约束组合仅运行10个种子，统计功效有限；Reacher仅3×10⁵时间步，其他环境10⁶步，对SAC家族这类样本效率较低的算法可能不够充分。作者未评估ConstraintNet，也未探索除线性/凸约束外的约束类型，因此对更广泛约束场景的泛化能力未经验证。此外，硬件配置未明确，计算时间比较的绝对数值缺乏可复现的硬件基准。

工程启示

工程启示：复现与选型的第一性检查

先核对约束类型与动作维度的匹配度。论文所有结论建立在线性不等式（加权和上界）与椭圆约束上，若你的下游任务含状态相关约束（如避障锥、关节限位耦合），文中方法（除椭圆特例外）均未覆盖，直接套用会踩空。复现时优先确认：约束是否可写成 Ax ≤ b 或 (x-c)ᵀQ(x-c) ≤ b 形式，且 A 每行需归一化（范数为1）、Q 需满足 tr Q = d，否则惩罚项量纲失衡，训练直接发散。

最容易踩坑的三处：

  1. DPro 的 critic 训练陷阱：用投影动作训练 critic 但 actor 更新仍用预投影动作，论文明确指出这“理论上不严谨”，实际表现为 Q 值震荡。若选 DPro，务必加惩罚项 ||max{Ax-b,0}||，且监控预投影动作的 Q 值是否异常——这是复现时最先崩的地方。

  2. 可微优化层（DOpt）的零梯度：多个违规动作投影到同一点时雅可比消失，梯度直接归零。复现需用 cvxpylayers 且必须加惩罚项，否则训练中期 loss 停滞。计算开销大，Reacher 尚可，HalfCheetah（d=6）下每步多一次 QP 求解，建议先跑通小维度再扩展。

  3. SAC 家族的熵项：SAC+α-projection 的边界测度权重是任意超参数（论文取1），且非尺度不变；SAC+径向压缩需手动实现雅可比 (a-c_s)(grad tanh L/L)ᵀ + (tanh L/L)I，公式错一个符号概率密度就错。若团队不熟微分几何，直接选 SPre（预投影+投影进环境）最稳，计算最省，但需接受“经验学习投影效果”的局限。

选型建议：追求理论严谨选 NFWPO（Frank-Wolfe 解耦，无零梯度），但需调 FW 学习率（Reacher 0.05，其他 0.01）；追求计算效率选 DPre/SPre，投影只在 rollout 时执行；追求梯度不消失选径向压缩（DRad/SRad），但仅限线性约束。所有方法基于 SB3+PyTorch，超参表（表I）可直接复用，但注意 Reacher 的折扣因子 0.98 与其他环境 0.99 不同，复制时别混。代码在 github.com/omron-sinicx/action-constrained-RL-benchmark，先跑通 Reacher 再上高维。
