Overview

System Identification and Parameter Calibration is a critical process node in the motion control algorithm development and validation phase (P10.3). Its core mission is to estimate the robot's true dynamic parameters from experimental data, narrowing the gap between simulation and reality. What it truly changes is not the accuracy of a single simulation, but the credibility of the entire sim-to-real transfer chain—without a calibrated model, even the best control algorithm is nothing more than a castle in the air.

Content

What It Is: Precise Definition

System Identification and Parameter Calibration is a methodological framework for estimating a robot's true dynamic parameters (mass, center of mass, inertia tensor, friction, actuator gains, and delays) from experimental data. Its core mathematical fact is that rigid-body dynamics equations are linear in these parameters—\(\boldsymbol{\tau} = \mathbf{Y}(\mathbf{q},\dot{\mathbf{q}},\ddot{\mathbf{q}})\,\boldsymbol{\pi}\)—allowing the minimum parameter set to be solved from torque-motion data via least squares. It is the common prerequisite for the sim-to-real "gap reduction" approach and high-fidelity model-based control (MPC/WBC).

At the engineering process level, this node belongs to the P10.3 Sim-to-Real and Testing work package, unfolding into five third-level subtasks: input organization and target quantification (P10.3.1.1), approach/method design (P10.3.1.2), implementation/prototype/sample fabrication (P10.3.1.3), validation and issue closure (P10.3.1.4), and documentation output and downstream delivery (P10.3.1.5). Each subtask is further broken down into several fourth-level key actions, forming a complete engineering loop.

Why It Exists: Pain Points and Historical Positioning

In the early stages of humanoid robot development, simulation parameters often directly adopted theoretical values from CAD models, while actual hardware involves uncertainties such as machining tolerances, assembly errors, friction nonlinearities, and cable drag. These discrepancies cause control algorithms that perform excellently in simulation to fail on real hardware—the classic "works in simulation, falls in reality" dilemma.

System Identification and Parameter Calibration exists precisely to address this pain point. Its historical positioning can be summarized as: after the hardware platform is finalized and before full-system integration testing, it translates the physical system's true characteristics into model parameters usable by control algorithms. Without this step, subsequent compliant control and whole-body control (WBC) are built on incorrect model assumptions, and debugging costs escalate exponentially.

Principle Breakdown

① Linear Regression: The Mathematical Essence of Dynamic Parameters

The standard robot dynamics equation is:

\[ \boldsymbol{\tau} = \mathbf{M}(\mathbf{q})\ddot{\mathbf{q}} + \mathbf{C}(\mathbf{q},\dot{\mathbf{q}})\dot{\mathbf{q}} + \mathbf{g}(\mathbf{q}) \]

where \(\mathbf{M}\) is the inertia matrix, \(\mathbf{C}\) is the Coriolis/centrifugal term, and \(\mathbf{g}\) is the gravity term. The key property is that this equation is linear in the dynamic parameters (mass, center-of-mass position, inertia tensor elements) and can be rewritten as:

\[ \boldsymbol{\tau} = \mathbf{Y}(\mathbf{q}, \dot{\mathbf{q}}, \ddot{\mathbf{q}}) \, \boldsymbol{\pi} \]

\(\mathbf{Y}\) is the regression matrix, and \(\boldsymbol{\pi}\) is the parameter vector to be identified. This means that by collecting multiple (motion state, torque) data pairs, the parameters can be solved directly using least squares—no iterative optimization required, with high computational efficiency and global convergence.

② Excitation Trajectory Design: The Prerequisite for Identifiability

Parameter identifiability depends on the column rank of the regression matrix \(\mathbf{Y}\). If the excitation trajectory is insufficient (e.g., joint motion range too small, speeds too low), some parameters become unidentifiable or have extremely poor identification accuracy. In engineering, Fourier series trajectories are commonly used as excitation signals, offering rich frequency content and controllable amplitudes that effectively excite various dynamic terms. A key constraint is excitation signal safety—trajectory amplitude, velocity, and acceleration must be limited to the hardware's allowable range to avoid damaging actuators or triggering safety protections.

③ Friction and Inertia Identification: Engineering Handling of Nonlinear Terms

Friction models typically use Coulomb + viscous friction form: \(\tau_f = f_c \cdot \text{sign}(\dot{q}) + f_v \cdot \dot{q}\). Inertia identification requires constant-velocity segments to separate inertial and friction terms. Engineering practice often employs a segmented identification strategy: first identify friction parameters at low speeds, then inertia parameters at high speeds, and finally cross-validate using frequency-domain identification.

Who Uses It · Application Cases

This process node has broad application scenarios in humanoid robot development. In the motion control algorithm development and validation phase (P10.3), System Identification and Parameter Calibration serves as the key bridge connecting simulation and reality. Specific applications include:

  • Dynamic model feedforward control: Identified parameters are used to compute feedforward torques, significantly reducing the burden on feedback control and improving tracking accuracy.
  • MPC/WBC model updates: Whole-body control (WBC) relies on accurate dynamic models; identification results directly update model parameters.
  • Simulation environment calibration: Identified parameters are fed back into the simulation environment, making simulated behavior closer to reality and improving sim-to-real transfer success rates.
  • Fault diagnosis: When identified parameters deviate excessively from nominal values, it can indicate mechanical wear, loose assembly, or other anomalies (referencing the causal diagnosis approach of the CARE method).

Limitations and Boundaries

System Identification and Parameter Calibration is not a panacea, and its limitations must be clearly recognized:

  1. Limited parameter identifiability: Certain parameters (e.g., cross-terms of link inertia tensors) are difficult to identify independently under conventional excitation, requiring special trajectory design or dimensionality reduction.
  2. Model errors cannot be eliminated: Identification can only narrow the gap between model and reality, not eliminate it entirely—unmodeled dynamics (e.g., flexibility, hysteresis) always remain.
  3. Excitation signal safety constraints: Overly strong excitation may damage hardware or trigger safety protections, limiting the upper bound of identifiable parameter accuracy.
  4. Time-varying parameter issues: Parameters such as friction and temperature change over time; single identification results may quickly become invalid, requiring periodic recalibration.

Common Misconceptions

  1. "Identify once and done"—Wrong. Friction changes with temperature and wear, inertia changes with load; a periodic recalibration mechanism must be established.
  2. "Stronger excitation means better identification"—Wrong. Overly strong excitation may excite nonlinear effects (e.g., flexible modes), actually reducing model accuracy and posing safety risks.
  3. "Least squares is the only method"—Wrong. Least squares is sensitive to noise; in low signal-to-noise ratio scenarios, maximum likelihood or frequency-domain identification is superior.
  4. "The identification report is just documentation"—Wrong. The frequency response comparison in the identification report is core evidence for validating model quality and a critical input for downstream dependents (e.g., WBC development).
