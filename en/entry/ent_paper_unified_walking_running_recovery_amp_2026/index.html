Summary

We propose a unified reinforcement learning framework that enables a single policy to perform walking, running, and fall recovery on the Unitree G1 humanoid robot, validated on physical hardware without any explicit mode-switching command at deployment. Institutions per source list: 香港大学等.

Overview

This paper proposes a unified humanoid robot control framework based on State-Dependent Adversarial Motion Priors, which achieves end-to-end learning of walking, running, and fall recovery under a single actor policy by switching between recovery and locomotion discriminators via a gating function. The authors validate the complete sequence from prone/supine recovery to walking/running on the Unitree G1, without requiring explicit mode switching at deployment time.

What It Changes

Traditional humanoid robot control treats walking, running, and recovery as independent modules coordinated by hand-crafted FSMs, leading to fragile mode boundaries and degraded switching quality. While existing AMP methods can learn end-to-end, a single shared motion prior cannot simultaneously capture the dynamics of high-speed running and recovery—either losing running statistics or confusing recovery with locomotion distributions. What this paper truly changes is transforming "modes" from an architectural design problem into a discriminator conditioning problem: continuously interpolating walking/running reference distributions via velocity commands, and gating recovery modes via projected gravity. This enables a single policy to cover all three behaviors without any mode logic at inference time. This eliminates hand-tuned transition logic, making mode switching an implicit learned behavior.

Method Breakdown

Overall Architecture

  • A single actor policy πθ(a_t|o_t), trained end-to-end, deployed as a frozen ONNX model with no runtime mode logic.
  • The observation o_t is 96-dimensional (body angular velocity, projected gravity, commanded velocity, relative joint positions/velocities, previous action), concatenated over 4 frames of history to yield a 384-dimensional input; the action a_t ∈ ℝ²⁹ is target joint positions tracked by a low-level PD controller.

Dual Discriminator Design

  • Recovery discriminator D_φ^rec: trained only on fall recovery reference clips (fallAndGetUp2_subject2).
  • Velocity-conditioned locomotion discriminator D_φ^loco: additionally takes normalized commanded velocity v̂_t = min(v_x^cmd / v_max, 1) as input, trained jointly on walking (walk1_subject1) and running (run1_subject2) references. At each discriminator update, walking references are sampled with probability (1−v̂_t) and running references with probability v̂_t, achieving condition-consistent distribution interpolation.

Gating Mechanism

  • The gating function z_t = rec when |g_z + 1| > 0.6, otherwise loco, where g_z is the projected gravity z-component (≈ −1 when upright, near 0 or positive when fallen).
  • The threshold corresponds to approximately 37° of tilt, located in the low-occupancy region of the bimodal gravity signal, providing accurate noise robustness without learning.
  • Key design: gating is active only during training; at inference, the policy is a single integrated network with no explicit mode variables.

Training Objective

  • Task reward (Eq. 1): R_t = w_v·R_cmd + w_s·R_smooth + w_p·R_posture − w_e·C_energy − w_f·C_fall.
  • AMP reward (Eq. 3): R_AMP = −log(1 − D_φ^rec(s_t, s_t+1)) when z_t = rec; R_AMP = −log(1 − D_φ^loco(s_t, s_t+1|v̂_t)) when z_t = loco.
  • Total reward (Eq. 4): R_t^total = R_t + λ_amp·R_AMP, with λ_amp = 0.5.
  • Training algorithm: PPO, three-layer MLP, Isaac Lab simulation.

Key Innovations

  1. Velocity-conditioned discriminator replacing multi-mode priors: Continuous interpolation between walking/running references via v̂_t avoids training multiple locomotion discriminators or manually defining mode boundaries. This is a key extension to the AMP framework—encoding behavioral modes as conditioning variables rather than discrete modules.
  2. Simplicity of projected gravity gating: Leveraging the naturally bimodal distribution of the gravity signal, a fixed threshold (37°) implements recovery/locomotion discriminator switching without learning a gating network. It is active during training and omitted at inference, ensuring a clean deployment policy.
  3. Minimal reference data: Only 3 LAFAN1 clips (1 walking + 1 running + 1 recovery) suffice to cover three behaviors, demonstrating that conditioned discriminators can efficiently utilize limited reference data and reduce dependence on large-scale motion libraries.

Implications of results: Hardware experiments demonstrate that a single policy can complete the full "recovery→walking→running" sequence without mode-switching commands, with gait characteristics consistent with biomechanical expectations. Fast mode requires explicit operator commands to enable, which the authors describe as an "intentional safety constraint."

Boundaries and Limitations

The paper does not explicitly discuss limitations. Identifiable boundaries: fast mode relies on explicit operator commands (not autonomous decision-making); the gating threshold (37°) lacks systematic sensitivity analysis; no validation for additional fall postures such as side-lying, and no testing on complex terrain like stairs or slopes; velocity range does not exceed 3.0 m/s; no quantitative comparison against FSM-coordinated modular baselines. Training data volume, training duration, and hardware specifications are not mentioned.

Engineering Insights

When reproducing, prioritize checking three points: gating threshold (|g_z + 1| > 0.6)—whether the gravity signal distribution on the target robot remains bimodal; if sensor noise or mounting deviations shift the distribution, recalibration is needed; velocity-conditioned interpolation (v̂_t)—the v_max setting directly affects the sampling ratio between walking/running references and must match the commanded velocity range; reference data retargeting quality—with only 3 clips, if inverse kinematics retargeting to the target robot's joint space introduces kinematic distortions, the discriminator will learn incorrect priors. The most common pitfall is the difference between gating active during training and omitted at inference: ensure no mode variables remain in the deployment code, otherwise the policy input distribution will mismatch training. Downstream teams seeking to extend the velocity range or add new behavioral modes should prioritize adjusting the v̂_t conditioning scheme rather than increasing the number of discriminators.
