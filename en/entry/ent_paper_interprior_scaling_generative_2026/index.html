Summary

InterPrior: Scaling Generative Control for Physics-Based Human-Object Interactions is a 2026 work on physics-based character animation for humanoid robots.

Sources

  • InterPrior: Scaling Generative Control for Physics-Based Human-Object Interactions (arXiv)

概述

InterPrior 是一个面向物理仿真人-物交互（HOI）的生成式控制框架，由三阶段构成：全参考模仿专家（InterMimic+）、变分蒸馏为掩码条件潜变量策略、以及强化学习后训练。其核心贡献在于将大规模模仿学习与稀疏目标条件下的生成控制解耦，使策略在保持轨迹跟随能力的同时，获得对未见配置、新交互技能（如起身）和跨数据集微调的鲁棒性。

它改变了什么

现有 HOI 运动生成研究长期被一个矛盾困住：要么依赖显式规划器提供密集的全身与物体参考轨迹，要么用对抗式分布匹配加 RL 的生成式控制器，但后者在规模上难以扩展，存在优化不稳定与判别器模式崩溃。InterMimic 这类全参考模仿器虽然能吸收大规模数据，却在参考覆盖不足时（如移动操作中物体自由度导致的组合爆炸）变得脆弱，面对薄物体或初始化扰动时成功率骤降。

InterPrior 真正改变的是“控制目标”的定义方式。它不再要求策略复现一条完全指定的轨迹，而是从稀疏目标（如一个远未来快照、一组短视距预览、或仅接触信息）出发，让策略在潜空间中自主采样可行的交互行为。这相当于把“模仿”降级为训练手段，把“生成式控制”提升为最终目标，从而将任务覆盖从“参考覆盖了什么”扩展到“配置空间允许什么”，并首次在物理仿真中实现了从跌倒状态起身这类完全无参考数据的新技能学习。

方法拆解

三阶段范式

  1. InterMimic+ 专家训练：在 InterMimic 基础上扩展，使用 PPO 训练全参考模仿策略 π_E。关键改动包括：初始化时对人体和物体姿态施加随机变化，滚动中施加稀疏脉冲扰动；引入参考无关手部奖励 r_h = exp(−w_h e_h)，其中 e_h 衡量拇指与其余指尖指向物体表面最近点的方向一致性，w_h 随手-物距离减小而增大；终止惩罚 r_ter 由跌倒或状态大偏差触发。完整奖励为 r_t = (r_track × r_energy × r_h) + r_ter。

  2. 变分蒸馏：将专家蒸馏为掩码条件变分策略。策略由三部分组成：

  3. 先验 p_ψ(z_t | x_{t−ℓ:t}, G_t)：四层 Transformer 编码器，4 个注意力头，潜在维度 512，前馈宽度 1024；
  4. 编码器 q_ϕ(z_t | x_t, G_t, y_{t:t+H}, y_{t+L})：仅训练时使用的 MLP；
  5. 解码器 f_θ(a_t | x_{t−ℓ:t}, z_t)：MLP，隐藏层 (1024, 1024, 512)。

训练时采用残差后验 N(μ_p + μ_q, Σ_q)，重参数化采样 z_t = (μ_p + μ_q) + Σ_q^{1/2}ε，ε 在 episode 内固定以促进时间一致性。推理时仅用先验采样，并投影 z_t ← z_t/‖z_t‖ 使策略在超球面上操作。总损失 L_total = L_ELBO + λ_scale·L_scale + λ_tc·L_tc，其中 L_scale = E_t[(‖μ_{p,t}‖₂ − 1)²] 约束先验均值单位幅度，L_tc 用高斯分布间平方 2-Wasserstein 距离惩罚连续时间步先验变化。蒸馏采用 DAgger 在线框架，从教师完全控制轨迹开始，逐步增加学生驱动比例至 95%。

  1. RL 后训练：将微调表述为插值任务——策略从随机初始配置向数据集中随机抽取的单帧目标跟踪。奖励 r_t^PT = (r_energy × r_h) + r_goal + r_ter，其中 r_goal 为稀疏成功信号，当掩码特征距离 ‖m_{t+L} ⊙ Δ(ỹ_{t+L}, x_t)‖₁ < τ 时激活。分布内新技能（如重新抓取）通过目标条件插值自然涌现；分布外技能（如起身）需显式学习，追加可学习 token 并添加辅助奖励 r^{getup} = w_{height}·σ(h_t − h_{target}) + w_{upright}·σ(n_t · n_{up})，h_{target} = 0.7。为缓解灾难性遗忘，环境分为两组：RL 环境仅用后训练奖励优化，蒸馏环境继续用 ELBO 目标由专家监督，策略参数共享，梯度同步聚合。

目标条件化与掩码设计

  • 观测空间 x_t = [r_t^h, θ_t^h, ṙ_t^h, θ̇_t^h, r_t^o, θ_t^o, ṙ_t^o, θ̇_t^o, D_t, C_t]，包含人体/物体运动学、符号距离场 D_t 和接触 C_t。
  • 短视距预览：偏移集合 K = {1, 2, 4, 16}；长视距快照：偏移 L ∈ [1, 128]，训练时随机初始化，每步递减，归零后重采样。
  • 训练时掩码按刚体级别独立采样：人体状态和交互分量以概率 0.1 揭示，物体分量以概率 0.5 揭示，掩码随时间遵循一阶马尔可夫过程，p_reset = 0.01。
  • 推理时通过掩码提示工程定义任务：快照条件仅揭示长视距快照；轨迹条件揭示短视距预览并保留长视距快照；接触条件仅揭示接触条目、关联 SDF 和相关人体部位。多目标链通过拼接不同数据序列提取，仅对齐人体根位置（不含高度）和绕垂直 z 轴朝向。

关键创新

  1. 潜变量整形与有界化：将先验均值正则化到单位超球面（L_scale），并引入时间一致性损失（L_tc），解决了生成式控制器在蒸馏中常见的潜变量坍缩或爆炸问题。这不是简单的技巧堆叠——它使策略在超球面上操作，显著提升了长时域行为和随机初始化下的鲁棒性（表 1 中压力测试成功率从 92.4 提升至 94.6，长时域 E_o 从 5.3 降至 2.5）。

  2. RL 后训练与蒸馏并行：将微调表述为插值任务，而非直接优化新技能奖励。通过环境分组（RL 组 + 蒸馏组）并行优化，既学习了分布外技能（起身），又保持了原有轨迹跟随能力（表 1 中轨迹跟随 Succ 从 71.9 提升至 90.7）。这解决了生成式控制器微调中普遍存在的灾难性遗忘问题。

  3. 掩码提示工程：推理时不改变策略参数，仅编辑目标 G_t 即可实现任务切换。例如，当轨迹跟随中状态滞后时，移除轨迹目标并将最近路径点重新定义为快照目标；当人-物目标矛盾时，将人体根目标设为当前物体位置并掩码所有其他关节，鼓励自然的重新接近行为。这使单一策略无需重新训练即可支持多种交互模式。

实验与结果

实验在 IsaacGym 中进行，控制频率 30 Hz，仿真步长 1/60 s。数据集使用 InterAct 的 OMOMO 子集，泛化性评估使用 BEHAVE 和 HODome。

关键结论：潜变量整形损失在分布内任务上改进适度，但在长时域和随机初始化下增益明显；RL 微调主要增强鲁棒性，在压力测试上改进更显著。轨迹跟随保持的两个原因：(I) 微调不改变轨迹条件输入下的模型（由并行蒸馏损失保护）；(II) 偏离目标轨迹时重新定义快照目标，轨迹跟随隐式受益于快照目标跟随的 RL 微调。跨数据集上，InterPrior + finetuning 在 BEHAVE 上达到 52.0 成功率，HODome 上 72.4，显著优于 InterMimic 直接微调（38.9 和 55.5）。

边界与局限

论文明确排除了以软体动力学为主的交互（如背包肩带），G1 人形机器人排除了薄几何物体（因无灵巧手支持单手抓取）。未随机化驱动参数或添加观测噪声，作者认为这些不直接增强状态或动力学覆盖。分布外技能（如起身）必须显式学习，因为所需行为在数据集中不存在。未做真实机器人部署实验，仅进行 sim-to-sim 转移评估（IsaacGym 到 MuJoCo）。

失败模式包括：训练中未见过的极薄或细长物体；多目标链中规范化引入大的对齐差异，导致策略偏向保持平衡而非实现精确目标配置。模型针对刚体物体设计，仍会出现浅层相互穿透、脚滑步等伪影，以及长 rollout 中物体掉落。当前手部和接触表示不适用于细粒度手指灵巧操作或手中操作。三阶段训练引入了额外复杂性和超参数。

工程启示

复现 InterPrior 时，最先要核对的是掩码采样逻辑：训练时掩码按刚体级别独立采样（人体 0.1、物体 0.5），且随时间遵循一阶马尔可夫过程（p_reset = 0.01）。如果掩码采样与论文不一致，蒸馏出的潜变量策略会在推理时出现严重的分布偏移。其次是潜变量归一化——采样后必须投影 z_t ← z_t/‖z_t‖，否则策略在超球面上操作的假设不成立，长时域行为会退化。

最容易踩坑的地方是 RL 后训练的环境分组。论文强调 RL 组和蒸馏组并行优化、梯度同步聚合，如果只跑 RL 组而忽略蒸馏组，轨迹跟随能力会迅速崩溃。建议先复现表 1 的消融路径：先确认 InterPrior 基线（74.9 任务内 Succ），再加 Latent Shaping（89.1），再加 Bounded Latent & Obs（90.0），最后加 RL Finetuning（90.0），每一步的增益来源清晰可查。

对于下游团队，如果目标是跨数据集增量学习（如从 OMOMO 迁移到 BEHAVE），InterPrior + finetuning 的范式（52.0 vs 27.4 成功率）值得采用，但需注意新数据集的状态应作为额外长时程目标和 RL rollout 的初始化来源，蒸馏组继续正则化到原始先验。推理效率方面，策略推理仅 0.43 ms，总运行时约 39.8 ms（观测 20.16 ms + 物理 19.02 ms），具备实时部署潜力，但观测和物理开销远大于策略本身，优化时应优先考虑这两部分。
