Overview

The Shooting Method is a numerical technique for solving two-point Boundary Value Problems (BVPs). Its core idea is to transform the boundary value problem into an Initial Value Problem (IVP) through iterative solving. What it truly changes is not the choice of solver, but rather the conversion of the global constraint of "satisfying boundary conditions" into a local iterative process of "adjusting the initial guess," thereby making boundary value problems, which cannot be solved directly, tractable.

Content

What It Is: A Precise Definition of the Shooting Method

The Shooting Method belongs to the method category, within the domain of AI models and algorithms (07_ai_models_algorithms), at the intelligence layer of the value chain. Its English name is Shooting Method, and its Korean name is 슈팅 방법.

Mathematically, the Shooting Method addresses two-point boundary value problems of the following form: given system dynamics \(\dot{x}(t) = f(t, x(t), u(t))\), with boundary conditions \(x(t_0) = x_0\) and \(x(t_f) = x_f\), where \(t_0\) and \(t_f\) are the initial and terminal times, respectively. The basic strategy of the Shooting Method is: first, guess the unknown components of the initial state (the "shooting angle"), then integrate the system dynamics forward from \(t_0\), and check whether the terminal state satisfies \(x(t_f) = x_f\). If not, adjust the initial guess based on the terminal error and repeat the integration until convergence.

This process closely resembles the trial-and-correction logic of artillery firing: fire a shot, observe the impact point deviation, then adjust the barrel angle—hence the name "Shooting Method."

Why It Exists: Pain Points and Historical Positioning

Boundary value problems are ubiquitous in robotics: two-point boundary value problems in optimal control, start and end state constraints in trajectory planning, and periodic boundary conditions in gait planning. However, boundary value problems cannot be solved directly through a single integration like initial value problems—the terminal constraint means the solution must satisfy conditions at both ends, which is essentially an implicit equation solving problem.

Before the Shooting Method emerged, engineers primarily relied on analytical methods or trial-and-error for boundary value problems. Analytical methods are only effective for a very few linear or special nonlinear systems; trial-and-error relies entirely on experience, lacking systematic rigor and convergence guarantees. The historical significance of the Shooting Method lies in its first transformation of boundary value problems into a low-dimensional root-finding problem—requiring only the solution of the terminal error function \(F(s) = 0\), where \(s\) is the initial guess vector and \(F\) is the terminal error vector. This transformation allows mature root-finding algorithms such as Newton-Raphson to be applied directly, thereby incorporating the solution of boundary value problems into the unified framework of numerical analysis.

Principle Breakdown

① Transformation from Boundary Value Problem to Initial Value Problem

Consider a two-point boundary value problem for a system of first-order ordinary differential equations:

\[ \dot{x}(t) = f(t, x(t)), \quad t \in [t_0, t_f], \quad g(x(t_0), x(t_f)) = 0 \]

where \(g(\cdot, \cdot)\) is the boundary condition function. Assume the system state dimension is \(n\) and the number of boundary conditions is \(n\) (i.e., the number of constraints equals the number of states, making the problem well-posed). Split the boundary conditions into known parts at the initial end and unknown parts: let \(x(t_0) = x_0(s)\), where \(s \in \mathbb{R}^k\) is the undetermined initial guess parameter (\(k\) is the number of unknown initial states), and \(x_0(s)\) is a known functional relationship. Integrate the system from this initial state to \(t_f\) to obtain the terminal state \(x(t_f; s)\), and define the terminal error function:

\[ F(s) = h(x(t_f; s)) \]

where \(h(\cdot)\) is the residual function of the terminal boundary condition. The original boundary value problem is thus transformed into a root-finding problem for \(F(s) = 0\).

② Iterative Solving and Sensitivity Propagation

The standard method for solving \(F(s) = 0\) is Newton-Raphson iteration. Given the current guess \(s^{(k)}\), the iteration scheme is:

\[ s^{(k+1)} = s^{(k)} - \left[ J_F(s^{(k)}) \right]^{-1} F(s^{(k)}) \]

where \(J_F = \partial F / \partial s\) is the Jacobian matrix of the terminal error with respect to the initial guess (i.e., the sensitivity matrix). This matrix can be obtained through propagation of the variational equation: let \(\Phi(t) = \partial x(t) / \partial s\), then \(\Phi(t)\) satisfies:

\[ \dot{\Phi}(t) = \frac{\partial f}{\partial x}(t, x(t)) \, \Phi(t), \quad \Phi(t_0) = \frac{\partial x_0}{\partial s} \]

By integrating the variational equation simultaneously with the system dynamics from \(t_0\) to \(t_f\), we obtain \(J_F = \partial h / \partial x \cdot \Phi(t_f)\). This approach of "integrating state and sensitivity simultaneously" allows each iteration to obtain complete gradient information with only one forward integration, avoiding the additional computational cost of finite differences.

③ Step Size Control and Convergence

The convergence of the Shooting Method depends on the quality of the initial guess. If the initial guess is too far from the true solution, Newton iteration may diverge. Common mitigation strategies in engineering include: damped Newton methods (multiplying the iteration step by a decay factor), homotopy methods (gradually transitioning from relaxed to strict boundary conditions), and multiple shooting methods (dividing the time domain into segments, shooting each segment independently with continuity constraints imposed). Among these, the multiple shooting method significantly reduces the sensitivity of a single integration to initial errors by splitting the long integration interval into multiple shorter intervals, making it the most robust variant in engineering applications.

Direct Collocation Discretizes all states and controls High (\(n \times N\)-dimensional) Low (global algebraic constraints) Satisfied explicitly through NLP constraints

The core advantage of the Shooting Method lies in its low variable dimension—only the initial guess parameters need to be optimized, making the per-iteration computational cost significantly lower than direct collocation. However, its trade-off is that the error amplification effect of single-segment integration results in a smaller convergence radius, making it particularly sensitive to strongly nonlinear systems or long-horizon problems. Direct collocation sacrifices variable dimension for robustness to initial guesses by discretizing dynamics constraints into algebraic constraints, but the scale of the NLP problem correspondingly increases. Engineering judgment: for problems with short horizons (e.g., single-step planning, approximately 0.5–1 second) and relatively smooth dynamics, the Shooting Method is advantageous due to its low dimensionality and high accuracy; for problems with long horizons or strong nonlinearity (e.g., whole-body motion planning for legged robots), direct collocation is more reliable.

Who Uses It: Application Cases

In the field of humanoid robotics, the Shooting Method is primarily applied in the following scenarios:

  1. Single-step trajectory planning: Given a starting posture and a target posture, solve for the optimal trajectory satisfying dynamics constraints. Since the single-step horizon is short (typically 0.5–1 second), the low-dimensional advantage of the Shooting Method is fully leveraged, and terminal accuracy is high (reaching \(10^{-8}\) order of magnitude, to be confirmed by user), making it suitable for tasks with strict landing point accuracy requirements.

  2. Periodic gait generation: Walking gaits require the states of adjacent step cycles to be identical (periodic boundary conditions), which is naturally a two-point boundary value problem. The Shooting Method generates stable periodic gaits by adjusting the initial state guess so that the terminal state returns to the initial state.

  3. Indirect method for optimal control problems: Based on Pontryagin's minimum principle, optimal control problems can be transformed into two-point boundary value problems of the Hamiltonian system (with costate variables satisfying transversality conditions at both ends). The Shooting Method directly solves this boundary value problem, yielding solutions that strictly satisfy first-order optimality conditions, with higher accuracy than the NLP approximations of direct methods.

Limitations and Boundaries

The core limitation of the Shooting Method is its sensitivity to the initial guess. For strongly nonlinear systems, the terminal error function \(F(s)\) may exhibit multiple roots, discontinuities, or even unbounded behavior, causing Newton iteration to diverge. Additionally, when the system dynamics exhibit stiffness within the integration interval, explicit integrators require extremely small step sizes, leading to sharply increased computational costs.

Another important boundary is that the Shooting Method solves for "deterministic trajectories under given boundary conditions"; it does not directly handle inequality constraints (such as joint torque limits or foot friction cone constraints). If the problem includes inequality constraints, a constraint handling mechanism (such as penalty functions or projection) must be nested outside the shooting iteration loop, which significantly increases implementation complexity. For whole-body motion planning problems with numerous inequality constraints, direct collocation or direct transcription methods are more natural choices.

Common Misconceptions

  1. "The Shooting Method can only be used for linear systems"—Incorrect. The Shooting Method is equally applicable to nonlinear systems; convergence merely depends on the quality of the initial guess. For linear systems, the terminal error function is linear, and Newton iteration converges in one step, whereas nonlinear systems require multiple iterations.

  2. "The Shooting Method is always faster than direct collocation"—Not necessarily. The Shooting Method has low per-iteration cost, but if a poor initial guess leads to many iterations or divergence, the total cost may exceed that of direct collocation. Engineering judgment: the Shooting Method is faster in scenarios with short horizons and good initial guesses; otherwise, direct collocation is more reliable.

  3. "Multiple shooting is just a simple segmentation of the Shooting Method"—Inaccurate. Multiple shooting not only integrates in segments but also introduces continuity constraints at segment points, transforming the original problem into a constrained optimization problem (rather than a pure root-finding problem), which is structurally distinct from single-segment shooting.
