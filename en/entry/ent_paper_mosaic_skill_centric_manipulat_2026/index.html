Summary

arXiv:2504.16738v3 Announce Type: replace Abstract: Planning long-horizon manipulation motions using a set of predefined skills is a central challenge in robotics; solving it efficiently could enable general-purpose robots to tackle novel tasks by flexibly composing generic skills. Solutions to this problem lie in an infinitely vast space of parameterized skill sequences -- a space where common incremental methods struggle to find sequences that have non-obvious intermediate steps. Some approaches reason over lower-dimensional, symbolic spaces, which are more tractable to explore but may be brittle and are laborious to construct. In this work, we introduce MOSAIC, a skill-centric, multi-directional planning approach that targets these challenges by reasoning about which skills to employ and where they are most likely to succeed, by utilizing physics simulation to estimate skill execution outcomes. Specifically, MOSAIC employs two complementary skill families: Generators, which identify ``islands of competence'' where skills are demonstrably effective, and Connectors, which link these skill-trajectories by solving boundary value problems. By focusing planning efforts on regions of high competence, MOSAIC efficiently discovers physically-grounded solutions. We demonstrate its efficacy on complex long-horizon problems in both simulation and the real world, using a diverse set of skills including generative diffusion models, motion planning algorithms, and manipulation-specific models. Visit skill-mosaic.github.io for demonstrations and examples.

概述

MOSAIC 提出一种以技能为中心的操控规划框架，通过环境条件化自编码器将轨迹压缩为有序离散 token，将规划问题转化为潜空间中的贪心搜索。该方法在 Waymo 与 nuPlan 基准上验证了无需任务特定训练即可实现开环机动编辑与闭环规划，核心贡献在于分离轨迹真实性与测试时控制。

它改变了什么

深度学习与基于模型的规划长期割裂：前者将任务结构固化在条件化或奖励塑形中，难以适应新目标；后者在开放域中缺乏数据先验。MOSAIC 真正改变的是将“轨迹真实性”压缩进离散潜空间，使测试时控制简化为对 token 的搜索，而非重新训练或设计专用推理过程。这一分离让同一模型可服务于重建、语义迁移与多目标引导，无需修改网络权重。

方法拆解

轨迹压缩

  • 编码器 Enc 从轨迹 𝒯 与环境 ℰ 生成 N 个 D 维潜 token z，解码器 Dec 重建轨迹 𝒯_pred，轨迹为时间均匀采样的位置序列。
  • 解码器输出高斯分布的均值与方差，训练损失为 β-NLL。

自适应软量化

  • 训练时注入噪声 corrupt(z) = tanh(z) + ε_t，其中 ε_t ~ N(0, Iσ_t²)，σ_t² 从零自适应增加至期望重建精度。
  • 测试时 σ_t = 0，并对 token 元素级四舍五入到 N_l 个均匀间隔水平（类似 FSQ，但仅测试时应用）。

有序表示与多智能体

  • 编码器与解码器通过因果自注意力强制 token 顺序，嵌套丢弃支持变长编码。
  • 多智能体在各自中心坐标系处理，混合注意力掩码允许跨智能体双向信息，潜 token 间保持因果。

潜空间搜索

  • 测试时给定目标 f(𝒯_pred) ↦ (C, ≤_C)，从首个 token 开始枚举 N_l^D 个候选，解码评分后保留最优前缀，迭代进行。
  • 方差预测用于分布外检测，惩罚高方差轨迹；可选连续精化支持梯度优化，但离散搜索必不可少。

关键创新

  1. 测试时硬量化：训练时连续、测试时离散，避免量化误差影响训练，同时保留搜索所需的离散结构，这是与 FSQ 等端到端量化方法的本质区别。
  2. 自适应噪声调度：σ_t² 从零增加直至满足重建精度，自动确定压缩强度，无需人工调参，使 token 数（如 1-3 个）成为可解释的复杂度旋钮。
  3. 方差作为分布外信号：解码器预测的方差与重建误差相关，在搜索中作为隐式可行性过滤器，无需额外训练分类器。

  • 贪心搜索在重建目标下显著优于学习编码器（如 3 tokens 时 0.386 vs 0.403），束搜索仅边际改进。
  • 3 token 量化重建 ADE 0.386，优于 DriveGPT 的 0.524（6 预测最小 ADE）。
  • 语义实验中，token 交换可跨环境迁移行为；高减速编码在多个场景一致产生减速。
  • 变道目标中，3 tokens 贪心达到 99.04% 成功率，中心距离 0.670，接近 Ground truth 的 0.629。

边界与局限

论文未明确列出局限章节。从数据看，贪心搜索在无合法左转场景中可能产生运动学不可行轨迹（不可行性最高 2.38%），且未与潜在动作规划方法（如 Ozair et al., 2021）直接比较。闭环 nuPlan 结果在片段中未提供具体数字，无法评估真实驾驶性能。多智能体联合建模的扩展性未在片段中给出定量结果。

工程启示

复现时先核对自适应噪声调度的收敛行为——σ_t² 增长过快会牺牲重建精度，过慢则压缩不足。测试时硬量化必须与训练时噪声注入匹配，否则 token 分布偏移导致搜索失效。贪心搜索的每步枚举 N_l^D 候选，D 较大时计算量爆炸，建议先用 1-2 tokens 验证目标函数可区分性，再逐步增加 token 数。方差过滤阈值需按场景校准，过高会丢弃有效轨迹，过低则无法过滤不可行解。多智能体场景中，混合注意力掩码的实现细节（附录 A.1）直接影响跨智能体信息聚合质量，需严格复现。
