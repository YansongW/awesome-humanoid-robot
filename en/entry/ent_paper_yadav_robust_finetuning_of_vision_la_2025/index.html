Summary

Robust Finetuning of Vision-Language-Action Robot Policies via Parameter Merging (RETAIN), is a 2025 large vision-language-action model for robotic manipulation, introduced by UC Berkeley.

Sources

  • Robust Finetuning of Vision-Language-Action Robot Policies via Parameter Merging (arXiv)
  • RETAIN source

概述

本文提出一种名为 ProphRL 的鲁棒微调框架，将可少样本适应的 Prophet 世界模型与 VLA 策略后训练耦合，通过动作帧条件化、历史感知长展开生成，以及 FA-GRPO 与 FlowScale 两项 RL 优化改进，解决模仿学习在分布偏移下的脆弱性。核心贡献在于把世界模型从数据增强器转变为可实用的 RL 模拟后端，并在公共基准与真实机器人上验证了显著提升。

它改变了什么

现有 VLA 后训练要么依赖真实交互成本高昂的 RL，要么依赖难以工程化且存在视觉域迁移差距的传统模拟器。离线 RL 又缺乏闭环数据，削弱长时程信用分配。本文真正改变的，是让世界模型不再只是单场景的数据增强器，而是成为一个通用、少样本可适应、且能在现实计算预算下支撑 RL 的模拟器。它把“用学习模型替换现有模拟器”这一旧思路，推进到“解决使世界模型成为真实世界机器人实用 RL 后端”的新问题，即同时处理长时程展开、动作条件化精度和 RL 训练稳定性。

方法拆解

整体范式

  • 外层循环中，策略从指令和初始图像预测动作块，Prophet 基于动作块和初始图像生成视频片段，片段反馈给策略与 Prophet 实现长时程闭环展开。
  • 冻结的 VLM 奖励模型对每次展开评分产生组奖励，使用 FA-GRPO（公式 18）优化策略，FlowScale（公式 19）重新加权去噪步骤。

Prophet 世界模型

  • 基于潜在视频扩散管道：视频自编码器编码真实片段为潜在变量，DiT 去噪器学习条件扩散模型，优化目标为标准潜在空间噪声预测目标（公式 1）。
  • 动作定义为 7 维向量（D=7）：平移增量 3 维、欧拉角旋转增量 3 维、夹爪开度 1 维。跨数据集预训练时，N 固定为最大末端执行器数量（AgiBot 上为 2），不足用零填充。动作参数化为相对前一末端执行器帧的局部增量位姿，使动作空间更均匀。
  • 动作帧构建：将末端执行器动作投影到相机图像平面，黑背景渲染 2D 可视化，圆盘半径随深度单调递减（公式 8），控制信号通过固定色彩映射映射为颜色（公式 9）。

动作条件化（双层级）

  • 全局块级标量动作流嵌入：整个动作块展平为向量，经 MLP 映射为全局嵌入，加到 DiT 时间步嵌入。
  • 可选动作帧潜在嵌入：轻量 3D 投影（1×1×1 卷积、深度可分离 1×3×3 卷积、1×1×1 卷积），空间平均池化加时间正弦位置编码，MLP 映射后加到时间步嵌入。

历史感知与长展开

  • FramePack 风格模块维护低分辨率历史潜在帧记忆，经多时空步长 3D 平均池化和 1×1×1 投影块处理，拼接成记忆矩阵，两个线性层映射为额外键值向量，输入所有 DiT 块。
  • 自回归分块生成：从首帧初始化历史缓冲区，模型生成短片段，末帧作为下一段起始帧，新片段压缩进历史，重复维持时间连续性并扩展到长时程。

RL 优化改进

  • FA-GRPO：将 Flow-GRPO 的比率从内部流步骤级别改为动作级别——先聚合所有内部流步骤的对数概率（公式 16），再按动作块每个维度形成 PPO 比率（公式 17），每个 (s,c) 作为一个环境动作共享一个优势值。优化带 KL 正则化的裁剪比率目标（公式 18）。
  • FlowScale：引入状态和步骤相关权重 w_{s,k} 调制每个流步骤的梯度贡献。噪声尺度从扩散/流时间表获取（公式 20），权重构造为归一化-混合-裁剪规则（公式 22）。较早高噪声步骤相对上加权，较晚低噪声细化步骤下加权，保持每步平均梯度尺度不变。权重作为 stop-gradient 常数，只重缩放梯度不改变优化目标。
  • 理论依据：高斯近似下，每步似然因子的得分期望平方范数与 σ^{-2} 成正比（公式 25），FlowScale 通过重加权平衡各步骤梯度贡献。

关键创新

  1. 动作帧条件化：将 7 维动作向量渲染为相机图像平面上的 2D 可视化，并作为可选潜在嵌入注入 DiT，这比纯标量嵌入提供了更丰富的空间交互线索，直接改善末端执行器运动与接触的正确性。
  2. FA-GRPO 的动作级聚合：将流匹配 RL 的比率从内部流步骤级别提升到动作块级别，使每个环境动作共享一个优势值，避免了流步骤级更新信号不一致的问题，更贴合机器人控制的时间抽象。
  3. FlowScale 的方差平衡权重：基于得分范数与噪声尺度成反比的理论，设计归一化-混合-裁剪的权重规则，在不改变优化目标的前提下平衡各流步骤的梯度贡献，解决了得分驱动梯度异方差性导致的训练不稳定。

实验与结果

实验场景 提升幅度
公共基准成功率 5–17%
真实机器人不同 VLA 变体 24–30%
  • 公共基准上的提升表明方法在标准评估协议下具有泛化性。
  • 真实机器人上的更大提升说明世界模型作为 RL 后端在真实分布偏移下比传统模拟器更有效。
  • 论文片段未提供具体分项表格数字，上述为汇总范围。

边界与局限

论文未明确列出自身局限。但根据方法细节可推断：FlowScale 分析仅为近似，实际训练动态还取决于裁剪、KL 正则化及流步骤间相关性；域桥接 RM 的半合成监督是务实变通，诱导奖励仍有噪声，训练信号稳定性因任务而异；BRIDGE 与真实数据标注困难，收集多样化带标签失败数据成本高昂，离策略日志中很少包含干净的成功/失败标注。

工程启示

复现时先核对三处：一是动作帧渲染的相机内参、外参与深度半径映射（公式 8、9）是否正确，这直接影响动作条件化质量；二是 FA-GRPO 中动作级聚合的掩码处理（公式 15），变长片段终止后所有损失贡献置零的逻辑容易出错；三是 FlowScale 的归一化-混合-裁剪规则（公式 22），需确保权重作为 stop-gradient 常数，且裁剪范围 [w_min, w_max] 与混合强度 α 需针对具体任务调参。最易踩坑的是历史缓冲区长度 T_h 与自回归分块长度的匹配，过短会破坏长时程连续性，过长则显存压力大。RM 推理建议采用多次随机解码多数投票（如 5 次），并注意子采样帧数（如 50 帧）对评分稳定性的影响。
