Summary

arXiv:2606.31909v1 Announce Type: new Abstract: In this work, we study Compositional Dexterous Functional Object Manipulation (CD-FOM): tasks such as aiming and actuating a spray bottle on a plant or a glue gun on wood, which require both actuating an object's internal mechanism and controlling its pose to apply the object's function to the environment. These tasks pose significant challenges for robots due to the demanding integration of semantic understanding of the object's function, actuation mode, and application area with intricate physical dexterity to manage grasp stability, movement trajectory, and actuation. We introduce CoDex, a zero-demonstration framework that autonomously discovers CD-FOM manipulation strategies. CoDex uses vision-language models (VLMs) to infer semantic constraints from the task and scene. These constraints guide analytic constrained optimization to generate a short list of functional grasp candidates that can be efficiently refined with reinforcement learning to generate full grasp-move-actuate policies transferable from simulation to the real world. We evaluate CoDex on a 7-DoF robot arm with a 16-DoF multi-fingered hand across six CD-FOM tasks involving previously unseen objects with internal mechanisms, including spray bottles, hot glue guns, air dusters, flashlights, and pepper grinders, and their application to unseen target objects, showcasing its ability to autonomously discover and execute complex, physically viable dexterous behaviors without human demonstrations. More information at https://robin-lab.cs.utexas.edu/CoDex/.

概述

CoDex 由德州大学奥斯汀分校 RobIn 实验室提出，是一种零演示的组合式灵巧功能操作（CD-FOM）学习框架。其核心思路是将 VLM 的语义理解转化为显式几何约束，先通过约束优化生成功能有效的抓取候选，再用强化学习精化为完整的“抓取-移动-驱动”策略，在真实 Franka 臂 + LEAP 手上达到 73% 的任务成功率。

它改变了什么

这项工作的真正改变在于，它把 VLM 从“提供粗略抽象指导”的角色，提升为“生成可执行几何约束”的组件，从而绕开了两条传统路径的死胡同：一条是依赖大量遥操作数据的 LfD，另一条是需要手工设计奖励或优化目标的纯优化方法。CoDex 证明了语义理解可以被“翻译”成驱动点、功能点、目标位姿这类显式几何量，进而直接约束底层策略学习——这填补了 VLM 早期集成（如 ReKep、PIVOT）在精细手-臂协调上的空白。

更关键的是，它把“功能操作”从单一物体抓取扩展到了“物体内部机构驱动 + 物体位姿控制”的组合任务。以往方法要么只关注抓取稳定性，要么只关注语义规划，CoDex 首次在零演示条件下将两者耦合进一个可训练的策略框架，并且直接部署到真实硬件上验证，而非停留在仿真。

方法拆解

阶段一：VLM 语义约束生成

  • 输入语言任务描述 L 与 RGB-D 观测 I，用 LangSAM 做开放词汇分割识别功能物体，Tripo 重建 3D 网格并按场景点云高度缩放。
  • 局部约束：VLM 生成关键交互点文本（如 “trigger”），MoLMo 链接到 2D 像素，FoundationPose 对齐图像与网格后反投影到 3D，得到驱动点 p_act 与功能点 p_fnc。假设驱动方向 d_act 平行于表面法线且指向物体内部。
  • 全局约束：VLM-Guided CEM（VLM-CEM），迭代 N=6 轮，每轮 VLM 提出 K=10 个候选位姿，渲染后评分，保留精英子集，返回最高分位姿 T*。初始位姿由 AnchorInit(p_fnc, p_tgt) 生成。

阶段二：约束引导的策略训练

  • 子阶段 1（解析约束优化）：从有效关节空间 Q 采样初始手部配置 q0（逆运动学，偏置一根手指靠近 p_act），优化目标为最大化最小力闭合度量 l*(q)，约束包括：
  • 最小力闭合 l*(q) ≥ l_min
  • 表面接触 s(FK_i(q)) = 0
  • 碰撞避免 σ_j(q) ≥ d_j
  • 驱动点邻近 ||FK_tip(q,i_act) - p_act||_2 ≤ δ_dist
  • 驱动对齐 n_pad(q,i_act)·(-d_act) ≥ cos(δ_angle)
  • 失败则重采样 q0 重启。
  • 子阶段 2（约束引导 RL）：策略 π 输入观测 o（相对手部位姿、候选手指关节、指定驱动手指索引），输出动作 a ∈ R^38（16 维抓取关节偏移 + 16 维预抓取关节百分比 + 6 维残差手部位姿）。运动原语分四步：预接触 → 最终抓取 → 手指闭合 → 移动物体朝向 T* 并执行驱动。
  • 奖励：PPO 训练，统一奖励 R 为归一化加权和，含连续塑形奖励（抓取稳定性、提升、驱动对齐、方向力）、二值阶段完成奖励和最终任务成功奖励；检测到显著抓取位移时惩罚将奖励重置为零。

关键创新

  1. VLM 约束的显式几何化：不同于 ReKep 或 PIVOT 仅提供粗略空间关系，CoDex 将 VLM 输出转化为驱动点、功能点、目标位姿等可直接用于约束优化的几何量。这是首次让 VLM 语义理解与底层力闭合优化、RL 奖励设计形成闭环。
  2. 两阶段“解析优化 + RL”的级联：先用约束优化快速获得功能有效的抓取候选，再用 RL 精化为完整策略。这种设计避免了纯 RL 从零探索的高样本复杂度，也避免了纯解析方法对任务语义的盲区。
  3. 零演示的 CD-FOM 完整流程：从语义解析到真实部署，全程无需人类演示或物体特定奖励设计。对未见过物体（喷水瓶、热熔胶枪等）及其目标应用，策略能自主发现操作方式，这是此前方法未达到的泛化水平。

实验与结果

真实世界任务成功率（Q1，每任务 5 次试验）

方法 成功率
CoDex 73%
Analytical + VLM-CEM 33%
RL + PIVOT 0%

CoDex 相对 Analytical+VLM-CEM 的提升主要来自驱动鲁棒性；RL+PIVOT 因全局约束不满足任务要求（如喷瓶未瞄准植物）而完全失败。失败分析显示：全局约束预测错误导致错误物体运动占所有试验的 23.3%（占失败试验的 87.5%）；驱动失败占 23.3%；手电筒任务（按钮半径 < 0.5 cm）全部失败。

人类研究（Q2，20 名参与者，五分量表）

两种 VLM-CEM 变体在所有任务中均排名高于 PIVOT 基线，Wilcoxon 符号秩检验 p < 0.02。喷雾植物任务中，方向探索消融的 VLM-CEM 得分显著高于完整平移探索版本。

策略学习增益（Q3，每物体 3 个解析候选各重复 5 次）

指标 相对平均初始候选 相对 oracle 最佳候选
抓取稳定性 +36% 以上 +12% 以上
驱动成功率 +60% +26% 以上

盐研磨器任务中，所有初始抓取候选均未实现稳定抓取，但 CoDex 策略学习成功发现稳定抓取（由表内数值 0% → 成功 计算）。

边界与局限

  • 需要精确点接触的任务（如按压微小按钮，半径 < 0.5 cm）对手指尺寸和执行器公差敏感，当前手指形态无法可靠完成。
  • 策略假设单一驱动点，未覆盖需要交替或多点驱动的物体；也未扩展至轨迹级约束（如沿纸滑动剪刀需要持续的耦合臂-手运动）。
  • 未纳入触觉反馈，仿真到真实的差异（2D 图像重建几何、摩擦/密度/可变形性差异）仍是失败来源。
  • 未探索更丰富的交互式 VLM 对话，也未扩展到更复杂物体机制。论文未明确说明策略对物体位姿初始化的敏感度边界。

工程启示

复现时先核对三个关键点：一是 VLM-CEM 的候选位姿质量——全局约束错误是最大失败源（占失败试验的 87.5%），建议先单独验证 AnchorInit 与 VLM 评分的一致性；二是驱动点反投影精度，FoundationPose 的跟踪质量直接影响 p_act 的准确性，对高光或半透明物体需额外处理；三是 RL 训练中的“抓取位移惩罚”阈值，设置不当会导致策略过早放弃或过度保守。

工程上最容易踩坑的是仿真到真实的迁移：2D 重建几何误差和摩擦差异会显著影响驱动成功率，建议在真实部署前先用解析候选做一轮开环验证。另外，手电筒这类小按钮任务（半径 < 0.5 cm）在当前硬件下基本不可行，选型时优先选择驱动行程大、接触面积明确的物体。训练配置上，2,048 并行环境 + 约 1 小时收敛是合理基线，但若任务涉及多点驱动或轨迹级操作，需扩展动作空间与奖励结构。
