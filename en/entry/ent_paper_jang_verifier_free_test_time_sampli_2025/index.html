Summary

Verifier-free Test-Time Sampling for Vision Language Action Models (MG-Select), is a 2025 large vision-language-action model for robotic manipulation, introduced by KAIST, Seoul National University, RLWRLD.

Sources

  • Verifier-free Test-Time Sampling for Vision Language Action Models (arXiv)
  • MG-Select source

概述

本文提出 MG-Select，一种无需外部验证器的 VLA 测试时扩展框架，通过条件掩码分布置信度进行 Best-of-N 采样，并配合联合模仿学习（Joint-IL）训练策略提升动作选择精度。该方法在 RoboCasa、SIMPLER-WidowX、LIBERO 及真实世界任务上均取得一致提升，且推理延迟可控。

它改变了什么

现有 VLA 的 greedy decoding 在毫米级精度任务（如抓取、放置）上成为瓶颈，而此前基于外部验证器的测试时扩展方法（如 RL 价值函数或 VLM 验证器）需要额外训练且难以泛化到未见条件。MG-Select 真正改变的是：将测试时扩展的信号来源从外部模块转向模型自身内部属性，利用条件掩码分布与预测分布的 KL 散度作为置信度，从而绕开了验证器训练成本与泛化限制。这一转变使得测试时扩展成为 VLA 的即插即用能力，而非需要专门设计的附加系统。

方法拆解

两阶段采样框架

  1. 并行采样：以温度 τ > 0 从策略 π_θ 采样 N 个候选动作，公式为 \(\tilde{a}^{(n)}_{j}\sim\pi_{\theta}(\cdot\mid o_t,q_t,I,\tilde{a}^{(n)}_{<j};\tau)\)。
  2. Best-of-N 选择：依据置信度准则 M 选出最终动作 \(\mathbf{a}^{*}=\arg\max_{\tilde{\mathbf{a}}^{(n)}\in\tilde{A}} M_{\tilde{\mathbf{a}}^{(n)}}\)。

置信度指标：KL 散度而非似然

  • 微调后 VLA 动作分布过度集中，多次采样收敛到相同结果，似然选择失效。
  • Token 级置信度：\(C_i = \mathrm{KL}(Q_i \| P_i)\)，其中 \(P_i\) 为预测分布，\(Q_i\) 为参考分布。
  • 动作级置信度：\(C_{\mathbf{a}} = \sum_{i\in\mathcal{I}} C_i\)，π₀-FAST 默认聚合前 5 个 token。

条件掩码分布（参考分布生成）

  • 同一 VLA 在随机掩码状态/语言条件下生成参考分布，确保最大不确定性且保持任务分布对齐。
  • 三种变体：Text-masking、State-masking、Text&State-masking，不同环境最优变体不同（RoboCasa 中 state-masking 最佳，SIMPLER-WidowX 中 text-masking 更有效）。

联合训练策略（Joint-IL）

  • 微调时对状态和指令应用四种掩码组合进行数据增强，损失函数为： \(\mathcal{L}_{\text{Joint-IL}}(\theta;\mathcal{D}) = -\mathbb{E}_{((o_t,q_t),a_{t:t+H},I)\sim\mathcal{D}}\left[\mathbb{E}_{(q_t^{(m)},I^{(m)})\in\mathcal{M}}\left[\log\pi_{\theta}(\mathbf{a}_t\mid o_t,q_t^{(m)},I^{(m)})\right]\right]\)
  • 关键设计：直接掩码未训练的输入会导致意外动作，Joint-IL 使模型获得条件掩码分布意识，同时保持标准微调性能。

部署优化

  • 条件掩码分布需高正则化温度（τ = 4.0）防止峰值化。
  • 单次预填充部署：共享一次预填充给所有 N 个候选，N = 4 时延迟降低 45%（由表内数值 43.4 → 23.7 计算）。

关键创新

  1. 自生成置信度信号：首次将条件掩码分布与预测分布的 KL 散度作为 VLA 测试时扩展的置信度，完全摆脱外部验证器依赖，这是对现有测试时扩展范式的根本性简化。
  2. 联合训练与推理的协同设计：Joint-IL 不仅提升标准微调性能（RoboCasa 100 Demos PnP 从 17.0 提升至 28.5），还使条件掩码分布变得可用，推理与训练策略形成闭环，这是此前方法未考虑的关键设计。
  3. 单次预填充部署：通过共享预填充将 N = 4 的推理延迟从 43.4 秒降至 23.7 秒（由表内数值计算），使测试时扩展的实际部署成本接近单次推理，解决了采样方法落地的主要障碍。

实验与结果

模拟环境结果（平均成功率 %）

环境 基础模型 + MG-Select* 相对提升
RoboCasa 30 Demos PnP 5.3 14.2 168%
RoboCasa 100 Demos PnP 17.0 31.0 82%（由表内数值 2.2→0.4 计算）
SIMPLER-WidowX Average 46.9 50.3 7%（由表内数值 28.0−35.0 计算）
LIBERO Average (π₀-FAST) 92.0 93.1 1.2%（由表内数值 17.4÷14.2 计算）

真实世界结果（平均成功率 %）

任务类型 基础模型 + MG-Select* 相对提升
分布内（ID） 37.5 47.9 28%
分布外（OOD） 53.1 71.9 35%

消融实验关键发现（RoboCasa 100 Demos）

  • 推理策略：MG-Select (N=4) 31.0/48.1 优于 Likelihood (N=4) 30.5/46.8 和 Uniform KL (N=4) 30.0/46.5。
  • 候选数：N=4 最优（31.0/48.1），N=8 和 N=16 反而下降。
  • 正则化温度：τ=4.0 最优（31.0/48.1），τ=0.5 仅 27.5/43.9。
  • 聚合策略：First 5 最优（31.0/48.1），Sum 和 Avg 均较差。

边界与局限

论文未明确列出自身方法的局限性。从实验可推断：在 LIBERO 这类高精度任务上提升有限（92.0 → 93.1），说明方法对已高度优化的模型增益较小；SIMPLER-WidowX 的 Eggplant in Basket 任务上基础模型表现极差（8.3），MG-Select* 仅提升至 13.9，表明当基础模型完全无法完成任务时，采样方法难以弥补根本性缺陷。此外，方法未在更多机器人平台、更复杂长时程任务或真实世界 OOD 大规模场景中验证，泛化边界未明确。

工程启示

复现时先核对三个关键点：一是 Joint-IL 的掩码 dropout 比例（π₀-FAST 为 10%/10%/10%，OpenVLA 仅文本 10%），直接掩码未训练的输入会导致动作异常；二是正则化温度必须设为 τ = 4.0，过低（0.5）或过高（8.0）均显著降低性能；三是聚合策略对 π₀-FAST 必须用前 5 个 token 求和，Sum 或 Avg 会损失 5 个点以上。部署时优先启用单次预填充，N = 4 时延迟与单次推理相当。跨环境迁移时需重新搜索掩码变体（text vs state vs both），RoboCasa 中 state-masking 最佳，但 SIMPLER-WidowX 中 text-masking 更有效，不可直接沿用。
