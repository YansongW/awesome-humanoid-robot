Summary

Human hand-object demonstrations provide dense reference motions for training dexterous manipulation reinforcement learning (RL) policies through reference tracking. Institutions per source list: IIIS、Tsinghua University.

Overview

TopoRetarget is a retargeting framework for dexterous manipulation that, through topology-aware interaction mesh construction and Laplacian optimization, retargets human hand-object demonstrations into robot reference motions directly usable for RL tracking under fixed parameters. The authors are from academic institutions, and the core contribution lies in shifting the retargeting objective from hand pose alignment to preservation of local hand-object interaction structure, with significant improvements in retargeting quality and downstream policy performance validated on ContactPose, Ho-cap, and a self-collected Pen-Spin dataset.

What It Changes

Existing retargeting methods (DexPilot, GeoRT, OmniRetarget, etc.) essentially perform "hand-to-hand" mapping: the optimization objective revolves around hand pose, fingertip correspondence, or pinch relationships, attempting to make the robot hand morphologically resemble the human hand. However, the problem is that downstream RL policies truly need the "hand-to-object" contact structure—the topological relationship with which robot fingers should contact the object surface, and how contact points transfer as the object moves. Hand pose alignment does not guarantee correct contact structure; instead, it may introduce penetration or virtual contact artifacts, forcing downstream policies to expend substantial training budget correcting these errors.

TopoRetarget changes this paradigm: it no longer asks "does the robot hand look like the human hand," but rather "is the local neighborhood relationship between the robot hand and the object consistent with the demonstration." By uniformly constructing hand keypoints and object surface points as an interaction graph and comparing source and target local geometric relationships via Laplacian coordinates, it directly optimizes the preservation of contact topology. This shift enables retargeting results to serve as reliable references for RL tracking without per-case parameter tuning or downstream refinement—a substantive leap from "retargeting as an independent optimization problem" to "retargeting as a preprocessing pipeline for policy learning."

Method Breakdown

Overall Pipeline

Input: human hand trajectory \(P^h_{1:N}\) (MediaPipe 21 keypoints), object pose trajectory \(q^o_{1:N}\), and object mesh \(M\). Output: robot base pose \(q^{base}_{1:N}\) and joint trajectory \(q^\theta_{1:N}\). Each frame is optimized independently, with temporal regularization ensuring continuity.

Relative Bone Direction Initialization

For each non-distal finger keypoint \(k\), define a unit vector \(d_k\) pointing to the child keypoint of the same finger. Bone mismatch energy: [ E_{bone}(q) = \sum_{(k,l)\in A_B} |(d_k^r(q) - d_l^r(q)) - (d_k^s - d_l^s)|^2_2 ] Initial estimate \(\tilde{q}_t^r := \arg\min_q \lambda_{warm} E_{bone}(q) + \lambda_{smooth}\|q - \tilde{q}_{t-1}^r\|^2_2\). The first term reproduces relative bone directions; the second ensures inter-frame consistency. This initialization merely provides a good starting point for subsequent topology optimization, not the final result.

Interaction Mesh Construction

For each frame, construct source and robot hand-object vertex sets \(V_t^s = [P_t^h; O_t]\), \(V_t^r(q) = [P_t^r(q); O_t]\), where \(O_t\) comprises \(N_o=50\) object surface sample points, with total vertex count \(N_v = 21 + N_o\). Run Delaunay tetrahedralization on source vertices to obtain interaction edge set \(I_t\), and reuse the same connectivity for robot vertices. Key design decision: the shared graph structure makes source and target comparable under identical local neighborhoods and naturally supports generalization across object scales and hand morphologies—because graph topology is determined by source data, independent of specific geometric dimensions.

Topology-Aware Laplacian Optimization

For each interaction edge \((i,j)\in I_t\), compute distance-aware weights: [ \tilde{w}{ij,t} = \exp(-\kappa|v^s|}^s - v_{j,t2), \quad w} = \tilde{w{ij,t} / \sum} \tilde{w{ij',t} ] Weighted Laplacian coordinates \(\Delta_t(V)_i = \sum_{j\in N_t(i)} w_{ij,t}(v_i - v_j)\). Interaction mesh energy: [ E|\Delta_t(V_t^r(q))}(q) = \frac{1}{N_v}\sum_{i=1}^{N_vi - \Delta_t(V_t^s)_i|^2_2 ] Final optimization objective: [ \min s_i^2 ] Constraints: } \lambda_{IM} E_{IM}(q) + \lambda_{bone} E_{bone}(q) + E_{reg}(q; q_{t-1}^{r,*}) + \frac{w_s}{2}\sum_{i\in Q_t\(\phi_i(q) \geq -b\), \(\phi_i(q) + s_i \geq -\tau\), \(0 \leq s_i \leq b - \tau\). Here \(\phi_i(q)\) is the signed distance, \(\tau=0.001\)m is the soft tolerance, \(b=0.030\)m is the hard boundary, and \(s_i\) are slack variables. \(E_{reg}\) includes temporal smoothing \(\lambda_{reg}\|q - q_{t-1}^{r,*}\|^2_2\) and a lightweight base prior \(\lambda_{base,pos}\|q^{base}_{pos}\|^2_2 + \lambda_{base,rot}\|q^{base}_{rot}\|^2_2\).

Fixed Parameters

All experiments use the same parameter set without per-case tuning: \(N_o=50\), \(\lambda_{IM}=500\), \(\kappa=30\), \(\lambda_{warm}=1\), \(\lambda_{bone}=0.1\), \(\lambda_{smooth}=2.5\), \(\lambda_{reg}=2.5\), \(\lambda_{base,pos}=100\), \(\lambda_{base,rot}=1\), \(\tau=0.001\)m, \(b=0.030\)m, \(w_s=1.0\times10^5\).

Minimal RL Tracking Controller

PPO optimizes a finite-horizon MDP. Reference segment \(\xi_{ref} = \{q_k^{\theta,ref}, q_k^{o,ref}, p_{1:L,k}^{ref}\}_{k=0}^{N-1}\), where object and hand link references are expressed in the base coordinate frame, focusing the policy on relative hand-object interaction rather than global motion. Actions are residual joint position commands: \(q_t^{\theta,tar} = q_{k_t}^{\theta,ref} + a_t\). Observations include proprioception, object pivot points (6), and look-ahead references (offsets of 1, 3, 5 steps). The reward comprises four weighted Gaussian kernel tracking terms, with the object term weighted highest (8.0), followed by links (1.0), joints (1.0), and smoothing (-0.01).

Key Innovations

  1. Topology preservation as the retargeting objective: Hand-object interaction is modeled as Laplacian coordinate comparison on a shared graph, rather than traditional hand pose or fingertip correspondence. This is the first time "local neighborhood relationships" rather than "global pose" serve as the core optimization objective for retargeting, directly targeting the root cause of contact artifacts—local geometric mismatch between hand and object.

  2. Fixed parameters with zero tuning: All experiments use an identical parameter set without per-case adjustment. This breaks the convention of existing methods (e.g., OmniRetarget) requiring parameter tuning for different objects or tasks, making retargeting a plug-and-play preprocessing module and substantially reducing engineering deployment cost.

  3. End-to-end validation of retargeting and RL tracking: Beyond evaluating retargeting quality metrics, downstream RL policies are trained and deployed on the real Wuji Hand. On the Pen-Spin task, success rate exceeds the strongest baseline by over 40 percentage points (87.5% vs 46.9%), demonstrating that topology-preserving retargeting results can serve directly as reliable references for policy learning without additional refinement or correction.

Boundaries and Limitations

The paper explicitly acknowledges two limitations: first, dependence on the quality of upstream human reference motion—if the source demonstration itself contains motion capture noise or semantic errors, retargeting cannot correct them; second, poor handling of "virtual contacts" (where source fingers intend to interact with the object but do not actually contact the surface), which commonly occur in fast motions and cause unrealistic floating fingers in retargeting results. The authors do not mention specific solutions for virtual contacts, nor do they discuss deeply concave objects (e.g., mug, scissors, Utah teapot)—such geometries were excluded from experiments because no baseline method can reliably handle them. Additionally, while fixed parameters perform well on the test set, robustness boundaries under extreme object scales or hand morphology differences are not validated.

Engineering Insights

When reproducing, first verify the details of interaction graph construction: Delaunay tetrahedralization is sensitive to source vertex distribution, and the uniformity of object surface sample points \(N_o=50\) directly affects edge set quality; Poisson disk sampling is recommended over random sampling to ensure topological stability. Second, \(\lambda_{IM}=500\) far exceeds other terms, meaning Laplacian energy dominates optimization—if penetration occurs on custom hand models, prioritize adjusting \(\kappa\) (currently 30) rather than \(\lambda_{IM}\), because \(\kappa\) controls the decay rate of distance weights and directly affects local neighborhood sensitivity. In downstream RL training, the object term weight of 8.0 far exceeds other terms, and the termination condition includes object pivot error >0.05m, meaning the policy is extremely sensitive to object position error—if retargeting results contain slight contact offsets, training may terminate prematurely; it is recommended to verify retargeting contact accuracy below 1cm before investing in RL training. Finally, the object mass/inertia scale range [0.4, 1.6] in domain randomization is relatively wide; if simulation and real hardware dynamics differ significantly, narrowing this range first can help rule out interference factors causing training non-convergence.
