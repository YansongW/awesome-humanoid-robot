Summary

UP-VLA: A Unified Understanding and Prediction Model for Embodied Agent (UP-VLA), is a 2025 large vision-language-action model for robotic manipulation, introduced by Tsinghua University, Shanghai Qi Zhi Institute, and published at ICML 2025.

Sources

  • UP-VLA source

概述

UP-VLA 是一个面向具身智能体的统一理解与预测模型，由研究团队提出，旨在通过联合训练多模态理解（MMU）与未来视觉预测（PRE）任务，同时增强高层语义理解与低层空间物理感知。该模型在 CALVIN 模拟基准和 Franka 真实机器人上验证了其性能，核心贡献在于重新设计了 VLA 的预训练范式，将视频数据中的动态信息显式引入训练目标。

它改变了什么

现有 VLA 模型普遍依赖预训练 VLM 作为骨干，但这类 VLM 在预训练时被优化于高层语义任务（如 VQA），其内部表征对距离、大小、相对位置等低层空间细节以及物体物理动态的编码是缺失或弱化的。这导致机器人控制中关键的“手眼协调”和“动态响应”能力受限，模型往往“看得懂”场景却“够不着”物体。UP-VLA 真正改变的是这一预训练范式的根基：它不再将 VLM 视为冻结的特征提取器，而是通过引入视频预测任务，强制模型在预训练阶段就同时优化语义理解与像素级动态建模，从而在共享参数空间中调和了“认知”与“控制”两种需求。

这一改变的意义在于，它把 VLA 的训练从“静态图像理解 + 动作映射”的串联模式，转变为“动态世界模型 + 动作生成”的并联模式。通过让模型直接预测未来帧的离散 token，模型被迫学习物体如何运动、遮挡如何变化、场景如何响应动作，这些正是具身控制中比静态语义更关键的信息。这为后续的 VLA 预训练提供了一个新方向：与其寻找更大的 VLM，不如重新设计训练信号，让模型在预训练阶段就具备物理直觉。

方法拆解

UP-VLA 的方法核心在于将多模态理解与未来预测统一在一个自回归 Transformer 框架内，通过任务标识 token 区分不同目标。

骨干与编码器

  • 底层 LLM 使用 Phi-1.5。
  • 多模态理解（MMU）任务使用 CLIP-ViT 将图像投影到语言嵌入空间。
  • 图像预测（PRE）任务使用 VQ-GAN 将当前图像编码为离散 token，预测目标同样为离散 token。

统一序列格式

  • 输入序列通过特殊 token（如 |MMU|、|T2I|、|PRE|）分段并标识任务类型。
  • MMU 任务中，图像 token 位于语言 token 之前，两者可互相 attend。
  • PRE 任务中，图像 token 位于语言 token 之后，attend 所有先前信息，确保预测基于完整上下文。

未来视觉预测

  • 直接预测未来图像 token，而非噪声预测或掩码重建，公式为： \(P(O_{t+\Delta t}|O_t,L)=\prod_{i=1}^{M}p_\theta(v^i_{t+\Delta t}|\mathbf{v}_t,l)\)
  • 使用离散解码器（VQ-GAN decoder）重建预测图像。

动作学习

  • 联合预测未来观测和动作序列，公式为： \((\hat{O}_{t+\Delta t},\hat{A}_{t:t+\Delta t})=\pi_\theta^{PRE}(O_t,L')\)
  • 扩展语言指令输入为： \(L'=[E_1(O_t'),\pi_\theta^{MMU}(O_t,L_{\text{prompt}}),L]\) 其中 \(L_{\text{prompt}}\) 如“describe this image”，使动作预测条件化于模型自身的语义理解输出。
  • 动作输出通过小策略头（MAP 模块，单层注意力加线性层）实现，公式为： \(\hat{a}_{t:t+\Delta t}=MLP(MAP(\hat{A}_{t:t+\Delta t}))\)

训练策略

  • 初始化用 Show-o。
  • 训练时全微调 LLM 参数，冻结所有编码器。
  • 两阶段训练：
  • 第一阶段：混合 Bridge（25k 机器人演示）和 LLava-tuning-665k（665k 图像-文本对）进行预测和理解预训练。
  • 第二阶段：用下游具身任务微调，同时继续联合图像-文本对训练。

训练目标

  • 语言建模损失（交叉熵）：\(\mathcal{L}_{MMU}=\sum_i\log p_\theta(l_i|\mathbf{u},l_1,\cdots,l_{i-1})\)
  • 图像预测损失（交叉熵）：\(\mathcal{L}_{PRE}=\sum_j\log p_\theta(v_j'|\mathbf{l},v_1,\cdots,v_j,\cdots,v_M)\)
  • 动作建模损失（MSE + BCE）：\(\mathcal{L}_{ACT}=\sum||\hat{a}_{pos}-a_{pos}||^2_2+BCE(\hat{a}_{end},a_{end})\)
  • 总损失：\(\mathcal{L}=\lambda_1\mathcal{L}_{MMU}+\lambda_2\mathcal{L}_{PRE}+\lambda_3\mathcal{L}_{ACT}\)

关键创新

  1. 统一训练目标而非统一模型架构：UP-VLA 的创新不在于设计新的注意力机制或网络结构，而在于将 MMU 和 PRE 两个任务以统一的序列格式和损失函数进行联合训练。这使得模型在预训练阶段就同时获得语义理解能力和物理动态预测能力，避免了传统两阶段训练中“先理解后控制”的割裂问题。

  2. 直接预测未来 token 而非噪声或掩码：与扩散模型或掩码重建不同，UP-VLA 直接以自回归方式预测未来帧的离散 token。这一设计选择使得预测目标与语言建模目标在形式上完全一致，从而可以在同一个 Transformer 内无缝融合，无需额外的解码器或特殊的训练目标适配。

  3. 动作条件化于模型自身的语义输出：通过将 MMU 的输出（如“describe this image”的响应）作为动作预测的额外条件输入，UP-VLA 实现了“理解指导行动”的显式信息流。这不同于简单的特征拼接，而是让模型在生成动作前先“思考”场景内容，从而在复杂任务中提供更稳定的语义引导。

结果解读

  • UP-VLA 在 ABC→D 设置下，5 步任务完成率 0.699，相比之前最先进方法（GR-1 的 0.401）提升约 33%（由表内数值 0.401→0.699 计算）。
  • 消融实验显示，移除 Prediction 任务对 CALVIN 性能打击最大（Avg. Len 从 4.08 降至 1.44），说明未来预测是长程任务规划的关键。
  • 真实世界 Unseen 场景中，Full 模型（0.58）显著优于 w/o MMU（0.20），表明语义理解对泛化到新物体至关重要。

边界与局限

  • 多模态理解中对特定物体的识别仍不准确，作者归因于数据规模和骨干网络规模限制，未探索更大规模方案。
  • 未来预测存在背景颜色偏差：在 CALVIN D 环境预测时，模型倾向于使用训练数据集（ABC）的背景颜色，说明视觉生成预训练不足，限制了生成任务的泛化能力。
  • 未在更多样化的真实世界场景中验证，真实世界评估仅覆盖 6 种技能、2k 演示，且训练场景简单、测试场景复杂，结论可能不适用于更开放的任务。
  • 论文未明确推理频率与硬件配置，复现时需自行确定。

工程启示

  • 复现优先级：先核对 Bridge 数据集（25k 演示）与 LLava-tuning-665k（665k 图像-文本对）的采样比例，这是两阶段训练的关键超参。不同任务采样比例直接影响 MMU 与 PRE 的平衡，建议从 1:1 起步。
  • 最大踩坑点：冻结编码器（CLIP-ViT 与 VQ-GAN）是全微调 LLM 的前提，若编码器未冻结，梯度冲突会导致训练不稳定。务必在代码中显式设置 requires_grad=False。
  • 消融实验启示：Prediction 任务对长程任务（CALVIN）影响最大，但对真实世界 Unseen 泛化影响相对较小。若下游任务以短程操控为主，可考虑降低 PRE 损失权重以节省训练时间。
  • 下游团队适配：UP-VLA 的动作输出依赖 MAP 模块（单层注意力 + 线性层），若需适配不同机器人（如不同自由度），只需替换 MLP 输出维度，无需改动 Transformer 主干。但需注意，动作频率与预测时间步 \(\Delta t\) 需根据机器人控制频率重新标定。
  • 数据质量警示：真实世界评估中 Unseen 场景成功率（0.58）仍偏低，若团队目标是在新物体上部署，建议在预训练阶段加入更多样化的视频数据，而非仅依赖 Bridge 数据集的 25k 演示。
