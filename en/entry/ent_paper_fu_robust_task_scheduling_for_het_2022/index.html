Summary

Proposes CTAS, a stochastic mixed-integer programming framework that jointly optimizes task decomposition, assignment, and scheduling for heterogeneous robot teams under capability and requirement uncertainty, using CVaR to quantify non-completion risk.

Sources

  • Robust Task Scheduling for Heterogeneous Robot Teams under Capability Uncertainty

概述

本文提出 Freeform Preference Learning（FPL），一种从自由形式人类偏好中学习机器人策略的方法。核心贡献在于允许标注者沿任意任务相关轴（如速度、安全性）提供成对偏好，学习语言条件化奖励模型，并训练奖励条件化策略，实现测试时行为可操控性。该方法在真实世界四任务和仿真双任务上显著优于现有偏好学习基线。

它改变了什么

传统偏好学习将人类反馈压缩为单一“整体质量”二元标签，这在长时程操作任务中带来两个根本问题：一是标注者被迫将多个相互竞争的质量维度（速度、安全性、放置质量）折叠成一个模糊信号，导致监督信息严重丢失；二是固定评估标准无法随策略能力提升而动态调整——当策略已能完成基本任务时，标注者希望关注更细粒度的执行质量，但单轴偏好框架无法表达这种演化。

FPL 真正改变的是将“偏好”从一种标量监督信号重构为一种多维、语言可寻址的监督协议。它不再问“哪个轨迹更好”，而是问“沿‘小心程度’这个轴，哪个轨迹更优”。这一转变使得奖励模型能够学习轴条件化的密集反馈，策略可以在测试时通过改变条件奖励值被引导到不同行为模式，而无需重新训练。这解决了偏好学习中长期存在的信用分配模糊与测试时可操控性缺失问题。

方法拆解

偏好收集协议

标注者并排观看两段 rollout 视频，用自然语言自由定义偏好轴（如“折叠质量”“速度”），沿每个轴提供成对偏好，可标注等价（等价标签被丢弃）。开放式任务中标注者先自行指定轴再提供偏好。

奖励模型

  • 骨干为预训练 Qwen 3.5 VL 4B，输入问题“What is the score for l_k ?”（l_k 为自由偏好轴名），传入第一人称和第三人称全序列图像。
  • 对序列进行 stride 采样，冻结视觉编码器，全微调其余部分，保持因果掩码（文本和过去图像可被关注，未来图像不可）。
  • 对全序列做单次前向，取每时间步第二张图像的最终视觉分隔符 token，经单线性层投影为分数，最终分数为所有时间步分数之和（Eq 4）。
  • 选择前 500 个 epoch 中验证准确率最高的模型。

奖励条件化

用奖励模型对整个数据集 D 推理，计算均值 μ 和标准差 σ，标准化 r_cond = (r − μ)/σ。通过文本将条件传入策略，格式为 l_k : round((r_φ(l_k, τ) − μ)/σ)，分数保留 1 位小数。

策略学习

  • 使用 π_0.5 开源权重作为 VLA 预训练，flow matching 动作头，动作块大小 16，rollout 8 个动作，全微调 30000 步，批大小 32。
  • 输入为腕部与第三人称相机视图及带文本条件的任务提示。
  • 仿真中策略为基于 diffusion transformer 的 flow-matching 策略，条件以浮点向量直接传入；为避免小网络过拟合条件向量，标准化后添加 0.2 噪声（仅仿真需要）。

迭代训练流程

收集自由形式偏好 → 训练奖励模型 → 提取偏好轴 → 训练策略 → 滚动出新数据 → 加入数据集，重复 N 次。

关键创新

  1. 语言条件化奖励模型：将奖励模型条件化在自然语言轴上，利用视觉-语言模型的预训练表示，使语义相似的描述（如“speed”“fast”“efficient”）自动共享表示，无需预定义固定轴集合。这是对固定轴奖励学习（如 [51]）的根本改进。

  2. 保留分解奖励而非折叠为标量：不将多维奖励加权求和，而是保留分解形式。这使得数据中不存在的行为组合成为可能（如“快速且小心”），并支持测试时无需重训练的可操控性——通过改变目标奖励条件化引导策略。

  3. 离策略奖励条件化策略提取：采用奖励条件化策略方法（基于 prior work）而非 PPO，使真实世界 RL 可行。PPO 对真实世界机器人学习样本效率太低，而条件化方法可直接利用离线数据。

关键结果解读

  • 仿真中 FPL 在双峰方形 throughput 上达到 1.19，超过训练数据中演示行为，而单偏好基线未超越演示。
  • 双峰方形反转任务中，FPL 是唯一用同一策略在原始和反转任务上都达到高性能的方法（1.24 vs 单偏好 0.78），验证测试时可操控性。
  • 真实世界 FPL 平均成功率 0.75，比次优方法（Filtered BC 0.37）提升 38 个百分点（由表内数值 0.37→0.75 计算）。
  • 偏好收集成本：自由形式偏好比单偏好快约 1.85 倍（每个标签的平均墙钟时间）。

边界与局限

  • 偏好学习需要收集人类偏好，比完全无监督方法更昂贵。
  • 测试时需手动选择合适的奖励值，自动化这一选择是未来工作方向。
  • 当前策略条件化在固定偏好轴集合上，扩展到处理可变轴是 VLA 能力增强后的有前景方向。
  • 仿真实验中，小网络从头训练更易过拟合条件向量，需添加 0.2 噪声；真实世界不需要此操作。
  • Fold Shorts 任务中，为匹配单轴基线标签数而收集等量标签成本过高，但仍分配更多时间收集以公平比较。
  • 未在真实世界使用状态空间（仿真优先迭代速度，直接基于状态）；未在仿真中使用预训练模型（全部从头训练）。

工程启示

复现 FPL 时，首先核对奖励模型的序列采样参数（序列长度 20，stride 长度因任务而异：Plate Toast 和 Setup Table 为 20，Fold Shorts 为 60，Place Cube 为 10），以及图像尺寸统一为 128x128x3。最容易踩坑的是仿真中条件向量过拟合问题——小网络从头训练时必须添加 0.2 噪声，但真实世界全微调 VLA 时不要加。策略训练使用 π_0.5 权重、flow matching 动作头、动作块大小 16、全微调 30000 步、批大小 32，这些参数在真实世界任务间保持一致。

对于下游团队，建议优先在仿真中验证测试时可操控性（如双峰方形反转任务），这是 FPL 区别于单偏好基线的核心优势。真实世界部署时，注意偏好轴会随策略能力提升而演化（如 Fold Shorts 中从粗粒度折叠质量转向细粒度褶皱标准），标注协议需支持这种动态调整。硬件需求为真实世界训练 1 块 H100，仿真可用 NVIDIA RTX 4500。
