Summary

OneTwoVLA: A Unified Vision-Language-Action Model with Adaptive Reasoning (OneTwoVLA), is a 2025 large vision-language-action model for robotic manipulation, introduced by Tsinghua University, Shanghai Qi Zhi Institute, Shanghai Artificial Intelligence Laboratory, Fudan University, Spirit AI.

Overview

OneTwoVLA is a unified vision-language-action model designed for robotic manipulation tasks. Its core design enables the model to adaptively switch between reasoning and action modes, explicitly outputting reasoning content during long-horizon tasks while maintaining efficiency during action execution. Built upon the π₀ architecture, this work introduces [BOR]/[BOA] tokens, reference image inputs, synthetic data augmentation, and interactive clarification training, validating reasoning-action consistency, multimodal action generation, and deployment efficiency on real Franka and ARX platforms.

What It Changes

Existing VLA models (such as π₀) face a fundamental contradiction in real-world manipulation: they either output actions only, lacking explicit reasoning about task semantics, which prevents planning adjustments or interactive clarification during long-horizon tasks; or they incorporate reasoning but couple it too tightly with action generation, leading to uncontrollable computational overhead during deployment. What OneTwoVLA truly changes is decoupling "reasoning" from the implicit accompanying state of action generation, turning it into a mode that can be explicitly triggered and independently timed. This means the model is no longer forced to perform deep reasoning every control cycle but can enter reasoning mode only at critical moments (such as task transitions, ambiguous instructions, or error recovery), operating in pure action mode the rest of the time, thereby achieving an engineering-acceptable balance between cognitive capability and real-time performance.

Another significant change lies at the data level. Rather than relying solely on real demonstrations, the authors used Gemini 2.5 Pro to generate 16,000 synthetic images—6,000 for visual grounding and 10,000 for long-horizon planning—with fisheye distortion and synthetic gripper augmentation applied. This is essentially an attempt to distill "reasoning capability" from vision-language pretrained models into robot policies, allowing the model to maintain some generalization on unseen objects, although experiments show this generalization remains fragile.

Method Breakdown

Dual-Mode Architecture

The model is built on π₀, taking as input the current image I_t, a reference image I_ref (corresponding to the observation at the time of the latest reasoning content), and proprioceptive states (current, 0.05s ago, and 0.25s ago). On the output side, two special tokens are introduced: - [BOR]: Begin reasoning; the model outputs updated reasoning content R̂ - [BOA]: Begin action; the model outputs action sequences

Data Segmentation Training

Demonstration data is divided into two types of segments: - Reasoning segments: The model learns to predict [BOR] → updated reasoning → [BOA] → actions, while also learning to predict actions based on old reasoning when reasoning has not been updated in time - Action segments: The model learns to predict [BOA] → actions, and optionally predicts [BOR] based on outdated reasoning to mitigate class imbalance in decision token prediction

Deployment-Time Temporal Ensemble

In action mode, the policy generates temporally overlapping action sequences every 0.2 seconds, and the actually executed actions are obtained via exponentially weighted averaging of multiple predictions to ensure smoothness. Reasoning mode is triggered only at critical moments, and reasoning token counts below 20 do not affect execution efficiency.

Synthetic Data and Error Recovery

  • 16,000 synthetic images: 6,000 for visual grounding (17 instruction-reasoning pairs per image), 10,000 for long-horizon planning
  • Recovery data specifically collected for failure scenarios such as oil bottle slippage and slotted spoon grasping failures
  • In long-horizon tasks, the model is trained to proactively ask clarifying questions when instructions are ambiguous (e.g., "Which cocktail would you like?")

Training Configuration

Each task is trained on 8×H100 GPUs for 30,000 steps, approximately 10 hours, using π₀'s hyperparameters.

Key Innovations

  1. Dual-mode design with reasoning-action decoupling: This is the most fundamental difference from existing VLAs. The model can explicitly switch between reasoning and action modes rather than reasoning every control cycle. This compresses cognitive overhead in long-horizon tasks to approximately 10% of total duration (8.7% reasoning in the Tomato-Egg task, 10.4% in the Mountain Fuji task), while computation time in action mode is only about 0.02s more than π₀ (0.082s → 0.102s).

  2. Reference image input mechanism: In reasoning mode, the model receives I_ref (the image observation corresponding to the latest reasoning content), preventing confusion between outdated text descriptions and current visual input. This is an ingenious engineering detail—it acknowledges that reasoning content may lag behind environmental changes and proactively uses visual anchors to correct for this.

  3. Synthetic data-driven reasoning capability distillation: Using Gemini 2.5 Pro to generate synthetic images and instruction-reasoning pairs transfers large language models' vision-language reasoning capabilities into robot policies. Although Open-World visual grounding success remains low (3/40), this provides a reproducible path for research communities lacking large-scale real robot data.

OneTwoVLA-VL achieves 87.5% (calculated from 35/40 in the table) success rate in Single-Env, significantly outperforming π₀'s 5% (calculated from 2/40 in the table). However, in Open-World, OneTwoVLA (without VL fine-tuning) achieves only 3/40, indicating that synthetic data contributes limited generalization for visual grounding and the model still relies on in-task fine-tuning.

Multimodal Action Experiments

  • "Grasp the cube": OneTwoVLA grasps left 9 times, right 11 times; π₀ always chooses right
  • "Grasp the bottle": OneTwoVLA grasps left 8 times, right 12 times; π₀ always chooses right
  • π₀'s action MSE is 56% higher than OneTwoVLA's

This validates that explicit reasoning content can break π₀'s unimodal behavioral bias, enabling the model to select different action targets based on reasoning content.

Boundaries and Limitations

The paper does not provide complete statistics for all failure cases but acknowledges the following limitations: - Fragile generalization to unseen objects: In Open-World experiments, performance is unstable when encountering objects not present in the training data (e.g., instructed to grasp a small basketball toy but persistently moving toward the chessboard) - Fine-grained manipulation remains unreliable: Occasional grasping failures causing drops in Tomato-Egg, and orange juice spillage when pouring in Cocktail - No correction mechanism for reasoning errors: In Hotpot, the model misjudges ingredient positions (instructed to grasp bok choy but attempts to grasp enoki mushrooms); the model's actions follow the erroneous reasoning, demonstrating that the high consistency between cognition and behavior is both an advantage and a risk - ARX platform capabilities underutilized: The omnidirectional wheeled base and 1-DoF torso lift mechanism were not enabled in experiments - Reasoning latency has an upper bound: Exceeding 100 tokens requires the robot to pause for several seconds, making long reasoning chains infeasible in real-time scenarios

Engineering Insights

When reproducing or adopting OneTwoVLA, the following aspects deserve the most attention:

  1. Verify reasoning-action data segmentation labels first: This is the core of training. The quality of reasoning segment versus action segment division directly determines whether the model learns to trigger reasoning at critical moments. It is recommended to validate [BOR]/[BOA] token prediction accuracy on small-scale data before scaling up.

  2. Selection logic for reference image I_ref: This is the most error-prone area. I_ref must strictly correspond to the image observation at the time the current reasoning content was generated; otherwise, the model will be confused by vision-text misalignment. It is recommended to record timestamp correspondences between reasoning content and images during data collection.

  3. Quality threshold for synthetic data: The authors tried GPT-4o but found its spatial understanding weak, ultimately switching to Gemini 2.5 Pro. If reproducing with other generation models, be sure to manually verify the accuracy of spatial relationship descriptions on small samples first; otherwise, visual grounding performance will degrade significantly.

  4. Reasoning frequency control during deployment: When reasoning tokens exceed 100, the robot pauses for several seconds. In actual deployment, reasoning trigger conditions should be set (e.g., task transitions, ambiguous instructions, failure detection) rather than letting the model freely decide when to reason. The 5 reasoning instances and 16 seconds of total reasoning time in Tomato-Egg serve as a reasonable reference upper bound.

  5. Demonstration collection for multimodal action experiments: 50 demonstrations per object, 200 total, with instructions not specifying left or right. If demonstrations implicitly contain positional bias during reproduction (e.g., always grasping the left side first), the model may fail to learn multimodal behavior. It is recommended to deliberately balance left/right choices in demonstrations.
