Summary

arXiv:2607.04816v1 Announce Type: new Abstract: Vision-Language-Action (VLA) models have become a promising paradigm for generalist robot manipulation, where visual-language representations are used to condition continuous action generation. However, these representations are not explicitly optimized for action conditioning, leaving the action expert to bridge the gap between multimodal understanding and precise motor control. Recent action-reasoning methods introduce additional modules to generate explicit action plans or action-space reasoning signals, demonstrating the benefit of action-level guidance but often requiring separate action-generation frameworks. We propose CAC-VLA, a Context-Gated Action Conditioning framework that learns a lightweight latent-action interface directly within the VLM. Instead of generating executable trajectories, CAC-VLA trains the VLM to predict coarse-to-fine latent actions, which are structured representations encoded from future action segments, and adaptively leverages them to condition the action expert via a context gate. This enables VLM-native action conditioning while calibrating the influence of latent-action guidance on expert action generation. Experiments on LIBERO and LIBERO-Plus demonstrate the effectiveness of CAC-VLA, achieving 98.3% average success rate on LIBERO and 89.5% LIBERO-Plus, suggesting that context-gated latent-action conditioning is an effective interface for continuous expert control.

概述

CAC-VLA 在 π0.5 架构内引入轻量级潜在动作接口，让 VLM 预测未来动作片段的编码表示，并通过上下文门控机制动态调节其对动作专家的影响。核心贡献在于将动作条件化从固定信号变为随生成状态自适应调节的残差注入，在 LIBERO 上达到 98.3% 平均成功率，并在真实世界拾放任务中显著超越基线。

它改变了什么

现有 VLA 模型把视觉-语言表示当作多模态理解与动作生成之间的唯一接口，但这类表示并未针对动作条件化进行显式优化。动作专家被迫从并非围绕动作组织的特征中推断任务级动作结构和细粒度运动指令，这本质上是在一个不匹配的表示空间里做连续控制。近期方法如 ACoT-VLA 证明了动作级指导的益处，但它们通常需要独立的动作生成框架，且将动作指导视为固定条件信号——这忽略了指导的可靠性会随场景、任务阶段和动作生成状态而变化的事实。

CAC-VLA 真正改变的是动作条件化的性质：从静态注入变为动态门控。它让 VLM 具备显式潜在动作接口，同时让动作专家在连续控制过程中自适应地校准该动作结构化指导的影响。这意味着动作专家不再被动接收固定强度的指导，而是可以根据自身当前状态决定接受多少潜在动作信息——这更接近人类操作中“边做边想”的机制，而非“先规划后执行”的开环模式。

方法拆解

整体框架

在 π0.5 架构基础上扩展，添加三个关键组件：VLM 端潜在查询 token、OAT 对齐的潜在动作预测头、上下文门控专家条件化。原始 π0.5 动作专家作为连续动作生成器保持不变。

潜在动作实例化

使用有序动作分词器（OAT）对未来动作片段编码，产生具有由粗到细结构的紧凑动作表示： - z_oat_t = OAT(a_{t:t+Hl−1})，其中 Hl 为潜在动作视界 - LIBERO 上 Hl=20，LIBERO-Plus 上 Hl=10 - 原始 OAT 潜在维度 Dz=4

VLM 端潜在动作预测

  • 向 VLM 输入追加 Nq=8 个可学习潜在查询 token q
  • 使用专家感知注意力掩码，防止动作专家 token 直接关注查询 token
  • 查询隐藏状态通过轻量预测头投影到 OAT 潜在空间：ẑ_t = Wz·LN(h^q_t)
  • 对齐损失：L_align = (1/Σm_i)·Σ m_i·SmoothL1(ẑ_{t,i}, z_oat_{t,i})

上下文门控动作条件化

条件源在训练时使用编码的 OAT 潜在目标，推理时使用 VLM 预测的潜在动作。关键设计是将检索与注入分离： 1. 交叉注意力根据当前动作状态检索潜在动作信息 2. 计算上下文门 g = σ(Wg·tanh(Wx·s_x + Wu·s_u))，其中 s_x 和 s_u 是对动作 token 维度的平均池化 3. 通过门控残差连接注入：x^+ = x + g⊙u

门为跨所有动作 token 共享的通道级门。设计理由：相比固定融合，自适应残差注入更好地保留专家连续动作建模能力——门控可以完全关闭注入（g→0），避免干扰专家自身的行为模式。

训练目标

L = L_act + λ_align·L_align，其中 λ_align=0.1，L_act 为原始流匹配动作专家损失。训练时冻结 OAT 分词器编码真实未来动作片段；推理时移除 OAT 分词器，专家仅由 VLM 预测的潜在动作条件化。

关键创新

1. 潜在动作作为显式中间接口：不同于将视觉-语言表示直接作为动作生成的输入，CAC-VLA 训练 VLM 预测未来动作片段的编码表示（不直接执行），作为动作专家的中间结构化指导。这创造了一个“动作语义”的显式通道，使 VLM 的多模态理解能力与动作专家的连续控制能力解耦。

2. 上下文门控的自适应条件化：门控机制不是简单的注意力加权，而是将检索（交叉注意力获取潜在动作信息）与注入（门控残差连接决定更新幅度）分离。门值随动作生成状态动态变化，允许专家在需要时完全忽略潜在动作指导。这解决了固定条件信号在任务阶段变化时可能产生误导的问题。

3. 训练-推理差异的优雅处理：训练时使用真实未来动作的 OAT 编码作为条件源，推理时切换为 VLM 预测的潜在动作。这种设计避免了训练-推理分布偏移——模型在训练时学习如何利用高质量动作结构信息，推理时则依赖 VLM 的预测能力，两者通过对齐损失衔接。

消融实验

  • 潜在动作视界：Hl=20 最优（98.3%），Hl=10 和 Hl=30 均为 98.1%
  • 条件化设计：去除潜在动作条件化降至 98.0%，去除上下文门降至 97.9%，完整模型 98.3%

边界与局限

真实世界评估仅限于单一桌面拾放任务、单一机器人本体（UR7e）和每任务 50 个演示，泛化性证据有限。当预测的潜在动作不准确或固定潜在动作视界与当前任务阶段不匹配时，模型仍可能失败，尤其在更长视界或更多样化的操作场景中。论文未明确门控机制的理论最优性分析，也未验证在更多任务族上的泛化性。套件级平均可能掩盖单个操作任务的语义阶段差异，作者虽补充了阶段级可视化，但未提供因果证据证明门控行为直接导致性能提升——因果贡献由主论文消融实验评估。

工程启示

复现时先核对三个关键点：OAT 分词器必须保持冻结，训练时编码真实未来动作片段作为对齐目标，推理时移除——这是训练-推理差异的核心；潜在动作视界 Hl 的选择在 LIBERO 上 20 最优，但 LIBERO-Plus 上 10 更佳，说明视界需要根据任务复杂度调整；上下文门的 dropout 率 0.1 对防止过拟合至关重要，去除门控会导致 Long 套件从 95.4 降至 94.0。

最容易踩坑的地方：潜在查询 token 的注意力掩码设计——必须防止动作专家 token 直接关注查询 token，否则专家会绕过潜在动作接口直接利用 VLM 特征，破坏条件化结构。另外，训练时条件源使用真实 OAT 编码、推理时使用预测值，这种差异需要确保对齐损失权重 λ_align=0.1 足够小，避免 VLM 过度拟合到真实动作编码而失去泛化能力。硬件需求为 4 块 NVIDIA A100 GPU，全局批大小 64，学习率峰值 1.25×10⁻⁵ 配合 10K warmup 步。
