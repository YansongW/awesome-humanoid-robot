Summary

We present a novel method for populating 3D indoor scenes with virtual humans that can navigate in the environment and interact with objects in a realistic manner. Institutions per source list: ETH Zürich、Google.

Overview

This paper proposes a reinforcement learning (RL) framework for synthesizing diverse, realistic, and sustained human motion in 3D indoor scenes. The method combines a learned generative motion primitive model with scene-aware locomotion and interaction policies, enabling virtual humans to navigate complex environments, avoid collisions, and perform fine-grained interactions such as sitting and lying down. The core contributions lie in body-surface keypoint control, integrating scene information into state and reward design, and data augmentation strategies, which significantly improve motion naturalness, diversity, and physical plausibility, outperforming existing baselines on multiple metrics.

What It Changes

What this work truly changes is the boundary of controllability and physical plausibility for the task of "human-scene interaction synthesis." Previous methods (e.g., SAMP) often generate motions in cluttered indoor environments with severe body-scene penetration, unrealistic contacts, and unnatural perception, and struggle with fine-grained body-part control. By directly incorporating scene geometry information (e.g., SDF, walkable maps) into the RL state and reward design, this paper enables the policy to autonomously avoid collisions rather than relying on post-processing fixes, fundamentally altering the robustness of the generation pipeline. Additionally, it breaks the dependence of multi-stage frameworks (e.g., [54,55]) on predefined frame counts, enabling more flexible continuous motion generation and providing a more application-ready technical path for virtual humans "inhabiting" dynamic interactive environments.

Method Breakdown

Framework Overview

  • Uses reinforcement learning (RL) to train two core policies: the locomotion policy, responsible for moving from an initial position to a target position in the scene while avoiding obstacles, and the interaction policy, responsible for executing fine-grained interactions such as sitting and lying down.
  • Uses body-surface keypoints as fine-grained control targets rather than relying solely on root nodes or joint angles, improving interaction precision.

Locomotion Policy Training

  • Trained in randomly synthesized scenes, with the scene generation process:
  • Initial rectangular region with side lengths of 2–7 meters.
  • Randomly sample furniture (chairs, beds, sofas, tables, desks) from ShapeNet, limiting the number of large objects.
  • Randomly rotate and translate objects, expanding boundaries.
  • Uses a navigation mesh for collision-free path finding, sampling paired initial-target positions; during training, initial body poses and orientations are randomized.
  • Scene information is integrated into state and reward via a walkable map (a 2D occupancy map, 16x16 grid covering 1.6m x 1.6m, centered at the pelvis and aligned with the body's forward direction, dynamically updated each timestep) and SDF features (precomputed 128x128x128 grid, with trilinear interpolation at test time).

Interaction Policy Training

  • Data source: PROX dataset, with static human-scene interaction estimates (SMPL-X bodies from LEMO, object meshes from COINS), using only "sit on" and "lie on" annotations.
  • Data augmentation: Redirects PROX static interactions to random ShapeNet objects by optimizing scaling, rotation, and translation fitting, with slight augmentation applied.
  • During training, static interaction frames are randomly sampled to obtain object meshes and target body markers; with a 0.25 probability, initial and target bodies are swapped to learn "standing" behavior.
  • Uses a modified COINS to synthesize target static interactions: because the original COINS has limited object diversity on PROX, the authors annotate pelvis-frame data on a more diverse ShapeNet subset, retrain PelvisNet, and keep BodyNet unchanged.

Key Design Decisions

  • The navigation mesh uses the pynavmesh library, creating two versions: agent radius 0.2 (for path finding) and 0.02 (for local walkable maps), balancing global planning and local obstacle avoidance precision.
  • SDF features are precomputed with trilinear interpolation, balancing accuracy and computational efficiency.

Key Innovations

  1. Scene-aware RL state and reward design: Directly embeds scene geometry information such as SDF distances and walkable maps into policy inputs and reward functions, making collision avoidance an inherent behavior of the policy rather than a post-processing step. This is a fundamental improvement over the traditional "generate-then-fix" paradigm, significantly enhancing physical plausibility (inter. pene. mean reduced from 15.61 to 3.40).
  2. Fine-grained body keypoint control: Uses body-surface keypoints as interaction targets rather than relying solely on joints or root nodes, greatly improving contact quality for actions like sitting and lying (contact increased from 0.87 to 0.96), while handling complex object shapes.
  3. Data augmentation and COINS retraining: By redirecting PROX static interactions to ShapeNet objects and retraining COINS's PelvisNet, the issue of insufficient object diversity in training data is resolved, enabling the policy to generalize to unseen object shapes—a key factor for achieving diverse motion.

Boundaries and Limitations

  • Penetration issues are not fully resolved: Only rewards are used to encourage penetration avoidance, without hard constraints; combining with physics simulation could address this, but the paper does not mention a concrete implementation.
  • Lying motion naturalness is insufficient: The motion primitive model fails to learn a comprehensive lying action space under limited training data (lying data in AMASS is only 167 seconds, while sitting is about 5K seconds).
  • Limited scene types: The locomotion policy is restricted to flat ground, relying on 2D occupancy walkable maps; extending to uneven outdoor terrain or multi-story buildings would require replacing the environment perception mechanism.
  • Static scenes only: Dynamic interactions (movable objects, other humans, animals, vehicles, and other autonomous agents) are not handled.
  • Training configuration not disclosed: Details such as network architecture, optimizer, learning rate, training steps, inference frequency, and hardware are not specified in the paper.

Engineering Insights

  • Reproduction priority: First verify the data augmentation pipeline (PROX redirection to ShapeNet) and COINS retraining details, as these are key to generalization; then confirm the impact of the dual navigation mesh radii (0.2 and 0.02) on path finding and local obstacle avoidance.
  • Common pitfalls: The precomputation of SDF features (128x128x128) incurs significant memory and computational overhead, requiring a balance between accuracy and speed; the dynamic update frequency of the walkable map directly affects real-time obstacle avoidance, so it is advisable to first validate whether the 16x16 grid resolution is sufficient for the target scene.
  • Guidance for downstream teams: If extending to additional interaction types (e.g., touching, carrying), additional training data collection and policy redesign are needed; if the target scene contains dynamic objects, the current framework is not applicable, and physics simulation or dynamic scene modeling should be considered.
  • Performance bottlenecks: Tree-based sampling during inference increases computational cost and may limit real-time applications; it is recommended to first evaluate inference latency on the target hardware before deciding to adopt this framework.
