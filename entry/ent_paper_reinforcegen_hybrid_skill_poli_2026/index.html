ReinforceGen: Hybrid Skill Policies with Automated Data Generation and Reinforcement Learning

摘要

ReinforceGen 是由研究团队提出的机器人长时域操作系统，它结合任务分解、数据生成、模仿学习与运动规划形成初始方案，并通过强化学习微调各组件。该系统仅需10次人类演示即可生成训练数据，在Robosuite基准测试中达到80%成功率，微调带来平均89%的性能提升。

来源与参考

  • ReinforceGen: Hybrid Skill Policies with Automated Data Generation and Reinforcement Learning (arXiv)

概述

ReinforceGen 提出一种混合技能策略框架，通过自动化数据生成与强化学习微调，解决多阶段机器人操作任务中姿态预测误差与技能执行失败的级联问题。该方法结合姿态蒸馏、终止条件微调与技能微调，在 Robosuite 的 5 个长时程任务上显著提升成功率与抗噪鲁棒性。

它改变了什么

多阶段操作任务的核心难点在于子目标预测与技能执行的级联误差——起始姿态预测偏差会直接导致后续技能失败，而现有方法（如 HSP-Priv）在动作噪声与轨迹偏差下鲁棒性不足。ReinforceGen 真正改变的是将“预测-执行”的静态流程改造为“预测-重规划-微调”的动态闭环，并引入强化学习对技能策略进行针对性优化，而非仅依赖模仿学习。这一转变使得策略在测试时能容忍更大的姿态误差与动作噪声，从而提升长时程任务的端到端成功率。

方法拆解

整体流程（Algorithm 1）

  1. 环境重置获取初始观测 o。
  2. 对每个技能 ψ_i，预测起始姿态 p ← ℐ_θi(o)。
  3. 使用运动规划器 planToPose(env, p) 生成轨迹 τ。
  4. 执行轨迹动作，并在执行中实时重新预测姿态 p'，若姿态距离超过阈值 ϵ 则重新规划轨迹。
  5. 当终止条件 𝒯_θi(o) ≠ 1 时，循环执行策略动作 a ← π_θi(o)，直到子目标成功。

姿态蒸馏（Sec. 4.1）

  • 将预测的起始姿态作为目标，通过运动规划器生成轨迹。
  • 实时重规划阈值设为 0.05（姿态距离），确保执行过程中姿态偏差可控。

终止拒绝（Sec. 4.3）

  • 当预测任务完成率低于 0.4 时，拒绝终止，避免过早结束导致任务失败。

技能微调（Sec. 4.4）

  • 使用 DrQ-v2 进行强化学习微调，超参数见表 5（学习率 1e-4、批大小 256、训练步数 2M 等）。

端到端蒸馏（Appendix C.6）

  • 在轨迹生成时添加高斯噪声 𝒩(0,1)，σ = 0.01；每个任务生成 3000 条成功轨迹。

姿态距离度量（Appendix E.2）

  • 位置距离 d_pos = √((𝐩₁−𝐩₂)ᵀ(𝐩₁−𝐩₂))
  • 旋转距离 d_rot = (1/π) · min{cos⁻¹(𝐪₁ᵀ𝐪₂), cos⁻¹(−𝐪₁ᵀ𝐪₂)}
  • 总距离 d_pose = d_pos + d_rot

关键创新

  1. 实时重规划机制：在执行过程中持续预测姿态并触发重规划，而非一次性生成轨迹后盲执行。这显著降低姿态预测误差对后续技能的影响，是提升长时程任务成功率的关键设计。
  2. 终止条件微调：通过拒绝低置信度的终止预测，避免任务提前结束。这一机制直接针对多阶段任务中“子目标误判”这一常见失败模式，与姿态蒸馏形成互补。
  3. 强化学习微调技能策略：在模仿学习基础上引入 DrQ-v2 进行微调，使策略在动作噪声下更具鲁棒性。实验表明，ReinforceGen 对动作噪声的耐受性高于 HSP-Priv，这是纯模仿学习方法难以实现的。

边界与局限

  • 论文未明确列出作者承认的局限性或未做之事。
  • 仅指出 Nut Assembly 原始螺母放置范围会产生不可达初始位置，因此将 x 范围缩减为 (−0.15, 0.15)，这可能限制该方法在更复杂或更真实场景中的泛化性。
  • 实验仅在 Robosuite 仿真环境中进行，未在真实机器人上验证，因此仿真到现实的迁移效果未知。

工程启示

  • 复现核对：首先确认 DrQ-v2 超参数（表 5）与数据生成设置（每任务 3000 条轨迹、σ = 0.01）是否与原文一致，这些是影响微调效果的关键变量。
  • 重规划阈值：0.05 的姿态距离阈值是核心超参数，过小会导致频繁重规划增加计算开销，过大则无法及时纠正偏差。建议在目标任务上先做敏感性分析。
  • 终止拒绝阈值：0.4 的完成率阈值需根据任务阶段数调整，阶段越多，过早终止的风险越高，可能需要降低该阈值。
  • 最易踩坑：Nut Assembly 的初始位置范围缩减（(−0.15, 0.15)）是作者为处理不可达状态而做的特殊处理，复现时若不注意此改动，可能导致训练失败或结果不可比。
