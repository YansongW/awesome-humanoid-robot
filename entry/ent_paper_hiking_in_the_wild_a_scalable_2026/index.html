脚落在哪里，比走得多快更重要

Hiking in the Wild: A Scalable Perceptive Parkour Framework for Humanoids

层级
智能层
审校

摘要

《Hiking in the Wild》提出了一种可扩展的端到端感知跑酷框架，用于实现人形机器人在复杂非结构化环境中的稳健徒步。该工作由研究团队开发，核心贡献包括：通过地形边缘检测与足部体积点结合的立足点安全机制，以及平坦补丁采样策略，在单阶段强化学习下直接映射原始深度输入与本体感知到关节动作，无需外部状态估计。全尺寸人形机器人实地实验表明，该策略支持最高2.5 m/s的速度穿越复杂地形。

来源与参考

  • Hiking in the Wild: A Scalable Perceptive Parkour Framework for Humanoids (arXiv)
  • 脚落在哪里，比走得多快更重要 project page

概述

本文提出一种可扩展的端到端感知跑酷框架，用于人形机器人在非结构化地形上的高速动态运动。作者利用高频深度图像直接训练策略，通过边缘感知惩罚、位置基速度命令和对抗运动先验提升鲁棒性与运动质量，并在Unitree G1上实现零样本sim-to-real迁移，最高跑步速度达2.5 m/s。

它改变了什么

现有感知运动方法要么依赖中间高度图模块，在高速度或未知野外环境中性能受损；要么采用显式落脚点控制，对状态估计漂移和重建伪影脆弱。本文真正改变的是：将感知-控制链路压缩为直接从原始深度图像到关节动作的端到端映射，消除了中间表征的瓶颈。同时，针对训练中常见的“奖励黑客”问题（策略通过非物理方式获得高奖励），引入位置基速度命令生成，使导航信号与机器人实际运动能力对齐。边缘感知惩罚机制则直接作用于地形几何，而非依赖隐式学习，显著提升了落脚安全性。

方法拆解

问题公式化

将感知人形运动建模为部分可观测马尔可夫决策过程（POMDP），使用PPO训练。

观测空间

  • actor观测：基座角速度𝝎_t∈ℝ³、投影重力向量𝐠_t∈ℝ³、速度命令𝐜_t∈ℝ³、关节位置𝐪_t∈ℝ²⁹、关节速度𝐪̇t∈ℝ²⁹、上一动作𝐚，滑动窗口历史h步，训练时加噪声。}∈ℝ²⁹、深度图像𝐈_t∈ℝ^{W×H
  • critic观测：无噪声actor观测加基座线速度𝐯_t∈ℝ³（非对称架构）。

动作空间

策略输出目标关节位置𝐚_t∈ℝ²⁹，PD控制计算力矩：𝝉_t = k_p(𝐚_t − 𝐪_t) − k_d 𝐪̇_t，增益自BeyondMimic。

奖励函数

总奖励R = r_task + r_reg + r_safe + r_amp，分别促进命令跟踪、能量效率、约束满足和自然运动风格。

高效深度合成

  • 使用NVIDIA Warp实现GPU光线投射，根据相机外参（光心𝐩_c∈ℝ³、方向矩阵𝐑_c∈SO(3)）计算径向距离d_{i,j}，再投影到主轴得正交深度z_{i,j}。

双向深度对齐

  • 模拟管道：裁剪缩放、范围相关高斯噪声（ϵ∼𝒩(0,σ²)）、视差伪影合成、高斯模糊、归一化、OOD扰动（伯努利dropout，概率P_ood）。
  • 真实管道：裁剪缩放、深度修复、高斯模糊。
  • 目标：P(ℱ_sim(d_sim)) ≈ P(ℱ_real(d_real))。

时间深度聚合

  • 跨步采样：历史缓冲m帧，时间步长ℓ，单帧延迟模拟传感器延迟。序列ℋ_t = {I_{t−k·ℓ} | k=0,…,m−1}。

地形边缘接触惩罚

  • 边缘检测器比较相邻面二面角与阈值τ，构建圆柱碰撞网格𝒮。
  • 每脚碰撞流形内分布体积点𝒫，Warp并行距离查询计算穿透深度。
  • 惩罚项：r_vol = −Σ_{i=1}^{|𝒫|} ‖𝐝_i‖·(‖𝐯_i‖ + ϵ)，ϵ = 10⁻³。

位置基速度命令

  • 平坦补丁采样生成导航目标（半径r内最大高度差<δ）。
  • 速度命令：v_x = clip(k_v·x_g, 0, v_max)，ω_z = clip(k_ω·atan2(y_g, x_g), −ω_max, ω_max)，v_y = 0。
  • 速度限制按地形类别自适应；部分智能体在平坦地形接收纯转向命令。

对抗运动先验（AMP）

  • 参考数据50 Hz收集：MPC合成数据、NOKOV动捕人类运动、LAFAN跑步数据。
  • 行走数据集𝒟_walk（T = 379.62 s），跑步数据集𝒟_run（T = 1.54 s），分别训练避免模式崩溃。
  • 判别器输入短序列状态𝐒_t，使用MSE损失L_D = 𝔼_ℳ[(D(𝐒)−1)²] + 𝔼_𝒫[(D(𝐒)+1)²]，加梯度惩罚和权重衰减。
  • 风格奖励：r_t = max[0, 1 − 0.25(D(𝐒_t)−1)²]。

关键创新

  1. 端到端深度图像策略：直接利用高频深度图像训练策略，无需中间高度图或显式落脚点，在未知野外环境中保持鲁棒性。这是对现有感知运动范式的根本简化。
  2. 边缘感知接触惩罚：通过几何检测地形尖锐边缘并施加体积穿透惩罚，而非依赖隐式学习或启发式规则。该机制在模拟中显著提升小障碍物（Small Box）上的成功率（99.09% vs 93.17%），且能泛化到未见地形（Stones、Stakes）。
  3. 位置基速度命令生成：解决训练中“奖励黑客”问题，使导航信号与机器人运动能力对齐。消融显示移除该机制后Small Box成功率从99.09%降至90.68%，平均到达时间从8.03 s增至11.32 s。

真实世界部署

  • 最大跑步速度2.5 m/s，成功穿越32 cm高平台和50 cm宽间隙。
  • 每种地形和步态组合10次试验；长时间测试连续行走4分钟无摔倒。

关键结果解读

  • 深度历史对性能至关重要（移除后Small Box成功率降至1.66%），说明时间聚合对感知运动不可或缺。
  • AMP移除导致完全失败（0.00%），表明运动先验对自然风格和稳定性至关重要。
  • 边缘惩罚在Stair Descent上着陆面积提升显著（0.87→0.94），验证了其对落脚安全性的直接贡献。

边界与局限

  • 感知仅依赖单个前向深度相机，缺乏向后或侧向运动能力，作者明确提及未来可安装多相机实现全方位感知。
  • 同时训练多种地形和步态可能导致模式崩溃，统一策略性能低于专门策略，作者建议研究先进多任务RL技术。
  • 跑步数据集仅1.54 s，可能限制高速运动风格的多样性；论文未明确该数据量是否足以覆盖复杂跑步模式。
  • 真实世界评估未提供失败案例的详细分析，论文未明确在何种地形或条件下策略会失效。

工程启示

  • 复现优先级：先核对深度对齐管道（模拟与真实管道的噪声、模糊、修复参数），这是sim-to-real成功的关键。其次确认AMP数据集的采集与重定向流程，行走数据（379.62 s）与跑步数据（1.54 s）的差异可能影响风格质量。
  • 易踩坑点：深度历史长度（8帧）和跨步采样参数（m、ℓ）需严格匹配，消融显示移除历史导致成功率骤降至1.66%。位置基速度命令的增益（k_v、k_ω）和速度限制（v_max、ω_max）需按地形类别调整，否则可能引发奖励黑客。
  • 硬件选型：Intel RealSense D435i（480×270→36×18）和Jetson Orin NX（50 Hz推理）是已验证组合，若更换相机或计算平台需重新校准深度对齐参数。
  • 下游团队：若需部署到其他机器人（如四足），需重新采集AMP数据并调整PD增益；边缘检测器的二面角阈值τ需按机器人足部尺寸重新标定。
