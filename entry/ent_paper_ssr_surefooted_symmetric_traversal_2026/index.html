第一视角视觉驱动的人形机器人开放世界稳健穿越

SSR: Scaling Surefooted and Symmetric Humanoid Traversal to the Open World

摘要

SSR 是一个面向开放世界的仿人机器人高效端到端视觉导航框架，由研究团队提出。其核心贡献包括：通过想象落脚点引导减少边缘滑移，利用等变潜空间对称增强实现高效双边协调，并采用地形特定多判别器运动先验促进类人行为。实验表明，SSR 在楼梯、宽间隙、高平台等多样真实地形上实现了安全稳定的长距离行走。

概述

SSR是一个面向开放世界穿越的统一单阶段端到端强化学习框架，由AgiBot团队提出，直接从自我中心深度图像和本体感觉联合学习可靠落脚点与对称自然的全身运动。核心贡献在于将落脚点安全评估从接触时刻前移到摆动阶段（想象落脚点引导）、在潜在空间实现镜像等变对称增强（而非输入级增强），以及用地形特定判别器注入人类运动风格，最终在仿真和实机上实现了对楼梯、间隙、高台等异构地形的近100%成功率与1.3 km户外连续穿越。

它改变了什么

此前基于学习的人形穿越方法要么依赖多阶段流水线（如HPL）导致误差累积，要么在输入级做对称增强导致视觉循环策略的训练成本高到难以承受（InpSym峰值内存超24 GB，需48 GB显卡）。更根本的问题是，落脚点安全性评估通常只在接触时刻或接触后发生，摆动腿在空中的动作缺乏密集的早期引导信号，导致策略无法在触地前主动规避边缘和悬空区域。SSR真正改变的是将“安全落脚”从稀疏的接触事件奖励转化为密集的接触前引导，同时把对称性先验从昂贵的输入空间搬移到紧凑的潜在空间，使训练在单张RTX 4090上即可完成（内存从28.8 GB降至23.7 GB）。这解决了此前对称性学习与视觉策略耦合时“计算贵、易脆弱”的痛点，让左右对称的全身协调行为不再依赖大量镜像数据增强。

方法拆解

问题建模与架构

  • 将运动建模为POMDP，PPO优化，非对称actor-critic。策略观测 o_t = (o_{t-h+1:t}^p, I_t)，其中本体感觉 o_t^p ∈ ℝ^72（基座角速度、投影重力、速度指令、关节位置/速度、上一动作），深度图 I_t ∈ ℝ^{36×36}；动作 a_t ∈ ℝ^21 为关节位置目标。
  • Critic使用特权信息（地面真值速度、接触状态、肢体位置、脚/身体周围高度图）。
  • 策略由循环跨模态编码器（CNN编码图像 + MLP编码本体感觉 + GRU融合）、运动状态估计器（预测基座速度 v̂_t）和MoE actor组成。编码器三个头 ẑ_t^f, ẑ_t^b, ẑ_t^p 分别解码脚部高度图、基座高度图和下一本体感觉（VAE）。

想象落脚点引导（Imagined Foothold Guidance）

  • 训练中，落脚点想象模型从特权状态 s_t 和动作 a_t 预测每只脚的预期接触分布 q_{i,t}(p) = N(p; μ̂_{i,t}, (σ̂_{i,t})²I)，用高斯负对数似然监督：L_pred ∝ Σ_i (||p_{i,t}^* - μ̂_{i,t}||² / (2σ̂²) + 2log σ̂)。
  • 支撑缺陷 ρ(p) 在22.5 cm×10 cm脚掌补丁上每2.5 cm采样，度量接触点附近支撑重叠比例。落脚点奖励 r_t^f = exp(-(Σ_i ρ̃_{i,t})² / σ_f)，其中支撑脚用当前接触点评估，摆动脚用想象分布下的期望缺陷（离散高斯加权采样近似）。
  • 关键设计：仅在训练早期步态稳定（地形课程超过预设等级）后才启用接触前引导，避免噪声目标干扰；斜坡地形上强制 ρ̃ = 0 避免抑制倾斜接触。

等变潜在空间对称增强

  • 输入级镜像增强对视觉循环策略代价高（需重新编码镜像图像并展开GRU隐藏状态）。SSR只编码原始观测一次，然后镜像紧凑的actor输入 o_t^a = [o_t^p, v̂_t, ẑ_t]。
  • 编码器强制镜像等变：时间本体感觉经固定重组算子 𝒯 映射为左右分支（各 ℝ^{42×h}），镜像变换简化为分支交换 ℳ_c；CNN用lift卷积（K_l = [k_l; ℳ_2D k_l]）提升图像为成对通道，后续层用约束核 K_nl = [[k_a, k_b]; [ℳ_2D k_b, ℳ_2D k_a]] 保持对称结构。
  • 训练时镜像轨迹 τ^g = (M_o o_t^a, M_s s_t, M_a a_t) 附加到原始rollout用于PPO更新，不增加额外前向编码成本。

跨地形运动先验

  • 为每种地形类型（Slope、Stairs、Discrete、Gap、Platform）各训练一个判别器 D_i，从五帧历史 ψ_t（每帧63维）建模地形特定参考运动风格，提供AMP风格奖励。数据来自定制动作捕捉和AMASS子集（总时长：Slope 261.3 s，Stairs 295.8 s，Discrete 136.0 s，Gap 174.5 s，Platform 181.6 s）。

关键创新

  1. 接触前落脚点引导：将落脚点安全从“接触时评估”变为“摆动中密集引导”，通过想象接触分布和支撑缺陷度量，让策略在触地前就把脚导向平坦区域。这是对HPL/PIM等“接触后反馈”范式的根本改进，直接减少了边缘接触和滑倒。
  2. 潜在空间等变对称增强：通过构造镜像等变编码器（等变MLP/GRU/CNN的完整证明链），将对称性学习从输入级搬到潜在空间，训练内存降低18%（28.8→23.7 GB），使单张RTX 4090可训练，同时保留左右脚交替主导的灵活性（NoSym则固定主导腿）。
  3. 地形特定多判别器：用5个判别器分别建模不同地形的运动风格，而非共享判别器，显著降低峰值脚接触力（如Stairs Up从538.5 N降至507.7 N）和平均功率，使风格先验不被地形差异破坏。

对称性消融

  • SSR在八方向速度指令下跟踪更准，原地转向轨迹近镜像对称；NoSym累积漂移、固定主导腿。
  • SSR相比InpSym：相同训练时间回报更高、更早达到最大难度、GPU内存28.8→23.7 GB（-18%）。

户外与跨平台

  • 工业遗产公园1.3 km、40分钟连续穿越，无重置；零样本OOD泛化包括穿孔网格地板、1.3 m宽开式楼梯、螺旋楼梯。
  • 跨平台到DEEP Robotics DR02（1.8 m高、70 kg）：Stairs Up/Down 15/40 cm成功率100%，Gap 80 cm成功率100%，Platform 45 cm成功率95%（由表内数值 253.0→12.6 计算）。

边界与局限

  • 固定前向深度相机（俯仰50°）限制感知覆盖，全向穿越（如侧向或后退）困难；作者建议多视角感知或主动视点调整。
  • 严重深度感知失败（如强阳光下镜面反射）仍可能扭曲局部几何，导致落脚点误判；需更鲁棒的感知嵌入。
  • 仅关注脚-地面交互，上体接触（如手扶、攀爬）未探索；多接触技能和更丰富的人类演示可进一步扩展机动性。
  • 论文未明确：训练数据量、超参数敏感性分析、以及仿真到实机的sim-to-real gap量化。

工程启示

  • 复现优先级：先核对地形课程（5种地形×20难度，8 m×4 m区域）和命令范围（Table 4/5），这是训练稳定性的基础。其次检查等变CNN的核约束实现（K_nl = [[k_a, k_b]; [ℳ_2D k_b, ℳ_2D k_a]]），这是对称性增强的核心，最容易出错。
  • 最容易踩坑：想象落脚点引导的启用时机（课程等级阈值）和斜坡地形特殊处理（ρ̃=0）必须严格遵循，否则早期噪声目标会破坏策略；支撑缺陷采样（22.5 cm×10 cm补丁、2.5 cm间隔）的分辨率直接影响奖励质量。
  • 硬件与部署：深度渲染用NVIDIA Warp实现（每像素并行，不重建BVH），实机用Jetson AGX Orin + ONNX Runtime 50 Hz推理；关节增益（Table 14）需按平台调整，跨平台时保留相同训练流程但需重新收集运动先验数据。
  • 下游团队：若目标平台无腰装相机或相机俯仰角不同，需重新训练（感知分布变化）；若追求全向穿越，需先解决感知覆盖问题，SSR的固定前向相机是硬约束。
