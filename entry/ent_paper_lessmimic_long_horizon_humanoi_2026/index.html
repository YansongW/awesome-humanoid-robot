LessMimic: Long-Horizon Humanoid Interaction with Unified Distance Field Representations

摘要

LessMimic 是 2026 年提出的一种用于人形机器人长时域交互的统一距离场表示方法。它通过单一策略实现无参考运动推理、几何泛化与多技能组合，在 PickUp 和 SitStand 任务上对 0.4x 至 1.6x 尺寸物体保持 80-100% 成功率，并支持多达 40 个连续组合任务。

来源与参考

  • LessMimic: Long-Horizon Humanoid Interaction with Unified Distance Field Representations (arXiv)
  • LessMimic: Long-Horizon Humanoid Interaction with Unified Distance Field Representations project page

概述

LessMimic 提出 ℱ1，一个 4.2B 参数的预训练 VLA 框架，通过 Mixture-of-Transformer 架构将视觉预见生成集成到动作决策中，将控制问题重构为“预见引导的逆动力学”。核心贡献在于用三阶段训练（对齐、预训练、适应）和渐进式注意力机制，让模型先预测未来视觉状态再推断动作，在动态和长时程任务上显著超越反应式基线。

它改变了什么

现有 VLA 模型（如 π0、gr00t-N1）本质上是反应式的：输入当前观测，直接输出动作，缺乏对未来场景的显式推理。这导致在动态环境（移动目标、人机交互）和长时程任务（多步骤、误差累积）中行为短视、鲁棒性差。视频预测方法（如 VPP）虽引入时间建模，但未整合 VLM 语义，预测缺乏任务导向性。LessMimic 真正改变的是将“预测未来”从可选的辅助模块提升为决策管线的核心环节——动作不再仅由当前状态决定，而是由预期的视觉结果反推。这一转变使策略具备前瞻性，能主动规避动态干扰，而非被动响应。

方法拆解

架构：Mixture-of-Transformer (MoT)

  • 理解专家：从 π0 初始化，SigLIP 编码当前观测，与语言提示融合，decoder-only transformer 处理。
  • 生成专家：采用 next-scale prediction，残差 VQ-VAE 将观测分解为 16×16 patches 和 k 个空间尺度，自回归生成离散 tokens，解码为预测未来图像。
  • 动作专家：以语言目标、当前观测和生成的预见图像为条件，用 flow-matching 目标预测 chunked 动作序列。

注意力机制：UGA 渐进式注意力

  • 专家内双向注意力（生成专家内为因果、尺度条件模式）。
  • 专家间因果层级：生成专家关注理解专家，动作专家关注两者，无反向信息流，防止信息泄漏。

三阶段训练

  1. Pretrain Stage I：冻结理解专家，训练生成专家合成未来视觉 tokens，teacher forcing 稳定优化。
  2. Pretrain Stage II：联合优化所有专家，在大型公共数据集（330.9K 轨迹、73.8M 帧）上预训练，目标 L_total = L_gen_pred + λ · L_action（λ=0.1）。
  3. Post-train Stage：任务特定微调，适应新本体和精细技能。

推理

  • 先预测未来视觉状态（限制为 4 个尺度），再基于预见预测动作。
  • 总推理延迟约 235ms（图像处理 18ms + 时间下采样 28ms + 编码 18ms + 预见生成 76ms + 动作前向 95ms）。

关键创新

  1. 预见引导的逆动力学：将动作生成从“状态→动作”映射重构为“期望未来状态→动作”推断，这是对 VLA 决策范式的根本性改变。它让策略具备前瞻性，能主动规避动态干扰，而非被动响应。
  2. MoT 三专家架构：理解、生成、动作三个专用专家各司其职，通过 UGA 渐进式注意力实现信息单向流动。这种设计避免了多任务联合训练中的梯度冲突，且生成专家可独立预训练，降低优化难度。
  3. Next-scale prediction 机制：用多尺度残差 VQ 将视觉预测转化为 token 级分类问题，平衡计算效率和预测精度。推理时限制为 4 个尺度，在实时性（235ms）和预测质量间取得最优平衡。

边界与局限

论文未明确列出作者承认的局限。但根据事实要点推断：模型未在大规模生成数据集上预训练，细粒度物体细节（如可变形物体）的视觉保真度有限；图像 token 准确率绝对数值较低（约 40–45%）；长时程任务中性能随序列推进逐渐下降，归因于误差累积和时间推理难度。未来工作方向包括扩展到移动、灵巧操作、多智能体协作，引入结构化世界模型或物理先验，集成强化学习或在线适应。

工程启示

复现 ℱ1 时，先核对三阶段训练的超参数配置（阶段 I 批量 1280、学习率 3.0×10⁻⁴、512K 步；阶段 II 批量 2880、学习率 5.0×10⁻⁵、100K 步；阶段 III 批量 128、学习率 5.0×10⁻⁵）。最容易踩坑的是 Stage II 预训练——消融显示移除该阶段后性能大幅下降甚至低于 π0，因此公共数据集预训练是泛化能力的关键来源。推理时预见预测限制为 4 个尺度是实时性（235ms）与精度的平衡点，2 尺度会损失动态任务性能（Carrot 29.2%），6 尺度虽略优但延迟增加。部署时注意有线以太网连接，报告数字排除无线传输延迟。生成质量评估建议使用 Qwen2.5-VL-32B-Instruct，从场景一致性、物体一致性、任务进度跟随三个维度打分。
