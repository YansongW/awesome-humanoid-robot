Koopman DCM: Unstable Eigenfunctions as Data-driven Representations for Legged Balancing

Koopman DCM: Unstable Eigenfunctions as Data-driven Representations for Legged Balancing

领域
AI 模型与算法
层级
智能层
审校
AI 全文核验

摘要

本文提出将经典DCM（发散运动分量）重新定义为完整机器人动力学的Koopman本征函数，通过数据驱动方式直接从真实机器人测量-动作历史中学习，摆脱对简化模型（如LIP）和模型参数（质心高度）的依赖。作者在轮式双足机器人Cookie和仿真Unitree G1上验证了该方法，学习到的DCM在ZMP跟踪和抗扰动平衡控制上优于传统运动学DCM，并成功应用于约束MPC。

来源与参考

  • arXiv:2607.18760 Koopman DCM: Unstable Eigenfunctions as Data-driven Representations for Legged B

它改变了什么

传统DCM控制的核心假设是质心高度恒定，其自然频率 ω = g / h 完全由模型参数决定，这在实际机器人上往往不准确——尤其是像Cookie这样没有外展-内收关节、横向CoM只能通过腿长变化间接控制的平台，模型误差会直接转化为控制性能损失。本文真正改变的是将DCM从“模型推导的物理量”转变为“数据拟合的Koopman本征函数”，从而让DCM的动力学特性（特征值 ω 和本征函数 ξ ）完全由真实系统数据决定，而非由理想化模型强加。

另一个关键转变在于Koopman分析的目标选择。以往Koopman方法多关注接近零的特征值（捕捉守恒量或缓变模态），而本文刻意搜索具有大正特征值的不稳定特征对——这正是DCM的本质：它描述的是系统发散最快的方向，控制它的意义在于通过反馈将其稳定。这种“反向利用不稳定本征函数”的思路，为Koopman理论在机器人控制中的应用开辟了新方向。

方法拆解

问题形式化

将DCM学习建模为对 ( ω , θ ) 的一阶非线性优化，其中 ω 为特征值（标量）， θ 为MLP编码器参数。输入为延迟嵌入的测量-动作历史： z_k = (y_{k-H}, u_{k-H}, …, y_{k-1}, u_{k-1}, y_k)

两个关键约束

  1. 特征值正性： ω > 0 ，确保学习到的是不稳定方向（发散分量）。
  2. DCM线性动力学约束： ξ̇_θ = ω(ξ_θ - u) ，该约束将控制输入 u 限制为与状态无关的线性耦合，作为归纳偏置简化学习。

损失函数设计

  • DCM动力学损失（零阶保持输入下离散化）： ξ_{k+1} = e^{ωδt}ξ_k + (1 - e^{ωδt})u_k 一阶损失 ℓ_DCM^(0) 为残差的 ℓ2 范数期望。
  • CoM预测损失：利用LIP结构 ċ = ω(ξ - c) ，离散递推为： c_{k+1} = e^{-ωδt}c_k + (1 - e^{-ωδt})(ξ_k + ξ_{k+1})/2 添加此损失以避免平凡最小值 (ω, ξ_θ) ≡ (0, 0) 。

资格迹（TD(λ)变体）

定义 γ := e^{-ωδt} ∈ (0, 1) ，将DCM递推重写为Bellman方程形式，引入TD(λ)损失 ℓ_DCM^(λ) 和 ℓ_CoM^(λ) ，缓解真实数据上收敛到过低特征值的问题。最终目标： ℓ^(λ) = ℓ_DCM^(λ) + w_CoM · ℓ_CoM^(λ)

MPC应用

将横向行走任务公式化为有限时域 N 步约束线性二次最优控制问题： - 状态：DCM ξ_k - 输入：ZMP u_k - 动力学：离散DCM递推 - 硬约束：|ξ_k| ≤ ξ_max ， |u_k| ≤ u_max （支撑多边形，±1归一化单位）

训练细节

  • 编码器：两层隐藏层MLP，宽度128，tanh激活
  • 频率参数化： ω = exp(ω̃) 保证正性
  • 优化器：Adam，学习率 3×10^{-4} ，批大小1024块
  • 块采样：每次迭代采样长度 (m+1) 的块，m = 5H ，跨片段边界块丢弃

关键创新

  1. DCM的Koopman本征函数重新定义：首次将DCM从模型推导的物理量转化为数据驱动的Koopman本征函数，使DCM的动力学特性完全由真实系统数据决定。这一创新打破了传统DCM对简化模型（LIP）和精确模型参数（质心高度）的依赖，为复杂机器人平台（如无外展-内收关节的轮式双足）提供了更准确的平衡控制表示。

  2. 刻意搜索不稳定特征对：与以往Koopman分析关注接近零的特征值不同，本文专门搜索具有大正特征值的不稳定特征对。这一反直觉的选择抓住了DCM的本质——描述系统发散最快的方向，并通过反馈控制将其稳定。这种“反向利用”思路为Koopman理论在控制领域的应用提供了新范式。

  3. CoM预测损失作为正则化：通过引入CoM预测损失，有效避免了DCM损失陷入平凡最小值 (ω, ξ_θ) ≡ (0, 0) 。这一设计决策在LIP模型上验证了其必要性——当 w_CoM = 0.1 时，学习到的 ω̂ = 0.352 rad/s 远低于真实值 5.0 rad/s，而 w_CoM = 1 时恢复至 4.975 rad/s（由表内数值计算，相对误差 0.5%）。

实验与结果

LIP模型验证

在LIP模型上验证学习管线，地面真实自然频率 ω* = 5.0 rad/s。训练收敛至 ω̂ = 4.9992 rad/s，相对误差 1.6×10^{-4}（由表内数值计算）。最终验证残差：ℓ_DCM^(0) = 5.4×10^{-9} ，ℓ_CoM^(0) = 3.9×10^{-9} 。

边界与局限

  • 输入耦合限制：输入耦合被固定为线性且与状态同速率 ω ，更一般的耦合 ∇ξ·B(x) 及更一般的DCM动力学（如变高倒立摆中的双线性形式 ξ̇ = ωξ - λz ）留待未来工作。
  • ZMP驱动未建模：遵循DCM反馈惯例，假设ZMP被瞬时控制，未建模ZMP的驱动方式；未来可拟合ZMP侧因子以丰富输入耦合。
  • 未做仿真到硬件迁移：本文直接在真实机器人上训练，规避域适应问题；未验证在仿真中训练后迁移到硬件的可行性。
  • LIP模型结论的泛化性：LIP模型上延迟嵌入视界不敏感，但真实机器人上最佳为 H=10 ，说明简化模型结论不能直接推广到真实系统。

工程启示

  • 先核对数据质量：训练数据是在比例DCM反馈律下收集的闭环数据，观测DCM为运动学LIP估计 c + ċ/ω 。这意味着学习到的 ξ_θ 隐式继承了反馈控制器的行为模式，复现时需确保数据收集策略与论文一致，否则学习到的本征函数可能偏离真实系统特性。
  • CoM损失权重是关键超参数：从实验看， w_CoM = 1 是最优选择，过小（0.1）导致特征值严重低估，过大（100）导致过拟合。复现时建议从 w_CoM = 1 开始，并监控学习到的 ω̂ 是否接近物理直觉值。
  • 延迟嵌入视界需针对平台调优：LIP模型上视界不敏感，但真实机器人上 H=10 最优。对于不同平台，建议扫描 H ∈ {5, 10, 20} ，并注意块长度 m = 5H 与训练数据量的匹配。
  • MPC应用注意约束设置：ξ_max = 0.85 和 u_max = 1 是针对G1平台调优的，换平台时需根据支撑多边形和运动学限制重新标定。QP求解器（ProxQP）在 N = 50 时实时性满足100 Hz控制频率，但计算余量有限。
  • 最易踩坑之处：特征值正性约束通过 ω = exp(ω̃) 参数化实现，但训练初期 ω̃ 可能震荡导致 ω 过大或过小。建议对 ω̃ 加梯度裁剪，并监控训练过程中 ω 的演化，避免发散。
