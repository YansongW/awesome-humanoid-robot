摘要

Learning to Grasp Anything by Playing with Random Toys is a 2026 work on manipulation for humanoid robots.

来源与参考

  • Learning to Grasp Anything by Playing with Random Toys project page

概述

该论文提出一种极简的深度强化学习框架，通过课程学习与镜像对称损失，让多种形态的机器人（双足、四足、六足）从零开始自然涌现出类似生物的对称步态。核心贡献在于将对称性约束从奖励函数移入策略优化目标，并设计无需预训练、形态无关的虚拟助手课程机制。

它改变了什么

现有DRL生成的跑步控制器虽然能完成任务，但运动质量与生物系统差距明显：抖动、高频、能耗高，且对称形态常产生不对称步态。直接惩罚能量或使用轨迹级对称性度量，要么权重过低形同虚设，要么引入延迟稀疏奖励导致学习困难。本文真正改变的是将“对称性”从奖励信号中剥离，作为策略参数的显式正则项，同时用连续课程空间替代离散任务序列，让“自然运动”作为副产品涌现而非被强行塑造。

方法拆解

奖励函数设计

r(s,a) = w_v E_v(s) + E_u(s) + w_l E_l(s) + E_a + w_e E_e(a) - E_v：基于最近2秒平均速度与目标速度的误差，鼓励前进 - E_u：躯干直立惩罚，权重分轴独立 - E_l：质心偏离前进方向的惩罚 - E_a：存活奖励 - E_e：关节扭矩惩罚，权重极低（论文未明确具体值），仅作调节

课程学习

  • 课程空间由虚拟PD控制器参数 x=(k_p,k_d) 定义，起点 x₀=(2000,2000)
  • 平衡力阻尼增益为 0.1·k_p，推进力比例增益为 0
  • 两种变体：学习者中心（回报达阈值即更新）与环境中心（需同时通过平衡测试）
  • 环境中心中 x_end=(k²)%·x_begin，R̄=g%·AvgReturn(B)，g=70，终止条件 ε=5
  • 连续课程重叠是关键，允许技能迁移

镜像对称损失

L_sym(θ) = Σ_{i=0}^{B} ||π_θ(s_i) - Ψ_a(π_θ(Ψ_o(s_i)))||² - 每次迭代 B=20000 样本，权重 w=4 - 加入PPO目标而非奖励函数，因 L_sym 显式依赖策略参数，放入奖励会破坏策略梯度定理假设

关键创新

  1. 对称性作为策略正则而非奖励：避免延迟稀疏奖励，且不干扰策略梯度理论框架，这是方法论上的关键突破
  2. 形态无关的连续课程空间：基于SPD控制器，无需预训练或形态学知识，同一框架直接适用于双足、四足、六足
  3. “自然运动”涌现而非设计：不依赖运动捕捉或有限状态机，仅通过简单生物力学原理（直立、前进、低能耗）驱动，对称步态是优化过程的副产品

实验与结果

在四种形态（双足下半身、完整人形、四足、六足）上评估，与三个基线对比：无镜像损失、无课程学习、两者皆无。

配置 结果
无课程学习 策略无法前进或保持平衡
无镜像损失 需显著更多试验，产生不对称运动
完整方法 自然对称步态，能耗低于基线（论文未明确具体数值）

关键发现：课程学习是“能否学会”的门槛，镜像损失是“学得像不像”的优化器。两者缺一不可，且镜像损失对样本效率提升显著（论文未明确具体倍数）。

边界与局限

论文未明确讨论局限性。从方法看，至少存在以下边界：虚拟助手在课程后期完全移除后，策略对扰动（如外力、地形变化）的鲁棒性未验证；对称损失假设形态左右对称，对非对称形态（如带机械臂的人形）可能失效；课程参数 (k_p,k_d) 的初始值选择依赖经验，未见敏感性分析；所有实验在仿真环境（Pydart）完成，未涉及真实机器人迁移。

工程启示

复现时优先核对三点：一是镜像对称损失中的 Ψ_a 与 Ψ_o 映射是否正确实现左右关节/状态对应，这是最容易出错处；二是课程更新条件中“平衡测试”的具体判定标准（论文未明确），建议自行定义并保持与终止条件一致；三是 v̂ 的线性增加时间 0.5|v̂| 对应 2 m/s² 加速度，若修改目标速度需同步调整。对下游团队，若目标形态非左右对称，建议直接移除对称损失并观察步态退化程度；若追求样本效率，环境中心课程优于学习者中心，但需额外调 g 与 ε。
