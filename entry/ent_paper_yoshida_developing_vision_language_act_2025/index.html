Developing Vision-Language-Action Model from Egocentric Videos

摘要

本文由Institute of Science Tokyo、NII LLMC与Sony Interactive Entertainment联合提出，介绍了一种从第一人称视频中训练视觉-语言-动作模型（VLA）的方法。核心贡献在于提出EgoScaler框架，无需辅助标注即可从原始第一人称视频中提取6DoF物体操作轨迹，并构建大规模预训练数据集。实验表明，该预训练方法在模拟与真实机器人环境中将任务成功率提升超过20%，性能可与真实机器人数据集媲美。

来源与参考

  • Developing Vision-Language-Action Model from Egocentric Videos (arXiv)
  • Developing Vision-Language-Action Model from Egocentric Videos source

概述

本文提出一种从原始第一人称视频中提取显式6DoF操作轨迹用于VLA预训练的方法，无需任何辅助标注或专用硬件。作者利用EgoScaler框架从Ego4D等四个大规模数据集提取45,157个episodes，训练π_0模型，在真实机器人上达到与真实机器人数据集相当的性能，且与BridgeData V2合并后进一步提升。核心贡献在于证明纯视觉、无标注的egocentric视频可以作为VLA预训练的有效数据源。

它改变了什么

VLA预训练的数据瓶颈长期依赖遥操作，成本高且难以规模化。此前利用egocentric视频的工作要么需要手部姿态、动作时间戳等辅助标注，要么依赖多相机、深度传感器等专用硬件，这极大限制了数据来源的扩展性。LAPA等隐式方法虽免标注，但潜在动作表示在细粒度操作上表现不佳。本文真正改变的是：将egocentric视频从“需要复杂标注或硬件的辅助信号源”转变为“可直接提取显式动作轨迹的规模化预训练数据”，且性能不逊于真实机器人数据。这为VLA预训练打开了一个几乎无限的数据来源——互联网上大量的人类操作视频。

方法拆解

轨迹提取：EgoScaler四阶段流程

  1. 动作分割与目标识别：用GPT-4o识别动作起止时间戳及被操作物体，替代人工标注。
  2. 物体位置序列提取：开放词汇分割模型+密集3D点跟踪器，获取物体在每帧的3D位置。
  3. 坐标系归一化：通过点云配准将序列投影到动作起始帧的相机坐标系，消除佩戴者头部运动带来的坐标漂移。
  4. 旋转序列计算：用奇异值分解（SVD）计算连续物体点云间的变换，得到旋转序列。

轨迹表示与动作形式

  • 轨迹表示为 τ = {τ_1, ..., τ_T}，其中 τ_t = (x, y, z, roll, pitch, yaw)，近似机器人末端执行器状态（不含夹爪）。
  • 动作定义为 a_t = [Δx_t, Δy_t, Δz_t, Δrot6D_t]，其中rot6D_t为旋转矩阵前两列的展平向量，共9维。
  • 训练时对动作和本体感受状态归一化，缓解人机数据分布差异。

数据清洗策略

  • 旅行距离阈值（δ_DT）：丢弃累积位移过大的轨迹，用于剔除配准错误。
  • 背景轨迹相似度（BGTS）：计算物体与背景位移的平均余弦相似度，经验设置δ_BGTS = 0.7（基于模拟器实验），丢弃高相似度episodes。
  • 平滑滤波：五帧窗口平均平移向量，序列边界处窗口缩小。

训练配置

  • 架构：π_0（PaliGemma VLM + flow-matching动作头），冻结VLM参数。
  • 预训练20,000步，batch size 1,024；真实机器人评估40,000步，batch size 128。
  • 8×H200 GPUs，AdamW，bfloat16，恒定学习率5 × 10^{-5}。

关键创新

  1. 显式6DoF轨迹从纯视觉提取：此前egocentric视频方法要么依赖辅助标注，要么用隐式表示。本文首次证明无需任何标注，仅凭原始视频即可提取显式、可用的6DoF操作轨迹，且能直接用于VLA预训练。
  2. 数据清洗的通用性：提出的旅行距离阈值和BGTS阈值不依赖特定数据集或场景，可推广到任意egocentric视频源，为规模化数据构建提供了可复用的工程方案。
  3. 与真实机器人数据的互补性：实验显示作者数据集与BridgeData V2合并后性能超过任一单独数据集，说明egocentric视频与真实机器人数据在分布上互补，而非替代关系。

实验与结果

模拟环境（SIMPLER BridgeData V2）

  • 4个pick-and-place任务，每任务200个rollouts评估。
  • 预训练于作者数据集相比从零训练，成功率提升超过20%。
  • 作者数据集性能与真实机器人数据集相当，略优于BC-Z和BridgeData V2。

真实机器人（ALOHA）

  • 4个语言感知pick-and-place任务，每任务10个rollouts，成功率两阶段评分（抓取正确物体0.5分，放置正确位置再0.5分）。
  • 从零训练模型成功率为0%。
  • 作者方法一致优于LAPA；LAPA在模拟环境中性能下降。

边界与局限

  • 模拟环境中性能提升较小，作者归因于视觉域差距（visual domain gap）。
  • 作者数据集在模拟环境中性能下降，可能因模拟环境简化视觉系统。
  • 未使用夹爪状态（因无法从egocentric视频获取），限制了需要精确抓取的任务。
  • 未在更多样化的机器人硬件上验证，泛化性存疑。
  • 需要更丰富的物理建模、上下文感知规划、扩展操作能力、改进重建鲁棒性，以实现更通用可靠的规模化机器人学习。

工程启示

  • 复现时先核对数据清洗阈值：δ_BGTS = 0.7基于模拟器实验设定，在真实场景中可能需重新标定；旅行距离阈值δ_DT的具体值论文未明确，需自行实验确定。
  • 注意Ego4D相机内参问题：需用COLMAP预先估计，若无有效初始图像对则排除该实例，这会影响最终数据量。
  • 训练时冻结VLM参数：受SmolVLA启发，可显著降低计算成本；预训练20,000步、batch size 1,024在8×H200上约需数天，建议先小规模验证数据质量再全量训练。
  • 最易踩坑处：轨迹提取的配准错误是主要噪声源，建议优先检查旅行距离分布，若长尾明显需调整δ_DT；合并多数据集时注意动作和本体感受向量的填充与归一化，维度不匹配会导致训练崩溃。
  • 下游团队选型建议：若任务涉及精确抓取，需额外补充夹爪状态信息；若任务在模拟环境部署，需注意视觉域差距可能导致的性能下降。
