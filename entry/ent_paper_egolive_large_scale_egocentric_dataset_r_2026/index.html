EgoLive: A Large-Scale Egocentric Dataset from Real-World Human Tasks

EgoLive: A Large-Scale Egocentric Dataset from Real-World Human Tasks

摘要

EgoLive 是一个大规模、高质量的以自我为中心的视频数据集，专为机器人操作学习设计。该数据集由研究团队创建，核心贡献在于提供了目前最大的开源注释以自我为中心的数据集，专注于真实世界任务导向的人类日常活动，并通过定制头戴设备实现高精度多模态注释，数据全部采集于无约束的真实场景。

来源与参考

  • arXiv:2604.23570 EgoLive: A Large-Scale Egocentric Dataset from Real-World Human Tasks
  • 机器人下一代数据入口，可能就是Ego：9篇论文讲透第一视角技术路线

概述

EgoLive 是一个由京东等机构构建的大规模第一人称（egocentric）数据集，包含 1,680 小时、65,866 个 episode、346 个真实世界任务的高保真立体视频，配套深度、手部运动追踪和细粒度语言指令标注。其核心贡献在于通过定制头戴设备 JoyEgoCam 和全自动标注流水线，首次在真实服务场景中实现了兼具多视角、运动追踪、语言标注和深度信息的规模化数据采集，为通用机器人操作模型提供了野外（in-the-wild）训练基础。

它改变了什么

机器人学习社区长期被一个两难困境困扰：遥操作数据质量高但采集成本昂贵、可扩展性差；而互联网视频虽海量却缺乏机器人所需的动作、深度和交互结构。EgoLive 真正改变的是数据采集的“成本-质量”权衡曲线——它用第一人称头戴相机替代了机械臂遥操作和 UMI 等专用接口，让数据采集回归到“人自然做事”这一最原始、最可扩展的形态。这不仅是采集方式的替换，更意味着数据分布从实验室的受限场景转向了家庭、零售、药店等真实服务场景，环境多样性、物体类别和任务复杂度都跃升了一个量级。

另一个关键改变在于标注的“可自动化程度”。此前 EgoDex 等数据集虽有运动追踪但缺语言标注，Ego4D 有语言但无深度和手部追踪，EgoLive 首次在千小时规模上同时提供立体 RGB、深度、手部 6D 轨迹和细粒度语言指令，且全部通过自动流水线生成。这使得下游研究者无需再为数据清洗和标注投入大量人力，可以直接聚焦于策略学习本身。从工程角度看，这相当于把“数据工厂”的产能从手工小作坊提升到了自动化产线。

方法拆解

硬件层：JoyEgoCam 头戴设备

  • 立体 RGB 相机，分辨率 2160×2160 @ 60 FPS，FOV 130°×130°，模拟人眼双目视差
  • 集成 IMU，200 Hz 采样，用于相机自运动估计和视觉-惯性融合
  • 设计原则：最小侵入，不遮挡面部、不干扰手部运动，保证操作者自然行为

  3. 相机位姿：ORB-SLAM3 融合双目 RGB + IMU，从左相机第一帧初始化
  4. 语义理解：
  5. 手-物检测用 [Shan20] 模型，追踪用 BoT-SORT，分割掩码用 SAM2
  6. 每个 episode 根据手-物检测和追踪结果划分为子任务（时长 1-20 秒）

质量评估

  • LLM-as-a-Judge 协议，从手一致性、物体一致性、动作一致性、全局一致性四个维度打分

关键创新

  1. “真实任务”而非“演示任务”：EgoLive 的数据来自真实服务场景（家庭、零售、药店）中操作员自然执行的任务，而非实验室设计的标准动作。这意味着数据包含真实世界的长尾分布——杂乱桌面、光照变化、遮挡、非标准物体操作方式，这正是遥操作数据难以企及的多样性。

  2. 立体 + IMU + 深度 + 手部追踪 + 语言标注的五元组组合：此前没有任何数据集在千小时规模上同时具备这五种模态。Ego4D 有语言无深度，EgoDex 有追踪无语言，Xperience-10M 虽全有但分辨率仅 512×512 @ 20 FPS。EgoLive 以 2160×2160 @ 60 FPS 的旗舰规格补齐了这一空白，且深度精度在 0.9 m 内平均误差低于 5.4 mm，满足精细操作需求。

  3. 全自动标注流水线的工程化：手部追踪（HaMeR + 立体优化）、语义分割（SAM2）、语言生成（微调 Qwen3-VL-32B）的串联并非简单拼接，而是针对第一人称视角做了专门设计——例如手部 3D 优化解决了单目估计的手腕漂移问题，子任务划分机制让语言描述与动作片段对齐。这使得数据集可以持续低成本增长，而非一次性项目。

手部重建

与 EgoDex 相比，EgoLive 的 2D 关键点标注更准确、无空间错位；3D 关键点在四个视角（第一人称、正面、左侧、右侧）下均保持强空间一致性，无手腕漂移。

边界与局限

论文未明确列出局限性声明，但从事实要点可推断出以下边界： - 未进行机器人策略训练或 sim-to-real 迁移实验：数据集的价值停留在“数据供给”层面，尚未证明其能直接提升机器人操作成功率。 - 深度精度随距离衰减明显：1.5 m 以上平均误差超过 8.7 mm，2.5 m 以上超过 14 mm，对于远距离操作或大范围场景感知可能不够。 - 语言标注依赖 LLM 生成：虽经 LLM-as-a-Judge 评估，但具体分数未公开，且自由形式描述的质量上限受限于 Qwen3-VL-32B 的能力。 - 场景覆盖有限：346 个任务虽多，但集中在服务导向场景（家庭、零售、药店），未覆盖工业制造、户外作业等机器人应用领域。 - 数据采集人员为招募操作员：其行为模式可能与真实用户存在偏差，影响数据分布的生态效度。

工程启示

  1. 先核对深度精度是否满足你的任务需求：如果做近距离桌面操作（<0.9 m），EgoLive 的深度误差（<5.4 mm）完全够用；但若涉及移动操作或远距离感知，需考虑深度误差带来的策略退化风险。

  2. 手部追踪数据可直接用于模仿学习：EgoLive 的 3D 手部关键点经过立体优化，无手腕漂移，且与 2D 投影一致。下游团队可直接将其作为动作标签，无需额外清洗。但注意 MANO 参数是手部模型而非机器人末端执行器，做 human-to-robot 映射时需自行设计重定向策略。

  3. 语言指令的粒度设计值得借鉴：显式建模“手-物体-动作”三要素而非自由描述，使得指令与子任务（1-20 秒）对齐更紧密。复现时建议保留这一结构，而非直接使用 LLM 生成的自由文本。

  4. 最容易踩坑的地方是深度重建的分辨率：FoundationStereo 在 1152×1152 下运行，而原始视频是 2160×2160，这意味着深度图是降采样后的。如果下游需要像素级对齐的 RGB-D，需自行处理上采样或重新计算。

  5. 数据获取渠道已开放：可通过 https://robotdata-market.jdcloud.com/console/market 获取。但训练配置、推理频率等工程细节论文未提及，复现标注流水线时需自行摸索。
