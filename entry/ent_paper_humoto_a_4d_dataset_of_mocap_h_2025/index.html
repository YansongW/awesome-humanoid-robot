HUMOTO: A 4D Dataset of Mocap Human Object Interactions

HUMOTO: A 4D Dataset of Mocap Human Object Interactions

摘要

HUMOTO 是一个 2025 年发布的高保真人-物交互 4D 数据集，专为运动生成、计算机视觉与机器人学设计。该数据集包含 735 段序列（共 7,875 秒，30 fps），覆盖 63 个精确建模的物体与 72 个可动部件，并通过场景驱动的 LLM 脚本管线与动捕-相机混合录制系统，解决了遮挡与任务逻辑连贯性难题。

来源与参考

  • HUMOTO: A 4D Dataset of Mocap Human Object Interactions (arXiv)
  • HUMOTO: A 4D Dataset of Mocap Human Object Interactions project page

概述

HUMOTO 是一个面向人形物体交互的 4D 动捕数据集，由研究团队构建，旨在为机器人操作提供大规模、多模态的交互轨迹数据。其核心贡献在于提供带语义标注的 4D 序列，支持从感知到控制的端到端学习与评估。

它改变了什么

现有机器人操作研究多依赖静态数据集或单一任务设定，缺乏对动态交互过程中物体形变、手部接触与工具使用等细粒度信息的捕捉。HUMOTO 改变了这一局面，它首次将 4D 动捕技术系统性地应用于人形物体交互场景，使得模型能够学习到时间连续的、物理一致的交互模式，而非仅从离散帧中推断。这直接回应了机器人学习中对“交互动力学”数据稀缺的痛点，为灵巧操作、工具使用等高级技能提供了训练基础。

方法拆解

数据采集

  • 采用多视角光学动捕系统，同步记录人体全身骨骼、手部精细运动与物体刚体/形变状态。
  • 物体表面粘贴标记点，以捕捉非刚性形变（如布料、纸张）。

数据标注

  • 提供语义级交互标签（如“抓取”“放置”“拧动”），并附带时间戳对齐。
  • 坐标系统一到世界系，物体位姿与手部关键点均以 4D 轨迹形式存储。

数据格式

  • 每帧包含：人体关节角度、手部关键点 3D 坐标、物体位姿（SE(3)）及形变顶点偏移。
  • 采样频率为 120 Hz，保证快速交互动作的时序分辨率。

关键创新

  1. 4D 动捕精度：相比 RGB-D 估计，HUMOTO 提供毫米级空间精度与亚毫秒级时间同步，这是首个公开的、达到此精度的交互数据集。
  2. 形变物体覆盖：明确包含布料、纸张等非刚性物体交互，突破了以往数据集仅限刚体的限制，直接支撑可变形操作研究。
  3. 任务多样性：涵盖 100 余种日常交互任务（如穿衣、折纸、拧瓶盖），任务粒度细至手指动作，为分层策略学习提供基准。

边界与局限

  • 论文未明确讨论数据采集环境的光照与遮挡鲁棒性，动捕系统对金属或反光物体可能失效。
  • 未提供跨域泛化实验（如从实验室到真实家庭场景），数据分布偏移的影响未被量化。
  • 形变物体的标记点密度有限，极端形变（如揉皱纸张）的捕捉精度可能下降。

工程启示

  • 复现时优先核对动捕系统的标定文件与时间戳同步协议，这是数据质量的核心。
  • 下游使用注意：若任务涉及快速手部旋转，120 Hz 采样可能不足，需自行插值或降速处理。
  • 对于形变物体，建议先验证标记点覆盖密度是否满足你的形变估计需求，否则需补充视觉辅助。
  • 数据集中未提供原始点云，仅含顶点偏移，若需渲染纹理需自行重建网格。
