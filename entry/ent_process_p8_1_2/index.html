概述

FEA 模型准备（FEA model preparation）是结构强度仿真与迭代（Structural FEA）阶段中的关键工序节点，负责将 CAD 几何模型转化为可用于有限元求解的高质量分析模型。它真正改变的不是"网格画得细不细"这一个点，而是让"设计意图—仿真假设—工艺约束"三者之间建立起可追溯、可量化的工程闭环。该工序涵盖输入梳理、方案设计、实施制作、验证闭环与文档交付五个三级子任务，其输出质量直接决定后续求解结果的可靠性与工程决策的有效性。

核心内容

是什么：从"几何模型"到"可求解模型"的工程转化

FEA 模型准备（FEA model preparation）是有限元分析流程中承上启下的关键工序。上游接收来自结构设计阶段的 CAD 几何模型与载荷工况定义，下游交付给求解器执行计算。它的核心任务不是"画网格"本身，而是完成一系列工程决策：哪些特征可以简化、哪些区域必须细化、材料属性如何赋值、接触与边界条件如何设定。

在 WBS V3 中，该工序以 P8.1.2 编号展开，包含五个三级子任务：输入梳理与目标量化（P8.1.2.1）、方案/方法设计（P8.1.2.2）、实施/原型/样件制作（P8.1.2.3）、验证与问题闭环（P8.1.2.4）、文档输出与下游交付（P8.1.2.5）。每个子任务下又有若干四级关键动作，形成完整的工程执行链路。

该工序的方法/工具包括 HyperMesh / ANSA / Abaqus / ANSYS 等主流前处理与求解平台，以及网格收敛分析这一核心方法论。设计思考逻辑围绕"简化非承力特征、合理网格划分、材料属性、接触/绑定设置"展开，关键约束则聚焦于网格质量、计算时间与资源消耗的平衡。

为什么存在：痛点与历史定位

在有限元分析实践中，"模型准备"环节长期被低估，却恰恰是误差的主要来源。早期开发中，工程师往往直接对完整 CAD 模型划分网格，结果是小圆角、小孔、螺纹等细节特征导致网格数量爆炸式增长，计算时间以天计，而求解精度并未显著提升。更严重的是，未经简化的模型常常在细节特征处产生虚假的应力集中，误导设计决策。

在人形机器人领域，这一问题尤为突出。机器人结构件包含大量拓扑优化后的复杂曲面、薄壁加强筋、轻量化镂空特征，直接网格化几乎不可能得到可用的计算规模。FEA 模型准备因此成为连接"设计几何"与"可计算模型"之间的必经桥梁——它真正改变的不是"算得准不准"这一个点，而是让"设计—仿真—工艺"三者之间建立起可追溯、可迭代的闭环关系。

该工序的历史定位在于：它是 P8 结构强度仿真与迭代阶段中第一个执行性工序，其输出直接决定后续求解、后处理与设计迭代的效率与可信度。与 P8.1.1 任务定义不同，P8.1.2 回答的是"这个结构怎么变成能算的模型"——而这个问题必须在求解器启动之前回答清楚，否则一切计算都将建立在不可靠的基础上。

原理拆解

① 几何简化：从"完整"到"可算"的第一道取舍

FEA 模型准备的第一步是几何清理与简化。核心原则是"简化非承力特征"：小圆角、小孔、螺纹、倒角等特征如果不在关注区域，应予以移除或填充。这一步骤的工程依据在于：圣维南原理（Saint-Venant's Principle）指出，局部细节对远离该区域的应力分布影响可忽略不计。因此，简化非关注区域的细节特征不会显著影响整体求解精度，却能大幅降低网格规模。

② 网格划分：离散化的质量决定求解的精度

网格划分是将连续几何离散为有限单元的过程。网格质量直接决定求解精度与收敛性。关键参数包括单元类型（四面体/六面体）、单元尺寸、网格密度梯度等。网格收敛分析是验证网格无关性的标准方法：逐步加密网格，观察关键位置的应力/位移响应是否趋于稳定值。当两次加密之间的结果变化小于工程可接受阈值（通常为 5% 以内，工程判断）时，认为网格已收敛。

\[ \sigma_{\text{conv}} = \lim_{h \to 0} \sigma_h \quad \text{满足} \quad \left| \frac{\sigma_{h_2} - \sigma_{h_1}}{\sigma_{h_1}} \right| < \varepsilon \]

其中 \(h\) 为网格特征尺寸，\(\varepsilon\) 为收敛判据（工程判断）。这一公式体现了网格收敛分析的本质：求解结果应趋近于网格无关的精确解。

③ 材料属性与边界条件：物理真实性的载体

材料属性赋值包括弹性模量、泊松比、密度、屈服强度等，必须与后续工艺能实现的材料状态相匹配。边界条件设定则包括约束方式（固定/简支/对称）、载荷施加（力/压力/位移/温度）与接触定义（绑定/摩擦接触）。这一环节的关键在于：边界条件的设定必须反映真实工况，而非"方便求解"的理想化假设。例如，螺栓连接区域应使用绑定或梁单元模拟，而非简单固定。

④ 接触/绑定设置：多部件装配的力学传递

人形机器人结构件多为多部件装配体，部件之间的连接方式（焊接、螺栓、胶接）需要在模型中正确表达。绑定接触适用于焊接或胶接区域，摩擦接触适用于可相对滑动的界面。接触设置的合理性直接影响载荷传递路径的准确性，是模型准备中技术难度最高的环节之一。

谁在用·应用案例

FEA 模型准备在机器人结构开发中的应用场景包括：

  1. 结构轻量化验证：拓扑优化后的结构件需要重新建模并进行 FEA 校核。模型准备阶段需要将优化输出的隐式几何转换为可分析的实体模型，并合理简化非承力特征。
  2. 关节壳体强度校核：谐波减速器壳体承受复杂交变载荷，模型准备需精确处理轴承座、安装法兰等关键区域的网格细化，同时简化散热鳍片等非承力特征。
  3. 足部结构冲击分析：足底落地冲击分析需要精细的接触定义与材料本构，模型准备阶段需建立足底泡棉与结构件之间的接触对，并验证接触稳定性。

局限与边界

FEA 模型准备的局限性主要体现在：

  1. 简化带来的精度损失：特征简化必然引入误差，对于关注区域附近的细节特征，简化可能导致应力集中被低估。工程判断：简化应遵循"远离关注区域"原则，关注区域内的特征必须完整保留。
  2. 网格质量与计算资源的矛盾：高精度网格需要更多计算资源与时间。在项目周期紧张时，网格密度往往需要妥协，可能影响收敛性验证的充分性。
  3. 材料数据的准确性依赖：模型准备的精度上限受限于材料本构数据的准确性。对于新材料或特殊工艺状态（如增材制造件），材料数据缺失可能导致模型"精确但错误"。
  4. 边界条件理想化：实际工况中的载荷与约束往往具有不确定性，模型准备阶段的理想化假设可能忽略某些关键载荷路径。

常见误区

  1. "网格越细越准"——错。网格细化到一定程度后，精度提升趋于饱和，而计算成本持续上升。正确做法是进行网格收敛分析，找到精度与成本的平衡点。
  2. "简化就是删特征"——错。简化需要基于力学判断：承力路径上的特征必须保留，非承力特征才可简化。盲目删减可能导致载荷传递路径失真。
  3. "接触设置越复杂越好"——错。过度复杂的接触定义会增加收敛难度与计算时间，且未必提升精度。应根据实际连接方式选择最简且物理合理的接触类型。
  4. "模型准备是一次性工作"——错。设计迭代后，模型需要同步更新。模型准备应建立可复用的参数化流程，而非每次从零开始。
