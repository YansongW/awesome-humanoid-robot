Freeform Preference Learning for Robotic Manipulation

摘要

Freeform Preference Learning (FPL) 是一种从自由形式人类偏好中学习机器人策略的方法。它允许标注者定义自然语言偏好轴（如速度、安全性）并提供沿各轴的成对偏好，从而学习语言条件奖励模型。在六项长时域操作任务中，FPL 相比稀疏奖励和二元偏好方法提升了 38 个百分点。

概述

FPL（Freeform Preference Learning）由论文作者提出，是一种面向机器人操作的多维偏好学习方法。它允许标注者沿任意任务相关轴（如速度、小心程度）提供自然语言描述的二元偏好，并据此学习语言条件奖励模型与奖励条件策略，从而在真实世界长视野任务中显著超越现有基线，并支持测试时的行为可操控性。

它改变了什么

机器人策略学习长期受困于奖励设计的瓶颈。稀疏成功标签信号过少，而标准二元偏好又迫使标注者将速度、小心程度、任务完成度等相互竞争的质量概念压缩进一个模糊的“总体”判断中。这种做法在长视野任务中尤其有害——监督信号既难以提供，又充满歧义，最终将负担转嫁给强化学习算法，使其难以扩展到更真实的行为约束。

FPL真正改变的是“偏好”的定义方式。它不再要求标注者给出一个综合性的二元判断，而是允许其自由指定判断轴（如“是否碰了盘子”或“速度是否够快”），并沿该轴提供偏好。这一转变将监督信号从一维标量扩展为多维、可分解的语言条件形式，使奖励模型能够捕捉理想行为的多个方面，并让策略在训练后仍可通过指定不同轴组合进行测试时操控，而无需重新训练。

方法拆解

奖励模型学习

  • 将 Bradley-Terry 模型扩展为轴条件形式。奖励模型 r_φ 以轴标签 l_k 为条件，对轨迹对 (τ_i, τ_j) 输出标量，最小化负对数似然： ℒ_FPL-Reward(φ) = −𝔼[Σ_{k=1}^{K_ij} log σ((2y_k−1)(r_φ(τ_i|l_k) − r_φ(τ_j|l_k)))]
  • 轨迹级奖励定义为前缀段得分之和：r_φ(τ, l_k) = Σ_{i=1}^{T} g_φ(o_{1:i}, l_k)。其中 g_φ 是多模态 transformer，以观测历史为条件，而非单帧，以捕捉时间依赖。
  • 骨干网络使用预训练 Qwen 3.5 VL 4B，冻结视觉编码器，全微调其余部分。输入为问题“What is the score for l_k?”及双相机图像序列，取每时间步第二张图像的视觉分隔符 token 经线性投影解码为分数。

策略提取

  • 选择 K_π 个代表性偏好轴 L = {l_k}，策略以所有轴描述及对应轨迹奖励为条件： ℒ_FPL-Policy(θ) = −𝔼[Σ_{t=1}^{T_i} log π_θ(a_i^t | s_i^t, l_1, r_φ(τ_i|l_1) … l_{K_π}, r_φ(τ_i|l_{K_π}))]
  • 采用奖励条件策略（off-policy、批式在线），而非 PPO，因后者对真实世界机器人学习样本效率过低。
  • 策略为视觉-语言-动作模型（VLA），使用 π_0.5 开源权重，流匹配动作头，动作块大小 16，滚动 8 个动作，全微调 30000 步，批大小 32。

奖励标准化与测试时操控

  • 对数据集 𝒟 上每个轴的奖励计算均值 μ 和标准差 σ，标准化 r_cond = (r − μ) / σ，使奖励有界且测试时无需搜索即可指定。
  • 条件以文本格式传入策略：l_k: round((r_φ(l_k, τ) − μ) / σ)，分数保留 1 位小数。
  • 仿真中为避免策略过拟合条件向量，标准化后添加 0.2 噪声；真实世界不需要。

迭代训练

收集自由形式偏好 → 训练奖励模型 → 提取偏好轴 → 训练策略 → 滚动出新数据 → 合并数据集 → 重复。偏好轴可随迭代自然演变，形成课程学习。

关键创新

  1. 自由形式偏好轴：标注者可用自然语言指定任意判断轴，而非固定集合。这利用视觉-语言模型的预训练表示，使语义相似的描述（如“speed”、“fast”、“efficient”）能自然泛化，无需预定义轴集合。
  2. 分解奖励而非加权标量：不将多轴折叠为加权标量奖励，保留分解形式。这降低了奖励黑客和塑形问题的风险，使策略能展现数据中不存在的行为组合性（如将“快速”与“右钉”组合），并支持测试时无需重训的可操控性。
  3. 轨迹级、历史条件的奖励模型：与标准偏好模型对单帧或短段打分不同，FPL 以观测历史为条件，能捕捉时间依赖（如“先放盘子再放餐具”的顺序约束），这对长视野任务至关重要。

实验与结果

真实世界 4 个任务（Put cube into target bowl、Fold shorts、Plate toast、Set up the table）中，FPL 在所有任务上优于所有基线，平均成功率比次优方法提升 38 个百分点（由表内数值 0.75 vs 0.37 计算）。模拟任务结果如下：

边界与局限

  • 偏好学习需要收集人类偏好，比完全无监督方法更昂贵。
  • 奖励条件策略学习需要在测试时选择适当的奖励值，自动化这一选择是未来工作的重要方向。
  • 当前策略以固定偏好轴集合为条件，扩展方法以处理可变轴是 VLA 能力增强后有前景的方向。
  • 仿真中需添加 0.2 噪声避免过拟合，作者指出这在真实世界不必要，仅因仿真中从头训练较小网络更易过拟合。
  • 未在仿真中使用预训练模型（为优先迭代速度），未提及对更大规模任务或更多机器人平台的泛化验证。

工程启示

复现或采用 FPL 时，先核对以下关键点： 1. 奖励模型输入格式：确认 Qwen 3.5 VL 4B 的输入是否包含“What is the score for l_k?”问题及双相机图像序列，且因果掩码确保 token 不可关注未来图像。冻结视觉编码器、全微调其余部分是关键。 2. 奖励标准化：测试时操控依赖数据集 𝒟 上的均值和标准差。若下游任务分布偏移，需重新计算 μ 和 σ，否则条件值可能超出分布。 3. 仿真与真实世界的差异：仿真中需添加 0.2 噪声防止策略过拟合条件向量，但真实世界不需要。若在仿真中复现，务必包含此噪声；若迁移到真实世界，应移除。 4. 偏好轴选择：初始偏好轴应覆盖任务早期阶段和粗略行为属性，后期聚焦细节。迭代训练中 K_π 可变化，但需确保每个轴有足够标注数据（如 Plate Toast 任务中 295 个轨迹对产生 1477 个轴级比较，涵盖 41 个标签）。 5. 计算资源：真实世界策略全微调和奖励模型微调需 1 个 H100；仿真实验可用较小 GPU（如 NVIDIA RTX 4500）。若资源受限，优先保证奖励模型质量，策略微调可适当减少步数。
