Learning Locomotion Skills Using DeepRL: Does the Choice of Action Space Matter?

Learning Locomotion Skills Using DeepRL: Does the Choice of Action Space Matter?

领域
AI 模型与算法
层级
智能层
审校
草稿

摘要

本文研究了深度强化学习中动作空间选择对运动技能学习的影响。作者对比了力矩、肌肉激活、目标关节角度和目标关节角速度四种动作参数化方法，在多个平面关节图形的步态模仿任务上评估了学习时间、策略鲁棒性、运动质量和查询频率。结果表明，高层动作参数化提供的局部反馈能显著影响学习效果、鲁棒性和策略质量。

来源与参考

  • arXiv:1611.01055 Learning Locomotion Skills Using DeepRL: Does the Choice of Action Space Matter?

概述

本文系统比较了深度强化学习（DeepRL）中四种动作空间参数化方式（力矩、目标关节角速度、目标关节角、肌肉激活）对运动模仿学习的影响，覆盖双足、迅猛龙和狗三种角色。核心贡献在于揭示了动作表示对学习速度、最终性能、鲁棒性和策略查询率的显著影响，并提出了一种交替优化策略参数与执行器参数的启发式方法，使神经网络能有效控制复杂的肌肉骨骼模型。

它改变了什么

这项工作的价值不在于提出新的强化学习算法，而在于它把“动作空间设计”这个在工程实践中常被当作超参数随手处理的问题，提升到了决定学习成败的核心因素的高度。此前DeepRL研究多聚焦于网络架构、奖励塑形或算法改进，而动作表示的选择往往被默认视为“细节”，本文用系统的对照实验证明了这个“细节”对学习难度和最终策略质量的支配性影响——尤其是在复杂角色（狗、迅猛龙）和高维肌肉模型上，动作表示的选择甚至比算法本身更能决定成败。

它真正改变的是我们对“智能从何而来”的理解：作者通过对比肌肉激活（MTU）与简化动作抽象（PD）的表现，实证了生物力学结构本身（被动弹性、阻尼）承担了部分控制计算，即“具身智能”或“mechanical intelligence”在DeepRL框架下是可量化、可利用的。这为后续研究打开了一个新方向：与其只优化策略网络，不如同时优化“身体”参数（执行器特性），让控制与力学协同进化。

方法拆解

任务框架

  • 标准actor-critic结构，策略为高斯分布 π_θ(s,a) = N(μ_θ(s), Σ)，Σ固定为手动指定的对角协方差。
  • 目标为最大化期望累积奖励 J(π_θ) = E[Σ γ^t r_t]，γ=0.9。
  • 状态特征 s_t = (Φ(q_t, q̇_t), Φ(q_t, q̇_t))，即当前姿态特征加参考姿态特征，Φ包含根部高度、连杆相对位置和质心速度。

四种动作模型

  • PD（目标关节角）：动作指定目标角度 q̂，力矩 τ = k_p(q̂ − q) + k_d(q̇̂ − q̇)，其中 q̇̂=0，k_p、k_d手动设定。
  • Vel（目标关节速度）：动作指定目标速度 q̇̂，力矩 τ = k_d(q̇̂ − q̇)，k_d与PD相同。
  • Tor（力矩）：动作直接指定关节力矩，受手动设定的力矩限制，无需额外执行器参数。
  • MTU（肌肉激活）：动作指定肌腱单元激活 a_MTU ∈ [0,1]，力计算 F_MTU = F_SE = F_CE + F_PE，其中 F_CE = a_MTU · F_0 · f_l(l_CE) · f_v(v_CE)。肌肉成拮抗对出现，动作维度至少是其他模型的两倍。

关键训练技术

  • 正时序差分（PTD）更新：优势函数 A(s,a) = I[δ > 0]，δ = r + γV(s') − V(s)。仅当TD误差为正时更新actor，避免负TD更新将策略均值推向未知的劣质动作。
  • 有界动作空间处理：采用修正的inverting gradients方法——当策略均值 μ^i(s) 超出边界 [l^i, u^i] 且梯度方向指向边界外时，将梯度替换为 l^i − μ^i(s) 或 u^i − μ^i(s)；边界内则保留原始梯度。
  • 探索退火：训练时 λ ~ Ber(ε)，ε从1线性退火至0.2（500k次迭代），仅 λ=1 的元组用于actor更新，critic可用全部元组。
  • 执行器参数优化（算法2）：交替进行策略学习（算法1，250k次迭代）和CMA优化执行器参数 ψ（250代，每代16个样本，每个样本通过16次10s rollout评估），共6轮，约50小时。

奖励函数

r = 0.5·r_pose + 0.05·r_vel + 0.15·r_end + 0.1·r_root + 0.2·r_com，各分量均为指数型奖励，惩罚姿态、速度、末端执行器、根部和质心偏差。

关键创新

  1. 首次系统量化动作空间选择对DeepRL运动学习的影响：在统一框架下（相同网络结构、奖励、算法）对比四种动作表示，覆盖三个角色、七种运动，提供了可复现的基准数据。此前研究多局限于单一动作空间，无法回答“哪种表示更好、为什么”这一基本工程问题。

  2. 提出策略-执行器交替优化方法：将执行器参数（肌肉最大等长力、肌腱静息长度、力臂等）纳入优化循环，类比生物进化中“身体”与“控制”的协同适应。这是对“具身智能”理念的工程化实现——不是把身体当作固定约束，而是作为可优化的自由参数，使神经网络能有效驾驭高维肌肉模型。

  3. PTD更新与有界梯度修正的组合：PTD避免了负TD更新导致的高斯策略均值漂移问题，而有界梯度修正比Hausknecht & Stone (2015)的inverting gradients更保守——仅在边界被违反时改变梯度，边界内保留原始梯度，减少了信息损失。两者结合使训练在多种动作空间下均能稳定收敛。

关键发现

  • PD表现最稳定：在7个运动中的5个学习速度最快（AUC最高），最终性能在所有运动中均达到可比最佳。
  • Tor性能最差：在简单双足上尚可，但在狗和迅猛龙上显著恶化（如Raptor Run NCR仅0.6141）。
  • MTU学习最慢但潜力大：AUC普遍最低（如Biped Run仅0.5360），但优化执行器参数后，在Biped Walk上取得最佳NCR（0.9584），且产生更自然的运动。
  • 鲁棒性：PD在所有运动中对外力扰动最鲁棒；Tor在双足行走中显著脆弱；MTU在迅猛龙奔跑中最不鲁棒。不规则地形测试中，狗的Tor策略因“不自然抖动”反而意外鲁棒（作者怀疑该行为规避了跌倒检测）。
  • 查询率：PD和Vel在低查询率（15Hz）下表现更好，Tor退化最快；MTU在低查询率下更好、高查询率下更差。

边界与局限

  • 仅限2D平面模拟：所有结论基于平面铰接角色，未验证3D场景，而3D中力矩控制与肌肉模型的差异可能更大。
  • MTU参数优化可能未达最优：作者承认CMA优化所得执行器参数“可能仍非任务最优”，因此MTU与其他模型的比较可能低估了其潜力。
  • 优化针对单一运动：执行器参数针对特定运动优化，未考虑多任务适应性，而自然界期望更广泛的运动能力。
  • 超参数敏感性：探索率、协方差Σ、奖励权重等超参数对结果影响显著，作者认为总体趋势可能泛化，但无法给出确定性结论。
  • 未做之事：未测试其他RL算法（如PPO、SAC）或运动控制任务；未开发执行器力学与控制能力的协同设计算法。

工程启示

  • 优先选择PD或Vel动作空间：如果你的目标是快速获得稳定策略，PD（目标关节角）是最安全的选择——学习快、鲁棒性好、对查询率不敏感。Vel是PD的轻量替代，在简单任务上性能接近。
  • 避免直接使用力矩控制：除非任务极其简单（如2D双足），否则Tor策略在复杂角色上性能退化严重，且对扰动极脆弱。若必须使用，需配合更保守的探索策略和更长的训练时间。
  • MTU需配合执行器优化：直接使用肌肉模型几乎总是学习最慢的，但优化执行器参数后可能获得更自然的运动。复现时注意：MTU优化约需50小时（6轮CMA），且每轮需重新训练策略，计算成本高。
  • 核对关键超参数：PTD更新（仅正TD误差更新actor）和探索退火（ε从1到0.2）是稳定训练的关键，不要随意改动。有界梯度修正需与动作边界定义一致，否则会导致策略均值卡在边界。
  • 查询率选择：若控制频率受限（如嵌入式系统），优先选择PD或Vel；若使用MTU，低查询率反而可能更好，但原因尚不明确，需自行验证。
  • 最易踩坑处：MTU的动作维度是其他模型的两倍以上（如Dog MTU动作44维 vs PD 20维），状态维度也更高（214 vs 170），网络输出层和协方差Σ需相应调整；执行器参数（表1）有114-282个，手动设定几乎不可能，必须使用CMA优化。
