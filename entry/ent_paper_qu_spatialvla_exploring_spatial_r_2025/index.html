SpatialVLA

SpatialVLA: Exploring Spatial Representations for Visual-Language-Action Model

领域
AI 模型与算法软件中间件
层级
智能层
审校
待审校

摘要

SpatialVLA 是上海人工智能实验室、上海科技大学与 TeleAI 于 2025 年联合提出的视觉-语言-动作大模型，专注于机器人操作中的空间理解。其核心贡献在于引入 Ego3D Position Encoding 与 Adaptive Action Grids 两种空间表征方法，使模型能够从 110 万真实机器人数据中学习通用操作策略，并实现零样本跨机器人控制。

来源与参考

  • SpatialVLA: Exploring Spatial Representations for Visual-Language-Action Model (arXiv)
  • SpatialVLA source

概述

SpatialVLA（论文中模型名为 FLOWER）提出了一种参数少于 10 亿的高效视觉-语言-动作（VLA）策略，通过中间模态融合、全局 AdaLN-Zero 归一化与 Rectified Flow 动作生成，在 CALVIN 等基准上匹配甚至超越当前 SoTA 性能，同时将预训练计算成本降低至 OpenVLA 的约 1%。核心贡献在于系统性地重新分配 VLM 骨干与动作头的参数预算，而非简单缩小模型。

它改变了什么

现有 VLA 策略陷入一个两难：要么保留数十亿参数的完整 VLM 骨干以维持语义理解，但动作头因参数不足而无法建模多模态轨迹分布；要么缩小 VLM 以释放容量给动作头，却剥离了指令条件化所需的语义特征。这种参数分配的零和博弈导致扩散头长期处于"营养不良"状态，是 VLA 计算成本居高不下的根本原因。

本文真正改变的是对 VLM 内部表征的利用方式。它不再将 VLM 视为一个不可分割的语义提取器，而是依据 LLM 可解释性研究——Transformer 层倒数四分之一处已捕获广泛语义，最终层仅服务于下一个 token 预测——将剪枝后的中间层嵌入作为动作生成的条件。这一判断将"模型大小"与"表征质量"解耦，使得在 947M 参数规模下仍能保留稳健的语义基础，而非简单粗暴地压缩模型。

方法拆解

中间模态融合（Intermediate Modality Fusion）

  • 对 Encoder-Decoder VLM（Florence-2-L）：移除整个解码器，仅保留编码器 LLM 层，层数减少 50%。
  • 对 Decoder-Only VLM（SmolFlow2-Video）：丢弃最后 30% 的 Transformer 层。
  • 从 VLM 骨干中间层提取隐藏状态（在视觉与文本 token 联合编码之后），经线性层与 RMSNorm 映射后，通过交叉注意力注入 Flow Transformer。
  • 目标剪枝削减 20–35% 参数并降低每步延迟。

Rectified Flow 动作生成

  • 轨迹插值：z_t = (1-t) * a_bar_{n,k} + t * z_1，其中 z_1 ~ N(0, I)，t ∈ [0,1]。
  • 训练损失：L(θ) = E_{t,z_1}[||z_1 - a_bar_{n,k} - v_θ(z_t, t, s_bar_n, g, e)||²]。
  • 推理：单臂 N=4 步去噪，高频双臂 N=8 步。

成本效益预训练

  • 八个公共数据集组成的 "OXE-soup"（约 250k 轨迹），75% 来自 Droid、Google Robot 和 BridgeV2。
  • 动作块长度 20，单张静态图像输入；数据混合 74% delta-EEF 与 26% 单臂关节状态。
  • 360,000 步在 48 小时内完成（约 200 GPU 小时，H100）。

关键创新

  1. 中间层剪枝作为参数回收机制：不同于以往"剪枝即损失"的认知，本文证明 VLM 中间层嵌入在保留语义基础的同时可释放 20–35% 参数。这一发现直接挑战了"更大 VLM 必然更好"的假设，为高效 VLA 提供了新的设计维度。

  2. Global-AdaLN-Zero 统一归一化：将原本每层独立的调制参数压缩为跨层共享，同时通过 LoRA 保留层特定适应性。这一设计在减少超过 20% 参数的同时，维持了扩散 Transformer 的条件表达能力，解决了 AdaLN-Zero 在资源受限场景下的参数膨胀问题。

  3. 系统性消融揭示融合位置的关键性：中间融合在 LIBERO-Long 上达到 93.4% 成功率，比早期融合（33.4%）提升 61 个百分点（由表内数值 33.4→93.4 计算），比晚期融合（71.2%）提升 22 个百分点（由表内数值 71.2→93.4 计算）。这为后续 VLA 设计提供了明确的架构指导，而非依赖经验性选择。

边界与局限

论文未明确列出 Limitations 章节。从事实要点推断：作者提及"延长训练不再带来收益"，表明存在训练收益饱和点，但未分析其成因。中间融合并非完全原创（文中提及并发工作 [9] 也探索了该方向），本文的增量在于系统消融与洞察。此外，实验主要基于单张静态图像输入，对多视角或动态场景的泛化能力未充分验证；真实世界评估仅在厨房场景进行，其他实施例的泛化性证据有限。

工程启示

复现或采用 FLOWER 时，优先核对以下环节：

  1. VLM 剪枝比例：0.3 是性能与效率的甜点，0.5 会导致 LIBERO-Long 性能下降 8.2 个百分点（由表内数值 70.7→62.5 计算）。若更换 VLM 骨干，需重新扫描该超参数。
  2. 动作头容量：小动作头（384 潜在维度、6 层）性能骤降至 2.60，说明 1024 潜在维度与 18 层 Flow Transformer 是性能下限，不可随意缩减。
  3. VLM 是否参与训练：不训练 VLM 导致 CALVIN 性能下降 1.79（由表内数值 4.44→2.65 计算），必须联合微调 VLM 中间层。
  4. 数据混合比例：74% delta-EEF 与 26% 关节状态数据的配比是针对单臂场景调优的，迁移到双臂或灵巧手任务时需重新平衡。
  5. 推理步数：单臂 N=4、双臂 N=8 是经验值，高频控制场景下可尝试减少步数以降低延迟，但需验证性能损失。

最易踩坑处：Global-AdaLN-Zero 的零初始化与 LoRA 适配器的组合对学习率敏感，建议使用自定义学习率调度（消融显示移除 Custom LR 导致性能下降 0.04，由表内数值 4.44→4.40 计算）。
