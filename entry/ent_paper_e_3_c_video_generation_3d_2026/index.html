E$^3$C: Video Generation with 3D Environmental Memory and Ego-Exo Human Pose Control

摘要

E$^3$C 是一个可控的自我中心视频生成框架，由研究团队提出，用于具身智能体推理自身及他人动作如何改变世界。其核心贡献在于构建了基于半稠密点云的 3D 环境记忆，并分离了场景结构与人类动态控制，同时支持自我中心（ego）和外部（exo）人体姿态控制。在 Nymeria 数据集上的实验表明，E$^3$C 在视觉保真度、相机运动准确性、物体一致性及人体控制方面均优于强基线方法。

概述

E³C 是一个面向完全可控第一人称视频生成的扩散框架，由 Meta Reality Labs 与多伦多大学合作提出。其核心贡献在于将持久 3D 环境记忆（半稠密点云 + 逐点 VAE 外观特征）与人类驱动动态（ego 姿态令牌 + exo 骨架）解耦，通过双流条件注入（VACE Context Adapter + 姿态交叉注意力）实现几何一致性与人体控制的统一。在 Nymeria 数据集上，E³C 在视觉质量、相机轨迹精度、对象一致性和 ego/exo 人体控制指标上全面超越现有 3D 感知与姿态条件基线。

它改变了什么

第一人称视频生成长期被两个脱节的研究路线割裂：姿态条件模型（如 PEVA、EgoControl）能控制人体但缺乏对 3D 场景的持久记忆，导致快速头部运动下背景漂移和几何坍塌；而 3D 一致生成器（如 VMem、Gen3C）针对通用场景设计，不建模自我遮挡与附近人物的耦合运动。E³C 真正改变的是将“场景几何”与“人体动态”作为两个独立但互补的条件流注入扩散模型，而不是试图在一个隐空间中同时隐式建模两者。这一解耦设计使得相机轨迹控制（依赖几何）与人体姿态控制（依赖运动学）可以分别优化，且消融实验证明点云几何条件对 FVD 的改善（从 1380 降至 329）远超任何姿态控制模块，说明几何一致性是第一人称生成的首要瓶颈。

另一个关键改变在于 ego 姿态的表示方式。现有方法将 3D 关节投影为 2D 骨架叠加在 RGB 条件上，但 ego 身体频繁出视野导致绘制稀疏甚至缺失。E³C 引入持久 ego 姿态令牌——将关节与手腕轨迹编码为序列令牌，通过交叉注意力直接注入 DiT——这相当于给模型一个“本体感觉”通道，而非依赖视觉可见性。这一设计将 Hand-F1 从 36.03 提升至 41.44，证明隐式姿态令牌比显式绘制更鲁棒。

方法拆解

3D 环境记忆构建

  • 从上下文帧（前 m=200 帧）运行 SLAM（Project Aria MPS）获得半稠密点云 P ∈ ℝ^(N×3)，每个点分配 RGB 颜色 C（从观测帧采样，体素下采样 0.01m 后平均池化）。
  • 逐点外观特征：用 Wan2.1 视频 VAE 编码器 E 编码上下文帧，得到 16 通道潜图（空间分辨率 1/8），将每个 3D 点投影到特征图双线性插值采样，世界空间 0.02m 体素池化聚合多视图。

视点对齐渲染与条件注入

  • 给定目标相机轨迹 T_(1:n)，将增强点云（颜色 + 特征）投影渲染到每个目标视点，得到 RGB 渲染 c^pc 和特征渲染 c^feat。
  • exo 2D 骨架栅格化叠加在 c^pc 上形成 c^ctrl；ego 3D 关节与手腕 SE(3) 变换投影为 2D 骨架和小坐标轴也绘制在 c^ctrl 上。
  • 双流编码：视频编码器编码 c^ctrl 得 e^ctrl，轻量 3D 卷积特征编码器（隐藏宽度 1024，输出 96 通道）编码 c^feat 得 e^feat，求和融合后通过 VACE Context Adapter 注入视频 DiT 作为残差条件。
  • 关键设计：不显式输入可见性或深度图，模型隐式学习推理遮挡关系。

持久 ego 姿态令牌

  • 输入：ego 3D 身体关节 p^(e,s) ∈ ℝ^(n×J×3) 和 6DoF 手腕姿态 p^(e,w) ∈ ℝ^(n×2×4×4)（相机坐标系）。
  • 特征化：关节用 3D 坐标 + 一阶/二阶时间差分（15 维）；手腕用平移 + 连续 6D 旋转（27 维）。
  • 融合：身体与手腕流通过学习门控融合，空间 Transformer + 注意力池化聚合，时间传播。
  • 摘要令牌：K=4 个学习令牌交叉关注 n 个姿态令牌，拼接后得 H^e ∈ ℝ^((n+4)×1536)，通过专用姿态交叉注意力条件化 DiT。

训练与推理

  • 流匹配目标：L = E[ w(t) ||(ε - z_0) - ε_θ(z_t, t; τ, C)||_2^2 ]，z_t = (1-σ_t)z_0 + σ_t ε。
  • 从 Wan2.1-VACE-1.3B 初始化，LoRA 秩 256 微调主 DiT 和上下文适配器；ego 姿态编码器、特征编码器、姿态交叉注意力从头训练。
  • 推理：50 步 FlowMatch，σ_shift=5.0，CFG ω=5.0。

关键创新

  1. 双流条件解耦架构：将 3D 环境记忆（点云渲染 + 逐点特征）与人体动态（exo 骨架 + ego 姿态令牌）作为独立条件流，通过 VACE Adapter 和交叉注意力分别注入。这是首次在第一人称生成中显式分离“静态场景”与“动态人体”的表示，使得相机控制与人体控制可以独立调节，且消融证明两者互补而非冗余。

  2. 持久 ego 姿态令牌：将 ego 关节与手腕轨迹编码为时间序列令牌，通过交叉注意力直接条件化 DiT，而非投影为 2D 绘制。这解决了 ego 身体频繁出视野导致的控制信号稀疏问题，相当于给模型一个不依赖视觉可见性的“本体感觉”通道。Hand-F1 从 36.03 提升至 41.44 是该方法有效性的直接证据。

  3. 逐点 VAE 外观特征：将视频 VAE 的潜特征附加到 3D 点上，渲染后通过轻量特征编码器注入。这比仅用 RGB 点云颜色提供更丰富的纹理先验，LPIPS 从 0.440 降至 0.424，PSNR 从 17.1 提升至 17.9，说明特征级条件比像素级条件更利于生成器的感知质量。

实验与结果

在 Nymeria 测试集 100 个片段上评估，与三类基线对比：3D 感知生成器（Splatfacto、Gen3C、VMem）、微调 VACE（points+exo）、第一人称生成器（PEVA、EgoControl、EgoTwin）。

消融实验（逐步添加条件）显示：点云几何是最大贡献者（FVD 1380→329），逐点特征改善感知质量（LPIPS 0.440→0.424），exo 骨架提升 Exo-F1（19.87→38.40），编码 ego 令牌在 Hand-F1（36.03→41.44）和 Hand-mIoU（19.36→24.76）上增益最大。与 EgoTwin 对比中，E³C 的 I-FID 31.0 vs 98.2，TErr 2.40cm vs 67.0cm，优势显著。

边界与局限

  • 空间记忆假设环境大部分静态，仅通过人体运动建模动态，对移动物体或长时程场景变化性能会下降。
  • ego/exo 人体控制仅条件化运动，不显式条件化外观——人物离开视野再进入时外观可能漂移。
  • 半稠密 SLAM 点云集中在高梯度区域，低纹理区域（如白墙）代表性不足，可能影响无纹理场景的几何一致性。
  • 与 EgoTwin 的对比协议无法完全对齐（原始划分和实现不可用），比较结果需谨慎解读。
  • 未评估超过 80 帧的长时程生成，也未涉及户外场景专门处理或非人类动态物体控制。

工程启示

复现或应用 E³C 时，优先核对以下几点：

  1. SLAM 点云质量是天花板：消融显示点云条件贡献最大，但半稠密 SLAM 在低纹理区域稀疏。若目标场景纹理贫乏，需考虑补充稠密重建或深度估计，否则几何一致性会显著退化。建议先评估 MPS 点云在目标环境的覆盖率。

  2. 特征体素大小需调参：RGB 点记忆用 0.01m 体素，特征记忆用 0.02m（因特征更平滑）。若场景尺度差异大，这两个参数可能需要重新标定，过小会导致特征碎片化，过大会丢失细节。

  3. ego 姿态令牌的输入坐标系：关节和手腕姿态在相机坐标系中，且包含时间差分。若从其他动捕系统获取数据，需确保坐标系对齐（尤其手腕 SE(3) 的旋转表示），否则姿态交叉注意力会学到错误的映射。

  4. 训练成本高：64 块 H100、50 epoch、LoRA 秩 256。若资源有限，可先冻结特征编码器只训练姿态分支，消融显示 +Encoded Ego 的增益（Hand-F1 +5.41）相对独立，可能以较低成本获得主要收益。

  5. 评估指标陷阱：PCK@10% 仅对匹配的人体框计算，且与 Exo-F1 联合解读；Hand-mIoU 中空-空帧贡献 1，会虚高。复现评估时需严格遵循其匹配阈值（τ_obj=0.5，τ_exo=0.2）和过滤规则（SAM3 面积 <1536 像素过滤），否则数字不可比。
