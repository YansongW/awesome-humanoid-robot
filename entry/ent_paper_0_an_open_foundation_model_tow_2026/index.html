Ψ₀: An Open Foundation Model Towards Universal Humanoid Loco-Manipulation

摘要

Ψ₀（Psi-Zero）是一个面向人形机器人全身控制与操作任务的开源基础模型，由研究团队于2026年提出。其核心贡献在于提出分阶段训练范式，通过解耦人类与人形机器人的运动差异，仅用约800小时人类视频和30小时机器人数据，即在多项任务上超越使用10倍以上数据训练的基线模型，成功率提升超40%。

来源与参考

  • Ψ₀: An Open Foundation Model Towards Universal Humanoid Loco-Manipulation (arXiv)

概述

Ψ₀ 是一个面向人形机器人全身移动操作的开源基础模型，由研究团队提出，采用三重系统架构（system-2 视觉语言骨干、system-1 流匹配动作专家、system-0 强化学习跟踪策略），通过约 829 小时人类第一人称视频预训练和约 31 小时真实遥操作数据后训练，在 8 个长时程任务上平均总体成功率比最强基线 GR00T-N1.6 高至少 40%。核心贡献在于证明了以正确方式扩展正确数据（人类视频 + 少量机器人数据）可以显著超越依赖大规模遥操作数据的现有方法。

它改变了什么

人形机器人领域此前的主流路径是堆砌遥操作数据，但遥操作数据获取成本极高且难以扩展。Ψ₀ 真正改变的是数据策略的范式：它证明人类第一人称视频可以作为可扩展的预训练数据源，且通过分阶段训练（先学语义、再学动作分布）而非端到端联合训练，避免了人类与机器人动作分布差异导致的次优问题。这打破了“数据量越大越好”的直觉，转而强调数据类型的正确配比。

另一个关键改变是动作专家的架构选择。现有 VLA 模型多采用朴素 DiT 或直接微调 VLM 骨干，Ψ₀ 引入受 Stable Diffusion 3 启发的 MM-DiT 作为动作专家，并在后训练阶段冻结 VLM 骨干、从零训练动作专家。这一设计承认了“语言-视觉语义”与“动作生成”是两种不同性质的分布，分开建模比统一建模更有效，实验也证实了这一点。

方法拆解

三重系统架构

  • system-2：Qwen3-VL-2B-Instruct 视觉语言骨干，负责任务语义理解与视觉特征提取
  • system-1：约 500M 参数的流匹配 MM-DiT 动作专家，受 Stable Diffusion 3 启发，动作 token 与视觉-语言 token 执行联合全局注意力
  • system-0：现成 RL 跟踪策略 AMO，将 8-DoF 下半身动作映射为 15-DoF 下半身关节角度

三阶段训练流程

  1. 预训练：在 EgoDex 数据集（约 829 小时人类第一人称视频）上自回归训练 VLM 骨干，仅预测单步动作 a_t，使用 FAST tokenizer 将连续动作离散化为约 20 个 token。训练目标为 p_θ(a) = ∏ p_θ(a_t | a_{<t}, ℓ, o_t)。关键决策：不预测动作块，因为预训练目标是学习语义而非动作时序，单步预测计算开销大幅降低。
  2. 后训练：冻结 VLM 骨干，在 Humanoid Everyday 数据集（约 310 万帧真实遥操作数据）上从零训练流匹配动作专家。训练目标为 L_fm = E[||v_ρ^flow(z_t, a_t^τ, τ) − (ε − a_t)||]，其中 a_t^τ = τ·a_t + (1−τ)·ε。采用 MM-DiT 而非朴素 DiT，因为双调制设计和联合注意力能更有效融合动作与视觉-语言特征。
  3. 微调：仅微调动作专家，每任务 80 条轨迹，训练 40,000 步，余弦学习率调度，初始学习率 0.0001。

实时动作分块（RTC）

训练时随机移除前 d = uniform(0, d_max) 个 token 的扩散噪声并在损失中掩码，d_max ∈ [0, H−s)。模型单次前向传播约 160 ms。作者发现测试时 RTC 无法稳定引导模型，因此改为训练时实现。

遥操作系统

分离上半身姿态跟踪（PICO 头显 + 腕部追踪器，多目标 IK 求解）、灵巧操作（MANUS 手套）、运动命令（腰部 + 脚部追踪器推断平移速度和转向），支持单操作员全身控制。

关键创新

  1. 分阶段训练策略：预训练只学语义、后训练只学动作分布、微调只调动作专家，避免单一策略同时建模人类与机器人两种根本不同的动作分布。消融显示，无预训练有后训练时总体成功率仅 2/10，有预训练后提升至 8/10，证明预训练对语义理解的关键作用。

  2. MM-DiT 动作专家：将文本条件图像生成中的双调制架构引入动作预测，相比朴素 DiT 能更有效融合视觉-语言条件。消融显示，MM-DiT 相比朴素 DiT 在总体成功率上从 8/10 提升至 9/10（由表内数值 8/10→9/10 计算）。

  3. 训练时实时分块（RTC）：通过在训练时随机掩码前 d 个动作 token 的噪声，模拟推理延迟，使模型学会在部分动作已执行的情况下平滑续接。消融显示，加入 RTC 后总体成功率从 8/10 提升至 9/10（由表内数值 8/10→9/10 计算）。

边界与局限

  • 消融研究仅使用单个真实世界任务（拾玩具入箱并举起），受限于计算资源和时间，结论的泛化性未充分验证。
  • 测试时实时分块无法稳定引导模型，因此采用训练时实现，这限制了推理时的灵活性。
  • 多任务微调导致各单独任务性能下降，作者假设是学习目标分散导致欠拟合，但未深入分析。
  • 未涉及多机器人协同、未在多种人形平台上验证（仅 G1 和 H1）、未讨论安全性保证。
  • 硬件平台负载能力限制可能阻碍更强大操作行为的执行。
  • 论文未明确说明模型在未见过的物体或场景上的泛化能力。

工程启示

  • 数据配比是首要决策：预训练数据（人类视频）与后训练数据（真实机器人遥操作）的配比至关重要。消融显示，仅用 10% EgoDex 预训练时总体成功率从 8/10 降至 1/10（由表内数值 8/10→1/10 计算），说明预训练数据量不足会严重损害性能。复现时应优先保证预训练数据规模。
  • 分阶段训练不可跳过：直接冻结骨干微调动作头（总体 0/10）或跳过预训练（总体 2/10）都会导致失败。三阶段流程是性能的基石，不要试图端到端联合训练。
  • RTC 是部署关键：训练时 RTC 将总体成功率从 8/10 提升至 9/10（由表内数值 8/10→9/10 计算）。复现时注意 d_max 设为 6，且被掩码 token 不参与损失计算。测试时 RTC 不可行，务必在训练阶段实现。
  • FAST tokenizer 必须重训：原始开源 tokenizer 重建损失为 5.83×10⁻⁴，重训后降至 1.95×10⁻⁴。复现时用 500,000 个随机采样动作从头训练，动作 horizon 1、词表大小 2048、scale 100。
  • 硬件配置门槛高：预训练需 64 块 A100 GPU 约 10 天，后训练需 32 块 A100 约 30 小时。若资源有限，可考虑先用 10% EgoDex 验证流程，但需预期性能显著下降。
  • 遥操作数据采集：每任务 80 条轨迹即可微调，但需注意动作降采样至 10 Hz、状态填充至 32 DoF、动作填充至 36 DoF 等细节，缺失的下半身动作分量需填充。
