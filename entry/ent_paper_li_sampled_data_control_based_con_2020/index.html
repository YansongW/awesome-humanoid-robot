基于采样数据控制的分数阶多智能体系统一致性研究

Sampled-Data Control Based Consensus of Fractional-Order Multi-Agent Systems

领域
AI 模型与算法
层级
智能层
审校
待审校

摘要

本文针对分数阶多智能体系统提出一种分布式采样数据控制器，通过补偿历史控制输入来应对分数阶微积分的遗传性与无限记忆特性，并证明了全局有界性与渐近平均一致性。

来源与参考

  • Sampled-Data Control Based Consensus of Fractional-Order Multi-Agent Systems

概述

该论文针对无GPS环境下独轮机器人源搜索问题，提出基于投影梯度上升的控制律，同时调节纵向与角速度，并证明其全局渐近稳定性。作者进一步结合极值搜索控制处理传感器部分故障场景，并引入3D打印柔性石墨烯气流传感器进行硬件验证。核心贡献在于放松了现有方法对梯度曲率的限制，实现全局收敛，并提供了实际传感器集成方案。

它改变了什么

现有源搜索方法要么依赖全局定位（GPS），要么假设纵向速度恒定，这在深海、地下等拒止环境中不成立。文献[16]的控制律 F(a,b)=|a| 受限于梯度曲率边界，仅能保证半全局渐近稳定，意味着初始条件必须落在某个未知有界集内，工程上难以验证。本文真正改变的是：通过投影梯度上升结构，将稳定性条件从“梯度曲率有界”放松为“势函数严格凹且径向无界”，从而在单极值条件下实现全局渐近稳定——这是一个从“局部保证”到“全局保证”的质变。同时，将控制律设计为仅依赖局部梯度与朝向（轮式编码器可得），彻底摆脱了对全局坐标的依赖，使算法可部署于GPS失效场景。

方法拆解

动力学与测量模型

  • 机器人模型：[z1_dot; z2_dot; theta_dot] = [u*cos(theta); u*sin(theta); omega]，u 纵向速度，omega 角速度。
  • 势函数 J(z1,z2) 在源 (z1*,z2*) 处取全局最大值，机器人可测局部梯度 ∇J 与朝向 θ。

投影梯度上升控制律（方法一）

  • 控制律：
  • u = k1 * ⟨v(θ), ∇J⟩，k1 > 0
  • omega = -k2 * ⟨v(θ), ∇⊥J⟩，k2 > 0
  • 其中 v(θ)=[cos(θ); sin(θ)]，∇⊥J 为 ∇J 的正交向量，满足 ⟨∇⊥J, ∇J⟩=0、∇⊥J × ∇J > 0、‖∇⊥J‖=‖∇J‖。
  • 设计理由：纵向速度正比于梯度在朝向方向的投影，角速度正比于梯度在垂直方向的投影，形成“转向梯度方向并加速”的闭环。

稳定性证明

  • 引入辅助状态 [z3; z4]=[cos(θ); sin(θ)]，构造李雅普诺夫函数： V = -J(z1,z2) + 0.5*z3^2 + 0.5*z4^2 + J(z1*,z2*)
  • 时间导数：V_dot = -k1 * ⟨∇J, [z3; z4]⟩^2 ≤ 0
  • 利用La-Salle不变集原理，当 J 二次可微、径向无界、严格凹且唯一最大值时，闭环系统全局渐近收敛至源（命题III.1）。

传感器故障场景（方法二）

  • 当仅能获得梯度幅值（传感器部分故障）时，将极值搜索控制（ESC）与投影梯度上升结合，证明渐近收敛性。ESC用于估计梯度方向，投影上升用于驱动运动。

传感器硬件

  • 四个3D打印柔性石墨烯压阻式气流传感器，安装于前、后、左、右，提供双向流信息作为梯度代理。

关键创新

  1. 全局渐近稳定的放松条件：现有方法（如文献[16]）要求梯度曲率有界，本文通过投影结构将条件放松为势函数严格凹且径向无界，这是稳定性理论层面的实质性推进——从半全局到全局，消除了初始条件的不确定性。
  2. 同时控制纵向与角速度：多数源搜索算法固定纵向速度或仅调角速度，本文同时调节 u 与 omega，使机器人能根据梯度强度自适应加速/减速，收敛速度更快且路径更短。
  3. 传感器故障下的鲁棒性设计：将ESC与投影上升结合，使得在仅能获取梯度幅值（而非方向）时仍能收敛，这为实际传感器部分失效提供了容错方案，是理论到工程的关键一步。

边界与局限

  • 论文未明确列出局限性或未来工作（结论部分未包含在提供片段中）。
  • 稳定性证明要求势函数严格凹且径向无界，这意味着实际环境中若存在多个局部极值（如多热源、多气流干扰），全局收敛保证不成立。
  • 传感器故障场景仅考虑“仅能获得幅值”这一种退化，未覆盖传感器完全失效、偏置或噪声增大等更复杂故障模式。
  • 实验部分未提供定量结果，无法判断算法在真实硬件上的鲁棒性边界（如风速范围、传感器噪声水平、机器人速度限制）。
  • 论文未明确提及对非凸势函数或动态环境（源移动、气流变化）的适应性。

工程启示

  • 复现核对顺序：先确认势函数 J 是否满足严格凹且径向无界——这是全局收敛的前提，若实际环境不满足，需改用局部版本或增加扰动项。
  • 增益选择：k1 与 k2 的比值影响收敛路径形状。建议先固定 k2，从小到大调 k1，观察是否出现振荡（角速度响应过慢）或路径迂回（纵向速度过快）。
  • 传感器标定：3D打印石墨烯传感器需先做静态标定，确认输出与气流速度的单调关系，否则梯度代理可能失真。建议在实验前测量传感器响应曲线，并记录基线漂移。
  • 最易踩坑：∇⊥J 的方向选择（满足 ∇⊥J × ∇J > 0）必须与机器人角速度正方向一致，否则控制律会反转导致发散。实现时建议用叉积显式定义，而非依赖视觉判断。
  • 下游团队：若将算法移植到其他机器人平台，需重新验证编码器朝向测量的噪声水平——控制律对 θ 的精度敏感，高噪声下建议增加低通滤波，但会引入相位延迟，需权衡。
