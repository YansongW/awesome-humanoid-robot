来源与参考

概述

基于模型的定义（Model-Based Definition, MBD）是一种以三维数字模型为唯一权威数据源的工程方法，将几何尺寸、公差标注（GD&T）、材料属性、运动学约束与制造工艺信息直接嵌入CAD模型，取代传统二维工程图纸作为产品定义与传递的核心载体。它真正改变的不是绘图方式，而是产品数据从"图纸为中心"到"模型为中心"的权威性转移，使设计、仿真、制造与质检共享同一数字主模型。

核心内容

是什么：准确定义

基于模型的定义（MBD）属于 技术 类型，所属领域包括设计工程与制造工艺，价值链层级覆盖中游与上游。其核心思想是：将几何、运动学、质量特性、GD&T和标注嵌入单一数字主模型的CAD中心方法。英文名称为 Model-Based Definition。

在传统流程中，三维模型仅用于几何表达，而尺寸公差、表面粗糙度、热处理要求等关键信息分散在二维图纸上，模型与图纸之间需要人工同步，极易产生版本漂移。MBD 将这一切彻底改变——三维模型本身成为产品定义的唯一法律来源，所有下游环节（工艺规划、工装设计、检测编程、供应商协同）直接消费模型数据，不再依赖图纸转换。

为什么存在：痛点与历史定位

MBD 的诞生源于传统"三维建模 + 二维出图"并行工程模式的系统性缺陷：

  1. 数据双轨制：三维模型与二维图纸并存，任何设计变更需要同时更新两套数据，工程实践中常出现模型已改、图纸未更新的版本错位。
  2. 信息丢失：二维投影必然丢失三维拓扑关系，复杂曲面、形位公差的空间含义在图纸上难以完整表达。
  3. 传递链断裂：从设计到制造需要经历"模型→图纸→工艺员读图→编程"的多级人工翻译，每一级都可能引入理解偏差。
  4. 无法支撑数字线程：人形机器人这类复杂机电系统需要设计、仿真、制造、质检全链路数据贯通，图纸作为非结构化载体无法被计算机直接解析。

MBD 的历史定位是数字线程（digital thread）的基石。它把产品定义从"给人看的图纸"转变为"给机器读的数据"，使基于模型的工艺规划（MBP）、基于模型的检测（MBI）、基于模型的维护（MBM）成为可能。在人形机器人领域，关节模组、减速器、传感器支架等零部件的公差链分析、装配仿真、在线检测都依赖 MBD 提供的结构化数据。

原理拆解

① 单一数据源：主模型（Master Model）架构 MBD 的核心机制是建立"主模型"概念——一个包含全部产品定义信息的CAD文件，通常由以下层次构成：

  • 几何层：实体/曲面几何，是模型的基础骨架。
  • 标注层：GD&T 标注（尺寸、公差、基准）、表面粗糙度、焊接符号等，以三维标注形式直接附着在几何特征上。
  • 属性层：材料牌号、热处理状态、质量特性（质量、质心、惯性矩）等非几何属性，以PMI（Product and Manufacturing Information）形式存储。
  • 关联层：几何特征与标注之间的关联关系，确保模型修改时标注自动更新。

② PMI：让计算机"读懂"公差 PMI 是 MBD 的关键技术要素。传统图纸上的公差标注是给人读的图形符号，而 PMI 将公差信息以结构化数据格式（如 STEP AP242 标准）嵌入模型，使 CAM 系统可以直接读取公差值进行加工参数优化，CAQ 系统可以自动生成检测计划。这正是 MBD 区别于"三维标注"的本质——不仅是显示方式的改变，更是数据语义化的跃迁。

③ 数字线程：从设计到制造的无缝传递 MBD 模型作为数字线程的载体，贯穿产品全生命周期：

设计模型（含PMI）→ 工艺规划（读取公差→制定工序）→ 工装设计（基于模型拟合）→ NC编程（直接引用几何）→ 在线检测（比对实测与PMI）→ 质量闭环（反馈至设计）

每一环节都直接消费模型数据，无需人工重新录入，从根本上消除了数据转换误差。

关键参数与规格

MBD 实施涉及的关键参数与规格包括：

参数/规格 典型要求 说明
数据格式标准 STEP AP242、JT、3D PDF 需支持 PMI 语义化存储，而非仅几何交换
标注完整性 100% 关键特性标注 需自行确认企业标准
模型精度 与制造精度匹配 需自行确认
PDM/PLM 集成度 版本管理、权限控制、审批流 需自行确认
下游工具兼容性 CAM/CAQ/CAE 直接读取 需自行确认

选型要点：MBD 不是单一软件功能，而是一套企业级数据治理体系。核心决策包括：选择 PMI 数据格式标准（STEP AP242 是当前主流）、确定标注规范（参照 ASME Y14.41 或 ISO 16792）、规划 PLM 系统与 CAD 工具的集成深度。

MBD vs 传统二维图纸

维度 传统二维图纸 MBD
数据权威性 图纸为法律依据 模型为唯一依据
信息完整性 三维信息需投影表达，易丢失 三维标注完整保留空间关系
下游自动化 需人工读图、重新建模 数据直接驱动 CAM/CAQ
变更管理 模型与图纸双轨同步 单一数据源，自动关联
实施门槛 低，行业成熟 高，需重构流程与标准

MBD vs 轻量化模型（如 3D PDF） 轻量化模型仅用于可视化查看，不具备 PMI 语义化数据结构，无法被下游系统自动解析。MBD 模型则包含完整的结构化产品定义信息，是可用于制造与检测的"活数据"。

谁在用·应用案例

MBD 已在航空航天、汽车、重型装备等领域大规模落地，人形机器人行业正在快速跟进：

  • Tesla Optimus：作为高度集成化的机电产品，Optimus 的关节模组、减速器、结构件设计制造高度依赖 MBD 支撑的数字线程。其 Gen 3 手部从 11 DOF 提升至 22 DOF，单只手搭载 25 个执行器，双手共 50 个执行器（按邻居卡语料），如此高密度的集成设计必须依靠 MBD 实现公差链分析与装配仿真。
  • 关节模组供应商：谐波减速器、行星滚柱丝杠等精密零部件的制造需要 MBD 将 GD&T 信息直接传递给数控加工与在线检测系统，确保微米级精度要求（需自行确认具体数值）。
  • 科研机构：高校人形机器人实验室利用 MBD 实现快速设计迭代与多学科优化，缩短原型验证周期。

局限与边界

  1. 实施成本高：MBD 需要重构企业设计流程、标准体系与人员技能，初期投入大，中小团队需谨慎评估。
  2. 标准尚在演进：PMI 数据交换标准（如 STEP AP242）仍在完善中，不同 CAD 工具之间的 PMI 互操作性需自行确认。
  3. 供应链协同挑战：MBD 的价值依赖上下游伙伴共同采用，若供应商仍以图纸交付，则数字线程断裂。
  4. 不适合所有场景：对于简单零件或低复杂度产品，MBD 的投入产出比可能不如传统方式。
  5. 法律与合规问题：部分行业监管仍要求纸质图纸存档，MBD 的法规认可度需自行确认。

常见误区

  1. "MBD 就是三维标注"——错。三维标注只是显示层，MBD 的核心是 PMI 的结构化数据语义，能被计算机解析和驱动下游系统。
  2. "上了 MBD 就不需要图纸"——不完全对。MBD 取代的是图纸作为"法律依据"的地位，但某些场景（如现场装配指导、供应商沟通）仍可能需要图纸形式的派生视图。
  3. "MBD 是 CAD 软件的一个功能"——错。MBD 是企业级数据治理体系，涉及标准制定、流程重构、PLM 集成、人员培训，软件只是工具。
  4. "MBD 只对大型企业有意义"——不完全对。对于人形机器人初创团队，MBD 虽初期投入大，但可避免后期数据返工，需根据团队规模权衡。

왜 존재하는가:痛点과 역사적 위치

MBD의 탄생은 전통적인 "3D 모델링 + 2D 도면" 병행 엔지니어링 모델의 체계적 결함에서 비롯되었습니다:

  1. 데이터 이중 체계: 3D 모델과 2D 도면이 공존하며, 설계 변경 시 두 데이터 세트를 동시에 업데이트해야 하므로, 실제 엔지니어링에서는 모델은 변경되었지만 도면이 업데이트되지 않은 버전 불일치가 자주 발생합니다.
  2. 정보 손실: 2D 투영은 3D 토폴로지 관계를 필연적으로 잃게 되며, 복잡한 곡면, 형상 공차의 공간적 의미는 도면에서 완전히 표현하기 어렵습니다.
  3. 전달 체인 단절: 설계에서 제조까지 "모델→도면→공정 엔지니어 도면 해독→프로그래밍"의 다단계 수동 번역을 거쳐야 하며, 각 단계에서 이해 편차가 발생할 수 있습니다.
  4. 디지털 스레드 지원 불가: 휴머노이드 로봇과 같은 복잡한 전기기계 시스템은 설계, 시뮬레이션, 제조, 품질 검사 전 과정의 데이터 연결이 필요하며, 도면은 비구조화 매체로서 컴퓨터가 직접 해석할 수 없습니다.

MBD의 역사적 위치는 디지털 스레드(digital thread)의 초석입니다. 제품 정의를 "사람이 보는 도면"에서 "기계가 읽는 데이터"로 전환하여, 모델 기반 공정 계획(MBP), 모델 기반 검사(MBI), 모델 기반 유지보수(MBM)를 가능하게 합니다. 휴머노이드 로봇 분야에서 관절 모듈, 감속기, 센서 브래킷 등의 부품 공차 체인 분석, 조립 시뮬레이션, 온라인 검사는 모두 MBD가 제공하는 구조화된 데이터에 의존합니다.
