人形机器人行为基础模型

Behavior Foundation Model for Humanoid Robots

领域

层级

审校

摘要

这篇工作主要解决数据闭环：用本体状态与关节序列、遥操作/外骨骼数据、仿真交互数据采集人类操作和机器人状态，再通过教师-学生知识迁移、扩散策略/流匹配、全身控制器/WBC/MPC转成可训练、可复用的全身轨迹/动作序列、低层控制器目标。关键点是用特权信息训练教师策略，再把能力蒸馏到只能使用部署观测的学生策略。

来源与参考

  • 人形机器人行为基础模型 project page

概述

WorldVLA 是一个自回归动作世界模型，由阿里巴巴团队提出，旨在统一动作与图像的理解和生成，实现动作模型与世界模型的相互增强。其核心贡献在于通过动作注意力掩码策略解决自回归模型中多动作顺序生成的性能退化问题，并在 LIBERO 基准上验证了联合训练的有效性。

它改变了什么

现有 VLA 模型将动作仅作为输出，缺乏对动作的全面理解，而世界模型虽能预测未来视觉状态却不能直接生成动作，两者之间存在功能缺口。WorldVLA 真正改变的是将动作从“输出”提升为“可理解的输入”，使模型能够同时进行动作推理与视觉预测，从而在单一架构内实现动作模型与世界模型的相互增强。这一改变的意义在于，它不再将动作生成和视觉预测视为两个独立任务，而是统一为同一自回归框架下的联合学习问题。

方法拆解

架构设计

WorldVLA 采用三个独立分词器（图像、文本、动作），不同模态的 token 共享同一词汇表，在单一 LLM 架构内统一跨模态理解与生成。模型从 Chameleon 初始化，因其是统一的图像理解与生成模型。

分词器细节

  • 图像分词器：VQ-GAN 模型，带额外感知损失（针对人脸和显著物体），压缩比为 16，码本大小为 8192；256×256 图像生成 256 个 token，512×512 图像生成 1024 个 token。
  • 动作分词器：将连续机器人动作的每个维度离散化为 256 个 bin，bin 宽度由训练数据范围决定；动作表示为 7 个 token，包括 3 个相对位置、3 个相对角度和 1 个绝对夹爪状态。
  • 文本分词器：训练好的 BPE 分词器，词汇表大小为 65536，包含 8192 个图像 token 和 256 个动作 token。

数据格式

  • 动作模型：文本输入为 "What action should the robot take to + task instruction + ?"，输入含 M 张图像，输出含 K 个动作，仅计算动作 token 的损失。
  • 世界模型：文本输入为 "Generate the next frame based on the current image and the action."，下一帧预测基于动作重复 N 次，仅计算生成图像 token 的损失。

关键设计决策

  • 动作注意力掩码：当前动作仅依赖文本和视觉输入，禁止访问先前动作，使自回归框架能并行生成多个动作；世界模型部分采用传统因果注意力掩码。论文未明确该掩码的具体实现方式。
  • 训练目标：损失函数为 ℒ = ℒ_action + αℒ_world，其中 α 用于平衡损失贡献（因图像 token 远多于动作 token），默认 α=0.04。
  • 混合训练：混合动作模型数据与世界模型数据训练，理由包括世界模型学习环境物理、能模拟评估候选动作结果、需要精确解释动作输入；动作模型增强视觉理解，支持世界模型的视觉生成。

关键创新

  1. 动作注意力掩码策略：这是最关键的创新。传统自回归方法顺序生成多个动作会导致性能下降，原因是预训练多模态语言模型主要接触图像和文本而非动作，动作泛化能力有限，早期错误预测会传播至后续动作。掩码策略使当前动作仅依赖文本和视觉输入，禁止访问先前动作，从而在自回归框架内实现并行动作生成，带来 4% 至 23% 的抓取成功率提升（由表内数值计算）。
  2. 统一动作与图像的自回归框架：WorldVLA 是首个将动作作为输入、图像作为输出的自回归世界模型，实现了动作模型与世界模型的相互增强，而非简单拼接。
  3. 动作分词化的设计：将连续动作离散化为 256 个 bin，动作表示为 7 个 token，包括相对位置、相对角度和绝对夹爪状态，这一设计使动作能够与图像、文本 token 共享同一词汇表，实现跨模态统一。

实验与结果

基准与设置

  • 基准：LIBERO benchmark，包含 LIBERO-Spatial、LIBERO-Object、LIBERO-Goal、LIBERO-Long 和 LIBERO-90。
  • 数据集：过滤失败轨迹和无操作动作，90% 轨迹为训练集，10% 为验证集。
  • 训练配置：默认输入图像数 M=2，动作块大小 K=10（LIBERO Long 任务）和 K=5（其余三个任务），世界模型单轮 N=1，α=0.04。
  • 评估指标：动作模型每个任务评估 50 次 rollout 并记录成功率（SR）；世界模型记录 FVD、PSNR、SSIM 和 LPIPS 值。

关键结果解读

  • 动作注意力掩码策略带来显著提升：索引 3 到索引 4 的对比显示，Spatial 从 36.7 提升至 81.8，Long 从 16.9 提升至 49.3（由表内数值计算）。
  • 世界模型联合训练带来额外增益：索引 4 到索引 5 的对比显示，Goal 从 84.4 提升至 85.1，Spatial 从 81.8 提升至 84.0（由表内数值计算）。
  • 世界模型预训练带来约 4% 的平均成功率提升（由表内数值计算）。
  • 视频预测模型对比：世界模型集成在所有评估任务上提升动作模型性能；视频预测模型对两个任务有益，对一个任务产生负面影响。

边界与局限

  • 数据和模型规模的扩展是 WorldVLA 框架进一步发展的有前景方向，但论文未明确当前规模下的性能上限。
  • 当前依赖离散表示的图像分词器在感知表现力上存在局限；设计能同时理解和生成高质量视觉内容的统一分词器是重要改进方向。
  • 引入辅助动作头是提升抓取性能的另一种潜在策略，但论文未明确其具体实现与效果。
  • 动作块长度过长时，机器人及时调整策略的能力受限，导致整体性能下降，论文未明确最优动作块长度的确定方法。
  • 论文未明确 WorldVLA 在真实机器人上的部署效果，所有实验均在 LIBERO 仿真环境中进行。

工程启示

  • 复现核对：首先确认代码仓库（https://github.com/alibaba-damo-academy/WorldVLA）中的默认配置是否与论文一致，特别是 M=2、K=10（Long）和 K=5（其余任务）、N=1、α=0.04 这些关键超参数。
  • 最易踩坑：动作注意力掩码的实现细节是关键，当前动作仅依赖文本和视觉输入，禁止访问先前动作。若掩码实现有误，自回归生成多个动作时性能会显著下降（如 Spatial 从 81.8 降至 36.7，由表内数值计算）。
  • 分词器选择：图像分词器为 VQ-GAN，压缩比为 16，码本大小 8192；256×256 图像生成 256 个 token，512×512 图像生成 1024 个 token。若更换分词器，需重新验证 token 数量与性能的平衡。
  • 数据预处理：过滤失败轨迹和无操作动作，90% 轨迹为训练集，10% 为验证集。若数据过滤不彻底，可能影响动作分词器的 bin 宽度估计。
  • 下游团队：若需部署到真实机器人，需注意动作分词器的 bin 宽度由训练数据范围决定，真实机器人动作范围可能与仿真环境不同，需重新训练分词器。
