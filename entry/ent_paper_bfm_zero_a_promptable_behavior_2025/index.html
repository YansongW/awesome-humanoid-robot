BFM-Zero｜使用无监督强化学习的人形控制的即时行为基础模型

BFM-Zero: A Promptable Behavioral Foundation Model for Humanoid Control Using Unsupervised Reinforcement Learning

摘要

BFM-Zero 是一个面向人形机器人控制的提示式行为基础模型框架，由研究团队提出。其核心贡献在于通过无监督强化学习学习共享潜在表示，将运动、目标和奖励嵌入同一空间，使单一策略无需重新训练即可执行多种下游任务。该模型在 Unitree G1 人形机器人上实现了零样本运动跟踪、目标到达和奖励优化等真实世界全身技能。

概述

BFM-Zero 提出一种基于无监督强化学习的可提示行为基础模型，用于人形机器人控制。核心贡献在于将视觉-语言-动作（VLA）模型与扩散式视频生成器结合，通过多视角一致的合成数据增强策略学习，并引入自适应混合机制动态重加权训练样本。该方法在真实世界零样本视觉域任务中实现超过 200% 的相对性能提升。

它改变了什么

机器人操作领域长期受困于数据稀缺：真实遥操作采集成本高、规模小，而仿真数据存在视觉真实感差距。现有视频生成增强方法（如 Cosmos-Transfer1、RoboEngine）多从单一视角生成，无法保证跨相机一致性，直接限制了依赖多目输入的 VLA 策略；RoboTransfer 虽尝试多视角，但迁移到新域时多样性不足。更关键的是，此前工作将生成数据视为静态增强，未回答“如何在训练中有效使用这些合成样本”这一核心问题——这导致生成质量虽提升，但策略收益有限。

BFM-Zero 真正改变的是将“生成”与“学习”耦合为一个闭环：不仅生成多视角一致的视频，还依据策略在轨迹层面的表现动态调整数据采样权重。这把数据增强从一次性预处理升级为训练期自适应过程，使合成数据从“被动填充”变为“主动筛选”，直接回应了生成数据分布偏移与策略鲁棒性之间的矛盾。

方法拆解

整体架构

BFM-Zero 由两个核心组件构成：DreamTransfer（视频生成器）与 AdaMix（自适应数据混合策略），两者串联形成“演示视频 → 多视角一致生成 → 质量过滤 → 动态重加权训练”的流水线。

DreamTransfer 视频生成

  • 基础架构：基于扩散 Transformer（DiT）的双分支设计，主分支负责逐步去噪潜在视频令牌，并行 ControlNet 分支通过深度约束增强几何一致性。
  • 多视角编码：将 M 个视角的同步深度图沿宽度拼接，经 VAE 编码为统一潜在表示：d_init = Enc([v^(1), v^(2), …, v^(M)])，利用预训练扩散模型固有的多视角上下文学习能力保证时空一致性。
  • 文本控制：预训练 T5 文本编码器将提示转换为高维语义嵌入，通过交叉注意力与视觉特征融合，支持对前景、背景、光照的细粒度编辑，同时保持 3D 结构。
  • 两阶段微调：因拼接输入分辨率（1920×480）超出预训练模型支持范围，先在 576×128 低分辨率下稳定学习多视角几何（3500 步），再逐步适应全分辨率（4500 步），恢复高保真细节。

AdaMix 自适应数据混合

  • 质量过滤：基于深度一致性、多视角一致性、文本-视频相似度三维度评估，未达标样本初始采样权重设为零。
  • 三阶段训练：
  • 均匀采样训练至损失收敛；
  • 对每个样本计算三个轨迹级指标：
    • 动作预测误差：r^MSE_i = -(1/L)Σ||â_{i+t} - a_{i+t}||²₂
    • 轨迹平滑度：r^Smooth_i = -Σ_j |(a_{i+2,j} - 2a_{i+1,j} + a_{i,j})/(Δt)²|
    • 关节角度限制：二元指示器 r^Limit_i ∈ {0,1}
  • 分数经 min-max 归一化后组合 s_i = (r̃^MSE_i + r̃^Smooth_i + r̃^Limit_i)/3，采样权重更新为 p(i) ∝ γ + λ·(1 - s_i)，其中 γ 保证最小支持，λ 控制硬样本强调程度。
  • 防泄漏：所有评估与重加权严格限定在训练集，验证数据不参与。

关键创新

  1. 多视角一致生成：DreamTransfer 直接对拼接的多视角视频进行单次推理，而非逐视角独立生成后拼接，从根本上避免了跨视角不一致问题。平均像素匹配达 3270，较次优方法提升 42%（由表内 2298→3270 计算），这是此前方法未能解决的关键瓶颈。

  2. 训练期自适应重加权：AdaMix 将生成数据从静态增强转变为动态采样源，依据策略在轨迹层面的表现（动作误差、平滑度、安全限制）实时调整样本权重。这一设计使合成数据中“难学”的样本获得更高采样概率，直接提升策略在长时程、精度关键任务上的表现。

  3. 无需人工调参的平衡组合：三个指标等权组合（各占 1/3）即可有效识别困难样本，避免了复杂的权重学习或手动调参，工程可复现性强。

混合比例与 AdaMix 消融

  • 混合比例实验（Figure 4）：性能在 50% 生成数据时达峰，Fold Cloth 成功率从 0% 时的 10% 跃升至 65%；超过 50% 后收益平稳，90% 时 Throw Bottle 成功率从 50% 降至 45%。
  • AdaMix 消融（Table 3）：平均成功率从 FixMix 的 65% 提升至 78%，提升 13%；执行时间平均缩短 3.0 秒（由表内 33.0→30.0 计算），关节超限减少 7.0 次（由表内 46→39 计算）。

边界与局限

论文未明确列出作者承认的自身方法局限。但实验数据揭示两个边界条件：其一，当生成数据占比达 90% 时，Throw Bottle 任务成功率从 50% 降至 45%，表明过度依赖合成数据会传播细微视觉或动态不准确，损害快速、精度关键任务；其二，所有实验基于 Agilex CobotMagic 平台（两个 PiPER 臂、三个 RealSense D435i 相机），结论在异构硬件或不同相机配置下的泛化性未验证。此外，视频质量过滤依赖 Video Depth Anything 与 CLIP 等外部模型，其误差会传导至下游策略训练。

工程启示

复现或应用 BFM-Zero 时，优先核对以下环节： 1. 多视角拼接分辨率：DreamTransfer 两阶段微调（576×128 → 1920×480）是保证生成质量的关键，跳过低分辨率阶段直接全分辨率训练会导致几何一致性崩溃。 2. 混合比例阈值：生成数据占比严格控制在 50% 附近，超过 75% 后收益递减，90% 时出现性能回退——这是最容易踩坑的参数。 3. AdaMix 启动时机：动态重加权需在训练步数过半后启动，过早引入会干扰早期稳定学习；γ 与 λ 的取值论文未明确，需自行调参。 4. 质量过滤指标：深度一致性（Sq.Rel.）与多视角匹配（Pix.Mat.）是过滤低质量样本的核心依据，建议在生成后先离线评估再进入训练流水线，避免无效计算。
