Learning Motion Skills with Adaptive Assistive Curriculum Force in Humanoid Robots

摘要

A2CF（Adaptive Assistive Curriculum Force）是2025年提出的一种用于人形机器人运动技能学习的双智能体系统。该方法通过一个专用的辅助力智能体，根据机器人当前状态施加引导力，并随技能提升逐步减少辅助，从而加速复杂动作的学习。在双足行走、编舞舞蹈和后空翻三个基准任务上，A2CF比基线方法收敛速度快30%，失败率降低超过40%，最终能生成无需外部支持的鲁棒策略。

来源与参考

  • Learning Motion Skills with Adaptive Assistive Curriculum Force in Humanoid Robots (arXiv)

概述

A2CF（Adaptive Assistive Curriculum Force）框架由研究者提出，面向人形机器人运动技能学习。其核心是训练双智能体系统：一个运动策略智能体输出关节位置指令，另一个辅助力智能体在仿真中向骨盆施加可自适应衰减的6维空间力，以课程方式引导探索并最终撤除。该方法在行走、后空翻和舞蹈任务上验证了加速收敛和降低失败率的效果。

它改变了什么

现有RL和IL方法在人形高维控制中面临探索与利用的根本矛盾：早期随机探索效率低，易陷入局部最优或不稳定状态。人类学习运动技能时依赖外部物理支持（如父母扶助、教练施力），而机器人训练缺乏这种本能支持。A2CF改变了“机器人必须完全自主探索”的默认假设，将外部辅助力作为一种可学习的、可撤除的训练信号引入RL框架，使策略在受控外力引导下更快建立正确运动模式，再逐步摆脱依赖。这实质上是把“课程学习”从任务难度维度扩展到了“物理干预强度”维度，为复杂技能习得提供了新的训练范式。

方法拆解

双智能体架构

  • 运动策略智能体输出期望关节位置 a_t^motion，由PD控制器执行。
  • 辅助力智能体输出6维空间力 a_t^assi（线性力+力矩），施加于骨盆base link。
  • 联合动作空间 a_t = [a_t^motion, a_t^assi]，通过联合动作学习器（JAL）协同训练。

辅助力课程机制

  • 定义6D超立方体边界 B_k = {F ∈ R^6 | -η_{k,i} ≤ F_i ≤ η_{k,i}}。
  • 根据归一化力幅值 ‖F_k‖/‖η_k‖ 与阈值 ε=0.5 比较，自适应更新边界 η_k（衰减因子 δ=0.2）。
  • 当力幅低于阈值或技能习得标志触发时，边界衰减，最终辅助力降至零。

关键设计决策

  • 初始分布（ID）：任务相关初始化力边界 η_0。行走时xy平面需求大（f_t [40,40,10]），后空翻Jump/Air阶段z方向需求大（f_t [40,40,100]），Stand/Land阶段xy平面需求大。
  • 特权信息（PI）：辅助力智能体仅仿真中运行，利用地形、力边界、线速度、域随机化参数（摩擦系数、扰动速度、质量）等特权信息，帮助运动策略逃离局部最优。
  • 随机掩码（RM）：训练中按概率 ζ=0.2 随机屏蔽辅助力分量（F_t^assi = M_t ⊙ F_t），防止过度依赖。

训练架构

  • 非对称Actor-Critic（AAC）：运动策略仅接收观测 o_t 和历史信息 o_t^H，Critic接收完整状态（含特权信息）。
  • VAE压缩历史数据并估计线速度 v_t，优化MSE损失和KL散度。
  • PPO算法优化策略。
  • 奖励函数：总奖励 = 运动奖励（任务项+正则项）+ 辅助力奖励（惩罚过度使用，仅在运动智能体达到技能习得目标80%后引入）。

关键创新

  1. 物理辅助力作为可学习课程：将外部力注入RL训练循环，且由独立智能体学习何时施加、施加多大，而非预设固定曲线。这是对“课程学习”概念的实质性扩展，从任务难度调度转向物理干预调度。
  2. 自适应撤除机制：通过力幅阈值和技能习得标志双重条件触发辅助力衰减，确保策略在掌握技能后自主接管，避免依赖。随机掩码进一步强制策略在部分时间无辅助下工作，增强鲁棒性。
  3. 特权信息仅用于辅助智能体：辅助力智能体利用仿真特权信息（地形、物理参数）指导运动策略，而部署时完全移除，实现了训练期引导与部署期自主的干净分离。

实验与结果

任务 指标 A2CF Baseline 备注

行走 辅助力降至低于0.1 N 约7k 论文未明确 对35 kg机器人不显著
后空翻 成功率 超过90% 论文未明确 平地训练，随机摩擦和负载
舞蹈 关节位置跟踪误差阈值 0.16 论文未明确 A2CF精度优于Baseline
  • 摘要声明：A2CF比基线收敛快30%，失败率降低超过40%（由表内数值4k→10k计算，收敛加速约60%（由表内数值 2.5→1.0 计算））。
  • 消融实验：A2CF w/o PI、w/o ID、w/o RM均显示对应组件重要性。均匀初始限制（w/o ID）显著降低后空翻学习性能。
  • 行走任务平均最大地形等级约6；速度命令最大前向1.2 m/s、横向0.8 m/s、角速度1.5 rad/s。

边界与局限

  • 辅助力仅施加于骨盆基座，未扩展到其他连杆（如手部），限制了某些需要末端支撑的技能学习。
  • 后空翻任务未进行真实世界测试，仅在Genesis模拟器验证Sim2Sim，真实环境中的动态差异未验证。
  • 未探索环境中物体（如墙壁）作为辅助力来源的自主利用，即辅助力来源仅限于虚拟力，而非物理接触。
  • 论文未明确辅助力智能体在部署时的计算开销，以及其对实时控制延迟的影响。

工程启示

  • 复现时先核对初始力边界 η_0 的任务特定设置：行走和后空翻Stand/Land阶段z轴力需求小（10），后空翻Jump/Air阶段z轴需求大（100），舞蹈三轴均匀（40）。错误初始化会显著影响学习性能。
  • 随机掩码概率 ζ=0.2 是关键超参数，过小导致过度依赖辅助力，过大则削弱引导效果。建议在训练中期监控辅助力幅值，若长期高于阈值需检查掩码机制是否生效。
  • 辅助力奖励仅在运动智能体达到技能习得目标80%后引入，过早加入会干扰早期探索。需确保技能习得标志的判定标准与任务奖励设计一致。
  • 部署时仅用本体感觉传感器（关节角、速度、身体方向、角速度），控制策略在Intel Core i9-12900H CPU上50Hz执行。行走和舞蹈任务可直接迁移，无需微调，但后空翻需额外Sim2Sim验证。
  • 训练配置：4096并行环境，NVIDIA GeForce 4090 GPU，仿真时间步0.001s，环境步0.02s。行走和后空翻每迭代约5秒，舞蹈约8秒（因采样专家数据）。
