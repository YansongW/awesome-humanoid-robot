CLONE｜用于长时程任务的闭环全身人形远程操作

CLONE: Closed-Loop Whole-Body Humanoid Teleoperation for Long-Horizon Tasks

领域
设计工程AI 模型与算法
层级
中游智能层
审校

摘要

CLONE 主要解决数据闭环：用遥操作/外骨骼数据采集人类操作和机器人状态，再通过分层技能/专家策略、闭环纠错/人类干预转成可训练、可复用的全身轨迹/动作序列、低层控制器目标。关键点是把任务拆成可路由的技能或专家策略，再用高层模块在执行中选择和组合。

来源与参考

  • CLONE project page

概述

CLONE 是一套面向长时程任务的类人机器人全身闭环遥操作框架，由北京大学等团队开发，核心贡献在于将混合专家（MoE）全身控制策略、LiDAR 里程计闭环误差校正与系统化数据增强三者整合，仅凭商用 MR 头显（Apple Vision Pro）的 minimal 输入即可实现全身协调与低漂移的长时间操作。该系统将 8.9 米轨迹上的平移漂移降至 12cm，并支持行走中姿态转换、地面取物等此前难以完成的全身移动操作任务。

它改变了什么

类人遥操作长期被两个结构性缺陷困扰：一是上下半身控制解耦，导致操作者必须分别控制手臂与腿部，无法产生自然的全身协调运动；二是开环执行，即系统只回放预编程轨迹，缺乏全局位姿反馈，长时程任务中漂移累积使末端执行器与目标严重偏离。这两个问题叠加，使得“边走路边捡东西放进箱子”这类需要全身同步的移动操作任务几乎不可能完成。

CLONE 真正改变的不是某个控制器的精度，而是把遥操作从“分段开环演示”推进到“闭环全身协同”的范式。它用 LiDAR 里程计构建全局位姿闭环，让机器人知道自己在哪里、走偏了多少，而不是盲目执行；同时用 MoE 让一个统一策略同时管理上半身操作与下半身平衡，而不是分别训练再拼接。这解决了长时程任务中“手到了但身体没跟上”和“身体动了但手的位置全错”这两类根本性失效模式。

方法拆解

整体架构

CLONE 采用教师-学生蒸馏范式：教师策略使用特权信息（如真实状态、未来轨迹）训练，学生策略（MoE 网络）仅依赖可观测传感器输入，从教师行为中蒸馏得到。推理时学生策略直接输出全身关节指令。

三个关键模块

  • MoE 全身控制策略：统一策略内嵌多个专家网络，每个专家擅长一类运动技能（如蹲起、行走、上肢操作）。门控网络根据当前状态动态选择专家组合，使单一策略能覆盖“从地面取物”与“放入远处箱子”这类需要不同运动模式的复合任务，同时保证上下半身动作的时序协调。
  • LiDAR 闭环误差校正：系统集成 LiDAR 里程计与 Apple Vision Pro 跟踪，实时估计机器人全局位姿。将估计位姿与期望轨迹对比，计算平移与旋转误差，反馈至控制策略进行在线修正。该机制将 8.9 米轨迹上的平移漂移控制在 12cm（论文未明确具体控制律形式，如 PID 或模型预测控制）。
  • 数据增强与策展：从 AMASS 数据集子集出发，通过运动编辑采样多样化手部朝向，并加入额外动作捕捉数据，构建大规模数据集 CLONED。增强策略确保策略对未见过的操作者姿态（如不同蹲姿、转身角度）具备鲁棒性，而非过拟合训练时的固定姿态分布。

训练流程

  1. MoCap 预训练：在 CLONED 数据集上预训练 MoE 学生策略，学习全身运动先验。
  2. 环境感知跟踪：引入 LiDAR 位姿反馈，在仿真环境中微调策略以适应闭环误差校正。
  3. 蒸馏：从特权教师策略蒸馏至学生策略，压缩信息需求，保证推理时仅用传感器输入。

论文未明确推理频率、具体专家数量、门控网络结构及蒸馏损失函数细节。

关键创新

  1. 闭环全局位姿反馈首次用于全身遥操作：此前类人遥操作多依赖局部传感器（如关节编码器）或开环轨迹回放，CLONE 将 LiDAR 里程计与 MR 头显融合，提供全局位姿闭环。这使得长时程任务中的累积漂移可被实时校正，而非事后补偿，是“长时程”可行性的关键前提。
  2. MoE 统一策略替代上下半身解耦控制：传统方法将上半身操作与下半身平衡分开设计，导致协调性差。CLONE 用 MoE 让一个策略内多个专家协同，门控网络动态分配权重，使“蹲下捡物”与“站立放置”这类跨运动模式切换自然衔接，无需人工切换控制器。
  3. 数据增强面向操作者多样性：现有数据集多关注运动多样性，忽略操作者姿态差异。CLONE 通过采样手部朝向与引入额外 MoCap 数据，使策略对操作者身高、臂长、习惯姿态的差异具有鲁棒性，这是从实验室演示走向实际部署的必要条件。

实验与结果

论文未提供表格形式的定量实验数据（如成功率、误差数值、消融对比），以下数字均来自项目页公开资料：

指标 数值 备注
平移漂移 12cm 8.9 米轨迹上，闭环校正后
长距离行走距离 15 米 真实世界演示，行走中转换姿态后返回起点
演示速度 1x 所有视频均为实时遥操作，非加速回放

实验覆盖任务类型包括：全身跟踪（行走中姿态转换、户外长时程跟踪、圆形行走、转身、侧步、蹲走）、上半身运动跟踪（含手部姿态）、交互任务（乒乓球正反手、拳击、桌面物体操作、双手物体交接）、长时程交互任务（单手/双手从地面取物、双手通用拾放、蹲姿/站立擦拭）。

结果含义：12cm 漂移在 8.9 米轨迹上约为 1.3% 误差（由表内数值 12cm 与 8.9m 计算），表明闭环校正有效抑制了长距离累积误差；15 米行走并返回起点且漂移极小，验证了系统在真实环境中的持续稳定性。但论文未明确与开环基线或现有方法的定量对比，也未给出成功率统计，因此“显著优于”的结论缺乏直接数值支撑。

边界与局限

论文未明确列出作者承认的局限性。基于现有资料可推断的边界包括：实验任务均为结构化场景（如固定箱子位置、已知地面条件），未涉及非结构化地形或动态障碍物；LiDAR 里程计依赖环境特征，在空旷或高动态场景中可能退化；MoE 策略的专家数量与门控泛化能力未在论文中给出消融证据；数据增强虽覆盖手部朝向，但未明确是否涵盖极端操作者体型或非典型运动模式。论文未明确推理延迟、计算资源需求及多机器人平台迁移性。

工程启示

复现或选型时，先核对三个关键点：一是 LiDAR 里程计的更新频率与延迟，这直接决定闭环校正的实时性，若里程计输出滞后超过控制周期，漂移校正可能引入振荡；二是 MoE 门控网络的训练稳定性，专家数量过多或门控权重初始化不当易导致模式坍塌，建议从 4-8 个专家起步并监控门控熵；三是数据增强中手部朝向采样的分布范围，过窄则对操作者姿态变化不鲁棒，过宽则可能引入不自然运动。

最容易踩坑的地方在于教师-学生蒸馏的“信息差距”——教师使用特权信息（如真实全局位姿），学生仅依赖 LiDAR 估计，若仿真中 LiDAR 噪声模型与真实差异过大，蒸馏后的策略在真机上可能对漂移校正过度敏感或反应不足。建议在仿真中注入与真实 LiDAR 特性匹配的噪声，并先在短轨迹（如 3-5 米）上验证闭环稳定性，再扩展到 8.9 米以上长轨迹。此外，所有演示视频均为 1x 速度，复现时需确保控制频率与视频一致，否则“实时”结论不成立。
