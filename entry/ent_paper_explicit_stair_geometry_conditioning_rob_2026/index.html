Explicit Stair Geometry Conditioning for Robust Humanoid Locomotion

Explicit Stair Geometry Conditioning for Robust Humanoid Locomotion

领域

层级
智能层
审校

摘要

本文提出一种显式楼梯几何条件化框架，用于提升人形机器人攀爬楼梯的鲁棒性。该工作由研究团队基于Unitree G1人形机器人实现，核心贡献在于将楼梯的台阶高度、深度及偏航角等几何参数直接输入PPO强化学习策略，替代传统隐式地形表征，从而在仿真和真实环境中均展现出对未见楼梯高度的泛化能力，并在户外场景中成功连续攀登33级台阶。

来源与参考

  • arXiv:2605.09944 Explicit Stair Geometry Conditioning for Robust Humanoid Locomotion
  • GitHub仓库 Robotics_Notebooks

概述

本文提出一种显式楼梯几何条件化框架，将台阶高度、深度与相对偏航角作为紧凑地形 token 直接注入 PPO 运动策略，替代隐式高维地形表征。在 Unitree G1 上实现仿真到真实的零微调部署，户外 33 级连续台阶成功率 93%，跨构型泛化显著优于盲态与高度图基线。

它改变了什么

学习型双足爬楼梯长期困在“隐式表征”的泥潭里：盲态方法靠本体感觉硬猜，遇到需要精确净空的楼梯必然翻车；感知方法把地形压成高维潜在特征，看似聪明实则脆弱——感知噪声一上来，潜在表征就漂移，训练分布外的楼梯几何直接让策略失效。作者真正改变的，是把“楼梯通行”从高维感知问题降维成“三个数”的显式推理问题：台阶高度、台阶深度、相对偏航角。这个转变的深层含义是：策略不再需要从噪声点云里隐式解码地形语义，而是直接拿到可解释、可泛化的几何量做预判性步态调节。它改变了学习型足式机器人地形感知的范式——从“学一个隐式地形模型”转向“显式估计任务关键几何量”，这比单纯换网络架构或加奖励更本质。

方法拆解

感知前端：BEV 投影与地形编码

  • 局部点云 P = {p_i ∈ R³} 投影到 3 m × 3 m 网格，分辨率 0.05 m，网格 60 × 60
  • 每单元 6 通道特征：max(z)、min(z)、mean(z)、max(z)−min(z)、std(z)、归一化点密度
  • 多层卷积 + BN + ReLU 渐进下采样，输出 F_enc ∈ R^{128×8×8}

显式几何估计头

  • 从 F_enc 预测地形类别 s_t ∈ {flat, stairs-up, stairs-down}（交叉熵损失）
  • 回归台阶高度 h_step 与深度 d_step（SmoothL1 损失）
  • 偏航角 θ_t 直接取机器人当前航向角，不额外回归
  • 地形 token z_t = [s_t, h_step, d_step, θ_t] ∈ R⁴，平地时 h_step = d_step = 0

三阶段训练

  1. 策略预训练：用地面真值地形参数训练 PPO actor-critic，让策略先学会“给定几何量怎么走”
  2. 感知独立训练：教师监督下训练 BEV 编码器 + 几何估计头，损失 L_terrain = 0.6·L_CE + 1·L_h + 1·L_d
  3. 联合优化：总损失 L_total = L_PPO + 1·L_terrain，标准 clipped PPO + GAE

部署

移除特权教师，仅用机载点云 → BEV → 几何估计 → token 条件化策略，零微调直接部署。

关键创新

  1. 显式几何 token 替代隐式表征：这是最核心的差异。HeightMap-PPO 把地形压成 11×17 高程图隐式编码，MoRE 用专家混合隐式适应；本文直接把任务关键几何量（台阶高、深、偏航）作为策略条件输入。新在“可解释 + 可泛化”——策略看到的是物理量而非特征图，跨构型外推时不会因潜在表征漂移而失效。

  2. 三阶段解耦训练：先让策略在真值几何下学会“怎么走”，再让感知网络学会“看几何”，最后联合微调。这个顺序设计避免了感知误差与策略探索的耦合灾难，是工程上极务实的选择——比端到端联合训练更可控、更易调试。

  3. 平地退化设计：平地时 h_step = d_step = 0，θ_t 退化为航向角，token 自然退化为纯本体感觉条件。这个设计让策略在非楼梯地形上不会因几何估计噪声而退化，是鲁棒性的隐藏关键。

关键含义：显式几何条件化在训练分布内优势有限（+2.5%），但分布外差距随难度线性扩大（0.22 m 处 +13.3%），证明显式几何量确实提升了外推能力而非单纯拟合训练分布。真实世界 93% vs MoRE 72% 的差距说明隐式表征对真实感知噪声的脆弱性被显式估计有效缓解。

边界与局限

论文未明确讨论局限性。从事实要点可推断的边界：未验证 stairs-down 的专门实验，下降时重心控制与上升差异大，显式几何条件化是否同样有效存疑；未测试超过 0.22 m 台阶高度的极端构型，显式几何量的外推上限未知；未分析强光照变化、传感器故障等极端感知噪声场景；未与其他端到端深度图策略在真实世界直接对比；未报告推理延迟与计算资源消耗，部署效率未知。控制频率、训练时长、硬件配置均未提及。

工程启示

复现时先核对三件事：BEV 投影参数（3 m × 3 m、0.05 m 分辨率、6 通道特征）是否与论文一致，网格尺寸或通道定义偏差会直接影响几何估计精度；三阶段训练顺序不可打乱——先策略后感知再联合，跳过任何一阶段都会导致感知误差与策略探索耦合；损失权重 λ_cls = 0.6、λ_h = 1、λ_d = 1 中几何回归权重高于分类，说明作者刻意强调几何量精度而非地形类别，调参时不要反向加权。最容易踩坑的是真实部署时的点云噪声分布与仿真注入的高斯噪声不匹配——论文真实 MAE 比仿真高 50%（h_step 0.6→0.9 cm，θ 1.8°→3.9°），建议在仿真中注入更大方差噪声或加入随机 dropout 模拟传感器丢点。下游团队若要在其他机器人平台复现，需注意 token 维度与策略网络输入层的匹配，以及平地退化逻辑（h_step = d_step = 0）在非楼梯地形上的行为是否符合预期。
