HumanX｜从人类视频中走向敏捷和可推广的人形交互技能

HumanX: Toward Agile and Generalizable Humanoid Interaction Skills from Human Videos

领域
AI 模型与算法数据与数据集
层级
智能层
审校
待审校

摘要

HumanX 先从人类视频/动捕轨迹恢复场景、目标或运动表征，再用ACT/行为克隆模仿学习、IK/动作重定向、分层技能/专家策略生成可执行动作命令。关键点是把任务拆成可路由的技能或专家策略，再用高层模块在执行中选择和组合。

来源与参考

  • HumanX project page

概述

HumanX 提出 RynnVLA-001，一种通过三阶段渐进式训练将大规模第一人称人类视频中的操作技能迁移到人形机器人控制的新框架。核心思路是先训练视频生成模型，再引入轨迹感知中间阶段，最后在机器人数据上微调，以弥合视觉预测与低层动作空间之间的差距。该方法在相同机器人数据上微调时，相比 GR00T N1.5 和 Pi0 取得更高成功率。

它改变了什么

机器人操作领域长期受困于一个结构性矛盾：VLA 模型的性能天花板由数据规模决定，而机器人操作数据的获取成本远高于文本和图像数据。遥操作采集轨迹不仅劳动密集，且难以覆盖真实世界的长尾分布。现有最大规模的开源机器人数据集，如 O’Neill et al. 2024、Khazatsky et al. 2024 等，其体量仍比 LLM 和 VLM 的训练语料小数个数量级。这意味着单纯堆砌机器人数据无法突破泛化瓶颈，必须寻找替代数据源。

HumanX 真正改变的是数据策略的底层逻辑：不再将人类视频视为辅助正则化信号，而是将其作为预训练的主战场。通过视频生成任务隐式提取第一人称演示中的操作先验，再以轨迹预测为桥梁，最后用少量机器人数据完成领域对齐。这一思路将数据瓶颈从「机器人轨迹采集」转移为「人类视频筛选」，后者在互联网上近乎无限。如果成立，它实际上重新定义了 VLA 训练的数据经济性——用 12M 人类视频换取对 244K 机器人数据更充分的利用。

方法拆解

三阶段渐进式训练流程

阶段一：Ego-Centric Video Generative Pretraining - 训练 Image-to-Video (I2V) 模型，输入单张图像和语言指令，自回归预测后续帧 - 架构基于 AR 图像生成模型 Chameleon 扩展，采用自回归 Transformer - 训练数据：12M 个第一人称人类操作视频（网络来源筛选）+ 244K 个机器人操作视频（开源数据集筛选） - 输入序列结构为 [language tokens, visual tokens_t, language tokens, visual tokens_{t+1}, ...]，语言与视觉 token 交错排列以对齐 VLA 推理过程 - 损失函数：离散视觉 token 和语言 token 上的交叉熵损失

阶段二：Human-Centric Trajectory-Aware Video Modeling - 在带手部关键点标注的第一人称视频上继续训练 I2V 模型 - 除预测未来帧外，同时预测未来帧中的关键点轨迹 - 关键设计理由：手部关键点轨迹与机器人动作空间具有结构相似性，可作为视觉动态到低层动作的中间表征

阶段三：Robot-Centric Vision-Language-Action Modeling - 继承前两阶段权重，在自收集的机器人数据集上微调 - 输入：语言指令 + 当前观测（双视角 + 关节状态） - 优化目标：预测未来帧和动作嵌入

关键设计决策

多阶段课程学习的逻辑在于：纯视觉预测与动作生成之间存在表征鸿沟，直接跳转会浪费预训练信号。轨迹预测阶段作为「语义桥梁」，让模型先学会理解手部运动学，再映射到机器人执行空间。这一设计使三个阶段的知识传递损失最小化。

关键创新

1. 以视频生成为预训练主任务而非辅助目标 现有 VLA 工作多将人类视频作为辅助损失或数据增强，HumanX 将其作为第一阶段的主优化目标。视频生成迫使模型学习完整的物理动态和操作因果链，而非仅仅提取静态特征。这是从「看视频学表征」到「生成视频学动态」的范式转变。

2. 轨迹感知中间阶段弥合视觉-动作鸿沟 手部关键点轨迹预测作为显式中间监督，比纯视觉预测更接近动作空间，又比直接预测机器人动作更易获得大规模标注。这一设计选择在课程学习中扮演「锚点」角色，使阶段一到阶段三的迁移不是黑箱跳跃，而是有明确语义对应的渐进过程。

3. 交错 token 序列统一 VLA 推理格式 将语言、视觉、动作统一为离散 token 序列，使模型可以用单一自回归框架处理三种模态。这一设计不仅简化了架构，还使预训练的视频生成任务与下游的动作预测任务共享完全相同的优化目标形式，最大化知识迁移效率。

边界与局限

论文片段未明确列出作者承认的局限性。从方法本身可推断的边界包括：第一，阶段二依赖手部关键点标注，其标注质量与覆盖范围直接影响轨迹预测的泛化，但标注规模与筛选标准论文未明确；第二，12M 人类视频的筛选流程（如视角一致性、任务多样性、质量过滤）在片段中标注为「将在 Sec. 4 提供」，实际细节缺失；第三，ActionVAE 的动作块编码能力受限于训练数据的动作分布，对未见过的操作模式可能解码失真；第四，实验对比仅提及两个基线，未涉及与纯机器人数据训练（无人类视频预训练）的消融，无法量化人类视频预训练的净增益。论文未明确。

工程启示

复现或借鉴此方法时，优先核对三件事：第一，12M 人类视频的筛选标准——来源分布、视角一致性、任务类型覆盖，这直接决定预训练质量，但论文未给出细节，需自行设计或联系作者；第二，阶段二手部关键点标注的获取方式——是自动检测还是人工标注，标注噪声对轨迹预测的影响有多大，这决定了中间阶段的实际收益；第三，ActionVAE 的压缩比与动作块长度——压缩过紧会丢失精细操作，过松则无法与 token 预测框架有效对齐。

最容易踩坑的地方在于阶段一到阶段二的衔接：如果手部关键点轨迹与机器人动作空间的映射关系设计不当，中间阶段可能不仅无益，反而引入偏置。建议在阶段二训练后先做小规模机器人数据验证，确认轨迹预测确实提升了动作预测质量，再投入全量微调。另外，交错 token 序列的长度管理需要谨慎——语言、视觉、动作 token 的比例失衡可能导致训练不稳定，建议在阶段一就固定序列格式并在全流程保持一致。
