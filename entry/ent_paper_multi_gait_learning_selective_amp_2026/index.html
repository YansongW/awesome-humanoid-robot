Multi-Gait Learning for Humanoid Robots Using Reinforcement Learning with Selective Adversarial Motion Prior

Multi-Gait Learning for Humanoid Robots Using Reinforcement Learning with Selective Adversarial Motion Prior

领域
AI 模型与算法
层级

审校
AI 全文核验

摘要

本文提出一种基于强化学习的多步态学习方法，使12自由度人形机器人通过统一策略掌握行走、正步、奔跑、爬楼梯和跳跃五种步态。核心创新是选择性对抗运动先验（AMP）策略：仅对周期性、稳定性关键的步态施加AMP以加速收敛并抑制异常行为，而对动态步态（奔跑、跳跃）则有意省略以避免过度约束。实验证明，选择性AMP在所有五种步态上均优于统一AMP策略，在稳定性步态上实现更快收敛、更低跟踪误差和更高成功率，同时不牺牲动态步态的敏捷性。

概述

本文提出一种在统一强化学习框架下学习人形机器人五种步态（行走、正步走、爬楼梯、跑步、跳跃）的方法，核心贡献是提出“选择性对抗运动先验”（Selective AMP）策略：仅在周期性、中等关节振幅的步态（行走、正步走、爬楼梯）中激活AMP判别器，而在需要爆发性动态的步态（跑步、跳跃）中关闭AMP，以避免其正则化约束阻碍策略达到必要运动极限。方法在Isaac Gym中训练并在Lite_11人形机器人上零样本迁移部署。

它改变了什么

现有AMP类工作（如Peng et al. 2021, Escontrela et al. 2022, Lerario et al. 2024）都将AMP作为“万能添加剂”统一应用于所有任务，默认其总能提升行为质量。本文的洞察在于：AMP的有效性高度依赖目标步态的运动学特征——对于周期性、关节振幅适中的步态（行走、正步走），AMP能有效强化风格化运动模式；但对于需要大关节行程、快速加速和爆发性动态的步态（跑步、跳跃），人类运动参考数据稀缺，AMP判别器的正则化反而成为约束，迫使策略偏向保守、过度正则化的运动模式，阻碍其达到必要的运动极限。

这一发现改变了多步态学习的核心设计逻辑：不再追求“一个奖励函数+一个AMP配置”的通用方案，而是将AMP视为一种“按需启用的风格化工具”，根据步态的动态需求选择性激活。同时，本文证明了在统一MDP结构、统一观测空间、统一奖励公式下，仅通过参考轨迹参数、奖励权重和AMP配置的差异化，就能让单个策略网络学会五种运动特征差异巨大的步态，这挑战了此前“每种步态需要独立训练”的惯例。

方法拆解

统一RL框架

所有五种步态共享相同的MDP结构、策略架构（Actor MLP [512,256,128]，ELU激活）、观测空间（50维/帧，堆叠21帧=1050维）和奖励公式（r_total = Σ_i w_i r_i），仅通过参考轨迹参数、奖励权重和AMP配置区分。

观测空间（50维/帧）

  • 基座线速度 v_b ∈ ℝ³（缩放2.0）
  • 速度指令 c ∈ ℝ³
  • 相位编码 φ ∈ ℝ²：[sin(2πφ_t), cos(2πφ_t)]
  • 基座角速度 ω_b ∈ ℝ³（缩放0.25）
  • 投影重力向量 g_p ∈ ℝ³
  • 关节位置误差 q_e ∈ ℝ¹²（与默认站立构型之差）
  • 关节速度 q̇ ∈ ℝ¹²（缩放0.05）
  • 上一动作 a_{t-1} ∈ ℝ¹²
  • 相位变量 φ_t ∈ [0,1)，推进 φ_{t+1} = (φ_t + Δt/T_cycle) mod 1

参考轨迹生成

  • 周期性步态（行走、正步走、跑步、爬楼梯）：正弦参考 q_ref^L,hip = -s·𝟙_{s<0}，q_ref^L,knee = 2s·σ·𝟙_{s<0}，其中 s = sin(2πφ_t)，σ为目标关节位置缩放（行走/跑步0.26，正步走0.28）。各步态通过 (T_cycle, stance_ratio) 调制：行走(0.8s, 0.6)、正步走(0.7s, 0.45)、跑步(0.4s, 0.35)、爬楼梯(0.7s, 0.6)。
  • 跳跃：分段4.0s周期轨迹，五阶段（下蹲φ<0.30、起跳0.30-0.42、飞行0.42-0.48、落地0.48-0.75、站立φ≥0.75），课程学习在2000-10000 PPO迭代间逐渐增加下蹲深度。

动作与PD控制

  • 12维动作向量，目标关节位置 q_target = a_t·k_action·k_gain + q_default，k_action按步态区分（行走/爬楼梯0.25，跑步0.3，正步走0.4）
  • PD控制器 τ = K_P(q_target - q) - K_D q̇，K_P范围75-280 N·m/rad（正步走显著更高：髋俯仰450，膝800），策略50Hz，PD 200Hz，动作延迟5-10步

奖励设计（四类）

  1. 关节跟踪：r_track = 0.15 Σ(e^{-4e²} + e^{-20e²})，膝项仅摆动相掩码
  2. 基座平衡与姿态：姿态、基座高度、线速度跟踪（跑步w=20.0，跳跃0.0）、角速度跟踪
  3. 运动平滑：动作平滑惩罚、关节速度、额定扭矩
  4. 安全与步态专用：终止条件（|roll|>0.8 rad）、脚摆动高度、跳跃专用（高度目标0.275m高斯奖励w=150.0，垂直起跳速度分段非线性w=120.0）

选择性AMP策略

  • 判别器：3层MLP [1024,512,256]，ReLU，输入为(s_t, s_{t+1})拼接
  • AMP奖励：r_AMP = α·max(0, 1 - ¼(D-1)²)，与任务奖励线性插值 r_combined = (1-β)·r_AMP + β·r_task
  • 判别器损失：L_D = E_policy[(D+1)²] + E_expert[(D-1)²] + λ·E_expert[‖∇D‖²]，λ=10
  • 关键配置：行走(α=0.3, β=0.8)、正步走(α=0.6, β=0.7)、爬楼梯(α=0.3, β=0.8)、跑步(α=0.0, β=1.0)、跳跃(α=0.0, β=1.0且禁用对称损失)

训练与部署

  • PPO，4096并行环境（跑步/跳跃2048），学习率5×10⁻⁴，γ=0.99，GAE λ=0.95
  • 域随机化：接触属性、基座质量[-2,+5]kg、惯量[0.5,1.8]、电机强度、PD增益[0.8,1.2]、动作延迟课程[2→5]步
  • 零样本Sim-to-Real：ONNX导出，策略50Hz，PD 500Hz，基座线速度观测通道置零

关键创新

  1. 选择性AMP激活机制：首次系统性地论证AMP并非对所有步态有益，并提出按步态动态特征选择性启用的策略。对周期性步态（行走、正步走、爬楼梯）激活AMP以强化风格化运动，对爆发性步态（跑步、跳跃）关闭AMP以避免正则化约束。这一设计决策基于对AMP判别器作用机制的深入分析：AMP擅长强化周期性重复模式，但会阻碍大关节行程和快速加速。

  2. 统一框架下的多步态学习：在完全相同的MDP结构、观测空间（50维×21帧）和奖励公式下，仅通过参考轨迹参数（T_cycle, stance_ratio）、奖励权重和AMP配置的差异化，实现五种运动特征差异巨大的步态学习。这避免了为每种步态单独设计奖励函数和超参数的传统做法，显著降低了工程复杂度。

  3. 跳跃步态的专用奖励与课程设计：针对跳跃这一最难学习的步态，设计了分段非线性垂直起跳速度奖励（低于1.0 m/s线性斜坡，高于则二次）和0.275m高度目标的高斯奖励，配合下蹲深度课程学习（2000-10000迭代渐进增加），使策略能在11000次迭代内收敛，且无需AMP辅助。

AMP对比实验（图3）

  • 带AMP的正步走：总奖励快速增加、低训练误差、失败率快速衰减，验证AMP对周期性步态的正面作用
  • 不带AMP的跳跃：仍能达到持续奖励增长和低失败率，关节跟踪信号稳步改善，验证关闭AMP不影响爆发性步态学习

关键发现

  • 正步走使用更高AMP权重（α=0.6, β=0.7）强制独特直腿风格，训练误差仅5.4，成功率97%
  • 跳跃关节跟踪指标15.5显著高于其他步态，反映其大关节行程特性，但姿态稳定性指标8.6也最高，说明跳跃对平衡控制要求更高
  • 作者明确指出表III数值旨在表征统一框架下的训练行为，而非跨任务严格归一化的物理量

工程启示

  1. AMP配置是首要核对项：复现时先确认各步态的α和β设置——行走/爬楼梯(0.3, 0.8)、正步走(0.6, 0.7)、跑步/跳跃(0.0, 1.0)。这是本文最核心的设计决策，错误配置AMP会导致跑步和跳跃策略过度保守或无法达到运动极限。

  2. 正步走的PD增益是最大坑：正步走使用显著更高的刚度（髋俯仰450，膝800 N·m/rad）和阻尼（膝K_D最高40），远超其他步态。若统一使用行走的PD参数，正步走的直膝摆动风格将无法实现。建议按步态分别配置PD增益，而非共享。

  3. 跳跃奖励的敏感性：跳跃高度目标高斯奖励中心0.275m、垂直起跳速度阈值1.0m/s、水平速度惩罚w=-15.0，这些参数高度耦合。建议先固定高度奖励，再调起跳速度奖励，最后微调水平速度惩罚，避免参数间相互干扰。

  4. 基座线速度置零的工程技巧：硬件上无法直接测量基座线速度时，将对应观测通道设为零，依赖21帧观测历史堆叠隐式捕获速度信息。这一技巧对部署至关重要，但需确保训练时也模拟该缺失（而非仅在部署时置零）。

  5. 训练迭代数的差异：正步走仅需20001次迭代、跳跃11000次，而行走/爬楼梯/跑步需40001次。若训练资源有限，优先保证行走和爬楼梯的完整训练，正步走和跳跃可提前停止。

  6. 域随机化范围需按步态调整：跳跃采用更保守的随机化范围（电机强度[0.9,1.1]），而跑步/正步走使用更宽范围[0.8,1.2]。复现时注意不要对所有步态使用统一随机化参数，否则跳跃策略的鲁棒性会受影响。
