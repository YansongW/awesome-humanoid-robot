地形感知主动凝视的人形敏捷运动控制

TAGA: Terrain-aware Active Gaze Learning for Generalizable Agile Humanoid Locomotion

领域

层级

审校

摘要

TAGA 是一个面向注意力机制人形机器人控制的主动注视学习框架，由研究团队提出，旨在通过融合视觉、本体感知与运动指令，让机器人自主关注地形关键区域。其核心贡献在于仅通过强化学习即可自然涌现类人注视行为，无需额外监督，并在真实环境中实现了 1.2 米的最大间隙跨越距离。

概述

TAGA 是一个面向人形机器人敏捷 locomotion 的主动感知框架，由研究团队在 Isaac Lab 仿真与 Unitree G1 真机上实现。其核心贡献在于将“看哪里”的主动注视机制与多模态感知融合相结合，通过可微分的注视点预测与交叉注意力机制，在显著降低训练成本的同时实现了与全图扫描相当甚至更优的泛化性能。

它改变了什么

现有感知 locomotion 方法陷入了一个两难：基于高度图的方法在扩大感知范围时计算成本急剧上升，而基于前视深度图的方法虽然看得远却会遗漏脚部附近的关键地形细节。更根本的问题在于，这两种感知范式——视觉的远见与高度图的局部精度——本质上是互补的，但现有方法要么依赖单一来源，要么只是松散耦合，从未真正解决“何时看哪里”这一主动感知问题。人类和动物在复杂地形上行走时，目光会主动投向任务相关的区域，而不是均匀扫描整个视野。TAGA 改变了这一范式：它不再将感知视为被动的信息收集，而是将其建模为一个可学习的决策过程，让策略自主决定哪些局部地形信息对下一步动作最关键。

这一改变的实际意义在于，它打破了感知范围与计算成本之间的线性绑定。通过将注意力集中在高度图的一个紧凑区域（K=11 的裁剪块），TAGA 在保持前瞻视觉线索的同时，将局部几何处理的复杂度降低了近一个数量级。更重要的是，这种主动注视机制不是手工设计的启发式规则，而是通过端到端强化学习自动涌现的——策略学会了在不同地形上应该注视哪里，这比任何固定策略都更具适应性。

方法拆解

TAGA 的整体框架是一个 POMDP 策略，观测空间由三部分构成：前视深度图 d_t ∈ ℝ^{1×36×64}、以自我为中心的高度图 h_t^{xyz} ∈ ℝ^{3×21×21}、以及 5 帧本体感觉历史 p_t^H。动作空间为 29 维目标关节位置，以 50 Hz 输出，由 200 Hz 的低级 PD 控制器跟踪。

任务相关主动注视模块

  • 轻量级预测头 f_roi 接收视觉嵌入 e_t^d 与本体感觉嵌入 e_t^p 的拼接，输出归一化二维注视位置 r_t ∈ [0,1]²
  • 将 r_t 映射到高度图网格坐标 (u_t, v_t) = (⌊r_t^x M⌋, ⌊r_t^y M⌋)，其中 M=21
  • 通过可微分的双线性网格采样裁剪出 K=11 的紧凑地形块 h̃_t^{xyz}
  • 边界惩罚 L_roi 防止注视点退化到高度图边界，裕度 m=0.05

视觉运动融合编码器

  • 裁剪地形块经轻量级 CNN 与空间坐标 MLP 编码，得到逐点地形嵌入 E_t^m ∈ ℝ^{K×K×128}，作为 key 和 value
  • 投影头 f_proj 从视觉与本体感觉嵌入生成 query
  • 多头交叉注意力融合：e_t^{pg} = MHA(f_proj([e_t^p, e_t^d]), E_t^m, E_t^m)，输出 ℝ¹²⁸

动作解码与训练

  • 混合专家（MoE）模块，N_e=5 个专家，门控网络 g(·) 生成软路由权重 α_t^i = Softmax(g(e_t^π))_i，最终动作 a_t = Σ α_t^i E_i(e_t^π)
  • 非对称 actor-critic PPO 训练，critic 接收特权信息（真实线速度、完整高度图）
  • 两阶段训练：第一阶段 30k 次迭代无噪声训练核心技能，第二阶段 10k 次迭代降低熵系数并引入部署导向域随机化
  • 对比损失 L_con 通过 Sinkhorn 平衡分配将 MoE 门控嵌入与完整高度图地形嵌入在共享原型空间中对齐，鼓励专家地形专业化
  • 对称增强利用人形机器人左右对称性，镜像观测与动作并纳入 PPO 更新

关键创新

主动注视作为可学习决策：将“看哪里”建模为端到端可微的预测头，而非手工规则或固定策略。这是首次将主动感知机制与强化学习策略联合优化，使注视行为本身成为策略的一部分。其重要性在于，策略学会了在不同地形上自适应地分配感知资源——在间隙跨越时注视落脚点，在稀疏踏脚石上注视下一个支撑面。

裁剪式注意力替代全图处理：通过可微分的双线性采样从 21×21 高度图中裁剪出 11×11 的紧凑块，将局部几何处理的输入规模缩减约 73%。这不仅降低了计算成本，更重要的是通过信息瓶颈迫使策略聚焦于任务相关区域，避免了全图处理中的信息冗余与过拟合。实验证明，这种裁剪式注意力在 OOD 地形上的表现与全图扫描相当，但训练成本降低 65.2%。

MoE 与地形对比学习的协同：通过对比损失将 MoE 门控嵌入与完整高度图的地形嵌入在共享原型空间中对齐，使专家网络自发地 specialize 到不同地形类型。这解决了 MoE 在强化学习中常见的专家退化问题，同时为策略提供了地形感知的模块化决策能力。

实验与结果

仿真评估在 Isaac Lab 中进行，8,000 个并行环境，4 块 RTX 5090 GPU，训练总耗时约 17 GPU 天。每种地形评估 1,000 次试验。

关键对比结论： - TAGA 在 OOD 地形 C1、C2 上成功率分别为 93.70% 和 93.90%，显著优于 CReF（85.20%/43.10%）和 TAGA-InactiveGaze（72.70%/48.80%） - TAGA 与 TAGA-FullScan 性能相当，但训练成本降低 65.2%（17 vs 49 GPU-days） - TAGA-InactiveGaze 在 Gaps 上仅 57.10%，证明主动注视机制对间隙跨越至关重要 - 真实世界评估：Unitree G1 成功跨越 120 cm 间隙（对比方法最佳为 90 cm），稀疏踏脚石间距 50–70 cm 且高度变化 10 cm，并在室外、低光照、踢踹推搡下保持稳定

边界与局限

作者明确承认执行器热负荷问题：TAGA 实现的动态动作（爆发性跳跃、精确落脚、动态平衡恢复）在长时间运行中对执行器产生高热负荷，可能导致控制精度逐渐下降，表现为跳跃距离缩短或错过落脚点。此外，方法高度依赖高度图质量——在复杂地形上，高度图重建质量差会直接导致步态不当或失败。论文未明确提及数据量（AMP 参考数据的具体规模）以及在不同机器人平台上的迁移能力。值得注意的是，真实世界评估中的对比方法（HPL、PIM、CMoE 等）并非在同一实验条件下复现，而是引用了各自论文中的最佳结果，因此跨方法比较需谨慎解读。

工程启示

复现 TAGA 时，首先需要核对的是注视预测头的初始化与边界惩罚的权重——从消融实验看，TAGA-InactiveGaze（固定注视点）在 Gaps 上性能骤降至 57.10%，说明注视机制对间隙类地形至关重要，但若边界惩罚过强可能导致注视点过早收敛到中心区域，削弱自适应能力。其次，两阶段训练策略不可跳过：第一阶段的无噪声训练建立了核心技能，第二阶段的域随机化微调（特别是深度相机退化模拟与高度图噪声）是真实世界泛化的关键。最容易踩坑的地方在于对比损失 L_con 的 Sinkhorn 平衡分配实现——若原型字典 C 的更新频率或温度系数 T_con 设置不当，可能导致 MoE 专家退化而非专业化。对于下游团队，建议先在小规模地形集（如仅间隙与踏脚石）上验证注视行为是否合理，再扩展到全地形训练；训练成本约 17 GPU 天（4×RTX 5090），若资源有限可考虑减少并行环境数至 4,000 并观察性能衰减。部署时注意执行器热管理——TAGA 的爆发性动作在长时间运行中可能触发过热保护，建议在真机测试中加入执行器温度监控与降级策略。
