SQAP-VLA

SQAP-VLA: A Synergistic Quantization-Aware Pruning Framework for High-Performance Vision-Language-Action Models

摘要

SQAP-VLA 是南京大学电子科学与工程学院与亚利桑那大学联合提出的首个结构化、免训练的视觉-语言-动作模型推理加速框架。其核心贡献在于协同设计量化感知剪枝流程，解决了量化与剪枝技术之间的不兼容问题，在保持模型性能的同时实现 1.93 倍加速和最高 4.5% 的成功率提升。

来源与参考

  • SQAP-VLA: A Synergistic Quantization-Aware Pruning Framework for High-Performance Vision-Language-Action Models (arXiv)
  • SQAP-VLA source

概述

SQAP-VLA 是首个面向视觉-语言-动作模型（VLA）的结构化、免训练推理加速框架，由论文作者提出，旨在同时实现最先进的量化和 token 剪枝。其核心贡献在于通过量化不敏感 token 保留、机器人感知 token 保护与空间感知 token 采样三种策略，解决了 token 剪枝与量化结合时的根本性不兼容问题，在 W4A4 量化下实现 1.93× 端到端加速且成功率反超 FP16 基线。

它改变了什么

VLA 模型在边缘设备部署的最大障碍是计算与内存开销，而现有压缩手段——量化与 token 剪枝——各自为战时效果尚可，一旦结合便出现根本性冲突：token 剪枝会放大模型对量化的敏感度，量化则扭曲注意力分数分布，使得为高精度模型设计的剪枝策略在量化网络上完全失效。此前没有任何工作系统性地解决这一协同问题，导致实际部署中只能二选一，无法同时获得两者的收益。

SQAP-VLA 真正改变的是“压缩策略必须针对量化网络重新设计”这一认知。它不再将剪枝视为与量化无关的独立模块，而是基于量化后注意力分布的实证观察，重新定义了 token 保留的优先级。这种“量化感知的剪枝”思路，使得 4-bit 量化与激进剪枝（保留 60% token）可以共存，且最终精度不降反升——这在以往的工作中是不可想象的。

方法拆解

SQAP-VLA 采用“剪枝-量化”协同设计，整体流程分为三个剪枝策略与一个量化方案：

剪枝侧：三层 token 保留策略

  1. 量化不敏感 token 保留（策略 1）：基于实证发现，量化主要损害中等注意力分数的 token，而 top-k 注意力分数 token 的索引在量化前后保持稳定。因此直接用公式 𝒦_attn = Top_k(a_q, k) 从量化后的注意力图 a_q 中选择 top-k token，无需任何校准或微调。
  2. 机器人感知 token 保护（策略 2）：利用机器人已知的 3D 世界坐标 (x_w, y_w, z_w)，通过相机内参 K 和外参 [R|t] 投影到 2D 像素坐标 (u, v)（公式 λ[u v 1]^T = K[R|t][x_w y_w z_w 1]^T），再映射到 token 坐标 t_u = ⌊u/P_w⌋, t_v = ⌊v/P_h⌋。以 Chebyshev 距离（ℓ∞ 范数）在半径 R_t 内形成保护环 𝒦_ring，确保与机器人操作直接相关的视觉 token 不被剪除。
  3. 空间感知 token 采样（策略 3）：对剩余 token 𝒯_remain = 𝒯 \ (𝒦_attn ∪ 𝒦_ring) 应用 Farthest Point Sampling（FPS）选择 m 个空间多样 token 𝒦_fps = FPS(𝒯_remain, m)。最终保留集合为 𝒦_final = 𝒦_attn ∪ 𝒦_ring ∪ 𝒦_fps，兼顾语义重要性、任务相关性与空间覆盖度。

量化侧：通道级激活量化 + Hadamard 变换

  • 通道级激活量化：以更细粒度替代逐张量激活量化，提升量化保真度。
  • Hadamard 变换：受 QUIP# 启发，对 query 和 key 层的权重和激活应用 Hadamard 变换（公式 (W^T H^T)(H X) = W^T X），重新分布激活能量，抑制离群值，从而改善量化后注意力图的可靠性。
  • 张量级量化：克服 QUIP# 组级量化粒度对高效推理的限制，采用张量级量化以适配硬件高效执行。

关键设计决策

  • 免训练：直接应用于公开检查点，无需任何微调或校准数据。
  • 剪枝比率固定为 0.4（保留 60% token），W4A4 量化（4-bit 权重 + 4-bit 激活）。

关键创新

  1. 量化-剪枝协同设计（首个）：此前没有任何工作系统性地解决 token 剪枝与量化结合时的精度崩溃问题。SQAP-VLA 通过实证发现“量化主要影响中等注意力分数 token”这一规律，并据此设计剪枝策略，使得两者从互斥变为互补。这是方法论层面的根本创新。

  2. 机器人感知 token 保护：利用机器人已知的 3D 世界坐标投影到 2D 视觉 token 空间，形成保护环。这一策略将任务几何先验引入剪枝决策，确保与操作目标直接相关的视觉信息不被丢弃。相比纯注意力驱动的剪枝，它更符合机器人操作任务的实际需求，也是视觉-语言模型压缩工作中首次引入 3D 几何约束。

  3. Hadamard 变换与张量级量化的结合：将 QUIP# 的 Hadamard 变换从组级量化扩展到张量级量化，既保留了离群值抑制效果，又克服了组级量化对推理效率的限制。这一设计使得 4-bit 激活量化在 VLA 上首次达到实用水平。

实验与结果

实验在 CogAct 模型（Prism-DinoSigLIP-224px 视觉编码器 + LLM + 扩散动作头）上进行，评估两个变体（Visual Matching 和 Variant Aggregation），任务包括 Pick Coke Can、Move Near、Open/Close Drawer、Place Apple in Top Drawer。基线包括 FP16 原始模型、Random Dropping、FastV、VLA-Cache、EfficientVLA。

表 1：Visual Matching 变体关键结果

方法 平均成功率 (%) 加速比 BOPs (%)
CogACT (Baseline) FP16 74.8 1.0× 100.0
Random Dropping FP16 20.9 1.2× 58.5
FastV FP16 74.1 1.21× 42.0
VLA-Cache FP16 74.4 1.38× 80.1
EfficientVLA FP16 76.4 1.59× 45.1
SQAP-VLA W4A4 79.3 1.93× 26.3

表 2：Variant Aggregation 变体关键结果

方法 平均成功率 (%) 加速比 BOPs (%)
CogACT (Baseline) FP16 61.3 1.0× 100.0
Random Dropping FP16 8.9 1.20× 58.5
FastV FP16 62.1 1.19× 42.0
VLA-Cache FP16 62.3 1.37× 82.6
EfficientVLA FP16 63.2 1.57× 45.1
SQAP-VLA W4A4 64.4 1.93× 26.3

关键结论： - Visual Matching 中 SQAP-VLA 比 EfficientVLA 高 2.9%，比 FP16 基线高 4.5%；Variant Aggregation 中比基线高 3.1%。 - 相对基线 1.93× 加速，比 EfficientVLA 提升 36%（由表内 1.93× 与 1.59× 计算）。 - 端到端 1.93× 加速中，LLM 骨干贡献 2.56×（W4A4 量化贡献 2.09×，token 剪枝贡献 1.21×）。 - 峰值 GPU 内存从 14.3 GB 降至 7.6 GB。 - 消融实验（表 3）显示最佳剪枝比率为 0.4；W4A4 量化分别降低成功率 3.02% 和 3.12%，但协同剪枝后反超基线。 - 消融实验（表 4）显示三个策略逐步叠加，最终 Visual Matching 从 74.80 提升至 79.30，Variant Aggregation 从 61.30 提升至 64.40。

边界与局限

论文未明确列出具体局限性，但可从方法设计中推断： - 框架仅在 CogAct 模型上验证，未扩展到其他 VLA 架构（如 RT-2、OpenVLA 等），泛化性未知。 - 剪枝比率固定为 0.4，未实现动态、任务自适应的剪枝策略。 - 机器人感知 token 保护依赖已知的 3D 世界坐标与相机标定参数，在无精确标定的场景下该策略可能失效。 - 实验仅在 Simpler 模拟器上进行，未涉及真实机器人部署。 - 效率指标在单张 NVIDIA RTX 3090 GPU 上测得，其他硬件平台（如边缘设备）上的加速比可能不同。

工程启示

对复现与工程部署的直接指导：

  1. 先核对注意力分布稳定性：SQAP-VLA 的核心前提是“top-k 注意力 token 索引在量化后保持稳定”。复现时需先验证目标模型是否满足这一性质，若不满足，策略 1 可能失效。
  2. 相机标定精度是关键：策略 2 依赖精确的相机内参 K 和外参 [R|t]。在真实机器人系统中，标定误差会直接影响保护环的准确性，建议先验证投影误差对最终成功率的影响。
  3. Hadamard 变换的矩阵维度匹配：应用 (W^T H^T)(H X) 时，需确保 Hadamard 矩阵维度与权重/激活维度匹配，否则会引入额外开销或数值错误。
  4. 剪枝比率 0.4 是经验最优：消融实验显示 0.4 为最佳，但该值可能随模型和任务变化。建议在目标场景下重新扫描 0.3–0.6 区间。
  5. 内存收益显著但需验证：峰值内存从 14.3 GB 降至 7.6 GB，这对边缘部署意义重大，但需确认在更低内存预算（如 4 GB）下是否仍能保持性能。
  6. 免训练是最大工程优势：直接应用于公开检查点，无需微调管线，这意味着可以快速集成到现有部署流程中。代码已公开（https://github.com/ecdine/SQAP-VLA），建议先跑通官方复现，再迁移到自有模型。
