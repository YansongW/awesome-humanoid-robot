概述

人体/物体检测与跟踪（Human/object detection and tracking）是人形机器人感知系统的核心工序节点，属于 VLA / WAM / AI 算法集成（AI & Perception）工作包。它通过 2D/3D 检测、多目标跟踪与人体姿态估计等技术，为人机交互、避障与操作任务提供实时感知输入。该工序的关键约束在于遮挡、光照变化与实时性，其完成标准以检测准确率、跟踪 ID 稳定性与延迟为核心量化指标。

核心内容

是什么：准确定义

人体/物体检测与跟踪，是指在机器人感知系统中，对视野内的人体与物体进行空间定位、类别识别与时间维度上的持续关联。它并非单一算法，而是一条完整的感知流水线：检测回答"视野中有什么、在哪里"（2D 边界框或 3D 包围盒），跟踪回答"这些目标在时间轴上如何关联"（ID 保持与轨迹估计），姿态估计则进一步回答"人体各关节在空间中的构型如何"（2D 关键点或 3D 骨架）。

在人形机器人全流程开发中，P12.1.3 是感知层与决策层之间的桥梁——它输出的不是原始像素，而是经过结构化处理的目标级信息，供后续的避障规划、抓取操作与人机交互策略直接消费。

为什么存在：痛点与历史定位

在早期机器人系统中，感知往往是"为单一任务定制的孤岛"：避障系统只检测障碍物，抓取系统只识别工件，交互系统只追踪人脸。这种碎片化设计导致三个长期痛点：

  1. 感知与行动脱节：检测结果缺乏时间一致性，机器人无法判断一个物体是静止还是运动，更无法预测其轨迹。
  2. 多任务重复建设：每个子系统各自训练检测模型，数据标注成本成倍增加，模型之间互不共享。
  3. 人机共融场景失效：在家庭、医院等非结构化环境中，遮挡频繁、光照多变，单帧检测的准确率急剧下降，而跟踪恰好能通过时间上下文弥补单帧感知的不足。

P12.1.3 的历史定位，正是将"检测"与"跟踪"从各自独立的模块整合为一条统一的感知工序，使其成为机器人"具身智能"的感知基座。它真正改变的不是"看得见"这件事本身，而是"看得懂连续变化的世界"——从单帧快照到时空一致的场景理解。

原理拆解

① 检测：从滑动窗口到端到端回归

现代 2D 检测器（如 YOLO 系列、DETR 系列）将目标检测建模为密集预测问题。以 DETR 为代表的端到端方法，通过 Transformer 的注意力机制直接输出目标集合，无需手工设计的锚框和后处理。3D 检测则在此基础上增加深度估计分支，输出目标的中心点、尺寸与朝向。对于人形机器人，3D 检测通常依赖 RGB-D 相机或激光雷达，其核心公式为：

\[ [x_c, y_c, z_c, w, h, l, \theta] = f_{\text{det}}(I, D) \]

其中 \(I\) 为 RGB 图像，\(D\) 为深度图，输出为目标中心坐标、三维尺寸与朝向角。

② 跟踪：数据关联与状态估计

多目标跟踪（MOT）的核心是数据关联——将当前帧的检测结果与已有轨迹进行匹配。经典方法采用匈牙利算法求解最优匹配，代价矩阵由运动模型（如卡尔曼滤波预测）与外观特征（如 Re-ID 特征）共同构建。跟踪 ID 稳定性是衡量系统质量的关键指标：ID Switch 次数越少，说明系统对遮挡和交叉场景的鲁棒性越强。

③ 人体姿态估计：从关键点到骨架

人体姿态估计分为自顶向下（先检测人再估计关键点）与自底向上（先检测所有关键点再聚类成骨架）两条路线。对于人形机器人，姿态估计的意义不仅在于理解人的动作意图，更在于为模仿学习提供参考数据——通过观察人类操作者的关节角度轨迹，机器人可以学习相似的运动策略。

横向对比

在机器人感知领域，人体/物体检测与跟踪存在多种技术路线：

技术路线 优势 劣势 适用场景
2D 检测 + 2D 跟踪 算力需求低、生态成熟 缺乏深度信息，无法直接用于抓取 人机交互、简单避障
3D 检测 + 3D 跟踪 空间信息完整，可直接对接操作规划 依赖深度传感器，算力开销大 抓取操作、导航避障
单目 3D 重建 无需深度传感器，成本低 深度精度有限，遮挡下易失效 轻量级平台、数据采集
多传感器融合 鲁棒性最强，抗遮挡与光照变化 标定复杂、系统成本高 全尺寸人形机器人

P12.1.3 的设计思考逻辑决定了其技术选型：为人机交互、避障、操作提供感知输入，因此通常采用 2D/3D 检测与多目标跟踪的组合方案，并在关键场景中引入人体姿态估计作为补充。

谁在用·应用案例

案例一：人机协作装配（工业场景） 在工厂中，人形机器人需要与工人共享工作空间。通过人体检测与姿态估计，机器人实时感知工人的手臂位置，动态调整自身运动速度与轨迹，确保安全距离。跟踪模块维持工人的 ID，使机器人能够预测其运动意图，提前规避碰撞。

案例二：家庭服务（非结构化场景） 在家庭环境中，机器人需要识别并跟踪用户指定的物体（如"帮我拿桌上的杯子"）。3D 检测提供杯子的空间位置，跟踪模块在机器人移动过程中持续锁定目标，即使杯子被部分遮挡也能保持 ID 稳定。人体姿态估计则用于理解用户的指向手势，完成自然的人机交互。

案例三：模仿学习数据采集（研发场景） 参考 EmbodMocap 的工作，双 RGB-D 相机可以同时重建人体与场景，为机器人运动控制提供训练数据。P12.1.3 中的人体姿态估计模块在此场景下输出高精度的关节轨迹，配合 sim-to-real 强化学习，使人形机器人能够复现视频中的人体运动。

局限与边界

  1. 遮挡的物理极限：当目标被完全遮挡时，任何跟踪算法都只能依赖运动模型外推，误差随时间累积。这是感知的物理边界，无法通过算法完全消除。
  2. 光照变化的鲁棒性：剧烈光照变化（如逆光、夜间）会显著降低检测准确率，多传感器融合是缓解手段，但会增加系统复杂度与成本。
  3. 实时性与精度的权衡：高精度模型（如基于 Transformer 的大模型）往往计算量大，难以满足实时性要求。工程上需要在精度与延迟之间取折中，具体指标需自行确认。
  4. 数据标注成本：3D 检测与姿态估计的训练数据标注成本远高于 2D 检测，这限制了模型在特定场景下的泛化能力。

常见误区

  1. "检测准 = 跟踪稳"——错。检测准确率与跟踪 ID 稳定性是两个正交指标。即使单帧检测 mAP 很高，如果数据关联策略不当，ID Switch 依然会频繁发生。跟踪质量取决于关联算法的鲁棒性，而非单纯检测精度。
  2. "3D 检测一定优于 2D 检测"——错。3D 检测依赖深度信息的质量，在深度传感器失效或标定偏差时，其性能可能劣于成熟的 2D 方案。技术选型应基于具体任务需求。
  3. "姿态估计只是检测的附属品"——错。人体姿态估计输出的关节级信息，是模仿学习与意图理解的关键输入，其价值远超"检测到人"这一层。它真正改变的是机器人从"知道有人"到"理解人在做什么"的认知深度。

왜 존재하는가:痛点과 역사적 위치

초기 로봇 시스템에서 인지는 종종 "단일 작업을 위해 맞춤 제작된 고립된 섬"이었습니다: 장애물 회피 시스템은 장애물만 감지하고, 파지 시스템은 공작물만 인식하며, 상호작용 시스템은 얼굴만 추적했습니다. 이러한 파편화된 설계는 세 가지 장기적痛点을 초래했습니다:

  1. 인지와 행동의 단절: 감지 결과에 시간적 일관성이 없어 로봇이 물체가 정지 상태인지 운동 상태인지 판단할 수 없고, 궤적을 예측할 수도 없습니다.
  2. 다중 작업 중복 구축: 각 하위 시스템이 자체적으로 감지 모델을 훈련하여 데이터 라벨링 비용이 배로 증가하고, 모델 간 공유가 없습니다.
  3. 인간-로봇 공존 시나리오의 실패: 가정, 병원 등 비구조화 환경에서는 폐색이 빈번하고 조명이 다양하여 단일 프레임 감지 정확도가 급격히 떨어지지만, 추적은 시간적 맥락을 통해 단일 프레임 인지의 부족을 보완할 수 있습니다.

P12.1.3의 역사적 위치는 바로 "감지"와 "추적"을 각각 독립된 모듈에서 통합된 인지 공정으로 재편하여 로봇의 "구현 지능"을 위한 인지 기반으로 만드는 것입니다. 그것이 진정으로 바꾸는 것은 "볼 수 있다"는 사실 자체가 아니라 "연속적으로 변화하는 세계를 이해한다"는 것——단일 프레임 스냅샷에서 시공간 일관된 장면 이해로의 전환입니다.
