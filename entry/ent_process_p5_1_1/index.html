概述

中心骨架与四肢连杆设计（Central skeleton and limb link design）是人形机器人本体结构工程（P5）中第一个详细结构设计任务（P5.1.1），核心目标是构建承载躯干负载并传递至腿部的骨架系统，以及连接各关节的高刚度低重量四肢连杆。该工序以 SolidWorks / NX / CATIA 为建模工具，结合拓扑优化与尺寸优化方法，在刚度、强度、重量与装配可达性四大约束下完成从输入梳理、概念设计、原型制作到验证闭环的全流程工程动作，最终输出 3D 结构模型、关键截面设计与 BOM 初稿。

核心内容

是什么：一个从「负载路径」出发的结构定义工序

中心骨架与四肢连杆设计不是简单的三维建模，而是对人形机器人负载传递路径的工程定义。中心骨架是躯干的承力主干，它把头部、手臂、电池、计算单元等上部质量汇聚后传递至髋关节与腿部；四肢连杆则是连接各旋转关节的刚性臂段，其几何精度直接决定末端执行器的定位误差。

在 WBS V3 的展开中，该工序被拆分为五个三级子任务（P5.1.1.1 至 P5.1.1.5），每个子任务又包含三个四级关键动作，形成「输入量化 → 方案设计 → 原型实施 → 验证闭环 → 文档交付」的完整工程链条。它真正改变的不是某个零件的形状，而是把「机器人能不能站稳」这个模糊目标，翻译成一组可测量、可评审、可追溯的结构参数。

为什么存在：痛点与历史定位

在早期人形机器人开发中，结构设计常被当作「最后画图」的收尾工作，导致三个系统性痛点：

  1. 负载路径不清晰：电机选型与结构设计脱节，骨架刚度不足导致关节控制器出现难以排查的振动。
  2. 重量失控：四肢连杆过度设计，整机重量超标，直接推高所需电机扭矩与电池容量，形成「越重越要加大电机、电机越重」的恶性循环。
  3. 装配灾难：未提前考虑装配可达性，导致后期布线、螺丝锁付、维护拆装困难，返工成本极高。

该工序在 P5 阶段的位置决定了它是连接上游需求与下游制造的关键闸口。它输出的关键截面设计直接成为 P8 结构强度仿真（FEA）的网格与载荷假设基础，而 BOM 初稿则流向 P16 小批量试产阶段的 DFM/DFA 评审。若此环节质量失控，后续所有阶段都会继承缺陷。

原理拆解

① 刚度是「负载路径」的函数，不是材料的函数

中心骨架与四肢连杆设计的核心力学逻辑是：在给定材料（如铝合金或碳纤维）下，结构刚度由截面惯性矩与负载路径长度共同决定。对于承受弯矩的四肢连杆，其弯曲刚度与截面惯性矩 I 成正比，而 I 又由截面形状决定：

\[ I = \frac{b h^3}{12} \quad (\text{矩形截面，} b \text{为宽度，} h \text{为高度}) \]

这意味着增加截面高度 h 比增加宽度 b 对刚度提升更有效（三次方关系），但代价是重量与空间占用同步上升。设计的关键不是「选更硬的材料」，而是在给定包络内找到「最优截面形状」。

② 拓扑优化：让材料只出现在该出现的地方

拓扑优化是该方法族中最具变革性的工具。其数学本质是在给定设计域、载荷与约束条件下，寻找材料分布密度 ρ(x) 使结构柔度最小化：

\[ \min_{\rho} \; C(\rho) = \mathbf{F}^T \mathbf{U}(\rho) \quad \text{s.t.} \quad V(\rho) \leq V_{\text{frac}} \, V_0 \]

其中 C 为结构柔度（刚度倒数），F 为载荷向量，U 为位移向量，V_frac 为允许的体积分数。优化结果往往呈现有机形态的镂空结构——这正是「高刚度低重量」的物理解答。但拓扑优化结果通常需要工程师手工光顺与重构为 CAD 特征，因为直接输出的网格无法用于加工。

③ 尺寸优化：在拓扑骨架上做「精修」

拓扑优化确定「哪里该有材料」，尺寸优化则确定「材料该有多厚」。对连杆的壁厚、加强筋高度、圆角半径等参数进行参数化扫描，在满足刚度与强度约束下最小化重量。这一步通常与 FEA 迭代结合，形成「拓扑 → 尺寸 → 验证 → 再调整」的闭环。

谁在用·应用案例

该工序是所有全尺寸双足人形机器人产品开发的必经之路。在 WBS V3 的框架下，其应用场景包括：

  • P5 本体结构工程与原型：作为详细结构设计的第一个子任务，为后续关节接口设计（P5.1.2）、外观覆盖件设计（P5.1.3）提供结构基准。
  • P8 结构强度仿真与迭代：P5.1.1 输出的关键截面设计直接作为 FEA 的几何输入，其网格与载荷假设必须与后续工艺能实现的壁厚、圆角与加强筋相匹配（语料 chapter-10）。
  • P16 小批量试产与量产准备：BOM 初稿与结构方案进入 DFM/DFA 评审（P16.1.1），评估可制造性与可装配性，为模具与工装设计（P16.1.2）提供依据。

局限与边界

  1. 拓扑优化结果不可直接加工：优化输出的有机形态网格需人工重构为 CAD 特征，这一「翻译」过程高度依赖工程师经验，且可能引入性能偏差。
  2. 静态载荷假设的局限：该工序的优化通常基于准静态载荷工况，而人形机器人行走时的动态冲击载荷、模态频率与疲劳寿命并未在拓扑优化中显式建模，需依赖 P8 的动态仿真补充验证。
  3. 材料数据依赖：拓扑优化与尺寸优化的精度取决于材料属性输入的准确性，碳纤维等各向异性材料的铺层方向若未正确建模，优化结果将失真。
  4. 装配可达性难以量化：该约束在优化目标函数中难以显式表达，通常依赖评审经验判断，存在主观性。

常见误区

  1. 「拓扑优化就是自动设计」——错。拓扑优化只解决「材料分布」问题，不解决「接口定义」「装配策略」「制造工艺」问题。它输出的是一堆网格，不是一张可加工的图纸。
  2. 「刚度越高越好」——错。刚度提升通常伴随重量与成本上升，且过高的刚度可能将冲击载荷直接传递给关节减速器，反而降低寿命。正确做法是「按需定刚度」，以负载路径与动态特性为基准。
  3. 「先画图再优化」——错。若在详细建模完成后再做拓扑优化，设计空间已被 CAD 特征锁死，优化只能做局部微调，效果大打折扣。正确顺序是「先优化、后建模、再精修」。
  4. 「BOM 初稿是采购的事」——错。BOM 初稿在 P5.1.1 阶段就应建立，它不仅是物料清单，更是重量预算、成本估算与供应链风险识别的起点。拖延 BOM 会导致后续 DFM 评审缺乏依据。

왜 존재하는가:痛点과 역사적 위치

초기 휴머노이드 로봇 개발에서 구조 설계는 종종 '마지막에 도면을 그리는' 마무리 작업으로 취급되어 세 가지 체계적인 문제점이 발생했습니다:

  1. 하중 경로 불명확: 모터 선정과 구조 설계가 분리되어, 골격 강성 부족으로 관절 컨트롤러에서 추적이 어려운 진동이 발생했습니다.
  2. 중량 통제 실패: 사지 링크의 과도한 설계로 전체 중량이 기준을 초과하여, 필요한 모터 토크와 배터리 용량을 직접 증가시키며 '무거울수록 모터를 키우고, 모터가 무거울수록 더 무거워지는' 악순환을 형성했습니다.
  3. 조립 재앙: 조립 접근성을 사전에 고려하지 않아 후기 배선, 나사 체결, 유지보수 분해·조립이 어려워지고 재작업 비용이 매우 높아졌습니다.

이 공정이 P5 단계에서 차지하는 위치는 그것이 상류 요구사항과 하류 제조를 연결하는 핵심 게이트임을 결정합니다. 이 공정이 출력하는 주요 단면 설계는 P8 구조 강도 시뮬레이션(FEA)의 메시 및 하중 가정의 기초가 되며, BOM 초안은 P16 소량 시제품 생산 단계의 DFM/DFA 검토로 흘러갑니다. 이 단계의 품질이 통제되지 않으면 이후 모든 단계가 결함을 상속받게 됩니다.
