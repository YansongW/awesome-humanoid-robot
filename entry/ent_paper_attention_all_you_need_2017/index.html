Attention Is All You Need

摘要

本文由Google团队提出Transformer架构，完全基于注意力机制，摒弃了循环与卷积网络。在WMT 2014英德翻译任务上达到28.4 BLEU，英法翻译任务以41.8 BLEU创下新纪录，训练时间仅需3.5天（8 GPU）。该模型还成功泛化到英文成分句法分析任务。

概述

《Attention Is All You Need》由 Google Brain 团队提出，彻底摒弃了序列转导中主流的循环（RNN）和卷积（CNN）架构，首次构建了完全基于自注意力机制的 Transformer 模型。该模型通过多头注意力和位置编码，在显著提升并行训练效率的同时，在 WMT 2014 英德和英法翻译任务上取得了当时的最佳 BLEU 分数，并成为后续大语言模型（LLM）的基石架构。

它改变了什么

在 Transformer 之前，序列建模的范式被 RNN 及其变体（LSTM、GRU）所统治。其核心痛点在于计算是严格顺序的：处理第 t 个 token 必须等待第 t-1 个隐藏状态计算完毕。这种时间上的串行依赖不仅让训练样本内的并行化无从谈起，更使得长序列上的梯度传播面临严重的路径长度问题——信息需要经过 O(n) 步才能从序列一端传到另一端。尽管学术界尝试过各种分解技巧和条件计算来缓解，但顺序计算的根子没有被拔掉。注意力机制当时只是作为 RNN 的辅助组件存在，用来缓解长距离依赖，从未被当作主干的替代品。

这篇论文真正改变的，是将“注意力”从一种增强手段提升为唯一的计算原语。它证明了序列建模不需要显式的顺序状态传递，仅通过“查询-键-值”的全局两两交互，就能在常数级别的顺序操作内建立任意位置间的依赖关系。这不仅解决了并行化瓶颈，更从根本上重新定义了序列编码的复杂度——从 O(n) 的串行路径缩短为 O(1) 的并行路径。它宣告了“循环”在序列转导中的必要性终结，为后来者开辟了一条完全不同的技术路线。

方法拆解

Transformer 的整体架构遵循经典的编码器-解码器范式，但内部组件全部替换为注意力机制和前馈网络。

核心模块：缩放点积注意力

  • 输入为查询（Q）、键（K）和值（V），维度分别为 d_k、d_k 和 d_v。
  • 计算流程：Attention(Q,K,V) = softmax(QK^T / √d_k) V。
  • 关键设计决策：除以 √d_k 是必要的。作者指出，当 d_k 较大时，点积的数值会变得很大，导致 softmax 函数进入梯度极小的饱和区。缩放因子将点积的方差拉回 1，保证了梯度的稳定性。

多头注意力机制

  • 将 Q、K、V 通过不同的学习线性投影（参数矩阵 W_i^Q, W_i^K, W_i^V）映射到 h 个不同的子空间，并行执行注意力函数。
  • 公式：MultiHead(Q,K,V) = Concat(head_1,...,head_h) W^O，其中 head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)。
  • 默认配置：h=8，d_k=d_v=d_model/h=64。多头机制允许模型在不同表示子空间中联合关注不同位置的信息，避免了单头注意力因平均加权而导致的“分辨率”损失。

架构堆叠与子层

  • 编码器：N=6 层，每层包含一个多头自注意力子层和一个位置全连接前馈网络（FFN）子层。每个子层采用残差连接和层归一化（LayerNorm），输出为 LayerNorm(x + Sublayer(x))。
  • 解码器：同样 N=6 层，但额外插入一个对编码器输出执行的多头注意力子层。解码器内的自注意力子层使用掩码（mask），将非法连接的 softmax 输入设为 -∞，确保位置 i 的预测仅依赖于小于 i 的已知输出，保持自回归属性。
  • 前馈网络：FFN(x) = max(0, xW_1 + b_1)W_2 + b_2，内层维度为 2048，输入输出维度为 512。

位置编码

  • 由于模型没有循环和卷积，必须注入序列顺序信息。在编码器和解码器堆栈底部的输入嵌入中加入位置编码。
  • 采用正弦和余弦函数：PE_(pos,2i) = sin(pos/10000^{2i/d_model})，PE_(pos,2i+1) = cos(pos/10000^{2i/d_model})。
  • 选择该函数的关键理由：对于任意固定偏移 k，PE_pos+k 可以表示为 PE_pos 的线性函数，这使得模型更容易学习按相对位置进行关注。

训练与正则化

  • 优化器：Adam，β_1=0.9，β_2=0.98，ε=10^{-9}。
  • 学习率调度：lrate = d_model^{-0.5} · min(step_num^{-0.5}, step_num · warmup_steps^{-1.5})，其中 warmup_steps=4000，先线性上升后按平方根倒数衰减。
  • 正则化：残差 dropout（P_drop=0.1）、注意力 dropout（作用于 softmax 输出）和标签平滑（ε_ls=0.1）。

关键创新

  1. 彻底的去循环化架构：这是最根本的创新。Transformer 是第一个完全依赖自注意力来建模序列依赖的转导模型。它证明了在机器翻译这种强序列任务上，抛弃 RNN 的顺序计算不仅可行，而且效果更好。这打破了领域内对“时间步”概念的路径依赖，为并行计算打开了大门。
  2. 多头注意力作为特征子空间联合编码器：将注意力拆分为多个头，每个头在不同的投影子空间中独立计算。这不仅是工程上的并行技巧，更是一种表征学习策略。它允许模型同时关注不同位置、不同语义关系（如指代消解、局部语法、长距离依赖），显著提升了单头注意力因平均加权而丢失的“分辨率”。
  3. 纯位置编码的线性相对位置表达：选择正弦/余弦函数而非学习式位置嵌入，其精妙之处在于数学性质——PE_pos+k 是 PE_pos 的线性函数。这使得模型在理论上可以隐式地学习到相对位置关系，而无需额外的参数或计算开销，为处理变长序列提供了优雅的解决方案。

实验与结果

实验主要围绕 WMT 2014 英德和英法翻译任务，以及英语成分句法分析任务展开。

机器翻译结果

  • 英德翻译：Transformer (big) 达到 BLEU 28.4，超过此前最佳集成模型 2.0 BLEU 以上，训练仅需 3.5 天（8 个 P100 GPU）。
  • 英法翻译：Transformer (big) 达到 BLEU 41.0，超过所有已发布的单模型，且训练成本低于此前最佳模型的 1/4。
模型 英德 BLEU 英法 BLEU 训练成本 (FLOPs)
Transformer (base) 27.3 38.1 3.3×10^18
Transformer (big) 28.4 41.0 2.3×10^19
ConvS2S (基线) 25.16 40.46 9.6×10^18 / 1.5×10^20
GNMT + RL (基线) 24.6 39.92 2.3×10^19 / 1.4×10^20
MoE (基线) 26.03 40.56 2.0×10^19 / 1.2×10^20

模型变体消融实验（英德 newstest2013）

  • 注意力头数：h=1 时 BLEU 降至 24.9，h=16 时最佳（25.8），h=32 时下降至 25.4。单头比最优多头差 0.9 BLEU。
  • 键维度 d_k：d_k=16 时 BLEU 25.1，d_k=32 时 25.4，均低于 d_k=64 的 25.8。减小 d_k 损害质量，表明简单的点积兼容函数可能不够。
  • 模型规模：d_model=1024 时 BLEU 26.0，优于 d_model=512 的 25.8；d_ff=4096 时 BLEU 26.2，优于 d_ff=2048 的 25.8。更大模型更好。
  • 正则化：无标签平滑（ε_ls=0.0）时 BLEU 降至 24.6；无 dropout（P_drop=0.0）时 BLEU 降至 25.3。两者对防止过拟合至关重要。

句法分析结果

  • 在 WSJ 约 40K 句子上训练的 4 层 Transformer 达到 F1 91.3，优于 BerkeleyParser（90.4）和 Dyer et al. (2016)（91.7）。
  • 在半监督设置下（使用 17M 句子），Transformer 达到 F1 92.7，优于所有先前模型（除 RNN 文法 93.3 外）。

边界与局限

  • 计算复杂度的边界：作者明确指出，当序列长度 n 大于表示维度 d 时，自注意力的计算复杂度会超过循环层。这意味着 Transformer 在处理超长序列（如整本书或长视频）时，其 O(n²) 的复杂度会成为瓶颈。论文中提到的局部受限注意力机制（将注意力限制在邻域 r 内）只是计划，并未在本文中实施。
  • 有效分辨率的损失：自注意力通过加权平均来聚合信息，这本质上是一种平滑操作，会降低对单个位置的“分辨率”。多头注意力只是缓解而非根除这一问题。
  • 模态扩展未验证：论文仅验证了文本（翻译和句法分析）任务。作者计划将 Transformer 扩展到图像、音频和视频，但本文并未提供任何相关实验证据。
  • 生成顺序性未解决：解码器仍然是自回归的，即逐 token 生成，这限制了推理阶段的并行化。作者承认“使生成更少顺序化”是未来目标，但本文未涉及。

工程启示

  • 复现优先核对：首先确认学习率调度中的 warmup_steps=4000 和 d_model 的缩放因子。这是训练稳定性的关键，很多复现失败源于此。其次，确保标签平滑 ε_ls=0.1 和残差 dropout P_drop=0.1 的设置，它们对最终 BLEU 的影响在 1 个点以上。
  • 最容易踩坑的地方：注意力掩码的实现。解码器自注意力中的 -∞ 掩码必须正确应用，否则会导致信息泄漏，破坏自回归性质。此外，位置编码的添加位置是在嵌入层之后、第一个子层之前，且嵌入权重需乘以 √d_model，这个细节容易被忽略。
  • 下游团队选型指导：对于序列长度在数百到数千 token 的 NLP 任务，Transformer 是首选。但若涉及超长序列（如基因组、长文档），需警惕 O(n²) 复杂度，考虑稀疏注意力或 Longformer 等变体。对于推理延迟敏感的场景，自回归解码的串行特性是瓶颈，可考虑非自回归或蒸馏方案。
  • 架构调整的启示：消融实验表明，增加 d_model 和 d_ff 比单纯增加层数 N 更有效（d_model=1024 时 BLEU 26.0，N=8 时仅 25.5）。在资源有限时，优先扩大模型宽度而非深度。注意力头数 h=16 是甜点，过多或过少都会损害性能。
