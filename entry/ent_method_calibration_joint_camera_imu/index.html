摘要

在人形机器人中，相机提供密集纹理与语义信息，LiDAR 提供精确三维几何。要实现 RGB 点云着色、深度融合、目标 3D 定位等功能，必须精确标定相机与 LiDAR 之间的外参（旋转 $\mathbf{R}_{CL}$ 和平移 $\mathbf{t}_{CL}$）。

概述

联合标定（Joint-Camera-IMU Calibration）是人形机器人多传感器融合中的关键前置方法，用于精确估计相机、LiDAR 与 IMU 之间的空间变换关系（外参）。在人形机器人中，相机提供密集纹理与语义信息，LiDAR 提供精确三维几何，IMU 提供高频运动状态，三者协同才能实现 RGB 点云着色、深度融合、目标 3D 定位等功能。它真正改变的不是单个传感器的标定精度，而是让异构传感器从"各自为政"走向"统一时空基准"的融合范式。

核心内容

是什么：准确定义

联合标定（Joint-Camera-IMU Calibration）是指在同一参考框架下，估计相机、LiDAR 与 IMU 三者之间刚体变换关系的过程。具体而言，需要求解相机与 LiDAR 之间的外参（旋转矩阵 \(\mathbf{R}_{CL}\) 和平移向量 \(\mathbf{t}_{CL}\)）、相机与 IMU 之间的外参（\(\mathbf{R}_{CI}, \mathbf{t}_{CI}\)），以及 LiDAR 与 IMU 之间的外参（\(\mathbf{R}_{LI}, \mathbf{t}_{LI}\)）。这些外参构成一个闭环约束：\(\mathbf{R}_{CL} = \mathbf{R}_{CI} \mathbf{R}_{IL}\)，其中 \(\mathbf{R}_{IL}\) 表示 IMU 到 LiDAR 的旋转。联合标定的核心思想是利用多传感器同步采集的数据，通过特征对应与非线性优化，同时求解所有外参，而非逐个独立标定。

关键术语： - 外参（extrinsic parameters）：两个传感器坐标系之间的旋转和平移。 - 重投影误差（reprojection error）：LiDAR 点投影到图像后与对应图像特征之间的距离。 - 点云配准（point cloud registration）：把多组点云对齐到同一坐标系的算法，如 ICP。 - 标定靶（calibration target）：带有已知几何特征（棋盘格、圆孔、镂空图案）的板，用于提取对应特征。 - 手眼标定（hand-eye calibration）：估计相机与机械臂末端之间变换关系的经典方法，联合标定是其多传感器推广。

为什么存在：痛点与历史定位

在多传感器融合系统出现之前，单一传感器（如仅用相机或仅用 LiDAR）的标定问题相对独立。但随着人形机器人需要同时依赖视觉、激光与惯性信息完成导航、避障与操作任务，传感器之间的空间对齐成为瓶颈。若外参不准，RGB 点云着色会出现颜色错位，深度融合会产生重影，目标 3D 定位会偏移数十厘米——这在人形机器人的精密操作场景中是致命的。

历史上，相机-LiDAR 标定经历了从基于标定靶到无目标自动标定的演进。早期方法依赖棋盘格或圆孔板，通过提取 3D-2D 对应点求解外参；后来发展出利用场景中自然特征（如边缘、平面）的自动标定方法。IMU 的加入进一步复杂化了问题：IMU 提供的是高频角速度与加速度，需要与视觉、激光的低频数据在时间与空间上同时对齐。联合标定正是为解决这种"多传感器、多模态、多频率"的对齐问题而生。

原理拆解

① 坐标变换链：从 LiDAR 到像素

设空间点在世界/标定靶坐标系下为 \(\mathbf{P}_W\)，在相机坐标系下为 \(\mathbf{P}_C\)，在 LiDAR 坐标系下为 \(\mathbf{P}_L\)。相机内参矩阵为 \(\mathbf{K}\)，相机-LiDAR 外参为 \((\mathbf{R}_{CL}, \mathbf{t}_{CL})\)，则有：

\[ \mathbf{P}_C = \mathbf{R}_{CL} \mathbf{P}_L + \mathbf{t}_{CL} \]
\[ \mathbf{p} = \mathbf{K} \mathbf{P}_C / Z_C \]

其中 \(\mathbf{p} = [u, v, 1]^T\) 为图像像素坐标，\(Z_C\) 为相机坐标系下的深度。第一条公式建立了 LiDAR 到相机的刚体变换，第二条公式完成相机坐标系到像素坐标系的投影。联合标定的本质，就是通过最小化重投影误差来求解 \((\mathbf{R}_{CL}, \mathbf{t}_{CL})\)。

② 标定靶方法：3D-2D 对应的建立

最常用的标定靶是棋盘格板或带圆孔的铝板。步骤如下：

  1. 相机角点检测：在图像中检测棋盘格角点，得到像素坐标 \(\mathbf{p}_{ij}\)。
  2. LiDAR 特征提取：从 LiDAR 点云中提取标定靶平面或圆孔边缘，拟合得到 3D 坐标 \(\mathbf{P}_{L,ij}\)。
  3. 建立对应：将同一标定靶上的 3D 点与 2D 像素点配对，形成 3D-2D 对应集合。
  4. 求解外参：使用 PnP（Perspective-n-Point）算法获得初值，再用 ICP（Iterative Closest Point）或非线性优化（如 Levenberg-Marquardt）精化。

③ IMU 的引入：时间与空间的双重对齐

IMU 提供高频（通常 100–1000 Hz）的角速度与加速度，而相机与 LiDAR 通常工作在 10–30 Hz。联合标定需要解决两个问题：时间同步（将 IMU 数据插值到相机/LiDAR 采集时刻）与空间对齐（估计 IMU 与其他传感器的外参）。空间对齐通常利用运动激励：在标定过程中，操作者手持传感器平台做旋转与平移运动，IMU 积分得到的姿态变化与视觉/LiDAR 估计的姿态变化应一致，通过最小化两者差异求解外参。

横向对比

方法类型 代表方法 优点 缺点
基于标定靶 棋盘格 + PnP + ICP 精度高、鲁棒性强 需要人工布置靶标，操作繁琐
无目标自动标定 边缘对齐、平面拟合 无需靶标，可在线标定 依赖场景特征，精度略低

谁在用·应用案例

联合标定是人形机器人感知系统的标准前置流程，广泛应用于以下场景：

  1. RGB 点云着色：将 LiDAR 点云投影到相机图像上，为每个 3D 点赋予 RGB 颜色。外参不准会导致颜色错位，影响后续语义分割与目标识别。
  2. 深度融合：将相机深度图与 LiDAR 点云融合，生成高密度、高精度的深度图，用于避障与导航。
  3. 目标 3D 定位：利用相机检测目标（如人、物体），结合 LiDAR 测距，实现目标的精确 3D 定位与跟踪。
  4. SLAM 与建图：视觉-激光-惯性融合 SLAM（如 VINS-Fusion、LIO-SAM）依赖精确的外参初始化，联合标定是系统启动的第一步。
  5. 人形机器人操作：在抓取与操作任务中，需要将视觉识别的目标位置转换到机械臂坐标系，外参精度直接影响操作成功率。

局限与边界

  1. 标定靶覆盖范围有限：标定靶只能覆盖传感器视场的一部分，若传感器安装位置差异大（如相机朝前、LiDAR 朝上），可能需要多次摆放靶标。
  2. 时间同步误差：联合标定假设传感器数据已时间同步，若同步误差较大（如 > 10 ms），标定结果会显著退化。工程上需使用硬件同步或高精度软件同步。
  3. 运动激励不足：基于运动的方法需要充分的旋转与平移激励，若运动幅度过小或退化（如纯平移），外参的某些分量不可观测。
  4. 环境敏感性：无目标方法依赖场景中的边缘、平面等特征，在空旷或重复纹理环境中可能失效。
  5. 标定结果漂移：长期使用后，机械振动、热胀冷缩可能导致外参漂移，需要定期重新标定。

常见误区

  1. "标定一次就一劳永逸"——错。人形机器人在运行中会经历振动、温度变化，外参可能漂移。工程上建议每次部署或定期（如每月）重新标定。
  2. "重投影误差越小越好"——不完全对。重投影误差过小可能意味着过拟合（如标定靶摆放次数过多），反而降低泛化能力。工程判断：误差在 0.5–1 像素之间通常已足够。
  3. "联合标定就是手眼标定"——错。手眼标定只解决相机与机械臂末端的关系，联合标定同时处理相机、LiDAR、IMU 三者，且涉及时间同步问题，复杂度更高。
  4. "IMU 外参可以忽略"——错。IMU 外参不准会直接影响 VIO（视觉惯性里程计）与 LIO（激光惯性里程计）的精度，导致定位漂移。

왜 존재하는가:痛点과 역사적 위치

다중 센서 융합 시스템이 등장하기 전에는 단일 센서(예: 카메라만 또는 LiDAR만)의 캘리브레이션 문제가 상대적으로 독립적이었습니다. 그러나 휴머노이드 로봇이 내비게이션, 장애물 회피, 조작 작업을 위해 시각, 레이저, 관성 정보를 동시에 의존해야 하면서 센서 간 공간 정렬이 병목이 되었습니다. 외부 파라미터가 부정확하면 RGB 포인트 클라우드 착색에 색상 어긋남이 발생하고, 심층 융합에 고스트 현상이 생기며, 목표 3D 위치 파악이 수십 센티미터 어긋날 수 있습니다—이는 휴머노이드 로봇의 정밀 조작 시나리오에서 치명적입니다.

역사적으로 카메라-LiDAR 캘리브레이션은 캘리브레이션 타깃 기반에서 무타깃 자동 캘리브레이션으로 진화해 왔습니다. 초기 방법은 체커보드나 원형 구멍 판에 의존하여 3D-2D 대응점을 추출해 외부 파라미터를 풀었고, 이후 장면의 자연 특징(예: 모서리, 평면)을 활용하는 자동 캘리브레이션 방법이 개발되었습니다. IMU의 추가는 문제를 더욱 복잡하게 만들었습니다: IMU는 고주파 각속도와 가속도를 제공하며, 시각 및 레이저의 저주파 데이터와 시간 및 공간에서 동시에 정렬되어야 합니다. 결합 캘리브레이션은 바로 이러한 "다중 센서, 다중 모달, 다중 주파수" 정렬 문제를 해결하기 위해 탄생했습니다.
