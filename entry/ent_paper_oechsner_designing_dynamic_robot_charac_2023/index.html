设计动态机器人角色以改善人机通信

Designing Dynamic Robot Characters to Improve Robot-Human Communications

摘要

这是一篇CHI 2023研讨会立场论文，基于二十年人机通信研究，提出社交辅助机器人应具备动态人格：从初始透明外向的“相识”阶段过渡到更温和的“习惯”阶段，以维持长期信任与接受。

来源与参考

  • Designing Dynamic Robot Characters to Improve Robot-Human Communications

概述

社交辅助机器人（SAR）在高度敏感环境中运行，对安全性和用户通信提出高要求。论文指出，尽管不同通信模态已被广泛研究，但缺乏长期研究来考察用户通信需求随时间的变化。基于二十年人机通信研究，作者主张设计动态机器人人格，以释放SAR的全部潜力。

核心内容

核心问题

  • SAR在敏感环境中运行，其行为推理必须始终透明，以赢得用户信任与接受。
  • 现有研究多聚焦于不同通信模态（如语音、手势、表情），但缺乏长期研究来揭示用户通信需求随时间的变化。

动态人格设计

  • 基于二十年人机通信研究，论文提出动态人格概念：初始阶段采用透明、外向的“相识”人格，以建立初步信任；随后过渡到更温和、习惯化的人格，以维持长期互动。
  • 这种动态调整旨在平衡短期接受与长期信任，避免用户因人格一成不变而产生厌倦或不适。

研究意义

  • 动态人格设计有望释放SAR在长期辅助场景（如老年护理、康复训练）中的全部潜力。
  • 论文强调，未来研究需系统评估动态人格对用户信任、接受度及互动质量的影响。
