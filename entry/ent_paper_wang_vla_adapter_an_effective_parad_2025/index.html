VLA-Adapter

VLA-Adapter: An Effective Paradigm for Tiny-Scale Vision-Language-Action Model

摘要

VLA-Adapter 是北京邮电大学、西湖大学、浙江大学等机构于2025年提出的轻量级视觉-语言-动作模型范式，旨在降低VLA模型对大规模预训练和计算资源的依赖。其核心贡献在于通过Bridge Attention机制和轻量级Policy模块，仅使用0.5B参数骨干网络且无需机器人数据预训练，即可在模拟和真实机器人基准上达到SOTA性能，并在单张消费级GPU上8小时内完成训练。

来源与参考

  • VLA-Adapter: An Effective Paradigm for Tiny-Scale Vision-Language-Action Model (arXiv)

概述

WorldVLA 是一个自回归动作世界模型，在单一框架内统一了视觉-语言-动作（VLA）模型与世界模型，同时支持动作生成与未来视觉状态预测。该模型从 Chameleon 初始化，通过共享词汇表整合图像、文本与动作 tokenizer，并引入动作注意力掩码策略缓解自回归动作块生成中的误差累积。在 LIBERO 基准上，WorldVLA 相比同骨干动作模型抓取成功率提升 4%，相比普通世界模型 FVD 降低 10%。

它改变了什么

现有 VLA 模型将动作仅视为输出，缺乏对动作作为输入的深层理解，这限制了模型对物理环境的建模能力。世界模型虽能预测未来状态，却无法直接生成动作，形成功能缺口。作者的核心洞察在于：动作不应只是被生成的序列，更应作为理解环境动态的输入信号。这一转变将操作任务从"感知-规划"的分离范式，推向"理解-生成"的统一范式。

真正改变的是对自回归动作生成性能下降的归因。传统观点多归咎于模型容量或数据不足，而作者明确指出：预训练多模态语言模型主要接触图像与文本，动作泛化能力先天不足，且早期动作预测误差会沿序列传播。这一诊断将问题从"如何生成更多动作"转向"如何让模型更好地理解动作"，为架构设计提供了新方向。

方法拆解

架构总览

从 Chameleon 初始化，采用单一 LLM 架构统一处理图像、文本与动作三种模态。所有模态 token 共享同一词汇表，实现跨模态的理解与生成。

Tokenizer 设计

  • 图像：VQ-GAN，压缩比 16，码本大小 8192。256×256 图像生成 256 个 token，512×512 图像生成 1024 个 token。额外添加针对人脸和显著物体的感知损失。
  • 动作：每维离散化为 256 个 bin，bin 宽度由训练数据范围决定。动作表示为 7 个 token：3 个相对位置、3 个相对角度、1 个绝对夹爪状态。
  • 文本：BPE tokenizer，词汇表大小 65536，其中包含 8192 个图像 token 和 256 个动作 token。

训练数据混合

同时使用动作模型数据与世界模型数据训练，理由有三： 1. 世界模型通过学习"当前状态+动作→未来观测"理解环境物理，辅助操作任务。 2. 世界模型能模拟并评估候选动作的潜在结果，避免不利状态。 3. 世界模型需精确解读动作输入，反向促进动作模型生成更有效的动作。

动作模型数据格式

文本输入格式为 "What action should the robot take to + task instruction + ?"。token 序列为 [BOS]、文本、M 个图像（[BOI]...[EOI] 包裹）、[EOS]、K 个动作（[BOA]...[EOA] 包裹）、[EOS]。仅计算动作 token 的损失（L_action）。

动作注意力掩码

针对动作块生成，提出选择性掩蔽策略：生成当前动作时，掩蔽部分先前动作 token，以缓解误差累积。该策略在传统自回归方法成功率下降 10% 至 50% 的场景下，将成功率提升 4% 至 23%。

关键创新

  1. 动作作为输入的统一框架：首次在自回归模型中让动作同时作为输入与输出，使模型能通过预测未来状态来理解动作的物理后果。这不同于以往将动作仅视为输出序列的做法，为操作任务提供了环境动态建模能力。

  2. 动作注意力掩码策略：针对动作块生成误差累积问题，提出选择性掩蔽先前动作 token 的机制。该策略不改变模型架构，仅调整注意力模式，即可在性能下降 10% 至 50% 的场景下实现 4% 至 23% 的提升，工程成本极低。

  3. 三模态共享词汇表设计：通过统一词汇表（65536 个 token，含 8192 图像与 256 动作 token）实现跨模态理解与生成，避免了多模态对齐的复杂设计，使模型能在一个 LLM 内处理异构输入。

实验与结果

在 LIBERO 基准上评估，主要结果如下：

同骨干动作模型 抓取成功率 提升 4%
普通世界模型 FVD 降低 10%
传统自回归（动作块） 抓取成功率 下降 10% 至 50%
注意力掩码策略 抓取成功率 提升 4% 至 23%

表 2 为 LIBERO 基准评估结果（图片形式，数字未提取）。实验表明：统一动作理解与生成能同时提升操作成功率与视频预测质量；注意力掩码策略有效缓解了误差累积，且提升幅度与任务复杂度相关。

边界与局限

作者明确指出预训练多模态语言模型主要暴露于图像和文本而非动作，导致动作泛化能力有限，这是自回归动作生成性能下降的主要原因。论文未明确其他局限性，包括：未讨论模型在未见任务或新环境下的泛化能力；未提供训练配置、推理频率或硬件细节；未分析注意力掩码策略在不同动作块长度下的表现差异；未与更大规模 VLA 模型（如 RT-2、OpenVLA）进行直接对比。

工程启示

复现时首先核对动作 tokenizer 的 bin 宽度计算方式，这直接影响离散化精度与训练稳定性。其次，注意力掩码策略的实现需注意掩蔽比例与动作块长度的关系，建议从较小掩蔽比例开始调参。混合训练数据时，动作模型数据与世界模型数据的比例是关键超参数，论文未明确，需自行实验确定。初始化自 Chameleon 意味着需预先获取其权重并适配新 tokenizer 的嵌入层。代码已开源（github.com/alibaba-damo-academy/WorldVLA），建议先跑通 LIBERO 单任务再扩展多任务。最易踩坑处在于三模态 token 的序列拼接格式，需严格遵循 [BOS]、[BOI]、[EOI]、[BOA]、[EOA]、[EOS] 的包裹顺序。
