A Recurrent Vision-and-Language BERT for Navigation

A Recurrent Vision-and-Language BERT for Navigation

领域
AI 模型与算法
层级
智能层
审校
草稿

摘要

本文提出一种名为Recurrent Vision-and-Language BERT的循环BERT模型，用于视觉与语言导航任务。该模型通过引入时间感知的循环函数，使BERT架构能处理部分可观测马尔可夫决策过程，在R2R和REVERIE基准上取得最先进结果，并支持预训练与多任务联合求解。

来源与参考

  • arXiv:2011.13922 A Recurrent Vision-and-Language BERT for Navigation
  • GitHub仓库 Robotics_Notebooks

概述

本文提出 VLN↻BERT，一种将循环机制直接嵌入 Vision-and-Language BERT 架构的导航模型，使预训练 V&L BERT 本身成为导航策略网络，无需外部循环模块（如 LSTM）或下游决策网络。作者通过在 BERT 内部引入自回归状态 token 和跨模态注意力匹配，在 R2R 和 REVERIE 两个基准上取得当时 SoTA 结果，并系统验证了仅在初始化时对语言做自注意力的计算效率优势。

它改变了什么

这项工作的核心改变在于：它把 V&L BERT 从"语言编码器"或"指令-路径匹配器"的角色，直接提升为"导航决策器"本身。此前 PREVALENT 等模型虽然利用了预训练 V&L BERT，但只是将其作为特征提取器，真正的决策仍由下游的 EnvDrop 等网络完成。VLN↻BERT 证明了 BERT 的 Transformer 架构可以通过内部循环状态天然适配 POMDP 问题，这改变了"BERT 不适合序列决策"的普遍认知。

另一个关键改变是对语言自注意力的处理策略。作者通过实验证明，在每一步对语言重新做自注意力（Re-Attn）会导致严重的性能退化（SR 从 58.71% 降至 37.76%），因为每步输出的语言特征会过度聚焦当前视点相关的线索，抑制了指令其他部分对未来决策的价值。这一发现挑战了"更多注意力=更好性能"的直觉，为 V&L 模型在长序列决策任务中的计算分配提供了新的设计原则。

方法拆解

核心架构：循环状态 token

  • 初始化（t=0）：将 [CLS]、指令 token、[SEP] 输入模型，取 [CLS] 输出作为初始状态 s₀
  • 导航步（t>0）：语言 token 仅作为 Transformer 的 keys/values（类似 LXMERT 跨模态编码器），不参与查询计算，大幅节省计算
  • 状态 sₜ 作为引导 token 与视觉 token 拼接输入，通过跨模态自注意力更新内容，并以自回归方式成为下一步输入

状态细化（Eq. 9-12）

  • 在最后一层（l=12），计算状态与文本/视觉 token 的注意力分数
  • 跨 K=12 个注意力头平均并 Softmax 得到权重
  • 加权求和原始特征，通过元素级乘积进行跨模态匹配
  • REVERIE 中仅使用视觉特征（因指令是高层级的，逐步匹配价值低）

决策制定

  • 动作概率直接取最后一层所有注意力头对视觉 token 的平均注意力权重：pₜᵃ = Ãₗ^{s,v}
  • 停止通过向可导航方向列表添加零向量 vₜ^stop 实现，模型预测最大注意力分数时停止
  • REVERIE 中，当对象 token 的注意力分数超过所有场景 token 时停止并选择分数最大的对象

训练目标

  • 混合 A2C 强化学习和模仿学习：ℒ = -Σₜ aₜˢ log(pₜᵃ) Aₜ - λ Σₜ aₜ* log(pₜᵃ)
  • 奖励塑形：进度奖励（接近 +1.0/远离 -1.0）+ nDTW 路径保真奖励 + 负停止奖励（首次接近目标后又离开时触发）
  • 从 OSCAR 或 PREVALENT 初始化，适应 PREVALENT 时移除跨模态编码器中的语言分支

关键创新

  1. 循环机制内嵌于 BERT 架构：无需显式记忆缓冲区或外部 LSTM，仅通过状态 token 的自回归传递实现历史依赖建模。这是首次让 V&L BERT 本身具备处理 POMDP 的能力，而非依赖外部循环模块。

  2. 语言自注意力的"初始化一次"策略：通过实验证明每步重新自注意力会导致性能显著退化（Re-Attn 的 SR 比 Ours 低 20.95%），而仅在初始化时编码语言、后续仅作为 keys/values 参与计算，既保持性能又大幅降低内存（batch size 16 时仅 9.2GB vs 其他方法 batch size 6 时 11.0GB）。

  3. 注意力权重直接作为动作概率：将最后一层 Transformer 对视觉 token 的平均注意力权重直接映射为动作分布，消除了传统 Actor 网络的需求。这一设计使 BERT 的注意力机制同时承担特征融合和策略输出的双重角色，简化了架构并提升了可解释性。

消融关键发现

  • 仅用预训练 BERT 编码语言（Model #1）反而比 Baseline 更差（Unseen SR 44.15% vs 49.81%），必须微调才能获益
  • 加入视觉 token（Model #3）严重退化（SR 30.74%），说明简单拼接不够，需要状态和决策机制
  • 完整模型比 Baseline 在 Unseen 上 SR 提升 8.90%（由表内数值 6.62→6.01 计算），SPL 提升 9.96%（由表内数值 8.39→9.23 计算）

边界与局限

  • 论文未明确讨论局限性，但可从实验推断：模型在 REVERIE 的 RGS 指标上仍远低于人类（16.50% vs 77.84%），物体接地能力是明显短板
  • 未在连续环境（VLN-CE）或多语言导航（RxR）上验证，作者仅提及这些数据集存在但未实验
  • 未使用大规模数据集预训练，依赖 OSCAR/PREVALENT 的初始化质量；从随机初始化训练需要 600,000 次迭代约 7 天，收敛速度依赖预训练
  • 梯度累积实验显示，若在每步做语言自注意力（Emb-Attn），在更大有效 batch size 下 Unseen SR 可达 61.00%，超过 Ours 的 58.71%，说明计算资源充足时"初始化一次"策略未必最优
  • 训练时间较长：init. OSCAR 需 7 天完成 600K 迭代，即使 init. PREVALENT 也需 4.5 天

工程启示

复现时优先核对三点：语言自注意力的时机（仅在 t=0 编码，后续作为 keys/values）、状态 token 的自回归传递（sₜ 作为下一步引导 token）、注意力权重到动作概率的映射（最后一层平均注意力，无需额外 Actor 网络）。最容易踩坑的是 Re-Attn 陷阱——若在每步对语言重新自注意力，SR 会暴跌约 20%，这不是调参能救回来的。

工程上注意：单张 2080Ti 可跑 batch size 16（9.2GB 内存），但训练仍需数天；建议从 PREVALENT 初始化（1 天达到最佳），而非 OSCAR（3.5 天）。REVERIE 中物体特征需拼接位置投影（Wᵖ ∈ ℝ⁵ˣ¹²⁸）和方向编码，维度为 2048+128+128=2304。奖励塑形（nDTW + 负停止奖励）仅带来约 1% 的 SPL 提升，若时间紧张可先不加，优先保证循环 BERT 结构正确。
