ConRFT

ConRFT: A Reinforced Fine-tuning Method for VLA Models via Consistency Policy

领域

层级

摘要

ConRFT 是由中国科学院自动化研究所 SKL-MAIS 与国科大人工智能学院于 2025 年提出的一种基于一致性策略的强化微调方法，用于提升视觉-语言-动作（VLA）模型在机器人操作中的性能。其核心贡献在于通过离线与在线两阶段训练，在仅需少量演示数据的情况下，将平均成功率提升至 96.3%，并缩短了 1.9 倍的任务执行长度。

概述

ConRFT 提出一种基于一致性策略的强化微调方法，用于视觉语言动作（VLA）模型，旨在提升真实世界机器人操作的样本效率与策略稳定性。该方法将一致性损失引入策略微调，使模型在有限示范数据下更快收敛并保持动作一致性。核心贡献在于将一致性理论从扩散策略迁移至 VLA 微调场景，并验证其在多任务操作中的有效性。

它改变了什么

现有 VLA 模型微调多依赖行为克隆（BC），其本质是最大似然估计，对示范数据中的多模态分布敏感，且在小样本下易产生动作抖动与不连续。ConRFT 改变了这一范式：它不再仅拟合示范动作，而是通过一致性策略约束模型在相邻时间步输出动作的平滑性，从而在强化学习框架下同时优化任务奖励与动作一致性。这解决了 BC 在真实机器人部署中常见的“示范过拟合”与“分布外漂移”问题，使微调后的策略更具鲁棒性。

方法拆解

一致性策略目标

  • 定义策略 π_θ(a_t | o_t, g_t)，其中 o_t 为观测（本体感觉与图像），g_t 为目标图像。
  • 引入一致性损失 L_cons = E[||a_t - a_{t+1}||^2]，在强化学习目标 J = E[Σ γ^t r_t] 上叠加，形成联合优化：L_total = L_RL + λ L_cons。
  • 使用 PPO 作为基础 RL 算法，但将价值函数与策略网络共享主干，以降低参数量。

微调流程

  1. 预训练：在多样化机器人数据集上训练基础 VLA 模型（基于 Gato 架构，VQ-GAN 编码图像为 8×8 token 网格）。
  2. 任务示范收集：每任务通过遥操作收集 100–1000 个示范。
  3. 微调：在示范数据上先做 BC 初始化（约 10 个 epoch），再切换至 RL 微调，λ 从 0.1 线性增至 1.0。
  4. 自改进：微调后模型生成新轨迹，筛选成功轨迹加入训练集，迭代优化。

关键设计决策

  • 一致性损失作用于动作空间而非参数空间，理由：动作空间维度低，计算开销小，且直接约束行为平滑性。
  • 目标图像使用事后目标（hindsight goal）与语义等价目标混合，提升数据利用率。
  • 未来图像预测（k=5 步）作为辅助损失，增强模型对动态环境的建模能力。

关键创新

  1. 一致性策略微调：首次将一致性理论引入 VLA 微调，区别于传统 BC 或纯 RL 方法，在动作层面施加显式平滑约束，显著减少策略抖动。
  2. RL 与 BC 的混合初始化：先 BC 后 RL 的流程，既利用示范快速收敛，又通过 RL 探索超越示范分布，避免 BC 的保守性。
  3. 自改进循环：微调模型生成数据并筛选成功轨迹，形成闭环，降低对人工示范的依赖，这是向自主机器人学习迈出的关键一步。

边界与局限

论文未明确列出自身局限。但可推断：一致性损失可能不适用于高动态任务（如需要快速切换动作的场景），且 RL 微调阶段对奖励函数设计敏感。此外，自改进循环依赖成功轨迹筛选，若任务成功率低，数据生成效率可能受限。论文未明确。

工程启示

复现 ConRFT 时，先核对一致性损失权重 λ 的调度策略（从 0.1 线性增至 1.0），这是平衡探索与稳定的关键。最容易踩坑的是 RL 微调阶段的奖励稀疏问题——若任务奖励过于稀疏，PPO 可能不收敛，建议先使用密集奖励或课程学习。另外，VQ-GAN 编码器需冻结，且图像 token 化应提前完成以加速训练。对于下游团队，若任务动作空间维度高（如灵巧手），一致性损失计算开销会增大，需评估实时性。论文未明确硬件配置，但 1024 token 长度对应约 3 步历史，可据此估算显存需求。
