Sumo｜动态且可推广的全身移动操作

Sumo: Dynamic and Generalizable Whole-Body Loco-Manipulation

领域
设计工程AI 模型与算法
层级
中游智能层
审校
待审校

摘要

Sumo 把本体状态与关节序列、仿真交互数据转成可跟踪的身体目标，并通过扩散策略/流匹配、全身控制器/WBC/MPC、分层技能/专家策略训练或组合全身策略，最终输出全身轨迹/动作序列、低层控制器目标。关键点是把动作生成看成条件生成问题，用扩散或流匹配在多模态动作分布里采样可执行轨迹。

来源与参考

  • Sumo project page

概述

Sumo 提出一种 sim-to-real 分层架构，将预训练的全身控制（WBC）策略与测试时基于采样的 MPC 规划器相结合，使腿式机器人在无需额外训练的情况下动态操纵大型重物。该方法在 Spot 四足机器人上完成了扶正超额定负载的轮胎、拖拽比自身更大的屏障等真实世界任务，并在仿真中泛化至 G1 人形机器人的开门、推桌等操作。

它改变了什么

移动操纵（loco-manipulation）长期受困于一个矛盾：端到端强化学习策略难以泛化到训练分布之外的物体，而基于模型的 MPC 又受限于精确动力学建模与接触规划的复杂性。Sumo 真正改变的是将「泛化」从训练阶段剥离，转移到测试时的规划器引导中——低层策略只负责稳定的全身运动跟踪，高层采样 MPC 则根据当前任务动态调整躯干、手臂、腿部的期望指令。这使得同一套预训练权重可以应对不同重量、尺寸、摩擦特性的物体，而无需重新训练或微调。

这一设计隐含的范式转变在于：它不再追求一个「万能策略」，而是承认策略的局限性，并用一个轻量级、可在线调整的规划器来补偿。对于实际部署而言，这意味着机器人厂商可以预先训练一个通用的运动基元库，再针对具体任务编写成本函数——工程成本从训练转向了规划器设计，这更符合现有机器人团队的技能结构。

方法拆解

分层架构

  • 低层 WBC 策略：输入当前状态与期望的躯干、手臂、腿部指令，输出关节级指令，运行频率 50 Hz。该策略为预训练模型，不随任务变化。
  • 高层采样 MPC：输入当前状态估计，以 20 Hz 频率求解低层策略的期望指令，最小化任务特定成本函数。

测试时引导机制

  • 标准动力学 rollout 以关节级控制量 \(u\) 为动作；Sumo 的网络策略增强 rollout 以低层运动策略的输入 \(a\) 为动作，从而将学习到的全身协调先验嵌入规划器的预测模型。
  • 移动物体任务：通过替换规划器中的物体模型实现泛化，使用相同的 Move 成本函数与超参数。
  • 扶正物体任务：通过改变规划器成本函数（如从 Move 切换至 Upright）实现泛化，无需额外训练。

关键设计决策

  • 采样 MPC 而非梯度优化：避免对成本函数求导，便于测试时灵活替换成本项。
  • 低层策略固定不更新：保证运动稳定性的同时，将任务差异全部交由高层规划器吸收。
  • 频率分层（50 Hz 控制 / 20 Hz 规划）：规划器无需高频运行，降低计算负担，便于在真实机器人上实时部署。

关键创新

  1. 测试时规划器引导（test-time steering）：将泛化能力从训练阶段转移到测试时，通过替换物体模型或调整成本函数即可适配新任务。这是与端到端 RL 和分层 RL 的本质区别——后两者在训练分布外物体上性能急剧下降。
  2. 网络策略增强的动力学 rollout：将预训练 WBC 策略作为规划器内部的预测模型，而非仅作为底层执行器。这使得采样 MPC 能够利用学习到的全身协调先验，同时保持基于采样的灵活性与可解释性。
  3. 跨平台泛化：同一方法在 Spot 四足机器人（真实世界）与 G1 人形机器人（仿真）上均有效，表明该架构不依赖特定机器人形态，具备通用性。

任务 物体重量 结果

仿真（G1 人形机器人）

  • 任务：Table Push、Chair Push、Door Open、Box Push，论文未明确具体成功率数值。

对比分析

  • Sumo vs 端到端 RL vs MPC（移动物体到目标）：Sumo 在所有物体上均取得高成功率；端到端 RL 在 box、chair、cone 上有竞争力，但在 tire 和 tire rack 上性能急剧下降；端到端 MPC 在所有任务上表现挣扎。
  • Sumo vs E2E RL vs 分层 RL（HRL）（推动五种不同物体）：仅用 box pushing 训练的 E2E RL 和 HRL 在其他物体上失败，而 Sumo 通过测试时替换物体模型成功泛化。
  • 扶正任务：Sumo 通过改变规划器成本泛化，相同 E2E RL 和 HRL 策略在无额外训练时失败。

工程启示

复现 Sumo 时，优先核对以下三点：其一，低层 WBC 策略的预训练质量——规划器的 rollout 精度直接依赖策略对全身指令的跟踪能力，若策略本身不稳定，采样 MPC 的预测将失真；其二，采样 MPC 的候选动作分布设计——论文未明确采样策略的具体形式（如高斯扰动、交叉熵方法等），这直接影响搜索效率与成功率；其三，成本函数的权重标定——Move 与 Upright 两类成本函数的相对权重、接触惩罚项等细节论文未明确，需自行调参。

最容易踩坑的地方在于「测试时替换物体模型」：规划器中的物体动力学模型（质量、惯性、摩擦系数）必须与真实物体匹配，否则采样出的动作可能违反物理约束。建议在部署前对目标物体进行快速质量/摩擦辨识，而非直接沿用默认参数。另外，低层策略的 50 Hz 控制频率与高层 20 Hz 规划频率之间的同步延迟需仔细处理，避免规划指令与控制执行之间的相位错位导致抖动。
