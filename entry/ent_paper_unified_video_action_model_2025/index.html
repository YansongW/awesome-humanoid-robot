摘要

Unified Video Action Model (UVA) 是2025年面向人形机器人操作任务的工作，由研究团队提出。其核心贡献在于通过联合视频-动作潜在表示与解耦解码架构，同时实现高精度动作预测与高效推理，并支持策略学习、正/逆动力学建模及视频生成等多种任务。

来源与参考

  • Unified Video Action Model (arXiv)
  • Unified Video Action Model project page

概述

UVA 是一个统一视频-动作模型，由 Toyota Research Institute 等机构的研究者提出，旨在联合建模视频和动作但分别解码。核心贡献在于通过统一潜在表示和掩码训练，在推理时完全跳过视频生成，实现与动作仅方法相当的推理速度，同时保留视频生成带来的观测监督优势。

它改变了什么

视频生成方法（如 UniPi）和动作仅方法（如 Diffusion Policy）之间存在一个根本性的权衡：前者通过生成高分辨率视频来获得观测监督，但推理速度慢且生成错误会传播到动作预测；后者速度快但缺乏对场景动态的建模，容易过拟合动作历史。UVA 真正改变的是打破了这种二选一的局面——它证明视频和动作可以在一个共享的潜在空间中联合建模，而推理时无需解码视频。

这个问题的关键在于视频生成需要高空间分辨率，动作控制需要高时间频率，两者在计算需求上天然冲突。UVA 通过将两者统一到潜在空间，让视频生成成为训练时的辅助监督信号，而非推理时的必要步骤，从而在保留视频监督好处的同时，将推理速度提升到与动作仅方法相当的水平。

方法拆解

统一潜在视频-动作表示

历史图像观测通过预训练 VAE 编码器（kl-f16）编码为潜在图，展平后经全连接层投影为 d 维潜在向量，每个图像表示为 N 个视觉 token。历史动作以更高采样频率记录，每个图像观测对应 L 个动作，动作块重复 M 次以匹配视觉 token 数量，经全连接层转换为 N 个动作 token。

掩码自编码器训练

未来观测帧经 VAE 编码和全连接层处理后，训练时随机掩码部分 token。视觉 token 与历史视觉和动作 token 通道级拼接，经 Transformer 融合产生联合视频-动作潜在表示 {Z_{t+1},…,Z_{t+h}}。为最小化帧间信息泄漏，所有视频帧一致掩码相同位置。推理时从空序列开始，自回归生成所有 token，单步生成即可获得高质量观测。

解耦视频-动作扩散

两个轻量级扩散解码器分别处理动作和视频预测。视频扩散解码器处理每个潜在 token z_i 以预测视频帧中的单个 patch，重塑后经 VAE 解码器重建完整帧。动作扩散解码器将所有潜在 token 通过卷积层聚合，再经 MLP 层产生动作潜在，作为动作扩散模型的条件生成动作块。

损失函数

  • 动作扩散损失：L_action(Z,A) = E_{ε,k}[||ε - ε_θ(A^(k)|k,Z)||²]
  • 视频扩散损失：L_video(Z,O) = E_{ε,k}[(1/N)Σ_{i=1}^{N}||ε_i - ε_φ(O^{i,(k)}|k,z_i)||²]
  • 总损失：L = L_action + L_video，在时间视界 h 上求和

掩码训练

通过变化输入和输出组合，支持五种不同任务：机器人策略、视频模型、前向/逆向动力学模型、组合策略和规划器。未使用的组件被掩码并替换为学习的掩码 token，损失根据任务选择性应用。

关键创新

  1. 统一潜在表示的设计：UVA 不是简单地将视频和动作拼接，而是在潜在空间中让两者共享 Transformer 的联合建模。这使得模型能捕捉视觉与动作域之间的底层交互，同时避免高分辨率视频生成的计算开销。这是首个在潜在层面统一视频和动作建模的框架。

  2. 解耦解码的推理策略：训练时同时优化视频和动作扩散头，但推理时完全绕过视频生成，直接利用联合潜在表示进行动作预测。这一设计使得 UVA 在模拟任务上达到 0.23s 的推理速度，与 Diffusion Policy 相当，而 UniPi 需要 24.07s。

  3. 掩码训练的灵活性：通过统一的掩码机制，UVA 天然支持多种机器人功能（策略、前向/逆向动力学、规划器），无需为每个任务重新设计架构。这使得模型能利用不完整数据（如无动作标签的视频数据）进行训练，为未来利用大规模无动作视频数据提供了基础。

边界与局限

  • 真实世界单任务 Cup 上 UVA（0.85）不如 DP-UMI（0.95），作者归因于数据集包含大量失败恢复数据，对无历史依赖的模型更有利，而 UVA 使用较长历史窗口优先学习扩展时间模式。
  • 当背景颜色与物体颜色相同时 UVA 失败，视觉理解可通过训练额外无动作标签的视频数据增强。
  • 真实世界推理中 Attention 模块占推理时间一半，使 UVA 比 DP-UMI 稍慢，未来可用 Flash Attention 替换。
  • 框架未利用大规模无动作视频数据，这限制了泛化能力，偶尔仅能达到与 DP-UMI 相当的真实世界任务性能。
  • 前向动力学实验中，即使使用真实模拟器，成功率也仅限 75%，原因是采样轨迹次优和物体检测误差。

工程启示

  • 复现时需注意：模型基于 MAR-B 预训练模型，但为联合视频和动作建模进行了大量修改，不能直接套用原始 MAR 代码。
  • 推理速度测量条件不同：模拟任务在 NVIDIA L40 GPU 上测量，真实世界在 RTX 3080 上测量，对比时需注意硬件差异。
  • 真实世界多任务训练使用从每个数据集随机选择的 500 个 episode 合并成的 1500 个 episode 数据集，数据选择策略对结果影响显著。
  • 推理时扩散步数选择需权衡：16 步用于策略学习实验，100 步产生更平滑的动作预测和更高成功率，但速度从 95ms 增至 173ms。
  • 若需部署到边缘设备，可优先用 Flash Attention 替换标准 Attention，可减少 10ms 推理时间。
  • 视觉干扰实验中 UVA 在 GoalColor 设置下表现最好（0.64），但 BgColor 和 BgObject 下与其他方法差距缩小，说明对背景干扰的鲁棒性仍有提升空间。

动作分块变压器（ACT）是一种模仿学习方法：用变压器以条件变分自编码器（CVAE）形式一次性预测未来一段动作序列（chunk），再经时间集成平滑执行，显著降低长时程精细操作中的误差累积。
