摘要

TeamHOI 是一个由研究者提出的框架，旨在通过单一去中心化策略实现任意数量智能体间的协作人机交互。其核心贡献在于利用基于 Transformer 的策略网络与队友令牌机制，结合掩码对抗运动先验策略，在缺乏协作数据的情况下生成物理逼真的多智能体协作行为。

概述

TeamHOI 提出了一种基于 Transformer 的统一去中心化策略，用于任意规模（2-8 人）的人形智能体协作搬运任务。核心贡献在于通过 teammate tokens 的交叉注意力机制实现团队规模无关的策略泛化，并引入 Masked AMP 判别器解决有限单人体参考动作下的物体交互多样性问题。实验表明该方法在 2-8 人团队规模下成功率均超过 97%，且能零样本泛化至 16 人及未见过的桌子几何形状。

它改变了什么

多智能体物理协作（如抬桌子）长期被固定输入维度的 MLP 策略锁死——你训一个 4 人策略就只能在 4 人场景用，换 6 人就得重训。这背后的深层问题是：现有方法要么把协作简化为共享物体动力学的隐式通信（如 CooHOI），要么依赖显式但固定拓扑的通信图，两者都无法捕捉真实人类协作中"感知队友位置、动态调整发力点"的适应性。另一个被忽视的瓶颈是参考动作数据——多智能体协调动作几乎无法采集，现有框架只能退化为用单人体演示硬撑，导致学到的行为模式极其有限（比如只能前后抬，不能侧抬）。

TeamHOI 真正改变的是把"团队规模"从网络架构的硬约束变成了训练分布的一个维度。它不再为每个团队规模单独训练策略，而是让同一个策略网络通过注意力机制动态"关注"任意数量的队友，从而把多智能体协作问题重新定义为"变长序列条件下的单智能体决策"。同时，它用掩蔽判别器把"参考动作风格"和"物体交互自由度"解耦，让有限的单人体数据能支撑多样化的协作策略——这是对 AMP 框架在多智能体场景下的一次实质性重构。

方法拆解

策略网络：Teammate Tokens 交叉注意力

  • 每个智能体独立决策，共享同一套 Transformer 参数（去中心化）。
  • 观测编码：本体感知（ℝ²²³）、物体中心（ℝ³）、64 个候选接触点（ℝ⁶⁴×³）、最近手-物点（ℝ²×³）、目标位置（ℝ³）、队友线索（ℝ^(n−1)×9，含根部位置、6D 朝向、绕桌相对角度）各自通过独立三层 MLP tokenizer 编码为 64 维 token。
  • Transformer 结构：L 层交替自注意力（作用于自身 token）与交叉注意力（关注队友 tokens），更新后的嵌入经动作头输出 28 维目标关节旋转（PD 控制器目标）。

统一策略训练

  • 并行实例化 1024 个环境，每个环境配置不同团队规模（2-8），共享同一策略网络。
  • 团队规模优势归一化：因不同规模奖励尺度差异大，PPO 优势按团队规模 n 分别归一化：A_t^(n) ← (A_t^(n) − μ_n(A)) / (σ_n(A) + ε)，而非全局归一化。
  • 虚拟天花板技巧：IsaacGym 要求每个环境 actor 数相同，故实例化固定 N 个 agent，较小规模时多余 agent 置于虚拟天花板平面，不参与奖励、观测、梯度计算且 PD 禁用。

Masked AMP 判别器

  • 双判别器：D_full 评估完整参考动作（行走），D_mask 排除与物体交互的身体部位（手、前臂）。
  • 混合风格奖励：r_t^style = σ(α_t)·r_t^mask + (1−σ(α_t))·r_t^full，其中 α_t 为连续交互指示器（如手-物距离），σ 为 sigmoid。交互时用掩蔽判别器，非交互时用完整判别器。

编队奖励设计

  • 角分布奖励：r_ang = exp(−k_θ·½·[(Δφ_i^ccw − 2π/m)² + (Δφ_i^cw − 2π/m)²])，m 为团队规模，鼓励均匀角度分布。
  • 主轴覆盖奖励：将根部位置投影到物体周边采样点，凸包定义支撑多边形；每轴覆盖度 g_i = min(d̃_i⁺/ℓ_i⁺, d̃_i⁻/ℓ_i⁻)，奖励 r_cov = ½(g₁ + g₂)。关键设计：每个投影点替换为周边 ±2 索引的两个点，避免两智能体退化为线段。
  • 最终编队奖励 r_form = 0.25·r_ang + 0.75·r_cov（覆盖奖励权重更高，角分布提供早期分散信号使覆盖奖励非零）。

任务奖励分解

r_task = 0.2·r_walk^pos + 0.4·r_walk^vel + 0.2·√(r_walk^face·r_ang) + 0.6·r_form + 0.7·(r_hand·r_cov) + 0.7·r_contact + 0.7·(r_lift·r_cov) + 1.0·r_transport + 0.4·r_align + 1.0·r_put

三阶段训练

  1. 阶段 1（约 1.5 天）：1-4 agent，禁用运输/对齐/放下奖励，D_full 仅用前进/侧向行走参考，D_mask 额外接收拾取动作，目标位置 token 掩码，episode 400 timesteps。
  2. 阶段 1+2（约 5 天）：2-4 agent，启用全部奖励，取消目标掩码，加入后退行走参考，episode 600 timesteps。
  3. 微调（约 3 天）：2-8 agent。

关键创新

  1. 团队规模无关的策略架构：用交叉注意力处理变长队友序列，替代固定输入 MLP。这是首个能零样本泛化到训练未见团队规模（如 16 人）的物理人形协作策略，且无需微调。其意义在于把多智能体 RL 从"每规模训一个模型"的范式解放出来。

  2. Masked AMP 判别器：通过掩蔽与物体交互的身体部位，将"风格模仿"与"任务驱动交互"解耦。这使得从单人体参考动作（AMASS 中的行走+拾取）就能学到多样化的协作抬举策略（如侧握、边缘抬升），而非被参考动作锁死行为模式。与 PMP 直接学习部位级先验不同，TeamHOI 用任务奖励在掩蔽区域强制多样性，更轻量且可扩展。

  3. 主轴覆盖奖励的几何鲁棒性：通过惯性主轴计算支撑多边形覆盖度，天然适应非规则几何形状和非均匀质量分布（补充材料给出广义公式），且通过"投影点 ±2 索引替换"避免了小团队下的退化情况。这是对传统固定接触点分配（如 CooHOI 手动指定）的实质性改进。

消融

  • 移除 Masked AMP：抬举阶段协调失败率显著上升（运动真实性与物体交互目标冲突）。
  • 移除主轴覆盖奖励：智能体不沿物体主轴分布，出现过度绕垂直轴旋转和不自然对角步态。

边界与局限

  • 论文未明确讨论局限性，但补充材料与实验数据暴露以下边界：
  • 大团队拥挤问题：12-16 智能体时桌面周长拥挤，t_coop 骤降至 15.1%（16A），智能体未学会在狭窄支撑间隙中定位。
  • 两智能体大桌场景：机械杠杆不足，抬升稳定困难，SR 降至 71.0%。
  • 重载泛化上限：5× 桌重下 4A 成功率仅 3.5%，说明策略对质量增加的鲁棒性依赖团队规模补偿。
  • 未验证：训练未见过的物体质量（>5×）、真实世界部署、非均匀质量分布（补充材料仅提供公式，无实验数字）。
  • 参考动作依赖：仍依赖 AMASS 单人体数据，虽经掩蔽扩展了行为多样性，但未突破"无参考动作"的极限场景。

工程启示

  • 复现优先级：先核对团队规模优势归一化实现——这是混合规模训练稳定的关键，全局归一化会导致奖励尺度失衡（Figure 7 显示任务奖励显著下降）。
  • 最容易踩坑：虚拟天花板技巧。IsaacGym 要求环境 actor 数一致，多余 agent 必须完全禁用（无奖励、无观测、无梯度、PD 关闭），否则会引入噪声梯度。
  • 奖励调参：r_form 中 r_cov 权重（0.75）高于 r_ang（0.25）是刻意的——r_cov 在非规则几何下仍有效但可能稀疏，r_ang 提供早期分散信号使 r_cov 非零。若你的任务物体形状更极端，建议先验证 r_cov 的凸包计算是否退化。
  • 训练预算：单张 A100，三阶段共约 9.5 天（1.5+5+3）。若算力有限，可跳过阶段 1 直接训练 2-4 agent，但需注意阶段 1 建立的行走基础技能（位置/速度/朝向奖励）是后续协作的前提。
  • 下游团队：若需部署到真实机器人，注意 MuJoCo humanoid 的简化球形手（无手指）——真实手部接触动力学差异可能影响 r_contact 和 r_lift 的有效性。

대형(編隊) 보상 설계

  • 각도 분포 보상: r_ang = exp(−k_θ·½·[(Δφ_i^ccw − 2π/m)² + (Δφ_i^cw − 2π/m)²]), m은 팀 규모, 균일한 각도 분포를 장려.
  • 주축 커버리지 보상: 루트 위치를 객체 주변 샘플링 점에 투영하고, 볼록 껍질로 지지 다각형을 정의; 각 축 커버리지 g_i = min(d̃_i⁺/ℓ_i⁺, d̃_i⁻/ℓ_i⁻), 보상 r_cov = ½(g₁ + g₂). 핵심 설계: 각 투영 점을 주변 ±2 인덱스의 두 점으로 대체하여 두 에이전트가 선분으로 퇴화하는 것을 방지.
  • 최종 대형 보상 r_form = 0.25·r_ang + 0.75·r_cov(커버리지 보상 가중치가 더 높고, 각도 분포는 초기 분산 신호를 제공하여 커버리지 보상이 0이 아니게 함).
