概述

起作用集法（Active-set method）是一种求解不等式约束优化问题的迭代算法，其核心思想是在每次迭代中维护一个"工作集"（working set），即当前被当作等式约束处理的不等式约束集合，通过反复增删约束来逼近真正起作用的最优约束集合。它真正改变的不是求解单个子问题的效率，而是将"哪些约束该被激活"这一组合决策转化为一系列可高效求解的等式约束子问题，从而在中小规模凸二次规划（QP）中成为最可靠的选择之一。

核心内容

是什么：准确定义

起作用集法是一种求解带不等式约束优化问题的可行点法。它从某个可行点出发，在每一步迭代中，将当前"猜"为取等号的不等式约束与所有等式约束合并为工作集 \(\mathcal{W}_k\)，然后在该工作集上求解一个等式约束的子问题来确定搜索方向。若子问题的最优解违反了工作集之外的某个约束，则将该约束加入工作集；若工作集中某个约束对应的 Lagrange 乘子为负（对最小化问题而言），则说明该约束不应被激活，将其移出工作集。如此反复，直到满足 Karush-Kuhn-Tucker（KKT）条件。

该方法特别适用于凸二次规划问题，因为此时每个子问题都有闭式解或可通过直接法高效求解，且算法在有限步内终止。

为什么存在：痛点与历史定位

在起作用集法出现之前，处理不等式约束的主流思路是罚函数法——将约束惩罚项并入目标函数，把约束问题转化为无约束问题。罚函数法实现简单，但存在两个根本缺陷：一是惩罚参数需要人工调节，过大导致 Hessian 病态，过小则解严重偏离可行域；二是无法精确满足约束，只能逼近。

起作用集法的历史定位在于：它将组合问题与连续问题分离。不等式约束的难点在于"哪些约束起作用"是一个组合决策——若有 \(m\) 个不等式约束，理论上需要检查 \(2^m\) 种激活组合。起作用集法通过逐步交换工作集，避免了穷举，使得每次迭代只需求解一个规模远小于原问题的等式约束子问题。这一思想在 20 世纪 80 年代被系统化，并成为 QP 求解器（如 qpOASES）的核心引擎。

原理拆解

① 工作集：把不等式"假装"成等式

考虑凸二次规划：

\[ \min_x \; \frac{1}{2} x^{\top} H x + g^{\top} x \quad \text{s.t.} \quad A x = b, \; C x \le d. \]

设当前迭代点为 \(x_k\)，工作集 \(\mathcal{W}_k\) 包含所有等式约束以及当前被激活（取等号）的不等式约束。在 \(x_k\) 处，我们求解以下等式约束子问题来确定搜索方向 \(p_k\)：

\[ \min_p \; \frac{1}{2} p^{\top} H p + (H x_k + g)^{\top} p \quad \text{s.t.} \quad A p = 0, \; C_{\mathcal{W}_k} p = 0. \]

注意子问题中约束的右侧被设为 0，因为 \(x_k\) 已经满足工作集约束，我们只关心沿 \(p\) 方向移动时这些约束是否保持成立。

② 步长与约束交换：两个关键判定

求解子问题得到 \(p_k\) 后，需要确定步长 \(\alpha_k\)。若 \(p_k = 0\)，则 \(x_k\) 是工作集子问题的最优解，此时检查工作集中不等式约束对应的 Lagrange 乘子 \(\mu_j\)：若所有 \(\mu_j \ge 0\)，则 \(x_k\) 是原问题的最优解，算法终止；若存在 \(\mu_j < 0\)，则移除该约束（它不应对解产生"推力"），重新求解。

若 \(p_k \neq 0\)，则沿 \(p_k\) 方向移动，步长上限由工作集之外的约束决定：

\[ \alpha_k = \min \left\{ 1, \; \min_{i \notin \mathcal{W}_k, \, c_i^{\top} p_k > 0} \frac{d_i - c_i^{\top} x_k}{c_i^{\top} p_k} \right\}. \]

若 \(\alpha_k < 1\)，说明某个未加入工作集的约束被"撞上"，将其加入工作集，然后重新求解子问题。

③ 有限终止性：凸 QP 的保证

对于凸二次规划，起作用集法具有有限终止性：每次迭代要么使目标函数值严格下降，要么在保持目标值不变的情况下改变工作集（移除乘子为负的约束）。由于工作集的组合数有限，算法必然在有限步内到达 KKT 点。这一性质是内点法所不具备的——内点法只能渐近收敛。

关键参数与规格

参数/概念 含义 典型取值或性质
工作集 \(\mathcal{W}_k\) 当前被当作等式处理的约束集合 随迭代动态变化，大小通常远小于总约束数
搜索方向 \(p_k\) 在工作集约束下使目标下降的方向 由等式约束子问题求解得到
步长 \(\alpha_k\) 沿搜索方向移动的距离 取 1 与"撞到最近约束的距离"中的较小值
Lagrange 乘子 \(\mu_j\) 工作集中不等式约束的对偶变量 用于判定约束是否应被移出工作集
终止条件 梯度在零空间投影为零 + 乘子非负 等价于 KKT 条件

工程判断：在人形机器人全身控制（WBC）中，QP 问题通常规模不大（决策变量数十到数百），但需要在 1 kHz 甚至更高频率下实时求解。起作用集法因其warm-start 特性——上一控制周期的解可作为当前周期的初始工作集——成为 qpOASES 等实时求解器的首选。内点法（如 OSQP、ProxQP）则更适合离线规划或对精度要求极高的场景。

谁在用·应用案例

qpOASES 是起作用集法最著名的工程实现之一，其设计目标就是模型预测控制（MPC）中的参数化 QP 求解。在人形机器人领域，它被广泛用于：

  • 全身运动控制（WBC）：在满足动力学等式、摩擦锥不等式、关节力矩限制的前提下，实时求解关节加速度与接触力。语料中提到的"低层用 QP 或 MPC 实时跟踪"正是这一场景。
  • 模型预测控制（MPC）：每一步滚动优化中，QP 的结构（Hessian 与约束矩阵）变化很小，起作用集法可以利用上一时刻的工作集作为初始猜测，大幅减少迭代次数。
  • 轨迹优化：在分层规划的中层，用 QP 求解局部轨迹修正问题。

局限与边界

  1. 组合爆炸风险：虽然避免了穷举，但在最坏情况下，工作集的交换次数仍可能随约束数量指数增长。对于约束数量极大的问题（如 \(10^4\) 以上），内点法通常更优。
  2. 仅适用于凸问题：对于非凸 QP，起作用集法只能保证找到局部最优解，且有限终止性不再成立。
  3. 需要初始可行点：算法要求从可行点出发。若初始点不可行，需要先运行 Phase I 过程（求解一个辅助 LP 或 QP 来找到可行点），这增加了实现复杂度。
  4. 数值稳定性：当工作集约束接近线性相关时，子问题的 KKT 矩阵可能病态，需要正则化或采用更稳健的分解方法。

常见误区

  1. "起作用集法就是单纯形法"——两者共享"沿约束边界移动"的几何直觉，但单纯形法针对线性规划，起作用集法针对（通常凸的）非线性规划，且每次迭代的搜索方向由目标函数的二阶信息（Hessian）决定，而非单纯沿边。
  2. "工作集越大越好"——工作集过大意味着子问题规模增大，计算量上升；关键在于工作集是否准确，而非大小。一个包含多余约束的工作集可能导致错误的搜索方向。
  3. "乘子为负就一定要移除"——这仅在当前点是最优解（\(p_k = 0\)）时成立。若 \(p_k \neq 0\)，即使存在负乘子，也应先沿搜索方向移动，而非立即调整工作集。
  4. "起作用集法比内点法快"——这是问题规模依赖的判断。在中小规模、需要 warm-start 的场景下成立；但在大规模、稀疏问题上，内点法通常更快。

왜 존재하는가:痛点과 역사적 위치

활성 집합법이 등장하기 전에는 부등식 제약을 다루는 주류 접근법이 벌점 함수법이었습니다—제약 벌점 항을 목적 함수에 통합하여 제약 문제를 무제약 문제로 변환하는 방식입니다. 벌점 함수법은 구현이 간단하지만 두 가지 근본적인 결함이 있었습니다: 첫째, 벌점 매개변수를 수동으로 조정해야 하는데, 너무 크면 Hessian이 병적(ill-conditioned)이 되고 너무 작으면 해가 실현 가능 영역에서 크게 벗어납니다; 둘째, 제약을 정확히 만족시킬 수 없고 근사만 가능합니다.

활성 집합법의 역사적 위치는 조합 문제와 연속 문제를 분리한 데 있습니다. 부등식 제약의 어려움은 "어떤 제약이 활성화되는가"가 조합적 결정이라는 점입니다—\(m\)개의 부등식 제약이 있으면 이론적으로 \(2^m\)개의 활성화 조합을 검사해야 합니다. 활성 집합법은 작업 집합을 점진적으로 교체함으로써 완전 탐색을 피하고, 각 반복에서 원래 문제보다 훨씬 작은 등식 제약 하위 문제만 풀면 되게 합니다. 이 아이디어는 20세기 80년대에 체계화되었고, QP 솔버(예: qpOASES)의 핵심 엔진이 되었습니다.
