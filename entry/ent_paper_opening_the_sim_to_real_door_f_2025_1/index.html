打开仿真到现实世界的人形像素到动作策略传输之门

Opening the Sim-to-Real Door for Humanoid Pixel-to-Action Policy Transfer

摘要

这篇工作主要解决数据闭环：用相机图像/多视角观测、本体状态与关节序列、遥操作/外骨骼数据采集人类操作和机器人状态，再通过教师-学生知识迁移、全身控制器/WBC/MPC、闭环纠错/人类干预转成可训练、可复用的可执行动作命令。关键点是用特权信息训练教师策略，再把能力蒸馏到只能使用部署观测的学生策略。

  • 打开仿真到现实世界的人形像素到动作策略传输之门 project page

概述

本文提出一种分层视觉-语言-动作（Hierarchical VLA）模型，将复杂操作任务分解为选项级规划（System 2）与低级动作执行（System 1），并引入树搜索与分层强化学习框架，利用成功与失败演示数据训练价值函数，以提升决策的可解释性、可扩展性与失败恢复能力。核心贡献在于将价值函数定义为无折扣首达可达概率，并通过节点-边数据集与期望分位数损失实现分层策略学习。

它改变了什么

统一VLA模型在复杂长程任务中面临三个根本性缺陷：一是决策过程不可解释，无法回答“为什么选这个动作”；二是缺乏显式的层级抽象，导致策略难以迁移到新任务或新环境；三是失败恢复能力弱，一旦执行偏离轨迹，模型缺乏重规划机制。本文的动机并非简单堆叠更大的模型，而是从决策结构上引入分层与搜索——将“做什么”（选项）与“怎么做”（低级动作）解耦，使高层规划器能够基于抽象状态进行前瞻性推理，低层执行器则专注于局部控制。

真正改变的是对失败数据的处理方式：传统方法通常丢弃失败演示或仅作为负样本加权，本文则将其纳入价值函数训练，使模型学会识别“不可行动作”并触发重规划。这一转变将失败从噪声变为信息，直接服务于树搜索中的节点剪枝与分支选择，从而在测试时获得可扩展的推理能力。

方法拆解

问题形式化

  • 采用半马尔可夫决策过程（SMDP）建模，将任务分解为选项级（Option-Level）决策与低级动作执行。
  • 定义节点（Nodes）为抽象状态表示，边（Edges）为节点间转换，构建节点-边数据集用于分层学习。
  • 价值函数定义为成功概率（Success Probability），等价于无折扣首达可达概率（undiscounted first exit reachability probability）。

整体流程

  • System 2（高层规划）：负责节点与边的生成、节点评估，并使用树搜索算法进行决策。
  • System 1（低层执行）：训练与推理分开设计，执行由System 2选定的低级动作。

关键设计决策

  • 在节点-边MDP上使用期望分位数损失（Expectile losses）训练价值函数，而非标准均方误差——这使价值估计对尾部风险更鲁棒，避免低估低概率但关键的成功路径。
  • 节点-边核由低级选项诱导（node-edge kernel induced by low-level options），即高层规划的转移概率依赖于低层策略的可达性，形成闭环。
  • 树搜索在节点层面进行，而非动作层面，显著降低搜索分支因子，使测试时计算量可控。

训练数据构成

  • 同时使用成功与失败演示，失败数据用于训练价值函数识别不可行节点，从而在树搜索中剪枝。

关键创新

  1. 价值函数即可达概率：将价值函数定义为无折扣首达可达概率，而非折扣累积回报。这一选择与分层规划的语义天然对齐——高层关心的是“能否到达目标”，而非“累积奖励”。这使得价值函数可以直接用于树搜索的节点排序与剪枝，无需额外转换。

  2. 失败数据作为结构化信号：不同于将失败演示简单丢弃或加权，本文将其纳入节点-边数据集的构建，使价值函数学习到“哪些抽象状态不可行”。这直接增强了模型的失败恢复能力——当执行偏离时，System 2可以基于价值函数重新规划路径。

  3. System 2/System 1 解耦：高层规划与低层执行完全分离，且低层策略可独立替换或预训练。这种架构允许利用现成的低级控制器或预训练模型进行引导（bootstrapping），而高层规划器可以独立于具体执行器进行训练与评估。

边界与局限

论文未明确列出具体局限。从方法结构推断，存在以下边界条件： - 节点定义的依赖：节点与边的生成依赖人工设计或预训练VLM的抽象能力，若抽象粒度不当，价值函数学习可能失效。 - 低层策略的假设：节点-边核由低级选项诱导，意味着低层策略的可达性必须可估计——若低层策略本身不可靠，高层规划的价值估计将失真。 - 真实世界泛化：真实世界演示章节存在，但未提供数字，无法判断sim-to-real gap的具体表现。 - 重规划模块：作者将“即插即用重规划模块”列为未来方向，说明当前版本的重规划能力可能受限于树搜索的固定结构。

工程启示

  • 先核对节点定义：复现时最关键的步骤是确认节点与边的生成方式——是人工标注、VLM自动生成，还是两者混合。这直接决定节点-边数据集的质量，进而影响价值函数训练。
  • 失败数据的标注粒度：失败演示需要标注到“哪个节点不可行”，而非仅标注“任务失败”。若原始数据缺乏此类标注，需要额外的人工或自动标注流程。
  • 价值函数训练的损失选择：期望分位数损失（expectile loss）对超参数敏感，建议先在小规模节点-边数据集上验证价值函数的收敛性，再扩展到完整任务。
  • 树搜索的深度与宽度：节点层面的搜索虽然降低了分支因子，但深度仍受限于任务长度。建议先测试短程任务（如插头插入）验证搜索效率，再尝试长程任务。
  • 低层策略的独立性：System 1可以独立预训练，但需确保其动作空间与System 2的节点-边核兼容——否则高层规划的价值估计会与实际执行能力脱节。
