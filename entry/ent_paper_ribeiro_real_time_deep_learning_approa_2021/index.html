面向自主机器人操作的视觉伺服控制与抓取检测的实时深度学习方法

Real-Time Deep Learning Approach to Visual Servo Control and Grasp Detection for Autonomous Robotic Manipulation

领域
AI 模型与算法零部件
层级
智能层上游
审校

摘要

本文提出两种轻量级CNN用于机器人自主操作：一种基于Cornell Grasping Dataset从单张RGB图像预测五维抓取矩形，另一种利用自采集Kinova Gen3数据集从参考与当前图像对中回归视觉伺服相机速度，实现未知物体的实时动态抓取。

来源与参考

  • Real-Time Deep Learning Approach to Visual Servo Control and Grasp Detection for Autonomous Robotic Manipulation

概述

该工作聚焦非结构化动态环境中的机器人抓取视觉感知阶段，通过两个实时运行的轻量级卷积神经网络协同工作。第一个网络基于Cornell Grasping Dataset训练，能从工作区图像预测抓取矩形（包含位置、朝向和夹爪开度）；第二个网络从零开始学习视觉伺服控制，通过预测相机线速度和角速度的比例值，确保运动物体始终处于抓取网络视野内。系统在Kinova Gen3机器人上验证，实现了毫米级定位精度，且能泛化至多种未见过的物体。

核心内容

方法架构

  • 抓取检测网络：采用轻量级CNN架构，输入单张RGB图像，输出五维抓取矩形参数（中心坐标、旋转角度、夹爪宽度）。训练数据来自Cornell Grasping Dataset，支持实时推理。
  • 视觉伺服网络：从零开始训练的第二网络，输入为参考图像与当前图像的配对，直接回归相机所需的线速度与角速度比例值。训练数据由Kinova Gen3机械臂自动采集生成。

实验设置

  • 硬件平台：Kinova Gen3机械臂，搭载RGB相机。
  • 数据集：抓取网络使用Cornell Grasping Dataset；伺服网络使用自采集数据集（包含不同物体运动轨迹）。
  • 评估指标：离线验证集分析处理速度与效率；在线实验测试实时抓取性能。

关键结果

  • 定位精度：针对首次见到的目标物体，控制器最终位置误差达到毫米级。
  • 实时性能：两个网络均满足实时运行要求，支持动态环境下的连续抓取。
  • 泛化能力：系统可处理多种不同形状、尺寸的未知物体，无需重新训练。

结论

本文提出的双网络系统在实时性、精度和泛化性上均优于现有文献中从零学习的控制器方案，为自主机器人操作提供了高效解决方案。
