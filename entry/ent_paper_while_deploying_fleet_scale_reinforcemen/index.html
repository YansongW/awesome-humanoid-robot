Learning while Deploying: Fleet-Scale Reinforcement Learning for Generalist Robot Policies

摘要

LWD（Learning while Deploying）是由AGIBOT Finch Research提出的一个面向通用机器人策略的车队规模离线到在线强化学习框架。其核心贡献在于将部署过程本身转化为持续训练循环，利用整个机器人车队产生的异构经验（包括成功、失败和人工干预）来持续改进单一通用VLA策略，而非仅依赖专家演示。

概述

本文提出 Learning while Deploying（LWD），一个面向通用 VLA 机器人策略的车队级离线到在线强化学习框架，由 Agibot 团队在 G1 双臂机器人上实现。核心贡献在于将部署从评估终点转变为训练循环，通过 DIVL（分布隐式价值学习）与 QAM（伴随匹配 Q 学习）两个组件，解决异构车队回放与生成式动作头两大挑战，在 8 个真实操作任务上持续优于先前后训练基线。

它改变了什么

过去几年，VLA 预训练模型让机器人获得了强大的先验，但社区默认的范式是：预训练后冻结或仅用少量专家示范微调，部署只是收集更多示范的飞轮。LWD 真正改变的是这个隐含假设——它不再把部署当作数据采集的附属品，而是把整个车队当作一个持续运转的强化学习环境。这意味着失败轨迹、部分进展、人工干预这些过去被丢弃或仅用于对比学习的信号，现在都成为价值学习的监督来源。

更深层的改变在于后训练的对象。先前的后训练系统（如 RT-X 类工作）主要针对专用策略，每个任务一个控制器，而 LWD 坚持训练单一通用策略覆盖所有任务。这不仅是工程简化，而是对「通用性」的重新定义：通用不是预训练时的静态属性，而是部署中通过异构经验持续打磨出来的动态属性。作者明确抛弃了模仿学习作为后训练手段，转向离线到在线 RL，这要求价值函数在稀疏延迟奖励和高度异构的数据分布下依然稳定——这是此前系统刻意回避的难点。

方法拆解

LWD 的架构是一个闭环：预训练策略部署到车队 → 自主 rollout 与人工干预聚合到共享回放缓冲区 → 集中式 learner 更新策略 → 周期推回车队。

两阶段训练流程

  • 离线阶段：用先前收集的机器人数据（专家示范、历史 rollout、失败模式附近的探索数据）做离线 RL 初始化，为策略和 critic 提供稳定起点。这一步的关键是避免从零开始在线探索的冷启动问题。
  • 在线阶段：当前策略部署到车队，每台机器人执行真实任务并上传轨迹到共享在线缓冲区；learner 在静态离线缓冲区与增长的在线缓冲区混合数据上训练，周期性推送更新。

组件一：DIVL（Distributional Implicit Value Learning）

  • 不回归单一标量值，而是学习数据集中动作值的分布，提取分位数统计量作为 TD bootstrap 目标。
  • 保留 IQL 的分布内价值学习原则，避免分布外最大化导致的过估计——这对异构回放尤其重要，因为不同任务的奖励稀疏度和成功率差异极大。
  • 对长 horizon 任务使用多步 TD 目标，加速稀疏终止奖励的传播。

组件二：QAM（Q-learning with Adjoint Matching）

  • 针对 flow-matching 动作头设计。现代 VLA 策略通过多步去噪生成动作，无解析似然，直接策略梯度不稳定。
  • 利用 critic 梯度引导策略提取，将引导优化重构为沿 flow 轨迹的局部回归，避免通过完整生成过程反向传播。

整体解耦

DIVL 负责策略评估（从异构回放中学价值），QAM 负责策略提取（将价值转化为 flow 策略更新）。两者解耦使得价值学习可以独立于动作头结构，策略更新可以独立于价值估计的噪声。

关键创新

  1. 将部署本身变成 RL 训练信号源：此前数据飞轮只利用成功轨迹，LWD 明确将失败、部分进展、人工干预全部纳入价值学习。这不是简单的数据增广，而是对「什么构成学习信号」的重新定义——失败轨迹在 TD 学习中提供负向价值监督，人工干预提供接近成功状态的引导。

  2. DIVL 的分布价值学习适配异构回放：IQL 此前主要用于同质数据，LWD 将其扩展为分布形式，用分位数统计量作为 bootstrap 目标。这个设计直接回应了车队数据的核心矛盾——不同任务的成功率、奖励密度、干预频率差异巨大，单一标量值无法捕捉这种变异性，而分布形式天然具备鲁棒性。

  3. QAM 解决生成式动作头的策略提取：flow-matching 动作头是当前 VLA 的主流选择，但无法计算似然，导致基于最大似然的策略提取和直接策略梯度都不可行。QAM 将 critic 引导重构为沿 flow 轨迹的局部回归，绕开了完整生成过程的反向传播——这是对生成式策略 RL 训练的一个实用解法，且与动作头结构解耦。

实验与结果

实验在 Agibot G1 双臂机器人车队上进行，覆盖 8 个真实操作任务，包括多个持续 3-5 分钟的长 horizon 任务（冲泡功夫茶、调制鸡尾酒、制作果汁、打包鞋子、杂货补货）。训练单一通用策略覆盖所有任务。

边界与局限

论文未明确列出局限性讨论段落。从事实要点可推断的边界包括：

  • 未与专用策略对比：没有给出 LWD 通用策略与每任务专用策略的对比细节，因此无法判断通用性带来的性能损失幅度。
  • 未验证大规模部署：仅提出未来方向，未在更多家庭、商店、工厂场景验证。
  • 非长 horizon 任务改进幅度未提及：如果短任务改进有限，则框架价值可能集中在长 horizon 场景。
  • 车队规模未提及：无法判断框架在多大车队规模下有效，以及通信、同步开销如何随规模增长。

论文未明确：LWD 在短 horizon 任务上的表现、对人工干预频率的敏感性、离线数据质量对最终性能的影响。

工程启示

复现 LWD 时，最先要核对的是价值学习的稳定性——DIVL 的分位数参数和 IQL 的期望分位数选择直接决定 TD 目标的噪声水平，这可能是整个框架最敏感的部分。建议先在小规模离线数据上验证 DIVL 能否稳定收敛，再引入在线数据。

最容易踩坑的地方是异构回放的过拟合：在线缓冲区增长快，如果混合比例不当，价值函数会迅速偏向近期数据，导致灾难性遗忘。作者提到「避免过拟合瞬时在线数据」但未给出具体比例，复现时需自行实验确定离线/在线数据配比。

对下游团队的实际指导：

  • 如果已有 VLA 预训练模型和车队部署，LWD 的价值在于把现有部署数据（包括失败）转化为策略改进，无需重新设计数据采集流程。
  • QAM 的局部回归设计意味着你可以替换动作头结构而不必重写价值学习部分——架构解耦是工程上的实际红利。
  • 长 horizon 任务是 LWD 的优势区，如果业务场景主要是短任务，收益可能有限，先做小规模验证再决定是否全量投入。
  • 联系 Agibot（research@agibot.com）获取更多实现细节，但需注意论文未公开训练配置，复现成本可能较高。
