WMPO

WMPO: World Model-based Policy Optimization for Vision-Language-Action Models

领域
AI 模型与算法软件中间件
层级
智能层
审校
待审校

摘要

WMPO 是由香港科技大学与字节跳动 Seed 团队于 2025 年提出的世界模型策略优化框架，旨在解决视觉-语言-动作模型在机器人操作中依赖专家演示、难以从失败中学习的问题。其核心贡献在于通过像素级世界模型生成“想象”轨迹，结合在线策略的 GRPO 算法，在不接触真实环境的情况下实现高效强化学习，显著提升样本效率与泛化能力。

来源与参考

  • WMPO: World Model-based Policy Optimization for Vision-Language-Action Models (arXiv)
  • WMPO source

概述

WMPO 提出将视觉-语言-动作（VLA）策略的强化学习完全建立在像素空间动作条件视频生成世界模型之上，通过预训练高保真视频生成器并在策略自身行为数据上微调，实现大规模想象 rollout 下的 GRPO 优化。该方法在 Mimicgen 仿真与真实机器人任务上显著超越在线 GRPO 与 DPO 基线，同时缓解了分布外状态下的复合误差问题。

它改变了什么

这项工作真正改变的是 VLA 策略自我改进的“数据来源”问题。此前，基于模型的 RL 多在抽象潜空间运作，与在真实图像上预训练的 VLA 基础模型存在根本性不匹配——预训练的视觉理解无法直接应用于不匹配的潜动力学模型，导致世界模型与策略知识之间出现鸿沟。WMPO 将世界模型构建在像素空间，使策略能够在与其预训练分布一致的生成视觉数据上运作，从而弥合了这一鸿沟。

另一个关键改变在于将 RL 从“真实轨迹预算约束”中解放出来。在线 GRPO 在批次大小 64、组大小 8 时，单次更新需至少 512 条真实轨迹；在 P=128 的 rollout 预算下大批次不可行，P=1280 时也仅能更新一两次。WMPO 通过想象轨迹实现大规模 on-policy 更新，使策略优化不再受限于物理世界的采样效率，同时天然支持从同一初始状态重复 rollout——这在物理世界中难以实现，但对大规模 GRPO 训练至关重要。

方法拆解

整体框架

WMPO 包含三个训练阶段：先在 Open X-Embodiment (OXE) 数据集上预训练像素空间视频生成世界模型，再用下游策略收集的行为数据微调世界模型，最后在想象轨迹上执行 GRPO 策略优化。

世界模型架构

  • 基于 OpenSora 视频扩散骨干，将 3D VAE 替换为 SDXL 的 2D VAE，以保留细粒度运动细节并避免过度压缩导致的时间失真。
  • 扩散过程在 VAE 潜空间中运作，但将想象轨迹解码回像素空间以利用预训练知识。
  • 预测给定 c=4 个条件帧和一个动作块后的下 K=8 帧，动作块长度 K=8，每维离散化为 256 个 bin。

帧级动作控制

扩展 AdaLN 块，在帧级注入动作信号和扩散时间步嵌入。对每个动作 a_i，MLP 生成调制系数：LayerNorm 输出的缩放 γ₁ⁱ 和偏移 β₁ⁱ，以及 MHA 或 FFN 块残差连接的缩放 α₁ⁱ。更新规则为： xⁱ = xⁱ + (1+α₁ⁱ)·Block(γ₁ⁱ·LayerNorm(xⁱ)+β₁ⁱ)

噪声帧条件化

训练期间，条件帧以 50/1000 步的扩散噪声扰动而非保持干净，提高对不完美条件的鲁棒性，使世界模型能稳定生成长达数百帧的轨迹而无明显质量损失。

策略行为对齐

为缓解专家示范与策略 rollout 之间的状态分布不匹配，用策略自身收集的行为数据微调世界模型，使其能忠实模拟包括失败在内的多样场景。

奖励模型与策略优化

  • 奖励模型以 VideoMAE 编码器加线性头实现，用二元交叉熵损失训练；正样本为成功轨迹的终止片段，负样本来自成功轨迹的中间片段和失败轨迹的任意片段。
  • 推理时以步长 s 的滑动窗口计算每个片段的成功概率，任一片段超过阈值 τ_thr 则判定轨迹成功。
  • 采用 GRPO 算法，目标函数为 J(θ) = E[ (1/G)Σᵢ (1/T)Σₜ min(rᵢ,ₜ(θ)Âᵢ, clip(rᵢ,ₜ(θ), 1-ε_low, 1+ε_high)Âᵢ) ]，其中 rᵢ,ₜ(θ) = π_θ(aᵢ,ₜ|sᵢ,ₜ)/π_θ_old(aᵢ,ₜ|sᵢ,ₜ)，Âᵢ = (Rᵢ - mean({Rᵢ}))/std({Rᵢ})。
  • 若组内所有奖励全为 0 或全为 1，则跳过该组；裁剪比率 ε_low=0.20 和 ε_high=0.28，温度 1.6。

关键创新

  1. 像素空间世界模型与 VLA 预训练知识的对齐：这是最核心的创新。经典基于模型的 RL 在抽象潜空间运作，与在真实图像上预训练的 VLA 基础模型存在根本性不匹配。WMPO 将世界模型构建在像素空间，使策略能够在与其预训练一致的生成视觉数据上运作，从而弥合世界模型与策略预训练知识之间的鸿沟。

  2. 片段级自回归视频生成实现可靠的基于结果的奖励分配：通过片段级自回归视频生成完整试验，避免短视界预测难以定义准确奖励且易受奖励黑客攻击的问题。这使得学习奖励模型能够从完整轨迹判定二元结果，而非依赖短视界预测的累积奖励。

  3. 噪声帧条件化与策略行为对齐的组合：噪声帧条件化（50/1000 步扩散噪声扰动）提高对不完美条件的鲁棒性，使世界模型能稳定生成长达数百帧的轨迹；策略行为对齐则确保世界模型能忠实模拟包括失败在内的多样场景。两者结合使想象轨迹的质量足以支撑有效的策略优化。

真实世界实验

Cobot Mobile ALOHA 平台上执行“将方块插入杆中”任务，间隙仅 5 mm。30 次试验的平均成功率：基础策略 53%，DPO 60%，WMPO 70%。

终身学习

在 StackThree 任务上，迭代收集 P=128 条真实轨迹并执行 WMPO 优化，WMPO 稳定且大幅优于 DPO 基线；DPO 因训练不稳定无法迭代改进。

边界与局限

  • 假设机器人状态可仅由图像观测定义；对于更复杂的设置（如部分可观测 MDP），留待未来研究。
  • 仅聚焦于离散动作表示，未涉及连续动作空间；作者指出框架原则上支持基于流的策略，但本工作未实现。
  • 未在真实世界中系统评估所有场景，仅提供示例。
  • 论文未明确提及推理频率等工程细节。

工程启示

复现时需重点核对以下环节：

  1. 世界模型微调数据质量：策略行为对齐是核心，必须用策略自身收集的行为数据（而非仅专家示范）微调世界模型，否则无法忠实模拟失败场景。仿真中每任务 300 条专家轨迹用于基础策略微调，P=128 或 P=1280 条策略收集轨迹用于世界模型微调和策略优化。

  2. 噪声帧条件化的实现细节：条件帧以 50/1000 步的扩散噪声扰动，这一设计对长轨迹生成的稳定性至关重要，若省略可能导致数百帧生成质量明显下降。

  3. GRPO 的组过滤机制：若组内所有奖励全为 0 或全为 1，则跳过该组。这一设计避免了无信息梯度的更新，但需注意在奖励模型误判时可能过滤掉有效样本。

  4. 硬件与训练规模：SFT 在 8 块 H100 GPU 上进行，世界模型训练和策略优化在 32 块 H100 GPU 上进行。世界模型预训练 12,000,000 步，微调 3,000,000 步——这一规模对大多数团队而言是显著门槛，需评估是否可通过减少预训练步数或使用更小的骨干网络来权衡。

  5. 动作离散化与输出头：每维离散化为 256 个 bin，SFT 阶段排除机器人本体感觉状态和腕部相机输入，输出头预测离散动作 token 而非 L1 回归。若下游任务需要本体感觉信息，需重新设计状态表示。
