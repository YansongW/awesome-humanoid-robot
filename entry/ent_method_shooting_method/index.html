打靶法

Shooting Method

摘要

通过从初始猜测积分并调整决策变量以满足终端约束，从而求解边值问题的数值方法。

概述

打靶法（Shooting Method）是一种求解两点边值问题（Boundary Value Problem, BVP）的数值方法，其核心思想是将边值问题转化为初值问题（Initial Value Problem, IVP）进行迭代求解。它真正改变的不是求解器的选择，而是将"满足边界条件"这一全局约束转化为"调整初始猜测"这一局部迭代过程，从而让无法直接求解的边值问题变得可解。

核心内容

是什么：打靶法的准确定义

打靶法属于 方法 类型，所属领域为 AI 模型与算法（07_ai_models_algorithms），价值链层级为智能层。其英文名称为 Shooting Method，韩文名称为 슈팅 방법。

从数学上讲，打靶法针对如下形式的两点边值问题：给定系统动力学 \(\dot{x}(t) = f(t, x(t), u(t))\)，边界条件为 \(x(t_0) = x_0\) 和 \(x(t_f) = x_f\)，其中 \(t_0\) 与 \(t_f\) 分别为初始时刻与终端时刻。打靶法的基本策略是：先猜测初始状态中的未知分量（即"射击角度"），然后从 \(t_0\) 向前积分系统动力学，检查终端时刻的状态是否满足 \(x(t_f) = x_f\)。若不满足，则根据终端误差调整初始猜测，重复积分直至收敛。

这一过程与炮兵射击的试射-校正逻辑高度相似：先打一发，观察落点偏差，再调整炮口角度，故得名"打靶法"。

为什么存在：痛点与历史定位

边值问题在机器人学中无处不在：最优控制中的两点边值问题、轨迹规划中的起止状态约束、以及步态规划中的周期边界条件。然而，边值问题无法像初值问题那样直接通过单次积分求解——终端约束的存在使得解必须同时满足两端条件，这本质上是一个隐式方程求解问题。

在打靶法出现之前，工程师面对边值问题的主要手段是解析方法或试错法。解析方法仅对极少数线性或特殊非线性系统有效；试错法则完全依赖经验，缺乏系统性和收敛保证。打靶法的历史定位在于：它首次将边值问题转化为一个低维的根求解问题——只需求解终端误差函数 \(F(s) = 0\)，其中 \(s\) 为初始猜测向量，\(F\) 为终端误差向量。这一转化使得 Newton-Raphson 等成熟的求根算法可以直接应用，从而将边值问题的求解纳入了数值分析的统一框架。

原理拆解

① 从边值问题到初值问题的转化

考虑一个一阶常微分方程组的两点边值问题：

\[ \dot{x}(t) = f(t, x(t)), \quad t \in [t_0, t_f], \quad g(x(t_0), x(t_f)) = 0 \]

其中 \(g(\cdot, \cdot)\) 为边界条件函数。设系统状态维度为 \(n\)，边界条件数量为 \(n\)（即约束数等于状态数，问题适定）。将边界条件拆分为初始端已知部分与未知部分：令 \(x(t_0) = x_0(s)\)，其中 \(s \in \mathbb{R}^k\) 为待定的初始猜测参数（\(k\) 为未知初始状态的数量），\(x_0(s)\) 为已知函数关系。从该初始状态积分系统至 \(t_f\)，得到终端状态 \(x(t_f; s)\)，定义终端误差函数：

\[ F(s) = h(x(t_f; s)) \]

其中 \(h(\cdot)\) 为终端边界条件的残差函数。于是原边值问题转化为求 \(F(s) = 0\) 的根问题。

② 迭代求解与灵敏度传播

求解 \(F(s) = 0\) 的标准方法是 Newton-Raphson 迭代。设当前猜测为 \(s^{(k)}\)，则迭代格式为：

\[ s^{(k+1)} = s^{(k)} - \left[ J_F(s^{(k)}) \right]^{-1} F(s^{(k)}) \]

其中 \(J_F = \partial F / \partial s\) 为终端误差对初始猜测的雅可比矩阵（即灵敏度矩阵）。该矩阵可通过变分方程（variational equation）传播获得：令 \(\Phi(t) = \partial x(t) / \partial s\)，则 \(\Phi(t)\) 满足：

\[ \dot{\Phi}(t) = \frac{\partial f}{\partial x}(t, x(t)) \, \Phi(t), \quad \Phi(t_0) = \frac{\partial x_0}{\partial s} \]

将变分方程与系统动力学方程同时从 \(t_0\) 积分至 \(t_f\)，即可得到 \(J_F = \partial h / \partial x \cdot \Phi(t_f)\)。这一"同时积分状态与灵敏度"的做法，使得每次迭代只需一次正向积分即可获得完整的梯度信息，避免了有限差分带来的额外计算开销。

③ 步长控制与收敛性

打靶法的收敛性依赖于初始猜测的质量。若初始猜测距离真解过远，Newton 迭代可能发散。工程上常用的缓解手段包括：阻尼 Newton 法（在迭代步长上乘以衰减因子）、同伦法（从松弛边界条件逐步过渡到严格边界条件）、以及多重打靶法（将时间域分段，每段独立打靶并施加连续性约束）。其中多重打靶法通过将长积分区间切分为多个短区间，显著降低了单次积分对初始误差的敏感性，是工程应用中最稳健的变体。

打靶法的核心优势在于变量维度低——仅需优化初始猜测参数，因此单次迭代的计算成本远低于直接配点法。但其代价是：单段积分对初始误差的放大效应使得收敛半径较小，对强非线性系统或长时域问题尤为敏感。直接配点法通过将动力学约束离散为代数约束，牺牲变量维度换取了对初始猜测的鲁棒性，但 NLP 问题的规模也随之增大。工程判断：对于时域较短（如单步规划，约 0.5–1 秒）、动力学相对平滑的问题，打靶法因其低维度和高精度而更具优势；对于时域较长或存在强非线性（如足式机器人全身运动规划）的问题，直接配点法更为稳妥。

谁在用·应用案例

在人形机器人领域，打靶法主要应用于以下场景：

  1. 单步轨迹规划：给定起始姿态与目标姿态，求解满足动力学约束的最优轨迹。由于单步时域短（通常 0.5–1 秒），打靶法的低维度优势得以充分发挥，且终端精度高（可达 \(10^{-8}\) 量级，需自行确认），适合对落点精度要求严格的任务。

  2. 周期步态生成：行走步态要求相邻步周期的状态完全一致（周期边界条件），这天然是一个两点边值问题。打靶法通过调整初始状态猜测，使终端状态回到初始状态，从而生成稳定的周期步态。

  3. 最优控制问题的间接法求解：基于 Pontryagin 极小值原理，最优控制问题可转化为 Hamiltonian 系统的两点边值问题（协态变量在两端满足横截条件）。打靶法直接求解该边值问题，得到严格满足一阶最优性条件的解，精度高于直接法的 NLP 近似解。

局限与边界

打靶法的核心局限在于对初始猜测的敏感性。对于强非线性系统，终端误差函数 \(F(s)\) 可能出现多根、不连续甚至无界的情况，导致 Newton 迭代发散。此外，当系统动力学在积分区间内存在刚性（stiffness）时，显式积分器需要极小的步长，计算成本急剧上升。

另一个重要边界是：打靶法求解的是"给定边界条件下的确定性轨迹"，它不直接处理不等式约束（如关节力矩极限、足底摩擦锥约束）。若问题包含不等式约束，需在打靶迭代外层嵌套约束处理机制（如惩罚函数或投影），这会显著增加实现复杂度。对于包含大量不等式约束的全身运动规划问题，直接配点法或直接转录法（direct transcription）是更自然的选择。

常见误区

  1. "打靶法只能用于线性系统"——错。打靶法对非线性系统同样适用，只是收敛性依赖于初始猜测质量；线性系统的终端误差函数是线性的，Newton 迭代一次收敛，而非线性系统需要多次迭代。

  2. "打靶法一定比直接配点法快"——不必然。打靶法单次迭代成本低，但若初始猜测差导致迭代次数多甚至发散，总成本可能超过直接配点法。工程判断：在时域短、初始猜测好的场景下打靶法更快；否则直接配点法更可靠。

  3. "多重打靶只是打靶法的简单分段"——不准确。多重打靶不仅分段积分，还引入了分段点处的连续性约束，将原问题转化为一个带约束的优化问题（而非纯求根问题），其数学结构与单段打靶有本质区别。
