摘要

本文提出一种基于大语言模型（LLMs）的全局控制策略，用于工业机器人装配任务。该策略由Bosch人工智能中心与特拉维夫大学于2024年联合开发，核心贡献在于通过动态上下文切换，将通用控制策略转移至一组专门训练的高精度技能，从而解决通用策略在精密操作（如插入）中的精度不足问题。

概述

该论文提出一种统一训练流程，使单个视觉-语言-动作（VLA）模型同时支持全掩码预测（SFM）与异步掩码预测（AFM），并引入置信度评分器实现自适应掩码推理。核心贡献在于通过噪声注入与掩码采样策略缓解训练-推理暴露偏差，同时保持全掩码退化能力，提升数据效率与推理鲁棒性。

它改变了什么

问题在于：训练时未掩码 token 为干净动作，而推理时这些 token 由不完美的 SFM 预测替代，导致暴露偏差（exposure bias）。这并非简单的工程细节，而是生成式动作预测范式的结构性缺陷——模型在训练中从未见过“带噪声的上下文”，却在推理时被迫依赖此类上下文。作者将 SFM 视为 AFM 的全掩码特例，统一了两种推理模式，改变了“训练与推理必须分离”的既有认知。置信度评分器的引入则进一步将“预测不确定性”显式纳入推理决策，使模型能根据上下文质量动态调整掩码比例，而非固定掩码策略。

方法拆解

统一训练流程

  • VLM 主干与 FM 头联合训练，最小化 AFM 速度预测损失（公式 5）： L = E_τ { || [V_θ(o_t, ℓ, a_hat_{t:t+L}^τ) - u_{t:t+L}] ⊙ m ||^2 } 其中 u_{t:t+L} = n_{t:t+L} - a_{t:t+L}，n ~ N(0, I) 为高斯噪声。

中间异步噪声动作（公式 6-7）

  • 未掩码 token 注入噪声 ε ~ N(0, σ_c^2 I)，掩码 token 按 τ 进行扩散插值： a_hat = a_tilde - τ(a_tilde - n) ⊙ m
  • 关键设计：对未掩码 token 注入噪声（而非干净动作），以模拟推理时 SFM 预测的不完美性，减少暴露偏差。

掩码与时间采样

  • 掩码 m 元素独立同分布采样自 Bernoulli(y)，y ~ U(0,1)。
  • FM 时间 τ ~ Beta(1.5, 1)，强调接近 1 的噪声步（即高噪声区域）。
  • 当 m 全为 1 时，AFM 损失退化为 SFM 损失，保证统一模型能力。

置信度评分器训练

  • VLA 主干训练完成后冻结，端到端训练评分器。
  • 伪标签：q = 1 - α - β * (e - min{e}) / (max{e} - min{e} + ε)，其中 e 为 SFM 生成动作 chunk 的 token 级 MSE，α、β 控制伪标签范围约 [1-α-β, 1-α]。

关键创新

  1. 统一训练范式：将 SFM 与 AFM 纳入同一训练流程，消除训练-推理模式割裂，使模型天然支持两种推理路径，无需额外微调。
  2. 噪声注入策略：对未掩码 token 注入噪声而非使用干净动作，直接针对暴露偏差建模，增强模型对真实上下文误差的鲁棒性——这是与常规掩码训练的本质区别。
  3. 置信度驱动的自适应掩码：通过评分器预测 token 级误差，推理时仅重新生成高偏差 token，保留可靠上下文，在计算效率与生成质量间取得动态平衡。

边界与局限

论文未明确列出作者承认的局限或未做之事。基于方法推断：置信度评分器依赖 SFM 生成的 token 级 MSE 作为伪标签，可能受 SFM 自身误差分布影响；σ_c^2 与 α、β 等超参数需针对不同任务调优，泛化性未验证；实验部分缺失，无法评估实际性能增益。

工程启示

复现时先核对三点：一是 τ ~ Beta(1.5, 1) 的采样是否显著影响训练稳定性（建议先固定 τ=1 验证基线）；二是未掩码 token 的噪声方差 σ_c^2 需与动作尺度匹配，过大易破坏上下文信息，过小则无法缓解暴露偏差；三是置信度评分器的伪标签范围 [1-α-β, 1-α] 需根据任务误差分布调整，α、β 的默认值论文未明确，建议从 α=0.1, β=0.8 起步。最易踩坑处在于：联合训练时 SFM 与 AFM 损失权重未明确，若直接相加可能导致梯度冲突，建议先验证全掩码退化（m 全 1）时损失是否与纯 SFM 一致。
