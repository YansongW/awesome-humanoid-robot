Diversity is All You Need: Learning Skills without a Reward Function

Diversity is All You Need: Learning Skills without a Reward Function

层级

摘要

DIAYN 是一种无需奖励函数即可学习多样化技能的无监督强化学习方法，由研究团队提出。其核心贡献在于通过最大化信息论目标（结合最大熵策略），使智能体在模拟机器人任务中自主涌现行走、跳跃等技能，并可作为预训练机制提升下游任务的探索效率与数据利用率。

概述

DIAYN（Diversity is All You Need）是Ben Eysenbach等人提出的无奖励技能学习方法，通过最大化互信息与策略熵的联合目标，让智能体自主涌现出多样化、可区分的行为技能。该方法在多个连续控制基准上无需任务奖励即可学习解决任务，并可作为分层RL、模仿学习的有效基元。

它改变了什么

这篇论文真正改变的是“技能发现”问题的定义方式。此前无监督技能学习（如VIC）依赖对抗训练或学习技能先验，导致训练不稳定或技能坍缩到少数几个。DIAYN将问题重新形式化为一个合作博弈：固定均匀技能先验，用最大熵策略保证探索，用判别器提供可区分性奖励。这个转变看似简单，但彻底改变了训练动态——从对抗鞍点问题变成凸优化友好的目标，使得技能多样性成为可稳定优化的结果而非偶然涌现。

更重要的是，作者证明了“可区分”不等于“多样化”。两个技能只要在状态上有一丁点差异就可区分，但不一定语义上有意义。DIAYN通过最大熵项迫使技能必须探索远离其他技能的状态空间区域才能保持可区分，从而在“可区分”和“多样化”之间建立了因果联系。这一洞察直接指导了目标函数的设计，也是后续所有实验结果的根基。

方法拆解

目标函数

最大化 ℱ(θ) = I(S;Z) + ℋ[A|S] − I(A;Z|S)，其中： - I(S;Z)：状态与技能的互信息，鼓励不同技能访问不同状态 - ℋ[A|S]：策略熵，鼓励探索 - −I(A;Z|S)：给定状态时动作与技能的条件互信息，防止技能仅靠动作区分

变分下界

用判别器 q_φ(z|s) 近似后验 p(z|s)，得到可优化的下界： 𝒢(θ,φ) = ℋ[A|S,Z] + 𝔼[log q_φ(z|s) − log p(z)]

伪奖励设计

r_z(s,a) = log q_φ(z|s) − log p(z) - 减去 log p(z) 有两个作用：防止技能在吸收状态获得虚假奖励；确保奖励非负（当 q_φ ≥ p(z) 时） - 在希望尽快终止的环境（如mountain car）可移除该基线

算法流程

  1. 采样技能 z ∼ p(z)（均匀类别分布）
  2. 用 SAC 学习条件策略 π_θ(a|s,z)，最大化伪奖励
  3. 判别器 q_φ(z|s) 用 SGD 更新，从访问状态推断技能
  4. 熵正则化系数 α=0.1（经验选择）

关键设计决策

  • 固定 p(z) 而非学习：学习 p(z) 会导致“马太效应”——多样化的技能被更频繁采样，获得更多训练信号，最终有效技能数下降约10倍
  • 判别器查看每个状态而非仅最终状态：提供更密集的奖励信号
  • 使用最大熵策略：迫使技能探索远离其他技能的状态空间，否则随机动作会导致进入不可区分状态
  • 网络容量：Q函数、值函数、策略均用300隐藏单元（而非SAC默认的128），作者发现这对学习多种技能是必要的

关键创新

  1. 将技能发现转化为合作博弈：与VIC的对抗训练不同，DIAYN的判别器与策略是合作关系（判别器帮助策略获得奖励，而非对抗）。这避免了对抗鞍点的不稳定性，使训练对随机种子鲁棒（图13验证）。

  2. 固定技能先验的洞察：作者通过理论分析（附录E）和实验证明，学习p(z)会导致技能坍缩。固定均匀先验看似简单，却是防止“马太效应”的关键设计，这一发现对后续无监督RL研究有直接指导意义。

  3. 可区分性与多样性的解耦：通过最大熵项，DIAYN在理论上（附录B网格世界分析）和实验上（图2、图12）证明，可区分的技能必然趋向多样化。这个因果链条是此前方法未明确建立的。

实验与结果

实验 设置 关键结果
2D导航 6个技能 技能向彼此远离移动，覆盖状态空间
经典控制 InvertedPendulum, MountainCar 无需奖励即学习解决任务，且学到多个不同解法
连续控制 HalfCheetah, Hopper, Ant 涌现跑步、跳跃、翻跟头等多样化技能
策略初始化 5个基准任务，5个随机种子 无监督预训练使所有任务学习更快
分层RL（2D导航） 25个目标，5个种子 DIAYN显著优于VIME（即使VIME最佳种子也低于DIAYN）
分层RL（Cheetah跨栏/Ant导航） 稀疏奖励 DIAYN优于TRPO、SAC、VIME
模仿学习 600个任务 DIAYN取得最低轨迹L2距离，优于"low entropy"、"few skills"、"learn p(z)"基线
探索评估 3个奖励函数 DIAYN每种任务都有技能表现良好；VIME单一策略在所有任务上表现差

关键数字： - 熵正则化 α=0.1，所有实验统一 - 技能数量：多数实验20或50个 - 训练步数：最多100万步（1000 epoch × 1000 episode） - 模仿学习失败案例：未能模仿倒立（handstand） - Ant技能中未涌现直线行走

边界与局限

  • 收敛保证缺失：作者承认在连续和近似设置中无法提供收敛保证，仅依赖经验鲁棒性
  • Ant技能缺陷：学到的大多是弧线行走而非直线，很少技能在典型前进任务上获得大奖励
  • 模仿学习失败案例：无法模仿倒立，说明技能库可能不覆盖某些专家行为
  • 技能数量扩展性：若任务所需技能随观测维度指数增长，DIAYN可能无法学到所需技能（但实验显示可扩展到111维Ant）
  • 未做之事：未在真实机器人验证；未与所有现有无奖励方法全面对比（仅对比VIME）；未提及计算成本具体数字

工程启示

  • 复现时优先核对：网络容量（300隐藏单元）和熵正则化系数（α=0.1）是两个最敏感的超参数。作者明确提到增加模型容量对学习多种技能是必要的，若用SAC默认的128单元可能复现失败。
  • 伪奖励基线不可随意移除：log p(z) 项在多数环境中是必要的，防止技能在吸收状态获得虚假奖励。只有在明确希望技能尽快终止的环境（如mountain car）才可移除。
  • 判别器条件化是扩展关键：若下游任务需要特定类型的技能（如Ant导航需要质心移动），应条件化判别器于观测的函数 f(s)，而非直接使用完整状态。这是作者明确提出的简单修改。
  • 分层RL的元控制器设计：元控制器动作是选择技能并执行k步（Ant导航k=100，Cheetah跨栏k=10），这个k值需要根据任务时间尺度调整。技能覆盖足够好时，元控制器甚至只需单步决策。
  • 最易踩坑处：学习p(z)会导致技能坍缩（有效技能数下降约10倍），务必固定为均匀分布。另外，模仿学习检索技能时用M-投影而非I-投影，保证检索到的技能会访问专家访问的所有状态。
