GenCAD-3D: CAD Program Generation using Multimodal Latent Space Alignment and Synthetic Dataset Balancing

摘要

GenCAD-3D 是一个多模态生成框架，由研究团队提出，用于从点云和网格等非参数数据自动生成 CAD 程序。其核心贡献在于利用对比学习对齐 CAD 与几何编码器的潜在嵌入，并结合潜在扩散模型进行序列生成与检索，同时引入 SynthBal 数据增强策略以平衡和扩展数据集，显著提升复杂几何体的生成质量。

概述

GenCAD-3D 提出了一种多模态 CAD 程序生成框架，通过对比学习将 CAD 程序与点云、网格等几何表示对齐到共享潜在空间，并利用条件潜在扩散模型实现跨模态生成。核心贡献在于引入 SynthBal 合成数据平衡策略，显著缓解了复杂 CAD 程序在数据集中比例失衡的问题，同时提出了序列长度归一化评估指标以更公平地衡量模型在高复杂度样本上的表现。

它改变了什么

CAD 程序生成领域长期被 sketch-and-extrude 这一受限命令集所束缚，且现有方法（如 Point2Cyl、CAD-SIGNet、TransCAD）无法推广到 revolve、fillet 等工业常见命令。更根本的问题在于，DeepCAD 等数据集存在严重的序列长度分布失衡——序列长度不超过 6 的程序占 42%，而长度超过 20 的复杂程序占比极低，导致模型训练被简单样本主导，评估指标也被过表示的长度区间所掩盖。GenCAD-3D 真正改变的是对"数据不平衡"这一核心瓶颈的处理方式：不再像 DeepCAD 的 random replacement 或 ContrastCAD 那样在训练中盲目增强，而是离线生成经过有效性验证的平衡数据集，并配合序列长度归一化指标，让复杂几何上的改进不再被平均指标淹没。此外，它首次将网格模态纳入对比对齐框架，突破了 CAD-MLLM 等依赖已有基础模型的方法无法处理网格这类未开发模态的限制。

方法拆解

三阶段架构

  1. CAD 自动编码器：使用因果 transformer（与 GenCAD 相同）将 CAD 程序 𝒞 = (𝐜₁, …, 𝐜_ℓ) 编码为连续潜在向量 𝐳_𝒞 ∈ ℝ^{d_m}，通过因果掩码保持命令顺序关系。
  2. 多模态对比对齐：对每个模态（点云、点云+法线、网格）使用专用编码器 ℰ 映射到潜在空间，通过对比损失（公式 3）对齐模态与 CAD 潜在空间。关键设计是冻结 CAD 编码器，仅训练模态编码器，使框架可扩展至大规模数据集。余弦相似度 p(𝐮,𝐯) = 𝐮ᵀ𝐯/(||𝐮||||𝐯||)，τ 为可学习温度，批次大小 B 产生 2B 个数据点，仅对应配对为正样本。
  3. 条件潜在扩散：生成模型分解为 p(𝒞|ℳ,ℰ) = p(𝒞|𝐳_𝒞) × p(𝐳_𝒞|𝐳_ℳ)，先验为基于 ResNet-MLP 的条件扩散模型（参考 gorishniy2021revisiting），损失 L = 𝔼[||ε − ε_θ(𝐳_t, t, 𝐳_ℳ)||²₂]。每个模态训练独立的先验网络。

模态编码器

  • 点云（DGCNN）：4 层动态图卷积（通道 128,128,256,512），KNN=20，拼接中间层嵌入，max+mean pooling，MLP 1024-512，dropout 0.2，2.598×10⁶ 参数。
  • 点云+法线（PC+N）：6D 输入（位置+法线），2.599×10⁶ 参数，产生均匀表面采样。
  • 网格（FeaStNet）：Feature-Steered 卷积，顶点输入 6D（位置+法线），通道 16,32,64,128,256，滤波器库 M=10，mean-pooling 降维，2.66×10⁶ 参数。

SynthBal 数据增强

  • 目标：各序列长度均匀平衡（n_ℓ^𝒮 = N^𝒮/|ℒ|），先填充比例 r 的真实数据，其余用合成数据补齐。
  • 两种操作：(1) Noise：对连续参数添加扰动（[−m·256, m·256] 均匀采样，裁剪到 [1,255]），忽略离散值（如外伸方向）；(2) Replace-Sketch：随机替换程序中的草图操作为另一程序的对应草图。
  • 选择策略：40% 概率大噪声（m=0.07, p=0.6），60% 概率小噪声（m=0.02, p=0.8）后接 Replace-Sketch。
  • 关键区别：SynthBal 在训练外生成并验证（编译为 CAD 对象且无自相交），而 DeepCAD/ContrastCAD 在训练中增强且不验证。

训练策略

  • 先在 SynthBal 数据集上训练（1000 epochs, lr=1e-3, warmup 2000），再在 reduction-balanced 真实数据集（4,503 个模型）上微调最后一层（100 epochs, lr=1e-5）。
  • 数据防泄漏：仅在同一 train/val/test 拆分内配对，评估始终在原始 DeepCAD 数据集上进行。

关键创新

  1. SynthBal 离线验证式数据平衡：与现有增强方法在训练中盲目操作不同，SynthBal 在训练外生成合成数据并验证其可编译性，将无效 CAD 生成率从 3.44% 降至 0.845%。这一设计使数据增强从"碰运气"变为"可保证质量"，且能针对长序列（高复杂度）程序定向补充。
  2. 序列长度归一化评估指标：标准指标对整个数据集取平均，被占比 42% 的短序列样本主导。m^SL(𝒳) = (1/|ℒ|)Σ_ℓ m(𝒳_ℓ) 消除了对过表示长度的偏向，使复杂几何上的改进（或失败）不再被掩盖。这是评估方法论上的重要贡献，直接影响后续研究如何报告结果。
  3. 网格模态的对比对齐：首次将网格（FeaStNet）纳入 CAD 程序生成的对比学习框架，突破了依赖已有基础模型（如 CAD-MLLM）的限制。网格感知编码器在 top-1 检索上相对点云基线提升最高 11%，且增益在大型检索规模（2048 个 CAD 模型）中最显著，表明网格模态提供了点云无法捕获的表面拓扑信息。

实验与结果

实验设置

  • 数据集：DeepCAD 178,238 个程序，编译后 168,656 个；网格重网格化后训练集从 152,530 减至 136,384。
  • SynthBal：N^𝒮=170,000（由表内数值 3.44÷89.0 计算），r=0.2（16.7% 真实复制，83.3% 合成）；SynthBal-1M：N^𝒮=1,000,000，r=0.8（13.9% 真实，86.1% 合成）。
  • 检索评估：库批大小 10/128/1024/2048，从 7,616 个测试程序 bootstrap 采样，每批平均 100 次。
  • 训练硬件：单块 H100 80GB。

结果解读

SynthBal 对长序列（高复杂度）程序的 Chamfer 距离改进最显著（最高 89%），直接验证了数据平衡策略的有效性。网格编码器在大型检索库上的优势表明，当候选集增大时，网格提供的表面拓扑信息比点云更利于区分相似几何。序列长度归一化指标揭示了未归一化指标主要反映长度 5-15 的性能，而高长度样本的性能被系统性低估。

边界与局限

论文明确将命令限制为 Line、Arc、Circle 和 Extrude，未涵盖 fillets、lofts、revolves 等工业常用命令，尽管架构不假设命令类型，但实验验证仅覆盖 sketch-and-extrude。重网格化过程产生错误导致约 10% 的训练网格被移除（152,530→136,384），可能引入选择偏差。论文未提及不同命令类型的实验结果、推理时间、模型推理频率、消融实验细节，也未提供与其他方法（如 Point2Cyl、CAD-SIGNet）在相同条件下的直接对比数字。SynthBal 的验证依赖 OpenCascade 编译，对无法编译的合成数据直接丢弃，可能过滤掉某些有意义的几何变体。

工程启示

复现时首先核对数据预处理管线：网格重网格化（MeshLab 三次中点细分+五次各向同性重网格化）是瓶颈，约 10% 的网格会因错误被丢弃，建议提前验证目标顶点数（2000-4000）与偏转参数（线性 0.001，角度 0.1）的兼容性。SynthBal 的 r 参数（真实数据填充比例）是关键超参数——r=0.2 时 83.3% 为合成数据，r=0.8 时 86.1% 为合成数据，但微调阶段必须使用 reduction-balanced 真实数据集（4,503 个模型），否则合成数据分布偏移会导致性能退化。最容易踩坑的是对比训练中冻结 CAD 编码器这一设计——若同时训练两个编码器，对比损失可能破坏 CAD 潜在空间的语义结构，导致生成阶段解码失败。评估时务必同时报告原始指标和序列长度归一化指标，否则长序列上的改进会被短序列主导的平均值掩盖。硬件需求为单块 H100 80GB，点云对比训练 300 epochs 约需数天，生成训练 1×10⁶ epochs 需数周，建议先用 SynthBal-170K 验证管线再扩展至 1M。
