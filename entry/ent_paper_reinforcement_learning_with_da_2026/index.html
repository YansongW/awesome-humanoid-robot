Reinforcement Learning with Data Bootstrapping for Dynamic Subgoal Pursuit in Humanoid Robot Navigation

摘要

本文提出一种面向双足人形机器人导航的分层框架，通过动态子目标生成实现安全实时导航。高层采用强化学习（RL）规划器在机器人坐标系中选择子目标，低层基于模型预测控制（MPC）生成稳健步态。核心贡献在于引入数据自举技术，利用基于模型的导航方法生成多样化数据集以加速训练，在Agility Robotics Digit仿真中显著提升导航成功率与适应性。

来源与参考

  • Reinforcement Learning with Data Bootstrapping for Dynamic Subgoal Pursuit in Humanoid Robot Navigation

概述

本文提出一种面向双足人形机器人导航的分层框架：高层用Soft Actor-Critic（SAC）学习动态子目标生成策略，低层用线性倒立摆模型（LIP）的模型预测控制（MPC）生成稳定步态。核心贡献在于用RRT+LMPC收集的离线演示数据引导SAC训练（data bootstrapping），显著提升样本效率与导航成功率，并在MuJoCo仿真中验证了该方法相对纯学习或纯模型方法的优势。

它改变了什么

现有双足导航框架的根本矛盾在于：几何路径规划与实时运动控制分离，导致规划轨迹与执行轨迹因模型误差和外部扰动必然产生偏差，对欠驱动双足机器人而言，微小误差即可引发失稳。基于模型的方法（如MPC/QP）虽能保证稳定性，但难以有效整合高维占据地图等环境信息，非线性耦合的航向角与转弯速率会拖慢实时计算；而纯强化学习方法虽具适应性，却因样本效率低、缺乏环境先验，在连续动作空间和复杂环境中极易收敛到次优解。

本文真正改变的是“分层但割裂”的范式——它没有简单地将RL与MPC串联，而是让高层RL规划器在局部坐标系中动态生成子目标，低层LIP-MPC在每步起始时基于降阶动力学求解线性约束二次规划（LCQP）来跟踪该子目标。这种设计将非线性优化问题线性化，使MPC计算时间从毫秒级降至亚毫秒级，同时保留了RL对环境复杂性的适应能力。更重要的是，作者用离线演示数据引导在线RL训练，解决了SAC在稀疏奖励下初始探索无效的痛点，这是从“从零学习”到“引导学习”的关键转向。

方法拆解

分层架构

  • 高层RL规划器：在机器人局部坐标系中生成动态子目标 a = (d_c, φ_c)，其中 d_c ∈ [0, 3] 米，φ_c ∈ [-π/4, π/4] 弧度，受步长与转弯能力约束。
  • 低层LIP-MPC：基于线性倒立摆模型，状态 x = [p_x, v_x, p_y, v_y, θ]^T ∈ ℝ⁵，控制输入 u = [f_x, f_y, ω]^T ∈ ℝ³（落足点位置与转弯速率）。假设恒定步长时长 T = 0.4 秒，步态间动力学离散化为 x_{k+1} = A_L·x_k + B_L·u_k。

MDP建模

  • 状态空间 s = {𝒪, p_x, p_y, v_x, v_y, θ, i_l, d_g, δθ_g, d_o, 𝒢}，其中 𝒪 为 64×64 局部占据网格（前向 4.5 米，后向 1.5 米，横向 6 米），i_l 为支撑脚指示（-1 左脚，1 右脚），d_g 与 δθ_g 为目标距离与相对航向，d_o 为最近障碍物距离。
  • 关键设计：高层规划器在每个行走步开始时生成新子目标，因此用步态起始时刻的CoM状态表示降维的步态间动力学，避免连续时间状态的高维冗余。

策略学习

  • 使用SAC算法，策略 π(a|s) = 𝒩(μ_π(s), σ_π(s))，通过最大化熵正则化累积折扣奖励学习。
  • Actor网络：CNN处理占据地图（3个卷积层，3×3核，ReLU+最大池化），输出展平后经两个全连接层降至64维，再与其余状态拼接后经四个全连接层输出高斯参数。
  • 奖励函数 r = w[r_g, r_θ, r_a, r_v, r_o]^T + R_F，权重 w = [0.2, 0.1, 0.25, 0.2, 0.25]，各子奖励归一化到 [0, 1]。终止奖励 R_F：到达目标为 60e^(-0.4·N_step/T_max) + 40，失败为 -80，超时为 -70。

数据引导（Data Bootstrapping）

  • 用RRT+LMPC收集 10,000 条状态-动作转移数据。
  • 训练早期 80% 回放缓冲样本来自离线演示，20% 来自在线交互；随训练推进逐渐过渡到 100% 在线样本，总训练 10,000 个episode。
  • 理由：SAC的离策略公式虽促进探索，但初始探索无效（很少到达目标）会阻碍收敛；演示数据将代理引向更有前景的策略空间。

关键创新

  1. 子目标方向到转弯速率的映射：将 φ_c 映射到每个预测步的转弯速率控制 ω_k = φ_c/(N·T)，使优化问题从非线性二次规划简化为线性约束二次规划（LCQP）。这一设计是计算效率提升的关键——非线性LIP-MPC平均计算时间 110 毫秒，而线性LIP-MPC仅 0.94 毫秒，差距超过两个数量级。
  2. 离线演示引导在线RL训练：不同于纯模仿学习或纯RL，该方法用RRT+LMPC的演示数据作为回放缓冲的初始种子，在训练早期以 80% 比例混合，逐步退火至纯在线。这解决了SAC在稀疏奖励下探索效率低的问题，使成功率从纯SAC的 9% 提升至 93.3%。
  3. 局部地图驱动的子目标生成：高层规划器仅依赖 64×64 局部占据网格（前向 4.5 米，后向 1.5 米，横向 6 米），而非全局地图，这使策略具备对未见环境的泛化潜力，同时避免了全局地图带来的状态空间爆炸。

实验与结果

训练与测试设置

  • 平台：Agility Robotics Digit人形机器人，MuJoCo仿真；训练硬件为Ubuntu 20.04笔记本，NVIDIA RTX 4060 GPU。
  • 训练环境：50个随机生成场景，障碍物数量为 0、1、2、6、8（各10个），目标位置随机。
  • 测试未见环境：25个新场景，每个含 8 个障碍物，目标为 (10, 10) 米。

结果解读

  • 本文方法在已见与未见环境中均显著优于纯学习基线（CQL、PPO、SAC），成功率提升 5 至 10 倍（由表内数值 9→93.3 计算）。
  • 相比纯模型方法（LMPC、RRT+LMPC），成功率提升 3.3（由表内数值 2.33÷0.7 计算） 至 9.3（由表内数值 4.64→4.2 计算） 个百分点（由表内数值 84→93.3 计算），且时间比更低，说明RL高层规划器在导航效率上优于几何路径规划。
  • PPO因on-policy性质样本效率极低，完全无法学习；SAC对转移质量高度敏感，探索中很少到达目标时易绕圈直至超时。

边界与局限

  • 所有验证均在MuJoCo仿真中完成，未在真实Digit硬件上实验，仿真与现实的差距（如执行器延迟、地面摩擦变化）可能影响结论。
  • 方法仅依赖局部地图数据，与RRT使用的全局地图不同，引入略高的方差，可能源于策略结构的固有随机性。
  • 论文未明确讨论动态障碍物场景下的表现，也未涉及多机器人协作或极端地形（如楼梯、斜坡）的导航。
  • 训练依赖RRT+LMPC生成的演示数据质量，若演示策略本身存在系统性偏差，可能限制RL策略的上界。

工程启示

  • 复现优先级：先核对数据引导的退火调度——训练早期 80% 演示数据、20% 在线数据的混合比例，以及 10,000 个episode的总训练量，这是成功率从 9% 到 93.3% 的关键变量。若跳过此步骤，SAC在稀疏奖励下几乎必然失败。
  • 计算瓶颈：低层MPC的实时性依赖 φ_c 到 ω_k 的线性映射，务必确认预测时域 N = 3 与步长时长 T = 0.4 秒的匹配关系。若调整步长或时域，需重新验证LCQP的可行性。
  • 状态设计陷阱：局部地图的尺寸（前向 4.5 米，后向 1.5 米，横向 6 米）与机器人步长（最大 3 米）需协调——若地图过小，RL规划器可能因视野不足而频繁生成不可达子目标。
  • 硬件选型参考：RL规划器推理频率 2.5 Hz（每步更新一次），MPC更新频率 20 Hz 或更高，总计算时间约 2.24 毫秒（由表内数值 0.94→1.3 计算），在RTX 4060上可满足实时要求，但部署到嵌入式平台时需优先优化CNN推理。
