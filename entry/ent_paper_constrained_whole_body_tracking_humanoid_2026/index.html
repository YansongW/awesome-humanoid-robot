人形机器人全身动作跟踪的实时约束安全控制

Constrained Whole-Body Tracking for Humanoid Robots

领域
AI 模型与算法
层级
智能层
审校
AI 全文核验

摘要

ConstrainedMimic 是一个面向人形机器人的控制框架，由研究团队提出，旨在强化学习跟踪策略中实时强制执行运动学与动力学约束。其核心贡献在于融合操作空间控制与控制障碍函数（CBFs），在保持策略能力的同时实现碰撞避免、关节限位与质心稳定性等约束，且支持 CPU、GPU 与 TPU 部署，运行频率可达 300-500 Hz。

概述

本文提出 ConstrainedMimic，一个在运行时对预训练 RL 全身控制器施加任意安全约束（碰撞避免、关节限位、CoM 稳定性）的框架，不修改策略本身。作者在 Unitree G1 仿真平台上，通过约束重定向、运动学滤波器和动力学滤波器三个干预点，将 CBF 与接触约束动力学/运动学结合，实现了 250 Hz 的实时安全滤波，将自碰撞违规帧率从约 37% 降至接近 0%。

它改变了什么

现有 CBF 在人形机器人上的应用要么使用降阶双积分器模型（忽略真实接触动力学），要么只针对下肢 locomotion 而非全身跟踪。更关键的是，它们都试图修改策略本身或要求策略感知约束，这与“训练后任意指定约束”的工程需求背道而驰。本文真正改变的是安全干预的位置——从策略内部移到策略外部，在输入（运动学参考）和输出（关节指令）两个端口做滤波，从而实现了策略无关性和最小侵入性。

这解决了两个实际问题：一是预训练策略（如 TWIST2、SONIC）在部署时无法重新训练，但安全约束往往在部署时才明确；二是现有 CBF 方法在接触丰富的全身任务中，因未建模接触约束而导致脚滑、违反运动学一致性。本文通过将 CBF 建立在接触约束零空间上，让安全滤波尊重当前接触模式，这是对“安全滤波会破坏任务执行”这一固有矛盾的一次实质性回应。

方法拆解

总体架构

在 RL 运动跟踪栈中识别两个干预点：策略输入（运动学参考）和策略输出（关节指令），对应三种方法： 1. 约束重定向（Constrained Retargeting）：在 IK 重定向器内部加 CBF 2. 运动学滤波器（Kinematic Filters）：对重定向后的参考运动滤波 3. 动力学滤波器（Dynamic Filters）：对策略关节指令滤波

核心建模

  • 接触约束运动学：q̇ = N_c q̇₀，其中 N_c = I − J̄_c J_c 为接触零空间投影，保证滤波后的速度不破坏接触（脚不滑动）
  • 接触约束动力学：M q̈ + N_c^T(c + g) + J_c^T μ_{c,J̇} = N_c^T Γ，用于动力学滤波器的加速度级约束
  • CBF 条件：对控制仿射系统 ż = f(z) + g(z)u，要求 L_f h(z) + L_g h(z)u ≥ −α(h(z))，保证安全集前向不变

三种滤波器的 QP 结构

  • 约束重定向：最小化 Σ ||W_i(J_{i|c} u − ν_i)||₂²，14 个成对任务加权，受 CBF 约束、关节速度边界和松弛变量约束
  • 运动学滤波器：分层目标——主任务跟踪非接触末端执行器和 CoM 操作空间运动，次任务跟踪零空间姿态，QP 为 ||[W_t J_{t|c}; W_n N_{t|c}](q̇ − q̇_nom)||₂²
  • 动力学滤波器：三层分层——接触力跟踪 > 运动跟踪 > 姿态跟踪，求解力矩 Γ_body*，但因 Unitree G1 接口限制，映射回 PD 目标（公式 13）而非直接发送力矩

关键设计决策

  • 接触估计启发式：基于两脚相对高度和速度阈值判断接触模式（4 种离散模式），隐式假设模式 0（无接触）不发生
  • 离散时间处理：在线控制每时间步仅单步 diff IK，避免多步积分导致 ḣ(z) 表示错误
  • 松弛变量：QP 中引入松弛变量 t 处理约束冲突，目标为 ‖u − u_nom‖₂² + ρ^T t，牺牲严格保证换取可行性

关键创新

  1. 接触约束一致的 CBF 设计：现有 CBF 在人形机器人上使用降阶模型，本文首次将 CBF 建立在完整接触约束运动学/动力学上（N_c 投影），确保安全滤波不破坏接触模式。这是对“安全滤波导致脚滑”这一核心问题的直接回应。

  2. 三端口干预框架：在策略输入（重定向）、输入后（运动学滤波）、输出后（动力学滤波）三个位置提供安全干预，且可组合使用。这种“分层安全”设计允许用户根据计算预算和任务需求选择干预深度，而非一刀切。

  3. 任务一致的分层 QP 结构：滤波器 QP 的目标函数与全身运动跟踪的隐式任务层级一致（接触力 > 运动 > 姿态），约束激活时优先修改低优先级组件，最小化对任务执行的干扰。这是“最小侵入性”原则的具体实现。

实验与结果

实验在 Unitree G1 仿真中进行，使用未修改的 TWIST2 和 SONIC 策略，100 次试验随机化 CBF 参数（桌高、播放速度 0.5–2.0 倍）。

实验 方法 违规帧占比 (%) 最大违规 (mm)
自碰撞 基础策略 37.59 / 37.68 97.43 / 100.41
自碰撞 运动学安全 8.47 / 7.49 12.11 / 52.91
自碰撞 动力学安全 0.35 / 1.24 0.50 / 0.43
自碰撞 运动学+动力学 0.02 / 0.00 0.03 / 0.00
空手道 基础策略 20.59 / 18.89 424.43 / 253.07
空手道 运动学安全 12.55 / 7.59 100.28 / 64.59
空手道 动力学安全 0.28 / 3.10 0.09 / 5.98
空手道 运动学+动力学 0.05 / 0.29 0.02 / 0.25

关键结论：动力学滤波器单独即可将违规降至 ~1%（由表内数值 2.2÷2.3 计算） 以下，运动学+动力学组合几乎完全消除违规（<0.3%（由表内数值 3.1−3.4 计算））。但运动学滤波器单独在空手道实验中表现不佳（最大违规 100 mm），说明动力学层面的安全干预对高速动态任务不可或缺。

性能方面：约束重定向最高 300 Hz，运动学滤波器 2000 Hz，动力学滤波器 500 Hz；实验中动力学滤波器以 250 Hz（5 倍策略频率）运行，在 Jetson Orin Nano 上也能满足实时性。

边界与局限

  • 未做硬件实验：仅在仿真中验证，未在真实 Unitree G1 上测试；作者承认执行器不完美、惯性标定误差、接触估计不可靠会降低 CBF 硬件部署性能
  • 动力学滤波器仅在双支撑（模式 3）下评估：单脚或无接触模式下的动态滤波未探索，接触估计启发式隐式假设模式 0 不发生
  • 未考虑扰动：设计目标是尽量减少对 RL 策略恢复行为的干预，但未考虑会导致摔倒的外部扰动
  • 分布偏移：动力学滤波器可能导致策略输入分布外（OOD），作者未量化此效应
  • 机载感知：假设环境中碰撞体状态和几何形状已知，未使用机载感知数据
  • QP 可行性：大量 CBF 与输入约束冲突时 QP 可能不可行，松弛变量只能“执行但不保证”安全性；离散时间采样在低采样率（~50 Hz）下可能导致边界附近违反或抖动

工程启示

复现或部署时，先核对以下几点：

  1. 接触估计是最大风险点：启发式基于两脚相对高度和速度阈值，对平面接触和典型行走运动假设合理，但若任务涉及腾空或非平面接触，需替换为更鲁棒的估计器。动力学滤波器目前仅在双支撑下验证，单脚接触时 S N_c 可能不满秩（伪逆处理），需额外注意数值稳定性。

  2. 动力学滤波器的力矩映射是平台相关的：Unitree G1 接口限制导致必须将安全力矩映射回 PD 目标（公式 13），这会引入额外延迟和近似误差。若目标平台支持直接力矩指令（如 TORO 的 1 kHz），应优先使用直接力矩模式。

  3. 采样率决定 CBF 有效性：作者指出 ~1000 Hz 时离散时间差异可忽略，~50 Hz 时可能导致明显违反或抖动。动力学滤波器以 250 Hz（5 倍策略频率）运行是安全下限，若计算预算紧张，优先保证动力学滤波器频率而非运动学滤波器。

  4. 组合使用优于单独使用：运动学+动力学组合将违规降至 0.00–0.29%，而单独动力学滤波器仍有 0.35–3.10% 违规。若任务对安全要求极高，不要省略运动学层。

  5. JAX 实现细节：单线程运行（intra_op_parallelism_threads=1）在 ROS2 多节点栈中性能更好；启用 JAX_ENABLE_x64=1 避免数值精度问题；所有函数调用需 jax.block_until_ready() 避免异步调度计时误差。
