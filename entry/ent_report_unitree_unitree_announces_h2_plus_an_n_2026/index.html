摘要

Unitree Robotics 发布了 H2 Plus，这是一款面向学术研究的 NVIDIA Isaac GR00T 参考人形机器人。该机器人集成了 Unitree H2 本体、Sharpa 五指灵巧手、NVIDIA Jetson Thor 计算平台以及全新的 Isaac GR00T 开发平台，旨在加速人形机器人的研发流程。

概述

Unitree Robotics 推出的 H2 Plus 是一款专为学术研究设计的 NVIDIA Isaac GR00T 参考人形机器人。它融合了 Unitree H2 人形机器人的运动能力与 Sharpa 五指灵巧手，实现了精细操作。其核心计算单元为 NVIDIA Jetson Thor，负责高级推理与控制。此外，全新的 NVIDIA Isaac GR00T 开发平台覆盖了从数据采集与生成到模型评估与部署的全流程，能够帮助开发者显著加快人形机器人的开发工作。

核心内容

产品概述

Unitree Robotics 正式发布 H2 Plus，这是一款基于 NVIDIA Isaac GR00T 参考架构的人形机器人，主要面向学术研究领域。

核心组件

  • 本体：采用 Unitree H2 人形机器人作为基础平台。
  • 灵巧手：配备 Sharpa 五指灵巧手，具备精细操作能力。
  • 计算平台：搭载 NVIDIA Jetson Thor，提供高级推理与控制能力。
  • 开发平台：集成全新的 NVIDIA Isaac GR00T 开发平台。

开发平台功能

Isaac GR00T 开发平台覆盖了人形机器人开发的全流程，包括： - 数据采集与生成 - 机器人模型评估 - 模型部署

该平台旨在帮助开发者加速人形机器人的开发工作流程。
