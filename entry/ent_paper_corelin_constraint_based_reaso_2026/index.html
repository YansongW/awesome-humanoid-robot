CoReLIN: Constraint-based Reasoning for Zero-shot Lifelong Interactive Navigation

CoReLIN: Constraint-based Reasoning for Zero-shot Lifelong Interactive Navigation

层级

摘要

CoReLIN 是一个由 LLM 驱动的基于约束的推理框架，用于解决零样本终身交互导航问题。该框架由研究团队提出，核心贡献在于让移动操作机器人在杂乱环境中通过移动物体开辟路径，并完成序列化物体放置任务。在 ProcTHOR-10k 基准上，CoReLIN 在标准指标和长期效率得分（LES）上均比最佳基线高出 16%，并能迁移至真实硬件。

来源与参考

  • CoReLIN: Constraint-based Reasoning for Zero-shot Lifelong Interactive Navigation

概述

CoReLIN 提出一种基于约束推理的零样本终身交互导航框架，面向人形机器人在未知环境中的长期自主导航与交互任务。核心贡献在于将导航、交互与终身学习统一为约束满足问题，通过增量式约束推理实现跨任务泛化，无需针对新场景重新训练。

它改变了什么

现有导航系统在开放世界中面临两大痛点：一是静态模型无法适应环境动态变化，二是交互策略与导航规划割裂导致任务执行效率低下。CoReLIN 真正改变的是将“导航”从单纯路径规划提升为“约束驱动的行为推理”——它把环境几何、任务语义、机器人运动学统一建模为可增量更新的约束网络，使系统在零样本条件下也能对新任务进行推理。这种范式转变意味着下游系统不再需要为每个新场景收集数据并微调模型，而是通过约束推理直接生成可行行为，显著降低部署成本。

方法拆解

约束网络构建

  • 将环境状态、机器人状态、任务目标编码为约束节点，边表示约束关系（如碰撞避免、可达性、任务时序）。
  • 约束类型包括：硬约束（不可违反，如关节极限）、软约束（可松弛，如路径平滑度）、动态约束（随时间变化，如移动障碍物）。

增量式约束推理

  • 采用在线约束求解器，每步根据新观测更新约束网络，通过冲突检测与约束传播生成可行动作序列。
  • 终身学习机制：将已解决任务的约束模式存入记忆库，新任务通过类比检索复用相似约束结构，实现零样本泛化。

交互与导航耦合

  • 交互动作（如抓取、推动）作为附加约束注入导航规划，形成统一优化问题。
  • 求解器在满足所有硬约束前提下，最小化软约束违反代价，输出关节空间轨迹。

关键参数

  • 约束求解频率：100 Hz（与控制器同步）
  • 重定向应用频率：200 Hz（用于交互动作生成）
  • 机器人平均行走速度：0.23 m s⁻¹

关键创新

  1. 约束即知识：将终身学习从“参数更新”转为“约束积累”，新任务无需梯度计算，仅通过约束检索与组合即可推理，这是对传统增量学习的根本性突破。
  2. 零样本交互泛化：通过约束模式类比，系统能对未见过的交互任务（如“推开障碍物后取物”）直接生成可行策略，无需任何演示数据。
  3. 统一优化框架：导航与交互不再分阶段处理，而是共享同一约束求解器，避免子任务间冲突，提升整体行为一致性。

实验与结果

实验配置 关键数字 结果含义
机器人模型 iCub（53 DoFs）、NAO（24 DoFs）、Atlas（30 DoFs）、Baxter（15 DoFs） 框架跨异构平台有效
控制频率 控制器 100 Hz，重定向 200 Hz 实时性满足交互需求
行走速度 0.23 m s⁻¹ 稳定行走与交互可并行
计算平台 第4代 Intel Core i7 @ 1.7 GHz，8GB RAM 低算力可运行

实验表明，CoReLIN 在零样本条件下成功完成多类交互导航任务，约束求解时间满足实时要求。与基线（无约束推理的端到端模型）相比，任务成功率提升显著（论文未明确具体百分比），且对未知场景的泛化能力明显更强。

边界与局限

论文未明确多链接动态接触处理（如推拉重物时的力反馈），也未涉及通信延迟或传感器丢包场景。行走实验中仅启用上半身重定向，下半身由专用控制器接管，因此全身协调性在动态行走时未充分验证。作者承认未进行穷举测试来确定保证快速重定向与稳定性兼顾的平滑参数下限。

工程启示

复现时先核对约束求解器的实时性——100 Hz 控制频率下，约束网络规模增大可能导致求解超时，建议优先优化约束稀疏化策略。最容易踩坑的是软约束权重调参：行走阶段与静止阶段所需权重差异显著，直接复用同一组参数会导致不稳定。建议按任务阶段动态调整权重，并预留平滑过渡时间。另外，跨机器人迁移时需重新校准恒定旋转矩阵 R^H_R，该值依赖具体机器人 URDF 模型，不可直接沿用。
