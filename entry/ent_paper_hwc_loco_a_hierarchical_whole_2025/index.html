HWC-Loco: A Hierarchical Whole-Body Control Approach to Robust Humanoid Locomotion

摘要

HWC-Loco 是 2025 年提出的一种面向人形机器人行走任务的鲁棒全身控制算法。该工作通过将策略学习重构为鲁棒优化问题，并引入分层策略动态平衡目标追踪与安全恢复，显著提升了机器人在训练与部署环境差异下的鲁棒性。实验表明，HWC-Loco 在多种地形、机器人结构和行走任务中均优于现有模型。

来源与参考

  • HWC-Loco: A Hierarchical Whole-Body Control Approach to Robust Humanoid Locomotion (arXiv)

概述

HWC-Loco 提出一种分层全身控制框架，用于提升人形机器人在模拟与真实环境中的运动鲁棒性。该方法通过高层策略动态协调目标跟踪策略与安全恢复策略，将策略学习形式化为带约束的鲁棒优化问题，并利用 ZMP 动态约束与对抗模仿学习实现自然且安全的运动。核心贡献在于显式建模目标跟踪与安全恢复之间的权衡，而非依赖静态保守策略或过度正则化。

它改变了什么

现有端到端强化学习方法在 Sim2Real 迁移中面临根本性困境：过度正则化损害策略效率，非结构化域随机化无法捕捉真实世界中的安全关键模式，而传统鲁棒优化（max-min）只关注最坏情况导致策略过于保守。作者敏锐地指出，问题不在于单一策略能否同时兼顾任务完成与安全恢复，而在于这两种目标本质上是动态冲突的——高速跟踪命令时必然牺牲部分稳定性裕度，而过度追求安全则使机器人无法完成任务。

HWC-Loco 真正改变了这一格局：它将“一个策略应对所有情况”的范式，转变为“多个专业化策略 + 一个高层仲裁者”的分层架构。目标跟踪策略专注于任务性能，安全恢复策略专注于极端情况下的稳定性，高层策略则根据当前状态动态权衡。这种分解使得每个低层策略的训练目标更加清晰，避免了单一策略在任务与安全之间妥协导致的次优行为。更重要的是，作者将问题形式化为约束 RL 而非惩罚加权，消除了对手部或腿部姿态的显式正则化需求，显著增强了全身运动策略的表达能力。

方法拆解

问题形式化

环境建模为 POMDP M = (𝒮, 𝒜, 𝒪, P_𝒯, r, μ₀, γ)，动作 a ∈ 𝒜 为 PD 控制器目标关节角度。观测 o_t 包含速度命令 v_t^cmd ∈ ℝ³ 与本体感觉 o_t^p，状态 s_t = [o_t^H, ℙ_t] 包含时序观测与特权信息（基座速度、地形高度、外部扰动、ZMP 特征）。

约束 RL 公式

最大化任务奖励 r_𝔗，同时满足两个约束： - 模仿学习约束：𝒟_f(ρ_M^πE ∥ ρ_M^π) ≤ ε_f，采用 Wasserstein-1 距离（Kantorovich-Rubinstein 对偶）实现，判别器 f_d 带梯度惩罚 β·𝔼[(‖∇x̂ f_d(x̂)‖₂ - 1)²] 保证 Lipschitz 连续性。选择 Wasserstein 而非 KL/JS 是因为后者在支撑集重叠有限时失效。 - 可行性约束：𝔼[φ(τ)] ≥ ε_φ，其中 φ(s,a) = ‖p_ZMP(s,a) - p_ac‖₂，p_ZMP 基于线性倒立摆模型计算：p_ZMP(s,a) = p_CoM(s,a) - (z_CoM(s,a)/g)·p̈_CoM(s,a)。

目标跟踪策略 π₁

利用零对偶间隙性质将约束 RL 转化为无约束目标：max_π₁ 𝔼[Σγ^t·[r_𝔗(s_t,a_t) - λ·f_d(s^d)]]，使用 PPO 更新，判别器与策略交替训练。专家数据来自 CMU MoCap 数据集（318 个序列，总计 3729.18 秒），重定向至 H1/G1 机器人骨架。

安全恢复策略 π₂

目标为 max_π₂ min_{P̂_𝒯 ∈ 𝔓_α^L} 𝔼[Σγ^t·(r_𝔗 - λ·f_d)]，不确定性集 𝔓_α^L 通过四种极端情况构建： 1. 多尺度外部力/力矩（力 ±200 N，力矩 ±200 Nm，更新频率 1 Hz） 2. 本体感觉与 PD 增益随机高强度噪声 3. 恶意速度命令重采样（更新频率 5 Hz，地形课程过半时激活） 4. 域随机化（摩擦 [0.6, 2.0]、基座质量 [-1.0, 5.0]、电机强度 [0.8, 1.2] 等）

高层规划策略 π₀

使用 Double-DQN 学习离散动作（选择激活哪个低层策略），目标函数为 max_π₀ 𝔼[Σγ^t·[r_𝔗(s_t, ā_t) - 𝟙(ā_{t-1} ≠ ā_t) - α·𝟙(s_t)]]，其中切换惩罚系数 λ_switch = 0.001，α 调节安全与任务权衡。超参数：Batch Size 128，Learning Rate 1e-4，Gamma 0.99，Replay Buffer 2000000，Target Update Frequency 50。

部署推断

训练基于特权信息 ℙ_t，通过 VAE 估计器 P(e_t, z_t|o_t^H) 推断，引入频率编码增强 φ(·) 表示，使用可学习先验而非零均值高斯。Actor 网络采用编码器提取逐时间步特征，合并网络整合后输入主干网络。

关键创新

1. 分层策略分解取代单一策略妥协：将目标跟踪与安全恢复分离为独立策略，由高层策略动态仲裁。这一设计从根本上避免了单一策略在任务性能与安全裕度之间的内在冲突，使得每个低层策略可以专业化训练，无需在目标函数中手动平衡两类奖励。

2. 约束 RL 公式消除显式正则化：通过模仿学习约束（Wasserstein 距离）与可行性约束（ZMP 动态）替代传统的手部/腿部姿态正则化。这不仅减少了人工调参负担，还显著增强了全身运动策略的表达能力——策略可以自由探索更多样的运动模式，只要满足约束即可。

3. 极端情况不确定性集构建：不同于传统域随机化的无差别扰动，作者针对安全关键场景（外部冲击、传感器故障、恶意指令）构造结构化不确定性集，使恢复策略在训练中显式学习这些危险模式，而非寄希望于随机化碰巧覆盖。

边界与局限

作者主要关注转换动态中的不匹配（Definition 3.1），指出状态-动作空间差异和初始状态分布 μ₀ 也可能影响部署性能，但认为人形运动任务中大部分 Sim2Real 因素可由转换动态不匹配表征。论文未明确讨论上半身操作任务与运动控制的耦合问题，仅提及未来方向为集成操作技能。此外，α = 200 时训练不稳定表明高层策略的权衡参数存在有效范围，超出后恢复策略被忽视导致过度保守行为。真实部署仅在 Unitree H1/G1 上验证，其他硬件平台的泛化性论文未明确。

工程启示

复现 HWC-Loco 时，首先核对 ZMP 计算所需的支撑多边形中心 p_ac——这是每个机器人特定且预先已知的，错误设置会直接破坏可行性约束。其次，高层策略训练需要先加载两个已训练的低层策略生成数据，训练顺序不可颠倒。最容易踩坑的是极端情况不确定性集的构建：外部扰动力矩范围 ±200 Nm 与更新频率 1 Hz 需要根据目标机器人关节力矩限制调整，否则恢复策略可能学习到不切实际的响应。域随机化参数中电机强度缩放 [0.8, 1.2] 与动作延迟 [0, 5] 对真实部署影响显著，建议优先调试。高层策略的切换惩罚系数 λ_switch = 0.001 较小，若发现策略频繁切换可适当增大；α 建议从 20 开始调试，避免直接使用 200 导致训练不稳定。
