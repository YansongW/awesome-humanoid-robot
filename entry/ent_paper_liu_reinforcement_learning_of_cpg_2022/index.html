软体蛇形机器人CPG调节 locomotion 控制器的强化学习

Reinforcement Learning of CPG-regulated Locomotion Controller for a Soft Snake Robot

领域

层级
智能层中游上游
审校

摘要

本文提出一种用于软体蛇形机器人的仿生级联控制器，结合无模型强化学习（PPOC/option框架）与Matsuoka中枢模式发生器（CPG），实现目标追踪与平滑节律性气动驱动。该设计在仿真与真实实验中验证了最优性与鲁棒性，并通过与先进RL方法的对比凸显其优势。

来源与参考

  • Reinforcement Learning of CPG-regulated Locomotion Controller for a Soft Snake Robot

概述

本文提出 ERIQ 基准与 FACT 动作分词器，旨在解耦具身推理与精确控制，并通过 GenieReasoner 系统统一训练。核心贡献在于用 flow-matching 解码器替代传统离散 token 重建，在保持 VLM 推理能力的同时提升动作精度，在 ERIQ 上实现 41% 准确率提升。

它改变了什么

现有 VLA 模型的根本矛盾在于推理与执行的目标冲突：离散 token 适合语义规划但精度不足，连续回归适合控制但泛化受限。作者没有继续在单一表征上做折中，而是将问题拆解为“推理用离散、执行用连续”两个独立环节，这改变了以往“一个模型端到端输出动作”的设计范式。

ERIQ 基准的提出同样关键——现有评估要么只测空间理解（如 RoboSpatial），要么只测任务成功率，缺乏对错误恢复、人类意图等闭环推理维度的覆盖。作者用 6,052 个真实世界 QA 对填补了这一空白，使推理能力的评估不再依附于执行结果。

方法拆解

ERIQ 基准构建

  • 数据来源：全部来自真实机器人试验，第一人称视角，覆盖 100+ 任务场景
  • 领域分布：household 35%、restaurant 20%、supermarket 20%、industrial 15%、office 10%
  • 模态分布：Single Image 53%、Sequential Images 26%、Interleaved Image–Text 21%
  • 任务格式：标准化多项选择或二元（Yes/No），覆盖四个推理维度、15 个子任务

FACT 动作分词器

  • 编码器：MM-DiT 架构，patch size 1，零初始化查询 e_ini 与动作特征交互，公式 e = ℰ_θ(a_{0:H}, e_ini)
  • 量化：lookup-free 位级量化，c = sign(e)，码本为 {−1, +1}^{L×D}
  • 解码器：Rectified Flow 目标，线性插值 a^(t) = (1−t)z + ta，目标速度 v^(t) = a − z
  • 训练损失：熵损失 + 承诺损失 + flow-matching MSE 损失
  • 推理：VLM 自回归预测离散码 ĉ，解码器通过 ODE 数值积分从高斯噪声重建连续轨迹

GenieReasoner 训练

  • 将动作预测视为 next-token 任务，与 VLM 骨干联合训练
  • 第二阶段纳入 General VQA 数据以保留基础视觉-语言知识

关键创新

  1. 推理与执行解耦：FACT 将细粒度运动生成的负担从离散潜在分辨率转移到生成式解码过程，使 VLM 在紧凑离散空间规划，同时通过 flow-matching 恢复高保真连续控制。这是首次将生成式解码用于 VLA 动作 token 重建。

  2. ERIQ 基准的维度完整性：唯一同时覆盖 Spatial、Plan、Error、Human Intent 四个推理维度的基准，且全部数据来自真实世界试验而非仿真，避免了合成数据与真实分布的偏差。

  3. 位级量化的简洁性：lookup-free 量化（c = sign(e)）无需码本学习，避免了 VQ-VAE 的码本崩溃问题，同时保持离散表征的稳定性。

Ours-3B 在 Task Grd. 与 Rel. Pos. 上超越所有基线，包括参数量更大的 Qwen3-VL-8B（93.21 vs 88.27，77.51 vs 67.07）。摘要提及相比 π0-FAST 显著降低重建 MSE，并在真实世界任务中优于 flow-based 基线 π0.5，但具体数值论文未明确。

边界与局限

论文未明确列出 GenieReasoner 自身的局限性。从方法看，FACT 解码器依赖 ODE 数值积分，推理延迟可能高于直接回归；位级量化虽避免码本崩溃，但可能限制动作表征的表达范围。ERIQ 基准虽覆盖多领域，但未包含动态环境或人机协作场景，且所有数据来自固定任务集，泛化性需进一步验证。

工程启示

复现时先核对 FACT 编码器的时间压缩比（L ≤ H）与空间压缩比（D ≤ S），这直接影响离散 token 长度与重建精度。训练时注意熵损失权重——过小会导致码本使用率低，过大则可能破坏动作连续性。推理阶段需测试 ODE 求解步数对延迟的影响，实际部署时可能需要在精度与实时性间权衡。下游团队若已有 VLM 骨干，可直接替换动作头为 FACT 解码器，无需重新训练整个模型。
