摘要

本文介绍了2024年发布的Zeroth Bot项目，其核心贡献在于提出了一套面向人形机器人的开源硬件设计方案。该工作旨在降低人形机器人研发的硬件门槛，通过提供可复制的机械结构与电子系统设计，为学术界与工业界在仿人机器人领域的探索提供了基础平台。Zeroth Bot的设计聚焦于关键组件的集成与优化，体现了从概念验证向实用化硬件迈进的研究动机。

来源与参考

  • 2024.11, Zeroth Bot project page

概述

DreamVLA 是一个面向长时程多步操作任务的视觉-语言-动作（VLA）框架，通过动态区域引导的世界知识预测与块状结构化注意力机制，实现感知-预测-动作的闭环推理。在 CALVIN ABC-D 基准与真实机器人任务上达到 state-of-the-art 性能，核心贡献在于将预测目标从重建转向前瞻性世界知识，并设计解耦的注意力结构抑制跨模态噪声。

它改变了什么

现有 VLA 模型在长时程操作中普遍存在"前几步准确、后续动作漂移"的退化现象，根本原因在于动作解码器缺乏对物理世界演化的前瞻性表征——它们要么直接回归动作，要么用重建当前帧的方式间接学习，而这两者都无法为多步推理提供稳定的中间变量。DreamVLA 真正改变的是将"预测什么"这一问题的答案从"重建过去"转向"预测未来"：不是让模型记住当前场景长什么样，而是迫使它回答"接下来哪里会动、深度如何变化、语义如何演进"。这一转向把世界模型从辅助正则项提升为动作规划的主干信号，使每一步决策都建立在未来状态的显式估计之上。

另一个关键改变在于注意力机制的拓扑结构。vanilla causal mask 允许同一步骤内不同模态的 token 互相读取，这在单步任务中无伤大雅，但在多步推理中会引入跨类型知识泄漏——flow、depth、语义信号在注意力层内混合，梯度噪声随步数累积，最终导致长时程控制崩溃。DreamVLA 通过块状稀疏掩码彻底切断 query-to-query 边，让动作 query 只能访问历史信息，这一设计选择直接对应了 Table 6 中 Avg. Len. 从 3.75 到 4.44 的提升，说明问题不在模型容量而在信息流拓扑。

方法拆解

动态区域引导的知识预测

  • 使用预训练光流模型生成二值掩码，标记"哪里"发生相关运动，而非预测完整光流场。
  • 模型聚焦于动态区域、深度图、语义特征三类未来知识，作为动作规划的中间表征。
  • 关键设计决策：预测完整世界知识而非辅助重建。消融显示，重建当前 RGB、深度、语义或 DINOv2 特征均导致性能持续下降，因为重建仅回顾控制策略不需要的背景细节，而预测提供面向动作的前瞻信号。

块状结构化注意力机制

  • 稀疏注意力掩码移除所有 query-to-query 边，使 < action > query 仅查询过去的语言、状态和多模态预测，绝不读取同一步骤的兄弟 token。
  • 对比 vanilla causal mask：后者允许 < dream > query 读取同一步骤产生的 flow 和 depth token，导致额外交叉窥视混合不相关信号、增加梯度噪声，快速退化长时程控制。
  • 实现方式：在扩散-Transformer 解码器中应用该掩码，保持训练与推理一致的注意力拓扑。

分离 query 设计

  • 为动态区域、深度、语义分别分配独立 query，而非共享一组 query 再切分为子空间。
  • 共享设计将每个世界嵌入向量分成四个等长子空间，模态混合引入串扰，使扩散头接收噪声特征。
  • 分离 query 保持表征解耦，Table 7 显示 Avg. Len. 从 4.17 提升至 4.44。

query 数量选择

  • 每组分配 K 个 query，考察 K ∈ {4, 9, 16}。
  • K=4 容量不足，无法编码细粒度运动、几何和语义；K=9 在带宽与骨干负载间取得平衡，获得最佳成功率与最长连续任务执行；K=16 引入冗余 token，竞争注意力并增加 GPU 内存，无额外收益且泛化略降。
  • 最终选择 K=9。

关键创新

  1. 从重建到预测的范式转移：将 VLA 的辅助目标从"重绘当前帧"改为"预测未来动态区域、深度、语义"。这不是简单的损失函数替换，而是改变了模型学习到的表征语义——预测迫使模型编码因果演化规律，而重建只鼓励记忆静态外观。消融中每种重建替换均持续降低性能，且重建模型"能处理前几步但很快失去连贯性"，说明预测目标直接支撑了多步推理的稳定性。

  2. 注意力拓扑的结构性约束：块状稀疏掩码切断同步骤 query-to-query 边，这一设计在技术层面极其简单，但效果显著（Avg. Len. 3.75→4.44）。其创新性在于识别出"信息泄漏"而非"信息不足"才是长时程退化的主因，并用掩码而非更复杂的机制解决。这为后续 VLA 架构设计提供了新思路：注意力不是越稠密越好，任务相关的稀疏性可能更优。

  3. 动态区域掩码替代完整光流预测：用二值掩码聚焦"哪里在动"，而非预测完整光流场。这大幅降低训练复杂度（光流预测变体成功率明显降低），同时保留了对动作规划最关键的运动位置信息。这是一种"最小充分表征"的设计哲学，避免了预测冗余细节带来的优化负担。

边界与局限

  • 当前范围狭窄，主要练习平行夹爪操作，未涉及灵巧手或复杂抓取策略。
  • 依赖以 RGB 为中心的数据，未融合 3D 点云、触觉等模态。
  • 训练场景的几何和材质多样性有限，泛化到全新环境的能力未经充分验证。
  • 论文未明确：真实世界实验的具体任务数量、场景复杂度、失败模式分析；CALVIN 基准上与其他 SOTA 方法的精确对比数字；结构化注意力在不同骨干网络（非扩散-Transformer）下的普适性。

工程启示

复现或应用 DreamVLA 时，优先核对三个关键点：第一，动态区域掩码的质量直接决定知识预测的上限——如果预训练光流模型在目标场景上表现不佳，建议先微调光流模型或改用其他运动估计方法，否则二值掩码会引入噪声而非聚焦信号。第二，结构化注意力的实现必须严格保证 < action > query 不访问同步骤任何 token，这一约束在分布式训练或梯度检查点开启时容易被意外破坏，建议在注意力层添加显式掩码断言。第三，query 数量 K=9 是在 CALVIN 场景下调优的结果，迁移到更复杂任务时需重新扫描 K ∈ {4, 9, 16}，注意 K=16 时 GPU 内存增加且泛化下降，说明并非越多越好。最可能踩坑的地方在于共享 query 与分离 query 的实现差异——如果沿用共享设计再切子空间，会引入模态串扰，导致扩散头接收噪声特征，性能退化程度与 Table 7 中 Shared 列相当。
