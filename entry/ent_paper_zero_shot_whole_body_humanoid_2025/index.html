Zero-Shot Whole-Body Humanoid Control via Behavioral Foundation Models

Zero-Shot Whole-Body Humanoid Control via Behavioral Foundation Models

层级

摘要

Zero-Shot Whole-Body Humanoid Control via Behavioral Foundation Models 是2025年关于人形机器人物理动画的工作。该研究提出Meta Motivo，首个基于行为基础模型的人形机器人控制器，通过无监督强化学习与无标签行为数据集实现零样本全身控制。核心贡献在于Forward-Backward Representations with Conditional-Policy Regularization算法，使模型能同时处理运动跟踪、目标到达和奖励优化等多种任务。

来源与参考

  • Zero-Shot Whole-Body Humanoid Control via Behavioral Foundation Models (arXiv)

概述

本文提出 Moxin 7B 系列模型，以 Model Openness Framework (MOF) 为准则，追求训练数据、实现细节与权重的完全透明，对抗“openwashing”。核心贡献在于三个变体：Moxin-VLM（视觉-语言）、Moxin-VLA（视觉-语言-动作）与 Moxin-Chinese（中文能力），其中 VLA 变体在 LIBERO 模拟基准上以 9B 参数达到平均成功率 91.95%（带机器人预训练）与 92.5%（无预训练），超越同量级基线。

它改变了什么

它改变的不是“又出了一个 7B 模型”这件事，而是把“开源”从口号拉回到工程现实。当前领域里大量模型只公开权重，训练数据、数据配比、微调配方全部隐藏，导致复现者面对黑盒，下游研究者无法判断性能差异来自架构还是数据。Moxin 的定位是“可审计的模型”，MOF 框架要求训练集、代码、检查点、评估协议全部可见，这直接动摇了“openwashing”的生存空间——当别人还在用权重下载量证明开放性时，Moxin 把证据链摆在了桌面上。

更实质的变化在 VLA 训练策略上。作者没有简单套用 OpenVLA 的自回归动作预测，而是引入并行解码与动作分块（action chunking），一次性预测多未来时间步动作块。这看似是工程细节，实则改变了延迟与时间一致性的权衡：自回归逐 token 预测在机器人控制中会累积抖动，而分块预测让动作序列在时间上更平滑。另一个关键决策是 FiLM 模块在单臂设置下被排除——作者明确承认该模块在单臂机器人上无益，这种“负结果透明化”在论文中极为罕见，恰恰是 MOF 精神的体现。

方法拆解

Moxin-VLM：双视觉骨干融合

  • 视觉特征提取采用 DINOv2 与 SigLIP 双骨干，特征融合后经视觉-语言投影器送入 Moxin-7B-Base。
  • 设计理由：DINOv2 提供低层空间属性（边缘、形状），SigLIP 因训练数据含互联网图像（草图、图表）而提供高层语义，两者互补。
  • 预训练数据：LLaVa v1.5 混合，含 558K 图像-文本对（Conceptual Captions、LAION 等）与 665K 多模态指令微调样本（LLaVa Synthetic 158K、标准 VQA 224K、多选 VQA 50K、描述 22K、指代表达 116K、ShareGPT 语言数据 40K）。
  • 训练策略：单阶段训练，投影器与 LM 可训练，视觉模块冻结，训练两个 epoch。

Moxin-VLA：并行解码与动作分块

  • 骨干为 Moxin-VLM，微调配方基于 OpenVLA-OFT。
  • 两种变体：一种在 Open X-Embodiment 上通用预训练（超 1 百万真实机器人轨迹，22 种 embodiment，21 个机构）；另一种直接从 Moxin-VLM 微调。
  • 关键设计：用并行解码与动作分块替代自回归动作预测，预测多未来时间步动作块，降低延迟、增强时间一致性、减少抖动。
  • 数据混合以 Franka Emika Panda 为中心，最大组件为 CMU Franka Exploration (12.35%)，其次 Berkeley Cable Routing (9.88%)，TACO Play、VIOLA、Austin BUDS、NYU Franka Play、KAIST Non-Prehensile 各 7.41%，Jaco Play、Toto 各 4.94%，其余组件占比 2.47% 至 0.25% 不等。
  • 训练配置：单节点 8xH100 GPU，约两周，90k 训练步；微调 batch size 64，学习率 3e-4，输入为两帧图像历史与机器人本体感知状态，LoRA rank r=32。

Moxin-Chinese：词汇表扩展与继续预训练

  • 扩展 Moxin 词汇表，添加中文 token；从 WuDaoCorpus2 采样训练中文 BPE 词汇（SentencePiece），并手动合并其他高质量中文词汇，最终词汇量约 57k。
  • 继续预训练使用 WanJuan、gutenberg-books、Chinese-Data-Distill-From-R1 等；微调用中英翻译数据集（Garsa3112/ChineseEnglishTranslationDataset、FradSer/DeepSeek-R1-Distilled-Translate-en-zh_CN-39k-Alpaca-GPT4-without-Think）。

关键创新

  1. 可审计的开放权重：MOF 框架不是简单的“代码开源”，而是将训练数据配比、数据来源、微调配方、评估协议全部公开。这在当前“权重开源、数据隐藏”的行业惯例下是实质性突破——它让性能差异可归因，让复现不再是玄学。

  2. 动作分块替代自回归：VLA 中并行解码与动作分块的引入，直接解决了机器人控制中自回归预测的延迟与抖动问题。这不是性能微调，而是控制范式的改变——从“逐 token 预测”到“预测动作块”，时间一致性成为显式优化目标。

  3. 负结果透明化：FiLM 模块在单臂设置下被明确排除，并给出理由。这种对“什么不起作用”的坦诚，在论文中极为罕见，但对下游研究者节省了大量试错成本——这正是开放性的真正价值。

边界与局限

论文未明确列出局限章节，但隐含边界包括：VLA 训练中 FiLM 模块在单臂机器人设置下无益故排除，这意味着多臂或更复杂 embodiment 下该结论可能不成立；OpenVLA-OFT 检查点复现差异大，作者未报告其结果，说明跨实现的可复现性仍是行业痛点；Moxin-VLA 在 50k 步收敛，150k 步无显著提升，暗示训练收益存在上限。此外，VLA 评估仅在 LIBERO 模拟环境进行，真实机器人部署效果论文未明确。

工程启示

复现或选用 Moxin 系列时，先核对以下三点：第一，VLA 数据混合配比是否与论文一致——CMU Franka Exploration 占 12.35% 是最大组件，若下游任务场景与 Franka 差异大，需重新配比；第二，动作分块长度与并行解码的实现细节，这是性能增益的核心来源，直接套用自回归解码会丢失时间一致性优势；第三，LoRA rank r=32 与 batch size 64 是微调的关键超参，偏离可能导致收敛不稳定。最容易踩坑的地方是 OpenVLA-OFT 检查点的复现——作者明确报告其与论文结果差异大，若下游团队以该检查点为基线，需自行验证。Moxin-VLA 在 50k 步即收敛，150k 步无提升，训练预算可据此规划，避免无效算力消耗。
