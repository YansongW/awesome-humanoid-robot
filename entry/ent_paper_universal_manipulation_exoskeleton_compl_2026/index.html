Universal Manipulation Exoskeleton: Learning Compliant Whole-body Policies with Real-time Torque Feedback

摘要

Universal Manipulation Exoskeleton (UME) 是一种低成本、轻量化的上肢外骨骼系统，由研究团队开发，用于通过实时触觉扭矩反馈实现遥操作。其核心贡献在于支持学习全身主动柔顺策略，在高度受限空间中完成移动操作、力控翻转等任务，并兼容多种机器人平台。

来源与参考

  • arXiv:2606.14218 Universal Manipulation Exoskeleton: Learning Compliant Whole-body Policies with Real-time Torque Feedback
  • GitHub仓库 Robotics_Notebooks

概述

UME（Universal Manipulation Exoskeleton）是一个低成本（$1900）、7-DoF 可穿戴外骨骼遥操作系统，通过同轴执行器布局和通用重定向算法，实现关节级双向力矩反馈与跨机器人（OpenArm、Franka、X-ARM）遥操作。核心贡献在于将力矩数据纳入学习管线，使 ACT 策略能学习主动柔顺整臂行为，在力密集型任务上显著超越无力矩基线和 UMI 范式。

它改变了什么

现有遥操作数据采集管线（ALOHA、GELLO、UMI 手持式）普遍缺失关节力矩传感，这不仅是硬件缺口，更是学习范式的天花板——没有力矩数据，策略只能学位置/轨迹，无法学"该用多大力、何时该让"的柔顺行为。作者真正改变的是把遥操作从"运动捕捉工具"升级为"力觉交互接口"：操作者实时感受从臂与环境接触的阻力，同时记录关节级力矩信号供策略学习。这直接回应了 VLA 模型和机器人世界模型普遍不强调柔顺性的根本原因——缺乏力和力矩数据。

另一个被改变的痛点是整臂构型控制。UMI 式手持采集只记录末端位姿，推理时依赖 IK 解算碰撞约束，在高度受限空间（如 GPU 插拔、冰箱取物）中极易失败。UME 通过通用重定向将外骨骼与从臂的运动链分解为肩/肘/腕三个子机械臂，独立重定向位置、速度和力矩，避免了 6D 任务空间控制的奇异性问题，同时让操作者能直观控制整臂构型而非仅末端。

方法拆解

硬件设计

  • 同轴执行器配置：J1-J3 轴交于肩球关节中心，J5-J7 轴交于腕球关节中心，J4 对应肘关节，复制人类肩/腕完整运动范围。
  • 执行器选型：肩部选 Damiao DM-J4340-2EC（9Nm、362g、40:1 减速比），在便携性、力矩透明度、重力补偿所需力矩间取平衡；拒绝交叉滚子轴承版本（增加摩擦）和更低减速比版本（定子过重）。
  • 总成本：$1900，重量约 12kg（PLA 结构），典型成人可舒适穿戴 2 小时。

通用重定向（Universal Retargeting）

将外骨骼与从臂分解为三个子机械臂：虚拟 3-DoF 球肩、1-DoF 肘、虚拟 3-DoF 球腕，各子结构独立重定向：

  1. 位置前馈：肩部 q_shoulder_exo 通过 FK 得旋转矩阵 R_shoulder_exo，再经 IK 映射到从臂 q_shoulder_robot；肘部直接镜像；腕部同理。
  2. 速度前馈：ω_shoulder = J_shoulder_exo · q̇_shoulder_exo，从臂命令 q̇_shoulder_robot = (J_shoulder_robot)† · ω_shoulder；对非冗余 3-DoF 子臂，伪逆简化为标准逆 J† = J⁻¹。
  3. 力矩反馈：从臂力矩 τ_shoulder_robot 经动力学一致逆转置映射为空间力 F_shoulder = (J̄_shoulder_robot)^T · τ_shoulder_robot，其中 J̄ = A⁻¹J^T(JA⁻¹J^T)⁻¹；外骨骼反馈力矩 τ_shoulder_exo = (J_shoulder_exo)^T · F_shoulder；肘部直接映射 τ_elbow_exo = τ_elbow_robot。
  4. 力矩透明度：命令力矩 τ_command_exo = c(q, q̇) + g(q) + f(q̇) + τ_feedback_exo，包含科里奥利、重力、摩擦补偿。

移动基座与学习框架

  • IMU 控制：约 \(9 的 IMU 三维欧拉角线性映射到移动基座速度 [ẋ, ẏ, θ̇]；VR 头显（\)300）为替代方案。
  • 移动基座：Tidybot++ 升级版，用 Hexfellow PCW-25 动力脚轮（$900×4）替代 FRC swerve 模块，更低减速比和背隙提升柔顺性与里程计精度。
  • 学习：ACT（Action Chunking with Transformers），ResNet18 骨干，力矩数据与关节位置同样处理，嵌入附加到图像嵌入后输入 Transformer 编码器-解码器，输出期望关节位置。

关键创新

  1. 关节级双向力矩反馈的遥操作范式：不同于 HOMIE、AirExo 等仅做位置遥操作的外骨骼，UME 让操作者实时感知从臂所受阻力，且力矩数据直接进入学习管线。这是"力觉数据采集"而非"运动数据采集"的范式转变，使主动柔顺策略学习成为可能。

  2. 通用重定向的解耦架构：将 7-DoF 手臂分解为肩/肘/腕三个子机械臂独立重定向，避免了 6D 末端任务空间控制的运动学奇异性，各子臂雅可比逆互不干扰。这一设计使同一外骨骼可遥操作不同运动学构型的机器人（OpenArm、Franka、X-ARM），且无需重新标定。

  3. 低成本高透明度硬件设计：$1900 总成本实现关节级力矩反馈，通过准直驱电机（Damiao/Unitree）和同轴布局在便携性、力矩透明度、负载支撑间取得平衡。相比 AirExo 等方案，UME 在保持低成本的同時提供了完整的双向力觉交互。

实验与结果

表 1：任务成功率（各 20 次试验）

方法 Box Pushing Box Flipping GPU Picking Fridge Drink Retrieval
No-torque 0.50 0 0.75 0.90
UMI 0.40 0 0 0
UME (Ours) 0.90 0.85 0.95 0.95
  • Box Pushing（26 演示）：UME 0.9 vs No-torque 0.5 vs UMI 0.4，力矩反馈带来 80%（由表内数值 0.5→0.9 计算） 相对提升。
  • Box Flipping（40 演示）：UME 0.85，No-torque 和 UMI 均为 0——这是最典型的力密集型任务，无力矩数据完全无法学习。
  • GPU Picking（42 演示）：夹爪插入后仅 5mm 间隙，UME 0.95 vs No-torque 0.75，UMI 为 0——高度受限空间暴露了 UMI 末端位姿+IK 范式的根本缺陷。
  • Fridge Drink Retrieval（157 演示）：UME 0.95 vs No-torque 0.90，UMI 为 0；阶段成功率显示 UMI 在"取出饮料"步骤即失败（0.00），后续步骤全部为 0。
  • 数据采集吞吐量：box flipping 任务上 UME 相比无力矩基线实现 3.3× 提升，运行速度为人类速度的 71%。
  • 通用遥操作：真实世界成功遥操作双臂 X-ARM 拾取积木、双臂传递并放入杯中；Franka 仅在 MuJoCo 仿真中演示。

边界与局限

  • 硬件局限：PLA 连杆导致重量较高（约 12kg）、有效载荷低于更昂贵替代方案；连杆尺寸固定，不可调节，影响可及性和人体工学。
  • Franka 仅仿真：因交付延迟，Franka 遥操作仅在 MuJoCo 中演示，未在真实硬件验证；作者预期真实性能相似或更好（因 Franka 关节力矩传感更精确），但此预期未经验证。
  • 未提及：真实 Franka 臂实验、可调连杆版本、生产级轻量化版本、推理频率、数据量统计。
  • 结论边界：所有成功率数据基于 20 次试验，统计显著性未报告；数据采集吞吐量提升（3.3×）仅基于 box flipping 单任务测量。

工程启示

  • 先核对力矩数据质量：UME 的核心价值在力矩反馈，复现时优先验证外骨骼力矩透明度（科里奥利/重力/摩擦补偿是否充分），否则反馈力矩噪声会直接污染学习信号。
  • 注意子臂分解的适用条件：通用重定向依赖肩/腕为 3-DoF 球关节、肘为 1-DoF 旋转的假设。若目标从臂构型不满足此分解（如 4-DoF 肩部），需重新推导雅可比和动力学一致逆，不可直接套用。
  • 数据量参考：力密集型任务（Box Flipping）仅需 40 演示即可达到 0.85 成功率，但 Fridge Drink Retrieval 需要 157 演示——任务复杂度与演示需求非线性增长，建议按任务复杂度预留数据采集时间。
  • 硬件选型避坑：肩部执行器选型是关键决策——DM-J4340-2EC 在力矩透明度与负载支撑间平衡；若选交叉滚子轴承版本（DM-J4340P）会因摩擦增加降低力矩透明度，若选更低减速比版本（DM-J8006）会因定子过重牺牲便携性。
  • 移动基座升级方向：Tidybot++ 的 swerve 模块（\(300）被替换为 Hexfellow PCW-25（\)900）是因为更低齿轮比和减少背隙——若预算有限，可保留原基座但需接受柔顺性和里程计精度下降。
  • 训练配置可直接复用：ACT 超参数（batch 200、ResNet18、4 层编码器、7 层解码器、40k 步）在 4 个任务上均有效，可作为新任务的起点配置。
