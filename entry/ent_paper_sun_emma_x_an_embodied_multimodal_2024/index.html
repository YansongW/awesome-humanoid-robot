摘要

Emma-X 是 2024 年由 SUTD 与 Google DeepMind 联合提出的大型视觉-语言-动作模型，发表于 ACL 2024。其核心贡献在于通过分层具身数据集与基于夹爪状态的分段策略，实现了具身链式推理与前瞻空间推理，显著提升了机器人在长时域空间推理任务中的表现。

概述

Emma-X 是一个面向人形机器人的具身多模态动作模型，由作者团队提出，核心贡献在于将模型预测控制中的不确定性分解为规划不确定性与学习不确定性，并分别通过共形轨迹过滤与组相对策略约束加以解决。该方法在 HumanoidBench 上评估，旨在提升长时间任务执行中的鲁棒性。

它改变了什么

现有 TD-MPC 类方法在长时间任务中面临不确定性累积的致命问题：策略网络 rollout 可能传播错误行为，而 MPPI 规划器又过度拟合模型动态的不准确性，两者叠加导致性能急剧下降。作者敏锐地指出，传统方法将规划不确定性与学习不确定性混为一谈，这种整体化处理掩盖了问题根源——前者源于 aleatoric 噪声，后者源于 epistemic 模型缺陷，需要截然不同的应对策略。

这项工作的真正改变在于，它不再试图用一个统一的机制去“压制”不确定性，而是将问题拆解为两个可独立优化的子问题：规划端用共形预测提供带覆盖保证的轨迹过滤，学习端用 softmax 优势估计提供方差更小的策略更新信号。这种分解思路在 MBRL 领域具有范式意义，因为它承认了“模型永远不完美”这一现实，转而通过统计工具与优化技巧分别兜底。

方法拆解

不确定性分解

将 MBRL 总不确定性拆分为规划不确定性（aleatoric）与学习不确定性（epistemic），分别由共形预测与策略约束处理。

规划感知机制（Conformal Trajectories）

  • 从策略网络采样 Nπ 条先验轨迹，从 MPPI 采样 N 条候选轨迹，合并为集合 A。
  • 使用 TD-based 成本函数计算非一致性分数：s̄(i) = 1 - ηVθ(z, a)。
  • 通过分位数阈值 q̂ = quantile({s̄(i)}, 1-α) 构建共形预测集，保留分数低于阈值的轨迹。
  • 该集合满足边际覆盖保证：1-α+1/(Nπ+N+1) ≥ P[Vθ(z,a) ∈ A_conformal] ≥ 1-α。
  • 假设 TD-based 成本函数为“弱教师”，在子线性教学调度下，共形分位数具有渐近弱有效性。

策略感知学习（GRPC）

  • 改进 GRPO，使用组相对优势估计：A_i(q) = exp(q_i/τ) / Σ_g exp(q_i^g/τ)。
  • softmax 优势的梯度方差小于标准归一化优势，因其输出有界于 0 到 1，限制异常值影响。
  • 策略目标：Lπ(θ) = (1/G)Σ A_i(q) log πθ(a_i|s) + β log μ(a|s)，β 控制 KL 散度惩罚强度。
  • 模型目标同时优化编码器、潜在动力学、奖励网络与价值网络。

关键设计决策

  • 策略先验轨迹作为“热启动”，减少随机采样依赖，鼓励训练一致性。
  • 共形过滤保持模型无关性，无需对成本分布做参数假设。
  • softmax 优势有界且对异常值鲁棒，提供更稳定的策略更新。

关键创新

  1. 不确定性分解的显式建模：首次将 MBRL 中的规划不确定性与学习不确定性分开处理，而非笼统合并。这使每个子问题都能采用针对性工具——共形预测处理 aleatoric 噪声，GRPC 处理 epistemic 模型偏差，避免了传统方法中两类误差相互放大的恶性循环。

  2. 共形预测用于轨迹过滤：将统计学习中的共形预测引入 MPPI 规划器，提供带边际覆盖保证的轨迹筛选机制。这一设计的关键新颖性在于，它不依赖对成本分布的参数假设，且能自适应地调整过滤阈值，在模型误差较大时自动收紧筛选标准。

  3. softmax 优势替代标准归一化：证明 softmax-based 优势的梯度方差更小，因为输出有界于 0 到 1，天然抑制异常值对策略更新的冲击。这一数学性质保证了训练稳定性，尤其在奖励稀疏或噪声大的场景中优势明显。

边界与局限

作者承认 TD-based 成本函数可能是不完美的“弱教师”，但通过教学调度与渐近有效性保证来缓解。论文未明确讨论真实机器人部署、计算成本分析、不同硬件条件下的泛化能力，也未提供与 TD-MPC2 等强基线的定量对比。共形预测的覆盖保证依赖于“弱教师”假设，若该假设在特定任务中不成立，过滤效果可能退化。此外，GRPC 的 softmax 温度参数 τ 与 KL 惩罚系数 β 的敏感性未在片段中分析。

工程启示

复现时先核对三个关键点：其一，共形预测的分位数阈值 α 与轨迹采样数 Nπ、N 的比例关系，这直接影响覆盖保证的松紧；其二，GRPC 中温度参数 τ 的初始化，过小会导致优势分布过于尖锐，过大则退化为均匀分布；其三，KL 惩罚系数 β 的调度策略，它决定了策略更新步长，过大会限制探索，过小则破坏信任区域约束。最容易踩坑的地方在于“弱教师”假设的验证——如果 TD-based 成本函数与真实奖励偏差过大，共形过滤可能筛掉高质量轨迹，建议在训练早期监控过滤后轨迹集的平均回报变化。对于下游团队，若需部署到真实机器人，务必先在小规模任务上验证共形阈值的迁移性，因为仿真环境的 aleatoric 噪声分布与真实世界差异显著。
