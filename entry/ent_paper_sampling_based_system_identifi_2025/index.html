Sampling-Based System Identification with Active Exploration for Legged Robot Sim2Real Learning

摘要

SPI-Active 是 2025 年提出的一种面向足式机器人的采样式系统辨识框架，旨在通过主动探索策略最小化 sim-to-real 差距。该工作由相关研究团队完成，核心贡献在于结合大规模并行采样与 Fisher Information 最大化，无需可微动力学或直接力矩测量即可准确估计物理参数。

来源与参考

  • Sampling-Based System Identification with Active Exploration for Legged Robot Sim2Real Learning (arXiv)

概述

针对 sim-to-real 差异导致学习策略在真实世界中难以完成高精度任务的问题，SPI-Active 提出了一种两阶段框架。第一阶段通过大规模并行采样，最小化模拟与真实轨迹之间的状态预测误差，从而鲁棒地辨识关键物理参数。第二阶段引入主动探索策略，通过优化探索策略的输入指令来最大化真实轨迹的 Fisher Information，从而提升数据的信息量。实验表明，该方法在多种运动任务中比基线方法性能提升 42-63%，实现了精确的 sim-to-real 迁移。

核心内容

方法架构

SPI-Active 包含两个核心阶段： - 采样式参数辨识：利用大规模并行采样，通过最小化模拟轨迹与真实轨迹之间的状态预测误差，估计足式机器人的关键物理参数（如质量、惯性、摩擦系数等）。该方法不依赖可微动力学模型或直接力矩测量，适用于接触丰富的足式系统。 - 主动探索策略：为提升采集数据的有效性，引入基于 Fisher Information 的主动探索机制。通过优化探索策略的输入指令，最大化真实轨迹中包含的参数信息量，从而在有限数据下实现更准确的参数辨识。

实验设置与关键结果

  • 任务场景：在多种运动任务（如行走、奔跑、跳跃）中验证性能。
  • 对比基线：与 Domain Randomization (DR) 及标准 Sys-ID 方法对比。
  • 关键数字：SPI-Active 在真实机器人上实现策略迁移，性能提升 42-63%（具体数值因任务而异）。
  • 结论：主动探索策略显著提升了参数辨识的准确性和泛化能力，使学习策略在真实世界中达到高精度表现。
