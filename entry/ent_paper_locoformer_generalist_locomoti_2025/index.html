LocoFormer: Generalist Locomotion via Long-Context Adaptation

LocoFormer: Generalist Locomotion via Long-Context Adaptation

摘要

LocoFormer: Generalist Locomotion via Long-Context Adaptation is a 2025 work on locomotion for humanoid robots.

来源与参考

  • LocoFormer: Generalist Locomotion via Long-Context Adaptation project page

概述

LocoFormer 是一个面向全形态运动控制的基础模型，由研究团队提出，采用 Transformer-XL 骨干网络与跨回合的长上下文记忆，在程序化生成的多种机器人上通过大规模强化学习训练，使同一套策略能够部署到未见过的腿式与轮式机器人，并在线适应形态与动力学变化。其核心贡献在于将上下文长度跨越回合边界，使策略能够从历史经验中持续学习与适应，而非依赖精确的运动学模型。

它改变了什么

运动控制领域长期被“一形态一策略”的定制化范式主导，每个新机器人或新任务都需要重新设计奖励、调参甚至重训。LocoFormer 真正改变的，是打破了这种对精确运动学知识的依赖——它不再试图在部署前“知道”机器人长什么样，而是让策略在部署后“学会”如何控制它。这种从“先验建模”到“在线适应”的范式转移，使得一个通用策略可以覆盖从双足到轮式的广泛形态，这是此前强化学习运动控制方法未能跨越的鸿沟。

另一个被改变的是上下文长度的定义。传统运动策略通常只观察当前状态或短时间窗口，本质上是“近视”的（myopic），无法利用跨回合的经验。LocoFormer 将上下文扩展数个数量级并跨越回合边界，这意味着策略不仅能感知当前状态，还能记住“上一次在这个地形上是怎么摔倒的”，从而在后续回合中主动调整。这种时间维度的扩展，让“经验积累”成为控制策略的一部分，而非仅仅依赖即时反馈。

方法拆解

骨干网络与记忆机制

  • 使用 Transformer-XL（TXL） 作为策略网络，将上下文划分为固定长度的段（segments）。
  • 处理当前段时，键（keys）和值（values）同时从前一个缓存段的状态计算，但不传播梯度——这是关键设计，它让记忆可以无限延伸而不会导致训练时的梯度爆炸或计算开销失控。
  • 随着层数增加，TXL 的层级递进记忆机制允许网络利用比缓存段更早的信息，形成多时间尺度的记忆结构。

训练范式

  • 训练时，策略在一个 episode 内运行多个 trial（回合），记忆跨 trial 持续存在。
  • 优化目标为最大化整个 episode 上的期望累积奖励，而非单个 trial 的奖励——这迫使策略学会“从失败中学习”，因为早期 trial 的摔倒会通过记忆影响后期 trial 的决策。
  • 训练数据来自程序化生成的多种机器人形态，配合激进域随机化（aggressive domain randomization），覆盖腿式与轮式结构。

部署与在线适应

  • 同一套 LocoFormer 策略直接部署到所有机器人，无需针对特定形态重新训练。
  • 部署到新机器人仅需数分钟设置、数秒适应——策略在初始时对目标形态没有精确知识，在线动态构建稳定的、形态特定的表征。
  • 面对大扰动（形态变化、电机故障、重量变化），策略能够重建这些表征以实现在线适应；若适应失败，可开启新 trial，利用之前失败经历的记忆快速重新适应。

关键设计决策

  • 不传播梯度的跨段注意力：这是记忆扩展的工程前提，否则训练将因梯度路径过长而不可行。
  • 跨 trial 的优化目标：这是“从经验中学习”的行为学基础，使策略在 episode 层面而非 trial 层面最优。
  • 程序化生成 + 域随机化：这是泛化的数据基础，让策略见过足够多样的“身体”，才能在部署时快速匹配未知形态。

关键创新

  1. 长上下文跨越回合边界：此前运动控制策略的上下文通常限制在单个回合或短时间窗口内，LocoFormer 将上下文扩展至跨 trial 甚至跨 episode。这不是简单的窗口拉长，而是让策略具备“记忆”能力——它能记住早期 trial 的失败模式，并在后续 trial 中主动规避。这种时间维度的扩展，使“学习”从训练阶段延伸到了部署阶段。

  2. 无需精确运动学知识的在线适应：传统方法在部署前需要精确的机器人模型（质量分布、关节限位、动力学参数），LocoFormer 完全绕开了这一要求。策略通过在线经验动态构建形态表征，面对扰动时能重建这些表征。这从根本上改变了部署流程——从“先建模再控制”变为“先控制再学习”。

  3. 全形态单一策略：一个策略覆盖腿式与轮式、双足与多足，这在运动控制领域是罕见的。其可行性来自程序化生成的大规模形态多样性训练，而非手工设计某种“通用表示”。这为未来机器人技能基础模型提供了一条可复制的路径——不是设计更聪明的架构，而是提供更丰富的“身体经验”。

实验与结果

论文未明确提供具体数值结果（原文表格为图片形式，未提取数字）。实验场景与定性结论如下：

实验场景 设置 结果（定性）
未见形态部署 多种未见过的腿式与轮式机器人 LocoFormer 可直接部署，数秒内适应
大扰动适应 重量变化、电机故障、形态变化 能重建表征并在线适应
跨 trial 学习 早期 trial 摔倒，后期 trial 改进 策略能从失败中学习并保留有效策略
人形机器人行走 多种人形形态 稳健行走
对比实验 单一形态特化策略（specialist） 特化策略无法适应显著形态变化，LocoFormer 可以

关键对比结论：特化策略在形态变化面前失效，而 LocoFormer 能适应。这验证了“通用性来自多样性训练”的核心假设——特化策略在训练形态上可能表现更好，但一旦形态偏移，其性能急剧下降；LocoFormer 由于见过足够多的形态变化，反而在未知形态上更稳健。

边界与局限

  • 快速扰动适应的边界：论文承认，在某些具有挑战性的形态下，LocoFormer 可能无法足够快速地适应突发的在线扰动。这意味着“数秒适应”并非在所有场景下成立，对于动态变化极快或形态极端陌生的机器人，适应速度可能不足。
  • 训练与部署的形态固定性：训练过程中，机器人的形态和特定物理属性（如质心位置）在整个 episode 内保持固定不变。这限制了策略对“形态在运行中持续变化”场景的适应能力——如果机器人在一个 trial 内发生结构性改变（如关节断裂后重心偏移），策略可能无法实时响应。
  • 失败后的恢复机制：适应失败后，LocoFormer 依赖开启新 trial 并利用失败记忆来重新适应。这意味着它不具备“单次尝试内无限恢复”的能力，对于不允许重启任务的场景（如救援机器人），这一限制可能是致命的。
  • 工程细节缺失：论文未明确训练平台、数据量、训练配置、推理频率或硬件要求，复现难度较高。

工程启示

  • 先核对记忆机制的实现：TXL 的跨段注意力“不传播梯度”是实现长上下文的关键，复现时务必确认梯度截断是否正确——如果梯度意外传播，训练将因计算开销和梯度不稳定而失败。
  • 域随机化的范围决定泛化边界：LocoFormer 的泛化能力直接来自训练时程序化生成的形态多样性。复现时，随机化的范围（关节类型、肢体数量、质量分布）必须足够激进，否则部署到未见形态时适应速度会显著下降。
  • 跨 trial 优化目标不可省略：如果只优化单 trial 奖励而忽略 episode 级累积奖励，策略将失去“从失败中学习”的动力。这是 LocoFormer 在线适应能力的核心来源，也是与普通 RL 策略最本质的区别。
  • 最容易踩坑的地方：训练时形态在 episode 内固定不变，但部署时形态可能动态变化。如果下游任务涉及运行中形态改变，需要额外设计形态变化的模拟，否则策略在真实场景中的适应能力会大打折扣。
  • 对下游团队的启示：如果目标是快速部署到新机器人，LocoFormer 的“数分钟设置、数秒适应”是可行的；但如果任务要求单次尝试内的高可靠性（不允许失败后重启），需要评估策略的快速适应边界是否满足要求。
