A Hierarchical Framework for Humanoid Locomotion with Supernumerary Limbs

摘要

本文提出一种用于配备超数肢体（SLs）的人形机器人的分层控制框架，由浙江大学团队完成。核心贡献在于将基于学习的步态生成与基于模型的动态平衡解耦，使Unitree H1机器人在携带SLs时保持稳定行走。实验表明，主动平衡控制器使质心轨迹的DTW距离降低47%，并改善了步态周期内的再稳定能力。

来源与参考

  • A Hierarchical Framework for Humanoid Locomotion with Supernumerary Limbs (arXiv)

概述

本文提出一种解耦的分层控制框架，用于解决仿人机器人搭载重型主动驱动超数肢体（SLs）时的动态稳定行走问题。该框架由基于DRL的低层运动策略与基于模型的高层平衡控制器组成，在MuJoCo仿真中验证了其有效性，显著降低了CoM轨迹扰动并改善了步态稳定性。

它改变了什么

现有SL平衡研究多聚焦于静态锚定或专用非人形附属肢体，缺乏针对多用途SL手臂在快速重定位重负载时产生大幅时变力矩的通用动态步行稳定性策略。单一整体DRL策略同时控制运动与SLs平衡面临状态-动作空间剧增和潜在冲突目标，导致训练难以收敛。本文真正改变的是将平衡责任从运动策略中剥离，使DRL代理专注于核心行走任务，而由独立的高层控制器实时处理SLs引入的复杂动力学扰动。这种解耦不仅降低了训练复杂度，还使平衡控制具备高频、确定性的响应特性，避免了端到端策略在动态扰动下的不确定性。

方法拆解

总体架构

分层控制框架分为低层运动策略与高层平衡控制器，二者独立运行，仅在执行器层面融合。

低层DRL运动策略

  • 基于DeepMimic框架，使用PPO算法训练，折扣因子γ=0.99。
  • 策略网络：三个隐藏层，神经元数为[1024, 512, 256]，Tanh激活。
  • 奖励函数：R_t = w_survival * R_survival + w_stability * R_stability + w_imitation * R_imitation，权重分别为：关节位置匹配0.05、关节速度匹配0.01、相对部位位置匹配0.1、相对部位四元数匹配0.05、相对部位速度匹配0.01、生存奖励5.0、跌倒惩罚4.0。
  • 课程学习：总训练步数500百万，载荷从可忽略逐步增至19kg至30kg；手臂姿态从贴近身体自然位置分四阶段移至前伸姿态。

高层动态平衡控制器

  • 状态估计：CoM为所有身体链接位置的加权平均；CoS在单支撑阶段为支撑脚接触区域几何中心，双支撑阶段为基于地面反作用力的力加权平均CoP。
  • 动态稳定性指标：d_xy = CoM_xy - CoS_xy，作为动态稳定性指示器而非需消除的静态误差。
  • 目标手臂姿态：q_target_arm = q_base_arm - K_p_arm * d_xy，采用线性启发式控制律，选择理由为计算简单和实时可行性。
  • PD控制器：τ_arm = K_p * (q_target_arm - q_current_arm) - K_d * q_dot_current_arm，增益通过模拟中迭代手动调参确定，目标为临界阻尼行为。
  • 控制融合：每步中SL手臂执行器力矩被平衡控制器输出覆盖，人形腿部与躯干执行器力矩直接来自DRL策略。

关键设计决策

  • 解耦策略让DRL代理专注于核心运动任务，专门的平衡控制器处理SLs引入的复杂动力学。
  • 选择线性启发式控制律而非非线性全身优化，因后者计算成本高；目标是提供连续高频动态阻尼而非单一完美矫正姿态。

关键创新

  1. 解耦控制架构：将运动控制与SL平衡控制彻底分离，避免了单一DRL策略的状态-动作空间爆炸和冲突目标问题。这一设计使低层策略能更好地遵循学习到的协调模式，高层控制器则提供确定性的动态补偿，两者协同优于端到端方案。
  2. 动态稳定性指标d_xy的重新定义：将CoM与CoS的偏差视为动态稳定性指示器而非静态误差，通过线性启发式控制律实时调整SL姿态。这种处理方式计算成本极低，却能在每个步态周期内持续提供阻尼效应，而非追求单次完美矫正。
  3. 课程学习与载荷随机化：从可忽略载荷逐步增至19kg至30kg，配合手臂姿态分阶段课程，使DRL策略在训练初期即可稳定探索，避免了高载荷下的过早失败。这一策略显著提升了训练收敛性和最终性能。

实验与结果

实验在MuJoCo物理仿真中进行，机器人平台为Unitree H1（12 DoF）+ 两个Kinova Gen3手臂（各7 DoF）+ 2F-85夹爪，总计26个驱动自由度。三个场景对比：基线行走（无SLs）、静态载荷（SLs锁定前伸姿态，高层控制器禁用）、动态平衡（完整分层框架）。

指标 基线 静态载荷 动态平衡
CoM轨迹DTW距离 未明确 123.71 65.54
GRF方向误差 8.37° 5.59° 1.95°

动态平衡场景下，CoM轨迹DTW距离相比静态载荷减少约47%（由表内数值123.71→65.54计算），表明主动平衡控制显著降低了SLs对步态模式的破坏性影响。GRF方向误差在动态平衡场景中最低（1.95°），优于基线（8.37°）和静态载荷（5.59°）。GCSM在动态平衡场景达到最低中位数，表明更有效的再稳定能力。训练表现显示平均回合回报和平均回合长度持续上升，在100百万步标记处出现周期性下降，对应课程难度增加。

边界与局限

论文未明确执行器力矩是否饱和到物理极限，这是sim-to-real挑战的关键方面。基线步态并非完美最优（方向误差8.37°），可能源于参考动作捕捉数据不完善或DRL策略优先考虑稳定性。GRF协调性差异未进行严格统计分析确认显著性。动态平衡控制器不强制轨迹与基线完全匹配，仅部分缓解SLs对步态模式的破坏性影响。未进行真实机器人实验，仅物理模拟。框架仅将平衡作为SLs功能，未集成操作任务。未深入调查平衡控制在关节层面的实现机制，未进行SLs应急运动策略的逐时刻分析。

工程启示

复现时首先核对模拟环境配置：MuJoCo物理引擎配合JAX框架（利用JIT编译和自动微分），机器人平台为Unitree H1 + 两个Kinova Gen3手臂。训练配置需严格遵循：PPO算法、γ=0.99、网络结构[1024, 512, 256]、总训练步数500百万、课程每100百万步调整。最容易踩坑的点包括：载荷随机化范围（19kg至30kg）和手臂姿态课程的四阶段设计必须与原文一致，否则DRL策略可能无法收敛；高层控制器的增益（K_p_arm、K_p、K_d）需在模拟中迭代手动调参，目标为临界阻尼行为，直接使用默认值可能导致不稳定。控制融合逻辑需确保SL手臂执行器力矩每步被平衡控制器输出覆盖，而腿部与躯干执行器力矩直接来自DRL策略。推理频率论文未明确，需自行确定。代码和视频已开源：https://github.com/heyzbw/HuSLs。
