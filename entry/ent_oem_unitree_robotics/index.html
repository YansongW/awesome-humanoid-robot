概述

宇树科技（Unitree Robotics）是 2016 年成立、总部位于杭州的中国机器人公司，以高性价比四足机器人切入市场，后扩展到人形机器人（H1、G1、R1、H2 系列），坚持电机、驱动器、运控算法等核心部件的垂直整合与激进定价，是当前全球科研与开发者市场出货量最高的人形机器人平台之一。2026 年 6 月其科创板 IPO 过会，7 月 2 日获证监会同意注册，成为 A 股人形机器人第一股的领先候选（来源：财新、凤凰网财经）。

核心内容

是什么：准确定义

宇树是一家整机 OEM + 核心部件自研的机器人公司：对外销售四足机器人（Go2、B2 等）与人形机器人（H1/H1-2、G1、R1、H2）整机，对内自研关节电机（如 M107 永磁同步电机）、驱动器与整机运动控制算法，并向开发者开放 ROS2 兼容的 SDK 生态（来源：项目附录 D 宇树公司档案；宇树官网产品页）。

用产业链语言表达它的位置：上游自研电机与驱动器、外购减速器/轴承/电池/传感器，下游是高校、科研院所、开发者与行业客户（来源：项目附录 D 宇树公司档案）。

为什么存在：痛点与历史定位

2020 年前后的人形/腿足机器人市场对研究者有两道高墙：价格（动辄数十万到上百万美元）与封闭（不开放底层控制接口）。宇树的打法是把消费电

子式供应链管理带进机器人：用自研电机 + 国产供应链大幅压低整机价格（G1 国内上市起售价 9.9 万元人民币，此前全尺寸人形的公开售价普遍高出数倍——工程估算），同时开放关节级控制接口。这一步改变了市场的买家结构——人形机器人从"国家队和大厂的展品"变成"高校实验室和初创公司买得起的开发平台"。2023 年发布首款全尺寸人形 H1（官网称其为"中国首款能奔跑的全尺寸通用人形机器人"），2024 年推出紧凑型 G1，2025–2026 年推出 R1 与 H2，并完成从四足到人形、从硬件到"本体 + 开发平台"的扩展（来源：宇树官网 H1/G1/R1/H2 产品页；项目附录 D）。

原理拆解：技术与商业的双轮

① 垂直整合的关节动力链

宇树官网为 H1 标注的峰值扭矩密度为 189 N·m/kg，H1 最大关节扭矩 360 N·m（来源：宇树官网 H1 产品页）。R1 与 H2 的关节电机官方描述为"低惯量高速内转子 PMSM（永磁同步电机，更好的响应速度与散热）"，输出端配交叉滚子轴承（来源：宇树官网 R1/H2 参数页）——这是典型的准直驱（QDD）取向设计：低惯量电机 + 低减速比传动换取力透明度与抗冲击能力（减速比等细节未公开，需自行确认）。

② 运控算法与生态开放

整机运动控制（行走、奔跑、起身）自研，OTA 持续升级；对开发者开放关节与传感器控制接口，并支持主流仿真平台，便于算法从仿真无缝进入物理世界（来源：宇树官网 R1 产品页）。H2 Plus 进一步成为 NVIDIA Isaac GR00T 参考人形平台：H2 本体 + Sharpa 五指灵巧手 + Jetson Thor 计算单元（来源：图谱报告卡 ent_report_unitree_unitree_announces_h2_plus_an_n_2026）。

③ 成本工程

R1 把全尺寸人形的入门价打到 4,900 美元（AIR 版），其路径是结构件轻量化（约 27–29 kg）、自由度分级（20/26/26–40 DOF 三档）与灵巧手选配（来源：宇树官网 R1 参数页）。它证明的不是"便宜"，而是人形硬件开始遵循消费电子的成本曲线。

谁在用 / 应用案例

  • 科研平台：H1/G1 是开源全身控制与人形 RL 论文最常用的硬件之一——图谱内既有 JAEGER（双层级全身控制，ent_paper_jaeger_dual_level_humanoid_who_2025）也有基于 G1 的手臂功耗建模研究（ent_paper_deniz_identification_of_a_physics_ba_2026）；
  • NVIDIA 生态：H2 Plus 被选为 Isaac GR00T 参考人形平台（图谱报告卡）；
  • 四足基本盘：Go2/B2 系列用于电力巡检、应急救援与科研（附录 D 档案）；
  • 开发者教育：G1 EDU 面向高校教学与算法验证（官网 G1 页）。

局限与边界

  • 性能数据以官方自报为主：上表全部来自官网，缺乏第三方标准化实测（如续航、负载下的持续扭矩），工程选型需自行复测；
  • 强项在运动控制而非精细操作：Dex3-1 三指手为选配，双手精细操作生态相比专用灵巧手厂商仍在建设；
  • 企业级交付能力待验证：科研市场出货领先 ≠ 工业场景的规模交付能力，售后与可靠性数据公开有限（工程判断）；
  • 低价入门版能力边界：R1 AIR 为 20 DOF 无灵手配置，与演示视频中的高动态动作并非同一配置（官网参数页的分档差异需注意）。

常见误区

  1. "宇树 = 机器狗公司"——四足是现金流基本盘，但 2023 年起人形已是第二增长曲线，2026 年 IPO 募资主体投向包含机器人模型与本体研发（财新报道）。
  2. "低价 = 低性能"——360 N·m 腿关节扭矩、189 N·m/kg 扭矩密度（官网 H1/H2 页）在同价位无对手；低价来自成本工程而非性能妥协。
  3. "G1/R1 开箱即全能"——官网演示视频对应高配/特定软件版本，AIR 与 EDU 档自由度、灵巧手差异很大。
  4. "买宇树就绕开了国产供应链风险"——其减速器、轴承、电池仍外购（附录 D 档案），本质是整合商 + 部分自研。
  5. "上市即商业化成功"——IPO 过会与注册（2026-06/07）是资本市场事件，与人形机器人的场景盈利能力是两回事（工程判断）。

왜 존재하는가:痛点과 역사적 위치

2020년 전후 휴머노이드/족형 로봇 시장은 연구자에게 두 가지 높은 벽이 있었습니다: 가격(수십만에서 수백만 달러에 달함)과 폐쇄성(하위 제어 인터페이스 미개방). 우수의 전략은 소비 전자식 공급망 관리를 로봇에 도입한 것입니다: 자체 개발 모터 + 국산 공급망으로 완제품 가격을 대폭 낮추고(G1 국내 출시 시작가 9.9만 위안, 기존 전신 휴머노이드 공개 가격은 일반적으로 수 배 높았음——공학적 추정), 동시에 관절급 제어 인터페이스를 개방했습니다. 이 한 걸음이 시장의 구매자 구조를 바꾸었습니다——휴머노이드 로봇이 "국가대표팀과 대기업의 전시품"에서 "대학 연구실과 스타트업이 살 수 있는 개발 플랫폼"으로 바뀐 것입니다. 2023년 첫 전신 휴머노이드 H1을 출시했고(공식 웹사이트는 "중국 최초로 달릴 수 있는 전신 범용 휴머노이드 로봇"이라고 칭함), 2024년 컴팩트형 G1, 2025–2026년 R1과 H2를 출시하며 사족에서 휴머노이드로, 하드웨어에서 "본체 + 개발 플랫폼"으로 확장을 완료했습니다(출처: 우수 공식 웹사이트 H1/G1/R1/H2 제품 페이지; 프로젝트 부록 D).
