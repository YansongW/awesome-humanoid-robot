摘要

概述

最大似然估计（Maximum Likelihood Estimation, MLE）是一种统计原理，它选择使观测数据出现概率最大的模型参数。它是现代机器学习中交叉熵损失和下一个 token 预测任务的数学基础，也是机器人状态估计中后端优化的核心准则。

核心内容

是什么：从"猜参数"到"选最合理的参数"

最大似然估计回答一个根本问题：给定一组观测数据，哪个参数值最"合理"？它的答案很直接——让这些数据出现的概率最大的那个参数。假设我们有一个带参数 θ 的概率模型 p(x|θ)，观测到数据集 D = {x₁, x₂, ..., xₙ}，MLE 就是求解：

$$ \hat{\theta}{\text{MLE}} = \arg\max p(x_i \mid \theta) ```} \; p(D \mid \theta) = \arg\max_{\theta} \; \prod_{i=1}^{n

它真正改变的不是"如何计算概率"，而是"如何从数据反推参数"——把统计推断从先验假设转向数据驱动。在机器人领域，这意味着我们不再手动调参，而是让算法从传感器数据中自动找到最符合观测的模型参数。

为什么存在：痛点与历史定位

在 MLE 出现之前，参数估计主要依赖矩估计（Method of Moments）等启发式方法。这些方法虽然计算简单，但统计效率低，且难以推广到复杂模型。MLE 由 Ronald Fisher 在 1920 年代系统化提出，它提供了三个关键优势：

  1. 一致性：样本量增大时，估计值收敛到真实参数。
  2. 渐近有效性：在大样本下，MLE 达到 Cramér-Rao 下界，即所有无偏估计中最小的方差。
  3. 不变性：如果 θ̂ 是 θ 的 MLE，那么 g(θ̂) 就是 g(θ) 的 MLE。

在机器人领域，MLE 的引入解决了从噪声传感器数据中提取可靠状态估计的问题。无论是视觉里程计、激光雷达建图还是惯性导航，本质上都是在做"给定观测，反推状态"的 MLE 问题。

原理拆解：从高斯噪声到最小二乘

MLE 的强大之处在于，它在特定假设下会退化为我们熟悉的优化形式。考虑机器人后端优化的经典场景：假设测量噪声服从高斯分布，即 z = h(x) + ε，其中 ε ~ N(0, Σ)。那么单个观测的似然为：

\[ p(z \mid x) = \frac{1}{\sqrt{(2\pi)^k |\Sigma|}} \exp\left( -\frac{1}{2} (z - h(x))^\top \Sigma^{-1} (z - h(x)) \right) \]

取负对数后，最大化似然等价于最小化马氏距离平方和：

\[ \min_{\mathbf{x}} \frac{1}{2} \sum_i \|\mathbf{r}_i(\mathbf{x})\|^2_{\mathbf{\Sigma}_i} \]

其中 rᵢ(x) = zᵢ - hᵢ(x) 是残差，‖·‖²_Σ 表示马氏距离。这就是为什么机器人后端优化（如图优化、Bundle Adjustment）本质上都是 MLE 的具体实现——它们共享同一个数学内核。

关键参数与规格

MLE 的实现涉及以下关键要素：

要素 说明 典型选择
似然函数 描述数据生成过程的概率模型 高斯分布、伯努利分布、多项分布
优化目标 负对数似然（NLL） 最小二乘、交叉熵
求解算法 迭代优化方法 高斯-牛顿法、Levenberg-Marquardt
噪声模型 描述测量不确定性的分布 各向同性高斯、各向异性高斯

在深度学习语境下，MLE 对应交叉熵损失：对于分类任务，最大化似然等价于最小化预测分布与真实分布之间的交叉熵。对于下一个 token 预测，MLE 就是最大化给定上文条件下正确 token 的条件概率。

横向对比：MLE 与 MAP、贝叶斯估计

MLE 并非唯一的参数估计方法。与最大后验估计（MAP）和完全贝叶斯估计相比，MLE 处于"最数据驱动"的一端：

方法 先验使用 输出形式 计算复杂度 适用场景
MLE 不使用 点估计 低 数据量大、先验弱
MAP 使用 点估计 中 数据有限、有可靠先验
贝叶斯估计 使用 后验分布 高 需要不确定性量化

MLE 的局限在于：当数据量小时容易过拟合，且无法表达参数的不确定性。MAP 通过引入先验缓解了第一个问题，贝叶斯估计则同时解决两个问题，但代价是计算量显著增加。工程判断：在机器人实时系统中，MLE 和 MAP 是主流选择，完全贝叶斯方法多用于离线分析。

谁在用·应用案例

案例一：视觉惯性里程计（VIO） VIO 系统将相机重投影误差和 IMU 预积分误差联合建模为高斯分布，通过 MLE 框架求解最优位姿。实际系统中，后端优化器（如 g2o、Ceres）正是在最小化马氏距离平方和。

案例二：大语言模型的下一个 token 预测 GPT 系列模型的训练目标就是最大化下一个 token 的条件似然。给定前文 context，模型输出每个候选 token 的概率分布，训练时最小化交叉熵——这正是 MLE 在离散分布上的等价形式。

案例三：ISP 自动曝光（AE） 在相机图像信号处理中，AE 环路根据统计引擎输出的亮度直方图调整曝光时间。虽然这是一个控制问题而非严格意义上的 MLE，但其"根据观测统计反推最优参数"的逻辑与 MLE 一脉相承。

局限与边界

MLE 并非万能，它有明确的适用边界：

  1. 对模型假设敏感：如果似然函数形式错误（例如实际噪声不是高斯），MLE 结果会有偏。
  2. 小样本问题：数据量不足时，MLE 容易过拟合，估计方差大。
  3. 非凸优化：在复杂模型中（如深度网络），MLE 的优化目标非凸，只能找到局部最优。
  4. 计算代价：每次迭代需要计算雅可比矩阵和海森矩阵，在高维状态空间中代价高昂。
  5. 无法表达不确定性：MLE 只给出点估计，不提供参数的可信区间。

在机器人系统中，这意味着 MLE 需要配合鲁棒核函数（如 Huber 损失）来抵抗外点，并借助协方差矩阵传递不确定性。

常见误区

  1. "MLE 就是最小二乘"——不准确。最小二乘是 MLE 在高斯噪声假设下的特例；如果噪声服从拉普拉斯分布，MLE 对应的是 L1 范数最小化。
  2. "MLE 一定无偏"——错误。MLE 是渐近无偏的，小样本下可能有偏。例如估计高斯分布的方差时，MLE 给出的估计除以 n 而非 n-1，是有偏的。
  3. "MLE 不需要先验"——对，但这既是优点也是缺点。没有先验意味着在小数据场景下容易过拟合。
  4. "交叉熵和 MLE 是两个东西"——它们是同一枚硬币的两面。最小化交叉熵等价于最大化似然，只是表述方式不同。

Overview

Maximum Likelihood Estimation (MLE) is a statistical principle that selects the model parameters that maximize the probability of observing the given data. It serves as the mathematical foundation for cross-entropy loss and next-token prediction tasks in modern machine learning, and it is also the core criterion for backend optimization in robot state estimation.

Content

What It Is: From "Guessing Parameters" to "Choosing the Most Reasonable Parameters"

Maximum likelihood estimation answers a fundamental question: given a set of observed data, which parameter value is the most "reasonable"? Its answer is straightforward—the parameter that makes the observed data most probable. Suppose we have a probabilistic model p(x|θ) with parameters θ, and we observe a dataset D = {x₁, x₂, ..., xₙ}. MLE solves:

\[ \hat{\theta}_{\text{MLE}} = \arg\max_{\theta} \; p(D \mid \theta) = \arg\max_{\theta} \; \prod_{i=1}^{n} p(x_i \mid \theta) \]

What it truly changes is not "how to compute probabilities," but "how to infer parameters from data"—shifting statistical inference from prior assumptions to data-driven approaches. In robotics, this means we no longer manually tune parameters; instead, algorithms automatically find the model parameters that best match observations from sensor data.

Why It Exists: Pain Points and Historical Context

Before MLE, parameter estimation primarily relied on heuristic methods such as the Method of Moments. Although computationally simple, these methods had low statistical efficiency and were difficult to generalize to complex models. MLE was systematically formalized by Ronald Fisher in the 1920s, offering three key advantages:

  1. Consistency: As the sample size increases, the estimate converges to the true parameter.
  2. Asymptotic Efficiency: For large samples, MLE achieves the Cramér-Rao lower bound, i.e., the smallest variance among all unbiased estimators.
  3. Invariance: If θ̂ is the MLE of θ, then g(θ̂) is the MLE of g(θ).

In robotics, the introduction of MLE addressed the problem of extracting reliable state estimates from noisy sensor data. Whether it is visual odometry, LiDAR mapping, or inertial navigation, the underlying problem is essentially an MLE problem of "given observations, infer the state."

Principle Breakdown: From Gaussian Noise to Least Squares

The power of MLE lies in the fact that, under specific assumptions, it reduces to familiar optimization forms. Consider the classic scenario of robot backend optimization: assume measurement noise follows a Gaussian distribution, i.e., z = h(x) + ε, where ε ~ N(0, Σ). Then the likelihood of a single observation is:

\[ p(z \mid x) = \frac{1}{\sqrt{(2\pi)^k |\Sigma|}} \exp\left( -\frac{1}{2} (z - h(x))^\top \Sigma^{-1} (z - h(x)) \right) \]

Taking the negative logarithm, maximizing the likelihood is equivalent to minimizing the sum of squared Mahalanobis distances:

\[ \min_{\mathbf{x}} \frac{1}{2} \sum_i \|\mathbf{r}_i(\mathbf{x})\|^2_{\mathbf{\Sigma}_i} \]

where rᵢ(x) = zᵢ - hᵢ(x) is the residual, and ‖·‖²_Σ denotes the Mahalanobis distance. This is why robot backend optimization (such as graph optimization and Bundle Adjustment) is essentially a concrete implementation of MLE—they share the same mathematical core.

Key Parameters and Specifications

Implementing MLE involves the following key elements:

Element Description Typical Choice
Likelihood function Probabilistic model describing the data generation process Gaussian, Bernoulli, Multinomial distributions
Optimization objective Negative log-likelihood (NLL) Least squares, cross-entropy
Solving algorithm Iterative optimization methods Gauss-Newton, Levenberg-Marquardt
Noise model Distribution describing measurement uncertainty Isotropic Gaussian, anisotropic Gaussian
Regularization Penalty term to prevent overfitting L2 norm, early stopping

In the deep learning context, MLE corresponds to cross-entropy loss: for classification tasks, maximizing likelihood is equivalent to minimizing the cross-entropy between the predicted distribution and the true distribution. For next-token prediction, MLE is maximizing the conditional probability of the correct token given the preceding context.

Horizontal Comparison: MLE vs. MAP vs. Bayesian Estimation

MLE is not the only parameter estimation method. Compared to Maximum A Posteriori (MAP) estimation and full Bayesian estimation, MLE sits at the "most data-driven" end:

Method Prior Usage Output Form Computational Complexity Applicable Scenarios
MLE Not used Point estimate Low Large data, weak prior
MAP Used Point estimate Medium Limited data, reliable prior
Bayesian estimation Used Posterior distribution High Uncertainty quantification needed

MLE's limitations: it is prone to overfitting with small data and cannot express parameter uncertainty. MAP mitigates the first issue by introducing a prior, while Bayesian estimation addresses both issues but at the cost of significantly increased computation. Engineering judgment: in real-time robotic systems, MLE and MAP are the mainstream choices, while full Bayesian methods are mostly used for offline analysis.

Who Uses It · Application Cases

Case 1: Visual-Inertial Odometry (VIO) VIO systems jointly model camera reprojection errors and IMU pre-integration errors as Gaussian distributions, solving for the optimal pose within the MLE framework. In practice, backend optimizers (such as g2o, Ceres) are precisely minimizing the sum of squared Mahalanobis distances.

Case 2: Next-Token Prediction in Large Language Models The training objective of GPT-series models is to maximize the conditional likelihood of the next token. Given the preceding context, the model outputs a probability distribution over each candidate token, and training minimizes cross-entropy—this is exactly the equivalent form of MLE for discrete distributions.

Case 3: ISP Auto Exposure (AE) In camera image signal processing, the AE loop adjusts exposure time based on the brightness histogram output by the statistical engine. Although this is a control problem rather than strict MLE, its logic of "inferring optimal parameters from observed statistics" is consistent with MLE.

Limitations and Boundaries

MLE is not a panacea; it has clear applicability boundaries:

  1. Sensitive to model assumptions: If the likelihood function is misspecified (e.g., the actual noise is not Gaussian), MLE results will be biased.
  2. Small sample problems: With insufficient data, MLE is prone to overfitting and high estimation variance.
  3. Non-convex optimization: In complex models (such as deep networks), the MLE objective is non-convex, and only local optima can be found.
  4. Computational cost: Each iteration requires computing Jacobian and Hessian matrices, which is expensive in high-dimensional state spaces.
  5. Inability to express uncertainty: MLE only provides a point estimate and does not offer credible intervals for parameters.

In robotic systems, this means MLE needs to be paired with robust kernel functions (such as Huber loss) to resist outliers, and covariance matrices are used to propagate uncertainty.

Common Misconceptions

  1. "MLE is just least squares"—Inaccurate. Least squares is a special case of MLE under the Gaussian noise assumption; if the noise follows a Laplace distribution, MLE corresponds to L1 norm minimization.
  2. "MLE is always unbiased"—Incorrect. MLE is asymptotically unbiased but can be biased for small samples. For example, when estimating the variance of a Gaussian distribution, the MLE divides by n rather than n-1, making it biased.
  3. "MLE does not require a prior"—Correct, but this is both an advantage and a disadvantage. Without a prior, it is prone to overfitting in small-data scenarios.
  4. "Cross-entropy and MLE are two different things"—They are two sides of the same coin. Minimizing cross-entropy is equivalent to maximizing likelihood, just expressed differently.

개요

최대우도추정(Maximum Likelihood Estimation, MLE)은 관측된 데이터가 나타날 확률을 최대화하는 모델 파라미터를 선택하는 통계적 원리입니다. 이는 현대 머신러닝에서 교차 엔트로피 손실과 다음 토큰 예측 작업의 수학적 기반이자, 로봇 상태 추정에서 백엔드 최적화의 핵심 기준입니다.

핵심 내용

무엇인가: "파라미터 추측"에서 "가장 합리적인 파라미터 선택"으로

최대우도추정은 근본적인 질문에 답합니다: 주어진 관측 데이터에 대해 어떤 파라미터 값이 가장 "합리적인가?" 그 답은 매우 직접적입니다——이 데이터가 나타날 확률을 최대화하는 파라미터입니다. 파라미터 θ를 가진 확률 모델 p(x|θ)와 관측 데이터셋 D = {x₁, x₂, ..., xₙ}이 있다고 가정할 때, MLE는 다음을 풉니다:

\[ \hat{\theta}_{\text{MLE}} = \arg\max_{\theta} \; p(D \mid \theta) = \arg\max_{\theta} \; \prod_{i=1}^{n} p(x_i \mid \theta) \]

MLE가 실제로 바꾸는 것은 "확률을 계산하는 방법"이 아니라 "데이터에서 파라미터를 역산하는 방법"입니다——통계적 추론을 사전 가정에서 데이터 중심으로 전환합니다. 로봇 공학에서 이는 더 이상 수동으로 파라미터를 조정하지 않고, 알고리즘이 센서 데이터에서 관측에 가장 부합하는 모델 파라미터를 자동으로 찾는다는 것을 의미합니다.

왜 존재하는가:痛点과 역사적 위치

MLE가 등장하기 전에는 파라미터 추정이 주로 모멘트 방법(Method of Moments)과 같은 휴리스틱 방법에 의존했습니다. 이러한 방법들은 계산이 간단했지만 통계적 효율이 낮고 복잡한 모델로 확장하기 어려웠습니다. MLE는 Ronald Fisher가 1920년대에 체계적으로 정립했으며, 세 가지 핵심 장점을 제공합니다:

  1. 일관성: 표본 크기가 증가하면 추정값이 실제 파라미터로 수렴합니다.
  2. 점근적 효율성: 대표본에서 MLE는 Cramér-Rao 하한에 도달하며, 이는 모든 불편 추정량 중 가장 작은 분산입니다.
  3. 불변성: θ̂가 θ의 MLE라면, g(θ̂)는 g(θ)의 MLE입니다.

로봇 공학에서 MLE의 도입은 잡음이 있는 센서 데이터에서 신뢰할 수 있는 상태 추정을 추출하는 문제를 해결했습니다. 시각적 오도메트리, 라이다 매핑, 관성 항법 모두 본질적으로 "주어진 관측에서 상태를 역산하는" MLE 문제입니다.

원리 분해: 가우시안 잡음에서 최소제곱까지

MLE의 강력함은 특정 가정 하에서 우리에게 익숙한 최적화 형태로 축소된다는 점입니다. 로봇 백엔드 최적화의 전형적인 시나리오를 고려해 보겠습니다: 측정 잡음이 가우시안 분포를 따른다고 가정합니다, 즉 z = h(x) + ε, 여기서 ε ~ N(0, Σ)입니다. 그러면 단일 관측의 우도는 다음과 같습니다:

\[ p(z \mid x) = \frac{1}{\sqrt{(2\pi)^k |\Sigma|}} \exp\left( -\frac{1}{2} (z - h(x))^\top \Sigma^{-1} (z - h(x)) \right) \]

음의 로그를 취하면, 우도 최대화는 마할라노비스 거리 제곱합 최소화와 동일해집니다:

\[ \min_{\mathbf{x}} \frac{1}{2} \sum_i \|\mathbf{r}_i(\mathbf{x})\|^2_{\mathbf{\Sigma}_i} \]

여기서 rᵢ(x) = zᵢ - hᵢ(x)는 잔차이고, ‖·‖²_Σ는 마할라노비스 거리를 나타냅니다. 이것이 로봇 백엔드 최적화(그래프 최적화, 번들 조정 등)가 본질적으로 모두 MLE의 구체적인 구현인 이유입니다——그들은 동일한 수학적 핵심을 공유합니다.

잡음 모델 측정 불확실성을 설명하는 분포 등방성 가우시안, 이방성 가우시안
정규화 과적합을 방지하는 페널티 항 L2 노름, 조기 종료

딥러닝 맥락에서 MLE는 교차 엔트로피 손실에 해당합니다: 분류 작업의 경우 우도 최대화는 예측 분포와 실제 분포 사이의 교차 엔트로피 최소화와 동일합니다. 다음 토큰 예측의 경우 MLE는 주어진 이전 문맥 조건에서 올바른 토큰의 조건부 확률을 최대화하는 것입니다.

수평 비교: MLE와 MAP, 베이즈 추정

MLE는 유일한 파라미터 추정 방법이 아닙니다. 최대 사후 확률 추정(MAP) 및 완전 베이즈 추정과 비교할 때, MLE는 "가장 데이터 중심적인" 끝에 위치합니다:

방법 사전 사용 출력 형태 계산 복잡도 적용 시나리오
MLE 사용 안 함 점 추정 낮음 데이터量大, 사전 약함
MAP 사용 점 추정 중간 데이터 제한적, 신뢰할 수 있는 사전 존재
베이즈 추정 사용 사후 분포 높음 불확실성 정량화 필요

MLE의 한계는 데이터 양이 적을 때 과적합되기 쉽고 파라미터의 불확실성을 표현할 수 없다는 점입니다. MAP는 사전을 도입하여 첫 번째 문제를 완화하고, 베이즈 추정은 두 문제를 동시에 해결하지만 계산량이 크게 증가하는 대가가 있습니다. 공학적 판단: 로봇 실시간 시스템에서는 MLE와 MAP가 주류 선택이며, 완전 베이즈 방법은 주로 오프라인 분석에 사용됩니다.

누가 사용하는가·응용 사례

사례 1: 시각-관성 오도메트리(VIO) VIO 시스템은 카메라 재투영 오차와 IMU 사전 적분 오차를 가우시안 분포로 결합 모델링하고, MLE 프레임워크를 통해 최적의 자세를 해결합니다. 실제 시스템에서 백엔드 최적화기(g2o, Ceres 등)는 바로 마할라노비스 거리 제곱합을 최소화합니다.

사례 2: 대규모 언어 모델의 다음 토큰 예측 GPT 시리즈 모델의 훈련 목표는 다음 토큰의 조건부 우도를 최대화하는 것입니다. 주어진 이전 문맥에서 모델은 각 후보 토큰의 확률 분포를 출력하고, 훈련 시 교차 엔트로피를 최소화합니다——이는 이산 분포에서 MLE의 동등한 형태입니다.

사례 3: ISP 자동 노출(AE) 카메라 이미지 신호 처리에서 AE 루프는 통계 엔진이 출력하는 밝기 히스토그램에 따라 노출 시간을 조정합니다. 이는 엄밀한 의미의 MLE라기보다 제어 문제이지만, "관측 통계에서 최적 파라미터를 역산하는" 논리는 MLE와 맥을 같이합니다.

한계와 경계

MLE는 만능이 아니며 명확한 적용 경계가 있습니다:

  1. 모델 가정에 민감: 우도 함수 형태가 잘못되면(예: 실제 잡음이 가우시안이 아닌 경우) MLE 결과에 편향이 생깁니다.
  2. 소표본 문제: 데이터 양이 부족하면 MLE는 과적합되기 쉽고 추정 분산이 큽니다.
  3. 비볼록 최적화: 복잡한 모델(예: 심층 네트워크)에서 MLE의 최적화 목표는 비볼록이며 지역 최적해만 찾을 수 있습니다.
  4. 계산 비용: 각 반복에서 야코비 행렬과 헤시안 행렬을 계산해야 하며, 고차원 상태 공간에서 비용이 높습니다.
  5. 불확실성 표현 불가: MLE는 점 추정만 제공하며 파라미터의 신뢰 구간을 제공하지 않습니다.

로봇 시스템에서 이는 MLE가 이상치에 저항하기 위해 강건 커널 함수(예: Huber 손실)와 함께 사용되어야 하고, 공분산 행렬을 통해 불확실성을 전달해야 함을 의미합니다.

일반적인 오해

  1. "MLE는 최소제곱이다"——부정확합니다. 최소제곱은 가우시안 잡음 가정 하에서 MLE의 특수한 경우입니다; 잡음이 라플라스 분포를 따르면 MLE는 L1 노름 최소화에 해당합니다.
  2. "MLE는 항상 불편이다"——틀렸습니다. MLE는 점근적으로 불편이며 소표본에서는 편향될 수 있습니다. 예를 들어 가우시안 분포의 분산을 추정할 때 MLE가 제공하는 추정은 n이 아닌 n-1로 나누지 않아 편향됩니다.
  3. "MLE는 사전이 필요 없다"——맞습니다, 하지만 이는 장점이자 단점입니다. 사전이 없다는 것은 소규모 데이터 시나리오에서 과적합되기 쉽다는 뜻입니다.
  4. "교차 엔트로피와 MLE는 다른 것이다"——그것들은 같은 동전의 양면입니다. 교차 엔트로피 최소화는 우도 최대화와 동일하며, 단지 표현 방식만 다릅니다.

관련 지식

  • ent_foundation_probability_theory — 확률론은 MLE에 우도 함수, 분포, 기대값의 수학적 기반을 제공하며, MLE를 이해하기 위한 전제 조건입니다.
  • ent_self_attention_equation — 자기 주의 메커니즘의 softmax 정규화는 본질적으로 확률 분포이며, 그 훈련 역시 MLE 프레임워크를 기반으로 합니다.
