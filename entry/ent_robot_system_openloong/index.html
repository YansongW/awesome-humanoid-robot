摘要

OpenLoong（开放龙）/ 青龙是国家地方共建人形机器人创新中心推出的全尺寸开源人形机器人公版机，身高超 185 cm、体重超 80 kg，全身 43 个主动自由度（含五指灵巧手），经开放原子开源基金会孵化运营，开源内容包括硬件图纸、基于 MPC + WBC 的全身动力学控制框架（可部署于 MuJoCo 仿真）与数据集。

概述

OpenLoong（开放龙）/ "青龙"（Qinglong）是国家地方共建人形机器人创新中心（上海，2023-12-28 成立、2024-05-17 揭牌）与人形机器人（上海）有限公司推出的全尺寸开源人形机器人公版机，2024-12-19 通过开放原子开源基金会（OpenAtom）TOC 评审，捐赠基金会孵化运营。整机身高超 185 cm、体重超 80 kg，全身 43 个主动自由度（含五指灵巧手），开源内容包括硬件图纸、基于 MPC + WBC 的全身动力学控制框架（可部署于 MuJoCo 仿真）与数据集。它真正改变的不是"又一台人形机器人"，而是把全尺寸人形机器人的根技术（硬件图纸 + 控制框架 + 数据集）以公版机形式开放给整个产业。

核心内容

是什么：准确定义

OpenLoong 是一个全尺寸开源人形机器人公版机项目。所谓"公版机"，类比电子产业的参考设计（Reference Design）：不是一台面向终端用户销售的产品，而是一套经过验证的、可被第三方复制、修改、再生产的完整技术方案。其开源内容覆盖三个层面：

  1. 硬件层：OpenLoong-Hardware 仓库，包含设计指标、STEP 模型、电路原理图、安装维护手册；
  2. 软件层：OpenLoong-Dyn-Control 仓库，基于 MPC（模型预测控制）+ WBC（全身控制）的全身动力学控制框架，可部署于 MuJoCo 仿真；
  3. 数据层：OpenLoong-Dataset 仓库，提供机器人运行数据。

项目定位是产业"公版机/根技术"，被媒体称为全球首个全尺寸人形全栈开源项目。主要代码仓库采用 Apache-2.0 许可证；OpenLoong-Hardware、OpenLoong-Dataset 许可证为自定义/未明确（GitHub 标记 NOASSERTION）。

为什么存在：痛点与历史定位

人形机器人产业面临一个根本困境：重复造轮子。每一家初创公司都要从电机选型、结构设计、动力学建模、控制框架搭建开始做起，研发周期长达数年、成本极高。而全尺寸人形机器人的技术门槛尤其高——不同于小型双足或四足平台，全尺寸意味着更高的惯量、更大的关节力矩需求、更复杂的全身动力学耦合。

OpenLoong 的历史定位，是把"轮子"本身开源。它由国家地方共建人形机器人创新中心（一个国家级平台）牵头，经开放原子开源基金会（OpenAtom）孵化运营——这意味着它不是一个公司的商业项目，而是一个产业基础设施。2025-08 社区另推出更轻量、更低成本的 NanoLoong（小型双足）并已开源，进一步降低了入门门槛。

原理拆解

① 全身动力学控制：MPC + WBC 的分层架构

OpenLoong-Dyn-Control 的核心是 MPC（模型预测控制）与 WBC（全身控制）的分层组合。MPC 在较慢的时间尺度（通常 50–100 Hz）上，基于简化模型（如线性倒立摆或质心动力学）预测未来一段时域内的最优质心轨迹与落脚点；WBC 在较快的时间尺度（通常 500–1000 Hz）上，将 MPC 给出的高层指令转化为满足全身动力学约束的关节力矩。

WBC 的数学本质是一个带约束的二次规划（QP）问题：

\[ \min_{\ddot{q}, \tau, \lambda} \sum_{i} w_i \| J_i \ddot{q} + \dot{J}_i \dot{q} - \ddot{x}_i^{\text{des}} \|^2 \]
\[ \text{s.t.} \quad M(q)\ddot{q} + C(q,\dot{q}) + G(q) = S^T \tau + J_c^T \lambda \]

其中第一行是任务跟踪误差的最小化（\(J_i\) 为第 \(i\) 个任务的任务雅可比，\(\ddot{x}_i^{\text{des}}\) 为期望任务加速度），第二行是浮动基动力学方程（\(M\) 为质量矩阵，\(C\) 为科氏力/离心力项，\(G\) 为重力项，\(S\) 为选择矩阵，\(J_c\) 为接触雅可比，\(\lambda\) 为接触力）。约束还包括摩擦锥、关节力矩限、关节位置限位等。OpenLoong-Dyn-Control 提供行走、跳跃、盲踩障碍三个示例，已在实物样机实现行走与盲踩障碍。

② EtherCAT 总线：关节通信的确定性基础

OpenLoong 采用 EtherCAT 作为关节通信总线。EtherCAT 的核心特性是"processing on the fly"（飞读飞写）：从站在以太网帧经过时立即读写数据，无需完整接收帧再转发。这保证了多轴关节控制在单根网线上获得与专用硬件总线相当的确定性延迟——对于 43 个主动自由度的全身控制，通信延迟的确定性直接决定了控制环路的稳定性。

OpenLoong 的独特之处在于全栈开源 + 全尺寸的组合。学术界的开源平台（如 ODRI Bolt）多为小型机器人，无法覆盖全尺寸的动力学挑战；商业公司的全尺寸机器人（如 Unitree H1）则不开源。OpenLoong 填补了这两者之间的空白。

谁在用·应用案例

  • 产业复制：作为公版机，OpenLoong 的硬件图纸可被第三方制造商直接用于生产。媒体口径"最终由生产商定价"——即硬件成本由复制方自行决定。
  • 控制算法研究：OpenLoong-Dyn-Control 可部署于 MuJoCo 仿真，提供行走、跳跃、盲踩障碍三个示例，研究者无需实物即可开展全身控制算法研究。
  • 生态项目集成：dora-rs/dora-openloong 等生态项目已在实机集成 Intel RealSense D435 RGB-D 相机与麦克风阵列，用于感知与交互研究。
  • 教育：NanoLoong（2025-08 推出的小型双足）进一步降低了学习门槛，适合高校教学。

局限与边界

  1. 硬件成本未知：开源公版机不自售，BOM 总价未公布，实际生产成本需自行估算（工程判断：全尺寸 43 自由度人形机器人的 BOM 通常在数十万元人民币量级，但此数字需自行确认）。
  2. 执行器参数不透明：具体电机/减速器型号、扭矩参数未见统一规格表，需查阅 OpenLoong-Hardware 仓库的选型文件。
  3. 传感器清单未统一：官方未发布统一传感器清单，实机集成方案依赖生态项目自行选型。
  4. 新手友好度低：调研档案评估为 2 / 5——全尺寸平台的调试、维护、安全要求远高于小型平台。
  5. 许可证不统一：硬件与数据集仓库的许可证为自定义/未明确（GitHub 标记 NOASSERTION），商业使用时需谨慎评估。

常见误区

  1. "OpenLoong 是一台可以买到的机器人"——错。它是公版机，不自售；硬件由生产商定价制造。你拿到的是图纸，不是整机。
  2. "开源 = 低成本"——错。开源省的是研发成本，不是制造成本。全尺寸 43 自由度平台的物料与加工成本依然高昂。
  3. "MPC + WBC 是 OpenLoong 发明的"——错。MPC 与 WBC 都是学术界成熟方法（WBC 的 QP 形式可追溯至 2000 年代），OpenLoong 的贡献在于将其工程化、模块化并开源。
  4. "43 个自由度 = 43 个电机"——不准确。自由度包含五指灵巧手的关节，灵巧手内部可能有多个电机驱动一个关节或一个电机驱动多个关节的耦合设计（工程判断，具体结构需查阅硬件仓库）。

零力矩点

零力矩点（ZMP）是双足行走和平衡控制的基础稳定性判据：当地面反作用力等效作用点保持在支撑多边形内时，机器人可保持动态平衡，广泛用于步态规划与全身控制。

模型预测控制（MPC）

基于预测模型反复求解有限时域最优控制问题并仅执行首步控制量的优化控制方法。
