摘要

研究向量空间、线性变换、矩阵和线性方程组的数学分支。

来源与参考

  • Strang, Introduction to Linear Algebra

概述

线性代数是研究向量空间、线性变换、矩阵与线性方程组的一门基础数学分支。在人形机器人领域，它真正改变的不是"解方程的方式"，而是让机器人从"几何直觉"走向"可计算的代数结构"——从正运动学的坐标变换到逆运动学的伪逆求解，从动力学建模到接触力优化，线性代数是贯穿感知、决策与执行全链条的底层语言。

核心内容

是什么：准确定义

线性代数（Linear Algebra）是数学的一个分支，研究对象包括向量空间（vector space）、线性变换（linear transformation）、矩阵（matrix）以及线性方程组（system of linear equations）。其核心思想是：把几何对象（点、线、平面）抽象为向量，把几何操作（旋转、缩放、投影）抽象为矩阵乘法，从而用一套统一的代数框架处理高维空间中的关系。

在人形机器人知识体系中，线性代数属于基础学科（foundation）类型，价值链层级为基础层。它是整个知识图谱的"根基"——当分析一个机器人系统时，可以向上追溯其依赖的方法、形式化、原理和基础学科，形成完整的认知链路。例如：Tesla Optimus（system）依赖 MPC / Diffusion Policy（method），后者依赖 QP / MDP（formalism），再向上追溯到控制理论 / 机器学习（principle），最终落到线性代数 / 概率论（foundation）。

为什么存在：痛点与历史定位

在人形机器人出现之前，机械臂的运动学与动力学分析主要依赖几何作图与标量微积分。这种方法在自由度（DOF）较少时尚可应付，但人形机器人是典型的高维、欠驱动、强耦合系统——单条腿就有 5–6 个关节，全身自由度常超过 30 个。此时，每个关节的角度变化都会耦合影响末端位置，用标量方法逐关节推导几乎不可能。

线性代数提供了两条关键出路：一是矩阵化表达，把 n 个关节的角度打包成一个 n 维向量，把从关节空间到操作空间的映射打包成一个矩阵（Jacobian），从而把复杂的几何关系压缩为一次矩阵乘法；二是数值化求解，把逆运动学、动力学方程转化为线性方程组或最小二乘问题，交给计算机迭代求解。没有线性代数，现代机器人学中的运动规划、状态估计（卡尔曼滤波）、最优控制（MPC）与力控都将失去数学基础。

原理拆解

① 正运动学：从关节角到末端位置的矩阵化映射

以 3-DOF 平面机械臂为例，设三根连杆长度分别为 \(L_0=0.4\)、\(L_1=0.35\)、\(L_2=0.25\)（单位：m，按语料数据），关节角向量为 \(\mathbf{q}=[q_0, q_1, q_2]^T\)。末端位置 \(\mathbf{p}=[x, y]^T\) 由正运动学给出：

\[ x = L_0\cos q_0 + L_1\cos(q_0+q_1) + L_2\cos(q_0+q_1+q_2) \]
\[ y = L_0\sin q_0 + L_1\sin(q_0+q_1) + L_2\sin(q_0+q_1+q_2) \]

这本质上是把每个关节的旋转矩阵依次相乘，再取最后一列的位置分量——线性代数中的齐次变换矩阵正是为此而生。

② Jacobian：关节速度到末端速度的线性映射

对正运动学求偏导，得到 2×3 的 Jacobian 矩阵 \(\mathbf{J}(\mathbf{q})\)，它把关节速度 \(\dot{\mathbf{q}}\) 映射为末端速度 \(\dot{\mathbf{p}}\)：

\[ \dot{\mathbf{p}} = \mathbf{J}(\mathbf{q}) \, \dot{\mathbf{q}} \]

以语料中的示例位形 \(\mathbf{q}=[0.3, 0.8, -0.5]\)（rad）为例，计算得到的 Jacobian 为 2×3 矩阵。对 \(\mathbf{J}\) 做奇异值分解（SVD）\(\mathbf{J} = \mathbf{U}\mathbf{\Sigma}\mathbf{V}^T\)，奇异值 \(\mathbf{S}\) 反映了末端在各主轴方向上的速度放大能力。语料中计算了条件数（最大奇异值与最小奇异值之比）与可操作性指标：

\[ w = \sqrt{\prod_i \sigma_i^2} \]

其中 \(\sigma_i\) 为奇异值。当 \(w\) 趋近于 0 时，机械臂接近奇异位形，某些方向上的运动能力丧失——这是线性代数直接揭示的机器人学核心现象。

③ 逆运动学：伪逆与数值迭代

给定目标末端位置 \(\mathbf{p}_{\text{target}}\)，需要反解关节角 \(\mathbf{q}\)。由于 \(\mathbf{J}\) 是 2×3 矩阵（非方阵），无法直接求逆，需使用伪逆（pseudoinverse）：

\[ \Delta\mathbf{q} = \alpha \, \mathbf{J}^+ \, \Delta\mathbf{p} \]

其中 \(\mathbf{J}^+ = \mathbf{J}^T(\mathbf{J}\mathbf{J}^T)^{-1}\) 为 Moore-Penrose 伪逆，\(\alpha\) 为步长。语料中的 ik_pseudoinverse 函数采用此方法迭代求解：设定最大迭代次数 max_iter=200、容差 tol=1e-4、步长 alpha=0.5，目标位置为 [0.6, 0.4]（m）。每次迭代计算当前末端位置与目标的误差，若误差范数小于容差则停止，否则用伪逆更新关节角。语料还提示"阻尼最小二乘可提升数值稳定性"——即在 \(\mathbf{J}\mathbf{J}^T\) 中加入小量 \(\lambda\mathbf{I}\)，防止接近奇异时伪逆爆炸。

④ 动力学优化：线性代数作为约束建模工具

在全身动力学控制中，线性代数还承担约束建模的角色。语料展示了一个简化示例：优化变量为关节加速度 \(\ddot{\mathbf{q}}\)（3 维）、关节力矩 \(\boldsymbol{\tau}\)（3 维）与接触力 \(\mathbf{F}\)（2 维），目标函数为末端加速度跟踪误差与正则项之和：

\[ \min_{\mathbf{z}} \; \|\mathbf{J}\ddot{\mathbf{q}} - \ddot{\mathbf{x}}_{\text{des}}\|^2 + 10^{-4}\|\boldsymbol{\tau}\|^2 + 10^{-4}\|\mathbf{F}\|^2 \]

等式约束为动力学方程 \(\mathbf{M}\ddot{\mathbf{q}} + \mathbf{g} = \boldsymbol{\tau} + \mathbf{J}^T\mathbf{F}\)（其中 \(\mathbf{M}\) 为对角质量矩阵，语料取 [1.0, 0.8, 0.5]），不等式约束为摩擦锥 \(|F_x| \le \mu F_z\)、\(F_z \ge 0\)。该问题用 SLSQP（序列最小二乘规划）求解，ftol=1e-9、maxiter=200。这里线性代数的角色是双重的：既提供 \(\mathbf{J}^T\) 这样的力-力矩映射工具，又把物理约束表达为线性等式与不等式，使问题落入成熟的数值优化框架。

横向对比

线性代数与概率论并列为机器人学的两大数学基石，但角色不同。概率论处理不确定性——传感器噪声、状态估计中的置信度传播；线性代数处理确定性结构——坐标变换、力-力矩映射、约束建模。两者在卡尔曼滤波中交汇：状态预测用线性代数（状态转移矩阵），噪声融合用概率论（协方差矩阵）。

在数值方法层面，线性代数与微积分互补。微积分提供连续变化的描述（速度、加速度、曲率），线性代数提供离散化的代数结构（Jacobian、Hessian）。实际工程中，微积分关系最终都要离散为线性代数问题才能上计算机求解——这正是 FEA（有限元分析）的原理：把连续体离散为有限单元，把偏微分方程转化为线性代数方程组。

谁在用·应用案例

案例一：数值逆运动学求解（语料 §8 示例）

给定 3-DOF 平面臂目标位置 [0.6, 0.4]（m），使用 Jacobian 伪逆法迭代求解。语料代码展示了完整流程：正运动学计算当前末端位置 → 计算误差 → 求 Jacobian → 伪逆 → 更新关节角。该模式是工业机械臂与仿人机器人手臂控制的基本范式。

案例二：速度椭球与可操作性分析（语料 §8 示例）

在示例位形 \(\mathbf{q}=[0.3, 0.8, -0.5]\)（rad）下，对 Jacobian 做 SVD，绘制速度椭球图。单位圆上的关节速度被 \(\mathbf{J}\) 映射为末端速度空间中的椭圆，椭圆的长短轴由奇异值决定，主轴方向由 \(\mathbf{U}\) 的列向量给出。这用于评估机械臂在各方向上的运动能力，指导避奇异路径规划。

案例三：全身动力学优化（语料 §8 示例）

以末端加速度跟踪为目标，同时优化关节加速度、关节力矩与接触力，满足动力学等式约束与摩擦锥不等式约束。该问题用 SLSQP 求解，是模型预测控制（MPC）与全身控制（WBC）的简化雏形。

案例四：有限元分析（FEA）

FEA 把连续体离散为有限数量的单元，把偏微分方程转化为线性代数方程组求解，用于预测连杆、关节支架与壳体在载荷下的应力、变形与模态。这是线性代数在结构设计端的典型应用。

局限与边界

线性代数并非万能。一是线性假设的局限：机器人动力学本质上是强非线性的（科氏力、离心力、重力项），线性代数只能处理局部线性化（如 Jacobian 本身就是一阶近似），在大范围运动或高速场景下精度下降。二是计算复杂度：高维矩阵运算（如全身动力学中的质量矩阵求逆）在实时控制中可能成为瓶颈，需要利用稀疏性、并行计算或专用硬件加速。三是数值稳定性：接近奇异位形时 Jacobian 条件数急剧增大，伪逆解对噪声极其敏感，需引入阻尼项或奇异鲁棒逆。四是模型依赖：线性代数给出的解依赖于模型精度，模型误差会直接传导到解的质量——这正是系统辨识（System Identification）存在的意义。

常见误区

  1. "线性代数只是解方程组的工具"——错。它的核心价值在于提供一套描述高维空间结构与变换的抽象语言。Jacobian、齐次变换、李群李代数都是线性代数思想的延伸，解方程组只是冰山一角。

  2. "伪逆就是普通逆矩阵"——错。伪逆专门处理非方阵或奇异矩阵，\(\mathbf{J}^+\) 给出的是最小范数最小二乘解，而非唯一解。当 \(\mathbf{J}\) 行满秩时，伪逆解是无穷多解中范数最小的那个。

  3. "可操作性越大越好"——不准确。可操作性 \(w\) 衡量的是各方向运动能力的均衡程度，\(w\) 大意味着各向同性好，但某些任务恰恰需要各向异性（如拧螺丝需要绕轴大扭矩、其他方向小运动）。工程判断：应根据任务需求选择合适的工作点，而非盲目追求 \(w\) 最大化。

  4. "FEA 是结构工程师的事，与机器人算法无关"——错。FEA 把 PDE 转化为线性代数方程组求解，与机器人运动学/动力学中的矩阵求解共享同一套数值线性代数内核（稀疏求解器、预处理、特征值分解）。理解线性代数有助于理解 FEA 的精度与收敛性。

왜 존재하는가:痛点과 역사적 위치

휴머노이드 로봇이 등장하기 전, 로봇 팔의 운동학과 동역학 분석은 주로 기하학적 작도와 스칼라 미적분에 의존했습니다. 이러한 방법은 자유도(DOF)가 적을 때는 감당할 수 있었지만, 휴머노이드 로봇은 전형적인 고차원, 부구동(underactuated), 강결합 시스템입니다. 한쪽 다리만 해도 5–6개의 관절이 있고, 전신 자유도는 종종 30개를 초과합니다. 이때 각 관절의 각도 변화는 말단 위치에 결합적으로 영향을 미치므로, 스칼라 방법으로 관절별로 유도하는 것은 거의 불가능합니다.

선형대수학은 두 가지 핵심 해결책을 제공합니다. 첫째, 행렬화 표현으로, n개 관절의 각도를 하나의 n차원 벡터로 묶고, 관절 공간에서 작업 공간으로의 매핑을 하나의 행렬(Jacobian)로 압축하여 복잡한 기하학적 관계를 한 번의 행렬 곱셈으로 축소합니다. 둘째, 수치적 해법으로, 역기구학과 동역학 방정식을 선형 방정식 시스템 또는 최소제곱 문제로 변환하여 컴퓨터가 반복적으로 풀게 합니다. 선형대수학이 없다면 현대 로봇 공학의 운동 계획, 상태 추정(칼만 필터), 최적 제어(MPC), 힘 제어는 모두 수학적 기반을 잃게 됩니다.
