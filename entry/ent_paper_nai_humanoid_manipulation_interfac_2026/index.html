人形机器人操作接口（HuMI）：无需机器人演示的全身操作

摘要

HuMI 是一个便携式、无需机器人的数据采集与分层学习框架，能将人类全身操作演示转化为自主人形机器人技能。它通过手持传感器夹爪和可穿戴追踪器采集数据，训练高层 Diffusion Policy 预测关键点轨迹，再由低层强化学习全身控制器执行，在 Unitree G1 上实现 3 倍遥操作吞吐量和 70% 的未见环境成功率。

来源与参考

  • Humanoid Manipulation Interface: Humanoid Whole-Body Manipulation from Robot-Free Demonstrations

概述

HuMI 是一套面向人形机器人全身操作的数据采集与分层策略学习系统，由机器人免演示硬件（手持夹爪 + Vive Tracker）和“高层 Diffusion Policy + 低层 RL 全身控制器”两级架构组成。核心贡献在于用人在回路 IK 预览解决人类演示到人形机器人的运动学适配问题，并通过自适应末端执行器奖励、变速增强和相对姿态跟踪等机制，在 Unitree G1 上实现了五种全身任务的高成功率与数据采集效率的大幅提升。

它改变了什么

人形机器人全身操作长期被两条路线卡住：遥操作要求操作者同时管理平衡与控制器误差，劳动密集且难以规模化；视觉 sim-to-real 强化学习则受限于奖励工程和硬件物流，展示的任务数量少且局限于受控实验室。更根本的问题是，现有机器人免数据系统（如 UMI）只记录末端执行器轨迹，完全不足以指定“蹲下、跪地、弯腰”这类需要腰、腿、脚协同的全身动作——同样的低位伸手，髋膝踝的配置决定了任务成败。

HuMI 真正改变的是数据采集的“形态鸿沟”问题。它不试图把人类演示缩放或重定向到机器人运动学上（这通常导致自碰撞或可达性失败），而是通过实时 IK 预览让人类操作者在采集时主动调整动作，使演示在源头上就是机器人可行的。同时，它把“全身轨迹”而非“末端轨迹”作为策略接口，让低级控制器学习跟踪骨盆、脚部等非视觉锚定关键点，从而解锁了深蹲、跪地、行走清洁这类真正利用人形平台灵活性的任务。这等于把“机器人能做什么”的约束从后处理阶段前移到了数据采集阶段，改变了整个模仿学习管线的数据契约。

方法拆解

数据采集：机器人免演示硬件

  • 两个 3D 打印手持夹爪（腕装 GoPro 相机 + ArUco 标记追踪夹爪宽度），五个 HTC Vive Ultimate Tracker 分别安装在夹爪、腰部和双脚。
  • 选择 Vive Ultimate Tracker 而非头戴式系统，因为后者在蹲下与地面物体交互时因遮挡导致跟踪性能下降。
  • 跟踪五个关键操作框架：骨盆（浮动基座）、双手、双脚；排除头部（目标机器人 Unitree G1 无驱动颈部）。
  • 整个装置可装入单个背包，无需基站，每新场景仅需 1–2 分钟构建环境追踪地图。

人在回路运动学适配

  • 不缩放人类轨迹，保持原始未缩放姿态以维持视觉-空间对齐和物体交互几何关系；仅对骨盆追踪器高度做缩放。
  • 通过实时 IK 预览界面（Mink 求解 + Viser 可视化）让操作者实时调整演示，满足可行性与任务约束。
  • IK 子任务：追踪五个关键点的平移/旋转、避免自碰撞、姿态正则化维持自然构型。
  • 关键设计：控制虚拟机器人仅受运动学约束，认知负荷远低于遥操作物理机器人。

分层策略框架

  • 高层策略：Diffusion Policy（5 Hz），输入相机图像 + 本体感觉，输出递推视界任务空间轨迹（动作块：10 个路点覆盖未来 2 秒）。
  • 低级控制器：RL 训练的全身控制器（50 Hz），教师-学生框架（教师访问特权状态，DAgger 蒸馏为学生策略），学生观测含 25 步状态历史与过去动作。

自适应末端执行器跟踪奖励

  • 全身跟踪奖励：r_body = Σ_{χ∈{p,θ,v,w}} r(ē_χ^body, σ_χ)，其中 r(ē_χ, σ_χ) = exp(−ē_χ/σ_χ²)。
  • 自适应末端执行器奖励：r_EE = 𝕀(‖v_base^ref‖ < δ) · Σ_{χ∈{p,θ}} r(ē_χ^EE, σ_χ(v_EE^ref))。
  • σ_χ 基于参考末端执行器速度在 [σ_χ^min, σ_χ^max] 间线性插值（位置：0.01–0.1 m；旋转：5°–20°；v_max=0.1 m/s，v_min=0.05 m/s）。
  • 基座速度超过 δ 时通过 𝕀(·) 门控停用末端执行器跟踪，优先保证快速运动稳定性。
  • 课程学习：w_EE 从 0.0 线性增至 0.5，σ_p^min 在训练步 10k–15k 间从 0.1 m 退火至 0.01 m。

变速增强

  • 每 0.02 s 采样速度缩放因子 s ~ N_[0.25, 1.25]（1.0, σ²），σ 在训练步 10k–15k 间从 10⁻⁴ 线性增至 1.0。
  • 慢速变化给策略足够时间修正小误差，促进高精度运动学习。

策略接口改进

  • 目标姿态作为高层动作参考：不使用实际执行姿态作为动作块参考帧（会导致轨迹突然反向），改用前一个计划目标姿态，自然连接当前块与前一块，保持动态任务（如投掷）的平滑动量。
  • 非视觉锚定关键点的相对姿态跟踪：骨盆和脚部缺乏直接视觉锚定，推理时累积不可恢复误差（>5 cm 漂移）；修改跟踪目标为当前动作块内的相对变换而非绝对变换。默认 3 关键点（夹爪 + 基座），可扩展至 5 关键点（加脚部）。

关键创新

  1. 人在回路 IK 预览替代运动学重定向：这是对“人类演示 → 机器人策略”范式的根本性重构。传统方法要么缩放轨迹（物理场景不可缩放），要么用后处理重定向（破坏视觉-空间对齐）。HuMI 让人类在采集时通过实时 IK 反馈主动调整动作，既保证了机器人可行性，又保留了原始空间几何关系。消融显示去除该环节后求婚任务成功率从 85% 崩至 10%，证明这是系统成立的前提而非锦上添花。

  2. 自适应末端执行器奖励 + 变速增强的课程学习：低级控制器面临“稳定全身运动”与“精确末端对齐”的内在矛盾——快速运动时追求末端精度会导致摔倒，慢速时过度强调稳定则末端误差不可接受。通过 σ_χ 随参考速度动态缩放、基座速度门控停用末端奖励、以及变速增强让策略在不同速度尺度间切换学习，这套机制让单一控制器同时掌握慢速精确操作（深蹲捡瓶）与快速动态动作（投掷）。消融显示去除变速增强后拔剑成功率从 85% 降至 50%，去除自适应奖励后深蹲捡瓶从 85% 降至 50%。

  3. 非视觉锚定关键点的相对姿态跟踪：骨盆和脚部没有视觉锚定，绝对姿态跟踪在推理时因低级控制器误差累积导致 >5 cm 漂移，行走清洁任务中成功率从 75% 直接崩溃至 0/10。改为动作块内相对变换后，误差被限制在块内而非跨块累积，这是让“全身轨迹”作为策略接口真正可用的关键工程决策。

实验与结果

能力任务（域内设置，单环境 100 个演示）

任务 成功率 关键消融
求婚（跪地拾环） 17/20 = 85% 去除 IK 适配：1/10 = 10%；去除全身监督：0/10
拔剑 17/20 = 85%（EE 跟踪误差 15.7 mm） 去除变速增强：5/10 = 50%，误差增至 21.2 mm

行走清洁 15/20 = 75% EE-only：6/10 = 60%；EE+pelvis：15/20 = 75%；EE+pelvis+feet：7/10 = 70%；绝对姿态跟踪：0/10

泛化实验（蹲下拾取）

  • 训练：7 环境 × 7 瓶子 = 350 个演示；测试：4 未见环境 + 6 未见物体（含形状纹理差异显著的花瓶）。
  • 总体成功率：14/20 = 70%。

消融实验（自适应末端执行器奖励，深蹲捡瓶）

  • 固定奖励基线（σ_p=0.01 m，σ_θ=5°，ω_EE=0.5）：成功率从 17/20 = 85% 降至 5/10 = 50%。
  • 典型失败：深蹲阶段失去平衡摔倒，或陷入勉强稳定但无法继续操作的姿态。

边界与局限

论文未在结论部分明确列出局限性（片段截断）。从方法细节可推断的边界包括：系统依赖视觉追踪器，需要足够的环境纹理和光照条件（Vive Tracker 在弱纹理或强光照下可能失效）；低级控制器并非通用目的，训练配置统一但未验证跨任务泛化；评估仅在 Unitree G1 单一平台上进行，未在其他类人机器人上验证；5 关键点配置（加脚部）仅在行走清洁任务中报告了结果（70%），未在全部任务上系统评估；变速增强的 s_min、s_max、Δ 等超参数具体取值未披露；未讨论动态行走与操作切换的鲁棒性边界、长时间自主运行的稳定性、以及更复杂地形上的表现。

工程启示

复现时优先核对三个最容易踩坑的环节：第一，人在回路 IK 预览的实时性——Mink 求解必须足够快（否则操作者无法流畅调整动作），且 IK 目标必须使用原始未缩放轨迹（仅缩放骨盆高度），任何试图“优化”演示轨迹的做法都会破坏视觉-空间对齐。第二，低级控制器的课程学习调度——w_EE 从 0 线性增至 0.5、σ_p^min 在训练步 10k–15k 间从 0.1 m 退火至 0.01 m、变速增强 σ 同步从 10⁻⁴ 增至 1.0，这三个调度必须同步进行，单独调整任何一个都可能破坏“先稳定全局运动、再精确末端对齐”的学习顺序。第三，非视觉锚定关键点的相对姿态跟踪——这是最容易忽略但影响最大的接口设计，绝对姿态跟踪在行走清洁任务中直接导致 0/10 崩溃，务必在动作块内使用相对变换而非全局绝对变换。数据采集效率对比时注意 TWIST2 是遥操作基线，HuMI 的优势在深蹲/跪地类任务上尤其显著（TWIST2 完全无法完成求婚任务），若下游任务以直立操作为主，此优势可能缩小。硬件上注意 GoPro 时间戳同步需通过陀螺仪与追踪器角速度的交叉关联实现，夹爪宽度提取依赖 ArUco 标记检测，这两处是数据质量的关键瓶颈。
