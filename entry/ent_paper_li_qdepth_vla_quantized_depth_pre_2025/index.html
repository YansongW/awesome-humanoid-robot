QDepth-VLA

QDepth-VLA: Quantized Depth Prediction as Auxiliary Supervision for Vision-Language-Action Models

领域
AI 模型与算法软件中间件
层级
智能层
审校
待审校

摘要

QDepth-VLA 是由中国科学院大学人工智能学院、中国科学院自动化研究所及北京中科慧灵机器人技术有限公司于2025年提出的视觉-语言-动作大模型，用于机器人精细操作。其核心贡献在于引入辅助深度预测任务，通过VQ-VAE编码器预测量化深度潜变量令牌，增强模型的空间感知与推理能力。实验表明，该方法在仿真基准和真实任务中均展现出强大的空间推理性能。

来源与参考

  • QDepth-VLA: Quantized Depth Prediction as Auxiliary Supervision for Vision-Language-Action Models (arXiv)
  • QDepth-VLA source

概述

CrayonRobo 提出一种以 2D 蜡笔风格视觉提示作为辅助监督的 VLA 训练框架，将末端执行器的接触点、姿态方向与移动方向编码为彩色线条叠加在 RGB 图像上，并配合文本数值输入消除歧义。该方法在 SAPIEN 模拟器的 16 个操作任务上，以仅微调适配器与投影模块的方式，显著超越 Flowbot、ManipLLM、Implicit3D 与 RT-Traj 等基线。

它改变了什么

现有 VLA 模型在传达任务目标时面临根本性矛盾：自然语言指令要么模糊要么过度冗长，目标图像携带大量与操作无关的背景冗余，而视频演示则带来沉重的编码与生成负担。RT-Sketch 仅描述最终状态，丢失中间关键帧的过渡信息；RT-Trajectory 只给出位置轨迹，不表达接触时的姿态与接触后的运动方向，且长轨迹与关键帧重叠时易造成规划混乱。CrayonRobo 的实质改变在于：它不再试图从高维、冗余的视觉或语言模态中隐式推断操作意图，而是将“要接触哪里、以什么姿态接触、接触后往哪移动”这三个核心决策显式地编码为低维、可解释的 2D 视觉提示，使模型从被动理解输入转变为主动对齐输出动作与提示的几何约束。这一转变将任务规约从“描述世界状态”重构为“指定交互协议”，从而绕开了语言歧义与视觉冗余的纠缠。

方法拆解

提示设计

  • 四种颜色编码：蓝色圆点标记接触点（2D 位置 a₀ᵖ ∈ ℝ²）；红色与绿色线段分别表示末端执行器接触时的 z 轴（a₀ᶻ）与 y 轴（a₀ʸ）方向；黄色线段表示接触后的移动方向（a₀ᵐ）。所有方向均为 ℝ² 中的单位向量。
  • 文本输入同步给出对应数值（如接触点坐标、方向向量分量），以消除多线条重叠时的视觉歧义。

数据生成

  • 在 SAPIEN 模拟器中，基于规则启发式与约 1500 个 PartNet-Mobility 物体形状交互，记录成功接触的 3D 位姿（接触点、z 轴 a₀ᶻ′、y 轴 a₀ʸ′）与移动方向 a₀ᵐ′。
  • 将 3D 接触点反投影至 2D 图像，沿方向向量定位远端 3D 点并再次反投影，连接两点形成彩色线段。共收集约 10000 个训练样本，耗时约 6-8 小时。

模型与训练

  • 骨干遵循 Li et al. 2024 的开源 VLA 架构，仅微调 LLaMa 中的适配器（Hu et al. 2021）与多模态投影模块，冻结其余参数。CLIP 视觉编码器提取图像特征，LLaMa 预训练分词器编码文本。
  • 位姿预测表述为语言建模任务：将归一化 3D 方向向量离散化为 100 个 bin（范围 [-50, 50]，跨度 0.02），以交叉熵损失 ℒ_T 监督。
  • 附加两项几何约束：
  • 正交损失 ℒ_O：对模型输出的 a₀ᶻ 与 a₀ʸ 施加 Gram-Schmidt 正交约束。
  • 投影损失 ℒ_P：将预测 3D 方向反投影回 2D，与输入提示方向计算余弦相似度损失，公式为 ℒ_P = (1 - (a₀ᶻ·a₀ᶻ)/(‖a₀ᶻ‖‖a₀ᶻ‖)) + (1 - (a₀ʸ·a₀ʸ)/(‖a₀ʸ‖‖a₀ʸ‖)) + (1 - (a₀ᵐ·a₀ᵐ)/(‖a₀ᵐ‖‖a₀ᵐ‖))。
  • 总损失 ℒ = λ₁ℒ_T + λ₂ℒ_O + λ₃*ℒ_P，其中 ℒ_P 根据输入提示类型动态调整（无移动方向时排除对应项）。
  • 训练采用渐进式信息量输入对（图 2 (a)-(d)），逐步引入接触点、姿态方向与移动方向，帮助模型理解各提示的物理语义。

推理

  • 自动模式：Grounded-DINO 检测物体边界框并取中心为蓝圈，自动生成 32 条均匀采样（360 度）的 2D 方向线，由 GPT-4 选择代表 z 轴、y 轴与移动方向的线条（红、绿、黄）。
  • 手动模式：用户直接在图像上绘制蜡笔提示。
  • 交互策略：a₀ᵖ 通过深度信息与相机参数映射为 3D 位置 a₀ᴾ；a₀ᶻ 与 a₀ʸ 共同决定旋转矩阵；若提供 a₀ᵐ 则按预测方向执行接触后运动。对垂直于相机的方向向量添加轻微噪声以增强可见性。

关键创新

  1. 显式几何提示替代隐式语义推断：将接触位姿与运动方向编码为 2D 彩色线条，使模型输出与输入提示形成直接的几何对应关系（投影损失 ℒ_P），而非依赖语言或图像的隐式关联。这是对 RT-Sketch 与 RT-Trajectory 的根本性超越——前者只给最终状态，后者只给位置，而 CrayonRobo 同时表达“姿态”与“方向”。
  2. 文本数值消歧与离散化语言建模：在文本输入中显式给出方向向量数值，消除多线条重叠的视觉歧义；同时将 3D 方向离散化为 100 个 bin 并以交叉熵训练，使连续几何量能无缝融入 LLM 的 token 预测框架，避免了回归头与语言模型的结构冲突。
  3. 正交与投影双重几何约束：ℒ_O 确保 z 轴与 y 轴正交（符合刚体旋转约束），ℒ_P 将 3D 预测拉回 2D 提示平面，形成闭环监督。这种“从 2D 提示到 3D 输出再反投影回 2D”的循环一致性设计，是现有 VLA 方法未见的。

实验与结果

实验在 SAPIEN 模拟器上进行，使用 Franka Panda 夹爪，评估 16 个操作任务（含 Seen 与 Unseen）。成功率定义为物体部分移动距离超过阈值的二元标准。

边界与局限

论文未明确列出局限章节。从事实要点推断：实验全部在 SAPIEN 模拟器进行，未提供真实机器人部署的详细评估；未讨论模型对极端噪声（如提示线条完全遮挡）或完全缺失提示时的鲁棒性边界；未与其他方法在真实硬件上进行对比。数据收集依赖模拟器中的规则启发式，真实世界的接触位姿标注成本可能显著更高。此外，GPT-4 在自动提示生成中扮演关键角色，其选择质量直接影响性能，但论文未量化 GPT-4 选择错误的概率或影响。

工程启示

复现时首先核对数据生成管线：3D 接触点反投影到 2D 的相机参数标定必须与训练时完全一致，否则投影损失 ℒ_P 会引入系统性偏差。其次，离散化 bin 的边界（[-50, 50] 与跨度 0.02）直接影响文本监督的精度，若下游任务需要更高方向精度，需重新设计 bin 划分而非直接沿用。最容易踩坑的是 ℒ_P 的动态调整逻辑——当输入无移动方向提示时，必须从损失中排除对应项，否则模型会被迫学习不存在的监督信号。训练时仅微调适配器与投影模块，但需确认 LLaMa 的冻结参数不会因梯度累积产生数值漂移。推理阶段，GPT-4 选择方向线时建议固定随机种子并多次采样取众数，以降低单次选择的方差。对于下游团队，若任务涉及长时序列，建议将关键帧提示按时间顺序拼接输入，并验证模型对提示顺序的敏感性——论文未明确此点，需自行实验确认。
