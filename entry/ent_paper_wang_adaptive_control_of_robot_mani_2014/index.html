具有不确定运动学和动力学的机器人机械臂自适应控制

Adaptive Control of Robot Manipulators With Uncertain Kinematics and Dynamics

摘要

本文针对机器人操作臂在运动学与动力学参数均不确定情况下的自适应控制问题，提出了两种基于逆雅可比反馈与分离自适应环路的控制方案，实现了任务空间轨迹跟踪。核心贡献在于控制器具有分离特性，且第一种方案经适当修改后可在不牺牲保守增益选择的前提下提升性能。

来源与参考

  • Adaptive Control of Robot Manipulators With Uncertain Kinematics and Dynamics

概述

CoT4AD 是一个面向自动驾驶的统一 VLA 框架，通过显式建模「感知-问题-预测-动作」四阶段链式思维推理，在 nuScenes 与 Bench2Drive 上取得领先的规划性能。其核心贡献在于将多步 CoT 推理与条件扩散模型结合，在训练时对齐推理与动作空间，推理时以隐式单次前向传播实现高效规划。

它改变了什么

现有端到端自动驾驶 VLA 模型普遍将 LLM 当作从感知到数值输出的整体映射器，忽略了其多步推理能力，导致在需要因果推理的复杂场景中预测不可靠。此前 CoT 方法（如 CoT-VLA、ECoT）多聚焦于受限的具身或机器人场景，未针对自动驾驶所需的精确数值推理、长时程规划与动态环境鲁棒性进行定制。CoT4AD 真正改变的是将「链式思维」从一种提示技巧提升为 VLA 架构中的显式训练目标，使感知、语言推理、未来预测与轨迹规划在统一框架内形成可优化的推理链，而非简单的输入-输出映射。

方法拆解

整体流程

训练时显式建模 perception–question–prediction–action 四阶段 CoT 链，推理时执行隐式 CoT，单次前向传播直接输出轨迹。

感知模块

  • 多视角图像经 2D backbone（EVA-CLIP）提取多尺度特征，通过相机参数投影至 BEV 空间。
  • 使用 PB-SSM 框架进行多视角融合，生成 BEV 特征。
  • 两个视觉分词器：MapTokenizer（静态元素）与 ObjectTokenizer（动态物体），分别生成 map tokens 与 object tokens。

推理与预测

  • VQA 推理：基于 prompt 监督微调，对齐语言与视觉空间。
  • 未来预测：条件潜在 DiT 模型，以 VLM 嵌入为条件扩散当前帧潜在表示，经 VAE 解码重建未来帧。

轨迹规划

  • 采用 VLM 条件扩散规划，遵循无潜在空间的 vanilla 扩散模型。
  • 噪声从动作锚点初始化，锚点通过 K-Means 聚类数据集得到。
  • 扩散 transformer 接收噪声动作与条件嵌入，预测去噪轨迹与分类分数。

训练与推理差异

  • 训练时联合优化视觉编码器、视觉扩散 transformer、规划扩散 transformer 与 LLM。
  • 推理时直接从环境 token 与 prompt 生成条件嵌入，每个去噪步骤以上一步预测轨迹为输入，使用 DDIM 更新，仅需 2 步去噪。

关键创新

  1. 显式 CoT 训练链：将「感知-问题-预测-动作」作为可优化的训练目标，而非推理时提示，使模型在训练阶段即对齐推理空间与动作空间，这是与现有 CoT-VLA 类方法的本质区别。
  2. 双扩散架构：分别对潜在图像（未来预测）与动作轨迹（规划）进行条件扩散，共享 VLM 条件嵌入，实现感知-预测-规划的统一概率建模，缓解了扩散模型训练不稳定性。
  3. 隐式推理加速：推理时不显式生成中间推理步骤，以单次前向传播直接输出轨迹，在保持规划性能的同时将去噪步数压缩至 2 步，解决了多步 CoT 推理的计算复杂度问题。

消融实验

  • 分词器消融（Table 3）：T_map+T_obj+T_bev 组合最佳（DS 80.24，SR 55.22）；仅 T_bev 效果（SR 39.64）显著低于基于感知标签的分词器（SR 50.88），表明感知标签提供更有价值的规划引导。
  • CoT 预训练消融（Table 4）：完整组合（ID 5）DS 80.24、SR 55.22；仅未来模块（ID 4）DS 72.38、SR 45.22，显著高于仅感知（ID 2）的 DS 66.44、SR 36.86，说明未来扩散模块贡献最大，因其通过自监督学习获得更丰富的感知表征。

边界与局限

论文未明确列出作者承认的局限性。从方法本身推断：受限于多步 CoT 推理的计算复杂度，推理时虽压缩至 2 步去噪，但训练时仍需完整四阶段联合优化；扩散模型的训练不稳定性可能影响复现；实验仅在 nuScenes 与 Bench2Drive 两个数据集验证，未涉及真实道路测试或极端天气/光照条件；闭环评估基于 CARLA V2 仿真，与真实物理环境存在 sim-to-real 差距。

工程启示

复现时先核对三个关键点：其一，感知分词器的消融结果（Table 3）表明 T_bev 单独使用效果不佳（SR 39.64），必须与 T_map、T_obj 联合使用，直接基于视觉特征的分词器设计需谨慎；其二，CoT 预训练中未来扩散模块贡献最大（ID 4 vs ID 2，SR 45.22 vs 36.86），若计算资源受限可优先保留该模块；其三，推理去噪步数仅 2 步，但训练时扩散调度截断为 50/1000，需确保训练与推理的噪声调度一致。工程上最容易踩坑的是 VLM 条件嵌入与扩散 transformer 的维度对齐，以及 K-Means 动作锚点的聚类数量选择（论文未明确），建议先在 Bench2Drive 的 950 个训练 clips 上验证分词器组合，再扩展至全量数据。
