OmniContact: Chaining Meta-Skills via Contact Flow for Generalizable Humanoid Loco-Manipulation

摘要

OmniContact 是一个面向人形机器人全身移动操作任务的层次化框架，由上海交通大学等机构提出。其核心创新在于引入“接触流（Contact Flow）”这一紧凑表示，包含关键身体轨迹与时间序列二值接触信号，并以此为基础构建了低层技能库（CF-Track）与高层规划器（CF-Gen）。实验表明，该方法在长时序任务中成功率显著优于现有基线，并能与 VLM 结合实现语义驱动的复杂行为。

概述

OmniContact 提出以“接触流”（Contact Flow）作为人形机器人移动操作中高层语义规划与低层全身执行之间的统一接口，通过 CF-Gen 规则规划器与 CF-Track 强化学习控制器分层协作，实现长时程、可恢复的技能链式组合。核心贡献在于用稀疏非均匀采样的身体轨迹加四维二值接触信号，同时兼顾表达力与紧凑性，在仿真中显著超越现有基线。

它改变了什么

人形移动操作长期卡在“表示”的选择上：完整的人-物交互（HOI）状态精度高但维度爆炸，难以支撑高层规划；隐式技能嵌入紧凑却不可解释，组合时缺乏可靠性保证。现有强化学习方案要么依赖遥操作开环执行、要么需要逐帧全身参考，本质上都回避了“技能如何被高层任务调用”这一核心问题。OmniContact 真正改变的是将“接触”从执行细节提升为规划原语——它不再让高层规划器去预测稠密运动学，而是只输出物体级目标，由接触流作为中间语言衔接语义与物理。这一改动让 VLM 等基础模型得以介入长时程任务分解，同时保留了低层策略的鲁棒性与恢复能力，是接口设计上的范式转移。

方法拆解

接触流（Contact Flow）表示

  • 形式化：在时间步 t，接触流 F_t = {(b_{t+k}, c_{t+k})}_{k∈T}，其中 T = {0,1,2,3,4,8,12,16,24,32,50} 为非均匀未来帧偏移。
  • b 为稀疏身体运动目标（躯干、手腕、踝关节位置与朝向），c ∈ {0,1}^4 为四维二值接触信号，指定末端执行器接触状态。
  • 非均匀采样在近处密集、远处稀疏，兼顾短期精度与长期规划视野。

CF-Track（低层控制器）

  • 统一策略跟踪接触流目标，输入为 x_t = [F_t, H_t]，H_t 为 K=5 步历史缓冲。
  • 观测包含本体感受（关节运动学、基座朝向、末端执行器位置、上一动作）与物体状态（相对 6D 位姿、包围盒）。
  • 奖励：r_t = λ_track·r_t^track + λ_amp·r_t^amp + λ_reg·r_t^reg，最优权重 W_track–W_amp = 0.85–0.15。
  • Actor 与 Critic 均采用 Transformer（隐藏维度 [512,256,128]，3 层，8 头），而非 MLP。

CF-Gen（中层规划器）

  • 基于规则的参考合成器：给定物体级目标、当前状态、物体位姿与尺寸，生成密集参考运动。
  • 相位模板库：每个元技能分解为有序相位块（如搬运：接近→预抓取→抬升→行走→释放），每相位有明确接触语义。
  • 关键帧生成：仅末端执行器放置需精确时用 IK（最多 20 次迭代），纯移动相位仅指定踝关节姿态，其余用默认名义姿态。
  • IK 优化变量：骨盆高度 z_pelvis、骨盆俯仰 θ_pitch、所有关节自由度 q，严格排除腰部横滚与偏航。
  • 轨迹插值：平移与关节用 LERP，旋转用 SLERP。
  • 在线重规划：50 Hz 监控，检测偏差 δ_t 超阈值 ε 时中止当前计划并从当前状态重规划。

层次化执行与 VLM 集成

  • CF-Gen 将任务目标转化为物体中心接触流片段，CF-Track 执行并持续监控，相位完成或失败时 CF-Gen 更新状态并合成下一片段。
  • VLM（Gemini 3.1 Pro Preview）仅做物体级规划：识别物体、分配目标区域/位姿、选择元技能，输出 JSON 格式计划，不预测任何低层运动学。

关键创新

  1. 接触流作为可组合的中间表示：将接触信号显式编码为二值时序向量，与稀疏身体轨迹耦合。消融显示，加入接触项（C）将 [T, EE] 基线的成功率从 11.50% 提升至 98.70%，证明接触是技能组合的关键语义锚点，而非冗余细节。
  2. 规则规划器与学习控制器的解耦：CF-Gen 用启发式相位模板与 IK 生成参考，CF-Track 用 RL 跟踪并平滑伪影。这一设计避免了端到端学习对长时程组合的脆弱性，同时让重规划逻辑透明可调试。
  3. VLM 接口的极简约束：将基础模型的输出限制为物体级子目标列表，不要求预测关节轨迹或接触时序。这使开放词汇语义推理（如“把圆柱体放进篮子”）能直接驱动低层接触丰富的执行，且失败模式可归因（模糊接地、不可行布局、执行偏差）。

  • 在线重规划显著提升：Push Suitcase 从 82.5% 提升至 94.5%（平均重规划 0.77 次），Stack Boxes 从 56.6% 提升至 80.5%（0.96 次）。
  • 消融关键发现：显式接触建模（C）是成功率跃升的主因；加入全关节目标（Dof）反而导致失败（0.00%），说明过度指定自由度会压制策略的适应性。
  • 奖励平衡：纯跟踪（1.0–0.0）稳定性仅 46.30%，最优平衡（0.85–0.15）达到 98.70% 成功率且稳定性 58.80%。
  • 鲁棒性：Carry Box + Drop 最终成功率 92.5%（平均重规划 1.64 次），Object Pose Offset 下 97.5%。
  • 长时程：协议 I（单物体顺序目标）40 分钟存活率 100%，但协议 III（多物体）40 分钟存活率降至 10.0%，平均物体掉落 26.0 次。
  • 数据规模：从 10%（2.2h）扩展到 100%（22.3h），成功率与物体精度均提升。

边界与局限

论文未明确列出局限性声明，但可从实验推断：欠驱动夹爪限制精细操作，接触流扩展到灵巧手是未竟之事；基于规则的 CF-Gen 在高度动态场景（如快速踢球）中表现不佳，作者设想用可学习数据驱动方法替代启发式接触锚生成。所有定量结果均在仿真（Isaac Lab 训练、MuJoCo 评估）中获得，真实部署仅在 Unitree G1 上做了定性展示，无定量数据。长时程多物体任务（协议 III）成功率衰减严重（40 分钟仅 10%），表明技能链式组合在物体数量增加时仍存在累积误差问题。球类任务成功率较低（Relocate Ball 72.5%，Kick Ball 76.5%），因模拟球光滑刚性易滑动。

工程启示

复现时优先核对三点：一是接触流采样偏移 T 与历史窗口 K=5 的配置，这是表示紧凑性的关键；二是奖励权重 W_track–W_amp = 0.85–0.15，偏离此值会显著影响成功率（0.5–0.5 时仅 0.10%）；三是 IK 优化中排除腰部横滚与偏航的约束，这是保持躯干稳定的前提。最容易踩坑的地方在于：加入全关节目标（Dof）会破坏策略适应性（成功率降至 0.00%），因此 CF-Gen 合成参考时务必只指定躯干、手腕、踝关节，其余自由度交给策略自主决策。对下游团队，建议将接触流作为模块间接口标准——高层规划器只输出物体级目标，低层策略只消费接触流，中间不传递稠密运动学。重规划频率 50 Hz 与偏差阈值 ε 的设定需根据任务动态调整，推任务平均重规划 0.77 次即可显著提升成功率，但多物体长时程任务中重规划次数会随掉落事件激增，需预留计算余量。
