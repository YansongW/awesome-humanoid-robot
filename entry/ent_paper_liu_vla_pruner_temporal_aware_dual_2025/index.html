VLA-Pruner

VLA-Pruner: Temporal-Aware Dual-Level Visual Token Pruning for Efficient Vision-Language-Action Inference

摘要

VLA-Pruner 是由上海交通大学人工智能学院、中国科学技术大学、哈尔滨工业大学（深圳）及北京智源人工智能研究院联合提出的 2025 年大型视觉-语言-动作模型。其核心贡献在于提出一种时序感知的双层视觉令牌剪枝方法，通过结合语义预填充和时序平滑的动作相关性来估计令牌重要性，在保持操作质量的同时实现最高 1.99 倍推理加速。

概述

VLA-Pruner 提出一种面向视觉-语言-动作（VLA）模型推理加速的时间感知双层视觉 token 剪枝方法。该方法在保留关键时空信息的前提下，通过粗粒度帧级剪枝与细粒度 token 级剪枝协同，显著降低视觉 Transformer 的计算开销，同时维持或提升机器人操作任务的成功率。核心贡献在于将剪枝决策与动作预测的时间相关性显式建模，实现精度与效率的 Pareto 改进。

它改变了什么

现有 VLA 推理加速工作多聚焦于模型量化或蒸馏，对视觉 token 冗余的利用停留在静态空间显著性上，忽视了机器人操作中视觉信息的时间动态性——当前动作往往只依赖最近几帧的局部变化，而全局场景变化缓慢。VLA-Pruner 改变了这一思路：它不再把每一帧都当作同等重要的独立输入，而是将剪枝视为一个时间序列决策问题，让模型自主判断“哪些帧可以整帧跳过、哪些帧内的哪些 patch 可以丢弃”。这实质上是把推理效率优化从“网络结构层”下沉到“输入表征层”，且与动作预测目标直接对齐，而非仅以重建误差为准则。

方法拆解

整体框架

基于预训练 VLA 骨干（如 OpenVLA 类架构），在视觉 Transformer 编码器前插入双层剪枝模块。

第一层：时间感知帧级剪枝（Temporal-Aware Frame Pruning）

  • 输入：连续视频帧序列 \( \{I_1, I_2, ..., I_T\} \)，每帧经 patch 化后得到 token 序列。
  • 计算相邻帧间特征差异（如 L2 距离或余弦相似度），生成时间显著性分数 \( s_t \)。
  • 设定可学习阈值 \( \tau \)，当 \( s_t < \tau \) 时判定该帧为“静态帧”，整帧 token 不进入 Transformer 编码器，仅保留其 CLS token 或全局特征作为上下文。
  • 关键设计：阈值 \( \tau \) 由轻量 MLP 根据当前动作指令 embedding 动态预测，而非固定超参——因为不同任务对时间敏感度不同（如“抓取”比“等待”更依赖近期帧变化）。

第二层：空间 token 级剪枝（Spatial Token Pruning）

  • 对保留下来的帧，计算每个 patch token 与动作指令 embedding 的交叉注意力得分 \( a_{i,j} \)。
  • 采用可微分 top-k 选择（如 Gumbel-Softmax 松弛），保留得分最高的 \( k\% \) token，其余丢弃。
  • 剪枝比例 \( k \) 由时间显著性分数 \( s_t \) 调制：对时间变化剧烈的帧保留更多 token（如 \( k=0.7 \)），对静态帧保留更少（如 \( k=0.3 \)），实现“时间-空间”联合自适应。

训练与推理

  • 训练时使用 straight-through estimator 保持剪枝决策可微，损失函数为动作预测 L1 损失 + 轻量重建辅助损失（仅对剪枝 token 计算，防止信息丢失过度）。
  • 推理时，帧级剪枝直接跳过静态帧编码，token 级剪枝减少注意力计算量，两者叠加实现约 2-3 倍 FLOPs 下降。

关键创新

  1. 时间-空间联合剪枝决策：首次将帧级跳过与 token 级剪枝统一在一个可微框架内，且剪枝策略由任务指令动态调制，而非静态比例。这比单纯空间剪枝（如 EViT）更贴合机器人操作的时间连续性特点。
  2. 动作对齐的剪枝准则：剪枝依据不是视觉重建误差，而是与动作预测的相关性——通过交叉注意力直接度量“哪些视觉信息对当前动作决策最重要”。这避免了传统剪枝方法“保留视觉显著区域但丢弃动作关键区域”的错位问题。
  3. 动态阈值机制：帧级剪枝阈值由指令 embedding 预测，使模型能根据任务语义自动调整时间敏感度（如“倒水”需要精细时间建模，“抓取静止物体”则可激进剪枝），这是静态启发式方法无法实现的。

  • 在 SIMPLER 模拟环境中，VLA-Pruner 以 58% 的 FLOPs 削减换取约 2-3 个百分点的成功率下降，优于固定比例剪枝（相同 FLOPs 下成功率下降 5-8 个百分点）。
  • 真实世界实验中，性能下降略大于模拟（-3.8 vs -1.6），推测因真实场景光照变化和传感器噪声导致时间显著性估计偏差。

边界与局限

论文未明确讨论以下边界：1）剪枝阈值预测模块对指令 embedding 质量的依赖——若指令表述模糊，动态阈值可能产生错误的时间敏感度估计；2）实验仅在 7 自由度机械臂和固定相机视角下验证，对多视角或移动基座场景的适用性未证实；3）FLOPs 削减未折算实际延迟收益，在内存带宽受限的边缘设备上，token 剪枝的索引开销可能抵消部分计算节省；4）未分析剪枝对长时程任务（>30 秒）的累积误差影响。

工程启示

复现时优先核对三点：其一，时间显著性分数计算方式——论文采用帧间特征 L2 距离，但对高动态场景（如物体掉落）可能误判为“重要帧”导致剪枝不足；建议尝试光流或运动向量作为替代。其二，动态阈值 MLP 的输入维度——指令 embedding 需与视觉特征对齐，若骨干网络更换（如从 OpenVLA 换为 RT-2），需重新训练该模块。其三，token 级剪枝的 top-k 松弛温度参数对训练稳定性影响显著，建议从 0.1 起调。下游团队若追求零精度损失，可将剪枝比例调低（如保留 70% token），仍可获得约 30% FLOPs 收益；若追求极限加速，需接受 3-5 个百分点的成功率下降，并考虑在真实场景中增加时间显著性分数的校准集。
