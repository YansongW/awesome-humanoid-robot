Geometry-Aware Motion Latents for Learning Robust Manipulation Policies

摘要

GeoMoLa（Geometry-Aware Motion Latents）是一种学习离散运动潜码的方法，通过预测操作过程中点云的演变而非重建视觉观测来提取运动模式。该方法仅需单视角RGB-D输入即可达到最先进性能，在多种操作基准上表现优异，其核心贡献在于利用四维几何目标（空间几何随时间变化）迫使潜表示编码真实物理运动而非外观模式。

来源与参考

  • Geometry-Aware Motion Latents for Learning Robust Manipulation Policies (arXiv)

概述

该论文提出 GeoMoLa，一种通过显式 4D 时空建模（3D 点图序列）学习几何感知运动潜变量（motion latent）的机器人操作策略框架。作者将自监督未来预测与离散化运动原语词汇表相结合，用于条件化 3D 去噪 Transformer 生成可执行轨迹，在 RLBench、CALVIN 及真实世界任务中显著超越现有基线。核心贡献在于用可迁移的几何运动表征替代静态 3D 特征或 2D 视觉序列，提升了策略的样本效率、泛化能力与遮挡鲁棒性。

它改变了什么

现有操作策略大多将视觉观测视为静态 3D 场景快照（如 GNFactor、Act3D）或 2D 像素序列，动作预测缺乏对物体随时间运动的显式建模。这导致在遮挡、杂乱场景及需要精细空间推理（如堆叠、对齐）的任务中，策略容易因缺乏时间动态信息而失败。GeoMoLa 改变了这一范式：它不再仅仅从当前观测推断动作，而是先学习一个“接下来场景会如何运动”的隐空间表征，并以此作为动作生成的高层条件。这种从“感知静态几何”到“预测动态几何”的转变，是其在长时程任务和真实世界迁移中性能提升的根本原因。

方法拆解

方法分为两个阶段：几何感知运动潜变量学习与条件动作生成。

运动潜变量学习（4D 动力学）

  • 点图编码：将 RGB-D 观测反投影为点图 P^t ∈ R^{H×W×3}，由 3D 感知 VAE（编码器 ψ^enc、解码器 ψ^dec）映射到潜空间 h_pm^{t'} = ψ^enc(P^{t'})。该 VAE 从预训练 RGB VAE（Blattmann et al., 2023）初始化，并在点图上微调。
  • 未来预测：条件扩散模型 ψ^diff 基于历史潜变量与运动潜变量 z^t 预测未来 w 步潜变量：ĥ_pm^{t+1:t+w} = ψ^diff(h_pm^{t-w+1:t}, z^t; φ)。训练目标为去噪损失 L_diff^pm = E_{k,ε}[||ε - ε_φ(h_k, k, h_pm^{t-w+1:t}, z^t)||^2]，其中 h_k 为噪声潜变量。
  • 联合训练：同时训练 RGB 预测分支（L_diff^rgb），共享运动潜变量 z^t。总损失 L_total = L_diff^pm + L_diff^rgb + L_vq，其中 L_vq = ||sg[f^t] - c||_2^2 + β||f^t - sg[c]||_2^2 为 VQ-VAE 损失，迫使相似运动收敛到离散码本，形成可复用的运动原语词汇表。

条件动作生成（3D 去噪 Transformer）

  • 输入标记化：四类 token 输入 ε_θ：
  • 运动潜变量标记：离散 z^t 通过嵌入 E_z ∈ R^{n_s × d_code} 映射。
  • 轨迹标记：噪声动作经 MLP 编码，拼接 3D 位置 p^{t+k}。
  • 场景标记：冻结 CLIP-ResNet50 提取特征 F，通过深度图与相机内参提升至 3D 位置 q_ij。
  • 本体感受标记：机器人状态 c^t 经 MLP 编码，加上末端执行器位置嵌入。
  • 注意力机制：第一阶段对轨迹、场景、本体感受 token 执行自注意力，使用旋转 3D 位置编码（a_{q,k} ∝ x_q^T M(p_q - p_k) x_k）。第二阶段从这些 token 向运动潜变量嵌入执行交叉注意力，注入高层运动先验。
  • 训练与推理：训练时对干净动作块 a^{t:t+h-1} 加噪，损失为 L_θ = E_{i,ε}[||ε - ε_θ(a_i, i, o^t, z^t, c^t)||]，其中组件损失为 λ_p||ε_p - ε_{θ,p}||1 + λ_r||ε_r - ε||_1 + λ_g · BCE(g, ĝ)。推理时按 DDPM 迭代去噪，输出 6-DoF 位姿与夹爪命令。

关键创新

  1. 显式 4D 运动潜变量：不同于现有方法仅编码静态 3D 场景，GeoMoLa 通过自监督未来预测学习“场景如何运动”的隐表征。该表征作为动作生成的条件，使策略能理解物体动态，而非仅匹配静态模式。这是对操作策略表征空间的本质扩展。
  2. 离散运动原语词汇表：通过 VQ-VAE 将连续运动潜变量离散化，形成可复用的运动原语。这类似于语言中的“词”，使策略能组合已知运动模式应对新任务，提升了样本效率与泛化能力，尤其在多任务与零样本迁移场景中。
  3. 点图作为核心几何表征：选择点图而非体素或隐式场，因其在扩散过程中能自然保持场景结构，且比 3D 高斯变形更易学习。消融实验证明点图预测对旋转重型任务（成功率下降近 9%）至关重要，而 RGB 预测分支贡献较小。

边界与局限

论文未明确探讨以下边界：动态物体与非刚性物体。所有实验（仿真与真实）均假设操作对象为刚性或静态场景，未涉及移动目标、可变形物体（如布料、绳索）或流体。作者在局限中提及未来可扩展至可变形物体，但未给出当前方法在此类场景下的失败模式或性能边界。此外，真实世界实验仅 6 个任务、每个任务 20 条演示，样本规模有限，结论在更复杂工业场景中的普适性论文未明确。运动潜变量词汇表的大小（Codebook size 64）与维度（32）是否随任务复杂度增长而需要扩展，论文未明确。

工程启示

复现或应用 GeoMoLa 时，以下环节最易踩坑：

  1. 点图 VAE 初始化：必须从预训练 RGB VAE 初始化，并在点图上微调数轮。直接从头训练会导致几何重建质量差，进而影响运动潜变量学习。核对预训练权重来源与微调轮数（论文未明确具体轮数）。
  2. 联合训练平衡：L_total = L_diff^pm + L_diff^rgb + L_vq 中，两个扩散分支共享运动潜变量 z^t。若 RGB 分支权重过大，可能主导潜变量学习，削弱几何信息。建议先单独预训练点图分支，再联合微调。
  3. 注意力计算开销：场景标记数量为 H×W（如 256×256），需使用最远点采样（FPS）降采样（RLBench 20%、CALVIN 33%）。FPS 比例直接影响性能与速度，需根据 GPU 显存调整。
  4. 组件损失权重：λ_p、λ_r、λ_g 需调参。论文未给出具体值，建议从位置 L1 损失权重较高开始，旋转次之，夹爪 BCE 权重最低，因夹爪状态对噪声更敏感。
  5. 真实世界部署：使用 ALOHA 平台与 Intel RealSense（分辨率 640×480，下采样至 256×256）。推理时通过 MoveIt 执行目标夹爪位姿，需确保相机标定准确，否则 3D 提升（q_ij）误差会直接传导至动作生成。
