概述

世界模型 / WAM 构建（World Model/WAM Construction）是人形机器人产品开发流程 P12 阶段（VLA / WAM / AI 算法集成）下的三级工序节点，编号 P12.3.1。它通过视频生成模型、动力学模型、神经辐射场与 MPC 的结合，构建能预测动作后果的决策内核，支持长程规划与风险预判。它真正改变的不是单个预测算法的精度，而是让机器人从"感知-反应"的反射式控制升级为"预测-规划"的主动式决策。

核心内容

是什么：准确定义

世界模型 / WAM 构建是 P12.3「世界模型与人机交互」工作包下的首个三级子任务，属于方法（method）类型，归属领域为 07_ai_models_algorithms，价值链层级为 intelligence。它不是一个单一算法，而是一组工程化流程的集合：从输入梳理与目标量化开始，经过算法/控制方案设计、算法实现与仿真验证、算法调参与性能验证，最终以文档输出与下游交付收尾。

该工序节点的核心方法/工具组合为：视频生成模型、动力学模型、神经辐射场、MPC 结合。设计思考逻辑是"预测动作后果，支持长程规划与风险预判"；关键约束包括模型幻觉、计算开销、预测时域；完成标准/输出物为"世界模型预测能力演示、预测误差指标"。

为什么存在：痛点与历史定位

在人形机器人产品化进程中，传统控制方法（如纯 MPC 或强化学习）面临一个根本性困境：它们只能对"当前状态"做出反应，无法对"未来状态"进行推演。这导致机器人在面对长程任务（如"把客厅收拾干净"）时，缺乏将粗粒度指令分解为细粒度子任务并预判后果的能力。

世界模型 / WAM 构建正是为解决这一痛点而存在。它位于 P12 阶段的决策核心位置，上游承接感知栈（P12.1）输出的场景理解结果，下游为 VLA 与操作策略（P12.2）提供预测性先验。它的历史定位在于：将 AI 能力从"实验室演示"变成"可验收的工程交付物"——通过标准化的五步法（输入梳理→方案设计→实施/原型→验证闭环→文档交付），让世界模型的预测能力可量化、可追溯、可交付。

原理拆解

① 预测即规划：世界模型的核心逻辑

世界模型的核心思想是：如果机器人能预测动作的未来后果，它就能在真实执行之前进行"心智演练"。这一逻辑通过以下公式形式化表达：

\[ \hat{s}_{t+1} = f_{\theta}(s_t, a_t) \quad \Rightarrow \quad \pi^*(a_t) = \arg\max_{a_t} \sum_{k=0}^{H} \gamma^k \, r(\hat{s}_{t+k}, a_{t+k}) \]

其中 \(f_{\theta}\) 是学习到的世界模型（由视频生成模型、动力学模型或神经辐射场实现），\(H\) 是预测时域，\(\gamma\) 是折扣因子。该公式表明：最优动作 \(\pi^*\) 不是直接由当前状态决定，而是通过"预测未来状态序列 → 评估累积回报"的推演过程得出。

② 多模态融合：视频生成 + 动力学 + 神经辐射场

  • 视频生成模型负责预测像素级未来帧，提供视觉层面的后果预演；
  • 动力学模型负责预测物理量（位置、速度、接触力），提供力学层面的后果推演；
  • 神经辐射场（NeRF）负责隐式场景表征，提供几何与外观的连续建模；
  • MPC（模型预测控制）作为优化引擎，在预测时域内求解最优控制序列。

这四者的结合形成了"视觉-物理-几何-控制"的闭环预测链。工程判断：在实际部署中，视频生成模型的计算开销最大，因此通常以较低频率运行（如 1–5 Hz），而动力学模型与 MPC 以较高频率运行（如 50–100 Hz），形成"粗预测 + 细控制"的分层架构。

谁在用·应用案例

案例一：DSWAM 双系统世界动作模型（关联实体 ent_paper_dswam_a_dual_system_world_acti_2026）

DSWAM 通过双系统架构解决了现有 World Action Models 在复杂多步家庭任务中缺乏语言级规划接口的问题。其 System 1 作为默认控制路径，基于世界感知进行动作生成；System 2 仅在需要任务分解时激活，从短期视觉历史和全局任务提示中预测可执行的子任务。这一设计正是 P12.3.1 中"预测动作后果，支持长程规划"的典型实现。

案例二：WAM-TTT 测试时训练（关联实体 ent_paper_wam_ttt_steering_world_action_2026）

WAM-TTT 将人类视频作为自适应记忆融入冻结的 WAM 中，通过自监督视频预测任务将其编码进轻量级键-值记忆模块。测试时仅需未标注的人类视频即可更新记忆，无需额外机器人演示或任务微调。这体现了 P12.3.1 中"输入梳理与目标量化"的工程智慧——将人类视频这一上游输入转化为可量化的记忆更新目标。

案例三：CLASP 接触约束形状精化（关联实体 ent_paper_saund_clasp_constrained_latent_shape_2021）

CLASP 在变分形状网络的隐空间中维护粒子滤波器，通过将粒子投影到接触流形上，确保生成的形状同时符合网络先验与接触信息。这展示了世界模型如何利用多模态感知（视觉 + 触觉）来精化环境状态估计，与 P12.3.1 中"神经辐射场"的几何建模目标高度契合。

局限与边界

  1. 模型幻觉：世界模型预测的未来状态可能与真实物理不符，尤其在长预测时域下误差累积显著。工程判断：需通过预测误差指标（完成标准之一）进行量化监控，并在超出容忍阈值时回退到保守控制策略。

  2. 计算开销：视频生成模型与神经辐射场的推理成本极高，难以在嵌入式平台上实时运行。工程判断：需采用分层架构（低频粗预测 + 高频细控制）或模型压缩技术（如 TensorRT 加速，见 DSWAM 案例）。

  3. 预测时域受限：受计算开销与误差累积的双重约束，预测时域 H 通常无法覆盖完整的长程任务。工程判断：需结合任务分解（如 DSWAM 的 System 2）将长程任务拆解为短时域可预测的子任务序列。

  4. 数据依赖：世界模型的训练需要大量配对的人-机器人数据或高质量仿真数据，数据稀缺是实际部署的主要瓶颈。

常见误区

  1. "世界模型就是视频预测模型"——错。视频生成只是世界模型的一种实现工具，完整的 WAM 构建还需结合动力学模型、神经辐射场与 MPC 优化，形成"预测-评估-决策"的闭环。

  2. "预测误差越小越好"——不完全是。过拟合于训练分布的"完美预测"反而会降低泛化能力。工程判断：应关注预测误差在典型/极端工况下的分布特性，而非单纯追求均值最小化。

  3. "MPC 与世界模型是竞争关系"——错。在 P12.3.1 的方法组合中，MPC 是世界模型的优化引擎，二者是协作关系：世界模型提供预测，MPC 在预测时域内求解最优控制序列。

  4. "仿真验证通过就等于产品可用"——错。P12.3.1.3 的仿真验证仅证明功能正确性，P12.3.1.4 的调参与性能验证才是确保典型/极端工况下满足指标的关键环节。
