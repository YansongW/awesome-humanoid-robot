The invariant extended Kalman filter as a stable observer

The invariant extended Kalman filter as a stable observer

摘要

本文是2014年关于仿人机器人状态估计的研究，提出了不变扩展卡尔曼滤波器（IEKF）作为稳定观测器。核心贡献在于证明了IEKF在更广泛系统类别中的局部稳定性，并展示了其在移动机器人和惯性导航中的优越性。

来源与参考

  • The invariant extended Kalman filter as a stable observer (arXiv)

概述

本文是《The invariant extended Kalman filter as a stable observer》的解读，但提供的论文题目与事实要点实为一篇关于人形机器人遥操作的综述。该综述由欧盟项目资助，系统梳理了遥操作架构、重定向策略、稳定性控制与全身协调的现状与挑战，指出将重定向、规划、稳定性与控制整合为全身协调运动的问题尚未有效解决，并强调简化模型假设在现实非结构化环境中的局限性。

它改变了什么

这篇综述真正改变的是对“人形机器人遥操作”这一问题的框架性认知。它不再把遥操作视为简单的“主从映射”或“信号传输”，而是将其重构为一个涉及重定向、规划、稳定性、全身控制、状态估计与共享决策的级联系统问题。作者明确指出，将重定向与规划分开处理在实验室外（如危险环境、灾难响应）效果不佳，这直接挑战了现有模块化设计的隐含前提——即各模块可独立优化、串联即可。

更关键的是，它揭示了现有技术栈的“隐性契约”：几乎所有稳定器（ZMP、DCM）都依赖固定CoM高度、忽略旋转运动、假设至少一个无滑移接触点。这些假设在平整地面、双足支撑的实验室场景下成立，但在非结构化动态环境中会系统性失效。作者将这一矛盾从“工程细节”提升为“领域核心挑战”，迫使研究者重新审视简化模型的使用边界——这是对领域问题定义的一次实质性修正。

方法拆解

遥操作通用架构

  • 测量人类运动学/动力学信息 → 传输给人形机器人
  • 重定向模块：将人类运动映射到机器人运动，可能需估计用户反作用力/力矩
  • 生理信号测量：估计用户心理生理状态（如注意力）
  • 基于估计状态选择重定向策略，提供参考给机器人

重定向策略分类

  • 单边（unilateral）：人-机器人耦合仅单向
  • 双边（bilateral）：人-机器人直接耦合，操作者接收动觉反馈（力、压力、振动）
  • 选择依据：任务类型、通信速率、共享自主度

重定向与控制定义

  • 映射 ℍ: A → A′，A 为人类行为域（运动学+动力学），A′ 为机器人行为空间
  • 映射原则：最小化人类意图与机器人行为差异，同时尊重场景约束

模型基础

  • 多体动力学：M(q)ν̇ + C(q,ν)ν + g(q) = Bτ + Σ J_k^T(q) f_k^c
  • 简化模型 LIPM：ẍ = (g/z₀)(x − x_b)
  • DCM 变量：ξ = x + bẋ，b = √(z₀/g)
  • DCM 动力学：ξ̇ = (1/b)(ξ − x_b)

稳定器方法

  • ZMP 方法：确保 ZMP 在支撑多边形内；局限：高扰动下不调整脚位、难扩展至非平坦地形
  • DCM-ZMP 方法：DCM 动力学不稳定（严格正特征值），需控制器稳定；用于全身重定向时引入预测支撑区域
  • 接触力旋量方法：优化每个接触点的期望接触力旋量

全身控制层（WBC）

  • 形式化：QP、LQR 或 MPC
  • 逆速度运动学：Jacobian 伪逆求解冗余 IK
  • 动量控制：QP 形式化，跟踪期望全身动量变化率，再经逆动力学计算关节力矩

共享控制

  • 混合策略：u* = (1-α)u + αr
  • 置信度：α = max(0, 1-d/D)，d 为到目标距离，D 为置信度降为 0 的阈值

关键创新

  1. 问题框架的重构：将遥操作从“信号传输”重新定义为“重定向-规划-稳定性-控制”的级联优化问题，并明确指出模块化分离在现实场景中的失效。这一框架性贡献比任何单一算法都更具持久价值，因为它改变了后续研究的提问方式。

  2. 对简化模型假设的系统性批判：综述首次将“固定CoM高度、忽略旋转、无滑移接触”等假设的适用范围作为核心议题，而非默认接受。这直接指向了ZMP/DCM方法在非结构化环境中的根本局限，为接触力旋量方法、全身动量控制等替代方案提供了理论动机。

  3. 共享控制与人类状态的显式建模：将生理信号（注意力、心理生理状态）纳入重定向策略选择，并用置信度公式 α = max(0, 1-d/D) 形式化人机权威分配。这超越了传统“主从”二分法，为自适应自主性提供了可计算的框架。

实验与结果

本文为综述论文，未提供新的实验数据。表格 I 汇总了主要遥操作工作与技术，涉及平台包括 iCub3、HRP-4CR、Valkyrie、Atlas、DRC-Hubo、JAXON、little HERMES、NimbRo Avatar、TELESAR VI、TORO、COMAN 等。

关键结果含义：人类对视觉与触觉的反应时间差异（250-300 ms vs 100-150 ms）直接支持了双边遥操作中触觉反馈的优先级论证——触觉通道的延迟预算更宽松，这为力反馈接口设计提供了生理学依据。

边界与局限

  • 作者明确承认：平衡反馈研究（文献 [39, 41, 6]）未研究动态行为，仅局限于双足支撑场景
  • 2019 年 Skybot F-850 太空任务设计效果不佳，表明人形机器人太空应用仍有待突破
  • 领域较新，开发资源需求高，从事研究的实验室不多
  • 视觉反馈存在运动病问题（机器人相机图像未稳定），通信带宽限制导致信息流延迟
  • 数据驱动方法（[96,97,98,100]）未同时考虑人类到人形机器人的全身协调运动重定向
  • 将人类角偏移重定向到机器人是开放问题
  • 仅本体感觉状态估计在偏航轴和绝对位置上不可观测
  • 全身 IK 求解耗时且结果可能不连续
  • 论文未明确：具体实验任务、基线、成功率数字、训练配置、数据量、推理频率或硬件参数

工程启示

对复现与选型的直接指导：

  1. 先核对简化模型假设：若你的场景涉及非平坦地形、支撑脚旋转/滑动或高动态扰动，ZMP/DCM 方法将系统性失效。优先考虑接触力旋量方法或全身动量控制，而非在 ZMP 框架内打补丁。

  2. 注意 DCM 动力学的开环不稳定性：ξ̇ = (1/b)(ξ − x_b) 具有严格正特征值，任何 DCM 控制器必须显式处理这一不稳定性，否则微小误差将指数放大。复现时务必验证控制器增益与采样时间的匹配。

  3. 共享控制参数 D 的标定：置信度公式 α = max(0, 1-d/D) 中，D 的取值直接决定人机权威切换点。建议根据具体任务的操作精度要求与通信延迟实测标定，而非凭经验设定。

  4. 最易踩坑处：低层关节力矩控制受摩擦和机械传动影响显著，纯力矩控制可能导致位置/速度跟踪差。文献 [30,76,54] 建议混合反馈和前馈，复现时优先采用此策略而非纯力矩控制。

  5. 状态估计的不可观测性：仅本体感觉无法观测偏航轴和绝对位置，必须融合 IMU 或外部传感器。若你的系统依赖纯本体感觉，需接受漂移误差的累积，或引入视觉/激光定位。
