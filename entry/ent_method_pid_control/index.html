摘要

一种基础反馈控制方法，将控制量表示为跟踪误差的比例、积分、微分三项线性组合。

来源与参考

  • K. J. Åström and T. Hägglund, Advanced PID Control, ISA, 2006
  • K. Ogata, Modern Control Engineering, 5th ed., Prentice Hall, 2010

知识关联

  • mentions 阻抗控制 PID 控制调节位置或速度；阻抗控制进一步调节与环境的动态交互力。

概述

PID 控制（比例-积分-微分控制）是关节伺服的主力算法：比例项提供即时纠正、积分项消除稳态误差、微分项提供阻尼抑制超调。在人形机器人中，它以级联结构运行——最内电流环（即力矩环，带宽数千赫兹）、中间速度环、最外位置环，内环带宽逐层高于外环 3–10 倍。教科书 PID 与真机可用 PID 之间隔着抗积分饱和、微分滤波与前馈补偿三件套工程细节（来源：项目 Wiki 第 14 章 §14.2）。

核心内容

是什么：准确定义

连续形式的 PID 控制律（来源：项目 Wiki 第 14 章 §14.2.2）：

\[ u(t) = K_p e(t) + K_i \int_0^t e(s)\, ds + K_d \frac{d e(t)}{dt}, \qquad e(t) = r(t) - y(t) \]

数字控制器以周期 \(T_s\) 采样，工程上更常用增量式（velocity form）：

\[ \Delta u[k] = K_p \left(e[k] - e[k-1]\right) + K_i T_s e[k] + \frac{K_d}{T_s}\left(e[k] - 2e[k-1] + e[k-2]\right) \]

增量式输出控制量增量，天然避免积分累加器显式累加，手动/自动切换无扰（Wiki §14.2.2）。

为什么存在：痛点与历史定位

PID 的生命力来自一个工程事实：大多数单关节跟踪问题不需要模型。Ziegler 与 Nichols 1942 年给出的经验整定法（DOI 10.1115/1.4019264）让 PID 免模型落地。在人形机器人中，它不是"低级算法"而是控制栈的地基：无论上层是 WBC、MPC 还是 RL 策略，最终都要经关节伺服环执行；RL 论文里的"PD 目标关节角"就是 PID 去积分项的变体。

它真正的价值在于分层解耦：内环把电机动态、摩擦、齿隙等脏动态"压平"成近似理想的力矩/位置源，上层控制器才得以在干净的抽象上工作。理解 PID 的局限，就是理解上层一切方法的前提假设从哪来。

原理拆解

① 级联控制结构（Wiki §14.2.1）

关节伺服普遍采用电流环/速度环/位置环三级嵌套，内环带宽必须显著高于外环——典型每向外一层降低 3–10 倍，否则内外环动态相互干涉。电流环对象是电机电气动态：经 FOC 变换后 q 轴电流近似一阶模型 \(L_q \frac{di_q}{dt} = v_q - R_s i_q - k_e \omega_m\)，电磁时间常数 \(L_q/R_s\) 典型亚毫秒级，电流环带宽可达数千赫兹。关节输出力矩 \(\tau_j = N\eta k_t i_q\)，故电流环实质就是力矩环。

② 反射惯量与减速比的分水岭

速度/位置环的对象是机电动态 \(J_{eff}\,\dot\omega = \tau_j - \tau_g - \tau_f - \tau_{ext}\)，其中 \(J_{eff} = J_m N^2 + J_l\)。注意 \(N^2\)：高减速比关节（谐波 N 典型 50–160）中负载侧惯量与扰动折算到电机侧缩小 \(N^2\) 倍——"天然抗扰但天然不透明"；QDD 刻意取低减速比（典型 N=6–12）换力矩透明度，代价是电流环直接承受负载扰动（Wiki §14.2.1）。

③ 工程三件套（Wiki §14.2.3）

  • 抗积分饱和：执行器限幅时误差持续使积分无限累积，解除后巨大超调。反算抗饱和把饱和差值经增益反馈到积分器：\(I[k+1] = I[k] + K_i T_s e[k] + K_t T_s (u_{sat}[k] - u_{unsat}[k])\)；
  • 微分滤波：微分放大噪声，必须串低通 \(D(s) = \frac{K_d s}{1 + s/N_f}\)，滤波系数 \(N_f\) 典型取 5–20；并用微分先行（只作用于测量值）避免给定阶跃的"微分冲击"；
  • 前馈补偿：\(\tau_{cmd} = \underbrace{J_{eff}\ddot q_d + \tau_g(\hat q) + \hat\tau_f(\hat\omega)}_{\text{模型前馈}} + \underbrace{K_p e + K_d \dot e + K_i \int e}_{\text{反馈}}\)——模型前馈承担可预测部分，反馈只纠残差。

  • FOC 电流环：ent_method_field_oriented_control 与 PID 共同构成电机伺服内核。

局限与边界

  • 单入单出：PID 不理解关节间耦合，人形全身协调必须由上层（WBC/MPC/策略）承担；
  • 无约束概念：限位、力矩限幅只能靠饱和截断与抗饱和补救；
  • 固定增益：非线性工况（变负载、接触切换）下需增益调度或前馈补偿；
  • 积分项在力控场景危险：力矩环中慎用积分，避免与接触刚度构成慢振荡（工程判断）。

常见误区

  1. "PID 过时了"——它是控制栈地基；上层方法越先进，越依赖内环 PID 把关节压成理想源。
  2. "三增益调大响应就快"——超带宽比整定会引发级联干涉振荡；先内后外、带宽比 3–10 倍是纪律。
  3. "抗饱和可有可无"——限幅场景缺抗积分饱和是炸机级隐患。
  4. "微分直接用误差差分"——无滤波微分放大噪声、给定阶跃产生微分冲击；微分滤波 + 微分先行是默认配置。

4.5.5 电流环、速度环、位置环的级联控制 实际关节驱动通常采用三级级联控制：最内层 电流环（力矩环），中间 速度环，最外层 位置环。每一层带宽约为下一层的 5-10 倍，以保证稳定性。
