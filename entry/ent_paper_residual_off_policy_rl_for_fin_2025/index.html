Residual Off-Policy RL for Finetuning Behavior Cloning Policies

摘要

Residual Off-Policy RL for Finetuning Behavior Cloning Policies 是2025年针对人形机器人操作任务的工作。该方法通过残差学习框架，将行为克隆（BC）策略作为黑箱基础，利用样本高效的离策略强化学习（RL）学习轻量级逐步残差修正。核心贡献在于首次在真实世界中对配备灵巧手的人形机器人成功进行RL训练，仅需稀疏二值奖励信号即可显著提升操作策略性能。

来源与参考

  • Residual Off-Policy RL for Finetuning Behavior Cloning Policies (arXiv)

概述

ResFiT 提出一种两阶段残差离线策略 RL 框架，在冻结的行为克隆（BC）基础策略之上学习残差动作，用于真实世界高自由度（DoF）系统（含人形机器人）的样本高效微调。核心贡献在于将残差 RL 从仿真/简单场景扩展到真实人形机器人（29 维动作空间），并系统验证了 UTD、n 步回报、层归一化等设计决策在高 DoF 图像任务中的必要性。

它改变了什么

现有 BC 策略受限于演示质量与数据收集成本，而直接对真实机器人做 RL 面临样本效率低、安全风险与稀疏奖励下长时程任务学习困难。现代 BC 架构（如动作分块、扩散模型）参数规模庞大（数千万到数十亿），直接端到端 RL 优化在计算与稳定性上均不可行。此前残差 RL 工作局限于仿真或简单场景，缺乏在高 DoF 系统上直接进行真实世界 RL 的演示。

ResFiT 真正改变的是「在冻结大规模 BC 策略之上做 RL」的可行性边界。它不试图让 RL 从头学习完整策略，而是将问题分解为「基础策略提供先验动作 + 残差策略修正偏差」，从而将 RL 的搜索空间限制在基础策略附近。这一设计使 RL 能够以极低样本量（真实世界 134 次 episode）显著提升成功率，同时避免了对基础策略的灾难性遗忘或破坏。其意义在于：为「演示数据 + 少量在线交互」的实用机器人学习范式提供了可复现的真实世界验证。

方法拆解

两阶段训练流程

  1. BC 预训练：在演示数据集上训练基础策略 \(\pi_{\text{base}}\)，使用动作分块（action chunking）预测未来 \(k\) 个动作，减少复合误差。训练后冻结。
  2. 残差 RL 微调：初始化残差策略 \(\pi_{\theta}(s_t, a_t^{\text{base}})\)、Q 集成、视觉编码器与空在线缓冲区。完整动作为 \(a_t = a_t^{\text{base}} + a_t^{\text{res}}\)。

离线策略 RL 核心设计

  • 演员-批评者架构：DDPG 风格，批评者预测完整动作的值： [ Q_{\phi}(s_t, a_t^{\text{base}} + \pi_{\theta}(s_t, a_t^{\text{base}})) ]
  • 样本效率关键决策：
  • UTD > 1：每次环境交互执行多次梯度更新，显著加速学习（BoxCleanup 中 UTD=4 已捕获大部分收益）。
  • n 步回报（n=3）：缓解稀疏奖励下长时程任务的信用分配问题，但过大（如 n>3）会增加偏差。
  • 层归一化：在批评者中加入，缓解过估计。
  • TD3 风格：延迟演员更新（每 2-8 次批评者更新）、Polyak 平均（\(\tau = 0.005\)）、目标策略平滑。
  • REDQ：随机集成双 Q 学习，TD 目标用随机子集的最小 Q 值，策略更新用完整集成，减少过估计偏差。
  • 视觉编码器：浅层 ViT + DrQ 风格随机平移增强，适应图像输入。
  • 数据混合：在线 RL 阶段每批 50% 来自冻结的离线演示数据，50% 来自在线缓冲区（对称采样），防止灾难性遗忘。

算法流程（Algorithm 1）

  1. 初始化残差策略、Q 集成、视觉编码器、空在线缓冲区。
  2. 缓冲区预热：用噪声 + 基础动作探索。
  3. 循环：采样基础动作和残差动作，执行环境步骤，存入缓冲区；重复 UTD 次更新批评者和演员。

系统架构

演员和学习者分离为独立进程，学习者加载最新重放缓冲区进行模型更新，数据收集器重置场景并开始下一轨迹。真实世界平台配备力-扭矩传感器安全限制与碰撞检查。

关键创新

  1. 真实世界高 DoF 残差 RL 首次验证：在 29 维动作空间的人形机器人（Vega）上，仅用 134 次自主 RL 执行（约 15 分钟数据）将成功率从 14% 提升至 64%。此前残差 RL 工作未在如此高 DoF 真实系统上演示。
  2. 对基础策略参数化不可知：残差方法可应用于大型动作分块 BC 策略（如 ACT），无需修改基础策略内部结构，仅需冻结并叠加残差。这使方法可直接适配现有 BC 生产管线。
  3. 系统化的离线策略 RL 设计决策组合：将 UTD、n 步回报、层归一化、REDQ、对称采样等独立技术整合为统一框架，并验证了在高 DoF 图像任务中这些决策的协同必要性（如无动作分块的方法在 Coffee 任务稀疏奖励下失败）。

实验与结果

仿真任务（Robosuite，20 Hz 控制频率）

  • 单臂任务：Can、Square（Franka，7 维动作空间，300 个演示）。
  • 双臂任务：BoxCleanup、CanSort、Coffee（DexMimicGen，24 维动作空间，1000 个演示）。

关键结果对比

任务 ResFiT 收敛步数 基线收敛步数 备注
BoxCleanup 200k 40M（PPO） 样本效率提升约 200 倍（由表内数值 200k→40M 计算）
Can 约 75k 约 150k ResFiT 更快收敛
Square 150k 内 >90% 成功率 仅 Tuned RLPD 可达 其余基线失败
Coffee 高效收敛 基线崩溃或需更长时间 无动作分块方法失败

消融与基线

  • Filtered BC：稳定但提升极小，从约 20% 初始性能提升后快速饱和。
  • UTD 研究：BoxCleanup（150-250 步时程）UTD>1 明显有益，UTD=1/2 学习显著变慢，UTD=4 捕获大部分收益，8 或更高收益递减。
  • n 步研究：n>1 对稀疏奖励任务重要，但过大增加偏差影响性能。

真实世界任务（Vega 人形机器人，29 维动作空间）

任务 基础策略成功率 ResFiT 后成功率 RL 数据量
WoollyBallPnP 14% 64% 134 次 episode（约 15 分钟）
PackageHandover 23% 64% 343 次 episode（约 76 分钟）

评估采用盲 A/B 测试，匹配初始条件，随机分配策略标签。

边界与局限

  • 策略搜索空间受限：学习到的行为受限于基础策略附近，无法发现基础策略未编码的根本不同策略或技能。
  • 人工监督依赖：真实世界实验仍需人工重置场景与标注奖励，无自动重置机制、成功检测或安全护栏，无法实现完全自主的技能提升。
  • 未探索放松冻结约束：未研究在训练中逐步解冻基础策略以扩大搜索空间的方法。
  • 未进行策略蒸馏：未实验将组合策略（基础+残差）蒸馏回单一基础策略，以简化部署。
  • 论文未明确：真实世界实验的失败案例细节、残差策略的参数量、以及不同随机种子下的方差。

工程启示

  • 先核对基础策略质量：ResFiT 的收益上限受限于基础策略的初始性能。若基础策略成功率过低（如 <10%），残差 RL 可能难以有效修正，建议先提升 BC 质量。
  • UTD 与 n 步是首要调参对象：UTD=4、n=3 是仿真与真实世界任务的稳健起点。UTD 过低（≤1）学习极慢，过高（≥8）收益递减；n 过大引入偏差。
  • 对称采样（50% 离线 + 50% 在线）是防遗忘关键：直接丢弃离线数据会导致基础策略行为被覆盖，务必保留此设计。
  • 真实世界部署注意：需配备力-扭矩传感器安全限制与碰撞检查；演员-学习者分离架构可避免推理阻塞，但需确保数据收集器能及时重置场景。
  • 最易踩坑点：批评者过估计在高 DoF 图像任务中尤为严重，层归一化与 REDQ 缺一不可；若省略任一，可能导致 Q 值发散或策略崩溃。
