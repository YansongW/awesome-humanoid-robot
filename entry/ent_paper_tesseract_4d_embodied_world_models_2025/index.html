TesserAct: Learning 4D Embodied World Models

TesserAct: Learning 4D Embodied World Models

领域
AI 模型与算法
层级
智能层
审校
AI 全文核验

摘要

TesserAct 提出了一种学习 4D 具身世界模型的新方法，通过预测 3D 场景在智能体动作下的动态演化，实现时空一致性。该方法利用 RGB-DN（RGB、深度和法线）视频训练模型，超越了传统 2D 模型，并支持高效学习逆动力学模型。核心贡献在于将生成视频直接转换为高质量 4D 场景，显著提升了策略学习性能。

来源与参考

  • arXiv:2504.20995 TesserAct: Learning 4D Embodied World Models
  • Project page
  • GitHub仓库 Robotics_Notebooks

概述

TesserAct 是一个面向具身智能的 4D 世界模型，通过联合预测 RGB、深度和法向图序列来表征动态场景，并利用法向积分与光流约束实现时间一致的 4D 点云重建。该方法基于 CogVideoX 架构微调，在约 285k 混合合成/真实视频上训练，在深度/法向精度与 4D 重建质量上显著超越现有视频生成基线，并可直接服务于下游动作规划。

它改变了什么

现有视频世界模型（如 OpenSora、CogVideoX）在 2D 像素空间操作，输出缺乏几何一致性——物体尺寸和形状随时间漂移，无法为抓取、导航等需要精确 6-DoF 位姿的任务提供可靠的空间先验。TesserAct 真正改变的是“世界模型输出什么”这一根本问题：从纯视觉外观预测转向“外观+几何”联合预测，将深度和法向作为显式中间表示，从而让生成过程受三维几何约束，而非仅受像素统计约束。

这一转变的深层意义在于：它使世界模型从“视频生成器”升级为“可操作的场景模拟器”。下游策略可以直接消费 4D 点云而非 2D 帧，逆动力学模型得以在几何空间而非像素空间学习动作映射。同时，通过复用现有视频扩散模型（CogVideoX）的生成能力，避免了从零训练 4D 生成模型的巨大计算开销——这是该工作能落地的关键工程判断。

方法拆解

核心表示：RGB-DN 四通道视频

  • 预测 RGB、深度（相对图，[0,1]）、法向图序列，维度低于显式体素/点云，且与视频模型输入格式天然兼容。
  • 深度为 affine-invariant 相对图，需后续优化恢复尺度。

模型架构（基于 CogVideoX 微调）

  1. 编码：3D VAE 分别编码 RGB、深度、法向视频（VAE 冻结不微调），三个独立 InputProj 投影器提取各模态嵌入。
  2. 融合：DiT 接收三种嵌入之和，以文本 𝒯（动作指令+机械臂名）和去噪步 t 为条件。
  3. 解码：RGB 输出沿用原方案；新增 Conv3D 层将输入潜变量与预测 RGB 去噪输出拼接，再与 DiT 隐藏状态结合，经 DNProj 输出深度和法向去噪预测。
  4. 初始化：全部新模块零初始化，保证训练初期 RGB 输出与预训练 CogVideoX 一致，稳定训练。

训练目标

  • 联合噪声预测损失：L = 𝔼[||[ε_v, ε_d, ε_n] − ε_θ(x_t, t, x^0, 𝒯)||²]

4D 场景重建（推理后处理）

  • 法向积分：利用预测法向图优化深度，最小化空间一致性损失 ℒ_s。
  • 光流分割：RAFT 计算帧间光流，按幅度阈值 c 划分静态/动态/背景区域。
  • 两个新损失：
  • 时间一致性损失 ℒ_c：对动态和背景区域施加跨帧深度一致性。
  • 正则化损失 ℒ_r：约束优化深度与生成深度相似（动态/背景掩码加权）。
  • 总损失：arg min_D̃ L_s + L_c + L_r，从第一帧迭代优化至第 i 帧。

数据管线

  • 合成：RLBench 20 个高难度任务 × 1000 实例 × 4 视角 = 80k 视频，深度来自模拟器，法向由 DSINE depth2normal 估计。
  • 真实：RT1 Fractal（80k）、Bridge（25k）、SomethingSomethingV2（100k），深度用 RollingDepth，法向用 Temporal-Consistent Marigold-LCM-normal。
  • 场景随机化（Colosseum 管线）：改变背景、桌面纹理、光照。

关键创新

  1. RGB-DN 联合生成范式：首次将深度和法向作为与 RGB 平等的生成目标纳入视频扩散模型，而非事后估计。这使得几何信息在生成过程中参与约束，而非作为后处理附加——这是与所有基线（OpenSora/CogVideoX 后估计）的本质区别。

  2. 零初始化多模态融合：通过将新增深度/法向分支的所有参数零初始化，确保训练初期模型行为与预训练视频模型完全一致，避免多模态联合训练常见的灾难性遗忘和训练不稳定。这一设计决策虽简单但极其有效，是工程上的关键创新。

  3. 光流引导的深度优化损失：利用光流幅度区分动态/静态/背景区域，分别施加时间一致性约束。相比全局一致性约束，这避免了动态物体（如机械臂）运动导致的错误深度惩罚，使重建的 4D 点云在运动区域保持几何真实。

实验与结果

实验在两类域上进行对照：真实域（RT1 Fractal 与 Bridge 数据集，400 个未见样本）与合成域（RLBench 数据集，200 个未见样本）。基线包括 OpenSora、CogVideoX（均为视频扩散模型，无深度/法线标注，事后用 Rolling Depth 与 Marigold 估计）以及 4D Point-E（直接输出点云）。所有指标在 10 次运行上取平均。关键结果如下表（数字逐字取自论文 Table 2）：

（4D Point-E 仅报告 Chamfer L₁：Real 域 0.2211，Syn 域 0.1086。）

  • 深度与法线精度全面领先：在真实域，TesserAct 的 AbsRel 为 22.07，优于 CogVideoX 的 26.17 与 OpenSora 的 31.41；δ₁ 与 δ₂ 分别达到 66.80 与 82.60，均为最优。合成域优势更明显，δ₁ 达 69.26、δ₂ 达 93.03，11.25° 精度为 36.85，显著高于基线（由表内数值 26.04→36.85 计算）。这表明显式建模 RGB-DN 四模态优于事后估计深度/法线的做法。
  • 4D 点云重建精度最优：TesserAct 在真实域 Chamfer L₁ 为 0.2030，合成域为 0.0811，均低于所有基线（合成域较 CogVideoX 的 0.2884 降低约 72%，由表内数值 0.2884→0.0811 计算）。4D Point-E 在合成域（0.1086）优于视频扩散基线但仍落后于本文方法，说明 RGB-DN 视频表示比直接点云生成更高效，尤其在捕捉动态场景细粒度细节方面。
  • RGB 质量权衡：合成域 TesserAct 的 FVD（40.01）与 SSIM（77.59）优于所有基线；真实域 FVD（21.59）与 SSIM（75.86）略逊于 CogVideoX（20.64 与 79.38），但作者指出这是「没有明显损害 RGB」的权衡——以极小的 RGB 代价换取深度、法线与点云精度的大幅提升。

边界与局限

  • 单表面表示：RGB-DN 仅捕获世界单一表面，无法处理遮挡和多视角信息，作者明确承认未来需生成多视图 RGB-DN 构建完整 4D 模型。
  • 深度尺度模糊：深度为相对图（[0,1]），无法直接恢复度量尺度，重建依赖优化过程，可能引入累积误差。
  • 真实数据标注依赖估计器：RollingDepth 和 Marigold-LCM-normal 均为估计结果，存在噪声，可能限制模型在真实场景的上限。
  • 任务覆盖有限：动作规划仅在 RLBench 9 个任务上验证，未涉及真实机器人部署；open microwave 等任务上 4D 信息无增益。
  • 消融细节缺失：论文未提供各损失项单独移除的量化对比（仅定性描述），也未报告推理延迟和显存占用。
  • 训练计算成本未披露：40k 迭代、batch size 16、49 帧输出的总训练时间未提及。

工程启示

  • 复现优先级：先核对数据管线——合成数据（RLBench 20 任务 × 4 视角）和真实数据（RT1/Bridge/SSv2）的深度/法向估计器版本（RollingDepth、Marigold-LCM-normal、DSINE）必须一致，否则几何监督信号质量差异会直接影响深度 AbsRel 指标。
  • 最易踩坑点：零初始化策略是训练稳定的关键，新增 Conv3D 和 DNProj 若未零初始化，初期 RGB 输出会偏离预训练分布，导致 FVD 崩坏。建议严格遵循“所有新模块零初始化”的设定。
  • 超参敏感性：损失权重 λ_d=20、λ_b=200 在真实/合成域通用，但 λ_g1/λ_g2 需按域调整（真实 20，合成 2）——合成数据法向更干净，正则化权重应降低，否则过度约束生成多样性。
  • 下游集成：逆动力学模型（ID）训练需每任务 500 样本，输入为 8192 点采样 + 20% 高斯噪声增强。若下游任务涉及动态遮挡，建议先验证光流分割阈值 c 的敏感性，该参数直接影响 ℒ_c 的有效性。
  • 硬件需求：论文未披露，但 49 帧 × 512×512 × 3 模态的 DiT 训练，结合梯度检查点，预计至少需要 8×A100 级别；若资源有限，可先尝试降低帧数（如 25 帧）验证几何监督收益是否保持。
