This Roboticist-Turned-Teacher Built a Life-Size Replica of ENIAC

摘要

Tom Burick，一位前机器人公司创始人，现为亚利桑那州PS Academy的技术教师，带领神经多样性学生团队，为纪念ENIAC诞生80周年，按1:1比例复刻了这台1940年代的标志性计算机。该项目使用了近300平方米厚纸板、1600根热熔胶棒和7加仑黑漆，安装了18000个模拟真空管，精确还原了ENIAC被拆解前的原貌。

概述

Tom Burick曾创办White Box Robotics公司，开发了模块化通用机器人平台914 PC-Bot，售出约200台至17个国家。2008年金融危机导致公司于2010年关闭后，他转向教学，先在自闭症青年职业培训项目工作，后于2019年加入PS Academy Arizona。Burick本人患有计算障碍，他将此视为“超能力”，认为其增强了自己的3D空间推理能力。他通过ENIAC复刻等大型项目，让学生利用高度专注和精确重复等特质进行学习，项目共使用近300平方米厚纸板、1600根热熔胶棒和7加仑黑漆，安装了18000个模拟真空管。

核心内容

从机器人专家到教师

Tom Burick自幼受电视剧《迷失太空》中的机器人角色启发，对机器人技术产生终身热爱。15岁时，他建造了一台150磅重的钢制消防机器人，并因此获得IEEE等机构奖项。他通过联系Carnegie Mellon University的学生和Saint Vincent College的讲师自学，最终选择不读大学，直接投身现实世界的问题解决。

创业经历：White Box Robotics

2000年，Burick创立White Box Robotics，灵感来自组装“白盒”PC时发现机器人领域缺乏类似标准化产品。他开发了模块化通用平台914 PC-Bot，其底盘像“乐高盒子”一样可灵活组合：拼接两个躯干可加倍有效载荷，更换驱动系统或传感器头部。他为此申请了实用和设计专利，并与加拿大国防机器人公司Frontline Robotics合并后投产。公司共售出约200台机器人至17个国家，但于2010年底因2008年金融危机倒闭。

神经多样性作为超能力

Burick本人患有计算障碍，这使传统数学学习更具挑战，但也赋予他强大的3D空间推理能力。他形容自己“脑中24小时运行着一个CAD程序”，并认为计算障碍是他机器人事业成功的关键。在教学中，他鼓励自闭症学生将神经多样性视为“超能力”，强调需要比他人多一份坚韧，但最终会获得独特的才能和优势。

ENIAC复刻项目

为纪念ENIAC诞生80周年，Burick带领学生从2025-26学年开始建造全尺寸复刻品。ENIAC由40个大型金属面板组成U形布局，包含20个相同设计的累加器，以及三个用于存储数值常数的函数表和两台穿孔卡机。项目挑战在于重复面板的对称性——任何微小偏差都会累积放大。最终成果使用了近300平方米厚纸板、1600根热熔胶棒和7加仑黑漆，安装了18000个模拟真空管，精确匹配了ENIAC在1950年代被拆解前的原貌。此前，学生们还建造过一辆8英尺长的可驾驶Tesla Cybertruck（配备400瓦立体声系统和低音炮）。Burick计划继续此类项目，可能复刻阿波罗登月任务的相关设备。
