Towards Learning a Generic Agent for Vision-and-Language Navigation via Pre-training

摘要

本文提出了首个面向视觉-语言导航（VLN）任务的预训练与微调范式。通过在大规模图像-文本-动作三元组上进行自监督学习，模型（Prevalent）习得了视觉环境与语言指令的通用表征，可直接嵌入现有VLN框架。在Room-to-Room基准上，该模型将路径加权成功率从47%提升至51%，并在视觉-对话导航和"Help, Anna!"等任务上刷新了最优结果。

概述

本文提出 Prevalent，首个面向视觉语言导航（VLN）的预训练-微调范式。作者利用 Matterport3D 模拟器构建 658 万图像-文本-动作三元组（其中 98.4% 由 Speaker 模型合成），通过图像注意的掩码语言建模（MLM）与动作预测（AP）两个自监督目标训练跨模态编码器，并在 R2R、CVDN、HANNA 三个下游任务上验证其作为即插即用组件的有效性，显著超越现有基线。

它改变了什么

VLN 领域长期受困于数据稀缺——最大数据集 R2R 仅 104K 样本，比典型视觉语言预训练语料小一个数量级。现有方法要么从零训练序列到序列模型，要么直接套用 BERT/ViLBERT 等通用 VLP 模型，但后者依赖 Faster R-CNN 区域特征，与 VLN 的全景视图输入（每视图 36 张图像）在计算上不兼容。Prevalent 真正改变的是：将预训练从"语言中心"转向"导航中心"，首次在图像-文本-动作三元组上自监督学习，使编码器同时编码视觉环境、语言指令与动作轨迹的联合分布。这意味着下游模型不再需要从零学习视觉-语言对齐，而是直接继承一个已经理解"看到什么、说什么、往哪走"三者关系的通用表示，从而显著缩小 seen 与 unseen 环境的性能差距（如 HANNA 上 SPL 差距从 38.42 降至 30.66）。

方法拆解

输入表示

  • 视觉嵌入：每个全景视图 36 张图像（12 角度 × 3 俯仰），每张图像为 2176 维向量 = 2048 维 ResNet 特征 + 128 维方向特征（[sinψ; cosψ; sinω; cosω] 重复 32 次），经 LayerNorm(W_e·s + b_e) 映射至 d_h=768。
  • 文本嵌入：标准 Transformer token 嵌入 + 位置嵌入，LayerNorm 后输入。

编码器架构（三层 Transformer 堆叠）

  1. 单模态文本编码器（L_text=9）：标准自注意力，掩码矩阵 M 全零。
  2. 单模态视觉编码器（L_vision=1）：标准自注意力，处理 36 张全景图像。
  3. 跨模态编码器（L_cross=3）：查询来自另一模态前层输出，键值来自当前模态 H_{ℓ-1}，实现跨模态全连接；后接自注意力与 FFN。

注意力计算：A_ℓ = Softmax(QK^T/√d_k + M)V，M 中 0 允许注意，−∞ 禁止。

预训练目标

  • 图像注意的 MLM：15% 概率掩码词，基于周围词与全部图像预测，损失 L_MLM = −E log p(x_i | x_{\i}, s)。
  • 动作预测（AP）：在 [CLS] token 输出上接 FC 层预测动作，损失 L_AP = −E log p(a | x_[CLS], s)。
  • 总损失 L = L_MLM + L_AP。作者尝试掩码图像建模但效果不佳，故排除。

预训练数据

  • R2R 训练集：104K 三元组。
  • Speaker 模型（seq2seq 自回归）合成：6,482K 三元组（占 98.4%）。
  • 总计 6,582K 三元组，在 Matterport3D Simulator 上收集最短路径轨迹。

微调设计

  • R2R：预训练词嵌入输入 LSTM 编码器-解码器；两阶段——先基于特征训练，再微调交叉注意力层（20k 迭代，lr=2×10⁻⁶）。
  • CVDN：序列长度限制 300，超出部分截断。
  • HANNA：触发帮助时用预训练模型编码指令。

关键创新

  1. 首个 VLN 专用预训练范式：不同于 BERT/ViLBERT 等通用 VLP，Prevalent 在图像-文本-动作三元组上预训练，直接对齐"视觉-语言-动作"三者关系，而非仅视觉-语言。这使得预训练表示天然适配导航决策，而非需要额外适配层。
  2. 图像注意的 MLM：与 BERT 的纯文本 MLM 不同，掩码词预测时跨模态编码器可关注全部 36 张全景图像，使语言理解与空间视觉上下文绑定。消融实验证明该设计在 CVDN 上优于 BERT 预训练（Mixed 指标 3.15 vs 2.64）和 BERT 微调（3.15 vs 2.28）。
  3. 合成数据规模化：利用 Speaker 模型将预训练数据扩大 63 倍（104K→6,582K），解决 VLN 数据稀缺瓶颈。合成数据占 98.4%，且实验证明其有效性——预训练词嵌入在 R2R 上适应速度显著快于随机初始化（Figure 4）。

实验与结果

SPL 从最先进 47% 提升至 51%（单指令），多指令下 SPL=56 优于 Press 的 53。

方法 Oracle Navigator Mixed
Seq2Seq 1.25 2.11 2.35

Prevalent 在所有设置下显著优于 Seq2Seq。

HANNA 结果

方法 SEEN-ENV SR/SPL/NE/#R UNSEEN-ALL SR/SPL/NE/#R
Anna 88.37/63.92/1.33/2.9 47.45/25.50/7.67/5.8

Prevalent 在 unseen 上全面优于 Anna，seen-unseen 差距更小（SPL 差距 30.66 vs 38.42）。

消融实验

  • CVDN 预训练目标（Mixed 指标）：完整目标 3.15 > 仅 MLM 3.14 > BERT 预训练 2.64 > BERT 微调 2.28。
  • R2R 特征提取 vs 微调：微调 SR=54/SPL=51 优于特征提取 SR=52/SPL=49。
  • HANNA 目标消融：完整目标 UNSEEN-ALL SR=52.91 显著优于仅 MLM 44.29、BERT 特征 24.12、BERT 微调 26.36。

边界与局限

  • 掩码图像建模被尝试但效果不佳，已排除，说明视觉重建目标对导航任务可能非必要。
  • 未在真实物理机器人上验证，所有实验基于 Matterport3D 模拟器。
  • 未对合成数据质量进行系统性评估，也未分析合成指令与人工指令的分布差异。
  • 未讨论 CVDN 序列长度限制 300 可能造成的信息丢失。
  • 未分析 HANNA 中 #R 略高（6.6 vs 5.8）的原因，可能影响帮助请求效率。
  • 未报告预训练总计算量（GPU 小时数），仅提及 8×V100、batch 96、20 轮。

工程启示

复现时优先核对三点：预训练数据构建——Speaker 模型生成质量直接决定预训练效果，建议先在小规模合成数据上验证指令与轨迹对齐；跨模态编码器层数配置（L_text=9, L_vision=1, L_cross=3）是经验值，若下游任务视觉信息更复杂（如连续导航），需重新调优；微调两阶段策略——R2R 上先特征提取后微调交叉注意力层（lr=2×10⁻⁶）是性能关键，跳过特征提取阶段直接微调可能导致过拟合。最易踩坑的是合成数据规模：6,482K 三元组占 98.4%，若计算资源有限缩减合成数据，需注意预训练收益可能非线性下降。对于 CVDN，序列长度 300 的截断策略会丢失长对话历史，下游任务若涉及多轮交互，建议改用滑动窗口或层次编码。
