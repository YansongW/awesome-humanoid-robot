InteractGen

Transforming Monolithic Foundation Models into Embodied Multi-Agent Architectures for Human-Robot Collaboration

摘要

InteractGen 是清华大学与北京邮电大学于 2025 年提出的具身多智能体架构，旨在将单体基础模型转化为面向人机协作的分布式系统。其核心贡献在于通过 LLM 驱动的多智能体编排，将机器人智能分解为感知、规划、决策、反思与人类委托等专用模块，并在异构机器人团队上经过三个月开放使用验证，显著提升了任务成功率与协作适应性。

来源与参考

  • Transforming Monolithic Foundation Models into Embodied Multi-Agent Architectures for Human-Robot Collaboration (arXiv)
  • InteractGen source

概述

TeleGate 框架由作者提出，用于将单体基础模型转化为具身多智能体架构，以解决实时全身遥操作中多样化动作高精度跟踪的难题。其核心贡献在于通过门控专家选择机制保留领域专家全部能力，并引入基于 VAE 的运动预测先验补偿未来轨迹缺失，在约 2.5 小时数据上实现了 97.3% 的跟踪成功率，显著优于现有蒸馏方法。

它改变了什么

实时遥操作的核心矛盾在于：单一通用策略无法同时驾驭动态特性差异巨大的动作（如跳跃与行走），而现有解决方案——无论是知识蒸馏（TWIST、Any2track）还是混合专家联合训练（GMT）——本质上都是“有损压缩”，将多个专家决策边界强行拟合进一个策略，必然导致性能退化。TeleGate 真正改变了这一范式：它不再试图融合知识，而是保留每个专家的完整能力，用轻量级门控网络在运行时动态选择最优专家。这相当于把“训练一个全能策略”的问题转化为“训练一个精准的调度器”，从根本上绕开了多任务强化学习中的灾难性遗忘和蒸馏带来的精度损失。

另一个关键改变在于对“未来信息缺失”的处理。实时遥操作无法预知未来参考轨迹，而动态动作（如从跳跃到站立）的切换需要前瞻性控制。TeleGate 引入基于 VAE 的运动预测先验，从历史轨迹中隐式预测未来运动趋势，并将这一预测编码为潜变量注入策略观测。这不同于简单地将历史帧堆叠作为输入——VAE 的非对称设计（编码历史、解码未来）迫使潜变量承载真正的预测语义，而非仅仅描述当前状态。

方法拆解

三阶段框架

TeleGate 采用三阶段流水线：数据采集与预处理、专家策略训练（带运动预测先验）、门控网络训练。

状态与动作空间

  • 状态空间 s_t = {o_t, m_t, z_t}，其中本体感受 o_t 包含重力投影 g_t^proj ∈ R³、基座线速度 v_t、角速度 ω_t、关节位置 q_t、速度 q̇t 及上一目标位置 q^target。
  • 单帧参考轨迹 m_t 包含目标关节角度/角速度、骨盆系重力投影、线/角速度、骨盆与脚部高度。
  • 历史窗口 M_t⁻ = {m_{t-20}, m_{t-10}, m_{t-5}, m_{t-1}, m_t} 采用非均匀稀疏采样：近期帧捕捉瞬时动态，远期帧提供运动趋势，以相同计算成本覆盖更长时间跨度。
  • 动作空间为残差修正：q_t^target = q̂_t + a_t·α，PD 控制律 τ_t = K_p(q_t^target - q_t) - K_d q̇_t，策略以 50Hz 输出。

运动预测先验（VAE）

  • 编码器 E_φ 接收历史窗口 M_t⁻，输出潜变量 z_t 的分布参数 (μ_t, σ_t)，通过重参数化采样 z_t = μ_t + σ_t ⊙ ε。
  • 解码器 D_ψ 以 z_t 为条件重建未来窗口 M̃_t⁺ = D_ψ(z_t)。
  • 关键设计：VAE 与专家策略联合训练而非分阶段。若先独立训练 VAE 再冻结训练策略，潜变量语义可能与策略决策需求不对齐，策略会将 z_t 视为噪声而忽略。联合训练使潜空间表示在预测未来轨迹的同时被策略梯度塑造。
  • 总损失 L = L_PPO + λ_recon·L_recon + λ_KL·L_KL，其中 L_recon = ‖M̃_t⁺ - M_t⁺‖₂²，λ_recon=0.5，λ_KL=0.0005，潜变量维度 d=32。

专家划分与门控

  • 六类动作按动态相似性分为四组：行走+跑步、舞蹈+武术、跌倒+恢复、跳跃，每个专家仅在其子集上训练。
  • 门控网络 G_θ: S′ → R^K 保持所有专家冻结，输入本体感受与参考轨迹，输出 K 个选择分数，每控制周期选择最高分专家执行 a_t = π_{i}(o_t, m_t, z_t^{i})。
  • 门控训练使用与专家阶段完全相同的设置（仿真环境、奖励、域随机化），损失仅含 PPO 策略梯度。
  • 切换平滑性通过两点保证：专家输入包含上一时间步目标电机位置（使新激活专家感知瞬时动态）；训练中动作正则化奖励抑制切换瞬间的动作跳变。

课程采样

基于失败率的课程采样：w_i = T_i·(1 + min(γ·f_i, β))，其中 γ=0.6 为失败率放大系数，β=19.0 为权重增益上限，失败率 f_i 通过指数移动平均更新。动态动作片段被分割至 10 秒以内并保留部分重叠。

关键创新

  1. 门控专家选择替代知识蒸馏：这是最根本的创新。TeleGate 不训练单一通用策略，而是保留多个领域专家的完整能力，用轻量级门控网络做运行时调度。这避免了蒸馏的“有损压缩”本质——通用策略在拟合多个专家决策边界时必然能力退化。实验表明，Top-1 Gating 成功率 96.7% 甚至略优于 Oracle 上界 96.3%，因为运动片段标签并非帧级精确，门控网络可以逐帧选择最优专家。

  2. 非对称 VAE 运动预测先验：与 VMP 编码当前状态不同，TeleGate 的 VAE 编码历史窗口、解码未来窗口，使潜变量 z_t 天然包含对运动的隐式预测。这一设计直接针对实时遥操作无法获取未来轨迹的痛点，赋予策略前瞻性控制能力。消融实验显示，引入 VAE 后成功率从 96.7% 提升至 97.3%，E_mpjpe 相对提升 4.5%（由表内数值 18.03→17.22 计算），E_mpjae 相对提升 7.6%（由表内数值 0.092→0.085 计算）。

  3. 联合训练 VAE 与策略：这是容易被忽视但至关重要的设计决策。若分阶段训练，潜变量语义与策略需求不对齐，策略会将 z_t 视为噪声而忽略。联合训练允许 VAE 的潜空间表示在预测未来轨迹的同时被策略梯度塑造，确保预测先验真正服务于控制决策。

实验与结果

与现有方法比较（表 II）

方法 SR (%) E_plve (mm/帧) E_mpjpe (mm) E_mpjae (rad)
TWIST 68.9 3.880 53.552 0.158
Any2track 91.2 8.93 18.40 0.090
GMT 92.0 9.65 29.14 0.181
TeleGate (Ours) 97.3 8.37 17.22 0.085

TWIST 取得最佳骨盆速度跟踪（E_plve=3.88）但成功率仅 68.9%，因其常在困难样本上早期失败，成功完成的简单样本速度跟踪更容易，导致平均速度误差偏低。TeleGate 在成功率上大幅领先，跟踪精度也最优。

切换平滑性

无专家切换时平均目标关节位置变化为 1.38°/帧，有切换时为 3.49°/帧。角度变化在切换时刻增加但幅度在可接受范围内。

边界与局限

论文片段中未明确列出作者承认的局限与未做之事。从内容推断，至少存在以下边界：遥操作到自主控制的迁移尚未完成（作者列为未来工作）；实验仅在 Unitree G1 单一人形平台上验证，未涉及其他硬件形态；专家划分依赖人工对动作动态相似性的判断，缺乏自动划分机制；门控网络采用 Top-1 硬选择，未探索软融合或概率采样的潜在优势。

工程启示

复现 TeleGate 时，最需要优先核对的是数据采集与预处理的一致性——训练和部署的数据处理流程必须完全一致以消除分布不匹配，这是框架有效性的前提。其次，VAE 与专家策略的联合训练是关键但易出错：若分阶段训练，潜变量会被策略忽略，务必使用联合训练损失 L = L_PPO + λ_recon·L_recon + λ_KL·L_KL。

最容易踩坑的地方在于专家划分。Random Partition 的 E_mpjpe 为 19.89mm，显著差于基于动态相似性划分的方法，说明划分质量直接决定门控上限。建议先对动作数据做动态特征聚类，而非凭直觉分组。另一个潜在陷阱是门控网络训练时的域随机化配置——必须与专家阶段完全一致，否则门控在部署时可能因分布偏移做出错误选择。

对于下游团队，建议关注切换平滑性指标（有切换时 3.49°/帧 vs 无切换 1.38°/帧）。虽然幅度可接受，但在高精度任务中可能需要额外的滤波或插值策略。最后，惯性动作捕捉数据集将在论文被接收后共享，复现时可优先使用官方数据以保证可比性。
