Unified-IO 2

Unified-IO 2: Scaling Autoregressive Multimodal Models with Vision, Language, Audio, and Action

层级

摘要

Unified-IO 2 是 Allen Institute for AI、伊利诺伊大学厄巴纳-香槟分校和华盛顿大学于 2023 年提出的首个自回归多模态模型，能够同时理解和生成图像、文本、音频与动作。其核心贡献在于通过统一的 token 化空间和单编码器-解码器 Transformer 架构，在超过 35 个基准上取得领先性能，包括 GRIT 基准和机器人操作任务。

来源与参考

  • Unified-IO 2 source

概述

Unified-IO 2 是 Google 团队提出的从零训练的自回归 encoder-decoder 多模态大模型，统一处理图像、文本、音频和动作四种模态的输入与生成。核心贡献在于证明了单一模型通过大规模预训练和指令微调，能在视觉语言、生成、视频理解、3D 检测和具身动作等广泛任务上达到接近专用模型的性能，且多模态广度未显著牺牲单模态能力。

它改变了什么

此前多模态模型要么像 CoDi、Emu 那样在图像生成忠实度上不足，要么像 minDALL-E、AudioLDM 那样只能处理单一模态，缺乏一个端到端、从零训练的通用模型。Unified-IO 2 真正改变的是“多模态统一”的可行性边界：它不再是将现成 LLM 接上视觉编码器的拼接方案，而是从架构、训练目标到数据混合都围绕四模态统一设计，并首次将动作生成纳入同一自回归框架。

更关键的是，它改变了“广度必然牺牲深度”的行业假设。在 TIFA 上达到 81.3（XXL），接近专用文生图模型 minDALL-E 的 79.4；在 ScienceQA 上 88.7，超过所有同规模通用模型。这意味着多模态预训练不再只是“附加能力”，而是可以成为视觉语言性能的增强器而非拖累。

方法拆解

架构总览

自回归 encoder-decoder，从零训练，覆盖图像、文本、音频、动作。编码器使用 ViT-B（图像）和 AST-B（音频），因内存限制未用更大版本。生成侧图像用 VQ-GAN（压缩比 8，词汇表 16384），音频用自实现 ViT-VQGAN（码本 8196），文本用 BPE（词汇表 32000 + 210 特殊 token）。

输入表示

  • 稀疏结构：连续值（点、框、相机变换、3D 立方体）用 1000 个特殊 token 离散化。框用 [y1, x1, y2, x2] 归一化坐标，3D 立方体用 12 参数（投影中心、虚拟深度、对数尺寸、6D 旋转）。
  • 稠密结构：逐像素标签转 RGB 图像，深度归一化为灰度图，表面法线将 x/y/z 转 r/g/b。
  • 历史输入：图像/音频历史经 perceiver resampler 压缩，图像输出 32 token，音频输出 16 token，最大 4 帧/段。
  • 2D 旋转嵌入：RoPE 无参数，文本每层应用，其他模态将 query/key 分成两半分别用两坐标旋转嵌入，位置为 (h, w) 或 (t, l)。

训练目标

多模态混合去噪目标（multimodal mixture of denoiser objective），统一处理不同模态的生成与理解任务。预训练 150 万步，batch size 512，约 1 万亿 token。指令微调 batch size 256，227 个数据集共 775M 样本。

关键工程决策

  • 动态打包：因多模态样本缺模态导致大量填充，将多样本打包进单一序列，用掩码防跨样本注意力。TPU 上用 one-hot 矩阵乘法实现，最大输入 1152，目标 2048，约 4 倍加速。
  • 任务增强：分割任务增加“分割不存在的类别”“框内分割”“构建非类别像素图”等变体，提升泛化。

关键创新

  1. 四模态统一自回归框架：首次将图像、文本、音频、动作置于同一 encoder-decoder 从零训练，无需任何现成 LLM 初始化。动作生成直接预测离散 token，与文本生成共享同一输出空间，这是此前 CoDi、Emu 未做到的。

  2. 多模态混合去噪目标：不是简单的 next-token prediction，而是针对不同模态设计统一的去噪训练信号，使模型能同时学习生成（图像/音频）和理解（分类/QA）任务。这解决了多模态训练中“模态缺失导致填充效率低下”的核心问题。

  3. 细粒度 VQ-GAN + 大规模预训练的组合：作者明确将强图像生成能力归因于细粒度 VQ-GAN 和 1 万亿 token 预训练。在 TIFA 上 81.3 分证明，自回归离散 token 生成在忠实度上可以超越扩散模型（CoDi 71.6、Emu 65.5），尽管 FID 仍落后。

实验与结果

文本到图像/音频/动作生成（Table 4）

模型 FID ↓ TIFA ↑ FAD ↓ Succ. ↑
CoDi 11.26 71.6 1.80 -
Emu 11.66 65.5 - -
UIO-2 L 16.68 74.3 2.82 50.2
UIO-2 XL 14.11 80.0 2.59 54.2
UIO-2 XXL 13.39 81.3 2.64 56.3

TIFA 上 UIO-2 XXL 比 CoDi 高 9.7 分，比 Emu 高 15.8 分（由表内数值 81.3−71.6、81.3−65.5 计算）。FID 落后但作者归因于自回归生成本质，定性上图像平滑且细节丰富。动作成功率 56.3，低于专用 VIMA 的 72.6，但远超 VIMA-IMG 的 42.5。

视觉语言任务（Table 5）

  • VQA v2 上 XXL 达 79.4，仅被 13B LLaVa 的 80.0 超越。
  • ScienceQA 88.7，TallyQA 75.9，均领先所有同规模通用模型。
  • POPE 87.7（XXL），幻觉控制优于多数基线。
  • OK-VQA 55.5 是明显短板，作者归因于文本预训练不如 Qwen-VL 等专用语言模型充分。

视频/音频/3D（Table 6、7）

  • SEED-Bench Temporal 46.8，比 BLIP-2 的 36.7 高 10.1 分（由表内数值 46.8−36.7 计算）。
  • Kinetics-Sounds 89.3，优于仅在该数据集训练的 MBT 的 85.0。
  • 单目标 3D 检测 AP3D 42.4（XXL），接近 Cube-RCNN 的 50.8；但多目标 3D 检测显著下降，因训练数据仅 1.0% 聚焦 3D 检测。

GRIT 与 NLP（Table 13、14）

GRIT 综合 66.9（XXL），远超 GPV-2 的 31.9 和 OFA 的 22.4。NLP 上 MMLU 30.4 明显低于 LLaMA 7B 的 42.6，显示多模态预训练对纯文本能力有代价。

边界与局限

  • 编码器规模受限：因内存约束使用 ViT/AST base 版本，作者明确表示更大编码器可显著提升性能。
  • 图像生成质量：FID 13.39 仍落后扩散模型，作者承认质量不及 stable diffusion。
  • 音频生成时长：单次生成上限 4.08 秒，AudioCaps 评估需分段生成，限制实际应用。
  • 弱模态可靠性：深度、视频、3D 检测等任务可靠性低，可能因任务多样性不足。多目标 3D 检测训练数据仅 1.0%。
  • 超参数探索不足：计算资源有限，更大 batch size 可能提升性能；人工提示多样性不足，新指令任务性能下降明显。
  • NLP 能力退化：MMLU 30.4 远低于同规模纯文本模型，多模态广度对语言能力有明确代价。

工程启示

  • 复现先核对数据混合：预训练数据中文本占 33.0%、图像/文本 31.3%、视频 25.0%，交错数据仅 8.70%。若下游任务偏视频或 3D，需按 Table 10 比例调整，否则弱模态性能会像 3D 检测一样崩（AP3D 仅 42.4）。
  • 动态打包是性能关键：标准填充在多模态下效率极低，UIO-2 的启发式打包算法（内存小样本池 + 最大可打包配对）带来约 4 倍加速。复现时若用 PyTorch 需注意 JAX 的 one-hot 矩阵乘法实现不可直接迁移。
  • 音频生成别用无分类器引导：作者明确测试发现 CFG 导致音频性能差，推理时仅用 top-p 0.95。图像生成则需 CFG 尺度 α=10.0，两者策略完全不同。
  • VQA 视频输入帧选择有讲究：视频问答用第 3 帧作为图像输入效果最好，而非首帧或末帧；动作分类和字幕则用最后 1 帧。下游团队直接套用默认“中间帧”策略可能损失 2-3 分。
  • 最易踩坑处：RefCOCO-g 结果基于 Google split 而非 UMD split，对比时需确认基准版本；POPE 上 UIO-2 L 的 % Yes 高达 61.37，小模型幻觉倾向明显，部署时建议至少用 XL。
