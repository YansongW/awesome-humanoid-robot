Integrated linkage-driven dexterous anthropomorphic robotic hand

摘要

Integrated linkage-driven dexterous anthropomorphic robotic hand is a 2021 work on hardware design for humanoid robots.

来源与参考

  • Integrated linkage-driven dexterous anthropomorphic robotic hand project page

概述

本文提出了一款集成连杆驱动的拟人灵巧手 ILDA hand，通过并联-串联混合机构实现 15 自由度（20 关节）运动，指尖力达 34 N，重量 1.1 kg。该设计将全部驱动与传感部件嵌入手指本体，旨在解决腱驱动与直驱方案在集成性、成本与维护上的固有矛盾。

它改变了什么

机器人灵巧手长期在两条技术路线间挣扎：直驱电机方案使手指尺寸与性能被电机规格绑架，高端电机与力传递部件推高成本，电机重量导致惯性大、控制复杂，且指间空间狭窄难以布线传感器；腱驱动方案虽将驱动器移至前臂，却难以与现有商用机械臂集成，腱需穿越关节旋转轴或特殊结构，装配维护复杂，拮抗机制预应变增加摩擦、降低效率，单腱复位弹簧侧力控制困难。连杆驱动虽结构紧凑，但传统上难以实现多自由度运动与大工作空间，连杆粗硬不易独立驱动每个关节。

本文真正改变的是连杆驱动的能力边界：通过并联机构实现 MCP 关节 2 自由度，串联四杆机构实现 PIP/DIP 耦合运动，在窄手指空间内同时获得高灵巧度、大工作空间与高指尖力。更重要的是，所有驱动部件（电机、滚珠丝杠、传感器）全部嵌入手指本体，无需外部驱动单元，使手可直接集成到现有机械臂上，这是对集成性问题的根本性回应。

方法拆解

手指机构拓扑

  • 每个手指由三个串联链组成，均布置在同一地面：前方两个 PSS（棱柱-球-球）链构成 2 自由度并联机构，配合一个万向节形成虚拟三角形结构，三角形顶点固定在执行 MCP 运动的万向节上。
  • PSU（棱柱-球-万向）链穿过三角形内部，末端 V 形曲柄作为转动副连接到三角形一侧，实现驱动力高效传递。
  • 交叉四杆机构与曲柄串联，实现 1 自由度 PIP 运动；另一四杆机构耦合 PIP 与 DIP 关节运动。

驱动与运动学

  • 三个线性位移（d₁、d₂、d₃）由旋转电机与滚珠丝杠组合产生，三个电机可同时产生 3 自由度运动与高力输出。
  • 逆运动学分解为四个模型：两个 PSS 链、一个 PSU 链、PIP 四杆机构、DIP 四杆机构，均推导出闭式方程。
  • 关键设计决策：
  • 杆端（rod end）作为关键关节，可轴向连续旋转，不限制 MCP 关节 0–90° 屈伸与 ±35° 外展/内收，球轴承特性可承受高载荷并分散载荷。
  • LM 导轨布置用于抵消滚珠丝杠扭矩，无需固定丝杠顶部，简化装配并确保 MCP 关节运动。
  • 所有手指采用相同结构，仅拇指与小指长度不同，模块化设计降低成本。

电气与控制

  • 15 个电机（Maxon DCX 8 M，直径 8 mm，齿轮箱 GPX8 减速比 16:1，编码器 ENX 8 mag）通过五条合并柔性 PCB 线连接到集成连接板。
  • 八个双全桥电机驱动器（A3909）驱动十五个直流电机；八个从 MCU（STM32F411）传输控制命令，主 MCU（STM32F407）通过 SPI 总线与从 MCU 通信。
  • 指尖传感器通过 I2C 通信，主 MCU 通过 CAN 总线与顶层控制器通信。
  • 控制策略采用手部协同（hand synergy）：关节角 q = Sσ，其中 S 为协同向量（人类常见抓取类型的主成分），σ 为协同系数。

关键创新

  1. 并联-串联混合连杆机构：在单个手指内融合 2 自由度并联机构（MCP）与串联四杆机构（PIP/DIP），突破了连杆驱动难以实现多自由度与大工作空间的传统限制。这是对连杆驱动能力边界的实质性拓展，而非简单组合。

  2. 全嵌入式驱动与传感：所有电机、滚珠丝杠、LM 导轨、六轴 F/T 传感器全部嵌入手指本体，无需外部驱动单元。这直接解决了腱驱动难以与现有机械臂集成的痛点，同时避免了直驱方案的高成本与高惯性问题。

  3. 杆端关节设计：采用杆端作为关键转动副，可轴向连续旋转且不限制 MCP 关节运动范围，球轴承特性同时提供高承载能力。这一设计选择同时解决了运动学约束、强度与装配复杂度三个问题，是工程细节上的关键创新。

实验与结果

实验覆盖力控精度、动态响应、工具操作与可靠性四个方面。指尖力测试中，手固定在墙上，手指对商用参考传感器（Nano25，ATI Industrial Automation）施加外力，电流每 2 秒增加 25 mA。

可靠性测试通过 18-kg 哑铃举升验证结构强度。镊子实验成功操作厚度 0.9 mm、长度 6 mm 的扁平方形芯片。工作空间体积超过人类手指约 57%（由表内数值 188740→119800 计算），表明运动范围优于人类基准。

边界与局限

论文未明确长期耐久性测试结果与极端环境（温度、湿度、冲击）下的性能表现。作者承认难以准确定量评估剪刀工具操作的有效性，镊子操作虽稍简单，但握住镊子、转向期望方向并在持物时保持抓握仍具挑战。手部协同控制依赖从 Feix 抓取分类学选取的 14 种抓取类型，对分类学之外的非常规抓取模式可能覆盖不足。论文未明确提及手指在高速动态运动下的控制带宽与跟踪精度。

工程启示

复现或选型时，首先核对三个关键点：杆端关节的轴向旋转自由度是否满足 MCP 关节 0–90° 屈伸与 ±35° 外展/内收的完整运动范围，这是机构能否正常工作的前提；LM 导轨与滚珠丝杠的配合是否有效抵消扭矩，否则丝杠顶部固定方式会限制 MCP 运动并增加装配复杂度；柔性 PCB 布线在连杆运动路径中的干涉情况，传感器布线需确保不干扰手指运动。

最容易踩坑的环节是 PSU 链中 V 形曲柄与三角形侧边的转动副配合——此处摩擦直接影响驱动力传递效率与指尖力上限。材料选择上，手指框架与关键轴使用 SUS303 钢，其余为铝 6061，若替换材料需重新校核强度与重量平衡。控制层面，手部协同向量依赖视觉模拟器预测关节角，实际部署时需针对目标物体尺寸与摩擦系数重新采集主成分，直接迁移可能降低抓取成功率。
