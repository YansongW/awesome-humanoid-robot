Sabanto Inc. and Verdant Robotics Announce Technical Integration of Autonomous Tractor Operation with SharpShooter Plant-Level Precision Application

摘要

Sabanto Inc. 与 Verdant Robotics 宣布技术集成，将 Sabanto 的自主导航系统与 Verdant 的 SharpShooter 植物级精准施药系统结合，实现从田间导航到单株施药的全流程无人驾驶作业。该集成方案无需驾驶舱操作员，通过 CAN 总线实时通信，由 SharpShooter 根据田间数据自动调整拖拉机速度和机具高度，显著减少劳动力需求并降低投入成本。

来源与参考

概述

Sabanto Inc. 和 Verdant Robotics 首次将各自的系统集成，形成单一解决方案，使农业机械能够完全自主地完成从导航到植物级精准施药的全过程，无需操作员在驾驶舱内。Sabanto 的自主系统与 Verdant 的 SharpShooter 精准施药系统通过 CAN 总线直接通信，SharpShooter 利用 Aim & Apply 技术识别单个植物和杂草，仅在需要处施药，从而大幅减少投入。集成系统还能根据田间数据实时调整拖拉机的速度和机具高度，优化性能。该方案已在 Bethel Farms 的商业化草皮生产中验证，展示了在苛刻条件下的可靠性。

核心内容

集成方案概述

Sabanto Inc. 是农业机械自主改装解决方案的领导者，Verdant Robotics 是 SharpShooter 精准施药系统的开发商，双方首次将系统集成，形成单一解决方案。该方案使生产者能够完全自动化田间作业，从导航到植物级精准施药，无需操作员在驾驶舱内。

技术细节

  • 通信机制：SharpShooter 通过 CAN 总线与 Sabanto 改装的拖拉机直接通信，在主动导航期间向 Sabanto Autonomy System 实时传输田间数据。
  • 自主决策：基于数据，SharpShooter 指示拖拉机根据田间条件调整速度和机具高度，无需操作员输入。原本由熟练操作员在驾驶舱做出的决策，现在由集成系统自主执行。
  • 核心组件：Sabanto Autonomy System 包括高精度 GNSS、摄像头、先进车辆操作系统和专有路径规划；SharpShooter 采用 Aim & Apply 技术，通过物理 AI 识别单个植物和杂草，实现毫米级精准施药。

关键优势

  • 劳动力减少：完全自主操作消除了对驾驶舱操作员的需求，应对农业中普遍存在的劳动力短缺问题。
  • 投入节省：SharpShooter 实时识别单个植物和杂草，仅在需要处精准施药，而非全田喷洒，大幅降低投入成本。
  • 全天候生产力：Sabanto 的改装自主系统支持 24/7 无人操作；SharpShooter 的轻量化设计允许更早进入田间和运输，增加作业时间，覆盖更多英亩数。
  • 实地验证：该集成已在 Bethel Farms 的商业化草皮生产中展示可靠性能，适用于多种作物市场。

行业评价

  • Craig Rupp（Sabanto 创始人兼CEO）：强调该集成是农业实用、可扩展自主性的重大飞跃，通过将 Sabanto 的改装系统与 SharpShooter 结合，为生产者提供在现有设备上运行的完整解决方案，实现 24/7 精准作业，应对劳动力短缺并削减投入成本。
  • Gabe Sibley（Verdant Robotics 联合创始人兼CEO）：指出 SharpShooter 用户旨在减少投入、运行无人值守作业，该集成使他们无需操作员即可覆盖更多英亩，保持植物级精准度，直接解决 growers 的挑战。

兼容性与背景

  • 兼容性：集成系统兼容多种拖拉机品牌和型号，延续 Sabanto 的改装理念，利用农民现有设备。
  • 市场背景：该合作应对当前市场挑战，如高利率、上升的投入成本、劳动力问题和更紧的施药窗口。
  • 公司简介：Sabanto 成立于 2018 年，总部位于爱荷华州艾姆斯，提供经济实惠的后市场改装套件；Verdant Robotics 提供 AI 驱动的精准施药技术，SharpShooter 是唯一在施药前瞄准的系统。
