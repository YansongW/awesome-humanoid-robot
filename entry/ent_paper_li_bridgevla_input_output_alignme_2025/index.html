BridgeVLA

BridgeVLA: Input-Output Alignment for Efficient 3D Manipulation Learning with Vision-Language Models

领域

层级
智能层
审校

摘要

BridgeVLA 是字节跳动 Seed、中国科学院大学、中国科学院自动化研究所、FiveAges、南京大学等机构在 NIPS25 上提出的 3D 视觉-语言-动作模型。其核心贡献在于通过将 3D 输入投影为多张 2D 图像并与 VLM 骨干对齐，同时利用 2D 热图预测动作，实现了输入输出空间在 2D 图像空间中的统一。该模型在 RLBench、COLOSSEUM、GemBench 等仿真基准和真实机器人实验中均显著超越现有方法，展现出极高的样本效率。

来源与参考

  • BridgeVLA: Input-Output Alignment for Efficient 3D Manipulation Learning with Vision-Language Models (arXiv)

概述

BridgeVLA 提出一种输入-输出对齐的视觉-语言-动作（VLA）训练范式，通过统一距离场（DF）交互表示与三阶段蒸馏流程，使单一人形策略在无运动参考、无任务奖励、无独立规划器条件下，实现跨物体尺度与几何的多样化长时程操作。核心贡献在于将交互几何先验编码为速度分解的潜变量，并利用判别式后训练与视觉蒸馏弥合仿真到现实的鸿沟。

它改变了什么

现有参考动作方法（如 HDMI、ResMimic）将策略与示范中的物体几何强耦合，一旦物体尺度或形状偏离训练分布，规定动作即失效，这本质上是把“记忆”当“泛化”。参考无关方法（如 PhysHSI）虽提升鲁棒性，却依赖任务特定奖励或手工交互线索，导致每个技能需独立训练，无法在单一策略内组合多种交互。BridgeVLA 真正改变的是：将“交互”本身从任务描述中剥离，定义为锚定于物体几何的动态距离场，使策略学习的是“如何与任意表面交互”而非“如何复现某条轨迹”。这使单一策略能同时覆盖抓取、坐立、推、搬运等异构技能，且对物体尺度变化保持稳定，而非在训练分布边缘崩溃。

方法拆解

交互表示构建

  • 定义距离场 Φ: ℝ³ → ℝ，锚定于物体几何，对每个链节位置 x_t 与速度 v_t 获取表面距离 Φ(x_t) 与局部表面方向 ∇Φ(x_t)。
  • 速度分解：法向分量 v_t^norm = (v_t·∇Φ(x_t))∇Φ(x_t) 捕捉接近/施力强度；切向分量 v_t^tan = v_t − v_t^norm 捕捉表面滑动。
  • 每个时间步构建元组 u_t = [Φ(x_t), ∇Φ(x_t), v_t^norm, v_t^tan]，在时间窗口 l 上形成交互表示 I_t = {u_{t−l+1}, …, u_t}，对物体全局位姿与尺度不变。

三阶段训练

  1. 交互技能预训练：教师策略 π_mimic 跟踪重定向人体运动生成物理有效数据；π_base 通过行为克隆训练，输入根轨迹命令 c_t^root、本体感觉 o^prop 与 DF 潜变量 z_t（由 VAE 编码 I_t 得到），无参考动作。
  2. 判别式后训练：π_base 经 RL 微调，由 AIP 判别器引导，在随机化物体几何的几何域中正则化交互有效性，生成 π_full。
  3. 视觉-运动蒸馏：π_full 通过 DAgger 式监督蒸馏为 π_vis，用自我中心深度帧历史 S_t 替代 mocap 输入，视觉编码器 E_φ 将 S_t 映射到潜变量 z_t，蒸馏损失 L_distill = E_{s∼π_vis}[‖π_vis(o_vis) − π_full(o_base)‖²₂]。

推理输入

策略仅需目标根轨迹与当前 DF 观测，无运动参考、无任务奖励、无独立规划器。蒸馏期间应用相机外参扰动、深度观测加性噪声与物理属性随机化，促进 sim-to-real 迁移。

关键创新

  1. 统一 DF 交互表示：将交互强度（法向速度）与表面流动（切向速度）解耦，使策略学习的是几何不变的交互规律，而非任务特定轨迹。这是首个将距离场作为跨任务统一动作表示的方案，直接支撑多技能组合。
  2. AIP 判别式后训练：在随机化几何域中用判别器正则化交互有效性，而非依赖任务奖励，使策略在训练分布外仍保持物理合理交互。消融显示移除 AIP 后 PickUp 在 0.4× 尺度成功率从 63.0% 跌至 0.0%。
  3. 视觉蒸馏替代 mocap：用自我中心深度帧历史学习恢复 DF 提供的几何线索，使策略仅依赖便携式视觉输入即可部署，且保持尺度泛化（视觉变体在 0.4× 尺度 PickUp 达 63.7%）。

边界与局限

MoCap 模型依赖全局物体信息（mocap 系统），在大多数真实部署中不可用；视觉模型在 Push 任务接触率偏低（0.6× 尺度仅 1.2%），SitStand 因背侧接触的自我中心可观测性有限被排除在视觉评估外。长时程组合中视觉变体在 N=10 即降至 2.5%，显示蒸馏后组合能力显著衰减。论文未明确探索其他感知模态（如触觉、RGB）或铰接/可变形物体的扩展。

工程启示

复现时先核对三处：其一，DF 表示的时间窗口 l 与 VAE 潜变量维度直接影响训练稳定性，建议从较小窗口（如 5）起步；其二，AIP 判别器与 RL 微调是尺度泛化的关键，移除后 PickUp 在 0.4× 尺度从 63.0% 跌至 0.0%，此环节不可跳过；其三，视觉蒸馏的域随机化（相机外参扰动、深度噪声）对 sim-to-real 至关重要，但需注意视觉变体在接触密集任务（Push、Carry）上的性能衰减，下游团队若聚焦此类任务应优先评估 mocap 方案或增加触觉模态。最易踩坑处在于几何随机化范围：禁用随机化（Ours - Rand.）导致训练尺度外近零成功，务必覆盖 0.4× 至 1.6× 全区间。

知识关联

方法

动作分块变压器（ACT）

动作分块变压器（ACT）是一种模仿学习方法：用变压器以条件变分自编码器（CVAE）形式一次性预测未来一段动作序列（chunk），再经时间集成平滑执行，显著降低长时程精细操作中的误差累积。

 评测基准

LIBERO-Plus

一个针对视觉-语言-动作模型的鲁棒性基准，扩展自 LIBERO，涵盖 10,030 项任务，覆盖相机视角、机器人初始状态、语言、光照、背景、噪声与物体布局七种扰动维度。

 方法

OpenVLA

基于Open X-Embodiment数据集训练的开源视觉-语言-动作模型，用于可泛化的机器人操作。
