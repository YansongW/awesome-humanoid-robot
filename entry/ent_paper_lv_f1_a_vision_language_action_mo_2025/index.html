F1: A Vision-Language-Action Model Bridging Understanding and Generation to Actions

摘要

F1 是上海人工智能实验室与哈尔滨工业大学（深圳）于 2025 年联合提出的大型视觉-语言-动作模型，专为机器人操作任务设计。其核心贡献在于将视觉前瞻生成融入决策流程，通过 Mixture-of-Transformer 架构实现感知、预测与控制的统一，并在 136 项任务的 33 万条轨迹数据集上训练，显著提升了动态环境下的任务成功率与泛化能力。

来源与参考

  • F1: A Vision-Language-Action Model Bridging Understanding and Generation to Actions (arXiv)
  • F1 source

概述

F₁ 是一个从零训练的统一视觉-语言-动作（VLA）模型，将理解、生成与动作执行整合进单一 encoder-decoder transformer，通过多模态混合去噪器与动态掩码机制实现跨模态联合学习。核心贡献在于将动作纳入统一 token 空间，并以“前瞻引导的逆动力学”重构控制任务，在长时程与动态操作中显著超越纯反应式 VLA 基线。

它改变了什么

现有 VLA 模型普遍从当前观测直接映射动作，缺乏对场景演变的显式推理，导致动态与长时程任务中决策短视。同时，统一视觉语言模型（如 MoT 架构）仍以理解和生成为中心，未将动作视为认知智能的组成部分。F₁ 真正改变的是将“预测未来”作为动作推导的中间变量，使控制不再是被动响应，而是基于预期视觉结果的前瞻规划——这从范式上区分于 OpenVLA、π₀ 等纯行为克隆模型。

另一个关键转变在于训练策略：F₁ 不依赖预训练 LLM 初始化，而是从零训练覆盖图像、文本、音频、动作的统一模型。这挑战了“LLM 底座 + 多模态适配”的主流路线，主张通过模态共现自然习得跨模态关联，而非在冻结的语义空间上打补丁。其代价是训练稳定性问题（梯度范数失控、损失爆炸）成为必须解决的一等公民问题，而非可回避的工程细节。

方法拆解

统一任务表示

所有模态（图像、文本、音频、动作、稀疏结构）编码为共享语义空间的 token 序列，由单一 encoder-decoder transformer 处理。文本用 LLaMA BPE；稀疏结构（框、点、位姿）离散化为 1000 个特殊 token；动作离散化为文本命令（如“move ahead”）加状态 token。

图像与音频编解码

  • 图像：预训练 ViT 拼接第二层与倒数第二层 patch 特征，线性投影嵌入；生成用 VQ-GAN，8×8 patch，256×256 图像 → 1024 token，codebook 16512。
  • 音频：编码最多 4.08 秒为频谱图，预训练 AST 提取特征；生成用自实现 ViT-VQGAN，256×128 频谱图 → 512 token，codebook 8196。
  • 历史输入：最多 4 个额外图像/音频段，perceiver resampler 压缩为 32（图像）/16（音频）token。

架构稳定性设计

  • 2D Rotary Embedding：RoPE 扩展到二维位置，query/key 嵌入分两半分别旋转，适配非文本模态的空间结构。
  • QK Normalization：点积注意力前对 query/key 应用 LayerNorm，抑制多模态注意力 logits 极端值。
  • Scaled Cosine Attention：perceiver resampler 内应用，进一步稳定训练。
  • float32 注意力 logits：避免数值不稳定；预训练冻结 ViT/AST，指令微调末尾解冻。

训练目标：多模态混合去噪器

结合 UL2 的 [R]/[S]/[X] 范式：图像/音频定义 [R]（随机掩码 x% patch 重建）与 [S]（仅基于其他模态生成目标模态）。输入前缀含模态 token（[Text]/[Image]/[Audio]）与范式 token。

自回归动态掩码

解码器掩码 token 除非预测该 token 本身，避免生成与去噪任务相互干扰；图像/音频生成用行、列、conv 形状稀疏注意力。动态打包在 encoder-decoder 前后进行，吞吐量提升近 4 倍。

优化器

Adafactor，线性 warm-up 5000 步，学习率衰减 1/√k，β1=0.9，β2=1.0−k^−0.8，梯度裁剪 1.0，训练 3.0M 步（1.5M 预训练 + 1.5M 指令微调）。

关键创新

  1. 前瞻引导的逆动力学：动作不仅从当前状态推导，还从预期的视觉结果推导。这使模型在动态任务中具备“先想象后行动”的能力，而非纯反应式映射。消融显示移除生成专家（No-Gen）导致成功率从 77.5% 降至 60.3%，证明前瞻分支并非装饰而是性能支柱。

  2. 从零训练的统一多模态架构：不依赖预训练 LLM，通过多模态混合去噪器同时学习理解、生成与动作。这避免了 LLM 底座对非文本模态的归纳偏置，但也迫使解决梯度范数失控、损失爆炸等稳定性问题——QK Normalization 与 2D RoPE 是为此设计的通用方案，而非任务特定补丁。

  3. 动态掩码与打包：自回归动态掩码解决解码器信息泄漏，使生成与去噪任务可共存于同一序列；动态打包将吞吐量提升近 4 倍，使 600 TB 级数据训练成为可能。这两项是工程层面的关键创新，直接决定模型能否规模化。

消融与真实世界

  • 完整模型 LIBERO 成功率 77.5%；Frozen-Gen 降至 73.8%；No-Gen 降至 60.3%。
  • 真实世界“Handover”任务：No-Gen 40.0% vs. 完整模型 93.3%（15 次试验）。
  • 长时程 10 步任务：π₀ 第 3 步后全部失败（0.0%），F₁ 第 10 步仍保持 40.0%。
  • 动态环境（ARX LIFT II，47 个演示）：F₁ 连续双臂抓取 66.7%，π₀ 整体 33.3%。

边界与局限

  • 图像 token 准确率绝对值较低（约 40–45%），细粒度物体形状与纹理保持困难（如网格购物车、塑料袋、可变形衣物），作者归因于未在大规模生成数据集上预训练。
  • 长时程任务性能随序列推进逐渐下降（第 10 步降至 40.0%），误差累积与时间扩展推理的复合难度未解决。
  • HellaSwag 显示语言建模能力介于典型 3B 与 7B 模型之间，因仅见约 2500 亿 token，远少于语言 LLM。
  • VQA 新源问题（Visual Genome 构建）性能下降，整体 VQA 分数略低于 Unified-IO。
  • 未进行任务特定微调，所有实验为零样本或指令跟随评估；未提供推理频率与硬件细节。

工程启示

  • 复现时优先核对训练稳定性三件套：QK Normalization、2D RoPE、float32 注意力 logits。若跳过任一，多模态注意力 logits 极端值可能导致损失在 350k 步后爆炸、下一 token 准确率在 400k 步下降——这是论文明确记录的失败模式。
  • 动态打包是吞吐量关键（提升近 4 倍），但需注意其与自回归动态掩码的交互：打包改变序列边界，掩码逻辑必须按 token 位置而非样本边界计算，否则信息泄漏会悄悄侵蚀生成质量。
  • 下游团队若只关心动作性能，不要直接移除生成分支——No-Gen 消融显示成功率从 77.5% 降至 60.3%。前瞻分支的收益在动态任务（Handover 93.3% vs. 40.0%）中尤为显著，静态任务可能收益较小。
  • 长时程任务（>10 步）是当前瓶颈，若部署场景接近此范围，建议先验证第 5 步后的成功率衰减曲线，而非只看平均成功率。
