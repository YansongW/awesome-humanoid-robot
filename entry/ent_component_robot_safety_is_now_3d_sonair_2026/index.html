Robot safety is now 3D: Sonair unveils world's first safety-certified 3D ultrasonic sensor for human-robot collaboration

摘要

The ADAR One sensor is now suitable for SIL2 and PL d applications and is certified to fulfil all requirements of the European machine directive as a sensor for the safe detection of humans and objects.

来源与参考

  • Robot safety is now 3D: Sonair unveils world's first safety-certified 3D ultrasonic sensor for human-robot collaboration

概述

ADAR One 是全球首款通过安全认证的 3D 超声波传感器，适用于 SIL2 和 PL d 应用，并已认证满足欧洲机械指令中关于安全检测人员和物体的全部要求。它利用声学而非光学原理，为自主移动机器人和人形机器人提供 180°×180° 的 3D 空间感知能力，填补了传统 2D 激光扫描仪在安全感知维度上的盲区。

核心内容

是什么：从 2D 平面到 3D 空间的感知跃迁

ADAR One 是 Sonair 公司推出的声学探测与测距（acoustic detection and ranging, ADAR）传感器，其核心定位是安全级（safety-rated）3D 感知硬件。它并非传统意义上的超声波测距模块，而是一个完整的、经过独立认证的安全传感器系统，专为人机协作（human-robot collaboration）场景设计。

该传感器已通过认证，适用于 SIL2（Safety Integrity Level 2，IEC 61508 定义的安全完整性等级）和 PL d（Performance Level d，ISO 13849 定义的安全性能等级）应用。这意味着它能够满足欧洲机械指令（European machine directive）对安全检测人员和物体的全部要求，可作为安全回路中的核心感知元件直接使用。

它真正改变的不是"机器人能看多远"，而是"机器人能否在任何条件下可靠地知道人类就在附近"——这是安全感知（safe perception）的本质问题。

为什么存在：2D 安全系统的结构性盲区

当前大多数移动机器人系统依赖 2D 激光扫描仪来定义安全周界（safety perimeter）。这类传感器的工作原理是在一个水平面内发射激光束并测量反射时间，从而构建该平面内的障碍物分布图。然而，这种方案存在一个根本性缺陷：它无法检测到单个平面之上或之下的人员和障碍物。

在工业环境中，这意味着：

  • 蹲下检修设备的工人可能完全处于扫描平面之下，成为"隐形人"；
  • 堆放在通道上的货物若高于或低于扫描平面，同样无法被感知；
  • 人形机器人由于具有多自由度躯干和手臂，其运动范围远超单一平面，2D 扫描根本无法覆盖其工作空间。

Sonair CEO Knut Sandven 对此的表述切中要害："安全人机共存的瓶颈不是智能或速度，而是安全感知——在任何条件下可靠地知道人类就在附近。"这一判断揭示了行业长期存在的结构性缺口：AI 的进步让机器人变得更聪明，但安全基础设施却未能同步跟上。

原理拆解

① 声学探测与测距（ADAR）的核心机制

ADAR One 采用超声波作为探测媒介。与激光或相机依赖光线反射不同，超声波传感器发射声波脉冲并接收回波，通过测量声波从发射到返回的时间差来计算目标距离。其基本测距原理为：

\[ d = \frac{v_{\text{sound}} \cdot t_{\text{flight}}}{2} \]

其中 \(d\) 为目标距离，\(v_{\text{sound}}\) 为声速（约 343 m/s，常温空气声速，通用物理常数），\(t_{\text{flight}}\) 为声波往返时间。除以 2 是因为声波需要走一个来回。

② 3D 空间感知的实现方式

ADAR One 的关键突破在于将超声波从"单点测距"扩展为"3D 空间感知"。它通过相控阵（phased array）或多换能器阵列的方式，在 180°×180° 的视场范围内同时发射和接收多路声波信号，利用不同方向回波的时间差和相位差，重建出三维空间中的障碍物分布。

这一方案的优势在于：

  • 不受光照条件影响：在黑暗、强光、眩光等相机失效的场景中依然可靠工作；
  • 不受颜色和纹理影响：激光扫描仪对深色或高反光表面可能失效，声波则无此问题；
  • 全高度覆盖：能够检测到地面上蹲着的人、高于扫描平面的障碍物等 2D 系统无法感知的目标。

③ 安全认证的技术基础

SIL2 和 PL d 认证要求传感器具备故障安全（fail-safe）特性：当传感器自身发生故障时，系统必须能够检测到故障并进入安全状态，而非输出错误的安全信号。这要求 ADAR One 具备：

  • 自诊断能力：持续监控自身工作状态，检测换能器失效、信号异常等情况；
  • 冗余设计：关键路径的冗余配置，确保单一故障不会导致安全功能丧失；
  • 确定性响应：在规定的响应时间内给出确定性的安全输出。

ADAR One 的核心差异化在于：它是首个通过安全认证的 3D 传感器，且采用声学而非光学原理。这意味着它在相机失效的场景（黑暗、眩光、烟雾）中依然能提供经过认证的安全保障。

谁在用·应用案例

ADAR One 的设计目标市场是自主移动机器人（autonomous mobile robots, AMR）和工业自动化领域。其小尺寸（tiny footprint）设计使其能够齐平嵌入（embedded flush）到几乎任何机器人形态中，包括人形机器人（humanoids）。

典型应用场景包括：

  • 人机协作工作站：在工业机器人工作区域内提供经过认证的 3D 安全监控，替代或补充传统的 2D 安全扫描仪；
  • 自主移动机器人导航：在仓库、工厂等动态环境中，检测所有高度的人员和障碍物，避免碰撞；
  • 人形机器人安全层：作为底层安全感知基础设施，独立于相机和 AI 系统运行，为上层决策提供"空间是否安全"的确定性判断。

据语料信息，ADAR One 已进入系列生产（series production）阶段，并已在部署的工业机器人上发货。Sonair CEO 将其定位为"一种新的安全层，一个经过认证的 3D 感知基础，位于任何相机、AI 栈或运动系统之下，独立验证机器人周围空间是否安全"。

局限与边界

  1. 声速受环境温度影响：声速随温度变化，可能影响测距精度。虽然可通过温度补偿缓解，但在极端温度变化环境中需额外校准（工程判断）。
  2. 探测范围有限：超声波传感器的有效探测距离通常短于激光雷达，适用于近距离安全监控而非远距离导航（需自行确认具体数值）。
  3. 多径效应：声波在复杂环境中可能发生多次反射，产生虚假回波，需要信号处理算法进行抑制。
  4. 不替代相机和 AI：ADAR One 定位为安全层而非感知主传感器，它验证"空间是否安全"，但不提供语义理解（如"这是什么物体"）。
  5. 认证范围：SIL2 / PL d 适用于特定安全功能，更高安全等级（如 SIL3 / PL e）的应用需另行评估。

常见误区

  1. "ADAR One 只是普通超声波传感器"——错。它通过了 SIL2 / PL d 安全认证，具备故障安全特性和确定性响应，这是普通超声波模块不具备的。
  2. "3D 传感器就能替代 2D 安全系统"——不完全是。ADAR One 是补充而非简单替代，它填补了 2D 系统在高度维度上的盲区，但 2D 激光扫描在远距离和周界定义上仍有优势。
  3. "安全认证只是营销噱头"——错。SIL2 / PL d 认证意味着传感器经过了独立验证，满足 IEC 61508 和 ISO 13849 的功能安全要求，这是法律和保险层面的硬性要求。
  4. "超声波在工业环境中不可靠"——部分误解。工业环境中的噪声和振动确实可能干扰超声波，但 ADAR One 的设计目标正是"在任何条件下可靠"，其信号处理算法需自行确认其抗干扰能力。
