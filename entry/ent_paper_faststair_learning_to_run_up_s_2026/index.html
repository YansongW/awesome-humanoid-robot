FastStair: Learning to Run Up Stairs with Humanoid Robots

FastStair: Learning to Run Up Stairs with Humanoid Robots

摘要

FastStair 是一个由规划器引导的多阶段学习框架，旨在让双足人形机器人实现快速且稳定的上楼梯动作。该工作由研究团队提出，核心贡献在于融合了基于模型的落脚点规划器与强化学习，并通过 LoRA 技术集成速度专家策略，最终在 Oli 人形机器人上实现了最高 1.65 m/s 的指令速度，并赢得了广州塔机器人竞速大赛冠军。

来源与参考

  • FastStair: Learning to Run Up Stairs with Humanoid Robots (arXiv)

概述

上楼梯对人类而言轻而易举，但对人形机器人却极具挑战，因为它同时要求高敏捷性和严格的稳定性。无模型强化学习能生成动态运动，但隐式的稳定性奖励和任务特定的奖励塑造常导致不安全行为；而基于模型的落脚点规划器虽能编码接触可行性与稳定性结构，但其硬约束往往导致保守运动，限制速度。FastStair 框架通过将并行模型落脚点规划器集成到强化学习训练循环中，引导探索朝向动态可行的接触点，并预训练一个注重安全的基础策略。为了缓解规划器带来的保守性以及高低速动作分布的差异，基础策略被微调为速度专家，并通过 LoRA 技术集成，实现了在全指令速度范围内的平滑运行。

核心内容

方法

FastStair 的核心是一个规划器引导的多阶段学习框架，旨在调和基于模型与无模型方法的互补优势。 - 规划器引导的强化学习：在训练循环中并行运行一个基于模型的落脚点规划器，其输出用于指导强化学习策略的探索，使其偏向于动态可行的接触点。同时，利用规划器的输出预训练一个注重安全的基础策略。 - 多阶段微调与集成：为了克服规划器带来的保守性以及低速与高速动作分布之间的差异，基础策略被进一步微调为多个速度专精的专家策略。这些专家策略通过 Low-Rank Adaptation (LoRA) 技术进行集成，使得最终策略能够在整个指令速度范围内平滑切换和运行。

实验设置与结果

  • 机器人平台：Oli 人形机器人。
  • 性能指标：
    • 实现了最高 1.65 m/s 的指令速度下的稳定上楼梯。
    • 成功在 12 秒 内完成了一段包含 33 级台阶 的螺旋楼梯（每级台阶高度 17 cm），展示了在长楼梯上的鲁棒高速性能。
  • 竞赛成绩：该方案在 广州塔机器人竞速大赛 中获得了冠军。
