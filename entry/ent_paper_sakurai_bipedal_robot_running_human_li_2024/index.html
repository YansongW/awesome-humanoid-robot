双足机器人跑步：利用快/慢自适应实现类人驱动时机

Bipedal Robot Running: Human-like Actuation Timing Using Fast and Slow Adaptations

摘要

本文提出一种基于中枢模式发生器（CPG）的控制器，通过结合触地时的快速相位重置与慢速步态周期收敛，在肌肉骨骼双足跑步机器人中复现人类肌肉激活时序。该方法在弹簧负载倒立摆模型和真人尺寸机器人上得到验证，核心贡献在于利用快慢适应机制实现类人跑步的适应性控制。

来源与参考

  • Bipedal Robot Running: Human-like Actuation Timing Using Fast and Slow Adaptations

概述

RoboMirror 提出首个免重定向的视频到运动框架，将人形机器人运动视为生成问题，通过“理解-重建-控制”三阶段实现从第一/第三人称视频直接合成物理合理且语义一致的运动。核心贡献在于用生成式重建替代传统姿态估计-重定向-跟踪管道，将延迟从 9.22 s 降至 1.84 s，任务成功率绝对提升 3.7%。

它改变了什么

现有最先进的人形运动系统要么依赖精心策划的动捕轨迹，要么依赖稀疏文本命令，在视觉理解与控制之间存在关键空白。文本到运动方法受限于语义稀疏性和分阶段管道错误；基于视频的方法仅做机械姿态模仿，缺乏真正的视觉理解。传统“姿态估计-重定向-跟踪”管道脆弱，误差累积和延迟问题在架构上无法支持语义理解。

RoboMirror 真正改变的是将运动生成从“模仿姿态”转向“理解后生成”。它不再试图从视频中精确提取人体关节位置再映射到机器人，而是让视觉语言模型先理解场景语义，再用扩散模型在运动潜空间重建合理动作。这一转变消除了重定向环节，使系统在架构上具备语义理解能力，而非仅在数值上逼近姿态。

方法拆解

三阶段流程

  • 理解：采用 Qwen3-VL 从第一/第三人称视频提取高层语义潜变量 l_VLM。
  • 重建：训练 VAE 在运动数据集上获得运动潜变量 l_motion，使用基于流匹配的扩散模型 D_θ 重建运动潜变量。
  • 噪声构造：ε_motion = τ · l_motion + (1 − τ) · ε，τ ∈ [0,1] 为流匹配时间步，ε ~ N(0, I)。
  • 损失函数：L_fm = E[||D_θ(l_VLM, ε_motion, τ) − (ε − ε_motion)||²₂]。
  • 架构：堆叠 transformer 块，交叉注意力关注视频潜变量强制语义一致性，自注意力捕获时间依赖。
  • 控制：教师策略用 PPO 训练，利用特权信息（真实根速度、全局关节位置、物理属性、本体感受、参考运动），输出残差偏移 â_t = p_target + δ_a，动作维度 ℝ²³。集成混合专家（MoE），最终动作 â_t = Σᵢ₌₁ⁿ pᵢ · aᵢ。

学生策略

采用 DAgger 类范式，在模拟中滚动部署查询教师最优动作，训练时注入高斯噪声，以重建潜变量 l_v2m 为引导，噪声过程遵循马尔可夫链。推理时无需姿态估计和重定向。

关键设计决策

“重建优于对齐”：通过生成式重建实现稳健跨模态对齐，而非浅层特征匹配。初始策略 π₀ 仅在第三人称数据集 D_third 上训练，因第一人称数据集 D_first 相对简单。

关键创新

  1. 免重定向架构：首次将视频到运动映射从“姿态估计+重定向”改为“语义理解+潜空间重建”，从架构上消除误差累积和延迟来源，这是本质性改变而非工程优化。
  2. 生成式跨模态对齐：用流匹配扩散模型在运动潜空间重建，而非浅层特征匹配。这一设计使系统能处理语义稀疏的视频输入，在缺乏显式姿态监督时仍能合成一致运动。
  3. 教师-学生潜变量引导：教师策略利用特权信息学习残差动作，学生策略以重建潜变量为引导进行生成式模仿，实现从模拟到真实的可迁移控制，且推理时无需特权信息。

边界与局限

论文未明确列出局限性。作者提到可扩展到精细手部操作和低摩擦远程操作，但未说明实现或验证细节。初始策略仅在第三人称数据集训练，第一人称数据集的泛化边界未充分探讨。教师策略依赖特权信息，学生策略在真实世界部署的 sim-to-real 差距未在片段中量化。

工程启示

复现时先核对视频理解模块的潜变量维度与运动潜变量是否对齐，这是跨模态重建的瓶颈。教师策略的 MoE 门控概率初始化敏感，建议先用单专家预训练再扩展。学生策略的 DAgger 训练中，高斯噪声注入幅度需与教师动作尺度匹配，过大易导致策略发散。过滤阈值 e(s) > 0.6 依赖关键下肢地标误差与关节角度误差的加权，需根据机器人型号重新标定 α 和 β。推理延迟优势主要来自消除重定向环节，但视频理解模块 Qwen3-VL 的推理时间未单独报告，端到端延迟可能受其影响。
