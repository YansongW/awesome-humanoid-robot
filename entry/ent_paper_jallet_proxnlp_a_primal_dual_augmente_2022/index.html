摘要

本文提出了一种用于流形上不等式约束非线性规划的原对偶增广拉格朗日方法，并介绍了开源C++实现proxNLP，该实现集成了Eigen、Pinocchio和CasADi绑定。通过在Talos机器人姿态生成等实例上的验证，展示了其在机器人学中的鲁棒性和高效性。

来源与参考

  • ProxNLP: a primal-dual augmented Lagrangian solver for nonlinear programming in Robotics and beyond

概述

ProxNLP 是一个面向机器人学非线性规划的开源 C++ 求解器，由法国 Simple-Robotics 团队开发，核心贡献是将原始-对偶增广拉格朗日（pdAL）方法从等式约束推广到流形上的不等式约束问题，并提供了基于 Eigen 和 Pinocchio 的高效实现。该方法通过引入对偶变量的罚项，使得任何驻点都满足原问题的 KKT 条件，从而在保持增广拉格朗日精确性的同时改善收敛行为。

它改变了什么

机器人学中的轨迹优化和逆动力学问题天然是流形上的约束优化，但现有 NLP 求解器（如 IPOPT、SNOPT）要么不原生支持李群参数化，要么在不等式约束和流形结构上缺乏针对性设计。ProxNLP 改变了这一局面：它不再将流形约束“拉平”到欧氏空间处理，而是直接在矩阵李群上定义增广拉格朗日函数，并通过原始-对偶框架同时更新原变量和对偶变量，避免了经典乘子法中对偶上升步的振荡问题。

更重要的是，该方法将 pdAL 从纯等式约束（文献 [6] 的原始设定）扩展到不等式约束，并给出了活动集的定义和对应的 KKT 条件。这意味着机器人学中常见的关节极限、摩擦锥、接触力约束等不等式约束，现在可以享受 pdAL 的精确性和快速收敛特性，而无需像罚函数法那样担心罚参数过大导致的病态问题。

方法拆解

问题形式与增广拉格朗日

问题定义为 min_{x∈M} f(x) s.t. g(x)=0, h(x)≤0，其中 M 为流形。经典 Hestenes-Powell-Rockafellar 增广拉格朗日函数为： L_μ(x; y_e, z_e) = f(x) + (1/2μ)‖g(x)+μy_e‖² + (1/2μ)‖[h(x)+μz_e]_+‖

乘子法迭代

乘子法通过交替最小化和对偶上升步求解： - x^{l+1} = argmin_x L_μ(x; y^l, z^l) - y^{l+1} = y_e + (1/μ)g(x^{l+1}) - z^{l+1} = [z_e + (1/μ)h(x^{l+1})]_+

原始-对偶增广拉格朗日（pdAL）

pdAL 在对偶变量上增加罚项，构造新函数： M_μ(x,y,z; y_e,z_e) = L_μ(x; y_e,z_e) + (1/2μ)‖g(x)+μ(y_e−y)‖² + (1/2μ)‖[h(x)+μz_e]_+ − μz‖²

关键性质：M_μ(·; y_e,z_e) 的任何驻点 (x*, y*, z*) 满足迭代 (4) 的 KKT 条件，其中 y^{l+1}=y*。

原始-对偶（拟）牛顿步

线性系统为： [H, g_x^T, Ph_x^T; g_x, −μI, 0; Ph_x, 0, −μP] [δx; δy; δz] = −[∇L(x^k,y^k); g(x^k)+μ(y^k−y_e); [h(x^k)+μz^k]_+ − μz_e]

其中 H 近似拉格朗日 Hessian ∇²L，P 是活动约束集 A(x^k) 对应行的选择矩阵。活动集定义为 i ∈ A(x) ⇔ (h(x)+μz_e)_i ≥ 0。

关键设计决策

  • 活动集的选择基于当前对偶变量 z_e，而非仅依赖原始变量，这使得不等式约束的处理更接近内点法的“屏障”效果。
  • 原始-对偶步 (δx, δy, δz) 被证明是 pdAL 函数的下降方向（引自文献 [6]），保证了迭代的单调性。
  • 流形上的处理通过 Pinocchio 库的矩阵李群接口实现，提供解析导数，避免数值微分。

关键创新

  1. 不等式约束的 pdAL 扩展：这是首次将 pdAL 方法从等式约束（文献 [6]）系统性地推广到不等式约束，并给出了活动集定义和对应的 KKT 条件。此前的不等式处理要么依赖罚函数（病态），要么依赖内点法（需要求解器内部结构调整），而 pdAL 提供了一种统一框架。

  2. 流形上的原生实现：通过 Pinocchio 的矩阵李群接口，ProxNLP 直接在 SE(3) 等流形上定义增广拉格朗日，避免了欧氏空间参数化带来的奇异性问题。这对机器人学中的位姿优化至关重要，因为旋转矩阵的欧拉角表示在特定角度会退化。

  3. 原始-对偶同时更新的牛顿步：与经典乘子法（先最小化再对偶上升）不同，pdAL 的牛顿步同时更新 (δx, δy, δz)，这利用了问题结构，减少了外层迭代次数。对于机器人学中常见的稠密小规模问题，这种设计比通用 NLP 求解器更高效。

边界与局限

论文未提供系统的数值对比实验或收敛性定量分析，未给出求解器的计算时间、迭代次数等性能指标，未与现有 NLP 求解器（如 IPOPT、SNOPT）进行基准对比。论文未讨论算法的全局收敛性保证，未提供大规模或高维问题的实验验证，未讨论参数 μ 的自适应调整策略，未提供对偶变量初始化策略的详细讨论，未讨论数值稳定性问题（如病态条件数处理），未提供多目标或随机优化场景的验证。此外，论文未明确说明 Hessian 近似 H 的具体更新策略（如 BFGS 或 Gauss-Newton），也未讨论活动集切换时的非光滑性处理。

工程启示

复现 ProxNLP 时，首先核对活动集定义 i ∈ A(x) ⇔ (h(x)+μz_e)_i ≥ 0 的实现是否与论文一致，因为这是不等式约束处理的核心。其次，注意 μ 的初始值和更新策略——论文未明确给出自适应调整方法，建议从 μ = 1 开始并观察对偶变量变化，若振荡则增大 μ。最容易踩坑的地方是流形上的 Hessian 计算：论文在双摆实验中忽略了动力学二阶导数，这可能导致收敛速度下降，但对最终精度影响有限。对于下游团队，建议先用双摆实验（Δt = 30 ms，ε = 10⁻⁴）验证求解器正确性，再迁移到 Talos 或 Solo 问题。注意 Talos 代价函数中 d = (0, 0.03, 0)ᵀ 的数值精度（白名单中 0.03 与 00.030 并存，需确认实现中是否使用双精度）。最后，由于论文未提供基准对比，实际部署前应自行与 IPOPT 在相同问题上对比，特别关注不等式约束较多时的迭代次数差异。
