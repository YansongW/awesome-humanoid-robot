圆形移动机器人的角度约束编队控制

Angle-Constrained Formation Control for Circular Mobile Robots

领域
AI 模型与算法
层级
智能层
审校
待审校

摘要

本文针对平面圆形移动机器人的编队控制问题，提出了一种基于梯度法的分布式控制律。该控制律仅利用视觉传感器获取的相邻机器人内角/方位测量值，在实现刚性编队的同时保证邻接机器人间的碰撞避免，并证明了误差动力学的局部指数收敛性。

来源与参考

  • Angle-Constrained Formation Control for Circular Mobile Robots

概述

本文针对圆形移动机器人（非质点）提出一种仅依赖相对方位测量的角约束编队控制律。作者利用相邻机器人圆盘的内角信息构造势函数，通过梯度下降实现编队成形，并证明在最小无穷小距离刚性图拓扑下误差系统局部指数收敛，同时保证邻居间碰撞避免。核心贡献在于将编队控制从距离/完整向量测量降维到纯方位测量，并给出严格的稳定性分析。

它改变了什么

现有编队控制理论（距离刚性、方位刚性）几乎都建立在“机器人是平面上的点”这一理想假设上，每个邻居对只能交换一个标量或向量测量。这导致两个实际痛点：一是真实机器人有物理尺寸，点模型无法刻画碰撞边界；二是距离测量（如激光测距）在近距离或遮挡下可靠性下降，而方位测量（视觉特征点）更鲁棒、成本更低。作者将机器人建模为等半径圆盘，使每个邻居可观测到圆盘的两个切点，从而获得“内角”这一新测量量——它同时编码了相对距离（通过 sin(θ/2)=r/d）和方位信息。这一改变的本质是把编队约束从“距离空间”搬到“角度空间”，使得控制律在数学上仅需单位向量，工程上仅需单目视觉即可实现。相比距离基方法，它省去了距离估计环节，且势函数中天然包含碰撞避免项，这是对现有刚性编队框架的一次实质性简化。

方法拆解

模型与测量

  • 机器人 i 中心 p_i ∈ ℝ²，半径 r，单积分器动力学 ṗ_i = u_i。
  • 观测模型：机器人 i 检测邻居 j 圆盘的两个最外点 p_{jL_i}、p_{jR_i}，得到单位向量 g_{ijL}、g_{ijR}，内角 θ_ij 满足 cos θ_ij = g_{ijL}^T g_{ijR}。
  • 几何关系：sin(½θ_ij) = r / d_ij，其中 d_ij = ‖p_j - p_i‖。

势函数与误差

  • 误差信号：e_ij = cos θ_ij - cos θ_ij，θ_ij 为目标内角。
  • 局部势函数 V_ij(e_ij) 非负且仅在 e_ij = 0 时为零；包含项 (cos θ_ij - ½) 确保 ‖p_j - p_i‖ > 2r（碰撞避免）。
  • 增益函数 k_ij(e_ij)：当 cos θ_ij < 5/6 时在可行域内可能变号；当 cos θ_ij ≥ 5/6 时恒正。

控制律推导

  • 总体势函数 V(e) = Σ V_ij(e_ij)，控制律 u_i(t) = -Σ_{j∈N_i} (∂V_ij/∂p_i)^T。
  • 关键化简：利用几何关系将控制律改写为仅依赖方位和的形式： u_ij^T = -2 v̂ij(e_ij) (1 - cos θ_ij) sin θ_ij ‖g 其中 g_{ij+} = g_{ijL} + g_{ijR}，v̂_ij(e_ij) = e_ij c_ij / (e_ij + c_ij)³。}‖^{-2} g_{ij+
  • 该形式完全不含距离项，仅需单位向量测量。

稳定性分析

  • 闭环系统紧凑形式：ṗ(t) = -R_angle^T v(e)，误差动力学 ė(t) = -F v(e)，其中 F = R_angle R_angle^T = D(d) R_dist R_dist^T D(d) 对称半正定。
  • 对最小无穷小距离刚性框架，F 在原点附近正定，误差系统自治。
  • 构造紧致不变子水平集 Ω_β（超立方体 H_b 与球 B_q 的交），势函数时间导数 V̇ = -v^T F v ≤ 0 作为 Lyapunov 候选。
  • 定理 1：若 e(0) ∈ Ω_β，则 e = 0_m 局部指数稳定，误差范数上界 ‖e(t)‖ ≤ (c_2/c_1)^{1/2} ‖e(0)‖ exp(-γ/2 t)，γ = λρ/c_2。
  • 平衡集分析：正确形状集 W_c = {p | e = 0_m}；错误形状集 W_i 包含共线配置（非无穷小刚性）。

关键创新

  1. 纯方位测量的角约束编队：现有方位刚性方法通常需要每个邻居对至少两个不同特征点，而本文通过圆盘几何将两个切点方位合并为一个内角标量，控制律最终只依赖 g_{ij+} 这一个合成向量。这是首次将内角作为编队控制的状态变量，并证明其与距离刚性框架在数学上等价（通过 F 矩阵的分解）。
  2. 碰撞避免内建于势函数：势函数中的 (cos θ_ij - ½) 项在 d_ij → 2r 时势能趋于无穷，从机制上保证间距下界，无需额外的避碰子控制器。这比传统“编队+避碰”分层架构更简洁，且稳定性证明覆盖了避碰约束。
  3. 局部指数收敛的严格证明：通过构造紧致不变集 Ω_β 和 Lyapunov 分析，给出了收敛速率 γ = λρ/c_2 的显式表达式，而非仅渐近稳定。这为工程上的收敛时间预估提供了理论依据。

实验与结果

仿真设置：4 个圆形机器人（r = 1）形成矩形编队，目标距离 d_12 = d_34 = 3，d_13 = d_24 = 4，d_14* = 5，对应目标内角余弦值如下：

目标对 cos θ* 数值
(1,2),(3,4) cos θ_12 = cos θ_34 0.7778
(1,3),(2,4) cos θ_13 = cos θ_24 0.8750
(1,4) cos θ_14* 0.9200

初始位置：p_1(0) = [0,0]^T，p_2(0) = [2.05,0]^T，p_3(0) = [-2.05,0.05]^T，p_4(0) = [-1,1.85]^T。参数 b = 0.08，增益 K = 50。

关键结果： - 机器人 2 与机器人 1 初始接近（间距 2.05 > 2r），快速远离后与机器人 4 的距离增至约 4.9。 - 误差信号在 t = 3 s 左右开始指数收敛，最终所有误差信号低于阈值 b = 0.08。 - 图 2 中黑色实线表示 d_min = 2（最小间距）与 b = 0.08（收敛阈值）。

结果含义：验证了碰撞避免（间距始终 > 2）和误差收敛两个核心性质，且收敛行为与定理 1 的指数速率预测一致。但论文未提供与距离基方法的定量对比实验。

边界与局限

  • 论文未明确列出作者承认的局限，但可从证明结构推断：指数稳定性仅在紧致不变集 Ω_β 内保证，初始配置 p(0) ∉ H_b 时虽可展示碰撞避免与收敛，但无理论保证。
  • 错误平衡集 W_i 包含共线配置，未提供全局收敛保证——即从某些初始条件出发可能收敛到错误形状。
  • 证明中 c_1、c_2、ρ 的确定引用文献 [2] 与 [15]，未在文中展开，复现时需查阅原始文献。
  • 仿真仅针对 4 机器人矩形编队，未验证更大规模或更复杂拓扑（如三角网格）下的可扩展性。
  • 传感模型假设可精确检测圆盘两个最外点，实际视觉系统存在噪声和遮挡，论文未做鲁棒性分析。

工程启示

  • 复现核对顺序：先验证几何关系 sin(½θ_ij) = r/d_ij 在代码中的实现精度，这是整个控制律正确性的基石；再检查增益函数 k_ij(e_ij) 在目标 cos θ* ≥ 5/6 时是否恒正，否则需调整可行域定义。
  • 最易踩坑点：控制律中的 ‖g_{ij+}‖^{-2} 项在 g_{ij+} 接近零向量（即两切点方位几乎相反，θ_ij ≈ π）时数值不稳定，需设置最小阈值保护；另外势函数中的 (cos θ_ij - ½) 项在初始间距恰好等于 2r 时会产生无穷大势能，初始化时需确保间距严格大于 2r。
  • 下游团队选型建议：若机器人已配备单目视觉且能稳定提取邻居圆盘边缘，此方法可直接部署；若传感器同时提供距离信息，建议保留距离作为冗余校验，但控制律本身无需距离。对于需要全局收敛保证的场景（如高动态环境），需额外设计切换策略或全局势函数，因为本文仅保证局部收敛。
  • 参数调优：增益 K = 50 在仿真中效果良好，但实际中需根据执行器饱和限制调整；b = 0.08 作为收敛阈值决定了稳态精度，过小会导致频繁振荡，过大则编队误差偏大。
