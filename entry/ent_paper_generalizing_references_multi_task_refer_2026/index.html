Generalizing from References using a Multi-Task Reference and Goal-Driven RL Framework

摘要

本文提出一种统一的多任务强化学习框架，将参考运动作为行为塑造的先验而非部署约束，通过联合优化参考引导模仿任务与目标条件泛化任务，使单一策略同时具备类人运动自然性与跨分布适应性。该方法在基于箱子的跑酷场景中验证，无需对抗目标或显式轨迹跟踪即可实现跳跃、攀爬等多样运动技能，并支持长时域技能组合。

概述

本文提出一个统一的多任务强化学习框架，将参考运动视为行为塑造的先验而非部署时的约束，通过联合训练参考引导模仿任务和目标条件泛化任务，使单一策略在Unitree G1人形机器人上同时获得类人运动质量和超出演示数据集的泛化能力。核心贡献在于用课程机制（辅助力缩放与任务混合调度）弥合参考跟踪与纯任务驱动RL之间的鸿沟，无需对抗目标、显式轨迹跟踪或相位变量。

它改变了什么

参考驱动方法长期存在一个根本性矛盾：要么严格跟随参考轨迹，在演示分布外脆弱不堪；要么完全抛弃参考，用稀疏任务奖励硬学，结果动作质量崩塌（如直接从50cm箱子跳下而非受控下降）。作者看穿了现有范式的共同盲点——参考运动被当作部署时的约束（轨迹、教师、分布），而非训练时的行为先验。这一区分是本质性的：约束限制策略的表达空间，先验则塑造策略的偏好而不限制其能力。

该框架真正改变了"参考数据如何参与策略学习"这一核心问题。通过将参考从策略输入中彻底移除（不观测参考轨迹、未来窗口或相位变量），策略被迫学习目标条件与运动行为之间的结构化映射，而非记忆特定演示。这使得运动质量与特定参考数据解耦，为泛化到训练分布之外的新任务条件提供了可能。

方法拆解

多任务联合训练

单一目标条件策略π(a_t|s_t, g_t)在两个任务上联合训练，共享观测和动作空间，但初始化、命令空间和奖励结构不同： - 参考引导模仿任务：参考轨迹定义密集模仿奖励r_t^imi = r_track + r_reg + r_surv，但参考不作为策略输入 - 目标条件泛化任务：目标独立于参考采样，奖励仅反映任务成功r_t^gen = r_goal + r_reg + r_surv

观测与动作空间

  • 策略观测：机器人状态s_t（关节配置/速度、投影重力、躯干角速度，字符中心坐标系）+ 目标g_t（水平面目标根位置2D坐标）
  • 动作空间：关节级PD控制器，策略输出残差动作a_t，映射到命令关节位置：q_j^cmd = q̄ + Σa_t，其中q̄为默认关节位置，Σ为每自由度动作尺度对角矩阵。省略参考关节位置作为前馈项，以保留偏离参考的能力

课程机制

全局难度标量λ∈[0,1]在线自适应调整，控制两个关键机制： 1. 辅助力课程：F_b = M(v̂̇ + k_p^v(p̂−p) + k_d^v(v̂−v) − g)，M_b = Iω̂̇ + k_p^ω I(Φ̂⊖Φ) + k_d^ω I(ω̂−ω) + ω×(Iω) − r_b,com×Mg，应用辅助扳手w_e = β(λ)[F_b; M_b]，β(λ) = (1−λ)β_max，β_max = 0.75 2. 任务混合调度：p_imi(λ) = (1−λ)p_0 + λp_target，从p_0 = 1.0线性过渡到p_target = 0.5

训练架构

Isaac Lab中PPO，非对称actor-critic。Actor为三层MLP（1024, 512, 256），映射(s_t, g_t)到PD目标关节位置的高斯动作分布。Critic额外接收任务指示变量k_t和特权信息（完整根部状态、接触力、辅助扳手信号），仅用于价值估计。

关键创新

  1. 参考作为先验而非约束：这是范式层面的创新。参考运动仅通过密集奖励信号塑造行为偏好，从不进入策略输入或作为前馈项。这使得策略在部署时完全不受参考数据束缚，能够适应训练分布之外的新条件。

  2. 统一课程标量λ同时控制辅助力和任务混合：单一难度变量协调两个互补机制——训练早期用强辅助力防止灾难性失败，同时以高模仿概率塑造运动质量；随训练推进，辅助力减弱、泛化任务占比增加。这种协同设计避免了分别调参的复杂性。

  3. 无对抗、无相位变量的简洁设计：相比ZEST等需要对抗训练或相位变量的方法，本框架仅需标准PPO和精心设计的奖励结构，大幅降低训练复杂度和复现门槛。

关键发现：移除任务课程导致walk-jump和walk-climb完全失败（成功率0.00），说明课程机制对学习接触丰富技能至关重要；移除模仿任务导致运动质量崩溃（root R高达4.75，joint pos q高达12.97）；移除泛化任务在标称条件下几乎无损，但在Beyond Nominal下显著下降（walk-jump从0.62降至0.27）。

定性观察：tabula rasa RL在climb-down中直接从50cm高箱子跳下而非受控下降；本方法在walk-jump和walk-climb中约2s完成任务，而参考运动通常需10s，说明策略学会了更高效的运动策略而非简单复现参考。

边界与局限

  • 感知未集成：硬件实验依赖MoCap获取全局状态反馈，未集成板载外部感知，限制了真实部署的自主性
  • 目标接口有限：仅支持根目标位置和离散行为标签，未扩展到更丰富的任务描述
  • 技能库规模：仅验证三个技能（walk-jump、walk-climb、climb-down），每个使用单一参考运动，未测试多参考运动或大规模数据集
  • 长时域组合：多技能组合仅在仿真中演示，未在真实硬件上验证长期组合行为
  • 高层决策：未用学习的高层策略替代手工设计的状态机，长时域决策仍依赖人工编排

工程启示

  • 先核对课程超参数：β_max = 0.75、p_0 = 1.0、p_target = 0.5是关键起点。λ的更新准则（避免提前终止+宽松跟踪一致）对训练稳定性至关重要，建议优先复现此机制
  • 最容易踩坑：奖励权重。跟踪奖励的σ_i归一化常数（如基座位置σ₁ = 0.4、关节位置σ₅ = 0.3·√n_j）对运动质量影响极大，需仔细核对。正则化项中脚滑惩罚（−2.0）和平踝惩罚（−20.0）对防止不自然步态至关重要
  • PD增益未给出具体数值，仅说明按文献[25]程序指定。复现时需自行确定，建议从默认Unitree G1参数开始并做灵敏度分析
  • 控制频率50Hz（仿真步长0.004s，降采样5）是硬性约束，下游部署需确保推理延迟满足此频率
  • 域随机化范围（摩擦𝒰(0.8, 2.5)、躯干质量±4kg、外部推力0.4m/s）是sim-to-real迁移的关键，建议完整复现而非简化
  • 非对称critic的特权信息（完整根部状态、接触力、辅助扳手信号）仅用于训练，部署时actor不依赖这些，但需确保训练和部署的观测空间严格一致
