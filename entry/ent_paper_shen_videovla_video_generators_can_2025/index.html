VideoVLA

VideoVLA: Video Generators Can Be Generalizable Robot Manipulators

领域
AI 模型与算法软件中间件
层级
智能层
审校
待审校

摘要

VideoVLA 是由西安交通大学 IAIR、微软亚洲研究院和复旦大学联合提出的 2025 年大型视觉-语言-动作模型，发表于 NIPS25。其核心贡献在于将大规模视频生成模型转化为通用的机器人操作 VLA 模型，通过联合预测动作序列与未来视觉结果，显著提升了操作任务中的泛化能力。

来源与参考

  • VideoVLA: Video Generators Can Be Generalizable Robot Manipulators (arXiv)
  • VideoVLA source

概述

VideoVLA 是一个面向视觉-语言-动作（VLA）模型的开源一站式工具箱，由研究团队提出，旨在统一分散的 VLA 框架、提供更强的预训练模型（Dexbotic 系列）并简化实验开发。其核心贡献在于构建了模块化的 VLA 架构、从零预训练的 DexboticVLM 视觉语言模型，以及一套完整的训练、推理与数据格式工具链，显著提升了多个基准上的操作成功率。

它改变了什么

当前 VLA 研究领域面临的核心痛点并非单一算法性能不足，而是生态碎片化：不同框架（如 OpenVLA、CogACT、OFT）架构各异，比较策略需要为每个模型配置不同的环境与数据格式，开发成本极高。更关键的是，现有主流 VLA 模型仍基于过时的视觉语言模型（如 Llama2），无法利用 Qwen3 等新一代 VLM 的能力，这导致整个领域在预训练基础模型上存在系统性滞后。

VideoVLA 真正改变的是 VLA 研究的“基础设施层”。它不再只是提出一个新模型，而是提供了一个统一框架，让研究者可以像搭积木一样组合 VLM 与动作专家（扩散 Transformer、MLP 或 MoE），并直接受益于从零预训练的 DexboticVLM。这降低了公平比较的门槛，同时将预训练模型的性能天花板整体抬高，使得下游策略优化可以在更强的基座上展开，而非在过时的视觉语言表征上打转。

方法拆解

统一模块化框架

策略被解耦为 VLM（视觉编码器、投影器、LLM）与动作专家（扩散 Transformer、MLP 或 MoE）两部分，支持灵活替换与组合。

DexboticVLM 预训练

  • 从零预训练，采用 CLIP 视觉编码器、两层 MLP 投影器、Qwen2.5 LLM。
  • 两阶段训练：先冻结视觉编码器与 LLM，仅训练投影器；再解冻全网络更新。
  • 训练数据：LLaVA 与 Cambrian 数据集。

动作表示与模型变体

  • 离散动作：连续动作映射为 LLM 输出空间的离散 token，每维度离散化为 256 个 bin。
  • Dexbotic-Base（离散）：基于 DexboticVLM，单臂数据预训练，数据含 Open-X Embodiment 子集、RLBench、LIBERO、ManiSkill2 模拟数据及 UR5 等真实数据，目标为预测 N 个离散 token（N 为自由度）。
  • Dexbotic-CogACT（单臂连续）：基于 Dexbotic-Base，VLM 用其初始化，DiT 头随机初始化，用 GT 连续动作监督。数据含 Open-X Embodiment 子集与私有数据集（52 个操作任务、8 种单臂机器人）。
  • 混合臂连续模型：噪声 token 数从 7 改为 16，覆盖 6-DoF 与 7-DoF 手臂，前半 token 对应左臂、后半对应右臂。基于 Dexbotic-CogACT 继续训练，数据含 Robomind、AgiBot World 及 ALOHA 私有双臂数据，单臂数据仅监督前半 token。多视图共享视觉编码器，视觉 token 拼接后输入 LLM。

实验层与工程

  • “分层配置 + 工厂注册 + 入口调度”架构，用户继承 base_exp 脚本修改差异化参数。
  • Dexdata 格式：video 目录（mp4）与 jsonl 目录（每行一帧多视图图像、机器人状态、文本提示），比 LeRobot 和 RLDS 更省存储。
  • 推理服务：DexClient 通过 Web API（Flask）发送请求，系统处理图像和文本后输入 VLA 模型，生成连续动作序列返回。

关键创新

  1. 从零预训练的 VLM 基座：DexboticVLM 是首个专为机器人操作从零预训练的 VLM，而非直接借用通用 VLM。这使得视觉语言表征与机器人操作任务的对齐更紧密，避免了通用 VLM 在领域分布上的偏差，是性能提升的根本来源。
  2. 统一框架下的公平比较机制：通过模块化设计与分层配置，VideoVLA 让不同策略（离散、连续、单臂、双臂）在同一 VLM 基座、同一数据格式、同一训练流程下进行对比，消除了以往因实现差异导致的不可比性，使得 SimplerEnv 上 DB-OFT 相对 OFT 提升 46.2 个百分点这类结果更具说服力。
  3. 混合臂连续动作建模：将噪声 token 从 7 扩展到 16 并明确左右臂分工，使得单一模型可同时处理 6-DoF 与 7-DoF 手臂，且单臂数据可部分监督双臂模型，这种设计在数据利用率和架构通用性上具有创新性。

实验与结果

实验覆盖 SimplerEnv-Bridge（WidowX）、RoboTwin2.0、LIBERO、CALVIN 四个基准，验证了 Dexbotic 基座对多种策略的通用增益。

基准 策略 平均成功率（变化）
SimplerEnv-Bridge CogACT vs DB-CogACT 51.3 → 69.5（+18.2）
SimplerEnv-Bridge OFT vs DB-OFT 30.2 → 76.4（+46.2）
SimplerEnv-Bridge MemVLA vs DB-MemVLA 71.9 → 84.4（+12.5）
RoboTwin2.0 CogACT vs DB-CogACT 43.75 → 58.5（+14.75）
LIBERO CogACT vs DB-CogACT 93.6 → 94.9（+1.3）
LIBERO MemVLA vs DB-MemVLA 96.7 → 97.0（+0.3）
CALVIN（ABC→D） CogACT vs DB-CogACT 3.25 → 4.06（+0.81，平均任务长度）
CALVIN（ABC→D） OFT vs DB-OFT 3.47 → 3.54（+0.07，平均任务长度）

结果含义：Dexbotic 基座在 SimplerEnv 和 RoboTwin 这类真实/仿真操作任务上增益显著，而在 LIBERO 这类相对饱和的基准上增益有限，说明基座提升主要体现在复杂视觉泛化与长时程任务上。CALVIN 上 DB-CogACT 的平均任务长度提升 0.81，表明更强的 VLM 表征直接转化为更长的任务完成链。

边界与局限

论文未明确讨论 Dexbotic 自身模型的局限性，例如在极端光照、高度动态场景或未见过的物体类别上的表现边界。当前支持的策略类型有限（π0、OpenVLA-OFT、CogACT、MemoryVLA、MUVLA），π0.5 和 VLN 策略（NaVid、NaVILA）仅近期支持，说明框架的兼容性仍在扩展中。机器人平台支持目前限于 UR5、Franka、ALOHA，对于其他常见机械臂（如 KUKA、ABB）的适配未提及。此外，混合臂模型虽支持 6-DoF 与 7-DoF，但双臂协同的复杂任务（如双手精细装配）效果未在基准中单独验证。

工程启示

复现或使用 VideoVLA 时，首先核对预训练模型版本与数据格式的匹配：Dexbotic-Base 使用离散动作（256 个 bin），Dexbotic-CogACT 使用连续动作，混合臂模型需确认噪声 token 数是否为 16。最容易踩坑的地方在于数据格式转换：Dexdata 的 jsonl 每行需包含多视图图像、机器人状态与文本提示，若从 LeRobot 或 RLDS 迁移，需注意存储结构与字段映射，否则推理时会出现维度不匹配。训练时建议先冻结 VLM 仅训练投影器，再解冻全网络，以避免早期不稳定的梯度。推理服务依赖 Flask 的 Web API，部署时需确保图像预处理（尺寸、归一化）与训练时一致，否则动作输出会偏移。对于下游团队，若需在自有机器人上部署，优先从 Dexbotic-CogACT 单臂模型开始，其私有数据已覆盖 8 种单臂机器人，迁移成本相对较低。
