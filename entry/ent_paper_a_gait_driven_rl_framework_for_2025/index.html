A Gait Driven RL Framework for Humanoid Robots

摘要

本文提出了一种2025年的人形机器人步态驱动强化学习框架。核心贡献包括：基于动力学解耦的实时步态规划器（将3D模型分解为两个2D混合倒立摆H-LIP），以及三组奖励函数组成的强化学习框架，显著缩短学习时间并提升运动性能。

来源与参考

  • A Gait Driven RL Framework for Humanoid Robots (arXiv)

概述

该论文提出 ABot-M0.5，一个面向移动与桌面双场景的机器人操作基础模型，核心贡献在于引入潜在动作抽象（latent action abstraction）与 rollout-aligned 训练，在不牺牲精细操作能力的前提下扩展至移动操作，并在 RoboCasa365 与 LIBERO 基准上验证了组合式多任务泛化能力。

它改变了什么

机器人基础模型长期面临一个两难：移动操作需要高维动作空间与视觉鲁棒性，而桌面精细操作要求细粒度控制精度。以往方案要么为移动平台定制架构导致桌面性能退化，要么固守桌面场景无法扩展。本文真正改变的是「架构扩展不必以操作精度为代价」这一假设——通过潜在动作抽象将动作生成从原始控制信号中解耦，使同一模型在两种场景下都能保持竞争力。另一个实质变化在于训练策略：rollout-aligned 训练让模型在部署时的视觉分布偏移不再成为性能断崖，这比单纯堆数据增强更接近真实部署需求。

方法拆解

潜在动作抽象（Latent Action Abstraction）

  • 将原始动作映射到潜在动作空间，模型在该空间内生成控制指令，再解码为实际执行信号。
  • 关键设计：即使模型不启用移动能力，该抽象层依然保留，作者认为这能改善细粒度控制生成，而非仅为移动场景服务。

Rollout-Aligned 训练

  • 训练时模拟 rollout 过程中的视觉状态分布，而非仅使用静态演示帧。
  • 目的：增强模型对相机视角、光照等视觉变化的鲁棒性，缩小仿真训练与真实部署的域差距。

架构扩展策略

  • 在保持组合式多任务泛化能力的前提下，扩展模型以同时处理移动操作与桌面操作。
  • 未采用任务特定分支，而是通过共享表征与统一动作接口实现双场景覆盖。

关键创新

  1. 潜在动作抽象的双场景复用：该抽象并非移动操作专属模块，而是统一用于桌面与移动场景，这打破了「移动操作必须改变动作表征」的惯例，使得单一模型无需切换策略即可应对两类任务。
  2. Rollout-Aligned 训练作为泛化手段：不同于常见的数据增强或域随机化，该方法直接对齐训练与 rollout 时的状态分布，针对视觉变化导致的策略退化问题提供了更直接的解决方案。
  3. 组合式泛化的架构保持：在扩展至移动场景时未牺牲多任务组合能力，RoboCasa365 上 clean 与 randomized 设置均保持 94 以上成绩，说明架构扩展与泛化能力并非零和关系。

边界与局限

论文未明确列出作者承认的局限。从实验设置推断：LIBERO 基准中 ABot-M0.5 的具体成绩缺失，无法判断其在长时程任务上的表现；RoboCasa365 的对比方法均为近期模型，缺乏与更早基线的对照。此外，论文未提及真实机器人部署验证、动态环境（移动障碍物、人类干扰）下的表现，以及跨机器人平台（不同机械臂型号）的迁移能力。移动操作与桌面操作的性能权衡是否在更复杂任务（如多物体交互）中保持，论文未明确。

工程启示

复现时优先核对潜在动作抽象的具体实现——动作空间的维度选择与解码方式直接决定控制精度，这是与常规 VLA 模型差异最大的模块。Rollout-aligned 训练需要仔细设计视觉状态分布的模拟方式，若仅做简单图像扰动可能无法复现论文中的鲁棒性增益。RoboCasa365 上 clean 与 randomized 成绩接近（94.00 与 94.20）是一个重要信号：如果复现时 randomized 显著低于 clean，说明 rollout-aligned 训练未正确实现。LIBERO 上建议先跑 L-Spatial 与 L-Object 两个子集验证基础操作能力，再评估 L-Long 以判断长时程短板是否可接受。训练硬件与数据规模论文未明确，需自行估计资源需求。
