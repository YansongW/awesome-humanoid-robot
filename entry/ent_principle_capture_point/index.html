摘要

捕获点（Capture Point, CP）是人形机器人推恢（push recovery）与步态规划中的核心概念：它是地面上这样一个点——若机器人能在该点立即踩下去并把质心置于支撑脚正上方，则无需再迈下一步即可停止[44][45]。捕获点的存在把复杂的动态平衡问题转化为“下一步应踩在哪里”的几何问题。

核心内容

是什么：准确定义

捕获点（Capture Point, CP）是人形机器人推恢（push recovery）与步态规划中的核心概念：它是地面上这样一个点——若机器人能在该点立即踩下去并把质心置于支撑脚正上方，则无需再迈下一步即可停止[44][45]。捕获点的存在把复杂的动态平衡问题转化为“下一步应踩在哪里”的几何问题。

更形式化地说，捕获点是给定当前质心状态，单步之内使机器人恢复静止所需的落脚点。它真正改变的不是平衡控制的反馈增益，而是把“如何保持不摔倒”这一动态问题，压缩为一个落脚点选择的几何问题——控制器不再需要实时求解复杂的全身动力学，只需回答“脚踩到哪里”。

为什么存在：痛点与历史定位

在人形机器人发展的早期，动态平衡主要依赖两种思路：一是静态步行，即每一步都保证质心投影落在支撑多边形内，速度极慢且能耗高；二是基于 ZMP 的反馈控制，通过调节踝关节力矩维持 ZMP 在支撑多边形内，但这种方法在受到较大外部扰动时往往力不从心——踝关节力矩有限，ZMP 一旦超出支撑多边形，机器人便不可避免地倾倒。

捕获点的提出正是为了解决这一痛点：它从 LIPM 的解析解中识别出质心运动的发散分量（DCM），并指出——只要把下一步落脚点放在 DCM 的当前位置，发散分量就被立即“捕获”，机器人无需再迈下一步即可停止。这一洞察把推恢问题从“如何施加力矩”转变为“脚踩到哪里”，为后来的 preview 控制、模型预测控制（MPC）与捕获区域理论奠定了基础。

原理拆解

① LIPM：捕获点的动力学基础

在线性倒立摆模型（Linear Inverted Pendulum Model, LIPM）中，假设质心高度 \(z_c\) 恒定，且质点通过无质量杆连接到地面上的 ZMP。LIPM 的水平动力学为：

\[ \ddot{x} = \frac{g}{z_c}(x - x_{\text{ZMP}}) \]

其中 \(g\) 为重力加速度，\(x\) 为质心水平位置。该方程可改写为：

\[ \dot{x} = \omega_0 (x - x_{\text{ZMP}}) \]

其中 \(\omega_0 = \sqrt{g/z_c}\) 为 LIPM 的自然频率。这是一个二阶常系数线性 ODE，其通解由收敛分量与发散分量构成。发散分量称为发散运动分量（Divergent Component of Motion, DCM）：

\[ \xi = x + \frac{\dot{x}}{\omega_0} \]

② 捕获点：DCM 的几何落点

捕获点本质上就是当前 DCM 的位置。对于二维 LIPM：

\[ x_{\text{CP}} = x_{\text{CoM}} + \frac{\dot{x}_{\text{CoM}}}{\omega_0} \]

三维水平面扩展为：

\[ \mathbf{r}_{\text{CP}} = \mathbf{r}_{\text{CoM}}^{xy} + \frac{\dot{\mathbf{r}}_{\text{CoM}}^{xy}}{\omega_0} \]

若把下一步落脚点（即新的 ZMP）正好置于捕获点，则质心将沿直线趋向该点并最终静止；若不迈到捕获点，DCM 将继续发散，机器人必须再迈一步甚至跌倒。

③ 与 ZMP 的关系：同一动力学的三个视角

由 LIPM 方程可直接导出 ZMP 表达式。将 \(\ddot{x} = \omega_0^2 (x - x_{\text{ZMP}})\) 变形：

\[ x_{\text{ZMP}} = x - \frac{\ddot{x}}{\omega_0^2} = x - \frac{z_c}{g} \ddot{x} \]

捕获点 \(x_{\text{CP}}\) 则是把下一步 ZMP 放在 DCM 当前位置，使发散分量立即被“捕获”。因此 LIPM、ZMP 与捕获点三者是同一动力学模型的不同视角：LIPM 描述质心运动，ZMP 给出地面反作用力等效点，捕获点指出恢复平衡所需的落脚点。

谁在用·应用案例

捕获点理论在人形机器人领域有广泛的应用。在推恢（push recovery）场景中，机器人受到外部推扰后，通过计算捕获点并迈出一步即可恢复平衡。在步态规划中，捕获点被用作落脚点生成的依据——每一步的落脚点都规划在捕获点附近，从而保证行走过程的稳定性。

更一般的捕获理论定义了 N-step capture region：机器人在 N 步之内能恢复平衡的所有初始状态集合。该理论为模型预测控制（MPC）提供了可行性判据：控制器只需规划使系统状态始终位于某 N-step capture region 内的轨迹[45]。此外，捕获点与 DCM 控制也被用于全身 QP 控制框架中，作为任务优先级中的高层平衡约束。

局限与边界

捕获点理论建立在 LIPM 的简化假设之上，因此存在明确的边界：

  1. 质心高度恒定假设：LIPM 假设 \(z_c\) 恒定，忽略了质心垂直运动的影响。实际机器人行走时质心高度会有波动，尤其在快速奔跑或上下楼梯时。
  2. 忽略角动量：捕获点仅考虑线动量，未考虑上身旋转产生的角动量。在需要上身协调（如摆臂）的场景中，捕获点可能不够精确。
  3. 单步假设：基本捕获点假设单步即可恢复静止，对于大扰动可能需要多步。N-step capture region 虽扩展了该理论，但计算复杂度随之增加。
  4. 地面与接触假设：捕获点假设地面平坦且接触为点接触，对于非平面地面、多接触点（如手脚并用）的情况需要三维扩展。

常见误区

  1. “捕获点就是 ZMP”——错。ZMP 是地面反作用力等效作用点，反映当前支撑状态；捕获点是使机器人恢复静止所需的未来落脚点。二者在数值上可能重合，但物理含义完全不同。
  2. “捕获点只适用于推恢”——不准确。捕获点同样适用于步态规划、落脚点生成与全身控制，推恢只是其最直观的应用场景。
  3. “捕获点计算需要完整动力学模型”——错。捕获点仅需质心位置、速度与质心高度三个量，计算极其轻量，适合实时控制。
  4. “捕获点能处理所有扰动”——错。捕获点基于 LIPM 假设，对于超出模型范围的扰动（如质心高度剧烈变化、角动量显著影响）可能失效。
