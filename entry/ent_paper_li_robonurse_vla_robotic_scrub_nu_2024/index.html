RoboNurse-VLA

RoboNurse-VLA: Robotic Scrub Nurse System based on Vision-Language-Action Model

摘要

RoboNurse-VLA 是2024年由香港中文大学、多尺度医疗机器人中心及意大利技术研究院等机构联合提出的视觉-语言-动作模型，用于手术器械的自主抓取与传递。其核心贡献在于整合 SAM 2 与 Llama 2 模型，实现基于语音指令的实时高精度器械操作，在 IROS 2024 发表。

来源与参考

  • RoboNurse-VLA source

概述

RoboNurse-VLA 是一个面向手术室器械交接任务的视觉-语言-动作（VLA）机器人系统，由研究团队提出，集成 SAM 2 视觉模块与 7B 参数 Llama 2 语言骨干（基于 OpenVLA 预训练）。核心贡献在于首次将 VLA 模型应用于结构复杂且相似的手术器械交接场景，通过微调在未见工具与难抓取物品上达到 90% 以上成功率，并验证了零样本条件下对相似器械的区分能力。

它改变了什么

手术室器械传递长期依赖护士人工完成，疲劳导致的误递与锐器刺伤是真实存在的职业风险。此前机器人洗手护士原型多停留在“识别器械”与“接受指令”层面，交接（handover）这一物理交互步骤被系统性忽略——这恰恰是错误率最高的环节。现有基于学习的操作策略在陌生环境与任务上鲁棒性差，而基础模型虽有泛化潜力，却因缺乏机器人操作数据而未被充分挖掘。

RoboNurse-VLA 真正改变的，是让 VLA 模型从“能看懂指令”推进到“能在相似器械中完成可靠交接”。它没有停留在识别精度上，而是将视觉分割、语言理解与动作生成整合为一条可微调的流水线，并证明在手术器械这种高相似度、结构复杂的物体集合上，VLA 的微调潜力远超通用操作模型。这为手术机器人从“辅助识别”走向“自主交接”提供了首个可复现的基线。

方法拆解

架构总览

三部分级联：SAM 2 视觉模块（600M 参数）→ 2 层 MLP 投影器 → OpenVLA 预训练的 7B Llama 2 骨干。

视觉处理流程

  1. 预训练 YOLOv8 检测器（平均精度 99.2%，召回 99.4%）输出目标与手的边界框。
  2. 边界框送入 SAM 2 图像编码器与掩码解码器，生成分割掩码（Dice 0.962，IoU 0.933）。
  3. 图像编码器特征与掩码经通道拼接；掩码先经三个 Conv2D 层、全局平均池化与全连接层处理以保留空间信息。
  4. 拼接后的特征向量经 MLP 投影为 patch 输入 Llama 2。

动作生成与离散化

  • 输入为深度相机视觉数据与操作者语音；语音经 Gladia ASR 转文本（器械命令准确率 99.5%）作为 Llama 2 提示。
  • 连续动作每维度离散为 256 个 bin，映射为离散 token；因 Llama 分词器限制，覆盖 256 个最少使用的 token 作为动作 token。
  • 训练目标为下一 token 预测，仅聚焦动作 token。

训练配置

  • 输入图像分辨率 224×224，平衡计算需求（高分辨率导致 patch token 增多、上下文长度二次方增长）。
  • 冻结视觉模块，微调 Llama 2，使用 LoRA 在所有线性层应用多个秩值。
  • 单张 A100 GPU，微调耗时 20 小时。
  • 提供关节位置控制器（30 Hz，动作定义为关节目标，经高频 PD 控制器转换）与末端执行器控制器；论文数据均使用关节位置控制器。

关键创新

  1. VLA 首次覆盖完整交接链路：现有 VLA 模型未展示在结构复杂且相似物体上的手术交接能力。RoboNurse-VLA 将识别、分割、语言理解与动作生成串成端到端可微调系统，而非仅做识别或指令解析。
  2. SAM 2 与 LLM 的异构融合：将 SAM 2 的分割掩码经空间信息保留处理（Conv2D + 池化 + FC）后投影进语言嵌入空间，解决了视觉特征与语言 token 的模态对齐问题，且冻结视觉模块降低了训练成本。
  3. 动作 token 的离散化策略：利用 Llama 分词器中 256 个最少使用的 token 作为动作 token，避免了新增词表带来的嵌入层改动，使预训练语言知识得以保留，这是工程上巧妙且可复现的设计。

实验与结果

数据集

  • 700 张图像，RGB-DSLR 拍摄，分辨率 6000×4000，6 类器械各 100 实例，手动 LabelImg 标注。
  • 648 个演示，由预定义脚本策略生成，含轨迹与对应图像。

关键结果解读

  • 零样本 Lift 任务 65% 对 OpenVLA 的 10%，证明 SAM 2 视觉模块对相似器械的区分能力是关键增益。
  • 微调后 On table 达 100%，Pose change 保持 95%，说明 LoRA 微调在手术器械场景下能有效迁移预训练操作知识。
  • 难抓取物品（乒乓球）实验中，夹爪力设为 4N（超过 4N 球会破裂），需抓取质心；RoboNurse-VLA 成功率 95%，其他模型低于 50%（由表内数值 95% 与 50% 对比计算）。
  • 推理频率 5 Hz，满足交接任务的实时性要求。

边界与局限

  • 零样本阶段模型未学习如何正确抓取手术器械，导致部分失败——说明视觉识别与抓取策略在无微调时仍脱节。
  • RT-2-X 因推理 API 不支持微调，未参与微调对比实验，因此微调阶段的对比缺少一个强基线。
  • 论文未明确提及避障策略、多器械同时出现在夹爪路径上的冲突处理，以及真实手术室中灯光、反光、遮挡等干扰下的表现。
  • 数据集规模有限（700 张图像、648 个演示），且演示由脚本策略生成，与真实护士交接动作的分布差异未量化。

工程启示

复现时先核对三处：一是 YOLOv8 检测器的边界框质量对 SAM 2 分割的直接影响——若检测框偏移，Dice 与 IoU 会显著下降；二是动作 token 覆盖的 256 个最少使用 token 需与分词器版本严格对应，否则训练时会出现 token 冲突；三是 LoRA 的秩值选择对微调效果敏感，论文未给出具体秩值，建议从 8 到 64 网格搜索。

工程上最易踩坑的是关节位置控制器（30 Hz）与推理频率（5 Hz）的失配——动作命令以 5 Hz 生成，但控制器以 30 Hz 执行，中间需要插值或缓冲，否则机械臂会抖动。另外，夹爪力 4N 的设定对抓取质心要求极高，复现时需确保力控精度，否则乒乓球会滑落或破裂。下游团队若想迁移到其他手术器械，建议先验证 SAM 2 在新器械上的分割质量，再决定是否需要重新训练检测器。
