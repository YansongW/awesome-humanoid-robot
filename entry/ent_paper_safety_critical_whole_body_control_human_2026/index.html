基于输入到状态安全控制屏障函数的人形机器人安全关键全身控制

Safety-Critical Whole-Body Control for Humanoid Robots via Input-to-State Safe Control Barrier Functions

摘要

本文提出一种基于输入到状态安全控制屏障函数（ISSf-CBF）的人形机器人分层安全关键全身控制框架。该框架由运动学级全身控制器（KinWBC）、ISSf-CBF安全滤波器和动力学级全身控制器（DynWBC）组成，可在未知扰动下保证运动学安全约束。仿真与实物实验表明，该方法在模型失配时提升安全裕度，并实时满足关节限位、自碰撞规避等多重约束。

概述

本文提出一种面向人形机器人的分层安全关键全身控制框架，将输入到状态安全控制障碍函数（ISSf-CBF）嵌入运动学级与动力学级全身控制器之间，在未知模型扰动下同时保证运动学安全约束、接触稳定性与任务性能。作者在仿真（MuJoCo）与真实TOCABI机器人（33自由度）上验证了该方法相对标准CBF与eCBF基线的鲁棒性优势。

它改变了什么

现有仿人机器人安全控制方法在理想模型假设下能提供安全保证，但一旦面对真实硬件固有的模型失配（如连杆质量误差、跟踪误差、外部扰动），运动学层面的安全屏障（如CBF）会因底层动力学跟踪不精确而失效——这正是作者要改变的核心痛点。此前eCBF方法将安全约束提升到加速度层，但其有效性高度依赖高保真动力学模型与低层控制器的精确跟踪，在模型不确定时安全保证同样退化。本文真正改变的是安全保证的“责任层级”：不再让动力学层独自承担安全执行，而是通过ISSf-CBF在运动学层生成对扰动有鲁棒性的安全速度参考，再传递给动力学层跟踪，从而将安全保证从“依赖模型精度”转变为“依赖扰动有界性”。这一转变使得安全控制从仿真理想环境走向真实硬件成为可能。

方法拆解

分层架构

框架由三层组成，信号自上而下传递： 1. KinWBC（运动学级全身控制）：通过优先级伪逆在投影零空间中迭代求解关节速度命令： ˙qdes_i = ˙qdes_{i−1} + J†{i|pre}(xdes_i − x_i − J_i ˙qdes) 其中 J_{i|pre} = J_i N_{i−1}，小奇异值置零以避免奇异性。 2. ISSf-CBF安全滤波器：在全身速度运动学模型（y = q, v = ˙q_safe, ˙y = v + d）上求解QP： ˙q_safe = argmin ‖˙q − ˙q_des‖² 约束包括四类：关节极限、自碰撞避免、物体碰撞避免、工作空间边界。每类约束均采用ISSf-CBF形式： L_f h(y) + L_g h(y)v ≥ −α(h(y)) + (1/ε)‖∇h(y)‖² 其中 ε > 0 控制扰动容忍区域大小，α 为线性类K函数（α(h) = αh）。 3. DynWBC（动力学级全身控制）：将安全滤波后的运动学参考通过PD反馈转换为期望加速度： ¨qsafe = Kdyn_p(qsafe − q) + Kdyn_d(˙qsafe − ˙q) 然后求解QP，目标函数包含四项加权（加速度跟踪误差 w_¨q、接触力偏差 w_c、力矩平滑 w_τ、加速度能量 w_M），约束包括线性化6D接触力锥（UF_c ≤ 0）与全身运动方程（M(q)¨q + h(q, ˙q) = S^T τ + J_c(q)^T F_c）。最终力矩命令： τ_cmd = τ_opt + K_p(q_safe − q) + K_d(˙q_safe − ˙q)

关键设计决策

  • 扰动建模：将全阶FOM动力学投影到ROM（此处为全身速度运动学模型），扰动 d 定义为投影闭环FOM与理想ROM之差，ISSf-CBF条件中的 (1/ε)‖∇h‖² 项显式补偿该有界扰动。
  • 参数调优：遵循实用指南，α 和 ε 从小值初始化，逐步增大直到性能足够，避免过大导致安全速度命令抖动。
  • 并行计算：ISSf-CBF QP在主线程、DynWBC QP在并行线程求解，满足2 kHz控制周期。

关键创新

  1. 首次将ISSf-CBF扩展到全阶人形机器人：此前ISSf-CBF仅与降阶模型结合，本文将其嵌入运动学级与动力学级全身控制之间，实现了从运动学安全参考到全阶动力学的一致传递，填补了该理论在腿式机器人上的空白。
  2. 安全保证与模型保真度解耦：通过ISSf-CBF在运动学层显式补偿ROM-FOM扰动，安全保证不再依赖高保真动力学模型或低层控制器的精确跟踪，而是依赖扰动有界性假设——这是对eCBF类方法本质缺陷的直接回应。
  3. 分层安全责任分配：不在动力学层承担全部安全执行，而是让运动学层生成鲁棒安全参考、动力学层专注接触力跟踪与平衡，这种分工使得接触稳定性（通过接触力锥约束）与运动学安全（通过ISSf-CBF）可以独立调优，工程上更易实现。

实验与结果

仿真对比（MuJoCo，连杆质量+20%失配）

基线 碰撞率/穿透深度 备注
w/o-CBF 左手穿透躯干 >5 cm 无安全滤波
CBF（标准） 碰撞率约50%（α全范围） α≥30时关节速度严重抖动
eCBF 平均碰撞率约50% α≤20被排除（运动偏离过大）
ISSf-CBF（ε=10） α≤30时无碰撞 α≥35时因抖动碰撞率增加
ISSf-CBF（ε增大） 碰撞率随ε增加 参数不足以补偿ROM-FOM扰动

行走场景：w/o-CBF双脚相互穿透>3 cm，ISSf-CBF保持有符号距离屏障值始终为正。

真实机器人（TOCABI，33自由度，约6%质量失配）

  • 单腿平衡TAICHI：CoM移向左脚中心，双手分别移动30 cm与60 cm，实测ZMP保持在支撑多边形内。
  • 避障遥操作（ε_OC_AO=30.0）：三次重复运动均未碰撞，屏障值h_AO接近零但保持非负。
  • 避障遥操作（ε_OC_AO=50.0）：三次试验屏障值均低于零，最大穿透深度8 cm。
  • 消融验证：仅用PD反馈（不含τ_opt）时机器人摔倒，证明DynWBC中接触力跟踪与力锥约束对平衡的关键作用。

边界与局限

  • 当多个CBF约束冲突导致QP不可行时，本文未观察到（因上肢冗余度充足），但对自由度较少的平台可能失效；作者提及可用松弛变量解决，但会牺牲安全保证（Remark 1）。
  • 未涉及动态障碍物场景（物体碰撞中障碍物速度用卡尔曼滤波估计，但未明确动态障碍物实验）。
  • 真实实验仅包括单腿平衡与遥操作，未进行真实行走实验。
  • 未与其他全身安全控制方法（如基于MPC的方法）进行定量对比。
  • 接触稳定性依赖接触力锥约束，在地形高度或摩擦条件不确定时仍可能失衡。

工程启示

复现或工程应用时，建议按以下顺序核对： 1. 参数调优优先：α 和 ε 的初始化与步长直接影响安全性与任务性能——从小值开始逐步增大，若出现安全速度命令抖动（α过大）或碰撞（ε过小），需重新平衡二者。 2. 扰动建模验证：ISSf-CBF的鲁棒性依赖于ROM-FOM扰动有界性假设，实际部署前需测量或估计最大扰动幅度，据此选择 ε 值；ε 过大会导致安全屏障失效（如实验中ε=50时穿透8 cm）。 3. QP求解器配置：2 kHz控制周期内需并行求解两个QP（ISSf-CBF与DynWBC），建议使用qpOASES并确保主线程与并行线程的时序同步，避免延迟导致安全约束违反。 4. 接触力锥约束不可省略：仅靠关节PD反馈（不含τ_opt）会导致摔倒，DynWBC中的期望接触力跟踪与力锥约束是平衡稳定的必要条件，不可为简化而移除。 5. 碰撞几何建模精度：障碍物与机器人连杆的球/胶囊近似半径直接影响屏障值计算，实验中障碍物球半径11.5 cm、手部6 cm，实际部署时需根据真实几何尺寸校准。
