MASH: Cooperative-Heterogeneous Multi-Agent RL for Single Humanoid Robot Locomotion

MASH: Cooperative-Heterogeneous Multi-Agent RL for Single Humanoid Robot Locomotion

领域

层级

审校

摘要

MASH 是 2025 年提出的一种用于单台人形机器人运动控制的新方法，其核心创新在于将每条肢体（腿和手臂）视为独立智能体，通过合作异构多智能体深度强化学习（MARL）来优化运动。该方法在训练收敛速度和全身协作能力上均优于传统单智能体强化学习方法。

来源与参考

  • MASH: Cooperative-Heterogeneous Multi-Agent RL for Single Humanoid Robot Locomotion (arXiv)

概述

MASH 将单台人形机器人的运动学习重构为合作-异构多智能体强化学习问题，把双腿双臂视为四个独立智能体，在 CTDE 范式下用 MAPPO 训练。核心贡献在于证明了肢体级解耦与经验共享能显著加速收敛、提升动作平滑性与躯干稳定性，并在实体机器人上实现了稳定的 sim-to-real 行走。

它改变了什么

长期以来，人形机器人全身运动控制被默认为一个高维单智能体问题，无论是端到端 PPO 还是分阶段训练，都试图让一个策略网络同时管理 20 个自由度。这种做法的隐性假设是：全身协调可以通过单一策略的容量和训练技巧来隐式学习。但实际工程中，上下身策略协调不足、复杂任务适应性差是常态，单智能体方法在训练收敛速度和最终动作质量上往往顾此失彼。

MASH 真正改变的是问题的分解粒度。它不再把机器人当作一个整体，而是把每条腿和每条手臂视为一个独立决策者，通过合作 MARL 让肢体间显式地协商步态相位与力矩分配。这一转变的价值在于：它把「全身协调」这个模糊的全局目标，转化为「肢体间合作」这个结构化的局部问题，使得策略网络可以专注于低维的肢体控制，而协调性由多智能体框架来保证。这为长期困扰人形机器人 RL 的样本效率与动作平滑性矛盾提供了一个新的解法方向。

方法拆解

问题建模

将单机器人运动建模为部分可观测去中心化马尔可夫决策过程（decPOMDP），元组 G = (𝒮, 𝒜, 𝒫, r, 𝒵, 𝒪, N, γ, T)。四个智能体（双腿、双臂）各自基于局部观察决策，共享全局奖励。

网络架构与参数共享

  • 双腿共享一个 actor 网络，双臂共享另一个 actor 网络。设计理由：(1) 降低计算开销；(2) 利用左右肢体的对称性先验。
  • Critic 网络输入为全局状态，维度 ℝ¹⁰⁶，包含全身电机位置 q_t ∈ ℝ²⁰、速度 q̇_t ∈ ℝ²⁰、上一步动作 a_t ∈ ℝ²⁰、位置偏差 d_t ∈ ℝ²⁰、时序引导 ϕ_t ∈ ℝ²、控制指令 c_t ∈ ℝ⁴、躯干线速度 v_t ∈ ℝ³、欧拉角 θ_t ∈ ℝ³、角速度 ω_t ∈ ℝ³、外部扰动力 f_t ∈ ℝ²、力矩 τ_t ∈ ℝ³、摩擦系数 μ_t ∈ ℝ¹、质量 m_t ∈ ℝ¹、以及支撑/接触二值掩码各 ∈ ℝ²。
  • 腿部 actor 输入 ℝ⁶⁴（32 维观察 × 2），输出连续力矩 a_t ∈ ℝ¹²；手臂 actor 输入 ℝ⁵²（26 维观察 × 2），输出 a_t ∈ ℝ⁸。

时序引导器

T_i(t) = sin(2π(kt + Δ_i))，其中 k 为步态周期缩放因子，Δ_i 为第 i 个肢体的相位偏移。该设计为每个肢体提供独立的步态相位参考，是肢体协调的关键机制。

奖励函数

16 项加权和，关键项包括：Joint Position (3.5)、Tracking Linear Velocity (1.5)、Tracking Angular Velocity (1.4)、Feet Air Time (2.0)、Feet Clearance (2.0)、DOF Torques (−2.0×10⁻³)、Action Smoothness 1 (−0.1)、Action Smoothness 2 (−0.1)。

关键创新

  1. 肢体级智能体分解：首次将 MARL 原理应用于单台人形机器人的内部肢体协调，而非多机器人系统。这一视角转换使得策略网络维度从全身 20 自由度降至单肢 6-8 自由度，显著降低了每个策略的拟合难度，同时通过共享参数保留了对称性先验。

  2. 时序引导器与相位偏移：通过 T_i(t) = sin(2π(kt + Δ_i)) 为每个肢体提供独立的步态相位参考，将节律性运动先验显式注入网络输入。这是实现双腿双臂自然协调的关键设计，避免了纯数据驱动方式下相位漂移问题。

  3. CTDE 与经验共享的结合：在集中训练阶段，critic 使用 106 维全局状态（含外部扰动力、摩擦系数、身体质量等环境参数），使得价值函数能够感知环境变化，而执行阶段 actor 仅依赖局部观察。这种不对称设计在保持去中心化执行的同时，提升了训练稳定性。

实验与结果

实验在 Isaac Gym 训练 3000 个 episode（episode 长度 48 步），与单智能体 PPO 基线对比，评估双足行走与摆臂行走两种任务。

指标 MASH（双足） PPO（双足） MASH（摆臂） PPO（摆臂）
收敛时间 T_Conv 1306 1661 1017 1238
动作平滑度 S_action 0.107 0.547 0.124 0.546
躯干稳定性 S_torso 8.240×10⁻⁴ 3.398×10⁻³ 2.720×10⁻³ 2.802×10⁻²
肢体协调 C_limb 0.612 0.974 0.421 0.951

关键结果解读： - 收敛时间在双足任务上缩短约 21%（由表内数值 1661→1306 计算），摆臂任务缩短约 18%（由表内数值 1238→1017 计算），表明多智能体分解确实加速了训练。 - 动作平滑度提升近 5 倍（0.547→0.107），躯干稳定性提升约 4 倍（3.398×10⁻³→8.240×10⁻⁴），肢体协调性提升约 37%（由表内数值 0.974→0.612 计算）（0.974→0.612），这些指标在摆臂任务中差距更大，说明手臂参与协调时 MASH 优势更明显。 - 实体机器人膝关节角度呈周期性振荡（约 1.2 至 1.7 弧度，步态周期约 0.6 秒），验证了 sim-to-real 迁移的有效性。

边界与局限

论文未明确列出自身方法的局限性，但存在以下边界条件： - 仅验证了单一配置的 BanXing 人形机器人，未测试不同尺寸、自由度配置的泛化性。 - 任务局限于平坦地形上的直线行走，未涉及上下坡、楼梯、不平整地面等复杂地形。 - 奖励函数仍为手动设计，16 项加权和需要大量调参经验，作者也承认手动设计奖励函数劳动密集。 - 域随机化参数范围有限（如摩擦系数 [0.1, 1.2]、质量缩放 [0.9, 1.13]），未覆盖极端环境变化。 - 未与基于模仿学习的方法进行对比，无法判断在数据效率上的相对优劣。

工程启示

复现 MASH 时，首先核对时序引导器的相位偏移 Δ_i 设置——这是肢体协调的核心机制，不同偏移量会直接改变步态模式。其次，critic 的 106 维输入中包含外部扰动力 f_t ∈ ℝ² 和环境摩擦系数 μ_t ∈ ℝ¹，这些环境感知信息对训练稳定性至关重要，实现时需确保仿真器能正确暴露这些量。

最容易踩坑的地方在于奖励函数中 16 项权重的平衡，特别是 DOF Torques (−2.0×10⁻³) 与 Action Smoothness (−0.1) 之间的相互作用——力矩惩罚过重会导致动作过于保守，平滑度惩罚过重则可能抑制必要的快速响应。建议先复现 Table I 的权重，再根据实际动作质量微调。

对于下游团队，若需将 MASH 迁移到其他机器人平台，重点检查两点：一是肢体自由度数量是否匹配（腿 6、臂 4），二是 PD 控制器的 K_p/K_d 缩放因子是否在域随机化范围内（K_d 为 [0.95, 1.05]）。若机器人构型差异较大，需重新设计观察空间维度与共享参数策略。
