First Humanoid Application Centre in the Netherlands opened at MICS: humanoid robots from demo to practical application

摘要

荷兰首个类人机器人应用中心（Humanoid Application Centre, HAC）在MICS开幕，由Dura Vermeer、VolkerWessels等企业联合创立。该中心旨在弥合机器人技术研发与工业实际应用之间的鸿沟，重点在建筑、物流、医疗等领域测试类人机器人的部署可行性。

来源与参考

  • First Humanoid Application Centre in the Netherlands opened at MICS: humanoid robots from demo to practical application

概述

位于荷兰斯希丹Mechatronics Innovation Campus Schiedam (MICS)的Humanoid Application Centre (HAC)于2026年7月2日开幕，这是荷兰首个专注于类人机器人实际应用的创新中心。该中心汇集企业、技术伙伴、教育机构与公共部门，在建筑、园艺、物流、工业、医疗及设施管理等行业探索类人机器人的真实工作场景部署。开幕演示中，多款类人机器人展示了砌砖、清洁、包装、行走、跳舞及跑步等能力，强调技术定位是辅助而非替代人类劳动力。

核心内容

核心定位与目标

  • HAC旨在解决劳动力短缺、生产力、安全及人口老龄化等社会经济问题，通过真实条件测试帮助企业评估机器人技术的可行性、安全性及商业案例。
  • 重点聚焦重复性、体力密集型或复杂环境下的任务，如工业检测与物流、医疗辅助、温室甜椒采摘等。

首批应用案例

  • Dura Vermeer作为创始合作伙伴，率先探索类人机器人在基础设施项目铺路作业中的辅助作用。其技术总监Jaap Hulshoff指出，建筑行业面临劳动力生产率、安全及熟练工人短缺挑战，需提前学习如何通过机器人化实现行业未来可持续性。

全球竞争与欧洲短板

  • 全球科技公司正投入数十亿欧元开发类人机器人，但欧洲缺乏大规模实践所需的基础设施与专业知识。HAC联合创始人Evert Jaap Lugt强调，挑战已从建造机器人转向成功整合至现有业务流程。

合作生态与校园支持

  • 创始合作伙伴包括Dura Vermeer、VolkerWessels、Harvest House、GOM (Facilicom Group)及Eurocaps。
  • HAC坐落于MICS，该园区专注高科技制造业与机电一体化，由SDK Vastgoed开发，提供演示、培训及实施计划，并与职业院校至大学合作培养学生。
