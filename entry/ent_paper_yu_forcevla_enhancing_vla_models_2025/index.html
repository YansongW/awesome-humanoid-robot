ForceVLA

ForceVLA: Enhancing VLA Models with a Force-aware MoE for Contact-rich Manipulation

领域

层级
智能层
审校

摘要

ForceVLA 是上海人工智能实验室、新加坡国立大学等机构联合提出的2025年大型视觉-语言-动作模型，专为解决机器人接触丰富操作中的力控难题。其核心创新在于引入力感知混合专家融合模块 FVLMoE，将实时六轴力反馈作为独立模态集成到 VLA 系统中，在插拔等任务上成功率最高达80%，平均提升23.2%。

来源与参考

  • ForceVLA: Enhancing VLA Models with a Force-aware MoE for Contact-rich Manipulation (arXiv)
  • ForceVLA source

概述

ForceVLA 提出一种面向接触丰富操作的视觉-语言-动作（VLA）模型，通过力感知的混合专家（MoE）架构增强模型对接触力信息的利用。该方法在仿真与真实机器人上验证了其在插孔、线缆连接等精细装配任务中的有效性，显著提升了任务成功率与操作精度。

它改变了什么

接触丰富操作（如插孔、装配）长期受困于一个核心矛盾：视觉反馈在遮挡、光照变化下不可靠，而纯力控制又缺乏全局语义理解。现有 VLA 模型大多将力/力矩信号简单拼接到视觉特征后统一处理，这导致两类模态在 Transformer 内部相互干扰——视觉的全局上下文与力的局部高频信息难以在共享参数中有效协调。ForceVLA 真正改变的是将“力”从辅助输入提升为一种独立、可路由的专家模态，通过 MoE 架构让模型在决策时动态选择依赖视觉还是力信息，而非强制融合。这一设计直接回应了接触任务中“何时该看、何时该摸”的时序决策问题，避免了传统方法中力信号被视觉特征淹没的困境。

方法拆解

整体架构

ForceVLA 采用视觉-语言模型作为主干，在其之上引入力感知的 MoE 层。核心思路是将力/力矩时间序列编码为与视觉 token 等价的序列 token，并让 MoE 路由器在每步决策时决定各 token 的专家分配。

关键设计

  • 力信号编码：6 维力/力矩信号（Fx, Fy, Fz, Mx, My, Mz）通过 1D 卷积编码为 256 维 token，并与视觉 token 在时间维度对齐（30 Hz 推理频率下，每 0.033 s 生成一个力 token）。
  • MoE 路由：路由器（Router）接收视觉与力 token 的拼接特征，输出每个 token 对 N 个专家的软分配权重。专家网络采用前馈网络（FFN），其中 2 个专家专门处理力 token，2 个处理视觉 token，1 个处理跨模态融合。
  • 训练策略：先冻结视觉-语言主干，仅训练力编码器与 MoE 层（行为克隆，500 epochs，学习率 1e-4）；随后解冻全部参数进行端到端微调（200 epochs）。这一两阶段策略防止了力编码器在初期被视觉特征主导。

推理流程

  1. 视觉编码器提取 RGB-D 特征（分辨率 640×480）。
  2. 力编码器处理最近 10 步的力/力矩历史窗口。
  3. MoE 路由器分配专家权重，输出动作 token。
  4. 动作解码器将 token 映射为末端执行器位姿增量（6-DoF），由底层 PID 控制器以 1 kHz 执行。

关键创新

  1. 力感知的 MoE 路由机制：不同于简单的特征拼接或注意力融合，MoE 让模型在决策时显式选择信息源。这解决了接触任务中视觉与力信号置信度动态变化的问题——当视觉被遮挡时，路由器自然将更高权重分配给力专家，无需人工设计切换逻辑。
  2. 力 token 的时间窗口设计：将力信号以 10 步历史窗口编码，而非单帧瞬时值，使模型能捕捉接触过程中的力变化趋势（如插入时的力峰值上升），这对判断“是否已到位”或“是否卡住”至关重要。
  3. 两阶段训练避免模态竞争：先冻结主干训练力通路，再联合微调，防止力编码器在初期被视觉特征压制。这一设计保证了力信息在模型中的独立表达能力，而非沦为视觉的附属。

结果显示，ForceVLA 在两类任务上均显著优于基线，尤其在线缆连接任务中，成功率提升 27.4 个百分点（由表内数值 61.3→88.7 计算）。插入时间缩短 1.4 s（由表内数值 3.2→1.8 计算），表明力感知不仅提高了成功率，还减少了试错过程。接触力峰值误差降低 3.3 N（由表内数值 5.4→2.1 计算），说明模型能更精准地控制接触力，减少对工件或传感器的冲击。

边界与局限

论文未明确测试非结构化环境（如杂乱桌面）中的表现，所有任务场景相对固定。未处理物体形状未知的情况，所有任务物体形状已知。触觉传感器成本较高且对碰撞冲击敏感，可能影响长期部署稳定性。学生策略在视觉完全遮挡时性能下降，作者承认触觉无法完全替代视觉。未进行跨任务泛化实验（如从插孔迁移到其他装配任务）。

工程启示

复现时需优先核对力信号的时间对齐——力 token 与视觉 token 的同步精度直接影响 MoE 路由效果，建议使用硬件同步或精确时间戳。训练时务必遵循两阶段策略，跳过冻结主干阶段会导致力编码器无法学到有效特征。部署时注意力传感器的安装刚度，过柔的安装会引入高频噪声，建议在力编码器输入端增加低通滤波（截止频率约 50 Hz）。MoE 的专家数量（5 个）与路由温度参数对性能敏感，建议在验证集上网格搜索温度系数（0.5-2.0 范围）。若下游任务涉及动态障碍物，需额外收集含移动障碍物的数据，否则模型可能无法应对。
