OmniH2O｜通用灵巧的人对人全身远程操作和学习

OmniH2O: Universal and Dexterous Human-to- Humanoid Whole-Body Teleoperation and Learning

领域
设计工程AI 模型与算法
层级
中游智能层
审校

摘要

OmniH2O 主要解决数据闭环：用语言指令、相机图像/多视角观测、人类视频/动捕轨迹采集人类操作和机器人状态，再通过教师-学生知识迁移、PPO/RL 策略训练、ACT/行为克隆模仿学习转成可训练、可复用的全身轨迹/动作序列、低层控制器目标。关键点是用特权信息训练教师策略，再把能力蒸馏到只能使用部署观测的学生策略。

来源与参考

概述

WorldVLA 是一个自回归动作世界模型，由阿里巴巴团队提出，在单一 LLM 架构内统一了动作与图像的理解和生成。它通过共享词汇表、动作注意力掩码和混合训练策略，使动作模型与世界模型相互增强，在 LIBERO 基准上显著提升了机器人操作的成功率与视频预测质量。

它改变了什么

现有 VLA 模型把动作仅当作输出，缺乏对动作本身的深层理解；而世界模型虽能预测未来视觉状态，却无法直接产出动作。这种割裂导致动作规划缺少对物理动态的显式建模，世界模型也无法从真实动作数据中获益。WorldVLA 真正改变的是将这两个原本分离的范式合并为一个可端到端训练的统一框架，让动作生成和视觉预测共享同一套参数与表征，从而在推理时互相提供先验与约束。

另一个关键改变在于处理自回归生成多动作时的性能崩塌。作者发现，预训练多模态语言模型对动作的泛化能力弱，早期动作预测错误会沿序列传播放大。他们用动作注意力掩码切断动作 token 之间的依赖，使多个动作可并行生成，这直接扭转了“动作越长、成功率越低”的困境，也改变了 VLA 模型对动作序列建模的基本假设。

方法拆解

架构与分词

  • 三个独立分词器分别编码图像、文本和动作，token 共享同一词汇表（文本 65536，图像 8192，动作 256），在单一 LLM 内统一跨模态理解与生成。
  • 图像分词器为 VQ-GAN，压缩比 16，码本 8192；256×256 图像生成 256 个 token，512×512 生成 1024 个 token。
  • 动作分词器将每个连续维度离散化为 256 个 bin，动作表示为 7 个 token（3 相对位置、3 相对角度、1 绝对夹爪状态）。
  • 模型从 Chameleon 初始化，因其原生支持统一图像理解与生成。

训练目标

  • 损失函数：L = L_action + α·L_world，α 固定为 0.04，用于平衡动作 token（7 个）与图像 token（256 或 1024 个）的数量差异。
  • 动作模型数据格式：文本为“What action should the robot take to + task instruction + ?”，输入 M 张图像，输出 K 个动作，仅计算动作 token 损失。
  • 世界模型数据格式：文本为“Generate the next frame based on the current image and the action.”，基于动作重复 N 次预测下一帧，仅计算图像 token 损失。

动作注意力掩码

  • 当前动作仅依赖文本和视觉输入，禁止访问先前动作，使自回归框架能并行生成多个动作。
  • 世界模型部分保持传统因果注意力掩码，以正确建模时序依赖。

混合训练

  • 混合动作模型数据与世界模型数据训练，使模型同时具备两种能力。
  • 世界模型数据增强动作生成的三个原因：学习环境物理动态、模拟评估候选动作结果、精确解释动作输入。

关键创新

  1. 动作世界模型统一框架：首次将动作生成与视觉预测合并进单一自回归 LLM，共享参数与词汇表。这不仅是架构拼接，而是让动作模型在训练时隐式学习环境动态，世界模型则从真实动作数据中获得更精确的物理约束，两者互为正则化器。

  2. 动作注意力掩码策略：针对自回归模型顺序生成多动作的性能崩塌，提出切断动作 token 间依赖的掩码。这一设计使动作块可并行生成，将 LIBERO Long 任务成功率从 16.9% 提升至 49.3%（由表内数值 16.9→49.3 计算），且块越长优势越明显。

  3. 统一分词器设计：将连续动作离散化为 256 个 bin 并与图像、文本 token 共享词汇表，使 LLM 能像处理语言一样处理动作。这种设计避免了额外动作头或专用解码器，保持了架构的简洁性和可扩展性。

边界与局限

  • 数据和模型规模的扩展是框架进一步发展的方向，但论文未进行大规模预训练，表 2 中 WorldVLA 无预训练，预训练被列为未来工作。
  • 依赖离散表示的图像分词器在感知表现力上存在局限，设计能同时理解和生成高质量视觉内容的统一分词器是重要改进方向。
  • 引入辅助动作头是提升抓取性能的另一种潜在策略，但论文未实现。
  • 动作块过长会限制机器人及时调整策略的能力，导致性能下降，论文未明确最优块长与任务复杂度的关系。
  • 硬件平台细节未在片段中明确给出。

工程启示

复现时先核对三个关键点：一是分词器配置，图像压缩比 16、码本 8192，动作 bin 数 256，任何偏差都会影响 token 对齐；二是动作注意力掩码的实现，必须确保动作 token 间无因果依赖，否则块生成会退化为顺序生成；三是 α 值固定为 0.04，若图像分辨率从 256 提升到 512，图像 token 数从 256 增至 1024，需重新平衡损失权重。

最容易踩坑的地方是训练数据过滤——必须滤除不成功轨迹和无操作动作，否则世界模型会学到错误动态。推理时建议从 2 帧历史输入起步，兼顾成功率（84.4%）与速度（3.13 FPS）。若下游任务需要高频控制，可考虑 1 帧输入配合块生成，成功率 74.0% 但 FPS 提升至 3.67。对于长时任务，优先使用 K=10 的动作块，但需监控动作块过长导致的策略调整滞后问题。
