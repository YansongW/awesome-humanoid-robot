COLA｜学习人机协调以协作搬运物体

Learning Human-Humanoid Coordination for Collaborative Object Carrying

领域
设计工程AI 模型与算法
层级
中游智能层
审校
待审校

摘要

COLA 先从本体状态与关节序列、人类视频/动捕轨迹、仿真交互数据恢复场景、目标或运动表征，再用PPO/RL 策略训练、世界模型/视频预测、闭环纠错/人类干预生成全身轨迹/动作序列、低层控制器目标。关键点是把PPO/RL 策略训练、世界模型/视频预测放在同一条训练/部署链路里，减少高层目标到低层动作之间的断点。

来源与参考

  • COLA project page
  • COLA: Learning Human-Humanoid Coordination for Collaborative Object Carrying

概述

VideoVLA 将视频生成模型 CogVideoX-5B 改造为视频-动作联合扩散 Transformer，通过同时去噪未来视频帧与 7 维动作块，实现机器人操作。该方法在 SIMPLER 仿真 12 项任务上取得 63.0% 平均成功率，超过 CogACT 的 62.6%，并验证了视频预测质量与动作成功率的相关性。核心贡献在于用视频生成器替代理解模型作为 VLA 骨干，将物理动态先验直接注入动作决策。

它改变了什么

现有 VLA 模型（RT 系列、OpenVLA、CogACT）依赖视觉-语言理解模型作为骨干，这类模型擅长语义匹配但缺乏对物理动态的显式建模，导致面对未见物体、新任务时动作推理常出现违反物理规律的行为。VideoVLA 的转变在于：将骨干从“理解世界”的判别模型换成“生成世界”的扩散视频模型，利用视频生成器在训练中被迫学习物体运动、碰撞、抓取等物理规律的特性，使动作输出天然具备物理合理性。这改变了 VLA 的设计哲学——不再把动作视为从感知到决策的分类问题，而是视为与视觉想象联合生成的生成问题。

另一个关键改变是动作与视频的联合去噪。此前工作要么只预测动作（如 RT-2），要么只生成视频（如 UniPi），VideoVLA 将两者绑定在同一扩散过程中，迫使模型在生成未来帧的同时生成与之匹配的动作，从而在训练中建立“想象-执行”的一致性约束。这种设计让视频生成中学到的物理一致性直接约束动作空间，而非通过额外的奖励或后处理间接引导。

方法拆解

架构：视频-动作扩散 Transformer

  • 骨干为 CogVideoX-5B 的 DiT 结构，初始化自预训练权重，保留全部视频生成能力。
  • 输入序列拼接四类 token：当前观察潜在 𝑽₁（来自 3D 因果 VAE 编码器，仅编码第一帧）、未来帧潜在 {𝑽′ⱼ}ⱼ₌₂ⁿ、T5 编码的 226 个语言 token、动作块 𝒜 = {𝒂ᵢ ∈ ℝ⁷}ᵢ₌₁ᴷ。
  • 动作不 token 化，直接以 7 维向量（3 旋转 + 3 平移 + 1 夹爪）作为独立模态输入，避免离散化损失。

训练流程

  1. 对 {𝑽′ⱼ}ⱼ₌₂ⁿ 和 𝒜 施加 DDPM 高斯噪声，噪声时间步嵌入通过自适应 LayerNorm 注入（遵循 DiT）。
  2. 优化目标为联合扩散损失：同时去噪视频潜在与动作向量。
  3. 预训练 100K 次迭代，微调 15K 次迭代，批大小 256，使用 32 块 AMD MI300X GPU。
  4. 优化器 AdamW，学习率 1e-5，权重衰减 1e-4。

推理配置

  • 仿真：预测 13 个未来视频潜在（对应 49 帧），6 个动作步，DDIM 采样 50 步去噪。
  • 真实世界：预测 4 个未来潜在（对应 13 帧），6 个动作步，部署时仅执行前 3 个。
  • 关键设计：动作与视频共享同一去噪过程，采样时两者同步生成，无需额外动作解码器。

关键创新

  1. 视频生成器作为 VLA 骨干：这是首个将 5B 规模视频扩散模型直接用于动作预测的工作。与理解模型不同，视频生成器在预训练阶段被迫学习物体交互的物理规律（如重力、碰撞、接触），这种先验直接迁移到动作推理，使模型在未见场景中能推断出物理可行的动作序列。

  2. 动作-视频联合扩散：将动作与未来帧作为同一扩散过程的两个输出模态，而非级联生成（先预测视频再映射动作）。这种设计消除了“视频→动作”的中间翻译误差，且训练时视频生成损失为动作学习提供密集梯度信号，缓解了动作标签稀疏的问题。

  3. 因果 VAE 的观察编码：利用 CogVideoX 的 3D 因果 VAE，使第一个视频潜在仅编码当前帧，天然作为观察表示，无需额外视觉编码器。这简化了架构，且观察与未来帧共享同一潜在空间，利于跨模态对齐。

实验与结果

仿真评估（SIMPLER 环境）

在 OXE 预训练后直接评估，不经过任务微调。12 项任务总体平均成功率如下：

模型 平均成功率 (%)
RT-1-X 24.8
Octo-Base 9.9
OpenVLA 26.0
SpatialVLA 47.1
π₀ 50.0
CogACT 62.6
VideoVLA 63.0

分项表现：WidowX 机器人（VM 设置）4 项任务平均 53.1%，与 π₀ 并列最高；Google 机器人 VA 设置平均 62.8%，为最高；VM 设置平均 73.1%，仅次于 CogACT 的 75.2%。

真实世界实验

在 5824 个样本（pick、stack、place 三任务）上微调后部署，论文未给出具体成功率数字，但指出动作与视频预测的一致性直接影响任务表现。

关键发现

预测动作与生成视频片段存在强相关性：当生成视频与真实环境结果对齐时，对应动作成功率显著更高。这验证了联合建模的有效性——视频生成质量可作为动作可靠性的代理指标。

边界与局限

  • 论文未明确列出局限性章节，以下为推断：真实世界仅覆盖 3 个任务（pick、stack、place），任务多样性不足，无法验证复杂长程操作。
  • 泛化评估仅涉及新物体（YCB/GSO 数据集）和跨形态迁移，未测试新指令组合或动态环境干扰。
  • 对 π₀ 基线省略了本体感知输入，可能低估其性能；VideoVLA 自身也未利用本体感知，在需要精确力控的任务上可能受限。
  • 计算成本未讨论：5B 模型 + 50 步 DDIM 采样的推理延迟在真实机器人控制中可能成为瓶颈，论文未报告实时性数据。

工程启示

复现时先核对三点：一是 CogVideoX-5B 的因果 VAE 是否支持自定义帧率输入，这直接影响观察编码的时序对齐；二是动作维度 7 与 OXE 数据集中不同形态动作空间的映射关系，特别是夹爪二值化处理；三是 DDIM 50 步采样在真实机器人上的延迟，若需实时控制，可尝试减少步数或蒸馏。

最容易踩坑的是动作-视频联合去噪的权重平衡：视频损失占主导时动作可能退化，需监控两者 loss 尺度。另一个隐患是 OXE 子集（22.5 百万帧）的筛选标准，不同形态的动作空间差异大，需确保 7 维动作定义与所有数据集兼容。对于下游团队，建议先在小规模数据上验证视频预测质量与动作成功率的关联性，再决定是否投入全量预训练。
