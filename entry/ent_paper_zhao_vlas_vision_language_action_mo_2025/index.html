VLAS

VLAS: Vision-Language-Action Model With Speech Instructions For Customized Robot Manipulation

领域

层级

审校

摘要

VLAS 是西安交通大学于 ICLR25 提出的视觉-语言-动作模型，首次将语音指令直接集成到机器人策略中，通过内语音-文本对齐实现端到端操控。其核心贡献在于提出 SQA 和 CSI 两个新数据集支持三阶段调优，并设计语音检索增强生成（RAG）范式处理个性化任务，实验证明能有效完成多样化语音指令的机器人操控。

来源与参考

  • VLAS source

概述

VLAS 是首个无需外部 ASR 即可直接理解语音指令的视觉-语言-动作模型，由作者团队提出。其核心贡献在于将语音作为独立模态端到端融入 VLA 框架，并引入 Voice RAG 模块利用声纹检索定制化知识，在个性化机器人操作任务上显著超越文本指令基线。

它改变了什么

现有 VLA 模型把语音当作文本的附属品，先经 ASR 转写再送入 VLM，这等于主动丢弃了语音中与任务意图强相关的副语言信息（声纹、语气、强调）。更关键的是，级联 ASR 引入的错误传播和额外计算开销，在机器人实时操作场景中是不可忽视的负担。VLAS 真正改变的是“语音在机器人策略中扮演的角色”——从被压缩成文本的中间表示，升级为与视觉、文本平权的输入模态，并利用声纹这一天然的身份标识来查询外部知识库，从而让机器人理解“谁在说”比“说了什么”更重要的定制化指令。

方法拆解

架构总览

VLAS 以语音指令 s 和视觉观测 O 为输入，直接输出动作序列 a。嵌入公式为： Emb(s,O) = concat(MLP_s(Emb_s(s)), Tok_l(RAG(s)), MLP_v(Emb_v(O))) 其中 Emb_s 为 Whisper 编码器，Emb_v 为 CLIP 视觉编码器，MLP 为投影器，Tok_l 为文本 tokenizer。

语音处理

  • 语音经 STFT 转为 80-bin mel-spectrogram，填充至固定 3000 帧，Whisper 编码器输出 1500 个隐藏表示。
  • 沿时间维度 reshape 缩减因子为 5，将语音 token 压缩至 300 个，降低 LLM 计算负担。
  • 压缩后的语音 token 经 MLP 投影到与文本/视觉共享的语义空间。

动作 token 化

  • 连续动作值离散化为 256 个均匀间隔 bin，复用 LLM 词汇表中 256 个最不常用的 token。
  • 7 维动作 [x, y, z, φ, θ, ψ, g] 的 token 用空格连接形成文本字符串作为训练标签。
  • 训练时合并 5 个时间步动作作为单个标签，推理时一次预测 5 步并连续执行（r=5）。

三阶段训练

  • Stage I：LibriSpeech train-clean-100 上粗粒度语音对齐，仅更新语音编码器与 LLM 间的 MLP，5 epochs，lr 1e-3，batch 16，单 GPU。
  • Stage II：SQA 数据集（185K 样本，1152 种声音）+ LLaVA 665K VQA 数据 + LibriSpeech train-clean-360，1 epoch，lr 2e-5，batch 16，得到 VLAS-Base。
  • Stage III：CSI 机器人操作数据集（389 条指令 × 500 种声音 ≈ 194K 样本），1 epoch，lr 2e-5，batch 16。

关键创新

  1. 端到端语音理解，摒弃 ASR 级联：这是首个将原始语音直接作为 VLA 输入模态的工作。相比 Whisper large-v2 + VLA 的管线，VLAS 避免了 ASR 错误传播，且推理时无需额外运行语音识别模型，降低了系统复杂度和延迟。
  2. Voice RAG 利用声纹检索定制化知识：将说话人识别与检索增强生成结合，使机器人能根据“谁在说话”获取个性化背景知识。消融实验显示移除 RAG 后定制化任务成功率从 55.1% 骤降至 9.6%，证明该模块是定制化能力的核心。
  3. 语音频谱下采样 + 多步预测执行：通过时间维度 reshape（缩减因子 5）和 r=5 的多步动作预测，将推理频率从 1.17 Hz 提升至 2.50 Hz，在保持操作性能的同时满足实时性要求。

实验与结果

CALVIN 基准（ABCD/D 分割，文本指令）

模型 LH-1 LH-2 LH-3 LH-4 LH-5 Len
VLA+ 95.5% 85.0% 74.9% 66.8% 58.2% 3.80
VLAS+ 94.5% 84.4% 73.6% 64.6% 56.6% 3.74
RoboFlamingo*+ASR 89.8% 78.6% 68.2% 56.5% 48.3% 3.41
VLAS* 94.2% 84.0% 73.2% 64.3% 54.6% 3.70

VLAS 在文本指令下与 VLA 基线几乎持平（Len 3.74 vs 3.80），语音指令下（VLAS*）与 ASR 管线相比优势明显（Len 3.70 vs 3.13）。真实语音评估中 VLAS 与 VLA 基线差距仅 0.19，验证了语音模态的鲁棒性。

定制化任务基准

模型 Ownership Preference Compound Avg.
VLA+ 17.9% 30.8% 23.1% 19.2%
VLAS* 94.7% 84.6% 100.0% 86.5%
VLAS*−RAG 15.4% 12.8% 25.6% 16.0%
VLA++RAG 97.4% 84.6% 97.4% 82.0%

VLAS 在定制化任务上平均成功率 86.5%，远超 VLA 基线的 19.2%。移除 Voice RAG 后性能跌至 16.0%，而给 VLA 加上 RAG 后提升至 82.0%，证明 RAG 是定制化能力的决定性因素。

通用多模态基准（VLAS-Base）

模型 VQA v2 VizWiz SQA I VQA T POPE GQA
LLaVA v1.5 78.8 50.0 66.8 58.2 85.9 62.0
VLAS-Base 78.7 51.1 72.2 58.1 85.5 62.0

VLAS-Base 在通用 VQA 基准上与 LLaVA 持平，在 SQA I 上提升 5.4（由表内数值 84.4→89.2 计算） 分，说明语音对齐未损害视觉语言能力。

推理效率

模型 Actions/Sec (Hz) Len
VLA+ (r=1) 1.89 2.30
VLAS* (r=1) 1.17 2.02
VLA+ (r=5) 3.60 3.80
VLAS* (r=5) 2.50 3.70

r=5 在效率与性能间取得最佳平衡（2.50 Hz，Len 3.70）；r=20 虽达 3.80 Hz 但 Len 骤降至 0.70。

边界与局限

  • VLAS 在 CALVIN ABCD/D 分割上略逊于 RoboFlamingo（Len 3.74 vs 4.09），作者归因于缺乏历史信息（LSTM 策略头），两种方法正交可结合。
  • VLAS-Base 在 SGQA 基准上（50.8）落后于使用真实文本指令的 LLaVA（62.0），语音模态在纯问答任务上仍有信息损失。
  • 定制化任务失败案例集中在偏好任务和复合任务第二阶段，错误模式一致，表明模型理解指令但执行动作失败，策略头架构需改进。
  • 作者未在 CALVIN 基准上使用 Voice RAG，未对语音频谱下采样因子（x=5）进行消融分析。
  • 真实语音评估仅 10 人录制，样本量有限，泛化性待验证。

工程启示

复现时先核对三处：语音频谱下采样因子（x=5）直接影响推理速度与识别精度的平衡，建议在自有数据上做 1-2 组消融；动作 token 映射需确保 256 个最不常用 token 与 LLM 词表一致，否则训练标签错位；Stage I 单 GPU 训练是作者明确强调的细节，多卡并行可能导致对齐效果退化。最易踩坑的是 Voice RAG 的声纹提取模块——预训练模型的选择直接影响检索质量，建议先用小规模数据验证声纹区分度再投入全量训练。对于下游团队，若任务不涉及个性化需求，可跳过 Voice RAG 以简化部署；若涉及，务必保证外部知识库的覆盖度和更新机制，否则模型会退化为随机猜测（VLAS*−RAG 仅 16.0%）。
