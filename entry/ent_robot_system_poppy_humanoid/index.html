摘要

Poppy Humanoid 是法国 Inria Flowers 团队发起的开源 3D 打印人形机器人，约 84 cm / 3.5 kg，25 个自由度（含 5 自由度仿生脊柱），由 25 台 ROBOTIS Dynamixel 智能舵机驱动，基于树莓派与自研 pypot Python 库，支持 Scratch 图形化编程与柔顺反驱示教，是教育与 HRI 研究的经典平台。

概述

Poppy Humanoid 是法国 Inria Bordeaux Sud-Ouest 的 Flowers 团队（联合 Ensta ParisTech）于 2012 年发起的开源 3D 打印人形机器人，源于 Matthieu Lapeyre 的博士论文（导师 Pierre-Yves Oudeyer），ERC Explorer 资助，现由非营利组织 Poppy Station 维护社区。整机约 84 cm / 3.5 kg，25 个自由度（含 5 自由度全驱动仿生脊柱，屈膝式腿构型）（来源：调研档案 poppy-humanoid.md，下同）。它真正改变的不是人形机器人的运动能力，而是把「可反驱、可示教、可 3D 打印」的透明性带入了教育与人机交互研究——让一台人形机器人不再是封闭的工业展品，而是每个实验室都能拆开、改写、甚至重新设计身体的开源平台。

核心内容

是什么：准确定义

Poppy Humanoid 是一个开源硬件 + 开源软件的完整人形机器人平台。硬件层面，全身结构件采用 3D 打印制造，由 25 台 ROBOTIS Dynamixel 智能舵机驱动；软件层面，基于树莓派（Raspberry Pi）与自研的 pypot Python 库，提供从底层关节控制到高层行为编排的完整接口。许可证方面，硬件采用 CC BY-SA 4.0、软件采用 GPLv3、文档采用 CC-BY-SA 4.0。

它属于机器人系统（robot_system）类型，价值链层级为中游（midstream）——不生产电机或传感器，而是将现成的智能舵机、开源主控与 3D 打印结构件整合为一个可复现、可修改的整机方案。与工业人形机器人（如 Unitree H1）追求动态性能不同，Poppy Humanoid 的核心设计目标是教学与 HRI（人机交互）研究：让使用者能理解每一个关节、每一行代码，甚至能重新设计机器人的身体。

为什么存在：痛点与历史定位

在 Poppy Humanoid 出现之前（2012 年前后），人形机器人研究平台面临一个两难困境：工业级平台（如 Honda ASIMO、Aldebaran NAO）性能强但价格昂贵、软件封闭，一台 NAO 售价超过 €10,000，且不允许用户修改硬件结构；DIY 平台（如用 hobby 舵机自制的机器人）虽然便宜，但缺乏统一的软件栈与社区支持，每个实验室都在重复造轮子。

Poppy Humanoid 的定位恰好填补了这个空白：用 3D 打印降低结构件成本，用 Dynamixel 智能舵机免去电机驱动电路设计，用 pypot 库统一软件接口，用开源许可证允许一切修改。它的历史意义在于证明了「一台完整的人形机器人可以像开源软件一样被 fork、修改、再分发」——这个理念后来影响了 ToddlerBot（斯坦福，2025）等新一代开源人形平台。

原理拆解

① 智能舵机总线：25 个关节的「神经系统」

Poppy Humanoid 的 25 个自由度全部由 ROBOTIS Dynamixel 智能舵机驱动。每个舵机内部集成了电机、减速器、绝对编码器与驱动电路，通过 TTL 串行总线级联。这意味着外部主控（树莓派）只需一根信号线就能同时控制 25 个关节，无需为每个关节单独布线。舵机内部闭环完成位置、速度、力矩控制，外部控制器只发送指令包。

② 柔顺模式（Compliant Mode）：反驱示教的核心

Dynamixel 舵机支持「柔顺模式」——此时电机不输出力矩，关节可以被外力自由转动。Poppy Humanoid 的教学设计核心卖点正是「手把手」示教编程：教师将机器人置于柔顺模式，手动摆出目标姿态，软件记录各关节角度，再回放为动作序列。这一能力让零编程基础的学生也能在几分钟内让机器人学会一个新动作。

③ pypot 库：从关节到行为的抽象层

pypot 是 Poppy 团队自研的 Python 库，封装了 Dynamixel 总线通信、运动学计算与行为编排。它提供两类接口：底层接口直接读写关节角度、速度、力矩；高层接口支持定义「行为」（如走路、挥手）并绑定到传感器事件。pypot 还集成了对 Scratch 图形化编程的支持，让小学生也能通过拖拽积木块控制机器人。

Poppy Humanoid 的独特优势在于：5 自由度仿生脊柱（多数同尺寸平台只有 2–3 个腰部自由度）与柔顺反驱示教能力；主要劣势在于：2014 年的硬件设计已显老旧（无电池、FSR 传感器精度有限），且社区维护基本停滞（主仓库最后 push 为 2021-12-06，官方文档最后更新 2022-12-20）。

谁在用·应用案例

Poppy 社区官网明确将用户分为三类：教育者（通过机器人教计算机科学）、艺术家（用机器人「赋予想法以生命」）、科学家与极客（开源、可破解是实验与知识共享的核心优势）。具体应用场景包括：

  • 课堂教学：Poppy Torso（Poppy Humanoid 的简化版）被设计为可放在桌面上的教学平台，配合 Scratch 图形化编程，适合课堂与 FabLab 场景。
  • HRI 研究：Flowers 团队自身利用 Poppy Humanoid 研究婴儿运动发育的机器人模型——通过柔顺反驱与可编程阻抗，模拟婴儿探索身体与环境的过程。
  • 艺术表演：艺术家利用其模块化与参数化设计，改造身体结构（如更换手臂、添加装饰），编排舞蹈或互动装置。
  • 工程教学：多所工程学校将其用于机器人学课程，学生可实践运动学标定、轨迹规划与力控制。

局限与边界

  1. 硬件老化：2014 年的设计在今天已显落后——无电池供电（移动性受限）、FSR 力传感器精度有限、PS Eye 相机分辨率低。需自行确认是否仍适合作为新研究项目的起点。
  2. 社区停滞：GitHub 主仓库最后 push 为 2021-12-06，官方文档最后更新 2022-12-20，维护基本停滞。新用户可能面临依赖库与新版树莓派不兼容的问题。
  3. 成本不低：约 €7,500–8,000 的硬件成本（其中电机约 €5,000）主要来自 25 台高端舵机，对个人爱好者并不友好——「开源」不等于「便宜」。
  4. 运动能力有限：高减速比舵机 + 3D 打印结构件决定了它无法实现动态行走或跳跃，其价值在于教学与交互而非运动性能。

常见误区

  1. 「Poppy Humanoid 是玩具」——错。它是一台完整的、可编程的人形机器人研究平台，被 Inria 等机构用于严肃的 HRI 与发育机器人学研究；「看起来像玩具」恰恰是它的设计目标——降低心理门槛，让非专业用户愿意与之互动。
  2. 「3D 打印 = 廉价」——错。结构件 3D 打印确实便宜，但 25 台 Dynamixel 舵机（约 €5,000）才是成本大头。开源的是设计，不是物料。
  3. 「柔顺模式 = 无力矩控制」——错。柔顺模式只是 Dynamixel 舵机的一种工作模式（力矩输出为零），Poppy 还支持力矩控制模式，可编程设定关节输出力矩，用于阻抗控制等研究。
  4. 「Poppy 项目已死」——部分对。主仓库确实停止维护，但 Poppy Station 非营利组织仍在维护社区与文档，且其设计理念（开源、可打印、可反驱）已深刻影响了后续开源人形平台。

逆运动学

根据期望的末端执行器位姿反求关节角，常用Jacobian伪逆数值求解或简单几何解析求解。
