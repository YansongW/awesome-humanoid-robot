UrbanVLA

UrbanVLA: A Vision-Language-Action Model for Urban Micromobility

领域

层级

审校

摘要

UrbanVLA 是由北京大学、Galbot、中国科学技术大学和 BAAI 于 2025 年提出的大规模视觉-语言-动作模型，专为城市微型移动机器人设计。其核心贡献在于提出一种路径条件化的 VLA 框架，通过两阶段训练（监督微调与强化微调）实现从低层导航（如避障）到高层规划（如路径-视觉对齐）的协同优化，并在 MetaUrban 的 SocialNav 任务中超越强基线 55% 以上。

来源与参考

  • UrbanVLA: A Vision-Language-Action Model for Urban Micromobility (arXiv)

概述

UrbanVLA 是一个面向城市微移动场景的路线条件化视觉-语言-动作（VLA）框架，由研究团队提出，旨在解决配送机器人、辅助轮椅等设备在真实城市环境中遵循长时程路线指令的导航问题。其核心贡献在于将高层路线编码为结构化语言表示（roadbooks），并通过两阶段训练（监督微调 SFT 与离线强化微调 RFT）实现从 RGB 观测直接预测轨迹路径点，在 MetaUrban 模拟基准和真实世界部署中显著超越现有 LiDAR 基线。

它改变了什么

城市微移动导航长期被两个割裂的范式所困：一端是依赖高精地图与占用网格的传统 SLAM，其维护成本在动态城市中近乎失控；另一端是基于学习的目标导航，如 CityWalker，虽摆脱了显式地图，却不得不屈从于消费级导航工具（如 Google Maps）的路径点——这些工具只保证路线级拓扑，几何精度极差，导致路径点与物理世界频繁错位。现有 VLA 方法则多聚焦于桌面操作或短程室内导航，面对城市级距离、噪声路线指令、交通信号与人行道礼仪时，既缺乏对路线结构的显式理解，也缺少在动态人流与多变地形中实时调整动作的能力。

UrbanVLA 真正改变的，是首次将“路线跟随”这一城市导航核心任务，从“点目标到达”重构为“结构化语言条件化轨迹生成”。它不再试图让模型从零理解整个城市，而是把导航工具给出的粗糙路线当作一种带噪声的先验，通过启发式轨迹提升（HTL）主动注入几何模糊性，迫使模型学会从视觉线索而非理想化路线输入中提取导航信息。这一设计直击了模拟到真实迁移中最隐蔽的过拟合源——模型对路线指令的机械记忆。

方法拆解

高层路线编码

  • 将导航工具（如高德地图）返回的路线转换为两部分结构化语言表示：
  • 从高层路线重采样的路径点，提供整体几何与方向；
  • 下一次转弯的距离与方向指令（如“30米后右转”）。
  • 关键参数：重采样前方 D=40 米路线，采样间隔 d=2 米，产生 20 个路径点。

VLA 模型前向

  • 双视觉编码器：DINOv2 与 SigLIP，在通道维度拼接特征，经网格池化下采样。
  • 跨模态投影：双层 MLP 将视觉特征映射到 LLM（Qwen2）嵌入空间。
  • 动作解码：导航任务中，当前时间步的动作 token 通过 MLP 动作模型解码为轨迹 τ。

启发式轨迹提升（HTL）

  • 流程：Savitzky–Golay 滤波器去噪网络轨迹 → 移除自相交或低质量路径 → 检测显著转向点形成粗略路径点并分割轨迹 → 每段添加高斯位置噪声 → 平滑合并并按固定空间步长重采样。
  • 设计理由：避免模型过拟合理想化路线输入，鼓励从视觉线索学习真实导航的模糊性。

强化微调（RFT）

  • 将路线引导导航建模为 POMDP，状态 s 取自 LLM 骨干第 n=17 层最后一个 token 的隐藏状态（而非顶层，因顶层过度调整为动作 logits，导致 Q 函数不稳定）。
  • 动作 a 为轨迹 τ 展平的一维向量，a := vec(τ) ∈ ℝ³ᴺ。
  • 使用隐式 Q 学习（IQL）的优势加权回归目标： Lπ^IQL = E_{(s,a)∼D}[exp(βA(s,a))||a−π(s)||²]
  • 奖励函数：r(s,a) = λ_comp·l_completion − λ_coll·1_collision − λ_dev·1_deviation，权重 λ_comp=0.5、λ_coll=1、λ_dev=1。

关键创新

  1. 路线作为结构化语言条件：将高层路线编码为路径点加转弯指令的文本形式，而非直接输入坐标序列。这让 LLM 能够利用其语言先验理解“30米后右转”这类指令的语义，同时保持对几何信息的显式编码。这是首个将城市导航路线系统性地转化为 VLA 语言条件的方案。

  2. HTL 启发式轨迹提升：通过向训练轨迹注入高斯噪声并重采样，主动模拟导航工具路径点与物理世界的错位。这一设计在模拟中看似轻微降低成功率（SR 从 93% 降至 89%），却在真实世界路线完成率（RC）上带来从 42% 到 100% 的质变，揭示了“过拟合路线指令”这一模拟到真实迁移的关键障碍。

  3. 中层隐藏状态用于离线 RL：选择 LLM 第 17 层而非顶层隐藏状态作为 POMDP 状态，规避了顶层状态对动作 logits 的过度适配导致的 Q 学习不稳定。这一工程细节虽小，却是 RFT 阶段能够稳定提升未见场景泛化能力（Unseen SR +6%）的前提。

实验与结果

实验在 MetaUrban 模拟器（1000 个测试场景、100 个未见场景）与真实世界（Unitree Go2 四足机器人，超过 500 米轨迹）双轨展开。模拟中对比七个 LiDAR 基线，UrbanVLA 仅用 RGB 输入即在所有指标上大幅领先。

指标 UrbanVLA (RGB) PPO (LiDAR) PPO-Lag (LiDAR) IQL (LiDAR)
PointNav Test SR 94% 66% 60% 36%
PointNav Test SPL 0.91 0.64 0.58 0.33
SocialNav Test SR 91% 34% 17% 36%
SocialNav Test SNS 0.87 0.64 0.51 0.67
SocialNav Unseen SR 88% 24% 8% 27%

关键消融：HTL 在模拟中 Cost 略升（0.81→0.86），但真实世界 RC 从 42% 跃升至 100%；RFT 在未见场景上 SR 提升 +6%（82%→88%），Cost 降低 −0.16（0.98→0.82）。作者承认累积成本（Cost）高于 PPO-Lag 等安全基线，归因于成功率更高导致行驶距离更长，且 RGB 避障比 LiDAR 更具挑战性。

边界与局限

论文未明确讨论以下边界：方法在极端天气（暴雨、大雪）或夜间无照明条件下的视觉退化表现；对非结构化地形（楼梯、泥地）的适应性；以及当导航工具提供的路线严重错误（如封路未更新）时，模型是否具备重新规划能力。作者仅提及未来将探索更广泛的多模态线索与城市适应性，但未给出量化分析。此外，真实世界评估仅在单一城市环境（约 60 米 C 形人行道）进行，路线偏移约 10 米，样本规模有限。

工程启示

复现时最先核对的是 HTL 的噪声注入参数——高斯噪声的幅度与重采样步长直接决定模型对路线指令的过拟合程度，论文未明确给出噪声标准差，需自行调参。其次，RFT 阶段务必使用第 17 层隐藏状态，若直接采用顶层，IQL 训练可能发散。训练数据方面，SFT 阶段需同时保证导航轨迹与 VideoQA 数据的比例平衡，否则真实场景理解能力会退化。部署时注意系统运行频率为 2 Hz，这意味着动作轨迹 τ 的预测间隔需与机器人底层控制器匹配，否则会出现轨迹滞后。真实世界奖励标注依赖 LiDAR-Odometry 系统，若下游团队无此设备，需考虑替代方案。最后，Cost 指标偏高是 RGB 方案的固有代价，若任务对碰撞极度敏感，建议在奖励函数中增大 λ_coll 权重（当前为 1），而非直接改用 LiDAR。
