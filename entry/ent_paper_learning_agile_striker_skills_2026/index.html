从嘈杂的感官输入中学习人形足球机器人的敏捷前锋技能

Learning Agile Striker Skills for Humanoid Soccer Robots from Noisy Sensory Input

摘要

这篇工作先从相机图像/多视角观测、本体状态与关节序列、仿真交互数据恢复场景、目标或运动表征，再用教师-学生知识迁移、PPO/RL 策略训练、全身控制器/WBC/MPC生成可执行动作命令。关键点是用特权信息训练教师策略，再把能力蒸馏到只能使用部署观测的学生策略。

来源与参考

概述

本文提出一套面向人形足球机器人的持续踢球技能学习框架，通过四阶段训练（特权教师、定向踢球、DAgger 蒸馏、在线约束 RL 适应）在噪声感知条件下实现从追球、踢球到重新定位的完整闭环。作者在 Booster T1 人形机器人（高 1.18 m，23 DoF）上验证，仿真平均成功率 79.5%，真实场地成功率 66.7%，核心贡献在于将感知噪声显式建模并纳入策略适应过程，弥合 sim-to-real gap。

它改变了什么

人形机器人踢球此前多被视为单次动作生成问题，要么假设完美状态估计，要么在仿真中忽略感知延迟与遮挡。本文真正改变的是将「持续踢球」视为一个在部分可观测条件下的闭环控制问题，而非孤立动作序列。作者意识到，真实比赛中球的位置估计噪声、相机帧丢失、以及本体感受延迟会从根本上改变最优策略结构——例如在接近球时过早减速或急转弯，这些在特权仿真中不会出现。

另一个关键转变在于训练范式的分层：先用特权信息学出理想行为，再通过蒸馏和在线 RL 逐步剥离特权，而不是直接端到端从噪声输入学习。这改变了以往「仿真到现实迁移靠域随机化硬扛」的思路，转而承认感知噪声有其结构（速度相关、延迟、遮挡），值得单独建模并针对性适应。对工程实践而言，这意味着踢球技能的上限不再由动作生成决定，而是由感知-控制耦合的鲁棒性决定。

方法拆解

四阶段训练框架

  1. 长距离追球（教师策略）：使用地面真值球位置，学习从多种初始构型接近球的鲁棒行走步态。此阶段不涉及踢球，专注步态稳定性与路径规划。
  2. 定向踢球（教师策略）：使用特权球门位置，学习精确踢球动作。关键设计是通过域随机化（如初始姿态偏移、球位置扰动）迫使策略学会从不完美状态（踢空、身体倾斜）中恢复，而非仅记忆理想轨迹。
  3. 教师蒸馏（学生策略）：采用 DAgger 将特权教师行为蒸馏到学生策略。感知噪声建模包含三个组件：
  4. 速度相关噪声模型：球位置估计误差随机器人移动速度增大而增大；
  5. 延迟与异步更新：模拟相机与本体感受不同步；
  6. 遮挡导致的帧丢失：模拟球被对手或自身肢体遮挡。
  7. 学生适应与精化：使用在线约束 RL 算法（N-P3O）在噪声感知条件下微调学生策略。动机是蒸馏后的策略在部分可观测状态下存在不均匀信用分配问题——某些状态-动作对在教师中从未出现，导致学生产生腿部抖动或不安全急转弯。

控制与输入输出

  • 控制频率 50 Hz；
  • 输入：本体感受测量历史 + 带噪声的球与目标位置估计；
  • 输出：关节位置目标（位置控制模式）。

关键设计决策

  • 教师-学生分离而非端到端：因为踢球动作需要精确时序，端到端从噪声学习容易陷入局部最优；
  • 在线约束 RL 而非纯 PPO：约束条件限制能量消耗与动作平滑度，避免适应过程中产生危险动作；
  • 噪声建模刻意保守：速度相关噪声与帧丢失模拟比实际更恶劣，以提升鲁棒性裕度。

关键创新

  1. 感知噪声的结构化建模：将噪声分解为速度相关、延迟、遮挡三类，而非统一高斯噪声。这使蒸馏和适应过程能针对性地补偿不同失效模式，例如帧丢失时策略应保持当前动作而非重新规划。此前工作多假设噪声为各向同性，忽略了其与机器人状态的相关性。

  2. 在线约束 RL 用于学生适应：N-P3O 在适应阶段显式约束能量消耗与动作平滑度，解决了蒸馏后策略在部分可观测状态下产生抖动的问题。相比固定正则化的 PPO，约束 RL 能自适应地决定何时牺牲精度换取稳定性，这是「安全适应」的关键。

  3. 完整闭环的持续踢球：将追球、踢球、重新定位整合为单一策略，而非分模块拼接。这使得策略能在踢球后根据球的实际落点（而非预期落点）调整重新定位路径，在真实比赛中至关重要——因为踢球误差会累积到下一轮追球。

关键含义：适应后学生策略几乎追平特权教师（79.5% vs. 81.1%），且能量消耗减半，说明在线约束 RL 有效恢复了部分可观测状态下的性能损失。PPO 的高能量成本（255.8 J/s）表明固定正则化无法区分「安全但低效」与「高效但危险」的动作。

边界与局限

论文未明确列出作者承认的局限。从实验设置可推断的边界包括：真实实验仅 5 个球位置、每位置 3 次试验，统计功效有限；未测试对抗性干扰（如对手推挤）下的性能；未报告踢球精度在真实场景中的量化结果；未讨论策略对球大小、颜色、光照变化的泛化能力。此外，速度相关噪声模型的具体参数（如噪声方差与速度的映射关系）论文未明确，这直接影响复现时的调参难度。

工程启示

复现时首先核对噪声建模的三个组件是否与你的传感器特性匹配——速度相关噪声系数、延迟时长、帧丢失率这三个参数直接决定蒸馏后策略的鲁棒性裕度，设置过小会导致 sim-to-real 失败，过大则过度保守。其次，N-P3O 的约束权重（能量成本与平滑度）需要针对具体机器人重新调，本文的 108.6 J/s 是在 Booster T1 上得到的，换平台后约束边界可能完全不同。

最容易踩坑的地方在于蒸馏阶段的 DAgger 数据混合比例：如果教师数据占比过高，学生策略会过度依赖特权信息，在噪声下产生不连续动作；如果学生数据占比过高，则可能遗忘教师学到的鲁棒步态。建议先在小规模仿真中扫描混合比例，再上真实机器人。另外，真实实验的 66.7% 成功率与仿真的 79.5% 差距主要来自感知延迟——如果你的视觉管线延迟超过 50 ms，需要重新训练学生适应阶段，而非仅调整噪声参数。
