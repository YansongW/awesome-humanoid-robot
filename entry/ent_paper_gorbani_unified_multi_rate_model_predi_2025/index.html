喷气动力人形机器人的统一多速率模型预测控制

Unified Multi-Rate Model Predictive Control for a Jet-Powered Humanoid Robot

摘要

本文提出了一种针对喷气动力人形机器人iRonCub的多速率模型预测控制框架，该框架联合嵌入了质心动量动力学与二阶非线性喷气发动机动力学，并通过MuJoCo仿真验证了其有效性。

来源与参考

  • Unified Multi-Rate Model Predictive Control for a Jet-Powered Humanoid Robot

概述

本文提出一种面向喷气动力人形机器人iRonCub的统一多速率MPC框架，将质心动量动力学与二阶非线性喷气模型集成，通过LPV线性化和多速率控制策略，在200 Hz下实现1秒预测时域的在线飞行控制。核心贡献在于原生处理关节（1000 Hz）与喷气发动机（10 Hz）驱动速率差异，无需分层分解，并在MuJoCo仿真中验证了抗扰与轨迹跟踪性能。

它改变了什么

喷气动力人形机器人的控制长期面临一个被忽视的硬约束：喷气发动机的动力学是高度非线性的二阶系统，且其低层控制带宽远低于关节伺服（10 Hz vs 1000 Hz）。现有工作要么忽略喷气动力学（如[16-18]），要么依赖离线轨迹生成（[21]）或需要精确力矩级控制的RL框架（[22]），均未在统一优化框架内同时解决“非线性喷气模型”与“多速率驱动”这两个耦合问题。本文真正改变的是：将喷气动力学显式嵌入MPC预测模型，并通过多速率公式在单层优化中同时输出关节位置指令（高频）和喷气推力指令（低频），避免了级联架构中慢速执行器动态被截断或忽略的问题。这为喷气动力机器人的实时飞行控制提供了一个可落地的优化范式，而非仅停留在仿真演示。

方法拆解

核心建模选择

  • 采用质心动量方程（式3）而非全阶运动方程，将状态维度压缩至质心位置、线动量、欧拉角、角动量、推力及推力变化率（式13），控制输入为关节位置s和喷气辅助输入v（式14），显著降低QP规模。
  • 在机体坐标系𝒢[ℬ]中表达质心动量方程，使线性化矩阵A_lin(s)和A_ang(s)仅依赖关节构型s，便于后续泰勒展开。

线性化与LPV-MPC

  • 对非线性动力学在（z_c, u_c）处一阶泰勒展开，假设预测时域内旋转矩阵R_B^J、角速度ω_B及惯性矩阵I_B恒定（Assumption 2），将问题转化为LPV-MPC。
  • 喷气动力学采用[19]的二阶模型（式12）：T̈_i = h(T_i, Ṫ_i) + g(T_i, Ṫ_i)v(u_th,i)，其中v对油门指令可逆，使MPC可直接优化辅助输入v。
  • 增广状态加入误差变量e_x和e_φ以惩罚稳态偏移，目标函数包含位置、动量、欧拉角、角动量、控制增量及误差项的加权和，约束包括动力学离散化（Forward Euler）、状态初值和关节位置/速度边界。

多速率机制

  • 慢速执行器（喷气）控制输入仅在MPC迭代j = i·N_r时更新，中间迭代强制u_s,0等于上次计算值，保证喷气油门以10 Hz恒定保持0.1秒。
  • 采用变采样间隔：预测时域内采样时间从短到长，以17个knots覆盖1秒控制时域，在200 Hz频率下满足实时性。

关键创新

  1. 统一多速率MPC公式：区别于[24-26]的分层/级联架构，本文在单层优化中通过约束慢速输入在中间迭代保持不变，原生处理关节与喷气的速率差异。这避免了级联设计中慢速执行器动态被截断或忽略的问题，且无需额外协调层。
  2. 喷气动力学的显式嵌入：将二阶非线性喷气模型（式12）直接纳入MPC预测模型，并通过可逆映射v(u_th)将油门指令转化为辅助输入，使优化问题保持凸性。消融实验证明移除该模型后控制器完全失效，凸显其必要性。
  3. 基于动量的LPV线性化：选择质心动量方程并在机体坐标系表达，使线性化矩阵仅依赖关节构型，配合预测时域内旋转矩阵恒定的假设，在1秒时域内保持线性结构。这比全阶模型线性化计算量更小，且实验证明在VTOL操作范围内假设成立。

结果含义：多速率策略在位置误差上降低约20-30%，姿态误差降低一个数量级（Roll从0.0765降至0.0076 rad），证明显式处理慢速执行器比简单丢弃中间输入更有效。喷气动力学消融实验证实模型嵌入是稳定性的必要条件。

边界与局限

  • 依赖欧拉角表示姿态，存在奇异性：在iRonCub参考系下，仅当机器人经历90°俯仰旋转（完全水平）时出现奇异。平台设计用于VTOL，避免水平飞行，因此理论限制不影响预期操作，但限制了向激进机动（如翻转）的扩展。
  • 线性化假设预测时域内旋转矩阵和角速度恒定，对快速姿态变化或大角度机动不适用。
  • 忽略空气动力效应，未建模气动阻力、升力等对飞行的影响。
  • 论文未明确提及仿真中喷气模型与真实发动机的差异对控制鲁棒性的影响，也未给出真实硬件实验数据。

工程启示

  • 复现核对点：首先确认喷气动力学模型（式12）的h和g函数形式及EKF识别参数，这是MPC预测模型的核心；其次检查多速率约束实现——确保u_s,0在中间迭代被正确固定为上次计算值，否则会退化为单速率。
  • 易踩坑处：线性化假设（R_B^J和ω_B恒定）在预测时域内是否成立，需根据实际机动幅度评估；若机器人需要快速旋转，需缩短预测时域或引入姿态误差反馈补偿。另外，欧拉角奇异在接近90°俯仰时会导致数值发散，需在状态估计中监控。
  • 下游团队指导：若目标平台喷气低层控制频率低于10 Hz，需调整N_r和采样间隔分布；若关节数量多（>20），建议验证QP求解器（OSQP）在200 Hz下的计算余量（本文最大4.45 ms接近5 ms周期，余量有限）。喷气推力控制输入v的更新频率（10 Hz）与MPC频率（200 Hz）的20倍差异是性能提升的关键，不可简单合并。
