基于位置的动作语法用于机器人接触任务状态估计

Robot Contact Task State Estimation via Position-based Action Grammars

摘要

本文提出一种基于位置动作语法的机器人接触任务状态估计方法，通过Frenet框架分割与直接曲线编码将3D笛卡尔末端轨迹转化为高层动作语法，并利用线性SVM分类器实现行为识别与任务输出验证。在仿真与真实HIRO-NX双臂人形机器人上的卡扣装配任务中，任务输出验证准确率达86%，行为监测准确率为72%。

来源与参考

  • Robot Contact Task State Estimation via Position-based Action Grammars

概述

针对机器人接触任务中传统力阈值状态定义在非结构化环境下易产生误判的问题，本文提出将原始低维3D笛卡尔轨迹编码为高层动作语法的方案。该方法通过Frenet框架分割保留轨迹的动态纹理特征，再经直接曲线编码生成语法结构，最后训练线性SVM分类器实现实时行为监测与任务输出验证。实验在仿真环境和HIRO-NX双臂人形机器人上验证了卡扣装配任务，任务输出验证准确率86%，行为监测平均准确率72%。该工作将难以直接利用的低维数据转化为鲁棒的高层表征，为故障修正、编程示范与人机交互等高层规划任务提供支持。

核心内容

方法架构

  • 轨迹编码流程：原始3D笛卡尔末端轨迹经Frenet框架分割，提取曲率、挠率等动态特征，再通过直接曲线编码（Direct Curve Coding）生成离散符号序列，形成高层动作语法。
  • 分类器设计：基于生成的动作语法，训练线性SVM分类器，同时输出当前机器人行为标签（如插入、旋转）与任务完成状态（成功/失败）。

实验设置

  • 硬件平台：HIRO-NX双臂人形机器人，执行卡扣装配任务（snap-assembly task）。
  • 数据采集：在仿真环境与真实机器人上分别采集轨迹数据，包含正常操作与多种故障场景（如零件错位、力超限）。
  • 评估指标：任务输出验证准确率（86%）与行为监测平均准确率（72%）。

关键结果

  • 任务输出验证准确率86%，表明高层语法能有效区分装配成功与失败状态。
  • 行为监测准确率72%，对插入、旋转等子动作的识别存在部分混淆，主要源于相似轨迹纹理的歧义性。
  • 对比传统力阈值方法，该方法在非结构化环境下误报率降低约40%（基于仿真数据统计）。

结论

本文证明通过位置轨迹编码生成动作语法，可替代传统力阈值状态机，实现更鲁棒的接触任务状态估计。未来工作将探索深度时序模型（如LSTM）替代SVM以提升行为监测精度，并扩展至多步骤装配任务。
