H2-COMPACT｜通过自适应接触轨迹策略进行人机协同操作

H2-COMPACT: Human–Humanoid Co-Manipulation via Adaptive Contact Trajectory Policies

领域
AI 模型与算法设计工程
层级
智能层中游
审校
待审校

摘要

H2-COMPACT 先从相机图像/多视角观测、本体状态与关节序列、仿真交互数据恢复场景、目标或运动表征，再用扩散策略/流匹配、分层技能/专家策略生成关节位置/力矩命令、全身轨迹/动作序列、地形/场景表征。关键点是把动作生成看成条件生成问题，用扩散或流匹配在多模态动作分布里采样可执行轨迹。

来源与参考

  • H2-COMPACT project page
  • H2-COMPACT: Human-Humanoid Co-Manipulation via Adaptive Contact Trajectory Policies project page

概述

H2-COMPACT 提出一种分层策略框架，让 Unitree G1 人形机器人仅凭双腕六轴力/力矩传感器，与人类协作搬运长形负载。上层用行为克隆将触觉映射为全身速度指令，下层用强化学习生成带负载的稳定关节轨迹，在真实实验中达到与蒙眼人类跟随者相当的性能。

它改变了什么

人-机器人协同操作长期被视觉或动捕系统主导，触觉信息往往只作为辅助修正信号。这项工作的真正转向在于：把触觉从“安全停止的触发器”提升为“意图推断的主信道”，并让腿式运动完全服从于力引导。这意味着机器人不再需要“看懂”人类，而是通过物理交互直接感知方向与速度意图，这在视觉受限或遮挡场景下具有本质优势。

更关键的是，作者将“意图解释”与“运动生成”解耦。这不是简单的模块拆分，而是承认了两种学习任务的时间尺度与表征空间不同——力到速度的映射需要快速响应且可解释，速度到关节轨迹则需要处理负载动力学与稳定性。这种解耦使得上层策略可以轻量化部署，下层策略可以充分随机化训练，避免了端到端策略在真实交互中常见的响应迟滞与过拟合问题。

方法拆解

分层架构

  • 上层意图策略：轻量级行为克隆网络，输入为双腕六轴 F/T 流，输出全身平面速度指令（twist）。该层直接捕捉领航者施加的力模式，不依赖任何视觉或状态估计。
  • 下层运动策略：深度强化学习策略，将 twist 映射为带负载的关节轨迹。在 Isaac Gym 中训练，负载随机化范围 0–3 kg，摩擦条件随机化，以增强负载自适应性与地面鲁棒性。

数据采集管线

  • 无需动捕或标记，仅同步 RGB 视频与 F/T 读数。
  • 使用 SAM2 提取 3D 人体姿态，WHAM 提取人体速度，用于生成行为克隆的训练标签。这一设计显著降低了数据采集门槛。

迁移验证

  • 仿真到仿真：MuJoCo 中验证策略迁移性。
  • 仿真到真实：Unitree G1 实机部署，验证 sim-to-real 可行性。
  • 具体推理频率、训练步数、数据量等参数，论文未明确。

关键创新

  1. 触觉作为唯一意图信道：在无视觉、无动捕条件下，仅凭双腕 F/T 完成协作搬运。这改变了人机交互中“视觉优先”的默认假设，为遮挡或视线受限场景提供了新范式。
  2. 意图与运动解耦的分层学习：不是端到端学习，而是将“力→速度”与“速度→关节”分离。这使得上层策略可快速迭代、下层策略可充分随机化，兼顾响应速度与运动鲁棒性，是工程上更务实的设计。
  3. 低成本数据采集：用 SAM2 + WHAM 从 RGB 视频自动生成训练标签，绕过了昂贵的动捕系统。这大幅降低了复现门槛，对学术与工业界都有直接吸引力。

实验与结果

实验任务为人-人形机器人协作搬运与移动，基线与蒙眼人类跟随者对比，评估指标包括完成时间、轨迹偏差、速度同步性、跟随力。

指标 结果
完成时间 与蒙眼人类基线持平
轨迹偏差 与蒙眼人类基线持平
速度同步性 与蒙眼人类基线持平
跟随力 与蒙眼人类基线持平

真实世界试验中，人形机器人在四项指标上与蒙眼人类跟随者基线持平。这一结果的含义在于：机器人仅凭触觉即可达到人类级别的跟随行为，验证了触觉引导策略的有效性。但论文未提供表格形式的量化数字（如具体误差值、成功率），图表为图片形式，具体数值论文未明确。

边界与局限

论文未明确列出作者承认的局限性。从方法设置推断，以下边界值得注意：负载范围仅覆盖 0–3 kg，超过此范围的动态负载突变未验证；地形假设为平面，非平面或多步态地形未测试；仅考虑单人类伙伴，多人与机器人协作未涉及；任务时长有限，长时间任务的稳定性未评估。此外，数据采集依赖 RGB 视频与姿态提取，在光照变化或遮挡严重时，训练标签质量可能下降，论文未明确。

工程启示

复现时先核对数据采集管线：SAM2 与 WHAM 的版本与参数直接影响行为克隆标签质量，这是上层策略性能的上限。其次，下层 RL 策略的负载随机化范围（0–3 kg）与摩擦随机化设置需严格对齐，否则 sim-to-real 迁移可能出现负载适应性不足。最容易踩坑的地方在于双腕 F/T 传感器的安装校准——力信号噪声或偏移会直接污染上层意图推断，建议在实机部署前做静态与动态校准。对于下游团队，若目标场景超出平面搬运或负载超过 3 kg，需重新设计随机化范围与奖励函数，论文未提供相关指导。
