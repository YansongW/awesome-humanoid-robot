Unitree G1人形机器人手臂基于物理的电力消耗模型辨识

Identification of a Physics-Based Electrical Power Consumption Model for the Unitree G1 Humanoid Arm

摘要

本文针对Unitree G1人形机器人七自由度左臂，提出了一种基于物理原理的线性参数化电功率消耗模型。该模型融合了执行器损耗项、基线扭矩校正项以及成对关节速度交互项，并在943条物理机器人轨迹上完成了验证。

  • integrates 主板功率传感器 用于采集回归用功率数据的车载传感器。

概述

本文为Unitree G1人形机器人七自由度手臂建立了一个物理基线性参数电力消耗模型，以机载功率测量为回归目标，通过轨迹平均和约束优化实现参数识别。核心贡献在于引入基线铜损校正以预测负净功率、成对关节速度交互项以捕捉多关节耦合效应，并在943条轨迹上验证了模型精度。

它改变了什么

现有机械臂功率建模要么依赖大量数据且外推能力差，要么需要无法获取的执行器内部参数，且几乎不关注重力补偿和多关节耦合。本文真正改变的是：将功率建模从“固定基座工业臂”推进到“现代人形机器人手臂”，并证明在仅有电机扭矩估计和关节状态（而非内部物理参数）的条件下，物理基线性模型依然可以做到高精度。它把“功率预测”从理论可行性变成了工程可落地的工具，直接服务于能量感知运动规划和电池管理。另一个关键改变是揭示了“负净功率”现象——当手臂移动到重力负载低于家姿态时，实测功率低于静态基线，传统模型无法处理，本文通过基线铜损校正给出了物理解释和预测手段。

方法拆解

电机与关节级模型

  • 忽略电气瞬态，电机电压方程 V_i = R_i I_i + K_{m,i} ω_{m,i}，其中 ω_{m,i} = n_i q̇i，I_i = τ_i / (n_i η)。} K_{m,i
  • 总电功率分解为铜损 R_i I_i² 和机械功率 τ_{m,i} ω_{m,i}，得到关节级模型： P_el,i = a_i τ_i q̇i + b_i τ_i² + c_i |q̇_i| + d_i q̇_i² 其中 a_i = 1/η)²，c_i、d_i 分别建模库仑和粘性摩擦。}，b_i = R_i / (n_i η_{g,i} K_{m,i

基线铜损校正

  • 定义净功率 P_net,i = P_el,i − P_base,i，其中 P_base,i 为静止姿态（q=0, q̇_i=0）的静态贡献。
  • 引入 Δτ_i²(t) ≔ τ_i²(t) − τ̄_0,i²，τ̄_0,i² 为静态预空闲窗口的平均平方扭矩，得到 P_net,i = a_i τ_i q̇_i + b_i Δτ_i² + c_i |q̇_i| + d_i q̇_i²。
  • 当手臂移动到重力负载低于家姿态时 Δτ_i² 为负，从而正确预测 P_net,i < 0。

多关节交互项

  • 实测发现同时多关节运动时功率超过单关节贡献之和，加入成对交互项： P_net(t) = Σ_{i=1}^{7} P_net,i(t) + Σ_{i<j} e_ij |q̇_i| |q̇_j|，e_ij ≥ 0。
  • 完整参数向量 θ ∈ ℝ⁴⁹：28个关节参数（4×7）+ 21个成对交互系数（C(7,2)=21）。

轨迹级聚合与约束优化

  • 原始逐样本拟合条件数 κ(Φ^T Φ) ≈ 7.8×10¹¹，R² < 0.04，因MBS传感器约1 Hz而运动学100 Hz导致样本重复约100次。
  • 改为将每条轨迹聚合为一行：φ̄j = (1/N_j) Σ φ_k，P̄net,j = (1/N_j) Σ P_net,k，中位 N_j ≈ 1016，平均降噪 √N_j ≈ 32 倍。
  • 求解严格凸QP：θ* = argmin_θ ‖Φ̄θ − ȳ‖₂²，约束 a_i ≥ 1, b_i ≥ 0, c_i ≥ 0, d_i ≥ 0, e_ij ≥ 0，用IPOPT经CasADi求解。

异常值过滤

  • IMU稳定性拒绝：σ_ω > 2.5 × median(σ_ω) 的轨迹被拒，1017条中104条被拒。
  • 两轮3σ残差拒绝：额外丢弃16条，残差峰度从77改善到2.97。
  • 最终保留 M = 897 条轨迹用于拟合。

关键创新

  1. 基线铜损校正：首次在功率模型中显式处理“负净功率”轨迹，通过减去静态姿态的平方扭矩贡献，使模型能够预测手臂移动到低重力负载构型时的功率下降。这是对传统“功率恒正”假设的实质性突破，对能量回收和任务时长估计至关重要。
  2. 成对关节速度交互项：识别出多关节同时运动时的耦合功率消耗，并用非负系数 e_ij 建模。最大交互系数出现在肩部滚转/肘部（e_{1,3}=1.1053），说明耦合效应不可忽略，且物理上可解释为共享电源轨或机械耦合。
  3. 轨迹平均识别方法：针对传感器采样率不匹配（1 Hz功率 vs 100 Hz运动学）导致的病态回归问题，提出将每条轨迹聚合为单样本，将条件数从 7.8×10¹¹ 降至可解范围，R² 从 <0.04 提升至 0.933。这是工程可复现的关键设计。

关键结果含义

  • 验证集RMSE 3.58 W高于训练集1.07 W，因验证集功率范围更大（实测至121.7 W vs 训练上限27 W），相对误差为满量程的2.9%。
  • 最差残差17.2 W出现在快速肘部–腕部–俯仰–偏航组合（1.0 rad/s），该速度区域未在训练集中明确覆盖该关节组。
  • 成对交互项最大为肩部滚转/肘部 e_{1,3}=1.1053，肩部俯仰/肘部 e_{0,3}=0.9090，说明肩肘耦合显著。

边界与局限

  • 温度依赖：绕组电阻 R_i 随温度漂移，长时间实验中有效 b_i 会变化，作者未做运行特定校正，留作未来工作。
  • 制动不对称：谐波驱动器不可反向驱动，减速时齿轮效率为 η_g,i 而非 1/η_g,i，当前模型对两种模式使用单一 a_i，可能引入系统偏差。
  • 共线性：当两关节遵循相同速度曲线时，|q̇_i||q̇_j| ≡ q̇_i²，导致粘性和交互特征完全共线，单个 d_i 和 e_ij 不可分别识别，仅组合效应可靠。
  • Dex3-1手的影响：所有实验均安装手，腕部大粘性系数（腕部偏航 d_6=1.7848）可能部分反映手部负载惯性拖曳而非纯齿轮摩擦，作者未做移除手的对照实验。
  • 未验证场景：未提及模型在腿部运动、不同负载条件、长时间运行或不同机器人姿态下的验证；未与数据驱动方法做定量比较。

工程启示

  • 先核对传感器采样率匹配：这是最容易踩坑的地方。MBS约1 Hz vs 关节状态100 Hz，直接逐样本拟合必然病态（κ≈7.8×10¹¹），必须做轨迹级聚合，否则R² < 0.04。
  • 务必包含腕部关节轨迹：作者明确强调，若训练集不含腕部，腕部 b_i、c_i、d_i 不可识别，IPOPT会分配任意值。复现时需覆盖全部7个关节的单关节扫描和所有两关节组合。
  • 过滤流程不可省略：IMU稳定性拒绝（σ_ω > 2.5×median）和两轮3σ残差拒绝是保证拟合质量的前提，峰度从77降到2.97说明异常值影响极大。
  • 约束优化用IPOPT+CasADi：严格凸QP带不等式约束（a_i ≥ 1, b_i ≥ 0, c_i ≥ 0, d_i ≥ 0, e_ij ≥ 0），必须精确执行约束，否则物理不可解释。
  • 验证集速度要覆盖训练集间隙：本文验证集用中间速度（0.75, 1.25, 1.75, 2.25 rad/s），训练集用端点速度（0.5, 1.0, 1.5, 2.0, 2.5 rad/s），这样能暴露外推能力。最差残差17.2 W正是出现在训练未覆盖的速度-关节组合。
  • 注意共线性陷阱：设计轨迹时避免两关节速度曲线完全相同，否则 d_i 和 e_ij 不可分，只能报告组合效应。
