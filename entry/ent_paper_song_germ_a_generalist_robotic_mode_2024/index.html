GeRM

GeRM: A Generalist Robotic Model with Mixture-of-experts for Quadruped Robot

摘要

GeRM 是西湖大学 MiLAB 团队在 IROS 2024 上提出的大型视觉-语言-动作模型，专为四足机器人多任务操作设计。其核心贡献在于利用离线强化学习优化数据利用策略，并引入 Mixture-of-Experts 结构提升推理速度与模型容量，同时发布了自动采集的 QUARD-Auto 数据集。

来源与参考

  • GeRM source

概述

GeRM 是一个面向四足机器人的通用 VLA 模型，由研究团队提出，核心贡献在于将混合专家（MoE）架构与离线强化学习结合，使模型能从次优（失败）数据中学习，突破专家示范的性能上限。该模型在仿真多任务基准上显著超越现有 IL 方法，同时保持激活参数效率。

它改变了什么

现有 VLA 机器人策略几乎都依赖高质量专家示范进行模仿学习，这带来两个根本性瓶颈：一是数据收集成本极高，尤其对四足机器人这种高自由度（DOFs）平台，遥操作或仿真内专家策略设计都异常昂贵；二是 IL 策略的性能天花板被示范质量锁死，模型永远无法学会超越专家的行为。GeRM 真正改变的是“数据利用范式”——它不再把失败轨迹当作垃圾丢弃，而是通过离线 RL 将其转化为学习信号，让策略从自身探索的错误中迭代进步。同时，它直面了 RL 策略参数扩增带来的性能退化问题，用稀疏 MoE 结构在增加总参数的同时保持激活计算量基本不变，从而解锁了 RL 在大模型上的扩展能力。

方法拆解

整体架构

GeRM 是一个 decoder-only 的稀疏 MoE Transformer，输入为指令文本（经 universal sentence encoder 编码为 512 维向量）与 7 帧历史图像（第 7 帧仅用于 Q 值计算），图像经 ImageNet 预训练的 EfficientNet-B3（带 FiLM 条件层）提取特征，再经 TokenLearner 压缩为紧凑 token 集，最终由 MoE Transformer 输出离散动作 token，反离散化为 12 维命令。

离线 RL 设计

  • 采用类似 Q-Transformer 的深度 Q 学习框架，用 Transformer 替代价值函数直接输出离散化动作。
  • 引入 CQL 保守惩罚项，压低数据集外动作的 Q 值，确保 argmax 动作落在数据分布内。
  • 损失函数为 MSE（缩放 0.1），与 IL 的交叉熵损失形成对比。

MoE 门控机制

  • FFN 层包含 8 组专家参数，每个 token 由路由网络选择 Top-2 专家处理并加性组合。
  • 门控网络 G(x) 在 softmax 前添加可调高斯噪声：H(x) = (x·W_g)_i + N(0,1)·Softplus((x·W_noise)_i)，K(x,k) = TopK(x·W_g)。噪声项既促进负载均衡，又使离散选择过程可微，支持梯度回传。

数据收集

  • 全自动流程：预训练 GeRM w/o MoE 作为高层策略，低层控制采用 [51] 方法输出关节角度，在 Isaac Gym 中收集 QUARD-Auto 数据集，包含成功与失败轨迹。

关键创新

  1. 首次将 MoE 与离线 RL 系统性结合于四足 VLA 策略：此前 MoE 主要用于语言模型扩展，机器人领域鲜有探索。GeRM 证明了稀疏激活结构能有效缓解 RL 策略参数增加带来的优化困难，这是对“参数越多 RL 越难训”这一经验法则的直接挑战。
  2. 次优数据利用机制：通过 CQL 保守惩罚与稀疏奖励设计（示范奖励 1.0，次优奖励 0.0），GeRM 能从失败轨迹中提取负面信号，这在四足机器人领域是首次大规模验证。其效果直接体现在 Go_through 任务上：加入次优数据后成功率从 73.66 提升至 75.00。
  3. 参数效率与性能的兼得：总参数 83.48M，但激活仅 39.31M（约 1/2 总参数、1/8 FFN 层），相比 RT-1 仅增加 5.81M 激活参数，却在所有任务上实现 30%-70% 的性能提升。

关键观察

  • MoE 与 RL 的协同：GeRM w/o MoE 加入次优数据后，Go_through 从 35.34 提升至 47.79；而 GeRM 加入次优数据后，Stop 从 50.31 跃升至 71.00，说明 MoE 放大了 RL 对次优数据的利用效率。
  • 训练效率：在 “Go to the red cube” 任务中，GeRM 第 2 个 epoch 即达到 RT-1 第 20 个 epoch 的水平，约第 7 个 epoch 收敛；IL 方法到第 10 个 epoch 仍未收敛。
  • 数据规模：示范数据 8610 条轨迹（2238600 个 VLA 集，每条 260 帧），次优数据 2766 条轨迹（1548960 个 VLA 集，每条 560 帧），比例 75.69% / 24.31%。

边界与局限

论文明确承认模型仅在仿真环境（Isaac Gym）中验证，未在真实四足机器人上部署实验。这意味着仿真到现实的 gap（如动力学差异、感知噪声、延迟）完全未被评估。此外，任务范围限于 5 类结构化场景，对开放世界泛化能力未做测试。MoE 路由机制和多专家内存加载引入额外推理开销，论文指出其更适合批量工作负载，单机实时推理效率存疑。训练硬件与时长论文未明确。

工程启示

复现时最先核对三点：一是离线 RL 的 CQL 惩罚系数与奖励缩放（MSE 损失需乘 0.1），这直接决定次优数据能否被有效利用；二是 MoE 门控噪声的 Softplus 缩放参数，它影响负载均衡与训练稳定性；三是 TokenLearner 的压缩率，它决定了视觉 token 数量与计算开销的平衡。最容易踩坑的地方在于：次优数据的奖励设置（全 0）与示范数据（全 1）的稀疏奖励设计，若直接照搬 dense reward 会导致 Q 值估计偏差。另外，MoE 的专家数量与 Top-k 选择（8 选 2）在迁移到其他机器人平台时可能需要重新调优，因为四足机器人的动作维度（12 维）与任务复杂度直接影响路由网络的判别难度。下游团队若想复现，建议先在单任务上验证 RL 训练稳定性，再扩展到多任务，避免直接端到端训练导致的问题定位困难。
