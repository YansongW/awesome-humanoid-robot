VINE

Hierarchical Vision Language Action Model Using Success and Failure Demonstrations

摘要

VINE 是由韩国大学、KAIST、首尔国立大学和 NAVER AI Lab 于 2025 年提出的分层视觉-语言-动作模型，用于机器人操作。其核心贡献在于利用混合质量数据（包括成功与失败演示）进行规划时的失败感知推理，通过分层强化学习框架将失败转化为结构化学习信号，从而提升策略鲁棒性。

来源与参考

  • Hierarchical Vision Language Action Model Using Success and Failure Demonstrations (arXiv)
  • VINE source

概述

现有视觉-语言-动作模型通常仅依赖遥操作成功演示进行训练，而丢弃了数据收集过程中自然产生的大量失败尝试。VINE 通过引入分层架构解决了这一问题：高层系统（System 2）基于场景图抽象进行可行性引导的树搜索，利用成功与失败数据预测子目标转换的成功概率，并剪除脆弱分支；低层系统（System 1）则执行选定的子目标序列。该模型完全从离线遥操作数据训练，将负面经验直接整合到决策循环中，在多种复杂操作任务中持续提升了成功率和鲁棒性。

核心内容

方法架构

VINE 采用分层强化学习框架，将高层推理（System 2）与低层控制（System 1）分离： - System 2：基于 2D 场景图抽象进行可行性引导的树搜索。它提出子目标转换，从成功和失败演示中预测成功概率，并在执行前剪除脆弱分支，将规划评估转化为可行性评分。 - System 1：接收选定的子目标序列，执行低层动作，不修改核心技能。

训练与数据

  • 完全从离线遥操作数据训练，整合负面经验（失败演示）到决策循环中。
  • 失败数据被视为结构化学习信号，而非噪声监督，用于学习失败感知推理。

实验设置与结果

  • 在多种挑战性操作任务上进行评估，具体任务名称未在摘要中列出。
  • 与仅使用成功演示训练的基线模型相比，VINE 持续提升了成功率和鲁棒性。
  • 关键结论：失败数据是将 VLA 模型的广泛能力转化为鲁棒执行的关键资源。
