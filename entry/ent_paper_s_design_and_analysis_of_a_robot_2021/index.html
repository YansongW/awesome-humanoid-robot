采用五杆机构的机器蜥蜴设计与分析

Design and Analysis of a Robotic Lizard using Five-Bar Mechanisms

层级

摘要

Rajashekhar 等人提出了一种基于五杆机构集成的仿生机器人蜥蜴，通过矢量环法推导了其位置运动学，并利用伺服电机驱动的原型验证了行走步态。核心贡献在于将两个五杆机构以特定顺序连接，形成四足运动结构，实现了粗糙地形的仿生移动。

来源与参考

  • Design and Analysis of a Robotic Lizard using Five-Bar Mechanisms

概述

本文提出一种基于五杆机构的新型机器人蜥蜴，通过两个主动与两个被动五杆模块的组合，实现四自由度行走步态。作者完成了拓扑综合、自由度分析、位置求解与工作空间绘制，并用轻木与Arduino UNO搭建原型验证了平坦表面上的移动能力。核心贡献在于将五杆机构作为模块化肢体骨架，而非简单仿形，从而在机构层面逼近真实蜥蜴的运动学特征。

它改变了什么

现有仿蜥蜴机器人多聚焦于外观或驱动冗余，却鲜有在核心机构层面复现蜥蜴步态的运动学约束。本文真正改变的是：将五杆机构从常见的平面并联执行器，重新定位为可串联成躯干-四肢-尾部链的拓扑单元。这一转变使得自由度分配、驱动副选择与步态规划可以在同一机构框架内统一处理，而非依赖外部控制补偿机构缺陷。

对行家而言，其价值不在单个五杆环的精度，而在如何用四个环（两个主动、两个被动）的耦合关系，自然产生蜥蜴行走所需的侧向弯曲与抬腿序列。这为后续仿生机器人设计提供了一条“机构先行”的路径，即先确定拓扑，再反推控制策略，而非相反。

方法拆解

拓扑综合

采用文献[16]的八步法，从独立环数出发：总连杆数 n=13、总关节数 m=16，计算独立环数 v = m − n + 1 = 4。每个环的独立位移方程数均为3，故机构自由度 F = 16 − (3+3+3+3) = 4。

分支结构

八个SOC分支明确划分固定与移动平台： - 固定平台：R1、R5、R11、R12 - 移动平台：其余转动副 - 分支示例：SOC1(−R1‖R2‖R3−)、SOC3(−R1‖R7‖R8−)、SOC5(−R5‖R7‖R9−)等，形成头部、身体两侧与尾部的对称拓扑。

自由度验证

选择 R1、R5、R11、R12 作为驱动副，固定后 F* = 12 − (3+3+3+3) = 0，确认驱动副选择无冗余或欠约束。POC集 M_{Pa} = [t²; r¹] 表明每个模块具有两个平移与一个旋转自由度，与蜥蜴肢体运动模式匹配。

位置分析

采用矢量环法，建立五个方程： - 头部：R2 + R3 − R4 − R5 − R1 = 0 - 身体侧1：R6 + R7 − R8 − R9 − R10 = 0 - 身体侧2：R12 + R13 − R14 − R15 − R11 = 0 - 尾部：R17 + R19 − R16 − R18 − R20 = 0

求解采用封闭形式，例如 θ4 = 2 arctan(−B − √(B²−4AC))/(2A)，θ3 = 2 arctan(−E + √(E²+4DF))/(2D)，保证实时性。

工作空间与步态

Python算法中，θ5 从 135 递减至 0，θ2 从 45 递增至 160，按特定顺序驱动四个伺服电机，使机器人呈现向前行走步态。控制器为Arduino UNO，GUI基于Processing IDE。

关键创新

  1. 五杆机构作为仿生肢体骨架：不同于传统串联腿或并联平台，本文用五杆环的耦合关系直接生成蜥蜴步态所需的侧向弯曲与抬腿序列，无需额外机构补偿。这是拓扑层面的创新，而非控制层面的修补。

  2. 被动五杆模块的引入：两个被动五杆环不直接驱动，但参与自由度分配与运动约束，使得整体自由度恰好为4，且驱动副选择后 F*=0，证明机构无内部奇异或冗余。这种“主动+被动”混合拓扑在仿生机器人中罕见。

  3. 封闭解位置分析：矢量环法配合解析求解（如 θ4、θ3 的 arctan 形式），避免了数值迭代，为实时控制与工作空间绘制提供了确定性基础。这比依赖雅可比迭代的通用方法更适合嵌入式实现。

实验与结果

项目 数值 说明
机构自由度 F 4 由 F = 16 − (3+3+3+3) 计算
驱动副固定后 F* 0 验证驱动副选择无冗余
独立环数 v 4 由 n=13、m=16 计算
θ5 范围 135 → 0 工作空间绘制算法递减
θ2 范围 45 → 160 工作空间绘制算法递增

实验仅验证了平坦表面上的行走步态，未提供速度、负载或能耗数据。工作空间图以图片形式呈现，文中未提取具体数值。结果的意义在于：证明四自由度机构在给定驱动序列下能产生连续向前运动，且无卡死或奇异位形。但缺乏与真实蜥蜴步态的定量对比（如关节角度轨迹、步频），故“紧密模仿”的论断主要基于定性观察。

边界与局限

论文未明确提及以下方面： - 未进行动力学分析，机构在高速或负载下的动态响应未知。 - 未测试非平坦地形或障碍物，步态鲁棒性未验证。 - 未提供能耗、速度或步态周期等量化指标。 - 尾部被视为被动连杆，未参与驱动，其实际功能（如平衡）未建模。 - 工作空间图未给出数值边界，仅以图片呈现，复现时需自行提取。 - 深度强化学习仅作为未来工作提及，未实现或验证。

工程启示

复现或选型时，先核对以下关键点： 1. 自由度计算：确认 n=13、m=16、v=4 的计数是否与你的CAD模型一致。若连杆或关节数有增减，F 值会变化，驱动副选择需重新验证。 2. 驱动副固定验证：务必执行 F = 12 − (3+3+3+3) = 0 的检查，否则可能出现欠驱动或过约束，导致机构卡死。 3. 位置求解的符号约定：θ4、θ3 的 arctan 解依赖矢量环的坐标方向，复现时需严格对齐 R1、R5、R11、R12 的固定平台定义，否则符号错误会导致工作空间不对称。 4. 材料与驱动：轻木（balsa wood）在CNC上加工，注意各向异性与湿度变形；四个伺服电机的驱动顺序需按文中 θ5 递减、θ2 递增的序列，否则步态会退化为原地摆动。 5. 最易踩坑处：被动五杆环的装配间隙会直接放大自由度误差，导致 F 不为0时仍能运动但轨迹漂移。建议在装配后手动检查每个环的独立位移方程数是否为3，而非仅依赖理论计算。
