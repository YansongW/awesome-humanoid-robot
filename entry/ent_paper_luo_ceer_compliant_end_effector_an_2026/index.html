CEER：作为分层人形机器人移动操作统一接口的柔顺末端执行器与根控制

CEER: Compliant End-Effector and Root Control as a Unified Interface for Hierarchical Humanoid Loco-Manipulation

摘要

CEER 提出了一种用于人形机器人全身移动操作的分层控制抽象，通过端-根（EE-root）指令实现柔顺控制。该方法采用教师-学生蒸馏框架，将全身运动跟踪策略转化为仅依赖端-根命令的低层策略，支持异构高层规划器即插即用，无需重新训练。实验表明，该方法在仿真和硬件上实现了 3.3 cm 的末端执行器跟踪精度，并显著降低了加加速度。

概述

CEER 提出一种统一的顺从末端执行器-根（EE-root）控制抽象，作为模块化人形机器人移动操作的执行接口。该方法通过教师-学生蒸馏框架，将关节空间跟踪策略转化为仅依赖任务级命令（根位姿+末端执行器位姿）的学生策略，并在 Unitree G1 上验证了接触丰富操作与长时程任务的有效性。核心贡献在于弥合高层规划器与低层全身控制之间的接口鸿沟，同时引入阻抗一致性目标以增强交互顺从性。

它改变了什么

人形机器人的运动控制已相当成熟，但接触丰富操作始终卡在“接口不匹配”上：规划器产出的是稀疏任务级目标（根导航、末端位姿），而执行层需要稠密关节轨迹。现有方案要么让规划器直接生成高维关节命令（数据稀缺、形态特定），要么用任务特定力/阻抗设定点（缺乏泛化性）。CEER 真正改变的是把“执行接口”从关节空间提升到任务空间——末端执行器位姿加根位姿，同时保留阻抗控制的顺从性。这意味着下游技能模块（遥操作、运动规划、VLM 轨迹预测）可以统一输出这种稀疏命令，无需为每个新任务重训底层策略或编写适配器。

另一个关键转变是训练范式的解耦：教师策略在人类运动数据上学到丰富的全身协调，学生策略只以 EE-root 命令为条件，通过两个估计器（特权状态、目标关节）桥接信息差。这避免了端到端从任务奖励直接学习 EE-root 控制器的样本效率灾难，也让策略权重可以直接继承，微调稳定。本质上，CEER 把“全身控制”封装成一个可插拔的顺从执行器，让上层智能（LLM、VLM、经典规划）专注于任务推理，而不是关节级肌肉记忆。

方法拆解

阻抗控制公式与顺从目标

  • 笛卡尔阻抗：F = K_m(ẍ − ẍ_d) + K_d(ẋ − ẋ_d) + K_p(x − x_d)，实践中设 ẍ_d = 0，增益恒定。
  • 外部交互建模为弹簧扰动 f_ext，准静态下稳态动力学简化为 K_p(x_imp − x_ref) + K_d(ẋ_imp − ẋ_ref) = f_ext,t。
  • 假设速度跟踪成立（ẋ_imp = ẋ_ref），顺从目标变为 x_imp = x_ref + K_p⁻¹ f_ext,t。该阻抗一致目标 (x_imp, ẋ_imp) 用作特权观测和奖励构建。

教师-学生策略框架

  • 教师策略 π_T：输入 o_t^T = (c_t^T, o_t, o_t^p)，其中 c_t^T ∈ ℝ²⁹ 为关节空间参考命令（直接提供，不经过编码器压缩，理由：参考关节配置是运动跟踪的主要监督信号），o_t^p 包含外部力 f_t^ext、特权跟踪状态 s_t^ref、模拟器真值 s_t^sim、执行器状态 s_t^act。
  • 学生策略 π_S：输入 o_t^S = (c_t^S, o_t)，命令 c_t^S ∈ ℝ¹⁶（根位姿 x,y,z,yaw + 末端执行器位置与方向）。共享观测 o_t 仅含本体感觉（投影重力向量 g_t、根角速度 ω_t、过去 K 步关节位置 q_{t−K:t}、过去 L 步动作 a_{t−L:t−1}）。
  • 两个估计器：特权状态估计器 f_θp（从 o_t 预测剩余特权信息）、目标关节估计器 f_θq（从 (o_t, c_t^S) 预测 29 维参考关节配置）。关键设计：学生输入维度与教师一致，可直接继承教师权重，稳定微调。
  • 训练：PPO 两阶段，教师先基于 AMASS 人类运动数据训练，再蒸馏给学生。

三层层次化架构

  • 低层：CEER 策略 50 Hz，消费标准化 EE-root 命令，映射为关节 PD 目标。
  • 中层：模块化技能（10–20 Hz），包括 VR/键盘遥操作、混合 A* 运动规划（支持原地旋转和后退）、操作原语（抓取/放置）、VLM 轨迹预测、扩散策略。
  • 高层：LLM 任务管理器（秒级），通过函数调用接口选择技能，系统提示编码工作空间坐标系、手位置状态（rest/hold/ready/grasp）及安全分类，不微调 LLM。

奖励函数

  • 总奖励 r_total = w_ee·r_ee + w_c·r_compliance + w_m·r_motion + w_l·r_locomotion，其中 r_ee = exp(−‖x_t^ee − x_t^ref‖²) 为新增末端执行器跟踪项，其余沿用先前工作。

关键创新

  1. 统一任务级执行接口：将根导航与末端执行器位姿组合成 16 维命令空间，覆盖移动操作的全部自由度需求。相比关节轨迹或密集全身参考，该接口天然匹配模块化规划器的输出格式，无需重定向或适配器。这是首个将“顺从性”直接编码进任务空间抽象的工作，而非事后在关节层叠加阻抗。

  2. 阻抗一致性目标作为特权信号：不是简单用末端位置误差做奖励，而是将阻抗动力学推导出的顺从目标 (x_imp, ẋ_imp) 作为特权观测和奖励构建依据。这让学生策略学到的是“在交互中如何偏离参考以保持顺从”，而非僵硬地跟踪目标。消融实验显示移除力扰动训练（No-force RL）后 jerk 从 4.5 升至 9.9，证明该信号对平滑交互至关重要。

  3. 教师权重直接继承机制：通过目标关节估计器 f_θq 将学生输入维度对齐到教师维度，使学生策略可以加载教师权重初始化。这避免了从零训练学生策略的收敛问题，显著加速微调。消融显示移除 f_θq 后位置误差从 0.033 m 恶化至 0.124 m，jerk 从 4.5 升至 33（×10³），验证了该设计的必要性。

失败分析

52.6% 的自主失败源于 LLM 层面规划不准确（估计方向角和距离），导致不稳定抓取。这指向高层空间推理是当前瓶颈，而非低层控制。

边界与局限

  • 阻抗参数（K_p, K_d, K_m）在执行期间固定，无自适应刚度调制机制。对变刚度交互场景（如易碎物体、人机物理协作）适应性未知。
  • 策略不支持自主手臂运动：末端执行器目标必须显式提供，行走时手臂保持静止，除非手动指定摆动轨迹。部分目标指定（仅根命令）未实现。
  • 未支持灵活接触规格（如肘部或脚部放置），限制了全身接触操作的表达范围。
  • 规划器兼容性研究仅定性验证，无定量指标。跨不同机器人形态的迁移实验未提及。
  • 长时程任务成功率（2/10）低于人类（4/10），且 52.6% 失败源于 LLM 空间推理，恢复机制不足。

工程启示

  • 复现优先级：先核对目标关节估计器 f_θq 的实现——消融显示移除后位置误差恶化近 4 倍（由表内 0.033→0.124 计算），这是整个蒸馏框架的命门。确保学生输入维度与教师严格对齐，否则权重继承失效。
  • 训练配置：16,384 并行环境 + 4×L40s + 8 小时是已验证的配置。若资源受限，优先保证教师策略质量（AMASS 数据覆盖度），学生蒸馏对数据量要求较低。
  • 部署踩坑：低层 50 Hz 与中层 10–20 Hz 的速率差需通过命令缓冲处理，避免丢帧导致末端抖动。VR 遥操作务必使用有线连接（如 Pico 4 + ALVR），无线延迟会直接破坏阻抗控制的稳定性。
  • 下游集成：LLM 任务管理器不微调，依赖系统提示编码空间布局。若迁移到新环境，需重写提示中的坐标系和手位置状态定义，否则 52.6% 的规划错误会重现。建议在提示中加入“先估计距离再行动”的显式推理步骤。
  • 扩展方向：若需自主手臂摆动，需扩展策略输入空间支持部分目标指定；若需变刚度交互，需引入阻抗参数调制网络，但注意这会改变特权观测分布，需重新蒸馏。

标准二次规划（QP）
