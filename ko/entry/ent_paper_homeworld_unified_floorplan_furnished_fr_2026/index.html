요약

Indoor scene generation is crucial for robot simulation and modern interior design. However, complex layouts together with scarce 3D scene data make learning-based generation challenging. Institutions per source list: Ace Robotics、CUHK MMLab、Shenzhen Loop Area Institute（*Equal contribution、†Project lead）.

개요

HomeWorld는 연구팀이 제안한 자연어 프롬프트에서 제어 가능하고 밀집된 상호작용형 전체 주택 장면을 생성하는 통합 계층적 프레임워크입니다. 핵심 기여는 전체 주택 생성을 평면도 합성, 계층적 로밍 배치, 재귀적 세분화, 조작 가능한 객체 배치의 네 단계로 분해하고, 대규모 실제 평면도 데이터로 훈련된 LLM과 명시적 3D 앵커링을 결합하여 기존 방법의 전역적 일관성, 물리적 실현 가능성, 시뮬레이션 준비성 부족 문제를 해결한 것입니다.

무엇을 바꾸었는가

전체 주택 장면 생성은 오랫동안 평면도 합성, 단일 방 레이아웃, 객체 배치 등의 고립된 하위 작업으로 분리되어, 생성된 장면은 전역적 위상 일관성과 방 간 의미적 연속성이 부족했습니다. 기존 방법은 수동 규칙(예: ProcTHOR)에 의존하여 반복적이고 편향된 레이아웃을 생성하거나, 직접 3D 학습을 수행하지만 훈련 데이터 부족과 계산 비용에 제약을 받거나, 2D 승격(예: Text2Room)을 채택하지만 강력한 3D 사전 앵커링이 부족하여 전체 주택으로 확장 시 기하학적 파편화가 발생했습니다. HomeWorld가 진정으로 바꾼 것은 "생성"을 "제어 가능한 계층적 인스턴스화" 프로세스로 재정의한 것입니다: 먼저 LLM을 사용하여 구조화된 표현에서 위상적으로 올바른 평면도를 합성하고, 명시적 3D 셸 제약 하의 2D 인페인팅으로 점진적으로 가구를 채운 다음, VLM으로 물리적 위반을 재귀적으로 교정합니다. 이 패러다임은 데이터가 부족한 3D 생성 문제를 데이터가 상대적으로 풍부한 2D 생성 및 3D 검증 문제로 변환하여, 생성 결과의 위상적 유효성, 객체 밀도, 물리적 합리성을 동시에 향상시킵니다.

방법 분해

단계 1: 평면도 생성 (LLM + K-D 트리)

  • 데이터 구축: 온라인 부동산 저장소에서 108.4만 장의 평면도 이미지를 수집하고, 2K장의 수동 주석 이미지로 검출 모델을 훈련하여 문, 창, 벽, 치수선을 식별합니다. 검출 박스를 중심선으로 변환하고 인접 끝점을 병합하여 벡터화 구조를 재구성합니다. OCR로 방 레이블과 치수를 추출하고 품질 필터링 후 31.4만 장의 검증 평면도를 얻습니다.
  • 표현 설계: 평면도를 이진 K-D 트리로 인코딩하며, 내부 노드는 분할 축과 좌표를 저장하고, 리프 노드는 공간 단위에 해당하며 방 의미를 할당합니다. 문, 창 등의 부속물은 JSON에서 별도로 표현됩니다. 다각형 좌표를 직접 예측하는 것보다 K-D 트리 출력 공간이 더 구조화되어 있으며, 결정론적으로 다각형 겹침과 빈 공간을 방지합니다.
  • 훈련: Qwen3-4B-Instruct를 사용하고 LoRA 지도 미세 조정, 데이터 분할 281K/15K/15K.

단계 2: 계층적 로밍 배치 (2D 승격 + 3D 앵커링)

  • 셸 인스턴스화: Blender에서 기본 조명과 재질을 갖춘 빈 무가구 셸을 생성하여 로밍의 명시적 3D 제약으로 사용합니다.
  • 전역 레이아웃(탑뷰): 탑뷰를 렌더링하고 문, 창, 문 인접 방을 주석 처리한 후, 이미지 인페인팅 모델(Gemini 3.0 Image Pro Preview)로 가구가 있는 탑뷰를 합성하고, SAM-3로 인스턴스 마스크와 2D 박스를 추출하며, VLM으로 개방 어휘 카테고리 인식을 수행합니다.
  • 세부 세분화(자아 중심 뷰): 히트맵 기반 시점 선택 전략으로 바닥을 그리드로 이산화하고, 가장 적게 관측된 영역을 덮는 시점을 탐욕적으로 선택합니다. 각 시점에 대해 자아 중심 이미지를 렌더링하고 인페인팅으로 보조 객체를 합성하며, SAM-3D로 3D 기하학을 재구성하고 기하학 정렬 모듈로 방에 통합합니다.
  • 로밍 순서: 먼저 탑뷰로 대형 기능 가구(침대, 소파)를 배치한 다음, 자아 중심 뷰로 소형 물품을 점진적으로 풍부하게 합니다.

단계 3: 재귀적 레이아웃 세분화 (VLM 순차 결정)

  • 세분화를 순차 결정 프로세스로 공식화: VLM 세분화기가 현재 레이아웃 상태를 관찰하고 구조화된 교정 동작(이동, 회전 또는 결합 변환)을 예측하며, 동작은 3D 경계 상자에 결정론적으로 적용되고, 재렌더링 후 검사하며, 검증 통과 또는 반복 제한에 도달할 때까지 루프합니다.
  • 미세 조정 데이터 구축: 손상된 레이아웃 구성(경계 위반, 충돌, 출입구 막힘 등 교란 주입), Oracle 교정 동작 레이블링(잔여 오류, 새로 도입된 위반, 이동 비용, 의미적 합리성 점수로 진실값 선택), 모델 인 더 루프 샘플(초기 세분화기 롤링, 중간 상태를 oracle로 재레이블링).

단계 4: 조작 가능한 객체 배치

  • 의미적 카테고리와 기하학적 속성(수평 표면 존재성과 충분한 사용 가능 면적)에 따라 소형 객체를 지지할 수 있는 가구를 식별합니다.
  • 각 가구에 대해 로컬 표면 캔버스를 구축하고 인페인팅 모델로 표면 수준 배열을 합성합니다.
  • PhysX-Anything으로 물리 속성(밀도, 영률, 푸아송 비)을 추론하고, 밀도와 메시 부피로 질량을 추정합니다.
  • VLM이 합성 표면 이미지를 조작 가능한 객체 집합(의미적 카테고리, 스케일, 상대 위치 및 방향)으로 파싱하고 전역 좌표계로 변환합니다.
  • 삽입 전 경량 물리 필터링: 지지 경계를 벗어나거나, 심각한 충돌, 부유, 또는 카테고리 수준 지지 제약을 위반하는 객체를 제거하고 명시적 지지 관계를 유지합니다.

핵심 혁신

  1. K-D 트리 평면도 표현: 평면도 생성을 자유 다각형 예측에서 구조화된 재귀 분할 예측으로 변환하여 위상 오류(겹침, 빈 공간, 비연결성)를 근본적으로 제거합니다. 이는 단순 제약이 아닌 출력 공간의 재구성으로, LLM 생성이 구조적으로 자연스럽게 유효하며 결정론적으로 기존 표현으로 변환 가능합니다.
  2. 계층적 로밍(Hierarchical Roaming): 먼저 탑뷰 전역 레이아웃, 그다음 자아 중심 뷰 세부 세분화를 수행하고 명시적 3D 셸 제약을 결합하여 순수 2D 승격 방법의 전체 주택 규모 기하학적 불일치 문제를 해결합니다. 이 설계는 2D 생성 사전과 3D 앵커링을 효과적으로 결합하여 직접 3D 학습의 데이터 병목을 피합니다.
  3. VLM 재귀 세분화기: 레이아웃 교정을 순차 결정 프로세스로 모델링하고, 손상된 레이아웃 구성 + Oracle 레이블링 + 모델 인 더 루프의 3단계 데이터 구축을 통해 VLM이 실행 가능한 3D 경계 상자 편집 동작을 출력하도록 훈련합니다. 이로써 세분화 프로세스가 일회성 생성이 아닌 검증 가능하고 반복 가능해집니다.

경계 및 한계

논문은 한계를 명시적으로 논의하지 않았지만, 사실적 요점에서 추론할 수 있습니다: 셸 텍스처 생성은 간단한 전략(3D-FRONT 자산 재사용 또는 2D 생성 모델 합성)을 채택하고 전용 재질 파이프라인을 도입하지 않았습니다. 조명은 규칙 기반 생성이며 학습 기반 방법이 아닙니다. 생성된 장면의 물리 시뮬레이션 검증 결과, 실제 세계 장면과의 일반화 테스트, 생성 시간/계산 비용의 구체적 수치, 사용자 연구의 상세 통계 결과는 언급되지 않았습니다. VLM 세분화기의 반복 제한 구체적 값, 시점 선택의 구체적 매개변수(그리드 해상도, 시야각, 안전 거리)도 언급되지 않았습니다. 조작 가능한 객체 수의 구체적 통계(표 1의 >15 제외)도 언급되지 않았습니다. 또한 LayoutGPT는 living room과 bedroom만 지원하므로 kitchen과 bathroom 비교에서 평가되지 않아 기준선 비교의 완전성에 영향을 미칠 수 있습니다.

공학적 시사점

HomeWorld를 재현하거나 채택할 때 다음 단계를 우선 확인하십시오: K-D 트리 표현의 올바른 구현은 평면도 생성 품질의 기초이며, 절제 연구는 정규 표현이 9.2% 겹침, 2.0% 빈 공간, 16.2% 비연결성을 초래하는 반면 K-D 트리는 비연결성을 12.3%로 낮추지만 여전히 0이 아니므로 리프 노드 의미 할당의 제약에 주의해야 합니다. VLM 세분화기의 데이터 구축은 가장 함정이 많은 부분입니다—손상된 레이아웃에 주입된 교란 유형과 크기는 oracle 레이블링 품질에 직접 영향을 미치므로, 논문의 경계 위반, 충돌, 출입구 막힘, 회전, 스케일, 카테고리 수준 오류의 6가지 교란 유형을 엄격히 따르고 중간 상태를 덮기 위해 모델 인 더 루프 샘플을 유지하는 것이 좋습니다. 계층적 로밍의 시점 선택은 최종 객체 밀도에 큰 영향을 미치며(제거 시 FOD가 4.16에서 2.6으로 하락), 히트맵 커버리지 전략의 그리드 해상도는 방 규모에 따라 조정해야 합니다. 조작 가능한 객체 배치는 PhysX-Anything의 물리 속성 추론에 의존하므로, 밀도와 메시 부피 추정의 정확성을 먼저 검증하는 것이 좋습니다. 그렇지 않으면 질량 추정 편차로 물리 필터링이 잘못 삭제할 수 있습니다. 마지막으로, 데이터셋 공개(300K 평면도 + 5K 장면)는 재현의 핵심 의존성이며, 확보할 수 없으면 31.4만 검증 평면도 하위 집합으로 LLM을 훈련할 수 있지만 분포 차이에 주의해야 합니다.
