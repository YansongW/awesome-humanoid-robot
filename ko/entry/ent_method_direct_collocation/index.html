요약

상태와 제어 입력을 배치점에서 이산화하고 결과 비선형 계획법을 직접 푸는 궤적 최적화 방법.

출처

  • Wiki extraction

개요

직접 배치법(Direct Collocation)은 궤적 최적화 방법으로, 핵심 아이디어는 일련의 배치점(collocation points)에서 시스템의 상태 변수와 제어 입력을 동시에 이산화하고, 연속 시간 최적 제어 문제를 직접 비선형 계획(Nonlinear Programming, NLP) 문제로 변환하여 푸는 것입니다. 이것이 실제로 바꾸는 것은 솔버의 선택이 아니라, "최적화"와 "동역학 시뮬레이션"이라는 두 개의 분리된 단계를 하나의 통합된 대수적 제약 시스템으로 병합하여, 고차원이고 강하게 결합된 로봇 운동 계획 문제를 풀 수 있게 만드는 것입니다.

핵심 내용

무엇인가: 직접 배치법의 정확한 정의

직접 배치법은 방법 유형에 속하며, 소속 분야는 AI 모델 및 알고리즘(07_ai_models_algorithms)이고, 가치 사슬 계층은 지능 계층입니다. 영어 명칭은 Direct Collocation이며, 한국어 명칭은 직접 배치법입니다.

수학적으로 직접 배치법은 연속 시간 최적 제어 문제:

\[ \min_{x(\cdot), u(\cdot)} \int_{t_0}^{t_f} L(x(t), u(t)) \, dt + \Phi(x(t_f)) \]
\[ \text{s.t.} \quad \dot{x}(t) = f(x(t), u(t)), \quad x(t_0) = x_0, \quad g(x(t), u(t)) \leq 0 \]

를 유한 차원의 NLP 문제로 이산화합니다. 구체적인 방법은 시간 축 \([t_0, t_f]\)을 \(N\)개의 구간으로 나누고, 구간 끝점(즉, 배치점)에서 상태 변수 \(x_k\)와 제어 변수 \(u_k\)(\(k = 0, 1, \ldots, N\))를 정의하는 것입니다. 그런 다음 배치점의 상태와 제어량을 사용하여 동역학 방정식을 근사합니다—가장 일반적인 것은 사다리꼴 법칙(trapezoidal rule) 또는 Hermite-Simpson 법칙을 사용하여 미분 방정식 제약을 대수 방정식으로 변환하는 것입니다. 최종적으로 전체 문제는 표준 NLP 문제가 되며, 성숙된 솔버(예: IPOPT, SNOPT)로 풀 수 있습니다.

왜 존재하는가: 문제점과 역사적 위치

직접 배치법이 등장하기 전에 궤적 최적화는 주로 두 가지 큰 흐름으로 나뉘었습니다:

  1. 간접법(Indirect Methods): 폰트랴긴 최소 원리(Pontryagin's Minimum Principle)에 기반하여, 해밀턴 시스템의 2점 경계값 문제(BVP)를 풀어 최적 궤적을 얻습니다. 이 방법은 수학적으로 우아하지만 초기 추측에 극도로 민감하고, 복잡한 수반 방정식(adjoint equations)을 유도해야 하며, 접촉 제약이 있는 휴머노이드 로봇 문제에는 거의 불가능합니다.

  2. 사격법(Shooting Methods): 제어량을 매개변수화한 다음, 동역학 방정식을 정방향 적분하여 목적 함수와 제약을 평가합니다. 단일 사격법(Single Shooting)은 초기 추측에 매우 민감하고, 장시간 적분은 수치적 불안정성을 초래합니다; 다중 사격법(Multiple Shooting)은 안정성을 개선하지만 여전히 동역학을 반복적으로 적분해야 합니다.

직접 배치법의 역사적 위치는 "적분"이라는 단계를 완전히 우회한다는 데 있습니다. 동역학 방정식을 배치점의 대수적 제약으로 변환함으로써, 정방향 적분이 더 이상 필요하지 않아 누적 오차와 초기 추측 민감성 문제를 피할 수 있습니다. 이로 인해 휴머노이드 로봇과 같은 고차원, 저구동, 강결합 시스템의 궤적 최적화에서 주류 선택이 되었습니다. 이것이 실제로 바꾸는 것은 해석 정밀도가 아니라 문제 구조입니다—동적 최적화 문제를 정적 최적화 문제로 바꾸어, 성숙된 NLP 솔버가 직접 개입할 수 있게 합니다.

원리 분해

① 배치와 이산화

시간 그리드를 \(t_0 < t_1 < \cdots < t_N = t_f\)로 설정하고, 각 노드 \(t_k\)에서 상태 \(x_k \approx x(t_k)\)와 제어 \(u_k \approx u(t_k)\)를 정의합니다. 결정 변수는 \(\mathbf{z} = [x_0, u_0, x_1, u_1, \ldots, x_N, u_N]\)입니다.

② 동역학 제약의 대수화

사다리꼴 법칙을 예로 들면, 동역학 제약 \(\dot{x} = f(x, u)\)는 다음과 같이 근사됩니다:

\[ x_{k+1} - x_k - \frac{h_k}{2} \left[ f(x_k, u_k) + f(x_{k+1}, u_{k+1}) \right] = 0 \]

여기서 \(h_k = t_{k+1} - t_k\)입니다. 이 제약은 인접한 두 배치점의 변수만 관련되므로, 야코비 행렬은 희소한 띠 구조를 가집니다—이것이 직접 배치법이 효율적으로 풀 수 있는 핵심입니다.

③ 목적 함수와 제약의 이산화

적분형 목적 함수는 수치 적분(예: 사다리꼴 법칙 또는 Simpson 법칙)으로 근사하고, 경로 제약(예: 관절 토크 한계, 마찰 원뿔 제약)은 배치점에서만 적용하면 됩니다. 경계 조건(예: 초기 상태, 최종 상태)은 NLP에 등식 제약으로 직접 추가됩니다.

④ 해법

얻어진 NLP 문제는 희소 NLP 솔버(예: IPOPT)로 풉니다. 솔버는 제약 야코비 행렬의 희소성을 활용하여 내점법 또는 순차 2차 계획법(SQP)으로 반복 해법을 수행합니다. 동역학을 적분할 필요가 없으므로 각 반복의 비용은 사격법보다 훨씬 낮습니다.

주요 매개변수와 사양

매개변수 일반값/범위 설명

배치 법칙 사다리꼴 법칙 / Hermite-Simpson Hermite-Simpson이 더 높은 정밀도(3차 vs 2차)를 제공하지만 변수가 더 많음

수렴 허용 오차 \(10^{-6}\)–\(10^{-4}\) (직접 확인 필요) 특정 솔버 설정에 따라 다름

수평 비교

방법 이산화 대상 동역학 처리 방식 초기 추측 민감성 적용 시나리오
단일 사격법 제어량만 정방향 적분 매우 높음 단순 시스템, 짧은 시간 영역
다중 사격법 제어량+노드 상태 구간 적분+연속성 제약 중간 중간 복잡도 시스템
직접 배치법 상태+제어량 대수적 제약(적분 없음) 낮음 고차원, 강제약 시스템(휴머노이드 로봇)
간접법 상태+공동 상태 BVP 해법 매우 높음 이론 분석, 단순 시스템

직접 배치법의 핵심 장점은 초기 추측에 둔감하고 제약 처리 능력이 강하다는 것이며, 대가는 NLP 규모가 크다는 것입니다. 그러나 휴머노이드 로봇과 같은 시스템에서는 이 대가를 치를 가치가 있습니다.

누가 사용하는가·응용 사례

직접 배치법은 휴머노이드 로봇 분야에서 널리 응용되며, 대표적인 시나리오는 다음과 같습니다:

  • 전신 운동 계획: 이족 보행, 점프, 달리기 등의 전신 동적 운동을 계획합니다. 접촉 시퀀스(예: 발 착지/이지)를 명시적으로 제약으로 모델링함으로써, 직접 배치법은 물리적으로 일관된 전신 궤적을 생성할 수 있습니다.
  • 다중 접촉 조작: 손-발-몸통이 협력하는 다중 접촉 조작 작업(예: 사다리 오르기, 무거운 물건 운반)을 계획합니다. 접촉력을 결정 변수로 직접 최적화에 포함하여 마찰 원뿔 제약을 충족합니다.
  • 공동 설계 최적화: 기계 설계 단계에서 궤적 최적화와 구조 매개변수(예: 링크 길이, 액추에이터 매개변수)를 공동 최적화합니다. 예를 들어, 이웃 카드 ent_paper_a_co_design_framework_for_high_2026에서 언급된 2단계 최적화 프레임워크는 첫 번째 단계에서 액추에이터 최적화를 통해 속도비와 질량, 효율의 매핑을 구축하고, 두 번째 단계에서 CMA-ES로 기계 설계와 제어 매개변수를 공동 최적화합니다—직접 배치법은 궤적 평가의 핵심 도구로 사용될 수 있습니다.
  • 모델 예측 제어(MPC)와 결합: 직접 배치법은 MPC의 하위 솔버로 사용되어 온라인 재계획에 활용될 수 있습니다. 계산량이 크지만 warm-start와 희소 솔버를 통해 비교적 짧은 주기 내에 해법을 완료할 수 있습니다.

한계와 경계

  1. 계산 복잡도가 높음: NLP 규모는 상태 차원, 제어 차원, 시간 그리드 수에 따라 빠르게 증가합니다. 고자유도 휴머노이드 로봇(예: 30+ DOF)의 경우, 전차원 직접 배치법의 해법 시간이 수 초에서 수 분에 이를 수 있어 실시간 제어 요구를 충족하기 어렵습니다(구체적인 수치는 직접 확인 필요).
  2. 모델 정밀도에 대한 의존도가 강함: 직접 배치법은 정확한 동역학 모델이 필요합니다. 모델 오차는 생성된 궤적이 실제 플랫폼에서 실행 불가능하게 만들 수 있습니다.
  3. 국소 최적 문제: NLP 솔버는 국소 최적 해만 보장할 수 있습니다. 비볼록 문제(예: 접촉 마찰 원뿔 제약 포함)의 경우, 초기 추측의 품질이 해의 품질에 큰 영향을 미칩니다.
  4. 접촉 시퀀스를 사전에 지정해야 함: 표준 직접 배치법은 접촉 시퀀스(언제 어디서 발이 착지하는지)를 사전에 지정해야 합니다. 접촉 시퀀스 자체가 최적화 변수인 경우 문제는 더욱 복잡해집니다(이웃 카드 ent_paper_contact_planning_implicit_optimization_core_papers의 암시적 접촉 최적화 방법 참조).

일반적인 오해

  1. "직접 배치법은 다중 사격법이다"—틀림. 다중 사격법은 동역학을 구간별로 적분해야 하지만, 직접 배치법은 적분이 전혀 필요 없으며 동역학이 대수적 제약으로 변환됩니다. 이것은 본질적인 차이입니다.
  2. "배치점이 많을수록 좋다"—완전히 맞지는 않음. 그리드가 너무 조밀하면 NLP 규모가 급격히 증가하고 수치적 병리 현상이 발생할 수 있습니다. 실제로는 적응형 그리드 세분화(mesh refinement) 전략을 사용하여 필요한 곳에만 그리드를 조밀하게 만듭니다.
  3. "직접 배치법은 오프라인에서만 사용할 수 있다"—완전히 맞지는 않음. 전통적으로 오프라인 계획에 사용되지만, warm-start, 실시간 반복(real-time iteration) 등의 기술을 통해 온라인 MPC에도 사용할 수 있습니다. 핵심은 계산 하드웨어의 성능이 충분한지 여부입니다.
  4. "동역학 제약에 사다리꼴 법칙이면 충분하다"—정밀도 요구가 높은 시나리오(예: 고속 동적 운동)에서는 사다리꼴 법칙의 2차 정밀도가 부족할 수 있으므로, Hermite-Simpson 법칙(3차 정밀도) 또는 더 높은 차수의 배치법을 사용해야 합니다.
