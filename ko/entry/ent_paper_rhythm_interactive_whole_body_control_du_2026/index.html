요약

Realizing interactive whole-body control for multi-humanoid systems is critical for unlocking complex collaborative capabilities in shared environments. Institutions per source list: 上海交通大学、香港中文大学（深圳）等.

출처

개요

Rhythm은 최초로 이족 보행 휴머노이드 로봇 간 실제 세계 물리적 상호작용 배치를 구현한 통합 프레임워크로, IAMR(상호작용 인식 운동 재타겟팅), IGRL(상호작용 유도 강화 학습), 실제 세계 배치 모듈의 세 부분으로 구성됩니다. 핵심 기여는 자체 운동과 상호작용 기하학을 분리하는 최적화 전략을 통해 운동학적 충돌을 해결하고, 그래프 기반 보상과 커리큘럼 기반 훈련을 통해 시뮬레이션에서 Unitree G1 하드웨어로의 견고한 전이를 달성하는 데 있습니다.

무엇을 바꾸었는가

이족 보행 휴머노이드 로봇 간 상호작용 연구는 오랫동안 시뮬레이션 단계에 머물러 있었습니다. 핵심 장애물은 단일 알고리즘의 결함이 아니라 전체 프로세스에서 간과된 두 가지 결합 문제, 즉 재타겟팅 단계의 자체 운동 충실도와 상호작용 기하학 정밀성 사이의 근본적 모순, 그리고 훈련 단계에서 에이전트를 고립된 개체로 간주하여 결합 역학 모델링이 부재한 문제입니다. PAIR, Harmanoid와 같은 기존 방법은 결합 공식을 채택하여 운동학적 충돌 시 상호작용 제약을 엄격히 충족시키기 위해 자연스러운 자세를 희생하는 경우가 많으며, 이는 실제 배치에서 사용할 수 없는 왜곡된 동작을 생성합니다.

Rhythm이 실제로 바꾼 것은 '상호작용'을 사후 제약에서 사전 지식으로 승격시킨 것입니다. 더 이상 두 에이전트를 두 개의 독립된 개체나 하나의 통합 메시(mesh)로 간주하지 않고, 위상 분할을 통해 에이전트 내부 엣지(자체 운동)와 에이전트 간 엣지(상호작용 기하학)를 명시적으로 구분하고, 이를 기반으로 분리된 최적화 목표와 보상 함수를 설계합니다. 이러한 관점 전환은 재타겟팅 결과가 개별 운동 스타일을 유지하면서 상호작용 기하학을 정밀하게 유지하도록 하며, 강화 학습 정책이 암시적으로 추측하는 대신 결합 역학을 명시적으로 학습할 수 있게 하여, 결국 이족 보행 상호작용을 시뮬레이션에서 실제 하드웨어로 이끌었습니다.

방법 분해

IAMR: 상호작용 인식 운동 재타겟팅

  • 이중 다양체 참조 구축: 원본 3D 키포인트 시퀀스를 개별 다양체 M_ind(개별 신체 비율에 따라 스케일링)와 통합 다양체 M_uni(전역 평균 스케일링)에 각각 매핑합니다. 전자는 운동학적 실행 가능성을 보장하고, 후자는 상호작용 기하학 일관성을 유지합니다.
  • 위상 분할 및 분리 최적화: 상호작용 메시 엣지를 에이전트 내부 엣지 E_self와 에이전트 간 엣지 E_inter로 분할하고, 혼합 에너지 q* = argmin_q (E_self(q) + E_inter(q))를 최소화하며, 제약 조건 q ∈ C_phy(관절 한계, 충돌 회피, 발바닥 제로 속도)를 적용합니다.
  • 가변 강성 상호작용 제약: E_inter는 거리 의존 스프링 포텐셜 에너지를 채택하며, 강성 ω_ij = ω_max · e^(-γ d_ij)로 근거리에서는 더 단단해져 관통을 방지하고, 원거리에서는 유연하여 자유로운 운동을 허용하며, 경직된 제약으로 인한 자세 왜곡을 피합니다.
  • 최적화 구현: 프레임별 SQP, 가중치 w_self=2.0, w_inter=10.0, w_reg=0.1, λ_rot=0.1, CVXPY/OSQP 솔버 사용.

IGRL: 상호작용 유도 강화 학습

  • 다중 에이전트 MDP 및 CTDE: MAPPO 알고리즘을 채택하며, 관측 공간에는 고유 감각 o_prop, 동료 인식 o_peer(상대 자세 P_rel = R_ego^T(P_peer - P_ego) 포함), 참조 운동 o_ref가 포함됩니다.
  • 계층적 정책 네트워크: 이중 1D-CNN 시간 인코더(Conv1d(60→40, k=6, s=2) + Conv1d(40→20, k=4, s=2))가 과거 및 미래 창을 처리하고, 출력 임베딩을 현재 관측과 연결한 후 MLP [512, 256, 128]을 통해 동작을 디코딩합니다.
  • 그래프 기반 보상: 상호작용 그래프 보상 r_inter = exp(-(1/σ_inter) Σ ω_ij ||d_ij^sim - d_ij^ref||²)은 IAMR의 거리 인식 동적 가중치를 계승합니다. 접촉 그래프 보상에는 활성/비활성 접촉 일관성 및 힘 정규화가 포함됩니다.
  • 커리큘럼 기반 적응형 샘플링: 다중 목표 오류 벡터 [e_fail, e_track, e_inter] 기반의 평활 샘플링으로, 커리큘럼 가중치는 안정 단계 [0.8, 0.1, 0.1]에서 정밀 단계 [0.05, 0.30, 0.65]로 전환됩니다(L̄_max 350/500 임계값 기준).
  • 이중 에이전트 도메인 무작위화: 동료 관측에 20-60ms 무작위 지연을 적용하여 무선 통신을 시뮬레이션하고, 초기 상태에 ±5cm/±0.2rad 섭동을 적용하여 복구 동작 학습을 강제합니다.

실제 세계 배치

  • 계층적 위치 추정: POINT-LIO가 10Hz 고주파 오도메트리를 제공하고, GICP 전역 정합이 드리프트를 보정하며, 칼만 필터 융합이 드리프트 없는 전역 자세를 출력합니다.
  • 비동기 동기화 메커니즘: LCM을 통해 전역 자세를 브로드캐스트하고, 운동 위상 φ를 연속 동기화 변수로 사용하며, φ_dot_ego = 1.0 + k(φ_peer - φ_ego)로 클록 드리프트를 보상합니다.
  • 제어 아키텍처: 고수준 정책이 50Hz로 목표 관절 위치를 출력하고, 저수준 PD 컨트롤러가 500Hz로 실행하며, ONNX Runtime 추론 지연 시간은 <3ms입니다.

핵심 혁신

  1. 분리형 재타겟팅 최적화: 상호작용 기하학과 자체 운동 충실도를 처음으로 조정 가능한 가중치의 최적화 목표로 명시적으로 분리하고, 가변 강성 스프링 포텐셜 에너지를 통해 '근거리 경직, 원거리 유연'의 상호작용 제약을 구현하여, 기존 방법이 운동학적 충돌 시 자연스러운 자세를 희생하는 결함을 피했습니다. 이 설계는 Inter-X 데이터셋(현저한 인체 측정 불일치)에서 F1-Strict가 강력한 기준선 DOR보다 43% 향상되도록 합니다.

  2. 위상 사전 지식 기반 보상 설계: IAMR이 추출한 상호작용 그래프와 접촉 그래프를 직접 강화 학습 보상으로 변환하여, 정책이 암시적으로 추측하는 대신 결합 역학을 명시적으로 학습하도록 합니다. 상호작용 그래프 보상의 거리 인식 동적 가중치는 근거리 정밀 접촉과 원거리 자유 운동의 차별화된 학습을 보장하고, 접촉 그래프 보상의 힘 정규화는 물리적 합리성을 제약합니다.

  3. 실제 배치를 위한 견고한 훈련 전략: 커리큘럼 기반 적응형 샘플링이 '생존 우선'에서 '상호작용 정밀도 우선'으로 점진적으로 전환되고, 이중 에이전트 도메인 무작위화(통신 지연, 초기 섭동)와 결합하여, 정책이 실제 하드웨어에서 비동기 관측과 물리적 불일치에 직면했을 때도 상호작용 위상을 능동적으로 복구할 수 있게 합니다. 실제 실험에서 Rhythm은 Single Agent 기준선보다 60% 이상 향상되었습니다.

Rhythm은 실제 하드웨어에서 모든 작업 성공률이 80%를 초과하며, Single Agent 기준선보다 60% 이상 향상되었고, Greeting 작업에서 가장 큰 차이를 보였습니다(82.2% vs 12.2%). 견고성 테스트에서 밀기, 당기기, 발차기 등의 외부 섭동에 직면했을 때, 에이전트는 균형을 성공적으로 회복하고 상대 상태를 능동적으로 조정했습니다.

경계 및 한계

논문은 한계를 명시적으로 논의하지 않았지만, 방법 세부 사항에서 경계를 추론할 수 있습니다. 현재 상태 추정은 사전 구축된 지도에 의존하며, 저자는 이를 제한 사항으로 인정하고 향후 이 의존성을 제거할 계획입니다. 논문은 두 개 이상의 에이전트로의 확장, 비휴머노이드 상호작용 형태를 다루지 않았으며, 훈련 시간, 계산 자원 소비 및 실패 사례에 대한 상세 분석도 보고하지 않았습니다. 실제 실험은 Unitree G1 플랫폼에서만 검증되었으며, 다른 하드웨어 형태는 테스트되지 않았습니다. 커리큘럼 샘플링의 임계값(350/500)은 특정 작업 분포에 의존할 수 있으며, 다른 상호작용 범주로 전이할 때는 재조정이 필요합니다.

공학적 시사점

Rhythm을 재현할 때, IAMR의 가중치 설정(w_self=2.0, w_inter=10.0)을 우선적으로 확인하십시오. 이는 자체 운동 충실도와 상호작용 정밀도 사이의 균형을 직접 결정하며, Inter-X에서의 43% F1 향상이 바로 여기서 비롯됩니다. 강화 학습 훈련에서 가장 함정에 빠지기 쉬운 부분은 커리큘럼 샘플링의 임계값 전환으로, L̄_max의 350/500 임계값은 에피소드 길이 정의와 강하게 연관되어 있으므로 논문과 일치하는지 확인해야 합니다. 이중 에이전트 도메인 무작위화의 통신 지연(20-60ms)과 초기 섭동(±5cm/±0.2rad)은 Sim-to-Real 성공의 핵심이므로 생략할 수 없습니다. 실제 배치 시, LCM 통신의 위상 동기화 이득 k는 실제 클록 드리프트율에 따라 조정해야 하며, 오프라인 동기화 테스트를 먼저 수행할 것을 권장합니다. 상태 추정의 칼만 필터 융합 주파수(POINT-LIO 10Hz + GICP 저주파)는 50Hz 정책 제어 루프와 일치해야 하며, 그렇지 않으면 자세 점프가 발생할 수 있습니다.
