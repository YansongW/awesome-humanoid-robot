요약

휴로봇의 모든 관절과 접촉점을 조율하여 균형·시선·조작 등 다중 작업을 동시에 수행하는 제어 프레임워크.

출처

  • Wiki extraction

개요

전신 제어(Whole-Body Control, WBC)는 휴머노이드 로봇의 모든 관절과 접촉점을 하나의 최적화 문제에 통합하여 일괄적으로 푸는 제어 프레임워크입니다: 부유 기반 동역학, 마찰 원뿔, 관절 토크 제한 등의 하드 제약 조건을 충족시키는 전제 하에, 균형, 족착점 추적, 팔 조작 등 여러 작업을 우선순위에 따라 동시에 성립시킵니다. 이것은 현대 고동역학 휴머노이드 로봇의 "소뇌" 표준 형태입니다——고전적 구현은 2차 계획법(QP) 기반 전신 제어로, 50–200 Hz의 제어 외부 루프에서 실행됩니다(출처: 프로젝트 Wiki 8장 §8.4.10, 제어 루프 계층화).

핵심 내용

무엇인가: 정확한 정의

WBC의 정확한 정의는 세 가지 층위를 포함합니다:

  1. 작업 계층의 통일된 표현: 각 제어 목표(질량 중심 위치, 발끝 궤적, 손끝 자세, 자세……)는 작업 공간의 기대 가속도 또는 기대 힘으로 표현됩니다;
  2. 전신 결합 해석: 관절별 독립 제어가 아니라, 전신 일반화 좌표(부유 기반 6자유도 + 전체 관절)에서 가속도, 관절 토크, 접촉력을 한 번에 해석합니다;
  3. 제약 조건의 명시적 처리: 동역학 방정식, 마찰 원뿔, 토크 제한, 관절 한계가 최적화 제약 조건으로 나타나며, 사후 포화 절단이 아닙니다.

"30개 관절에 각각 PID를 하나씩 배치"하는 것과의 본질적 차이: 휴머노이드 로봇은 저구동(underactuated) 시스템입니다——부유 기반에는 액추에이터가 없고, 균형은 지면 접촉력을 통해서만 간접적으로 실현되며, 접촉력은 다시 전신 관절 토크에 의해 공동 결정됩니다. 전신 결합 항을 분리하지 않으면 동적 균형을 논할 수 없습니다.

왜 존재하는가: 문제점과 역사적 위치

휴머노이드 로봇이 동시에 수행해야 하는 작업은 자연적으로 충돌합니다: 팔을 앞으로 뻗는 조작은 질량 중심을 앞으로 끌어당겨 균형을 깨뜨립니다; 보폭 순간 단일 지지상의 제어 가능 자유도가 급감합니다. 초기 휴머노이드 로봇(예: Honda ASIMO 1세대)은 사전 계산 보행 패턴 + 온라인 안정화 장치로 이 문제를 우회했습니다——동작 라이브러리를 오프라인으로 계획하고, 온라인에서는 작은 수정만 수행하며, 대가는 동작이 경직되고 예기치 않은 접촉에 대응할 수 없다는 점입니다.

학술적 흐름은 두 갈래로 합류합니다: 하나는 Khatib가 1987년에 제안한 운영 공간 제어(Operational Space Formulation)로, 힘 제어를 관절 공간에서 작업 공간으로 옮겼습니다; 다른 하나는 Sentis와 Khatib가 2000년대 중반에 발전시킨 전신 작업 우선순위 프레임워크로, 영공간 투영을 사용하여 낮은 우선순위 작업이 높은 우선순위 작업을 방해하지 않도록 합니다. 실시간 QP 솔버가 성숙해짐에 따라, 두 흐름은 오늘날의 표준 형태인 전신 QP 제어로 합쳐졌습니다(Herzog 등 2016년 전후의 구조화된 접촉 힘 최적화 작업이 대표적). WBC가 실제로 바꾼 것은 특정 제어 법칙이 아니라 문제의 조직 방식입니다: "수십 개의 제어기가 어떻게 충돌하지 않는가"라는 공학적 악몽을, 매 밀리초마다 한 번씩 해석되는 볼록 최적화 문제로 바꾼 것입니다.

원리 분해

① 작업 공간 역동역학(TSID)——WBC의 가장 기본 형태

주어진 작업 기대 가속도 \(\ddot{\mathbf{x}}_i^*\)를 작업 야코비안을 통해 전신 일반화 가속도로 매핑합니다(출처: 프로젝트 Wiki 8장 §8.4.10.1):

\[ \ddot{\mathbf{x}}_i = \mathbf{J}_i \dot{\mathbf{v}} + \dot{\mathbf{J}}_i \mathbf{v} \]

여기서 \(\mathbf{v}\)는 부유 기반을 포함한 일반화 속도입니다. 그런 다음 부유 기반 동역학 방정식에서 관절 토크와 접촉력을 역산합니다.

② 운영 공간 제어(OSC)와 영공간 투영

작업 힘은 야코비안 전치를 통해 관절 토크로 매핑되고, 낮은 우선순위 작업은 높은 우선순위 작업의 영공간에 투영되어 실행됩니다(출처: 프로젝트 Wiki 8장 §8.4.10.1):

\[ \boldsymbol{\tau} = \sum_i \mathbf{J}_i^T \mathbf{F}_i^* + \mathbf{N}^T \boldsymbol{\tau}_0 \]

엄격한 계층 구조에서, 하위 작업 속도 수정은 \(\mathbf{N}_1 \mathbf{J}_2^\dagger(\dot{\mathbf{x}}_2^* - \mathbf{J}_2\mathbf{J}_1^\dagger\dot{\mathbf{x}}_1^*)\)로 표현됩니다——의미는 직관적입니다: 먼저 균형을 보장하고, 그런 다음 "균형에 영향을 주지 않는 관절 운동 부분"을 사용하여 조작을 완료합니다.

③ 전신 QP——현대 주류 구현

위의 모든 것을 2차 계획법으로 작성합니다(출처: 프로젝트 Wiki 8장 §8.4.10.3):

\[ \min_{\dot{\mathbf{v}}, \boldsymbol{\tau}, \mathbf{F}_c} \quad \sum_i w_i \left\| \mathbf{J}_i \dot{\mathbf{v}} + \dot{\mathbf{J}}_i \mathbf{v} - \ddot{\mathbf{x}}_i^* \right\|^2 + w_{\tau}\|\boldsymbol{\tau}\|^2 + w_{f}\|\mathbf{F}_c\|^2 \]

제약 조건: 부유 기반 동역학 등식 \(\mathbf{M}\dot{\mathbf{v}} + \mathbf{C}\mathbf{v} + \mathbf{g} = \mathbf{S}^T\boldsymbol{\tau} + \sum_c \mathbf{J}_{c}^T \mathbf{F}_c\); 마찰 원뿔 \(\mathbf{F}_c \in \mathcal{C}(\mu)\); 관절 토크 제한 \(\boldsymbol{\tau}_{\min} \le \boldsymbol{\tau} \le \boldsymbol{\tau}_{\max}\); 관절 한계. 가중치 \(w_i\)는 작업 우선순위를 표현합니다(극단적 가중치 차이는 엄격한 계층 구조를 근사할 수 있음).

④ 질량 중심 운동량 작업

위치/가속도 작업 외에도, WBC는 종종 질량 중심 각운동량을 명시적으로 추적하여 동적 균형과 상체 협응에 사용합니다(출처: 프로젝트 Wiki 8장 §8.4.10).

⑤ 제어 스택에서의 위치

전형적인 계층 구조: 최외곽 루프 작업 계획/WBC/QP(50–200 Hz)가 기대 궤적과 접촉 힘 분배를 생성하고, 아래로 임피던스/어드미턴스 제어기에 전달하며, 최내곽 루프는 관절 전류 루프(kHz 수준)입니다(출처: 프로젝트 Wiki 8장 제어 루프 계층화). QP 솔버는 OSQP, qpOASES, ProxQP가 일반적으로 사용됩니다.

누가 사용하는가 / 적용 사례

  • 학술 및 오픈소스: TSID(stack-of-tasks 유지)는 Pinocchio 기반 최적화 역동역학 제어 라이브러리를 제공하며, 휴머노이드와 사족 Python 예제가 포함되어 있어 WBC 재현의 일반적인 시작점입니다(출처: TSID GitHub README);
  • 고동역학 보행 플랫폼: ANYmal, MIT Cheetah 3 등 플랫폼의 공개 문헌에 있는 힘 제어 프레임워크는 모두 QP 형태로 전신 작업을 구성합니다(Stephens & Atkeson 2010의 "동적 균형 힘 제어"는 이 접근 방식의 초기 대표 사례, 참고 문헌 참조);
  • 학습형 제어와의 역할 분담: 최근 휴머노이드 로봇(예: Unitree H1/H1-2의 오픈소스 전신 정책 JAEGER, ent_paper_jaeger_dual_level_humanoid_who_2025)은 전신 협응을 RL 정책에 맡기고, 하위 계층은 여전히 PD/토크 인터페이스를 사용합니다——이는 커뮤니티에서 고전적 WBC에 대한 도전이자 보완으로 간주되며, 대체는 아닙니다(JAEGER 카드는 관절 각도 추적 오차가 다른 오픈소스 방법의 30–60%임을 보여줍니다).

한계와 경계

  • 모델 의존성: QP의 동역학 행렬은 강체 모델에서 비롯되며, 매개변수 오차는 직접 접촉 힘 분배 오류가 됩니다; 시스템 식별과의 연계는 공학적 필수 요구 사항입니다;
  • 접촉 로직은 QP 외부에 있음: 접촉의 설정/해제 시점(접촉 시퀀스 계획)은 QP가 결정하지 않으며, 상위 상태 머신이나 MPC가 필요합니다;
  • 가중치 튜닝: 가중 합으로 구현된 우선순위는 가중치로 표현되며, "가중치 튜닝"은 여전히 휴머노이드 제어 엔지니어의 일상적 고통입니다;
  • 단일 단계, 선제적 예측 없음: WBC 자체는 미래를 보지 않으며, 넘어짐 위험의 선제적 회피는 MPC/계획 계층의 책임입니다;
  • 연산량과 실시간성: 전신 QP를 임베디드 플랫폼에서 200 Hz로 실행하려면 정교한 최적화(솔버 핫 스타트, 제약 조건 축소)가 필요합니다.

일반적인 오해

  1. "WBC는 MPC다"——WBC는 예측 시간 영역이 없는 단일 단계 최적화입니다; MPC는 이동 시간 영역이 있습니다. 둘은 종종 직렬로 연결되며 동일하지 않습니다.
  2. "우선순위는 가중치로 충분하다"——가중 합은 작업 간 상호 절충을 허용하며, 안전 관련 작업(예: 넘어지지 않기)은 일반적으로 엄격한 계층 구조나 하드 제약 조건이 필요합니다.
  3. "WBC는 관절 위치 명령을 출력한다"——고전적 WBC가 출력하는 것은 관절 토크(및 가속도/접촉력)이며, 위치형 로봇은 별도의 역동역학 또는 임피던스 계층 변환이 필요합니다.
  4. "RL 정책이 있으면 WBC가 필요 없다"——JAEGER 등의 작업은 RL이 전신 협응을 인계받을 수 있음을 증명하지만, 하위 실행 인터페이스와 안전 제약 백업은 여전히 WBC의 개념과 구조를 많이 차용합니다.
  5. "QP는 빠를수록 좋고, 주파수에 상한이 없다"——외부 루프 50–200 Hz는 오랜 공학적 균형의 결과입니다; 무분별한 주파수 증가는 모델 오차와 노이즈의 영향을 증폭시킬 뿐입니다(공학적 판단).
