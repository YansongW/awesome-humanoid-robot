Diversity is All You Need: Learning Skills without a Reward Function

Diversity is All You Need: Learning Skills without a Reward Function

영역
AI 모델 및 알고리즘
계층
지능 계층
검증
초안

요약

Intelligent creatures can explore their environments and learn useful skills without supervision. In this paper, we propose DIAYN ('Diversity is All You Need'), a method for learning useful skills without a reward function.

출처

  • arXiv:1802.06070 Diversity is All You Need: Learning Skills without a Reward Function
  • Project page
  • 智元、众擎都在卷的人形机器人运控基座：41篇论文看懂BFM

개요

DIAYN(Diversity is All You Need)은 Ben Eysenbach 등이 제안한 보상 없는 기술 학습 방법으로, 상호 정보와 정책 엔트로피의 결합 목표를 최대화하여 에이전트가 자율적으로 다양하고 구분 가능한 행동 기술을 창발하게 합니다. 이 방법은 여러 연속 제어 벤치마크에서 작업 보상 없이도 작업을 해결하는 방법을 학습할 수 있으며, 계층적 강화학습, 모방 학습의 효과적인 기본 요소로 활용될 수 있습니다.

무엇을 바꾸었는가

이 논문이 진정으로 바꾼 것은 '기술 발견' 문제의 정의 방식입니다. 이전의 비지도 기술 학습(예: VIC)은 적대적 훈련이나 기술 사전 분포 학습에 의존하여 훈련이 불안정하거나 기술이 소수로 붕괴되는 문제가 있었습니다. DIAYN은 이 문제를 협력 게임으로 재정식화했습니다: 고정된 균일 기술 사전 분포, 최대 엔트로피 정책으로 탐험 보장, 판별기로 구분 가능성 보상 제공. 이 전환은 단순해 보이지만 훈련 역학을 완전히 바꾸었습니다—적대적 안장점 문제에서 볼록 최적화에 친화적인 목표로 바뀌어, 기술 다양성이 우연한 창발이 아닌 안정적으로 최적화 가능한 결과가 되었습니다.

더 중요하게, 저자들은 '구분 가능함'이 '다양함'과 같지 않음을 증명했습니다. 두 기술은 상태에서 아주 작은 차이만 있어도 구분 가능하지만, 반드시 의미론적으로 유의미한 것은 아닙니다. DIAYN은 최대 엔트로피 항을 통해 기술이 구분 가능성을 유지하려면 다른 기술의 상태 공간 영역에서 멀리 떨어진 곳을 탐험해야 하도록 강제하여, '구분 가능함'과 '다양함' 사이에 인과적 연결을 구축했습니다. 이 통찰은 목표 함수 설계를 직접적으로 안내했으며, 이후 모든 실험 결과의 기반이 되었습니다.

방법 분해

목표 함수

ℱ(θ) = I(S;Z) + ℋ[A|S] − I(A;Z|S)를 최대화합니다. 여기서: - I(S;Z): 상태와 기술 간의 상호 정보로, 서로 다른 기술이 서로 다른 상태를 방문하도록 장려 - ℋ[A|S]: 정책 엔트로피로, 탐험을 장려 - −I(A;Z|S): 상태가 주어졌을 때 행동과 기술 간의 조건부 상호 정보로, 기술이 행동만으로 구분되는 것을 방지

변분 하한

판별기 q_φ(z|s)로 사후 확률 p(z|s)를 근사하여 최적화 가능한 하한을 얻습니다: 𝒢(θ,φ) = ℋ[A|S,Z] + 𝔼[log q_φ(z|s) − log p(z)]

의사 보상 설계

r_z(s,a) = log q_φ(z|s) − log p(z) - log p(z)를 빼는 데는 두 가지 역할이 있습니다: 기술이 흡수 상태에서 허위 보상을 얻는 것을 방지; 보상이 음수가 되지 않도록 보장(q_φ ≥ p(z)일 때) - 빠른 종료를 원하는 환경(예: mountain car)에서는 이 기준선을 제거할 수 있음

알고리즘 흐름

  1. 기술 z ∼ p(z) 샘플링(균일 범주 분포)
  2. SAC로 조건부 정책 π_θ(a|s,z) 학습, 의사 보상 최대화
  3. 판별기 q_φ(z|s)는 SGD로 업데이트, 방문한 상태에서 기술 추론
  4. 엔트로피 정규화 계수 α=0.1(경험적 선택)

핵심 설계 결정

  • p(z)를 학습하지 않고 고정: p(z)를 학습하면 '마태 효과'가 발생—다양한 기술이 더 자주 샘플링되어 더 많은 훈련 신호를 받고, 결국 유효 기술 수가 약 10배 감소
  • 판별기가 최종 상태만이 아닌 각 상태를 확인: 더 조밀한 보상 신호 제공
  • 최대 엔트로피 정책 사용: 기술이 다른 기술의 상태 공간에서 멀리 떨어진 곳을 탐험하도록 강제. 그렇지 않으면 무작위 행동으로 구분 불가능한 상태에 진입
  • 네트워크 용량: Q 함수, 가치 함수, 정책 모두 300개의 은닉 유닛 사용(SAC 기본값 128 대신). 저자들은 이것이 여러 기술을 학습하는 데 필요하다고 발견

핵심 혁신

  1. 기술 발견을 협력 게임으로 전환: VIC의 적대적 훈련과 달리, DIAYN의 판별기와 정책은 협력 관계입니다(판별기는 정책이 보상을 얻도록 돕는 역할이지 적대하는 것이 아님). 이는 적대적 안장점의 불안정성을 피하고 훈련이 무작위 시드에 강건하도록 만듭니다(그림 13 검증).

  2. 고정 기술 사전 분포의 통찰: 저자들은 이론적 분석(부록 E)과 실험을 통해 p(z) 학습이 기술 붕괴를 초래함을 증명했습니다. 고정 균일 사전 분포는 단순해 보이지만 '마태 효과'를 방지하는 핵심 설계이며, 이 발견은 이후 비지도 RL 연구에 직접적인 지침을 제공합니다.

  3. 구분 가능성과 다양성의 분리: 최대 엔트로피 항을 통해 DIAYN은 이론적으로(부록 B 그리드 월드 분석) 그리고 실험적으로(그림 2, 그림 12) 구분 가능한 기술이 필연적으로 다양해지는 경향이 있음을 증명했습니다. 이 인과 사슬은 이전 방법들이 명확히 확립하지 못한 것입니다.

실험 및 결과

실험 설정 핵심 결과
2D 내비게이션 6개 기술 기술이 서로 멀어지는 방향으로 이동, 상태 공간 커버
고전 제어 InvertedPendulum, MountainCar 보상 없이 작업 해결 학습, 여러 다른 해법 학습
연속 제어 HalfCheetah, Hopper, Ant 달리기, 점프, 공중제비 등 다양한 기술 창발
정책 초기화 5개 벤치마크 작업, 5개 무작위 시드 비지도 사전 훈련으로 모든 작업 학습 가속
계층적 RL(2D 내비게이션) 25개 목표, 5개 시드 DIAYN이 VIME보다 현저히 우수(VIME 최고 시드도 DIAYN보다 낮음)
계층적 RL(Cheetah 허들/Ant 내비게이션) 희소 보상 DIAYN이 TRPO, SAC, VIME보다 우수
모방 학습 600개 작업 DIAYN이 최저 궤적 L2 거리 달성, "low entropy", "few skills", "learn p(z)" 기준선보다 우수
탐험 평가 3개 보상 함수 DIAYN은 각 작업 유형에 대해 우수한 성능의 기술 보유; VIME의 단일 정책은 모든 작업에서 성능 저조

핵심 수치: - 엔트로피 정규화 α=0.1, 모든 실험에서 통일 - 기술 수: 대부분의 실험에서 20 또는 50개 - 훈련 스텝: 최대 100만 스텝(1000 epoch × 1000 episode) - 모방 학습 실패 사례: 물구나무서기(handstand) 모방 실패 - Ant 기술에서 직선 보행 미창발

경계 및 한계

  • 수렴 보장 부재: 저자들은 연속 및 근사 설정에서 수렴 보장을 제공할 수 없음을 인정, 경험적 강건성에만 의존
  • Ant 기술 결함: 학습된 대부분이 직선이 아닌 곡선 보행이며, 전형적인 전진 작업에서 큰 보상을 얻는 기술이 거의 없음
  • 모방 학습 실패 사례: 물구나무서기를 모방할 수 없어, 기술 라이브러리가 일부 전문가 행동을 커버하지 못할 수 있음을 시사
  • 기술 수 확장성: 작업에 필요한 기술이 관측 차원에 따라 지수적으로 증가하면 DIAYN이 필요한 기술을 학습하지 못할 수 있음(하지만 실험은 111차원 Ant로 확장 가능함을 보여줌)
  • 수행하지 않은 것: 실제 로봇에서 검증하지 않음; 모든 기존 무보상 방법과 포괄적으로 비교하지 않음(VIME와만 비교); 계산 비용 구체적 수치 미언급

공학적 시사점

  • 재현 시 우선 확인 사항: 네트워크 용량(300 은닉 유닛)과 엔트로피 정규화 계수(α=0.1)는 가장 민감한 두 하이퍼파라미터입니다. 저자들은 모델 용량 증가가 여러 기술 학습에 필수적임을 명시했으며, SAC 기본값인 128 유닛을 사용하면 재현에 실패할 수 있습니다.
  • 의사 보상 기준선 임의 제거 금지: log p(z) 항은 대부분의 환경에서 필요하며, 기술이 흡수 상태에서 허위 보상을 얻는 것을 방지합니다. 기술이 빠르게 종료되기를 명시적으로 원하는 환경(예: mountain car)에서만 제거 가능합니다.
  • 판별기 조건화가 확장의 핵심: 하위 작업에 특정 유형의 기술이 필요하면(예: Ant 내비게이션에 질량 중심 이동 필요), 판별기를 관측의 함수 f(s)에 조건화해야 하며, 전체 상태를 직접 사용하지 않아야 합니다. 이는 저자들이 명시적으로 제안한 간단한 수정입니다.
  • 계층적 RL의 메타 컨트롤러 설계: 메타 컨트롤러의 행동은 기술을 선택하고 k 스텝 동안 실행하는 것입니다(Ant 내비게이션 k=100, Cheetah 허들 k=10). 이 k 값은 작업 시간 척도에 따라 조정해야 합니다. 기술 커버리지가 충분히 좋으면 메타 컨트롤러는 단일 스텝 결정만으로도 충분합니다.
  • 가장 함정에 빠지기 쉬운 부분: p(z)를 학습하면 기술 붕괴가 발생(유효 기술 수 약 10배 감소)하므로 반드시 균일 분포로 고정해야 합니다. 또한, 모방 학습에서 기술 검색 시 I-프로젝션이 아닌 M-프로젝션을 사용하여, 검색된 기술이 전문가가 방문한 모든 상태를 방문하도록 보장해야 합니다.
