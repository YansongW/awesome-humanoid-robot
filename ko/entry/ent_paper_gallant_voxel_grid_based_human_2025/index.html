Gallant: Voxel Grid-based Humanoid Locomotion and Local-navigation across 3D Constrained Terrains

Gallant: Voxel Grid-based Humanoid Locomotion and Local-navigation across 3D Constrained Terrains

요약

Gallant 先从相机图像/多视角观测、本体状态与关节序列、深度/点云/高度图恢复场景、目标或运动表征，再用策略网络和控制模块生成地形/场景表征、导航/到达目标。关键点是把策略网络和控制模块放在同一条训练/部署链路里，减少高层目标到低层动作之间的断点。

출처

  • Gallant project page

개요

Gallant는 복셀 그리드(voxel grid)를 유일한 인식 입력으로 사용하고, 엔드투엔드 강화 학습으로 휴머노이드 로봇의 locomotion 및 로컬 내비게이션 정책을 훈련한 최초의 연구로, Unitree 관련 팀이 수행했으며 Unitree G1에서 제로샷 sim-to-real 전이를 달성했습니다. 핵심 기여는 2.5D 고도 맵을 3D 복셀 표현으로 대체하고, 경량 LiDAR 시뮬레이션 파이프라인과 도메인 무작위화를 결합하여 단일 정책이 지상, 측면, 머리 위의 세 가지 공간 제약을 동시에 처리할 수 있게 한 것입니다.

무엇을 바꾸었는가

기존 인식 방식의 근본적 결함은 "차원 축소"에 있습니다. 고도 맵은 3D 포인트 클라우드를 2.5D 높이 필드로 압축하여 돌출물, 낮은 천장, 계단 밑면과 같은 수직 구조 정보를 직접 버립니다. 깊이 이미지는 좁은 FoV와 제한된 범위로 인해 공간적으로 확장된 환경에 대한 추론을 지원할 수 없습니다. 더 중요하게는, 이러한 인식-제어 분리 아키텍처(상위 플래너가 경로를 출력하고 하위 정책이 추종)는 정책이 수동적으로 추종할 수밖에 없어 지형의 기하학적 특징(예: 미리 고개 숙이기, 발을 들어 넘기)을 능동적으로 활용할 수 없습니다. Gallant는 이 패러다임을 바꾸었습니다. "환경이 어떻게 생겼는가"가 아니라 "정책이 올바른 결정을 내리기 위해 무엇을 봐야 하는가"를 묻습니다. 전체 환경을 이진 복셀 점유 그리드로 인코딩하고 정책이 원시 기하학에서 직접 행동을 학습하게 함으로써, 엔드투엔드 학습이 전통적인 계층적 내비게이션을 대체할 수 있고 전체 공간 장애물 유형을 포괄할 수 있음을 증명했습니다.

방법 분석

문제 정식화

인식-운동을 POMDP로 모델링하고 PPO로 비대칭 actor-critic을 훈련합니다. Actor는 복셀 그리드만 수신하고, Critic은 특권 정보로 고도 맵을 추가로 수신하여 배포 시 지연 민감 채널에 의존하지 않도록 합니다.

복셀 인식 표현

  • 인식 볼륨 Ω=[-0.8,0.8]m×[-0.8,0.8]m×[-1.0,1.0]m, 해상도 Δ=0.05m, 32×32×40 이진 점유 텐서 X∈{0,1}^{C×H×W} 생성 (C=40은 높이 슬라이스, H=W=32).
  • 각 복셀은 최소 하나의 LiDAR 포인트가 포함되면 1, 그렇지 않으면 0으로 설정.

z 그룹 2D CNN

z축을 채널 차원으로 사용하고 x-y 평면에 2D 컨볼루션을 적용하며, 출력 공식: Y_{o,v,u}=σ(Σ_c Σ_{Δv,Δu} W_{o,c,Δv,Δu}·X_{c,v+Δv,u+Δu}+b_o) 3D 커널 k³에 비해 계산 및 메모리 비용이 약 k배 감소합니다.

LiDAR 시뮬레이션 파이프라인 (NVIDIA Warp)

  • 각 메시는 로컬 좌표계에서 BVH를 사전 계산하고, 시뮬레이션 시 광선 원점만 변환하며 방향은 회전 성분만 적용: raycast(TM, p, d) = T⁻¹·raycast(M, T⁻¹p, R⁻¹d).
  • 병렬 커널 형태 (N_envs, N_meshes, N_rays).
  • 도메인 무작위화: 자세 섭동 N(0,1)cm / N(0,(π/180)²)rad; 히트 위치 섭동 N(0,1)cm; 지연 100-200ms; 무작위 마스크 2% 복셀.

보상 설계 (범용, 기하학 인식)

  • 목표 도달 보상 r_reach = 1/(1+‖P_t‖²) · 𝟙(t>T-T_r)/T_r, T_r=2s.
  • 방향 속도 보상 r_velocity_direction = (a(p,g)·v_t) / ‖a(p,g)·v_t‖₂, 반경 r=1m, κ=0.8.
  • 머리 높이 보상 r_head_height = exp(−4(H_head_est − H_head)²), H_head_est는 목표 방향으로 0.45m 전진, 0.5×0.5m 정사각형 내 평균 지형 높이에서 0.1m 오프셋을 빼서 계산.
  • 발 들림 보상 r_feet_clearance = exp(−4(H_feet_est − H_feet)²), H_feet_est는 각 발 앞 0.5m 지점의 지형을 조회.

커리큘럼 훈련

8가지 지형(Plane/Ceiling/Forest/Door/Platform/Pile/Upstair/Downstair), 각각 스칼라 난이도 s∈[0,1]로 매개변수화, 매개변수 보간 p_τ(s)=(1-s)·p_τ^min+s·p_τ^max. 성공 시 승급, 실패 시 강등.

대칭성 증강

복셀 그리드를 y축으로 미러링하고, 뒤집힌 고유수용감각 입력과 정렬하며, 보상은 불변, 원본과 뒤집힌 샘플을 함께 rollout 버퍼에 저장.

핵심 혁신

  1. 복셀 그리드를 유일한 인식 입력으로 하는 엔드투엔드 정책: 순수 복셀 표현(고도 맵, 깊이 맵, 명시적 플래너 없음)이 휴머노이드 로봇의 복잡한 3D 지형에서 locomotion 및 로컬 내비게이션을 지원할 수 있음을 증명한 최초의 연구. 고도 맵과 달리 복셀은 완전한 수직 및 다층 구조 정보를 보존하여 정책이 머리 위 제약을 능동적으로 인식하고 자세를 조정할 수 있게 합니다.
  2. 경량 LiDAR 시뮬레이션 파이프라인과 도메인 무작위화: BVH 사전 계산, 광선 원점만 변환, 병렬 커널 형태 (N_envs, N_meshes, N_rays)를 통해 효율적이고 확장 가능한 LiDAR 시뮬레이션 구현. 지연(100-200ms), 노이즈, 자세 섭동의 명시적 모델링은 sim-to-real 전이 성공의 핵심 — 소거 실험에서 도메인 무작위화 없음(NoDR)이 지상급 지형에서 성능이 크게 저하됨을 보여줌.
  3. z 그룹 2D CNN 아키텍처: z축을 채널 차원으로 사용하고 x-y 평면에 2D 컨볼루션을 적용하여 계산 비용이 3D 컨볼루션의 약 1/k. 이 설계는 3D 기하학 정보를 유지하면서 계산 및 메모리 오버헤드를 크게 줄여 Orin NX에서 실시간 실행 가능.

실제 세계 실험

  • 동일 정책을 Unitree G1에 직접 배포, 미세 조정 없음. 시나리오는 평평한 지형, 무작위 높이 천장, 측면 잡동사니, 간격이 있는 높은 플랫폼, 디딤돌, 계단 포함.
  • Gallant는 모든 실제 지형에서 HeightMap 및 NoDR 기준선보다 일관되게 우수 (Fig. 5, 15회 시행).
  • HeightMap은 Ceiling과 Door에서 실패, 2.5D 표현의 한계 때문; NoDR은 지상급 지형에서 성능이 크게 저하, LiDAR 지연 및 노이즈 미모델링 때문.
  • 시뮬레이션-실제 상관관계 (Fig. 6): 시뮬레이션 성공률이 높은 지형은 하드웨어에서도 좋은 성능을 보여, 대규모 시뮬레이션 평가가 실제 성능을 예측할 수 있음을 검증.

핵심 병목

  • Pile 지형에서 성공률 약 80% 플랫폼; 시뮬레이션에서 LiDAR 지연이 0일 때 90% 이상으로 상승, 실제 센서 지연(10Hz에서 100ms 초과)이 핵심 병목임을 시사.

경계 및 한계

  • 논문은 한계 섹션을 명시적으로 나열하지 않았지만, 실험 데이터가 다음을 드러냄: Pile 지형(돌무더기) 성공률 82.1%로 8개 지형 중 최저, 저자는 LiDAR 지연이 주요 병목임을 인정 — 10Hz 작동 주파수에서 각 스캔이 광 반사 및 통신 오버헤드로 100ms 이상 지연되어 능동 반응 능력 제한.
  • 실제 세계에서 각 시나리오의 구체적 성공률 수치 미언급 (Fig. 5는 "15 trials"만 표시, 숫자는 텍스트에 없음).
  • 다른 비소거 방법(예: 깊이 이미지 기반 방법)과의 실제 세계 직접 비교 실험 미언급.
  • 완전히 알려지지 않은 지형 유형에 대한 정책 일반화 테스트 미언급.
  • 계산 지연의 구체적 밀리초 수치 미언급 ("lower inference latency"만 언급).
  • 구체적 PPO 하이퍼파라미터(학습률, 배치 크기, GAE 매개변수 등) 및 총 훈련 시간 미언급.

공학적 시사점

  1. LiDAR 지연 모델링을 먼저 확인: sim-to-real 전이 성공의 핵심. NoDR 소거는 지연 미모델링이 지상급 지형 성공률을 크게 저하시킴을 보여줌. 재현 시 시뮬레이션에 100-200ms 지연을 명시적으로 추가하고 지연 분포가 실제 센서와 일치하는지 검증.
  2. 복셀 해상도 5cm가 최적점: 2.5cm는 성능 붕괴(Ceiling 13.3% vs 97.1%), 10cm는 Platform에서 저하(75.5% vs 96.1%). 높은 해상도를 맹목적으로 추구하지 말 것, 노이즈와 계산 오버헤드가 정밀도 이득을 상쇄.
  3. 자체 스캔(self-scan) 생략 불가: w/o-Self-Scan은 Platform/Pile/Upstair에서 성공률이 82-96%에서 22-33%로 급락. 정책이 외부 관측에만 의존하지 않고 자신과 환경의 상대적 위치를 인식할 수 있도록 보장.
  4. z 그룹 2D CNN이 3D CNN보다 우수: Sparse-3D-CNN은 Pile에서 52.4% vs Gallant의 82.1%, 계산 비용도 더 낮음. 재현 시 z 그룹 2D 컨볼루션 아키텍처를 우선 채택.
  5. 통신 최적화가 배포의 핵심: TCP로 LiDAR 데이터를 전송하고 LCM 내부 상태 공유로 약 200ms 지연 발생; LiDAR 출력 트리밍, 공유 메모리(복셀 그리드와 관측, 상태 읽기와 동작 명령)로 거의 모든 통신 지연 제거 가능. 배포 시 엔드투엔드 지연 체인을 반드시 확인.
  6. 훈련 구성 참고: 8개 RTX 4090, 1024×8 환경 수, 4000회 반복, PPO clip 0.2, 엔트로피 계수 0.003, GAE λ 0.95, γ 0.99, 학습률 5e-4. 평가 규모는 5회 독립 평가 × 1000 에피소드, 평균±표준편차 보고.
