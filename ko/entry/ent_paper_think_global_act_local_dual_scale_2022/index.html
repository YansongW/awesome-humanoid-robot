요약

Following language instructions to navigate in unseen environments is a challenging problem for autonomous embodied agents. The agent not only needs to ground languages in visual scenes, but also should explore the environment to reach its target. Institutions per source list: 法国国家信息与自动化研究所.

출처

개요

DUET(Dual-scale Graph Transformer)은 시각-언어 내비게이션(VLN)을 위한 이중 스케일 그래프 트랜스포머 모델로, 프랑스 팀이 제안했다. 핵심 기여는 순환 상태 추적을 순수 트랜스포머 아키텍처로 대체하고, 조대한 스케일의 토폴로지 그래프와 미세한 스케일의 파노라마 인코딩의 협력적 추론을 통해 목표 지향 내비게이션(REVERIE, SOON)에서 탐색 효율성과 객체 접지 정확도를 동시에 향상시킨 것이다. REVERIE 테스트 세트에서 성공률은 당시 SOTA(HAMT) 대비 22.11% 향상되었고, SPL은 9.39% 향상되었다.

그것이 바꾼 것

이 작업의 진정한 가치는 VLN에서 오랫동안 기본값으로 여겨졌던 두 가지 "기반"을 동시에 건드렸다는 점이다: 하나는 상태 추적 메커니즘이고, 다른 하나는 행동 공간의 정의다. 기존의 주요 방법들(HAMT, E.T.)은 내비게이션을 마르코프 결정 과정으로 간주하여 각 단계에서 인접 위치로만 이동할 수 있었고, N단계를 되돌아가려면 모델을 N번 다시 실행해야 했다——이는 순환 아키텍처의 오류 누적을 증폭시킬 뿐만 아니라 장기 계획을 계산적으로 감당할 수 없게 만들었다. DUET은 "되돌아가기"를 암시적 시퀀스 재생에서 명시적 그래프 탐색으로 바꾸었다: 토폴로지 그래프가 구축되면 임의 노드에서 임의 노드까지의 경로는 Floyd 알고리즘으로 한 번에 풀 수 있으며, 모델은 목표 노드만 예측하면 되고 점진적으로 접근할 필요가 없다. 이는 "과정 제어"에서 "목표 제어"로의 패러다임 전환이다.

또 다른 변경된 가정은 "토폴로지 그래프 노드에 압축된 시각적 특징이면 충분하다"는 것이다. 기존 그래프 기반 방법들(예: [8,19,20])은 그래프의 확장성을 위해 노드의 세부 정보를 희생했고, 그 결과 "파란 소파 옆의 플로어 램프"와 같은 지시문의 설명을 그래프 노드와 정렬할 수 없었다. DUET의 통찰은: 조대한 스케일 그래프는 "어디로 갈지"를 담당하고, 미세한 스케일 파노라마는 "거기에 무엇이 있는지 확인"을 담당하며, 둘 다 동시에 존재하고 동적으로 융합되어야 한다는 것이다. 이 "이중 스케일" 설계는 단순한 멀티태스크 연결이 아니라 VLN 작업 본질의 재분해다——내비게이션은 계층적 결정이지 단일 스케일 시퀀스 결정이 아니다.

방법 분해

토폴로지 매핑: 증분 그래프 구축

  • 환경 그래프 G는 알려지지 않으며, 모델은 경로를 따라 점진적으로 로컬 그래프 Gt = {Vt, Et}를 구축한다. 노드는 세 가지 유형으로 나뉜다: 방문됨, 내비게이션 가능(탐색되지 않았지만 부분적으로 보임), 현재 노드.
  • 각 단계에서 현재 노드의 방문되지 않은 이웃을 그래프에 추가하고, 엣지는 서로 내비게이션 가능한 노드만 연결한다.
  • 노드 시각적 표현: 현재 노드는 파노라마 특징 Rt와 객체 특징 Ot의 평균 풀링을 사용하고, 내비게이션 가능한 노드는 여러 위치에서 보일 때 모든 부분 뷰 임베딩을 평균한다.
  • 핵심 설계: Rt, Ot를 미세한 표현으로 유지하고 압축하지 않는다——이것이 이후 미세 스케일 추론의 입력이다.

조대한 스케일 교차 모달 인코더(전역 행동)

  • 노드 임베딩 = 시각적 특징 + 위치 인코딩(현재 노드의 자아 중심 관점에서 방향/거리) + 내비게이션 단계 인코딩(방문된 노드의 최근 방문 시간, 미탐색은 0).
  • 'stop' 노드 v0를 추가하고 모든 노드와 완전 연결한다.
  • 그래프 인식 자기 주의(GASA): 표준 자기 주의에 학습 가능한 거리 편향 행렬 M = EWe + be를 추가하며, 여기서 E는 쌍별 최단 거리 행렬이다. 수식: GASA(X) = Softmax(XWq(XWk)T/√d + M)XWv.
  • 전역 행동 점수: sci = FFN(ˆvi), 방문된 노드는 마스킹한다.

미세한 스케일 교차 모달 인코더(로컬 접지)

  • 입력: 지시문 + 현재 노드의 {Rt, Ot}.
  • 두 가지 유형의 위치 임베딩: ①현재 노드의 시작 노드 대비 지도 위치("1층 거실로 가기" 지원), ②각 이웃의 현재 노드 대비 자아 중심 방향("우회전" 지원).
  • 'stop' 토큰 r0를 추가하고 [r0; Rt; Ot]로 연결하여 표준 교차 모달 트랜스포머에 입력한다.
  • 출력: 로컬 행동 점수 s fi와 객체 접지 점수(ˆOt 기반 FFN).

동적 융합

  • 로컬 점수를 전역 공간에 매핑: 방문된 노드 점수 = sback(N(Vt)에서 방문된 노드 점수의 합), 방문되지 않은 이웃은 원래 점수를 유지한다.
  • 융합 가중치: σt = Sigmoid(FFN([ˆv0; ˆr0])), 즉 두 스케일의 stop 표현이 어떤 스케일을 신뢰할지 함께 결정한다.
  • 최종 점수: si = σtsci + (1 − σt)s f′i.

훈련

  • 사전 훈련: 행동 복제(SAP) + 마스크 언어 모델링(MLM) + 마스크 영역 분류(MRC) + 객체 접지(OG).
  • 정책 학습: 의사 상호작용 시연기(PID), DAgger와 유사하며, 훈련 시 환경 그래프에 접근할 수 있고 최종 목적지까지의 전체 최단 거리를 가진 노드를 다음 목표로 선택하여 전문가 궤적의 차선성을 피한다.
  • 총 손실: L = λLSAP + LPID + LOG, λ는 행동 복제와 PID의 균형을 맞춘다.

추론

  • 각 단계에서 토폴로지 그래프 업데이트 → 전역 행동 예측 → 내비게이션 행동이면 Floyd 알고리즘으로 최단 경로 계산 → 최대 단계 수 초과 시 강제 중지 → 중지 위치에서 객체 점수가 가장 큰 객체 선택.

핵심 혁신

  1. 그래프 인식 자기 주의(GASA): 토폴로지 그래프의 쌍별 거리 행렬을 주의 편향으로 트랜스포머에 주입한다. 이는 단순한 그래프 신경망 메시지 전달이 아니라, 주의 가중치가 "노드 간 최단 경로 길이"를 직접 인코딩하게 한다——모델은 "거리가 가까울수록 더 관련 있다"는 귀납적 편향을 암시적으로 학습할 수 있으며, 동시에 GNN의 과평활화 문제를 피한다. 소거 실험에서 GASA는 동적 융합 하에 SPL을 32.88에서 33.73으로, RGS를 29.91에서 32.15로 향상시켰다.

  2. 의사 상호작용 시연기(PID)로 강화 학습 대체: 전통적 RL(예: REVERIE의 RL 미세 조정)은 환경과의 상호작용 샘플링이 필요하여 샘플 효율이 낮고 불안정하다. PID는 훈련 시 접근 가능한 환경 그래프를 활용하여 "최종 목적지까지의 최단 경로상 다음 노드"를 직접 감독 신호로 선택한다. 이는 최적 경로 계획기로 온라인 시연을 생성하는 것과 같다. 소거 실험에서 PID는 RL 대비 SR을 4.63% 향상시켰고(42.35→46.98), 추가 상호작용 비용이 없다.

  3. 이중 스케일 동적 융합: 단순한 점수 평균이 아니라, 두 스케일의 stop 표현으로 게이트 가중치 σt를 학습한다. 이 설계의 정교함은: σt 자체가 "현재 노드가 충분히 확신하는지"를 반영한다——미세 스케일이 stop에 확신이 있을 때(예: 목표 방에 도달), σt는 0에 가까워지고 미세 스케일이 주도한다; 장거리 탐색이 필요할 때는 조대한 스케일이 주도한다. 소거 실험에서 동적 융합은 평균 융합 대비 SPL을 1.79% 향상시켰다(31.94→33.73).

실패 분석(REVERIE)

  • 잘못된 방 유형이 29.82%, 올바른 방이지만 잘못된 위치가 23.20%——세밀한 장면 이해가 여전히 주요 병목이다.
  • 올바른 위치 도달 후 객체 정확한 위치 파악률 68.43%——객체 접지는 이미 위치가 파악된 장면에서 비교적 양호하다.

경계와 한계

  • 이산 환경 한계: 방법은 Matterport3D의 이산 내비게이션 그래프(사전 정의된 위치와 행동 집합)에 의존하며, 연속 환경(예: 실제 로봇)에서 검증되지 않았다. 저자는 이 한계를 명시적으로 인정한다.
  • 세밀한 이해 부족: 29.82%의 오류는 방 유형 판단 오류에서 비롯되며, 모델은 여러 유사한 방(예: 여러 욕실)이 있을 때 목표 객체가 없는 방에 도달할 수 있다.
  • 언어 견고성 부족: 동일 궤적의 세 지시문 중 하나만 성공하며, 모델은 지시문 표현 변화에 민감하다.
  • SOON 데이터 노이즈: SOON의 객체 주석 중 약 50%의 다각형이 객체 중심점을 포함하지 않으며, 저자가 BUTD 검출기로 정제했지만 의사 레이블 품질이 여전히 상한을 제한할 수 있다.
  • 계산 자원 미공개: 논문은 총 파라미터 수, 추론 빈도, 훈련 시간을 언급하지 않아 재현 비용을 예측하기 어렵다.
  • 합성 데이터 증강의 한계 효과: PID 정책 학습 단계에서 합성 지시문 데이터는 향상이 없으며(SR 46.98→46.58), 증강이 사전 훈련에만 효과적임을 시사한다.

엔지니어링 시사점

  • 재현 우선순위: GASA의 거리 행렬 계산을 먼저 확인하라——E는 쌍별 최단 경로 거리(Floyd 또는 BFS로 사전 계산)여야 하며, 직접 인접 거리가 아니다. 이것이 주의 편향의 핵심이며, 잘못 구현하면 그래프 구조 정보가 손실된다.
  • 훈련 순서 민감성: 사전 훈련(SAP+OG+Aux)과 정책 학습(PID)은 반드시 분리해야 한다. 합성 데이터 증강은 사전 훈련 단계에서만 효과적이며, PID 단계에서는 오히려 SR을 약간 낮춘다——모든 단계에서 증강 데이터를 일괄 사용하지 말 것.
  • λ 균형 인자: λ=0일 때 내비게이션 성능이 가장 좋지만(SR 48.22) 객체 위치 파악이 약하며(RGS 32.12); λ=0.2가 종합적으로 최적이다. 하위 작업이 객체 위치 파악에 더 중점을 둔다면 λ=0.5를 시도할 수 있다(RGS 32.43). λ=1일 때 모든 지표가 전반적으로 하락하며, 행동 복제 가중치가 너무 높으면 PID의 탐색 이점을 억제함을 시사한다.
  • 되돌아가기 행동은 특징이지 버그가 아니다: val unseen에서 48.6%의 궤적이 되돌아가기를 포함하지만, val seen은 13.7%에 불과하다——되돌아가기 비율은 일반화 능력의 진단 지표로 사용할 수 있다. 모델의 unseen에서 되돌아가기 비율이 이 값보다 현저히 낮다면 탐색 부족을 의미할 수 있다.
  • SOON의 함정: 데이터셋 분할은 원래 논문의 분할이 아닌 공개 챌린지 분할을 사용하며, BUTD 검출기로 주석을 정제해야 한다. 재현 시 분할 버전을 반드시 확인해야 하며, 그렇지 않으면 비교 결과가 무의미하다.
  • 하드웨어 장벽은 높지 않다: 사전 훈련은 P100 2개, 미세 조정은 P100 1개면 충분하지만, SOON 미세 조정 배치 크기는 2에 불과하므로 그래디언트 누적 전략에 주의해야 한다.
