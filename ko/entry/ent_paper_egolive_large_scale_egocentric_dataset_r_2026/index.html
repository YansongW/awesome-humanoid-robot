EgoLive: A Large-Scale Egocentric Dataset from Real-World Human Tasks

EgoLive: A Large-Scale Egocentric Dataset from Real-World Human Tasks

영역

초안

요약

The advancement of robot learning is currently hindered by the scarcity of large-scale, high-quality datasets. While established data collection methods such as teleoperation and universal manipulation interfaces dominate current datasets, they suffer from inherent limitations in scalability and real-world deployability. Institutions per source list: Joy Future Academy、JD.

출처

  • arXiv:2604.23570 EgoLive: A Large-Scale Egocentric Dataset from Real-World Human Tasks
  • 机器人下一代数据入口，可能就是Ego：9篇论文讲透第一视角技术路线

개요

EgoLive는 JD.com 등 기관이 구축한 대규모 일인칭(egocentric) 데이터셋으로, 1,680시간, 65,866개 에피소드, 346개 실제 세계 작업의 고충실도 스테레오 비디오를 포함하며, 깊이, 손 동작 추적 및 세분화된 언어 명령 주석이 함께 제공됩니다. 핵심 기여는 맞춤형 헤드셋 JoyEgoCam과 완전 자동 주석 파이프라인을 통해 실제 서비스 시나리오에서 다중 시점, 동작 추적, 언어 주석 및 깊이 정보를 갖춘 대규모 데이터 수집을 최초로 실현하여, 범용 로봇 조작 모델에 야외(in-the-wild) 훈련 기반을 제공한 것입니다.

그것이 바꾼 것

로봇 학습 커뮤니티는 오랫동안 딜레마에 시달려 왔습니다: 텔레오퍼레이션 데이터는 품질이 높지만 수집 비용이 비싸고 확장성이 낮은 반면, 인터넷 비디오는 방대하지만 로봇에 필요한 동작, 깊이 및 상호작용 구조가 부족합니다. EgoLive가 진정으로 바꾼 것은 데이터 수집의 "비용-품질" 균형 곡선입니다—로봇 팔 텔레오퍼레이션과 UMI 같은 전용 인터페이스를 일인칭 헤드셋 카메라로 대체하여 데이터 수집을 "사람이 자연스럽게 일하는" 가장 원시적이고 확장 가능한 형태로 되돌렸습니다. 이는 단순한 수집 방식의 교체가 아니라, 데이터 분포가 실험실의 제한된 시나리오에서 가정, 소매, 약국 등 실제 서비스 시나리오로 전환되었음을 의미하며, 환경 다양성, 객체 범주 및 작업 복잡성이 모두 한 단계 도약했습니다.

또 다른 핵심 변화는 주석의 "자동화 가능성"에 있습니다. 이전의 EgoDex 같은 데이터셋은 동작 추적이 있지만 언어 주석이 없었고, Ego4D는 언어가 있지만 깊이와 손 추적이 없었으며, EgoLive는 천 시간 규모에서 스테레오 RGB, 깊이, 손 6D 궤적 및 세분화된 언어 명령을 동시에 제공하면서 모두 자동 파이프라인으로 생성합니다.这使得 하류 연구자들은 더 이상 데이터 정제와 주석에 많은 인력을 투입할 필요 없이 정책 학습 자체에 집중할 수 있습니다. 공학적 관점에서 이는 "데이터 공장"의 생산 능력을 수공업 소규모 작업장에서 자동화 생산 라인으로 끌어올린 것과 같습니다.

방법 분해

하드웨어 계층: JoyEgoCam 헤드셋

  • 스테레오 RGB 카메라, 해상도 2160×2160 @ 60 FPS, FOV 130°×130°, 인간 눈의 양안 시차 모사
  • 통합 IMU, 200 Hz 샘플링, 카메라 자체 운동 추정 및 시각-관성 융합에 사용
  • 설계 원칙: 최소 침습, 얼굴을 가리지 않고 손 동작을 방해하지 않아 조작자의 자연스러운 행동 보장

자동 주석 파이프라인(3단계)

  1. 동작 추적:
  2. 손: 2단계 방법—먼저 HaMeR로 단안 비디오에서 MANO 파라미터를 추정한 후, 스테레오 최적화를 수행하여 양안 2D 투영 제약을 만족하는 일관된 3D 손 키포인트 획득
  3. 카메라 포즈: ORB-SLAM3가 양안 RGB + IMU를 융합, 왼쪽 카메라 첫 프레임에서 초기화
  4. 의미 이해:
  5. 손-물체 감지는 [Shan20] 모델, 추적은 BoT-SORT, 분할 마스크는 SAM2 사용
  6. 각 에피소드는 손-물체 감지 및 추적 결과에 따라 하위 작업(1-20초)으로 분할
  7. 명령 생성: Qwen3-VL-32B 미세 조정, 추론 시 다단계 전략으로 손, 조작 물체, 동작의 세 가지 요소를 명시적으로 모델링—자유 형식 설명이 아님
  8. 3D 재구성:
  9. 깊이: FoundationStereo가 1152×1152 해상도에서 보정된 스테레오 비디오로부터 재구성
  10. 깊이 평가: ChArUco 보정판 + 계단 배열, 거리 0.5-3.5 m, BFGS 공동 최적화로 전역 재투영 오차 최소화

품질 평가

  • LLM-as-a-Judge 프로토콜, 손 일관성, 물체 일관성, 동작 일관성, 전역 일관성의 네 가지 차원에서 점수 부여

핵심 혁신

  1. "데모 작업"이 아닌 "실제 작업": EgoLive의 데이터는 실험실에서 설계된 표준 동작이 아닌 실제 서비스 시나리오(가정, 소매, 약국)에서 운영자가 자연스럽게 수행하는 작업에서 비롯됩니다. 이는 데이터가 실제 세계의 긴 꼬리 분포—어수선한 테이블, 조명 변화, 폐색, 비표준 물체 조작 방식—를 포함함을 의미하며, 이는 텔레오퍼레이션 데이터가 따라잡기 어려운 다양성입니다.

  2. 스테레오 + IMU + 깊이 + 손 추적 + 언어 주석의 5중 조합: 이전에는 어떤 데이터셋도 천 시간 규모에서 이 다섯 가지 모달리티를 동시에 갖추지 못했습니다. Ego4D는 언어가 있고 깊이가 없으며, EgoDex는 추적이 있고 언어가 없으며, Xperience-10M은 모두 있지만 해상도가 512×512 @ 20 FPS에 불과합니다. EgoLive는 2160×2160 @ 60 FPS의 플래그십 사양으로 이 공백을 메웠고, 깊이 정밀도는 0.9 m 내에서 평균 오차가 5.4 mm 미만으로 정밀 조작 요구를 충족합니다.

  3. 완전 자동 주석 파이프라인의 공학화: 손 추적(HaMeR + 스테레오 최적화), 의미 분할(SAM2), 언어 생성(미세 조정 Qwen3-VL-32B)의 직렬 연결은 단순한 조합이 아니라 일인칭 시점에 맞춰 특별히 설계되었습니다—예를 들어 손 3D 최적화는 단안 추정의 손목 드리프트 문제를 해결하고, 하위 작업 분할 메커니즘은 언어 설명과 동작 세그먼트를 정렬합니다.这使得 데이터셋이 일회성 프로젝트가 아닌 지속적으로 저비용으로 성장할 수 있습니다.

손 재구성

EgoDex와 비교하여 EgoLive의 2D 키포인트 주석은 더 정확하고 공간적 어긋남이 없으며, 3D 키포인트는 네 가지 시점(일인칭, 정면, 왼쪽, 오른쪽)에서 모두 강한 공간 일관성을 유지하고 손목 드리프트가 없습니다.

경계와 한계

논문은 한계에 대한 명시적 성명을 제시하지 않았지만, 사실적 요점에서 다음 경계를 추론할 수 있습니다: - 로봇 정책 훈련 또는 sim-to-real 전이 실험 미수행: 데이터셋의 가치는 "데이터 공급" 수준에 머물러 있으며, 로봇 조작 성공률을 직접 향상시킬 수 있음을 아직 입증하지 못했습니다. - 깊이 정밀도가 거리에 따라 현저히 감소: 1.5 m 이상에서 평균 오차가 8.7 mm를 초과하고, 2.5 m 이상에서 14 mm를 초과하여, 원거리 조작 또는 대규모 장면 인식에는 충분하지 않을 수 있습니다. - 언어 주석은 LLM 생성에 의존: LLM-as-a-Judge 평가를 거쳤지만 구체적인 점수는 공개되지 않았으며, 자유 형식 설명의 품질 상한은 Qwen3-VL-32B의 능력에 제한됩니다. - 장면 커버리지 제한: 346개 작업이 많지만 서비스 지향 시나리오(가정, 소매, 약국)에 집중되어 있으며, 산업 제조, 야외 작업 등 로봇 응용 분야를 포괄하지 않습니다. - 데이터 수집자는 모집된 운영자: 그들의 행동 패턴은 실제 사용자와 차이가 있을 수 있어 데이터 분포의 생태학적 타당성에 영향을 미칩니다.

공학적 시사점

  1. 먼저 깊이 정밀도가 작업 요구를 충족하는지 확인: 근거리 테이블 조작(<0.9 m)을 한다면 EgoLive의 깊이 오차(<5.4 mm)는 충분합니다. 하지만 이동 조작이나 원거리 인식이 포함된다면 깊이 오차로 인한 정책 성능 저하 위험을 고려해야 합니다.

  2. 손 추적 데이터는 모방 학습에 직접 사용 가능: EgoLive의 3D 손 키포인트는 스테레오 최적화를 거쳐 손목 드리프트가 없고 2D 투영과 일치합니다. 하류 팀은 추가 정제 없이 이를 동작 라벨로 직접 사용할 수 있습니다. 단, MANO 파라미터는 손 모델이지 로봇 엔드 이펙터가 아니므로, human-to-robot 매핑 시 리타게팅 전략을 직접 설계해야 합니다.

  3. 언어 명령의 세분화 설계는 참고할 가치: 자유 형식 설명이 아닌 "손-물체-동작"의 세 요소를 명시적으로 모델링하여 명령과 하위 작업(1-20초)의 정렬이 더 긴밀합니다. 재현 시 LLM이 생성한 자유 텍스트를 직접 사용하지 말고 이 구조를 유지하는 것이 좋습니다.

  4. 가장 함정에 빠지기 쉬운 부분은 깊이 재구성의 해상도: FoundationStereo는 1152×1152에서 실행되는 반면 원본 비디오는 2160×2160이므로, 깊이 맵은 다운샘플링된 것입니다. 하류에서 픽셀 수준으로 정렬된 RGB-D가 필요하다면 업샘플링 또는 재계산을 직접 처리해야 합니다.

  5. 데이터 획득 채널은 이미 개방: https://robotdata-market.jdcloud.com/console/market 에서 얻을 수 있습니다. 하지만 훈련 구성, 추론 빈도 등 공학적 세부 사항은 논문에 언급되지 않아, 주석 파이프라인을 재현할 때 직접 탐색해야 합니다.
