요약

We present OSCAR, a precise action-conditioned video world model that generalizes across different robot embodiments and enables robot policy evaluation. Institutions per source list: Peking University、University of Michigan、NVIDIA.

출처

  • arXiv:2606.04463 OSCAR: Omni-Embodiment Action-Conditioned World Model for Robotics
  • Project page
  • GitHub仓库 Robotics_Notebooks

개요

OSCAR는 2D 운동학적 스켈레톤 렌더링을 통합 조건 표현으로 사용하는 동작 조건부 비디오 세계 모델로, Cosmos-Predict2.5-2B에서 미세 조정되었으며, 대규모 로봇 + 인간 1인칭 비디오 데이터를 결합하여 학습함으로써 4가지 로봇 체현(Franka Panda, KUKA iiwa, AgiBot G1, Toyota HSR)에 걸친 정밀한 동작 추종과 일반화를 달성했습니다. 핵심 기여는 잠재 동작이나 밀집 기하 조건을 무질감 스켈레톤 렌더링으로 대체하여 동작 구속력을 유지하면서 URDF 자산과 특정 질감에 대한 의존성을 제거하고, 인간 데이터가 로봇 비디오 생성에 미치는 긍정적 전이를 최초로 체계적으로 검증한 것입니다.

무엇을 바꾸었는가

이 작업이 실제로 바꾼 것은 동작 조건부 세계 모델의 '표현력-일반화-데이터 규모' 삼각 관계의 교착 상태입니다. 기존의 명시적 기하 조건(포인트 클라우드, 메시)은 동작이 정밀하지만, 외관에 과적합되거나(Kinema4D는 OOD에서 성능 저하), URDF 자산에 의존하거나(메시 렌더링은 체현 간 전이가 불가능), 잠재 동작 방법은 범용적이지만 동작 추종이 모호했습니다. OSCAR는 2D 스켈레톤 렌더링으로 두 가지 문제를 동시에 해결했습니다. 운동학적 체인에만 의존하고(체현 변경 시 운동학 사양만 업데이트), 무질감 처리로 모델이 외관을 기억하는 대신 운동학과 실제 동작 간의 매핑을 학습하도록 강제합니다. 더 중요한 것은, 이로 인해 인간 손 비디오(EgoDex, EPIC-Kitchens)를 직접 훈련 데이터로 사용할 수 있게 되었다는 점입니다. 이전에는 어떤 동작 조건부 세계 모델도 인간 손과 로봇 그리퍼의 기하 표현을 통합할 수 없어 이를 달성하지 못했습니다. 이는 실제로 로봇 비디오 생성의 훈련 데이터 풀을 약 10.9k 시간의 로봇 데이터에서 추가 929시간의 인간 데이터로 확장했으며, 긍정적 전이를 입증했습니다.

방법 분해

조건 표현: 2D 운동학적 스켈레톤 렌더링

  • 조작기(로봇 팔 또는 인간 손)의 운동학적 체인을 2D 선 그림으로 투영하여 두 번째 RGB 비디오 스트림 S₁:T로 사용하며, 대상 비디오와 프레임 단위로 정렬됩니다.
  • 핵심 설계: 스켈레톤은 질감이 없고 운동학적 체인만 포함합니다. 체현 변경 시 운동학 삼중항 (M, q_t, o_k)만 교체하면 되며, 여기서 M은 운동학 모델(URDF 또는 MANO 손 모델), q_t는 관절 각도, o_k는 카메라 외부 파라미터입니다.
  • 인간 손의 경우: MANO 손 모델로 교체하며, 다섯 손가락의 자유도가 두 손가락 그리퍼보다 높지만 동일한 2D 선 그림으로 통합 렌더링됩니다. 스켈레톤은 대략적인 동작을 구속하고, 사전 학습된 비디오 사전 지식이 세밀한 시각적 세부 사항을 채웁니다.

조건 주입

  • 스켈레톤 렌더링 S₁:T는 WAN 2.1 VAE로 인코딩되어 스켈레톤 잠재 z^s가 되며, 대상 비디오 잠재 z^v와 형태가 동일합니다(둘 다 (T, C, H, W)).
  • 각각 patch embedder PE_v와 PE_s로 DiT 히든 차원 D=2048에 임베딩한 후, 두 토큰 텐서를 요소별로 더하여 DiT 디노이징에 입력합니다.
  • 훈련 시 0.2 확률로 S₁:T를 0으로 설정(classifier-free guidance), 추론 시 guidance scale w=6.

데이터 파이프라인(4단계)

  1. 데이터 큐레이션: RH20T(cfg5/cfg7), DROID, AgiBot World, InternData-A1, AIROA-MoMa, EgoDex, EPIC-Kitchens에서 소스 비디오 2,165,359개 클립 수집.
  2. 데이터 필터링: 4가지 메커니즘 — 길이 ≥70프레임; 정적 카메라(카메라 움직임이 임계값 미만); 의미 있는 동작(비자명한 조작기 동작 시퀀스); 가시 스켈레톤(가시 스켈레톤 비율이 임계값 미만이면 제거).
  3. 의미론적 중복 제거: 2단계 — 1단계는 SigLIP 이미지 임베딩(5프레임 균일 샘플링) 코사인 유사도 >0.95인 쌍을 표시; 2단계는 64단계 리샘플링 조작기 궤적을 추출하여 단계별 RMS 거리가 적응형 임계값 미만인 중복을 표시.
  4. 데이터 주석: Qwen3-VL-30B-A3B-Instruct가 80–100단어 영어 설명 생성, 로봇 데이터와 인간 데이터에 동일한 시스템 프롬프트 사용; DROID 클립은 샘플링 속도를 1–2fps로 낮춤(길이가 다른 소스의 약 5배이므로), 다른 소스는 15fps.

훈련 구성

  • 기본 모델: Cosmos-Predict2.5-2B(rectified-flow 목적), WAN 2.1 VAE.
  • 옵티마이저: AdamW, lr=3×10⁻⁵, batch size=16.
  • 시간 단계 샘플링: logit-normal 분포 가중치, shift=5.
  • 데이터 균형: 빈도 온도 가중치 wᵢ ∝ n_frames,i^(1/T), T=3.
  • 훈련 창 81프레임, 시작 프레임은 사다리꼴 사전 확률로 그리핑/릴리스 이벤트에 편향.
  • 2단계: 1단계는 4개 로봇 체현에서 15k 반복 훈련; 2단계는 전체 로봇+인간 혼합 데이터에서 계속 훈련(warm-start).

잠재 동작 경로(소거 연구용)

  • 팔당 7차원 동작(3 병진 + 3 회전 + 1 그리퍼), 프레임 간 차분을 이전 프레임 로컬 좌표계로 표현, 병진/회전 차분을 20배 스케일링.
  • 다중 본체 정렬: 통합 14차원 벡터, 양팔 연결, 단일 팔은 뒤 7차원을 0으로 설정.
  • 주입: D차원 토큰을 시간 단계 임베딩에 추가, 3D 차원 토큰을 adaptive LayerNorm 변조 신호에 추가.

핵심 혁신

  1. 스켈레톤 렌더링을 통한 체현 간 통합 조건: 로봇 팔과 인간 손을 동시에 2D 운동학적 스켈레톤으로 다루는 최초의 동작 조건부 세계 모델입니다. 핵심 혁신은 '무질감' — 모델이 로봇 외관을 기억하는 대신 운동학과 실제 동작의 관계를 명시적으로 학습해야 하며, 이는 OOD 성능 저하를 직접 완화합니다. 메시 렌더링(URDF 자산 의존)과 포인트 클라우드(외관 과적합)에 비해 스켈레톤은 표현력과 일반화 사이에서 더 나은 균형을 달성합니다.

  2. 인간 데이터 긍정적 전이의 실증: 로봇 전용 훈련에 85,827개의 인간 손 클립(EgoDex+EPIC-Kitchens)을 추가하여 모든 지표가 지속적으로 개선되었습니다(FVD 7.69→7.08, FID 16.37→15.07). 이는 인간 1인칭 비디오가 로봇 데이터 부족 문제를 효과적으로 보완할 수 있음을 처음으로 입증했으며, warm-start 전략(로봇 먼저, 혼합 나중)이 처음부터 혼합하는 것보다 수렴이 더 빠릅니다.

  3. 재현 가능한 평가 프로토콜: 4개 체현에 걸친 200클립 평가 벤치마크(N 제곱근 할당으로 긴 꼬리 균형)를 구축하고, RoboArena 플랫폼(65세션×7정책=455유닛)으로 비디오 생성 품질과 하위 정책 평가 간의 상관관계를 처음으로 검증했습니다(Spearman ρ=0.750, Pearson r=0.852). GPT-5를 VLM 스코어러로 사용(인간 라벨과 78/100 일치).

체현별 성능(표 6-11)

OSCAR는 AgiBot G1(PSNR 23.70), DROID(21.60), InternData(27.65), RH20T-cfg5(26.92), RH20T-cfg7(25.85)에서 모두 최적입니다. AIROA-MoMa에서만 Genie Envisioner에 뒤처집니다(PSNR 20.77 vs 23.31). 이는 이동 베이스+팔 조합이 훈련 데이터에서 차지하는 비중이 극히 작기 때문입니다(3,712클립).

경계 및 한계

  • 데이터 규모는 캘리브레이션 품질에 제한됨: 카메라 내부/외부 파라미터 오차는 스켈레톤-RGB 정렬을 직접 저하시켜 안정적으로 변환 가능한 원본 비디오 수를 제한합니다. 이는 현재 가장 큰 병목입니다 — 모델 용량이 아니라 캘리브레이션 품질입니다.
  • 정적 카메라 가정: 로봇 동작에만 초점을 맞추며, 카메라 움직임은 향후 작업으로 남겨둡니다. 이는 이동 조작의 능동 시각(active perception) 시나리오에는 적용할 수 없음을 의미합니다.
  • 2B 백본 상한: 2B 파라미터만 사용하며, 저자는 더 큰 백본으로 확장하면 추가 개선이 가능하지만 더 많은 계산이 필요하다고 인정합니다.
  • VLM 스코어러 보수적: GPT-5의 재현율은 0.66에 불과하여 실제 성공의 약 1/3을 놓치며, 성공률을 과대평가하지 않고 과소평가합니다. 정책 평가의 절대 성공률 수치는 주의 깊게 해석해야 합니다.
  • AIROA-MoMa 일반화 부족: 이동 베이스+팔 조합이 훈련 데이터에서 차지하는 비중이 극히 작으며(3,712/180,657 ≈ 2%), OSCAR는 이 하위 집합에서 Genie Envisioner에 뒤처집니다. 긴 꼬리 체현에는 여전히 더 많은 데이터가 필요함을 시사합니다.
  • 소거 연구 정량 세부 사항 미공개: 표 3은 본문에서만 언급되고, 부록에는 정성적 그림만 제공됩니다. 인간 데이터 정량 평가 지표는 제공되지 않았습니다.

엔지니어링 시사점

  • 재현 시 데이터 파이프라인 우선 확인: 필터링 후 180,657/2,165,359클립(8.3% 보존율)만 유지되며, 의미론적 중복 제거(SigLIP>0.95 + 64단계 궤적 RMS)가 핵심 단계입니다. 중복 제거를 건너뛰면 중복 클립이 훈련을 지배하고 일반화를 저해합니다. DROID의 1–2fps 다운샘플링(클립 길이가 다른 소스의 약 5배이므로)과 RH20T의 cfg5/cfg7 선택(cfg1은 고유 수용 감각 부족, cfg3은 외부 파라미터 캘리브레이션 오류)을 먼저 재현하는 것이 좋습니다.
  • 스켈레톤 렌더링 구현 요점: 조건 주입은 '스켈레톤 잠재 z^s와 대상 잠재 z^v의 요소별 덧셈'이며, 연결이 아닙니다 — 이는 두 VAE 인코딩 후 형태가 완전히 동일해야 함을 요구합니다. 체현 변경 시 운동학 삼중항 (M, q_t, o_k)만 업데이트하면 되지만, 카메라 외부 파라미터 o_k와 스켈레톤 렌더링의 투영 행렬이 엄격히 정렬되어야 합니다. 그렇지 않으면 스켈레톤-RGB 오프셋이 생성 품질을 직접 저하시킵니다.
  • 훈련 전략: warm-start(로봇 15k 반복 먼저, 인간 데이터 혼합 나중)가 처음부터 혼합하는 것보다 수렴이 빠르고 효과가 좋습니다. 데이터 균형은 빈도 온도 가중치 T=3을 사용하여 작은 데이터 소스(예: AIROA-MoMa 3,712클립)의 가중치를 높일 수 있습니다. 훈련 창 81프레임, 시작 프레임은 사다리꼴 사전 확률로 그리핑/릴리스 이벤트에 편향 — 이는 그리퍼 개폐 신호를 활용하며 조작 비디오 생성에 중요합니다.
  • 평가 프로토콜: 지표는 처음 49프레임에서 계산됩니다(Kinema4D 프로토콜 준수). 정책 평가 시 GPT-5 스코어링의 보수성(재현율 0.66)에 주의하고, 절대 성공률만이 아닌 MMRV와 Spearman ρ를 함께 보고하는 것이 좋습니다. 카메라 캘리브레이션은 MoGe-v2(내부 파라미터) + CtRNet-X(외부 파라미터, BPnP 대 URDF 정운동학)를 사용 — 이는 정책 평가 재현의 가장 큰 엔지니어링 위험 지점입니다.
  • 가장 흔한 함정: IRASim의 7-DoF 동작 인터페이스는 양팔 AgiBot G1과 이동 베이스 AIROA-MoMa와 호환되지 않으므로 비교 시 제외해야 합니다. EnerVerse-AC의 파라미터 수는 공식적으로 보고되지 않았습니다(저자 실측 U-Net 훈련 가능 파라미터 1.46B). Kinema4D는 추론이 매우 느리므로(0.089FPS), 정책 평가 시 충분한 시간을 확보해야 합니다.
