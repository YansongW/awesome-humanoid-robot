Universal Manipulation Exoskeleton: Learning Compliant Whole-body Policies with Real-time Torque Feedback

요약

For robots to work safely in household environments, they need to be compliant and react to torque and force feedback during contact. However, the majority of existing data collection pipelines still lack the ability to capture force and torque data for learning active compliant policies. Institutions per source list: Ant Group、Stanford University.

출처

  • arXiv:2606.14218 Universal Manipulation Exoskeleton: Learning Compliant Whole-body Policies with Real-time Torque Feedback
  • GitHub仓库 Robotics_Notebooks

개요

UME(Universal Manipulation Exoskeleton)는 저비용($1900), 7-DoF 웨어러블 외골격 원격 조작 시스템으로, 동축 액추에이터 배치와 범용 리타게팅 알고리즘을 통해 관절 수준의 양방향 토크 피드백과 로봇 간(OpenArm, Franka, X-ARM) 원격 조작을 구현합니다. 핵심 기여는 토크 데이터를 학습 파이프라인에 통합하여 ACT 정책이 능동적 컴플라이언트 전완 동작을 학습할 수 있게 하고, 힘 집약적 작업에서 무토크 베이스라인 및 UMI 패러다임을 크게 능가한다는 점입니다.

무엇을 바꾸었는가

기존 원격 조작 데이터 수집 파이프라인(ALOHA, GELLO, UMI 핸드헬드)은 관절 토크 센싱이普遍적으로缺失되어 있습니다. 이는 단순한 하드웨어 격차가 아니라 학습 패러다임의 한계입니다—토크 데이터가 없으면 정책은 위치/궤적만 학습할 수 있고, "얼마나 힘을 써야 하는지, 언제 양보해야 하는지"와 같은 컴플라이언트 동작을 학습할 수 없습니다. 저자들이 실제로 바꾼 것은 원격 조작을 "모션 캡처 도구"에서 "힘 감각 상호작용 인터페이스"로 업그레이드한 것입니다: 조작자는 팔과 환경 간 접촉 저항을 실시간으로 느끼고, 동시에 관절 수준 토크 신호를 정책 학습용으로 기록합니다. 이는 VLA 모델과 로봇 세계 모델이 컴플라이언스를普遍적으로 강조하지 않는 근본 원인—힘 및 토크 데이터 부족—에 직접적으로 대응합니다.

또 다른 개선된痛点은 전완 형상 제어입니다. UMI식 핸드헬드 수집은 엔드 이펙터 포즈만 기록하고, 추론 시 IK로 충돌 제약을 해결하는데, 고도로 제한된 공간(예: GPU 삽입, 냉장고 물건 꺼내기)에서 매우 실패하기 쉽습니다. UME는 범용 리타게팅을 통해 외골격과 종속 팔의 운동 사슬을 어깨/팔꿈치/손목 세 개의 서브 매니퓰레이터로 분해하고, 위치, 속도, 토크를 독립적으로 리타게팅하여 6D 태스크 공간 제어의 특이점 문제를 피하면서, 조작자가 엔드 이펙터뿐만 아니라 전완 형상을 직관적으로 제어할 수 있게 합니다.

방법 분해

하드웨어 설계

  • 동축 액추에이터 구성: J1-J3 축은 어깨 볼 조인트 중심에서 교차하고, J5-J7 축은 손목 볼 조인트 중심에서 교차하며, J4는 팔꿈치 조인트에 해당하여 인간의 어깨/손목 전체 운동 범위를 복제합니다.
  • 액추에이터 선정: 어깨에는 Damiao DM-J4340-2EC(9Nm, 362g, 40:1 감속비)를 선택하여 휴대성, 토크 투명성, 중력 보상에 필요한 토크 간 균형을 맞췄습니다; 크로스 롤러 베어링 버전(마찰 증가)과 더 낮은 감속비 버전(고정자 과중)은 거부했습니다.
  • 총 비용: $1900, 무게 약 12kg(PLA 구조), 일반 성인이 2시간 동안 편안하게 착용 가능.

범용 리타게팅(Universal Retargeting)

외골격과 종속 팔을 세 개의 서브 매니퓰레이터로 분해: 가상 3-DoF 볼 어깨, 1-DoF 팔꿈치, 가상 3-DoF 볼 손목. 각 서브 구조는 독립적으로 리타게팅됩니다:

  1. 위치 피드포워드: 어깨 q_shoulder_exo는 FK를 통해 회전 행렬 R_shoulder_exo를 얻고, IK를 통해 종속 팔 q_shoulder_robot으로 매핑; 팔꿈치는 직접 미러링; 손목도 동일.
  2. 속도 피드포워드: ω_shoulder = J_shoulder_exo · q̇_shoulder_exo, 종속 팔 명령 q̇_shoulder_robot = (J_shoulder_robot)† · ω_shoulder; 비레던던트 3-DoF 서브 팔의 경우, 유사역행렬은 표준 역행렬 J† = J⁻¹로 단순화.
  3. 토크 피드백: 종속 팔 토크 τ_shoulder_robot는 동역학 일관 전치 매핑을 통해 공간 힘 F_shoulder = (J̄_shoulder_robot)^T · τ_shoulder_robot으로 변환, 여기서 J̄ = A⁻¹J^T(JA⁻¹J^T)⁻¹; 외골격 피드백 토크 τ_shoulder_exo = (J_shoulder_exo)^T · F_shoulder; 팔꿈치는 직접 매핑 τ_elbow_exo = τ_elbow_robot.
  4. 토크 투명성: 명령 토크 τ_command_exo = c(q, q̇) + g(q) + f(q̇) + τ_feedback_exo, 코리올리, 중력, 마찰 보상 포함.

이동 베이스 및 학습 프레임워크

  • IMU 제어: 약 \(9의 IMU 3D 오일러 각도를 이동 베이스 속도 [ẋ, ẏ, θ̇]로 선형 매핑; VR 헤드셋(\)300)이 대안.
  • 이동 베이스: Tidybot++ 업그레이드 버전, FRC swerve 모듈을 Hexfellow PCW-25 파워 캐스터($900×4)로 교체, 더 낮은 감속비와 백래시 감소로 컴플라이언스와 오도메트리 정밀도 향상.
  • 학습: ACT(Action Chunking with Transformers), ResNet18 백본, 토크 데이터는 관절 위치와 동일하게 처리되며, 임베딩이 이미지 임베딩 뒤에 추가되어 Transformer 인코더-디코더에 입력되고, 원하는 관절 위치를 출력.

핵심 혁신

  1. 관절 수준 양방향 토크 피드백 원격 조작 패러다임: HOMIE, AirExo 등 위치 원격 조작만 하는 외골격과 달리, UME는 조작자가 종속 팔에 가해지는 저항을 실시간으로感知하게 하고, 토크 데이터가 직접 학습 파이프라인에 들어갑니다. 이는 "운동 데이터 수집"이 아닌 "힘 감각 데이터 수집"의 패러다임 전환으로, 능동적 컴플라이언트 정책 학습을 가능하게 합니다.

  2. 범용 리타게팅의 분리 아키텍처: 7-DoF 팔을 어깨/팔꿈치/손목 세 개의 서브 매니퓰레이터로 분해하여 독립적으로 리타게팅함으로써 6D 엔드 이펙터 태스크 공간 제어의 운동학적 특이점을 피하고, 각 서브 팔의 야코비안 역행렬이 서로 간섭하지 않습니다. 이 설계로 동일한 외골격이 다른 운동학적 구성을 가진 로봇(OpenArm, Franka, X-ARM)을 재보정 없이 원격 조작할 수 있습니다.

  3. 저비용 고투명성 하드웨어 설계: $1900 총 비용으로 관절 수준 토크 피드백을 구현, 준직결 구동 모터(Damiao/Unitree)와 동축 배치를 통해 휴대성, 토크 투명성, 부하 지지 간 균형을 달성. AirExo 등 방식과 비교해 UME는 저비용을 유지하면서 완전한 양방향 힘 감각 상호작용을 제공합니다.

실험 및 결과

표 1: 작업 성공률(각 20회 시험)

방법 Box Pushing Box Flipping GPU Picking Fridge Drink Retrieval
No-torque 0.50 0 0.75 0.90
UMI 0.40 0 0 0
UME (Ours) 0.90 0.85 0.95 0.95
  • Box Pushing(26 데모): UME 0.9 vs No-torque 0.5 vs UMI 0.4, 토크 피드백으로 80%(표 값 0.5→0.9 기준 계산) 상대적 향상.
  • Box Flipping(40 데모): UME 0.85, No-torque와 UMI 모두 0—가장 전형적인 힘 집약적 작업으로, 무토크 데이터로는 전혀 학습 불가.
  • GPU Picking(42 데모): 그리퍼 삽입 후 간격 5mm에 불과, UME 0.95 vs No-torque 0.75, UMI 0—고도로 제한된 공간에서 UMI의 엔드 이펙터 포즈+IK 패러다임의 근본적 결함 노출.
  • Fridge Drink Retrieval(157 데모): UME 0.95 vs No-torque 0.90, UMI 0; 단계별 성공률에서 UMI는 "음료 꺼내기" 단계에서 실패(0.00), 이후 모든 단계가 0.
  • 데이터 수집 처리량: box flipping 작업에서 UME는 무토크 베이스라인 대비 3.3× 향상, 실행 속도는 인간 속도의 71%.
  • 범용 원격 조작: 실제 세계에서 이중 팔 X-ARM으로 블록 집기, 이중 팔 전달 및 컵에 넣기 성공; Franka는 MuJoCo 시뮬레이션에서만 시연.

학습 구성: ACT 모델 40k 그래디언트 스텝, 8시간(단일 RTX 4090); batch size 200, ResNet18, 인코더 4층, 디코더 7층, 피드포워드 차원 3200, 히든 차원 512, 8헤드, dropout 0.1, 이미지 백본 lr 1×10⁻⁵, transformer lr 1×10⁻⁴.

경계 및 한계

  • 하드웨어 한계: PLA 링크로 인해 무게가 비교적 높고(약 12kg), 페이로드가 더 비싼 대안보다 낮음; 링크 크기가 고정되어 조절 불가, 도달 범위와 인체공학에 영향.
  • Franka는 시뮬레이션만: 납품 지연으로 Franka 원격 조작은 MuJoCo에서만 시연, 실제 하드웨어에서 검증되지 않음; 저자는 실제 성능이 유사하거나 더 나을 것으로 예상(Franka 관절 토크 센싱이 더 정밀하기 때문)하지만, 이 예상은 검증되지 않음.
  • 미언급: 실제 Franka 팔 실험, 조절 가능한 링크 버전, 생산급 경량화 버전, 추론 빈도, 데이터량 통계.
  • 결론 경계: 모든 성공률 데이터는 20회 시험 기반, 통계적 유의성은 보고되지 않음; 데이터 수집 처리량 향상(3.3×)은 box flipping 단일 작업 측정에만 기반.

공학적 시사점

  • 먼저 토크 데이터 품질 확인: UME의 핵심 가치는 토크 피드백에 있으므로, 재현 시 외골격 토크 투명성(코리올리/중력/마찰 보상 충분 여부)을 우선 검증해야 합니다. 그렇지 않으면 피드백 토크 노이즈가 학습 신호를 직접 오염시킵니다.
  • 서브 팔 분해 적용 조건 주의: 범용 리타게팅은 어깨/손목이 3-DoF 볼 조인트, 팔꿈치가 1-DoF 회전이라는 가정에 의존합니다. 대상 종속 팔 구성이 이 분해를 충족하지 않으면(예: 4-DoF 어깨), 야코비안과 동역학 일관 역행렬을 다시 유도해야 하며 직접 적용할 수 없습니다.
  • 데이터량 참고: 힘 집약적 작업(Box Flipping)은 40 데모만으로 0.85 성공률 달성 가능하지만, Fridge Drink Retrieval은 157 데모 필요—작업 복잡도와 데모 요구량은 비선형적으로 증가하므로, 작업 복잡도에 따라 데이터 수집 시간을 계획하는 것이 좋습니다.
  • 하드웨어 선정 함정 피하기: 어깨 액추에이터 선정이 핵심 결정—DM-J4340-2EC는 토크 투명성과 부하 지지 간 균형; 크로스 롤러 베어링 버전(DM-J4340P)을 선택하면 마찰 증가로 토크 투명성이 낮아지고, 더 낮은 감속비 버전(DM-J8006)을 선택하면 고정자 과중으로 휴대성이 희생됩니다.
  • 이동 베이스 업그레이드 방향: Tidybot++의 swerve 모듈(\(300)이 Hexfellow PCW-25(\)900)로 교체된 이유는 더 낮은 기어비와 백래시 감소—예산이 제한적이면 원래 베이스를 유지할 수 있지만 컴플라이언스와 오도메트리 정밀도 저하를 감수해야 합니다.
  • 학습 구성 직접 재사용 가능: ACT 하이퍼파라미터(batch 200, ResNet18, 4층 인코더, 7층 디코더, 40k 스텝)는 4개 작업 모두에서 유효하므로, 새 작업의 시작 구성으로 사용할 수 있습니다.
