Unified Walking, Running, and Recovery for Humanoids via State-Dependent Adversarial Motion Priors

Unified Walking, Running, and Recovery for Humanoids via State-Dependent Adversarial Motion Priors

요약

We propose a unified reinforcement learning framework that enables a single policy to perform walking, running, and fall recovery on the Unitree G1 humanoid robot, validated on physical hardware without any explicit mode-switching command at deployment. Institutions per source list: 香港大学等.

출처

  • arXiv:2605.18611 Unified Walking, Running, and Recovery for Humanoids via State-Dependent Adversarial Motion Priors
  • 万字长文，读懂人形机器人AMP：19篇论文搭起的运动先验圣经

개요

본 논문은 상태 의존 적대적 운동 사전(State-Dependent Adversarial Motion Priors)에 기반한 통합 휴머노이드 로봇 제어 프레임워크를 제안한다. 단일 actor 정책 하에서 게이팅 함수를 통해 복구 및 운동 판별기를 전환하여 보행, 달리기, 낙상 복구를 종단 간 학습한다. 저자는 Unitree G1에서 엎드린/누운 자세 복구부터 보행/달리기까지의 전체 시퀀스를 배포 시 명시적 모드 전환 없이 검증했다.

무엇이 바뀌었는가

기존 휴머노이드 로봇 제어는 보행, 달리기, 복구를 독립적인 모듈로 간주하고 수작업 FSM으로 조정하여 모드 경계가 취약하고 전환 품질이 저하되는 문제가 있었다. 기존 AMP 방법은 종단 간 학습이 가능하지만, 단일 공유 운동 사전으로는 고속 달리기와 복구의 동역학적 특성을 동시에 포착할 수 없었다—달리기의 통계적 특성이 손실되거나 복구와 운동 분포가 혼동되었다. 본 논문이 실제로 바꾼 것은 '모드'를 아키텍처 설계 문제에서 판별기 조건화 문제로 전환한 것이다. 속도 명령으로 보행/달리기 참조 분포를 연속적으로 보간하고, 중력 투영으로 복구 모드를 게이팅하여 단일 정책이 추론 시 어떤 모드 로직도 없이 세 가지 행동을 모두 커버할 수 있게 했다. 이는 수작업 튜닝이 필요한 전환 로직을 제거하고 모드 전환을 학습된 암시적 행동으로 만들었다.

방법 분석

전체 아키텍처

  • 단일 actor 정책 πθ(a_t|o_t), 종단 간 훈련, 동결된 ONNX 모델로 배포, 런타임 모드 로직 없음.
  • 관측 o_t는 96차원(신체 각속도, 투영 중력, 명령 속도, 상대 관절 위치/속도, 이전 행동)이며, 4프레임 히스토리를 연결하여 384차원 입력 생성; 행동 a_t ∈ ℝ²⁹는 목표 관절 위치이며, 하위 PD 컨트롤러가 추적.

이중 판별기 설계

  • 복구 판별기 D_φ^rec: 낙상 복구 참조 클립(fallAndGetUp2_subject2)에서만 훈련.
  • 속도 조건화 운동 판별기 D_φ^loco: 정규화된 명령 속도 v̂_t = min(v_x^cmd / v_max, 1)를 추가 입력으로 받아 보행(walk1_subject1) 및 달리기(run1_subject2) 참조에서 공동 훈련. 각 판별기 업데이트 시 확률 (1−v̂_t)로 보행 참조, 확률 v̂_t로 달리기 참조를 샘플링하여 조건 일관된 분포 보간 구현.

게이팅 메커니즘

  • 게이팅 함수 z_t = rec (|g_z + 1| > 0.6), 그 외 loco. 여기서 g_z는 투영 중력 z성분(직립 시 ≈ −1, 낙상 시 0 또는 양수에 근접).
  • 임계값은 약 37° 기울기에 해당하며, 중력 신호의 이중 모드 분포에서 점유율이 낮은 영역에 위치하여 학습 없이도 정확한 노이즈 내성을 확보.
  • 핵심 설계: 게이팅은 훈련 시에만 활성화되고, 추론 시 정책은 단일 통합 네트워크로 명시적 모드 변수가 없음.

훈련 목표

  • 작업 보상(식 1): R_t = w_v·R_cmd + w_s·R_smooth + w_p·R_posture − w_e·C_energy − w_f·C_fall.
  • AMP 보상(식 3): R_AMP = −log(1 − D_φ^rec(s_t, s_t+1)) (z_t = rec일 때); R_AMP = −log(1 − D_φ^loco(s_t, s_t+1|v̂_t)) (z_t = loco일 때).
  • 총 보상(식 4): R_t^total = R_t + λ_amp·R_AMP, λ_amp = 0.5.
  • 훈련 알고리즘: PPO, 3층 MLP, Isaac Lab 시뮬레이션.

핵심 혁신

  1. 속도 조건화 판별기가 다중 모드 사전을 대체: v̂_t를 통해 보행/달리기 참조 간 연속 보간하여 여러 운동 판별기 훈련이나 수작업 모드 경계 정의를 피함. 이는 AMP 프레임워크의 핵심 확장—행동 모드를 이산 모듈이 아닌 조건 변수로 인코딩.
  2. 중력 투영 게이팅의 단순성: 중력 신호의 자연스러운 이중 모드 분포 특성을 활용하여 고정 임계값(37°)으로 복구/운동 판별기 전환을 구현. 게이팅 네트워크 학습이 필요 없고, 훈련 시 활성화·추론 시 은닉되어 배포 정책의 순수성을 보장.
  3. 극소 참조 데이터: LAFAN1의 3개 클립(보행 1 + 달리기 1 + 복구 1)만으로 세 가지 행동을 커버할 수 있어, 조건화 판별기가 제한된 참조 데이터를 효율적으로 활용하고 대규모 운동 라이브러리 의존도를 낮춤.

실험 및 결과

실험 내용 설정 핵심 결과
시뮬레이션 훈련 Isaac Lab, PPO, λ_amp=0.5, 3층 MLP 속도 추적 범위 일반 [−0.5, 1.0] m/s, 고속 [−1.5, 3.0] m/s
하드웨어 배포 Unitree G1, 50 Hz, ONNX 모델 엎드린/누운 자세 복구 성공, 동일 컨트롤러에서 보행→달리기 부드러운 전환
보행 특성 시뮬레이션 관찰 보행: 규칙적인 발뒤꿈치-발가락 접촉; 달리기: 보폭 증가, 이중 지지상 단축
도메인 전이 표준 시뮬레이션 파라미터 무작위화만 적용 sim-to-real 적응이나 도메인 무작위화 미세 조정 없이 직접 배포 성공

결과 의미: 하드웨어 실험은 단일 정책이 모드 전환 명령 없이 '복구→보행→달리기' 전체 시퀀스를 완료할 수 있음을 증명했으며, 보행 특성은 생체역학적 기대에 부합. 고속 모드는 명시적 운영자 명령이 필요하며, 저자는 이를 '의도적 안전 제약'이라고 설명.

경계 및 한계

논문은 한계를 명시적으로 논의하지 않음. 식별 가능한 경계: 고속 모드는 명시적 운영자 명령에 의존(자율 결정 아님); 게이팅 임계값(37°)에 대한 체계적 민감도 분석 없음; 옆으로 누운 자세 등 더 다양한 낙상 자세 미검증, 계단/경사 등 복잡한 지형 미테스트; 속도 범위가 3.0 m/s를 초과하지 않음; FSM 조정 모듈식 베이스라인과의 정량적 비교 없음. 훈련 데이터 양, 훈련 시간, 하드웨어 사양은 언급되지 않음.

공학적 시사점

재현 시 다음 세 가지를 우선 확인: 게이팅 임계값(|g_z + 1| > 0.6)이 대상 로봇의 중력 신호 분포에서 여전히 이중 모드인지—센서 노이즈나 설치 편차로 분포가 이동하면 재보정 필요; 속도 조건 보간(v̂_t)의 v_max 설정이 보행/달리기 참조 샘플링 비율에 직접 영향을 주므로 명령 속도 범위와 일치해야 함; 참조 데이터 리타겟팅 품질—클립이 3개뿐이므로 역운동학으로 대상 로봇 관절 공간에 리타겟팅할 때 운동학적 왜곡이 발생하면 판별기가 잘못된 사전을 학습하게 됨. 가장 흔한 함정은 훈련 시 게이팅 활성화와 추론 시 은닉의 차이: 배포 코드에 모드 변수가 남아 있지 않은지 확인해야 함—그렇지 않으면 정책 입력 분포가 훈련과 불일치. 하위 팀이 속도 범위를 확장하거나 새 행동 모드를 추가해야 한다면 판별기 수를 늘리는 대신 v̂_t 조건화 방식을 조정하는 것이 우선.
