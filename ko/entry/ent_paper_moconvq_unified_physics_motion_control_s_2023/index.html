MoConVQ: Unified Physics-Based Motion Control via Scalable Discrete Representations

MoConVQ: Unified Physics-Based Motion Control via Scalable Discrete Representations

요약

In this work, we present MoConVQ, a novel unified framework for physics-based motion control leveraging scalable discrete representations. Building upon vector quantized variational autoencoders (VQ-VAE) and model-based reinforcement learning, our approach effectively learns motion embeddings from a large, unstructured dataset spanning tens of hours of motion examples.

출처

  • arXiv:2310.10198 MoConVQ: Unified Physics-Based Motion Control via Scalable Discrete Representations

개요

MoConVQ는 벡터 양자화 변분 오토인코더(VQ-VAE)와 모델 강화 학습을 기반으로 하는 통합 물리 캐릭터 모션 제어 프레임워크로, 연구팀에 의해 제안되었으며, 물리 캐릭터가 수십 시간 분량의 대규모 예시 모션 데이터에서 다양한 기술을 습득하고, 상호작용 제어, 물리 포즈 추정, 텍스트 기반 모션 생성 및 대규모 언어 모델 통합을 위한 통합 인터페이스를 제공하는 것을 목표로 합니다. 핵심 기여는 잔차 VQ-VAE(RVQ)를 도입하여 확장 가능한 이산 모션 표현을 구축하고, 미분 가능한 세계 모델과 결합하여 효율적인 훈련을 달성하며, 최종적으로 미지의 모션 추적, 텍스트 기반 모션 생성 등의 작업에서 해당 표현의 견고성과 일반화 능력을 검증한 것입니다.

무엇을 바꾸었는가

오랫동안 물리 캐릭터 애니메이션은 두 가지 문제에 묶여 있었습니다. 첫째, 데이터셋 규모가 분 단위에 머물러 학습된 기술 라이브러리가 극도로 제한적이었고, 둘째, 잠재 모션 표현에 의미론이 부족하여 사용자가 잠재 공간에서 원하는 동작을 직관적으로 선택하거나 조합할 수 없었으며, 각 특정 작업마다 보상 함수를 재설계하고 상위 정책을 훈련해야 했습니다. MoConVQ가 진정으로 바꾼 것은 "모션 표현"을 연속 잠재 변수에서 이산 코드북으로 전환하고, 이 코드북을 모든 하위 작업의 통합 인터페이스로 만든 것입니다. 이러한 전환의 심층적 의미는 다음과 같습니다. 이산 코드는 자연스럽게 조합 가능할 뿐만 아니라(인덱스 튜플은 언어 모델이나 상위 정책이 직접 소비할 수 있음), 양자화 과정 자체가 원시 모션의 고주파 노이즈와 물리적 불일치를 걸러내어 물리 시뮬레이터가 추적 시 데이터 결함에 오도되지 않도록 합니다. 또한 저자는 이전 방법에서 균형 유지를 위해 루트 잔여 힘에 의존하던 "인형극" 메커니즘을 명시적으로 배제하여, 캐릭터가 순수 물리 구동 하에서 안정성을 유지하도록 했으며, 이는 이후 포즈 추정, 텍스트 생성 등의 작업에 더 신뢰할 수 있는 물리적 기반을 제공합니다.

방법 분해

전체 아키텍처

MoConVQ는 세 부분으로 구성됩니다: 인코더 ℰ(1D 컨볼루션 네트워크), 디코더 𝒟(1D 디컨볼루션 네트워크 + 제어 정책 𝝅 + 시뮬레이션 모듈), 이산 코드북 ℬ. 입력 모션 클립 𝑴(T=24프레임, 1.2초)은 ℰ를 통해 잠재 벡터 시퀀스 𝑽로 인코딩되고, 최근접 이웃 검색을 통해 코드 시퀀스 𝒁로 양자화되며, 디코더는 시뮬레이션 환경에서 모션 𝑴̃를 재구성합니다.

잔차 VQ-VAE(RVQ)

  • N=8개의 양자화 레이어를 사용하며, 각 레이어의 코드북 크기는 |ℬ|=512, 코드 차원은 768입니다.
  • 양자화 과정은 레이어별로 진행됩니다: 첫 번째 레이어는 원래 잠재 벡터를 양자화하고, 이후 레이어는 이전 레이어의 잔차 r_d = 𝒗 − ∑_{j<d} 𝒛_j를 양자화합니다.
  • 최종 코드는 각 레이어 코드의 합 𝒛^k = ∑_{d=0}^{N} 𝒛_d^k이며, 이는 인덱스 튜플 I^k = (I_0^k, …, I_N^k)과 동일합니다.
  • 핵심 설계 근거: 코드북을 직접 키우는 대신, RVQ는 모델 용량이 레이어 수에 따라 지수적으로 증가하게 하면서, 조대한 것에서 세밀한 것까지의 계층적 표현을 구축합니다—조대한 코드는 모션의 주요 성분을 포착하고, 세밀한 코드는 세부 사항을 보완합니다.

미분 가능한 세계 모델 훈련

  • 시뮬레이션을 블랙박스로 간주하고, 4층 MLP(512 유닛) 세계 모델 𝒲를 훈련하여 시뮬레이터를 근사함으로써 디코딩 과정을 완전히 미분 가능하게 만듭니다.
  • 훈련 흐름: 매 라운드마다 세계 모델과 MoConVQ 구성 요소를 번갈아 업데이트합니다. 세계 모델은 캐릭터가 무작위 참조 모션을 추적하도록 하여 시뮬레이션 시퀀스를 생성하고, 𝒲를 재생하여 합성 시퀀스를 생성한 후 손실 ℒ_𝒲 = ‖𝑴̃_sim − 𝑴̃_𝒲‖를 최적화합니다.
  • MoConVQ 구성 요소는 손실 ℒ = ‖𝑴 − 𝑴̃_𝒲‖ + β₁‖ℰ(𝑴) − sg(𝒁)‖ + β₂‖sg(ℰ(𝑴)) − 𝒁‖ + β₃ℒ_reg를 최적화하며, 처음 세 항은 표준 VQ-VAE 손실(재구성, 커밋먼트, VQ 목표)이고, ℒ_reg는 동작 정규화입니다.

동작 정규화 및 코드북 유지

  • 동작 정규화: ℒ_reg = Σ_t w₁‖𝒂̂^t − 𝒂̄_t‖ + w₂‖𝒂̂^t‖, 여기서 𝒂̄_t는 동작의 지수 이동 평균(EMA)이며 β=0.8입니다. 첫 번째 항은 부드러운 동작 시퀀스를 장려하고, 두 번째 항은 동작 크기를 제한합니다.
  • 코드북 EMA 업데이트: ℬ ← (1−γ)ℬ + γℬ̂, γ=0.99; 동시에 비활성 코드를 재설정하여 코드북 붕괴를 완화합니다.
  • 양자화기 드롭아웃: 훈련 시 무작위로 전방 RVQ 레이어 범위를 선택([1, N]에서 무작위 선택)하여 모션이 임의의 전방 레이어 표현으로 사용 가능하게 하여, 런타임 시 표현 복잡도와 재구성 품질 사이를 조절할 수 있게 합니다.

하위 작업 인터페이스

  • 일반 추적 제어: 인코더-디코더 구성, 양자화 임베딩이 노이즈를 걸러내어 미지의 모션을 모방할 수 있습니다.
  • 상호작용 제어: 디코더 전용 구성, 상위 정책 𝝅_steering이 자기회귀적으로 잠재 코드를 예측하며, 계획 샘플링(초기 p=0.8에서 점진적으로 0으로 감소)으로 훈련합니다.
  • MoConGPT: 인덱스 기반 GPT, 이중 Transformer 아키텍처(시간 Transformer N_T=12레이어, 깊이 Transformer N_D=5레이어), 훈련 손실은 음의 로그 우도 ℒ_GPT입니다.
  • LLM 통합: 인덱스-디코더 전용 구성, 컨텍스트 내 학습(ICL)을 통해 Claude-2에 1600개의 텍스트-인덱스 쌍 예시를 제공하며, 미세 조정 없이 수행됩니다.

핵심 혁신

  1. 물리 모션 표현으로서의 잔차 VQ-VAE: RVQ를 물리 캐릭터 제어에 도입한 것은 이번이 처음입니다. 연속 잠재 변수와 달리, 이산 코드북은 용량이 확장 가능할 뿐만 아니라(8레이어 × 512코드), 자연스럽게 노이즈 내성을 갖습니다—절제 실험에 따르면 가우시안 노이즈를 추가했을 때 연속 VAE의 추적 정확도는 크게 떨어지지만, MoConVQ의 성능은 거의 변하지 않습니다. 이 특성은 실제 모션 캡처 데이터의 결함을 처리하는 데 중요합니다.
  2. 다중 작업을 포괄하는 통합 인터페이스: 동일한 이산 표현이 상호작용 제어, 물리 포즈 추정, 텍스트 기반 모션 생성 및 LLM 통합을 동시에 지원합니다. 특히 LLM 통합은 컨텍스트 내 학습을 통해 Claude-2가 인덱스 시퀀스를 직접 출력하게 하여, 미세 조정 없이도 "걷고 나서 앉기"와 같은 조합 동작을 생성할 수 있으며, 이 동작 조합은 훈련 데이터에 없습니다—이는 이산 표현이 "모션 언어"로서 의미론적 조합 가능성을 보여줍니다.
  3. 잔여 힘 없는 완전 물리 구동: MoConVQ는 물리 포즈 추정 작업에서 루트 잔여 힘을 전혀 사용하지 않으며, SimPoE의 무근력 버전(MPJPE=115.2 mm)과 비교하여 MoConVQ는 125.6 mm로 정확도는 약간 낮지만, 모션 부드러움(e_smooth=3.4 vs 23.5)이 현저히 우수하고 물리적으로 더 사실적입니다.

절제 실험(HDM05 + 가우시안 노이즈 ε∼N(0,0.1))

  • 연속 VAE는 깨끗한 데이터에서 정확도가 더 높지만, 노이즈 하에서 성능이 크게 저하됩니다; MoConVQ는 노이즈 하에서 성능이 거의 변하지 않습니다.
  • 잔차 레이어는 추적 정확도를 현저히 향상시키면서 양자화 견고성을 유지합니다.

경계 및 한계

논문에서 명확히 다루지 않은 부분은 다음과 같습니다: MoConGPT 및 T2M-MoConGPT의 정량적 평가 지표(정성적 예시만 제공); 더 복잡한 작업에서의 LLM 통합에 대한 체계적 평가. 저자가 인정한 한계는 다음과 같습니다: 모델이 데이터셋에서 희소하고 고립된 동작(예: 백플립)을 학습하기 어려움; 컨볼루션 디코더가 여러 미래 모션 코드를 필요로 하여 실시간 지연을 유발할 수 있음; 모션 표현이 신체 부위를 구분하지 않아 개별 사지를 제어하기 어려움; 프레임워크가 단일 캐릭터 동작만 지원하며 환경 상호작용이나 다중 에이전트로 확장되지 않음. 또한 물리 포즈 추정 작업에서 전역 위치 제어가 구현되지 않아 정렬되지 않은 MPJPE가 높음; 텍스트 생성 작업의 R-precision은 리타겟팅 전략의 영향을 크게 받음. 훈련 데이터의 결함(예: 트레드밀 캡처로 인한 발 미끄러짐)은 여전히 모델 성능을 저하시키며, EMA 소프트 제약이 완화하지만 완전히 제거하지는 못합니다.

공학적 시사점

MoConVQ를 재현할 때 다음 단계를 우선적으로 확인하십시오: 데이터 전처리—훈련 데이터는 20 FPS로 다운샘플링하고 시뮬레이션 캐릭터(19관절, 20강체)로 리타겟팅해야 하며, 리타겟팅 품질이 텍스트 생성 지표에 직접 영향을 미칩니다; 세계 모델과 MoConVQ의 교대 훈련—재생 버퍼 크기 50000, 매번 1024프레임 교체, 약 6일 훈련(RTX 3090), 세계 모델이 충분한 정확도로 먼저 수렴해야 하며, 그렇지 않으면 디코더의 그래디언트 신호가 신뢰할 수 없습니다; 동작 정규화—EMA 평활화 인자 β=0.8은 경험적 값으로, 너무 작으면 동작이 떨리고, 너무 크면 과도하게 평활화되어 세부 사항이 손실됩니다; 양자화기 드롭아웃—훈련 시 무작위로 RVQ 레이어 수를 선택하며, 이 기법을 생략하면 모델이 전체 8레이어에 의존하여 런타임 시 표현 복잡도를 유연하게 조절할 수 없습니다. 가장 함정에 빠지기 쉬운 부분은 데이터 결함 처리입니다: 모션 캡처 데이터의 고주파 노이즈는 VQ가 모션 세부 사항으로 오인할 수 있으므로, 훈련 전에 원시 데이터를 가볍게 평활화하는 것이 좋지만, EMA 하드 제약은 피해야 합니다(미세한 동작을 제거할 수 있음). LLM 통합의 경우, Claude-2의 100k 컨텍스트 제한에 주의하고, 예시 텍스트는 평균 167자 이내로 제한해야 하며, LLM이 때때로 동작을 과도하게 세분화하거나 의미적으로 유사한 완전한 예시를 직접 출력할 수 있으므로 추가 프롬프트 안내가 필요합니다.
