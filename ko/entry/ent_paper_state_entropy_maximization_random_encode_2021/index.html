State Entropy Maximization with Random Encoders for Efficient Exploration

State Entropy Maximization with Random Encoders for Efficient Exploration

요약

Recent exploration methods have proven to be a recipe for improving sample-efficiency in deep reinforcement learning (RL). However, efficient exploration in high-dimensional observation spaces still remains a challenge.

출처

  • arXiv:2102.09430 State Entropy Maximization with Random Encoders for Efficient Exploration
  • Project page
  • Project page
  • 智元、众擎都在卷的人形机器人运控基座：41篇论文看懂BFM

개요

RE3(Random Encoders for Efficient Exploration)는 무작위 초기화되고 훈련 중 고정된 인코더 표현 공간에서 k-최근접 이웃 상태 엔트로피 추정기를 사용하여 내재적 보상을 계산함으로써 심층 RL 탐색을 효율적으로 구동하는 방법을 제안합니다. 이 방법은 UC Berkeley 등 기관의 연구자들이 제안했으며, 핵심 기여는 학습된 표현이나 보조 작업 없이도 컨볼루션 아키텍처의 귀납적 편향만으로 효과적인 상태 엔트로피 최대화가 가능함을 증명하여 탐색 메커니즘을 크게 단순화하고 샘플 효율성을 향상시킨다는 점입니다.

무엇을 바꾸었는가

기존 상태 엔트로피 최대화 방법(Tao et al. 2020, Badia et al. 2020, Liu & Abbeel 2021)은 이론적으로는 정확하지만 실제로는 학습된 잠재 표현에 의존합니다——동역학 모델, 역동역학 예측 또는 대조 학습을 사용합니다. 이는 세 가지 비용을 초래합니다: 다중 목표 최적화의 불안정성, 추가 하이퍼파라미터 튜닝 부담, 그리고 상당한 계산 오버헤드입니다. RE3가 실제로 바꾼 것은 "탐색에는 학습이 필요하지 않다"는 전제입니다: 모든 학습된 표현을 무작위 고정 인코더로 대체하여 상태 엔트로피 추정을 "정교한 훈련이 필요한 보조 모듈"에서 "단일 순전파와 k-NN 쿼리"로 축소했습니다. 이는 단순한 엔지니어링 단순화일 뿐만 아니라, 개념적으로 탐색 문제를 "무엇을 학습할 표현인가"에서 "기존 구조적 사전 지식을 어떻게 활용할 것인가"로 되돌려 놓았으며, Ulyanov et al. (2018)과 Caron et al. (2018)이 발견한 컨볼루션 네트워크 자체가 강력한 귀납적 편향이라는 사실에 직접적으로 대응합니다.

방법 분해

핵심 공식 체인

  • k-NN 엔트로피 추정기 (수식 1):
    Ĥ^N_k(X) = (1/N) Σ_{i=1}^N log(N · ||x_i − x_i^k-NN||_2^q · π̂^(q/2) / (k · Γ(q/2 + 1))) + C_k
    여기서 C_k = log k − Ψ(k)는 편향 보정이고, Ψ는 digamma 함수입니다. 핵심 통찰: 임의의 q > 0에 대해 이 식은 (1/N)Σ log||x_i − x_i^k-NN||_2 (수식 2)에 비례하므로 차원 q는 상대적 순서에 영향을 미치지 않습니다.
  • 내재적 보상 (수식 3):
    r^i(s_i) := log(||y_i − y_i^k-NN||_2 + 1), y_i = f_θ(s_i)는 무작위 인코더 출력입니다.
  • 총 보상 (수식 4):
    r^total_j := r^e(s_j, a_j) + β_t · r^i(s_j), β_t = β_0(1 − ρ)^t는 지수 감쇠입니다.

핵심 설계 결정

  1. 고정 무작위 인코더: 거리가 고정된 표현 공간에서 훈련 중 변하지 않으므로 내재적 보상 신호가 안정적이며, 학습된 표현으로 인한 비정상성을 피할 수 있습니다.
  2. 리플레이 버퍼에 저차원 표현 y 저장: 매 업데이트마다 고차원 상태를 인코더로 처리할 필요가 없어 계산 비용이 "매 단계 전체 순전파"에서 "저장 시 1회 순전파"로 줄어듭니다.
  3. 전체 버퍼 k-NN 검색: on-policy 샘플(Mutti et al. 2021)이나 미니배치(Liu & Abbeel 2021)와 비교하여 전체 버퍼 검색이 더 안정적이고 정확한 엔트로피 추정을 제공합니다.
  4. 독립 RL 인코더: 정책 최적화용 인코더와 무작위 엔트로피 추정 인코더를 분리하여 탐색 신호가 작업 표현 학습을 방해하지 않도록 합니다.

두 가지 사용 모드

  • 온라인 RL: 외재적 보상이 작업 해결을 유도하고, 내재적 보상이 중첩되어 탐색을 구동합니다.
  • 비지도 사전 훈련: r^e = 0일 때 순수 내재적 보상으로 탐색하며, 사전 훈련된 정책을 미세 조정하여 하류 작업 샘플 효율성을 향상시킬 수 있습니다 (DeepMind Control에서 500K 스텝만 필요, Liu & Abbeel의 5M 스텝과 대조).

알고리즘 흐름 (Off-policy 버전)

  1. 무작위 인코더 θ, 정책 φ, 리플레이 버퍼 ℬ 초기화.
  2. 매 단계 (s_t, a_t, s_{t+1}, r^e_t) 수집, y_t = f_θ(s_t) 계산하여 ℬ에 저장.
  3. 미니배치 샘플링, 각 샘플에 대해 ℬ의 모든 y와 L2 거리 계산, k-NN 탐색.
  4. 내재적 보상 계산, 감쇠된 β_t 중첩, 정책 업데이트.

핵심 혁신

  1. 학습된 표현이 없는 엔트로피 추정: 무작위 고정 인코더만으로 상태 엔트로피 최대화를 지원할 수 있음을 처음으로 증명하여, 보조 작업(동역학, 역동역학, 대조 학습)으로 인한 다중 목표 최적화 및 하이퍼파라미터 튜닝 부담을 완전히 제거했습니다. 이는 "탐색에는 표현 학습이 필요하다"는 암묵적 가정에 대한 직접적인 도전입니다.
  2. 계산 효율성의 자릿수 향상: 사전 저장된 표현으로 반복 인코딩을 피하며, FLOPs 분석에 따르면 RAD + SE w/ Random이 Hopper Hop에서 500K 스텝 성능에 도달하는 데 7.233e+16 FLOPs가 필요한 반면, 역동역학 방식은 약 2배가 필요합니다; 전체 계산 오버헤드는 순수 RAD와 동등하여 엔트로피 탐색을 처음으로 "공짜 점심"으로 만들었습니다.
  3. 아키텍처 사전 지식의 명시적 활용: 컨볼루션 네트워크의 강력한 귀납적 편향(Ulyanov et al. 2018)을 실행 가능한 탐색 도구로 전환하고, 초기화 방식(Xavier/He/Orthogonal)과 k 값(1-9)에 대한 견고성을 검증하여 특정 아키텍처 미세 조정에 의존하지 않음을 보여줍니다.

실험 및 결과

DeepMind Control Suite (5회 실행 평균 ± 표준편차)

비교 핵심 결과
RAD + RE3 vs RAD/DrQ Cheetah Run Sparse에서 RE3가 601.6 평균 보상 달성, RAD와 DrQ는 모두 해결 실패
SE w/ Random vs SE w/ Contrastive/Inverse/ImageNet Random이 모든 학습된 표현 방식보다 일관되게 우수
RE3 vs RND/ICM 대부분의 작업에서 RE3가 더 우수
계산 효율성 Hopper Hop 500K 스텝: Random은 7.233e+16 FLOPs 필요, Inverse는 약 2배; Random은 순수 RAD와 동등

MiniGrid (5회 실행)

  • DoorKey-8x8: 2.4M 스텝에서 A2C + RE3가 0.49 평균 보상 달성, A2C + ICM은 0.20에 불과, A2C + RND와 A2C는 모두 비자명한 보상 획득 실패.
  • 사전 훈련: Empty-16x16에서 100K 스텝 사전 훈련 후 미세 조정, A2C + RE3 + PT가 샘플 효율성을 크게 향상.
  • 대조 학습은 MiniGrid에서 실패: 이미지 특정 증강(무작위 이동, 색상 지터)에 의존하여 컴팩트 임베딩과 호환되지 않음.

Atari (3회 실행)

  • RE3는 Montezuma's Revenge 등 하드 탐색 게임에서 Rainbow 및 Rainbow + SE w/ Contrastive보다 우수, 인간 정규화 점수 평균은 그림 13(c) 참조.

견고성

  • 무작위 인코더 앙상블이 가우시안 노이즈 및 색상 변화에 대한 견고성을 향상 (그림 10(a)(b)).
  • k ∈ {1,3,5,7,9} 및 다양한 초기화 방식에서 안정적 성능 (그림 10(c)(d)).

경계 및 한계

저자들은 표현 학습이나 추가 모델이 탐색에 불필요하다고 주장하지 않으며, 고정 무작위 인코더의 실용성만을 보여줍니다. 검증되지 않은 시나리오: 실제 로봇 하드웨어, 3D 물리 시뮬레이션(Isaac Gym, Manipulation 작업). 더 복잡한 시각 영역에 대해 저자들은 사전 훈련된 고정 표현이 더 유용할 수 있음을 인정하지만, 환경 접근과 광범위한 상태 분포 사전 훈련이 필요하여 그 자체로 비자명한 문제이므로 향후 작업으로 남겨둡니다. 논문은 추론 빈도, 하드웨어 구성 등의 엔지니어링 세부 사항을 언급하지 않습니다. 하이퍼파라미터 검색은 MiniGrid와 Atari에서 최상의 결과를 보고하며, 특정 작업에 대한 과적합 위험이 있을 수 있습니다.

엔지니어링 시사점

재현 시 다음 세 가지를 우선 확인하세요: ①무작위 인코더 아키텍처는 기본 RL 인코더와 일치해야 합니다 (DeepMind Control은 4층 컨볼루션 + 32채널 + 50차원 출력, Dreamer는 4층 컨볼루션 + 채널 {32,64,128,256}, Atari는 3층 컨볼루션 + 선형 레이어 차원 축소), 아키텍처 불일치는 귀납적 편향 가정을 깨뜨립니다; ②k-NN 검색 범위——모델 무관 RL은 전체 버퍼를 사용하고, Dreamer는 궤적 세그먼트 훈련으로 k=50이며 미니배치 내에서만 검색, MiniGrid는 10K 샘플 버퍼를 사용, 범위 선택 오류는 엔트로피 추정 안정성에 크게 영향을 미칩니다; ③β_t 감쇠 스케줄——ρ=0(감쇠 없음)은 Dreamer에서 가능하지만, 모델 무관 RL에서는 감쇠(ρ∈{0.00001, 0.000025})가 경험적으로 성능을 안정화하며, ρ=0을 그대로 적용하면 훈련 후반에 탐색 노이즈가 과도할 수 있습니다. 가장 쉽게 함정에 빠지는 부분은 MiniGrid에서 대조 학습 기준선의 실패입니다——하류 작업 관측이 자연 이미지가 아니라면 대조 학습 표현이 사용 가능하다고 가정하지 마세요, RE3의 무작위 인코더가 더 안정적입니다. 또한 DeepMind Control의 Walker/Cheetah Run Sparse는 자체 설계 작업(보상 임계값 0.25)이므로 재현 시 환경 버전 일치를 확인해야 합니다.
