요약

Vision-Language-Action (VLA) models have emerged as a promising paradigm for robot learning, but their representations are still largely inherited from static image-text pretraining, leaving physical dynamics to be learned from comparatively limited action data. Institutions per source list: Mondo Robotics（摩多机器人）、香港科技大学（广州）、香港科技大学.

개요

DiT4DiT는 이중 DiT 캐스케이드 아키텍처(비디오 Diffusion Transformer + 액션 Diffusion Transformer)를 통해 비디오 생성 사전 지식을 연속 로봇 제어에 직접 연결하는 엔드투엔드 Video-Action Model(VAM)입니다. 핵심 기여는 미래 프레임 재구성에 의존하지 않고, 비디오 생성 과정의 중간 노이즈 제거 특징에서 시간적으로 근거한 시각적 조건을 추출하며, 이중 스트림 매칭 목표로 공동 훈련하여 LIBERO(98.6%), RoboCasa-GR1(50.8%) 및 실제 Unitree G1에서 새로운 SOTA를 달성하고, GR00T 데이터 양의 15%만으로 제로샷 일반화를 구현한다는 점입니다.

그것이 바꾸는 것

기존 VLA 모델의 가장 큰 문제는 파라미터 부족이 아니라 사전 지식이 잘못되었다는 점입니다. 이들은 정적 이미지-텍스트 사전 훈련 백본을 계승하여 시공간 구조와 물리적 동역학을 상대적으로 제한된 액션 데이터에서만 학습할 수 있습니다. 이로 인해 모델은 실제 세계의 복잡한 조작에서 "물체가 힘에 어떻게 반응하는지, 상태가 시간에 따라 어떻게 전환되는지"에 대한 암시적 이해가 부족합니다. 비디오 생성 모델(VGM)은 풍부한 시공간 구조와 암시적 물리적 동역학을 인코딩하지만, 이를 활용하는 기존 방식(합성 훈련 데이터, 잠재 표현 추출을 통한 역동역학 모델 훈련)은 모두 다단계而非엔드투엔드 방식으로 제어가 간접적이며, "비디오 생성 모델이 정책 학습의 원리적 백본이 되어야 한다"는 핵심 문제를 해결한 적이 없습니다.

DiT4DiT가 실제로 바꾸는 것은 비디오 생성을 "보조 감독 신호"에서 "정책 학습의 백본 조건"으로 승격시킨 것입니다. 비디오 생성 목표 자체가 강건한 액션 정책 훈련 목표가 될 수 있으며, 비디오 모델이 학습한 시공간 표현이 재구성 프레임이 아닌 중간 노이즈 제거 특징을 통해 액션 생성과 직접 결합될 수 있음을 증명했습니다. 이 변화의 의미는 기존 대규모 모델 데이터의 극히 일부(15%만)로 최첨단 제로샷 일반화를 구현하는 경로를 제공하고, 비디오 생성을 임베디드 지능의 최적 스케일링 프록시로 위치시킨다는 점입니다—이는 이전에는 없던 작업입니다.

방법 분해

전체 아키텍처

이중 DiT 캐스케이드: 비디오 Diffusion Transformer(Video DiT)와 액션 Diffusion Transformer(Action DiT)가 결합되어 엔드투엔드로 훈련됩니다. 비디오 백본은 Cosmos-Predict2.5-2B로 초기화되며(인과 비디오 VAE + 비디오 확산 Transformer 포함), 언어 명령은 Cosmos-Reason1의 다층 임베딩을 통해 주입됩니다.

특징 추출 메커니즘

포워드 훅 메커니즘을 통해 흐름 시간 단계 τ_f에서 중간 숨은 활성화(특정 깊은 Transformer 블록 또는 모든 레이어 평균에서 가능)를 캡처하여 생성 과정을 시각적 토큰으로 변환합니다. 핵심 설계 결정: - 추출 레이어 선택: 초기 레이어(2–8)는 저수준 시각적 텍스처를 인코딩하여 조작 가능한 의미론이 부족합니다. 성능은 레이어 18에서 최고조에 달합니다. 최종 레이어(24–28)는 즉각적인 비디오 노이즈 제거 및 픽셀 수준 재구성 목표에 과도하게 전문화되어 성능이 급격히 하락합니다. - 노이즈 제거 단계 수: 단일 단계 노이즈 제거가 최고 성능을 얻으며, 단계 수가 증가할수록 성공률이 단조롭게 감소합니다—과도한 반복 노이즈 제거는 숨은 상태가 특정 재구성 미래의 픽셀 수준 세부 사항에 과도하게 전념하도록 강제합니다.

삼중 시간 단계 방식(Tri-timestep scheme)

  • 비디오 생성 모듈: τ_v ~ U[0,1], 모델을 모든 노이즈 수준에 노출
  • 특징 추출: 고정 시간 단계 τ_f, 반복 간 결정적 일관 표현 보장, 하류 액션 모듈 입력 안정화
  • 액션 모듈: τ_a = 1 - σ, σ ~ Beta(α=1.5, β=1.0), 훈련 용량을 흐름 궤적의 가장 중요한 단계에 할당

공동 훈련 목표

이중 스트림 매칭 손실: L_total = L_action + λ × L_video. 액션 손실은 마스크 손실: L_action = ||(v_hat_action - v*_action) ⊙ M||² / ||M||₁. 훈련 중 텍스트 인코더와 시각 VAE는 동결되고 두 DiT 모듈만 업데이트됩니다. 추론 시 비디오 샘플링은 N_v 단계 Euler 적분이 필요하며, 액션 샘플링은 단일 결정적 특징 추출(고정 τ_f에서 한 번의 포워드)만 필요하고, 그 다음 N_a 단계 Euler 적분으로 액션 궤적을 생성합니다.

액션 DiT 세부 사항

GR00T-N1에서 각색된 DiT-B 유형: 숨은 크기 2560, 최대 시퀀스 길이 1024, 액션 차원 32, 상태 차원 64, 미래 액션 창 15, 액션 시간 도메인 16, 교차 주의 차원 2048, dropout 0.2, AdaLN 정규화, 16 레이어. 입력은 고유수용성 상태 임베딩, 인코딩된 노이즈가 있는 액션 궤적 및 학습 가능한 "미래 토큰"입니다.

핵심 혁신

  1. 중간 노이즈 제거 특징을 액션 조건으로 사용(재구성 프레임이 아닌): 이것이 가장 핵심적인 혁신입니다. 완전히 재구성된 미래 프레임에 의존하지 않고 비디오 생성 과정의 중간 숨은 상태에서 특징을 추출합니다—이 특징은 자연스럽게 미래 동적 전환을 인코딩하여 액션 정책에 우수한 시간 일관성을 부여합니다. 절제 실험에서 silhouette score가 0.09에서 0.17(약 2배)로 향상되어 공동 훈련이 시각 백본이 연속적이고 물리적으로 인식 가능한 시간 진행을 임베딩하도록 강제함을 증명합니다.

  2. 삼중 시간 단계 방식: 비디오 생성, 특징 추출, 액션 생성 세 과정의 노이즈 시간 단계를 분리합니다. 비디오 모듈은 모든 노이즈 수준(τ_v ~ U[0,1])에 노출되고, 특징 추출은 τ_f를 고정하여 결정성을 보장하며, 액션 모듈은 Beta 분포(α=1.5, β=1.0)를 사용하여 훈련 용량을 흐름 궤적의 가장 중요한 단계에 할당합니다. 이 설계는 "비디오 생성이 모든 노이즈 수준을 탐색해야 한다"와 "액션 조건이 안정적 입력을 필요로 한다"는 모순을 해결합니다.

  3. 엔드투엔드 공동 훈련 패러다임: 이전의 비디오 모델 활용 방법(합성 데이터, 역동역학 모델)은 모두 다단계였습니다. DiT4DiT는 이중 스트림 매칭 목표로 비디오 DiT와 액션 DiT를 통합하여 훈련 중 비디오 백본이 연속적이고 물리적으로 인식 가능한 시간 진행을 임베딩하도록 강제하고, 액션 정책이 장시간 도메인 실행과 상태 전환 추론을 수행하도록 직접 지원합니다.

경계 및 한계

논문은 명시적인 한계 논의 섹션을 언급하지 않았지만, 실험 설정에서 경계를 추론할 수 있습니다. 가장 명백한 제한은 제어 주파수입니다: DiT4DiT는 6Hz에 불과하여 Qwen3DiT(9Hz) 및 GR00T-N1.5(13Hz)보다 낮으며, 비디오 백본이 도입한 계산적 트레이드오프는 고주파 피드백이 필요한 정밀 조작에서 병목이 될 수 있습니다. 단일 시점 의존성: 현재 물리적 배포는 단일 제1인칭 카메라만 사용하며, 복잡한 양손 작업에서 심각한 시각적 폐색(로봇 자체 팔 또는 큰 물체가 일시적으로 시야를 가림)에 취약하며, 저자는 손목 카메라나 촉각 피드백과 같은 보조 감각 입력을 통합하지 않았음을 인정합니다. 다단계 노이즈 제거 성능 하락의 극단적 민감성은 공동 훈련 패러다임에 기인하지만, 저자는 추가 완화 방안을 제공하지 않았습니다. 더 긴 horizon 작업 미검증(LIBERO-Long 및 720단계 상한 초과), 다중 카메라 또는 비 ego-view 설정 미검증. 모든 가능한 비디오-액션 모델 기준선과의 포괄적 비교 미수행(예: Cosmos Policy, VideoVLA는 참고 문헌에서만 언급). 대규모 교차 형태 데이터 세트 훈련 미수행, 다양한 로봇 형태(다른 운동학, 그리퍼, 카메라 파라미터)에 대한 사전 훈련 데이터 확장 미수행.

공학적 시사점

DiT4DiT를 재현할 때 가장 먼저 확인해야 할 것은 특징 추출 레이어 선택입니다—레이어 18이 성능 최고점이며, 레이어 2–8은 조작 가능한 의미론이 부족하고, 레이어 24–28은 성능이 급격히 하락합니다. 기본 구성을 그대로 따르지만 백본 네트워크가 다르면 이 최적 레이어 위치가 이동할 수 있으므로 재스캔이 필요합니다. 다음은 노이즈 제거 단계 수입니다: 단일 단계 노이즈 제거가 최고이며, 단계 수가 증가함에 따라 단조롭게 감소합니다(1에서 32단계)—직관과 반대이므로 비디오 노이즈 제거 단계를 늘려 성능을 향상시키려 하지 마십시오. 삼중 시간 단계 방식에서 τ_f 고정은 반복 간 결정성을 보장하는 핵심이며, τ_a는 Beta(1.5, 1.0)를 사용하여 훈련 용량을 흐름 궤적의 중요한 단계에 할당하며, 이 두 파라미터는 훈련 안정성에 직접 영향을 미칩니다.

공학적으로 가장 쉽게 함정에 빠지는 부분은 훈련 중 LLM 구성 요소가 훈련에 참여하지 않는다는 점입니다—LLM 특징은 사전 추출 및 캐시하여 반복 추론을 피할 수 있으며, 이는 유효 배포 주파수를 크게 향상시킬 수 있습니다(DiT4DiT가 여전히 6Hz에 불과하지만). 사전 훈련-하류 분리 전략은 참고할 만합니다: VLM과 비디오 백본을 목표 데이터 세트에서 자기 지도 훈련 후 동결하고, 액션 전문가만 미세 조정합니다. 사전 훈련 데이터 양은 GR00T의 15%(241,450 클립)에 불과하지만 효과는 전반적으로 능가합니다—이는 비디오 생성 목표의 데이터 효율성이 기존 VLA 목표보다 훨씬 높다는 것을 보여줍니다. 실제 세계 배포 시 주의: Qwen3DiT는 실제 세계에서 거의 완전히 붕괴(대부분 작업 0%)하여 정적 이미지-텍스트 사전 지식이 실제 물리적 상호작용에서 취약함을 보여주며, DiT4DiT의 강건성은 비디오 생성 사전 지식의 암시적 물리적 동역학에서 비롯됩니다.
