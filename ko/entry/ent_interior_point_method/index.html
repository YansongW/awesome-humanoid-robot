요약

장벽 또는 페널티 함수를 통해 실행 가능 영역 내에서 매끄러운 중심 경로를 따라 제약 최적화 문제를 푸는 최적화 알고리즘 집합.

출처

  • J. Nocedal and S. J. Wright, Numerical Optimization, 2nd ed., Springer, 2006

관련 개체

  • requires 제약 자격 내점법의 수렴 이론은 일반적으로 KKT 체계가 양호하게 정의되도록 제약 자격을 가정합니다.
  • is_alternative_to 활성 집합법 활성 집합법은 명시적으로 구속 제약을 추적하는 반면, 내점법은 장벽 항을 통해 경계를 완전히 피합니다.

개요

내점법은 제약 최적화 문제를 푸는 알고리즘 계열로, 실행 가능 영역 내부에 장벽 함수 또는 페널티 항을 구성하여 매끄러운 중심 경로를 따라 최적해에 접근한다. 이는 단체법이 경계를 따라 탐색할 때 겪는 조합적 어려움을 피하고, 초기 페널티 방법에서 매개변수가 무한대로 발산하던 병리적 문제도 극복하여, 현대 대규모 비선형 계획법 솔버의 핵심 엔진으로 자리 잡았다.

핵심 내용

무엇인가: 정확한 정의

내점법(Interior-point method)은 제약 최적화 문제를 풀기 위한 수치 알고리즘 계열이다. 핵심 아이디어는 실행 가능 영역의 경계를 따라 탐색하지 않고, 실행 가능 영역 내부에서 엄밀히 실행 가능한 반복점 수열을 생성하는 것이다. 점차 조여지는 장벽 매개변수를 통해 반복점 수열이 "중심 경로"(central path)라 불리는 매끄러운 곡선을 따라 원래 문제의 최적해로 수렴하게 한다.

일반적인 형태의 제약 최적화 문제를 고려하자:

\[ \min_{x} \; f(x) \quad \text{s.t.} \quad c_i(x) \ge 0, \; i \in \mathcal{I}, \quad A x = b \]

내점법은 다음과 같은 장벽 하위 문제를 구성한다:

\[ \min_{x} \; f(x) - \mu \sum_{i \in \mathcal{I}} \log(c_i(x)) \quad \text{s.t.} \quad A x = b \]

여기서 \(\mu > 0\)는 장벽 매개변수이다. \(\mu \to 0\)일 때, 장벽 하위 문제의 해 \(x^*(\mu)\)는 중심 경로를 따라 원래 문제의 최적해로 수렴한다. 내점법이 실제로 바꾸는 것은 "어떤 점이 최적인지 판단하는 방법"이 아니라 "최적점으로 가는 경로를 어떻게 생성하는가"이다. 이 경로는 경계 위가 아니라 실행 가능 영역 내부에 있다.

원리 분해

① 장벽 함수: 부등식 제약을 "부드럽게" 만들기

로그 장벽 함수 \(-\mu \log(c_i(x))\)의 핵심 성질은 \(c_i(x) \to 0^+\)일 때 장벽 항이 \(+\infty\)로 발산한다는 것이다. 이는 "무한히 높은 벽"을 형성하여 반복점이 엄밀히 실행 가능 영역 내부에 머물도록 보장한다. 장벽 매개변수 \(\mu\)는 벽의 가파른 정도를 제어한다: \(\mu\)가 크면 벽이 완만하여 반복점이 경계에서 멀리 떨어지고, \(\mu\)가 작으면 벽이 가팔라 반복점이 경계에 밀착된다.

② 중심 경로: 정교하게 설계된 곡선

각 \(\mu > 0\)에 대해, 장벽 하위 문제는 (볼록 문제에서) 유일한 해 \(x^*(\mu)\)를 가진다. \(\mu\)가 큰 값에서 작은 값으로 변함에 따라 \(x^*(\mu)\)는 실행 가능 영역 내부에 연속 곡선, 즉 중심 경로를 그린다. 내점법의 각 반복은 단 한 가지 일만 수행한다: 현재 \(\mu\)에 대해 장벽 하위 문제를 풀고, \(\mu\)를 줄인 다음, 새로운 하위 문제를 다시 푸는 것.

③ 뉴턴 스텝과 KKT 조건

고정된 \(\mu\)에 대한 장벽 하위 문제의 KKT 조건은 다음과 같다:

\[ \nabla f(x) - \sum_{i \in \mathcal{I}} \frac{\mu}{c_i(x)} \nabla c_i(x) + A^{\top} \lambda = 0 \]

\(s_i = \mu / c_i(x)\)(쌍대 변수)로 정의하면, 위 식은 다음과 같이 다시 쓸 수 있다:

\[ \nabla f(x) - \sum_{i \in \mathcal{I}} s_i \nabla c_i(x) + A^{\top} \lambda = 0, \quad s_i c_i(x) = \mu \]

이것이 바로 섭동 KKT 조건이다: 상보 여유 조건 \(s_i c_i(x) = 0\)이 \(s_i c_i(x) = \mu\)로 완화된 형태이다. \(\mu \to 0\)일 때, 섭동 KKT 조건은 정확한 KKT 조건으로 수렴한다. 내점법의 각 반복은 뉴턴 방법으로 이 비선형 방정식 시스템을 풀면서 동시에 \(\mu\)를 점차 줄인다.

④ 원시-쌍대 방법

현대 구현은 거의 모두 원시-쌍대 내점법을 사용한다: 원시 변수 \(x\)와 쌍대 변수 \(s, \lambda\)를 동시에 갱신한다. 초기 "장벽 방법"처럼 하위 문제를 완전히 푼 다음 \(\mu\)를 줄이는 방식이 아니라, 각 뉴턴 스텝 후에 직접 \(\mu\)를 줄일 수 있어 수렴 속도가 현저히 빨라지고 초기점에 대한 요구도 더 관대하다.

누가 사용하는가·응용 사례

① 전신 제어(WBC)에서의 실시간 QP 해법

현대 휴머노이드 로봇 제어기는 작업 추적 목표, 동역학 등식, 마찰 원뿔 부등식, 토크 제한을 하나의 QP 문제로 통합한다. 자료에서 실제 WBC가 "실시간 QP 솔버(예: OSQP, qpOASES, ProxQP)"를 필요로 한다고 명시되어 있으며, OSQP와 ProxQP는 모두 내점법 또는 그 변형(교대 방향 승수법 ADMM과 내점법의 결합)을 사용한다. 이러한 솔버는 1 kHz 제어 주파수에서 작동하며, 각 해법 시간은 1 ms 이내로 제한되어야 한다(공학적 판단).

② 궤적 최적화

자료는 중간 계층 계획이 최적화 기반 방법(예: CHOMP, TrajOpt)을 자주 사용한다고 언급한다. 이러한 방법이 장애물 회피 제약이 있는 궤적 최적화 문제를 풀 때, 내점법은 충돌 제약을 장벽 항으로 변환하여 궤적이 장애물 사이를 "비집고" 지나가는 매끄러운 경로를 생성한다.

③ 위상 최적화에서의 SIMP 방법

자료는 SIMP(Solid Isotropic Material with Penalization) 방법을 자세히 설명한다: 각 유한 요소의 밀도 \(\rho_e \in [0,1]\)를 설계 변수로 두고, 페널티 인자 \(p \geq 3\)를 도입하여 중간 밀도를 비경제적으로 만든다. SIMP의 해법은 본질적으로 경계 제약이 있는 비선형 최적화 문제이며, 내점법은 이러한 문제를 푸는 표준 도구 중 하나이다.

④ 베이지안 최적화에서의 제약 처리

자료는 베이지안 최적화를 결합할 때, 각 반복에서 기대 개선(Expected Improvement, EI)이 가장 큰 점을 선택하여 고충실도 시뮬레이션을 수행한다고 언급한다. 대리 모델에 제약이 포함된 경우, 내점법은 제약이 있는 획득 함수 최대화 문제를 푸는 데 사용될 수 있다.

한계와 경계

① 대규모 선형 대수 병목

내점법은 각 반복에서 대규모 희소 선형 방정식 시스템을 풀어야 한다. 휴머노이드 로봇 전신 제어와 같은 고차원 문제(자유도 30+, 제약 수백 개)의 경우, 선형 대수 해법이 전체 계산 시간의 70% 이상을 차지할 수 있다(공학적 판단). 이는 문제 구조(희소성, 블록 구조 등)를 활용한 전용 솔버 설계를 요구한다.

② 초기점 요구 사항

원시-쌍대 내점법은 초기 장벽 방법보다 초기점 요구가 관대하지만, 여전히 초기점이 엄밀한 실행 가능성(모든 부등식 제약이 엄밀히 성립)을 만족해야 한다. 실행 불가능한 문제의 경우, 먼저 "실행 가능성 회복" 하위 문제를 풀어야 하므로 추가 계산이 발생한다.

③ 비볼록 문제의 국소 수렴성

내점법의 수렴성 이론은 주로 볼록 문제를 대상으로 한다. 비볼록 문제(예: 자체 충돌 제약이 있는 전신 궤적 최적화)의 경우, 내점법은 국소 최적해로의 수렴만 보장할 수 있으며, 장벽 함수의 비볼록성으로 인해 중심 경로가 분기할 수도 있다.

④ 병적 조건수

\(\mu\)가 매우 작아지면 장벽 하위 문제의 Hessian 행렬 조건수가 무한대로 발산하여 뉴턴 스텝의 수치적 안정성이 떨어진다. 현대 구현은 스케일링과 전처리를 통해 이 문제를 완화하지만, 극단적인 경우에는 여전히 주의가 필요하다.

흔한 오해

  1. "내점법이 단체법보다 항상 빠르다" — 틀렸다. 소규모 문제(변수와 제약이 100개 미만)의 경우, 단체법이나 활성 집합 방법이 보통 더 빠르다. 이는 웜 스타트(warm start) — 이전 해를 초기점으로 사용 — 를 활용할 수 있기 때문이다. 내점법은 웜 스타트가 어려워 매번 처음부터 풀어야 한다.

  2. "내점법의 반복점은 항상 실행 가능 영역 내부에 있다" — 완전히 맞지는 않다. 원시-쌍대 내점법은 반복 과정에서 실행 불가능한 점을 생성할 수 있으며(특히 실행 가능성 회복 단계에서), 수렴 시 최종적으로 실행 가능 영역으로 돌아온다. 엄밀히 실행 가능성을 유지하는 방법을 "실행 가능 내점법"이라 부르지만, 실제 구현에서는 거의 사용되지 않는다.

  3. "장벽 매개변수가 작을수록 좋다" — 틀렸다. \(\mu\)가 너무 작으면 병적 조건수가 발생하여 수치 오차가 커진다. 현대 구현은 적응형 전략을 사용한다: 뉴턴 스텝의 품질을 보장하면서 가능한 한 빠르게 \(\mu\)를 줄인다.

  4. "내점법은 볼록 최적화에만 사용할 수 있다" — 틀렸다. 내점법은 비볼록 문제에도 사용할 수 있으며, 다만 수렴성 보장이 국소 수렴으로 약화될 뿐이다. 실제로 많은 비선형 계획법 솔버(예: IPOPT)가 내점법에 기반하며, 비볼록 궤적 최적화 문제에 널리 사용된다.

관련 지식

  • ent_active_set_method — 내점법의 주요 대안으로, 실행 가능 영역 경계를 따라 탐색하며 중소규모이고 웜 스타트가 필요한 QP 문제에 적합하다.
  • ent_constraint_qualification — KKT 조건이 국소 최적점에서 성립하도록 보장하는 정칙성 조건으로, 내점법의 수렴성 분석은 제약 규격(예: Slater 조건)에 의존한다.
