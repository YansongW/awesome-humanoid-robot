Deep Residual Learning for Image Recognition

Deep Residual Learning for Image Recognition

영역
AI 모델 및 알고리즘
계층
지능 계층
검증
초안

요약

Deeper neural networks are more difficult to train. We present a residual learning framework to ease the training of networks that are substantially deeper than those used previously. Institutions per source list: Microsoft Research.

출처

  • arXiv:1512.03385 Deep Residual Learning for Image Recognition
  • GitHub仓库 Robotics_Notebooks

개요

허카이밍(何恺明) 등은 잔차 학습 프레임워크(ResNet)를 제안하여, 항등 지름길 연결(identity shortcut connection)을 통해 심층 네트워크를 잔차 함수 F(x) + x로 모델링함으로써 초심층 네트워크(예: 152층)의 최적화 저하 문제를 해결했습니다. 이 연구는 ImageNet 분류, 검출, 위치 파악 및 COCO 검출·분할 작업에서 전반적으로 기록을 경신하며 딥러닝 비전 분야의 이정표적 기반 아키텍처가 되었습니다.

그것이 바꾼 것

ResNet 이전에 비전 분야에서는 네트워크 깊이가 정확도의 핵심이라고 널리 여겨졌지만, VGG, GoogLeNet 등의 아키텍처는 일정 깊이를 초과하면 훈련 오차가 줄지 않고 오히려 증가하는 "저하(退化)" 현상이 나타났습니다. 이는 과적합이 아니라 최적화의 어려움입니다. 저자들은 실험을 통해 단순히 반복 횟수를 늘리는 것(3×)으로는 저하 문제를 해결할 수 없음을 증명했으며, 이는 문제가 옵티마이저의 심층 비항등 매핑 적합 능력에 있음을 시사합니다. ResNet의 진정한 변화는 "네트워크가 목표 매핑 H(x)를 적합하도록 하는" 암묵적 가정을 "네트워크가 잔차 H(x)-x를 적합하도록 하는" 것으로 명시적으로 재구성하고, 파라미터가 없는 항등 지름길 연결을 도입한 것입니다. 이 변경은 사소해 보이지만 수백 층의 네트워크가 처음으로 SGD로 안정적으로 최적화될 수 있게 했으며, 항등 연결은 파라미터와 계산량을 전혀 추가하지 않습니다. 이는 같은 시기의 Highway 네트워크(게이팅, 파라미터 포함)와의 본질적 차이입니다. 이는 전체 분야의 "깊이"에 대한 인식을 바꾸었습니다. 깊이는 더 이상 훈련 장애물이 아니라 체계적으로 활용할 수 있는 정확도 원천이 되었습니다.

방법 분해

핵심 구성 블록

  • 잔차 블록 정의: y = F(x, {W_i}) + x, 여기서 F는 적층 컨볼루션 레이어(예: 두 개의 3×3 컨볼루션), x는 입력, 항등 지름길 연결은 직접 더함
  • 차원 불일치 시: y = F(x, {W_i}) + W_s x, W_s는 선형 투영(1×1 컨볼루션), 차원 증가 시에만 사용

아키텍처 설계 규칙

  • 동일 출력 특성 맵 크기의 레이어는 동일한 필터 수를 유지; 특성 맵 크기가 절반이 되면 필터 수는 두 배
  • 다운샘플링은 stride=2의 컨볼루션으로 직접 수행, 네트워크 끝은 전역 평균 풀링 + 1000-way 완전 연결 + softmax
  • 병목 설계(ResNet-50/101/152): 각 잔차 함수는 1×1→3×3→1×1 세 개 레이어로 적층, 1×1 레이어는 차원 축소 및 복원 담당, 3×3 레이어는 병목 역할(입출력 차원이 작음), 계산량을 크게 줄임

핵심 훈련 설정

  • ImageNet: SGD, mini-batch=256, lr=0.1(plateau 시 10으로 나눔), 60×10^4 반복까지 훈련, weight decay=0.0001, momentum=0.9, dropout 없음
  • 각 컨볼루션 후, 활성화 전에 BN 사용; 가중치 초기화는 [13]의 방법 사용
  • CIFAR-10: mini-batch=128, lr=0.1(32k 및 48k 반복 시 10으로 나눔), 64k 반복에서 종료; 110층 네트워크는 처음 400회 반복에 warm-up lr=0.01 사용

검출/분할 적응

  • Faster R-CNN/FCN의 VGG-16을 ResNet-101로 교체, 나머지 검출/분할 기술은 완전히 변경 없음
  • 사전 훈련 후 BN 레이어 고정(ImageNet에서 통계량 계산), 미세 조정 시 BN은 상수 오프셋이 있는 선형 활성화가 되어 메모리 소비 감소
  • 미세 조정: lr=0.001, 240k 반복, mini-batch=1(검출) 또는 8(분할), weight decay=0.0001, momentum=0.9

핵심 혁신

  1. 항등 지름길 연결(Identity Shortcut): Highway 네트워크의 게이팅 지름길과 달리 항등 연결은 파라미터가 없고 절대 닫히지 않으며 정보가 항상 완전히 전달됩니다. 이로 인해 잔차 함수 F는 완전한 매핑 대신 "수정량"을 학습할 수 있어, 메커니즘적으로 심층 네트워크의 기울기 소실과 최적화 어려움을 완화합니다. 부록 실험은 항등 연결이 병목 아키텍처에 결정적으로 중요함을 보여줍니다. 투영으로 바꾸면 시간 복잡도와 모델 크기가 두 배가 됩니다.

  2. 잔차 함수의 응답 강도 분석: 저자들은 각 레이어 출력의 표준 편차(BN 후, 비선형 전)를 측정하여 ResNet의 레이어 응답이 일반적으로 plain 네트워크보다 작고, 네트워크가 깊을수록 단일 레이어 응답이 더 작음을 발견했습니다. 이는 "잔차 함수가 0에 더 가깝다"는 가설을 직접 검증하며 잔차 학습의 효과성에 대한 메커니즘 수준의 증거를 제공합니다.

  3. 깊이를 보편적 정확도 지렛대로: 검출/분할 작업에서 백본 네트워크만 교체(VGG-16→ResNet-101)하고 검출/분할 기술은 전혀 변경하지 않았음에도 COCO 검출 mAP@[.5,.95]가 21.9%에서 27.6%로 향상(상대적 약 26% 향상), 분할 mIoU는 24.4%에서 28.6%로 향상. 이는 심층 표현의 이점이 작업별 설계 없이 하위 작업으로 손실 없이 전이될 수 있음을 증명합니다.

대회 성적

  • ILSVRC 2015 검출: 앙상블 모델 test mAP=62.1%, 2위보다 8.5포인트 초과
  • ILSVRC 2015 위치 파악: top-5 위치 파악 오차 9.0%, ILSVRC 14 결과 대비 64% 감소
  • COCO 2015 검출: 3개 모델 앙상블 test-dev mAP@[.5,.95]=37.4%

경계와 한계

  • 1202층 ResNet은 CIFAR-10에서 테스트 오차(7.93%)가 110층(6.43%)보다 높았으며, 저자들은 과적합(19.4M 파라미터 vs 50k 훈련 이미지)으로 귀인했지만 maxout/dropout 등 강한 정규화 시도에서 뚜렷한 이점을 보지 못했고, 과파라미터화된 네트워크 최적화는 여전히 열린 문제
  • 저하 문제의 근본 원인은 완전히 설명되지 않았으며, 저자들은 최적화 어려움과 관련이 있다고 추측만 했을 뿐 이론적 분석은 제공하지 않음
  • 다중 스케일 훈련은 수행되지 않음(다중 스케일 테스트만), 다중 스케일 테스트는 Fast R-CNN 단계에만 사용되고 RPN에는 사용되지 않음
  • 논문은 정확한 훈련 시간과 하드웨어 구성을 보고하지 않음; 코드는 공개되지 않음
  • 초록의 "28% 상대적 향상"은 본문 데이터(약 26%)와 불일치하며, 저자들은 부록에서 이 수치가 직접 재현될 수 없음을 인정

공학적 시사점

  • 재현 우선순위: BN 고정 전략을 먼저 확인하세요. 검출 미세 조정 시 BN 통계량은 사전 훈련 모델에서 동결해야 하며, 그렇지 않으면 작은 배치 훈련(검출 mini-batch=1)으로 BN 통계량이 급격히 변동합니다. 이것이 가장 쉽게 함정에 빠지는 부분입니다.
  • 항등 연결은 대체 불가: 병목 아키텍처에서 투영 지름길로 항등을 대체하면 시간 복잡도와 모델 크기가 두 배가 되고 정확도 향상은 미미합니다(Table 10에서 A/B/C 옵션 차이 <1%). 공학적으로는 파라미터 없는 항등 연결을 우선 선택해야 합니다.
  • 깊이와 데이터 규모의 매칭: 1202층이 50k 이미지에서 과적합된 교훈은 초심층 네트워크가 상응하는 규모의 데이터 또는 강한 정규화를 필요로 함을 보여줍니다. 데이터가 제한적일 때 110층 정도가 CIFAR-10 수준의 합리적 선택입니다.
  • 하위 작업 전이 비용이 매우 낮음: 검출/분할 작업은 백본만 교체해도 상당한 향상을 얻을 수 있으며 작업 헤드를 변경할 필요가 없습니다. 사전 훈련 + BN 고정 + 미세 조정은 표준 프로세스로 다른 비전 작업에 재사용 가능합니다.
  • 계산 예산 참고: 152층 ResNet FLOPs는 11.3B로 VGG-16(15.3B) 및 VGG-19(19.6B)보다 낮습니다. 깊이 증가가 반드시 계산 부담 증가를 의미하지 않으며 병목 설계가 핵심입니다.
