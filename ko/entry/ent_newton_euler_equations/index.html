요약

강철 또는 관절 연결 다물체 시스템의 운전을 기술하는 결합된 힘 및 토크 평형 방정식 집합.

출처

  • R. Featherstone, Rigid Body Dynamics Algorithms, Springer, 2014

관련 개체

  • is_alternative_to 라그랑지안 뉴턴-오일러 형식과 라그랑지안 형식은 강체 시스템에서 동치입니다. 전자는 힘/토크 균형에, 후자는 에너지에 초점을 맞춥니다.

개요

뉴턴-오일러 방정식은 강체 또는 다관절 다물체 시스템의 운동을 설명하는 일련의 결합된 힘 평형 및 모멘트 평형 방정식으로, 뉴턴 제2법칙과 오일러 회전 방정식이 결합된 형태입니다. 휴머노이드 로봇 분야에서는 속도/가속도를 전방으로 재귀적으로 전파하고 힘/모멘트를 후방으로 재귀적으로 전파하는 알고리즘을 통해 \(O(n)\)의 계산 복잡도로 각 관절에 필요한 토크를 실시간으로 계산합니다. 이는 전신 동역학 제어(WBC), 운동 계획 및 시뮬레이션 검증을 뒷받침하는 핵심 계산 도구입니다.

핵심 내용

무엇인가: 뉴턴-오일러 방정식의 정의와 위치

뉴턴-오일러 방정식(Newton-Euler equations)은 방정식 유형에 속하며, 소속 분야는 기초 과학, 가치 사슬 계층은 기초 계층입니다. 영문 명칭은 Newton-Euler equations, 한글 명칭은 뉴턴-오일러 방정식입니다.

이는 본질적으로 단일 방정식이 아니라 뉴턴 제2법칙과 오일러 회전 방정식의 결합입니다. 뉴턴 방정식은 강체 질량 중심의 병진 운동을 설명합니다—힘은 질량 곱하기 선형 가속도와 같습니다. 오일러 방정식은 강체의 질량 중심 주위 회전을 설명합니다—모멘트는 관성 텐서 곱하기 각가속도에 자이로 항을 더한 것과 같습니다. 이 둘을 연립하면 3차원 공간에서 강체의 완전한 운동 설명이 구성됩니다.

휴머노이드 로봇이라는 고차원, 저구동, 강결합 시스템에서 뉴턴-오일러 방정식의 가치는 "기대 운동"에서 "필요한 관절 토크"로의 결정적 계산 경로를 제공한다는 점이며, 이는 역동역학의 핵심 수학 도구입니다. 이것이 실제로 바꾼 것은 강체 역학 자체가 아닙니다—그것은 300년 전에 이미 확립되었습니다—고전 역학을 실시간 계산 가능한 재귀 알고리즘으로 변환하여 30개 이상의 자유도를 가진 이족 보행 로봇이 밀리초 시간 척도에서 토크 계산을 완료할 수 있게 한 것입니다.

왜 존재하는가: 문제점과 역사적 위치

뉴턴-오일러 방정식이 재귀적 형태로 로봇 공학에 도입되기 전, 다물체 시스템 동역학 해석은 근본적인 난관에 직면했습니다: 전역 동역학 방정식을 직접 수립하고 해석하는 계산량이 자유도 수에 따라 지수적으로 증가한다는 점입니다. 6자유도 산업용 로봇 팔의 경우, 라그랑주 방법으로 유도된 운동 방정식은 많은 결합 항을 포함하여 기호 유도가 번거롭고 수치 계산 효율이 낮았습니다. 휴머노이드 로봇과 같은 30+ 자유도 시스템의 경우 전역 방정식은 거의 불가능했습니다.

뉴턴-오일러 재귀 알고리즘(Newton-Euler recursive algorithm)의 돌파구는 인접 링크의 계산 결과를 반복 활용하여 복잡도를 낮추는 것으로, 계산량을 \(O(n^3)\) 이상에서 \(O(n)\)—즉 계산 시간이 링크 수에 비례—으로 줄였습니다. 이 특성 덕분에 실시간 제어에서 역동역학의 최우선 방법이 되었고, 1980년대 이후 라그랑주 방법을 점차 대체하여 로봇 동역학 계산의 주류가 된 근본 원인입니다.

역사적 위치에서 보면, 뉴턴-오일러 방정식은 로봇 공학의 "모델링—계획—제어" 체인의 최하위 계층에 있습니다. 모델 예측 제어(MPC)의 예측 모델, 전신 제어(WBC)의 동역학 제약, 또는 시뮬레이터의 순방향 동역학 적분 모두 궁극적으로 뉴턴-오일러 방정식 또는 이와 동등한 동역학 표현에 의존합니다. 이는 "운동학적으로 가능함"과 "동역학적으로 가능함"을 연결하는 다리입니다.

원리 분석: 재귀 알고리즘의 두 단계 전파

뉴턴-오일러 재귀 동역학 방법의 핵심 아이디어는 전역 동역학 문제를 국소 재귀로 분해하는 것이며, 두 가지 반대 방향의 단계로 나뉩니다:

① 외향 전파(forward recursion): 베이스에서 말단으로 운동학량 전파

베이스에서 시작하여 각 링크의 각속도, 각가속도, 선형 가속도 및 질량 중심 가속도를 순차적으로 계산합니다. 이 단계는 운동학적 관계만 포함합니다—인접 링크 사이의 관절 속도/가속도 제약을 이용하여 베이스의 운동 상태를 링크별로 외부로 전파합니다. 링크 \(i\)의 경우 각속도 \(\boldsymbol{\omega}_i\)는 부모 링크 각속도에 관절 회전 기여를 더하여 얻어지고, 선형 가속도 \(\dot{\mathbf{v}}_i\)는 병진 기여를 추가로 중첩합니다.

② 내향 전파(backward recursion): 말단에서 베이스로 힘/모멘트 전파

말단 실행기에서 시작하여 각 링크에 뉴턴 방정식(힘 평형)과 오일러 방정식(모멘트 평형)을 적용하여 링크에 작용하는 순힘과 순모멘트를 계산하고, 해당 관절을 구동하는 데 필요한 토크를 추출합니다. 링크 \(i\)의 경우 뉴턴 방정식은 질량 중심 힘을 제공합니다:

\[ \mathbf{f}_i = m_i \left( \dot{\mathbf{v}}_{c,i} + \boldsymbol{\omega}_i \times \mathbf{v}_{c,i} \right) \]

여기서 \(m_i\)는 링크 질량, \(\dot{\mathbf{v}}_{c,i}\)는 질량 중심 가속도, \(\boldsymbol{\omega}_i \times \mathbf{v}_{c,i}\)는 구심 가속도 항입니다. 오일러 방정식은 질량 중심 주위 모멘트 평형을 제공합니다:

\[ \boldsymbol{\tau}_i = \mathbf{I}_i \dot{\boldsymbol{\omega}}_i + \boldsymbol{\omega}_i \times \left( \mathbf{I}_i \boldsymbol{\omega}_i \right) \]

여기서 \(\mathbf{I}_i\)는 링크의 질량 중심 주위 관성 텐서, \(\boldsymbol{\omega}_i \times (\mathbf{I}_i \boldsymbol{\omega}_i)\)는 자이로 모멘트 항입니다. 내향 전파 시 각 링크에 작용하는 힘/모멘트는 두 부분으로 구성됩니다: 자체 관성 힘/모멘트에 더하여 외측 링크가 관절을 통해 전달하는 반작용 힘/모멘트입니다. 관절 구동 토크는 해당 관절에서 전달 모멘트의 투영입니다.

③ 계산 복잡도: \(O(n)\)의 공학적 의미

전체 알고리즘은 각 링크에 대해 상수 횟수의 연산만 수행하므로 총 계산량은 링크 수 \(n\)에 따라 선형적으로 증가합니다. 이는 휴머노이드 로봇이 30개 이상의 자유도를 가지더라도 역동역학 해석이 1 kHz 이상의 제어 주파수에서 실시간으로 완료될 수 있음을 의미합니다. 이것이 뉴턴-오일러 방법을 다른 동역학 해석 방법과 구별하는 결정적 장점입니다.

핵심 매개변수와 사양

뉴턴-오일러 방정식의 실제 계산에는 다음 입력 매개변수가 필요합니다:

매개변수 유형 구체적 매개변수 설명
운동학 매개변수 관절 각도 \(\mathbf{q}\), 관절 각속도 \(\dot{\mathbf{q}}\), 관절 각가속도 \(\ddot{\mathbf{q}}\) 시스템의 현재 운동 상태 설명
관성 매개변수 링크 질량 \(m_i\), 질량 중심 위치 \(\mathbf{c}_i\), 관성 텐서 \(\mathbf{I}_i\) 링크의 질량 분포 설명
운동학 구조 관절 유형(회전/병진), 링크 길이, 관절 축 방향 링크 간 연결 관계 설명
외부 힘/모멘트 말단 실행기에 작용하는 외력 \(\mathbf{f}_{\text{ext}}\), 외부 모멘트 \(\boldsymbol{\tau}_{\text{ext}}\) 환경과의 상호작용 경계 조건 설명

출력은 각 관절에 필요한 구동 토크 \(\boldsymbol{\tau} \in \mathbb{R}^n\)입니다. 순방향 동역학 모드(forward dynamics)에서는 입력과 출력이 교환됩니다—관절 토크가 주어지면 관절 가속도를 해석하며, 이 경우 질량 행렬의 역행렬을 추가로 해석해야 하므로 계산 복잡도가 \(O(n^2)\)에서 \(O(n^3)\)로 상승하지만, 재귀 알고리즘(예: Featherstone의 관절체 알고리즘)을 통해 \(O(n)\)을 유지할 수 있습니다.

횡적 비교: 뉴턴-오일러 vs 라그랑주

비교 차원 뉴턴-오일러 방법 라그랑주 방법
출발점 힘/모멘트 평형 (뉴턴 제2법칙 + 오일러 방정식) 에너지 (운동 에너지 - 위치 에너지)
수학 도구 재귀 계산, 벡터/텐서 연산 편미분, 기호 유도
계산 복잡도 \(O(n)\), 실시간 제어에 적합 \(O(n^3)\) ~ \(O(n^4)\), 오프라인 분석에 적합
물리적 직관성 높음, 각 단계에 명확한 물리적 의미 낮음, 중간량(예: 일반화 힘)이 추상적
적용 시나리오 실시간 역동역학, 전신 제어, 시뮬레이션 시스템 분석, 제어 법칙 설계, 소규모 시스템
제약 처리 관절 제약을 명시적으로 처리해야 함 제약이 일반화 좌표에 자동으로 내포됨

공학적 판단: 둘은 수학적으로 동등합니다—라그랑주 방정식에서 유도된 운동 방정식과 뉴턴-오일러 방정식은 동일한 물리 시스템을 설명합니다. 차이는 계산 경로에 있습니다: 라그랑주 방법은 전역 방정식을 한 번에 수립하여 해석적 분석과 제어 설계에 적합하고, 뉴턴-오일러 방법은 재귀적으로 단계별 해석하여 수치 계산과 실시간 구현에 적합합니다. 현대 로봇 공학에서는 둘을 보완적으로 사용합니다: 라그랑주 방법은 제어 법칙의 구조적 형태를 유도하는 데, 뉴턴-오일러 방법은 실제 수치 해석에 사용됩니다.

누가 사용하는가: 적용 사례

① 전신 제어(WBC) 및 작업 공간 역동역학(TSID)

작업 공간 역동역학에서 각 작업의 기대 가속도 \(\ddot{\mathbf{x}}_i^*\)가 주어지면, 야코비안을 통해 작업 가속도를 관절 가속도로 매핑합니다:

\[ \ddot{\mathbf{x}}_i = \mathbf{J}_i \dot{\mathbf{v}} + \dot{\mathbf{J}}_i \mathbf{v} \]

여기서 \(\mathbf{J}_i\)는 작업 야코비안 행렬, \(\dot{\mathbf{v}}\)는 관절 가속도 벡터입니다. 동역학 제약(즉, 뉴턴-오일러 방정식)은 등식 제약으로 최적화 문제에 내장되어, 계산된 관절 토크가 시스템 동역학을 충족하도록 보장합니다. MIT 휴머노이드 로봇(ent_paper_chignoli_the_mit_humanoid_robot_design_2021)은 공중제비 및 회전 점프와 같은 곡예 동작의 착지 제어에서 모델 예측 제어와 전신 펄스 제어를 동역학적으로 일관된 방식으로 연결했으며, 그 동역학 모델은 뉴턴-오일러 방정식을 기반으로 구축되었습니다.

② 모델 예측 제어(MPC)의 예측 모델

제트 추진 휴머노이드 로봇 iRonCub의 통합 다중 속도 MPC 프레임워크(ent_paper_gorbani_unified_multi_rate_model_predi_2025)는 질량 중심 운동량 방정식을 사용하여 전차수 운동 방정식 대신 상태 차원을 압축하지만, 질량 중심 운동량 방정식 자체는 뉴턴-오일러 방정식을 전체 링크에 대해 합산하여 유도된 것입니다. 200 Hz 제어 주파수에서 1초 예측 시간 영역의 온라인 비행 제어를 구현하는 것은 뉴턴-오일러 방정식의 효율적 계산 특성에 의존합니다.

③ 시뮬레이터의 순방향 동역학

모든 물리 기반 로봇 시뮬레이터(예: MuJoCo, PyBullet, Drake)의 핵심은 순방향 동역학 해석입니다—관절 토크가 주어지면 관절 가속도를 계산합니다. Featherstone의 Rigid Body Dynamics Algorithms(Springer, 2008)은 공간 6D 벡터 표기법 기반의 강체 동역학 알고리즘을 체계적으로 정리했으며, 재귀 뉴턴-오일러 알고리즘과 관절체 알고리즘을 포함하여 시뮬레이터 구현의 표준 참고 자료입니다.

한계와 경계

① 모델 정밀도 의존성

뉴턴-오일러 방정식의 계산 결과는 입력 매개변수의 정확성에 전적으로 의존합니다. 관성 매개변수(질량, 질량 중심, 관성 텐서)의 식별 오차는 토크 계산 편차를 직접 초래합니다. 공학적 판단: 휴머노이드 로봇의 경우 링크 관성 텐서의 식별 오차는 일반적으로 5%–15% 사이이며, 이는 고동적 운동에서 상당한 토크 오차를 초래할 수 있습니다.

② 모델링되지 않은 효과

뉴턴-오일러 방정식은 이상적인 강체 동역학을 설명하며, 관절 마찰, 백래시, 유연 변형, 모터 포화와 같은 비이상적 효과를 포함하지 않습니다. 실제 시스템에서 이러한 효과는 관절 토크의 상당한 비율을 차지할 수 있으며, 특히 저속, 고부하 조건에서 두드러집니다.

③ 계산 실시간 경계

재귀 뉴턴-오일러 알고리즘의 복잡도가 \(O(n)\)이지만, 휴머노이드 로봇의 30+ 자유도 규모에서 단일 역동역학 해석은 여전히 수십 마이크로초가 소요됩니다. MPC에서 동역학 제약은 각 최적화 반복에서 여러 번 평가되어야 하므로 계산 부담이 크게 증가합니다. 공학적 판단: 1 kHz 제어 주파수의 전신 제어에서 뉴턴-오일러 방정식을 MPC 내부 제약으로 직접 사용하는 것은 일반적으로 불가능하며, 단순화된 모델(예: 질량 중심 운동량 모델) 또는 오프라인 사전 계산 전략이 필요합니다.

일반적인 오해

  1. "뉴턴-오일러 방정식은 뉴턴 제2법칙이다"—틀림. 이는 뉴턴 제2법칙과 오일러 회전 방정식의 결합이며, 둘 중 하나가 없으면 안 됩니다. 병진만 고려하고 회전을 고려하지 않으면 강체의 완전한 운동을 설명할 수 없습니다.

  2. "뉴턴-오일러 방법이 라그랑주 방법보다 더 정밀하다"—틀림. 둘은 수학적으로 엄밀히 동등하며 동일한 물리 시스템을 설명합니다. 차이는 계산 경로와 적용 시나리오에 있으며, 정밀도에는 없습니다.

  3. "재귀 알고리즘은 역동역학에만 사용할 수 있다"—틀림. 적절한 변환(예: Featherstone의 관절체 알고리즘)을 통해 재귀 아이디어는 순방향 동역학 해석에도 동일하게 적용되며 \(O(n)\) 복잡도를 유지합니다.

  4. "뉴턴-오일러 방정식은 직렬 로봇 팔에만 적용된다"—틀림. 고전적 재귀 알고리즘은 트리 구조를 대상으로 하지만(직렬 로봇 팔은 특수한 경우), 확장(예: 폐쇄 체인 및 병렬 메커니즘 처리)을 통해 뉴턴-오일러 방법은 더 일반적인 다물체 시스템에도 적용됩니다.

  5. "뉴턴-오일러 방정식이 있으면 라그랑주 방법이 필요 없다"—틀림. 라그랑주 방법은 제어 법칙 설계, 시스템 분석 및 에너지 성형 제어에서 여전히 대체 불가능한 가치가 있습니다. 둘은 대체 관계가 아니라 보완 관계입니다.

  • ent_formalism_euler_lagrange_equations — 오일러-라그랑주 방정식은 라그랑주 방법의 수학적 형식화이며, 뉴턴-오일러 방정식과 동일한 물리 시스템을 설명합니다.

  • ent_paper_lift_towards_bridging_the_gap_2026 — 해당 sim-to-real 프레임워크의 세계 모델은 강체 동역학 사전 지식을 내장하며, 뉴턴-오일러 방정식은 동역학 예측의 핵심 계산 기반입니다.
