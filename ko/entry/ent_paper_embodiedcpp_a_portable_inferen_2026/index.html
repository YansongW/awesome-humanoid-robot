요약

arXiv:2607.02501v2 Announce Type: replace Abstract: Embodied AI models now span vision-language-action (VLA) models and world-action models (WAMs), but practical deployment remains fragmented across model-specific Python stacks, backend assumptions, and robot-side glue code, especially on heterogeneous edge devices. Existing inference runtimes are designed mainly for request-response serving and therefore do not satisfy the runtime contract of embodied deployment: multi-rate execution inside closed-loop control, latency-first batch-1 inference on heterogeneous hardware, and extensible embodied interfaces beyond fixed token I/O. We present Embodied$.$cpp, a portable C++ inference runtime for embodied models. Based on an architectural analysis of representative VLA models and WAMs, Embodied$.$cpp captures a shared execution path and organizes it into five layers: input adapters, sequence builders, backbone execution, head plugins, and deployment adapters. The runtime provides modular multi-rate execution, latency-first fused inference, and extensible operator and I/O support, enabling deployment across heterogeneous devices, robots, and simulators through one backend abstraction. We evaluate Embodied$.$cpp on two VLA models, HY-VLA and pi0.5, and on a preliminary WAM benchmark using a LingBot-VA Transformer block. The VLA deployments achieve successful closed-loop execution with 100.0% and 91.0% task success rates, respectively. The WAM benchmark reduces block memory from 312.2 MiB to 88.1 MiB. These results show that Embodied$.$cpp improves deployment efficiency while preserving high accuracy across diverse embodied model architectures.

개요

기존 추론 런타임은 주로 요청-응답 서비스를 대상으로 하여, 실현(具身) 배포의 실시간 폐루프 제어 요구를 충족할 수 없습니다. Embodied\(.\)cpp는 대표적인 VLA 모델과 WAM 모델을 분석하여 공유 실행 경로를 추출하고, 이를 입력 어댑터, 시퀀스 빌더, 백본 실행, 헤드 플러그인, 배포 어댑터의 5계층 아키텍처로 구성합니다. 이 런타임은 모듈식 다중 속도 실행, 지연 우선 융합 추론, 확장 가능한 연산자 및 I/O 지원을 제공하며, 단일 백엔드 추상화를 통해 이기종 디바이스, 로봇, 시뮬레이터 간 배포를 구현합니다.

핵심 내용

방법 아키텍처

  • 5계층 설계: 입력 어댑터는 다중 모달 입력을 처리하고, 시퀀스 빌더는 토큰 시퀀스를 구성하며, 백본 실행 계층은 핵심 모델을 실행하고, 헤드 플러그인은 작업별 출력을 지원하며, 배포 어댑터는 다양한 하드웨어 백엔드에 연결됩니다.
  • 핵심 특징: 모듈식 다중 속도 실행은 폐루프 제어에서 서로 다른 주파수의 모델 호출을 지원합니다. 지연 우선 융합 추론은 batch-1 시나리오에 최적화되어 있습니다. 확장 가능한 연산자 및 I/O 지원은 고정 토큰 인터페이스를 넘어선 실현 상호작용을 가능하게 합니다.

실험 설정

  • VLA 모델 평가: HY-VLA와 pi0.5 두 모델에서 폐루프 실행을 테스트했으며, 작업 성공률은 각각 100.0%와 91.0%에 도달했습니다.
  • WAM 벤치마크: LingBot-VA Transformer 블록을 사용한 초기 평가에서 블록 메모리 사용량을 312.2 MiB에서 88.1 MiB로 줄였습니다.

핵심 결론

  • Embodied\(.\)cpp는 높은 정밀도를 유지하면서 배포 효율성을 크게 향상시키며, 이기종 디바이스, 로봇, 시뮬레이터의 통합 추론을 지원합니다.
  • 메모리 최적화 효과가 두드러지며, WAM 벤치마크에서 메모리가 70% 이상 감소하여 아키텍처 설계의 유효성을 검증했습니다.
