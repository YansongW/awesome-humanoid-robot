요약

The ability to react dynamically to tactile signals has long been considered crucial to agile human-level dexterity. Yet contemporary learning-based Vision-Language-Action (VLA) models for robotic manipulation generally either overlook the tactile modality or are limited to encoders with static cues, due in part to the scarcity of diverse training data and standardized evaluation, architectural constraints in current Institutions per source list: UC Berkeley、NVIDIA、Stanford、Panasonic、La Sapienza University、ItalAI.

개요

T-Rex는 촉각 반응형 정밀 조작(tactile-reactive dexterous manipulation)을 위한 통합 기반 모델로, 연구팀이 제안했으며 대규모 촉각 데이터셋(T-Rex Dataset, 100시간)과 3단계 훈련 패러다임(사전 훈련-중간 훈련-후속 훈련)을 포함합니다. 핵심 기여는 Mixture-of-Transformer-Experts(MoT) 아키텍처와 비동기 캐스케이드 플로우 매칭(asynchronous cascaded flow matching)을 통해 표준 VLA 백본에 고주파 촉각 반응 능력을 효율적으로 주입하여, 12개의 접촉 집약적 작업에서 평균 성공률 65%를 달성, 최강 기준선인 EgoScale(35%)보다 30% 포인트 높은 성능을 보인 것입니다.

무엇을 바꾸었는가

기존 VLA 모델은 로봇 조작에서 촉각을 거의 체계적으로 무시하거나, 단지 정적 단서로만 인코딩합니다. 이는 단순한 데이터 부족이 아니라 세 가지 구조적 모순이 겹친 결과입니다: 촉각 반응은 시각 루프보다 훨씬 높은 제어 주파수를 필요로 하며(인간의 손재주는 빠르고 세밀한 촉각 신호에 의존), 표준 VLM 백본의 실행 주파수는 이를 따라잡을 수 없습니다; 대규모 사전 훈련 패러다임(예: EgoScale)은 1인칭 인간 비디오를 중심으로 하여 힘 변화, 미세 슬립, 국부 변형과 같은 핵심 물리적 신호가 부족합니다; 촉각 정책을 처음부터 학습하려면 대규모 동기화된 시각-촉각 데이터가 필요하지만, 세밀한 손재주 원격 조작 데이터 수집 비용이 너무 높습니다. 저자들은 사전 훈련 단계에서 촉각 데이터 부족 문제를 해결하려 하지 않고, 전용 "중간 훈련" 단계를 통해 사전 훈련과 작업 후속 훈련 사이에 촉각 접지(tactile grounding)를 삽입하여 사전 훈련 단계의 촉각 데이터 요구를 우회합니다. 이는 "촉각 능력은 처음부터 학습해야 한다" 또는 "대규모 촉각 사전 훈련에 의존해야 한다"는 기존 경로를 바꾸어, 촉각 반응을 기본 표현의 일부가 아닌 효율적으로 전이 가능한 기술로 간주합니다.

방법 분해

3단계 훈련 패러다임

  1. 사전 훈련: EgoScale을 따라 22,889시간의 1인칭 인간 비디오에서 잠재 전문가(latent expert)와 행동 전문가(action expert)를 사전 훈련합니다. 잠재 전문가는 머리 시점 관측의 시각-언어 표현을 학습하고, 행동 전문가는 통합 행동 공간에서 재타겟팅된 인간 팔과 손 움직임을 훈련합니다.
  2. 중간 훈련: 100시간의 원격 조작 양팔 조작 데이터(동기화된 촉각 신호 포함)를 사용하여 행동 전문가를 로봇 다중 시점 관측과 실행 가능한 행동에 적응시키는 동시에, 촉각 전문가(tactile expert)를 훈련하여 고주파 노이즈 제거를 세밀한 정제로 수행합니다.
  3. 후속 훈련: 약 100개의 작업 시연에서 미세 조정하여 특정 작업 요구 사항에 적응하면서, 중간 훈련에서 얻은 촉각 반응 행동을 유지합니다.

모델 아키텍처: Mixture-of-Transformer-Experts(MoT)

  • 잠재 전문가: Qwen3VL-2B, 은닉 차원 2048, 28개 레이어, 파라미터 수 1.41B, 시각 및 언어 관측을 처리하고 미래 시각 표현을 예측합니다.
  • 행동 전문가: Qwen3VL-2B, 행동 차원 62, 행동 블록 16, 파라미터 수 1.41B, 저주파 행동 노이즈 제거(순수 노이즈에서 중간 시간 단계 τ_split까지).
  • 촉각 전문가: 행동 차원 62, 행동 블록 16, FFN 중간 크기 1536, 파라미터 수 0.62B, τ_split에서 τ=0까지 노이즈 제거, 고주파 촉각 관측으로 행동 정제.

공간-시간 촉각 인코딩

  • 손가락별 VQ-VAE가 최근 힘 이력 f_{t-15:t}(15단계 이력)를 압축하여 컴팩트한 시간 토큰(코드북 크기 K=64, EMA 업데이트, 진폭 가중 MSE 손실)으로 변환합니다.
  • 현재 힘 벡터 f_t는 직접 투영되어 순간 접촉 정보를 보존합니다.
  • 컨볼루션 인코더(ResNet-18 백본, 단일 채널 입력, 처음 세 개의 잔차 단계)가 현재 변형 맵 d_t의 특징을 추출합니다.
  • 세 가지를 연결하여 촉각 토큰 시퀀스 z_t^τ를 형성합니다.

비동기 촉각 반응 캐스케이드 플로우 매칭

  • 고정 시간 단계 τ_split에서 플로우 매칭 궤적을 분할: 행동 전문가는 상단 구간 τ∈[τ_split,1]을 노이즈 제거하고, 촉각 전문가는 캐시된 시각-언어 컨텍스트를 재사용하며 실시간 촉각 관측으로 나머지 노이즈 제거 τ∈[0,τ_split]를 완료합니다.
  • 공유 플로우 목표: 시연 행동 블록 A_demo와 가우시안 노이즈 ε가 주어지면, 선형 보간 x_τ=(1-τ)A_demo+τε, 일정 속도 목표 v=ε-A_demo; 두 전문가는 서로소 하위 구간에서 동일한 목표 v를 회귀합니다.
  • 추론 구성: N=10 오일러 단계, τ_split=0.4, K_slow=6단계(Δτ=-0.1), K_fast=4단계, 행동 블록 길이 T_a=16, 고속 플로우 트리거 오프셋 {0,4,8,12}.
  • 훈련 프로토콜: 행동 전문가는 τ_act~Beta(1.5,1.0)을 (0,1]에서 샘플링; 촉각 전문가는 τ_tac=τ_split·τ̃, τ̃~Beta(1.5,1.0)을 (0,τ_split]에서 샘플링; 총 손실 L = L_act + λ_tac·L_tac + λ_future·L_future, λ_tac=1.0, λ_future=0.5.
  • 지연 증강: Uniform{0,4,8,12}에서 이산 지연 δ를 추출하여 촉각 토큰 프레임 인덱스를 무작위로 이동, 배포 시의 오래된 정도 분포와 일치시킵니다.
  • 런타임 직렬화: 단일 스레드 요청 소켓과 명시적 실행 잠금으로 고속 틱이 저속 틱이 KV_τsplit 캐시와 중간 경계 상태 x̂_τsplit을 커밋하기 전에 시작되지 않도록 보장합니다.

핵심 혁신

  1. 비동기 캐스케이드 플로우 매칭(Asynchronous Cascaded Flow Matching): 플로우 매칭 궤적을 고정 시간 단계 τ_split에서 분할하고, 행동 전문가(저속 플로우)와 촉각 전문가(고속 플로우)가 서로소 하위 구간에서 동일한 속도 목표를 회귀합니다. 이는 VLA 백본 주파수와 촉각 반응 요구 사이의 근본적 불일치를 해결합니다—촉각 전문가는 원시 시각 관측과 완전히 독립적이며, 고주파 촉각 토큰과 캐시된 시각-언어 컨텍스트만을 조건으로 하므로, 각 제어 단계의 계산 비용은 경량 촉각 전문가의 K_fast 오일러 단계에 의해 지배됩니다.
  2. 촉각 접지 중간 훈련(Tactile Grounding Mid-training): 사전 훈련과 후속 훈련 사이에 전용 촉각 접지 단계를 삽입하고, 100시간의 촉각 동기화 원격 조작 데이터(502개 물체-운동 원시 조합, 22개 운동 원시)를 사용하여 모델이 효율적으로 촉각 반응 능력을 획득하게 하여 사전 훈련 단계의 촉각 데이터 요구를 우회합니다. 이는 하류 작업에 필요한 데이터 양을 크게 줄입니다(그림 5: 저데이터 영역에서 성능 향상이 뚜렷함).
  3. 공간-시간 촉각 인코딩: 손가락별 VQ-VAE가 힘 이력을 이산 드리프트 방지 토큰으로 압축하고, 현재 힘 벡터는 직접 투영되어 순간 접촉 정보를 보존하며, 컨볼루션 인코더가 변형 맵 특징을 추출합니다. 세 가지를 연결하여 통합된 촉각 토큰 시퀀스를 형성하며, 시간 컨텍스트, 순간 힘, 국부 변형을 모두 고려하고, VQ-VAE의 이산화 설계는 교차 장치 견고성을 강화합니다.

실험 및 결과

대조 실험에서 T-Rex는 여섯 개 기준선(ViTacFormer, RDP, Tactile-VLA, EgoScale, π₀.₅, π₀.₅ + tactile)과 12개의 접촉 집약적 작업에서 하나씩 비교되었으며, 각 작업은 16회 시험, 물체 위치와 회전은 무작위화, 다단계 작업은 진행 기반 점수 기준을 사용했습니다. 표 1은 각 방법의 평균 작업 성공률(%)을 보고하며, 결과는 먼저 시험별 평균 후 작업별 평균입니다.

  • 대규모 사전 훈련은 정밀 조작의 기초: 작업별 시연만으로 처음부터 훈련된 소형 정책(ViTacFormer 평균 3, RDP 평균 6)은 모든 작업에서 지속적으로 저조한 성능을 보였습니다; 반면 EgoScale은 대규모 1인칭 사전 훈련과 손 자세 감독 덕분에 작업별 실제 로봇 데이터만으로 훈련된 π₀.₅(35 vs 17)와 Tactile-VLA(35 vs 15)보다 크게 우수했습니다. T-Rex는 사전 훈련과 촉각 접지 중간 훈련을 결합하여 평균 성공률 65를 달성, 최강 기준선 EgoScale보다 30% 높습니다(표 내 수치 35→65로 계산).
  • 촉각 피드백은 접촉 집약적 조작에 필수적이지만, 통합 방식이 성패를 결정: EgoScale과 같은 사전 훈련 VLA 모델도 정밀 접촉 조정과 힘 민감 행동에서 여전히 실패합니다; T-Rex는 대규모 사전 훈련과 촉각 접지 중간 훈련 및 촉각 반응 제어를 결합하여 최강 전체 성능을 달성합니다. 주목할 점은, 단순한 촉각 조건화는 오히려 성능을 저해한다는 것입니다—π₀.₅ + tactile은 π₀.₅ 대비 평균 성공률이 17에서 6으로 감소(표 내 수치 17→6으로 계산)하여, 효과적인 촉각 통합 방식의 중요성을 부각합니다.
  • 비동기 캐스케이드와 각 촉각 양식은 독립적 기여를 가짐: 소거 실험에서 모든 촉각 입력 제거 시 감소 폭이 가장 큼(평균 65→42, -23%); 변형만 사용(-11%)과 힘만 사용(-6%) 모두 손실이 있어, 공간 변형 인식과 시간 힘 인코딩이 상호 보완적임을 시사; VQ-VAE 힘 인코더는 MLP 힘 인코더보다 우수(59 vs 58, -6% vs -7%); 비동기 정제는 동기 기준선보다 일관되게 우수(60 vs 65, -5%)하여, 저주파 시각 운동 계획과 고주파 촉각 제어의 분리 이점을 검증합니다. 훈련 레시피 소거는 사전 훈련과 중간 훈련 각 단계가 기여함을 추가로 보여줍니다: 사전 훈련 없음 및 중간 훈련 없음 시 평균 18에 불과, 중간 훈련 추가 시 34로 상승, 사전 훈련 추가 시 45로 상승, 전체 레시피는 65에 도달.

경계와 한계

  • 장시간 작업에서 정밀 접촉 조정과 밀착 공차 시나리오의 원격 조작이 어려우며, 향후 강화 학습 또는 온라인 상호작용 정제를 통합할 수 있습니다.
  • 촉각 반응 조작은 하드웨어 병목에 제한됩니다: 센서 왜곡, 교차 장치 보정 드리프트, 전손 조작을 지원하는 밀집 손바닥 센싱 부족.
  • 병렬 그리퍼 또는 단일 팔 실체에서 검증되지 않음; 강화 학습 통합 탐구되지 않음; 교차 장치 촉각 센서 일반화 미해결.
  • 실패 사례 분석은 다음을 보여줍니다: 세밀한 시각 정렬 부족(전구 조이기 작업에서 전구와 베이스 충돌), 작은 물체 파지 불안정(자물쇠 열기 작업에서 키 미끄러짐), 정밀 위치 결정 결함(계란 옮기기 작업에서 계란 트레이에 넣지 못함), 단일 손가락 수준 조정 부족(마작 분류 작업에서 엄지가 인접 패를 잘못 건드림), 변형 가능한 물체에 대한 힘 제어 과대(치약 짜기 작업에서 치약 과다 배출), 슬라이딩 운동 촉각 타이밍 조건 부족(카드 뽑기 작업에서 균일한 힘 적용 실패).
  • 논문에서 명시되지 않음: 구체적 모델 파라미터 수(부록의 세 전문가 파라미터 수 외), 훈련 에폭 수, 배치 크기, 학습률, 옵티마이저, 훈련 시간, GPU 수, 촉각 센서 구체적 모델, 데이터 수집 주파수, 추론 주파수의 구체적 수치(Hz), 코드 오픈소스 저장소 주소(프로젝트 홈페이지만 언급).

공학적 시사점

  • 먼저 하드웨어와 데이터 수집을 확인: T-Rex는 Dexmate Vega-1 양팔 플랫폼과 Sharpa Wave 손재주 손(22-DoF)에 의존하며, 촉각 관측은 손가락 끝별 6D 힘/토크 + 단일 채널 변형 깊이 맵입니다. 플랫폼의 촉각 센서 모델이나 레이아웃이 다르면 VQ-VAE 힘 인코더와 변형 인코더의 입력 분포가 달라져 재보정 또는 미세 조정이 필요합니다.
  • 가장 함정에 빠지기 쉬운 지점: 비동기 캐스케이드 노이즈 제거의 런타임 직렬화—고속 틱은 저속 틱이 KV_τsplit 캐시와 중간 경계 상태 x̂_τsplit을 커밋한 후에만 시작해야 하며, 그렇지 않으면 오래되었거나 준비되지 않은 캐시를 읽게 됩니다. 논문은 단일 스레드 요청 소켓과 명시적 실행 잠금을 명확히 사용하므로, 재현 시 동일한 동기화 메커니즘을 구현해야 합니다.
  • 데이터 효율성이 핵심 판매 포인트: 중간 훈련 단계(100시간, 502개 물체-운동 원시 조합)는 하류 작업에 필요한 시연 수를 크게 줄입니다(그림 5). 작업 예산이 제한적이라면(예: <50개 시연), 작업별 데이터를 처음부터 수집하는 대신 T-Rex 데이터셋을 재사용한 중간 훈련을 우선 고려하세요.
  • 촉각 인코딩의 세부 사항이 성패를 결정: VQ-VAE 코드북 크기 K=64, EMA 업데이트, 진폭 가중 MSE 손실(고힘 접촉 프레임에 더 높은 페널티 할당); 컨볼루션 가중치는 다섯 손가락 간 공유, 인코딩 전 손가락 ID 임베딩 주입. 센서 노이즈가 크다면 VQ-VAE의 이산화 안정성(드리프트 방지 설계)을 먼저 검증하는 것이 좋으며, 그렇지 않으면 촉각 토큰 품질이 고속 플로우 노이즈 제거 효과에 직접 영향을 미칩니다.
  • 추론 구성 조정 가능: τ_split=0.4, K_slow=6, K_fast=4, 행동 블록 T_a=16, 고속 플로우 트리거 오프셋 {0,4,8,12}는 논문의 기본값입니다. 작업이 더 높은 주파수의 촉각 반응(예: 더 빠른 슬립 감지)을 요구한다면 τ_split을 줄이거나 고속 플로우 트리거 주파수를 높일 수 있지만, 행동 전문가가 제공하는 시각 운동 사전이 그에 따라 약해진다는 점(그림 4의 트레이드오프)에 유의하세요.
