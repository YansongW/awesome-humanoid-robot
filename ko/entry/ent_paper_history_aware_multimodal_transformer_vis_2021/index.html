요약

Vision-and-language navigation (VLN) aims to build autonomous visual agents that follow instructions and navigate in real scenes. To remember previously visited locations and actions taken, most approaches to VLN implement memory using recurrent states. Institutions per source list: 法国国家信息与自动化研究所.

출처

  • arXiv:2110.13309 History Aware Multimodal Transformer for Vision-and-Language Navigation
  • Project page
  • GitHub仓库 Robotics_Notebooks

개요

본 논문은 HAMT(History Aware Multimodal Transformer)를 제안한다. 이는 전체 Transformer 아키텍처 기반의 시각-언어 내비게이션(VLN) 모델로, 계층적 인코더를 통해 장기간의 궤적 히스토리를 명시적으로 모델링하고, 지시문 및 현재 관측과 결합하여 다중 모달 행동 예측을 수행한다. 저자는 R2R, RxR, R4R, CVDN, REVERIE 등 7개 데이터셋에서 SOTA를 달성했으며, 특히 장기 내비게이션 작업에서 큰 성능 향상을 보였다.

무엇을 바꾸었는가

VLN 분야는 오랫동안 Seq2Seq + LSTM 패러다임이 지배해 왔으며, 히스토리 정보는 고정 차원의 순환 상태로 압축되어 장기 내비게이션에서 초기 관측과 행동에 대한 기억이 심각하게 감쇠되었다. PREVALENT와 같은 이전 연구들은 Transformer 사전 학습을 도입했지만, 단일 단계의 관측과 지시문만 인코딩할 뿐 궤적 히스토리에 대한 명시적 모델링이 부족했다. HAMT가 진정으로 바꾼 것은 '히스토리'를 암시적 순환 상태에서 명시적인 계층적 토큰 시퀀스로 승격시켜, 텍스트 및 현재 관측과 동등한 지위로 교차 모달 어텐션 계산에 참여할 수 있게 한 것이다. 이 변경은 VLN의 '긴 지시문 + 긴 궤적' 시나리오에서 메모리 손실이라는 핵심 문제점을 직접적으로 해결했으며, 역추적이나 장거리 계획이 필요한 R2R-Back, R4R 등의 작업에서 상당한 향상을 가져왔다.

방법 분석

전체 아키텍처

  • 세 개의 인코더: 단일 모달 언어 인코더(BERT 초기화), 단일 모달 시각 인코더(ViT-B/16), 교차 모달 Transformer.
  • 히스토리 인코딩은 계층적 전략을 사용: 각 단계의 방향성 뷰를 먼저 로컬 관측 토큰으로 인코딩한 후, 전역 히스토리 토큰으로 집계하여 현재 관측 토큰과 함께 교차 모달 Transformer에 입력.

2단계 훈련

  1. 에이전트 작업 사전 학습(엔드투엔드):
  2. MLM(마스크 언어 모델링): 15% 확률로 지시문 단어 마스킹, 음의 로그 우도 손실.
  3. MRM(마스크 영역 모델링): 15% 확률로 관측 마스킹, ImageNet 사전 학습 ViT의 클래스 분포와 KL 발산 매칭.
  4. ITM(지시문-궤적 매칭): 4개의 네거티브 샘플(2개 무작위, 2개 시간 순서 섞기), Noisy Contrastive Estimation.
  5. SAP(R)(단일 단계 행동 예측 및 회귀): 모방 학습으로 행동 직접 예측.
  6. SPREL(공간 관계 예측): 파노라마 내 공간 관계를 자기 지도 학습.
  7. 샘플링 비율: MLM:MRM:ITM:SAP:SAR:SPREL = 5:2:2:1:1:1.
  8. 미세 조정: RL + IL 공동 최적화, 작업별 다른 보상 사용(R2R/RxR/R4R은 경로 충실도 고려; R2R-Last/REVERIE/CVDN은 거리 감소만 사용).

핵심 설계 결정

  • 시각 특징: 에이전트 작업 단계에서는 ImageNet 사전 학습 ViT 사용; RxR 실험에서는 CLIP 특징 사용(엔드투엔드 아님); REVERIE에서는 R2R 엔드투엔드 최적화 ViT로 객체 특징 추출.
  • 구조 변형: 인코더-디코더 변형(텍스트-시각 교차 모달 어텐션 제거)은 긴 지시문 작업(R4R, RxR)에서 더 효율적.
  • 옵티마이저: AdamW; RandAugment 및 stochastic depth로 과적합 방지.

핵심 혁신

  1. 명시적 계층 히스토리 인코딩: 궤적 히스토리를 전역 토큰 시퀀스로 인코딩하여 텍스트 및 현재 관측과 병렬로 교차 모달 어텐션에 참여. 순환 상태나 시간 인코딩만 사용하는 방식과 비교하여, 계층적 방식은 R2R-Back에서 val unseen SPL을 37.7에서 51.7로 향상(e2e 없이)시켜 장기 정보를 효과적으로 보존함을 증명.
  2. 2단계 엔드투엔드 훈련: 단일 단계 엔드투엔드가 아닌 에이전트 작업 사전 학습 후 RL 미세 조정. 단일 단계 25k 반복 후 SPL은 53.5에 불과하여 엔드투엔드 없는 56.5보다 오히려 낮았으며, 이는 VLN 데이터가 제한적일 때 점진적 훈련이 더 안정적임을 시사.
  3. SPREL 자기 지도 작업: 파노라마 공간 관계 예측을 통해 보지 못한 환경에 대한 일반화 능력 향상. 절제 실험에서 SPREL 추가 시 val unseen SR이 64.5에서 65.7로 향상되었으며, SAP(R)과 상호 보완적.

핵심 결론

  • 에이전트 작업 사전 학습은 처음부터 훈련하는 것보다 val unseen에서 SR이 상대적으로 16.7% 향상.
  • ViT 엔드투엔드 훈련은 val unseen에서 SPL 2.1% 향상, 그러나 val seen에서는 0.8% 하락.
  • 다국어 HAMT는 RxR 테스트 세트에서 SR이 2위보다 12.83% 높지만, 여전히 인간 성능에는 크게 미치지 못함.

경계 및 한계

  • REVERIE 객체 위치 파악 한계: RGS 및 RGSPL이 테스트 세트에서 SOTA보다 낮음. 저자는 R2R 최적화 ViT로 객체 특징을 추출하여 객체 감지 사전 학습 특징보다 일반화가 떨어진다고 분석.
  • 단일 단계 엔드투엔드 실패: 25k 반복 시 오히려 엔드투엔드 없는 것보다 나쁨. VLN 데이터 양이 직접 엔드투엔드 훈련을 지원하기에 부족함을 시사.
  • 추론 오버헤드: HAMT는 RecBERT보다 1.5배 느림(104초 vs 69초), noT2V 변형은 1.1배 느림. 실시간 배포 시 트레이드오프 필요.
  • 인간과의 격차: RxR에서 다국어 HAMT와 인간 성능 간 격차가 여전히 크며, 논문은 구체적인 격차 수치를 정량화하지 않음.
  • 수행하지 않은 것: 연속 행동 VLN, 교차 데이터셋 전이의 상세 분석, 실제 로봇 배포 검증 미포함; 실패 사례 분석은 정성적으로만 언급(예: 주류 선반 인식 실패).

공학적 시사점

  • 히스토리 인코딩 방식 먼저 확인: 재현 시 계층적 히스토리 토큰의 집계 방식(전역 vs 로컬)이 논문과 일치하는지 반드시 확인. 이것이 성능 향상의 핵심. 시간 인코딩만 사용하면 R2R-Back에서 SPL이 약 9포인트 손실.
  • 2단계 훈련은 건너뛸 수 없음: 직접 엔드투엔드 훈련은 성능 하락(SPL 53.5 vs 56.5). 에이전트 작업 사전 학습의 순서와 샘플링 비율(5:2:2:1:1:1)을 엄격히 준수해야 함.
  • 시각 특징 선택은 양날의 검: ViT 엔드투엔드 최적화는 unseen에서 SPL 2.1% 향상, 그러나 seen에서 0.8% SPL 희생; REVERIE 작업에서는 객체 감지 사전 학습 모델로 객체 특징을 추출해야 하며, 그렇지 않으면 RGS가 뒤처짐.
  • RL+IL 둘 다 필수: IL만 사용 시 SR 57.2, RL만 63.5, 공동 사용 시 65.7. 모방 학습은 안정적인 그래디언트를 제공하고 RL은 탐색을 담당하며 상호 보완적.
  • 추론 시간 예산: 지연 시간에 민감한 배포 시나리오에서는 noT2V 변형 사용(76초 vs 104초), 성능은 SR 1%만 손실되지만 긴 지시문 작업에서의 성능 확인 필요.
  • 가장 함정에 빠지기 쉬운 부분: 에이전트 작업에서 ITM의 네거티브 샘플링(2개 무작위 + 2개 시간 순서 섞기) 및 Noisy Contrastive Estimation 구현 세부 사항; R2R-Back의 보상은 2단계로 계산해야 함(먼저 원래 목표에 도달한 후 시작점으로 복귀), 그렇지 않으면 훈련이 불안정해짐.
