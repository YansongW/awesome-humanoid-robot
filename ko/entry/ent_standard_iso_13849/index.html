요약

기계의 제어 시스템 설계를 위한 안전 표준으로, 위험 감소를 위한 성능 등급(PL)과 안전 카테고리를 규정.

개요

ISO 13849는 국제표준화기구가 발표한 기계 안전 관련 제어 시스템(SRP/CS) 기능 안전 표준으로, PL(Performance Level, 성능 등급) a–e로 안전 기능이 고장 상황에서도 여전히 올바르게 실행될 수 있는 능력을 정량화합니다. 이 표준이 실제로 바꾸는 것은 "로봇이 얼마나 안전한가"라는 추상적 약속이 아니라, "감사 가능한 엔지니어링 파라미터로 안전을 어떻게 증명할 것인가"라는 구체적 방법입니다. 휴머노이드 로봇이 인간-로봇 공존 환경에서 작동하려면, 그 안전 관련 제어 시스템은 기능 안전 요구사항을 충족해야 합니다: 고장이 발생했을 때에도 시스템이 여전히 로봇을 안전 상태로 이끌 수 있어야 합니다[37][38].

핵심 내용

무엇인가: 정확한 정의

ISO 13849(전체 명칭 Safety of machinery — Safety-related parts of control systems)는 기계 안전 표준 체계에서 B 클래스(일반 안전 표준)에 해당하며, 제어 시스템의 안전 관련 부품에 대한 기능 안전 요구사항을 제시합니다. 이 표준은 위험 평가에서 안전 기능 검증에 이르는 완전한 엔지니어링 방법론을 정의하며, 핵심 산출물은 PL(Performance Level)——PL a에서 PL e까지의 5단계 안전 성능 등급으로, 시간당 위험 고장 확률 \(PFH_d\)(Probability of Dangerous Failure per Hour)의 정량적 구간에 대응합니다.

휴머노이드 로봇 맥락에서 ISO 13849는 비상 정지, 안전 정지, 속도 모니터링, 충돌 감지 등의 안전 기능을 위한 제어 시스템 설계에 적용됩니다. 이 표준은 IEC 61508(기능 안전 일반 표준, SIL 1–4 정의)과 상호 보완적입니다: IEC 61508은 전기/전자/프로그래밍 가능 전자 시스템을 대상으로 하고, ISO 13849는 기계 안전 관련 제어 시스템에 특화되어 있으며, 두 표준은 기계 분야에서 IEC 62061을 통해 연결됩니다.

왜 존재하는가: 문제점과 역사적 위치

휴머노이드 로봇이 실험실 프로토타입에서 공장, 물류, 가정 환경으로 나아가기 위해 넘어야 할 문턱은 단일 성능 지표가 아니라 적합성(compliance)입니다: 제품이 목표 시장에서 법적으로 판매가 허용되어야 하고, 사고 발생 시 책임 추적에 견딜 수 있어야 합니다. 사고 발생 시 "적용 가능한 현행 표준을 준수했는지 여부"는 법원과 규제 기관이 제조업체가 주의 의무(duty of care)를 다했는지 판단하는 최우선 근거입니다. 표준 준수가 책임을 면제하는 것은 아니지만, 법적 위험을 크게 낮춥니다.

역사적으로 산업용 로봇 안전은 "격리" 철학에 의존했습니다: 인간과 로봇은 물리적 공간에서 울타리로 완전히 분리되었습니다. 그러나 휴머노이드 로봇의 형태학적 장점은 바로 인간의 작업 위치에 적응하고 인간과 물리적 공간을 공유할 수 있다는 점에 있습니다——이는 동시에 인간과의 근접 접촉이라는 시험을 견뎌야 함을 의미합니다. ISO 13849는 바로 이러한 배경에서 휴머노이드 로봇 안전 제어 시스템의 "공용어"가 되었습니다: 구체적인 제품 형태를 규정하지 않고, 안전 기능 고장 확률의 정량화 방법을 규정하므로 모든 전기기계 시스템에 적용 가능합니다.

원리 분석

① 위험 그래프 방법: 위험에서 목표 PL까지

ISO 13849는 기계 산업에서 가장 널리 사용되는 위험 평가 도구인 위험 그래프(risk graph)를 제공합니다. 설계자는 세 가지 차원에서 식별된 각 위험을 평가합니다:

  1. 상해 심각도(S): S1(경미한 상해, 일반적으로 회복 가능, 예: 찰과상, 경미한 타박상) 또는 S2(심각한 상해, 일반적으로 비가역적, 예: 골절, 절단, 사망);
  2. 위험 노출 빈도 및 지속 시간(F): F1(드물게 발생하거나 노출 시간이 짧음) 또는 F2(빈번하게 발생하거나 노출 시간이 김);
  3. 위험 회피 가능성(P): P1(특정 조건에서 회피 가능, 예: 충분한 반응 시간과 공간이 있는 경우) 또는 P2(회피가 거의 불가능).

세 차원의 조합이 목표 PL 등급에 매핑됩니다. 예를 들어 S2 + F2 + P2는 일반적으로 PL d 또는 PL e를 요구합니다.

② 네 가지 요소가 달성 가능한 PL 결정

엔지니어링적으로 하나의 채널이 달성할 수 있는 PL을 결정하려면 네 가지 요소를 동시에 평가해야 합니다:

  1. 구조 카테고리(Category): 아키텍처의 내결함성을 설명합니다. Category B는 진단 없는 단일 채널; Category 1은 검증된 부품과 안전 원칙 사용; Category 2는 주기적 테스트 도입; Category 3은 이중 채널 중복으로 단일 고장이 안전 기능 상실을 초래하지 않음; Category 4는 Category 3을 기반으로 고장이 적시에 감지되어야 함.
  2. 평균 위험 고장 시간 MTTF\(_d\)(Mean Time To dangerous Failure): 각 채널의 부품 수준 신뢰성 통계량으로, 낮음(3–10년), 중간(10–30년), 높음(30–100년)의 세 등급으로 구분됩니다. 부품 고장률 데이터(예: 제조업체가 제공하는 B10\(_d\) 값)로 계산됩니다:
\[ MTTF_d = \frac{B_{10d}}{0.1 \times n_{op}} \]

여기서 \(B_{10d}\)는 10% 부품에서 위험 고장이 발생할 때의 사이클 수, \(n_{op}\)는 연간 작동 횟수입니다.

  1. 평균 진단 커버리지 DC\(_{avg}\)(Diagnostic Coverage): 위험 고장 중 자가 진단으로 발견되는 비율로, 없음(<60%), 낮음(60–90%), 중간(90–99%), 높음(≥99%)의 네 등급으로 구분됩니다. 교차 모니터링, 패리티 검사, 워치독, 출력 재판독은 모두 DC를 높이는 수단입니다.
  2. 공통 원인 고장(CCF, Common Cause Failure): 중복 채널이 공통 원인(동일한 전원 강하, 동일한 고온 환경, 동일한 소프트웨어 버그)으로 동시에 고장나는 현상. 표준은 격리, 다양성, 환경 시험 등의 조치를 통해 충분한 CCF 점수를 얻을 것을 요구합니다.

③ 통 효과: 전체 체인 단계별 달성

시스템 전체의 SIL은 어떤 단일 요소가 지원할 수 있는 최고 SIL을 초과할 수 없습니다. 이것이 "SIL 3 레이저 레이더에 일반 MCU를 사용하는 것"으로 SIL 3를 주장할 수 없는 이유입니다——통 효과는 전체 체인이 단계별로 기준을 충족해야 함을 결정합니다. 마찬가지로 PL 등급은 Category, MTTF\(_d\), DC\(_{avg}\), CCF 네 가지 요소에 의해 공동 결정되며, 어느 하나라도 기준 미달이면 전체 PL이 낮아집니다.

핵심 파라미터 및 사양

ISO 13849의 PL 등급과 시간당 위험 고장 확률 \(PFH_d\)의 대응 관계는 다음과 같습니다:

PL \(PFH_d\)(시간당) 일반적 적용
PL a \(5 \times 10^{-5} \sim <10^{-4}\) 저위험
PL b \(3 \times 10^{-5} \sim <5 \times 10^{-5}\) 일반 위험
PL c \(2 \times 10^{-6} \sim <3 \times 10^{-5}\) 중간 위험
PL d \(1 \times 10^{-6} \sim <2 \times 10^{-6}\) 비교적 높은 위험
PL e \(\sim 1 \times 10^{-6}\) 고위험

ISO 13849는 비상 정지의 안전 기능 카테고리(Category)를 B에서 4까지 정의합니다:

카테고리 구조 요구사항 진단 커버리지(DC) 일반적 구현
Category B 단일 채널 — 일반 정지 버튼
Category 1 단일 채널 + 고신뢰성 부품 — 높은 MTTFd 단일 채널
Category 2 단일 채널 + 주기적 테스트 낮음 자체 점검 기능이 있는 단일 채널
Category 3 이중 채널, 단일 고장 안전 중간 이중 채널 비상 정지, 교차 모니터링
Category 4 이중 채널, 단일 고장 안전 및 대부분 고장 진단 가능 높음 이중 채널 + 높은 DC

휴머노이드 로봇과 같은 복잡한 전기기계 시스템의 경우 일반적으로 SIL2/PL d가 비교적 높은 요구사항이며, SIL3/PL e는 인간과 빈번하게 근접 상호작용하는 핵심 기능에 사용됩니다. 휴머노이드 로봇 핵심 안전 기능의 일반적 목표는 PL d / SIL 2에서 PL e / SIL 3이며, 안전 계층은 VLA 스택을 실행하는 기능 계층과 반드시 독립적이어야 합니다.

수평 비교

ISO 13849는 IEC 61508, IEC 62061과 함께 기능 안전 표준의 세 가지 계층을 구성합니다:

표준 위치 등급 체계 적용 대상
IEC 61508 기능 안전 일반 표준 SIL 1–4 전기/전자/프로그래밍 가능 전자 시스템
ISO 13849 기계 안전 관련 제어 시스템 PL a–e 기계 제어 시스템(유압, 공압 포함)
IEC 62061 IEC 61508의 기계 분야 적용 SIL 등급 기계 전기 제어 시스템

IEC 61508의 SIL은 주로 전기/전자/프로그래밍 가능 전자 시스템을 대상으로 하며, SIL1–SIL4는 서로 다른 위험 감소 요소에 대응합니다. IEC 62061은 IEC 61508의 기계 안전 분야 적용 표준으로, 로봇 안전 제어 시스템 설계에 자주 사용되며, SIL 등급을 채택하고 ISO 13849의 PFH_d 계산 방법을 결합하여 시스템 안전 무결성을 평가합니다. 실제 프로젝트에서 휴머노이드 로봇 안전 기능(예: 안전 정지, 속도 모니터링, 충돌 감지)은 적용 가능한 기계 안전 표준과 기능 안전 표준을 동시에 충족해야 합니다.

사용 사례·적용 사례

① 산업용 로봇 분야

ISO 13849는 산업용 로봇 안전 제어 시스템의 업계 표준입니다. 현대 휴머노이드 로봇의 비상 정지는 일반적으로 Category 3 또는 Category 4 이중 채널 설계를 채택합니다. 두 개의 비상 정지 접점이 직렬 또는 병렬로 안전 릴레이에 연결되며, 안전 릴레이는 두 채널의 상태가 일치하는지 지속적으로 감지합니다. 어느 한 채널이 끊기거나(버튼 눌림) 두 채널이 불일치하면(라인 고장), 안전 릴레이는 즉시 모터 드라이버 전원을 차단하거나 안전 토크 오프를 트리거합니다.

② 협동 로봇 분야

Mantis Robotics의 MR-1 단일 암 로봇은 ISO 10218 및 ISO 13849 인증을 통과했으며, 작동 속도는 10.6 m/s로 기존 협동 로봇의 6배입니다. 후속 제품인 MR-X 이중 암 로봇은 특허받은 Mantis SafetyCore 플랫폼——반사 시스템으로, 로봇이 실시간으로 환경을 인식하고 사람이 경로에 진입하면 작동을 중단하지 않고 자율적으로 반응할 수 있게 합니다. 이는 ISO 13849 인증과 혁신적 안전 아키텍처의 결합을 보여줍니다: 표준은 구체적인 구현 방식을 규정하지 않고, 고장 확률과 구조 요구사항만 규정합니다.

③ 휴머노이드 로봇 완제품

휴머노이드 로봇의 현재 곤란한 상황은 전용 C 클래스 표준이 없다는 점입니다. 이족 보행 휴머노이드 로봇은 ISO 10218의 "산업용 로봇"에도 완전히 속하지 않고, ISO 13482의 "개인 케어 로봇"에도 완전히 속하지 않으므로, 제조업체는 일반적으로 여러 표준을 조합하여 인용하고 인증 기관에 적용 가능성을 입증해야 합니다. 이것이 휴머노이드 로봇 인증 주기가 긴 근본적 이유 중 하나입니다. ISO 13849는 B 클래스 일반 안전 표준으로서 휴머노이드 로봇 안전 제어 아키텍처 설계의 핵심 근거입니다.

한계와 경계

① "성능 부족" 위험을 다루지 않음

IEC 61508과 ISO 13849는 "시스템 고장"——기능 상실로 인한 위험을 처리합니다. 그러나 휴머노이드 로봇에는 또 다른 유형의 위험이 있습니다: 시스템에 고장이 전혀 없지만, 기능 자체가 환경에 대응하기에 부족한 경우입니다. 예를 들어 시각 모델이 역광에서 사람을 배경으로 오인하거나, VLA 정책이 훈련 분포 밖의 명령에 대해 위험한 동작을 생성하는 경우입니다. 이러한 "성능 부족" 위험은 의도된 기능 안전(SOTIF, Safety Of The Intended Functionality, 자동차 분야의 ISO 21448에서 유래) 프레임워크로 처리됩니다. SOTIF는 시나리오를 네 가지 사분면으로 구분합니다: 알려진 안전, 알려진 불안전, 알려지지 않은 불안전, 알려지지 않은 안전. 엔지니어링 목표는 시나리오 라이브러리 축적, 트리거 조건 분석, 설계 개선을 통해 "알려진 안전" 영역을 지속적으로 확장하고 "알려지지 않은 불안전" 영역을 축소하는 것입니다.

② C 클래스 표준 부재 문제를 해결하지 않음

ISO 13849는 B 클래스 표준으로, 특정 제품 유형을 대상으로 하지 않습니다. 휴머노이드 로봇은 전용 C 클래스 제품 안전 표준이 부재하여, 제조업체는 여러 표준을 조합하여 인용하고 인증 기관에 적용 가능성을 입증해야 하므로 인증 주기가 길고 비용이 높습니다. 전체 인증 주기는 일반적으로 6–18개월이며, 완제품 아키텍처 설계와 동시에 시작해야 합니다.

③ 정량화 방법이 부품 데이터에 의존

MTTF\(_d\) 계산은 부품 고장률 데이터(예: B10\(_d\) 값)에 의존하지만, 휴머노이드 로봇이 사용하는 많은 신형 액추에이터와 센서는 장기 신뢰성 데이터 축적이 부족하여 MTTF\(_d\) 추정에 불확실성이 존재합니다. 이것은 엔지니어링 판단 차원의 현실적 제약입니다.

일반적인 오해

  1. "PL 등급이 높을수록 좋다"——틀림. PL e는 \(PFH_d\) 약 \(1 \times 10^{-6}\)에 해당하며, 이는 11.4년마다 한 번의 위험 고장만 허용됨을 의미합니다. 이 등급을 달성하려면 Category 4 아키텍처 + 높은 DC + 높은 MTTF\(_d\)가 필요하며, 비용과 복잡성이 급격히 증가합니다. 엔지니어링적으로는 위험 그래프 결과에 따라 "충분한" PL 등급을 선택해야 하며, 맹목적으로 최고를 추구해서는 안 됩니다.

  2. "SIL 3 센서 + 일반 MCU = SIL 3 시스템"——틀림. 통 효과는 시스템 전체의 SIL이 어떤 단일 요소가 지원할 수 있는 최고 SIL을 초과할 수 없음을 결정합니다. 안전 체인의 모든 요소——센서, 통신, 컨트롤러, 액추에이터——는 단계별로 기준을 충족해야 합니다.

  3. "ISO 13849 준수 = 안전"——틀림. 표준 준수가 책임을 면제하는 것은 아니지만, 법적 위험을 크게 낮춥니다. ISO 13849는 제어 시스템 고장으로 인한 위험만 다루며, "성능 부족"(SOTIF 범주)이나 기계 구조 고장 등의 위험은 다루지 않습니다.

  4. "Category 3 = 이중 채널"——불완전함. Category 3은 중복 이중 채널과 단일 고장이 안전 기능 상실을 초래하지 않음을 요구하지만, 고장이 적시에 감지될 것을 요구하지는 않습니다. Category 4에서만 고장의 적시 감지가 요구됩니다. 이중 채널이 공통 원인 고장(예: 공용 전원)을 겪으면 Category 3도 고장날 수 있습니다——이것이 CCF 점수가 존재하는 이유입니다.

  • ent_concept_human_robot_collaboration_safety — 인간-로봇 협동 안전은 ISO 13849를 포함한 다중 표준 체계이며, ISO 13849는 제어 시스템 기능 안전의 정량화 방법을 제공합니다.
  • ent_standard_iso_ts_15066_2016 — ISO/TS 15066은 협동 로봇의 인간-로봇 접촉 시 힘과 압력 한계를 정의하며, ISO 13849의 기능 안전 요구사항과 함께 협동 안전의 기술적 기반을 구성합니다.
  • ent_component_safety_mcu — 안전 MCU는 ISO 13849 안전 기능을 실행하는 대표적인 하드웨어载体이며, 메인 컨트롤러와 독립된 "안전 섬" 아키텍처는 Category 3/4의 중복 요구사항에 대응합니다.
  • ent_report_industry_mantis_robotics_extends_potent_2026 — Mantis Robotics의 MR-1은 ISO 13849 인증을 통과했으며, 고속 협동 로봇에서 ISO 13849의 실제 적용 사례입니다.
  • ent_standard_ul_fcc_ce — CE 마크 등의 지역 시장 진입 인증은 기계 안전 분야에서 일반적으로 ISO 13849를 조화 표준으로 인용하여 적합성 체인의 일부를 구성합니다.
