Scaling Data Generation in Vision-and-Language Navigation

Scaling Data Generation in Vision-and-Language Navigation

요약

Recent research in language-guided visual navigation has demonstrated a significant demand for the diversity of traversable environments and the quantity of supervision for training generalizable agents. Institutions per source list: 澳大利亚国立大学、上海 AI Lab.

출처

  • arXiv:2307.15644 Scaling Data Generation in Vision-and-Language Navigation
  • GitHub仓库 Robotics_Notebooks

개요

본 논문은 ScaleVLN을 제안한다. 이는 완전 자동화되고 재현 가능한 대규모 시각-언어 내비게이션(VLN) 데이터 생성 및 훈련 패러다임이다. 저자들은 HM3D와 Gibson의 1200개 이상의 실제 환경을 활용하여 고품질 내비게이션 그래프를 구축하고, 렌더링 이미지를 복구하며, 490만 개의 명령-궤적 쌍을 생성하고, 2단계 사전 훈련-미세 조정을 통해 R2R, REVERIE, CVDN, R2R-CE 네 가지 벤치마크에서 새로운 SOTA를 달성했다. 핵심 기여는 '장면 수가 샘플 수보다 중요하다'는 점과 '내비게이션 그래프 품질과 이미지 품질이 사전 훈련 효과에 결정적인 영향을 미친다'는 점을 입증한 것이다.

그것이 바꾼 것

VLN 분야는 오랫동안 데이터 부족에 발목이 잡혀 있었다. R2R은 22k개의 수동 주석만 있고, PREVALENT 증강 데이터도 178k개에 불과하며, 모두 MP3D의 61개 장면에서 비롯되었다. 이전의 주류 해법은 네트워크 이미지-텍스트 사전 훈련된 대형 VLM에 의존하거나, AutoVLN처럼 희소하고 충돌이 있는 내비게이션 그래프로 때우거나, MARVAL처럼 비공개인 Marky와 MURAL에 의존하는 것이었다——재현이 불가능할 뿐만 아니라 문제를 복잡하게 만들었다.

ScaleVLN이 진정으로 바꾼 것은 '데이터가 어디서 오는가'라는 근본적인 가정이다. 이는 모델 아키텍처나 사전 훈련 작업에 머리를 싸매기보다 '탐색 가능한 환경을 사용하여 고품질 도메인 내 데이터를 생성하는 것'에 힘을 쏟는 것이 낫다는 것을 증명했다. 저자들은 데이터 생성을 내비게이션 그래프 구축, 이미지 복구, 궤적 샘플링, 명령 생성의 네 가지 하위 문제로 분해하고, 각각 기성 도구로 해결하여 최종적으로 R2R의 352배에 달하는 데이터 양을 생산했다. 이 패러다임의 의의는 VLN 커뮤니티가 처음으로 재현 가능하고 확장 가능하며 이전의 모든 증강 방식보다 훨씬 우수한 데이터 생성 파이프라인을 갖게 되었다는 점이다——신비한 모델이 아니라 Habitat 시뮬레이터, Co-Mod GAN, EnvDrop Speaker 같은 기성 구성 요소를 공학적으로 조립한 것이다.

방법 분해

데이터 생성 파이프라인(4단계)

  1. 내비게이션 그래프 구축
  2. Habitat으로 시점을 샘플링하고, 임의의 두 시점 간 측지 거리 > 0.4 m.
  3. 응집 클러스터링(임계값 1.0 m)으로 인접 시점을 병합하여 노드가 자동으로 개방 공간 중심에 가까워지도록 함.
  4. 5.0 m 내 시점을 무작위로 연결하고, 노드당 최대 간선 수 5개, 그래프 정제 방법으로 완전 연결 및 완전 탐색 가능성을 보장.

  5. 최종 그래프 평균 변 길이 1.41 m, 평균 노드 차수 4.55, 충돌률 0.00%(AutoVLN의 29.35%와 대조).

  6. 이미지 복구

  7. 손상된 렌더링을 이미지-이미지 변환으로 간주하고, Co-Modulated GAN을 Matterport3D 렌더링-카메라 이미지 쌍으로 훈련.

  8. 512×1024 파노라마에서 4장의 512×512 이미지(중심 각도 0°/90°/180°/270°)를 잘라내어 각각 복구한 후 36장의 단일 시점 이미지(12 시점 × 3 앙각)를 추출.

  9. 궤적 샘플링

  10. PREVALENT를 따라 3-5개의 중간 노드로 연결된 임의의 두 점 사이의 최단 경로를 수집.

  11. HM3D에서 2,890,267개, Gibson에서 2,051,443개 생성, 총 4,941,710개의 명령-궤적 쌍.

  12. 명령 생성

  13. 기성 EnvDrop Speaker(R2R에서 훈련된 LSTM)로 각 궤적에 대한 명령 생성.
  14. 저자들은 GPT-2와 명시적으로 비교: EnvDrop의 Bleu-4가 더 높고(27.66 vs 24.36), R2R 에이전트 성능 향상은 유사하지만 다양성은 더 낮음.

훈련 전략

  • 사전 훈련: DUET 또는 HAMT, 20k 반복, batch size 256, lr 5×10⁻⁵, 2×A100, 약 72 GPU 시간.
  • 대리 작업: MLM(15% 토큰 마스킹), MRM(15% 뷰 마스킹), SAP(다음 행동 예측), 각 반복에서 동일 확률로 하나를 샘플링.
  • 미세 조정: DA GGER(모방 학습), 200k 반복, batch size 16, 단일 GPU, 약 48 GPU 시간.
  • 핵심 결정:
  • 사전 훈련은 R2R+PREV+HM-E 세 가지를 상호 보완적으로 사용; 미세 조정은 HM-E를 유지하지만 PREV를 제거(PREV가 MP3D에 과적합을 유발).
  • 미세 조정에 Gib-E를 추가하는 것은 무익함(도메인 격차가 노이즈를 유발).
  • MRM을 MLM+SAP와 결합하면 오히려 성능이 약간 하락(대규모 데이터가 이미 풍부한 의미론을 제공하므로 마스킹 영역 예측이 노이즈를 유발).

핵심 혁신

  1. '장면 수 > 샘플 수'의 실증적 결론: 표 2는 800개 장면/700k 샘플(Val-Unseen SR 76.25)이 200개 장면/700k 샘플(SR 74.84)보다 훨씬 우수하고, 800개 장면/2890k 샘플(SR 76.59)과 800개 장면/700k 샘플(SR 76.25)의 차이는 매우 작다는 것을 보여준다. 이는 '데이터 양 쌓기'라는 직관을 직접적으로 뒤집으며, 이후 데이터 생성 작업의 방향을 제시한다——환경을 더 많이 수집하는 것이 궤적을 더 많이 샘플링하는 것보다 효율적이다.

  2. 고품질 내비게이션 그래프의 재현 가능한 구축 방법: AutoVLN의 그래프 노드는 희소하고(밀도 0.36 노드/m²), 충돌률은 29.35%이며, MARVAL은 훈련된 모델로 탐색 가능한 방향을 예측한다(복잡하고 오류 가능). ScaleVLN은 Habitat 샘플링 + 응집 클러스터링 + 그래프 정제를 통해 밀도 1.16 노드/m², 충돌률 0.00%의 그래프를 얻고 완전히 재현 가능하다. '단순한 공학적 해법이 복잡한 학습 해법을 이기는' 이 사례는 VLN 데이터 생성 분야에서 설득력이 있다.

  3. 이미지 복구가 사전 훈련에 미치는 결정적 영향: 표 4는 HM-E (R) + Gib-E (F)(환경이 61% 더 많지만 이미지 손상)가 HM-E (R) 단독보다 더 나쁘다는 것을 보여준다(Val-Unseen SR 76.33 vs 76.59). 이는 '시각적 품질 > 환경 수'를 의미한다——Co-Mod GAN으로 이미지를 복구하는 것은 단순한 부가 기능이 아니라 데이터 생성 파이프라인의 필수 단계이다.

소거 실험 핵심 결론

  • 데이터 양: 800개 장면/700k 샘플(SR 76.25) ≈ 800개 장면/2890k 샘플(SR 76.59), 하지만 200개 장면/700k(SR 74.84)보다 훨씬 우수——장면 수가 지배적.
  • 사전 훈련 데이터 조합: R2R+PREV+HM-E 사전 훈련 + R2R+HM-E 미세 조정(방법 6)이 Val-Unseen SR 79.10에 도달, seen/unseen 격차 < 1%(80.02 vs 79.10).
  • 사전 훈련 작업: MLM+SAP는 사전 훈련 없음보다 SPL이 16.49% 높음; MRM 추가 시 약간 하락(Val-Unseen SR 75.82 vs 76.59).
  • 시각 인코더: CLIP ViT-H/14가 B/16보다 Val-Unseen SPL이 1.4 높음(표 내 수치 11.0÷8.0으로 계산)(69.71 vs 68.31).
  • 깊이 모달리티: HM3D 증강이 없을 때 RGBD가 SR을 크게 향상(74.12 vs 72.92); HM3D 증강이 있을 때 RGBD의 SR은 RGB-only보다 약간 낮음(76.46 vs 76.59).
  • 교차 모델 일반화: Seq2Seq, EnvDrop, HAMT가 ScaleVLN을 사용할 때 PREVALENT를 사용할 때보다 SR이 각각 12.2%, 3.8%, 5.5% 향상.

경계와 한계

저자들은 한계 섹션을 명시적으로 나열하지 않았지만 실험에서 추론할 수 있다:

  • 명령 품질의 한계: EnvDrop Speaker의 Bleu-4는 27.66에 불과하며, 저자들은 생성된 명령의 품질이 낮고 다양성이 부족하며 두 가지 간단한 생성 모델만 시도했다고 인정한다. 더 나은 명령 생성(예: GPT-4 수준)은 명확히 탐구되지 않은 방향이다.
  • 미세 조정 단계에서 Gibson 데이터의 무효화: 저자들은 도메인 격차가 노이즈를 유발한다고 추측하지만 깊이 있는 분석(도메인 적응이나 데이터 필터링 등)은 수행하지 않았다.
  • 정지 문제 미해결: 저자들은 인간과의 6% SR 격차가 OSR-SR 격차(6-7%)와 유사하다고 지적하며 정책 네트워크의 개선이 필요함을 시사하지만 해결책을 제시하지는 않았다.
  • 실제 세계 검증 없음: sim-to-real 전이 실험은 언급되지 않았다.
  • 깊이 모달리티 결론의 의문: 저자들은 데이터 규모가 커지면 깊이 정보가 더 이상 필요하지 않을 수 있다고 의심하지만 검증하지는 않았다.

공학적 시사점

ScaleVLN을 재현하거나 참고할 때 다음 세 가지를 우선 확인하라:

  1. 내비게이션 그래프 품질이 기초: 먼저 그래프의 충돌률과 노드 밀도를 확인하라. AutoVLN의 29.35% 충돌률은 사전 훈련 데이터를 직접 오염시킨다. Habitat 샘플링 + 응집 클러스터링(임계값 1.0 m) + 5.0 m 연결 + 최대 간선 수 5의 매개변수를 사용하면 평균 변 길이 1.41 m, 노드 차수 4.55가 합리적인 목표이다.

  2. 이미지 복구는 건너뛸 수 없음: HM3D/Gibson의 렌더링 이미지 손상은 실제 문제이다. 표 4는 '환경이 61% 더 많지만 이미지가 손상된 경우'가 '환경이 적지만 이미지가 좋은 경우'보다 나쁘다는 것을 증명한다. Co-Mod GAN을 Matterport3D에서 훈련하면 되지만, 파노라마 이음새의 세로선(0°와 180°를 독립적으로 복구하여 발생)에 주의해야 한다——저자들은 최종 데이터에는 나타나지 않는다고 하지만 재현 시 크롭 로직을 확인해야 한다.

  3. 미세 조정 데이터 조합이 가장 큰 함정: 사전 훈련은 R2R+PREV+HM-E 세 가지를 상호 보완적으로 사용하지만, 미세 조정에서는 반드시 PREV를 제거해야 한다(그렇지 않으면 MP3D에 과적합되어 Val-Unseen SR이 79.10에서 75.78로 하락). Gibson 데이터는 사전 훈련에만 사용하고 미세 조정에 추가하면 오히려 해롭다. 이 '사전 훈련과 미세 조정 데이터 비대칭' 결론이 가장 쉽게 함정에 빠지는 부분이다——PREVALENT 시대의 '사전 훈련+미세 조정 모두 동일한 증강 사용'을 그대로 따르면 성능이 크게 하락한다.

또한 시각 인코더로 CLIP ViT-H/14를 선택하면 SPL이 안정적으로 향상되지만(+1.4) 훈련 비용이 두 배가 된다; 계산 자원이 제한적이라면 ViT-B/16의 SR 차이가 크지 않으므로(78.08 vs 78.20) B/16으로 소거 실험을 우선 수행하는 것이 좋다.
