LIMMT: Less is More for Motion Tracking

LIMMT: Less is More for Motion Tracking

요약

We argue that high-quality motion data can steer tracking policies toward better optimization trajectories early in training. In this work, we introduce LIMMT (Less Is More for Motion Tracking). Institutions per source list: 清华大学、银河通用、上海交大、北京大学、上海期智研究院.

개요

LIMMT는 GQS(General Quality Selection) 3단계 데이터 큐레이션 파이프라인을 제안하여, 대규모 인체 모션 데이터에서 고품질 하위 집합을 선별해 휴머노이드 로봇 전신 모션 추적 정책 훈련에 사용한다. 저자들은 AMASS에서 단 10% 데이터만으로 전체 데이터 기준선(SR 0.959 vs 0.942)을 능가하고, 실제 Unitree G1 로봇에서 +7.5% 성공률 향상을 달성했음을 증명한다. 핵심 기여는 "데이터 품질이 수량을 지배한다"는 훈련 패러다임을 확립하고, 물리적 실현 가능성 필터링, 주기적 오토인코더 임베딩, 복잡도 가중 전역 샘플링을 통해 이를 구현한 것이다.

무엇을 바꾸었는가

모션 모방 강화 학습 분야는 오랫동안 "데이터가 많을수록 좋다"는 기본 가정을 유지해 왔지만, 저자들은 이 가정이 물리 시뮬레이션 환경에서 무너지고 있음을 지적한다. 대규모 야생 모션 데이터(예: 비디오 재구성)는 시간적 지터, 발 미끄러짐, 지면 관통과 같은 체계적 아티팩트를 내포하며, 이러한 노이즈는 모방 신호에 편향된 그래디언트를 주입하여 정책을 취약하게 만들거나 보상 해킹을 유발한다. 더욱 중요하게는, 훈련 비용이 데이터 규모에 따라 비선형적으로 증가한다는 점이다. 더 큰 rollout 풀은 참조 샘플링, 커리큘럼 설계, 장기 최적화의 오버헤드를 증폭시키지만, 그에 따른 이득은 점점 줄어든다.

이 연구의 진정한 변화는 데이터 큐레이션을 "정제"에서 "능동적 설계"로 승격시킨 것이다. 기존 방식은 손상된 조각을 제거하거나 단순 무작위 샘플링을 수행했지만, GQS는 품질을 3차원 구조로 정의한다: 물리적 실현 가능성(시뮬레이션 가능성), 동작 다양성(모션 매니폴드 커버리지), 동작 복잡성(정보 밀도). 이는 연구자들이 정책 학습에서 데이터의 역할을 재고하도록 강제한다—수동적으로 원본 분포를 대표하는 것이 아니라, 능동적으로 분포를 평탄화하고 정보 밀도를 우선시하는 것이다. 저자들은 "Less is More"로 데이터 규모 숭배에 도전하며, 자원이 제한된 로봇 연구실에 실행 가능한 대안 경로를 제공한다.

방법 분해

1단계: 물리적 실현 가능성 필터링

  • 하드 제약: 궤적 길이 <0.5초 또는 관절 속도 위반 >0.05 rad/s는 즉시 폐기
  • 소프트 점수: S_phy(T) = 100 - Σ w_i * L_i, 6가지 패널티(부유, 관통, 속도, 발 미끄러짐, 자가 충돌, 저크)
  • 임계값 보정: w_i = 10 / Boundary_i, S_phy < 90인 조각이 최소 하나의 심각한 위반을 포함하도록 보장
  • 발 미끄러짐 임계값 5cm: Unitree G1 URDF의 발목-지면 간격 범위 3.50-5.26cm에서 도출

2단계: 주기적 오토인코더(PAE) 임베딩

  • 입력 창 T=4.0s, 주파수 영역 파라미터로 매핑: 진폭 A, 주파수 F, 위상 φ, 오프셋 b(각각 k=8차원)
  • 재구성 공식: z_i(t) = A_i * sin(2π(F_i * t + φ_i)) + b_i
  • 결정적 매핑: 재구성 손실만으로 최적화, VAE 정규화가 물리적 스케일을 왜곡하는 것을 방지
  • 전역 임베딩: z_global = (1/N) Σ [A_w, F_w](시간 평균 로컬 디스크립터)

3단계: 복잡도 가중 전역 FPS

  • 복잡도 지표: C(x) = (1/T) Σ (||q_dot_t||² + λ||q_ddot_t||²), 순위 정규화 [0,1]
  • 혼합 점수: Score(u) = α * D_hat(u,S) + (1-α) * C_hat(u), α=0.99
  • 전역 vs 클러스터링: 임베딩 매니폴드에서 직접 WFPS, 클러스터 경계 없음(전역 SR 95.9% vs 클러스터 95.3%)

ARS 휴리스틱(새 데이터셋 비율 선택)

  • EDR = d_eff / D(95% PCA 분산 설명 차원 / 임베딩 총 차원)
  • 최적 비율 예측: r* = 0.5 * EDR²
  • AMASS 예측 11.0%(경험적 최적 10%); PHUMA 예측 32.8%(경험적 최적 30%)

핵심 혁신

  1. 3단계 순서의 인과적 설계: 필터링은 임베딩 학습 이전에 반드시 수행되어야 하며(그렇지 않으면 아티팩트가 매니폴드를 오염), 복잡도 가중은 마지막에 수행되어야 한다(앞선 두 단계의 출력에 의존). 이는 단순 파이프라인이 아니라, 각 단계가 다음 단계의 필요 조건을 창출하는 구조다.

  2. PAE의 결정적 주파수 영역 임베딩: VAE나 대조 학습과 달리, 사인 사전 지식이 모션을 해석 가능한 물리 파라미터(진폭/주파수/위상)로 분해하도록 강제하여 잠재 공간이 물리적 스케일을 왜곡하는 것을 방지한다. k=8의 차원 선택은 표현력과 일반화 사이의 균형을 이룬다(k=4는 과소적합, k=32는 과적합).

  3. 복잡도 가중 FPS의 "앵커" 전략: 가장 높은 복잡도의 모션을 시작점으로 샘플링하여 하위 집합이 "가장 어려운" 모션 패턴을 포함하도록 보장한다. 이는 균일 샘플링이나 무작위 샘플링과 다르다—훈련 분포의 "어려운 샘플" 영역을 능동적으로 구성하여 정책이 더 견고한 역학 모델을 학습하도록 강제한다.

구성 요소 소거(3% 데이터 비율)

  • 물리 필터링 없음: SR 0.911(-4.5%)
  • 희소화 없음: SR 0.934(-2.2%)
  • 복잡도 없음: SR 0.946(-1.0%)
  • 전체 GQS: SR 0.956

실제 배포(Unitree G1, 제로샷)

  • 평균 SR: Full 0.775(표 내 값 0.942−0.159로 계산) → GQS 10% 0.850(표 내 값 0.942−0.114로 계산)(+7.5%)
  • 평균 MPJPE: 0.1528 → 0.1287(-15.8%)
  • 점프 클래스: Full 8/10 → GQS 9/10

교차 코퍼스(LaFAN1→AMASS 제로샷)

  • GQS 없음: SR 0.8571, MPJPE 0.1283
  • +GQS: SR 0.8643, MPJPE 0.1254

하이퍼파라미터 민감도

  • S_phy=90 최적(SR 0.8250 vs 80일 때 0.8107)
  • 발 미끄러짐 임계값 5cm 최적(SR 0.8250 vs 0cm일 때 0.8131)
  • PAE 창 4초 최적(SR 0.8881 vs 1초일 때 0.8340)
  • k=8 최적(SR 0.8881 vs k=4일 때 0.8607)

경계 및 한계

  • 품질 평가가 규칙 기반: 저자들은 현재가 휴리스틱 패널티 항임을 명시적으로 인정하며, 향후 인간 선호도를 수집해 보상 모델을 훈련해야 한다(RLHF와 유사)
  • 저품질 모션 미복원: GQS는 선별만 수행하며, 저품질 데이터의 "암묵적 지식"을 복원하거나 증류하려 시도하지 않음
  • ARS는 두 코퍼스에서만 검증: 저자들은 "더 광범위한 실증 연구가 필요하다"고 밝히며, 교차 도메인 일반화 결론은 신중해야 함
  • LaFAN1 개선 폭 제한적: 절대 성능은 작은 훈련 풀(1,532 조각)과 게임-모션 캡처 도메인 격차에 의해 제한되며, GQS는 "적절하지만 일관된 개선"만 제공
  • 조작 작업 미포함: Vision-Language-Action 모델이나 로봇 팔 조작 시나리오에는 적용되지 않음

공학적 시사점

  • 물리 필터링 임계값 먼저 검증: S_phy=90과 발 미끄러짐 5cm는 Unitree G1 URDF로 보정된 값이므로, 로봇 플랫폼을 바꾸면 반드시 재도출해야 함(발목-지면 간격 범위가 다름)
  • PAE 창과 k 값이 가장 민감: 4초 창과 k=8은 성능 변곡점이며, 둘 중 하나를 바꾸면 PAE와 하위 추적기를 처음부터 재훈련해야 함(민감도 분석은 1×10⁹ 스텝 축소 예산에서 수행)
  • α=0.99는 "거의 순수 다양성": 복잡도 가중은 1%에 불과하지만, 소거 실험에서 제거 시 SR이 1.0% 하락—이 미세한 가중치가 "밸러스트" 역할
  • 재현 비용: PPO 2×10⁹ 환경 스텝, 8× RTX 4090, 10개 시드—전체 재현은 수 주 GPU 시간이 필요하므로, 먼저 3% 데이터 비율로 파이프라인 정확성을 검증할 것
  • 가장 흔한 함정: 도메인 무작위화 파라미터(마찰 𝒰(0.3,2.0), 외력 간격 𝒰(5,10))와 GQS 선택 간 상호작용—도메인 무작위화가 너무 강하면 데이터 품질 차이를 가려 GQS 이점이 불분명해질 수 있음
  • ARS를 빠른 사전 판단으로 활용: 새 데이터셋은 먼저 1단계+2단계를 실행하고 EDR을 계산해 r*를 예측하여, 맹목적인 전체 훈련을 피할 것
