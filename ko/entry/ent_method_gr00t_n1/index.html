요약

NVIDIA의 범용 휴로봇 기반 모델로, 자연어 조건 하에서 조작 및 이동 기술을 가능하게 함.

출처

  • Wiki extraction

개요

GR00T N1은 NVIDIA가 발표한 "범용 휴머노이드 로봇을 위한 오픈 기반 모델"입니다: 이중 시스템 아키텍처——Eagle-2 VLM이 시각-언어 추론(느린 시스템)을 담당하고, 흐름 매칭 DiT 액션 헤드가 실시간 모션 생성(빠른 시스템)을 담당합니다. 데이터 측면에서는 실제 로봇 궤적, 인간 비디오, 시뮬레이션 합성 데이터(Cosmos 월드 모델 및 Isaac 시뮬레이션 결합)를 이기종으로 혼합하여 휴머노이드 실물 데이터 부족 문제를 완화합니다. 방법론으로서 휴머노이드 VLA의 첫 번째 오픈 레퍼런스 구현을 제공합니다(출처: 프로젝트 Wiki 19장 §19.3.4; arXiv:2503.14734).

핵심 내용

무엇인가: 정확한 정의

GR00T N1의 방법 구성(출처: 프로젝트 Wiki 19장 §19.3.4):

  1. 이중 시스템: 비전-언어 모델(Eagle-2 VLM)이 의미 이해와 작업 추론을 담당하고, 흐름 매칭 DiT 액션 전문가가 연속 액션 블록을 생성합니다——"느린 사고 + 빠른 실행"의 이중 시스템 패러다임에 해당(Wiki §19.2.4);
  2. 흐름 매칭 액션 헤드: 노이즈에서 액션 분포로의 결정적 속도장을 학습하고, 수치 적분을 통해 액션 블록을 얻습니다;
  3. 이기종 데이터 레시피: 실제 궤적 + 인간 비디오(액션 주석/잠재 액션 학습) + 시뮬레이션 합성 데이터(Cosmos 월드 모델 + Isaac);
  4. 오픈 가중치: 휴머노이드 로봇 제조사와 연구 커뮤니티에 공개.

원리 분석

① 이중 시스템 아키텍처(느린 사고 + 빠른 실행)

느린 시스템(VLM)은 낮은 주파수로 시각과 언어를 처리하여 의미 수준의 의도 표현을 출력합니다; 빠른 시스템(액션 전문가)은 높은 주파수로 의도 표현을 연속 액션 블록으로 변환합니다. 이 분리는 "무거운 사고"를 담당하는 대형 모델이 제어 루프의 실시간성을 충족할 필요가 없게 하고, 액션 전문가는 언어를 이해할 필요가 없게 합니다——각각 적절한 주파수로 작동합니다(Wiki §19.2.4, §19.3.4).

② 흐름 매칭 액션 생성

선형 보간 경로 \(a^\tau = \tau a^1 + (1-\tau) a^0\)(\(a^0\)는 가우시안 노이즈, \(a^1\)는 실제 액션)를 취하고, 속도장 \(v_\theta\)의 조건부 흐름 매칭 손실을 학습합니다(Wiki §19.2.3):

\[ \mathcal{L}_{\mathrm{FM}}(\theta) = \mathbb{E}_{\tau, a^0, a^1} \big\| v_\theta(a^\tau, \tau \mid o_t, \ell) - (a^1 - a^0) \big\|^2 \]

추론 시 \(a^0 \sim \mathcal{N}(0, I)\)에서 출발하여 ODE \(\dot{a}^\tau = v_\theta(a^\tau, \tau)\)를 수치 적분합니다. 이산 토큰과 비교: 본래 연속적이고, 자연스럽게 다중 모드이며, 고정 스텝 반복으로 휴머노이드의 고차원 고주파 액션에 적합합니다(Wiki §19.2.3).

③ 데이터 레시피: 월드 모델이 데이터 루프에 진입

휴머노이드 데이터의 삼각 레시피(Wiki §19.3.4): 실제 로봇 궤적(원격 조작 수집)이 물리적 현실성을 제공; 인간 비디오가 액션 주석/잠재 액션 학습을 통해 규모와 다양성을 제공; 시뮬레이션 합성 데이터(Cosmos 월드 모델 생성 + Isaac 물리 시뮬레이션)가 롱테일 커버리지를 제공. 이는 "월드 모델의 네 가지 용도" 중 합성 데이터 엔진 역할과 맞물립니다(Wiki 20장).

누가 사용하는가 / 적용 사례

  • 레퍼런스 플랫폼: Unitree H2 Plus가 Isaac GR00T 레퍼런스 휴머노이드로 선정됨(Jetson Thor + Sharpa 다섯 손가락 로봇 핸드, 그래프 리포트 카드);
  • 데이터 플라이휠: Cosmos(월드 모델), Isaac Sim/Lab(시뮬레이션)과 함께 "데이터 생성 → 정책 학습 → 평가 환류" 루프를 구성(Wiki 20장 §20.2.2);
  • 하류 생태계: Open-H-Embodiment 등 프로젝트가 GR00T와 Cosmos를 기반으로 의료 로봇 기반 모델을 구축(Wiki §20.2.2);
  • 평가: HumanoidBench, LIBERO-Plus 등 벤치마크(그래프 이웃: ent_benchmark_humanoidbench, ent_benchmark_libero_plus).

한계와 경계

  • 이중 시스템의 인터페이스 병목: 느린 시스템의 의도에서 빠른 시스템의 액션으로의 표현 인터페이스가 성능 상한의 제약입니다(Wiki §19.2.4 패러다임 논의; 엔지니어링 판단);
  • 합성 데이터 의존성: 월드 모델/시뮬레이션 데이터의 물리적 정확성 오류가 정책으로 전파됩니다(Wiki 20장 월드 모델 한계);
  • 휴머노이드 전신 제어는 여전히 계층적: VLA 출력은 일반적으로 전신 제어/하위 제어기를 통해 실행되며, 엔드투엔드 직접 토크 제어는 아직 현실적이지 않습니다(Wiki §19.5.1);
  • 온보드 연산: 휴머노이드 본체가 지능형 컴퓨팅에 예약한 지속 전력은 수십 와트 수준에 불과하며, VLM 추론은 비동기/양자화가 필요합니다(Wiki §19.3.5).

흔한 오해

  1. "GR00T N1은 모터를 직접 제어하는 엔드투엔드 대형 모델이다"——의미-모션 이중 시스템이며, 모션 측은 여전히 계층적 제어 스택을 통해 실행됩니다.
  2. "오픈 가중치 = 바로 사용 가능"——휴머노이드 본체 차이로 인해 후속 학습과 액션 공간 적응이 필요합니다(Wiki §19.5.1).
  3. "합성 데이터가 실물 데이터를 무한히 대체할 수 있다"——실제 궤적은 레시피에서 대체 불가능하며, 합성 데이터의 가치는 롱테일 커버리지와 증강입니다(Wiki §19.3.4).
  4. "흐름 매칭이 확산보다 느리다"——오히려 반대입니다. 흐름 매칭은 일반적으로 더 적은 스텝으로 샘플링을 완료합니다(Wiki §19.2.3).
