요약

전문가 시연을 모방하도록 정책을 지도학습하는 모방 학습 방법으로, 로봇 기술 학습의 기준선으로 자주 사용됨.

출처

  • Wiki extraction

개요

행동 복제(Behavior Cloning, BC)는 가장 직접적인 모방 학습 방법이다: 전문가 시연 데이터를 지도 학습 샘플로 취급하여, 정책 네트워크가 관측으로부터 전문가 행동을 회귀(또는 분류)하도록 훈련한다. 구현이 간단하고, 훈련이 안정적이며, 환경 상호작용이 필요 없고, 시연 데이터가 충분히 포괄적이고 작업 시간이 짧을 때 사용 가능한 성능에 도달한다. 이는 휴머노이드 로봇의 모든 새로운 작업에 있어 사실상의 "첫 번째 베이스라인"이다(출처: 프로젝트 Wiki 18장 §18.2.1).

핵심 내용

무엇인가: 정확한 정의

시연 데이터셋 \(\mathcal{D} = \{(o_t, a_t)\}\)(관측-행동 쌍)이 주어졌을 때, 행동 복제는 지도 학습 문제를 푼다:

\[ \theta^* = \arg\min_\theta \; \mathbb{E}_{(o,a)\sim\mathcal{D}} \; \ell\big(\pi_\theta(o),\, a\big) \]

연속 행동에는 회귀 손실(L1/L2)을, 이산화된 행동에는 교차 엔트로피를 사용한다. 강화 학습과의 본질적 차이: 보상 함수가 없고, 환경 상호작용이 없으며, 탐험이 없다——정책의 모든 지식은 시연 데이터의 통계적 분포에서 비롯된다.

원리 분석

① 복합 오차와 공변량 이동——BC의 구조적 약점

지도 학습의 i.i.d. 가정은 순차적 의사결정에서 성립하지 않는다: 훈련 시 상태는 전문가 궤적 분포에서 오고, 실행 시 상태는 정책 자신의 궤적 분포에서 온다. 정책이 전문가 궤적에서 벗어나면 훈련 세트에 없는 상태에 들어가게 되고, 오차는 점진적으로 증폭된다——이것이 공변량 이동(covariate shift)으로 인한 복합 오차다(출처: 프로젝트 Wiki 18장 §18.1.2). 이것이 DAgger 계열 데이터 집합 방법이 존재하는 이유이기도 하다.

② 대규모 BC의 창발: BC-Z와 RT-1

시연 규모가 십만 개 수준으로 올라가면, 단순 BC는 질적 변화를 보여준다(출처: 프로젝트 Wiki 18장 §18.2.2):

  • BC-Z(Google, 2021): 12.9만 개 시연에서 언어/비디오 조건 정책을 훈련하여, 처음으로 제로샷 작업 일반화를 시연——훈련 중 보지 못한 언어 명령을 직접 실행 가능;
  • RT-1(Google, 2022): 약 13만 개, 700여 개 작업을 포괄하는 실제 시연 + Transformer + 행동 이산화 토큰 자기회귀, "데이터 규모 + 트랜스포머 + 멀티태스크" 경로의 확장성을 체계적으로 검증(arXiv:2212.06817).

③ 다중 모드 문제의 세 가지 고전적 해법

단순 회귀는 "동일한 관측, 여러 합리적 행동"(왼쪽/오른쪽 회피 모두 가능)에 직면했을 때 절충 행동을 출력하여 양쪽 모두에 충돌한다. 개선 변형(출처: 프로젝트 Wiki 18장 §18.2.4): 행동 이산화(비닝 + 분류 손실, 자연스럽게 다중 모드 지원, RT-1이 이 방식); 혼합 밀도 네트워크 MDN(가우시안 혼합 파라미터 출력); 분위수 회귀와 에너지 모델(후자는 사상적으로 확산 모델로 직결).

누가 사용하는가 / 적용 사례

  • 연구 베이스라인: BC는 LIBERO 등 벤치마크의 표준 대조군이다(그래프: ent_benchmark_libero);
  • 대규모 이정표: BC-Z, RT-1(Google), 이후 RT-2가 VLM 지식을 제어로 이전하여 VLA 패러다임을 열었다(Wiki §18.2.2);
  • 양산 현실: 연산 제약이 있는 엣지 배포에서 경량 BC는 여전히 고정 시나리오 집기-놓기 등 양산 기능의 실제 선택이다(Wiki §18.2.1);
  • 데이터 생태계 진입점: ALOHA/Mobile ALOHA(ent_technology_mobile_aloha_2024), UMI(ent_technology_umi_gripper_interface_2024) 등 수집 시스템이 생산한 데이터는 먼저 BC 계열 정책에 공급된다.

한계와 경계

  • 다중 모드 평균화: 회귀 손실이 다중 모드 시연에서 절충 행동을 출력한다(Wiki §18.2.3);
  • 장기 드리프트: 복합 오차로 분 단위 작업의 성공률이 급락한다;
  • 분포 외 복구 불가: 시연 커버리지 밖의 상태는 맹점과 같다;
  • 인과 혼동: 정책이 행동과 상관관계만 있고 인과관계는 없는 "지름길 특징"(조작자의 습관적 동작, 고정 배경)을 학습할 수 있으며, 환경이 바뀌면失效한다(Wiki §18.2.3)——이것은 데이터 엔지니어링 문제이지 알고리즘 문제가 아니다.

흔한 오해

  1. "BC는 그냥 일반 지도 학습이다"——순차적 의사결정이 i.i.d. 가정을 깨뜨리며, 공변량 이동은 BC 고유의 실패 모드다.
  2. "시연이 많을수록 좋다"——커버리지 다양성이 수량보다 중요하다; 동질적 반복 시연은 분포 외 일반화에 거의 기여하지 않는다.
  3. "검증 세트 오차가 낮음 = 실기 사용 가능"——오프라인 오차와 폐루프 성공률 사이에는 복합 오차가 있다; 반드시 폐루프 rollout 평가를 해야 한다.
  4. "BC는 이미 확산 정책에 의해淘汰되었다"——단일 모드, 짧은 시간, 강한 실시간 시나리오(예: 생산 라인 고정 동작)에서 BC는 여전히 최우선이다; 그것은 진단 베이스라인이지 역사적 유물이 아니다.
