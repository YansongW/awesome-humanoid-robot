요약

RoboCasa: Large-Scale Simulation of Everyday Tasks for Generalist Robots is a 2024 work on simulation benchmark for humanoid robots, with open-source code available.

출처

  • RoboCasa: Large-Scale Simulation of Everyday Tasks for Generalist Robots (arXiv)
  • RoboCasa: Large-Scale Simulation of Everyday Tasks for Generalist Robots project page

개요

RoboCasa는 사실적인 물리 시뮬레이션을 활용하여 로봇 분야의 데이터 규모 부족 병목 현상을 극복하며, 주방 환경에서의 범용 로봇 훈련에 초점을 맞춥니다. 이 프레임워크는 150개 이상의 객체 카테고리에서 수천 개의 3D 자산과 수십 종의 상호작용 가능한 가구 및 가전제품을 제공하며, text-to-3D 모델 및 text-to-image 모델과 같은 생성형 AI 도구를 통해 환경의 사실성과 다양성을 강화합니다. 체계적인 평가를 위해 RoboCasa는 대규모 언어 모델의 지침으로 생성된 복합 작업을 포함한 100개의 작업을 설계했습니다. 또한, 이 프레임워크는 고품질의 인간 시연을 제공하고 자동화된 궤적 생성 방법을 통합하여 인적 부담을 최소화하면서 데이터 세트를 대폭 확장합니다.

핵심 내용

방법

RoboCasa의 핵심 방법은 사실적인 물리 시뮬레이션을 통해 로봇 학습에 필요한 환경, 작업, 데이터 세트를 규모 있게 확장하는 것입니다. 이는 text-to-3D 모델로 객체 자산을 생성하고 text-to-image 모델로 환경 텍스처를 생성하는 등 생성형 AI 도구를 활용하여 시뮬레이션 환경의 사실성과 다양성을 향상시킵니다.

아키텍처

프레임워크는 주방 장면에 초점을 맞추며, 150개 이상의 객체 카테고리에서 수천 개의 3D 자산과 수십 종의 상호작용 가능한 가구 및 가전제품을 포함합니다. 이러한 자산과 장면은 범용 로봇 훈련을 지원하기 위해 고도로 사실적이고 다양하게 설계되었습니다.

실험 설정

체계적인 평가를 위해 RoboCasa는 대규모 언어 모델의 지침으로 생성된 복합 작업을 포함한 100개의 작업을 설계했습니다. 실험에서는 고품질의 인간 시연을 사용했으며, 자동화된 궤적 생성 방법을 통합하여 인적 부담을 최소화하면서 데이터 세트를 대폭 확장했습니다.

주요 수치

  • 150개 이상의 객체 카테고리
  • 수천 개의 3D 자산
  • 수십 종의 상호작용 가능한 가구 및 가전제품
  • 100개의 체계적 평가 작업

결론

실험 결과, RoboCasa로 생성된 합성 로봇 데이터는 대규모 모방 학습에서 뚜렷한 확장 추세를 보여주며, 실제 세계 작업에서 시뮬레이션 데이터를 활용할 수 있는 큰 잠재력을 입증했습니다. 비디오 및 오픈 소스 코드는 https://robocasa.ai/ 에서 확인할 수 있습니다.
