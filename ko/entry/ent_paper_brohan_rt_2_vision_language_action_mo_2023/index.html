RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control

RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control

요약

RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control (RT-2), is a 2023 large vision-language-action model for robotic manipulation, introduced by Google DeepMind, and published at CoRL 2023.

출처

  • RT-2 source
  • RT-2 Vision-Language-Action Model

개요

RT-2는 Google이 제안한 비전-언어-행동(VLA) 모델로, 로봇의 행동을 이산화된 텍스트 토큰으로 변환하고, 네트워크 규모의 데이터로 사전 학습된 VLM(PaLI-X, PaLM-E)을 공동 미세 조정하여 엔드투엔드 로봇 제어를 구현합니다. 핵심 기여는 인터넷 규모의 비전-언어 사전 학습이 저수준 제어 정책으로 직접 전이될 수 있음을 증명하고, 상당한 일반화 향상과 창발적 의미 추론 능력을 가져왔다는 점입니다.

무엇을 바꾸었는가

RT-2 이전에는 LLM/VLM의 로봇 분야 적용이 '고수준 계획' 역할로 엄격히 제한되었습니다. 즉, 명령을 해석하고 하위 목표를 출력하는 역할이었으며, 저수준 행동 실행은 여전히 독립적으로 학습된 소형 모델(예: RT-1)이 수행했습니다. 이러한 분리는 저수준 컨트롤러가 인터넷 규모의 의미론적 지식의 혜택을 결코 받을 수 없음을 의미하며, 그 일반화 능력은 로봇 시연 데이터의 규모와 다양성에 제한되었습니다. RT-2가 진정으로 바꾼 것은 이 경계를 허문 것입니다. 동일한 모델이 "사과를 컵과 같은 색의 용기에 넣어라"와 같은 추상적 의미를 이해하면서도 엔드 이펙터의 7차원 행동 벡터를 직접 출력할 수 있게 했습니다. 이는 아키텍처의 단순화일 뿐만 아니라 '로봇 데이터 희소성'이라는 근본적 병목에 대한 대응입니다. 수백만 개의 로봇 궤적을 무리하게 수집하는 대신, VLM이 수십억 개의 이미지-텍스트 쌍에서 학습한 세계 지식을 재사용하는 것입니다.

방법 분석

행동 인코딩 및 토큰화

  • RT-1 기반 이산화 방식: 6자유도 엔드 이펙터 포즈(위치+회전) + 그리퍼 개폐 + 종료 명령, 연속 차원을 256개 bin으로 균일 양자화하여 행동을 8개의 정수로 표현.
  • 행동 토큰 매핑: PaLI-X는 0-255 정수 토큰을 직접 재사용; PaLM-E는 어휘집에서 가장 적게 사용되는 256개 토큰을 행동 어휘로 선택하여 자연어 토큰과의 충돌을 방지.

입력 및 출력 형식

  • 입력은 표준 VQA 형식: "Q: what action should the robot take to [명령]? A:", 출력은 행동 토큰 문자열.
  • 추론 시 행동 작업에는 출력 제약을 적용하여 유효한 행동 토큰만 샘플링; 표준 VQA 작업은 제약 없음.

공동 미세 조정(Co-Fine-Tuning)

  • 핵심 설계: 로봇 데이터를 원본 네트워크 데이터(WebLI, VQA, 이미지-텍스트 인터리브 등)와 혼합하여 학습하며, 로봇 데이터만으로 미세 조정하지 않음. 로봇 데이터 샘플링 가중치를 높여 배치 비율을 균형 있게 조정(PaLI-X 약 50%, PaLM-E 약 66%).
  • 동기: 미세 조정만 수행하면 모델이 네트워크 사전 학습 지식을 망각하게 되며, 공동 미세 조정은 정책이 추상적 시각 개념에 지속적으로 노출되어 더 강력한 일반화를 얻을 수 있게 함.

실시간 추론

  • 다중 TPU 클라우드 서비스에 배포되어 네트워크 쿼리를 통한 폐루프 제어를 구현하며, 여러 로봇을 동시에 서비스할 수 있음. 55B 모델 추론 주파수는 1-3 Hz, 5B 모델은 약 5 Hz.

사고 사슬 변형

  • 데이터에 "Plan" 단계를 추가하여 먼저 자연어로 행동 의도를 설명한 후 행동 토큰을 출력. 수백 단계만 미세 조정하여 정성적으로 효과를 관찰.

핵심 혁신

  1. 행동을 텍스트로 표현하는 통합 표현: 연속 행동 공간을 텍스트 토큰으로 이산화하여 로봇 제어와 VLM의 next-token 예측 목표를 완전히 정렬. 이 설계는 단순해 보이지만 모델이 아키텍처 변경 없이 사전 학습 가중치를 재사용할 수 있게 하며, VLA 패러다임의 기초 작업입니다.
  2. 공동 미세 조정 전략: '사전 학습 후 미세 조정'의 2단계가 아니라 로봇 데이터와 네트워크 데이터를 지속적으로 혼합 학습. 소거 실험에서 공동 미세 조정이 미세 조정만 수행한 것보다 현저히 우수함(55B 모델 미경험 평균 성공률 63% vs 52%)을 증명하여 사전 학습 지식을 '생생하게' 유지하는 중요성을 밝힘.
  3. 창발적 의미 추론: 미경험 명령(예: "move apple to 3", "move the coke can to the person with glasses")에서 RT-2는 추가 시연 없이 평균 성공률 60%에 도달하며, 이는 RT-1(17%)의 3배 이상입니다. 이는 인터넷 사전 학습이 제공하는 기호 이해, 다국어, 기초 추론 능력이 제로샷으로 행동 생성에 전이될 수 있음을 증명합니다.

경계 및 한계

  • 물리적 기술 추가 없음: RT-2는 로봇 데이터에 없는 새로운 행동 능력을 얻지 못하며, 기존 기술을 새로운 방식으로 조합할 수만 있습니다. 저자는 이것이 데이터셋의 기술 축 다양성 부족 때문임을 명시적으로 인정.
  • 특정 조작 실패: 특정 부위(예: 손잡이) 잡기, 새로운 동작(수건 닦기, 도구 사용), 정교한 조작(수건 접기), 다층 간접 추론 등의 시나리오에서 성능 저하.
  • 계산 비용: 55B 모델 추론은 1-3 Hz에 불과하여 고주파 제어 요구를 충족하기 어려움; 저자는 향후 양자화 및 증류 탐구를 제안.
  • 사고 사슬 미정량화: 정성적 관찰만 수행, 정량적 평가 없음.
  • 55B 처음부터 학습 미평가: 5B 처음부터 학습 성능 저하(9%)로 인해 건너뛰었으며, 더 큰 규모가 결론을 바꿀 수 있는지 확인 불가.

공학적 시사점

  • 재현 우선순위: 먼저 행동 토큰 매핑 방식을 확인 — PaLI-X는 정수 토큰을 직접 재사용, PaLM-E는 가장 적게 사용되는 토큰을 선택해야 하며, 구현 세부 사항이 다르므로 잘못 선택하면 학습이 수렴하지 않을 수 있음.
  • 공동 미세 조정이 핵심: 네트워크 데이터 혼합을 건너뛰지 말 것. 소거 실험에서 미세 조정만 수행하면 55B 모델의 미경험 일반화가 63%에서 52%로 떨어지며, 5B 모델은 차이가 더 큼. 로봇 데이터 샘플링 가중치(50%-66%)가 핵심 하이퍼파라미터.
  • 규모 민감성: 5B와 55B는 미경험 일반화에서 현저한 차이(44% vs 63%)를 보이므로, 자원이 제한된 경우 학습 단계 수보다 모델 규모를 우선시.
  • 추론 주파수는 하드 제약: 55B 모델의 1-3 Hz는 저속 조작 작업에만 적합; 고주파 제어가 필요하면 5B 버전 또는 증류 방안 고려.
  • 평가 프로토콜: 미경험 환경 Easy와 Hard의 차이가 매우 큼(63% vs 35%), 결과 보고 시 난이도 수준을 반드시 구분해야 하며, 그렇지 않으면 모델 능력을 과대평가할 수 있음.
