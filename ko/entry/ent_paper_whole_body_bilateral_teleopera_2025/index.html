요약

Whole-Body Bilateral Teleoperation with Multi-Stage Object Parameter Estimation for Wheeled Humanoid Locomanipulation is a 2025 work on teleoperation for humanoid robots.

출처

  • Whole-Body Bilateral Teleoperation with Multi-Stage Object Parameter Estimation for Wheeled Humanoid Locomanipulation (arXiv)

개요

이 연구는 바퀴형 휴머노이드 로봇의 전신 원격 조작 문제를 해결하기 위해, 객체 인식 양방향 제어 프레임워크를 설계했습니다. 핵심 기술은 다단계 관성 매개변수 추정에 있습니다: 먼저 시각을 통해 객체 크기를 추정하고, 이후 대형 비전-언어 모델(VLM)을 활용해 초기 매개변수 추측을 생성하며, 마지막으로 분리된 계층적 샘플링 전략을 통해 질량, 질량 중심, 관성 텐서를 순차적으로 추정합니다. 이러한 설계는 샘플링 탐색 공간을 크게 줄이고, VLM 사전 오차에 대한 강건성을 강화합니다. 추정된 매개변수는 로봇의 균형점을 실시간으로 업데이트하는 데 사용되어, 조작자가 이동과 조작에 더 집중할 수 있게 하며, 동적 동기화 중 힘-촉각 피드백을 개선합니다. 실험 결과, 이 시스템은 실제 하드웨어에서 로봇 자체 중량의 약 1/3에 해당하는 부하로 들어 올리기, 전달, 놓기 등의 작업을 수행할 수 있음을 보여줍니다.

핵심 내용

방법 아키텍처

  • 전체 프레임워크: 전신 양방향 원격 조작과 온라인 다단계 객체 관성 매개변수 추정 모듈을 결합하여, 객체 인식 원격 조작 제어를 구현합니다.
  • 다단계 추정 프로세스:
  • 1단계: 시각 기반 객체 크기 추정기로 초기 기하 정보를 제공합니다.
  • 2단계: 대형 비전-언어 모델(VLM)을 활용해 객체 관성 매개변수의 초기 추측을 생성하여 사전 지식으로 사용합니다.
  • 3단계: 분리된 계층적 샘플링 전략으로, 먼저 질량과 질량 중심을 추정한 후 객체 크기에 따라 관성 텐서를 추론하여 물리적 타당성을 보장합니다. 다중 가설 방식을 채택하여 VLM 사전 오차에 대한 강건성을 강화합니다.
  • 실시간 업데이트: 추정기는 고충실도 시뮬레이션 및 실제 하드웨어와 병렬로 실행되어 온라인 매개변수 업데이트를 구현합니다. 추정된 매개변수는 바퀴형 휴머노이드 로봇의 균형점을 조정하는 데 사용되어, 조작자가 이동과 조작에 더 집중할 수 있게 합니다.

실험 설정

  • 하드웨어 플랫폼: 기계식 그리퍼와 인간-기계 인터페이스를 갖춘 맞춤형 바퀴형 휴머노이드 로봇.
  • 작업: 로봇 자체 중량의 약 1/3에 해당하는 부하로 들어 올리기, 전달, 놓기 작업을 실시간으로 수행합니다.
  • 핵심 지표: 객체 동역학을 보상하여 조작 추적 정밀도를 개선하면서도 유연한 동작을 유지합니다. 힘-촉각 피드백은 동적 동기화 중에 강화됩니다.

결론

이 프레임워크는 다단계 매개변수 추정을 통해 미지의 객체에 대한 실시간 동역학 보상을 구현하여, 중량 부하 시나리오에서 바퀴형 휴머노이드 로봇의 전신 원격 조작 성능을 크게 향상시킵니다. 실험은 실제 작업에서의 유효성과 실시간성을 검증했습니다.
