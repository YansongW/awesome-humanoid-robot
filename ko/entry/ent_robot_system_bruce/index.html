요약

A 70 cm, 4.8 kg child-size bipedal humanoid platform co-developed by Westwood Robotics and UCLA RoMeLa, with 16 degrees of freedom, proprioceptive quasi-direct-drive Koala BEAR actuators with liquid cooling on key joints, and a variable-frequency MPC stack for highly dynamic walking, running and jumping.

출처

  • Westwood-Robotics GitHub Organization
  • BRUCE at World Robot Conference
  • BRUCE on aparobot.com

개요

BRUCE(Bipedal Robot Unit with Compliance Enhanced)는 Westwood Robotics(웨스트우드 로보틱스, 2018년 UCLA RoMeLa 전 핵심 멤버들이 설립)와 UCLA RoMeLa가 공동 개발한 아동 사이즈 이족 보행 휴머노이드 플랫폼으로, 설계 논문은 Liu et al., ICRA 2022입니다. 전체 높이 70cm, 무게 4.8kg, 16자유도(다리 각 5, 팔 각 3)로, "달리고 점프할 수 있는" 소수파 소형 고동역학 이족 플랫폼입니다(출처: 조사 아카이브 bruce-westwood.md, 이하 동일). 이것이 실제로 바꾼 것은 "소형 로봇이 걸을 수 있다"가 아니라 "아동 사이즈도 고동역학 운동에 필요한 폭발력과 연산력을 담을 수 있다"는 점입니다.

핵심 내용

무엇인가: 정확한 정의

BRUCE는 준직구동 액추에이터를 핵심으로 하여 고동역학 운동 연구를 겨냥한 소형 이족 보행 휴머노이드 플랫폼입니다. 설계 목표는 산업 현장의 반복 작업이 아니라, 보행 로봇 연구에 "살 수 있고, 달릴 수 있고, 개조할 수 있는" 하드웨어 기반을 제공하는 것입니다. 전체 시스템은 Westwood Robotics가 상업적 구매 채널로 판매하며, 공식 포지셔닝은 "개방형 플랫폼(open platform)"으로, 오픈소스 소프트웨어와 모델을 표방하지만 전체 제어 프레임워크의 공개 저장소는 GitHub 검색에서 찾을 수 없었습니다(2026-07-01 기준, 라이선스 조건을 직접 검증하지 못함); 컴포넌트 수준 저장소(PyBEAR, BRUCE_SENSE, Wireless_ESTOP 등)는 Westwood-Robotics 조직 아래 오픈소스로 제공됩니다.

원리 분해

① 본체 감각 준직구동: 힘 제어의 물리적 기반

BRUCE는 자체 개발한 Koala BEAR 본체 감각(proprioceptive) 준직구동 액추에이터를 탑재합니다. 준직구동(QDD) 아키텍처의 핵심은 낮은 감속비 전동(보통 3:1–10:1)과 높은 토크 밀도 모터의 결합으로, 외부 힘이 모터 측으로 직접 "투과"될 수 있게 하는 것입니다. 따라서 모터 전류만 측정하면 출력 토크를 추정할 수 있으며, 관절 토크 센서 없이도 고대역폭 힘 제어가 가능합니다. 단일 Koala BEAR는 250g에 불과하며, 최대 토크는 10.5 N·m(다리 관절 기준)입니다. 출력 토크 추정 관계는 다음과 같습니다:

\[ \tau_{\text{out}} \approx G \, k_t \, I_m - J_{\text{eq}} \ddot{\theta}_m \]

여기서 \(G\)는 감속비, \(k_t\)는 모터 토크 상수, \(I_m\)은 모터 전류, \(J_{\text{eq}}\)는 등가 관성, \(\ddot{\theta}_m\)은 모터 각가속도입니다. 두 번째 항은 관성 보상 항입니다. 감속비가 작아 마찰과 백래시 비선형성도 작으므로, 이 추정은 공학적으로 충분히 정확합니다—이것이 "토크 센서 없이도 힘 제어가 가능한" 모든 비밀입니다.

② 액체 냉각: 폭발력의 열 관리

핵심 관절(무릎 등)은 액체 냉각을 채택하여 폭발 토크와 지속적인 고동역학 출력을 지원합니다. 고동역학 운동(점프, 급정지)은 짧은 시간에 많은 줄 열을 발생시키며, 제때 배출하지 못하면 모터 권선 온도 상승으로 토크 상수가 저하되거나 심지어 감자(감자석)될 수 있습니다. 액체 냉각은 관절 코어에서 열을 빼내어 액추에이터가 더 오랜 시간 동안 최대 출력을 유지할 수 있게 합니다—이것은 BRUCE가 "한 번 점프하는" 것이 아니라 "달릴 수 있는" 핵심 열 관리 수단입니다.

③ 가변 주기 MPC: 운동 제어의 두뇌

소프트웨어 측면에서 BRUCE는 가변 주기(variable-frequency) MPC 운동 제어 알고리즘을 채택하여 보행/주행/점프 같은 고동역학 행동을 지원합니다. MPC(모델 예측 제어)의 핵심 아이디어는 각 제어 주기에서 현재 상태와 동역학 모델을 기반으로 유한 시간 영역의 최적 제어 문제를 온라인으로 풀고 첫 단계만 실행하는 것입니다. 가변 주기는 컨트롤러가 운동 상태에 따라 해석 주기를 동적으로 조정할 수 있음을 의미합니다—빠른 주행 시 주파수를 높여 안정성을 보장하고, 느린 보행 시 주파수를 낮춰 연산력을 절약합니다. 모델 라이브러리와 시뮬레이션 환경은 여러 제3자 논문에서 인용되어, 소프트웨어 스택이 일정한 학술적 영향력을 가지고 있음을 보여줍니다.

세 가지는 세 가지 방식을 대표합니다: BRUCE는 "상품화된 고동역학 플랫폼", ToddlerBot은 "극소 오픈소스 복제", Bolt는 "학술 오픈소스 기반"입니다. BRUCE의 차별점은 세 가지 중 유일하게 주행/점프 같은 고동역학 행동을 명시적으로 지원하는 플랫폼이며, 상업 채널로 전체 시스템과 기술 지원을 제공한다는 점입니다—대가는 가격 비공개와 제한된 오픈소스 수준입니다.

사용자·적용 사례

BRUCE의 주요 사용자는 대학 보행 로봇 연구실과 일부 기업 연구 부서입니다. 설계 논문(Liu et al., ICRA 2022)은 여러 제3자 논문에서 인용되었으며, 모델 라이브러리와 시뮬레이션 환경도 비교 연구에 사용됩니다. 공식 포지셔닝이 개방형 플랫폼이고 컴포넌트 수준 저장소(PyBEAR, BRUCE_SENSE, Wireless_ESTOP 등)가 Westwood-Robotics GitHub 조직 아래 오픈소스로 제공되므로, 연구자는 액추에이터와 센싱 방식을 기반으로 2차 개발이 가능합니다. 구체적인 배치 기관 목록은 직접 확인이 필요합니다.

한계와 경계

  1. 오픈소스 수준 제한: 전체 제어 프레임워크의 공개 저장소는 GitHub 검색에서 찾을 수 없었습니다(2026-07-01 기준, 라이선스 조건을 직접 검증하지 못함), ToddlerBot의 MIT License 전체 스택 오픈소스와 대조됩니다;
  2. 가격 비공개: 공식은 견적 문의 방식이며 공개 가격이 없고, 제3자 논문은 약 $6.5K 수준으로 제시—실제 구매 비용은 구성과 지원 서비스에 따라 다를 수 있습니다;
  3. 짧은 배터리 수명: 3000 mAh 배터리, 연속 동적 운행 약 20분, 장시간 실험은 여러 배터리 교체가 필요합니다;
  4. 낮은 초보자 친화도: 조사 아카이브 평가 2 / 5, 일정 수준의 로봇 제어 및 디버깅 경험이 필요합니다;
  5. 제한된 연산력: 메인 컨트롤러 연산력 6 TOPS, 주요 딥러닝 프레임워크를 지원하지만 대규모 RL 정책이나 비전 모델 실행 시 부족할 수 있습니다.

흔한 오해

  1. "BRUCE는 오픈소스 로봇이다"—부정확합니다. 공식 포지셔닝은 "개방형 플랫폼"이며, 컴포넌트 수준 저장소는 오픈소스지만 전체 제어 프레임워크의 공개 저장소는 찾을 수 없고 라이선스 조건도 검증되지 않았습니다. "반개방"에 가깝습니다: 하드웨어는 구매 가능, 일부 소프트웨어는 열람 가능, 핵심 프레임워크는 불투명합니다.
  2. "준직구동 = 직구동"—틀렸습니다. Koala BEAR에는 감속기가 있습니다(구체적인 감속비는 직접 확인 필요), 단지 감속비가 낮아 힘 투명성을 유지할 뿐입니다. 감속기를 제거하면 모터 토크로는 70cm 본체의 점프 동작을 지탱할 수 없습니다.
  3. "액체 냉각은 그냥 마케팅"—공학적 판단: 지속적인 고동역학 출력에서 열 관리는 실제 병목입니다. 액체 냉각은 최대 토크를 높이는 것이 아니라 최대 토크의 지속 시간을 연장합니다.
  4. "$6.5K면 살 수 있다"—이 수치는 제3자 논문 비교표(ToddlerBot, arXiv:2502.00893 Table I)에서 나온 것이며, 공식은 견적 문의 방식이라 실제 가격은 더 높을 수 있습니다.

관련 지식

  • ent_technology_quasi_direct_drive_actuator_2024 — BRUCE의 Koala BEAR 액추에이터는 준직구동 방식의 공학적 산물이며, 해당 엔티티는 QDD의 원리와 역사를 자세히 설명합니다.
  • ent_robot_system_toddlerbot — 동일한 아동 사이즈 오픈소스 플랫폼이지만 "극소 복제" 방식을 취하며, BRUCE의 "상품화 고동역학"과 뚜렷한 대조를 이룹니다.
  • ent_method_zero_moment_point — ZMP는 이족 균형의 고전적 판정 기준이며, BRUCE의 MPC 운동 제어는 고속 운동 시 ZMP의 정적 가정을 넘어서야 합니다.
  • ent_robot_system_odri_bolt — 학술 오픈소스 이족 플랫폼으로, 고동역학 하드웨어를 얻는 또 다른 경로(오픈소스 하드웨어 + 자체 개발 드라이버)를 대표합니다.
  • ent_component_imu_2024 — BRUCE는 6축 IMU(통신/샘플링 속도 2 kHz)를 탑재하며, 상태 추정과 MPC 피드백의 핵심 센서입니다.
  • ent_method_model_predictive_control — BRUCE의 가변 주기 MPC 운동 제어 알고리즘은 이 방법의 공학적 사례이며, 해당 엔티티는 MPC의 수학적 기초와 변형을 다룹니다.
