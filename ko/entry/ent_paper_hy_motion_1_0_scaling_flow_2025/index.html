HY-Motion 1.0: Scaling Flow Matching Models for Text-To-Motion Generation

요약

We present HY-Motion 1.0, a series of state-of-the-art, large-scale, motion generation models capable of generating 3D human motions from textual descriptions.

출처

  • arXiv:2512.23464 HY-Motion 1.0: Scaling Flow Matching Models for Text-To-Motion Generation
  • Project page
  • GitHub仓库 Robotics_Notebooks

개요

HY-Motion 1.0은 DiT 기반 플로우 매칭 모델을 10억 파라미터 규모로 확장한 최초의 텍스트-모션 생성 시스템으로, 텐센트 등 기관이 완성했습니다. 3000시간 이상의 다중 소스 모션 데이터 파이프라인(야외 비디오, 모션 캡처, 3D 에셋)을 구축하고, 계층적 이중 조건 텍스트 인코딩과 3단계 훈련(사전 훈련-미세 조정-RL)을 결합하여 명령 수행(SSAE 78.6%) 및 모션 품질(3.43/5)에서 기존 오픈소스 벤치마크를 크게 능가합니다.

무엇을 바꾸었는가

이 작업의 진정한 변화는 "데이터 규모"를 조연에서 주연으로 끌어올린 것입니다. 기존 이 분야의 주류 접근 방식(MoMask, GoToZero, LoM)은 HumanML3D와 같은 소규모 주석 데이터셋에 의존하거나, 이산 토크나이저를 사용하여 모션의 부드러움을 희생하면서 의미적 다양성을 확보했습니다. HY-Motion 1.0은 모션 데이터가 수천 시간 규모에 도달하고 체계적으로 정제·주석 처리되었을 때, 순수 연속 표현의 플로우 매칭 모델이 "의미 정렬 불량"과 "물리적 아티팩트 과다"라는 두 가지 장기적 문제를 동시에 해결할 수 있음을 증명했습니다. 새로운 수학적 프레임워크를 발명한 것이 아니라, LLM 분야에서 이미 검증된 "데이터+규모" 경로를 모션 생성에 성공적으로 이식한 것입니다.

더 중요하게는, 이는 업계의 "모션 생성 스케일링 곡선"에 대한 인식을 바꾸었습니다. 저자들은 절제 실험을 통해 비자명한 결론을 밝혔습니다: 명령 수행 능력은 모델 규모에 따라 단조 증가하지만(0.05B→1B 평균 점수 3.10→3.34), 모션 품질은 0.46B 이후 포화됩니다(3.26→3.34로 미미한 증가). 이는 과거 커뮤니티의 맹목적인 파라미터 증가 방식이 비효율적이었음을 의미합니다. 진정한 병목은 데이터 다양성과 의미적 커버리지에 있으며, 모델 용량이 아닙니다. 이 발견은 후속 작업에 자원 할당 방향을 직접적으로 제시합니다.

방법 분해

데이터 파이프라인 (핵심 장벽)

  • 다중 소스 수집: 1200만 개의 야외 비디오 클립(샷 경계 감지+사람 감지기 필터링) → GVHMR로 SMPL-X 궤적 재구성; 추가로 약 500시간의 모션 캡처/3D 애니메이션 에셋.
  • 통합 처리: 모두 중립 SMPL-H(손 제외 22개 관절)로 리타겟팅, 3단계 필터링(중복 제거, 이상 자세/속도/변위 감지, 발 미끄러짐 아티팩트 감지), 30fps로 리샘플링, 12초 초과 시퀀스 분할.
  • 주석 강화: 비디오 소스는 원본 비디오를 직접 사용하고, 3D 데이터는 합성 비디오로 렌더링; Gemini-2.5-Pro로 초기 주석 생성, 고품질 하위 집합은 수동 검증, LLM으로 구조 표준화 및 다양화 재작성.

모션 표현

각 프레임 벡터 f ∈ ℝ²⁰¹: 전역 루트 이동 t ∈ ℝ³, 전역 방향 r ∈ ℝ⁶, 로컬 관절 회전 jr ∈ ℝ²¹ˣ⁶, 로컬 관절 위치 jp ∈ ℝ²²ˣ³. 핵심 결정: 속도/발 접촉 라벨 제거(저자들은 수렴이 더 빠르다는 것을 관찰), 회전은 연속 6D 표현 사용(애니메이션 워크플로우와 호환, HumanML3D와 다름).

HY-Motion DiT 아키텍처

  • 하이브리드 트랜스포머: 이중 스트림 블록(모션/텍스트 독립 QKV+MLP, 공동 어텐션 상호작용)과 단일 스트림 블록(시퀀스 연결, 병렬 공간+채널 어텐션)이 교대로 배치.
  • 비대칭 어텐션 마스크: 모션 토큰은 텍스트를 전역적으로 주시하지만, 텍스트 토큰은 마스킹되어 모션을 주시하지 않음 — 텍스트 표현이 모션 노이즈로 오염되는 것을 방지.
  • 협대역 시간 마스크: 어텐션을 121프레임 슬라이딩 윈도우(30fps에서 약 4초)로 제한하여 긴 시퀀스의 계산 복잡도 감소.
  • 계층적 이중 조건: Qwen3-8B가 토큰 수준 의미 추출(Bidirectional Token Refiner를 통해 양방향 전환), CLIP-L이 전역 임베딩 제공, 분리된 AdaLN으로 주입.

훈련 전략

  • 플로우 매칭 목표: 최적 전송 경로 x_t = (1−t)x₀ + tx₁, 손실 L_FM = E[||v_θ(x_t, c, t) − (x₁−x₀)||²].
  • 3단계: 3000+시간 사전 훈련(상수 LR η_pre) → 400시간 정제 미세 조정(LR=0.1η_pre) → 2단계 RL(DPO 정제 9228쌍 + Flow-GRPO가 TMR 의미 보상과 발 미끄러짐/루트 드리프트 물리 페널티 통합).
  • 지속 시간 예측: Qwen3-30B-A3B 2단계 훈련(SFT가 "최적화된 프롬프트+지속 시간" 생성, GRPO가 Qwen3-235B로 의미 및 시간 합리성 평가).

핵심 혁신

  1. 모션 생성 모델의 스케일링 법칙 최초 검증: 0.05B/0.46B/1B 세 가지 DiT의 체계적 비교를 통해 명령 수행 능력은 규모에 따라 지속적으로 향상되지만, 모션 품질은 포화점이 있음을 증명. 이 발견은 "라이트 버전 Lite(0.46B)" 출시 전략을 직접적으로 안내 — 모든 시나리오에 1B 모델이 필요한 것은 아님.

  2. 데이터 엔지니어링이 최우선 생산력: LLM 분야의 "데이터 배합+정제+증강" 방법론을 모션 분야에 완전히 이식. 특히 "비디오→3D 재구성→통합 스켈레톤→VLM 주석→수동 정제→LLM 재작성"의 폐쇄 루프 파이프라인은 기존 모션 데이터셋의 규모 부족과 주석 불일치라는 근본 병목을 해결. 3000시간 사전 훈련 데이터는 기존 공개 데이터셋(HumanML3D 약 14시간)의 약 200배 규모.

  3. 비대칭 어텐션+협대역 시간 마스크: 이 아키텍처 설계는 단순해 보이지만 매우 실용적 — 텍스트 토큰이 모션을 주시하지 않아 의미 표현이 모션 노이즈로부터 보호되고, 협대역 마스크는 121프레임 윈도우 내에서 로컬 시간 연속성을 유지하면서 계산 복잡도를 O(T²)에서 O(T·W)로 감소. 이는 공학적으로 "마스크로 효율성을 얻는" 전형적인 사례.

실험 및 결과

SOTA 비교 (2000+ 프롬프트, 인간 1-5점)

모델 명령 수행 SSAE 모션 품질
MoMask 2.31 58.0% 2.79
GoToZero 2.19 52.7% 2.86
DART 2.31 42.7% 3.11
LoM 2.17 48.9% 3.06
HY-Motion 1.0 3.24 78.6% 3.43

HY-Motion의 명령 수행 우위(+0.93 (표 내 값 2.1÷2.2로 계산) vs 최강 기준선)는 모션 품질(+0.32 (표 내 값 1.0→1.0으로 계산))보다 훨씬 크며, 이는 규모화가 주로 "명령 이해"를 해결한다는 것을 의미합니다("모션 생성"이 아니라).

카테고리별 성능 (HY-Motion 최강 항목)

  • 명령 수행: 이동류 (a) 3.76 최고, 게임 캐릭터 (f) 3.01 최저 — 복잡한 캐릭터 동작은 여전히 약점.
  • 모션 품질: 이동류 3.59 최고, 피트니스류 (c) 3.28 최약.

규모 절제 (표 3/4)

모델 명령 수행 모션 품질
DiT-0.05B 3.10 2.91
DiT-0.46B 3.20 3.26
DiT-0.46B-400h 3.05 3.31
DiT-1B 3.34 3.34

핵심 발견: DiT-0.46B-400h(400h 데이터만)의 모션 품질 3.31은 1B의 3.34에 근접하지만, 명령 수행은 3.05로 1B의 3.34에 훨씬 못 미침 — 데이터 규모가 의미 이해에 미치는 영향은 모델 용량보다 훨씬 큼.

경계 및 한계

  • 복잡한 명령은 여전히 난제: 저자들은 고도로 상세한/조합적 명령에 대한 이해가 불충분함을 명시적으로 인정. 근본 원인은 주석 파이프라인이 미세한 동작에 대해 완전하고 정확한 텍스트 설명을 생성하기 어렵기 때문 — 이는 데이터 엔지니어링의 고유한 한계이며, 모델 아키텍처만으로 해결할 수 없음.
  • 사람-물체 상호작용(HOI) 부재: 현재 표현에는 물체 기하 정보가 포함되지 않아, 도구 사용, 카트 밀기 등의 상호작용 동작 생성 시 물리적 접촉점 정확성을 보장할 수 없음. 이는 표현 수준의 근본적 제한이며, 훈련 기법으로 보완할 수 없음.
  • 표준 벤치마크 지표 미보고: 논문은 HumanML3D에서의 FID, R-Precision 등의 정량적 비교를 제공하지 않아, 기존 연구와 직접 정렬할 수 없음. 저자들이 의도적으로 회피했을 가능성 — 데이터 분포와 평가 프로토콜이 HumanML3D와 크게 다르기 때문.
  • 핵심 엔지니어링 세부 사항 미공개: 훈련 스텝 수, 배치 크기, 하드웨어 구성, 추론 지연 시간이 모두 제공되지 않아 재현 장벽이 높음.

엔지니어링 시사점

  • 모델 논의 전에 데이터 파이프라인부터 검증: HY-Motion의 핵심 장벽은 3000시간 정제 데이터. 재현한다면 GVHMR 재구성 품질(발 미끄러짐 필터 임계값, 이상 자세 감지 파라미터)과 VLM 주석 일관성을 우선 검증 — 이 두 단계가 이후 모든 훈련의 상한을 결정.
  • 규모 선택에 신중: 목표가 모션 품질 우선(예: 영화 프리비즈)이라면 0.46B Lite 버전으로 충분; 목표가 복잡한 명령 수행(예: 가상 인간 어시스턴트)이라면 반드시 1B 사용. 대형 모델을 맹목적으로 추구하지 말고, 먼저 다운스트림 작업의 의미 이해 요구 강도를 평가.
  • 가장 함정에 빠지기 쉬운 부분: ① 속도/발 접촉 라벨 제거 후, 물리 보상(Flow-GRPO의 발 미끄러짐 페널티)이 충분히 강해야 함, 그렇지 않으면 모션 부드러움이 저하; ② 비대칭 어텐션 마스크 구현 시 오류 발생 가능 — 텍스트 토큰의 어텐션 마스크는 명시적으로 0으로 설정해야 하며, 그렇지 않으면 훈련이 불안정; ③ 협대역 시간 마스크의 윈도우 크기(121프레임)는 샘플링 속도와 강하게 연관되므로, 샘플링 속도를 변경하면 재조정 필요.
  • RL 단계의 비용 효율성 높음: DPO(9228쌍)와 Flow-GRPO의 개선 효과는 논문에서 개별 절제되지는 않았지만, 0.46B-400h와 0.46B의 비교에서 데이터 양이 명령 수행에 미치는 영향이 RL보다 훨씬 큼 — 사전 훈련 데이터 품질을 먼저 보장한 후 RL 튜닝에 투자할 것을 권장.
