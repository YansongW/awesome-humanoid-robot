당신의 비전-언어-액션 모델에는 이미 경로 편차 탐지를 위한 어텐션 헤드가 있다

Your Vision-Language-Action Model Already Has Attention Heads For Path Deviation Detection

요약

본 논문은 고정된 비전-언어-액션(VLA) 모델 내 어텐션 엔트로피 신호가 궤적 편차를 나타내는 소수의 '네비게이션 헤드(Navigation Heads)'를 식별하여, 학습 불필요 이상 탐지기와 경량 RL 롤백을 제안한다. VLN-CE R2R 및 RxR에서 44.6%의 편차 탐지율과 11.7%의 오탐률을 보였으며, AgileX Scout 2.0 이동 로봇에서 탐지-회복 파이프라인을 검증했다.

출처

  • Your Vision-Language-Action Model Already Has Attention Heads For Path Deviation Detection

개요

본 논문은 로봇 분야 연구팀에 의해 작성되었으며, 동결된 VLA 모델 내부에 내비게이션 전용 어텐션 헤드(Navigation Heads)가 존재함을 최초로 식별하고, 이를 기반으로 훈련이 필요 없는 경로 이탈 감지 및 복구 프레임워크를 구축했다. 핵심 기여는 VLA 모델의 내부 어텐션 메커니즘이 추가 훈련이나 외부 모델 없이 실시간 환각 감지에 직접 사용될 수 있음을 증명하고, 실제 로봇에 성공적으로 배포하여 검증한 것이다.

그것이 바꾼 것

이 작업이 실제로 바꾼 것은 "VLA 모델의 내부 상태를 신뢰할 수 있는가"라는 질문에 대한 답변 방식이다. 기존의 경로 이탈 감지는 사후 운동학적 휴리스틱(충돌, 정체)에 의존하거나, 보조 모듈 훈련 또는 외부 대형 모델 호출이 필요했으며, 세 가지 모두 VLA 모델 자체의 순전파 부산물을 활용하지 못했다. 저자들은 동결된 모델 내부에 희소한 어텐션 헤드가 존재하며, 그 분포 패턴이 자연스럽게 시각-언어 시공간 정렬 상태를 인코딩한다는 것을 발견했다. 이는 모델 내부에서 "무료" 이상 지표를 찾은 것과 같다.

더 중요한 것은, 이 발견이 감지 지연을 초 단위(외부 LLM 호출) 또는 사후적(충돌 후) 수준에서 밀리초 단위의 스칼라 연산으로 압축했으며, GPU 메모리 오버헤드를 전혀 추가하지 않는다는 점이다. 이는 VLA 내비게이션 시스템의 아키텍처 패러다임을 바꾼다. VLA를 설명 불가능한 블랙박스로 취급하지 않고, 내부 신호를 통한 자체 모니터링을 가능하게 하며, 저수준 RL 정책과 계층적 협업을 형성할 수 있다. 고수준 VLA는 의미론적 계획을 담당하고, 저수준 RL은 반응적 장애물 회피와 복귀를 담당하며, 둘은 어텐션 엔트로피 신호를 통해 분리된다.

방법 분해

궤적 단계 분류(오프라인 GT 생성)

  • 3단계 프로세스: 목표 추적(비감소 웨이포인트 인덱스 j_t ≥ j_{t-1} 강제) → 진행 평가(Δd_t > 0은 이탈을 의미) → 단계 분류(인내 파라미터 p를 가진 단방향 상태 머신, 연속 p단계 이탈 시 비가역적으로 이상 상태 𝒜로 전환)
  • 최종 에피소드는 세 가지 유형으로 분류됨: 정상만(𝒩), 이상만(𝒜), 정상에서 이상으로 전환(𝒩→𝒜)

내비게이션 헤드 선택(오프라인 통계 분석)

  • 시공간 정렬 점수 I_diag(h) = E_{τ∼ℰ_ideal}[S_uniform^(h) · S_peak^(h) · (λ·S_diag^(h) + (1−λ)·S_shift^(h))], 여기서:
  • S_uniform: 프레임 에너지 균일성, 어텐션 품질 소멸을 페널티
  • S_peak: 초점 예리도, 단일 피크 분포 보장
  • S_diag: 대각선 정렬, 어텐션 중심과 이상적 위치의 근접도 측정
  • S_shift: 부드러운 전이, 점프 페널티
  • 인지 이상 민감도: Cohen's d(h) = |μ_𝒩 − μ_𝒜| / σ_pooled, 정상/이상 단계의 S_peak 분포 분리 정도를 정량화

온라인 감지(O(1) 조회)

  • 수식(5): 상대 엔트로피 점수 ℛ_t = E_t / ((1/W)Σ_{i=1}^{W}E_{t−i} + ε), 여기서 E_t는 top-K 헤드 평균 어텐션 엔트로피
  • GT 라벨의 인내 메커니즘 미러링: ℛ_t가 임계값 τ를 연속 P단계 초과할 때만 이상 등록
  • 정상 단계에서 안전 체크포인트 𝒞_safe = {s_t, 𝒱_t, ℳ_t, A_t} 지속 업데이트

저수준 RL 정책

  • PPO 훈련, 입력 128×128 동적 2D costmap(6.4m×6.4m, 0.05m/픽셀) + 상대 목표 좌표
  • 출력 연속 속도 명령 (v, ω), tanh 활성화로 [−1,1] 제한
  • 14개 밀집 보상, 5m에서 20m 목표 거리까지 커리큘럼 학습
  • 핵심 하이퍼파라미터: γ=0.96(즉시 장애물 회피 우선), 상태 전처리기 비활성화(costmap의 절대 기하학적 스케일 유지)

실물 배포

  • Fast-LIVO2(CPU 오도메트리) + AprilTag + EKF 융합 위치 추정, ZED VIO와 VLA의 GPU 경쟁 방지
  • 3단계 동작 평활화기: 속도 포화 → 대칭 가속도 클램핑 → 데드존 억제

핵심 혁신

  1. 내비게이션 전용 어텐션 헤드를 최초로 식별: 시공간 정렬 점수 + 인지 이상 민감도의 이중 기준을 통해 32레이어×32헤드에서 3개의 작업 관련 헤드([21,12], [16,1], [14,1])를 선별하여, VLA 내부에 해석 가능한 내비게이션 상태 인코딩 메커니즘이 존재함을 증명했다. 이 발견은 VLA 모델의 해석 가능성과 내부 상태 모니터링에 새로운 방향을 제시한다.

  2. 훈련 없는 이상 감지: 감지는 O(1) 조회와 스칼라 연산만 필요하며, 단계당 지연 증가는 <20ms, 추가 GPU 메모리는 0이다. 학습 기반 감지기(훈련 필요) 및 외부 LLM(API 호출 필요)과 비교하여 계산 오버헤드에서 본질적 우위를 가지며, 임의의 동결 VLA 모델에 직접 적용 가능하다.

  3. 계층적 아키텍처의 엔지니어링 구현: 고수준 VLA(0.3Hz)는 의미론적 계획을, 저수준 RL 정책(10Hz)은 반응적 제어를 담당하며, 어텐션 엔트로피 신호를 통해 분리된다. 이탈 감지 후 단순 정지가 아닌 최단 경로 복귀를 트리거하여 완전한 "감지-복구" 폐루프를 구현했다.

경계 및 한계

논문은 한계 논의 섹션을 명시적으로 언급하지 않았지만, 사실적 요점에서 다음 경계를 추론할 수 있다: - NaVILA(VILA-8B 아키텍처) 단일 VLA 모델만 검증했으며, 다른 VLA 아키텍처(예: RT-2, OpenVLA)에 대한 일반화는 테스트되지 않음 - 학습 기반 감지기(SMNA, IEDL)와 직접 비교하지 않았으며, 제로 추론 오버헤드의 휴리스틱 기준선만 비교 - 동적 환경에서의 장기 배포 안정성은 평가되지 않음(실물 검증은 수십 미터 거리에 불과) - 𝒜 단계에서 노이즈 수정의 잘림으로 인한 유효 데이터 손실 가능성을 처리하지 않음 - 인지 오류 루프는 해결되지 않음: 물리적 궤적만 수정하고 VLA 내부 컨텍스트를 동기화하지 않아 반복적 인지 오류를 유발할 수 있음 - 더 복잡한 명령이나 더 긴 horizon 작업은 평가되지 않음

엔지니어링 시사점

재현 시 먼저 세 가지 핵심 사항을 확인해야 한다: 1. 내비게이션 헤드 선택의 이식성: 저자들이 VLN-CE R2R 데이터셋에서 선별한 헤드([21,12], [16,1], [14,1])가 당신의 작업/모델에서도 유효한가? 먼저 오프라인 GT 분석(표 1 프로세스)을 실행하여 Cohen's d가 >1.2인지 검증하고, 그렇지 않으면 재선별이 필요하다. 2. 하이퍼파라미터 민감성: τ=0.95 부근에서 감지기 민감도가 급격히 변화하며(그림 7), 9,000가지 조합의 그리드 검색을 통해서만 최적을 찾았다. 훈련 세트에서 검색을 재현하는 것이 좋으며, 특히 W=10, P=9 조합은 긴 작업에서 큰 감지 지연을 유발할 수 있으므로 주의해야 한다. 3. 실물 배포의 함정: ZED VIO와 VLA가 GPU를 경쟁하여 추론 시간이 3.488s에서 4.584s로 증가했다(표 13). 반드시 Fast-LIVO2와 같은 CPU 오도메트리를 사용해야 하며, 동작 평활화기의 데드존 임계값 ε=0.02는 섀시 모터 특성에 따라 조정해야 한다. 그렇지 않으면 크롤링이나 진동이 발생할 수 있다.

가장 함정에 빠지기 쉬운 부분: RL 정책의 costmap 파이프라인에서 시간 감쇠 인자 γ=0.9와 자체 가림 제외 영역(1.10m×0.80m)은 실제 LiDAR 설치 위치에 따라 재보정해야 하며, 상태 전처리기는 반드시 비활성화해야 한다. 그렇지 않으면 costmap의 절대 기하학적 스케일이 왜곡되어 장애물 회피가 실패할 수 있다.
