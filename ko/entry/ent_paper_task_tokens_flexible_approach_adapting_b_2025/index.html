Task Tokens: A Flexible Approach to Adapting Behavior Foundation Models

Task Tokens: A Flexible Approach to Adapting Behavior Foundation Models

영역

계층
지능 계층
검증
초안

요약

Recent advancements in imitation learning have led to transformer-based behavior foundation models (BFMs) that enable multi-modal, human-like control for humanoid agents.

출처

  • arXiv:2503.22886 Task Tokens: A Flexible Approach to Adapting Behavior Foundation Models
  • 智元、众擎都在卷的人形机器人运控基座：41篇论文看懂BFM

개요

본 논문은 Task Tokens 방법을 제안하며, 작업 인코더를 통해 작업 목표를 토큰 시퀀스로 매핑하여 행동 기반 모델(Behavior Foundation Models)에 유연하게 적응시킵니다. 저자는 아키텍처 절제 실험과 인간 선호도 연구를 통해 다양한 인코더 규모, 현재 자세 연결 여부, 관절 조건화 사용 여부에 따른 방법의 견고성을 검증하고, 생성된 행동의 인간 유사성을 평가합니다. 핵심 기여는 기본 모델을 미세 조정하지 않고도 다양한 하위 작업에 적응할 수 있는 경량화되고 모듈화된 작업 적응 메커니즘을 제공한다는 점입니다.

그것이 바꾸는 것

행동 기반 모델(예: 로봇 조작 또는 운동 생성 모델)은 일반적으로 대규모 데이터로 사전 학습되지만, 하위 작업 적응은 종종 전체 미세 조정이나 복잡한 프롬프트 설계에 의존하여 비용이 높고 유연성이 떨어집니다. Task Tokens는 이러한 패러다임을 바꿉니다. 기본 모델 가중치를 수정하지 않고, 학습 가능한 작업 인코더를 통해 작업 설명을 컴팩트한 토큰 시퀀스로 변환하여 조건 입력으로 모델에 주입합니다. 이것이 실제로 바꾸는 것은 "적응 비용"과 "작업 확장성" 사이의 균형입니다. 하위 작업 팀은 더 이상 새 작업마다 모델을 재학습하거나 복사본을 저장할 필요 없이, 경량 인코더(MLP 규모가 [256,256] 또는 [512,512,512]에 불과)만 학습하면 추론 시 동적으로 작업을 전환할 수 있습니다. 이 설계는 작업 적응을 "모델 수준"에서 "입력 수준"으로 축소하며, 이는 행동 모델의 엔지니어링 배포에 있어 핵심적인 단계입니다.

방법 분석

작업 인코더 아키텍처

  • 입력: 작업 목표(예: 방향, 목표 위치)와 선택적 현재 자세(머리/골반 위치)를 연결합니다.
  • 인코더: MLP, 두 가지 구성 — [256,256](기본값) 및 [512,512,512](Bigger MLP).
  • 출력: Task Tokens, 조건 토큰 시퀀스로 행동 기반 모델의 transformer 레이어에 주입됩니다.

핵심 설계 결정

  • 관절 조건화(Joint Conditioning, J.C.): Direction, Steering, Reach 작업에서 관절 상태를 작업 토큰과 함께 입력합니다. 절제 실험에 따르면 J.C.는 특히 소형 인코더 + 현재 자세 없음 조합에서 성능 안정성을 크게 향상시킵니다(Steering 성공률이 84.28%에서 86.88%로 상승).
  • 현재 자세 연결(Using Current Pose): head/pelvis 위치를 작업 목표와 연결합니다. 절제 실험에 따르면 이 작업은 J.C.가 없을 때 오히려 성능을 저하시킵니다(예: Bigger MLP=False일 때 84.28%에서 66.31%로 하락). 이는 중복된 자세 정보가 작업 인코딩을 방해할 수 있음을 시사합니다.
  • 인코더 규모: [512,512,512]는 J.C.가 없을 때 [256,256]보다 약간 우수하지만(83.30% vs 84.28%로 유의미하지 않음), J.C.가 있을 때는 거의 동일합니다(87.58% vs 86.88%). 이는 작업 인코더가 클수록 좋은 것이 아니며, J.C.가 더 중요한 조건 신호를 제공함을 보여줍니다.

인간 연구 프로토콜

  • 각 질문마다 3개의 나란히 배치된 비디오(무작위 샘플링 시퀀스)를 제시하고, 참가자는 가장 인간다운 행동을 선택합니다.
  • 알고리즘 순서는 무작위로 섞이고, 비디오 촬영 각도는 유사하며, Task Tokens가 항상 등장하도록 보장합니다.
  • 승률 공식: winning percentage^A_env = (# Task Tokens 선택 횟수) / (# Task Tokens 선택 횟수 + # Algorithm A 선택 횟수).

핵심 혁신

  1. 작업 적응의 "입력 수준" 추상화: 작업을 토큰 시퀀스로 인코딩하고 모델 가중치를 수정하지 않음으로써, 하나의 기본 모델이 동시에 여러 작업을 서비스할 수 있고 작업 전환 비용이 거의 0에 가깝습니다. 이는 prompt tuning과 유사하지만, 행동 시퀀스 생성을 위해 특별히 설계되었습니다(예: 관절 조건화와의 결합).
  2. 중복 조건에 대한 견고성 분석: 절제 실험을 통해 "현재 자세 연결"이 J.C.가 없을 때 유해하다는 점(성능 18% 포인트 하락)을 명확히 하여, 실무자에게 명확한 입력 설계 지침을 제공합니다 — 조건 특징을 무분별하게 쌓지 말 것.
  3. 인간 선호도 검증의 엄격성: 96명 참여, 3개 양식, 각 질문마다 무작위 순서, 승률 계산에서 자기 비교 편향을 배제하여 "인간 유사성" 품질에 대한 재현 가능한 평가 프로토콜을 제공합니다.

실험 및 결과

표 4: Task Encoder 아키텍처 절제(Steering 성공률 %)

구성 Bigger MLP 현재 자세 사용 J.C. 성공률 (%)
Task Tokens + J.C. True True 예 87.77 ± 7.14
Task Tokens + J.C. True False 예 87.58 ± 7.02
Task Tokens + J.C. False False 예 86.88 ± 6.65
Task Tokens False False 아니요 84.28 ± 7.72
Task Tokens True False 아니요 83.30 ± 10.06
Task Tokens + J.C. False True 예 79.47 ± 4.71
Task Tokens True True 아니요 78.59 ± 8.93
Task Tokens False True 아니요 66.31 ± 13.11

핵심 해석: - J.C.를 사용할 때, "소형 인코더 + 현재 자세"를 제외한 모든 구성의 성공률이 >86%이며, 이는 J.C.가 성능 안정성의 주요 원천임을 보여줍니다. - J.C.를 사용하지 않을 때, "현재 자세 연결"은 유의미하게 유해하며(66.31% vs 84.28%), 분산도 증가합니다(±13.11). 이는 중복 입력이 노이즈를 유발함을 시사합니다. - 인간 연구: 96명 참여, 각 양식 40문항, Task Tokens의 승률은 사실 요점에 구체적인 수치가 제공되지 않았지만, 실험 설계는 각 알고리즘과의 공정한 비교를 보장했습니다.

경계 및 한계

논문은 다음 한계를 명시적으로 언급하지 않았습니다: - 인간 연구에서 Task Tokens의 구체적인 승률 수치를 보고하지 않았으며, 실험 프로토콜만 설명하여 상대적 우위를 정량화할 수 없습니다. - 다중 작업 동시 추론 시 토큰 충돌 또는 어텐션 간섭 문제를 다루지 않았습니다. - [512,512,512]를 초과하는 인코더 규모의 성능 상한을 테스트하지 않았으며, 학습 데이터 양과 인코더 수렴 간의 관계도 설명하지 않았습니다. - 절제 실험은 Steering 작업에서만 보고되었으며, Direction 및 Reach 작업의 결과는 제공되지 않아 일반화 가능성에 의문이 남습니다.

엔지니어링 시사점

  • Joint Conditioning 우선 활성화: 절제 데이터는 J.C.가 성능 안정성의 핵심임을 강력히 시사하므로, 재현 시 기본적으로 활성화해야 하며 특히 Direction, Steering, Reach 유형의 작업에서 중요합니다.
  • 현재 자세를 무분별하게 연결하지 말 것: J.C.가 없을 때 head/pelvis 위치를 연결하면 성능이 크게 저하되므로(66.31% vs 84.28%), 해당 특징을 도입하기 전에 먼저 절제 실험을 수행하는 것이 좋습니다.
  • 인코더 규모 선택: [256,256]은 J.C.가 있을 때 [512,512,512]와 거의 동일하므로(86.88% vs 87.58%), 과적합 위험과 추론 오버헤드를 줄이기 위해 소형 모델을 우선 선택합니다.
  • 인간 평가 프로토콜 재사용 가능: 96명, 3개 양식, 무작위 순서 설계는 참고할 만하지만, 비디오 샘플링의 무작위성이 분산을 유발할 수 있으므로 무작위 시드를 고정하고 반복 횟수를 늘리는 것이 좋습니다.
  • 가장 흔한 함정: 현재 자세 연결은 J.C.가 없을 때 "성능 킬러"입니다. 하위 작업 자체에 자세 정보가 포함된 경우, 작업 토큰과 중복되는지 반드시 검증해야 합니다.
