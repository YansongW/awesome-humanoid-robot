요약

News Summary: ●&nbsp;Unitree Robotics introduces H2 Plus, an NVIDIA Isaac GR00T Reference Humanoid Robot combining a Unitree H2 humanoid robot, Sharpa five-fingered hands for dexterous manipulation, NVIDIA Jetson Thor for advanced reasoning and control, and the new NVIDIA Isaac GR00T development platform. ● The Isaac GR00T development platform &mdash; spanning data capture and generation to robot model evaluation and deployment &mdash; helps developers accelerate humanoid development workflows.

출처

  • Unitree Announces H2 Plus, an NVIDIA Isaac GR00T Reference Humanoid Robot for Academic Research

개요

Unitree Robotics가 출시한 H2 Plus는 학술 연구를 위해 설계된 NVIDIA Isaac GR00T 참조 휴머노이드 로봇입니다. 이 로봇은 Unitree H2 휴머노이드 로봇의 운동 능력과 Sharpa 오지(五指) 정교한 손을 결합하여 세밀한 조작을 구현합니다. 핵심 연산 장치는 NVIDIA Jetson Thor로, 고급 추론 및 제어를 담당합니다. 또한, 새로운 NVIDIA Isaac GR00T 개발 플랫폼은 데이터 수집 및 생성부터 모델 평가 및 배포까지 전 과정을 포괄하여 개발자가 휴머노이드 로봇 개발을 크게 가속화할 수 있도록 지원합니다.

핵심 내용

제품 개요

Unitree Robotics가 공식적으로 H2 Plus를 발표했습니다. 이는 NVIDIA Isaac GR00T 참조 아키텍처를 기반으로 한 휴머노이드 로봇으로, 주로 학술 연구 분야를 대상으로 합니다.

핵심 구성 요소

  • 본체: Unitree H2 휴머노이드 로봇을 기본 플랫폼으로 사용합니다.
  • 정교한 손: Sharpa 오지 정교한 손을 장착하여 세밀한 조작 능력을 제공합니다.
  • 컴퓨팅 플랫폼: NVIDIA Jetson Thor를 탑재하여 고급 추론 및 제어 기능을 제공합니다.
  • 개발 플랫폼: 새로운 NVIDIA Isaac GR00T 개발 플랫폼을 통합했습니다.

개발 플랫폼 기능

Isaac GR00T 개발 플랫폼은 휴머노이드 로봇 개발의 전 과정을 포괄하며, 다음을 포함합니다: - 데이터 수집 및 생성 - 로봇 모델 평가 - 모델 배포

이 플랫폼은 개발자가 휴머노이드 로봇 개발 워크플로우를 가속화하는 데 도움을 주기 위해 설계되었습니다.
