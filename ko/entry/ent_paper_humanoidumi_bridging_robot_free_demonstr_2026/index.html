요약

High-quality demonstration data are essential for humanoid robot skill learning, especially for whole-body behaviors that require coordinated perception, locomotion, and manipulation. Institutions per source list: Beijing Academy of Artificial Intelligence（BAAI）.

출처

  • arXiv:2606.27239 HumanoidUMI: Bridging Robot-Free Demonstrations and Humanoid Whole-Body Manipulation
  • GitHub仓库 Robotics_Notebooks

개요

HumanoidUMI는 베이징 인공지능 연구원 팀이 제안한 로봇 독립적(robot-free) 휴머노이드 전신 조작 데이터 수집 및 정책 훈련 파이프라인입니다. PICO 4 VR 추적과 UMI 방식의 휴대용 그리퍼를 활용해 인간 시연을 수집하고, 공간 키포인트 리타겟팅(SKR)과 확산 정책을 통해 희소 작업 공간에서 Unitree G1에 배포 가능한 전신 제어 정책을 생성합니다. 핵심 기여는 UMI 패러다임을 데스크톱 조작에서 균형과 보행 조정이 필요한 전신 작업으로 확장한 것입니다.

무엇을 바꾸었는가

휴머노이드 로봇 스킬 학습은 오랫동안 데이터 수집 병목에 막혀 있었습니다: 원격 조작은 대상 로봇 하드웨어, 숙련된 조작자, 안전 감독이 필요해 효율이 극히 낮고 확장이 어렵습니다. UMI 패러다임은 로봇 독립적 시연이 데스크톱 조작에서 가치가 있음을 입증했지만, 휴머노이드 전신 작업에 직접 이식하면 실패합니다—휴머노이드 로봇은 조작, 균형, 자세 조정, 보행을 동시에 처리해야 하며, 이러한 형태 의존적 전신 운동은 인간 시연에서 직접 매핑할 수 없기 때문입니다.

HumanoidUMI가 실제로 바꾼 것은 "대상 로봇 없이 배포 가능한 전신 정책 데이터를 수집할 수 있는" 가능성의 경계입니다. 전신 제어의 모든 난제를 해결하려 하지 않고, 문제를 영리하게 계층화했습니다: 고수준 정책은 희소 작업 공간(키포인트 자세)에서만 조작 의도를 추론하고, 저수준은 학습된 운동 추적 컨트롤러가 형태 관련 전신 조정을 담당합니다. 이러한 분리는 로봇 독립적 시연을 가능하게 하면서도 최종 정책의 물리적 로봇 배포 가능성을 유지합니다.

방법 분석

데이터 수집 시스템

  • 하드웨어: PICO 4 VR(헤드셋 + 핸드 컨트롤러 + 하체 트래커 3개) + 자체 개발 UMI 방식 그리퍼 2개(어안 카메라 + 모터 구동 랙 앤 피니언 기구)
  • 추적: 관성, 지자기, 능동 적외선 융합, SMPL 형식 6-DoF 신체 운동 추정 출력
  • 기록 모달리티: 손목 어안 이미지, 컨트롤러 6-DoF 자세, 골반/발 자세, 그리퍼 폭(모터 엔코더)
  • 핵심 설계: SKR 모듈을 온라인으로 실행, 하체 DoF 위치 q_low_t를 정책 조건 입력으로 기록

고수준 정책(확산 정책)

  • 행동 공간: 기본 47차원(키포인트 5개 × 9 + 그리퍼 폭 2개), 확장 65차원(키포인트 7개 × 9 + 2)
  • 키포인트 자세는 골반 좌표계에서 표현, 미래 자세는 쿼리 시점 자세 기준 상대적: T_rel_k,τ = (T_pel_k,t)^(-1) T_pel_k,τ
  • 정규화: 병진과 그리퍼 폭은 min-max로 [-1,1], 6D 회전은 스케일링 없음
  • 관측: 224×224 좌우 손목 RGB 이미지 쌍 + 15차원 하체 고유수용감각 벡터 3프레임 히스토리
  • 예측 수평선 H = 48, receding-horizon 행동 블록

공간 키포인트 리타겟팅(SKR)

  • 형태 인식 이방성 조정: 다리 키포인트에만 골반 국소 수직 스케일링, d̄_i = [d_i,x, d_i,y, λ_i·d_i,z], λ_leg = 0.75로 인간과 G1 다리 길이 차이 보상
  • 제약 가중 IK: q*t = argmin Σ w_i‖e_i(q_t)‖²₂ + λ_q‖q_t − q‖²₂, 2단계 최적화(먼저 발 지지, 이후 골반/TCP)

저수준 컨트롤러

  • MJLab에서 훈련된 운동 추적 컨트롤러, 50 Hz 동작, 29차원 잔차 관절 위치 출력
  • 목표 관절 위치: q_des_t = q⁰ + s ⊙ clip(a_t, −a_max, a_max), 관절 공간 PD 제어로 실행

핵심 혁신

  1. 로봇 독립적 전신 데이터 수집: UMI 패러다임을 전신 조정이 필요한 휴머노이드 작업으로 최초 확장, 소비자급 VR 기기 + 휴대용 그리퍼로 원격 조작 대체, 데이터 수집 처리량 2-61배 향상, 초보자도 10분 지도로 숙련 사용자 효율에 근접.

  2. 희소 작업 공간 + 계층 제어 아키텍처: 고수준 정책은 5-7개 키포인트의 작업 공간에서만 추론하고 관절 명령을 직접 예측하지 않음; 저수준은 학습된 운동 추적 컨트롤러가 형태 관련 전신 조정 담당. 이러한 분리는 전신 작업에서 엔드투엔드 정책의 데이터 요구 폭발을 피하면서 물리적 배포 가능성을 유지.

  3. SKR의 형태 인식 리타겟팅: 단순 전신 IK가 아닌, 휴머노이드 다리 길이 차이에 대한 이방성 스케일링(수직 방향만 λ=0.75)과 2단계 가중 IK로 발 지지와 방향 일관성을 우선 보장. 이 설계 결정은 인간 시연에서 휴머노이드 운동학 매핑의 핵심 모순을 직접 해결.

경계와 한계

논문에서 한계 논의 섹션을 명시적으로 언급하지 않음. 사실적 요점에서 추론 가능한 경계: Unitree G1에서만 검증, 다른 로봇 플랫폼 미테스트; 대규모 데이터 수집 또는 데이터 규모 확장성 검증 없음; 장기/다단계 복잡 작업 평가 없음; 시뮬레이션-실제 전이 검증 없음; 엔드투엔드 관절 예측 정책과의 정량적 비교 없음; 조명, 배경, 객체 구성 변화에 대한 강건성 미테스트. 훈련 데이터량, 훈련 설정(epoch/batch size/학습률), 추론 빈도, GPU 모델 등 핵심 엔지니어링 파라미터는 모두 미언급.

엔지니어링 시사점

재현 시 가장 함정에 빠지기 쉬운 세 가지를 우선 확인: 지연 매칭—논문에서 동적 공 던지기 작업에서 지연 매칭 제거 시 성능 저하를 명시, 손목 관측, 그리퍼 상태, 정책 추론, 로봇 제어 간 상대 지연 보정이 시스템 핵심임을 의미, UMI의 지연 매칭 절차를 엄격히 따를 것을 권장; SKR의 λ_leg 보정—0.75는 인간과 G1 다리 길이 차이에 대한 경험값, 로봇이나 조작자 체형 변경 시 반드시 재보정 필요, 그렇지 않으면 다리 리타겟팅 오류 발생; 2단계 가중 IK의 가중치 설정—발 지지 먼저, 이후 골반/TCP 최적화 순서가 균형 보장의 핵심, 단일 단계 IK로 직접 변경 시 배포 중 넘어짐 가능성 높음.

하류 팀에 대한 실질적 조언: 목표가 휴머노이드 조작 데이터를 빠르게 축적하는 것이라면, 이 시스템은 원격 조작보다 한 자릿수 효율적이지만, 생성되는 정책이 "작업 공간 키포인트 + 저수준 추적 컨트롤러"의 계층 구조이며 엔드투엔드 관절 명령 정책이 아님을 유의—하류에서 직접 관절 수준 제어가 필요하면 추가 적응 계층 필요. 또한 7키포인트 변형(무릎 추가)은 쪼그리기나 하지 조정이 필요한 작업에서 5키포인트보다 명확히 우수하므로 기본 활성화를 권장.
