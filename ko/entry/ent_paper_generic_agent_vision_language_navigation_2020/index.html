Towards Learning a Generic Agent for Vision-and-Language Navigation via Pre-training

Towards Learning a Generic Agent for Vision-and-Language Navigation via Pre-training

요약

Learning to navigate in a visual environment following natural-language instructions is a challenging task, because the multimodal inputs to the agent are highly variable, and the training data on a new task is often limited. Institutions per source list: 杜克大学、微软研究院.

출처

  • arXiv:2002.10638 Towards Learning a Generic Agent for Vision-and-Language Navigation via Pre-training
  • Project page
  • GitHub仓库 Robotics_Notebooks

개요

본 논문은 Prevalent를 제안한다. 이는 시각-언어 내비게이션(VLN)을 위한 최초의 사전학습-미세조정 패러다임이다. 저자들은 Matterport3D 시뮬레이터를 활용하여 658만 개의 이미지-텍스트-행동 삼중항(그중 98.4%는 Speaker 모델이 합성)을 구축하고, 이미지 주의 마스크 언어 모델링(MLM)과 행동 예측(AP)이라는 두 가지 자기지도 학습 목표를 통해 교차양상 인코더를 훈련시킨다. R2R, CVDN, HANNA 세 가지 하위 과제에서 플러그 앤 플레이 구성 요소로서의 효용성을 검증하며, 기존 기준선을 크게 능가한다.

그것이 바꾼 것

VLN 분야는 오랫동안 데이터 희소성에 시달려 왔다. 가장 큰 데이터셋인 R2R은 단 104K 샘플로, 전형적인 시각-언어 사전학습 말뭉치보다 한 자릿수 작다. 기존 방법들은 시퀀스-투-시퀀스 모델을 처음부터 훈련하거나 BERT/ViLBERT 같은 범용 VLP 모델을 직접 적용했지만, 후자는 Faster R-CNN 영역 특징에 의존하여 VLN의 파노라마 뷰 입력(뷰당 36장의 이미지)과 계산적으로 호환되지 않는다. Prevalent가 진정으로 바꾼 것은 사전학습을 "언어 중심"에서 "내비게이션 중심"으로 전환한 것이다. 이미지-텍스트-행동 삼중항에 대해 최초로 자기지도 학습을 수행하여 인코더가 시각 환경, 언어 명령, 행동 궤적의 결합 분포를 동시에 인코딩하게 한다. 이는 하위 모델이 더 이상 시각-언어 정렬을 처음부터 학습할 필요 없이, "무엇을 보고, 무엇을 말하고, 어디로 가는지"의 관계를 이미 이해하는 범용 표현을 직접 상속받아 seen과 unseen 환경 간 성능 격차를 크게 줄인다는 것을 의미한다(예: HANNA에서 SPL 격차가 38.42에서 30.66으로 감소).

방법 분해

입력 표현

  • 시각 임베딩: 각 파노라마 뷰는 36장의 이미지(12 각도 × 3 피치)로 구성되며, 각 이미지는 2176차원 벡터 = 2048차원 ResNet 특징 + 128차원 방향 특징([sinψ; cosψ; sinω; cosω]를 32회 반복)이며, LayerNorm(W_e·s + b_e)을 통해 d_h=768로 매핑된다.
  • 텍스트 임베딩: 표준 Transformer 토큰 임베딩 + 위치 임베딩, LayerNorm 후 입력.

인코더 아키텍처(3계층 Transformer 적층)

  1. 단일양상 텍스트 인코더(L_text=9): 표준 자기주의, 마스크 행렬 M은 전부 0.
  2. 단일양상 시각 인코더(L_vision=1): 표준 자기주의, 36장의 파노라마 이미지 처리.
  3. 교차양상 인코더(L_cross=3): 쿼리는 다른 양상의 이전 계층 출력에서, 키-값은 현재 양상 H_{ℓ-1}에서 가져와 교차양상 완전 연결을 구현; 이후 자기주의와 FFN이 이어진다.

주의 계산: A_ℓ = Softmax(QK^T/√d_k + M)V, M에서 0은 주의 허용, −∞는 금지.

사전학습 목표

  • 이미지 주의 MLM: 15% 확률로 단어 마스킹, 주변 단어와 전체 이미지를 기반으로 예측, 손실 L_MLM = −E log p(x_i | x_{\i}, s).
  • 행동 예측(AP): [CLS] 토큰 출력에 FC 계층을 연결하여 행동 예측, 손실 L_AP = −E log p(a | x_[CLS], s).
  • 총 손실 L = L_MLM + L_AP. 저자들은 마스크 이미지 모델링을 시도했지만 효과가 좋지 않아 제외했다.

사전학습 데이터

  • R2R 훈련 세트: 104K 삼중항.
  • Speaker 모델(seq2seq 자기회귀) 합성: 6,482K 삼중항(98.4% 차지).
  • 총 6,582K 삼중항, Matterport3D 시뮬레이터에서 최단 경로 궤적 수집.

미세조정 설계

  • R2R: 사전학습 단어 임베딩을 LSTM 인코더-디코더에 입력; 두 단계로 진행 — 먼저 특징 기반 훈련, 그다음 교차 주의 계층 미세조정(20k 반복, lr=2×10⁻⁶).
  • CVDN: 시퀀스 길이를 300으로 제한, 초과분은 절단.
  • HANNA: 도움 요청 시 사전학습 모델로 명령 인코딩.

핵심 혁신

  1. 최초의 VLN 전용 사전학습 패러다임: BERT/ViLBERT 같은 범용 VLP와 달리, Prevalent는 이미지-텍스트-행동 삼중항에서 사전학습하여 "시각-언어-행동"의 관계를 직접 정렬하며, 단순한 시각-언어 정렬이 아니다. 이는 사전학습 표현이 추가 적응 계층 없이 내비게이션 결정에 자연스럽게 적합하게 한다.
  2. 이미지 주의 MLM: BERT의 순수 텍스트 MLM과 달리, 마스킹된 단어 예측 시 교차양상 인코더가 전체 36장의 파노라마 이미지를 주의할 수 있어 언어 이해가 공간적 시각 맥락과 결합된다. 절제 실험은 이 설계가 CVDN에서 BERT 사전학습(Mixed 지표 3.15 vs 2.64)과 BERT 미세조정(3.15 vs 2.28)보다 우수함을 증명한다.
  3. 합성 데이터 규모화: Speaker 모델을 활용하여 사전학습 데이터를 63배 확장(104K→6,582K), VLN 데이터 희소성 병목을 해결. 합성 데이터가 98.4%를 차지하며, 실험을 통해 그 효용성이 입증됨 — 사전학습 단어 임베딩은 R2R에서 무작위 초기화보다 적응 속도가 현저히 빠름(Figure 4).

절제 실험

  • CVDN 사전학습 목표(Mixed 지표): 전체 목표 3.15 > MLM만 3.14 > BERT 사전학습 2.64 > BERT 미세조정 2.28.
  • R2R 특징 추출 vs 미세조정: 미세조정 SR=54/SPL=51이 특징 추출 SR=52/SPL=49보다 우수.
  • HANNA 목표 절제: 전체 목표 UNSEEN-ALL SR=52.91이 MLM만 44.29, BERT 특징 24.12, BERT 미세조정 26.36보다 현저히 우수.

경계와 한계

  • 마스크 이미지 모델링은 시도되었지만 효과가 좋지 않아 제외되었으며, 이는 시각 재구성 목표가 내비게이션 작업에 필수적이지 않을 수 있음을 시사.
  • 실제 물리적 로봇에서 검증되지 않았으며, 모든 실험은 Matterport3D 시뮬레이터 기반.
  • 합성 데이터 품질에 대한 체계적 평가가 없으며, 합성 명령과 인간 명령의 분포 차이도 분석되지 않음.
  • CVDN 시퀀스 길이 제한 300으로 인한 정보 손실 가능성에 대해 논의하지 않음.
  • HANNA에서 #R이 다소 높은(6.6 vs 5.8) 원인을 분석하지 않았으며, 이는 도움 요청 효율성에 영향을 미칠 수 있음.
  • 사전학습 총 계산량(GPU 시간)을 보고하지 않았으며, 8×V100, batch 96, 20 에포크만 언급.

공학적 시사점

재현 시 세 가지를 우선 확인해야 한다: 사전학습 데이터 구축 — Speaker 모델 생성 품질이 사전학습 효과를 직접 결정하므로, 소규모 합성 데이터에서 명령-궤적 정렬을 먼저 검증할 것; 교차양상 인코더 계층 구성(L_text=9, L_vision=1, L_cross=3)은 경험적 값으로, 하위 작업의 시각 정보가 더 복잡하면(예: 연속 내비게이션) 재조정 필요; 미세조정 2단계 전략 — R2R에서 특징 추출 후 교차 주의 계층 미세조정(lr=2×10⁻⁶)이 성능의 핵심이며, 특징 추출 단계를 건너뛰고 직접 미세조정하면 과적합이 발생할 수 있다. 가장 함정에 빠지기 쉬운 부분은 합성 데이터 규모다: 6,482K 삼중항이 98.4%를 차지하므로, 계산 자원이 제한되어 합성 데이터를 줄이면 사전학습 이득이 비선형적으로 감소할 수 있음을 유의해야 한다. CVDN의 경우 시퀀스 길이 300 절단 전략은 긴 대화 기록을 잃을 수 있으므로, 하위 작업이 다중 턴 상호작용을 포함한다면 슬라이딩 윈도우나 계층적 인코딩을 권장한다.
