요약

Learning long-horizon humanoid loco-manipulation poses a dual challenge: it requires not only the robust execution of meta-skills but also their seamless, closed-loop chaining equipped with autonomous recovery. Institutions per source list: 诺亦腾机器人（Noitom Robotics）、香港科技大学（HKUST）、武汉大学（WHU）、香港大学（HKU）.

개요

OmniContact는 휴머노이드 로봇의 이동 조작에서 고수준 의미론적 계획과 저수준 전신 실행 사이의 통합 인터페이스로 '접촉 흐름'(Contact Flow)을 제안합니다. CF-Gen 규칙 기반 플래너와 CF-Track 강화학습 컨트롤러의 계층적 협업을 통해 장시간 지속 가능하고 복구 가능한 스킬 체인 조합을 구현합니다. 핵심 기여는 희소 비균일 샘플링 신체 궤적과 4차원 이진 접촉 신호를 결합하여 표현력과 압축성을 동시에 확보하고, 시뮬레이션에서 기존 베이스라인을 크게 능가한다는 점입니다.

무엇을 바꾸었는가

휴머노이드 이동 조작은 오랫동안 '표현' 선택에 막혀 있었습니다. 완전한 인간-물체 상호작용(HOI) 상태는 정확도가 높지만 차원이 폭발하여 고수준 계획을 지원하기 어렵고, 암시적 스킬 임베딩은 압축적이지만 해석이 불가능하며 조합 시 신뢰성 보장이 부족합니다. 기존 강화학습 접근법은 원격 조작 개루프 실행에 의존하거나 프레임별 전신 참조가 필요하여 본질적으로 '스킬이 고수준 작업에 의해 어떻게 호출되는가'라는 핵심 문제를 회피했습니다. OmniContact가 진정으로 바꾼 것은 '접촉'을 실행 세부사항에서 계획 원시어(primitive)로 승격시킨 것입니다. 더 이상 고수준 플래너가 조밀한 운동학을 예측하도록 요구하지 않고 물체 수준 목표만 출력하며, 접촉 흐름이 의미론과 물리 사이의 중간 언어 역할을 합니다. 이 변경으로 VLM과 같은 기반 모델이 장시간 작업 분해에 개입할 수 있게 되면서도 저수준 정책의 견고성과 복구 능력을 유지하며, 인터페이스 설계의 패러다임 전환입니다.

방법 분해

접촉 흐름(Contact Flow) 표현

  • 형식화: 시간 단계 t에서 접촉 흐름 F_t = {(b_{t+k}, c_{t+k})}_{k∈T}, 여기서 T = {0,1,2,3,4,8,12,16,24,32,50}은 비균일 미래 프레임 오프셋입니다.
  • b는 희소 신체 운동 목표(몸통, 손목, 발목 관절 위치 및 방향), c ∈ {0,1}^4는 4차원 이진 접촉 신호로 말단 실행기 접촉 상태를 지정합니다.
  • 비균일 샘플링은 가까운 곳은 밀집, 먼 곳은 희소하여 단기 정밀도와 장기 계획 시야를 동시에 고려합니다.

CF-Track(저수준 컨트롤러)

  • 통합 정책이 접촉 흐름 목표를 추적하며, 입력은 x_t = [F_t, H_t], H_t는 K=5 단계 히스토리 버퍼입니다.
  • 관측에는 고유수용감각(관절 운동학, 베이스 방향, 말단 실행기 위치, 이전 행동)과 물체 상태(상대 6D 포즈, 경계 상자)가 포함됩니다.
  • 보상: r_t = λ_track·r_t^track + λ_amp·r_t^amp + λ_reg·r_t^reg, 최적 가중치 W_track–W_amp = 0.85–0.15.
  • Actor와 Critic 모두 MLP가 아닌 Transformer(은닉 차원 [512,256,128], 3계층, 8헤드)를 사용합니다.

CF-Gen(중간 계층 플래너)

  • 규칙 기반 참조 합성기: 물체 수준 목표, 현재 상태, 물체 포즈 및 크기가 주어지면 밀집 참조 운동을 생성합니다.
  • 위상 템플릿 라이브러리: 각 메타 스킬은 순서화된 위상 블록으로 분해됩니다(예: 운반: 접근→사전 파지→들어올리기→보행→놓기), 각 위상은 명확한 접촉 의미론을 가집니다.
  • 키프레임 생성: 말단 실행기 배치가 정밀해야 하는 경우에만 IK(최대 20회 반복)를 사용하고, 순수 이동 위상은 발목 관절 자세만 지정하며 나머지는 기본 명목 자세를 사용합니다.
  • IK 최적화 변수: 골반 높이 z_pelvis, 골반 피치 θ_pitch, 모든 관절 자유도 q, 허리 롤과 요(yaw)는 엄격히 제외합니다.
  • 궤적 보간: 병진과 관절은 LERP, 회전은 SLERP를 사용합니다.
  • 온라인 재계획: 50Hz 모니터링, 편차 δ_t가 임계값 ε를 초과하면 현재 계획을 중단하고 현재 상태에서 재계획합니다.

계층적 실행 및 VLM 통합

  • CF-Gen은 작업 목표를 물체 중심 접촉 흐름 세그먼트로 변환하고, CF-Track은 실행하며 지속적으로 모니터링합니다. 위상 완료 또는 실패 시 CF-Gen이 상태를 업데이트하고 다음 세그먼트를 합성합니다.
  • VLM(Gemini 3.1 Pro Preview)은 물체 수준 계획만 수행합니다: 물체 인식, 목표 영역/포즈 할당, 메타 스킬 선택, JSON 형식 계획 출력, 저수준 운동학은 전혀 예측하지 않습니다.

핵심 혁신

  1. 접촉 흐름의 조합 가능한 중간 표현: 접촉 신호를 이진 시계열 벡터로 명시적으로 인코딩하고 희소 신체 궤적과 결합합니다. 절제 실험에서 접촉 항(C) 추가 시 [T, EE] 베이스라인의 성공률이 11.50%에서 98.70%로 향상되어, 접촉이 스킬 조합의 핵심 의미론적 앵커임을 증명합니다. 중복 세부사항이 아닙니다.
  2. 규칙 기반 플래너와 학습 컨트롤러의 분리: CF-Gen은 휴리스틱 위상 템플릿과 IK로 참조를 생성하고, CF-Track은 RL로 추적하며 아티팩트를 평활화합니다. 이 설계는 엔드투엔드 학습의 장시간 조합 취약성을 피하면서 재계획 로직을 투명하고 디버깅 가능하게 만듭니다.
  3. VLM 인터페이스의 극소 제약: 기반 모델의 출력을 물체 수준 하위 목표 목록으로 제한하고 관절 궤적이나 접촉 타이밍 예측을 요구하지 않습니다. 이를 통해 개방 어휘 의미론적 추론(예: "원통을 바구니에 넣어")이 저수준 접촉 풍부 실행을 직접 구동할 수 있으며, 실패 모드가 귀인 가능합니다(모호한 접지, 불가능한 배치, 실행 편차).

  • 데이터 규모: 10%(2.2h)에서 100%(22.3h)로 확장 시 성공률과 물체 정밀도 모두 향상.

경계 및 한계

논문은 한계 선언을 명시적으로 나열하지 않았지만 실험에서 추론할 수 있습니다: 저구동 그리퍼는 정밀 조작을 제한하며, 접촉 흐름을 다섯 손가락 로봇 손으로 확장하는 것은 미해결 과제입니다; 규칙 기반 CF-Gen은 고도로 동적인 시나리오(예: 빠른 공 차기)에서 성능이 좋지 않으며, 저자들은 휴리스틱 접촉 앵커 생성을 학습 가능한 데이터 기반 방법으로 대체할 것을 구상합니다. 모든 정량적 결과는 시뮬레이션(Isaac Lab 훈련, MuJoCo 평가)에서 얻었으며, 실제 배포는 Unitree G1에서 정성적 시연만 수행했고 정량적 데이터는 없습니다. 장시간 다중 물체 작업(프로토콜 III)은 성공률 감소가 심각하며(40분에 10%만), 스킬 체인 조합이 물체 수 증가 시 누적 오류 문제가 여전히 존재함을 나타냅니다. 공 작업 성공률은 낮으며(Relocate Ball 72.5%, Kick Ball 76.5%), 시뮬레이션 공이 매끄럽고 강체라 미끄러지기 쉽기 때문입니다.

공학적 시사점

재현 시 세 가지를 우선 확인하십시오: 첫째, 접촉 흐름 샘플링 오프셋 T와 히스토리 창 K=5의 구성 — 표현 압축성의 핵심; 둘째, 보상 가중치 W_track–W_amp = 0.85–0.15 — 이 값에서 벗어나면 성공률에 큰 영향(0.5–0.5일 때 0.10%에 불과); 셋째, IK 최적화에서 허리 롤과 요를 제외하는 제약 — 몸통 안정성 유지의 전제. 가장 함정에 빠지기 쉬운 지점: 전관절 목표(Dof) 추가는 정책 적응성을 파괴하므로(성공률 0.00% 하락), CF-Gen 참조 합성 시 반드시 몸통, 손목, 발목만 지정하고 나머지 자유도는 정책의 자율 결정에 맡겨야 합니다. 하류 팀에게는 접촉 흐름을 모듈 간 인터페이스 표준으로 채택할 것을 권장합니다 — 고수준 플래너는 물체 수준 목표만 출력하고, 저수준 정책은 접촉 흐름만 소비하며, 중간에 밀집 운동학을 전달하지 않습니다. 재계획 주파수 50Hz와 편차 임계값 ε의 설정은 작업 동적 특성에 따라 조정해야 하며, 밀기 작업은 평균 재계획 0.77회로 성공률을 크게 높일 수 있지만, 다중 물체 장시간 작업에서는 낙하 이벤트에 따라 재계획 횟수가 급증하므로 계산 여유를 확보해야 합니다.
