Learning Locomotion Skills Using DeepRL: Does the Choice of Action Space Matter?

요약

The use of deep reinforcement learning allows for high-dimensional state descriptors, but little is known about how the choice of action representation impacts the learning difficulty and the resulting performance. Institutions per source list: Xue Bin Peng、Michiel van de Panne.

출처

  • arXiv:1611.01055 Learning Locomotion Skills Using DeepRL: Does the Choice of Action Space Matter?
  • GitHub仓库 Robotics_Notebooks

개요

본 논문은 심층 강화 학습(DeepRL)에서 네 가지 동작 공간 파라미터화 방식(토크, 목표 관절 각속도, 목표 관절 각도, 근육 활성화)이 운동 모방 학습에 미치는 영향을 이족 보행, 랩터, 개 세 가지 캐릭터에 걸쳐 체계적으로 비교한다. 핵심 기여는 동작 표현이 학습 속도, 최종 성능, 강건성 및 정책 쿼리 빈도에 미치는 유의미한 영향을 밝히고, 정책 파라미터와 실행기 파라미터를 교대로 최적화하는 휴리스틱 방법을 제안하여 신경망이 복잡한 근골격 모델을 효과적으로 제어할 수 있게 한 점이다.

무엇을 바꾸었는가

이 연구의 가치는 새로운 강화 학습 알고리즘을 제안하는 것이 아니라, 공학 실무에서 종종 하이퍼파라미터처럼 취급되던 '동작 공간 설계' 문제를 학습 성패를 결정짓는 핵심 요소로 끌어올린 데 있다. 기존 DeepRL 연구는 주로 네트워크 아키텍처, 보상 형성 또는 알고리즘 개선에 집중했으며, 동작 표현의 선택은 암묵적으로 '세부 사항'으로 간주되었다. 본 논문은 체계적인 대조 실험을 통해 이 '세부 사항'이 학습 난이도와 최종 정책 품질에 지배적인 영향을 미친다는 것을 증명했다—특히 복잡한 캐릭터(개, 랩터)와 고차원 근육 모델에서는 동작 표현의 선택이 알고리즘 자체보다 성패를 더 크게 좌우한다.

이 연구가 진정으로 바꾼 것은 '지능이 어디서 오는가'에 대한 이해다: 저자들은 근육 활성화(MTU)와 단순화된 동작 추상화(PD)의 성능을 비교함으로써, 생체역학적 구조 자체(수동 탄성, 감쇠)가 일부 제어 계산을 담당한다는 것, 즉 '구현된 지능(embodied intelligence)' 또는 '기계적 지능(mechanical intelligence)'이 DeepRL 프레임워크에서 정량화 가능하고 활용 가능하다는 것을 실증했다. 이는 후속 연구에 새로운 방향을 열어준다: 정책 네트워크만 최적화하는 대신 '신체' 파라미터(실행기 특성)도 함께 최적화하여 제어와 역학이 공진화하도록 하는 것이다.

방법 분해

작업 프레임워크

  • 표준 actor-critic 구조, 정책은 가우시안 분포 π_θ(s,a) = N(μ_θ(s), Σ), Σ는 수동으로 지정된 대각 공분산으로 고정.
  • 목표는 기대 누적 보상 J(π_θ) = E[Σ γ^t r_t] 최대화, γ=0.9.
  • 상태 특징 s_t = (Φ(q_t, q̇_t), Φ(q_t, q̇_t)), 즉 현재 자세 특징과 참조 자세 특징의 결합, Φ는 루트 높이, 링크 상대 위치, 질량 중심 속도를 포함.

네 가지 동작 모델

  • PD(목표 관절 각도): 동작이 목표 각도 q̂를 지정, 토크 τ = k_p(q̂ − q) + k_d(q̇̂ − q̇), 여기서 q̇̂=0, k_p, k_d는 수동 설정.
  • Vel(목표 관절 속도): 동작이 목표 속도 q̇̂를 지정, 토크 τ = k_d(q̇̂ − q̇), k_d는 PD와 동일.
  • Tor(토크): 동작이 관절 토크를 직접 지정, 수동 설정된 토크 제한을 받으며 추가 실행기 파라미터 불필요.
  • MTU(근육 활성화): 동작이 힘줄 단위 활성화 a_MTU ∈ [0,1]를 지정, 힘 계산 F_MTU = F_SE = F_CE + F_PE, 여기서 F_CE = a_MTU · F_0 · f_l(l_CE) · f_v(v_CE). 근육은 길항 쌍으로 나타나며, 동작 차원은 다른 모델의 최소 두 배.

핵심 훈련 기술

  • 양의 시간차(PTD) 업데이트: 이점 함수 A(s,a) = I[δ > 0], δ = r + γV(s') − V(s). TD 오차가 양수일 때만 actor를 업데이트하여, 음의 TD 업데이트가 정책 평균을 알 수 없는 열등한 동작으로 밀어내는 것을 방지.
  • 유계 동작 공간 처리: 수정된 inverting gradients 방법 사용—정책 평균 μ^i(s)가 경계 [l^i, u^i]를 벗어나고 그래디언트 방향이 경계 밖을 가리킬 때, 그래디언트를 l^i − μ^i(s) 또는 u^i − μ^i(s)로 대체; 경계 내에서는 원래 그래디언트 유지.
  • 탐색 어닐링: 훈련 시 λ ~ Ber(ε), ε는 1에서 0.2로 선형 어닐링(500k 반복), λ=1인 튜플만 actor 업데이트에 사용, critic은 전체 튜플 사용 가능.
  • 실행기 파라미터 최적화(알고리즘 2): 정책 학습(알고리즘 1, 250k 반복)과 CMA 실행기 파라미터 ψ 최적화(250세대, 각 세대 16개 샘플, 각 샘플은 16회 10초 rollout 평가)를 교대로 수행, 총 6라운드, 약 50시간.

보상 함수

r = 0.5·r_pose + 0.05·r_vel + 0.15·r_end + 0.1·r_root + 0.2·r_com, 각 구성 요소는 지수형 보상으로 자세, 속도, 말단 실행기, 루트 및 질량 중심 편차를 페널티.

핵심 혁신

  1. 동작 공간 선택이 DeepRL 운동 학습에 미치는 영향의 최초 체계적 정량화: 통일된 프레임워크(동일한 네트워크 구조, 보상, 알고리즘)에서 네 가지 동작 표현을 비교하고, 세 캐릭터, 일곱 가지 운동을 포괄하며 재현 가능한 벤치마크 데이터를 제공. 기존 연구는 대부분 단일 동작 공간에 국한되어 '어떤 표현이 더 나은가, 왜 그런가'라는 기본적인 공학적 질문에 답할 수 없었다.

  2. 정책-실행기 교대 최적화 방법 제안: 실행기 파라미터(근육 최대 등척성 힘, 힘줄 휴지 길이, 모멘트 팔 등)를 최적화 루프에 포함시켜 생물학적 진화에서 '신체'와 '제어'의 협응 적응을 유추. 이는 '구현된 지능' 개념의 공학적 구현—신체를 고정된 제약이 아닌 최적화 가능한 자유 파라미터로 취급하여 신경망이 고차원 근육 모델을 효과적으로 다룰 수 있게 함.

  3. PTD 업데이트와 유계 그래디언트 수정의 결합: PTD는 음의 TD 업데이트로 인한 가우시안 정책 평균 드리프트 문제를 방지하고, 유계 그래디언트 수정은 Hausknecht & Stone (2015)의 inverting gradients보다 보수적—경계가 위반될 때만 그래디언트를 변경하고 경계 내에서는 원래 그래디언트를 유지하여 정보 손실을 줄임. 두 기법의 결합으로 다양한 동작 공간에서 훈련이 안정적으로 수렴.

핵심 발견

  • PD가 가장 안정적: 7개 운동 중 5개에서 학습 속도가 가장 빠르고(AUC 최고), 최종 성능은 모든 운동에서 비교 가능한 최고 수준.
  • Tor 성능 최악: 단순 이족 보행에서는 그럭저럭이지만, 개와 랩터에서는 현저히 악화(Raptor Run NCR 0.6141에 불과).
  • MTU 학습 가장 느리지만 잠재력 큼: AUC가 전반적으로 가장 낮지만(Biped Run 0.5360), 실행기 파라미터 최적화 후 Biped Walk에서 최고 NCR(0.9584) 달성, 더 자연스러운 운동 생성.
  • 강건성: PD는 모든 운동에서 외력 교란에 가장 강건; Tor는 이족 보행에서 현저히 취약; MTU는 랩터 달리기에서 가장 비강건. 불규칙 지형 테스트에서 개의 Tor 정책은 '부자연스러운 떨림'으로 인해 오히려 예상외로 강건(저자들은 이 행동이 낙상 감지를 회피한다고 의심).
  • 쿼리 빈도: PD와 Vel은 낮은 쿼리 빈도(15Hz)에서 더 우수, Tor는 가장 빠르게 성능 저하; MTU는 낮은 쿼리 빈도에서 더 좋고 높은 쿼리 빈도에서 더 나쁨.

경계 및 한계

  • 2D 평면 시뮬레이션에만 국한: 모든 결론은 평면 관절 캐릭터 기반, 3D 장면은 검증되지 않았으며 3D에서 토크 제어와 근육 모델의 차이는 더 클 수 있음.
  • MTU 파라미터 최적화가 최적이 아닐 수 있음: 저자들은 CMA 최적화로 얻은 실행기 파라미터가 '여전히 작업 최적이 아닐 수 있다'고 인정, 따라서 MTU와 다른 모델의 비교는 그 잠재력을 과소평가했을 수 있음.
  • 단일 운동에 대한 최적화: 실행기 파라미터는 특정 운동에 대해 최적화되었으며 다중 작업 적응성을 고려하지 않음, 자연계에서는 더 넓은 운동 능력이 기대됨.
  • 하이퍼파라미터 민감성: 탐색률, 공분산 Σ, 보상 가중치 등의 하이퍼파라미터가 결과에 유의미한 영향을 미치며, 저자들은 전체 경향이 일반화될 수 있다고 보지만 확정적 결론은 내릴 수 없음.
  • 수행하지 않은 것: 다른 RL 알고리즘(PPO, SAC 등)이나 운동 제어 작업을 테스트하지 않음; 실행기 역학과 제어 능력의 공동 설계 알고리즘을 개발하지 않음.

공학적 시사점

  • PD 또는 Vel 동작 공간 우선 선택: 빠르게 안정적인 정책을 얻는 것이 목표라면 PD(목표 관절 각도)가 가장 안전한 선택—학습이 빠르고, 강건성이 좋으며, 쿼리 빈도에 둔감. Vel은 PD의 경량 대안으로 단순 작업에서 성능이 유사.
  • 직접 토크 제어 회피: 작업이 극도로 단순하지 않다면(2D 이족 보행 등), Tor 정책은 복잡한 캐릭터에서 성능 저하가 심하고 교란에 극도로 취약. 반드시 사용해야 한다면 더 보수적인 탐색 전략과 더 긴 훈련 시간 필요.
  • MTU는 실행기 최적화와 병행 필요: 근육 모델을 직접 사용하면 거의 항상 학습이 가장 느리지만, 실행기 파라미터 최적화 후 더 자연스러운 운동을 얻을 수 있음. 재현 시 주의: MTU 최적화는 약 50시간(6라운드 CMA)이 소요되며 각 라운드마다 정책을 재훈련해야 하므로 계산 비용이 높음.
  • 핵심 하이퍼파라미터 확인: PTD 업데이트(양의 TD 오차만으로 actor 업데이트)와 탐색 어닐링(ε 1에서 0.2)은 안정적 훈련의 핵심이므로 임의로 변경하지 말 것. 유계 그래디언트 수정은 동작 경계 정의와 일치해야 하며, 그렇지 않으면 정책 평균이 경계에 갇힐 수 있음.
  • 쿼리 빈도 선택: 제어 빈도가 제한된 경우(임베디드 시스템 등), PD 또는 Vel을 우선 선택; MTU를 사용한다면 낮은 쿼리 빈도가 오히려 더 나을 수 있지만 원인은 아직 불명확하므로 직접 검증 필요.
  • 가장 흔한 함정: MTU의 동작 차원은 다른 모델의 두 배 이상(Dog MTU 동작 44차원 vs PD 20차원), 상태 차원도 더 높음(214 vs 170), 네트워크 출력 레이어와 공분산 Σ를 그에 맞게 조정해야 함; 실행기 파라미터(표 1)는 114-282개로 수동 설정이 거의 불가능하므로 반드시 CMA 최적화 사용.
