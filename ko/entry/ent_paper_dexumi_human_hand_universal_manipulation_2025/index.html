DexUMI: Using Human Hand as the Universal Manipulation Interface for Dexterous Manipulation

DexUMI: Using Human Hand as the Universal Manipulation Interface for Dexterous Manipulation

요약

We present DexUMI - a data collection and policy learning framework that uses the human hand as the natural interface to transfer dexterous manipulation skills to various robot hands.

출처

  • arXiv:2505.21864 DexUMI: Using Human Hand as the Universal Manipulation Interface for Dexterous Manipulation
  • GitHub仓库 Robotics_Notebooks

개요

DexUMI는 소프트웨어-하드웨어 협력 방식의 범용 덱스터러스 조작 인터페이스를 제안하며, 인간의 손을 다양한 로봇 핸드의 통합 조작 인터페이스로 사용합니다. 핵심 기여는 웨어러블 외골격(하드웨어 적응)과 비전 복원 파이프라인(소프트웨어 적응)이라는 이중 수단을 통해 인간 손과 다양한 덱스터러스 핸드 간의 동작 차이와 관측 차이를 체계적으로 줄여, 수집된 시연 데이터를 정책 학습에 직접 사용할 수 있게 하는 것입니다. 시스템은 Inspire Hand와 XHand 두 하드웨어 플랫폼, 네 가지 작업에서 평균 86%의 성공률을 검증했습니다.

무엇을 바꾸었는가

덱스터러스 조작 분야는 오랫동안 구현 격차(embodiment gap)에 시달려 왔습니다. 인간 손과 로봇 손의 운동학적 구조, 접촉 표면, 촉각 정보, 시각적 외형의 체계적 차이로 인해 "인간 시연-로봇 실행" 패러다임은 하드웨어 간 일반화가 어려웠습니다. 기존 접근법은 리타게팅 알고리즘과 수동 수정에 의존하거나(예: Dexcap), 실제 로봇 손을 들어 올려 실시간 원격 조작해야 하는 방식(예: 핸드-온 시스템)으로, 데이터 규모, 하드웨어 가용성, 배포 비용 측면에서 명확한 병목이 있었습니다.

DexUMI가 실제로 바꾼 것은 "수집 측"의 패러다임입니다. 사후에 알고리즘으로 인간 손과 로봇 손의 차이를 메우려 하지 않고, 수집 원천에서 하드웨어 외골격으로 인간 손의 운동학을 대상 로봇 손의 구성 공간에 "구속"하는 동시에, 소프트웨어 복원으로 시각 관측의 "인간 손" 픽셀을 "로봇 손" 픽셀로 대체합니다. 이는 수집된 데이터 자체가 "로봇 손 관점"임을 의미하며, 정책 학습은 비교적 깨끗한 데이터 분포에서 직접 수행될 수 있어 복잡한 리타게팅 후처리가 필요 없습니다. 이 접근법은 원격 조작에서 "인간이 로봇에 적응"하는 부담을 하드웨어 설계 단계로 앞당기고, 학습 단계의 데이터 분포 이동 문제를 크게 단순화합니다.

방법 분석

하드웨어 적응: 웨어러블 외골격 설계

  • 이중 최적화 프레임워크: 대상 로봇 손의 URDF를 입력으로 사용하여 외골격 설계 파라미터 p = {j₁,...,jₙ, l₁,...,lₘ}(관절 위치 및 링크 길이)를 최적화하고, 외골격 손끝 작업 공간과 로봇 손 손끝 작업 공간의 유사도를 최대화합니다: S = -(Σₖ min_θ_exo ||F_exo^tip(p, θ_exo) - F_robot^tip(θ_robot,k)||² + Σₙ min_θ_robot ||F_exo^tip(p, θ_exo,n) - F_robot^tip(θ_robot)||²) 첫 번째 항은 외골격이 로봇 손의 작업 공간을 덮도록 보장하고, 두 번째 항은 외골격 작업 공간이 로봇 손 능력을 초과하지 않도록 제약합니다.
  • 언더액추에이티드 핸드 처리: Inspire Hand와 같은 폐루프 메커니즘(4절 링크)을 포함하는 손의 경우 URDF로 직접 표현할 수 없으므로, 모션 캡처 시스템으로 손끝 SE(3) 포즈를 기록하고, 등가 범용 링크 설계를 초기 템플릿으로 사용한 후 동일한 최적화 공식으로 파라미터를 결정합니다.
  • 물리적 구현 세부 사항: 각 손가락의 마지막 링크를 3mm 연장; 관절 한계를 보수적으로 5° 축소(예: XHand 실제 -110°~20°에 대해 외골격 -105°~15°); 엄지 4절 링크 메커니즘을 넓혀 카메라 시야의 중공 영역 제거; PLA-CF 재료 최소 구조 폭 4mm.

센서 통합

  • 관절 엔코더: Alps RDC506018A 회전 센서, ADC 샘플링 후 실시간 전압 정규화(α_joint = V_ADC / V_supply × 360°), UART 전송, 데이터 패킷에 2바이트 헤더 및 체크섬 포함.
  • 손목 자세: iPhone ARKit으로 6DoF 캡처, 데이터 수집에만 사용.
  • 비전: 150° DFoV 광각 카메라 OAK-1을 손목 아래에 장착, 외골격과 로봇 손 카메라 포즈가 완전히 일치.
  • 촉각: XHand는 포함된 자기 기반 촉각 어레이(120포인트 3차원 힘, SPI 인터페이스) 사용; Inspire Hand는 FSR 저항식 센서(분압 회로, V_ADC 판독값을 직접 촉각 입력 대리로 사용).

소프트웨어 적응: 시각 격차 브리징(4단계)

  1. 분할: SAM2로 인간 손과 외골격 픽셀 분할(작업자는 고정 시작 제스처를 유지하고 프롬프트 포인트 재사용; 녹색 장갑 착용으로 분할 보조).
  2. 복원: ProPainter의 플로우 기반 방법으로 제거된 영역을 채워 순수 배경 복원.
  3. 로봇 손 비디오 녹화: 관절 동작 재생, 로봇 손만 녹화, SAM2로 손 픽셀 추출 및 배경 폐기.
  4. 합성: 외골격 마스크와 로봇 손 마스크의 교집합으로 가시 마스크 계산, 해당 마스크 내에서만 로봇 손 픽셀로 복원된 관측을 대체하여 손-물체 가림 관계 유지.

정책 학습

  • 입력: DINO-V2의 CLS 토큰과 촉각 판독값 연결; 출력: 16단계 동작 시퀀스(6-DOF 엔드 이펙터 상대 동작 + N-DOF 손 동작).
  • 정책은 10 Hz로 실행, 16단계를 예측하지만 처음 8단계만 실행; UR5는 125 Hz, Inspire Hand는 10 Hz, XHand는 60 Hz로 실행하며 선형 보간으로 주파수 일치.
  • 상대 손 동작: 현재 모터 위치를 읽고 상대량을 더함; XHand는 가상 현재 위치 사용(평가 시작 시 실제 위치를 읽고 이후 상대 동작 누적)으로 물리적 드리프트 영향 감소.
  • 400 에폭 훈련, DINO-V2는 동결하지 않음, 데이터 증강에는 무작위 크롭, 색상 지터, 무작위 그레이스케일, 가우시안 블러 포함.

핵심 혁신

  1. 하드웨어 수준의 "동작 공간 제약"이지 "동작 리타게팅"이 아님: DexUMI의 외골격은 단순한 데이터 장갑이 아니라, 최적화 프레임워크를 통해 인간 손 운동학을 대상 로봇 손의 손끝 작업 공간에 "투영"합니다. 이로써 수집된 데이터는 자연스럽게 로봇 손의 운동학적 제약을 충족하며, 사후 리타게팅의 오차 누적을 제거합니다. 언더액추에이티드 핸드(Inspire Hand)의 등가 4절 링크 메커니즘 모델링도 실용적 혁신으로, URDF가 폐루프 메커니즘을 표현할 수 없는 문제를 해결합니다.

  2. 시각 수준의 "픽셀 단위 구현 대체": SAM2 + ProPainter로 인간 손 픽셀을 로봇 손 픽셀로 대체하고, 마스크 교집합으로 손-물체 가림 관계를 유지합니다. 이는 단순한 이미지 합성보다 정교합니다—정책이 보는 시각 관측은 픽셀 수준에서 "로봇 손이 조작하는" 것이며, 훈련과 배포의 시각 분포 이동이 체계적으로 압축됩니다. 카메라가 외골격과 로봇 손에서 완전히 동일한 포즈를 가지므로 관측 일관성이 더욱 보장됩니다.

  3. 상대 동작 표현의 견고성 발견: 실험에서 상대 손가락 궤적이 절대 궤적보다 일관되게 우수함을 보여줍니다(예: Cube 작업 1.00 vs 0.10). 상대 동작은 반응형 행동을 학습합니다—증분이 지속적으로 누적되어 핵심 이벤트(예: 손가락 접촉 폐쇄)가 발생할 때까지 진행되며, 하드웨어 백래시와 노이즈에 더 견고합니다. 이 발견은 덱스터러스 조작 정책의 동작 표현 설계에 직접적인 지침을 제공합니다.

실험 및 결과

핵심 결론: - 완전한 DexUMI(상대 동작 + 촉각 + Inpaint)는 두 손, 네 가지 작업에서 평균 성공률 86%. - 상대 궤적이 절대 궤적보다 일관되게 우수; 시각 복원(Inpaint)이 Mask와 Raw보다 현저히 우수(Cube: 0.95 vs 0.60 vs 0.20). - 촉각의 역할은 작업 의존적: 소금 집기 작업에서 촉각이 현저한 향상(0.15 → 0.75)을 가져오는데, 센서가 손가락이 소금 그릇에 닿을 때 명확한 판독값을 주고 시각이 그릇에 가려지기 때문; 집게 조작에서는 촉각이 도움이 되지 않음(집게를 잡으면 최소 판독값만 발생). - XHand 촉각 센서는 고압력 후 드리프트가 발생하여 대부분의 경우 촉각을 추가하면 오히려 성능이 저하; Inspire Hand의 수동 설치 FSR은 노이즈가 더 커서 모든 방법에서 촉각 추가 시 성능이 하락. - 데이터 수집 효율: DexUMI는 맨손보다 느리지만, 기존 원격 조작보다 3.2배 효율적(15분 세션, 차 도구 집기 작업).

경계 및 한계

  • 하드웨어 일반화 제한적: 각 로봇 손에 대해 전용 외골격을 설계해야 하며, 최적화 프레임워크는 여전히 하드웨어 특정 튜닝이 필요(특히 착용성); 현재 공식은 손끝 작업 공간만 일치시키며 손바닥 등 다른 접촉 기하학은 모델링하지 않음.
  • 촉각 센서 신뢰성이 명확한 약점: Inspire Hand의 FSR은 설치 방식에 민감하고, XHand의 자기 기반 센서는 고압력 후 드리프트; 인간 손이 생성하는 힘이 로봇 손보다 커서 외골격 조작 시 촉각 판독값이 자주 드리프트.
  • 3D 프린팅 재료 강도 부족: 인간 손이 외골격 링크를 약간 비틀 수 있으며, 엔코더가 이 변형을 포착할 수 없어 로봇 손가락 위치와 외골격 실제 위치가 정렬되지 않음.
  • 소프트웨어 적응에도 실제 로봇 하드웨어 필요: 동작을 재생하여 로봇 손 비디오를 녹화해야 하며, 순수 생성적 대체는 아직 미구현; 조명 효과를 완전히 재현할 수 없어 일부 복원 영역이 흐릿함.
  • 카메라는 강체로 고정되어야 함: 이동 카메라 미지원; 로봇 손과 인간 손의 크기 차이가 너무 클 경우(예: 2배), 착용성이 무효화.
  • 하드웨어 정밀도 제한: Inspire Hand와 XHand 모두 백래시와 마찰로 인해 충분한 정밀도가 부족하며, 회귀 모델은 일반적으로 "한 방향" 정밀도만 보장; XHand의 모터-손끝 매핑은 시간이 지나거나 재시작 후 차이가 발생.

공학적 시사점

  • 정책 논의 전에 하드웨어 정밀도부터 확인: Inspire Hand와 XHand의 모터 백래시는 체계적 오차이므로, 엔코더-모터 회귀 모델을 피팅할 때 양방향 정밀도를 반드시 검증하세요. 단방향 정밀도만 보장된다면 정책에서 상대 동작 표현을 통일적으로 사용하는 것이 좋습니다—실험에서 상대 궤적이 하드웨어 노이즈에 대한 견고성이 절대 궤적보다 훨씬 우수함이 입증되었습니다.
  • 촉각 센서가 가장 큰 함정: XHand의 자기 기반 센서는 고압력 후 드리프트, Inspire Hand의 FSR은 설치에 극도로 민감. 재현 시 압력-판독 안정성 테스트를 먼저 수행하고, 센서가 신뢰할 수 없다면 촉각을 아예 추가하지 않는 것이 좋습니다—대부분의 작업에서 노이즈 촉각이 오히려 성능을 낮추며, 상대 궤적만이 노이즈 촉각에서 이점을 얻을 수 있습니다.
  • 시각 복원 품질이 정책 상한을 직접 결정: Raw 관측(인간 손 가시)은 Cube 작업에서 0.20 성공률에 불과하지만, Inpaint 후 0.95에 도달. SAM2 분할이 불완전하면 외골격의 작은 영역이 누락될 수 있으므로, 인쇄 재료와 같은 색상의 장갑을 착용하여 분할을 보조하는 것이 좋습니다; 훈련 시 반드시 가우시안 블러와 색상 지터 증강을 추가하여 복원 흐림과 조명 불일치에 대응하세요.
  • 데이터 정렬이 잠재적 핵심 요소: 카메라, 엔코더, 촉각의 지연을 정밀하게 측정해야 합니다(QR 코드 방식으로 카메라 지연 측정, 오버레이 그림 방식으로 엔코더 지연 조정). 그렇지 않으면 정책이 학습하는 시계열 관계가 잘못됩니다. XHand 촉각은 30 FPS 이상에서 불안정하므로, 기록 주파수를 하드웨어에 맞게 조정해야 합니다.
  • 동작 실행 주파수 일치: 정책은 10 Hz로 16단계 예측을 출력하지만 처음 8단계만 실행하며, UR5 125 Hz, Inspire Hand 10 Hz, XHand 60 Hz는 선형 보간으로 일치시켜야 합니다. XHand는 가상 현재 위치로 상대 동작을 누적하여 물리적 드리프트 영향을 줄이는 것이 좋습니다.
