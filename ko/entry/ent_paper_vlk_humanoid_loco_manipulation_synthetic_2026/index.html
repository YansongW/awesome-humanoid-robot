VLK: Learning Humanoid Loco-Manipulation from Synthetic Interactions in Reconstructed Scenes

VLK: Learning Humanoid Loco-Manipulation from Synthetic Interactions in Reconstructed Scenes

초안

요약

Perception-based humanoid loco-manipulation requires connecting egocentric observations and task instructions to whole-body motion. Learning this mapping requires synchronized egocentric images, language commands, and robot-compatible kinematic trajectories, yet no existing data source provides this complete tuple at scale. Institutions per source list: UC Berkeley、CMU、Shanghai AI Lab.

출처

  • arXiv:2606.30645 VLK: Learning Humanoid Loco-Manipulation from Synthetic Interactions in Reconstructed Scenes
  • GitHub仓库 Robotics_Notebooks

개요

본 논문은 VLK 시스템을 제안하며, 실제-시뮬레이션-실제 파이프라인을 통해 3DGS 재구성 장면에서 대규모 시각-언어-운동학 삼중항 데이터를 합성하여 Unitree G1 휴머노이드 로봇의 인식-위치추정-조작 정책을 훈련한다. 핵심 기여는 3DGS 장면 재구성과 전신 운동 추적을 완전한 데이터 생성 시스템으로 연결하여, 인간 시연 없이 종단 간 언어 명령 기반 조작을 구현하고 120회의 실제 세계 실험에서 타당성을 검증한 것이다.

무엇을 바꾸었는가

휴머노이드 로봇의 위치추정-조작 학습은 오랫동안 데이터 부족에 시달려 왔다: 실제 원격 조작은 비용이 높고 확장이 어려우며, 인간 모션 캡처는 로봇의 자기중심 관측이 부족하고, 자기중심 비디오는 로봇 호환 운동학이 부족하다. 저자가 실제로 바꾼 것은 데이터 생성 패러다임이다—더 이상 인간 시연이나 실제 데이터 수집에 의존하지 않고, 3DGS로 실제 장면을 재구성하고, 상호작용 궤적을 합성하며, 자기중심 관측을 렌더링하여 세 가지 파편화된 솔루션(장면 재구성, 운동 합성, 시각 렌더링)을 폐쇄 루프 데이터 공장으로 통합한다. 이러한 전환은 훈련 데이터를 필요에 따라 생성하고 무한히 확장할 수 있게 하며, 자연스럽게 시각-언어-운동학 정렬을 갖추어, 이전 데이터 소스가 삼중항을 동시에 제공할 수 없던 근본적 모순을 해결한다.

방법 분석

데이터 생성 파이프라인 3단계

  1. 장면 재구성 및 주석: iPhone 14 Pro Polycam 스캔(RGB+LiDAR 깊이)으로 미터 단위 3DGS 장면 재구성; 포인트 클라우드 추출, viser 도구로 수동 의미론적 3D 경계 상자(의자/테이블/상자 등 객체 클래스) 및 보행 가능 영역 다각형 주석.
  2. 상호작용 합성: 내비게이션 모델은 BONES-SEED의 G1 운동으로 훈련; 상호작용 모델은 OMOMO 시퀀스를 OmniRetarget으로 G1에 리타겟팅하여 훈련. 상호작용 합성은 CHOIS/HiHi 조건 확산 공식 기반, 추가 조건에는 초기 객체 상태, 객체 기하( BPS 표현+MLP 투영), 기대 상대 손목 자세(객체 좌표계 정의) 및 손목 접촉 라벨 포함.
  3. 자기중심 렌더링: Isaac Sim에서 합성 G1 궤적 재생, 3DGS 장면 로드, 가상 ZED 2i 카메라를 머리에 장착(외부 파라미터 보정이 실제 카메라와 일치); 도메인 무작위화 적용(조명 변화, 카메라 외부 파라미터 및 초점 거리 섭동, 이미지 공간 증강).

운동 표현 및 정책 아키텍처

  • 운동학 상태: x_τ = [Δx_τ, Δy_τ, Δψ_τ, h_τ, R^root_τ, sin(q_τ), cos(q_τ), c_τ], 여기서 c_τ는 좌우 손목-객체 접촉 라벨(∈{0,1}), 배포 시 자기회귀 예측이지 직접 관측이 아님.
  • 객체 궤적: X_obj = [o, R_obj], o는 전역 객체 위치, R_obj는 입력 객체 기하에 상대적인 6D 회전.
  • VLK 정책: 입력은 현재 자기중심 RGB 관측 o_t, 언어 명령 ℓ, 현재 운동학 상태 x_t; 출력은 H=30프레임 미래 궤적(30Hz에서 1초). 사전 훈련된 π_0.5에서 초기화, 전체 모델 미세 조정; 흐름 매칭 x_0 예측 목표, 재구성 손실 L_traj = ||x̂ − x||²₂.
  • 보조 손실: 발-지면 접촉 예측(포컬 손실), 누적 루트 궤적 일관성, 순방향 운동학 정밀도(발목/손목, 가중치 1.0), 발 미끄러짐 정규화(가중치 0.05).

후처리 및 배포

  • 발 미끄러짐 보정: 예측 발 접촉 라벨로 접촉 단계 식별, 각 단계 내에서 역운동학으로 발이 접촉 위치에 고정되도록 제약.
  • 손-객체 접촉 최적화: EgoAllo 최적화 방법을 각색, 손목 위치와 회전을 객체 로컬 좌표계의 입력 손목 자세로 구동.
  • 배포 시스템: Triton 추론 백엔드, VLK는 RTX 5090(종단 간 31ms), 전신 추적은 RTX 5000 Ada(50Hz, 틱당 4.3ms); 인접 동작 블록 10프레임 중첩; 라플라시안 분산 기반 선명도 프레임 선택으로 모션 블러 대응.

핵심 혁신

  1. 합성 데이터 폐쇄 루프: 처음으로 3DGS 장면 재구성과 전신 운동 추적을 완전한 데이터 생성 시스템으로 연결하여 실제-시뮬레이션-실제 폐쇄 루프를 구현. 이전 파편화 솔루션과 달리, 이 시스템은 필요에 따라 임의 규모의 쌍 데이터를 생성하고 자연스럽게 시각-언어-운동학 정렬을 보장.
  2. 접촉 라벨 자기회귀 예측: 배포 시 손목-객체 접촉을 직접 관측할 필요 없이 정책이 자기회귀로 접촉 라벨을 예측하여 추가 센서 의존을 피하면서 객체 상호작용의 안정적 제어를 유지.
  3. 미분 가능 순방향 운동학 계층: 훈련 손실에 미분 가능 FK 계층을 도입하여 전역 신체 및 말단 실행기 위치에 기하학적 제약을 부과, 생성 궤적의 물리적 타당성과 손목 배치 정밀도를 크게 향상—순수 관절 각도 공간 훈련으로는 달성하기 어렵다.

핵심 소거 실험

  • 접촉 라벨 필요성: 접촉 라벨이 없는 Pick (Floor)는 실제 세계 두 장면 모두 성공률 0/5, 접촉 라벨이 조작 안정성에 결정적임을 증명.
  • 데이터량 영향: Pick (Surface)는 데이터 10%에서 성공률 0%에서 전체 데이터셋에서 46%로 향상, 복잡한 작업에 대한 데이터 규모의 결정적 역할을 보여줌.
  • 도메인 무작위화: 보행 모드 성공률이 무작위화 없음 41%에서 전체 무작위화 90%로 향상, 조명 무작위화 단일 기여가 가장 큼(87%, 원문 Table 수치).

경계 및 한계

상호작용 합성은 OMOMO 적용 범위 제한으로 유한한 대형 객체 상호작용만 포함하며, 생성된 행동은 컵이나 도구 같은 소형 객체를 잡기보다 양손으로 상자형 객체를 운반하는 데 더 적합. 접촉 인식 추적기는 대형 객체 조작을 안정화하지만 정밀한 객체 파지에는 대응하지 않음. 표면 수준 상호작용(Pick/Put Surface) 신뢰성은 상대적으로 낮으며, 부분적으로는 리타겟팅된 상호작용 데이터가 다양한 지지면 높이의 상자 조작에 대한 적용 범위가 제한적이기 때문. 논문은 실제 세계 실패 사례 분류, 다른 로봇 플랫폼으로의 일반화, 보지 못한 객체 클래스나 장면 레이아웃에 대한 일반화 능력, 장시간 배포 안정성 문제를 명시적으로 논의하지 않음.

공학적 시사점

재현 시 세 가지를 우선 확인: 첫째, 장면 재구성 품질—3DGS 최적화 수렴 여부, 의미론적 주석 정확성, 이는 합성 데이터 품질에 직접 영향; 둘째, 도메인 무작위화 구성—조명 무작위화가 성공률 향상에 가장 큰 기여(41%→87%), 반드시 완전히 구현; 셋째, 접촉 라벨 생성 및 예측—이는 조작 안정성의 핵심, 접촉 라벨이 없으면 Pick (Floor) 실제 세계 성공률이 직접 0이 됨. 가장 함정에 빠지기 쉬운 부분: OMOMO의 G1 리타겟팅 운동 품질(리타겟팅 후 궤적의 물리적 타당성 먼저 검증 권장), 배포 시 모션 블러 처리(선명도 프레임 선택 창 0.3s는 추론 빈도와 일치해야 함), 비동기 블록 병합의 타이밍 동기화(병합 단계는 3.4ms 기여, 50Hz 추적 루프를 차단하지 않도록 보장). 데이터 생성 비용은 환경당 약 600 GPU 시간, 소규모로 파이프라인 정확성을 먼저 검증한 후 전체 생성 권장.

관련 개체

방법

행동 클로닝

전문가 시연을 모방하도록 정책을 지도학습하는 모방 학습 방법으로, 로봇 기술 학습의 기준선으로 자주 사용됨.

 방법

전신 제어(WBC)

휴로봇의 모든 관절과 접촉점을 조율하여 균형·시선·조작 등 다중 작업을 동시에 수행하는 제어 프레임워크.

 방법

정욕동학

주어진 관절 각도로부터 동차 변환 사슬 또는 지수곱을 이용해 말단 동작기 위치·방향을 계산하는 방법.

 방법

도메인 랜덤화

훈련 중 시뮬레이션 파라미터를 무작위화하여 실제 세계의 모델 불일치에 대한 정책 강건성을 높이는 Sim-to-Real 기법.

 방법

시뮬-실제 전이

시뮬레이션에서 학습한 정책·컨트롤러를 실제 로봇으로 전이하는 기술; 도메인 랜덤화·시스템 동정·적응 등을 사용.
