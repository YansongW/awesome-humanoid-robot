능동 공간 뇌와 일반화 가능한 동작 소뇌를 통한 휴머노이드 전신 조작

Humanoid Whole-Body Manipulation via Active Spatial Brain and Generalizable Action Cerebellum

대기 중

요약

본 논문은 능동 공간 지각 및 계획을 담당하는 능동 공간 뇌와 하지 이동·상지 정교 조작으로 분리된 일반화 가능한 동작 소뇌를 결합한 다중 에이전트 프레임워크를 제안하여, 작업별 실제 로봇 데이터 없이 공간 인식형 휴머노이드 전신 조작을 수행하고 공간 지능 벤치마크와 실제 Unitree G1 휴머노이드 로봇으로 검증한다.

출처

  • Humanoid Whole-Body Manipulation via Active Spatial Brain and Generalizable Action Cerebellum

개요

본 논문은 실제 로봇 데이터 없이 작동하는 휴머노이드 전신 조작 프레임워크를 제안하며, "능동 공간 뇌"(Active Spatial Brain)와 "일반화 가능한 동작 소뇌"(Generalizable Action Cerebellum)의 계층적 다중 에이전트 아키텍처를 채택한다. VLM의 공간 추론 및 일반화 지식을 활용하여 공간 인식, 작업 계획 및 동작 생성을 수행한다. 시스템은 Unitree G1 로봇에서 검증되었으며, 다양한 공간 인식 작업에서 데이터 기반 베이스라인보다 현저히 우수한 성능을 보였고, 특히 하드(hard) 시나리오에서 성공률이 크게 향상되었다.

무엇을 바꾸었는가

이 작업의 핵심 변화는 휴머노이드 전신 조작을 "데이터 기반" 패러다임에서 "모델 기반 + 공간 추론" 패러다임으로 전환한 것이다. 기존 방법(TrajBooster, Ψ₀ 등)은 대규모 실제 로봇 궤적 데이터에 의존하며, 데스크톱 시나리오에서는 유효하지만 휴머노이드 로봇으로 확장할 때 관측 공간(RGB-D+고유수용감각)과 행동 공간(카메라, 다섯 손가락 로봇 손, 상하반신)이 급격히 팽창하여 데이터 수집 비용과 분포 이동 문제가 병목이 된다. 본 논문은 데이터 병목을 직접 우회하여 VLM의 공간 지능으로 데이터 기반 인식 및 계획을 대체하고, 파라미터화된 동작 프리미티브로 학습 기반 동작 생성을 대체함으로써 제로 실제 로봇 훈련 데이터 조건에서 교차 시나리오 일반화를 달성한다.

더 중요하게는, 이는 조작 작업에서 "공간 인식"의 역할을 바꾼다. 더 이상 고정 시점의 수동적 관측이 아니라, 능동 카메라 운동(2자유도 목 + 4자유도 베이스)을 결정 변수로 삼아 VLM이 작업 단계에 따라 시점을 동적으로 조정하게 한다. 이러한 "인식이 곧 행동" 설계는 시스템이 능동적으로 폐색을 제거하고 더 포괄적인 공간 정보를 획득할 수 있게 하며, 이는 데이터 기반 방법으로는 구현하기 어렵다. 동시에, 세밀한 측정 작업(예: 웨이포인트 생성)을 VLM에서 분리하여 결정론적 알고리즘(격자 지도 + A* + RDP)에 맡김으로써 VLM의 정밀 측정 약점을 회피한다.

방법 분석

전체 아키텍처: 계층적 폐루프 다중 에이전트

시스템은 긴밀하게 결합된 두 구성 요소로 폐루프를 형성한다: Active Spatial Brain(VLM 기반)은 공간 인식, 작업 분해 및 의사 결정을 담당하고, Generalizable Action Cerebellum(MLLM + 파라미터화된 프리미티브)은 실행 가능한 동작 생성을 담당한다. Brain은 장기 목표를 하위 작업 시퀀스로 분해하고, Cerebellum의 에이전트를 단계적으로 호출하며, 피드백을 Brain에 반환하여 작업이 완료될 때까지 반복한다.

능동 공간 인식(Active Spatial Perception)

  • 사전 정의된 행동 공간: 2자유도 카메라 목 운동 + 4자유도 베이스 운동(x, y, z 병진 + z축 회전).
  • VLM은 RGB-D 관측과 작업 명령에서 직접 시점 결정을 내리며, 명시적 3D 재구성이 필요 없다.

메모리 뱅크(Memory Bank)

  • 혼합 기록 운동 조건화 전략: 마지막 베이스 이동 이후 인식 모듈이 캡처한 이미지만 아카이브하고, 각 이미지의 카메라 포즈를 대응시킨다.
  • 동시에 Brain이 Cerebellum에 보낸 모든 명령과 피드백을 기록하는 텍스트 로그를 유지한다.
  • 설계 근거: 선택적 이미지 아카이브는 정보 중복을 피하고, 전역 텍스트 로그는 VLM이 작업 단계를 정확히 추론하고 공간 인식 일관성을 유지할 수 있게 한다.

적응형 작업 계획(Adaptive Task Planning)

  • 각 단계에서 시퀀스와 메모리 뱅크를 평가하여 두 가지 동작 중 하나를 트리거한다: (i) 능동 시점 조정; (ii) 하위 에이전트 호출.
  • 동적 재계획 지원: 그리핑 실패 감지 시 조작 에이전트를 자동으로 다시 호출하여 두 번째 시도를 수행한다.

하반신 운동(Lower-Body Locomotion)

  • 내비게이션 에이전트: 깊이 맵 → 카메라 좌표계 3D 포인트 집합 → 지면 이산 격자 맵(격자 크기 d). 점유 판정: 𝒢(i,j)=1 (∃𝐱∈𝒞_ij, z(𝐱)>h인 경우), 그 외 0. A* 알고리즘으로 충돌 없는 경로 계산, RDP 알고리즘으로 단순화하여 웨이포인트 시퀀스 {𝐩_i} 생성, 폐루프 추적으로 v_x,t와 ω_y,t 계산, 공칭 베이스 높이 h_t 유지.
  • 엔드 이펙터 도달 가능 공간 솔버: 최적화 목표 min λ₁‖Δ𝐝‖²₂ + λ₂(Δz)² + λ₃‖𝐩_obj(𝐩_t,Δ𝐝,Δz)−𝐩_shoulder(Δz)‖²₂, 제약 ‖𝐩_obj−𝐩_shoulder‖₂≤ηL (η=0.8 안전 여유). MuJoCo 시뮬레이션으로 운동학적 오프셋 모델 Φ(z)=(δx(z),δz(z)) 추정.
  • RL 정책: HOMIE 방법 채택, 입력 고유수용감각 상태 s_t 및 베이스 명령 c_t=[v_x,t,ω_y,t,h_t], 출력 a_lower,t=π_loco(s_t,c_t).

상반신 손재주 조작(Upper-Body Dexterous Manipulation)

  • 그리핑 포즈 생성: 다중 모달 기반 생성 모델로 손-물체 상호작용 이미지 Î_ho 생성 → Hyper3D로 3D 메시 ℳ_o 생성 → EasyHOI로 MANO 손 포즈 𝒢_mano 추정 → 손끝 정렬 리타겟팅, 최적화 min Σ_k‖p_dex,ft_k−p_mano,ft_k‖²₂.
  • 그리핑 후 궤적 생성: 대형 모델이 의미론적 2D 키포인트를 예측하고 동작 프리미티브를 선택하며, 키포인트를 3D로 승격시킨 후 프리미티브 운동학 규칙에 따라 6-DoF 엔드 이펙터 포즈를 도출한다. 네 가지 프리미티브: Push(선형 병진), Pull(선형 병진), Place(손-물체 공간 오프셋 유지), Rotate(피벗 기반 국소 회전). 모든 프리미티브는 정렬 단계로 시작하며, IK 솔버가 연속 포즈를 관절 명령으로 변환한다.

핵심 혁신

  1. 제로 실제 로봇 데이터의 전신 조작 프레임워크: 데이터 기반 패러다임을 완전히 우회한 최초의 휴머노이드 전신 조작 솔루션. 기존 방법(TrajBooster, Ψ₀)은 작업당 최소 20개 궤적 미세 조정이 필요하지만, 본 논문은 작업별 실제 데이터 훈련이나 미세 조정 없이 VLM의 사전 훈련 지식을 직접 활용하여 교차 시나리오 일반화를 달성한다. 이는 데이터 수집 비용이 높은 휴머노이드 로봇 분야에서 패러다임적 의미를 가진다.

  2. 능동 공간 인식과 메모리 뱅크의 폐루프 설계: 카메라 운동을 결정 변수에 포함시켜 시스템이 능동적으로 폐색을 제거하고 더 포괄적인 공간 정보를 획득할 수 있게 한다. 혼합 기록 운동 조건화 전략(베이스 이동 후 이미지만 아카이브 + 전역 텍스트 로그)은 정보 완전성과 계산 효율성 사이의 균형을 이루며, VLM이 작업 단계를 정확히 추론할 수 있게 한다 — 이는 데이터 기반 방법으로는 구현하기 어려운 "인식이 곧 행동" 능력이다.

  3. VLM 고수준 계획과 결정론적 알고리즘의 세밀한 실행 분리: 웨이포인트 생성과 같은 정밀 측정이 필요한 작업을 VLM에서 분리하여 격자 맵 + A* + RDP와 같은 결정론적 알고리즘에 맡기고, 그리핑 포즈 생성을 Hyper3D + EasyHOI와 같은 전용 기반 모델에 맡긴다. 이러한 "VLM은 의사 결정, 전용 모델은 실행" 분업은 VLM의 세밀한 측정 약점(Task 3 최고 Appropriate율 64.91%)을 회피하면서 VLM의 일반화 능력을 유지한다.

VLM 공간 지능 벤치마크(표 4)

  • Task 1(이미지 격자 매핑): gemini-3.1-pro 정확도 최고(98.84%), qwen3.5-plus 가장 느림(155.63초).
  • Task 2(능동 인식): gemini-3.1-pro 성공률 최고(94.11%), 관측 횟수 최소(2.00회).
  • Task 3(웨이포인트 생성): gemini-3.1-pro의 Appropriate율 최고(64.91%)지만 여전히 21.05%의 Fail율 — VLM의 세밀한 측정 병목을 확인시켜 준다.

경계와 한계

논문은 별도의 "Limitations" 섹션을 두지 않았으며, 내용에서 다음 경계를 추론할 수 있다: - 단순 시나리오에서 우위 제한적: easy 작업에서 본 프레임워크는 Ψ₀, CaP와 큰 차이가 없으며(일부 작업 동률), 저난이도 시나리오에서 데이터 기반 방법이 여전히 경쟁력이 있음을 시사한다. - VLM 측정 인식 병목: Task 3 웨이포인트 생성 최고 Appropriate율이 64.91%에 불과하고 Fail율이 여전히 21.05%로, VLM의 정밀 공간 측정 능력이 제한적임을 보여준다. 본 프레임워크는 분리를 통해 이 문제를 회피하지만, VLM 자체의 능력이 여전히 시스템의 상한이다. - 동적 환경 미포함: 이동 장애물, 동적 목표 등의 시나리오는 언급되지 않았으며, 현재 설계는 정적 환경을 가정한다. - 다중 객체 및 장기 작업 미검증: 다중 객체 복잡 조작이나 장시간 연속 다중 작업 실행은 다루지 않았다. - 플랫폼 이전 미검증: Unitree G1 + Inspire FTP 다섯 손가락 로봇 손 + Realsense D435i에서만 검증되었으며, 다른 로봇 손 모델이나 휴머노이드 플랫폼은 테스트되지 않았다.

공학적 시사점

  • VLM 선택을 먼저 확인하라: 표 4는 gemini-3.1-pro가 공간 추론(Task 1/2)에서 전반적으로 우세하지만, qwen3.5-plus는 속도에서 뚜렷한 이점(Task 2 시간 32.15초 vs gemini-3.1-pro의 44.73초)을 보여준다. 실시간 요구사항이 높다면 정밀도와 속도 사이의 균형이 필요하다.
  • 가장 함정에 빠지기 쉬운 지점: VLM의 세밀한 측정 능력(Task 3)이 시스템 병목이며, 최고 Appropriate율이 64.91%에 불과하다. 재현 시 반드시 "VLM은 고수준 의사 결정, 결정론적 알고리즘은 세밀한 실행"의 분리 설계를 유지하고, VLM이 정밀 웨이포인트나 포즈를 직접 출력하도록 시도하지 말아야 한다.
  • 능동 인식(AP)과 엔드 이펙터 도달 솔버(EES)는 둘 다 필수: 소거 실험은 둘을 결합했을 때 최상의 효과(67.5%/70.0%)를 보여주며, 단독 사용 시 성능이 크게 저하된다. 재현 시 두 모듈이 모두 올바르게 구현되었는지 확인해야 하며, 특히 EES의 MuJoCo 운동학적 오프셋 모델 Φ(z) 캘리브레이션이 중요하다.
  • hard 시나리오가 핵심 가치: 본 프레임워크는 Task4(장애물 회피) hard 시나리오에서 0%에서 60%로, Task3(높이+위치) hard 시나리오에서 10%에서 55%로 향상시켰다. 하위 작업이 주로 단순 데스크톱 조작이라면 본 프레임워크의 우위는 제한적이며, 데이터 기반 솔루션을 고려할 수 있다.
  • 메모리 뱅크 설계 주의: 혼합 기록 전략(베이스 이동 후 이미지만 아카이브 + 전역 텍스트 로그)은 공간 인식 일관성의 핵심이다. 재현 시 카메라 포즈와 이미지의 정밀한 정합을 보장해야 하며, 그렇지 않으면 VLM의 공간 추론이 왜곡될 수 있다.
