요약

OneTwoVLA: A Unified Vision-Language-Action Model with Adaptive Reasoning (OneTwoVLA), is a 2025 large vision-language-action model for robotic manipulation, introduced by Tsinghua University, Shanghai Qi Zhi Institute, Shanghai Artificial Intelligence Laboratory, Fudan University, Spirit AI.

출처

  • OneTwoVLA: A Unified Vision-Language-Action Model with Adaptive Reasoning (arXiv)
  • OneTwoVLA source

개요

OneTwoVLA는 로봇 조작 작업을 위한 통합 비전-언어-액션 모델로, 핵심 설계는 모델이 추론과 액션 두 가지 모드 사이에서 적응적으로 전환하여 장기 작업에서 추론 내용을 명시적으로 출력하고 액션 실행 중에는 효율성을 유지하는 것입니다. 이 작업은 π₀ 아키텍처를 기반으로 하며, [BOR]/[BOA] 토큰, 참조 이미지 입력, 합성 데이터 증강 및 상호작용 명확화 훈련을 도입하여 실제 Franka 및 ARX 플랫폼에서 추론-액션 일관성, 다중 모드 액션 생성 능력 및 배포 효율성을 검증했습니다.

무엇을 바꾸었는가

기존 VLA 모델(예: π₀)은 실제 조작에서 근본적인 모순에 직면합니다. 액션만 출력하여 작업 의미론에 대한 명시적 추론이 부족하여 장기 작업에서 계획 조정이나 상호작용 명확화가 불가능하거나, 추론을 도입하더라도 추론 과정이 액션 생성과 너무 밀접하게 결합되어 배포 시 계산 오버헤드를 제어할 수 없습니다. OneTwoVLA가 실제로 바꾼 것은 '추론'을 액션 생성의 암시적 동반 상태에서 분리하여 명시적으로 트리거하고 독립적으로 시간을 측정할 수 있는 모드로 만든 것입니다. 이는 모델이 더 이상 모든 제어 주기에서 심층 추론을 강제로 수행하지 않고, 중요한 순간(작업 전환, 명령 모호성, 오류 복구 등)에만 추론 모드로 전환하며, 나머지 시간은 순수 액션 모드로 실행하여 인지 능력과 실시간성 사이에서 공학적으로 수용 가능한 균형을 달성함을 의미합니다.

또 다른 중요한 변화는 데이터 측면에 있습니다. 저자는 실제 시연에만 의존하지 않고 Gemini 2.5 Pro를 사용하여 16,000장의 합성 이미지를 생성했으며, 그중 6,000장은 시각적 접지, 10,000장은 장기 계획에 사용하고 어안 왜곡과 합성 그리퍼 증강을 적용했습니다. 이는 사실상 '추론 능력'을 비전-언어 사전 훈련 모델에서 로봇 정책으로 증류하려는 시도로, 모델이 보지 못한 물체에서도 일정 수준의 일반화를 유지할 수 있게 하지만, 실험 결과 이러한 일반화는 여전히 취약함을 보여줍니다.

방법 분석

이중 모드 아키텍처

모델은 π₀를 기반으로 구축되며, 입력은 현재 이미지 I_t, 참조 이미지 I_ref(최신 추론 내용에 해당하는 관측), 그리고 고유 감각 상태(현재, 0.05초 전, 0.25초 전 세 시점)입니다. 출력 측에는 두 개의 특수 토큰이 도입됩니다: - [BOR]: 추론 시작, 모델이 업데이트된 추론 내용 R̂ 출력 - [BOA]: 액션 시작, 모델이 액션 시퀀스 출력

데이터 분할 훈련

시연 데이터는 두 가지 유형의 구간으로 나뉩니다: - 추론 구간: 모델이 [BOR] → 추론 업데이트 → [BOA] → 액션 예측을 학습하며, 추론이 적시에 업데이트되지 않을 때 이전 추론을 기반으로 액션을 예측하는 것도 학습 - 액션 구간: 모델이 [BOA] → 액션 예측을 학습하고, 선택적으로 오래된 추론을 기반으로 [BOR]을 예측하여 결정 토큰 예측의 클래스 불균형 완화

배포 시퀀스 통합

액션 모드에서 정책은 0.2초마다 시간적으로 중첩되는 액션 시퀀스를 생성하며, 실제 실행 액션은 여러 예측의 지수 가중 평균을 통해 계산되어 부드러움을 보장합니다. 추론 모드는 중요한 순간에만 트리거되며, 추론 토큰 수가 20 미만일 때 실행 효율성에 영향을 미치지 않습니다.

합성 데이터 및 오류 복구

  • 합성 이미지 16,000장: 6,000장 시각적 접지(각각 17쌍의 명령-추론 쌍), 10,000장 장기 계획
  • 오일 병 미끄러짐, 스키머 그리퍼 실패 등 특정 실패 시나리오를 위한 복구 데이터 별도 수집
  • 장기 작업에서 명령이 모호할 때 모델이 능동적으로 질문하여 명확화하도록 훈련(예: "어떤 칵테일을 원하십니까?")

훈련 구성

각 작업은 8×H100 GPU에서 30,000스텝, 약 10시간 훈련하며 π₀의 하이퍼파라미터를 사용합니다.

핵심 혁신

  1. 추론-액션 분리 이중 모드 설계: 기존 VLA와 가장 본질적인 차이점입니다. 모델은 모든 제어 주기에서 추론하는 대신 추론 모드와 액션 모드 사이를 명시적으로 전환할 수 있습니다. 이를 통해 장기 작업에서 인지 오버헤드가 총 시간의 약 10%로 압축되며(Tomato-Egg 작업에서 추론 8.7%, Mountain Fuji 작업에서 10.4%), 액션 모드의 계산 시간은 π₀보다 약 0.02초만 더 소요됩니다(0.082초 → 0.102초).

  2. 참조 이미지 입력 메커니즘: 추론 모드에서 모델은 I_ref(최신 추론 내용에 해당하는 이미지 관측)를 수신하여 오래된 텍스트 설명과 현재 시각적 입력 간의 혼동을 방지합니다. 이는 공학적으로 매우 영리한 세부 사항입니다. 추론 내용이 환경 변화보다 지연될 수 있음을 인정하고 시각적 앵커로 능동적으로 교정합니다.

  3. 합성 데이터 기반 추론 능력 증류: Gemini 2.5 Pro를 사용하여 합성 이미지와 명령-추론 쌍을 생성하여 대규모 언어 모델의 비전-언어 추론 능력을 로봇 정책으로 전이합니다. Open-World 시각적 접지 성공률이 여전히 낮지만(3/40), 이는 대규모 실제 로봇 데이터가 부족한 연구 커뮤니티에 재현 가능한 경로를 제공합니다.

실험 및 결과

시각적 접지 작업 (표 3)

설정 OneTwoVLA-VL OneTwoVLA π₀
Single-Env 35/40 31/40 2/40
Open-World 29/40 3/40 1/40

OneTwoVLA-VL은 Single-Env에서 87.5%(표 내 35/40 계산) 성공률을 달성하여 π₀의 5%(표 내 2/40 계산)보다 크게 우수합니다. 그러나 Open-World에서 OneTwoVLA(VL 미세 조정 없음)는 3/40에 불과하여 합성 데이터가 시각적 접지 일반화에 기여하는 바가 제한적이며, 모델이 여전히 작업 내 미세 조정에 의존함을 보여줍니다.

다중 모드 액션 실험

  • "큐브 잡기": OneTwoVLA는 왼쪽 9회, 오른쪽 11회 잡음; π₀는 항상 오른쪽 선택
  • "병 잡기": OneTwoVLA는 왼쪽 8회, 오른쪽 12회 잡음; π₀는 항상 오른쪽 선택
  • π₀의 액션 MSE는 OneTwoVLA보다 56% 높음

이는 명시적 추론 내용이 π₀의 단일 모드 행동 선호도를 깨뜨려 모델이 추론 내용에 따라 다른 액션 대상을 선택할 수 있게 함을 검증합니다.

배포 효율성 (NVIDIA 4090)

구성 입력 토큰 출력 토큰 계산 시간
π₀ 20 — 0.082초
OneTwoVLA-Act-20 20 1 0.102초
OneTwoVLA-Act-200 200 1 0.104초
OneTwoVLA-Reason-20 200 20 0.853초

추론 토큰이 100을 초과하면 로봇이 몇 초간 멈춰야 하지만, 실제 배포에서는 추론이 소수의 중요한 순간에만 발생합니다.

장기 작업 예시

Tomato-Egg 총 소요 183초, 추론 5회 총 16초(8.7%); Mountain Fuji 총 소요 135초, 추론 5회 총 14초(10.4%).

경계 및 한계

논문은 모든 실패 사례의 완전한 통계를 명시적으로 제시하지 않았지만, 다음과 같은 경계를 인정했습니다: - 보지 못한 물체 일반화 취약: Open-World 실험에서 훈련 데이터에 없는 물체를 만날 때 불안정한 성능(예: 작은 농구 장난감을 잡으라는 명령에 계속 체스판으로 이동) - 세밀한 조작 여전히 불안정: Tomato-Egg에서 가끔 잡음이 불안정하여 떨어뜨림, Cocktail에서 오렌지 주스 따를 때 흘림 - 추론 오류에 대한 교정 메커니즘 없음: Hotpot에서 재료 위치를 잘못 판단(청경채를 잡으라는 명령에 팽이버섯을 잡으려 함), 모델의 액션이 잘못된 추론을 따름. 인지와 행동의 높은 일관성은 장점이자 위험임을 보여줌 - ARX 플랫폼 기능 미활용: 전방향 바퀴 베이스와 1-DoF 몸통 승강 메커니즘이 실험에서 활성화되지 않음 - 추론 지연 상한 존재: 100 토큰 초과 시 로봇이 몇 초간 멈춰야 하므로 긴 추론 체인은 실시간 시나리오에서 불가능

공학적 시사점

OneTwoVLA를 재현하거나 채택할 때 다음 단계가 가장 주목할 가치가 있습니다:

  1. 추론-액션 데이터 분할 라벨링 먼저 검증: 이것이 훈련의 핵심입니다. 추론 구간과 액션 구간의 분할 품질이 모델이 중요한 순간에 추론을 트리거할 수 있는지 여부를 직접 결정합니다. 소규모 데이터에서 [BOR]/[BOA] 토큰 예측 정확도를 먼저 검증한 후 데이터 양을 확장하는 것이 좋습니다.

  2. 참조 이미지 I_ref 선택 로직: 가장 함정에 빠지기 쉬운 부분입니다. I_ref는 현재 추론 내용이 생성될 때의 이미지 관측과 엄격히 일치해야 하며, 그렇지 않으면 모델이 시각-텍스트 불일치로 혼동합니다. 데이터 수집 시 추론 내용과 이미지의 타임스탬프 대응 관계를 기록하는 것이 좋습니다.

  3. 합성 데이터 품질 기준: 저자는 GPT-4o를 시도했지만 공간 이해가 약해 최종적으로 Gemini 2.5 Pro로 전환했습니다. 재현 시 다른 생성 모델을 사용한다면 소규모 샘플에서 공간 관계 설명의 정확성을 수동으로 검증해야 하며, 그렇지 않으면 시각적 접지 성능이 크게 저하됩니다.

  4. 배포 시 추론 빈도 제어: 추론 토큰이 100을 초과하면 로봇이 몇 초간 멈추므로, 실제 배포에서는 모델이 추론 시점을 자유롭게 결정하도록 두지 말고 추론 트리거 조건(작업 전환, 명령 모호성, 실패 감지 등)을 설정해야 합니다. Tomato-Egg의 5회 추론, 총 16초 추론 시간은 합리적인 참조 상한입니다.

  5. 다중 모드 액션 실험의 시연 수집: 각 물체당 50개 시연, 총 200개이며 명령은 좌우를 지정하지 않습니다. 재현 시 시연에 위치 선호도(예: 항상 왼쪽 먼저 잡기)가 암시되어 있으면 모델이 다중 모드 행동을 학습하지 못할 수 있습니다. 시연에서 좌우 선택을 의도적으로 균형 있게 하는 것이 좋습니다.
