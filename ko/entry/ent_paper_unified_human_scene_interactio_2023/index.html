요약

Unified Human-Scene Interaction via Prompted Chain-of-Contacts is a 2023 work on physics-based character animation for humanoid robots.

출처

  • Unified Human-Scene Interaction via Prompted Chain-of-Contacts (arXiv)
  • Unified Human-Scene Interaction via Prompted Chain-of-Contacts project page

개요

UniHSI는 인간-장면 상호작용(HSI)에서 상호작용 제어의 다양성과 사용자 인터페이스 친화성 부족 문제를 해결하는 것을 목표로 합니다. 이 프레임워크는 상호작용 과정을 '접촉 체인'(CoC), 즉 인체 관절과 객체 부품 간의 접촉 단계 시퀀스로 추상화하며, 이 설계는 상호작용 유형과 접촉 영역 간의 강한 상관관계에 기반합니다. 프레임워크는 두 가지 핵심 모듈로 구성됩니다: 자연어 지시를 CoC 형태의 작업 계획으로 변환하는 대규모 언어 모델(LLM) 기반 플래너와, CoC를 구체적인 물리적 실행 동작으로 변환하는 통합 컨트롤러입니다. 훈련 및 평가를 지원하기 위해 연구팀은 LLM이 다양한 장면을 기반으로 생성한 수천 개의 작업 계획을 포함하는 ScenePlan 데이터셋을 수집했습니다. 실험 결과, UniHSI는 다양한 상호작용 작업을 효과적으로 수행할 수 있으며 실제 스캔 장면으로 일반화할 수 있음을 보여줍니다.

핵심 내용

방법 아키텍처

UniHSI의 핵심은 '접촉 체인'(Chain of Contacts, CoC) 개념으로, 인간-장면 상호작용을 일련의 인체 관절과 객체 부품 간의 접촉 단계로 분해합니다. 예를 들어, '앉기' 동작은 '엉덩이-좌석 표면 접촉'과 같은 단계 시퀀스로 표현될 수 있습니다. 프레임워크는 두 부분으로 구성됩니다: - LLM 플래너: GPT-4와 같은 대규모 언어 모델을 활용하여 자연어 지시를 CoC 작업 계획으로 파싱합니다. 이 계획에는 상호작용 객체, 접촉 관절, 접촉 순서 등의 구조화된 정보가 포함됩니다. - 통합 컨트롤러: CoC 계획을 연속적인 운동 제어 신호로 변환하는 물리 기반 시뮬레이션 컨트롤러입니다. 강화 학습으로 훈련되며 다양한 객체 기하학적 형태와 초기 상태에 적응할 수 있습니다.

실험 설정

  • 데이터셋: ScenePlan 데이터셋은 2000개 이상의 작업 계획을 포함하며, 50가지 상호작용 유형(예: 앉기, 눕기, 밀기, 당기기)과 100개의 가상 장면을 다룹니다. 각 계획은 LLM에 의해 자동 생성되고 인간 검증을 거칩니다.
  • 훈련: 컨트롤러는 Isaac Gym 시뮬레이터에서 PPO 알고리즘을 사용하여 훈련되며, 훈련 단계 수는 1억 단계입니다.
  • 평가 지표: 작업 성공률(Success Rate), 접촉 정확도(Contact Accuracy), 물리적 타당성(Physical Plausibility) 등이 포함됩니다.

주요 결과

  • 10가지 대표적인 상호작용 작업에서 UniHSI의 평균 성공률은 87.3%로, 기준 방법(예: 규칙 기반 플래너 + 전통적 컨트롤러)의 62.1%보다 크게 높습니다.
  • 실제 스캔 장면(예: Replica 데이터셋)에서 UniHSI의 일반화 성공률은 79.5%로, 보지 못한 객체 배치와 기하학적 형태에 적응할 수 있음을 보여줍니다.
  • 제거 실험에서 CoC 플래너를 제거하면 성공률이 54.2%로 떨어져 접촉 체인 표현의 효과성을 검증합니다.

결론

UniHSI는 상호작용을 접촉 체인으로 추상화하고 대규모 언어 모델 계획과 통합 물리 제어를 결합하여 언어 기반의 다양한 인간-장면 상호작용을 구현합니다. 오픈 소스 코드와 ScenePlan 데이터셋은 후속 연구를 위한 기준을 제공합니다. 향후 작업은 더 복잡한 다중 객체 상호작용과 동적 장면으로 확장될 수 있습니다.
