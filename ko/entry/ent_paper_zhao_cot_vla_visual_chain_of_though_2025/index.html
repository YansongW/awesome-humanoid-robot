요약

CoT-VLA: Visual Chain-of-Thought Reasoning for Vision-Language-Action Models (CoT-VLA), is a 2025 large vision-language-action model for robotic manipulation, introduced by NVIDIA, Stanford University, MIT, and published at CVPR25.

출처

  • CoT-VLA source

개요

CoT-VLA는 저자 팀이 VILA-U를 기반으로 구축했으며, 처음으로 명시적 시각적 사고 사슬(CoT)을 시각-언어-행동 모델(VLA)에 도입했다: 먼저 자동 회귀적으로 미래 하위 목표 이미지를 중개 추론 단계로 예측한 다음, 해당 목표를 달성하기 위한 행동 시퀀스를 생성하여 모델에 시간적 계획 능력을 부여한다. 핵심 기여는 무행동 비디오 데이터(EPIC-KITCHENS, Something-Something V2)를 활용한 시각적 추론 향상과 혼합 주의 메커니즘(이미지/텍스트 인과, 행동 전체 주의) 및 행동 청킹(청크 크기 10) 설계에 있다. LIBERO 벤치마크에서 평균 성공률 81.13%로 OpenVLA(76.5%) 대비 약 6% 향상되었으며, 실제 세계 Franka-Tabletop 작업에서 SOTA 대비 17% 향상되었다. 사전 학습 단계는 46.7%의 상대적 향상(53.7%→78.8%)을 가져왔지만, 256개의 이미지 토큰 생성으로 인해 추론이 평균 7배 느려졌고, 자동 회귀 이미지 품질은 확산 모델보다 낮다.

무엇을 바꾸었는가

이 작업의 진정한 변화는 VLA에 모듈을 하나 더 추가한 것이 아니라, VLA 패러다임에서 기본적으로 받아들여지고 거의 의문시되지 않던 가정을 흔들었다는 점이다: 시각-언어-행동 모델은 관측에서 행동으로 직접 매핑되어야 한다. CoT-VLA는 이 단일 매핑 과정을 두 단계의 명시적 인과 사슬로 분해했다——먼저 "미래가 어떻게 보일지"를 예측하고, 그 다음 "그곳에 어떻게 도달할지"를 결정한다. 이 분해는 단순해 보이지만, 실제로는 "계획"을 잠재 공간에서 끌어내어 감독 가능하고, 개입 가능하며, 검증 가능한 중간 변수로 만든 것이다.

이 변화가 실질적인 이유는 무엇인가? 기존 VLA(OpenVLA, Octo 등)는 본질적으로 조건부 확률 모델링을 수행하며, 언어 명령과 현재 프레임이 행동 분포를 직접 결정한다. 이러한 종단 간 매핑은 단기적 작업에는 충분하지만, 작업에 다단계 추론이 필요해지면(예: "A를 먼저 잡고, B에 놓은 다음, C를 밀어내기"), 모델에는 추론 과정을 고정할 명시적 "중간 상태"가 부족하다. CoT-VLA는 하위 목표 이미지를 이 고정점으로 사용하여 모델에 "자체 검사점"을 장착한 셈이다——행동을 생성하려면 먼저 다음에 무엇을 보게 될지 명확히 생각해야 한다. 이 메커니즘은 장기 작업(LIBERO 장기 스위트 69.0% vs OpenVLA의 53.7%)과 실제 세계 다단계 조작에서 VLA의 체계적 약점에 직접 대응한다.

더 흥미로운 것은 데이터 측면의 변화다. 하위 목표 이미지 생성에는 행동 주석이 필요하지 않으므로, CoT-VLA는 방대한 무행동 비디오(EPIC-KITCHENS, Something-Something V2)를 흡수하여 시각적 추론 능력을 사전 학습할 수 있다. 이는 VLA의 데이터 병목에 대한 근본적 해결책이다——로봇 시연 데이터는 희소하고 비싸지만, 인터넷에는 "사람이 장면을 보고 다음 행동을 하는" 비디오가 넘쳐난다. 저자들은 사전 학습 소거 실험을 통해 이를 증명했다: 사전 학습을 포함한 경우가 기본 모델을 직접 미세 조정한 것보다 상대적으로 46.7%(53.7%→78.8%) 향상되었다. 이 수치는 시각적 CoT 능력이 로봇 데이터에서 학습된 것이 아니라 무행동 비디오에서 "사전 설치"되었음을 보여준다.

하지만 변화에는 대가가 따른다. 256개의 이미지 토큰 생성은 평균 7배 추론 지연을 초래하며, 이 비용은 실제 로봇 폐루프 제어에서 치명적이다——고주파 피드백은 조작 안정성의 생명선이다. 저자들도 행동 청킹(청크 크기 10)이 청크 간 불연속성을 유발하고, Bridge-V2의 시각적 일반화 작업에서 실패의 주요 원인이 시각적 추론이 아닌 파지 행동임을 인정한다. 이는 CoT-VLA의 "생각"은 강해졌지만 "실행"의 정밀도는 희생되었음을 의미한다. 이는 VLA의 추론 구조를 바꾸었지만, 실행 계층의 시간적 연속성 문제는 동시에 해결하지 못했다——이것이 후속 작업을 기다리는 진정한 균열이다.

방법 분해

CoT-VLA의 핵심은 "먼저 생각하고 나중에 행동"을 두 개의 자동 회귀 단계로 명시적으로 분해한 것이지, 모델이 언어 명령에서 직접 행동 시퀀스로 점프하게 하는 것이 아니다. 전체 아키텍처는 VILA-U 7B를 기반으로 하며, 입력 이미지는 16×16×4개의 토큰(잔차 깊이 4)으로 인코딩되고, 모든 이미지는 256×256 해상도로 통일된다.

2단계 추론

  • 1단계(시각적 추론): 현재 관측 \(s_t\)와 언어 명령 \(l\)이 주어지면, 모델은 미래 \(n\)번째 프레임의 하위 목표 이미지 \(\hat{s}_{t+n}\)을 자동 회귀적으로 예측하여 중개 시각적 추론 단계로 사용한다. 여기서 \(n\)은 고정값이 아니라 데이터셋 특정 범위 \([n_l, n_u]\)에서 균일하게 샘플링된다(예: Bridge는 [5,10], TOTO는 [20,24]). 목적은 모델이 다양한 시간 척도에서 계획하는 법을 배우게 하는 것이다.
  • 2단계(행동 생성): 예측된 하위 목표 이미지 토큰과 원래 컨텍스트를 기반으로 \(m\)개의 행동 시퀀스(행동 청크 크기 10)를 생성하여 해당 하위 목표 상태를 달성한다. 행동 시퀀스의 예측 조건은 더 이상 원본 이미지가 아니라 "상상된 미래 프레임"이다——이것이 직접 입력-출력 매핑 VLA와의 본질적 차이점이다.

핵심 설계 결정

  • 시각적 토큰 예측: 깊은 트랜스포머 \(P_\delta\)를 사용하여 \(D\)개의 잔차 토큰을 자동 회귀적으로 예측하며, 훈련 목표는 시각적 손실(수식 4)이다. 단일 토큰 예측 대신 잔차 토큰을 선택한 이유는 제한된 계산으로 생성 이미지 품질을 향상시키기 위해서다——저자들은 시각적 품질이 여전히 확산 기반 모델보다 낮음을 인정한다.
  • 행동 이산화: 각 행동은 7개의 토큰(7-DoF 엔드 이펙터 제어에 해당)으로 표현되며, 각 연속 행동 차원은 256개의 이산 빈에 독립적으로 매핑된다. 빈 너비는 훈련 데이터 행동 분포의 1번째와 99번째 백분위수로 균일하게 분할하여 결정되며, 고정 범위가 아니다——이는 극단적 행동 값으로 인한 양자화 낭비를 방지한다. 행동 빈 토큰은 텍스트 토크나이저 어휘에서 가장 덜 사용되는 256개의 토큰을 직접 차용하므로 어휘 확장이 필요 없다.
  • 혼합 주의 메커니즘: 이미지/텍스트 생성에는 인과 주의(자동 회귀 순서 보장)를 사용하지만, 행동 생성에는 전체 주의를 사용하여 동일한 행동 청크 내의 모든 행동 토큰이 서로 상호작용할 수 있게 한다. 이는 의도적인 설계다: 행동 시퀀스 내부의 각 차원은 강한 상관관계(예: 위치와 속도)를 가지며, 전체 주의는 모델이 디코딩 시 차원별 독립 생성이 아닌 전체 행동 청크를 공동으로 고려할 수 있게 한다.
  • 훈련 목표: 총 손실은 행동 손실과 시각적 손실의 합(수식 6)이며, 두 단계는 분리 훈련이 아닌 공동 최적화된다. 시각적 손실의 존재는 LLM 백본이 순수 행동 매핑으로 퇴화하지 않고 실제로 "미래를 상상하는" 법을 배우도록 강제한다.

훈련 절차

  • 사전 학습 단계: Open X-Embodiment 하위 집합(OpenVLA 전처리 방식, 3인칭 뷰와 단일 팔 7-DoF 제어 선택)과 무행동 비디오 데이터셋(EPIC-KITCHENS, Something-Something V2)에서 공동 훈련한다. 무행동 비디오는 언어 설명과 이미지만 제공하며 시각적 추론 능력을 강화하는 데 사용된다——하위 목표 이미지 생성에는 행동 주석이 필요 없으므로 모델이 방대한 비디오에서 "상태가 어떻게 진화하는지"에 대한 상식을 학습할 수 있다. LLM 백본, 프로젝터, 깊은 트랜스포머를 최적화하고 시각적 타워는 동결한다. 학습률 1e-4, 코사인 감쇠, 전역 배치 크기 2048, 10 에폭, 11K A100 GPU 시간 소요.
  • 적응 단계: 대상 로봇 설정의 작업별 시연 데이터에서 미세 조정하며, 동일한 훈련 설정(LLM 백본, 프로젝터, 깊은 트랜스포머 훈련 가능, 시각적 타워 동결)을 유지하지만 학습률은 상수 1e-5로 낮추고 150 에폭 훈련한다. Bridge-V2는 훈련 행동 예측 정확도가 95% 임계값에 도달할 때까지 추가 미세 조정한다.
  • 테스트 시 폐루프 제어(알고리즘 1): "하위 목표 이미지 샘플링 → 행동 시퀀스 샘플링 → 행동 실행 → 관측 업데이트" 루프를 반복한다. 행동 청크 크기가 10이므로 10단계마다 관측이 업데이트되며, 이는 저자들이 인정한 "청크 간 불연속 행동"과 "고주파 피드백 부족" 문제를 설명한다.

소거 검증

  • 사전 학습 단계는 상당한 이득을 가져온다: 사전 학습을 포함한 CoT-VLA는 기본 VILA-U를 직접 미세 조정한 것보다 상대적으로 46.7%(53.7% → 78.8%) 향상되어, 무행동 비디오 사전 학습이 시각적 추론 능력에 미치는 핵심적 역할을 증명한다.
  • 시각적 추론 유효성: 실제 목표 이미지를 사용할 때 하위 작업 1/2 성공률은 각각 60%/40%인 반면, 생성된 목표 이미지를 사용하면 20%/0%로 떨어진다——절대 차이 40%. 이는 현재 생성 이미지 품질이 여전히 병목이지만, 메커니즘 자체(하위 목표를 중개로 사용)는 유효함을 보여준다.

핵심 혁신

CoT-VLA의 핵심 혁신은 "생각"과 "행동"을 아키텍처 수준에서 명시적으로 분리하고, 하위 목표 이미지 생성을 중개 추론 단계로 사용하여 모델이 언어 명령에서 직접 행동 시퀀스로 점프하지 않게 한 것이다. 이 설계에는 세 가지 깊이 파볼 가치가 있는 점이 있다:

첫째, 하위 목표 이미지 생성을 VLA의 사고 사슬(CoT) 단계로 처음 도입했다. 이전 VLA(예: OpenVLA)는 본질적으로 "입력-출력" 종단 간 매핑이며 작업의 중간 상태에 대한 명시적 모델링이 부족했다. CoT-VLA는 모델이 먼저 미래 n프레임의 하위 목표 이미지 ŝ_{t+n}을 자동 회귀적으로 예측한 다음, 해당 이미지를 기반으로 행동 시퀀스를 생성하게 한다. 이 "어떤 시각적 상태를 달성할지 먼저 명확히 한 다음, 어떻게 움직일지 결정"하는 분해는 복잡한 조작 작업에 시간적 계획이 필요하다는 문제에 직접 대응한다. 핵심 증거는 소거 실험이다: 생성된 목표 이미지를 사용할 때 하위 작업 성공률은 20%/0%였지만, 실제 목표 이미지로 교체하면 60%/40%로 급등하여 절대 40% 포인트 향상되었다——이는 시각적 추론 단계 자체가 성능 병목이며, 모델이 생성한 하위 목표 이미지는 완벽하지 않지만 유효한 계획 정보를 담을 수 있음을 보여준다.

둘째, 하위 목표 이미지 생성에는 행동 주석이 필요 없어 방대한 무행동 비디오 데이터 활용의 문을 열었다. 전통적 VLA 훈련은 로봇 시연 데이터(행동 주석이 비싸고 희소함)에 제한되지만, CoT-VLA의 시각적 추론 단계는 이미지 시퀀스에만 의존하므로 EPIC-KITCHENS와 Something-Something V2 같은 대규모 인간 비디오에서 직접 사전 학습할 수 있다. 사전 학습의 이득은 실질적이다: VILA-U를 직접 미세 조정하는 것과 비교해 사전 학습 단계를 포함하면 상대적으로 46.7%(53.7%에서 78.8%로) 향상된다. 이는 VLA의 시각적 이해 능력을 "로봇 전용 데이터"에서 해방시켜, 더 풍부한 인간 조작 비디오로 "상태 변화를 이해하는" 법을 먼저 학습한 다음 로봇 제어로 전이하는 것과 같다.

셋째, 혼합 주의 메커니즘은 다중 모달 생성과 행동 예측의 충돌을 해결했다. 이미지/텍스트 생성에는 인과 주의(자동 회귀 일관성 보장)를, 행동 생성에는 전체 주의(7개의 행동 토큰이 서로 상호작용)를 사용하여 인과 마스킹으로 인한 행동 차원 간 협력 정보 손실을 방지한다. 행동 청킹(청크 크기 10)과 256개의 이산 빈 행동 토큰화와 결합하여, 모델은 단일 단계 결정이 아닌 일관된 행동 시퀀스를 출력할 수 있다. 이 설계는 작지만 행동 품질에 직접 영향을 미친다——Bridge-V2의 운동 작업에서 CoT-VLA는 60% vs OpenVLA의 45%를 달성했으며, 그 차이는 행동 생성의 조정성에서 비롯된다.

주목할 점은 저자들이 256개의 이미지 토큰 생성이 평균 7배 추론 지연을 가져오고 이미지 품질이 확산 모델보다 낮음을 솔직히 인정한다는 것이다——이는 무료 개선이 아닌 계산으로 계획 능력을 얻는 명확한 트레이드오프다.

실험과 결과

CoT-VLA의 실험 설계는 세 가지 수준으로 구성된다: 시뮬레이션 벤치마크(LIBERO), 실제 로봇 일반화(Bridge-V2), 자체 구축 실제 테이블탑 작업(Franka-Tabletop), 그리고 사전 학습과 시각적 추론 구성 요소의 독립적 기여를 검증하는 두 가지 핵심 소거 실험이 추가된다.

LIBERO 벤치마크(표 1)는 주요 비교 대상이며, 각 작업 스위트는 500회 시도, 3개의 무작위 시드로 구성된다. CoT-VLA-7B는 평균 81.13±0.6%로 모든 기준선을 크게 앞서며, 특히 장기 작업(69.0±0.8%)에서 Diffusion Policy(50.5±1.3%) 대비 18.5(표 내 값 88.4→72.4 계산) 포인트 향상되어, 하위 목표 이미지가 중개 추론 단계로 다단계 작업에 미치는 가치를 직접적으로 입증한다. 주목할 점은 객체 작업에서 Diffusion Policy(92.5±0.7%)가 CoT-VLA(91.6±0.5%)보다 약간 높다는 것으로, 단일 단계, 객체 속성이 명확한 시나리오에서는 명시적 시각적 추론의 이득이 제한적임을 보여준다.

Bridge-V2 벤치마크(표 2)는 각 클래스당 10회 시도의 부분 신용 점수를 사용하여 네 가지 일반화 차원을 조사한다. CoT-VLA는 운동 클래스(60%)와 의미 클래스(50%)에서 크게 앞서며 각각 OpenVLA보다 15 및 10 포인트 높아, 미래 프레임 예측의 시각적 추론이 운동학적 및 의미적 변화를 효과적으로 인코딩할 수 있음을 보여준다. 그러나 시각 클래스(65% vs 75%)와 언어 클래스(70% vs 75%)에서는 OpenVLA보다 약간 낮으며, 저자들은 이를 시각적 추론 오류가 아닌 행동 청킹으로 인한 파지 실패로 귀인한다——이는 중개 추론과 행동 실행 사이의 분리 위험을 시사한다.

소거 실험은 가장 강력한 인과 증거를 제공한다. 사전 학습 소거는 Open X-Embodiment 하위 집합과 무행동 비디오(EPIC-KITCHENS, Something-Something V2)의 사전 학습 단계를 추가하면 기본 VILA-U 모델을 직접 미세 조정하는 것보다 46.7%(53.7%→78.8%) 향상되어, 무행동 비디오 데이터의 시각적 추론 능력에 대한 전이 가능한 이득을 검증한다. 시각적 추론 소거(표 3)는 더 결정적이다: 생성된 목표 이미지를 사용할 때 하위 작업 1 성공률은 20%, 하위 작업 2는 0%였지만, 실제 목표 이미지로 교체하면 각각 60%와 40%로 상승하여 절대 40% 포인트 향상되었다. 이 비교는 현재 자동 회귀 이미지 생성 품질이 성능 병목임을 명확히 보여준다——생성 이미지와 실제 상태 사이의 분포 이동이 하류 행동 예측의 정확성을 직접 제한한다.

Franka-Tabletop에서의 전반적 성능 향상(실제 세계에서 최첨단 VLA 대비 17%, 시뮬레이션 벤치마크 대비 6%)은 위 소거 결론과 일치한다: CoT-VLA의 아키텍처 이점은 장기적, 다단계 작업에서 충분히 발휘되지만, 생성 이미지 품질과 행동 청킹으로 인한 실행 불연속성에 의해 제한된다. 7배 추론 지연(256개 이미지 토큰 생성)과 청크 간 행동 불연속성은 현재 설계의 실시간성과 부드러운 제어 측면에서의 명시적 비용이다.

경계와 한계

CoT-VLA의 경계와 한계는 먼저 계산 비용에서 나타난다: 추론 시 256개의 이미지 토큰 생성은 평균 7배 지연(행동 청크 크기 10)을 가져와 실시간 제어 시나리오에서 적용이 어렵고, 저자들도 현재 계산 제약이 새로운 작업의 시각적 추론 일반화 구현을 제한한다고 인정한다. 둘째, 자동 회귀 이미지 생성의 시각적 품질은 확산 기반 SOTA 모델보다 낮아, 하위 목표 이미지가 중개 추론 단계로 갖는 신뢰성에 상한이 있음을 의미한다——중간 시각적 표현 자체에 손실이 있으면 후속 행동 생성은 필연적으로 오류를 이어받는다.

더 본질적인 한계는 행동 청킹 메커니즘에 있다: 청크 간 불연속 행동이 발생할 수 있고, 실행 중 고주파 피드백이 부족하다. 이는 Bridge-V2의 시각적 및 언어 일반화 작업에서 이미 비용으로 드러났다——CoT-VLA 성공률(65%, 70%)이 OpenVLA(75%, 75%)보다 낮으며, 저자들은 이를 시각적 추론 오류가 아닌 파지 실패로 귀인하지만, 이는 행동 실행 계층이 분포 외 시나리오에서 충분히 견고하지 않음을 보여준다. 또한, 분포 외 하위 목표 생성은 여전히 어렵고, 사전 학습 소거는 상대적 향상 46.7%가 대규모 사전 학습 데이터(OpenX, EPIC-KITCHENS, Something-Something V2)에 의존함을 보여주며, 대상 도메인과 사전 학습 분포의 차이가 크면 이 이득은 크게 줄어들 수 있다.

저자들이 하지 않은 일도 마찬가지로 중요하다: 실제 로봇에서 교차 형태 일반화를 검증하지 않았고(프랑카와 WidowX 두 플랫폼만), 하위 목표 예측 시간 단계 n의 샘플링 범위(예: RoboTurk의 u_l=1, u_u=2)가 장기 작업 성능에 미치는 민감도를 논의하지 않았으며, 시각적 손실과 행동 손실 간의 가중치 균형이 최종 정책에 미치는 영향도 분석하지 않았다. 시각적 추론 소거에서 생성된 목표 이미지는 하위 작업 성공률 20%/0%에 그친 반면, 실제 이미지는 60%/40%였다——이 40%의 절대적 격차는 현재 생성적 시각적 추론과 이상적 중개 표현 사이의 간극을 드러내며, 논문은 이 간극을 메우기 위한 메커니즘적 설명을 제공하지 않는다.

공학적 시사점

CoT-VLA를 재현하기 전에 두 가지를 먼저 확인하라: 첫째, 데이터 혼합 가중치 표(표 4)에서 각 데이터셋 가중치와 하위 목표 범위 [u_l, u_u]는 수동으로 조정된 것이므로 그대로 적용하면 문제가 생긴다——예를 들어 RoboTurk의 u_l=1, u_u=2는 매우 가까운 미래 프레임 예측을 의미하고, TOTO의 u_l=20, u_u=24는 모델이 20프레임 이후를 보도록 요구하므로, 하류 작업의 시간 척도가 일치하지 않으면 시각적 추론이 실패한다. 둘째, 행동 이산화 세부 사항: 각 행동 차원은 256개의 빈에 매핑되며, 빈 너비는 훈련 데이터 행동 분포의 1번째와 99번째 백분위수로 결정된다. 이는 행동 분포 꼬리에 민감함을 의미하며, 데이터셋에 비정상적으로 큰 행동이 있으면 빈 너비가 넓어져 작은 행동의 양자화 오류가 급증한다.

가장 쉽게 빠지는 함정은 추론 지연이다: 256개의 이미지 토큰 생성은 평균 7배 지연(행동 청크 크기 10일 때)을 가져와 폐루프 제어 주파수가 크게 감소한다. 하류 작업에 고주파 피드백이 필요하면(예: 힘 제어 삽입), 이 접근 방식은 적합하지 않다; 작업이 초 단위 결정을 허용한다면 충분한 계산 여유를 확보해야 한다. 또 다른 은밀한 문제는 행동 청크 간 불연속성이다——청크 크기가 10이므로 청크 경계에서 고주파 피드백 수정이 없으며, Bridge-V2의 시각/언어 일반화 작업에서 OpenVLA보다 낮은 것은 시각적 추론 오류가 아닌 파지 실패 때문이다. 재현 시 단일 작업 미세 조정(단일 A100 노드 10-24시간)을 먼저 실행하여 훈련 행동 예측 정확도가 임계값(Bridge-V2는 95%)에 도달하는지 확인한 다음 확장하는 것을 권장한다.
