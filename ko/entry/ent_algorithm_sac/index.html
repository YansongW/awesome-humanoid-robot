요약

기대 보상을 최대화하면서도 정책 엔트로피를 최대화해 탐색을 장려하는 오프폴리시 액터-크리틱 강화학습 알고리즘.

개요

소프트 액터-크리틱(SAC)은 기대 보상을 최대화하면서 동시에 정책 엔트로피를 최대화하여 탐색을 촉진하는 오프-폴리시 액터-크리틱 강화 학습 알고리즘입니다. 목적 함수에 엔트로피 정규화 항을 도입하여 탐색과 활용 사이에 명시적인 균형 메커니즘을 확립하며, 연속 행동 공간 제어 작업에서 안정성과 샘플 효율성이 뛰어난 기준 알고리즘이 되었습니다.

핵심 내용

무엇인가: 정확한 정의

소프트 액터-크리틱(Soft Actor-Critic, SAC)은 알고리즘 유형에 속하며, 소속 분야는 AI 모델 및 알고리즘(07_ai_models_algorithms), 가치 사슬 계층은 지능 계층입니다. 핵심 아이디어는 표준 강화 학습 목표인 기대 누적 보상 최대화 위에 정책 엔트로피 최대화 항을 추가하는 것입니다. 엔트로피는 정책 분포의 무작위성을 측정하며, 엔트로피가 클수록 행동 선택이 더 분산되고 탐색성이 강해집니다. SAC의 최적화 목표는 다음과 같이 쓸 수 있습니다:

\[ J(\pi) = \sum_{t} \mathbb{E}_{(s_t, a_t) \sim \rho_\pi} \left[ r(s_t, a_t) + \alpha \, \mathcal{H}\left(\pi(\cdot|s_t)\right) \right] \]

여기서 \(\alpha\)는 온도 계수로, 엔트로피 정규화 항의 가중치를 제어합니다. \(\alpha \to 0\)일 때 SAC는 표준 기대 보상 최대화로 퇴화하며, \(\alpha\)가 증가할수록 정책은 무작위 탐색을 선호합니다. 이러한 목적 함수 설계 덕분에 SAC는 이론적으로 높은 보상 획득과 행동 다양성 유지라는 겉보기에 상충되는 두 목표를 동시에 최적화할 수 있습니다.

SAC는 오프-폴리시(off-policy) 알고리즘에 속하며, 이는 현재 정책이 생성한 데이터에만 의존하지 않고 경험 재생 버퍼(replay buffer)에 저장된 과거 샘플을 사용하여 학습할 수 있음을 의미합니다. 이 특성은 샘플 효율성을 크게 향상시켜 SAC를 실제 로봇 시스템에서 특히 귀중하게 만듭니다. 실제 플랫폼의 상호작용 비용이 시뮬레이션 환경보다 훨씬 높기 때문입니다.

원리 분해

① 소프트 정책 반복: 교대 최적화와 수렴 보장

SAC의 학습 과정은 소프트 정책 반복(soft policy iteration) 프레임워크 위에 구축되며, 소프트 정책 평가와 소프트 정책 개선 두 단계가 교대로 진행됩니다. 소프트 정책 평가는 벨만 연산자를 사용하여 Q 함수를 업데이트합니다:

\[ Q_{\text{soft}}(s, a) = r(s, a) + \gamma \, \mathbb{E}_{s' \sim p}\left[ V_{\text{soft}}(s') \right] \]

여기서 소프트 상태 가치 함수는 \(V_{\text{soft}}(s) = \mathbb{E}_{a \sim \pi}\left[ Q_{\text{soft}}(s, a) - \alpha \log \pi(a|s) \right]\)로 정의됩니다. 소프트 정책 개선은 정책과 Q 함수의 지수 형태 사이의 KL 발산을 최소화하여 정책을 업데이트합니다:

\[ \pi_{\text{new}} = \arg\min_{\pi'} D_{\text{KL}}\left( \pi'(\cdot|s) \;\Big\|\; \frac{\exp\left(\frac{1}{\alpha} Q^{\pi_{\text{old}}}(s, \cdot)\right)}{Z^{\pi_{\text{old}}}(s)} \right) \]

여기서 \(Z^{\pi_{\text{old}}}(s)\)는 정규화를 위한 분배 함수입니다. 이 반복 과정은 이론적으로 최적 소프트 정책으로 수렴함이 증명되었습니다.

② 이중 Q 네트워크와 목표 네트워크: 안정성의 공학적 보장

SAC는 구현 측면에서 두 가지 핵심 공학적 기법을 채택합니다. 첫째, 두 개의 독립적인 Q 네트워크(이중 Q 네트워크)를 사용하며, 업데이트 시 두 값의 최솟값을 목표값으로 취하여 가치 함수의 과대평가 편향을 억제합니다 — 이 기법은 TD3에서 계승되었습니다. 둘째, 목표 네트워크(target network)를 사용하여 소프트 업데이트 방식(Polyak 평균)으로 온라인 네트워크 파라미터를 천천히 추적함으로써 학습 과정의 비정상성을 줄입니다. 이 두 가지 설계 덕분에 SAC는 복잡한 고차원 작업에서 단일 Q 네트워크 구조보다 훨씬 안정적입니다.

③ 자동 온도 조절: 엔트로피 가중치의 적응

SAC의 실용적 확장 중 하나는 온도 계수 \(\alpha\)를 자동으로 조절하는 것입니다. 그 아이디어는 엔트로피를 고정 가중치가 아닌 하한 목표로 제약하는 것입니다: 최소 기대 엔트로피 \(\mathcal{H}_{\text{target}}\)를 설정한 다음, 경사 하강법을 통해 \(\alpha\)를 조정하여 정책 엔트로피가 해당 목표보다 낮아지지 않도록 합니다. 이는 \(\alpha\)를 수동으로 조정하는 부담을 제거하며, 특히 보상 척도를 알 수 없는 실제 작업에 적합합니다.

SAC의 핵심 장점은 확률적 정책의 탐색 능력과 오프-폴리시 학습의 샘플 효율성을 동시에 갖추는 데 있습니다. PPO와 비교하여 SAC는 샘플 효율성에서 일반적으로 수 배 향상됩니다(말뭉치 데이터 추론 기준, 구체적 배수는 직접 확인 필요). TD3와 비교하여 SAC의 엔트로피 정규화는 인위적으로 추가된 노이즈에 의존하지 않고 더 체계적인 탐색 메커니즘을 제공합니다.

누가 사용하는가·응용 사례

휴머노이드 로봇 분야에서 SAC는 운동 기술 학습 및 제어 정책 훈련에 널리 사용됩니다. 대표적인 응용 시나리오는 다음과 같습니다:

  1. 시뮬레이션-실제 전이 사전 훈련: MuJoCo, Isaac Sim 등의 시뮬레이션 플랫폼에서 SAC는 초기 정책 훈련에 자주 사용되며, 이후 도메인 무작위화 또는 시스템 식별을 통해 실제 하드웨어로 전이됩니다.
  2. 전신 운동 제어(whole-body control): SAC는 각 관절의 목표 토크 또는 목표 위치를 직접 출력할 수 있으며, 하위 레벨 PD 컨트롤러와 결합하여 전신 협조 운동을 구현합니다.
  3. 비교 기준선으로서: 학술 연구에서 SAC는 새 알고리즘 성능을 평가하는 표준 기준선 중 하나입니다. 예를 들어, DoublyAware 논문은 HumanoidBench 운동 스위트에서 Unitree 26-DOF H1-2 휴머노이드 로봇 모델을 사용하여 SAC를 비교 기준선 중 하나로 포함했습니다(이웃 카드 말뭉치 출처).

한계와 경계

SAC는 만능 알고리즘이 아니며, 그 한계는 실제 로봇 배포에서 특히 두드러집니다:

  1. 샘플 효율성이 여전히 직접 온라인 학습에는 부족함: SAC는 샘플 효율성이 가장 높은 오프-폴리시 알고리즘 중 하나이지만, 실제 휴머노이드 로봇의 상호작용 비용이 매우 높아 처음부터 온라인 훈련은 여전히 불가능합니다. 실제 응용은 일반적으로 시뮬레이션 사전 훈련과 미세 조정이 필요합니다.
  2. 보상 함수 설계에 민감함: 엔트로피 정규화는 탐색을 촉진하지만, 보상이 희소하거나 부적절하게 설계되면 SAC는 여전히 차선 정책에 빠질 수 있습니다. 구체적 작업에서의 보상 형성 전략은 직접 확인해야 합니다.
  3. 하이퍼파라미터 민감성: 온도 계수 \(\alpha\), 목표 엔트로피 등의 파라미터는 성능에 큰 영향을 미치며, 자동 온도 조절이 파라미터 조정 부담을 완화하지만 만능은 아닙니다.
  4. 고차원 행동 공간의 확장성: 행동 차원이 매우 높을 때(예: 전신 근골격 모델), SAC의 정책 네트워크 출력 차원이随之 증가하여 훈련 난이도가 크게 상승합니다.

일반적인 오해

  1. "SAC가 반드시 PPO보다 우수하다" — 틀림. 시뮬레이션 대규모 병렬 훈련 시나리오에서 PPO의 단순성과 안정성이 종종 더 우수합니다. SAC의 장점은 샘플 효율성에 있으며 절대적 성능 상한이 아닙니다.
  2. "엔트로피가 클수록 좋다" — 틀림. 과도한 엔트로피는 정책을 지나치게 무작위하게 만들어 행동이 심하게 떨리고, 실제 하드웨어에서 진동이나 손상을 유발할 수 있습니다. 엔트로피 정규화 항의 목적은 "충분한 탐색"이지 "최대 무작위성"이 아닙니다.
  3. "SAC는 파라미터 조정이 필요 없다" — 틀림. 자동 온도 조절은 \(\alpha\)의 조정 부담을 줄이지만, 학습률, 네트워크 구조, 보상 척도 등은 여전히 작업에 맞게 조정해야 합니다.
  4. "SAC를 실제 로봇에 직접 배포할 수 있다" — 틀림. SAC의 오프-폴리시 특성은 오프라인 훈련에 적합하지만, 실제 배포는 여전히 sim-to-real 격차, 안전 제약 등의 문제를 해결해야 합니다.
