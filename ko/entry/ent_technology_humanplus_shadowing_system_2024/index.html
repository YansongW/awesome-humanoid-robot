요약

RGB 칩차 기반 인체 자세 추정 및 시뮬레이션 학습된 저수준 정책을 통한 전신 휨로봇 텔레오퍼레이션 및 데이터 수집.

출처

  • HumanPlus Shadowing System

개요

HumanPlus 섀도잉 시스템(HumanPlus Shadowing System)은 RGB 카메라 기반의 인간 자세 추정과 시뮬레이션 훈련을 결합한 풀스택 휴머노이드 로봇 원격 조작 및 데이터 수집 기술입니다. 강화 학습을 통해 시뮬레이션에서 저수준 정책을 훈련하여 로봇이 운영자의 전신 및 손 동작을 실시간으로 따라갈 수 있게 하며, 수집된 데이터를 활용해 자율 기술을 추가로 학습합니다. 이 시스템이 진정으로 바꾸는 것은 원격 조작의 정밀도가 아니라 휴머노이드 로봇 데이터 획득의 규모와 비용 구조입니다.

핵심 내용

무엇인가: HumanPlus 섀도잉 시스템의 정확한 정의

HumanPlus 섀도잉 시스템은 스탠포드 대학 연구팀이 2024년 CoRL 컨퍼런스에서 발표한 완전한 기술 솔루션입니다(논문 제목: HumanPlus: Humanoid Shadowing and Imitation from Humans, 최우수 논문상 후보 6위 안에 진입). 이는 기술 유형의 개체이며, 가치 사슬 계층은 지능 계층으로, 핵심 기능은 다음 두 가지 모듈을 포함합니다:

  1. 섀도잉 모드(Shadowing): 운영자는 RGB 카메라 하나만으로 동작을 수행하고, 로봇은 저수준 정책을 통해 인간의 전신 및 손 동작을 실시간으로 따라가며 원격 조작을 구현합니다.
  2. 자율 기술 학습(Autonomous Skills): 섀도잉 모드에서 수집한 전신 데이터를 활용해 지도식 행동 복제로 기술 정책을 훈련하여, 로봇이 1인칭 시각을 기반으로 자율적으로 작업을 완료할 수 있게 합니다.

이 시스템이 진정으로 바꾸는 것은 원격 조작의 정밀도가 아니라 휴머노이드 로봇 데이터 획득의 규모와 비용 구조입니다. 즉, 기존의 고가 모션 캡처 장비나 힘 피드백 원격 조작 레버에 의존하던 데이터 수집 방식을 "사람 한 명, 카메라 한 대"로 충분한 저비용 솔루션으로 대체합니다.

왜 존재하는가: 문제점과 역사적 위치

휴머노이드 로봇 연구는 오랫동안 역설에 직면해 왔습니다: 인간형 형태를 구축하는 핵심 동기는 방대한 인간 데이터를 재사용하는 것이지만, 실제 훈련은 데이터 부족에 시달립니다. 구체적인 문제점은 다음과 같습니다:

  • 형태 및 구동 차이: 휴머노이드 로봇과 인간은 운동학, 동역학에서 물리적 차이가 있어 인간 운동 데이터를 직접 전이하면 실행 불가능한 관절 명령이 생성됩니다.
  • 인지 및 제어 복잡성: 휴머노이드 로봇의 전신 자유도는 33개(HumanPlus 맞춤형 플랫폼)에 달하며, 실시간 전신 제어는 동역학적 결합과 균형 문제를 해결해야 합니다.
  • 데이터 파이프라인 부재: 인간 데이터에서 로봇 자율 기술로 이어지는 종단 간 데이터 수집 및 학습 프로세스가 이전에는 없었습니다.

HumanPlus 이전의 주류 솔루션은 고가의 모션 캡처 시스템(예: Vicon)에 의존하거나 원격 조작 장치(예: ALOHA 시스템)를 사용해 작업별로 데이터를 수집하여 비용이 높고 확장성이 낮았습니다. HumanPlus의 역사적 위치는 다음과 같습니다: "인간 비디오 데이터 → 시뮬레이션 훈련 → 실제 섀도잉 추종 → 자율 기술"의 전체 파이프라인을 처음으로 연결했으며, RGB 카메라만으로 작동할 수 있습니다.

원리 분석

HumanPlus 섀도잉 시스템의 기술 아키텍처는 세 계층으로 구성되며, 단계적으로 심화됩니다:

① 저수준 정책: 시뮬레이션에서의 강화 학습

시스템은 기존의 40시간 인간 운동 데이터 세트(말뭉치에서 "existing 40-hour human motion datasets"로 명시)를 활용하여 시뮬레이션 환경에서 강화 학습을 통해 저수준 정책을 훈련합니다. 이 정책의 입력은 인간 자세 추정 결과(RGB 카메라에서 얻음)이고, 출력은 로봇 관절 명령입니다. 핵심 수학적 형태는 다음과 같이 추상화할 수 있습니다:

\[ \pi_{\text{low}}^{*} = \arg\max_{\pi} \; \mathbb{E}_{\tau \sim p(\tau)} \left[ \sum_{t=0}^{T} \gamma^t \, r(s_t, a_t) \right] \]

여기서 보상 함수 \(r(s_t, a_t)\)는 관절 한계 초과를 동시에 페널티하고, 자세 유사성과 균형 유지를 장려합니다. 시뮬레이션 훈련의 핵심은 도메인 무작위화(domain randomization)로, 정책이 실제 세계의 시각적 노이즈와 동역학적 편차에 대해 강건성을 갖도록 합니다.

② 섀도잉 추종: RGB 카메라 실시간 구동

훈련된 저수준 정책은 실제 로봇에 직접 배포됩니다. 운영자가 RGB 카메라 앞에 서서 동작을 수행하면, 시스템이 인간의 3D 자세(손 키포인트 포함)를 실시간으로 추정하여 로봇 목표 자세로 매핑하고, 저수준 정책이 부드럽고 안정적인 관절 명령을 생성합니다. 전체 과정은 모션 캡처 슈트, 힘 피드백 장치 없이 단안 시각만으로 작동합니다.

③ 자율 기술: 행동 복제

섀도잉 모드를 통해 운영자는 로봇을 원격 조작하여 특정 작업(예: 옷 개기, 물건 집기)을 수행하면서 전신 상태와 1인칭 시각 데이터를 동시에 수집합니다. 이후 시스템은 지도식 행동 복제로 기술 정책을 훈련하며, 입력은 1인칭 이미지, 출력은 전신 동작입니다. 이 단계의 핵심 공식은 행동 복제의 지도 학습 목표입니다:

\[ \theta^{*} = \arg\min_{\theta} \; \mathbb{E}_{(o_t, a_t) \sim \mathcal{D}} \left[ \left\| \pi_{\theta}(o_t) - a_t \right\|^2 \right] \]

여기서 \(\mathcal{D}\)는 섀도잉 모드에서 수집된 시연 데이터 세트입니다.

사용자 및 적용 사례

HumanPlus 섀도잉 시스템은 스탠포드 대학 로봇 연구소에서 검증되었으며, 다음 작업에서 자율 기술을 시연했습니다(말뭉치에서 명시적으로 나열):

  • 신발 신고 일어나 걷기: 로봇이 앉은 자세에서 신발을 신고 일어나 걷습니다.
  • 창고 선반 하역: 선반에서 물건을 내립니다.
  • 운동복 접기: 천 접기 작업을 수행합니다.
  • 물체 재배열: 흩어진 물체를 지정된 위치에 배치합니다.
  • 타이핑: 키보드 입력 동작을 수행합니다.
  • 다른 로봇과 인사하기: 사회적 상호작용 유형의 작업입니다.

위 작업은 모두 60–100%의 성공률로 완료되었으며, 각 작업은 최대 40회의 시연만 필요합니다(말뭉치 데이터 기준 추산). 이 시스템의 하드웨어 지원은 Inspire-Robots와 Unitree Robotics에서 제공하며, 실험 시설은 스탠포드 로봇 센터에서 제공합니다.

한계와 경계

  1. 데이터 의존성: 저수준 정책은 40시간 인간 운동 데이터 세트에 의존하며, 이 데이터 세트의 다양성이 섀도잉 추종의 일반화 능력을 직접 결정합니다. 데이터 세트에 포함되지 않은 동작 패턴(예: 극단적 자세, 복잡한 지면)에서는 정책이 실패할 수 있습니다(공학적 판단).
  2. 시각적 강건성: 단안 RGB 자세 추정은 폐색, 급격한 조명 변화, 빠른 움직임 시나리오에서 정확도가 떨어져 섀도잉 추종 품질에 영향을 줍니다. 말뭉치는 관련 정량적 지표를 제공하지 않으므로 직접 확인이 필요합니다.
  3. 행동 복제의 한계: 자율 기술은 지도식 행동 복제를 사용하므로 성능이 시연 품질과 수량에 제한됩니다. 복잡한 장기 작업(예: 다단계 조립)은 사용 가능한 수준에 도달하기 위해 40회 이상의 시연이 필요할 수 있습니다(공학적 판단).
  4. 시뮬레이션-실제 격차: 도메인 무작위화를 채택했지만, 시뮬레이션과 실제 간의 동역학적 차이는 특히 발 접촉, 부드러운 물체 상호작용과 같은 시나리오에서 정책 성능 저하를 초래할 수 있습니다.

일반적인 오해

  1. "HumanPlus는 모션 캡처 시스템이다" — 틀렸습니다. 모션 캡처 장비에 의존하지 않고 RGB 카메라만 사용합니다. 핵심 가치는 "시뮬레이션 훈련 + 정책 전이"에 있으며 단순한 모션 캡처가 아닙니다.
  2. "섀도잉 모드는 원격 조작만 할 수 있다" — 완전하지 않습니다. 섀도잉 모드는 동시에 데이터 수집 파이프라인이며, 수집된 데이터는 자율 기술 훈련에 사용되어 "섀도잉 → 데이터 → 기술"의 폐루프를 형성합니다.
  3. "행동 복제는 종단 간 학습이다" — 정확하지 않습니다. HumanPlus는 계층적 아키텍처를 채택합니다: 저수준 정책(강화 학습) + 고수준 기술 정책(행동 복제)으로, 단일 종단 간 모델이 아닙니다.
  4. "40회 시연으로 모든 작업을 해결할 수 있다" — 오해입니다. 60–100%의 성공률은 여러 작업의 평균 범위이며, 간단한 작업(예: 인사)은 100%에 가깝고 복잡한 작업(예: 옷 개기)은 60%에 가까울 수 있습니다(말뭉치 데이터 기준 추산).

관련 개체

기술

MimicGen

물체 자세 및 초기 조건을 변형하여 시뮬레이션에서 소량의 인간 시드 데모를 확장하는 데모 증강 프레임워크.

 개념

데모-제품 간격

데모를 위한 지표와 대량생산·인증 가능한 제품이 요구하는 지표 사이의 체계적 간극.

 방법

양방향 원격 조작

명령 신호는 마스터→슬레이브, 힘·촉각 피드백은 슬레이브→마스터로 흐르는 원격 조작 구조로 투명성과 안전성을 향상.

 기술

Mobile ALOHA

가정 및 창고 조작 데이터 수집을 위한 전신 이동 양손 텔레오퍼레이션 플랫폼.

 데이터셋

HumanPlus Shadowing 데이터셋

휴로봇으로 인간 동작을 따라 촬영하여 수집한 데이터셋으로, 전신 모방 및 원격 조작 정책 학습에 사용.

 기술

UMI 그리퍼 인터페이스

로봇 없이 실외 조작 시연을 수집할 수 있는 휴 대용 그리퍼 인터페이스.

 논문

TWIST2: Scalable, Portable, and Holistic Humanoid Data Collection System

TWIST2의 구현 경로는 먼저 카메라 이미지/다중 시점 관측, 인간 비디오/모션 캡처 궤적, 원격 조작/외골격 데이터를 다중 모달 표현으로 인코딩한 다음, ACT/행동 복제 모방…

 데이터셋

AMASS 모션 데이터셋

인체 형태와 자세를 포함한 대규모 클린 모션 캡처 데이터셋, 휨로봇 시뮬레이션 사전 학습에 널리 사용.

 논문

HumanPlus: Humanoid Shadowing and Imitation from Humans

HumanPlus는 주로 데이터 폐루프(data closed-loop) 문제를 해결한다: 카메라 이미지/다중 시점 관측, 본체 상태와 관절 시퀀스, 인간 비디오/모션 캡처 궤적을…

 개념

데이터 플라이휠

배포된 로봇이 데이터를 생성하고, 데이터가 AI 모델을 개선하며, 모델이 로봇 성능을 높여 더 많은 데이터를 생성하는 자기 강화 순환.

 기술

ALOHA 텔레오퍼레이션 시스템

모방 학습을 위한 인간 시연 데이터를 수집하는 저비용 양손 리더-팔로워 텔레오퍼레이션 하드웨어.
