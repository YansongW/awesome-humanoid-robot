Green-VLA: Staged Vision-Language-Action Model for Generalist Robots

요약

We introduce Green-VLA, a staged Vision-Language-Action (VLA) framework for real-world deployment on the Green humanoid robot while maintaining generalization across diverse embodiments. Institutions per source list: Sber Robotics Center.

출처

  • arXiv:2602.00919 Green-VLA: Staged Vision-Language-Action Model for Generalist Robots
  • Project page
  • GitHub仓库 Robotics_Notebooks

개요

Green-VLA는 Green 팀이 제안한 약 4B 파라미터 규모의 비전-언어-행동(VLA) 모델로, 범용 로봇 조작을 대상으로 한다. 핵심 기여는 5단계 훈련 커리큘럼(L0→L1→R0→R1→R2)을 제안하여 인터넷 규모 사전 훈련, 교차-본체 로봇 사전 훈련, 본체 미세 조정, 강화 학습 정렬을 체계적으로 통합하고, 통합 행동 공간, 데이터 품질 파이프라인(DataQA), 목표 균형 샘플링 등의 엔지니어링 수단을 함께 제공하여 ALOHA, SimplerEnv 및 휴머노이드 로봇 등 여러 벤치마크에서 π₀, OpenVLA 등 강력한 베이스라인을 크게 능가한다.

무엇을 바꾸었는가

진정으로 바꾼 것은 "VLA 훈련 패러다임"의 근본 논리이다. 더 이상 데이터 규모를 최우선 동력으로 삼지 않고, "품질 정렬, 행동 통일, RL 최적화"를 규모와 동등하거나 더 우선하는 지렛대로 삼는다. 기존 분야의 주류 접근법(예: π₀, OpenVLA)은 대규모 이질적 데이터 혼합 + 행동 클로닝(BC)에 의존했지만, BC는 빠르게 포화되고, 다중 본체 혼합 훈련 시 고모멘텀 최적화기(β₁=0.95–0.98)의 모멘텀 버퍼가 대규모 데이터셋의 그래디언트에 지배되어 희귀 본체가 "씻겨 나가는" 문제가 있었다. Green-VLA는 목표 균형 샘플링(αₜ를 0에서 1로 선형 증가)을 통해 샘플링 가중치 조정에만 의존하지 않고 메커니즘 수준에서 모드 망각을 완화한다.

동시에 "추론 지연"과 "시스템 처리량"을 엔지니어링 세부 사항에서 성공률과 동등한 일급 시민으로 승격시켰다. 기존의 명시적 추론 VLA(예: EO-1, WALL-OSS)는 자기회귀 루프에 의존하여 지연이 높다. Green-VLA는 플로우 매칭 행동 전문가 + SDPA 어텐션 커널 + 노이즈 제거 스텝 감소를 통해 높은 성공률을 유지하면서 추론 오버헤드를 압축한다. 또한 R2 단계의 RL 정렬 방식(궤적 최적화 + 소스 분포 최적화)은 플로우 매칭 모델이 전통적인 on-policy/off-policy RL에서 겪는 로그 확률 추정 문제와 값 그래디언트 역전파 불안정성을 우회하는데, 이는 "VLA에 RL을 어떻게 적용할 것인가"라는 공개 문제에 대한 실용적인 답변이다.

방법 분석

5단계 훈련 커리큘럼

  • L0(기본 VLM): 하위 비전-언어 모델(PaliGemma 3B), 로봇 행동 능력 없음.
  • L1(웹 사전 훈련): 2,400만 개의 비로봇 멀티모달 샘플로 물리 세계 이해와 의미론적 기반 구축.
  • R0(범용 로봇 사전 훈련): 1억 8,400만 개의 로봇 도메인 샘플(3,000시간 이상, 휴머노이드 및 로봇 팔 교차), 교차 본체 범용 사전 지식 학습. 48대 H100에서 10⁵ 스텝 이상 훈련.
  • R1(본체 특정 미세 조정): 목표 본체의 고품질 데이터셋 SFT로 범용 능력을 구체적 스킬로 전환.
  • R2(RL 정렬): BC 사전 지식과 RL 목표를 결합하여 장기 성공률, 견고성, 평균 체인 길이(ACL) 향상.

통합 행동 공간 (𝒜ᵤ)

  • 고정 의미론적 레이아웃의 64차원 통합 행동 공간으로 단순 패딩을 대체하고, 매핑 함수 Φₑ와 이진 마스크 mₑ를 통해 다중 본체 제어를 구현하여 패딩으로 인한 허위 그래디언트 제거.
  • 동적 본체 및 제어 유형 프롬프트 cₑ(팔 수, 손 수, 그리퍼/다섯 손가락 손, 관절/데카르트, 이동/정적, 슬롯 사용)로 행동 매핑을 명시화.

목표 균형 샘플링(Target-balanced sampling)

  • 샘플링 가중치: Wᵢ^(t) = wᵢ^αₜ / Σⱼ wⱼ^αₜ, αₜ ∈ [0,1], α₀=0, α_T=1.
  • 균일 혼합(α=0)에서 편향 분포(α=1)로 점진적 수렴하여 초기 붕괴를 지배적 본체로 방지하고, 모델이 먼저 공유 구조를 학습한 후 전문화하도록 함.

행동 정렬(Action alignment)

  • 단조 3차 스플라인으로 궤적을 리샘플링하고 행동을 보간하여 각 스텝의 유효 운동을 정규화.
  • 손목 카메라 평균 광류 크기로 각 데이터셋의 실행 속도 추정: 낮은 수집 빈도 데이터셋(Bridge, Fractal)은 프레임 간 광류가 커서 행동 밀집화 필요, 높은 빈도지만 느린 데이터셋(AgiBot DexHand)은 다운샘플링으로 가속.

시간 스케일 조건화(Temporal Scale Conditioning)

  • 각 샘플에 스칼라 속도 인자 v ~ p(v)를 추출하고, 보간/리샘플링으로 목표 궤적 왜곡: v>1은 느리게, v<1은 압축.
  • 행동 전문가 은닉 상태에 RMS 스타일 변조 적용: ĥₜ = γ(v)RMSNorm(hₜ) + β(v), γ, β는 v의 소형 학습 함수.
  • 추론 시 v는 하이퍼파라미터로, 로컬 정밀도와 장기 효율성 간의 균형을 조정.

에피소드 진행도(Episode progress)

  • 플로우 매칭 행동 전문가가 정규화된 진행 신호 ρ̂ₜ ∈ [0,1]을 공동 예측하고, 훈련 목표 ρₜ = t/T를 하위 계획자에 노출하여 지시 업데이트 요청.

OOD 탐지기

  • 온라인 탐지기는 훈련 세트 상태에 대한 가우시안 혼합 모델로 모델링: p_train(s) = Σₖ φₖ 𝒩(s|μₖ, Σₖ).
  • 예측 행동이 p_train(s) < τ_ood를 초래하면, 수정 상태 s + α∇p_train(s), α=0.2로 행동 재계산.

공동 예측 모듈(JPM)

  • 전용 VLM이 2D 조작 가능 지점 (u,v)을 예측하고, 깊이 d, 내부 파라미터 K, 카메라 포즈 T_c^w를 통해 3D로 승격: [p⋆; 1] = T_c^w [d(u,v)K⁻¹[u,v,1]ᵀ; 1].
  • IK를 풀어 실현 가능한 관절 구성 q⋆를 얻고, 의사 역행렬 안내(ΠGDM)로 각 노이즈 제거 스텝에서 속도 필드를 수정하여 사전 지식을 유지하면서 목표 제약을 충족.

R2 RL 미세 조정——궤적 최적화

  • R1 데이터에서 소형 독립 평가자(Implicit Q-Learning) 훈련: L_V(ψ) = 𝔼[L₂^τ(Q_θ̂(s,a) − V_ψ(s))], L_Q(θ) = 𝔼[(r + γV_ψ(s′) − Q_θ)²].
  • 기본 모델이 궤적 생성 후, ∇ₐQ(s,a)를 계산하고 정규화한 뒤 η 배율로 행동에 추가: a ← a + η·∇ₐQ/‖∇ₐQ‖, N회 반복.
  • Q가 최적이 아니므로, 최적화된 궤적은 환경에서 검증 필요(운영자가 초기 상태 복원, 개선 궤적 실행 및 저장).

R2 RL 미세 조정——소스 분포 최적화

  • actor-critic으로 소형 독립 actor 네트워크를 훈련하여 기본 모델에 입력되는 랜덤 노이즈를 생성하고 환경 보상을 최대화.
  • 기본 모델의 행동 생성 경향은 훈련 데이터 근처에 유지되므로, 노이즈 분포가 편향되어도 상대적으로 안전.

핵심 혁신

  1. 5단계 훈련 커리큘럼의 체계적 설계: 인터넷 사전 훈련(L1), 교차 본체 로봇 사전 훈련(R0), 본체 미세 조정(R1), RL 정렬(R2)을 명시적으로 계층화하고, 각 단계에 명확한 데이터 규모와 목표를 부여. 단순한 적층이 아니라 "범용 사전 지식"과 "본체 전용"을 분리——R0는 1억 8,400만 샘플로 교차 본체 공통성을 학습하고, R1은 고품질 데이터로 스킬 전환, R2는 RL로 장기 목표 정렬. π₀의 엔드투엔드 혼합 훈련과 달리, 이 계층화는 각 단계를 독립적으로 디버깅하고 평가할 수 있게 한다.

  2. 목표 균형 샘플링(αₜ 어닐링): 다중 본체 혼합 훈련의 "모드 망각" 문제를 직접 겨냥. 균일 혼합(α=0)에서 시작하여 희귀 본체가 초기 표현 학습에 기여하도록 한 후, 점진적으로 편향 분포(α=1)로 전환. 이는 고모멘텀 최적화기(β₁=0.95–0.98)의 동작 특성에 대한 맞춤형 설계——초기 균형은 모멘텀 버퍼가 대규모 데이터셋에 지배되지 않도록 보장.

  3. R2의 "비침습적" RL 미세 조정: 궤적 최적화(∇ₐQ 안내)와 소스 분포 최적화(actor 노이즈 생성) 모두 기본 모델 가중치를 직접 수정하는 RL 그래디언트 경로를 우회. 이는 플로우 매칭 모델이 전통적 RL에서 겪는 두 가지 핵심 난제를 회피: on-policy 방법(PPO/GRPO)의 로그 확률 추정 어려움, off-policy 방법의 값 그래디언트가 반복 생성 과정을 통한 역전파 불안정성. 엔지니어링적으로 더 견고하고 BC 사전 지식을 보존.

실험 및 결과

대조 실험은 단일 팔 로봇 팔, 이중 팔 이동 플랫폼에서 전신 휴머노이드까지 다양한 구현체 범위를 포괄하며, 베이스라인에는 π₀, GR00T N1, AgiBot GO-1, WALL-OSS, OpenVLA, RT-1-X, Flower, DB-MemVLA 등이 포함된다. 평가 지표는 성공률(SR)을 중심으로 평균 완료 시간, 평균 체인 길이(ACL) 등을 보조로 사용. 훈련은 5단계 커리큘럼을 따름: L0(기본 VLM) → L1(웹 사전 훈련, 2,400만 비로봇 멀티모달 샘플) → R0(범용 로봇 사전 훈련, 1억 8,400만 로봇 도메인 샘플, 총 3,000시간) → R1(구현체 SFT) → R2(RL 정렬). R0는 48대 H100 GPU에서 10⁵ 최적화 스텝 이상 훈련하며, 데이터량은 π₀의 10,000시간 이상(논문은 π₀의 구체적 데이터량을 명시하지 않고 > 10,000 hours만 제공)보다 현저히 적다. 아래 표는 각 단계의 핵심 결과를 요약한다.

결과 의미 요점:

  • R0 사전 훈련 단계에서 강력한 일반화 발휘: ALOHA 데스크톱 정리에서 Green-VLA(R0)의 첫 번째 물품 성공률 69.5%는 π₀의 35.6%보다 현저히 높으며(표 내 수치 35.6→69.5로 계산, 상대적 향상 약 95%), 평균 완료 시간 1m35s는 π₀의 2m59s보다 훨씬 빠르다. Simpler Google Robot에서 R0 평균 성공률 60.2%는 이미 π₀ 미세 조정 후의 56.8%를 초과하며, 특정 구현체에 대한 추가 튜닝이 필요 없다. 이는 통합 행동 공간과 마스크 BC 목표가 단순 제로 패딩의 "가짜 페널티" 그래디언트를 효과적으로 제거하여 다중 구현체 사전 훈련 데이터가 서로 방해하지 않고 상호 촉진할 수 있음을 시사한다.

  • R1→R2의 RL 정렬로 지속적이고 현저한 이득: Simpler WidowX에서 R0에서 R1, R2로 갈수록 평균 그립 성공률이 75.0% → 76.1% → 91.7%로, 평균 작업 성공률이 45.0% → 55.2% → 79.1%로 상승. Simpler BRIDGE WidowX 환경에서 R2 정렬은 R1 모델 성공률을 절대 24% 향상(논문 원문 an absolute 24%). Google Robot에서 R2 평균 성공률 71.8%는 R1의 61.3% 대비 뚜렷한 향상(표 내 수치 61.3→71.8로 계산). 저자는 행동 클로닝이 장기 및 접촉이 풍부한 조작에서 빠르게 포화되지만, R2의 보상 형성 정제가 특히 장기 일관성, 오류 복구, 정밀 작업 준수 측면에서 이 병목을 효과적으로 극복한다고 지적한다.

  • 데이터 규모와 다양성은 사전 훈련 품질의 핵심 지렛대: R0는 3,000시간의 통합 다중 구현체 데이터를 사용하며, π₀의 10,000시간 이상(논문은 π₀의 구체적 데이터량을 명시하지 않고 > 10,000 hours만 제공)보다 현저히 적지만 여러 벤치마크에서 π₀ 미세 조정 성능에 도달하거나 초과. 데이터 혼합에서 AgiBot twofinger는 가장 크고(774시간) 시각적 다양성이 가장 높아(D_vis=0.149) 최고 샘플링 가중치 0.210을 획득; DROID는 501시간, D_vis=0.140 및 0.129의 샘플링 가중치로 다음; Galaxea는 477시간, D_vis=0.168로 ALOHA 계열 데이터 중 시각적 다양성이 가장 높음. 자체 수집 Green Humanoid 데이터는 미러 및 시간 반전 증강으로 48시간 원본 데이터에서 167 훈련 시간으로 확장되어 0.089의 샘플링 가중치로 훈련에 참여. 이러한 다양성 지표 기반 가중 샘플링 전략은 제한된 데이터량에서도 광범위한 작업 및 스킬 분포를 포괄할 수 있게 한다.

경계와 한계

  • 리타게팅 충실도 의존성: 성능은 여전히 retargeting fidelity, 잔여 데이터셋 편향, 손재주 스킬 커버리지에 의해 제한. 소스 로봇 행동에서 목표 본체로의 매핑이 정확하지 않으면 R0에서 학습한 사전 지식이 R1을 편향시킬 수 있음.
  • 다국어 및 추론 모듈 부재: 다국어 지시 따르기 미구현, 경량 작업 분해 추론 모듈(사고 사슬 계획과 실시간 실행 결합) 미통합, 구현체 메모리 및 궤적 재생 미포함.
  • v는 하이퍼파라미터: 추론 시 시간 스케일 인자 v는 수동 설정 필요, 향후 상위 계획자가 자동 제어할 예정.
  • R2 궤적 최적화는 개선을 보장하지 않음: 저자는 Q 함수가 최적이 아니고 하이퍼파라미터(η, N)가 휴리스틱하게 튜닝되었음을 명시적으로 인정하며, 최적화된 궤적이 악화될 수 있어 환경 검증이 필요.
  • 명시되지 않은 파라미터: JPM의 VLM 구체적 모델, OOD 임계값 τ_ood, η와 N의 구체적 수치, v의 샘플링 분포 p(v)는 논문에 제공되지 않음.

엔지니어링 시사점

  • 먼저 샘플링 어닐링 곡선 확인: 목표 균형 샘플링(αₜ 0에서 1)은 다중 본체 모드 망각 방지의 핵심. 재현 시 αₜ의 스케줄 스텝 수와 총 훈련 스텝 수가 일치하는지 먼저 확인——α 증가가 너무 빠르면 희귀 본체가 여전히 씻겨 나가고, 너무 느리면 대형 본체가 과소적합.
  • 행동 정렬은 암묵적 병목: 데이터셋 간 실행 속도 차이(손목 카메라 광류로 추정)는 혼합 훈련 효과에 직접 영향. 재현 시 각 데이터셋의 평균 광류 크기를 먼저 계산한 후 보간/다운샘플링 전략을 결정해야 하며, 그렇지 않으면 모델의 역학 규모 기대가 혼란.
  • R2의 검증 루프는 건너뛸 수 없음: 궤적 최적화(∇ₐQ 안내)는 개선을 보장하지 않으므로 환경 검증 단계(초기 상태 복원, 개선 궤적 실행, 결과 저장)를 반드시 배포해야 함. 이 단계를 건너뛰면 악화된 궤적이 R1 데이터셋에 혼입되어 누적 오염을 초래할 수 있음.
  • 통합 행동 공간의 마스크 설계: 64차원 통합 행동 공간은 Φₑ와 mₑ의 올바른 구현에 의존. 단순 패딩은 허위 그래디언트를 생성하므로, 재현 시 먼저 서로 다른 본체 간 행동 슬롯의 의미론적 정렬이 일관적인지 검증.
  • 추론 최적화 관심 지점: SDPA 어텐션 커널과 플로우 매칭 노이즈 제거 스텝 감소는 지연 압축의 주요 수단. 하위 시스템이 실시간에 민감하면 모델 규모보다 이 두 가지를 우선 조정.
  • 데이터 품질 파이프라인(DataQA) 지표: 지터(J), 선명도(S), 다양성(D), 상태 분산(σ²)의 임계값은 본체별로 조정 필요——예: AgiBot twofinger의 D_state=3975는 DROID의 3.10보다 훨씬 높아, 통일 임계값을 직접 적용하면 유효 데이터가 잘못 삭제될 수 있음.
