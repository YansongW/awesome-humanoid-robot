Ego-Pi: VLA Fine-Tuning for Ego-Centric Human and Robot Data

Ego-Pi: VLA Fine-Tuning for Ego-Centric Human and Robot Data

요약

Robotics faces a fundamental challenge of data scarcity. Unlike language or vision research, there is no internet-scale dataset for robotic manipulation. Institutions per source list: Stanford、Meta.

출처

  • arXiv:2606.08107 Ego-Pi: VLA Fine-Tuning for Ego-Centric Human and Robot Data

개요

Ego-Pi는 π₀.₅ 기반 VLA 미세 조정 방법을 제안하며, 자기중심적 인간 비디오 데이터를 활용하여 손재주 로봇에 고수준 작업 의미론(예: 정렬, 조합, 규칙)을 주입한다. 목표 작업의 로봇 시연 없이도 가능하다. 핵심 기여는 동작 인터리빙, 골격선 시각적 정렬, 하위 작업 보조 손실을 통해 사전 훈련된 아키텍처를 유지하면서 교차-구현 의미론적 전이를 달성하고, 토마토 분류, 상자 포장, 패키징 세 가지 작업에서 로봇 데이터만으로 훈련된 기준선을 크게 능가하는 것이다.

그것이 바꾸는 것

로봇 학습은 오랫동안 데이터 부족에 시달려 왔으며, 물리적 하드웨어 수집 비용이 높고 규모가 제한적이다. 이전의 인간-로봇 공동 훈련(예: EgoMimic, PH²D)은 주로 분포 내 성능 향상이나 동일 작업 일반화에 초점을 맞추었으며, 교차-구현 고수준 작업 의미론 전이—즉 로봇 데이터에 존재하지 않는 '규칙'이나 '조합 논리'—에는 도달하지 못했다. Ego-Pi가 실제로 바꾸는 것은: 인간 데이터가 로봇 데이터의 양을 보완할 뿐만 아니라 로봇 데이터에 없는 '작업 의도'를 제공할 수 있으며, 이러한 의도가 인간 시연만으로 주입될 수 있고 목표 작업의 로봇 시연이 필요 없다는 것을 증명한 것이다. 이는 로봇 학습에 '먼저 기술을 배우고, 나중에 규칙을 배우는' 경로를 열어, 데이터 부족의 병목을 하드웨어 수집에서 인간 비디오 수집으로 전환시킨다. 후자는 비용이 낮고 규모가 크며 획득이 쉽다.

방법 분해

기본 아키텍처 및 훈련 목표

  • π₀.₅(flow-matching VLA) 기반으로, 사전 훈련된 비전-언어 모델을 로봇 제어로 확장한다.
  • 흐름 매칭 손실: ℒ = 𝔼_{τ,ω}[‖ω − a_{t:t+H} − f_θ(a_{t:t+H}^{τ,ω}, o_t, ℓ_t)‖²], 여기서 τ∈[0,1]은 흐름 시간 인덱스, ω~𝒩(0,I)는 가우시안 노이즈, a_{t:t+H}^{τ,ω} = τ·a_{t:t+H} + (1−τ)·ω는 부분적으로 노이즈가 제거된 동작이다.

동작 표현 정렬(로봇 중심 정렬)

  • 인간 손의 20개 키포인트(MANO 규약)를 각 링크 관절 각도로 변환한 후 로봇 관절 공간에 매핑한다.
  • 로봇 손은 원래 관절 각도를 직접 사용한다.
  • 정책 손 동작 a = {p, r, q} ∈ ℝ²⁹, 여기서 p∈ℝ³는 손목 위치, r∈ℝ⁶는 6D 회전 형식의 손목 자세, q∈ℝ²⁰는 로봇 손의 20개 관절 각도(Inspire 손은 q∈ℝ⁶).
  • 핵심 결정: 고차원 로봇 손(예: Tesollo 손 20개 활성 관절)의 경우 역운동학/최적화 방법은 자체 충돌이나 부자연스러운 손 자세를 유발하기 쉬우므로 직접 관절 각도 매핑을 사용한다.

동작 인터리빙(Token Interleaving)

  • π₀.₅의 최대 동작 차원은 32이지만, 손재주 손은 한 손당 29차원, 양손은 총 58차원으로 용량을 초과한다.
  • 최종 투영 레이어 출력 차원을 직접 늘리면 훈련 손실이 증가하고 사전 훈련 가중치가 손상된다.
  • 해결책: 왼손과 오른손 동작을 두 개의 동작 토큰에 분배(58차원을 두 개의 32차원 토큰에 분배), 유효 horizon이 H에서 H/2로 감소한다.
  • 이유: 사전 훈련 아키텍처와 매개변수를 보존하여 모델이 잘 수렴할 수 있게 한다.

시각적 정렬(골격선 오버레이)

  • 입력 이미지에 안내 골격선을 오버레이하고, 각 손가락에 고유한 색상을 할당하여 모델이 서로 다른 구현의 손가락 대응 관계를 이해하게 한다.
  • 깊이 인식, 폐색 인식 드로잉 방식 사용: 카메라에서 더 먼 손가락은 더 가까운 손가락 뒤에 그려진다.
  • 이유: 색상 코딩과 폐색 인식 드로잉이 없으면 선이 어느 손가락에 해당하는지 구별하기 어렵다.

보조 손실(하위 작업 생성)

  • VLM 구성 요소를 훈련하여 하위 작업 문자열을 출력하게 하고, 동작 예측 전의 중간 단계로 사용하여 정책이 '먼저 생각한 다음 행동'하도록 한다.

훈련 세부 사항

  • 인간과 로봇 데이터 배치 비율은 50%(1:1).
  • 인간 데이터에는 손목 이미지가 없으며, 로봇 손목 이미지는 40% 확률로 버려져 입력 일관성을 유지한다.

핵심 혁신

  1. 교차-구현 고수준 의미론 전이: 인간 데이터만으로 로봇이 로봇 데이터에 존재하지 않는 고수준 작업 의미론(예: 정렬 논리, 기술 조합, 규칙 순서)을 학습할 수 있고, 새로운 목표 작업의 로봇 시연이 필요 없다는 것을 처음으로 증명했다. 이는 이전 공동 훈련이 분포 내 성능에만 초점을 맞춘 한계를 돌파했다.
  2. 동작 인터리빙(Token Interleaving): 사전 훈련 가중치를 손상시키지 않으면서 58차원 손재주 손 동작을 두 개의 32차원 동작 토큰에 분배하여 π₀.₅의 동작 차원 상한 문제를 해결했다. 이 설계는 사전 훈련 아키텍처와 매개변수를 보존하여 모델이 잘 수렴하게 하며, 공학적 핵심 혁신이다.
  3. 골격선 시각적 정렬: 깊이 인식, 폐색 인식 컬러 골격선 오버레이를 통해 모델이 서로 다른 구현의 손가락 대응 관계를 이해하게 하여 교차-구현 시각적 정렬의 모호성 문제를 해결했다. 토마토 분류 작업에서는 정량적 개선이 없었지만, 상자 포장 작업에서는 기술 조합의 의미론적 이해에 암묵적 도움이 될 수 있다.

실험 및 결과

작업 로봇 데이터만 단순 공동 훈련 공동 + 하위 작업 예측 비고
토마토 색상별 분류 40%(무작위 배치) 92% — 로봇 데이터는 단일 그릇 배치를 가르치고, 인간 데이터는 다중 그릇 색상별 분류를 가르친다
상자 포장(Inspire 손) 20% 27% 93% 로봇 데이터는 상자 열기와 블록 배치를 가르치고, 인간 데이터는 조합을 가르친다
상자 포장(Tesollo 손) — — 67% Tesollo 손은 상태 입력에 비정상적으로 민감하다
패키징(규칙 순서) 10% 90% — 로봇 데이터는 작은 상자와 곰 인형 배치를 가르치고, 인간 데이터는 '작은 상자 먼저, 곰 나중'을 가르친다
  • 골격선 오버레이는 토마토 분류 작업에서 정량적 또는 정성적 개선이 없었다.
  • 테스트 시 손목 카메라를 버리면 토마토 분류에서 로봇이 토마토를 안정적으로 잡기 어려워 성능이 크게 저하된다.
  • Inspire 손이 Tesollo 손보다 우수하며(인간 손 크기에 더 가까움), Tesollo 손은 상자 포장 작업에서 하위 작업 예측이 있어도 성공률이 67%에 불과하다.

경계 및 한계

  • 단기간, 단순 집기-놓기 유형 작업만 탐구했으며, 고정 카메라 장면이다.
  • 장기간, 손재주 조작 작업은 평가하지 않았으며, 이동 조작은 포함하지 않았다.
  • 인간 데이터는 고수준 작업 의미론(기존 기술 연결)에만 사용되었으며, 저수준 기술 직접 전이는 구현되지 않았다.
  • 로봇이 필요한 저수준 기술을 이미 갖추고 있다고 가정하며, 직접적인 저수준 기술 전이는 열리지 않았다.
  • 실제 세계에서 EgoVLA를 평가하지 않았다(참고 [4]의 한계).
  • 더 복잡한 장면(예: 폐색, 동적 환경)에 대한 평가는 언급되지 않았다.
  • 논문은 추론 빈도와 GPU 모델/수량을 명시하지 않았다.

공학적 시사점

  • 먼저 동작 차원 상한을 확인하라: VLA 기본 모델의 동작 차원이 손재주 손 요구보다 낮다면, 투영 레이어를 직접 확장하는 것보다 동작 인터리빙을 우선 고려하라. 후자는 사전 훈련 가중치를 손상시키기 쉽다.
  • 인간 데이터 비율은 핵심 하이퍼파라미터: 50%의 1:1 비율은 저자가 검증한 효과적인 구성이지만, 작업에 따라 조정이 필요할 수 있다. 50%에서 시작하여 훈련 손실 곡선이 안정적인지 관찰하라.
  • 손목 카메라는 임의로 버릴 수 없다: 테스트 시 손목 카메라를 버리면 토마토 잡기 성능이 크게 저하되며, 이는 손목 시각이 근거리 조작에 필수적임을 의미한다. 훈련 시 40% 확률로 버리는 것은 인간 데이터 입력과 정렬하기 위함이지만, 추론 시에는 반드시 유지해야 한다.
  • 하위 작업 예측은 조합 유형 작업에 필수적이다: 상자 포장 작업에서 하위 작업 예측을 추가한 후 성공률이 27%에서 93%로 급등했다. 이는 '먼저 생각한 다음 행동'이 기술 조합 유형 작업에 상당한 이득을 준다는 것을 의미한다. 작업이 다단계라면 반드시 이 보조 손실을 추가하라.
  • 손 유형 선택이 일반화에 영향을 미친다: Inspire 손(6 관절)이 Tesollo 손(20 관절)보다 우수하며, 후자는 상태 입력에 비정상적으로 민감하다. 하위 작업이 상태 노이즈에 민감하다면 인간 손 크기에 더 가까운 말단 실행기를 우선 선택하라.
  • 골격선 오버레이는 만능이 아니다: 토마토 분류에서는 개선이 없었지만, 상자 포장에서는 기술 조합의 의미론적 이해에 암묵적 도움이 될 수 있다. 교차-구현 손가락 대응 관계가 관련된 작업에서는 유지하고, 단순 작업에서는 생략할 수 있다.
