개요

GE-Sim 2.0은 NVIDIA 팀이 제안한 폐루프 비디오 세계 시뮬레이터로, 2B 파라미터의 동작 조건부 비디오 생성 백본에 고유수용감각 상태 전문가, 세계 심판, DMD2 증류 가속의 세 가지 모듈을 추가하여 비디오 생성을 "시각적 예측만 하는 것"에서 "폐루프 평가와 학습이 가능한 완전한 시뮬레이터"로 발전시켰습니다. 핵심 기여는 상태 예측, 보상 평가, 고효율 추론을 단일 프레임워크에 처음으로 통합한 것이며, WorldArena 순위표에서 1위를 차지했고 폐루프 성공률과 실제 로봇 간의 일관성은 1 pp 이내입니다.

그것이 바꾼 것

로봇 학습은 "알고리즘 중심"에서 "데이터 중심"으로 전환되고 있지만, 평가 단계는 여전히 병목입니다. 실제 로봇 벤치마크 테스트는 느리고 재현이 어려우며, 고전 물리 시뮬레이터(MuJoCo, Isaac Gym 등)는 접촉 역학, 변형 가능한 물체, 시각적 사실성에서 근본적인 한계가 있습니다. 생성형 비디오 모델은 새로운 경로를 제공하지만, 기존 비디오 세계 시뮬레이터(GE-Sim 초기 버전 포함)에는 세 가지 치명적인 결함이 있습니다. 시각만 예측하고 고유수용감각 상태를 출력하지 않으며, rollout만 생성하고 검증 가능한 성공 신호를 제공하지 않으며, 추론 처리량이 대규모 병렬 평가 요구보다 훨씬 낮습니다.

GE-Sim 2.0이 진정으로 바꾼 것은 "비디오 세계 모델이 할 수 있는 것"의 경계입니다. 더 이상 수동적인 비디오 생성기가 아니라 능동적인 폐루프 평가기입니다. 고유수용감각 상태 예측, 판단 보상, 가속 추론을 단일 프레임워크에 통합함으로써 "시뮬레이터에서 정책을 훈련하고 평가하는 것"이 처음으로 실제 세계에 가까운 신뢰성을 갖게 되었습니다. 이는 단순한 엔지니어링 개선이 아니라 비디오 세계 모델의 로봇 학습 파이프라인 내 역할을 "시각화 도구"에서 "검증 가능한 시뮬레이션 환경"으로 재정의한 것입니다.

방법 분석

전체 아키텍처

GE-Sim의 동작 조건부 비디오 생성 백본(Cosmos-Predict2-2B-Video2World DiT)을 유지하고 수천 시간의 실제 로봇 데이터로 재훈련했으며, 세 가지 병렬 모듈을 추가했습니다. 시각 전문가(Visual Expert), 고유수용감각 상태 전문가(Proprioceptive State Expert), 세계 심판(World Judge), 그리고 DMD2 증류 가속 프레임워크입니다.

시각 전문가

  • 조건 입력: z_cond = [z_noisy; R_ray; M_pose; m_cond], 여기서 R_ray는 6채널 픽셀별 레이 맵(원점+단위 방향), M_pose는 3채널 EE 포즈 맵, m_cond는 메모리 프레임과 예측 대상 프레임을 구분하는 1채널 이진 마스크입니다.
  • 모든 입력은 [-1,1]로 정규화되어 확산 훈련 스케일 불일치를 방지합니다.
  • 훈련 손실: 흐름 매칭 목표 L_video = w(τ) ||(v_θ - (ε - l)) ⊙ (1 - M)||_2^2, 예측 대상 프레임에서만 계산됩니다.
  • 메모리 프레임 강화: 점진적 노이즈 혼합(σ_mem=0.2, 첫 프레임 σ_first=0.5), 국소 가우시안 블러(커널 크기 [1,5]), 다중 시점 동기 색상 지터(확률 0.3), 모두 외부 활성화 확률 0.8로 게이트됩니다.

고유수용감각 상태 전문가

  • 경량 Transformer 분기로, 시각 전문가의 모든 L 레이어 출력을 가중 융합(학습 가능한 스칼라 α_l 초기값 1)한 후 LayerNorm을 적용합니다. H_fuse = LayerNorm(Σ α_l h_l_video).
  • 상태 표현: 16차원 s_t = [θ_t^L, g_t^L, θ_t^R, g_t^R](7차원 관절 각도 + 그리퍼 개폐도).
  • 훈련 손실: L_proprio_state = E ||v_φ(s_τ, τ, H_fuse) - (ε - s_0)||_2^2, 시각 전문가는 동결됩니다.
  • 과거 상태 강화: 델타 인덱스 오프셋(Δ~Uniform{−3,…,3}) 및 시간 리샘플링(n_prev→n_prev−1→n_prev 저역 통과 보간), 각각 확률 0.5로 독립 적용됩니다.

세계 심판

  • Robometer 기반의 시각-언어 보상 모델로, 시각 인코더는 동결하고 언어 모델과 예측 헤드만 훈련합니다.
  • 각 프레임을 개별 입력으로 처리하고 전용 프레임별 토큰을 추가하며, 숨겨진 상태 f_i를 프레임 표현으로 사용합니다.
  • 프레임별 성공 예측 목표만 훈련합니다(진행도 예측 포기). 이유: 실제 궤적에는 오류 복구 동작이 포함되어 있어 진행도 레이블이 노이즈가 많고 비단조적입니다.
  • 손실: 클래스 균형 이진 교차 엔트로피 L_judge = Σ m_i w_i BCE(σ(s_hat_i), y_i) / Σ m_i w_i.

DMD2 증류 가속

  • 3단계 증류: 동결된 교사(주 훈련 단계의 시각 전문가), 소수 스텝 학생(목표 4스텝), 훈련 가능한 fake-score critic.
  • 분포 정합 기울기: ∇_DMD = (x₀^fake − x₀^teacher) / ‖x₀^student − x₀^teacher‖.
  • 학생은 5스텝마다 업데이트되고 critic은 나머지 4스텝에서 업데이트됩니다. 학생의 고정 sigma 스케줄은 [1.0, 0.9375, 0.8333, 0.625]입니다.
  • 무작위 스텝 크기 훈련: 각 chunk 프레임을 무작위 시간 스텝 크기로 샘플링하고, 추론 시 프레임을 건너뛸 수 있어 최대 4배 시간 범위를 커버합니다.

핵심 혁신

  1. 상태 예측과 시각 생성의 결합 모델링: 고유수용감각 상태 디코더를 비디오 생성기와 병렬로 처음 통합했으며, 학습 가능한 가중치 α_l을 통해 레이어 간 시각 컨텍스트 융합을 구현합니다. 이는 순수 시각 시뮬레이터에서 "명령 동작이 노이즈 대리자로 사용되어 드리프트하는" 근본적인 문제를 해결하여 폐루프 rollout에서 상태 누적 오차를 제어 가능하게 만듭니다.

  2. 세계 심판의 "희소 성공 신호" 설계: 진행도 예측을 포기하고 프레임별 성공 이진 분류만 사용하는 것은 실제 로봇 데이터 특성에 대한 깊은 통찰입니다. 궤적에는 우회, 재시도, 일시적 후퇴가 일반적이며 진행도 레이블은 비단조적이고 노이즈가 있습니다. 이 설계로 WM rollout에서 보상 신호 정확도가 79%에 달하며, 122B 파라미터의 Qwen3.5보다 19 pp 높습니다.

  3. DMD2 증류 + 무작위 스텝 크기 훈련의 결합 가속: 100프레임 rollout을 분 단위에서 2.3초(단일 H100, 4스텝)로 압축했으며, 무작위 스텝 크기 훈련은 추론 시 4배 프레임 건너뛰기를 지원합니다. 이는 대규모 병렬 평가를 처음으로 가능하게 만든 "폐루프 시뮬레이터"가 개념에서 엔지니어링 실용으로 전환되는 핵심 단계입니다.

실험 및 결과

WorldArena 순위표

GE-Sim 2.0은 2B 파라미터로 공개 순위표에서 1위를 차지하며 전용 로봇 세계 모델(Ctrl-World, DreamDojo, GigaWorld, ABot)과 폐쇄형 범용 비디오 생성기(Sora, Veo)를 능가했습니다.

폐루프 일관성(그림 8, 10)

  • 상태 조건 포함 시 피팅 추세 기울기가 1에 가깝고 작은 음의 오프셋이 있으며, 상태 조건 제거 시 추세가 더 얕아지고 양의 오프셋이 발생합니다.
  • 세그먼트 수준 정확도: 상태 포함 0.81 / 미포함 0.74 / Ctrl-World 0.63; 재현율: 0.82 / 0.67 / 0.25.

절제

  • 상태 전문가 제거: 세그먼트 수준 정확도 0.81→0.74, 재현율 0.82→0.67.
  • 세계 심판을 Qwen으로 교체: WM 모드 정확도 19 pp 하락, 이벤트 거리 30프레임 증가.

경계 및 한계

  • 접촉이 많은 작업(Pull out plug, Command grasp & release)에서는 여전히 거짓 양성 및 거짓 음성이 존재하며, 세밀한 접촉 상태와 장기 상태 누적은 여전히 과제입니다.
  • Pour water 및 Borrow flame에서 소규모 시각 신호(액체 레벨, 화염 전달) 감지는 여전히 미해결 문제입니다.
  • 기본 모델은 고정된 체형의 이팔 원격 조작 및 로봇 재생 데이터에서만 훈련되었으며, 체형 간, ego-view, UMI 스타일 데이터로 확장되지 않았습니다.
  • 세계 심판은 외부 모듈로, 단일 세계 모델로 통합되지 않았습니다(저자가 향후 방향으로 명시).
  • 실험은 오프라인 필터링 행동 클로닝만 검증했으며, 시뮬레이터 내 온라인 정책 학습이나 강화 학습은 수행하지 않았습니다.
  • 폐루프 및 절제는 단일 VLA 정책 계열(π_0.5)만 사용했으며, 더 넓은 정책 범위에서 검증되지 않았습니다.
  • 논문은 데이터 규모의 구체적 수치, 총 훈련 시간, 배치 크기 등의 엔지니어링 세부 사항을 언급하지 않았습니다.

엔지니어링 시사점

GE-Sim 2.0을 재현하거나 채택할 때 다음 항목을 우선적으로 확인하십시오.

  1. 메모리 프레임 강화 파라미터: 외부 활성화 확률 0.8, 점진적 노이즈 σ_mem=0.2, 첫 프레임 σ_first=0.5, 국소 블러 커널 [1,5], 색상 지터 확률 0.3 — 이러한 파라미터는 자기회귀 rollout의 분포 오프셋 제어 효과를 직접 결정하므로 논문 설정을 엄격히 따르고 임의로 조정하지 마십시오.

  2. DMD2 증류의 sigma 스케줄: 고정 [1.0, 0.9375, 0.8333, 0.625]는 고노이즈 영역에 집중되어 있으며, 생성기 업데이트 shift=3, critic 업데이트 shift=5, critic 손실 가중치 1/σ² — 이러한 세부 사항은 증류 안정성에 중요하며, 이탈 시 학생 모델 붕괴로 이어질 수 있습니다.

  3. 과거 상태 강화의 검증 시 비활성화: 델타 인덱스 오프셋과 시간 리샘플링은 훈련 시에만 활성화되며, 검증 시 반드시 꺼야 합니다. 그렇지 않으면 평가 결과가 오염됩니다.

  4. 가장 함정에 빠지기 쉬운 부분: 상태 전문가 훈련 시 시각 전문가는 완전히 동결해야 합니다. EE 포즈 맵 렌더러는 훈련과 추론에서 일관성을 유지해야 합니다(논문에서 명시적으로 강조). 세계 심판은 각 프레임을 개별 입력으로 처리하고 시간 축을 따라 평균하지 않으며, 텍스트 조건은 전체 작업 지시가 아닌 현재 청크와 일치하는 하위 작업 제목을 사용합니다.

  5. 하드웨어 요구 사항: 단일 H100에서 100프레임 rollout 생성은 약 2.3초(4스텝)이며, 이는 가속 후 결과입니다. 증류되지 않은 교사 모델의 추론 비용은 한 자릿수 더 높으므로, 연산 계획 시 증류 훈련 비용을 예비로 확보해야 합니다.
