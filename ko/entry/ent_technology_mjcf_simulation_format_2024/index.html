요약

접촉, 액추에이터 및 센서가 있는 관절 강체 시스템을 위한 MuJoCo의 XML 모델링 형식.

출처

  • MJCF Simulation Format

개요

MJCF(MuJoCo Simulation Format)는 MuJoCo 물리 엔진의 네이티브 모델링 형식으로, 접촉, 액추에이터, 센서를 갖춘 관절 강체 시스템을 설명하는 XML 기반 언어입니다. 그것이 진정으로 바꾼 것은 "로봇을 어떻게 설명하는가"가 아니라 "시뮬레이션 모델링을 웹 페이지 작성처럼 반복 가능하게 만드는 방법"입니다. CSS와 유사한 기본값 메커니즘을 통해 사용자가 최소 모델에서 시작하여 점진적으로 세부 사항을 추가하며, 모델링을 일회성 엔지니어링에서 대화형 실험으로 전환합니다.

핵심 내용

무엇인가: 정확한 정의

MJCF는 MuJoCo의 네이티브 모델 형식으로, 복잡한 동역학 시스템을 설명하도록 특별히 설계된 XML 기반 언어입니다. 접촉, 액추에이터, 센서를 포함한 다양한 모델 요소를 표현할 수 있으며, 내장 컴파일러를 통해 모델 설명에서 시뮬레이션 데이터 구조로의 변환을 완료합니다.

MJCF의 세 가지 판별적 특징(출처: MuJoCo 공식 문서 Modeling 장):

  1. 확장성 우선: 사용자가 처음부터 완전한 시스템을 구축하는 대신 작은 모델에서 시작하여 점진적으로 세부 사항을 추가할 수 있게 함;
  2. CSS식 기본값 메커니즘: HTML의 Cascading Style Sheets(CSS)에서 영감을 받아 기본값 설정을 통해 반복 설명을 크게 줄임;
  3. 컴파일 타임 계산: 내장 컴파일러가 다수의 복잡한 컴파일 타임 계산을 자동으로 수행하여 MJCF를 모델링 형식과 프로그래밍 언어 사이에 위치시킴.

원리 분석

① XML 트리 구조와 컴파일 파이프라인

MJCF 모델은 본질적으로 XML 트리이며, 루트 노드 <mujoco> 아래에 <worldbody>(세계 좌표계와 강체 트리), <actuator>(액추에이터 정의), <sensor>(센서 정의) 등의 하위 노드가 포함됩니다. 모델 파일은 MuJoCo 내장 컴파일러를 통해 처리되어 효율적인 C 데이터 구조 mjModel을 생성하며, 시뮬레이터에서 사용됩니다.

② 기본값 메커니즘: 모델링의 "CSS"

MJCF의 가장 정교한 설계는 <default> 노드입니다. 이를 통해 사용자가 특정 요소 유형에 대한 기본 매개변수를 설정할 수 있고, 하위 노드는 상속하거나 덮어쓸 수 있습니다. 예:

<default>
    <joint type="hinge" damping="0.1"/>
    <geom friction="1.0" density="1000"/>
</default>

이 선언은 이후 정의된 모든 관절이 기본적으로 0.1의 감쇠를, 모든 지오메트리가 기본 마찰 계수 1.0, 밀도 1000을 갖도록 합니다. 이는 반복 설명을 크게 줄여 모델 파일을 간결하게 유지합니다.

③ 컴파일 타임 자동 계산

MJCF 컴파일러는 관성 매개변수 집계(지오메트리 밀도에서 질량과 관성 텐서 유도), 운동학 트리 토폴로지 구축, 접촉 쌍 필터링 등 여러 계산을 자동으로 수행합니다. 이는 사용자가 링크 질량 중심 위치나 회전 관성을 수동으로 계산할 필요 없이 지오메트리 모양과 밀도만 정의하면 컴파일러가 나머지 작업을 자동으로 완료함을 의미합니다.

핵심 매개변수와 사양

MJCF의 핵심 사양 매개변수(출처: MuJoCo 공식 문서 Modeling 장):

매개변수/특성 설명
모델 요소 강체(body), 관절(joint), 지오메트리(geom), 액추에이터(actuator), 센서(sensor), 접촉 쌍(pair), 힘줄(tendon) 등
기본값 메커니즘 <default> 노드 지원, CSS 유사 캐스케이드 덮어쓰기
컴파일 타임 계산 관성 매개변수, 운동학 트리, 접촉 필터링 자동 유도
외부 형식 지원 URDF(URDF 확장을 통해), MJZ 압축 패키지, OpenUSD 모델 로드 가능
프로그래밍 방식 모델링 mjSpec API를 통해 C/C++ 또는 Python에서 모델 로드, 편집, 컴파일, 저장 지원

수평 비교

MJCF와 로봇 분야의 다른 주요 설명 형식 비교:

차원 MJCF URDF SDF
네이티브 엔진 MuJoCo ROS Gazebo
기본값 메커니즘 있음(CSS식) 없음 부분 지원
접촉 매개변수 설명 일급 시민 확장 필요 지원
센서/액추에이터 네이티브 지원 확장 필요 지원
컴파일 타임 계산 풍부함(관성, 토폴로지) 제한적 제한적

MJCF의 핵심 장점은 MuJoCo 물리 엔진에 맞춤 설계되었다는 점입니다. 접촉 모델, 액추에이터 모델, 센서 모델이 엔진의 솔버와 깊게 결합되어 형식 변환 시 정보 손실을 방지합니다. URDF의 장점은 ROS 생태계에서 널리 채택된 것이지만 표현력은 상대적으로 제한적입니다.

누가 사용하는가·응용 사례

MJCF는 휴머노이드 로봇의 시뮬레이션 모델링과 알고리즘 검증에 널리 사용됩니다(출처: 코퍼스 chapter-08 시뮬레이션 플랫폼 목록):

  1. Unitree H1: MJCF 기반 시뮬레이션 모델 구축, 운동 제어 및 강화 학습 훈련에 사용(관련 엔티티 ent_robot_unitree_h1_humanoid_robot_2024);
  2. HumanoidBench: Unitree H1 기반 전신 운동 및 조작 벤치마크, 40여 가지 작업 제공, MuJoCo/MJCF를 하위 시뮬레이션 환경으로 의존(관련 엔티티 ent_benchmark_humanoidbench);
  3. ManiSkill: 일반화 가능한 조작 기술을 위한 통합 벤치마크, MuJoCo를 물리 엔진으로, MJCF로 조작 장면 설명(관련 엔티티 ent_benchmark_maniskill);
  4. 학술 연구: 강화 학습, 모델 예측 제어(MPC), 전신 제어(WBC) 등 분야에서 MJCF는 디지털 트윈 모델 구축의 표준 선택입니다.

한계와 경계

MJCF는 만능이 아니며 그 경계를 명확히 해야 합니다:

  1. 범용 프로그래밍 언어 아님: MJCF는 범용 프로그래밍 언어의 표현력을 갖추지 못했으며, 복잡한 로직은 외부 스크립트나 mjSpec API를 통해 구현해야 함;
  2. 연체 지원 제한적: MuJoCo가 어느 정도의 연체(soft body)를 지원하지만, MJCF의 유연 재료 설명 능력은 전용 유한 요소 형식보다 약함;
  3. 생태계 결속: MJCF는 MuJoCo의 네이티브 형식이므로 다른 물리 엔진(예: Bullet, PhysX)으로 마이그레이션하려면 URDF 또는 SDF로 변환해야 하며, 일부 세부 사항이 손실될 수 있음;
  4. 학습 곡선: 기본값 메커니즘이 진입 장벽을 낮추지만, 고급 기능(접촉 쌍 필터링, 컴파일 타임 계산 등)은 MuJoCo 내부 메커니즘에 대한 깊은 이해가 필요함.

흔한 오해

  1. "MJCF는 URDF의 다른 표현 방식일 뿐이다" — 틀림. MJCF의 기본값 메커니즘, 컴파일 타임 계산, 접촉/액추에이터/센서의 일급 지원은 URDF의 표현력을 훨씬 능가합니다. URDF는 운동학 설명에 더 치우치고, MJCF는 동역학 시뮬레이션에 깊이 최적화되어 있습니다.

  2. "MJCF는 MuJoCo에서만 사용할 수 있다" — 부분적으로 맞음. MJCF는 MuJoCo 네이티브 형식이지만 변환 도구를 통해 URDF/SDF로 내보내 다른 엔진에서 사용할 수 있으며, 다만 일부 물리적 세부 사항이 손실됩니다.

  3. "모델이 상세할수록 좋다" — 공학적 판단: 과도하게 상세한 모델(예: 모든 볼트를 모델링)은 계산 오버헤드를 크게 증가시키고 시뮬레이션 정밀도를 반드시 향상시키지 않습니다. MJCF의 설계 철학은 "점진적 향상"입니다. 요구 사항을 충족하는 최소 모델에서 시작하여 필요에 따라 세부 사항을 추가합니다.

관련 지식

  • ent_software_mujoco_physics_engine_2022 — MuJoCo 물리 엔진은 MJCF 형식의 호스트이자 실행 환경이며, MJCF는 그 네이티브 모델링 언어입니다.
  • ent_technology_urdf_robot_description_format_2024 — URDF는 ROS 생태계의 로봇 설명 형식으로, MJCF와 표현력 및 설계 철학에서 대비를 이룹니다.
  • ent_benchmark_humanoidbench — Unitree H1 기반 전신 운동 및 조작 벤치마크, MJCF로 시뮬레이션 환경 설명.
  • ent_benchmark_maniskill — 조작 기술을 위한 통합 벤치마크, MuJoCo/MJCF를 하위 시뮬레이션 플랫폼으로 의존.
  • ent_method_hardware_in_the_loop — HIL 테스트에서 MJCF 모델은 가상 피제어 객체의 동역학 설명 기반으로 실시간 시뮬레이션 머신과 함께 사용될 수 있습니다.
  • ent_robot_unitree_h1_humanoid_robot_2024 — Unitree H1의 시뮬레이션 모델은 일반적으로 MJCF 형식으로 구축되어 제어 알고리즘 검증에 사용됩니다.

관련 개체

벤치마크

HumanoidBench

Unitree H1 로봇을 기반으로 한 전신 휨로봇 로코모션 및 조작 시뮬레이션 벤치마크로, VLA 및 제어 알고리즘의 통제된 비교를 위해 40개 이상의 작업을 제공함.

 벤치마크

ManiSkill

일반화 가능한 조작 기술을 위한 통합 벤치마크로, 표준화된 과제·시뮬레이션 환경·평가 프로토콜을 제공.

 방법

하드웨어 인 더 루프(HIL)

실제 하드웨어 컨트롤러가 플랜트의 실시간 시뮬레이션과 상호작용하여 제어 소프트웨어를 안전하고 반복 가능하게 검증하는 방법.

 소프트웨어 플랫폼

MuJoCo 물리 엔진

풍부한 접촉 역학을 가진 고충실도 물리 엔진, 휨로봇 제어 연구에 널리 사용.

 기술

URDF 로봇 설명 형식

시뮬레이션 및 제어를 위한 로봇 링크, 관절, 관성 및 기하를 설명하는 XML 기반 형식.

 논문
