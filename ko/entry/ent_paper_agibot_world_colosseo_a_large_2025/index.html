요약

AgiBot World Colosseo의 구현 경로는 먼저 언어 명령, 카메라 이미지/다중 시점 관측, 본체 상태 및 관절 시퀀스를 다중 모달 표현으로 인코딩한 다음, VLM 의미론적 계획/라우팅, 잠재 변수/동작 토큰, MM-DiT/Transformer 동작 헤드를 사용하여 전신 궤적/동작 시퀀스, 말단 실행기/손목-손 목표, 동작 청크/토큰을 예측한다. 핵심은 작업을 라우팅 가능한 스킬 또는 전문가 정책으로 분해하고, 상위 모듈이 실행 중에 이를 선택하고 조합하는 것이다.

개요

AgiBot World Colosseo는 지유안 로봇(AgiBot) 팀이 구축한 대규모 실제 세계 로봇 조작 플랫폼으로, 100대의 동일한 사양의 휴머노이드 로봇, 4,000제곱미터 시설, 100만 개 이상의 궤적 데이터를 포함합니다. 핵심 기여는 표준화된 수집 프로세스, 인간 개입 품질 관리, 그리고配套 GO-1(ViLLA 프레임워크) 정책 모델을 통해 로봇 조작 데이터의 파편화와 품질 불안정 문제를 체계적으로 해결하고, 데이터 규모와 정책 성능 간의 멱법칙 스케일링 관계를 입증한 데 있습니다.

무엇을 바꾸었는가

로봇 조작 분야는 오랫동안 '데이터 기아'와 '데이터 오염'이라는 이중적 곤경에 시달려 왔습니다. Open X-Embodiment와 같은 기존 데이터셋은 규모가 방대하지만, 본질적으로 여러 연구소 데이터의 단순拼接에 불과합니다—이기종 하드웨어, 비표준화 수집 프로토콜, 인간 피드백 기반 품질 관리 부재로 인해 모델 훈련 시 데이터 분포 차이에 적응하는 데 많은 용량을 소비해야 하며, 조작 기술 자체를 학습하는 데 집중하지 못합니다. DROID는 크라우드소싱으로 규모 문제를 해결하려 했지만, 고정된 단일 암 하드웨어와 검증되지 않은 궤적 품질로 인해 일반화 능력이 제한적입니다. AgiBot World가 진정으로 바꾼 것은 '데이터 생산'의 패러다임입니다: 더 이상 데이터가 기성품으로 수동적으로 수집 가능하다고 가정하지 않고, 데이터 수집 자체를 공학적 설계가 필요한 핵심 단계로 간주합니다—하드웨어 동질화, 원격 조작 표준화부터 인간 개입의 반복적 품질 폐루프까지, 각 단계에서 데이터의 체계적 노이즈를 제거합니다. 이러한 '데이터 공장' 접근 방식은 이후 모델 훈련이 데이터 정제가 아닌 알고리즘 혁신에 집중할 수 있게 하며, 이는 이전의 모든 데이터셋과의 가장 본질적인 차이입니다.

방법 분해

데이터 수집 인프라

  • 하드웨어 동질화: 100대의 AgiBot G1 휴머노이드 로봇, 이중 7-DoF 암 + 이동 베이스 + 조절 가능한 허리, 모듈식 엔드 이펙터(표준 그리퍼 또는 6-DoF 절제 손), 8개 카메라 구성(1 RGB-D + 3 어안 전면 + 각 손목 RGB-D/어안 + 2 후면 어안), 30Hz 동기화 이미지 및 고유 감각 기록.
  • 원격 조작 이중 채널: VR 헤드셋(제스처→엔드 이펙터 포즈→역운동학→관절 각도) 및 전신 모션 캡처(인체 관절 포함 손가락→로봇 자세 매핑), 후자는 단일 손가락 운동과 몸통 자세를 지원하여 절제 조작을 위한 데이터 기반을 제공합니다.

3단계 수집 프로세스

  1. 사전 수집 검증: 작업 가능성 확인, 수집 표준(궤적 시간, 동작 규범 등) 수립.
  2. 숙련된 운영자 수집: 표준에 따라 실행, 로컬 검증 완료 후 클라우드 업로드.
  3. 후처리 주석: 주석자가 에피소드별로 표준 충족 여부를 검증하고 언어 주석을 추가.

핵심 설계 결정

  • 실패 복구 데이터 보존: 약 1%의 궤적에는 운영자가 오류 후 복구하여 완료한 세그먼트가 포함되며, 실패 원인과 타임스탬프를 수동으로 주석 처리합니다. 저자는 이러한 데이터가 정책의 실패 반성과 견고성 정렬에 필수적이라고 주장합니다.
  • 인간 개입 반복: 소규모 데모 수집→정책 훈련→배포 평가→실패 패턴에 따른 수집 프로토콜 수정. 예를 들어 모델 동작 시작 시 긴 정지가 발견된 후, 유휴 프레임을 제거하는 후처리 단계를 도입했습니다.

GO-1 모델(ViLLA 프레임워크) 3단계 훈련

  • Stage 1 잠재 동작 모델(LAM): 인터넷 규모 이기종 데이터(Ego4D 인간 비디오 포함)에서 인코더-디코더 훈련. 인코더는 인과적 시간 마스크가 있는 시공간 트랜스포머, 디코더는 공간 트랜스포머로, VQ-VAE 목표를 통해 잠재 동작 토큰을 양자화하며, 코드북 크기 |C|, 토큰 수 k=4.
  • Stage 2 잠재 플래너: InternVL2.5-2B를 VLM 백본(24층 트랜스포머, 전방향 주의)으로 사용, 다중 시점 이미지(머리, 왼쪽 손목, 오른쪽 손목)와 언어 명령을 입력으로 잠재 동작 토큰 예측.
  • Stage 3 동작 전문가: 확산 목표로 저수준 동작의 연속 분포를 모델링, 동작 블록 A_t = [a_t, ..., a_{t+H}] 디코딩, H=30. 조건에는 다중 시점 이미지, 고유 감각 상태 p_t 및 언어 명령 포함.

설계 근거: 잠재 동작 공간은 OpenVLA의 이산 저수준 동작 공간보다 수 자릿수 작아, 범용 VLM이 로봇 정책에 효율적으로 적응할 수 있게 합니다; InternVL2.5-2B의 2B 파라미터 규모는 초기 실험에서 성능과 계산 비용 간의 균형을 이루는 것으로 입증되었습니다.

핵심 혁신

  1. 데이터 품질을 일급 시민으로: AgiBot World는 '인간 개입 검증'과 '실패 복구 데이터'를 체계적으로 데이터셋 설계에 통합한 최초의 플랫폼입니다. 이전 데이터셋은 자동 수집(DROID)에 전적으로 의존하거나 품질 피드백 메커니즘이 부재했지만, 여기의 3단계 검증 프로세스와 실패 궤적 주석은 데이터 신호 대 잡음 비를 직접 향상시킵니다—절제 실험에서 인간 검증된 528개 궤적이 검증되지 않은 482개보다 0.18 완료 점수 향상을 보여, 품질이 수량보다 더 중요함을 입증합니다.
  2. 잠재 동작 공간을 VLM과 로봇 정책의 브리지로: GO-1의 LAM은 고차원 연속 동작을 이산 잠재 토큰으로 압축하여 InternVL2.5-2B와 같은 범용 VLM이 아키텍처 수정 없이 로봇 제어에 사용될 수 있게 합니다. 이 설계는 OpenVLA에서 저수준 동작을 직접 이산화할 때 발생하는 의미론적 격차를 피하며, 'VLM 곧 정책' 경로의 중요한 공학적 돌파구입니다.
  3. 동일 하드웨어 + 표준화 프로세스의 확장성 검증: 100대의 동일 로봇에서 수집된 데이터는 하드웨어 간 도메인 차이를 제거하여 스케일링 법칙 연구를 가능하게 합니다—성능과 궤적 수 간의 멱법칙 관계(Pearson r=0.97)는 실제 세계 로봇 조작 데이터에서 검증된 최초의 명확한 스케일링 신호로, 향후 데이터 규모 결정에 정량적 근거를 제공합니다.

데이터셋 품질 비교(그림 6)

AgiBot World에서 사전 훈련된 정책: - 분포 내 시나리오: 평균 완료 점수 0.77 vs OXE의 0.47(+0.30) - 분포 외 시나리오: 0.67 vs 0.38(+0.29)

데이터량 효율성

AgiBot World alpha(약 236시간)는 OXE(약 2000시간)보다 훨씬 작음에도 더 높은 성공률을 달성; OXE 데이터량의 1/10만 사용했을 때 사전 훈련 정책 일반화 성능 18% 향상.

GO-1 비교 실험(그림 5)

5개 작업 × 30회 시도(10회 기존 + 20회 변형/간섭), GO-1이 RDT보다 유의미하게 우수, 잠재 플래너 추가 시 평균 0.12 작업 완료 점수 향상.

스케일링 법칙(그림 7a)

훈련 궤적 수가 9.2k(alpha의 10%)에서 1M(전체 beta)까지 증가할 때, 성능과 궤적 수 간 멱법칙 스케일링, Pearson 상관 계수 r = 0.97.

데이터 품질 절제(그림 7b)

'Wipe Table' 작업: 인간 검증된 528개 궤적 vs 검증되지 않은 482개, 완료 점수 0.18 향상.

평가 작업

6개 작업(Restock Bag, Table Bussing, Pour Water, Restock Beverage, Fold Shorts, Wipe Table), 각 작업당 2개 미경험 시나리오(위치 일반화, 시각적 간섭, 언어 일반화), 각 시나리오당 10회 rollout 평균.

경계 및 한계

  • 시뮬레이션 환경 부재: 모든 평가는 실제 세계에서 수행되었으며, 시뮬레이션 환경은 개발 중입니다. 이는 빠른 재현 가능한 벤치마크 테스트와 절제 연구 효율성을 제한합니다.
  • 절제 손 작업 별도 평가 없음: 하드웨어가 6-DoF 절제 손을 지원하지만, 논문은 절제 손 작업의 정량적 결과를 제공하지 않아 실제 이점이 명확하지 않습니다.
  • 다중 로봇 협업 미정량화: 플랫폼이 협업 작업을 지원하지만, 다중 로봇 협업 평가 데이터는 제공되지 않았습니다.
  • 실패 복구 데이터 비율 극히 낮음: 약 1%에 불과하며, 다양한 작업 유형에서의 적용 가능성과 최적 비율은 체계적으로 탐구되지 않았습니다.
  • 논문에서 명시되지 않음: 구체적인 GPU 모델, 훈련 시간, 추론 지연 시간, 모델 총 파라미터 수(VLM 백본 2B 제외) 등의 공학적 세부 사항.

공학적 시사점

  • 데이터 품질 프로토콜 먼저 확인: 이 데이터셋을 재현하거나 사용할 경우, '인간 검증' 및 '실패 복구' 주석 필드를 반드시 유지하세요—절제 실험에서 이 두 항목이 성능에 유의미한 기여(+0.18 완료 점수)를 하며, 이를 버리는 것은 데이터 가치를 낭비하는 것입니다.
  • 잠재 동작 공간에 주목, VLM 직접 미세 조정 지양: GO-1의 핵심은 LAM이 동작을 토큰으로 압축하는 것이며, 저수준 동작을 직접 이산화(OpenVLA 경로)하면 의미 정보가 손실됩니다. 재현 시 Stage 2/3로 건너뛰지 말고 LAM의 VQ-VAE 훈련을 우선 재현해야 합니다.
  • 스케일링 법칙은 양날의 검: r=0.97의 멱법칙 관계는 데이터량이 두 배가 되어도 수익이 감소함을 의미하지만, 동시에 현재 데이터 규모가 아직 포화되지 않았음을 시사합니다. 하류 팀은 자체 작업 복잡도에 따라 데이터 수집을 계속할지 모델 아키텍처를 최적화할지 결정해야 합니다.
  • 가장 함정에 빠지기 쉬운 부분: 궤적 시간 분포 차이가 매우 큽니다(30-60초가 주, 일부 2분 초과), 반면 DROID/OXE는 대부분 5-20초입니다. 직접 혼합 훈련 시 시간 스케일 불일치 문제를 처리해야 하며, 작업 유형별 그룹화 또는 동작 블록(H=30) 사용 시 시간 단계 정렬에 주의해야 합니다.
  • 하드웨어 동질성은 암묵적 전제: 모든 결론은 100대의 동일 로봇을 기반으로 합니다. 하류 팀이 이기종 하드웨어를 사용할 경우, 데이터셋의 사전 훈련 가중치가 직접 전이되지 않을 수 있으며 추가 도메인 적응 단계가 필요합니다.
