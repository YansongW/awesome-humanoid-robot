요약

최적해에서 활성(등호를 만족하는) 제약 집합을 추적하고 일련의 등식 제약 부분 문제를 풀어 최적해를 접근하는 반복 최적화 알고리즘.

출처

  • J. Nocedal and S. J. Wright, Numerical Optimization, 2nd ed., Springer, 2006

관련 개체

  • requires 제약 자격 활성 집합 QP 반복의 신뢰할 수 있는 수렴은 일반적으로 작업 집합에서 LICQ와 같은 제약 자격을 가정합니다.
  • is_alternative_to 내점법 내점법은 활성 집합을 추적하는 대신 실행 가능 영역 내에서 엄격하게 머무륾며 동일한 제약 문제를 풉니다.

개요

활성 집합법(Active-set method)은 부등식 제약이 있는 최적화 문제를 푸는 반복 알고리즘으로, 핵심 아이디어는 각 반복에서 "작업 집합"(working set), 즉 현재 등식 제약으로 취급되는 부등식 제약 집합을 유지하면서 제약을 반복적으로 추가·제거하여 실제로 활성화되는 최적 제약 집합에 접근하는 것입니다. 이 방법이 실제로 바꾸는 것은 단일 하위 문제를 푸는 효율성이 아니라, "어떤 제약이 활성화되어야 하는가"라는 조합적 결정을 일련의 효율적으로 풀 수 있는 등식 제약 하위 문제로 변환한다는 점이며, 이로 인해 중소규모 볼록 2차 계획법(QP)에서 가장 신뢰할 수 있는 선택지 중 하나가 되었습니다.

핵심 내용

무엇인가: 정확한 정의

활성 집합법은 부등식 제약이 있는 최적화 문제를 푸는 실현 가능점 방법입니다. 어떤 실현 가능점에서 출발하여 각 반복에서 현재 "등식이 성립한다"고 추정되는 부등식 제약을 모든 등식 제약과 합쳐 작업 집합 \(\mathcal{W}_k\)을 구성한 뒤, 해당 작업 집합에서 등식 제약 하위 문제를 풀어 탐색 방향을 결정합니다. 하위 문제의 최적해가 작업 집합 외부의 어떤 제약을 위반하면 해당 제약을 작업 집합에 추가하고, 작업 집합 내 어떤 제약에 대응하는 라그랑주 승수(Lagrange multiplier)가 음수(최소화 문제의 경우)이면 해당 제약이 활성화되지 않아야 함을 의미하므로 작업 집합에서 제거합니다. 이러한 과정을 Karush-Kuhn-Tucker(KKT) 조건이 만족될 때까지 반복합니다.

이 방법은 특히 볼록 2차 계획법 문제에 적합한데, 이 경우 각 하위 문제가 닫힌 형태의 해를 가지거나 직접법으로 효율적으로 풀 수 있고, 알고리즘이 유한 단계 내에 종료되기 때문입니다.

원리 분해

① 작업 집합: 부등식을 "등식"으로 가장하기

볼록 2차 계획법을 고려합니다:

\[ \min_x \; \frac{1}{2} x^{\top} H x + g^{\top} x \quad \text{s.t.} \quad A x = b, \; C x \le d. \]

현재 반복점을 \(x_k\)라고 하고, 작업 집합 \(\mathcal{W}_k\)은 모든 등식 제약과 현재 활성화된(등식이 성립하는) 부등식 제약을 포함합니다. \(x_k\)에서 다음 등식 제약 하위 문제를 풀어 탐색 방향 \(p_k\)를 결정합니다:

\[ \min_p \; \frac{1}{2} p^{\top} H p + (H x_k + g)^{\top} p \quad \text{s.t.} \quad A p = 0, \; C_{\mathcal{W}_k} p = 0. \]

하위 문제에서 제약의 우변이 0으로 설정된 이유는 \(x_k\)가 이미 작업 집합 제약을 만족하므로, \(p\) 방향으로 이동할 때 이러한 제약이 계속 성립하는지에만 관심이 있기 때문입니다.

② 보폭과 제약 교환: 두 가지 핵심 판정

하위 문제를 풀어 \(p_k\)를 얻은 후, 보폭 \(\alpha_k\)를 결정해야 합니다. \(p_k = 0\)이면 \(x_k\)는 작업 집합 하위 문제의 최적해이며, 이때 작업 집합 내 부등식 제약에 대응하는 라그랑주 승수 \(\mu_j\)를 검사합니다: 모든 \(\mu_j \ge 0\)이면 \(x_k\)는 원래 문제의 최적해이므로 알고리즘이 종료됩니다; \(\mu_j < 0\)인 것이 있으면 해당 제약을 제거하고(해에 "추진력"을 주지 않아야 함) 다시 풉니다.

\(p_k \neq 0\)이면 \(p_k\) 방향으로 이동하며, 보폭의 상한은 작업 집합 외부의 제약에 의해 결정됩니다:

\[ \alpha_k = \min \left\{ 1, \; \min_{i \notin \mathcal{W}_k, \, c_i^{\top} p_k > 0} \frac{d_i - c_i^{\top} x_k}{c_i^{\top} p_k} \right\}. \]

\(\alpha_k < 1\)이면 작업 집합에 포함되지 않은 어떤 제약에 "충돌"했음을 의미하므로, 해당 제약을 작업 집합에 추가한 뒤 하위 문제를 다시 풉니다.

③ 유한 종료성: 볼록 QP의 보장

볼록 2차 계획법의 경우, 활성 집합법은 유한 종료성을 가집니다: 각 반복에서 목적 함수 값이 엄격히 감소하거나, 목적 값이 유지된 채 작업 집합이 변경됩니다(음수 승수를 가진 제약 제거). 작업 집합의 조합 수가 유한하므로 알고리즘은 반드시 유한 단계 내에 KKT 점에 도달합니다. 이 성질은 내점법이 가지지 못한 것입니다—내점법은 점근적으로만 수렴합니다.

공학적 판단: 휴머노이드 로봇 전신 제어(WBC)에서 QP 문제는 일반적으로 규모가 크지 않지만(결정 변수 수십~수백 개), 1 kHz 이상의 주파수에서 실시간으로 풀어야 합니다. 활성 집합법은 warm-start 특성—이전 제어 주기의 해를 현재 주기의 초기 작업 집합으로 사용할 수 있음—덕분에 qpOASES와 같은 실시간 솔버의首选이 되었습니다. 내점법(OSQP, ProxQP 등)은 오프라인 계획이나 정밀도 요구가 매우 높은 시나리오에 더 적합합니다.

누가 사용하는가·응용 사례

qpOASES는 활성 집합법의 가장 유명한 공학적 구현 중 하나로, 설계 목표 자체가 모델 예측 제어(MPC)에서의 매개변수화된 QP 해석입니다. 휴머노이드 로봇 분야에서 널리 사용되는 곳은 다음과 같습니다:

  • 전신 운동 제어(WBC): 동역학 등식, 마찰 원뿔 부등식, 관절 토크 제한을 만족하면서 관절 가속도와 접촉력을 실시간으로 해석합니다. 말뭉치에서 언급된 "저수준에서 QP 또는 MPC로 실시간 추적"이 바로 이 시나리오입니다.
  • 모델 예측 제어(MPC): 각 단계의 롤링 최적화에서 QP의 구조(Hessian과 제약 행렬) 변화가 작으므로, 활성 집합법은 이전 시점의 작업 집합을 초기 추측으로 사용하여 반복 횟수를 크게 줄일 수 있습니다.
  • 궤적 최적화: 계층적 계획의 중간 계층에서 QP로 국소 궤적 수정 문제를 해석합니다.

한계와 경계

  1. 조합 폭발 위험: 완전 탐색은 피하지만, 최악의 경우 작업 집합 교환 횟수가 제약 수에 따라 지수적으로 증가할 수 있습니다. 제약 수가 매우 많은 문제(예: \(10^4\) 이상)에서는 일반적으로 내점법이 더 우수합니다.
  2. 볼록 문제에만 적용 가능: 비볼록 QP의 경우 활성 집합법은 국소 최적해만 보장할 수 있고, 유한 종료성도 더 이상 성립하지 않습니다.
  3. 초기 실현 가능점 필요: 알고리즘은 실현 가능점에서 출발해야 합니다. 초기 점이 실현 불가능하면 먼저 Phase I 과정(보조 LP 또는 QP를 풀어 실현 가능점을 찾는 과정)을 실행해야 하므로 구현 복잡도가 증가합니다.
  4. 수치 안정성: 작업 집합 제약이 선형 종속에 가까우면 하위 문제의 KKT 행렬이 병적이 될 수 있으며, 정규화나 더 견고한 분해 방법이 필요합니다.

흔한 오해

  1. "활성 집합법은 단체법(simplex method)이다"—둘 다 "제약 경계를 따라 이동"하는 기하학적 직관을 공유하지만, 단체법은 선형 계획법을 대상으로 하고 활성 집합법은 (일반적으로 볼록한) 비선형 계획법을 대상으로 하며, 각 반복의 탐색 방향은 단순히 경계를 따르는 것이 아니라 목적 함수의 2차 정보(Hessian)에 의해 결정됩니다.
  2. "작업 집합이 클수록 좋다"—작업 집합이 너무 크면 하위 문제 규모가 커져 계산량이 증가합니다. 핵심은 작업 집합의 정확성이지 크기가 아닙니다. 불필요한 제약이 포함된 작업 집합은 잘못된 탐색 방향을 초래할 수 있습니다.
  3. "승수가 음수이면 반드시 제거해야 한다"—이것은 현재 점이 최적해(\(p_k = 0\))일 때만 성립합니다. \(p_k \neq 0\)이면 음수 승수가 존재하더라도 먼저 탐색 방향으로 이동해야 하며, 즉시 작업 집합을 조정해서는 안 됩니다.
  4. "활성 집합법이 내점법보다 빠르다"—이것은 문제 규모에 의존적인 판단입니다. 중소규모이고 warm-start가 필요한 시나리오에서는 성립하지만, 대규모 희소 문제에서는 일반적으로 내점법이 더 빠릅니다.

관련 지식

  • ent_kkt_conditions — 활성 집합법의 종료 조건은 KKT 조건의 항목별 검증입니다: 정상성, 원시 실현 가능성, 쌍대 실현 가능성, 상보 여유.
  • ent_constraint_qualification — 최적해에서 KKT 조건이 성립하기 위한 전제 조건으로, 활성 집합법의 수렴성 분석도 이러한 정규성 조건에 의존합니다.
  • ent_interior_point_method — 활성 집합법과 나란히 놓이는 또 다른 대규모 제약 최적화 알고리즘으로, 수렴 속도, 적용 규모, warm-start 능력에서 상호 보완적입니다.
  • ent_paper_baek_toward_control_of_wheeled_huma_2024 — 이 논문의 균형점 예측 프레임워크는 실시간 매개변수 추정과 최적화를 포함하며, 활성 집합법은 그 하위 QP 해석의 후보 알고리즘이 될 수 있습니다.
  • ent_paper_sartore_optimization_of_humanoid_robot_2022 — 휴머노이드 로봇 설계 최적화의 다중 목적 문제는 종종 제약이 있는 하위 문제를 풀어야 하며, 활성 집합법은 그중 볼록 QP 하위 문제의 빠른 해석에 사용될 수 있습니다.
