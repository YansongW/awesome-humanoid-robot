Vesta: A Generalist Embodied Reasoning Model

요약

Robots operating in open-world environments must seamlessly integrate localization, spatial reasoning, navigation, and long-horizon planning. While specialist models excel at individual tasks, deploying a multi-model stack is computationally expensive and prone to cascading errors. Institutions per source list: NVIDIA.

출처

  • arXiv:2606.20905 Vesta: A Generalist Embodied Reasoning Model
  • GitHub仓库 Robotics_Notebooks

개요

Vesta는 Qwen3-VL-8B에서 미세 조정된 범용 임베디드 추론 모델로, 위치 파악, 내비게이션, 공간 추론 및 장기 계획을 여러 전문가 모델을 쌓는 대신 단일 플래너에 통합하는 것을 목표로 합니다. 핵심 기여는 여섯 가지 데이터 유형을 혼합한 지도 미세 조정과 극도로 단순한 메모리 장치(고정 예산 이미지 샘플링 + 텍스트 하위 작업 캐시)를 도입하여 학술 벤치마크, 오프라인 계획 및 실제 로봇 작업에서 SOTA 기준선 및 전문가 앙상블을 크게 능가한다는 점입니다.

무엇을 바꾸었는가

이 연구가 실제로 바꾼 것은 '임베디드 에이전트 능력 구성 방식'의 기본 가정입니다. 과거에는 내비게이션, 위치 파악, 추론이 각각 분리되어 있었고, 각 능력마다 전용 모델과 벤치마크가 있었으며, 배포 시에는 여러 모델을 쌓거나(계산 오버헤드 및 캐스케이드 오류), 단일 VLM이 특정 작업에서 우연히 잘 작동하기를 기대해야 했습니다. Vesta는 데이터 혼합과 통합 훈련을 통해 8B 모델이 모든 임베디드 인지 작업에서 전문가 수준에 동시에 도달하거나 능가할 수 있음을 증명했으며, 이러한 통합은 단순한 '능력 중첩'이 아니라 긍정적 전이를 생성합니다. 통합 모델은 순수 내비게이션 전문가보다 내비게이션에서 1.4 SR 높고, 순수 임베디드 전문가보다 임베디드 인지에서 평균 3.9점 높습니다. 이는 '전문 모델이 범용 모델보다 반드시 우월하다'는 업계 관행을 직접적으로 흔듭니다.

또 다른 변화는 메모리 메커니즘의 설계 철학입니다. 기존 방법(MemER, MEM)은 더 똑똑한 메모리, 즉 학습 기반 검색기, 장면 표현, 이벤트 추적기를 추구합니다. Vesta는 반대로 고정 예산의 최근 프레임 샘플링과 텍스트 하위 작업 로그를 사용하여 실제 로봇에서 액터 전용 기준선 대비 성공률을 38.3% 향상시켰습니다. 이는 planner-actor 계층 구조에서 메모리의 '모달리티 조합'이 '검색 전략'보다 중요하다는 것을 보여줍니다. 이미지+텍스트 혼합 메모리는 단일 모달리티보다 훨씬 강하며, 균일 샘플링과 최근 편향 샘플링 간에는 거의 차이가 없습니다. 이는 메모리 메커니즘에 과도하게 엔지니어링을 하는 팀에게 시사하는 바가 큽니다.

방법 분석

전체 아키텍처

  • 기본 모델: Qwen3-VL-8B, 전체 파라미터 미세 조정(비전 타워 + 프로젝터 + 언어 백본), 순수 bf16.
  • 훈련: 1 epoch, lr 1e-5, cosine 스케줄링, weight decay 0.01, batch size 256, 128대 H100, FSDP 전체 샤딩, FlashAttention-2, 시퀀스 패킹, 최대 길이 8192, 최대 비디오 프레임 32.
  • 모든 구조화된 출력(점, 박스)은 언어 헤드를 통해 텍스트 토큰으로 디코딩되며, 자유 형식 답변과 디코더 헤드를 공유합니다. 이는 통합 인터페이스의 핵심 설계입니다.

위치 파악: base–tail 전략

  • Base: Objects365, COCO, LVIS(광범위한 카테고리 커버리지).
  • Tail: 1인칭 관찰, 조작 중심 주석, 시간적 진화 상호작용 시퀀스(부분 관측 가능성 및 시점 변화에 적응).

내비게이션: R2R 스타일 VLN 공식화

  • 에피소드 e = (I, s₀, g), 결정 지점 t에서 포즈 sₜ, 1인칭 이미지 oₜ, 샘플링된 시각적 히스토리 Hₜ 관찰.
  • 최적화 목표: max_θ 𝔼[𝟙{d(s_T, g) ≤ d_succ}], d_succ = 3.0m.
  • 세 가지 동작 출력: 픽셀 목표(↓ + 정규화된 웨이포인트 (u,v) ∈ [0,1000]²), 회전 시퀀스({←,→}), stop.
  • 데이터: R2R, RxR, ScaleVLN의 VLN-CE, 시뮬레이션 렌더링.

메모리를 사용한 동작 계획

  • 비마르코프 프로세스: aₜ = π(o_{≤t}, a_{<t}, g), 근사 상태 sₜ = Φ(oₜ, ℳₜ, g).
  • 각 하위 작업 전에 4단계 CoT 생성: Observation → Progress → Reasoning → Action, aₜ만 메모리에 기록.
  • 메모리 장치: 튜플 mᵢ = ⟨i, τᵢ, oᵢ, aᵢ, g⟩, 히스토리 이미지는 샘플링 연산자 𝒮ₜ에 의해 최대 K 프레임으로 제한되며, 첫 번째 프레임은 항상 유지되고 균일 또는 최근 편향 샘플링을 지원합니다.

계층적 실행 아키텍처(실제 로봇)

  • Planner VLM(Vesta)이 하위 작업 출력 → Actor VLA(Gr00t-N1.6)가 동작 실행.
  • 동기 모드: planner 추론은 블로킹 호출(약 1초), 목표 변경 또는 최대 지연 τ_max 초과 시 actor 일시 중지.
  • 비동기 모드: planner 스레드가 지속적으로 실행되고, 제어 루프가 매 틱마다 캐시된 하위 작업을 읽으며 블로킹하지 않음.
  • 통신은 공유 변수 z(현재 하위 작업)를 통해서만 이루어지며, planner 메모리는 actor에 보이지 않음.

핵심 혁신

  1. 통합 플래너가 전문가 앙상블 대체: Vesta는 11개 인지 벤치마크와 5개 위치 파악 벤치마크에서 평균 68.7 및 69.9점을 달성하여 모든 단일 모델 기준선을 능가하고 oracle ensemble보다 >10% 높습니다. 이는 단순한 '멀티태스크 학습'이 아니라 긍정적 전이를 증명합니다. 통합 모델은 내비게이션 SR에서 순수 내비게이션 전문가보다 1.4 높고, 임베디드 인지에서 순수 임베디드 전문가보다 3.9 높습니다. 엔지니어링 팀에게는 여러 모델과 전환 로직을 유지할 필요가 없음을 의미합니다.

  2. 극도로 단순한 메모리 장치의 효율성: 고정 예산 이미지 샘플링 + 텍스트 하위 작업 캐시, 학습 기반 검색기 없음. 절제 실험에서 이미지+텍스트 혼합 메모리(75.9 전체 점수)가 이미지 전용(63.1) 및 텍스트 전용(49.7)을 크게 능가하며, 균일 샘플링과 최근 편향 샘플링 간에는 거의 차이가 없습니다(75.9 vs 75.3). 이는 planner-actor 아키텍처에서 메모리의 모달리티 조합이 주요 병목이며, 프레임 선택 전략은 부차적 문제임을 증명합니다. 이는 메모리 메커니즘 설계에 명확한 우선순위를 제공합니다.

  3. 전환 오버샘플링(transition oversampling) 발견: 기본 샘플링에서 전환 단계 데이터는 약 25%만 차지하며, 전환 샘플링을 1×에서 2×로 늘리면 전환 정확도가 크게 향상되고(58.1→68.1) 전체 정확도가 향상됩니다(73.6→75.9). 3×로 늘리면 미미한 개선만 있고 실행을 저해합니다. 이는 실행 가능한 데이터 엔지니어링 통찰력입니다. 장기 작업에서 작업 전환 순간(전환)이 실행 단계보다 더 주목할 가치가 있습니다.

절제 실험(표 4, 5)

  • 통합 vs 전문가: Vesta 평균 61.7, 내비게이션 전문가 전용(26.0) 및 임베디드 전문가 전용(33.2)을 크게 능가하며, 통합 모델은 자체 작업에서 전문가와 일치하거나 능가합니다.
  • 전환 샘플링: 2× 최적(75.9), 1×는 73.6, 3×는 75.3(실행 저해).
  • 메모리 모달리티: 이미지+텍스트(75.9) > 이미지 전용(63.1) > 텍스트 전용(49.7).

경계 및 한계

  • 실제 로봇 평가 범위 제한: 단일 플랫폼(I2RT 양팔 YAM 그리퍼) 및 세 가지 작업만 포함, 휴머노이드 로봇(전신 운동 + 양팔 결합), 이동 조작기(내비게이션과 조작 전환), 정교한 손(세분화된 하위 작업 어휘)은 미포함.
  • 규모 한계: 모든 수치는 8B 규모이며, 임베디드 SFT 혼합 데이터의 스케일링 동작은 웹 데이터만큼 충분히 이해되지 않아 더 큰 규모에서 결론이 유지되지 않을 수 있습니다.
  • 메모리 미학습: 메모리 하네스는 고정되어 있으며(균일/최근 샘플링 + 텍스트 로그), 메모리 자체를 학습 대상으로 삼지 않았고, 평생 학습(에피소드 간 통합, 망각, 재검색)을 다루지 않았습니다.
  • 액터 가정: 현재 설정은 액터가 고정 제어율로 소수의 자연어 하위 작업을 충실히 실행할 수 있다고 암묵적으로 가정합니다. 액터의 언어 추종 능력이 약하면 플래너의 이점이 실행 오류에 가려질 수 있습니다(실제 로봇 실험에서 대부분의 실패는 액터에 의해 유발됨).
  • 수행하지 않은 것: 다른 로봇 플랫폼 평가, 대규모 실제 세계 멀티태스크 배포, 더 큰 규모의 다른 범용 모델과의 비교, 증류 및 엣지 배포 실험은 수행하지 않았습니다.

엔지니어링 시사점

  • 데이터 혼합 비율 먼저 확인: Vesta의 성공은 여섯 가지 데이터 유형의 비율(공간 지능 27.1%, 내비게이션 21.8%, 위치 파악 20.8%)에 크게 의존합니다. 재현 시 비율을 임의로 조정하지 마십시오. 특히 내비게이션 데이터가 없으면 안 됩니다. 모든 일반 VLM 기준선이 R2R-CE에서 SR=0.0이므로 내비게이션 능력은 명시적으로 훈련되어야 합니다.
  • 가장 함정이 많은 부분은 전환 샘플링: 기본 샘플링에서 전환 데이터는 25%만 차지하며, 조정하지 않으면 장기 작업 성능이 크게 저하됩니다(73.6 vs 75.9). 데이터 파이프라인에서 전환 단계 비율을 명시적으로 계산하고 2× 오버샘플링을 설정하는 것이 좋습니다.
  • 메모리 모달리티가 검색 전략보다 중요: 리소스가 제한된 경우 이미지+텍스트 혼합 메모리를 우선 보장하고 프레임 샘플링 전략을 조정하는 데 시간을 쓰지 마십시오. 균일 샘플링과 최근 편향 간에는 거의 차이가 없습니다(75.9 vs 75.3).
  • 계층 구조의 통신 프로토콜은 단순해야 함: 플래너와 액터는 공유 변수 z(현재 하위 작업)를 통해서만 통신하며, 플래너 메모리는 액터에 보이지 않습니다. 동기 모드는 실험 재현에 적합하고, 비동기 모드는 생산 배포(운동 평활성 우선)에 적합합니다.
  • 실제 로봇 평가 시 액터 병목 주의: 액터 오류가 대부분의 실패 에피소드를 유발하므로, 평가 시 플래너 오류와 액터 오류를 반드시 구분해야 합니다. 그렇지 않으면 플래너 성능을 잘못 판단할 수 있습니다. 먼저 액터의 언어 추종 능력을 별도로 평가하는 것이 좋습니다.
  • 훈련 구성 직접 재사용 가능: 1 epoch, lr 1e-5, weight decay 0.01, batch 256, 128 H100, FSDP 전체 샤딩, FlashAttention-2, 시퀀스 패킹, 최대 길이 8192, 최대 비디오 프레임 32 — 이러한 매개변수는 논문에 명시되어 있으며 시작점으로 직접 사용할 수 있습니다.
