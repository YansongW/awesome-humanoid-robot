Reinforcement Learning with Prototypical Representations

Reinforcement Learning with Prototypical Representations

요약

Learning effective representations in image-based environments is crucial for sample efficient Reinforcement Learning (RL). Unfortunately, in RL, representation learning is confounded with the exploratory experience of the agent -- learning a useful representation requires diverse data, while effective exploration is only possible with coherent representations.

출처

  • arXiv:2102.11271 Reinforcement Learning with Prototypical Representations
  • 智元、众擎都在卷的人形机器人运控基座：41篇论文看懂BFM

개요

Proto-RL은 Denis Yarats 등이 제안한 이미지 강화 학습을 위한 비지도 표현 학습 방법으로, 자기 지도 프로토타입 클러스터링과 최대 엔트로피 탐색의 결합 훈련을 통해 작업과 무관한 시각 표현 사전 훈련을 달성하고, 이를 통해 하위 작업의 샘플 효율성과 다중 작업 일반화 능력을 향상시키는 것을 목표로 한다. 핵심 기여는 표현 학습과 탐색을 분리하여 사전 훈련된 표현을 동결하여 재사용할 수 있게 하고, 여러 DeepMind Control 작업에서 완전 지도 방식의 DrQ 기준선을 능가하거나 필적하는 성능을 달성한 것이다.

무엇을 바꾸었는가

이미지 RL에서 표현 학습과 탐색은 오랫동안 "닭과 달걀"의 딜레마에 직면해 왔다. 효과적인 표현은 다양한 탐색 데이터를 필요로 하고, 효율적인 탐색은 일관된 표현에 의존하기 때문이다. 기존 방법은 작업 보상에 의존하여 표현 학습을 유도하거나(예: DrQ), 표현이 특정 작업에 묶여 교차 작업 일반화가 불가능하거나, 보상이 없을 때 자기 지도 목표(예: CURL, SAC-AE)를 사용하지만 탐색 신호가 부족하여 희소 보상 환경에서 실패한다. Proto-RL이 진정으로 바꾼 것은 "표현 학습"과 "탐색"을 결합된 공동 최적화에서 해방시킨 것이다. 프로토타입 클러스터링을 통해 안정적인 자기 지도 목표를 제공하고, 동시에 엔트로피 최대화로 탐색을 유도하며, 둘은 공유 잠재 공간에서 협력하지만 그래디언트는 분리되어 있어 작업 보상이 없는 단계에서도 전이 가능한 일반 표현을 학습할 수 있다. 이 설계는 RL에 처음으로 CV/NLP의 "사전 훈련-미세 조정" 패러다임을 도입하여, 하위 작업은 표현을 동결하고 소량의 내재적 보상을 추가하기만 하면 빠르게 학습할 수 있으며, 처음부터 인코더를 훈련할 필요가 없다.

방법 분해

2단계 프레임워크

  • 1단계(작업 무관 사전 훈련): 에이전트는 내재적 보상(엔트로피 최대화)만 최적화하고, 동시에 자기 지도 표현 손실 LSSL을 최소화하며, 어떤 작업 보상도 접촉하지 않는다.
  • 2단계(하위 작업 학습): 인코더 fθ, 프로젝터 gθ 및 프로토타입 {ci}를 동결하고, 외재적 보상 rt와 내재적 보상 r̂t를 선형 결합(rt + αr̂t, α=0.2)하여 표준 SAC로 정책을 훈련한다.

표현 학습 흐름

  1. 증강 프레임 xt(무작위 이동) → 온라인 인코더 fθ(SAC-AE 아키텍처, 4층 3×3 컨볼루션, 32채널, 출력 39200차원) → 프로젝터 gθ(선형 레이어, 128차원) → 예측기 vθ(MLP 128→512→128) → 정규화하여 û를 얻는다.
  2. 타깃 네트워크(fξ, gξ)가 다음 프레임 xt+1을 인코딩하여 zt+1을 얻고, Sinkhorn-Knopp 클러스터링(3회 반복)으로 타깃 분포 qt+1을 얻는다.
  3. 손실: LSSL = −qTt+1 log pt, 여기서 p(i)t = exp(ûTt ci/τ) / Σk exp(ûTt ck/τ), τ=0.1, M=512개의 프로토타입.
  4. 그래디언트는 온라인 네트워크와 프로토타입만 업데이트하고, 타깃 네트워크는 EMA(모멘텀 0.05)로 업데이트한다. 예측기 vθ는 비대칭성을 도입하여 붕괴를 방지한다.

최대 엔트로피 탐색

  • 내재적 목표: 잠재 공간 상태 방문 분포의 엔트로피를 최대화하고, k-NN 추정기(k=3)를 사용한다: r̂t = ||zt+1 − NNk,Q(zt+1)||.
  • 최근접 이웃 계산 비용을 줄이기 위해 고정 크기 큐 Q(M×T=512×4=2048)를 유지하고, 각 프로토타입은 softmax 가중치로 T개의 후보를 샘플링한다.
  • RL 에이전트(SAC)는 전이 (yt, at, r̂t, yt+1)로 훈련하지만, LRL 그래디언트는 차단되어 표현이 작업과 무관함을 보장한다.

핵심 혁신

  1. 프로토타입 클러스터링과 탐색의 결합이지만 분리된 최적화: 기존 방법이 표현 학습과 탐색을 결합하는 것(예: APT가 엔트로피를 직접 최적화)과 달리, Proto-RL은 Sinkhorn-Knopp로 프로토타입 균등 할당을 보장하여 표현 학습 목표를 안정화하고, 동시에 엔트로피 보상으로 탐색을 유도하며, 둘은 공유 잠재 공간을 사용하지만 그래디언트는 분리된다(LRL이 인코더를 업데이트하지 않음). 이것이 작업 무관 표현을 달성할 수 있는 핵심이다.
  2. 동결 표현의 다중 작업 재사용: 사전 훈련 후 인코더와 프로토타입은 완전히 동결되어 여러 하위 작업(예: Walker의 4개 방향 작업)에 직접 사용되며, 각 작업마다 표현을 다시 학습할 필요가 없다. 이는 기존 RL 표현 학습 방법에서 드문 것으로, 표현의 일반화를 직접 검증한다.
  3. 프로토타입 샘플링의 저분산 엔트로피 추정: APT의 균등 샘플링과 달리, Proto-RL은 프로토타입 softmax 분포로 재균형 샘플링을 수행하여 Acrobot Swingup과 Hopper Hop에서 내재적 보상 분산을 크게 줄이고(그림 9), 탐색 신호를 더 안정적으로 만든다. 이는 희소 보상 작업에 특히 중요하다.

실험 및 결과

단일 작업 평가(그림 4, 8개 DMC 환경)

다중 작업 평가(그림 5, Walker 및 Reach Duplo 각 4개 작업)

  • Proto-RL은 모든 기준선(Random, APT, Curiosity, DrQ)보다 현저히 우수하며, 표현을 동결한 후 직접 재사용하므로 재훈련이 필요 없다.

사전 훈련 효율성(그림 6)

  • 200k 사전 훈련 스텝에서 Proto-RL은 이미 상태 공간을 충분히 탐색할 수 있으며, 하위 작업 성능이 기준선보다 우수하다. Walker Run에서 기준선은 사전 훈련 스텝이 증가할수록 성능이 오히려 하락하지만, Proto-RL은 안정적으로 유지된다.

하위 작업 탐색(그림 7)

  • α=0은 모든 작업에서 α≥0.1보다 열등하다. 희소 보상 작업(Cartpole Swingup Sparse, Reach Duplo)에서 α≥0.1은 α=0보다 현저히 우수하여 내재적 보상의 필요성을 검증한다.

상태 커버리지 및 분산(그림 8, 9)

  • Proto-RL 사전 훈련 단계는 더 높은 엔트로피의 상태 방문 분포를 달성한다(Cartpole Swingup Sparse, Walker Run).
  • 프로토타입 샘플링은 균등 샘플링(APT)보다 Acrobot Swingup과 Hopper Hop에서 내재적 보상 표준 편차가 더 낮다.

사전 훈련 없는 실험(그림 13)

  • Proto-RL은 사전 훈련 없이도 DrQ보다 우수하지만, 사전 훈련 버전보다는 낮아 사전 훈련 방식이 성능에 중요함을 증명한다.

경계 및 한계

  • Plan2Explore와의 비교 불공정성: 저자는 Plan2Explore가 작업 무관 단계에서 작업 보상으로 보상 모델을 사전 훈련(하위 작업 정보 누출)하고, 리플레이 버퍼를 유지하며 세계 모델 미세 조정을 허용하는 반면, Proto-RL은 작업 무관 전이를 완전히 무시하고 표현을 동결하므로 직접 비교는 공정하지 않다고 인정한다.
  • APT 기준선 구현 차이: 공정성을 위해 APT의 인코더 가중치를 동결했지만, Liu & Abbeel (2021)의 원래 구현은 미세 조정을 허용하므로 APT 성능을 과소평가할 수 있다.
  • 하지 않은 것: 실제 로봇 플랫폼 검증 없음; α, M, Sinkhorn 반복 횟수, 온도 τ의 민감도 분석 없음; 인코더 동결 vs 미세 조정의 심층 실험 없음(미세 조정 호환만 언급); 계산 자원 및 훈련 시간 보고 없음; 이론적 분석 없음(예: 이산 표현의 이론적 기반).
  • 적용 경계: DMC 연속 제어 작업에서만 검증되었으며, 이산 행동, 다중 에이전트 또는 고차원 3D 환경은 다루지 않음; 표현 학습은 1단계 동적 유사성을 유지하지만, 이중 시뮬레이션 메트릭과 같은 모델 최소화 기술과의 연결은 없음.

공학적 시사점

  • 재현 우선순위: 먼저 Sinkhorn-Knopp의 3회 반복과 온도 τ=0.1을 확인해야 한다. 이것이 프로토타입 균등 할당과 붕괴 방지의 핵심이다. 다음으로 LRL 그래디언트가 실제로 차단되었는지 확인해야 한다(그렇지 않으면 표현이 작업과 결합되어 일반화를 잃는다).
  • 쉽게 빠지는 함정: α 값은 희소 보상 작업에 큰 영향을 미치므로(α=0에서 성능이 현저히 하락), 목표 환경에서 먼저 α∈{0.1, 0.2, 0.5}를 스캔하는 것이 좋다. 큐 크기 M×T와 k-NN의 k=3은 일관성을 유지해야 하며, 그렇지 않으면 내재적 보상 스케일이 변동한다.
  • 하위 작업 적응: 인코더를 동결한 후 하위 작업 관측 분포가 사전 훈련과 크게 다른 경우(예: 다른 카메라 각도), 인코더 미세 조정을 시도할 수 있지만(저자는 호환 가능하다고 언급했지만 실험하지 않음), 표현의 작업 무관성을 손상시킬 수 있음에 주의해야 한다.
  • 기준선 비교 함정: APT를 재현할 때 인코더 동결 여부를 명확히 해야 하며, 그렇지 않으면 비교 결과가 왜곡된다. Plan2Explore와 비교할 때는 사전 훈련 단계의 정보 누출 조건을 엄격히 정렬해야 한다.
  • 자원 제안: 사전 훈련 200k 스텝으로도 사용 가능한 표현을 얻을 수 있으므로(그림 6), 계산이 제한된 경우 먼저 200k로 파이프라인을 검증한 후 500k로 확장할 수 있다. SAC 구현은 저자가 오픈소스로 공개한 pytorch_sac 버전(LayerNorm 및 39200→50 완전 연결 레이어 포함)을 직접 사용하는 것이 좋으며, 자체 구현으로 인한 편향을 피해야 한다.
