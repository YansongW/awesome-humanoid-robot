정책 병합을 통한 로봇 군단 학습

Robot Fleet Learning via Policy Merging

영역
AI 모델 및 알고리즘대량 생산소프트웨어 미들웨어
계층
지능 계층중위
검증
대기 중

요약

원시 데이터를 중앙 집중화하지 않고 이질적인 로컬 로봇 데이터로 훈련된 순환 신경망 정책을 통합하는 분산 정책 병합 방법 FLEET-MERGE를 제안하고 FLEET-TOOLS 도구 사용 벤치마크를 소개한다.

출처

  • Robot Fleet Learning via Policy Merging

개요

로봇 함대가 환경과 상호작용할 때 생성되는 대량의 이종 스트리밍 데이터는 저장 또는 전송 능력을 훨씬 초과합니다. FLEET-MERGE는 순환 신경망 매개변수화 제어 정책에서의 순열 불변성을 고려하여 분산 이종 데이터셋에서 정책을 효율적으로 병합합니다. 이 방법은 Meta-World 환경의 50개 작업에서 유효성이 검증되었으며, 테스트 시 거의 모든 훈련 작업에서 우수한 성능을 보였습니다. 새로 제안된 FLEET-TOOLS 벤치마크는 조합적이고 접촉이 풍부한 로봇 조작 작업에 초점을 맞추어 FLEET-MERGE의 실용성을 추가로 검증합니다.

핵심 내용

방법

  • FLEET-MERGE는 정책 병합(PoMe) 프레임워크를 기반으로 함대 수준의 분산 학습 문제를 해결합니다.
  • 핵심 혁신은 순환 신경망(RNN) 매개변수화 정책에서의 순열 불변성을 처리하는 것으로, 네트워크 가중치가 서로 다른 순열에서 동일한 기능에 해당할 수 있으므로 정렬 후 병합해야 합니다.
  • 원시 데이터를 중앙 집중화할 필요 없이 정책 매개변수만 교환하여 데이터 프라이버시를 보호하고 통신 비용을 줄입니다.

실험 설정

  • Meta-World 환경: 50개의 서로 다른 작업에서 독립 정책을 훈련하며, 각 작업은 로봇 조작 시나리오(예: 밀기, 당기기, 문 열기 등)에 해당합니다.
  • FLEET-TOOLS 벤치마크: 새로 설계된 도구 사용 작업 세트로, 조합적 조작(예: 망치로 못 박기, 삽으로 땅 파기)과 접촉이 풍부한 상호작용(예: 도구 잡기, 회전시키기)을 포함합니다.

주요 결과

  • Meta-World의 50개 작업에서 FLEET-MERGE로 병합된 정책은 테스트 시 거의 모든 작업에서 높은 성공률을 유지하며, 평균 성능은 개별 훈련 정책에 근접합니다.
  • FLEET-TOOLS 벤치마크에서 FLEET-MERGE는 서로 다른 도구 사용 정책을 성공적으로 병합했으며, 조합 작업에서 기준 방법(예: 단순 평균 또는 연방 학습 변형)보다 우수한 성능을 보였습니다.
  • 실험은 정책 병합 효율이 작업 수가 증가함에 따라 향상되고 데이터 이질성에 대해 강건함을 보여줍니다.

결론

FLEET-MERGE는 로봇 함대를 위한 확장 가능한 분산 학습 솔루션을 제공하며, 데이터를 중앙 집중화하지 않고 정책 병합을 통해 기술 공유를 실현합니다. FLEET-TOOLS 벤치마크는 특히 정밀 조작과 도구 상호작용이 필요한 시나리오에서 향후 연구를 위한 표준화된 평가 플랫폼을 제공합니다.
