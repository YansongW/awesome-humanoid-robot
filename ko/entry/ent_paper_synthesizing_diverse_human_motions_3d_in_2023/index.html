Synthesizing Diverse Human Motions in 3D Indoor Scenes

요약

We present a novel method for populating 3D indoor scenes with virtual humans that can navigate in the environment and interact with objects in a realistic manner. Institutions per source list: ETH Zürich、Google.

출처

  • arXiv:2305.12411 Synthesizing Diverse Human Motions in 3D Indoor Scenes

  • Project page

개요

본 논문은 3D 실내 장면에서 다양하고 사실적이며 지속적인 인간 동작을 합성하기 위한 강화 학습(RL) 기반 프레임워크를 제안한다. 이 방법은 학습된 생성적 동작 기초 모델과 장면 인식 동작 및 상호작용 정책을 결합하여 가상 인간이 복잡한 환경을 탐색하고, 충돌을 피하며, 앉기, 눕기와 같은 세밀한 상호작용을 수행할 수 있게 한다. 핵심 기여는 신체 표면 키포인트 제어, 상태 및 보상에 장면 정보 통합, 데이터 증강 전략을 통해 동작의 자연스러움, 다양성 및 물리적 타당성을 크게 향상시켜 여러 지표에서 기존 베이스라인보다 우수한 성능을 보인다는 점이다.

무엇을 변화시키는가

이 연구가 진정으로 변화시키는 것은 '인간-장면 상호작용 합성' 작업의 제어 가능성과 물리적 타당성의 경계이다. 기존 방법(예: SAMP)은 복잡한 실내 환경에서 생성된 동작에 심각한 신체-장면 관통, 부정확한 접촉, 부자연스러운 지각 문제가 자주 발생했으며, 세밀한 신체 부위 제어가 어려웠다. 본 논문은 SDF, 보행 가능 지도와 같은 장면 기하학 정보를 RL의 상태 및 보상 설계에 직접 통합함으로써 정책이 후처리 수정에 의존하지 않고 자율적으로 충돌을 회피할 수 있게 하여, 생성 프로세스의 견고성을 근본적으로 변화시킨다. 동시에 [54,55]와 같은 다단계 프레임워크의 사전 정의된 프레임 수 의존성을 극복하고 더 유연한 지속적 동작 생성을 가능하게 하여, 가상 인간이 동적 상호작용 환경에 '거주'하는 것에 더 가까운 실제 응용 기술 경로를 제공한다.

방법 분해

프레임워크 개요

  • 강화 학습(RL)을 사용하여 두 가지 핵심 정책을 훈련한다: 이동 정책(locomotion policy) 은 장면에서 초기 위치에서 목표 위치로 이동하고 장애물을 회피하는 역할을 담당하며, 객체 상호작용 정책(interaction policy) 은 앉기, 눕기와 같은 세밀한 상호작용을 실행한다.
  • 신체 표면 키포인트를 세밀한 제어 목표로 사용하며, 루트 노드나 관절 각도에만 의존하지 않아 상호작용의 정밀도가 향상된다.

이동 정책 훈련

  • 무작위 합성 장면에서 훈련하며, 장면 생성 단계:
  • 초기 직사각형 영역의 변 길이는 2–7미터.
  • ShapeNet에서 가구(의자, 침대, 소파, 테이블, 책상)를 무작위로 샘플링하고, 대형 객체 수를 제한.
  • 객체를 무작위로 회전 및 평행 이동하여 경계를 확장.
  • 내비게이션 메시지(navigation mesh) 를 사용하여 충돌 없는 경로 탐색을 수행하고, 초기-목표 위치 쌍을 샘플링하며, 훈련 중 초기 신체 자세와 방향을 무작위화.
  • 장면 정보는 보행 가능 지도(2D 점유 맵, 1.6미터×1.6미터를 덮는 16x16 그리드, 골반 중심, 신체 전방 정렬, 각 시간 단계마다 동적 업데이트)와 SDF 특징(사전 계산된 128x128x128 그리드, 테스트 시 삼선형 보간)을 통해 상태와 보상에 통합.

객체 상호작용 정책 훈련

  • 데이터 소스: PROX 데이터셋, 정적 인간-장면 상호작용 추정(SMPL-X 신체는 LEMO에서, 객체 메시는 COINS에서), 'sit on' 및 'lie on' 주석만 사용.
  • 데이터 증강: PROX 정적 상호작용을 무작위 ShapeNet 객체로 리타겟팅하고, 스케일, 회전, 평행 이동 최적화를 통해 피팅하며, 약간의 증강을 적용.
  • 훈련 시 정적 상호작용 프레임을 무작위로 샘플링하여 객체 메시와 목표 신체 마커를 획득하고, 0.25 확률로 초기 및 목표 신체를 교환하여 '서 있는' 동작을 학습.
  • 수정된 COINS를 사용하여 목표 정적 상호작용을 합성: 원래 COINS는 PROX에서 객체 다양성이 제한적이므로, 저자는 더 다양한 ShapeNet 하위 집합에 골반 프레임 데이터를 주석 처리하고 PelvisNet을 재훈련하며 BodyNet은 유지.

핵심 설계 결정

  • 내비게이션 메시지는 pynavmesh 라이브러리를 사용하며, 에이전트 반경 0.2(경로 탐색용)와 0.02(로컬 보행 가능 지도용)의 두 가지 버전을 생성하여 전역 계획과 로컬 장애물 회피 정밀도의 균형을 유지.
  • SDF 특징 사전 계산 및 삼선형 보간은 정밀도와 계산 효율성 사이의 균형을 제공.

핵심 혁신

  1. 장면 인식 RL 상태 및 보상 설계: SDF 거리, 보행 가능 지도와 같은 장면 기하학 정보를 정책 입력 및 보상 함수에 직접 통합하여 충돌 회피가 후처리가 아닌 정책의 고유 동작이 되게 한다. 이는 전통적인 '생성-수정' 패러다임에 대한 근본적인 개선으로, 물리적 타당성(inter. pene. mean 15.61→3.40)을 크게 향상시킨다.
  2. 세밀한 신체 키포인트 제어: 신체 표면 키포인트를 상호작용 목표로 사용하여 관절이나 루트 노드에만 의존하지 않음으로써, 앉기, 눕기와 같은 동작의 접촉 품질이 크게 향상되고(contact 0.87→0.96), 복잡한 객체 형태를 처리할 수 있다.
  3. 데이터 증강 및 COINS 재훈련: PROX 정적 상호작용을 ShapeNet 객체로 리타겟팅하고 COINS의 PelvisNet을 재훈련하여 훈련 데이터의 객체 다양성 부족 문제를 해결하고, 정책이 보지 못한 객체 형태로 일반화할 수 있게 한다. 이는 다양한 동작을 구현하는 핵심이다.

경계 및 한계

  • 관통 문제 완전 해결되지 않음: 보상으로 관통 회피를 장려할 뿐, 하드 제약을 적용하지 않음. 물리 시뮬레이션과의 결합으로 해결 가능하지만, 논문은 구체적인 구현을 언급하지 않음.
  • 누운 동작의 자연스러움 부족: 동작 기초 모델은 제한된 훈련 데이터로 포괄적인 누운 동작 공간을 학습하지 못함(AMASS에서 누운 데이터는 167초에 불과, 앉기는 약 5K초).
  • 장면 유형 제한: 이동 정책은 평평한 지면에 국한되며 2D 점유 보행 가능 지도에 의존. 평평하지 않은 야외 지형이나 다층 건물로 확장하려면 환경 인식 메커니즘을 교체해야 함.
  • 정적 장면 전용: 동적 상호작용(이동 가능한 객체, 다른 인간, 동물, 차량 등 자율 에이전트)을 처리하지 않음.
  • 훈련 구성 미공개: 네트워크 구조, 옵티마이저, 학습률, 훈련 스텝 수, 추론 빈도, 하드웨어 등 세부 사항이 논문에 명시되지 않음.

엔지니어링 시사점

  • 재현 우선순위: 먼저 데이터 증강 프로세스(PROX를 ShapeNet으로 리타겟팅)와 COINS 재훈련 세부 사항을 확인해야 하며, 이는 일반화 능력의 핵심이다. 다음으로 내비게이션 메시지 이중 반경 설정(0.2 및 0.02)이 경로 탐색과 로컬 장애물 회피에 미치는 영향을 확인.
  • 주의할 함정: SDF 특징 사전 계산(128x128x128)의 메모리 및 계산 오버헤드가 크므로 정밀도와 속도의 균형이 필요. 보행 가능 지도의 동적 업데이트 빈도는 장애물 회피 실시간성에 직접 영향을 미치므로, 먼저 16x16 그리드가 목표 장면에서 충분한 해상도인지 검증할 것.
  • 하위 팀 지침: 상호작용 유형(예: 터치, 운반)을 확장해야 한다면 추가 훈련 데이터 수집과 정책 재설계가 필요. 목표 장면에 동적 객체가 포함된 경우 현재 프레임워크는 적용 불가하므로 물리 시뮬레이션 또는 동적 장면 모델링 도입을 고려해야 함.
  • 성능 병목: 추론 시 트리 샘플링이 계산 비용을 증가시켜 실시간 응용을 제한할 수 있음. 먼저 목표 하드웨어에서의 추론 지연 시간을 평가한 후 프레임워크 채택 여부를 결정할 것.
