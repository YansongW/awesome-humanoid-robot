요약

접촉 작업에서 제약 방향으로는 힘을, 자유 방향으로는 위치를 동시에 제어하는 전략.

개요

힘/위치 혼합 제어(Force/Position Hybrid Control)는 작업 공간을 방향별로 직교 분해하여 각각 위치 제어와 힘 제어를 수행하는 조작 전략입니다. 선택 행렬 \(\boldsymbol{\Sigma}\)을 통해 작업 공간을 위치 제어 부분 공간과 힘 제어 부분 공간으로 나누며, 구속 방향(예: 테이블 표면에 수직인 법선 방향)에서는 접촉력을 제어하고 자유 방향(예: 테이블 표면에 평행한 접선 방향)에서는 위치를 제어합니다. 이 방법이 실제로 바꾸는 것은 "힘과 위치를 동시에 제어한다"는 단순한 바람이 아니라, "어느 방향에서 무엇을 제어할지"라는 작업 의미론을 제어 법칙에 명시적으로 부호화하여, 접촉이 풍부한 조작에서 기하학적 정밀도와 상호작용 안전성을 동시에 확보하는 것입니다.

핵심 내용

무엇인가: 하나의 방향, 하나의 제어 목표

힘/위치 혼합 제어는 조작 작업에서 근본적인 비대칭성을 해결합니다: 방향에 따라 제어 목표에 대한 요구가 본질적으로 다릅니다. 테이블 위에서 물체를 밀 때, 수평 방향은 목표 위치를 정밀하게 추적해야 하며(그렇지 않으면 물체가 목표 궤적에서 벗어남), 수직 방향은 목표 접촉력을 유지해야 합니다(그렇지 않으면 테이블을 부수거나 접촉을 잃게 됨). 모든 방향에 위치 제어를 적용하면 환경 강성의 불확실성으로 인해 접촉력이 통제 불능이 되고, 모든 방향에 힘 제어를 적용하면 자유 방향의 위치 정밀도를 보장할 수 없습니다.

이 방법의 수학적 핵심은 선택 행렬 \(\boldsymbol{\Sigma}\)로, 대각 0/1 행렬입니다:

\[ \boldsymbol{\Sigma} = \text{diag}(\sigma_1, \ldots, \sigma_m), \quad \sigma_i \in \{0,1\} \]
  • \(\sigma_i = 1\)이면, \(i\)번째 방향은 위치를 제어합니다.
  • \(\sigma_i = 0\)이면, \(i\)번째 방향은 힘을 제어합니다.

이로써 작업 공간은 두 개의 상보적 부분 공간으로 직교 분해됩니다: 위치 제어 부분 공간(\(\boldsymbol{\Sigma}\)의 상공간)과 힘 제어 부분 공간(\(\mathbf{I} - \boldsymbol{\Sigma}\)의 상공간). 제어 법칙은 다음과 같습니다:

\[ \mathbf{F}_{\text{cmd}} = \boldsymbol{\Sigma} \, \mathbf{K}_p (\mathbf{x}_d - \mathbf{x}) + (\mathbf{I} - \boldsymbol{\Sigma}) \, \mathbf{K}_f (\mathbf{F}_d - \mathbf{F}) \]

여기서 \(\mathbf{x}_d - \mathbf{x}\)는 위치 오차, \(\mathbf{F}_d - \mathbf{F}\)는 힘 오차, \(\mathbf{K}_p\)와 \(\mathbf{K}_f\)는 각각 위치와 힘의 비례 이득입니다. 최종적으로 \(\boldsymbol{\tau} = \mathbf{J}^T \mathbf{F}_{\text{cmd}}\)를 통해 작업 공간 힘을 관절 토크로 매핑합니다.

왜 존재하는가: 단일 제어 모드의 자연적 결함

힘/위치 혼합 제어가 등장하기 전, 로봇 조작은 딜레마에 직면했습니다. 순수 위치 제어(예: 산업용 로봇에서 가장 흔한 PTP/CP 모드)는 접촉 작업에서 극도로 취약합니다: 환경 위치 오차가 수 밀리미터에 불과해도 접촉력이 환경 강성 때문에 파괴적 수준으로 급증할 수 있습니다. 순수 힘 제어는 반대로 자유 공간에서 거의 사용할 수 없습니다—접촉이 없을 때 힘 오차 신호는 의미가 없으며 위치 드리프트가 불가피합니다.

힘/위치 혼합 제어의 역사적 위상은 "기하학적 구속과 힘 구속이 모두 있는" 작업을 위한 최초의 체계적 제어 프레임워크를 제공한 것입니다. 이는 하나의 통합 목표로 두 요구를 근사하려 하지 않고, 작업 공간의 이방성을 인정하며 선택 행렬로 각 방향의 제어 모드를 명시적으로 선언합니다. 이 사상은 이후 임피던스 제어와 어드미턴스 제어 설계에 깊은 영향을 미쳤습니다—후자들은 방향을 명시적으로 분해하지 않지만, 본질적으로도 힘과 위치 사이에서 동적 절충을 수행합니다.

원리 분해

① 선택 행렬: 작업 의미론의 수학적 부호화

선택 행렬 \(\boldsymbol{\Sigma}\)의 물리적 의미는 "구속 방향 검출"입니다. 접촉 작업에서 환경 기하학은 운동에 자연적 구속을 부과합니다: 테이블에 수직인 방향은 테이블에 의해 "잠겨" 로봇은 힘만 가할 수 있고 자유롭게 움직일 수 없습니다; 테이블에 평행한 방향은 구속이 없어 로봇은 자유롭게 움직일 수 있지만 안정적인 힘을 가할 수 없습니다. 힘/위치 혼합 제어의 핵심 통찰은 다음과 같습니다: 구속 방향은 힘을 제어하고, 자유 방향은 위치를 제어해야 합니다. \(\boldsymbol{\Sigma}\)는 바로 이 의미론의 수학적 표현입니다.

② 직교 분해: 채널 간 커플링 방지

위치 제어와 힘 제어가 직교 부분 공간에 할당된다는 것은 위치 오차가 힘 채널에서 제어 작용을 생성하지 않고, 힘 오차도 위치 채널에서 제어 작용을 생성하지 않음을 의미합니다. 이러한 분리는 힘/위치 혼합 제어가 "가중 합산" 방식의 컴플라이언트 제어와 구별되는 핵심입니다—후자는 본질적으로 여전히 단일 제어 목표이며 위치 오차와 힘 오차를 가중치로 혼합할 뿐, "한 방향은 엄격히 위치 제어, 다른 방향은 엄격히 힘 제어"를 실제로 구현할 수 없습니다.

③ 관절 토크 매핑: 작업 공간에서 관절 공간으로

제어 법칙이 출력하는 \(\mathbf{F}_{\text{cmd}}\)는 작업 공간 일반화 힘이며, 야코비안 전치를 통해 관절 토크로 매핑해야 합니다:

\[ \boldsymbol{\tau} = \mathbf{J}^T \mathbf{F}_{\text{cmd}} \]

이 매핑은 로봇이 비-중복, 비-특이 형상에 있다고 가정합니다. 휴머노이드 로봇에서는 플로팅 베이스와 전신 협조 요구가 있으므로, 일반적으로 힘/위치 혼합 제어를 전신 제어(WBC) 프레임워크에 내장하여 운동학적 구속 및 동역학적 최적화와 함께 연립으로 해결합니다.

주요 파라미터 및 사양

파라미터 의미 일반적인 값/설명
\(\boldsymbol{\Sigma}\) 선택 행렬, 대각 0/1 1은 위치 채널, 0은 힘 채널; 작업 방향에 따라 사전 설정 필요
\(\mathbf{K}_p\) 위치 비례 이득 위치 채널의 강성을 결정하며, 충격을 피하기 위해 환경 강성보다 낮아야 함(공학적 판단)
\(\mathbf{K}_f\) 힘 비례 이득 힘 채널의 수렴 속도를 결정하며, 너무 크면 힘 진동 유발(공학적 판단)
\(\mathbf{J}^T\) 야코비안 전치 작업 공간 힘을 관절 토크로 매핑하며, 로봇이 특이 형상이 아님을 보장해야 함
제어 주파수 힘 제어 루프 업데이트율 접촉 동역학 주파수보다 현저히 높아야 하며, 일반적으로 1 kHz 이상(공학적 판단)

수평 비교: 세 가지 힘 제어 프레임워크의 위치

프레임워크 핵심 사상 적용 시나리오 주요 한계
임피던스 제어 로봇을 질량-스프링-댐퍼 시스템으로 표현하고, 임피던스 파라미터 조절로 힘을 간접 제어 다리 착지 충격 흡수, 불확실한 환경 접촉 힘 정밀도가 환경 위치 추정에 의존하며, 환경 강성 미지 시 힘 오차 큼
어드미턴스 제어 외부 루프 힘 오차가 위치 보정량을 생성하고, 내부 루프 위치 제어가 추적 손목 힘 센서가 있을 때 안정적인 접촉력 추적 고정밀 위치 내부 루프 필요, 힘 루프 대역폭 제한적
힘/위치 혼합 제어 방향별 직교 분해, 위치 채널과 힘 채널 독립 제어 축 삽입, 곡면 연마, 테이블 밀기 접촉 전환 시 선택 행렬 급변, 힘 충격 유발 가능

공학적 선택 규칙은 다음과 같습니다: 관절 토크 제어성이 좋으면 임피던스, 위치 제어성이 좋으면 어드미턴스를 사용합니다. 휴머노이드 로봇의 다리는 주로 임피던스(착지 충격 흡수)를 사용하고, 팔은 손목 힘 센서가 있을 때 어드미턴스(접촉력 안정 추적)를 자주 사용합니다. 힘/위치 혼합 제어는 작업 방향 의미론이 명확하고 기하학적 정밀도와 힘 안전성을 동시에 보장해야 하는 시나리오에 적합합니다.

사용 사례·응용 사례

산업용 조립은 힘/위치 혼합 제어의 가장 고전적인 응용 시나리오입니다. 축 삽입(peg-in-hole) 작업에서 축 방향은 삽입력을 제어해야 하며(걸림 또는 부품 손상 방지), 반경 방향은 위치를 제어해야 합니다(구멍 중심 정렬 보장). 전통적인 위치 제어 방식은 축-구멍 간극이 작을 때 미세한 위치 오차로 인해 쉽게 걸릴 수 있으며, 힘/위치 혼합 제어는 축 방향 힘 제어와 반경 방향 위치 제어의 분해를 통해 조립 성공률을 크게 향상시킵니다.

휴머노이드 로봇 조작에서 힘/위치 혼합 제어는 종종 전신 제어와 결합됩니다. 예를 들어, 휴머노이드 로봇이 테이블 위 물체를 밀 때 팔의 수평 방향은 목표 궤적을 추적하고 수직 방향은 일정한 접촉력을 유지합니다; 또 다른 예로, 휴머노이드 로봇이 걸레로 테이블을 닦을 때 법선 방향 힘 제어로 청소 압력을 일정하게 유지하고 접선 방향 위치 제어로 커버 경로의 완전성을 보장합니다.

접촉 전환 시나리오는 힘/위치 혼합 제어의 가장 도전적인 응용입니다. 자유 공간 운동에서 접촉 확립으로 전환될 때 각 방향의 역할이 급변합니다—원래 자유였던 방향이 갑자기 구속 방향이 되고, 원래 위치 제어였던 방향이 갑자기 힘 제어가 필요해집니다. 선택 행렬 전환이 매끄럽지 않으면 힘 충격과 불안정이 발생합니다. 실제로는 힘/위치 혼합을 임피던스 프레임워크와 결합하는 경우가 많습니다, 즉 "가변 임피던스 + 방향 선택" 방식으로, 접촉 순간에 접근 방향 강성을 먼저 낮춘 후 목표 접촉력을 점진적으로 구축합니다.

한계와 경계

힘/위치 혼합 제어의 가장 고전적인 어려움은 접촉 전환 시 선택 행렬의 전환입니다. 자유 공간 운동에서 접촉 확립으로 전환될 때 각 방향의 역할이 급변하며, 전환이 매끄럽지 않으면 힘 충격이 발생할 수 있습니다. 이 문제의 근원은 선택 행렬이 이산적인 0/1 변수인 반면 접촉 상태는 연속적으로 진화하는 물리적 과정이라는 점입니다. 이산 전환과 연속 물리 사이의 간극은 힘/위치 혼합 제어의 고유한 이론적 한계입니다.

또한, 힘/위치 혼합 제어는 환경 기하학 모델에 대한 의존도가 높습니다. 선택 행렬의 설정은 어떤 방향이 구속되고 어떤 방향이 자유로운지 사전에 알아야 하며, 이는 환경 기하학의 정확한 모델링을 요구합니다. 미지의 또는 동적으로 변화하는 환경에서는 선택 행렬의 온라인 추정 자체가 어려운 문제입니다.

힘/위치 혼합 제어는 또한 채널 간 동적 커플링의 도전에 직면합니다. 위치와 힘 채널이 작업 공간에서 직교하지만, 로봇 동역학(특히 관성 커플링과 코리올리 힘)을 통해 여전히 서로 영향을 미칩니다. 고속 운동이나 대관성 부하에서는 이러한 커플링이 제어 성능을 저하시킬 수 있습니다.

일반적인 오해

  1. "힘/위치 혼합 제어는 힘과 위치를 동시에 제어하는 것이다"—부정확합니다. 이는 모든 방향에서 힘과 위치를 동시에 제어하는 것이 아니라, 방향별로 직교 분해하여 각 방향은 힘 또는 위치 중 하나만 제어하며 둘은 상호 배타적입니다. 진정한 "동시"는 서로 다른 방향 사이에서만 발생합니다.

  2. "선택 행렬은 임의로 설정할 수 있다"—오류입니다. 선택 행렬은 작업의 환경 구속과 일치해야 합니다: 구속 방향은 반드시 힘 채널로, 자유 방향은 반드시 위치 채널로 설정해야 합니다. 반대로 설정하면 제어 불안정 또는 작업 실패가 발생합니다.

  3. "힘/위치 혼합 제어가 임피던스 제어보다 더 고급이다"—아닙니다. 세 가지 힘 제어 프레임워크는 각각 적용 시나리오가 있습니다. 힘/위치 혼합 제어는 방향 의미론이 명확할 때 장점이 뚜렷하지만, 접촉 전환이 빈번하고 환경이 불확실할 때는 임피던스 제어의 강건성이 더 좋습니다.

  4. "힘/위치 혼합 제어는 힘 센서가 필요 없다"—오류입니다. 힘 채널은 실시간 힘 피드백 신호가 필요하며, 일반적으로 손목 힘/토크 센서 또는 관절 토크 센서에서 얻습니다. 힘 피드백이 없으면 힘 채널의 제어 법칙은 폐루프를 형성할 수 없습니다.

관련 지식

  • ent_method_admittance_control — 어드미턴스 제어는 힘/위치 혼합 제어의 자매 프레임워크로, 외부 루프 힘 오차로 위치 보정량을 생성하며 손목 힘 센서가 있을 때 안정적인 접촉력 추적에 적합합니다.
  • ent_paper_yu_forcevla_enhancing_vla_models_2025 — ForceVLA는 외부 힘 감지를 제1종 모달리티로 승격시키고, 동작 디코딩 단계에서 힘 피드백을 동적으로 통합하여 힘 제어 사상의 학습 기반 정책으로의 확장을 대표합니다.
  • ent_paper_one_shot_multimodal_learning_f_2026 — 이 연구는 단일 시연에서 운동 및 접촉력 특징을 동시에 재현하며, 힘 인식 운동 프리미티브는 힘/위치 혼합 제어의 방향 분해 사상과 맥을 같이합니다.
  • ent_paper_wang_tacrefinenet_tactile_only_gras_2025 — TacRefineNet은 순수 촉각 피드백으로 파지 자세를 반복 조정하며, 촉각-동작 폐루프는 힘/위치 혼합 제어의 힘 피드백 폐루프와 원리적으로 상통합니다.
  • ent_paper_hafo_a_force_adaptive_control_2025 — HAFO의 힘 적응 제어 방법은 동적 접촉 시나리오에서 힘/위치 혼합 제어의 확장으로 볼 수 있으며, 고정된 방향 분해보다 접촉력의 온라인 적응을 강조합니다.
