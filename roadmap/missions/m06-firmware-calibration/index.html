M06 · 固件与标定：让铁疙瘩第一次听懂指令

全局位置：M05 装配完成之后、M07 台架测试之前。输入是一台装好但还没"开智"的关节模组，输出是一块可通信、已标定、三环调好的关节模组——M07 把它上台架，用数据决定它配不配装进腿里。本页把 阶段 1 总览 的步骤 6（闭环控制阶梯）展开到手把手级。

前置条件：M05 装配验收通过（全程无卡滞、空载电流正常）；驱动板、电机、编码器、线束齐备；电脑上装好驱动板配套的上位机工具。

理论背景：FOC（磁场定向控制）、PID 控制、电流-速度-位置三环级联卡片，教科书见 第 4 章 执行器 与 第 14 章 机器人控制基础。

步骤 1：固件烧录与版本冻结

【做什么】固件由 M04 选的驱动板决定，对号入座：

驱动板 固件路线 备注
ST B-G431B-ESC1 Berkeley Humanoid Lite 开源 FOC 固件 板子 $19；真机底层代码在其仓库 berkeley_humanoid_lite_lowlevel 子目录（C 语言、独立于训练栈——Berkeley Humanoid Lite GitHub）
ODrive ODrive 官方固件 + odrivetool Berkeley 方案亦兼容 ODrive / moteus / VESC（调研档案）
moteus moteus 官方固件 + tview 固件与上位机版本要配套

烧录三件事按顺序做：

  1. 装好工具链（ST 系用 ST-Link + STM32CubeProgrammer 或 DFU 模式；先确认能进 bootloader、能读回芯片信息）；
  2. 烧录后立刻记录固件版本号/commit——整机 22 台执行器（Berkeley 构型为 6512×10 台 + 5010×12 台，调研档案）必须刷同一版本，混版本 = 通信协议与默认参数对不上；
  3. 备份出厂默认参数（dump 一份存盘），调崩了能一键回去。

【为什么】固件是驱动板的"操作系统"：FOC 换相、三环计算、CAN 协议栈全在里面。版本混用是批量调试最隐蔽的坑——现象是"这批关节听话、那批不听话"，查三天才发现固件差了两个 commit。

【你的情况怎么分析】照抄 Berkeley 方案：用其文档指定的固件版本，不要追 main 分支最新提交。自研固件：先把"能编译、能烧、能回读版本号"固化成脚本，22 台量产时你会感谢自己。

步骤 2：电机参数录入——填错一个数，全盘皆输

【做什么】逐台录入四个核心参数，填进参数登记表（同型号电机也有个体差异，逐台登记）：

参数 获取方法 填错的后果
极对数 数磁钢：极对数 = 磁钢片数 ÷ 2；或查电机手册 换相错乱——嗡鸣、不转或乱抖
相电阻 R 手册值；或毫欧表/LCR 表测线电阻 ÷ 2（星形接法） 电流环增益失配
相电感 L 手册值；或 LCR 表（1 kHz 档）测线电感 ÷ 2 电流环自整定失败
KV 值 M02 选型时定的手册值 速度前馈与最高速估算全错

算例（星形接法换算）：测得任意两相线间电阻 0.20 Ω，则相电阻 = 0.20 ÷ 2 = 0.10 Ω；线电感同理除以 2。

【为什么】这四个数是 FOC 的"身份证信息"：极对数决定电角度与机械角度的换算（电角度 = 机械角度 × 极对数），R/L 决定电流环增益的物理量级，KV 决定速度-电压映射。驱动板自整定本质也是在估这几个数——估出来必须和手册/实测对一遍，差一个量级说明接线或测量有问题。

【你的情况怎么分析】无人机 无刷直流电机（如 Berkeley 用的 MAD M6C12 150KV，$129，调研档案）手册常缺 R/L：百元级 LCR 表值得买；没有就用驱动板自整定值，但登记表里标注"来源：自整定，未复测"，M07 的 Kt 标定会替你兜底校核。

步骤 3：编码器偏置校准——对齐电角度零位与机械零位

【做什么】FOC 要知道转子磁极相对定子的精确角度才能换相，但 关节编码器 装上时零位是随机的。自动校准的原理：驱动板注入一个缓慢旋转的开环电流矢量，转子被电磁力矩"拽"着跟转，转到对齐 d 轴时记下编码器读数——这就是偏置（offset）。校准后必须写 flash 保存，然后断电重启验证读数还在。

验证判据（工程建议值，需按你的驱动板手册校核）：连续 5 次上电重新校准，偏置漂移 < 5° 电角度。漂移超标说明磁钢或编码器安装有问题，调参救不了，回 M05 查装配。

【为什么】偏置错一点电机照样转，但输出扭矩约按 cos(偏置误差角) 打折，多出来的电流全变成热；错到 90° 电角度，电机彻底不出力。每次上电偏置都在漂，等于每天都在开一台陌生的电机。

【你的情况怎么分析】校准失败/偏置乱跳的排查顺序：编码器原始读数是否干净（手转电机看读数单调递增）→ 磁钢与芯片同轴度 → 校准电流是否够（拖不动转子就加大校准电流，注意不超过相电流额定）。磁编码器对安装同轴度和相线电磁干扰敏感（第 5 章 传感与感知硬件），编码器线束远离大电流相线。

步骤 4：三环整定阶梯——从内到外，逐级驯服

【做什么】严格按 电流环 → 速度环 → 位置环 顺序整定，每级用阶跃验证通过再上一级。带宽按 5–10 倍递减（三环级联卡片的原则）：内环必须比外环快得多，外环才能把内环当成"理想执行器"。

  1. 电流环：按 R/L 估增益，或直接用驱动板自整定。极点配置估算式（工程常用起点，需按驱动板手册校核）：
L = 0.05 mH = 0.00005 H，R = 0.10 Ω，目标带宽 fc = 500 Hz
ωc = 2π × fc = 2π × 500 ≈ 3142 rad/s
Kp_i = L × ωc = 0.00005 × 3142 ≈ 0.16
Ki_i = R × ωc = 0.10 × 3142 ≈ 314

阶跃验证：给额定 30–50% 的电流阶跃，看上升时间（ms 级）与振铃——振铃多就降带宽。

  1. 速度环：带宽取电流环的 1/5–1/10（上例 500 Hz → 50–100 Hz，工程建议值）。给额定 20% 的小速度阶跃验证；增益过高的典型症状是电机啸叫（高频嗡嗡声），立刻降增益。
  2. 位置环：带宽再降 5–10 倍（10–20 Hz 量级，工程建议值）。30° 阶跃验证：超调 < 10%、稳态误差 < 0.5°（与 阶段 1 总览 判据一致，M07 会带载复测）。超调大先别急着降 P——加速度前馈往往更治本：位置指令变化时同步前馈一个速度指令，误差还没积累就被抵消。

【为什么】三环级联的物理意义：电流环管"出多大力"（扭矩 ∝ 电流），速度环管"转多快"，位置环管"停在哪"。外环带宽超过内环，等于让近视的人指挥显微镜——必然振荡。这是 PID 控制 在级联结构里的标准用法，理论见 第 14 章 机器人控制基础。

【你的情况怎么分析】驱动板自带电流环（Berkeley 固件、ODrive、moteus 都内置）：你的活主要是速度环与位置环。没有示波器：上位机录波功能（tview / odrivetool / 自定义日志）够用，采样率至少要高于被测环带宽 10 倍。舵机路线三环封闭在内部，本步骤退化为"读手册调寄存器"。

步骤 5：通信组网与参数归档

【做什么】

  1. CAN ID 分配：逐台单独上电，把默认 ID 改成分配表里的唯一 ID，贴标签（关节名 + ID），全部改完再组网。分配表成文，格式如"左髋 pitch = 0x01"。
  2. 统一波特率：全网同一速率。参考值：Berkeley 用 CAN 2.0 @ 1 Mbps，四肢各一条总线、经 USB-CAN 适配器接主控，单总线最多 64 台设备（调研档案）。
  3. 收发测试：上位机以 250 Hz 对全网关节做收发（对标 Berkeley 执行器与 IMU 通信 250 Hz，调研档案），连续 1 h 无掉线、无错误帧激增为通过（判据同 阶段 1 总览）。
  4. 参数归档：每台关节的最终参数（电机参数 + 偏置 + 三环增益 + ID）落盘成文件，git 仓库 + 表格双备份。

总线带载能力粗算（工程建议值，按你的帧长重算）：扩展帧满载约 130 µs/帧，6 台关节一条总线（Berkeley 每条肢体总线约 5–6 台）、250 Hz 双向收发 = 6 × 250 × 2 × 130 µs ≈ 占用 39%，健康；12 台全挂一条就逼近 80%，必须分总线。

【为什么】CAN 总线 多节点共享一对线，ID 冲突时两台设备同帧对发，错误帧滚雪球成总线风暴、全网瘫痪——而且现象是"随机掉线"，极难定位。参数归档则是 M07 与整机阶段的救命绳：22 台关节，三个月后没人记得 7 号关节的偏置。

【你的情况怎么分析】组网第一步永远是断电测 CANH-CANL 电阻：两端各 120 Ω 终端时应约 60 Ω——无穷大 = 终端没接，远低于 60 Ω = 接多了（同 阶段 1 总览 排查表）。通信协议与中间件选型见 第 22 章 软件中间件。

验收标准

  • [ ] 全部关节固件版本一致，版本号/commit 记录在案，出厂默认参数已备份。
  • [ ] 每台电机参数（极对数/R/L/KV）逐台登记，来源标注（手册/实测/自整定）。
  • [ ] 上电自动校准通过，连续 5 次重复校准偏置漂移 < 5° 电角度（或驱动板手册给定值），校准结果已写 flash。
  • [ ] 三环整定完成：空载 30° 阶跃超调 < 10%、稳态误差 < 0.5°，曲线存档。
  • [ ] CAN 组网完成：ID 分配表成文，250 Hz 收发连续 1 h 无掉线。
  • [ ] 全部参数落盘并双备份（git + 表格），可一键烧回任意一台关节。

组网后总线风暴、全网掉线 两台关节 ID 冲突 逐台单独上电改 ID、贴标签，再组网
电机高频啸叫、摸着发麻 速度环增益过高 速度环 Kp 降半试；确认其带宽 ≤ 电流环 1/5
偏置每次校准都漂移 磁钢松动 / 编码器安装偏心 检查磁钢胶合与同轴度，回 M05 修装配
电机反转、无力或嗡鸣不转 相序错 / 极对数填错 开环小电流旋转测试确认相序；重数磁钢

低速爬行、一顿一顿 电流环带宽太低 / 编码器分辨率不足 提电流环带宽；核对编码器位数与安装同轴度
