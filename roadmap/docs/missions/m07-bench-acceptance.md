# M07 · 台架测试与验收：数据说话，合格才准装机

**全局位置**：M06 固件与标定完成之后、整机阶段（M08 选型 / M09 装配）之前。输入是一台"能转"的关节模组，输出是一个**实测数据包**（曲线 + 结论）——并把 M01 指标表从"估算版"升级为"实测版"。六项测试全过，这台关节才准装机。本页把 [阶段 1 总览](../stage-1-actuator.md) 的步骤 7 展开到手把手级。

**前置条件**：M06 验收通过（三环调好、250 Hz 通信稳定）；型材台架、砝码杆与砝码、测温工具（红外测温枪或热电偶）齐备。

理论背景：测试方法见 [第 11 章 装配、集成与测试](/wiki/chapters/chapter-11/)，评测方法论见 [第 25 章 机器人评测体系](/wiki/chapters/chapter-25/)，控制判据见 [第 14 章 机器人控制基础](/wiki/chapters/chapter-14/)。

## 步骤 1：台架搭建——先保证台架自己不撒谎

【做什么】

1. **刚性固定**：铝型材 + 夹具把关节模组锁死，输出轴水平伸出。先做"手晃/敲击测试"：晃不动、敲击振动快速衰减、且台架固有频率与关节运动频率明显错开——台架共振会污染所有数据（见常见坑第 1 条）。
2. **砝码杆负载**：杆长从输出轴心量到砝码挂点，负载质量按峰值扭矩反推：

   ```
   m = τ_peak ÷ (g × L)
   算例：τ_peak = 8 N·m，杆长 L = 0.5 m
   m = 8 ÷ (9.81 × 0.5) ≈ 1.63 kg
   ```

   按 0 kg（空载）/ 0.8 kg（半载）/ 1.63 kg（满载）三档备砝码。
3. **记录链路**：驱动板上位机同步录角度/电流/温度，采样率 ≥ 控制频率（250 Hz，对标 Berkeley 通信速率，[Berkeley Humanoid Lite 论文](https://arxiv.org/html/2504.17249v1)）；每条曲线连同测试条件（负载档、固件版本、增益参数）存原始格式。

【为什么】台架不是配角，是测量仪器的一部分：夹具松 1 mm，阶跃曲线上就多一个假振铃；只存截图不存原始数据，三个月后无法复现分析。测得准的前提是"被测对象之外的一切都比它硬、比它稳"。

【你的情况怎么分析】没有铝型材：厚钢板 + 台虎钳也行，判据相同——手晃不动、敲击声脆。没有砝码：哑铃片、矿泉水瓶都行，但质量必须用秤实测，不许按标称值。砝码杆自重别漏：杆绕轴惯量 ≈ ⅓·m_杆·L²，要计入负载（见常见坑第 2 条）。

## 步骤 2：阶跃响应——刚性与阻尼的照妖镜

【做什么】给 30° 位置阶跃（砝码杆转到水平姿态时负载力矩最大），录角度曲线。判据（工程建议值，需按你的 M01 指标表回改；与 [阶段 1 总览](../stage-1-actuator.md) 一致）：

- 上升时间 < 0.2 s；
- 超调 < 10%（即峰值不超过 33°）；
- 稳态误差 < 0.5°。

空载 → 半载 → 满载三档各测 3 次，曲线全部存档。带载后上升变慢、超调变大是正常的；满载下任何一项超差，先回 M06 步骤 4 按实测惯量带载重整定，整定不动再怀疑指标本身。

【为什么】阶跃响应一次性暴露三件事：增益够不够（上升时间）、阻尼够不够（超调与振铃）、静差与重力/摩擦补偿行不行（稳态误差）。这三项直接决定整机阶段关节"跟不跟得上指令"。

【你的情况怎么分析】满载超调 15% 降不下去：先加重力前馈/摩擦补偿，再降位置环 P、补 D；还不行，重新核算负载惯量——惯量翻 4 倍，原增益必然振荡。髋、膝这类"支撑相吃整机冲击"的关节，建议满载档判据加严一档（如超调 < 5%，工程建议值），整机阶段会受益。

## 步骤 3：频率响应与带宽——它到底能不能当腿用

【做什么】

1. 先发 1 Hz、±20° 正弦位置指令。判据（工程建议值，同 [阶段 1 总览](../stage-1-actuator.md)）：幅值衰减 < 10%（输出峰-峰值 ≥ 36°）、相位滞后 < 15°。
2. 再扫频：0.5 → 1 → 2 → 5 → 10 → 20 Hz 逐档测输出/指令幅值比，找到幅值降到 70.7%（−3 dB）的频率——这就是**位置环带宽实测值**。

为什么带宽决定能不能当腿：行走时支撑相/摆动相每一步切换一次，步频 1–2 Hz 意味着关节每秒经历数次负载突变与指令反转，这些瞬态的频率分量远高于步频本身。位置环带宽只有几 Hz 时，支撑相切换瞬间关节"还在追上一个指令"，整机表现就是软脚、晃。腿部主关节带宽建议 ≥ 10 Hz 量级（工程建议值，需按你的步态频率校核）。

【为什么】阶跃看时域、扫频看频域，是同一个系统的两张照片；扫频把"响应能力"量化成可对比的硬指标，M01 指标表里的对应列就靠它升级成实测值。

【你的情况怎么分析】带宽不够的三板斧：提位置环增益（受超调约束）→ 加速度/速度前馈 → 检查机械背隙与编码器分辨率（非线性环节硬性限制带宽，调参无解）。高减速比舵机方案此项天然受限——拓扑决定的，如实记录并在指标表注明"不用于动态行走"。

## 步骤 4：反驱与力透明（QDD/直驱必做）

【做什么】[准直驱（QDD）](/entry/ent_technology_quasi_direct_drive_actuator_2024/) 与直驱方案加测三项；高减速比方案（舵机/谐波）此项直接记"不合格——拓扑决定"，不必硬测。

1. **断电反驱**：断电手掰输出轴，应顺滑无卡滞、无明显齿槽顿挫。
2. **零刚度拖动**：上电设零刚度（位置增益 = 0、小阻尼），应能"零重力"拖动输出轴——这是 [阻抗控制](/entry/ent_method_impedance_control/) 的退化形态，也是后续力控的入场券。
3. **电流-扭矩标定（测 Kt）**：挂已知砝码静止保持，记稳态相电流，反推实测扭矩常数：

   ```
   Kt_输出 = τ ÷ I = (m × g × L) ÷ I
   算例：m = 1.63 kg，L = 0.5 m → τ = 1.63 × 9.81 × 0.5 ≈ 8.0 N·m
   测得稳态相电流 I = 5.2 A
   Kt_输出 = 8.0 ÷ 5.2 ≈ 1.54 N·m/A
   ```

   与理论值（电机 Kt × 减速比 × 效率，M02 手册值）对比，偏差 > 10% 要查因（工程建议值）：电流采样标定错、摩擦吃掉扭矩、或手册 Kt 注水。
4. **双编码器方案**：同步记录电机端与输出端 [关节编码器](/entry/ent_component_joint_encoder_2024/) 读数，两者之差 = 减速器形变 + 背隙——ODRI 正是靠这对差值做本体感知力控（[ODRI 执行器硬件仓库](https://github.com/open-dynamic-robot-initiative/open_robot_actuator_hardware)）。空载差值近似背隙，带载差值增量近似减速器刚度形变，都写进数据包。

【为什么】力透明是 QDD 存在的意义："电流 ≈ 扭矩"这条等式成立，后续阻抗/力控才不需要额外力矩传感器。Kt 偏差大却照用手册值，整机力控前馈就全是错的。

【你的情况怎么分析】断电掰不动：查减速器装配过紧（回 M05）或拓扑本身不可反驱。零刚度拖动"一顿一顿"：多为齿槽转矩 + 摩擦未补偿，加小量电流前馈补偿，补偿量记入数据包（整机阶段直接复用）。

## 步骤 5：温升与耐久——时间是照妖镜

【做什么】

1. **温升**：额定负载（半载砝码持续跟踪 1 Hz 正弦，或按你 M01 的占空比等效）连续运行 30 min，记录壳温曲线。判据：壳温 < 60 °C（工程建议值；绝缘等级上限需自行向电机供应商确认）。测试环境温度一并记录，夏天复测按温升差值折算。
2. **耐久抽测**：Berkeley 用 60 小时连续运行验证 3D 打印摆线齿轮可靠性（[arXiv:2504.17249](https://arxiv.org/abs/2504.17249)）——自研减速器按此量级抽测：首件跑 60 h，量产件抽 10% 跑 10–20 h（工程建议流程）。跑完拆检齿面磨损，复测背隙与空载电流，与首件基线对比。
3. **效率粗测**：匀速大负载工况下，输入电功率 vs 输出机械功率：

   ```
   η = (τ × ω) ÷ (V × I)
   算例：输出 τ = 4 N·m、ω = 3 rad/s → 机械功率 12 W
   输入 24 V × 1.0 A = 24 W
   η = 12 ÷ 24 ≈ 50%
   ```

   这是减速器 + 电机 + 驱动的总效率，量级参考值，需按你的系统校核。

【为什么】阶跃过关只说明"瞬间能打"，温升与耐久说明"能不能一直打"——行走是分钟到小时级的连续工况，热余量不够 = 走两步就过热降额。效率直接决定 M09 电池选型与续航估算。热设计背景见 [第 6 章 计算、电源与热管理](/wiki/chapters/chapter-06/)。

【你的情况怎么分析】没有温度传感器：红外测温枪测壳体 + 驱动板内建温度读数双记录。30 min 撑不下来：逐步降持续电流限幅，找到"能撑满 30 min 的电流"，反推实际可用的持续扭矩——这个数才是 M01 指标表该写的额定值。

## 步骤 6：数据回写与放行决策

【做什么】

1. 把实测值逐项填回 [M01 指标表](m01-scenario-to-specs.md)：峰值扭矩（实测 Kt × 限流）、带宽、背隙、持续扭矩、效率——"估算版"升级"实测版"。
2. 超差项逐条处置，三条路选一：性能不够 → **换电机**（回 M02）；响应或扭矩不匹配 → **改减速比**（回 M03）；指标本身定高了 → **改指标**（回 M01，必须写书面理由："为什么降指标不影响任务书"）。
3. 全部达标后输出书面结论"该关节模组可装机"，附数据包索引（曲线目录 + 参数版本 + 台架照片 + 接线图）。

【为什么】回写是把经验变成资产：22 台关节的实测分布（Kt、背隙、温升）是整机仿真（M10/M11）执行器模型参数化的第一手数据——仿真用实测值，sim-to-real 的坑少一半。

【你的情况怎么分析】22 台逐台全测太累：首 3 台全测六项，其余测阶跃 + 温升 + Kt 三项关键项，数据分布与首件比对，离群个体再补全测（工程建议流程，按你的批量调整）。数据包命名一次定好：`关节编号_测试项_日期_固件版本`。

## 验收标准

- [ ] 六项测试（阶跃/正弦/扫频/反驱与 Kt/温升/耐久）曲线全部以原始格式存档，测试条件齐全。
- [ ] 30° 阶跃三档负载：上升时间 < 0.2 s、超调 < 10%、稳态误差 < 0.5°（或指标表自定值）。
- [ ] 1 Hz ±20° 正弦：幅值衰减 < 10%、相位滞后 < 15°；−3 dB 带宽有实测数值。
- [ ] QDD/直驱方案：零刚度拖动顺滑，实测 Kt 与理论值偏差 ≤ 10% 或偏差原因已查明；双编码器差值（背隙 + 形变）已量化。
- [ ] 额定负载 30 min 壳温 < 60 °C（或供应商上限内）；减速器耐久抽测完成并有拆检记录。
- [ ] M01 指标表升级为"实测版"，全部回写差异有处置结论（换电机/改减速比/改指标，含书面理由）。
- [ ] "可装机"结论书面化，台架照片与接线图存档。

## 常见坑与排查

| 症状 | 可能原因 | 排查动作 |
|---|---|---|
| 阶跃曲线上有固定频率的抖动 | 台架共振被误判为关节振荡 | 加固夹具/台架加配重复测；敲击台架听固有频率 |
| 带宽远低于 M06 空载调试值 | 砝码杆与砝码惯量被忽略 | ⅓·m_杆·L² + m_码·L² 计入负载，重新整定 |
| 两次温升结果对不上 | 环境温度/气流不固定 | 固定环境温度与摆放并记录室温；按温升差值折算 |
| 空载全过、装机就翻车 | 只测空载就宣布合格 | 三档负载是硬要求，满载不过 = 不合格 |
| 数据无法复现分析 | 只存截图、没存原始数据 | 原始格式（csv/日志）连同固件版本、参数一起存 |
| Kt 实测比手册小很多 | 摩擦未补偿 / 误读电源电流当相电流 | 确认读相电流；正反向各测一次取平均消摩擦 |
| 耐久测试后背隙变大 | 打印齿轮磨损 / 轴承游隙变大 | 拆检齿面；对照 Berkeley 60 h 量级评估换材料/工艺 |
