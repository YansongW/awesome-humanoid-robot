# M07 · 대형 테스트 및 검수: 데이터로 말한다, 합격해야 조립 가능

**전체 위치**: M06 펌웨어 및 캘리브레이션 완료 후, 전체 로봇 단계(M08 선정 / M09 조립) 이전. 입력은 "회전 가능한" 관절 모듈이며, 출력은 **실측 데이터 패키지**(곡선 + 결론)입니다. 그리고 M01 지표표를 "추정 버전"에서 "실측 버전"으로 업그레이드합니다. 6가지 테스트를 모두 통과해야 이 관절이 조립될 수 있습니다. 이 페이지는 [1단계 개요](../stage-1-actuator.md)의 7단계를 세부적으로 설명합니다.

**전제 조건**: M06 검수 통과(3루프 조정 완료, 250 Hz 통신 안정); 프로파일 대형, 추봉과 추, 온도 측정 도구(적외선 온도계 또는 열전대) 준비 완료.

이론적 배경: 테스트 방법은 [제11장 조립, 통합 및 테스트](/wiki/chapters/chapter-11/)를 참조, 평가 방법론은 [제25장 로봇 평가 시스템](/wiki/chapters/chapter-25/)을 참조, 제어 판단 기준은 [제14장 로봇 제어 기초](/wiki/chapters/chapter-14/)를 참조.

## 1단계: 대형 구축——먼저 대형 자체가 거짓말하지 않도록 보장

【수행 사항】

1. **강성 고정**: 알루미늄 프로파일 + 클램프로 관절 모듈을 고정하고, 출력축을 수평으로 돌출시킵니다. 먼저 "손으로 흔들기/타격 테스트"를 수행: 흔들리지 않고, 타격 시 진동이 빠르게 감쇠하며, 대형 고유 진동수와 관절 운동 주파수가 명확히 분리되어야 함——대형 공진은 모든 데이터를 오염시킵니다(일반적인 문제 1번 참조).
2. **추봉 부하**: 봉 길이는 출력축 중심에서 추 걸이 지점까지 측정, 부하 질량은 최대 토크로 역산:

   ```
   m = τ_peak ÷ (g × L)
   예시: τ_peak = 8 N·m, 봉 길이 L = 0.5 m
   m = 8 ÷ (9.81 × 0.5) ≈ 1.63 kg
   ```

   0 kg(무부하) / 0.8 kg(반부하) / 1.63 kg(만부하) 3단계로 추 준비.
3. **기록 링크**: 드라이브 보드 상위 컴퓨터가 각도/전류/온도를 동기 녹화, 샘플링 속도 ≥ 제어 주파수(250 Hz, Berkeley 통신 속도 기준, `data/roadmap/research/berkeley-humanoid-lite.md`); 각 곡선은 테스트 조건(부하 단계, 펌웨어 버전, 게인 파라미터)과 함께 원시 형식으로 저장.

【이유】대형은 조연이 아니라 측정 장비의 일부: 클램프가 1 mm 느슨해지면 계단 응답 곡선에 가짜 링잉이 추가됨; 스크린샷만 저장하고 원시 데이터를 저장하지 않으면 3개월 후 재현 분석 불가. 정확한 측정의 전제는 "측정 대상 외의 모든 것이 그것보다 단단하고 안정적"이어야 함.

【상황 분석 방법】알루미늄 프로파일 없음: 두꺼운 강판 + 바이스도 가능, 판단 기준 동일——손으로 흔들리지 않고, 타격음이 맑음. 추 없음: 덤벨 원판, 생수병도 가능, 하지만 질량은 저울로 실측해야 하며, 명목 값 사용 금지. 추봉 자체 중량을 빼먹지 마세요: 봉의 회전 관성 ≈ ⅓·m_봉·L², 부하에 포함해야 함(일반적인 문제 2번 참조).

## 2단계: 계단 응답——강성과 댐핑의 거울

【수행 사항】30° 위치 계단 명령(추봉이 수평 자세로 회전할 때 부하 토크 최대), 각도 곡선 기록. 판단 기준(공학 권장값, M01 지표표에 따라 수정 필요; [1단계 개요](../stage-1-actuator.md)와 일치):

- 상승 시간 < 0.2 s;
- 오버슈트 < 10%(즉, 최대값이 33°를 초과하지 않음);
- 정상 상태 오차 < 0.5°.

무부하 → 반부하 → 만부하 3단계 각각 3회 측정, 곡선 모두 보관. 부하 후 상승 시간 증가, 오버슈트 증가는 정상; 만부하에서 항목 중 하나라도 초과 시, 먼저 M06 4단계로 돌아가 실측 관성에 따라 부하 재튜닝, 튜닝이 안 되면 지표 자체를 의심.

【이유】계단 응답은 한 번에 세 가지를 드러냄: 게인 충분 여부(상승 시간), 댐핑 충분 여부(오버슈트 및 링잉), 정적 오차 및 중력/마찰 보상 작동 여부(정상 상태 오차). 이 세 가지는 전체 로봇 단계에서 관절이 "명령을 따라갈 수 있는지"를 직접 결정.

【상황 분석 방법】만부하 오버슈트 15% 감소 불가: 먼저 중력 피드포워드/마찰 보상 강화, 그다음 위치 루프 P 낮추고 D 보충; 그래도 안 되면 부하 관성 재계산——관성이 4배 증가하면 원래 게인은 반드시 진동. 엉덩이, 무릎과 같은 "지지 상에서 전체 로봇 충격을 받는" 관절은 만부하 단계 판단 기준을 한 단계 강화(예: 오버슈트 < 5%, 공학 권장값)하는 것이 좋으며, 전체 로봇 단계에서 이점을 얻음.

## 3단계: 주파수 응답 및 대역폭——과연 다리로 사용할 수 있는가

【수행 사항】

1. 먼저 1 Hz, ±20° 사인파 위치 명령 전송. 판단 기준(공학 권장값, [1단계 개요](../stage-1-actuator.md)와 동일): 진폭 감쇠 < 10%(출력 피크-피크 ≥ 36°), 위상 지연 < 15°.
2. 그다음 주파수 스윕: 0.5 → 1 → 2 → 5 → 10 → 20 Hz 단계별로 출력/명령 진폭비 측정, 진폭이 70.7%(−3 dB)로 감소하는 주파수 찾기——이것이 **위치 루프 대역폭 실측값**.

대역폭이 다리로 사용 가능한지 결정하는 이유: 보행 시 지지 상/스윙 상이 매 걸음마다 전환, 보행 주파수 1–2 Hz는 관절이 초당 여러 번의 부하 급변과 명령 반전을 경험함을 의미, 이러한 과도 상태의 주파수 성분은 보행 주파수 자체보다 훨씬 높음. 위치 루프 대역폭이 몇 Hz에 불과하면, 지지 상 전환 순간 관절이 "여전히 이전 명령을 추종"하여 전체 로봇은 다리가 약하고 흔들리는 현상 발생. 다리 주요 관절 대역폭은 ≥ 10 Hz 수준 권장(공학 권장값, 보행 주파수에 따라 검증 필요).

【이유】계단 응답은 시간 영역, 주파수 스윕은 주파수 영역을 보며, 동일한 시스템의 두 가지 사진; 주파수 스윕은 "응답 능력"을 비교 가능한 하드 지표로 정량화, M01 지표표의 해당 열이 이를 통해 실측값으로 업그레이드됨.

【상황 분석 방법】대역폭 부족 시 세 가지 방법: 위치 루프 게인 증가(오버슈트 제약 받음) → 가속도/속도 피드포워드 → 기계적 백래시 및 엔코더 해상도 확인(비선형 요소가 대역폭을 하드 제한, 파라미터 튜닝 불가). 고감속비 서보 모터 방식은 이 항목이 본질적으로 제한됨——토폴로지에 의해 결정, 사실대로 기록하고 지표표에 "동적 보행에 사용 불가" 명시.

## 4단계: 역구동 및 힘 투명성(QDD/직구동 필수)

【수행 사항】[준직구동(QDD)](/entry/ent_technology_quasi_direct_drive_actuator_2024/) 및 직구동 방식은 세 가지 추가 측정; 고감속비 방식(서보/하모닉)은 이 항목을 바로 "불합격——토폴로지 결정"으로 기록, 굳이 측정할 필요 없음.

1. **전원 차단 역구동**: 전원 차단 후 출력축을 손으로 돌림, 부드럽고 걸림 없으며, 명백한 코깅 토크 없어야 함.
2. **제로 강성 드래깅**: 전원 켜고 제로 강성 설정(위치 게인 = 0, 작은 댐핑), 출력축을 "무중력"으로 드래깅 가능해야 함——이것은 [임피던스 제어](/entry/ent_method_impedance_control/)의 퇴화 형태이자, 이후 힘 제어의 입장권.
3. **전류-토크 캘리브레이션(Kt 측정)**: 알려진 추를 매달아 정지 유지, 정상 상태 상전류 기록, 실측 토크 상수 역산:

   ```
   Kt_출력 = τ ÷ I = (m × g × L) ÷ I
   예시: m = 1.63 kg, L = 0.5 m → τ = 1.63 × 9.81 × 0.5 ≈ 8.0 N·m
   측정된 정상 상태 상전류 I = 5.2 A
   Kt_출력 = 8.0 ÷ 5.2 ≈ 1.54 N·m/A
   ```

   이론값(모터 Kt × 감속비 × 효율, M02 매뉴얼 값)과 비교, 편차 > 10%이면 원인 조사(공학 권장값): 전류 샘플링 캘리브레이션 오류, 마찰이 토크 소모, 또는 매뉴얼 Kt 부풀리기.
4. **듀얼 엔코더 방식**: 모터 측과 출력 측 [관절 엔코더](/entry/ent_component_joint_encoder_2024/) 판독값 동기 기록, 두 값의 차이 = 감속기 변형 + 백래시——ODRI는 바로 이 차이값을 이용해 본체 감지 힘 제어 수행(`data/roadmap/research/open-dynamic-robot-initiative.md`). 무부하 차이는 백래시에 근사, 부하 차이 증가분은 감속기 강성 변형에 근사, 모두 데이터 패키지에 기록.

【이유】힘 투명성은 QDD의 존재 의의: "전류 ≈ 토크" 등식이 성립해야, 이후 임피던스/힘 제어에 추가 토크 센서가 필요 없음. Kt 편차가 큰데도 매뉴얼 값을 그대로 사용하면, 전체 로봇 힘 제어 피드포워드가 모두 잘못됨.

【상황 분석 방법】전원 차단 후 돌리기 어려움: 감속기 조립 과도 조임(M05로 돌아감) 또는 토폴로지 자체가 역구동 불가 확인. 제로 강성 드래깅이 "뚝뚝 끊김": 대부분 코깅 토크 + 마찰 미보상, 소량의 전류 피드포워드 보상 추가, 보상량은 데이터 패키지에 기록(전체 로봇 단계에서 직접 재사용).

## 5단계: 온도 상승과 내구성 – 시간은 거울이다

【수행할 작업】

1. **온도 상승**: 정격 부하(반부하 추를 사용하여 1 Hz 사인파를 지속적으로 추적하거나 M01의 듀티 사이클에 따라 동등한 조건)에서 30분 연속 운전 후 케이스 온도 곡선을 기록합니다. 기준: 케이스 온도 < 60 °C (엔지니어링 권장 값; 절연 등급 상한은 모터 공급업체에 직접 확인 필요). 시험 환경 온도를 함께 기록하고, 여름 재시험 시 온도 상승 차이를 기준으로 보정합니다.
2. **내구성 샘플링 테스트**: Berkeley는 60시간 연속 운전으로 3D 프린팅 사이클로이드 기어의 신뢰성을 검증했습니다 (`data/roadmap/research/berkeley-humanoid-lite.md`). 자체 개발 감속기는 이 수준으로 샘플링 테스트를 수행합니다: 첫 번째 부품은 60시간, 양산 부품의 10%는 10–20시간 운전 (엔지니어링 권장 절차). 운전 후 기어 이면 마모를 점검하고, 백래시와 무부하 전류를 재측정하여 첫 번째 부품의 기준선과 비교합니다.
3. **효율 개략 측정**: 등속 대부하 조건에서 입력 전력 대 출력 기계적 전력:

   ```
   η = (τ × ω) ÷ (V × I)
   계산 예시: 출력 τ = 4 N·m, ω = 3 rad/s → 기계적 전력 12 W
   입력 24 V × 1.0 A = 24 W
   η = 12 ÷ 24 ≈ 50%
   ```

   이는 감속기 + 모터 + 드라이브의 총 효율이며, 대략적인 참고 값으로 시스템에 맞게 검증해야 합니다.

【이유】계단 응답 통과는 "순간적으로 힘을 낼 수 있다"는 것을 의미할 뿐, 온도 상승과 내구성은 "계속해서 힘을 낼 수 있는지"를 의미합니다. 보행은 분에서 시간 단위의 연속적인 작업 조건이며, 열 여유가 부족하면 몇 걸음만 걸어도 과열로 출력이 제한됩니다. 효율은 M09 배터리 선정과 주행 거리 추정을 직접적으로 결정합니다. 열 설계 배경은 [6장 계산, 전원 및 열 관리](/wiki/chapters/chapter-06/)를 참조하십시오.

【상황 분석 방법】온도 센서 없음: 적외선 온도 측정 총으로 케이스 온도를 측정하고, 드라이브 보드 내장 온도 판독값을 함께 기록합니다. 30분을 버티지 못할 경우: 지속 전류 제한을 점진적으로 낮추어 "30분을 버틸 수 있는 전류"를 찾고, 이를 통해 실제 사용 가능한 지속 토크를 역산합니다. 이 값이 M01 사양표에 기재되어야 하는 정격 값입니다.

## 6단계: 데이터 기록 및 출하 결정

【수행할 작업】

1. 측정값을 [M01 사양표](m01-scenario-to-specs.md)에 항목별로 채워 넣습니다: 최대 토크(실측 Kt × 전류 제한), 대역폭, 백래시, 지속 토크, 효율 – "추정 버전"을 "실측 버전"으로 업그레이드합니다.
2. 공차를 벗어난 항목은 개별적으로 처리하며, 세 가지 경로 중 하나를 선택합니다: 성능 부족 → **모터 교체** (M02로 복귀); 응답 또는 토크 불일치 → **감속비 변경** (M03으로 복귀); 사양 자체가 너무 높게 설정됨 → **사양 변경** (M01로 복귀, 서면 사유 필수: "사양을 낮추어도 작업 설명서에 영향을 미치지 않는 이유").
3. 모든 항목이 기준을 충족하면 "해당 관절 모듈은 장착 가능"이라는 서면 결론을 출력하고, 데이터 패키지 색인(곡선 디렉토리 + 파라미터 버전 + 테스트 벤치 사진 + 배선도)을 첨부합니다.

【이유】데이터 기록은 경험을 자산으로 전환합니다: 22개 관절의 실측 분포(Kt, 백래시, 온도 상승)는 전체 로봇 시뮬레이션(M10/M11) 액추에이터 모델 파라미터화를 위한 일차 데이터입니다. 시뮬레이션에 실측값을 사용하면 sim-to-real 문제의 절반을 줄일 수 있습니다.

【상황 분석 방법】22개 관절을 모두 테스트하는 것은 너무 힘듭니다: 처음 3개 관절은 6개 항목을 모두 테스트하고, 나머지는 계단 응답 + 온도 상승 + Kt의 세 가지 핵심 항목만 테스트합니다. 데이터 분포를 첫 번째 부품과 비교하고, 이상치 개체에 대해서만 전체 테스트를 추가로 수행합니다 (엔지니어링 권장 절차, 배치에 따라 조정). 데이터 패키지 명명 규칙을 한 번에 정합니다: `관절번호_테스트항목_날짜_펌웨어버전`.

## 합격 기준

- [ ] 6가지 테스트(계단 응답/사인파/주파수 스윕/역구동 및 Kt/온도 상승/내구성) 곡선이 모두 원시 형식으로 보관되었으며, 테스트 조건이 완비되었습니다.
- [ ] 30° 계단 응답, 세 가지 부하 수준: 상승 시간 < 0.2초, 오버슈트 < 10%, 정상 상태 오차 < 0.5° (또는 사양표 자체 설정 값).
- [ ] 1 Hz ±20° 사인파: 진폭 감쇠 < 10%, 위상 지연 < 15°; −3 dB 대역폭 실측 값 있음.
- [ ] QDD/직구동 방식: 제로 강성에서 부드럽게 구동 가능, 실측 Kt와 이론 값 편차 ≤ 10% 또는 편차 원인 파악 완료; 이중 엔코더 차이(백래시 + 변형) 정량화 완료.
- [ ] 정격 부하 30분 케이스 온도 < 60 °C (또는 공급업체 상한 이내); 감속기 내구성 샘플링 테스트 완료 및 분해 검사 기록 있음.
- [ ] M01 사양표가 "실측 버전"으로 업그레이드되었으며, 모든 기록 차이에 대한 처리 결론(모터 교체/감속비 변경/사양 변경, 서면 사유 포함)이 있습니다.
- [ ] "장착 가능" 결론이 문서화되었으며, 테스트 벤치 사진과 배선도가 보관되었습니다.

## 일반적인 문제점 및 점검

| 증상 | 가능한 원인 | 점검 조치 |
|---|---|---|
| 계단 응답 곡선에 고정 주파수의 떨림 발생 | 테스트 벤치 공진을 관절 진동으로 오인 | 고정구/테스트 벤치 보강 후 재측정; 테스트 벤치를 두드려 고유 진동수 확인 |
| 대역폭이 M06 무부하 튜닝 값보다 훨씬 낮음 | 추 봉과 추의 관성 무시 | ⅓·m_봉·L² + m_추·L² 를 부하에 포함시켜 재튜닝 |
| 두 번의 온도 상승 결과가 일치하지 않음 | 환경 온도/기류 불안정 | 환경 온도와 배치를 고정하고 실온 기록; 온도 상승 차이로 보정 |
| 무부하에서는 모두 통과했지만 장착 시 문제 발생 | 무부하만 테스트하고 합격 판정 | 세 가지 부하 수준은 필수 요구 사항, 최대 부하 통과 실패 = 불합격 |
| 데이터 재현 분석 불가 | 스크린샷만 저장하고 원시 데이터 미저장 | 원시 형식(csv/로그)을 펌웨어 버전, 파라미터와 함께 저장 |
| 실측 Kt가 매뉴얼보다 훨씬 작음 | 마찰 미보상 / 전원 전류를 상전류로 오독 | 상전류 확인; 정방향과 역방향 각각 측정 후 평균 내어 마찰 제거 |
| 내구성 테스트 후 백래시 증가 | 프린팅 기어 마모 / 베어링 유격 증가 | 기어 이면 분해 검사; Berkeley 60시간 수준과 비교하여 재료/공정 변경 평가 |
